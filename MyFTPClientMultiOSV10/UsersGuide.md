# My FTP Client — 사용자 가이드

## 1. 화면 구성

```
┌ 🔷 My FTP Client │ ● ftp://…  Profile [ 프로파일 ▾ ] 💾 🗑   …  🎨 ▾ 🇬🇧 ⚙ ⓘ │ ─ □ ✕ ┐
│ Protocol  Host              Port   User      Password        🕘▾  [ Connect ] │
├──────────────────────────┬────┬───────────────────────────────────────────────┤
│ 서버 (Server) │ /pub     │ ←  │ 로컬 (Local) │ C:\Users\me\Documents              │
│  [..]                    │    │  ▸ 로컬 디스크 (C:)                             │
│  📁 images    <DIR>      │ →  │    ▾ Users                                      │
│  📄 data.json   11 B     │    │      ▾ me                                       │
│  …                       │    │        ▾ Documents  ◀ 현재 로컬 폴더            │
├──────────────────────────┴────┴───────────────────────────────────────────────┤
│ 로그 (Log)                                                             ⧉  ⌫  │
│ [16:49:29]  연결 성공: ftp://127.0.0.1:21                                      │
├───────────────────────────────────────────────────────────────────────────────┤
│ 다운로드: video.mp4  63%  12.4 MB/s  (1/2)      1.2 MB / 1.9 MB ▓▓▓░ 취소   ⠿ │
└───────────────────────────────────────────────────────────────────────────────┘
```

| 영역 | 설명 |
|------|------|
| 툴바 | OS 타이틀바를 대신합니다. 앱 이름, 현재 연결(녹색 점), **프로파일**(선택 · 💾 저장 · 🗑 삭제), 테마(클릭 = 다음 테마, ▾ = 16개 목록), 언어 국기(전환할 언어의 국기), 설정, 정보, 그리고 데스크톱 앱에서는 **─ 최소화 · □ 최대화/이전 크기 · ✕ 닫기**. 빈 곳을 드래그하면 창이 움직이고, 더블클릭하면 최대화/복원됩니다. 창의 최소 크기는 1120×760 이며 이 크기에서도 모든 항목이 보입니다 |
| 접속 바 | 프로토콜(FTP/FTPS/SFTP) · 호스트 · 포트 · 사용자 · 비밀번호 · **🕘 접속 히스토리** · **Connect**(연결되면 빨간 **Disconnect**) |
| 서버 패널 | 서버의 현재 폴더 내용. `[..]` = 상위 폴더. 폴더 먼저, 이름순 |
| 전송 바 | **←** 로컬 → 서버 업로드, **→** 서버 → 로컬 다운로드. 바를 드래그하면 패널 너비가 바뀝니다 |
| 로컬 패널 | 드라이브(볼륨 이름) → 폴더 → 파일 트리. 제목 옆 **드라이브 버튼**(`OS (C:) ▾`)으로 다른 드라이브/홈으로 바로 전환(다른 드라이브는 접히고 선택한 드라이브가 맨 위에 펼쳐짐). 선택한 폴더(파일이면 그 폴더)가 다운로드 대상입니다 |
| 로그 | 시간이 붙은 이벤트 기록. ⧉ 복사, ⌫ 지우기. 위의 가로 바를 드래그하면 높이 조절 |
| 상태 표시줄 | 현재 상태, 전송 중이면 진행률 · 속도 · 바이트 · **취소**. 오른쪽 끝 **⠿ 크기 조절 마커**를 드래그하면 창 크기가 바뀝니다(창 가장자리도 드래그 가능) |

## 2. 서버에 연결하기

1. **Protocol** 을 고릅니다. 포트는 프로토콜에 맞게 바뀝니다 (FTP/FTPS 21, SFTP 22). 다른 포트를 쓰면 직접 입력하세요.
2. **Host**, **User**, **Password** 를 입력합니다. FTP 에서 User 를 비우면 anonymous 로 접속합니다.
   - Host 에 `ftp://ftp.example.com/pub` 이나 `sftp://user:pw@host:2222` 처럼 **URL 을 그대로 붙여 넣어도** 됩니다 — 프로토콜·호스트·포트·사용자·비밀번호로 자동 분해되고 경로는 무시됩니다.
3. **Connect** 를 누르거나 입력란에서 **Enter** 를 칩니다.
   - 연결 중에는 상태 표시줄에 진행 표시가 나오며 **취소** 할 수 있습니다. 30초 안에 연결되지 않으면 시간 초과입니다.
   - 성공하면 알림음과 함께 안내 창이 뜨고(설정에서 끌 수 있음) 서버의 `/` 가 표시됩니다.
   - 실패하면 오류 창에 원인과 자세한 내용이 표시됩니다. **자세한 내용 복사** 로 클립보드에 복사할 수 있습니다.
4. **Disconnect** 로 연결을 끊습니다. 앱을 닫아도 연결은 정리됩니다.

> **FTPS** 는 명시적 TLS(AUTH TLS) 를 사용하고 서버 인증서를 검증하지 않습니다(원본 WinForms 판과 동일).
> **SFTP** 는 비밀번호 인증(키보드 인터랙티브 포함)을 지원합니다.

## 3. 프로파일 (툴바) 와 접속 히스토리

- **💾 저장**: 현재 접속 정보를 이름을 붙여 저장합니다. 같은 이름이면 덮어씁니다.
- 목록에서 프로파일을 고르면 접속 정보가 채워집니다. 마지막에 고른 프로파일은 다음 실행 때 자동으로 채워집니다.
- **🗑 삭제**: 목록 창에서 여러 개를 체크한 뒤 삭제합니다 (확인 창이 뜹니다).
- **🕘 접속 히스토리** (Connect 왼쪽): 프로파일로 저장하지 않았더라도 **연결에 성공한 서버는 모두 기록**됩니다(최근 20개, 최신순, 접속 횟수·시각 표시). 항목을 고르면 프로토콜·호스트·포트·사용자가 채워지고, 같은 서버의 프로파일이 있으면 비밀번호도 채워집니다. 히스토리에는 비밀번호가 저장되지 않습니다. 목록 끝의 **히스토리 지우기**로 비웁니다.

## 4. 파일 탐색

**서버 패널**
- 폴더 더블클릭 / Enter: 폴더로 이동. `[..]` 더블클릭 또는 **Backspace**: 상위 폴더.
- 파일 더블클릭 / Enter: 현재 로컬 폴더로 다운로드.
- **Ctrl+클릭** / **Shift+클릭** 으로 여러 항목 선택, **Ctrl+A** 전체 선택, **F5** 새로 고침.

**로컬 패널**
- ▸ 를 클릭하거나 폴더를 더블클릭하면 펼쳐집니다. **→ / ←** 키로 펼치기/접기.
- 파일 더블클릭 / Enter: 서버의 현재 폴더로 업로드.
- 항목을 선택하면 그 폴더가 **현재 로컬 폴더**(다운로드 대상)가 되며 패널 제목 옆과 상태 표시줄에 표시됩니다. 이 폴더는 다음 실행 때 복원됩니다.

## 5. 업로드 / 다운로드

| 방법 | 동작 |
|------|------|
| 서버에서 항목 선택 → **→** 버튼 | 선택한 파일/폴더를 현재 로컬 폴더로 다운로드 |
| 로컬에서 항목 선택 → **←** 버튼 | 선택한 파일/폴더를 서버의 현재 폴더로 업로드 |
| 더블클릭 | 파일 하나를 바로 전송 |
| 오른쪽 클릭 → 다운로드 / 업로드 | 컨텍스트 메뉴 |

- 폴더는 하위 폴더까지 통째로 전송됩니다. 전송 전에 전체 파일 수와 크기를 계산해 진행률(%)과 속도를 보여 줍니다.
- 상태 표시줄의 **취소** 로 언제든 중단할 수 있습니다. 진행 중이던 파일은 불완전하게 남을 수 있습니다.
- **같은 이름의 파일이 이미 있으면** 충돌 창이 뜹니다:
  - **덮어쓰기** / **건너뛰기** / **취소**
  - "이후 항목에도 동일하게 적용" 을 체크하면 남은 파일에 같은 답을 적용합니다.
- 전송 중에는 **파일마다 로그 한 줄**(`↓ 원본 → 대상  크기  소요 시간 (속도)`, 건너뛴 파일은 그렇게 표시)이 남고, 끝나면 알림음과 함께 결과(파일 수, 건너뛴 수)가 기록되며 해당 패널이 새로 고쳐집니다.

## 6. 컨텍스트 메뉴 (오른쪽 클릭)

**서버**: 다운로드 · 새로 고침 · 상위 폴더로 · 새 폴더 · 이름 바꾸기 · 삭제 · 경로 복사
**로컬**: 업로드 · 새로 고침 · 탐색기에서 열기(데스크톱 앱만) · 열기 · 새 폴더 · 이름 바꾸기 · 삭제 · 경로 복사

- 서버의 삭제는 되돌릴 수 없습니다. 로컬의 삭제는 휴지통을 거치지 않고 바로 지웁니다. (설정에서 확인 창을 끌 수 있습니다.)
- 드라이브(트리 최상위)는 이름을 바꾸거나 삭제할 수 없습니다.

## 7. 설정 (툴바 ⚙)

| 항목 | 내용 |
|------|------|
| 언어 | 한국어 / English (툴바의 국기 버튼과 같음) |
| 테마 | 16가지 (어두운 10, 밝은 6) |
| 글꼴 크기 | 11 ~ 18 px |
| 삭제 전에 확인 | 삭제 확인 창 표시 |
| 시작할 때 마지막 로컬 폴더 복원 | 끄면 홈 폴더에서 시작 |
| 성공/오류 알림음 | 연결·전송 성공(두 음), 오류(낮은 음) |
| 연결 성공 시 안내 창 표시 | 연결 정보 요약 창 |

## 8. 웹 버전

```bash
npm run web                     # http://127.0.0.1:5188 — 같은 컴퓨터에서만 접속
node server/server.js --host 0.0.0.0 --port 8080 --token 비밀값 --no-open
```

- 브라우저 UI 는 데스크톱 앱과 같습니다. "로컬" 은 **서버 프로그램이 실행되는 컴퓨터**의 파일이고, FTP/SFTP 연결도 그 컴퓨터에서 이루어집니다.
- 다른 컴퓨터에서 쓰려면 반드시 `--token` 을 주고 `http://주소:포트/?token=비밀값` 으로 접속하세요. 서버 API 는 그 컴퓨터의 파일을 읽고 쓸 수 있습니다.
- 브라우저에서는 "탐색기에서 열기" 와 "열기" 를 쓸 수 없습니다.

## 9. 데이터 파일과 문제 해결

| 파일 | 위치 (Windows / macOS / Linux) |
|------|------|
| `session.json` (설정, 마지막 폴더, 창 위치) | `%APPDATA%\My FTP Client\` / `~/Library/Application Support/My FTP Client/` / `~/.config/My FTP Client/` |
| `profiles.json` (접속 프로파일) | 같은 폴더 |
| `history.json` (접속 히스토리, 비밀번호 없음) | 같은 폴더 |

- 비밀번호는 base64 로만 감춰집니다. 공용 컴퓨터에서는 프로파일에 비밀번호를 저장하지 마세요.
- 연결이 자주 끊기는 FTP 서버: 수동(passive) 모드로 접속하므로 방화벽 뒤에서도 대체로 동작하지만, 서버가 잘못된 수동 모드 주소를 알려 주면 데이터 연결이 실패할 수 있습니다.
- Windows 재설치 시 설치 프로그램이 이전 데이터를 지울지 물어봅니다. Linux/macOS 에서는 위 폴더를 직접 지우면 초기화됩니다.
