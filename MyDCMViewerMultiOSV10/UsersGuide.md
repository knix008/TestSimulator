# MyDCMViewer 사용자 가이드

MyDCMViewer는 Windows / macOS / Linux 데스크톱(Tauri)과 웹 브라우저에서 동작하는 DICOM 및 일반 영상 뷰어입니다.
의료 영상(.dcm)을 열어 윈도우/레벨 조정, 측정, 시네 재생, 시리즈 비교, MPR·3D 볼륨 렌더링, 영상 필터, PET/CT 융합, PACS 검색·가져오기·보내기, 45가지 형식으로 내보내기, 일괄 변환을 할 수 있습니다.

## 1. 시작하기

### 지원 형식

| 구분 | 확장자 | 비고 |
|------|--------|------|
| DICOM | `.dcm`, `.dicm`, `.dicom`, `.dic`, 확장자 없음 | 파일 내용으로 자동 감지, 다중 프레임·Enhanced multi-frame 지원 |
| DICOMDIR · ZIP | `DICOMDIR`(CD/DVD/USB), `.zip` | 환자 › 검사 › 시리즈 목록, ZIP 안의 파일을 읽기 전용 폴더로 탐색 |
| 이미지 | `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`, `.avif`, `.bmp`, `.ico`, `.svg` | 브라우저 엔진이 디코딩 |
| 고해상도·전문 이미지 | `.tif`/`.tiff` (다중 페이지 → 프레임 바로 페이지 이동, LZW/PackBits/Deflate/JPEG, 8·16-bit), `.heic`/`.heif`/`.hif`, `.jp2`/`.j2k`/`.jpc`/`.jpx` | 내장 디코더(UTIF, libheif, OpenJPEG) |

지원 전송 구문: Implicit/Explicit VR Little Endian, Explicit VR Big Endian, Deflated(데이터셋·Deflated Image Frame), RLE Lossless, JPEG Baseline / Extended(12-bit, Process 6·10 포함), JPEG Lossless, JPEG-LS, JPEG 2000, HTJ2K. 파일 메타(128바이트 머리말·DICM)가 없는 데이터셋, YBR_FULL_422 비압축 영상도 열립니다.

### 실행 방법

| 환경 | 방법 |
|------|------|
| 데스크톱(설치판) | 시작 메뉴의 **MyDCMViewer**, 바탕 화면 바로 가기, 또는 `.dcm` 파일 더블 클릭 |
| 데스크톱(개발) | `npm start` (Tauri 개발 실행) |
| 웹 | `npm run web` 후 브라우저에서 `http://127.0.0.1:8080` |

처음 실행하면 **시작 화면**과 **튜토리얼**이 나타납니다(18장). 데스크톱 판은 하나만 실행되며, 이미 실행 중일 때 `.dcm` 파일을 더블 클릭하면 그 창에서 열립니다.

### Windows 설치 (MyDCMViewer_x.y.z_x64-setup.exe)

1. 설치 언어(한국어/영어) 선택
2. **바로 가기 페이지**: 바탕 화면 바로 가기 / 시작 메뉴 바로 가기 / **DICOM 파일(.dcm·.dicm·.dicom)의 기본 프로그램으로 등록**. 등록하면 DICOM 파일이 전용 문서 아이콘으로 표시되고 더블 클릭으로 열립니다(Windows 10/11은 보안상 설정 › 기본 앱이 함께 열릴 수 있습니다).
3. 예전 Electron 판(MyDCMViewer)이 설치되어 있으면 먼저 완전히 제거하고, 남은 설정·최근 폴더 데이터도 지울지 묻습니다.
4. 제거(설정 › 앱)할 때 **앱 데이터 삭제**를 고르면 설정까지 지웁니다.

macOS는 .dmg, Linux는 AppImage / .deb 로 설치하며 `application/dicom` 파일 연결을 등록합니다.

| 창 제목 | 프로그램 이름·버전과 열린 파일(환자명 · Modality · 프레임)이 표시됩니다. |
| 폴더 트리 | 제목 옆 드라이브 버튼(`C:` `D:` …)으로 드라이브 바로 선택. 파일 한 번 클릭으로 열기, 폴더 더블 클릭으로 이동, `..`·드라이브는 한 번 클릭 |
| 정보 패널 | 정보 / 태그 / 히스토그램 / 시리즈 탭 |
| 파일 탭 | 뷰어 위에 열린 파일이 탭으로 표시됩니다. 탭 클릭으로 전환(각 탭의 프레임·윈도우·확대/이동·측정·실행 취소 기록이 그대로 유지), × 또는 가운데 클릭으로 닫기, `Ctrl+Tab`/`Ctrl+Shift+Tab` 전환, `Ctrl+W` 닫기(데스크톱). 탭이 한 줄을 넘으면 같은 줄 오른쪽에 ◀ ▶ 스크롤 버튼이 나타납니다. 이미 열린 파일을 다시 열면 그 탭으로 이동하고, 시리즈 스택 탐색(←/→)은 현재 탭 안에서 파일을 바꿉니다. 메모리 절약을 위해 최근 6개 탭만 디코딩 결과를 유지하고 나머지는 전환 시 다시 읽습니다. |
| 뷰어 | 이미지, 모서리 정보, 방향 표시(R/L/A/P/H/F), 배율 배지, 측정 표시 |
| 프레임 바 | 다중 프레임 파일에서만 표시. 재생/일시정지, fps, 반복 |
| 시리즈 바 | 폴더에 파일이 둘 이상이면 표시. 이전/다음 파일(스택) 이동 |

사이드바 폭과 트리/정보 패널의 높이는 경계를 드래그해 조절할 수 있고, `F9`로 사이드바를 숨길 수 있습니다.

## 3. 파일 열기

- **파일 → 파일 열기…** (`Ctrl+O`) 또는 툴바 **열기**
- **파일 → 폴더 열기…** (`Ctrl+Shift+O`) — 폴더를 트리에 표시
- **파일 → 최근 폴더** — 열어 본 폴더 최근 10개. 항목의 **×** 로 개별 삭제, **모두 지우기**로 전체 삭제 (데스크톱)
- 마지막으로 열었던 폴더는 다음 실행 때 자동으로 다시 열립니다(설정 → 파일 → 마지막 폴더 기억).
- 뷰어 또는 트리 영역에 파일/폴더를 **끌어다 놓기**
- 데스크톱: 탐색기에서 `.dcm` 더블 클릭(파일 연결), 명령줄 인수
- 확장자가 없는 파일도 내용이 DICOM이면 열립니다. 픽셀 데이터가 없는 DICOM(예: 구조화 보고서)은 태그만 표시합니다.

파일을 열 수 없으면 **오류** 창에 메시지와 상세 내용이 표시되고 **복사** 버튼으로 클립보드에 복사할 수 있습니다.

## 4. 폴더 탐색

| 동작 | 설명 |
|------|------|
| 파일 한 번 클릭 / `Enter` | 파일 열기 |
| 폴더 더블 클릭 / `Enter` | 해당 폴더로 이동 |
| `..` 클릭 / `↑` 버튼 / `Backspace` | 상위 폴더로 이동 (최상위에서는 드라이브·연결된 폴더 목록; 드라이브는 한 번 클릭으로 열림) |
| **폴더** 제목 옆 드라이브 버튼(`C:` `D:` …) | 시스템의 드라이브를 바로 선택 (현재 드라이브 강조; 웹에서는 연결된 폴더 루트) |

| `⟳` | 새로 고침 (데스크톱은 폴더 변경을 자동 감지) |

## 5. 이미지 보기

| 동작 | 방법 |
|------|------|
| 확대/축소 | 마우스 휠, 툴바의 **−** / **+** 버튼(가운데에 현재 배율 표시, 클릭하면 100%), `+`/`-`, 확대 도구 드래그 |
| 이동(패닝) | 왼쪽 버튼 드래그(이동 도구, 기본), 가운데 버튼 드래그 |
| 눈금자 / 격자 | 툴바 버튼 또는 `K` / `G`: 뷰어 위쪽(x축)과 왼쪽(y축) 전체에 이미지 원점 기준 눈금자(Pixel Spacing이 있으면 설정의 cm/Inch, 없으면 px) — 눈금 단위는 배율에 따라 자동 조정(주 눈금 60–150 px 간격), 마우스 위치가 녹색으로 표시. 격자는 뷰어 전체에 연한 선으로 깔리며, 굵은 선은 눈금자의 주 눈금에 맞고 그 사이를 5 × 5 칸으로 나눕니다(확대 · 축소하면 눈금에 맞춰 다시 나눔) |
| 컨텍스트 메뉴 | 오른쪽 버튼 클릭(드래그하지 않고 놓기) |
| 화면에 맞춤 / 실제 크기 | `Ctrl+0` / `Ctrl+1`, 툴바, 더블 클릭(이동 도구) |
| 회전 | `Ctrl+←` / `Ctrl+→` |
| 좌우 / 상하 반전 | `H` / `V` |
| 보기 초기화 | `R` |
| 부드러운 보간 | 보기 → 부드러운 보간 (기본: 확대 시 픽셀 그대로) |
| 반전(네거티브) | `I` |

배율 배지와 상태 표시줄의 배율은 화면 픽셀 대 이미지 픽셀 비율(100% = 1:1)입니다.
방향 표시(R/L/A/P/H/F)는 Image Orientation (Patient) 태그로부터 계산되며 회전/반전을 따라갑니다. 마우스 휠의 동작(확대 ↔ 프레임 이동)은 설정에서 바꿀 수 있습니다.

## 6. 윈도우 / 레벨

- **오른쪽 버튼 드래그**(모든 도구) 또는 **윈도우/레벨 도구**(`2`) 왼쪽 드래그: 가로 = 폭(W), 세로 = 중심(L)
- 메뉴 바(테마 버튼 왼쪽)의 **W / L** 입력란에 직접 입력하거나 양옆의 **−** / **+** 버튼으로 단계적으로 조정(값 범위에 따라 1·5·10 단위)
- **프리셋** 목록: 자동(최소–최대), 파일에 저장된 윈도우(여러 개 가능), CT 프리셋(뇌·경막하·뇌졸중·연부 조직·간·종격동·폐·뼈·복부·척추·혈관), VOI LUT
- **윈도우 메뉴**: VOI 함수(LINEAR / LINEAR_EXACT / SIGMOID), 컬러맵(회색·핫 아이언·PET·핫 메탈 블루·PET 20단계·제트·무지개·뼈), 반전, 윈도우 초기화(`Shift+W`)
- `A` 자동 윈도우, `W` 파일 윈도우

Rescale Slope/Intercept 또는 Modality LUT가 적용된 값(CT는 HU)으로 표시되며 Pixel Padding 값은 통계에서 제외됩니다. MONOCHROME1 과 Presentation LUT Shape(INVERSE)는 자동으로 반영됩니다.

| 키 | 도구 | 설명 |

| `2` | 윈도우/레벨 | 드래그로 W/L 조정 |
| `3` | 확대/축소 | 위/아래 드래그 |
| `4` | 프레임/슬라이스 스크롤 | 휠·드래그로 프레임 또는 시리즈 파일 이동 |
| `5` | 픽셀 값 조사 | 마우스 위치의 좌표·값(HU 등)·원시 값·RGB 표시 |
| `6` | 길이 | 두 점 사이 거리. Pixel Spacing이 있으면 설정의 단위(cm/Inch)로 자동 표시, 없으면 px |
| `7` | 각도 | 세 점(꼭짓점은 두 번째 점) — 클릭·드래그·클릭 |
| `8` | 사각형 ROI | 면적, n, 평균, 표준편차, 최소, 최대 |
| `9` | 타원 ROI | 위와 동일 |
| `0` | 텍스트 주석 | 클릭 후 텍스트 입력 |
| `Shift+5` | 점 | 클릭한 위치의 값(HU 등)을 표시 |
| `Shift+7` | Cobb 각 | 두 선(척추 끝판)을 차례로 그리면 사이 각도 |
| `Shift+8` | 다각형 ROI | 클릭으로 꼭짓점, 더블 클릭 또는 `Enter`로 닫기 — 면적·둘레·평균·SD·최소·최대 |
| `Shift+9` | 자유곡선 ROI | 끌어서 윤곽을 그림 — 다각형과 같은 통계 |
| `Shift+0` | 화살표 | 끌어서 화살표, 이름표 입력(비워 둘 수 있음) |
| `Q` | 돋보기 | 버튼을 누르고 있는 동안 그 자리를 3배로 확대 |

- 측정의 점(핸들)은 어떤 도구에서든 드래그해 옮길 수 있습니다.
- `Backspace` 마지막 측정 삭제, `Del` 모두 삭제. 보기 → 측정 표시로 숨길 수 있습니다.
- Pixel Spacing이 있으면 측정선·면적·눈금자에 실제 길이가 자동으로 표시됩니다. 단위(cm / Inch)는 설정 → 뷰어 → **수치 단위**에서 고릅니다.
- Pixel Spacing이 없는 파일(일반 이미지 등)은 길이 선을 그린 뒤 도구 → **이 길이를 실측값으로 보정**에서 실제 길이(예: `5 cm`)를 입력하면 이후 측정·눈금자·격자에 그 스케일이 적용됩니다.
- 측정 색상은 설정에서 바꿀 수 있고, "내보내기에 주석 포함"이 켜져 있으면 내보내는 이미지에 함께 그려집니다.

## 8. 다중 프레임 · 시네 · 시리즈 스택

### 다중 프레임 파일
- 프레임 바의 슬라이더, `↑`/`↓`, `Home`/`End`, 스크롤 도구의 휠
- 프레임 막대와 **시네** 메뉴: ▶ **재생**, ⏸ **잠시 멈춤**(지금 프레임에서), ⏹ **멈춤**(첫 프레임으로, `S`), 첫 · 이전 · 다음 · 마지막 프레임. `Space` 는 재생 / 잠시 멈춤. 재생 중에는 ▶ 단추가 강조됩니다.
- fps 기본값은 파일의 Frame Time / Cine Rate에서 가져오며 직접 바꿀 수 있습니다. 반복 재생 체크.

### DICOM 동영상
- MPEG-4 AVC(H.264) · HEVC 로 저장된 DICOM 동영상(내시경 · 초음파 · 수술 영상)은 프로그램의 동영상 엔진으로 그대로 재생 · 잠시 멈춤 · 멈춤 하고, 한 프레임씩 넘겨 측정 · 내보내기를 합니다.
- MPEG-2(또는 HEVC 디코더가 없는 컴퓨터의 HEVC)는 정보 화면과 **동영상 추출** 단추가 나옵니다. **도구 › DICOM 동영상 추출** 은 H.264 · HEVC 를 MP4 로, MPEG-2 를 .m2v 로 저장합니다.
- Enhanced multi-frame 파일은 프레임별 윈도우·위치·간격을 사용합니다.

### 시리즈 스택 (폴더의 여러 파일)
- 파일을 열면 같은 폴더의 파일들이 시리즈 바에 표시되고 `←`/`→`, `PgUp`/`PgDn`, 시리즈 슬라이더로 이동합니다. 이동할 때 확대·이동·윈도우 상태가 유지됩니다.
- **시네 → 폴더를 DICOM 시리즈로 정렬** (시리즈 패널의 버튼): 폴더의 모든 DICOM 헤더를 읽어 SeriesInstanceUID로 묶고 InstanceNumber → 슬라이스 위치 순으로 정렬합니다. 시리즈 패널에서 시리즈를 선택하면 스택이 바뀝니다.
- 프레임이 하나인 스택에서 `Space`를 누르면 파일들을 순서대로 재생합니다.

## 10. 고급 기능 (MPR · 3D · 필터 · 융합 · 배치)

### MPR / MIP 볼륨 보기 (`M`, 도구 메뉴, 툴바)
정렬된 시리즈(또는 다중 프레임 파일)의 슬라이스를 볼륨으로 쌓아 **축상면·관상면·시상면**을 동시에 보여 줍니다.
- 모드: MPR(단면), MIP(최대 강도 투영), MinIP, 평균 — 슬랩 두께(mm) 지정
- 각 면의 슬라이더·휠로 위치 이동, 클릭/드래그로 십자선 위치 지정(다른 두 면이 따라감)
- **곡면 MPR**: 켜고 축상면에 경로(치아 궁, 혈관, 척추 …)를 두 번 이상 클릭하면 그 곡선을 따라 펼친 영상이 나타납니다. *경로 지우기*로 다시 그립니다.
- W / L 입력, 십자선 표시, **보기 내보내기(PNG)**
- 먼저 **폴더를 DICOM 시리즈로 정렬**해야 합니다(다중 프레임 파일은 바로 가능). 회색조 영상만 지원합니다.

### 3D 볼륨 렌더링 (`Shift+M`, 도구 메뉴, 툴바의 정육면체 단추)
시리즈나 다중 프레임 영상을 GPU(WebGL2)로 3D 렌더링합니다.
- **모드**: 볼륨 렌더링(전달 함수 프리셋: CT 뼈 · CT 연부 조직 · CT 폐 · CT 혈관 조영 · MR · 회색 경사, 이동·불투명도·음영), **MIP / MinIP / 평균**(W/L, 자동), **등위면**(임계값)
- **보기**: 끌기 = 회전, 오른쪽/가운데 끌기 또는 `Shift`+끌기 = 이동, 휠 = 확대, 더블 클릭 = 초기화. 앞·뒤·왼쪽·오른쪽·위·아래 버튼
- **자르기**: 열(X)·행(Y)·슬라이스(Z) 방향 최소/최대 슬라이더로 볼륨을 잘라 안쪽을 봅니다.
- **품질**: 빠르게 / 보통 / 최고. 큰 볼륨은 GPU 한도에 맞춰 자동으로 줄이며 제목 옆에 표시됩니다.
- **PNG로 내보내기**로 현재 그림을 저장합니다.

### 영상 필터 (도구 › 영상 필터)
- 메뉴에서 하나를 바로 고르거나(부드럽게, 선명하게, 잡음 제거, 중앙값, 윤곽선, 엠보스, 라플라시안, 히스토그램 평활화, 값 반전, 임계값), **필터 연결…** 창에서 여러 필터를 순서대로 잇고 세기·반경 등을 조절합니다.
- 회색조 영상은 창 조절 **전에** 화소 값(HU 등)에 적용되므로 W/L을 바꿔도 다시 계산하지 않고, 컬러 영상은 그림에 적용됩니다.
- 내보내기·인쇄·복사에도 필터가 들어갑니다. 파일은 바뀌지 않습니다. *필터 없음*으로 원래대로 돌아갑니다.

### 영상 융합 (도구 › 영상 융합)
두 번째로 연 DICOM 영상(PET, SPECT, 선량, MR …)을 현재 영상 위에 컬러맵으로 겹칩니다.
- 두 영상에 위치 정보(Image Position/Orientation)가 있으면 **환자 좌표로 재표본화**하고, 다중 프레임 겹침 영상은 현재 단면에 가장 가까운 프레임을 씁니다.
- 위치 정보가 없거나 서로 겹치지 않는 다른 촬영이면 크기에 맞춰 늘려 겹치고 그 사실을 표시합니다.
- 컬러맵, 불투명도, 임계값(이보다 어두운 값은 투명)을 조절합니다.

### 화면 배치 · 동기 스크롤 · 기준선 (보기 메뉴)
- **화면 배치**: 1×1, 1×2, 2×1, 2×2, 1×3, 2×3, 3×3. 칸을 클릭하면 그 칸이 활성화되고, 열린 다른 탭의 영상이 빈 칸에 표시됩니다.
- **동기 스크롤**: 한 칸에서 슬라이스를 넘기면 다른 칸도 같은 위치(환자 좌표)의 슬라이스로 따라갑니다.
- **기준선**: 활성 칸의 단면이 다른 칸의 영상을 자르는 위치를 선으로 보여 줍니다.

### 시네 동영상 (파일 › 이미지 내보내기, 툴바)
다중 프레임 파일의 프레임(또는 시리즈의 파일들)을 현재 윈도우/컬러맵·fps로 **MP4(H.264)** 또는 **WebM** 동영상으로 저장합니다.

## 12. 폴더 일괄 변환

**파일 → 폴더 일괄 변환…** 또는 툴바 **일괄 변환**

1. 소스 폴더 선택(기본: 현재 트리 폴더)
2. 형식(PNG/JPEG/WebP/BMP/TIFF/GIF)과 옵션 선택 — 하위 폴더 포함, 모든 프레임, 현재 윈도우/컬러맵 사용
3. **시작** — 진행률과 결과(성공/실패 수, 출력 위치)가 표시되고 실패 목록은 오류 창에서 확인

출력은 소스 폴더 아래 `converted_png` 처럼 `converted_<형식>` 폴더(이미 있으면 `_2`, `_3`…)에, 다중 프레임은 `파일명_frame01.png` 형식으로 저장됩니다.
웹에서 쓰기 권한이 없는 폴더(파일 선택으로 연 경우 등)는 `converted_<형식>.zip`으로 다운로드됩니다.

- **언어**: 메뉴 바 오른쪽 **국기 버튼**을 누르면 한국어 ↔ English 로 전환됩니다. 국기는 전환될 언어를 나타냅니다 — 한국어 사용 중에는 영국 국기, 영어 사용 중에는 태극기 (보기 → 언어, 설정에서도 변경 가능).
- **프로그램 설정** (`Ctrl+,`, ⚙ 버튼, 보기 → 설정…):

| 탭 | 항목 |
|----|------|
| 모양 | 테마(20종), 언어, 사이드바 표시 |
| 시작 화면 | 시작할 때 시작 화면 보기, 시작할 때 튜토리얼 보기(튜토리얼 창 아래 확인란과 같은 설정), 시작 화면 배경·투명도·움직임 속도 |

| 파일(데스크톱) | 마지막 폴더 기억, 시작 시 열 폴더, 삭제 전 확인 |

설정 창의 크기는 탭에 관계없이 항상 같습니다. **기본값 복원** 버튼으로 모든 설정을 되돌릴 수 있습니다. 설정은 데스크톱에서는 사용자 데이터 폴더의 `dcmviewer-settings.json`, 웹에서는 브라우저 저장소에 보관됩니다.

데스크톱 판의 모든 대화상자(정보·설정·일괄 변환·오류·단축키·MPR·익명화·입력·인쇄·진행률)는 아이콘과 제목이 있는 **별도의 창**으로 열립니다. 메인 창 위에 유지되어 가려지지 않고, 내용에 맞춰 크기가 정해지므로 스크롤 없이 표시되며, 메인 창을 닫으면 함께 닫힙니다. 시리즈 정렬, 프레임 ZIP·애니메이션 GIF·동영상 내보내기처럼 오래 걸리는 작업은 **진행률 창**(막대 + %)이 표시되고 **취소**할 수 있습니다.

## 16. 웹 브라우저 모드

- `npm run web` (또는 `npm run build:web` 결과물을 정적 서버에 배포)
- **폴더 열기**는 Chrome/Edge의 File System Access API를 사용해 로컬 폴더를 읽고 쓸 수 있습니다(변환 결과를 `converted_…` 폴더에 직접 저장). 다른 브라우저에서는 폴더 선택 입력으로 읽기만 가능하며 결과는 ZIP으로 다운로드됩니다.
- 파일/폴더를 페이지에 끌어다 놓을 수 있습니다.
- 대화상자는 페이지 안의 창으로 표시됩니다. 파일 복사/삭제, 파일 관리자 열기, 파일 연결, **PACS(네트워크)** 는 데스크톱 전용입니다.
- 3D 볼륨 렌더링에는 WebGL2가 필요합니다(최근 Chrome/Edge/Firefox/Safari).

## 18. 시작 화면과 튜토리얼

> 모든 기능의 자세한 설명은 그림과 함께 **도움말 › 도움말** (`Ctrl+F1`) 창과 [doc/README.md](doc/README.md) 에 있습니다. 튜토리얼 전체 동영상: [MyDCMViewer-Tutorial.mp4](MyDCMViewer-Tutorial.mp4).

**시작 화면**은 실행할 때(설정에서 끌 수 있음)와 메뉴 바 왼쪽 **시작** 단추로 엽니다.
- **시작하기**: 파일 열기, 폴더 열기, DICOMDIR 열기, 폴더 일괄 변환, 설정, 단축키, 튜토리얼
- **예제 영상 18종**: CT, MR 뇌, Enhanced MR(10프레임), 컬러 도플러 심장 초음파(120프레임), 혈관 조영(XA), 흉부 X선(CR), 고해상도 MR, 컬러 초음파, Enhanced CT, 오버레이, 팔레트 컬러, Modality LUT, RT 선량·구조·계획, 구조화 보고서, 12유도 심전도, DICOMDIR — 카드를 누르면 바로 열립니다.
- **최근 파일**, 오늘의 팁, 움직이는 3D 배경(15종; 투명도·전체 속도·카메라/물체/하늘 속도 조절)

**튜토리얼**(도움말 › 튜토리얼, 처음 실행할 때 자동)은 11장 46단계로 모든 기능을 하나씩 보여 줍니다. 단계마다 화면의 한 부분을 강조하고 데모(예제 열기, 측정, 윈도우 프리셋, 시네 · 동영상 재생, 화면 배치, MPR, 3D, 필터, 융합, 태그 편집, 문서, 내보내기, PACS …)가 저절로 실행됩니다. 카드 위의 목록으로 장을 고르고, **▶ 다시 실행** 으로 데모를 다시 보고, **다음 / 이전**, `Esc` 로 닫습니다. 도움말 창의 **▶ 튜토리얼로 보기** 는 그 기능의 단계에서 시작합니다.

## 20. PACS (DICOM 네트워크)

**도구 › PACS (DICOM 네트워크)…** — 데스크톱 앱에서만 동작합니다.

1. **원격 노드 등록**: 이름, AE 타이틀(PACS 관리자에게 받은 값), 호스트(IP 또는 이름), 포트(보통 104 또는 11112)를 입력하고 **저장**합니다. 여러 노드를 목록에 둘 수 있습니다.
2. **연결 확인 (C-ECHO)**: 응답 시간이 표시되면 연결된 것입니다.
3. **이 컴퓨터**: 우리 AE 타이틀(기본 MYDCMVIEWER)과 수신 포트(기본 11112). **수신 시작**을 누르면 Storage SCP가 켜져 다른 장비가 보내는 영상(C-STORE)을 받습니다.
4. **검색 (C-FIND)**: 환자 이름(`DOE^*` 같은 와일드카드), 환자 ID, 날짜 범위, 장비(CT, MR …), 접수 번호로 검사를 찾습니다. 검사를 누르면 그 검사의 시리즈가 아래에 나타납니다.
5. **가져오기**
   - **C-GET**: 같은 연결로 바로 받습니다. 대부분의 PACS(Orthanc, dcm4chee …)가 지원하며 따로 등록할 필요가 없습니다.
   - **C-MOVE**: PACS가 우리 수신 포트로 보내 줍니다. **PACS에 우리 AE 타이틀·이 컴퓨터 주소·수신 포트가 등록되어 있어야** 합니다. 누르면 수신이 자동으로 켜집니다.
   - 시리즈를 고르지 않으면 검사 전체를 가져옵니다. 받은 파일은 `~/MyDCMViewer/PACS/<날짜-시각>/` 에 저장되고, 끝나면 그 폴더가 트리에 열리며 시리즈로 정렬됩니다(**받은 파일 열기**로 다시 열 수 있음).
6. **보내기 (C-STORE)**: 지금 연 파일(정렬된 시리즈라면 시리즈 전체)을 선택한 노드로 보냅니다. 상대가 압축 형식을 받지 않으면 자동으로 비압축으로 변환해 보냅니다.

시험용으로 `npm run mini-pacs` 를 실행하면 samples/ 의 영상을 가진 작은 PACS(AE `MINIPACS`, 포트 11113)가 뜹니다. C-MOVE 목적지를 쓰려면 `node scripts/mini-pacs.cjs --dest MYDCMVIEWER=127.0.0.1:11112` 처럼 실행합니다.
