# MPR · MIP · 곡면 MPR

정렬된 시리즈나 여러 프레임 파일의 슬라이스를 볼륨으로 쌓아 **축상면 · 관상면 · 시상면** 을 함께 봅니다. **도구 › MPR / MIP 볼륨 보기** (`M`) 또는 도구 모음의 단추.

![MPR](images/help-mpr.jpg)

## 사용법

1. 여러 프레임 파일을 열거나, 폴더를 열고 **시네 › 폴더를 DICOM 시리즈로 정렬** 합니다.
2. `M` 을 눌러 MPR 창을 엽니다.
3. 각 면의 슬라이더 · 휠로 위치를 옮기고, 한 면을 누르거나 끌면 십자선이 옮겨 가 다른 두 면이 따라옵니다.

| 항목 | 설명 |
| --- | --- |
| 모드 | MPR(단면), **MIP**(최대 강도 투영), **MinIP**(최소), **평균** |
| 슬랩 | 투영할 두께(mm) |
| W / L | 볼륨 전체의 윈도우 |
| 십자선 | 표시 · 숨기기 |
| 보기 내보내기 | 세 면을 PNG 로 |

## 곡면 MPR

**곡면 MPR** 을 켜고 축상면 위에 경로(치아 궁, 혈관, 척추 등)를 두 번 이상 누르면, 그 곡선을 따라 펼친 영상이 아래에 나타납니다. *경로 지우기* 로 다시 그립니다.

> 픽셀 간격과 슬라이스 간격(위치 차이의 중앙값)으로 실제 비율을 맞춥니다. 회색조 영상만 됩니다.
