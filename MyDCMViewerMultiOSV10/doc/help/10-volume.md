# 3D 볼륨 렌더링

시리즈나 여러 프레임 영상을 그래픽 카드(WebGL2)로 3D 로 그립니다. **도구 › 3D 볼륨 렌더링** (`Shift+M`) 또는 도구 모음의 정육면체 단추.

![3D 볼륨 렌더링](images/help-volume.jpg)

## 모드

| 모드 | 설명 |
| --- | --- |
| 볼륨 렌더링 | 값마다 색과 투명도를 주는 전달 함수로 그립니다. 프리셋: CT 뼈, CT 연부 조직, CT 폐, CT 혈관 조영, MR, 회색 경사. *이동 · 불투명도 · 음영* 으로 조절 |
| MIP · MinIP · 평균 | 시선 방향의 최대 · 최소 · 평균 값. W / L, *자동* |
| 등위면 | 임계값 이상인 면을 빛과 그림자로 |

## 조작

| 동작 | 방법 |
| --- | --- |
| 돌리기 | 왼쪽 끌기 |
| 이동 | 오른쪽 · 가운데 끌기, `Shift` + 끌기 |
| 확대 | 휠 |
| 초기화 | 두 번 누르기, *보기 초기화* |
| 미리 정한 방향 | 앞 · 뒤 · 왼쪽 · 오른쪽 · 위 · 아래 |
| 자르기 | 열(X) · 행(Y) · 슬라이스(Z) 의 최소 / 최대 슬라이더로 볼륨을 잘라 안을 봅니다 |
| 품질 | 빠르게 · 보통 · 최고 |
| PNG 로 내보내기 | 지금 그림을 저장 |

> 큰 볼륨은 그래픽 카드 한도에 맞춰 자동으로 줄이며 제목 옆에 표시합니다. 슬라이스 간격이 고르지 않으면 그 사실도 표시합니다.
