# 설정 · 테마 · 언어 · 단축키

## 테마 · 언어

- 메뉴 막대 오른쪽의 테마 단추를 누르면 다음 테마로 바뀌고, ▾ 에서 20가지 테마 가운데 고릅니다.
- 국기 단추로 한국어 ↔ 영어를 바꿉니다(바뀔 언어의 국기가 보입니다).

## 설정 창

![설정](images/help-settings.jpg)

**보기 › 설정…** (`Ctrl+,`) 또는 메뉴 막대의 ⚙ 단추.

| 탭 | 내용 |
| --- | --- |
| 모양 | 테마 20가지(미리보기), 언어, 사이드바, 시작할 때 시작 화면 보이기, 튜토리얼 완료(끄면 다음에 다시 시작) |
| 뷰어 | 부드러운 보간, 모서리 정보, 방향 표시, 오버레이, 측정 표시, 측정 단위(cm · inch), 내보내기에 주석 포함, 휠 동작(확대 · 슬라이스), 기본 fps, 반복, 동기 스크롤 · 기준선, 측정 · 오버레이 색 |
| 파일 (데스크톱) | 마지막 폴더 기억, 시작 폴더, 삭제 전에 확인 |

**설정 초기화** 로 처음 값으로 되돌립니다.

## 키보드 단축키

![단축키](images/help-shortcuts.jpg)

**도움말 › 키보드 단축키** (`F1`) 에 모든 단축키가 있습니다. 자주 쓰는 것:

| 키 | 동작 | 키 | 동작 |
| --- | --- | --- | --- |
| `Ctrl+O` | 파일 열기 | `Ctrl+Shift+O` | 폴더 열기 |
| `Ctrl+E` | PNG 내보내기 | `Ctrl+C` | 이미지 복사 |
| `Ctrl+P` | 인쇄 | `Ctrl+,` | 설정 |
| `Ctrl+Z` / `Ctrl+Y` | 실행 취소 / 다시 실행 | `Ctrl+W` | 탭 닫기 |
| `1` … `9`, `0` | 도구 | `Shift+5 7 8 9 0` | 점 · Cobb · 다각형 · 자유곡선 · 화살표 |
| `Q` | 돋보기 | `M` / `Shift+M` | MPR / 3D |
| `Space` | 재생 / 잠시 멈춤 | `S` | 멈춤 (첫 프레임으로) |
| `↑` `↓` · `Home` `End` | 프레임 | `←` `→` · `PgUp` `PgDn` | 시리즈 |
| `A` · `W` · `Shift+W` | 자동 · 파일 · 초기 윈도우 | `I` | 반전 |
| `K` · `G` | 눈금자 · 격자 | `F9` · `F11` | 사이드바 · 전체 화면 |

## 도움말 창과 튜토리얼

- **도움말 › 도움말** 은 이 설명을 그림과 함께 보여 주는 창입니다. 왼쪽 목록에서 주제를 고르고 위의 칸에서 찾습니다. 주제마다 있는 **▶ 튜토리얼로 보기** 단추는 그 기능의 튜토리얼 단계로 바로 갑니다.
- **도움말 › 튜토리얼** 은 모든 기능을 단계별 데모로 보여 줍니다. 위의 목록으로 장을 고르고, **▶ 다시 실행** 으로 데모를 다시 봅니다.
