# 시작 화면과 예제 영상

프로그램을 켜면 **시작 화면**이 나타납니다. 자주 쓰는 일을 바로 시작하고, 예제 영상으로 기능을 시험해 볼 수 있습니다. 메뉴 막대 맨 왼쪽의 **시작** 단추로 언제든 다시 열고 닫습니다.

![시작 화면](images/help-start.jpg)

## 시작하기 카드

| 카드 | 하는 일 |
| --- | --- |
| 튜토리얼 | 모든 기능을 단계별 데모로 보여 주는 안내를 시작합니다 |
| 파일 열기 | DICOM · TIFF · HEIF · JPEG 2000 · 일반 그림 파일을 엽니다 |
| 폴더 열기 | 폴더를 왼쪽 트리에 엽니다. 시리즈 단위로 넘겨 볼 수 있습니다 |
| DICOMDIR 열기 | CD · DVD · USB 의 `DICOMDIR` 을 환자 › 검사 › 시리즈 목록으로 엽니다 |
| 폴더 일괄 변환 | 폴더의 DICOM 을 한꺼번에 그림 파일로 바꿉니다 |
| 설정 · 단축키 | 프로그램 설정 창, 키보드 단축키 목록 |

## 예제 영상

**예제 영상** 묶음의 카드를 누르면 바로 열립니다. CT, MR 뇌, Enhanced MR(10프레임), 컬러 도플러 심장 초음파(120프레임), 혈관 조영(XA), 흉부 X선(CR), 고해상도 MR, 컬러 초음파, Enhanced CT, 오버레이 평면, 팔레트 컬러, Modality LUT, RT 선량 · 구조 · 계획, 구조화 보고서, 12유도 심전도, **DICOM 동영상(H.264 · HEVC · MPEG-2)**, DICOMDIR 이 들어 있습니다.

## 최근 파일과 오늘의 팁

- **최근 파일**: 최근에 연 파일을 다시 엽니다. 파일 메뉴의 *최근 파일*, *최근 폴더* 에도 같은 목록이 있습니다.
- **팁**: 매번 다른 사용 요령을 보여 줍니다. *더 보기* 로 자세히 읽습니다.

## 배경 바꾸기

시작 화면 아래쪽 **시작 화면 배경** 에서 움직이는 3D 배경 18종 가운데 하나를 고릅니다.

![배경 선택](images/help-background.jpg)

- CT 갠트리, MRI 단면, X선, DNA, 세포, 신경, 심장 박동, 혈관, 분자, 초음파, **내시경**, **PET 스캐너**, **방사선 치료기**, PACS 서버, 복셀, 병원, 폐, 척추
- **투명도**: 배경을 흐리게 해 글자를 더 잘 보이게 합니다.
- **전체 속도** 와 **카메라 · 물체 · 하늘** 속도를 따로 조절합니다. *기본값* 으로 되돌립니다.

> 시작할 때 시작 화면을 보이지 않게 하려면 아래의 *시작할 때 시작 화면 보이기* 를 끄거나 **설정 › 모양** 에서 바꿉니다.
