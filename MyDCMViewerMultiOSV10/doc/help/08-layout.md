# 화면 배치 · 동기 스크롤 · 기준선

여러 영상을 나란히 놓고 비교합니다.

![화면 배치](images/help-layout.jpg)

## 화면 배치

**보기 › 화면 배치** 또는 도구 모음의 배치 단추에서 1×1, 1×2, 2×1, 2×2, 1×3, 2×3, 3×3 을 고릅니다.

- 칸을 누르면 그 칸이 **활성 칸** 이 되고, 도구 · 윈도우 · 내보내기는 활성 칸에 적용됩니다.
- 열린 다른 탭의 영상이 빈 칸에 차례로 들어갑니다. 파일을 더 열면 다음 칸에 나타납니다.

## 동기 스크롤

**보기 › 동기 스크롤** 을 켜면 한 칸에서 슬라이스를 넘길 때 다른 칸도 **환자 좌표에서 같은 위치** 의 슬라이스로 따라갑니다. 이전 검사와 오늘 검사, CT 와 MR 을 비교할 때 씁니다.

## 기준선

**보기 › 기준선** 을 켜면 활성 칸의 단면이 다른 칸의 영상을 자르는 위치가 선으로 보입니다(축상면 위의 관상 · 시상 위치 등).

> 동기 스크롤과 기준선은 영상에 위치 정보(Image Position · Orientation)가 있어야 합니다. 설정 › 뷰어에서 기본값을 정합니다.
