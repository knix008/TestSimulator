# Start page and sample images

When the program starts, the **Start Page** appears. From here you can jump straight into common tasks and try out features with sample images. The **Start** button at the far left of the menu bar opens and closes it at any time.

![Start page](images/help-start.jpg)

## Get started cards

| Card | What it does |
| --- | --- |
| Tutorial | Starts a guided tour that shows every feature with step-by-step demos. Turn off **Show this tutorial when the program starts** at the bottom of the tour card and it no longer appears at launch (turn it back on in Settings › Start screen) |
| Open File | Opens DICOM, TIFF, HEIF, JPEG 2000 and ordinary picture files |
| Open Folder | Opens a folder in the tree on the left so you can step through it series by series |
| Open DICOMDIR | Opens the `DICOMDIR` on a CD, DVD or USB stick as a patient › study › series list |
| Batch Convert Folder | Converts all the DICOM files in a folder to picture files in one go |
| Settings · Keyboard shortcuts | The program's settings window and the list of keyboard shortcuts |

## Sample images

Click a card in the **Sample images** group to open it right away. The samples include CT, MR brain, Enhanced MR (10 frames), colour Doppler echocardiogram (120 frames), angiography (XA), chest X-ray (CR), high-resolution MR, colour ultrasound, Enhanced CT, overlay planes, palette colour, Modality LUT, RT dose · structure · plan, a structured report, a 12-lead ECG, **DICOM video (H.264 · HEVC · MPEG-2)** and a DICOMDIR.

## Recent files and the tip of the day

- **Recent files**: reopens files you opened recently. The same lists are under *Recent Files* and *Recent Folders* in the File menu.
- **Tip**: shows a different usage tip each time. Click *More* to read the details.

## Changing the background

Under **Start page background** at the bottom of the start page, pick one of 18 animated 3D backgrounds.

![Choosing a background](images/help-background.jpg)

- CT Scanner, MRI Slices, X-Ray, DNA Helix, Cells, Neurons, Heartbeat, Angiography, Molecules, Ultrasound, **Endoscope**, **PET scanner**, **Radiotherapy linac**, PACS Servers, Voxel Volume, Hospital, Lungs, Spine
- **Transparency**: fades the background so the text is easier to read.
- Adjust the **Overall speed** and the **Camera · Objects · Sky & light** speeds separately. *Defaults* resets them.

> To stop the start page from appearing at launch, turn off *Show the start page at launch* below, or change it in **Settings › Start screen**.
