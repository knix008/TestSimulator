# Settings · themes · language · shortcuts

## Theme · language

- At the right end of the menu bar are the **Theme · Language · Settings · About** buttons, in that order.
- Clicking the theme button switches to the next theme; ▾ lets you pick from 20 themes.
- The flag button switches between Korean and English (it shows the flag of the language you will switch to).

## Settings window

![Settings](images/help-settings.jpg)

**View › Settings…** (`Ctrl+,`) or the ⚙ button on the menu bar.

| Tab | Contents |
| --- | --- |
| Appearance | 20 themes (with preview), language, sidebar, properties panel |
| Start screen | Show the start page at launch, Show the tutorial at startup (the same setting as the check box under the tutorial window), start page background · transparency · motion speed |
| Viewer | Smooth interpolation, corner information, orientation markers, overlays, show measurements, measurement unit (cm · inch), include annotations in exported images, mouse wheel (zoom · slices), default fps, loop, synchronised scrolling · reference lines, measurement · overlay colours |
| Files (desktop) | Remember the last folder, folder to open at start-up, confirm before moving files to the trash |

**Restore defaults** returns everything to the initial values.

## Keyboard shortcuts

![Shortcuts](images/help-shortcuts.jpg)

**Help › Keyboard shortcuts** (`F1`) lists every shortcut. The most used:

| Key | Action | Key | Action |
| --- | --- | --- | --- |
| `Ctrl+O` | Open file | `Ctrl+Shift+O` | Open folder |
| `Ctrl+E` | Export PNG | `Ctrl+C` | Copy image |
| `Ctrl+P` | Print | `Ctrl+,` | Settings |
| `Ctrl+Z` / `Ctrl+Y` | Undo / Redo | `Ctrl+W` | Close tab |
| `1` … `9`, `0` | Tools | `Shift+5 7 8 9 0` | Point · Cobb · polygon · freehand · arrow |
| `Q` | Magnifier | `M` / `Shift+M` | MPR / 3D |
| `Space` | Play / pause | `S` | Stop (back to the first frame) |
| `↑` `↓` · `Home` `End` | Frames | `←` `→` · `PgUp` `PgDn` | Series |
| `A` · `W` · `Shift+W` | Auto · file · reset window | `I` | Invert |
| `K` · `G` | Rulers · grid | `F9` · `F11` | Sidebar · full screen |

## Help window and tutorial

- **Help › Help** is a window that shows these pages with pictures. Pick a topic from the list on the left and search with the box at the top. The **▶ Show in the tutorial** button on each topic jumps straight to that feature's tutorial step.
- **Help › Tutorial** shows every feature as a step-by-step demo. Pick a chapter from the list at the top and use **▶ Run again** to watch a demo again.
