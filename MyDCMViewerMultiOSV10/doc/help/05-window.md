# 윈도우 / 레벨과 컬러맵

윈도우(폭, W)와 레벨(중심, L)은 영상의 대비와 밝기입니다. CT 의 HU 처럼 넓은 값의 범위에서 보고 싶은 부분만 화면 밝기로 펼칩니다.

![윈도우 / 레벨](images/help-window.jpg)

## 바꾸는 방법

| 방법 | 설명 |
| --- | --- |
| 오른쪽 끌기 | 어느 도구에서나. 좌우 = 폭(W), 위아래 = 중심(L) |
| 윈도우 / 레벨 도구 (2) | 왼쪽 끌기로 바꿉니다 |
| W / L 입력 칸 | 메뉴 막대, 도움말 메뉴 바로 오른쪽. 숫자를 넣거나 − / + 로 조금씩 |
| 프리셋 | 도구 모음의 목록 · 윈도우 › 프리셋: 뇌, 폐, 뼈, 복부, 척추, 혈관 … |
| 자동 (`A`) | 현재 프레임의 최소 – 최대 |
| 파일 값 (`W`) | 파일에 저장된 윈도우 |
| 윈도우 초기화 (`Shift+W`) | 처음 상태로 |

## VOI LUT 와 VOI 함수

파일에 VOI LUT 가 있으면 **윈도우 › VOI LUT** 에서 고릅니다. **VOI 함수** 는 LINEAR, LINEAR_EXACT, SIGMOID 입니다.

## 컬러맵 · 반전

**윈도우 › 컬러맵** 또는 도구 모음의 컬러맵 목록에서 회색 대신 핫 아이언, PET, 제트, 무지개 등으로 봅니다. 반전(`I`)은 MONOCHROME1 영상처럼 밝기를 뒤집습니다.

> 회색조가 아닌 컬러 · 팔레트 영상은 윈도우와 컬러맵이 적용되지 않습니다.
