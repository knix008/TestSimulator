# 화면 구성

![화면 구성](images/help-screen.jpg)

| 영역 | 설명 |
| --- | --- |
| 메뉴 막대 | **시작 · 파일 · 보기 · 도구 · 윈도우 · 시네 · 도움말**. 모든 메뉴 항목에 아이콘이 있습니다. 오른쪽에는 W / L 입력, 테마, 설정, 언어(국기), 프로그램 정보가 있습니다 |
| 도구 모음 | 아이콘 단추: 왼쪽 패널 표시, 열기 · 폴더, 실행 취소 · 다시 실행, 마우스 도구, 확대 · 배율, 눈금자 · 축척 막대 · 격자, 회전 · 반전, 반전(네거티브), 화면 배치, MPR · 3D, DICOM 도구, 프리셋 · 컬러맵, 내보내기, 일괄 변환. 단추 위에 마우스를 올리면 설명이 나옵니다 |
| 폴더 트리 | 연 폴더의 파일. 위쪽 단추로 상위 폴더 · 새로 고침, 드라이브 단추로 드라이브를 고릅니다 |
| 정보 패널 | **정보 · 태그 · 히스토그램 · 시리즈** 탭 |
| 파일 탭 | 연 파일마다 탭. 파일별로 프레임 · 윈도우 · 확대 · 측정 · 실행 취소 기록을 따로 기억합니다 |
| 뷰어 | 영상, 모서리 정보(환자 · 검사 · W/L · 배율), 방향 표시(R/L/A/P/H/F), 측정 |
| 프레임 막대 | 여러 프레임 영상 · 동영상에서만: 재생 · 잠시 멈춤 · 멈춤, 프레임 이동, fps, 반복 |
| 시리즈 막대 | 폴더에 파일이 여럿일 때 이전 · 다음 파일 |
| 상태 표시줄 | 파일 경로, 환자 요약, 크기, W/L, 마우스 아래의 값, 배율 — 오른쪽 아래의 **크기 변경 표시**를 끌어 창 크기를 바꿉니다 |

## 오른쪽 단추 메뉴 (컨텍스트 메뉴)

모든 오른쪽 단추 메뉴의 항목에는 아이콘이 있습니다.

![컨텍스트 메뉴](images/help-contextmenu.jpg)

- **영상 위**: 파일 열기, 화면에 맞춤, 실제 크기, 보기 초기화, 이미지 복사, 이미지 내보내기, 마지막 측정 삭제, 측정 모두 지우기, 실측 보정
- **폴더 트리**: 열기, 파일 관리자에서 보기, 복사 · 잘라내기 · 붙여넣기 · 삭제, 경로 복사, 폴더 고르기, 새로 고침
- **파일 탭**: 탭 닫기, 다른 탭 모두 닫기, 모든 탭 닫기, 경로 복사, 파일 관리자에서 보기
- **입력 칸 · 고른 글자**: 잘라내기, 복사, 붙여넣기, 모두 선택

## 크기 조절

- 사이드바의 폭과 트리 / 정보 패널의 높이는 경계선을 끌어 바꿉니다.
- 왼쪽 패널은 폴더 머리글 오른쪽 끝의 **«** 단추로 접고, 접힌 자리에 남는 좁은 띠의 **»** 단추로 다시 폅니다. 도구 모음 맨 앞의 **패널 표시** 단추와 `F9` 도 같은 일을 합니다. 패널을 접거나 펴도 맞춰 보던 영상은 가운데에 다시 맞춰집니다.
- 숫자를 넣는 칸은 양옆의 **−** / **+** 단추로 한 단계씩 바꾸고(누르고 있으면 계속), 값은 칸 가운데에 보입니다. 슬라이더도 양옆에 **−** / **+** 단추가 있고, 지금 값은 **+** 단추 오른쪽에 나옵니다.
- 영상을 열면 언제나 보기 영역의 정가운데에 맞춰 놓입니다. 눈금자를 켜면 눈금자 띠를 뺀 나머지 영역의 가운데입니다.
- 창 크기는 창 테두리나 상태 표시줄 오른쪽 아래의 점 표시를 끌어 바꿉니다. 크기를 바꿀 수 있는 대화상자(MPR · 3D · PACS · 태그 편집 · 도움말)에도 같은 표시가 있습니다.
