# 영상 보기

![영상 보기](images/help-view.jpg)

## 확대 · 이동

| 동작 | 방법 |
| --- | --- |
| 확대 / 축소 | 마우스 휠, `+` / `-`, 도구 모음의 돋보기 단추, 배율 숫자 |
| 이동 | 이동 도구(1)로 왼쪽 끌기, 어느 도구에서나 가운데 단추 끌기 |
| 화면에 맞춤 | `Ctrl+0`, 이동 도구로 더블 클릭 |
| 실제 크기 (100%) | `Ctrl+1`, 도구 모음의 배율 숫자 누르기 |

## 회전 · 반전

- **보기 › 왼쪽 / 오른쪽으로 회전** (`Ctrl+←` / `Ctrl+→`), **좌우 반전** (`H`), **상하 반전** (`V`), **보기 초기화** (`R`).
- **반전 (네거티브)** (`I`) 는 밝기를 뒤집습니다.
- 모든 보기 변경은 **실행 취소** (`Ctrl+Z`) / **다시 실행** (`Ctrl+Y`) 할 수 있습니다.

## 화면 위 정보

| 보기 메뉴 | 설명 |
| --- | --- |
| 모서리 정보 표시 | 환자 · 검사 · 기관 · W/L · 배율 · 크기 · 슬라이스 위치 |
| 방향 표시 | 화면 가장자리의 R/L/A/P/H/F (Image Orientation 이 있을 때) |
| DICOM 오버레이 평면 | 60xx 오버레이 그림 · 글자 |
| 측정 표시 | 측정을 숨기거나 보입니다 |
| 눈금자 (`K`) · 격자 (`G`) | 실제 크기(mm / cm)의 자와 10 mm 격자 |
| 부드러운 보간 | 확대할 때 화소를 부드럽게 |

## 정보 · 태그 · 히스토그램 · 시리즈 패널

![태그 패널](images/help-tags.jpg)

- **정보**: 파일, 크기, 환자, 검사, 장비, 전송 구문, 화소 간격 등
- **태그**: 모든 DICOM 요소. 위의 칸에서 이름 · 번호 · 값으로 찾습니다
- **히스토그램**: 현재 프레임 값의 분포와 현재 윈도우 범위
- **시리즈**: 정렬된 시리즈 목록과 미리보기
