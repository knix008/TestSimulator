# 사용자 가이드 (Users Guide)

3D Space Maker를 설치하고, 이미지를 넣어 3D 공간을 탐험하는 방법을 설명합니다.

## 1. 시스템 요구 사항

- **OS**: Windows 10/11, macOS, Linux (Electron 지원 환경)
- **Node.js**: 18 이상 권장 (개발·실행 스크립트용)
- **메모리**: 8GB 이상 권장 (고해상도 이미지·모델 로딩)
- **네트워크**: 최초 깊이 모델 다운로드에만 필요 (이후 로컬 캐시 재사용)

GPU가 없어도 동작합니다. 깊이 추정은 WASM(CPU)으로 실행되므로 첫 생성은 수십 초 걸릴 수 있습니다.

## 2. 설치와 실행

```bash
# 프로젝트 폴더에서
npm install
npm run dev
```

창이 열리면 왼쪽 패널에서 이미지를 선택합니다.

빌드된 앱을 미리 보려면:

```bash
npm run build
npm run preview
```

## 3. 지원 이미지

| 형식 | 확장자 예 | 비고 |
|------|-----------|------|
| JPEG | `.jpg`, `.jpeg` | 일반 사진에 적합 |
| PNG | `.png` | 투명도는 불투명으로 처리 |
| GIF | `.gif` | **첫 프레임**만 사용 |
| AVIF | `.avif` | Chromium 디코더 지원 필요 |
| WebP | `.webp` | 정적 WebP 권장 |

### 고화질 이미지

- 원본이 매우 커도 불러올 수 있습니다.
- **텍스처**: 긴 변 최대 **4096px**로 유지/축소
- **깊이 추정**: 긴 변 최대 **1280px**로 축소해 처리 (속도·안정성)

상태줄에 원본 해상도(MP)와 텍스처 축소 여부가 표시됩니다.

## 4. 기본 사용 흐름

1. **이미지 선택** — JPEG/PNG/GIF/AVIF/WebP 파일 선택
2. **깊이 모델 선택** — Small(빠름) / Base(권장) / Large(고품질) 등
3. (선택) **깊이 강도** — 앞뒤 과장 정도
4. (선택) **메시 해상도** — 160 빠름 / 256 보통 / 384 선명
5. **3D 공간 생성** 클릭
6. 오른쪽 뷰를 **클릭**해 마우스를 잠근 뒤 탐험

선택한 모델 이름·계열·용량 힌트가 사이드바에 표시되고, 생성 후에는 화면 왼쪽 아래에 HUD로도 남습니다.
캔버스에는 XYZ 축(빨강/초록/파랑)과 바닥 그리드가 함께 표시됩니다.

## 4.1 권장 모델

| 목적 | 모델 |
|------|------|
| 빠른 미리보기 | Depth Anything V2 Small |
| 일반 공간 탐색 (기본) | Depth Anything V2 Base |
| 최대 디테일 | Depth Anything V2 Large |

## 5. 조작법

| 입력 | 동작 |
|------|------|
| 뷰포트 클릭 | 마우스 잠금 (1인칭 시야) |
| 마우스 이동 | 시야 회전 |
| `W` `A` `S` `D` | 이동 |
| `Space` | 위로 |
| `Ctrl` | 아래로 |
| `Esc` | 마우스 잠금 해제 |

간단한 충돌·바닥 보정으로 메시와 많이 겹치지 않도록 막습니다. 완벽한 물리 엔진은 아닙니다.

## 6. 좋은 결과물을 위한 팁

- **실내·거리·풍경**처럼 깊이감이 분명한 사진이 유리합니다.
- 정면으로 공간이 열린 구도(복도, 방 입구, 거리)가 “걸어 들어가는” 느낌에 잘 맞습니다.
- 지나치게 흐리거나 단일 평면(흰 벽만)인 사진은 깊이가 밋밋해질 수 있습니다.
- 사람·물체가 화면을 가리면 그 뒤는 비어 보일 수 있습니다.

## 7. 문제 해결

### “no available backend found” / WASM 관련 오류

- `npm run copy-ort` 후 `npm run dev`를 다시 실행하세요.
- `src/renderer/public/ort/`에 `.wasm` / `.mjs` 파일이 있는지 확인하세요.
- 방화벽이 CDN을 막아도, WASM은 로컬 `/ort/`를 쓰도록 설정되어 있습니다. 모델 가중치 다운로드는 별도로 네트워크가 필요합니다.

### 이미지 열기 실패

- 지원 형식인지 확인하세요 (JPEG, PNG, GIF, AVIF, WebP).
- AVIF가 실패하면 PNG/JPEG로 변환해 시도하세요.
- 파일이 손상되지 않았는지 확인하세요.

### 모델 다운로드가 끝나지 않음

- **첫 실행만** 다운로드가 필요합니다. 이후에는 앱 데이터 폴더의 `hf-model-cache`를 사용합니다.
- 인터넷 연결을 확인하세요.
- 회사망·프록시 환경이면 Hugging Face 접근이 막혀 있을 수 있습니다.
- 잠시 기다린 뒤 다시 **3D 공간 생성**을 누르세요 (부분 캐시가 남을 수 있음).

### 공간이 찌그러져 보이거나 구멍이 보임

한 장 복원의 한계입니다. 깊이 강도·메시 해상도를 조절하거나, 다른 구도의 사진을 사용해 보세요.

### 앱이 열리지 않음

- Node/Electron 설치 스크립트가 막혔다면 `electron` 설치가 완료됐는지 확인하세요.
- `node_modules/electron/dist`에 실행 파일이 있는지 확인한 뒤 `npm run dev`를 재시도하세요.

## 8. 개인정보·데이터

- 선택한 이미지는 **로컬에서 처리**됩니다.
- 깊이 모델은 Hugging Face에서 내려받은 뒤 로컬 `hf-model-cache`에 저장되어 재사용됩니다.
- 이미지를 외부 서버로 업로드하는 기능은 없습니다.
