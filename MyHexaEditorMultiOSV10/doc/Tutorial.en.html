MyHexaMaster — Tutorial

The same steps the tutorial shows in the program (Help › Tutorial, Shift+F1).

Start page

1. MyHexaMaster

A hex editor for files of any size, disks and process memory, byte by byte — with templates, a disassembler, search, compare, checksums and recovery.

2. What to do

Open a file, start a new one, open a disk or process memory, compare or import from here. Dropping a file on the window opens it too.

3. Sample files

Samples — PNG, ZIP, ELF, PE, a disk image, firmware — let you try the templates and tools at once.

4. Tools

Strings, disassembler, calculator, recovery, disks, compare, templates and file tools are also on the toolbar; each opens in its own window.

The hex view

5. The hex view

Offsets on the left, bytes in the middle, characters on the right. 00 is dim; control characters, high values and FF have colours. The wheel and scroll bar move through files of any size at once.

6. Text column and character sets

The text column reads ASCII, Windows-1252, UTF-8, UTF-16, EUC-KR, Shift_JIS, EBCDIC and more. One Korean character takes three bytes in UTF-8.

7. Editing

Type hex digits to change bytes; changed bytes turn red. Insert switches insert / overwrite, Tab types in the text column. Undo is unlimited.

8. Data inspector

The bytes at the caret read as integers, floats, dates, GUIDs, IPs, colours… Double-click a value to change it. LE/BE switches the byte order.

9. Explorer

The left panel shows the computer's folders and the open documents. Double-click a file to open it.

Structure

10. Structure (templates)

For a known file type, a template takes the structure apart, shows it as a tree on the right and colours the hex view. Click an item to select its bytes.

11. Template editor

Write structures in a C-like language, run them and keep them as your own templates (010 Editor / ImHex style).

12. File information

Size, type, MIME, source, modified state, caret and selection at a glance.

13. Bookmarks

Ctrl+D puts a coloured bookmark on the caret or selection; F2 moves between them. They are kept per file.

Tools

14. Find and replace

Find hex (with ?? wildcards), text in many encodings, regular expressions, integers and floats. Find all lists and marks every match.

15. Go to

Go to an offset: from the start, forward, back or from the end, hex or decimal, optionally selecting from the caret.

16. Strings

Finds every ASCII, UTF-8 and UTF-16 string. Click a line to go there.

17. Disassembler

Decodes x86 (16/32/64) and ARM (32, Thumb, 64) code in Intel, NASM, MASM or GAS syntax.

18. File recovery

Finds files inside disk images or dumps by their headers, to open in a tab or save.

19. Compare

Two documents side by side with the different bytes coloured; F8 goes to the next difference. Insertions and deletions can be found too.

20. Calculator

Evaluates expressions and shows hex, decimal, octal, binary, signed, float and text. Take the value at the caret or write it there.

Data

21. Operations and transforms

Apply XOR, add, shifts, byte swaps, AES/DES/RC4, zlib/gzip and Base64 to the selection.

22. Checksums and hashes

Computes 36 algorithms at once: CRCs, Adler, MD5, SHA-1, SHA-2, SHA-3, BLAKE and more.

23. Statistics and entropy

The byte histogram and the per-block entropy graph show compressed or encrypted parts. Click the graph to go there.

24. Export

Export as a hex dump, source arrays (C, Python…), Base64, Intel HEX, S-record or HTML, and import them back.

Finish

25. Status bar

Caret offset, selection size, byte value, file size, INS/OVR and character set. Click an item for its window.

26. Themes

Choose among many light and dark themes, or make your own.

27. Settings

Bytes per row, grouping, bases, fonts, colours, copy format and the tools' defaults.

28. Done

You can start the tutorial again here at any time. Enjoy!
