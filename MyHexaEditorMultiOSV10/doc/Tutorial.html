MyHexaMaster — 따라하기

프로그램 안의 따라하기(도움말 › 튜토리얼, Shift+F1)와 같은 단계입니다.

시작 화면

1. MyHexaMaster

어떤 크기의 파일이든, 디스크와 프로세스 메모리까지 바이트 단위로 보고 고치는 헥사 편집기입니다. 템플릿·디스어셈블러·검색·비교·체크섬·복구 도구를 함께 씁니다.

2. 무엇을 할까요

파일 열기, 새 파일, 디스크·프로세스 메모리 열기, 비교, 가져오기를 여기서 시작합니다. 파일을 창에 끌어 놓아도 열립니다.

3. 예제 파일

PNG·ZIP·ELF·PE·디스크 이미지·펌웨어 같은 예제로 템플릿과 도구를 바로 시험해 볼 수 있습니다.

4. 도구

문자열·디스어셈블러·계산기·복구·디스크·비교·템플릿·파일 도구는 툴바에도 있고, 각자 창으로 열립니다.

헥사 보기

5. 헥사 보기

왼쪽은 오프셋, 가운데는 바이트, 오른쪽은 글자입니다. 00은 흐리게, 제어 문자·높은 값·FF는 색으로 나뉩니다. 휠과 스크롤 막대로 아무리 큰 파일도 바로 이동합니다.

6. 글자 열과 문자 집합

글자 열은 ASCII·Windows-1252·UTF-8·UTF-16·EUC-KR·Shift_JIS·EBCDIC 등으로 읽을 수 있습니다. 한글 한 글자는 UTF-8에서 3바이트입니다.

7. 편집

16진수를 치면 바로 바뀌고 바뀐 바이트는 빨갛게 보입니다. Insert 키로 끼워 넣기/덮어쓰기, Tab으로 글자 칸 입력. 실행 취소는 무제한입니다.

8. 데이터 검사기

커서 위치의 바이트를 정수·실수·날짜·GUID·IP·색 등으로 읽습니다. 값을 두 번 클릭하면 고쳐 씁니다. LE/BE로 바이트 순서를 바꿉니다.

9. 탐색기

왼쪽 패널은 컴퓨터의 폴더와 열린 문서를 보여 줍니다. 파일을 두 번 클릭하면 헥사 편집기로 열립니다.

구조

10. 구조 (템플릿)

파일 형식을 알아보면 템플릿이 구조를 풀어 오른쪽에 나무로 보여 주고 헥사 보기에 색을 칠합니다. 항목을 누르면 그 바이트를 선택합니다.

11. 템플릿 편집기

C 비슷한 언어로 구조를 직접 적어 실행하고, 내 템플릿으로 저장합니다(010 Editor·ImHex 방식).

12. 파일 정보

크기·형식·MIME·출처·바뀜 여부·커서와 선택 영역을 한눈에 봅니다.

13. 책갈피

Ctrl+D로 커서나 선택 영역에 색 책갈피를 넣고 F2로 오갑니다. 파일마다 기억됩니다.

도구

14. 찾기·바꾸기

16진수(?? 와일드카드), 여러 인코딩의 텍스트, 정규식, 정수·실수를 찾습니다. 모두 찾기는 결과를 목록과 표시로 보여 줍니다.

15. 이동

오프셋으로 이동합니다: 처음·앞·뒤·끝 기준, 16진/10진, 커서부터 선택.

16. 문자열 추출

ASCII·UTF-8·UTF-16 문자열을 모두 찾습니다. 줄을 누르면 그 위치로 갑니다.

17. 디스어셈블러

x86(16/32/64)과 ARM(32·Thumb·64) 코드를 Intel·NASM·MASM·GAS 문법으로 풉니다.

18. 파일 복구

디스크 이미지나 덤프 안에서 머리글로 파일을 찾아 새 탭으로 열거나 저장합니다.

19. 비교

두 문서를 나란히 놓고 다른 바이트를 칠합니다. F8로 다음 차이로 갑니다. 끼워 넣기·삭제도 찾을 수 있습니다.

20. 계산기

식을 계산하고 16·10·8·2진수, 부호, 실수, 글자로 바꿔 봅니다. 커서의 값을 가져오거나 커서에 씁니다.

데이터

21. 바이트 연산·변환

선택 영역에 XOR·더하기·시프트·바이트 순서 바꾸기, AES·DES·RC4 암호화, zlib·gzip 압축, Base64 등을 적용합니다.

22. 체크섬·해시

CRC·Adler·MD5·SHA-1·SHA-2·SHA-3·BLAKE 등 36가지를 한 번에 계산합니다.

23. 통계·엔트로피

바이트 분포와 블록별 엔트로피 그래프로 압축·암호화된 부분을 찾습니다. 그래프를 누르면 그 블록으로 갑니다.

24. 내보내기

헥스 덤프, C·Python 등 소스 배열, Base64, Intel HEX, S-record, HTML로 내보내고 같은 형식에서 가져옵니다.

마무리

25. 상태 표시줄

커서 오프셋, 선택 크기, 바이트 값, 파일 크기, INS/OVR, 문자 집합이 나옵니다. 항목을 누르면 관련 창이 열립니다.

26. 테마

여러 밝은·어두운 테마와 직접 만든 테마를 고를 수 있습니다.

27. 설정

한 줄 바이트 수, 묶음, 진법, 글꼴, 색, 복사 형식, 도구 기본값을 정합니다.

28. 끝

튜토리얼은 언제든 여기서 다시 볼 수 있습니다. 즐겁게 쓰세요!
