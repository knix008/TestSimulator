# 사용 설명서

## 화면

```
┌ 주 툴바 ─ 취소 · 다시 │ 저장 · 그림 · 데이터 ──── 언어 ▾ · 테마 ▾ · 설정 · 정보 │ ─ □ ✕ ┐
├ 옵션 툴바 ─ 눈색 · 투명 · 비움 · 상향 · ECI · 교체 · 배치 · 디자인 ┤
│ 내용            │ 인코딩            │ QR 코드                       │
│ 로고            │ 내보내기          │  (미리보기 · 버전 · 용량)       │
│ 디자인          │                   │                               │
└ 상태 표시줄 ─ 메시지 ……………………………………… 형식·크기 · 엔진 · ⋰ 크기 조절 ┘
```

- 주 툴바의 빈 곳을 끌면 창이 움직이고, 두 번 누르면 최대화됩니다.
- 창이 좁으면 툴바 버튼은 아이콘만 남깁니다(마우스를 올리면 이름이 보입니다).
- 오른쪽 아래 점 무늬를 끌면 창 크기를 바꿀 수 있습니다.
- 창의 위치와 크기는 닫을 때 기억했다가 다음 실행 때 그대로 엽니다.

## 1. 내용 넣기

**내용** 카드에서 종류를 고르고 입력합니다. 입력하는 즉시 QR 코드가 바뀝니다.

| 종류 | 입력 | 스캔하면 |
| --- | --- | --- |
| 텍스트 | 자유 텍스트 | 글자가 보임 |
| URL | 웹 주소 (`https://`가 없으면 붙임) | 브라우저로 열림 |
| Wi-Fi | 네트워크 이름, 비밀번호, 보안, 숨김 여부 | 바로 접속 |
| 연락처 | 이름, 회사, 직함, 전화, 이메일, 웹사이트, 주소, 메모 | 연락처에 저장 |
| 이메일 | 받는 사람, 제목, 본문 | 메일 작성 |
| SMS | 번호, 메시지 | 문자 작성 |
| 전화 | 번호 | 전화 걸기 |
| 위치 | 위도, 경도 | 지도 열기 |

**인코딩될 데이터**를 펼치면 실제로 들어가는 문자열과 글자·바이트 수를 볼 수 있습니다. Wi-Fi 비밀번호는 저장되지 않습니다.

## 2. 꾸미기

**디자인** 카드
- 모듈 모양: 사각 · 둥근 · 점 · 막대
- 눈 테두리 / 눈 중심: 사각 · 둥근 · 원 · 잎
- 색상: 전경, 배경, 눈(옵션 툴바의 **눈색**을 끄면 따로 지정), 끝 색상(그라데이션)
- 그라데이션: 없음 · 세로 · 대각선 · 원형
- 여백: 바깥 흰 테두리 폭(모듈 단위, 권장 4)

**로고** 카드
- **이미지 선택…** 또는 창에 그림 파일을 끌어다 놓으면 가운데에 들어갑니다. PNG, JPEG, GIF, WebP, BMP, ICO, SVG, AVIF, TIFF를 넣을 수 있습니다. 로고를 넣으면 오류 정정이 H로 바뀝니다.
- 크기는 −/+ 또는 막대로 조절합니다.
- 옵션 툴바의 **비움**을 켜면 로고 아래 모듈을 지워 깔끔하게 보입니다.

QR 코드 아래 **노란 경고**가 보이면 스캔이 안 될 수 있다는 뜻입니다(대비 부족, 색 반전, 좁은 여백, 너무 큰 로고).

## 3. 인코딩 (선택)

- **오류 정정** L 7% · M 15% · Q 25% · H 30%: 높을수록 일부가 가려져도 읽히지만 코드가 커집니다.
- **버전**: 자동 또는 1–40 고정(데이터가 들어가지 않으면 오류 메시지가 나옵니다).
- **마스크**: 자동(가장 읽기 좋은 것) 또는 0–7.
- 옵션 툴바: **상향**(같은 크기에 여유가 있으면 오류 정정을 올림), **ECI**(한글 등을 UTF-8로 표시 — 일부 오래된 리더용).

QR 코드 아래에 버전·오류 정정·마스크·모드와 용량 사용률이 표시됩니다.

## 4. 내보내기

1. 주 툴바의 **형식** 드롭다운에서 고릅니다.

   | 형식 | 특징 |
   | --- | --- |
   | PNG | 무손실, 투명 지원 — 일반적인 선택 |
   | JPEG | 손실 압축, 투명 부분은 흰색 · 품질 지정 |
   | WebP | 무손실, 투명 지원 |
   | GIF | 256색, 투명 켜짐/꺼짐 |
   | BMP · TIFF | 무압축 / 출판용 |
   | ICO | 16–256 px 아이콘 묶음 |
   | SVG | 벡터, 웹·편집 프로그램용 |
   | PDF · EPS | 벡터, 인쇄용 — 크기를 mm로 지정 |

2. **내보내기** 카드에서 크기(px, 기본 1024 · ↺로 기본값), 프리셋, JPEG 품질 또는 인쇄 크기(mm)를 정합니다. 해당하지 않는 항목은 흐리게 표시됩니다.
3. **저장**(Ctrl+S)을 누르면 형식 창이 열립니다. 형식을 고른 뒤 **저장**을 누르면 파일이 만들어집니다. Ctrl+Shift+S는 SVG로 바로 저장합니다. 웹 판에서는 다운로드됩니다.

**그림**은 클립보드에 그림으로, **데이터**는 인코딩된 문자열로 복사합니다. 결과는 상태 표시줄에 나옵니다.

## 5. 편집 기능

- **취소 / 다시**: 툴바 버튼, Ctrl+Z / Ctrl+Y(또는 Ctrl+Shift+Z). 한 칸에 이어서 입력한 글자나 막대 끌기는 한 단계로 묶입니다.
- **카드 옮기기**: 카드 제목 오른쪽의 ⠿ 손잡이를 끌어 원하는 열·위치에 놓습니다. 배치는 저장되며 **배치**로 되돌립니다(기본: QR 코드가 오른쪽).
- **교체**: 전경색과 배경색을 맞바꿉니다. **디자인**: 디자인만 기본값으로(로고는 유지).

## 6. 언어와 테마

주 툴바 오른쪽 드롭다운에서 한국어(ㅎㆍㄴ)/English(Aa), 시스템·라이트·다크를 고릅니다. 데스크톱 앱에서는 드롭다운 목록이 창 밖으로도 펼쳐집니다.

## 단축키

| 키 | 동작 |
| --- | --- |
| Ctrl+S | 형식을 고르고 저장 |
| Ctrl+Shift+S | SVG로 저장 |
| Ctrl+Z | 실행 취소 |
| Ctrl+Y, Ctrl+Shift+Z | 다시 실행 |
| ↑ ↓ Enter Esc | 드롭다운 목록 이동·선택·닫기 |
