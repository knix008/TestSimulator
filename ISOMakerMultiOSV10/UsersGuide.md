# 사용자 가이드 — ISO Maker Multi-OS

ISO Maker를 처음 쓰는 분을 위한 설치·기능별 사용법입니다.  
기술 구조는 [Architecture.md](./Architecture.md), 개발 실행은 [README.md](./README.md)를 참고하세요.

---

## 1. 설치

### 1.1 Windows 설치 파일 (권장)

배포본이 있다면:

1. `ISO Maker-Setup-<version>.exe`를 실행합니다.  
2. 설치 대상(현재 사용자 / 모든 사용자)과 폴더를 선택합니다.  
3. **바로 가기** 화면에서 다음을 각각 선택할 수 있습니다.  
   - 바탕 화면에 바로 가기  
   - 시작 메뉴에 바로 가기  
4. 이미 설치된 버전이 있으면 **완전히 제거된 뒤** 새 버전이 설치됩니다.  
5. 설치가 끝나면 앱을 실행합니다.

개발자용으로 설치 파일을 직접 만들려면:

```bash
npm install
npm run dist:win     # Windows .exe
npm run dist:mac     # macOS .dmg  (macOS에서 실행)
npm run dist:linux   # Linux .AppImage
```

결과물은 `release/`에 생성된 뒤 프로젝트 루트로 복사됩니다.  
예: `ISO Maker-Setup-0.1.0.exe`, `ISO Maker-0.1.0-arm64.dmg`, `ISO Maker-0.1.0.AppImage`

### 1.2 소스에서 실행

[Node.js 20+](https://nodejs.org) 설치 후:

```bash
npm install
npm start
```

Windows: `start.cmd` 더블클릭 (최초 실행 시 `npm install` 후 시작).

### 1.3 xorriso (생성·부팅 ISO·전체 추출)

**ISO 열기·트리 편집·파일 드래그 저장**은 xorriso 없이 동작합니다.  
폴더에서 ISO를 만들거나, 부팅 ISO·전체 폴더 추출을 쓰려면 **xorriso**가 필요합니다.

**Windows (MSYS2 권장)**

1. [MSYS2](https://www.msys2.org/) 설치  
2. MSYS2 터미널에서:

```bash
pacman -S xorriso
```

기본 경로 예: `C:\msys64\usr\bin\xorriso.exe`  
앱이 자동으로 이 경로를 찾습니다.

**macOS**

```bash
brew install xorriso
```

**Linux (Debian/Ubuntu 계열)**

```bash
sudo apt install xorriso
```

상태바에 **xorriso 버전**이 보이면 엔진이 준비된 것입니다.

## 2. 화면 구성

- **도구 모음** — ISO 열기 / 저장, 탭(내용·생성·부팅·마운트), 실행·폴더, 테마·언어·정보(우측 고정)  
- **작업 패널** — ISO 트리(내용 탭) 또는 각 탭의 경로·옵션  
- **변경 로그** (우측) — 열기·추가·삭제·드래그·저장 기록. 경계선을 드래그해 너비 조절  
- **상태 바** — 엔진, ISO 경로, 볼륨·항목 수, dirty(변경됨), 진행 메시지  

메뉴 막대는 사용하지 않습니다.

---

## 3. ISO 열기 · 편집 · 저장

1. 도구 모음에서 **ISO 열기**를 누릅니다.  
2. **내용** 탭에 트리가 채워집니다.  
3. 편집(추가·삭제·이름 변경 등)이 있으면 제목·상태에 **변경됨**이 표시됩니다.  
4. **ISO 저장**으로 새 `.iso` 파일을 만듭니다.  
   - 참고: 저장본은 데이터 ISO에 가깝고, **부팅 정보는 보존되지 않을 수 있습니다.**

### 3.1 선택

- 클릭 — 단일 선택  
- **Ctrl**(Windows/Linux) 또는 **⌘**(macOS) — 선택 토글  
- **Shift** — 범위 선택  
- 툴바 오른쪽에 선택 개수가 표시됩니다.

### 3.2 컨텍스트 메뉴 (우클릭)

| 항목 | 설명 |
|------|------|
| 외부로 저장… | 파일 1개 → 다른 이름으로 저장 / 여러 개 → 폴더 선택 후 일괄 저장 |
| 파일 추가… | 현재 폴더(또는 클릭한 항목의 부모)에 파일 추가 |
| 새 폴더… | 하위 폴더 생성 |
| 이름 바꾸기… | 한 개만 선택했을 때 |
| 삭제 | 선택 항목 삭제(여러 개 가능) |
| 경로 복사 | ISO 내부 경로 |

빈 영역 우클릭 시 루트에 추가/폴더 생성이 가능합니다.

### 3.3 Drag & Drop

- **외부 → 트리:** 파일을 폴더(또는 트리 배경=루트)에 놓으면 추가됩니다.  
- **트리 → 외부:** 파일에 마우스를 잠시 올린 뒤(준비 중 `…`) OS로 드래그합니다.  
  - 여러 파일을 선택한 뒤 그중 하나를 드래그하면 함께 나갑니다.  
  - **폴더는** 외부로 드래그할 수 없습니다(파일만).  
- 큰 파일은 준비에 시간이 걸릴 수 있습니다. 실패하면 로그를 확인하세요.

### 3.4 다른 ISO를 열거나 종료할 때

저장하지 않은 변경이 있으면:

- **저장 후 열기 / 저장 후 종료**  
- **저장 안 함**  
- **취소**

## 4. ISO 생성 (폴더 → ISO)

1. **생성** 탭을 엽니다.  
2. **소스 폴더** · **출력 ISO** · **볼륨 라벨**을 지정합니다.  
3. **ISO 만들기**(또는 도구 모음 실행)를 누릅니다.  

xorriso가 필요합니다. 일반 데이터 ISO에 적합합니다.

---

## 5. 부팅 ISO 생성

1. **부팅 ISO** 탭을 엽니다.  
2. 소스 폴더에 부트로더 이미지가 있어야 합니다.  
   - BIOS 예: `boot/grub/i386-pc/eltorito.img`  
   - UEFI 예: `EFI/BOOT/efiboot.img`  
3. BIOS / EFI 옵션과 경로를 맞춘 뒤 생성합니다.

일반적인 흐름: 기존 부팅 ISO **추출**(xorriso) → 폴더 수정 → **부팅 ISO**로 재생성.

---

## 6. ISO 마운트

1. **마운트** 탭에서 ISO를 선택합니다.  
2. **마운트** / **언마운트**를 사용합니다.

| OS | 동작 요약 |
|----|-----------|
| Windows | 가상 CD/DVD 드라이브 |
| macOS | `/Volumes/...` |
| Linux | FUSE 또는 시스템 mount |

마운트 이미지를 고쳐도 원본 ISO가 바뀌지 않는 경우가 많습니다.  
새 ISO가 필요하면 **내용 탭 편집 후 저장** 또는 **추출 → 생성**을 사용하세요.

## 8. 웹 모드 (보기·편집)

```bash
npm run start:web
```

또는 `start-web.cmd`.

- ISO를 열어 트리를 보고 일부 편집 후 다운로드할 수 있습니다.

## 9. 오류가 날 때

| 증상 | 확인할 것 |
|------|-----------|
| 엔진을 찾을 수 없음 | xorriso 설치(생성·부팅·전체 추출 시), MSYS2 `pacman -S xorriso` |
| 큰 ISO에서 일부 파일만 읽기 실패 | 파일이 완전한지(용량). 앱은 4GB 초과 ISO도 지원하도록 수정되어 있음 — 최신 빌드 사용 |
| 드래그가 안 됨 | 파일만 가능. 준비(`…`)가 끝난 뒤 다시 드래그 |
| 저장 후 PC에서 부팅 안 됨 | 세션 저장은 부팅 정보를 보장하지 않음 → 부팅 ISO 탭·xorriso 워크플로 사용 |
| 심볼릭 링크 경고(추출) | Windows에서는 정상일 수 있음 |
| 설치 시 바로가기 없음 | 설치 마법사에서 해당 체크박스를 켰는지 확인 |
| 창이 비어 있음 | `npm start` 재실행, Node 20+ |

오류 대화상자의 **복사**로 메시지를 남겨 두면 원인 파악에 도움이 됩니다.

## 10. 단축 팁

- ISO를 연 뒤 **트리로 내용 확인** → 필요한 파일만 드래그하거나 저장하세요.  
- 수 GB ISO는 드래그 준비·저장에 시간이 걸립니다. 변경 로그·상태 바를 확인하세요.  
- 마지막에 쓴 폴더는 기억됩니다.  
- `.iso`와 작업용 추출 폴더는 git에 넣지 마세요.
