## 1. 소개

**FTP Server Manager**는 Linux 및 macOS에서 동작하는 GTK3 기반의 파일 전송 서버 관리 프로그램입니다. 하나의 GUI에서 세 가지 프로토콜을 동시에 운영할 수 있습니다.

| 프로토콜 | 설명 |
|---------|------|
| **FTP** | RFC 959 기반 표준 파일 전송 프로토콜 (암호화 없음) |
| **FTPS** | FTP over Implicit TLS (포트 990, PKCS#12 인증서 필요) |
| **SFTP** | SSH 기반 보안 파일 전송 (포트 22, RSA 호스트 키 필요) |

## 2. 시스템 요구사항

### 운영체제
- Linux (Ubuntu 20.04 이상 권장) 또는 macOS 12 이상

### 필수 패키지 (자동 설치됨)

| 패키지 | 용도 |
|--------|------|
| `libgtk-3-dev` | GTK3 UI 라이브러리 |
| `libssl-dev` | OpenSSL (FTPS 암호화, 인증서) |
| `libssh-dev` | libssh (SFTP 서버) |
| `libjson-c-dev` | JSON 설정 파일 저장/로드 |

> `make` 실행 시 누락된 패키지를 자동으로 감지하여 `sudo apt-get install`로 설치합니다.

## 5. 프로토콜 설정

화면 상단 **프로토콜 설정** 프레임에서 활성화할 프로토콜과 포트를 지정합니다.

| 항목 | 기본값 | 설명 |
|------|--------|------|
| FTP 포트 | 21 | 표준 FTP 포트 |
| FTPS 포트 | 990 | Implicit TLS 전용 포트 |
| SFTP 포트 | 22 | SSH 기본 포트 |

> **주의**: 포트 21, 22, 990은 특권 포트(1024 미만)입니다. 사용하려면 프로그램을 `sudo`로 실행하거나, 방화벽·포트 포워딩으로 상위 포트(예: 2121)에서 리디렉션해야 합니다.

### 1024 이상 포트 예시

| 프로토콜 | 권장 대체 포트 |
|---------|--------------|
| FTP | 2121 |
| FTPS | 9900 |
| SFTP | 2222 |

## 6. 공유 폴더 설정

### 개념

| 용어 | 설명 |
|------|------|
| **가상 이름** | FTP 클라이언트에게 보이는 디렉터리 이름 |
| **실제 경로** | 서버 파일시스템의 실제 디렉터리 경로 |

### 폴더 추가

1. **[+ 추가]** 버튼 클릭
2. 가상 이름 입력 (예: `data`, `public`)
3. 실제 경로 직접 입력 또는 **[…]** 버튼으로 디렉터리 선택
4. **[추가]** 클릭

### 단일 폴더 vs. 다중 폴더

**단일 폴더** (가상 이름을 비워 두거나 `/`로 설정):
- FTP 루트 `/`가 해당 폴더로 직접 매핑됩니다.
- 예: 실제 경로 `/home/user/share` → 클라이언트에서 `/` = `/home/user/share`

**다중 폴더** (각각 가상 이름 지정):
- FTP 루트 `/` 아래에 각 가상 이름의 하위 디렉터리가 생성됩니다.
- 예: 가상 이름 `docs` → 클라이언트에서 `/docs`로 접근

### 폴더 제거

목록에서 항목 선택 후 **[- 제거]** 클릭.

## 7. 사용자 인증 설정

### 익명 접근

**익명 접근 허용** 체크박스를 활성화하면 `anonymous` 계정으로 비밀번호 없이 접속할 수 있습니다 (읽기 전용).

### 사용자 추가

1. 인증 프레임의 **[+ 추가]** 버튼 클릭
2. 사용자 이름과 비밀번호 입력
3. 권한 설정:
   - **읽기**: 파일 다운로드, 디렉터리 목록 조회
   - **쓰기**: 파일 업로드, 삭제, 이름 변경, 디렉터리 생성/삭제
4. **[추가]** 클릭

### 사용자 편집

사용자 목록에서 항목을 더블클릭하면 편집 다이얼로그가 열립니다.

### 사용자 삭제

목록에서 항목 선택 후 **[- 제거]** 클릭.

### 권한 표시

| 표시 | 의미 |
|------|------|
| 읽기 | 읽기만 가능 |
| 쓰기 | 쓰기만 가능 |
| 읽기+쓰기 | 모두 가능 |
| 없음 | 로그인 후 접근 불가 |

## 8. FTPS 인증서 설정

FTPS를 사용하려면 PKCS#12 형식(`.pfx` 또는 `.p12`)의 인증서가 필요합니다.

### 자체 서명 인증서 생성 (권장)

1. **프로토콜 설정**에서 **FTPS** 체크박스 활성화
2. FTPS 인증서 프레임의 **[생성]** 버튼 클릭
3. 다음 항목 입력:

| 항목 | 예시 | 설명 |
|------|------|------|
| Common Name | `myserver.local` | 서버 식별 이름 |
| 유효 기간 (년) | `10` | 인증서 유효 기간 |
| 비밀번호 | `mypassword` | PFX 파일 보호 비밀번호 |
| 저장 경로 | `/home/user/server.pfx` | 저장할 파일 경로 |

4. **[생성]** 클릭 → 인증서 경로와 비밀번호가 자동으로 설정됩니다.

### 기존 인증서 사용

1. **[…]** 버튼으로 `.pfx` 또는 `.p12` 파일 선택
2. **비밀번호** 입력란에 해당 인증서의 비밀번호 입력

> FTPS 체크박스를 비활성화하면 인증서 설정 영역이 비활성화됩니다.

## 9. SFTP 호스트 키 설정

SFTP 서버는 클라이언트 인증을 위해 RSA 호스트 키가 필요합니다.

### 호스트 키 자동 생성

1. **프로토콜 설정**에서 **SFTP** 체크박스 활성화
2. SFTP 호스트 키 프레임의 **[생성]** 버튼 클릭
3. 키가 `~/.config/FTPServerGTK/ssh_host_rsa_key`에 생성됩니다.
4. 지문(fingerprint)이 화면에 표시됩니다. 클라이언트 최초 접속 시 이 값을 확인하세요.

### 서버 재시작 시 키 재사용

이미 생성된 키가 있으면 서버 시작 시 자동으로 로드됩니다. 키를 교체하려면 **[생성]** 버튼을 다시 클릭하세요.

### 키 파일 위치 확인

**[폴더 열기]** 버튼을 클릭하면 키 파일이 있는 디렉터리가 파일 관리자에서 열립니다.

### 지문(Fingerprint) 확인

지문은 `SHA256:xxxx...` 형식으로 표시됩니다. 클라이언트(FileZilla, WinSCP, `sftp` 명령어 등)에서 최초 접속 시 호스트 키를 수락할 때 이 값과 일치하는지 확인하세요.

> SFTP 체크박스를 비활성화하면 키 설정 영역이 비활성화됩니다.

## 10. 성능 설정

| 항목 | 기본값 | 설명 |
|------|--------|------|
| 버퍼 크기 (KB) | 64 | 파일 전송 시 사용하는 I/O 버퍼 크기 |
| 최대 스레드 | 10 | 동시 접속 처리에 사용되는 최대 스레드 수 |

- **버퍼 크기**를 크게 하면 대용량 파일 전송 속도가 향상되지만 메모리 사용량이 증가합니다. 권장 범위: 32~512 KB.
- **최대 스레드**는 동시 클라이언트 수의 상한입니다. 실제 연결은 각 클라이언트당 하나의 스레드가 할당됩니다.

## 11. 프로파일 관리

설정을 이름을 붙여 저장하고 불러올 수 있습니다. 여러 서버 환경(개발용, 운영용 등)을 전환할 때 유용합니다.

### 프로파일 저장

1. 프로파일 입력란에 이름 입력 (예: `production`)
2. **[저장]** 버튼 클릭
3. `~/.config/FTPServerGTK/profiles/<이름>.json`에 저장됩니다.

### 프로파일 불러오기

드롭다운에서 저장된 프로파일 이름 선택 → 설정이 자동으로 적용됩니다.

### 프로파일 삭제

드롭다운에서 삭제할 프로파일 선택 후 **[삭제]** 버튼 클릭.

### 자동 저장

프로그램 종료 시 현재 설정이 `~/.config/FTPServerGTK/settings.json`에 자동으로 저장되고, 다음 실행 시 자동으로 복원됩니다.

## 12. 서버 시작 및 중지

### 시작

1. 공유 폴더를 하나 이상 추가합니다.
2. 사용할 프로토콜을 하나 이상 체크합니다.
3. 우측 상단의 **[▶  시작]** 버튼을 클릭합니다.

서버가 정상적으로 시작되면 버튼이 **[■  중지]** (빨간색)로 변경됩니다.

### 시작 실패 원인

| 상황 | 해결 방법 |
|------|-----------|
| 공유 폴더 없음 | 폴더를 하나 이상 추가 |
| 프로토콜 미선택 | 하나 이상 체크 |
| 포트 이미 사용 중 | 다른 포트 번호로 변경 |
| FTPS 인증서 미설정 | 인증서 경로와 비밀번호 입력 |
| FTPS 인증서 오류 | 비밀번호 확인 또는 인증서 재생성 |
| 포트 1024 미만 (권한 없음) | `sudo ./ftpserver` 또는 1024 이상 포트 사용 |

### 중지

**[■  중지]** 버튼 클릭 → 현재 연결된 클라이언트와의 세션이 종료됩니다.

## 14. 클라이언트 연결 방법

### FTP — FileZilla

1. 서버: `<서버 IP>`
2. 사용자명: 설정한 사용자 이름
3. 비밀번호: 설정한 비밀번호
4. 포트: `21` (또는 설정한 포트)
5. 프로토콜: FTP

### FTPS — FileZilla

1. 서버: `<서버 IP>`
2. 사용자명, 비밀번호 입력
3. 포트: `990` (또는 설정한 포트)
4. 프로토콜: **FTP over TLS (Implicit)**
5. 자체 서명 인증서 경고가 뜨면 **[확인]** 클릭 (인증서 신뢰)

### SFTP — FileZilla

1. 서버: `<서버 IP>`
2. 사용자명, 비밀번호 입력
3. 포트: `22` (또는 설정한 포트)
4. 프로토콜: **SFTP**
5. 호스트 키 경고가 뜨면 지문을 확인 후 **[확인]** 클릭

### SFTP — 터미널

```bash
sftp -P 22 username@<서버 IP>
```

### FTP — 터미널

```bash
ftp <서버 IP> 21
```

### Python 스크립트 예시 (FTP)

```python
from ftplib import FTP

with FTP() as ftp:
    ftp.connect('192.168.1.100', 21)
    ftp.login('username', 'password')
    print(ftp.nlst())       # 파일 목록
    ftp.retrbinary('RETR file.txt', open('file.txt', 'wb').write)
```

### Python 스크립트 예시 (SFTP, paramiko)

```python
import paramiko

transport = paramiko.Transport(('192.168.1.100', 22))
transport.connect(username='username', password='password')
sftp = paramiko.SFTPClient.from_transport(transport)
sftp.get('/remote/file.txt', 'local_file.txt')
sftp.close()
transport.close()
```

## 15. 설정 파일 위치

| 파일 | 경로 | 설명 |
|------|------|------|
| 기본 설정 | `~/.config/FTPServerGTK/settings.json` | 종료 시 자동 저장 |
| 프로파일 | `~/.config/FTPServerGTK/profiles/<이름>.json` | 수동 저장 |
| 로그 파일 | `~/.config/FTPServerGTK/ftpserver.log` | 실행 중 자동 기록 |
| SFTP 호스트 키 | `~/.config/FTPServerGTK/ssh_host_rsa_key` | 키 생성 시 저장 |

### 설정 초기화

설정을 초기화하려면 다음 명령어를 실행합니다.

```bash
rm -rf ~/.config/FTPServerGTK
```

## 16. 문제 해결

### 서버가 시작되지 않는다

```
포트 21 (또는 22, 990)을 사용 중인 다른 프로세스가 있는지 확인:
```

```bash
sudo ss -tlnp | grep ':21\|:22\|:990'
```

또는 1024 이상의 포트(2121, 2222, 9900)로 변경 후 다시 시작합니다.

### 클라이언트가 접속되지만 파일 목록이 보이지 않는다

- **공유 폴더 실제 경로**가 존재하는지 확인합니다.
- 경로에 대한 읽기 권한이 있는지 확인합니다.

```bash
ls -la /path/to/shared/folder
```

### FTPS 인증서 오류

- 비밀번호가 인증서 생성 시 입력한 것과 동일한지 확인합니다.
- 인증서를 다시 생성합니다: **[생성]** 버튼 클릭.
- OpenSSL로 인증서를 직접 검증합니다.

```bash
openssl pkcs12 -info -in server.pfx -noout
```

### SFTP 호스트 키 불일치 오류

클라이언트의 `~/.ssh/known_hosts`에 이전 키가 저장되어 있을 수 있습니다.

```bash
# 기존 키 항목 제거 (클라이언트에서 실행)
ssh-keygen -R <서버 IP>
```

### 로그에 "Permission denied" 오류

- 사용자 계정에 쓰기 권한이 없는 경우입니다.
- 인증 설정에서 해당 사용자의 **쓰기** 권한을 활성화합니다.

### 빌드 오류: 패키지를 찾을 수 없음

```bash
sudo apt-get update
sudo apt-get install libgtk-3-dev libssl-dev libssh-dev libjson-c-dev
```

### macOS에서 패키지 설치

```bash
brew install gtk+3 openssl libssh json-c
```
