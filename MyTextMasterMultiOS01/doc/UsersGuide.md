# MyTextMaster 사용 설명서

MyTextMaster 는 **Markdown**, **HTML**, **텍스트** 문서를 쓰고 고치는 편집기입니다. Notepad++ 와 TextMate 의 편집 기능(탭, 구문 강조, 찾기·바꾸기, 파일에서 찾기, 책갈피, 매크로, 여러 커서, 스니펫, 인코딩 변환)에 Markdown 미리 보기와 **WYSIWYG** 편집, 그림·동영상·오디오·PDF 보기, **헥사 편집기**, 영어·한국어 **맞춤법 검사**를 더했습니다. Windows, macOS, Linux 데스크톱 프로그램(Tauri)과 웹 브라우저에서 같은 화면으로 실행됩니다.

## 1. 설치와 실행

| 플랫폼 | 설치 파일 | 만드는 명령 |
| --- | --- | --- |
| Windows | `MyTextMaster-Setup-<버전>.exe` | `npm run build:win` |
| macOS | `MyTextMaster-<버전>-<arch>.dmg` | `npm run build:mac` |
| Linux | `.deb` / `.rpm` / `.AppImage` | `npm run build:linux` |
| 웹 | `MyTextMaster-Web-<버전>.zip` | `npm run build:webapp` |

- `npm run build:all` 은 지금 운영체제의 설치 파일과 웹 앱을 함께 만듭니다. 만든 파일은 `release/` 와 프로젝트 루트에 복사됩니다.
- 개발 중에는 `npm start` 로 데스크톱 창을, `npm run dev` 로 브라우저 버전(<http://localhost:1472>)을 띄웁니다.
- 웹 앱은 압축을 풀어 아무 웹 서버(정적 호스팅)에 올리면 됩니다. 탐색기, 파일에서 찾기처럼 디스크를 직접 다루는 기능은 데스크톱 버전에만 있습니다.
- 프로그램은 여러 개를 동시에 띄울 수 있습니다. Windows 설치 프로그램은 `.md` 파일을 MyTextMaster 로 열 수 있게 등록합니다.

## 2. 화면 구성

창에는 운영체제의 제목 표시줄이 없습니다. 맨 위 줄이 제목 표시줄을 겸합니다.

| 부분 | 하는 일 |
| --- | --- |
| **메뉴 막대** | 프로그램 아이콘·이름·버전·지금 문서 이름, 홈, 파일·편집·서식·삽입·도구·매크로·보기·도움말 메뉴, 오른쪽 끝의 최소화·최대화·닫기. 빈 곳을 끌면 창이 움직이고 두 번 누르면 최대화됩니다. `Alt` 만 누르면 파일 메뉴가 열립니다. |
| **도구 모음** | 자주 쓰는 명령의 단추. 마우스를 올리면 이름과 바로 가기 키가 바로 보입니다. 창을 줄여도 단추가 잘리지 않도록 창의 최소 폭이 정해져 있습니다. |
| **왼쪽 패널** | 탐색기 · 개요 · 열린 문서 |
| **문서 탭** | 열린 문서마다 탭 하나. `●` 는 저장하지 않은 문서입니다. |
| **편집 영역** | 편집기와 미리 보기(나란히), 또는 WYSIWYG, 또는 뷰어(그림·동영상·PDF·헥사·사용 설명서) |
| **오른쪽 패널** | 정보(줄 카운터·통계·파일 정보·해시) · 책갈피 · 파일에서 찾기 |
| **아래 패널** | 문제(문서 검사와 맞춤법) · 로그 |
| **상태 표시줄** | 문서 종류·구문, 줄 카운터(현재 줄/전체 줄, 열), 단어·글자 수, 문제 수, 저장 상태, 맞춤법 사전, 들여쓰기, 줄 끝, 인코딩 |
| **크기 조절 마커** | 오른쪽 아래의 점 모양. 끌어서 창 크기를 바꿉니다. |

### 패널 접고 펴기

- 도구 모음의 **왼쪽 패널** · **아래 패널** · **오른쪽 패널** 단추로 켜고 끕니다(`Ctrl+Shift+B` · `Ctrl+Shift+J` · `Ctrl+Alt+B`).
- 각 패널의 제목 줄에는 아이콘·이름·탭 단추와 **접기** 단추(`‹` `›` `⌄`)가 있습니다. 접은 왼쪽·오른쪽 패널은 아이콘만 있는 좁은 막대가 되고, 그 아이콘을 누르면 해당 탭으로 다시 펴집니다.
- 패널 경계선을 끌어 폭과 높이를 바꿉니다. 크기와 열림 상태는 기억됩니다.

## 3. 시작 화면

프로그램을 켜면 시작 화면이 나옵니다(설정에서 끌 수 있습니다). 메뉴 막대의 **홈** 을 누르면 언제든 다시 나오고, 한 번 더 누르면 편집하던 문서로 돌아갑니다.

- **바로 가기**: 열기, 새 Markdown·HTML·텍스트, 붙여 넣어 새 문서, 폴더 열기(탐색기), 사용 설명서, 테마 설정, 언어 전환, 설정, 정보, 끝내기.
- **최근 항목**: 최근 파일과 최근 폴더. 폴더를 누르면 탐색기에서 열립니다. `×` 는 목록에서만 뺍니다.
- **새로 만들기**: 서식 파일 10가지(빈 Markdown·HTML·텍스트, README, 회의록, 블로그 글, 할 일 목록, 변경 기록, 웹 페이지, 편지).
- **예제 문서**: Markdown 10개, HTML 10개, 텍스트·코드 10개(Python, SQL, YAML, INI, CSS, TSV, JSON, 로그…). 고친 뒤 저장하면 내 파일이 됩니다.
- **테마**: 밝은 테마 20개, 어두운 테마 20개.
- **움직이는 배경**: 20가지 배경, 바꾸기, 멈추기, 속도, 카드 불투명도, 자동 변경 간격.

카드는 왼쪽 위 `≡` 손잡이로 끌어 옮기고, 오른쪽 아래 모서리로 크기를 바꿉니다. 모서리를 두 번 누르면 내용에 맞춰지고, **자동 정렬** 은 처음 배치로 되돌립니다.

## 4. 탐색기 (왼쪽 패널)

- 맨 위에 **시스템 드라이브**(Windows 는 `C:` `D:` …, macOS·Linux 는 `/` 와 연결된 볼륨)와 **홈 · 바탕 화면 · 문서 · 다운로드** 가 아이콘으로 보입니다. 누르면 그 위치가 탐색기의 뿌리 폴더가 됩니다.
- 아래에는 고른 폴더의 **트리**가 있습니다. 폴더를 누르면 펼쳐져 안의 폴더와 파일(크기 포함)이 보이고, 파일을 누르면 열립니다.
- 도구 줄: 상위 폴더, 폴더 고르기(`Ctrl+Shift+F2`), 지금 문서의 폴더, 새로 고침, 숨김 파일 보이기, 모두 접기.
- 파일을 오른쪽 단추로 누르면: 열기, 헥사 편집기로 열기, 기본 프로그램으로 열기, 경로 복사, 이 폴더에서 찾기.
- 탭의 오른쪽 단추 메뉴 › **탐색기에서 보기** 는 그 문서가 있는 폴더를 펼쳐 보여 줍니다.
- 같은 패널의 **개요** 탭은 문서의 제목 목록(목차), **열린 문서** 탭은 열린 문서 목록입니다.

## 5. 문서 다루기

### 새로 만들기와 열기

- **새 문서** (`Ctrl+N`): 설정의 "새 문서 종류"(기본 Markdown). 탭 줄의 `+` 나 빈 곳 두 번 누르기도 같습니다.
- **서식 파일로 새로 만들기**, **붙여 넣어 새 문서**(클립보드 글로, 종류는 자동으로 짐작).
- **열기…** (`Ctrl+O`): 여러 파일을 한 번에. 탐색기에서 창으로 **끌어다 놓아도** 열립니다.
- 문서 종류는 확장자로 정해집니다: Markdown(`.md`…), HTML(`.html`…), 텍스트(`.txt` 와 코드·설정 파일), **그림**·**동영상**·**오디오**·**PDF**(뷰어로), 이진 파일(헥사 편집기로). 텍스트가 아닌 파일은 자동으로 헥사 편집기에서 열립니다.

### 저장

- **저장** (`Ctrl+S`), **다른 이름으로 저장…** (`Ctrl+Shift+S`), **모두 저장** (`Ctrl+Alt+S`).
- 문서가 원래 쓰던 **인코딩**(UTF-8, UTF-8 BOM, UTF-16 LE/BE, EUC-KR)과 **줄 끝**(LF, CRLF)을 그대로 씁니다. 상태 표시줄에서 바꿀 수 있습니다.
- 저장은 임시 파일에 먼저 쓴 뒤 바꿔치기하므로 원래 파일이 망가지지 않습니다.
- 다른 프로그램이 파일을 바꾸면 창으로 돌아올 때 알려 줍니다. **자동 저장**(설정 › 파일)과 **지난 문서 다시 열기**(저장 안 한 글 포함)가 있습니다.

### 탭

- `×`, 가운데 단추, **탭 닫기** (`Ctrl+W`). 저장하지 않았으면 **저장 / 저장 안 함 / 취소** 를 묻습니다.
- 오른쪽 단추 메뉴: 다른 탭 닫기, 오른쪽 탭 닫기, 모두 닫기, 저장, 이름 바꾸기, 헥사 편집기로 열기, 경로·파일 이름 복사, 들어 있는 폴더 열기, 탐색기에서 보기.
- `Ctrl+Tab` / `Ctrl+Shift+Tab` 으로 탭을 옮겨 다닙니다.

## 6. 편집

| 기능 | 방법 |
| --- | --- |
| 찾기 / 바꾸기 | `Ctrl+F` / `Ctrl+H` — 대소문자, 단어 단위, 정규식, 모두 바꾸기 |
| 파일에서 찾기 | `Ctrl+Shift+F` — 오른쪽 패널. 폴더·확장자·대소문자·단어 단위를 정하고, 결과를 누르면 그 줄로 갑니다 (데스크톱) |
| 줄로 이동 | `Ctrl+G` 또는 상태 표시줄의 줄 카운터 |
| 여러 커서 | `Alt+클릭`, 같은 단어 하나 더 선택 `Ctrl+D`, 사각 선택 `Alt+끌기` |
| 줄 옮기기 / 복제 | `Alt+↑/↓`, `Shift+Alt+↓` |
| 들여쓰기 · 주석 | `Tab` / `Shift+Tab`, `Ctrl+]` / `Ctrl+[`, `Ctrl+/` |
| 접기 | 줄 번호 옆 `⌄`, **모두 접기** `Alt+0`, **모두 펼치기** `Alt+Shift+0` |
| 책갈피 | `Ctrl+F2` 설정/해제(또는 줄 번호 왼쪽 칸 누르기), `F2` 다음, `Shift+F2` 이전, 오른쪽 패널 **책갈피** 탭에 목록 |
| 자동 완성 · 스니펫 | 문서에 있는 단어를 자동 완성합니다. Markdown 은 `h1` `link` `img` `table` `code` `task` `details` `front` …, HTML 은 `html5` `a` `img` `div` `ul` `table` `form` … 을 쓰고 목록에서 고르면 칸이 있는 틀이 들어가고, `Tab` 으로 다음 칸으로 갑니다 |
| 읽기 전용 | **편집 › 읽기 전용** |

마우스 오른쪽 단추 메뉴에는 맞춤법 추천 단어, 실행 취소, 잘라내기·복사·붙여넣기, 찾기, 책갈피, 굵게, 링크, 대소문자, 인코드가 있습니다.

### 매크로 (Notepad++ 방식)

1. **매크로 › 매크로 녹화 시작** (`Ctrl+Shift+R`). 메뉴 막대에 빨간 **REC** 가 깜빡입니다.
2. 글을 쓰고 키(Enter, 방향키, 삭제, `Ctrl+…` 명령)를 누릅니다.
3. **녹화 중지** (`Ctrl+Shift+T`).
4. **매크로 실행** (`Ctrl+Shift+P`) 은 한 번, **여러 번 실행…** 은 횟수를 정해 되풀이합니다.

## 7. 서식과 삽입

서식 명령은 **Markdown 문서에는 Markdown 기호를, HTML 문서에는 HTML 태그를** 넣습니다. 한 번 더 누르면 풀립니다. WYSIWYG 에서는 보이는 글에 바로 적용됩니다.

| 명령 | 키 | Markdown | HTML |
| --- | --- | --- | --- |
| 굵게 / 기울임 / 취소선 | `Ctrl+B` / `Ctrl+I` / `Ctrl+Shift+X` | `**` / `*` / `~~` | `<strong>` / `<em>` / `<del>` |
| 인라인 코드 | ``Ctrl+` `` | `` ` `` | `<code>` |
| 제목 1–4, 본문 | `Ctrl+1`…`Ctrl+4`, `Ctrl+0` | `#`…`####` | `<h1>`…`<h4>`, `<p>` |
| 글머리 / 번호 / 할 일 목록 | `Ctrl+Shift+8` / `7` / `9` | `-` / `1.` / `- [ ]` | `<ul>` / `<ol>` |
| 인용 | `Ctrl+Shift+Q` | `>` | `<blockquote>` |
| 링크 / 그림 / 코드 블록 | `Ctrl+K` / `Ctrl+Shift+I` / `Ctrl+Shift+C` | `[글](주소)` / `![설명](경로)` / ```` ``` ```` | `<a>` / `<img>` / `<pre><code>` |

**삽입** 메뉴에는 표(열·행 수), 구분선, 각주, 날짜와 시간(`F5`)도 있습니다.

## 8. 그림을 글자처럼

- Markdown·HTML 문서의 `![설명](경로)` 나 `<img>` 뒤에는 **그림이 글 줄 안에 작게 보입니다**(보기 › 편집기에 그림 보이기). 글자처럼 지우면 그림도 사라집니다.
- 탐색기(파일 관리자)에서 **그림 파일을 문서 위로 끌어다 놓으면** 놓은 자리에 들어갑니다. 스크린샷을 **붙여 넣어도**(`Ctrl+V`) 됩니다.
  - 저장된 문서: 그림이 문서 옆 `images/` 폴더로 복사되고 `![이름](images/이름.png)` 가 들어갑니다(같은 이름이 있으면 `-2`, `-3` 을 붙입니다).
  - 저장하지 않은 문서와 웹 버전: 그림이 문서 안에 데이터(data URL)로 들어갑니다.
- WYSIWYG 에서도 그림은 한 글자처럼 선택하고 지우고, 끌어다 놓고 붙여 넣을 수 있습니다.

## 9. 미리 보기와 WYSIWYG

- **보기 › 편집기만 / 나란히 보기 / 미리 보기만 / WYSIWYG**, `Ctrl+\` 로 차례로 바꿉니다(WYSIWYG 은 Markdown 만). 가운데 경계선을 끌어 폭을 나눕니다.
- **스크롤 맞추기**: 나란히 볼 때 한쪽을 스크롤하면 다른 쪽이 같은 곳을 보여 줍니다. 커서가 있는 문단에는 미리 보기 왼쪽에 주황색 표시가 붙습니다.
- **WYSIWYG** (`Ctrl+Shift+W`): 미리 보기 모양 그대로 글을 고칩니다. 도구 모음과 바로 가기 키(굵게, 제목, 목록, 링크, 표, 그림…)가 보이는 글에 적용되고, 고친 내용은 곧바로 Markdown 원문으로 바뀌어 저장됩니다. 할 일 목록의 체크 상자도 누를 수 있습니다. 링크는 `Ctrl+클릭` 으로 엽니다. 처음 고칠 때 원문이 표준 Markdown 모양(목록 기호 `-`, 제목 `#` 등)으로 한 번 정리될 수 있습니다.
- **Markdown 요소 막대**: WYSIWYG 에서는 문서 탭 바로 아래에 Markdown 으로 쓸 수 있는 모든 요소가 단추로 나옵니다. 단추마다 아이콘과 그 요소가 쓰는 Markdown(`#`, `**B**`, `- [ ]` …)이 보이고, 누르면 선택한 글이나 커서 자리에 바로 적용됩니다. 커서가 있는 곳의 서식(굵게, 제목 수준, 목록 …)은 단추가 켜진 모양으로 표시되고, 켜진 단추를 다시 누르면 풀립니다.
  - **제목**: 제목 1–6, 본문 문단
  - **글자**: 굵게, 기울임, 굵게 + 기울임, 취소선, 인라인 코드, 링크, 그림, 줄 바꿈(문단 안에서), 서식 지우기
  - **문단**: 글머리 기호 목록, 번호 목록, 할 일 목록, 인용, 코드 블록, 표, 구분선
  - **HTML**(Markdown 안에 쓸 수 있는 태그): `<kbd>` 키보드 키, `<mark>` 형광펜, `<u>` 밑줄, `<sup>` 위 첨자, `<sub>` 아래 첨자
- **미리 보기 스타일**: GitHub, 문서, 논문, 단순.
- **안전**: Markdown 미리 보기와 WYSIWYG 은 스크립트를 실행하지 않고 위험한 속성을 지웁니다. HTML 문서도 기본으로 스크립트를 실행하지 않습니다(설정 › 미리 보기에서 켤 수 있음 — 이때 미리 보기는 프로그램과 분리됩니다).

## 10. 뷰어와 헥사 편집기

여러 종류의 파일을 팝업 창이 아니라 **메인 창의 탭**으로 보여 줍니다.

| 파일 | 보기 |
| --- | --- |
| 그림 (png, jpg, gif, webp, bmp, ico, avif) | 창에 맞춤(`0`) / 실제 크기(`1`), 확대·축소(`+` `−`, `Ctrl+휠`, 5 %–3200 %), 끌어서 이동, 두 번 누르기 맞춤⇄실제, 회전(`R` / `Shift+R`), 그림 복사, PNG·JPEG·WebP·BMP 로 저장, 인쇄 |
| 동영상 (mp4, webm, mkv, mov …) · 오디오 (mp3, wav, flac, ogg …) | 재생기(재생·탐색·음량·전체 화면), `←` `→` 5초, `M` 음소거. 해상도·길이·크기 표시 |
| PDF | 내장 PDF 뷰어 |
| 이진 파일 | **헥사 편집기** |

### 헥사 편집기

- 오프셋 · 16바이트(8+8) · ASCII 열. 수십 MB 파일도 부드럽게 스크롤합니다.
- 바이트나 글자를 누르고 16진수(헥사 열) 또는 글자(ASCII 열)를 입력해 고칩니다. `Tab` 으로 열을 바꿉니다.
- `Insert` 로 덮어쓰기(OVR)/삽입(INS) 전환, `Delete`/`Backspace` 로 바이트 삭제, `Shift`+방향키나 끌기로 선택, `Ctrl+Z`/`Ctrl+Y` 로 되돌리기.
- `Ctrl+G` 오프셋으로 이동(`0x1F` 또는 `31`), `Ctrl+F` 바이트(`DE AD BE EF`)나 글자 찾기, `Ctrl+C` 선택한 바이트를 16진수로 복사.
- 상태 표시줄에 커서 위치의 값(10진·16진·2진, 16/32비트 정수·실수 LE/BE)이 보입니다.
- 텍스트 문서도 **파일 › 헥사 편집기로 열기** 로 바이트를 볼 수 있습니다.

## 11. 맞춤법 검사와 사용자 사전

- **영어**(Hunspell en_US)와 **한국어**(Hunspell ko) 사전으로 검사합니다. 틀린 단어에 빨간 물결 밑줄이 생기고, 아래 패널 **문제** 에도 나옵니다. 코드, 주소, 태그, `CamelCase` 이름은 검사하지 않습니다.
- `F7` 또는 도구 모음의 **ABC** 단추로 켜고 끕니다. **도구 › 맞춤법 사전** 에서 영어 + 한국어 / 영어 / 한국어를 고릅니다.
- 틀린 단어를 **마우스 오른쪽 단추**로 누르면 추천 단어와 **사전에 추가** 가 나옵니다.
- **도구 › 사용자 사전…** 에서 단어를 추가·찾기·빼기, 텍스트 파일(한 줄에 한 단어)로 가져오기·내보내기, 모두 지우기를 할 수 있습니다.

## 12. 도구

- **대소문자**, **줄**(오름·내림·길이순 정렬, 뒤집기, 중복 지우기, 앞·뒤·앞뒤 공백 지우기, 빈 줄 지우기, 합치기 `Ctrl+J`, 줄 번호 붙이기), **탭과 공백**.
- **인코드·디코드**: Base64, URL, HTML 특수 문자, **해시**(SHA-1/256/512).
- **HTML 정리** (`Shift+Alt+F`), **문서 통계**.
- **구문 강조 (언어)**: 100가지가 넘는 언어 중에서 직접 고릅니다(자동은 확장자로). 상태 표시줄의 문서 종류를 눌러도 됩니다.
- **문서 종류**, **인코딩**, **줄 끝**.

## 13. 정보 · 문제 · 로그 패널

- **정보** 탭(오른쪽): **줄 카운터**(현재 줄, 전체 줄, 열, 선택한 줄 수), 위치·종류·구문·인코딩, 단어·글자·문단·읽는 시간·책갈피 수, 파일의 크기·만든/수정/접근 날짜·속성, **해시**(MD5·SHA-1·SHA-256; 저장 안 한 문서는 SHA), 정보 모두 복사.
- **문제** 탭(아래): Markdown(제목 수준 건너뜀, 빈 제목, 없는 `#제목` 링크, 그림 대체 글, 닫히지 않은 코드 블록…), HTML(닫히지 않은 태그, 짝 없는 닫는 태그, 중복 id, `<title>`·`<!doctype>`…), JSON 문법 오류, 줄 끝 공백, 섞인 들여쓰기, 맞춤법. 줄을 누르면 그곳으로 갑니다.
- **로그** 탭(아래): 열기·저장·자동 저장·찾기·오류 같은 일의 기록. **로그 지우기** 가 있습니다.

## 14. 내보내기와 인쇄

- **HTML 로 내보내기…** (`Ctrl+Shift+E`), **HTML 로 복사**, **기본 프로그램으로 열기**(HTML·PDF·그림·동영상을 시스템 프로그램으로).
- **인쇄…** (`Ctrl+P`): Markdown·HTML 은 미리 보기 모양, 텍스트는 고정폭 글꼴, 그림은 그림만. "PDF 로 저장" 을 고르면 PDF 가 됩니다.

## 15. 보기와 설정

- **자동 줄 바꿈** (`Alt+Z`), **줄 번호**, **현재 줄 강조**, **공백 문자 표시**, 글자 크기(`Ctrl+=` / `Ctrl+-` / `Ctrl+Alt+0`), **집중 모드** (`F11`), **항상 위**.
- **테마**: 도구 모음의 팔레트 단추는 무작위 테마, `▾` 는 테마 메뉴입니다. 메뉴에는 시스템 설정, **밝은 테마 20개**, **어두운 테마 20개**, **사용자 정의**, **테마 설정** 이 있습니다.
- **언어**: 국기 단추. 열린 문서는 그대로입니다.
- **설정…** (`Ctrl+,`): 일반(언어, 새 문서 종류, 패널, 항상 위, 숨김 파일), 모양(테마 40개 타일, **사용자 정의 테마** 색 12가지, 화면 글꼴), 편집기, 맞춤법, 미리 보기, 파일, 시작 화면. **바꾸는 즉시 적용**되고, **기본값으로** 는 모든 설정을 처음으로 되돌립니다(최근 파일과 열린 문서는 그대로).

## 16. 사용 설명서 보기

**도움말 › 사용 설명서** (`F1`) 는 이 설명서를 탭으로 엽니다. 왼쪽에 차례가 있고, 위쪽 막대에서 **글자 크기**(− / + / 100%)와 **언어**(한국어 / English)를 바꿀 수 있습니다. 바꾼 크기와 언어는 기억됩니다.

## 17. 바로 가기 키

도움말 › **바로 가기 키** 에 모든 키가 있습니다. 자주 쓰는 것:

| 키 | 동작 | 키 | 동작 |
| --- | --- | --- | --- |
| `Ctrl+N` / `Ctrl+O` / `Ctrl+S` | 새 문서 / 열기 / 저장 | `Ctrl+F` / `Ctrl+H` | 찾기 / 바꾸기 |
| `Ctrl+W` | 탭 닫기 | `Ctrl+Shift+F` | 파일에서 찾기 |
| `Ctrl+P` | 인쇄 | `Ctrl+G` | 줄로 이동 |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+K` | 굵게 / 기울임 / 링크 | `Ctrl+\` | 보기 전환 |
| `Ctrl+F2` / `F2` | 책갈피 / 다음 책갈피 | `Ctrl+Shift+W` | WYSIWYG |

macOS 에서는 `Ctrl` 대신 `⌘` 를 씁니다.

## 18. 문제 해결

| 증상 | 해결 |
| --- | --- |
| 한글이 깨져 보입니다 | UTF-8 도 EUC-KR 도 아닌 파일일 수 있습니다. 다른 편집기에서 UTF-8 로 저장한 뒤 다시 여세요. |
| "EUC-KR 로 저장할 수 없는 문자" | 상태 표시줄에서 인코딩을 UTF-8 로 바꾸고 저장하세요. |
| 그림이 안 보입니다 | 문서를 먼저 저장하세요. 상대 경로는 저장된 문서의 폴더를 기준으로 찾습니다. |
| 맞춤법 밑줄이 늦게 나옵니다 | 한국어 사전(약 14 MB)은 처음 한 번 읽는 데 몇 초 걸립니다. |
| 동영상이 재생되지 않습니다 | 운영체제에 그 코덱이 없을 수 있습니다(예: 일부 mkv, avi). |
| 큰 파일이 안 열립니다 | 64 MB 보다 큰 파일은 열지 않습니다. |
