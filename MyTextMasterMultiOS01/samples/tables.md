# Tables and alignment

Tables use pipes `|` and a separator row. Colons set the alignment.

| Left | Centre | Right |
| :--- | :---: | ---: |
| apple | 3 | 1,200 |
| banana | 12 | 300 |
| cherry | 7 | 9,800 |
