FAQ

Answers to the questions we hear most often. Click a question to open it.

Is my data stored in the cloud?

No. Every document stays on your computer unless you choose to save it to a synced folder yourself.

Which file types can I open?

Markdown, HTML and plain text, plus common code and data formats such as JSON, CSV, YAML, Python and SQL.

How do I switch between edit and preview?

Use the toolbar buttons, or press Ctrl + E to toggle the preview pane.

Can I export to PDF?

Yes. Choose File → Print and pick a PDF printer, or use Export → PDF for a cleaner layout.

Does it work offline?

Completely. The app never needs a network connection to edit, preview or save.
