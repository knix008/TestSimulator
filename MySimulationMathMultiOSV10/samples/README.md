# Samples · 샘플

시작 화면의 모든 샘플을 파일로 모은 폴더입니다. All the samples of the start page as files.

- `scripts/` — 샘플 · 예제 스크립트 (M files, `.mym`): open in the editor and press F5.
- `models/` — 모델 예제 (`.smdl` block-diagram models) and `build_*.mym`, the M code that builds each model.
- `templates/` — 새로 만들기 templates (function, class, live script).

Generated by `npm run generate:sample-files` from `src/lib/samples.js` and `src/lib/modelSamples.js`.
