# Keyboard Shortcuts

On macOS, use {{Cmd}} instead of {{Ctrl}}.

## Whole Program

| Key | Action |
| --- | --- |
| {{F1}} | User manual |
| {{Ctrl+N}} | New Script |
| {{Ctrl+O}} | Open |
| {{Ctrl+S}} | Save (editor, model) |
| {{Ctrl+,}} | Settings |
| {{Ctrl+0}} | Focus the Command Window |
| {{Ctrl+Shift+0}} | Focus the editor |
| {{Ctrl+Z}} / {{Ctrl+Y}} | Undo / Redo |

## Command Window

| Key | Action |
| --- | --- |
| {{Enter}} / {{Shift+Enter}} | Run / line break |
| {{↑}} / {{↓}} | Command history |
| {{Tab}} | Autocomplete |
| {{Ctrl+C}} | Copy or interrupt execution |
| {{Esc}} | Clear the input |

## Editor and Debugger

| Key | Action |
| --- | --- |
| {{F5}} | Run / Continue while debugging |
| {{Ctrl+Enter}} | Run Section |
| {{F9}} | Run selection |
| {{F10}} | Step |
| {{F11}} / {{Shift+F11}} | Step In / Step Out |
| {{F12}} | Toggle breakpoint |
| {{Ctrl+F}} | Find / Replace |
| {{Ctrl+G}} | Go to line |
| {{Ctrl+R}} / {{Ctrl+T}} | Comment / Uncomment |
| {{Ctrl+]}} / {{Ctrl+[}} | Indent / Outdent |
| {{Ctrl+D}} | Select the next occurrence of the same word |

## Figures

| Key · mouse | Action |
| --- | --- |
| Wheel | Zoom in/out at the cursor position |
| Middle-button drag | Pan |
| Drag (3D) | Rotate |
| {{Shift}}+click | Zoom out in Box zoom mode, add a tip in Data tips mode |
| {{Esc}} | Clear data tips, cancel `ginput` |
| {{Enter}} | Finish `ginput` |
