# 사용 설명서와 튜토리얼

## 사용 설명서 창

![사용 설명서 창: 왼쪽 목차, 오른쪽 내용, 위쪽 도구 모음](images/ko/guide.png)

이 설명서는 별도의 창으로 열립니다(데스크톱 판은 진짜 자식 창, 웹 판은 새 브라우저 창. 브라우저가 팝업을 막으면 화면 안에 떠 있는 창).

- **열기**: {{F1}}, 제목 표시줄의 책 단추, 시작 화면의 **사용 설명서**, 리본 **도움말 › 사용 설명서**.
- **왼쪽 목차**: 장과 절의 구조입니다. 누르면 그 자리로 가고, 내용을 스크롤하면 지금 읽는 절이 강조됩니다. 장 왼쪽의 ▸ 로 펼치고 접습니다.
- **오른쪽 내용**: 모든 장이 이어져 있어 계속 읽어 내려갈 수 있습니다.
- **문서**: 사용 설명서와 튜토리얼 문서 사이를 바꿉니다.
- **언어**: 한국어 / English. 처음에는 프로그램의 언어를 따릅니다.
- **글자 크기**: [−] 12px [+]. 기본은 12px 이며, 고른 크기는 기억됩니다.
- **인쇄**: 옆의 선택에서 **전체 설명서** 나 **현재 장** 을 고른 뒤 **인쇄**({{Ctrl+P}}). 그림이 들어간 인쇄용 페이지가 만들어지고, 쪽 설정과 미리 보기가 있는 인쇄 창이 열립니다.
- **튜토리얼 실행**: 메인 창에서 튜토리얼을 시작합니다.
- 창의 위치와 크기, 읽던 자리는 다음에 열 때 그대로 돌아옵니다.
- 프로그램의 테마를 그대로 따르며, 테마를 바꾸면 열린 설명서도 곧바로 바뀝니다.

## 튜토리얼

![튜토리얼 카드와 강조 표시](images/ko/tour.png)

튜토리얼은 실제 화면 위에서 진행되는 안내입니다. 단계마다 설명할 부분을 노란 테두리로 강조하고, 카드에 설명을 보여 줍니다. 필요한 화면(시작 화면, 편집기, 그림, 모델 편집기 …)은 튜토리얼이 직접 열고, 예제 코드도 직접 실행합니다.

- **시작**: 시작할 때의 안내 창 **실행**, 시작 화면의 **튜토리얼 실행**, 제목 표시줄의 학사모 단추, 리본 **도움말 › 튜토리얼 실행**, 설명서 창의 **튜토리얼 실행**.
- **카드**: 장 이름과 장 안의 순서, 진행 막대, 제목과 설명. 머리를 끌어 옮길 수 있습니다.
- **단추**: ⏮ 처음부터, ◀ 이전, ▶ 자동 재생 / ⏸ 일시 정지, **다음 ▶**, 마지막 단계에서는 **완료 ✓**.
- **장 목록**: 카드 아래 왼쪽에서 원하는 장으로 바로 갑니다.
- **키**: {{→}} / {{Space}} 다음, {{←}} 이전, {{Esc}} 끝.

튜토리얼은 작업 공간에 `x`, `y`, `A`, `X`, `Y`, `Z` 같은 변수를 만들고 그림을 몇 개 그립니다. 튜토리얼이 연 스크립트와 모델 탭은 다음 장으로 넘어갈 때 닫힙니다.

**튜토리얼 문서**(설명서 창의 **문서** 선택, 시작 화면의 **튜토리얼 문서**)에는 같은 단계가 그림과 함께 정리되어 있습니다.


## 도움말 탭

제목 표시줄 오른쪽 끝의 **도움말** 탭에는 도움이 되는 기능이 모여 있습니다.

![도움말 리본](images/ko/ribbon-help.png)

| 단추 | 동작 |
| --- | --- |
| 사용 설명서 | 이 설명서 ({{F1}}) |
| 튜토리얼 실행 | 대화형 튜토리얼을 처음부터 |
| 튜토리얼 문서 | 튜토리얼 단계를 그림과 함께 정리한 문서 |
| 명령 도움말 | 명령 창에서 `help` 실행 |
| 함수 찾기 | 낱말을 묻고 `lookfor` 실행 |
| 단축키 | 주요 단축키 목록 |
| 샘플 · 예제 | 시작 화면의 샘플 카드 |
| 환경 설정 | 설정 창 |
| 프로그램 정보 | 버전과 라이선스 |

## 명령으로 보는 도움말

| 명령 | 내용 |
| --- | --- |
| `help` | 도움말 목차 |
| `help plot` | 함수 하나의 설명 |
| `lookfor 낱말` | 설명에 낱말이 들어간 함수 |
| `doc plot` | 자세한 도움말 |
