# 명령 창

명령 창은 M 코드를 한 줄씩 바로 실행하는 곳입니다. `>>` 프롬프트 뒤에 식을 쓰고 {{Enter}} 를 누르면 결과가 아래에 나옵니다.

![명령 창: 변수 만들기, 행렬 출력, 오류 표시](images/ko/command.png)

## 기본 사용법

```m
x = 1:5
s = sum(x);
disp(s)
A = magic(3)
```

- 세미콜론(`;`)으로 끝낸 문장은 결과를 출력하지 않습니다.
- 변수 이름 없이 식만 쓰면 결과가 `ans` 에 들어갑니다.
- 한 줄에 여러 문장을 쓸 때는 `,` 나 `;` 로 나눕니다.
- 긴 줄은 `...` 로 끝내고 다음 줄에 이어 씁니다.
- `for`, `if`, `function` 같은 블록을 열면 {{Enter}} 가 줄 바꿈이 되고, 블록이 닫히면 한꺼번에 실행됩니다.

## 키

| 키 | 동작 |
| --- | --- |
| {{Enter}} | 실행 (블록이 열려 있으면 줄 바꿈) |
| {{Shift+Enter}} | 줄 바꿈 |
| {{↑}} / {{↓}} | 명령 기록 (입력한 글자로 시작하는 것만) |
| {{Tab}} | 자동 완성 (변수, 함수, 파일 이름) |
| {{Ctrl+C}} | 선택한 글자가 있으면 복사, 없으면 실행 중단 |
| {{Esc}} | 입력 지우기 |
| {{Ctrl+0}} | 명령 창으로 초점 옮기기 |

> 팁: 설정 › 키보드에서 {{Tab}} 자동 완성과 {{Ctrl+C}} 복사 동작을 끌 수 있습니다.

## 출력 형식

`format` 명령으로 숫자 표시 방식을 바꿉니다. 설정 › 명령 창의 **숫자 형식** 도 같습니다.

```m
format long
pi
format short
pi
format compact
```

| 명령 | 효과 |
| --- | --- |
| `format short` | 소수점 아래 4자리 (기본) |
| `format long` | 15자리 |
| `format shortE`, `format longE` | 지수 표기 |
| `format shortG`, `format longG` | 고정·지수 중 짧은 쪽 |
| `format rat` | 분수 근사 |
| `format compact` / `format loose` | 빈 줄 줄이기 / 넣기 |

## 오류와 링크

오류는 빨간색으로, 경고는 주황색으로 나옵니다. 메시지 안의 `파일.mym:줄` 이나 `(line 12)` 부분을 누르면 편집기에서 그 줄이 열립니다. `lasterr` 와 `MException` 으로 마지막 오류를 다시 볼 수 있습니다.

## 입력을 묻는 코드

`input('값: ')` 처럼 값을 묻는 코드가 실행되면 프롬프트가 묻는 글로 바뀝니다. 값을 쓰고 {{Enter}} 를 누르면 실행이 이어집니다. 엔진이 바쁜 동안 쓴 명령은 차례를 기다렸다가 실행됩니다.

## 자주 쓰는 명령

| 명령 | 내용 |
| --- | --- |
| `clc` | 명령 창 지우기 |
| `clear` / `clear x` | 작업 공간의 모든 변수 / x 지우기 |
| `who`, `whos` | 변수 목록 (크기·클래스 포함) |
| `help 이름`, `doc 이름` | 도움말 |
| `lookfor 낱말` | 설명에 낱말이 들어간 함수 찾기 |
| `which 이름`, `exist 이름` | 함수·파일 위치와 종류 |
| `pwd`, `cd 폴더`, `dir`, `ls` | 현재 폴더 보기·바꾸기·목록 |
| `tic`, `toc` | 걸린 시간 재기 |

## 터미널에서 실행

GUI 없이 같은 엔진을 터미널에서 쓸 수 있습니다.

| 명령 | 내용 |
| --- | --- |
| `npm run msm` | 대화형 프롬프트 (`exit` 로 끝냄) |
| `npm run msm -- -r "x = magic(3)"` | 코드 실행 후 끝 |
| `npm run msm -- --cd work run_me.mym` | 폴더를 바꾸고 스크립트 실행 |
