# 편집기

편집기는 `.mym` 스크립트, 함수, 클래스와 텍스트 파일을 쓰는 탭입니다. M 문법 색, 줄 번호, 괄호 짝 표시, 자동 완성, 찾기/바꾸기, 섹션 실행, 중단점 디버깅을 지원합니다.

![편집기: %% 섹션, 줄 번호, 문법 색, 실행 결과](images/ko/editor.png)

## 파일 다루기

| 동작 | 방법 |
| --- | --- |
| 새 스크립트 | 리본 **홈/편집기 › 새 스크립트**, {{Ctrl+N}} |
| 열기 | **열기**, {{Ctrl+O}}, 현재 폴더에서 두 번 클릭, 최근 파일 |
| 저장 | **저장**, {{Ctrl+S}} (제목 없는 파일은 이름을 묻습니다) |
| 다른 이름으로 저장 | 리본 **편집기 › 다른 이름으로 저장** |
| 닫기 | 탭의 ✕, 가운데 버튼 클릭 |

저장하지 않은 탭에는 ● 가 붙습니다. 탭을 닫거나 프로그램을 끝낼 때 저장할지 묻습니다. 설정 › 편집기에서 **자동 저장** 을 켜면 이미 저장한 적이 있는 파일을 정한 시간이 지난 뒤 저절로 저장합니다.

## 실행

| 동작 | 키 | 설명 |
| --- | --- | --- |
| 실행 | {{F5}} | 파일을 저장하고 스크립트 전체를 실행합니다 |
| 섹션 실행 | {{Ctrl+Enter}} | 커서가 있는 `%%` 구간만 실행합니다 (저장하지 않아도 됨) |
| 선택 영역 실행 | {{F9}} | 선택한 코드를 명령 창에서 실행합니다 |

```m
%% 데이터 만들기
x = linspace(0, 1, 50);
y = x.^2 + 0.05*randn(size(x));

%% 2차 다항식 맞추기
p = polyfit(x, y, 2);
plot(x, y, 'o', x, polyval(p, x), '-')
legend('데이터', '맞춘 곡선')
```

`%%` 로 시작하는 줄은 섹션의 경계이고, 편집기에서 굵은 선으로 구분됩니다. 섹션 이름을 `%%` 뒤에 쓰면 읽기 쉽습니다.

> 참고: 현재 폴더에 있는 스크립트는 이름만으로 실행되고, 다른 폴더의 스크립트는 `run('경로/파일.mym')` 으로 실행됩니다. 실행 명령은 명령 창과 명령 기록에 남습니다.

## 디버깅

![중단점에서 멈춘 편집기와 K>> 프롬프트](images/ko/debug.png)

1. 줄 번호 왼쪽을 누르거나 {{F12}} 로 **중단점** 을 겁니다(빨간 점). 다시 누르면 지워집니다.
2. {{F5}} 로 실행하면 중단점에서 멈추고 그 줄이 초록색으로 표시됩니다. 명령 창의 프롬프트는 `K>>` 로 바뀌어, 그 순간의 변수를 보거나 바꿀 수 있습니다.
3. 리본 **편집기** 의 디버그 단추나 키로 진행합니다.

| 동작 | 키 |
| --- | --- |
| 계속 | {{F5}} |
| 한 단계 (함수 안으로 들어가지 않음) | {{F10}} |
| 안으로 (함수 안으로 들어감) | {{F11}} |
| 밖으로 (현재 함수 끝까지) | {{Shift+F11}} |
| 중지 | 리본 **중지**, 명령 창의 ■ |

명령으로도 다룹니다: `dbstop in 파일 at 줄`, `dbclear all`, `dbcont`, `dbstep`, `dbquit`, `keyboard`(그 자리에서 멈춤). 리본 **중단점 모두 지우기** 는 모든 파일의 중단점을 지웁니다. 중단점은 다음 실행 때도 남아 있습니다.

## 편집 기능

| 동작 | 키 |
| --- | --- |
| 찾기 / 바꾸기 | {{Ctrl+F}} (찾기 막대의 바꾸기 칸) |
| 줄로 이동 | {{Ctrl+G}} |
| 주석 / 주석 해제 | {{Ctrl+R}} / {{Ctrl+T}} |
| 들여쓰기 / 내어쓰기 | {{Ctrl+]}} / {{Ctrl+[}} |
| 자동 완성 | 입력하면 목록이 뜨고 {{Enter}}/{{Tab}} 으로 고름 |
| 실행 취소 / 다시 실행 | {{Ctrl+Z}} / {{Ctrl+Y}} |
| 여러 곳 선택 | {{Alt}}+클릭, {{Ctrl+D}} (같은 낱말 추가 선택) |

글꼴, 크기, 탭 크기, 줄 번호, 줄 바꿈은 설정 › 편집기에서 바꿉니다.

## 함수 파일

함수 파일은 `function` 으로 시작하고 파일 이름이 함수 이름과 같아야 합니다. 현재 폴더(또는 `addpath` 로 더한 폴더)에 저장하면 명령 창과 다른 스크립트에서 이름으로 부를 수 있습니다.

```m
function [m, s] = stats(x)
%STATS 평균과 표준편차
%   [m, s] = stats(x)
m = mean(x);
s = std(x);
end
```

첫 주석 줄들은 `help stats` 로 보는 도움말이 됩니다. 스크립트 파일 끝에 지역 함수를 둘 수도 있습니다.

## 라이브 스크립트와 클래스 틀

시작 화면의 **새로 만들기 › 라이브 스크립트** 는 `%%` 섹션으로 나뉜 틀을, **함수** 와 **클래스** 는 `function` · `classdef` 틀을 새 탭에 엽니다.
