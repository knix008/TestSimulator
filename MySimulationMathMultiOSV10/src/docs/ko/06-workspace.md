# 작업 공간과 변수 편집기

## 작업 공간

작업 공간 창에는 지금 메모리에 있는 변수가 이름, 값, 크기, 클래스와 함께 나옵니다. 명령 창이나 스크립트가 변수를 바꾸면 곧바로 새로 고쳐집니다.

![작업 공간 창](images/ko/workspace.png)

- 머리글(이름·값·크기·클래스)을 누르면 정렬되고, 한 번 더 누르면 반대 순서가 됩니다.
- 위쪽 칸에 글자를 쓰면 이름으로 걸러 봅니다.
- 변수를 한 번 누르면 선택되고, 리본 **플롯** 탭의 단추들이 그 변수로 그림을 그립니다.
- 두 번 클릭하면 **변수 편집기** 탭이 열립니다.

오른쪽 클릭 메뉴:

| 항목 | 동작 |
| --- | --- |
| 열기 | 변수 편집기 |
| 그림 그리기 | `plot(이름)` |
| 이름 복사 | 이름을 클립보드로 |
| 이름 바꾸기 | 새 이름을 묻고 바꿈 (실행 취소 가능) |
| 복제 | `이름_copy` 로 복사 |
| MAT 파일로 저장 | `save` 로 저장할 파일을 고름 |
| 지우기 | `clear 이름` (실행 취소 가능) |

머리글의 **작업 공간 지우기** 단추와 리본 **홈 › 작업 공간 지우기** 는 확인을 받은 뒤 모든 변수를 지우며, 이것도 실행 취소({{Ctrl+Z}})로 되돌릴 수 있습니다.

## 변수 편집기

![변수 편집기: 행렬을 표로 보고 고치기](images/ko/variable-editor.png)

변수 편집기는 작업 공간 변수 하나를 표로 보여 줍니다. 실수 숫자 행렬과 논리 행렬은 고칠 수 있습니다.

- 숫자 행렬은 칸을 두 번 클릭하거나 {{Enter}} 로 고칩니다. `3.5`, `-2e-3`, `1+2i`, `Inf`, `NaN` 을 쓸 수 있습니다.
- 데이터 바로 다음의 빈 행이나 열에 쓰면 행렬이 커집니다(빈 칸은 0).
- 화살표 키로 칸을 옮기고, {{Esc}} 는 고치기를 취소합니다.
- 고친 내용은 실행 취소({{Ctrl+Z}})로 되돌립니다.
- 셀 배열, 구조체, 문자열은 읽기 전용으로 보여 줍니다.
- 숫자 형식(짧게 / 길게)은 설정 › 명령 창의 숫자 형식을 따릅니다.

## 명령 기록

명령 기록 창에는 실행한 명령이 세션(실행한 날짜와 시각)별로 쌓입니다. 프로그램을 다시 열어도 남아 있습니다(최대 2000개).

| 동작 | 방법 |
| --- | --- |
| 다시 실행 | 두 번 클릭 |
| 복사 / 프롬프트로 가져오기 | 오른쪽 클릭 › 복사, 프롬프트로 |
| 한 줄 지우기 | 오른쪽 클릭 › 지우기 |
| 모두 지우기 | 오른쪽 클릭 › 모두 지우기 (확인을 받음) |

명령 창에서 {{↑}} 를 누르는 것도 같은 기록을 씁니다.
