# 설정

제목 표시줄의 톱니바퀴, 리본 **홈 › 환경 설정**, {{Ctrl+,}} 로 설정 창을 엽니다. 데스크톱 판에서는 별도의 창이고 크기가 고정되어 있습니다. **확인** 을 눌러야 저장되며, **취소** 하면 테마·언어 미리 보기가 되돌아갑니다. 탭마다 **초기화** 단추가 있습니다.

![설정 창](images/ko/settings.png)

| 탭 | 항목 |
| --- | --- |
| 일반 | 언어, 시작 폴더, 열린 파일 다시 열기, 끝낼 때 저장 묻기, `.mym` 파일 연결(Windows) |
| 테마 | 40가지 테마(다크 20 · 라이트 20) 미리 보기와 선택 |
| 사용자 정의 테마 | 내 테마 만들기(색 하나하나 고르기), 가져오기 · 내보내기 |
| 시작 화면 | 시작할 때 시작 화면 보이기, **튜토리얼 안내 › 실행할 때 튜토리얼 실행 여부 묻기**, 배경 종류 · 속도 · 투명도 · 섞기, 카드 자동 정렬 |
| 명령 창 | 글꼴, 크기, 숫자 형식(`format`), compact, 보관할 줄 수 |
| 편집기 | 글꼴, 크기, 탭 크기, 줄 번호, 줄 바꿈, 자동 저장과 간격 |
| 그림 | 기본 렌더러, 격자, 눈금자 |
| 시뮬레이션 | 기본 솔버, 정지 시간 |
| 키보드 | {{Ctrl+Enter}} 섹션 실행, {{Tab}} 자동 완성, {{Ctrl+C}} 복사, 단축키 목록 |

숫자 값은 모두 − / + 단추와 가운데 값 칸으로 고치며(값을 바로 써도 됨), 목록은 아이콘이 붙은 드롭다운으로 고릅니다.

## 튜토리얼 안내 창

프로그램을 시작하면 "튜토리얼을 실행할까요?" 창이 나옵니다.

![시작할 때 나오는 튜토리얼 안내 창](images/ko/tutorial-ask.png)

- **실행**: 튜토리얼을 처음부터 시작합니다.
- **나중에**: 창을 닫습니다.
- **사용 설명서**: 이 설명서를 엽니다.
- **다음에도 이 창 보이기** 를 끄고 닫으면 다음 실행부터 나오지 않습니다. 설정 › 시작 화면의 **실행할 때 튜토리얼 실행 여부 묻기** 로 다시 켤 수 있습니다.

## 설정이 저장되는 곳

| 판 | 위치 |
| --- | --- |
| Windows 데스크톱 | `%APPDATA%\MySimulationMath\settings.json` |
| macOS | `~/Library/Application Support/MySimulationMath/settings.json` |
| Linux | `~/.config/MySimulationMath/settings.json` |
| 웹 판 | 서버의 같은 설정 폴더 (환경 변수 `MSM_USER_DATA` 로 바꿈) |

명령 기록, 중단점, 사용 설명서의 글자 크기와 읽던 자리는 브라우저 저장소(localStorage)에 따로 저장됩니다.
