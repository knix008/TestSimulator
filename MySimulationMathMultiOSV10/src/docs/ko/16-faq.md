# 자주 묻는 질문과 문제 해결

## 실행과 엔진

**명령을 쳤는데 아무 일도 일어나지 않습니다.**
상태 표시줄의 엔진 상태를 보세요. "실행 중" 이면 앞의 명령이 아직 돌고 있으며, 새 명령은 차례를 기다립니다. 명령 창에서 {{Ctrl+C}} 나 ■ 단추로 멈춥니다.

**엔진이 멈춘 것 같습니다.**
리본 **앱 › 엔진 다시 시작** 을 누르세요. 작업 공간의 변수는 사라지므로, 필요하면 먼저 `save` 로 저장합니다.

**"함수를 찾을 수 없습니다" 오류가 납니다.**
함수 파일이 현재 폴더나 `addpath` 로 더한 폴더에 있는지, 파일 이름이 함수 이름과 같은지 확인하세요. `which 이름` 으로 확인할 수 있습니다.

**스크립트를 고쳤는데 예전처럼 동작합니다.**
편집기에서 저장했는지(탭의 ● 표시) 확인하세요. {{F5}} 는 저장한 뒤 실행합니다.

## 그림

**그림이 안 보입니다.**
문서 탭의 **그림** 탭을 누르세요. 편집기에 입력하는 중에는 그림 탭이 앞으로 나오지 않습니다.

**3D 그림을 위에서 보고 싶습니다.**
도구 모음의 **2D / 3D** 단추나 `view(2)` 를 씁니다. 다시 3D 로는 같은 단추나 `view(3)`.

**확대한 그림을 처음대로 돌리려면?**
도구 모음 **맞춤** 을 누릅니다.

**3D 곡면이 너무 어둡거나 밝습니다.**
`shading interp`, `lighting gouraud`, `material dull` 등을 써 보세요.

## 시뮬레이션

**"대수 루프" 경고가 납니다.**
직접 통과(direct feedthrough) 블록만으로 된 되먹임 고리가 있습니다. 고리 안에 Unit Delay, Memory, Integrator 같은 상태가 있는 블록을 넣으세요. 모델 설정 › 진단에서 처리 방식을 바꿀 수 있습니다.

**시뮬레이션이 너무 느립니다.**
강성 문제라면 `ode15s` 같은 강성 솔버를 쓰고, 최대 스텝을 너무 작게 잡지 않았는지 확인하세요. 시뮬레이션 속도 조절(pacing)이 켜져 있으면 끕니다.

**스코프에 아무것도 없습니다.**
모델을 실행했는지, Scope 의 입력에 선이 이어져 있는지 확인하세요. 아래쪽 진단 목록에 경고가 있는지도 보세요.

## 화면과 설정

**창 배치가 엉망이 되었습니다.**
리본 **홈 › 레이아웃 › 기본 레이아웃** 을 누르세요.

**글자가 너무 작거나 큽니다.**
설정 › 명령 창 / 편집기에서 글꼴 크기를 바꿉니다. 사용 설명서는 창 안의 [−] [+] 로 바꿉니다.

**튜토리얼 안내 창이 매번 나옵니다 / 다시 보고 싶습니다.**
안내 창의 **다음에도 이 창 보이기** 를 끄거나, 설정 › 시작 화면의 **실행할 때 튜토리얼 실행 여부 묻기** 로 켜고 끕니다.

**웹 판에서 내 컴퓨터의 파일이 안 보입니다.**
웹 판은 서버의 작업 폴더만 씁니다. 서버를 `--root 폴더` 나 환경 변수 `MSM_ROOT` 로 시작해 작업 폴더를 정하세요.

**사용 설명서 창이 열리지 않습니다 (웹).**
브라우저가 팝업을 막으면 설명서가 화면 안의 떠 있는 창으로 열립니다. 주소창의 팝업 허용을 켜면 별도 창으로 열립니다.
