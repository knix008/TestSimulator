# 시작하기

MySimulationMath는 **M 언어**(`.mym` 스크립트와 함수)로 수치 계산을 하고, 2D·3D 그림을 그리고, **블록 다이어그램 모델**을 시뮬레이션하는 프로그램입니다. Windows, macOS, Linux 데스크톱 앱(Tauri 2)과 웹 브라우저에서 같은 화면으로 동작하며, 계산 엔진은 화면과 따로 Web Worker 안에서 돌아가므로 긴 계산 중에도 창이 멈추지 않습니다.

![MySimulationMath 데스크톱: 왼쪽 현재 폴더, 가운데 문서 탭과 명령 창, 오른쪽 작업 공간과 명령 기록](images/ko/desktop.png)

## 무엇을 할 수 있나요

| 분야 | 내용 |
| --- | --- |
| 계산 | 행렬·벡터 연산, 선형대수, 다항식, 보간, 수치 적분, 상미분 방정식(ODE), 최적화, 통계, 신호 처리, 제어 시스템 |
| 프로그래밍 | 스크립트, 함수, 익명 함수, 셀·구조체·테이블·문자열, 클래스(`classdef`), 오류 처리, 디버거 |
| 그림 | `plot`, `surf`, `mesh`, `contour`, `bar`, `histogram` 등 2D·3D 그림, 확대·이동·회전·데이터 팁, PNG·JPEG·SVG·PDF 내보내기 |
| 시뮬레이션 | 120개가 넘는 블록으로 모델을 그리고, 가변·고정 스텝 솔버로 실행하고, 스코프로 결과를 봅니다 |
| 데이터 | MAT, CSV, 엑셀(xlsx), JSON, XML, 그림, 소리 파일 읽기·쓰기 |

## 실행하기

데스크톱 앱은 설치 파일로 설치한 뒤 시작 메뉴(또는 응용 프로그램 폴더)에서 실행합니다. 소스에서 실행할 때는 다음 명령을 씁니다.

| 명령 | 내용 |
| --- | --- |
| `npm start` | 데스크톱 앱 (늘 최신 코드) |
| `npm run dev` | 웹 화면만 (개발 서버, 빈 포트를 자동으로 고름) |
| `npm run web` | 빌드한 뒤 웹 서버 시작 |
| `npm run msm` | 터미널 프롬프트(`>>`), `exit` 로 끝냄 |
| `npm run msm -- -r "disp(1)"` | 터미널에서 코드 한 줄 실행 |

> 참고: 웹 판은 **작업 폴더**(기본 `~/MySimulationMath`) 안의 파일만 다루고 `system()` 명령이 동작하지 않습니다. 데스크톱 판은 컴퓨터의 모든 폴더를 쓸 수 있습니다.

## 처음 5분

1. 프로그램을 열면 **시작 화면**과 함께 "튜토리얼을 실행할까요?" 창이 나옵니다. **실행** 을 누르면 실제 화면을 움직이며 기능을 차례로 보여 주는 튜토리얼이 시작됩니다.
2. 시작 화면의 **새 스크립트** 를 누르거나 리본의 **홈 › 새 스크립트**({{Ctrl+N}})로 편집기를 엽니다.
3. 아래 코드를 쓰고 {{F5}} 를 누르면 스크립트가 실행되고 그림 탭이 열립니다.

```m
t = linspace(0, 4*pi, 400);
y = sin(t) .* exp(-t/8);
plot(t, y)
grid on
title('감쇠하는 사인파')
```

4. 명령 창의 `>>` 뒤에 `max(y)` 처럼 짧은 식을 바로 써서 결과를 확인합니다.
5. 오른쪽 **작업 공간** 에서 `t`, `y` 를 두 번 클릭하면 변수 편집기에서 값을 표로 봅니다.

> 팁: 어디서든 {{F1}} 을 누르면 이 사용 설명서가 열리고, 명령 창에서 `help 함수이름` 을 치면 그 함수의 도움말이 나옵니다.

## 파일 형식

| 확장자 | 내용 | 두 번 클릭하면 |
| --- | --- | --- |
| `.mym`, `.m` | M 스크립트, 함수, 클래스 (새로 저장하면 `.mym`) | 편집기에서 열기 |
| `.smdl` | 블록 다이어그램 모델 (JSON) | 모델 편집기에서 열기 |
| `.slx`, `.mdl` | 다른 프로그램의 모델 (흔한 블록을 읽기 전용으로 가져옴) | 모델 편집기에서 열기 |
| `.mat` | 작업 공간 데이터 | `load` 로 불러오기 |
| `.csv`, `.txt`, `.xlsx`, `.json` | 표 데이터 | 변수로 가져오기 |
| `.png`, `.jpg`, `.bmp`, `.gif`, `.tif` | 그림 | `imread` 로 가져오기 |
| `.wav` | 소리 | `audioread` 로 가져오기 |

## 창 위치와 기억되는 것

창의 위치와 크기, 창(패널) 배치, 리본 탭, 열린 파일, 최근 파일, 테마와 언어는 다음 실행 때 그대로 돌아옵니다. 설정은 데스크톱 판에서는 사용자 설정 폴더에, 웹 판에서는 서버의 설정 폴더에 저장됩니다.
