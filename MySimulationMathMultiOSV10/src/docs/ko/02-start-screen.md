# 시작 화면

시작 화면은 프로그램을 열 때 나오는 첫 화면입니다. 창 전체를 덮으며, 움직이는 배경 위에 카드들이 놓입니다. 문서를 열거나 새로 만들면 자동으로 닫히고, 리본의 **홈 › 시작 화면** 단추로 언제든 다시 엽니다.

![시작 화면: 맨 위 카드, 새로 만들기, 최근 파일, 배경, 도움말, 샘플·예제](images/ko/start.png)

## 맨 위 카드

프로그램 아이콘과 이름, 버전, 한 줄 소개가 있고 오른쪽에 자주 쓰는 단추가 모여 있습니다.

| 단추 | 동작 |
| --- | --- |
| **튜토리얼 실행** | 실제 화면을 움직이며 기능을 보여 주는 대화형 튜토리얼을 처음부터 시작합니다 |
| **사용 설명서** | 이 설명서를 별도 창으로 엽니다 ({{F1}}) |
| **튜토리얼 문서** | 튜토리얼의 단계를 그림과 함께 정리한 문서를 설명서 창에서 엽니다 |
| **열기** | 파일 열기 대화 상자 ({{Ctrl+O}}) |
| **새 모델** | 빈 블록 다이어그램 모델 |
| **새 스크립트** | 빈 스크립트 ({{Ctrl+N}}) |

## 새로 만들기

할 일별로 시작점을 묶은 타일입니다. 타일 위에 마우스를 올리면 설명이 나옵니다.

- **코드**: 스크립트, 라이브 스크립트(`%%` 섹션이 들어 있는 틀), 함수(`function` 틀), 클래스(`classdef` 틀)
- **시뮬레이션**: 새 모델, 모델 열기, 블록 라이브러리
- **데이터**: 데이터 가져오기, 플롯 갤러리(리본의 플롯 탭), 그림 영역, 파일 찾기

## 최근 파일

최근에 연 스크립트와 모델이 최대 12개까지 나옵니다. 항목을 누르면 다시 열고, 오른쪽의 ✕ 는 목록에서만 지웁니다(파일은 그대로). 파일이 없어졌으면 알림이 나오고 목록에서 빠집니다. **모두 지우기** 는 확인을 받은 뒤 목록을 비웁니다.

## 도움말 카드

| 항목 | 동작 |
| --- | --- |
| 사용 설명서 | 이 설명서 |
| 튜토리얼 실행 | 대화형 튜토리얼 |
| 튜토리얼 문서 | 튜토리얼 단계 문서 |
| 명령 도움말 (help) | 명령 창에서 `help` 실행 |
| 함수 찾기 (lookfor) | 낱말을 묻고 `lookfor 낱말` 실행 |
| 단축키 | 주요 단축키 목록 |
| 환경 설정 | 설정 창 ({{Ctrl+,}}) |
| 정보 | 버전과 라이선스 |

## 배경

**배경** 카드에서 시작 화면 뒤에 흐르는 애니메이션을 고릅니다.

- 종류 단추로 배경을 바꾸고, **섞기** 를 켜면 정한 초마다 다른 배경으로 바뀝니다.
- **속도** 와 **투명도** 는 슬라이더 또는 − / + 단추로 조절합니다.
- **시작할 때 무작위 배경** 을 켜면 실행할 때마다 무작위로 고릅니다.
- 같은 설정은 **설정 › 시작 화면** 에도 있습니다.

## 샘플·예제

분야별(기초, 2D 그래프, 3D 그래프, 수치 해석, 선형 대수, 신호·영상, 통계·데이터, 최적화·피팅, 제어, 문자열·자료형, 프로그래밍) 예제 카드입니다. 위쪽 분류 단추로 거르고, 카드를 누르면 예제 코드가 새 스크립트로 열리며, 카드의 ▶ 단추는 편집기를 거치지 않고 바로 실행합니다.

## 카드 옮기기와 크기

- 카드 제목 왼쪽의 **⠿** 손잡이를 끌어 다른 칸으로 옮깁니다. 놓일 자리가 점선으로 보이고 다른 카드는 비켜 납니다.
- 카드의 오른쪽 아래 모서리를 끌어 크기를 바꾸고, 모서리를 두 번 클릭하면 내용에 맞춘 높이로 돌아갑니다.
- 키보드: 손잡이에 초점을 두고 {{Alt+←}} {{Alt+→}} {{Alt+↑}} {{Alt+↓}} 로 옮기고, {{Alt+Shift+화살표}} 로 크기를 바꿉니다.
- 오른쪽 위 **자동 정렬** 은 카드를 빈틈없이 다시 배치합니다.

> 팁: 아래쪽 **시작할 때 시작 화면 보이기** 를 끄면 다음 실행부터 바로 데스크톱이 열립니다.
