# 현재 폴더

현재 폴더는 명령 창의 `pwd` 와 같은 폴더입니다. 스크립트와 함수는 이 폴더에서 이름만으로 실행되고, `load`, `save`, `readtable` 같은 파일 명령의 상대 경로도 이 폴더를 기준으로 합니다.

![현재 폴더 창](images/ko/folder.png)

## 폴더 옮기기

- 위쪽 경로 칸에 폴더를 쓰고 {{Enter}}.
- **↑** 단추: 상위 폴더.
- 폴더 단추: 폴더 고르기 대화 상자.
- 새로 고침 단추: 목록 다시 읽기.
- 목록의 폴더를 두 번 클릭.
- 명령 창에서 `cd 폴더`.

시작할 때 열 폴더는 설정 › 일반의 **시작 폴더** 에서 정합니다(비워 두면 지난번 폴더나 기본 폴더).

## 파일을 두 번 클릭하면

| 파일 | 동작 |
| --- | --- |
| `.m`, 텍스트 | 편집기에서 열기 |
| `.smdl`, `.slx`, `.mdl` | 모델 편집기에서 열기 |
| `.mat` | `load` 로 작업 공간에 불러오기 |
| 그림·소리·CSV·엑셀·JSON | 변수로 가져오기 (실행한 명령이 명령 창에 보임) |
| 그 밖의 이진 파일 | 열지 않고 알림 |

## 오른쪽 클릭 메뉴

| 항목 | 키 | 동작 |
| --- | --- | --- |
| 열기 | {{Enter}} | 위 표와 같음 |
| 실행 | {{F9}} | 스크립트 실행 |
| 새 스크립트 / 새 모델 / 새 폴더 | | 이 폴더에 만들기 |
| 이름 바꾸기 | {{F2}} | 칸 안에서 바로 고침 |
| 삭제 | {{Del}} | 확인 후 삭제 (파일은 실행 취소로 되돌림) |
| 경로 복사 | | 전체 경로를 클립보드로 |
| 새로 고침 | | 목록 다시 읽기 |

목록은 폴더가 먼저 오는 트리이며, 폴더 왼쪽의 ▸ 를 눌러 펼칩니다. 맨 아래에는 선택한 파일의 크기와 수정 날짜 같은 정보가 나옵니다. 폴더를 오른쪽 클릭하면 **이 폴더로 이동** 도 있습니다.

> 참고: 웹 판에서는 서버의 작업 폴더 밖으로 나갈 수 없습니다. 파일 열기·저장도 화면 안의 파일 선택 창을 씁니다.

## 경로

`addpath 폴더` 로 다른 폴더의 함수도 부를 수 있게 하고, `rmpath`, `path` 로 관리합니다. `which 이름` 은 그 이름이 어느 파일에서 오는지 알려 줍니다.

## 파일 찾기

리본 **홈 › 파일 찾기** 는 현재 폴더 아래에서 파일 이름이나 내용으로 파일을 찾습니다. 결과를 두 번 클릭하면 그 줄로 편집기가 열립니다.
