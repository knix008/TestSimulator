# 단축키

macOS 에서는 {{Ctrl}} 대신 {{Cmd}} 를 씁니다.

## 프로그램 전체

| 키 | 동작 |
| --- | --- |
| {{F1}} | 사용 설명서 |
| {{Ctrl+N}} | 새 스크립트 |
| {{Ctrl+O}} | 열기 |
| {{Ctrl+S}} | 저장 (편집기·모델) |
| {{Ctrl+,}} | 설정 |
| {{Ctrl+0}} | 명령 창으로 초점 |
| {{Ctrl+Shift+0}} | 편집기로 초점 |
| {{Ctrl+Z}} / {{Ctrl+Y}} | 실행 취소 / 다시 실행 |

## 명령 창

| 키 | 동작 |
| --- | --- |
| {{Enter}} / {{Shift+Enter}} | 실행 / 줄 바꿈 |
| {{↑}} / {{↓}} | 명령 기록 |
| {{Tab}} | 자동 완성 |
| {{Ctrl+C}} | 복사 또는 실행 중단 |
| {{Esc}} | 입력 지우기 |

## 편집기와 디버거

| 키 | 동작 |
| --- | --- |
| {{F5}} | 실행 / 디버그 중이면 계속 |
| {{Ctrl+Enter}} | 섹션 실행 |
| {{F9}} | 선택 영역 실행 |
| {{F10}} | 한 단계 |
| {{F11}} / {{Shift+F11}} | 안으로 / 밖으로 |
| {{F12}} | 중단점 켜기/끄기 |
| {{Ctrl+F}} | 찾기 / 바꾸기 |
| {{Ctrl+G}} | 줄로 이동 |
| {{Ctrl+R}} / {{Ctrl+T}} | 주석 / 주석 해제 |
| {{Ctrl+]}} / {{Ctrl+[}} | 들여쓰기 / 내어쓰기 |
| {{Ctrl+D}} | 같은 낱말 더 선택 |

## 그림

| 키·마우스 | 동작 |
| --- | --- |
| 휠 | 커서 위치에서 확대/축소 |
| 가운데 버튼 끌기 | 이동 |
| 끌기 (3D) | 회전 |
| {{Shift}}+클릭 | 상자 확대 모드에서 축소, 데이터 팁 모드에서 팁 추가 |
| {{Esc}} | 데이터 팁 지우기, `ginput` 취소 |
| {{Enter}} | `ginput` 끝내기 |

## 모델 편집기

| 키 | 동작 |
| --- | --- |
| {{Ctrl+T}} | 시뮬레이션 실행 |
| {{Ctrl+Shift+D}} | 다이어그램 갱신 |
| {{Ctrl+E}} | 모델 설정 |
| {{Ctrl+0}} | 화면에 맞춤 |
| {{Ctrl+C}} / {{Ctrl+V}} / {{Ctrl+D}} | 복사 / 붙여넣기 / 복제 |
| {{Ctrl+R}} / {{Ctrl+I}} | 회전 / 뒤집기 |
| {{Ctrl+G}} | 서브시스템 만들기 |
| {{Ctrl+M}} | 마스크 편집기 |
| {{Del}} | 삭제 |
| {{Space}}+끌기 | 이동 |

## 사용 설명서 창

| 키 | 동작 |
| --- | --- |
| {{Ctrl+P}} | 인쇄 |
| {{Ctrl+=}} / {{Ctrl+-}} | 글자 크게 / 작게 |
| {{Esc}} | 닫기 |

## 튜토리얼

| 키 | 동작 |
| --- | --- |
| {{→}} / {{Space}} | 다음 단계 |
| {{←}} | 이전 단계 |
| {{Esc}} | 끝내기 |
