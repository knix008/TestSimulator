# 화면 구성

시작 화면을 닫으면 **데스크톱** 이 나옵니다. 맨 위에 제목 표시줄(리본 탭)과 리본, 가운데에 작업 영역, 맨 아래에 상태 표시줄이 있습니다.

![데스크톱의 각 부분](images/ko/desktop.png)

## 제목 표시줄

운영 체제의 제목 표시줄 대신 프로그램의 맨 위 줄이 제목 표시줄과 도구 모음을 겸합니다.

- 빈 곳을 끌면 창이 움직이고, 두 번 클릭하면 최대화/복원됩니다.
- 왼쪽: 아이콘, 프로그램 이름(저장하지 않은 변경이 있으면 앞에 ● 표시), **리본 탭**.
- 오른쪽: 실행 중 표시, **테마** 단추(누르면 다음 테마, ⌄ 는 테마 목록), **언어** 단추(국기, 한국어 ↔ English), **사용 설명서**(책), **튜토리얼**(학사모), **설정**(톱니바퀴), **정보**, 창 단추(최소화·최대화·닫기).
- 창이 좁아지면 탭과 테마 이름의 글자가 먼저 숨고 아이콘만 남습니다.

## 리본

리본 탭을 고르면 아래 줄의 단추가 바뀝니다. 모든 단추는 아이콘과 이름이 함께 있고, 마우스를 올리면 설명과 단축키가 나옵니다. 창이 좁으면 이름이 숨고 아이콘만 남습니다.

![홈 리본](images/ko/ribbon.png)

| 탭 | 단추 |
| --- | --- |
| **홈** | 시작 화면, 새 스크립트, 새 모델, 열기, 저장, 파일 찾기, 데이터 가져오기, 작업 공간 지우기, 명령 창 지우기, 실행 취소 / 다시 실행, 현재 폴더·작업 공간·명령 기록 켜기/끄기, 레이아웃, 환경 설정 |
| **플롯** | 작업 공간에서 고른 변수로 그리기: plot, area, bar, barh, stairs, stem, scatter, histogram, pie, polarplot, semilogy, surf, mesh, contour, imagesc, 그림 영역 |
| **앱** | 데이터 가져오기, 변수 편집기, 플롯 갤러리, 그림 영역, 블록 라이브러리, 파일 찾기, 엔진 다시 시작 |
| **편집기** | 새 스크립트, 열기, 저장, 다른 이름으로 저장, 실행, 섹션 실행, 디버그(계속·한 단계·안으로·밖으로·중지), 중단점, 중단점 모두 지우기, 찾기, 주석, 주석 해제, 들여쓰기, 내어쓰기 |
| **시뮬레이션** | 새 모델, 모델 열기, 저장, 라이브러리, 실행, 중지 |
| **도움말** | 사용 설명서 ({{F1}}), 튜토리얼 실행, 튜토리얼 문서, 명령 도움말, 함수 찾기, 단축키, 샘플 · 예제, 환경 설정, 프로그램 정보 |

> 참고: 플롯 탭의 단추는 실행할 명령을 명령 창에 보여 준 뒤 실행하므로, 같은 그림을 코드로 다시 만드는 법을 바로 알 수 있습니다.

## 작업 영역의 창

| 창 | 위치 | 내용 |
| --- | --- | --- |
| 현재 폴더 | 왼쪽 | 작업 폴더의 파일과 폴더 |
| 문서 탭 | 가운데 위 | 편집기, 변수 편집기, 그림, 모델 편집기 |
| 명령 창 | 가운데 아래 (문서가 없으면 가운데 전체) | `>>` 프롬프트 |
| 작업 공간 | 오른쪽 위 | 변수 목록 |
| 명령 기록 | 오른쪽 아래 | 실행한 명령 |

- 창 사이의 경계(스플리터)를 끌어 크기를 바꿉니다. 키보드로는 스플리터에 초점을 두고 화살표 키를 씁니다.
- 각 창의 머리글 오른쪽 ✕ 로 닫고, 리본 **홈** 의 켜기/끄기 단추나 **레이아웃** 메뉴로 다시 엽니다.
- **레이아웃 › 기본 레이아웃** 은 처음 배치로, **명령 창만** 은 옆 창을 모두 닫습니다.

## 문서 탭

파일을 열면 가운데 위에 탭이 생깁니다. 탭을 끌어 순서를 바꾸고, 가운데 버튼 클릭이나 ✕ 로 닫습니다. 저장하지 않은 탭에는 ● 가 붙고, 닫을 때 저장할지 묻습니다(저장 · 저장 안 함 · 취소). 탭이 많으면 오른쪽 끝의 `<` `>` 단추로 탭 줄을 넘깁니다(누르고 있으면 계속). 탭을 오른쪽 클릭하면 이 탭 닫기 · 다른 탭 닫기 · 오른쪽 탭 닫기 · 모두 닫기 메뉴가 나옵니다.

## 상태 표시줄

| 항목 | 내용 |
| --- | --- |
| 경로 | 현재 폴더 |
| 엔진 상태 | 준비 · 실행 중 · 일시 정지(디버그) · 시작 중 |
| 줄·열 | 편집기 커서 위치와 선택한 글자 수 |
| 인코딩·언어 | UTF-8, M / 텍스트 / 모델 / 변수 / 그림 |
| 크기 조절 손잡이 | 맨 오른쪽 점 무늬를 끌면 창 크기가 바뀝니다 |

## 실행 취소

리본의 **실행 취소**({{Ctrl+Z}}) / **다시 실행**({{Ctrl+Y}})은 편집기에 초점이 있으면 편집기의 글자를, 아니면 작업 공간 지우기, 변수 편집, 파일 이름 바꾸기·삭제 같은 앱 동작을 되돌립니다. 단추에 마우스를 올리면 무엇이 되돌려질지 나옵니다.

## 테마와 언어

40가지 테마(다크 20 · 라이트 20)와 사용자 정의 테마가 있습니다. 제목 표시줄의 테마 단추를 누를 때마다 다음 테마로 바뀌고, ⌄ 로 목록을 열어 미리 보며 고릅니다. 언어 단추는 한국어와 영어를 바꿉니다. 사용 설명서 창도 같은 테마를 따라갑니다.
