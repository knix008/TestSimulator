## 빠른 시작

### 1단계: 설치
1. `VNCServerSetup.msi` 파일을 다운로드합니다
2. 설치 파일을 더블클릭하여 실행합니다
3. 설치 마법사의 지시를 따릅니다
4. 바탕화면 또는 시작 메뉴에서 "VNC Server"를 실행합니다

### 2단계: 서버 시작
1. VNC Server 애플리케이션을 실행합니다
2. 기본 설정 확인:
   - 포트: 5900 (기본값)
   - 비밀번호 설정 (권장)
3. **"서버 시작"** 버튼을 클릭합니다
4. 시스템 트레이에 아이콘이 나타나면 준비 완료!

### 3단계: 클라이언트 연결
1. VNC 클라이언트(예: TightVNC, RealVNC, TigerVNC)를 설치합니다
2. 연결 주소 입력:
   - 같은 네트워크: `컴퓨터IP:5900` (예: 192.168.0.10:5900)
   - 외부 네트워크: 라우터 포트 포워딩 필요 또는 UPnP 사용
3. 설정한 비밀번호를 입력합니다
4. 원격 데스크톱에 연결됩니다!

## 설치 가이드

### 시스템 요구사항
- **운영체제**: Windows 10/11 (64비트)
- **.NET Runtime**: .NET 8.0 (자동 설치됨)
- **메모리**: 최소 2GB RAM (4GB 권장)
- **네트워크**: 인터넷 연결 (외부 접속 시)

### 설치 옵션

#### 완전 설치
- VNC Server 애플리케이션
- 바탕화면 바로가기
- 시작 메뉴 바로가기

#### 사용자 지정 설치
설치 중 "사용자 지정" 옵션을 선택하면 다음을 선택할 수 있습니다:
- 설치 위치 변경
- 바탕화면 바로가기 제외
- 시작 메뉴 바로가기 제외

### 자동 업데이트
- 애플리케이션이 시작 시 자동으로 업데이트를 확인합니다
- 새 버전이 있으면 알림이 표시됩니다

## 기본 사용법

### 서버 설정

#### 포트 변경
1. 메뉴 → **설정** 클릭
2. "포트" 필드에 원하는 포트 번호 입력 (예: 5901)
3. **저장** 클릭
4. 서버를 재시작합니다

#### 비밀번호 설정
1. **설정** 메뉴 열기
2. "비밀번호 요구" 체크박스 활성화
3. "비밀번호" 필드에 강력한 비밀번호 입력
4. **저장** 클릭

**권장 비밀번호**:
- 최소 8자 이상
- 대소문자, 숫자, 특수문자 조합
- 예: `Secure@2024!`

#### IPv6 지원
1. **설정** 메뉴 열기
2. "IPv6 활성화" 체크박스 활성화
3. 바인딩 주소 선택:
   - `0.0.0.0` (IPv4 전용)
   - `::` (IPv6 전용)
   - `::0` (듀얼 모드 - 권장)
4. **저장** 및 재시작

### 화면 공유 제어

#### 화면 품질 조정
1. **설정** → "이미지 품질" 슬라이더 조정
   - **낮음 (1-30)**: 저속 네트워크, 빠른 반응
   - **중간 (31-60)**: 균형잡힌 설정 (권장)
   - **높음 (61-100)**: 고속 네트워크, 최고 품질

#### 프레임레이트 설정
1. **설정** → "프레임레이트" 값 입력
   - **15 FPS**: 일반 사무작업
   - **30 FPS**: 비디오 시청, 게임 (권장)
   - **60 FPS**: 고성능 작업 (높은 대역폭 필요)

#### 특정 영역만 공유
1. **설정** → "선택 영역 사용" 체크
2. X, Y, Width, Height 값 입력
   - 예: X=0, Y=0, Width=1920, Height=1080 (주 모니터)
3. 또는 "영역 선택" 버튼으로 드래그하여 선택

### 원격 제어 옵션

#### 보기 전용 모드
**다른 사람이 화면을 보기만 하고 제어하지 못하게 하려면:**
1. **설정** → "보기 전용 모드" 체크
2. 마우스/키보드 입력이 차단됩니다
3. 프레젠테이션이나 교육에 유용

#### 제어 권한 요청
1. **설정** → "제어 요청 허용" 체크
2. 클라이언트가 제어를 요청하면 팝업이 표시됩니다
3. "허용" 또는 "거부"를 선택합니다

## 고급 기능

### 다중 모니터 관리

#### 모니터 선택하기
1. **설정** → "다중 모니터" 탭
2. 모니터 모드 선택:
   - **모든 모니터**: 전체 가상 화면 공유
   - **주 모니터**: 기본 모니터만 공유
   - **특정 모니터**: 선택한 모니터만 공유
3. 특정 모니터 선택 시 인덱스 입력 (0부터 시작)

#### 모니터 정보 확인
```
모니터 목록:
  [0] 주 모니터 - 1920x1080 @ (0, 0)
  [1] 보조 모니터 - 1920x1080 @ (1920, 0)
```

**사용 팁**:
- 민감한 정보가 있는 모니터는 공유하지 마세요
- 주 모니터만 공유하면 성능이 향상됩니다
- 여러 모니터 공유 시 네트워크 대역폭을 확인하세요

### 보안 기능

#### TLS/SSL 암호화
**중요한 데이터를 전송할 때는 암호화를 활성화하세요!**

1. **설정** → "보안" 탭
2. "TLS 활성화" 체크
3. 인증서 옵션:
   - **자체 서명 인증서**: 자동 생성 (테스트용)
   - **사용자 지정 인증서**: 신뢰할 수 있는 CA 인증서 (.pfx 파일)
4. 인증서 경로 지정 (옵션)
5. **저장** 및 재시작

**주의사항**:
- 자체 서명 인증서는 클라이언트에서 경고가 표시됩니다
- 프로덕션 환경에서는 유효한 CA 인증서를 사용하세요

#### 방화벽 설정
Windows 방화벽에서 VNC Server를 허용해야 합니다:

1. **Windows 방화벽** 열기
2. **앱 허용** 클릭
3. **설정 변경** 클릭
4. **다른 앱 허용...** 클릭
5. VNC Server 실행 파일 찾기:
   ```
   C:\Program Files\VNC Server\VNCServer.exe
   ```
6. **개인** 및 **공용** 네트워크 모두 체크 (필요 시)
7. **확인** 클릭

### UPnP 자동 포트 포워딩

**외부에서 접속하려면 라우터 포트를 열어야 합니다. UPnP를 사용하면 자동으로 설정됩니다!**

#### UPnP 활성화
1. **설정** → "네트워크" 탭
2. "UPnP 활성화" 체크
3. "서버 시작 시 자동 매핑" 체크 (권장)
4. **저장**
5. 서버를 시작하면 자동으로 포트가 매핑됩니다

#### 외부 IP 확인
1. 서버 시작 후 상태 표시줄 확인
2. "외부 접속 주소: xxx.xxx.xxx.xxx:5900" 메시지 확인
3. 이 주소를 외부 클라이언트에 알려줍니다

#### UPnP 문제 해결
**UPnP가 작동하지 않으면:**
1. 라우터에서 UPnP 기능이 활성화되어 있는지 확인
   - 라우터 관리 페이지 접속 (보통 192.168.0.1 또는 192.168.1.1)
   - 설정 → UPnP 또는 NAT-PMP 찾기
   - 활성화 체크
2. 공유기 환경에서는 UPnP가 제한될 수 있습니다
3. 수동 포트 포워딩이 필요할 수 있습니다

#### 수동 포트 포워딩
UPnP를 사용할 수 없는 경우:
1. 라우터 관리 페이지 접속
2. **포트 포워딩** 또는 **가상 서버** 메뉴 찾기
3. 새 규칙 추가:
   - **이름**: VNC Server
   - **외부 포트**: 5900
   - **내부 포트**: 5900
   - **프로토콜**: TCP
   - **내부 IP**: 컴퓨터의 로컬 IP (예: 192.168.0.10)
4. 규칙 저장 및 적용

### 클립보드 동기화

#### 텍스트 클립보드
1. **설정** → "클립보드 동기화 활성화" 체크
2. 서버와 클라이언트 간 텍스트가 자동으로 동기화됩니다
3. 복사(Ctrl+C) → 붙여넣기(Ctrl+V)가 양방향으로 작동합니다

#### 이미지 클립보드
1. 확장 클립보드 기능이 자동으로 활성화됩니다
2. 스크린샷 캡처 → 붙여넣기가 가능합니다
3. 대용량 이미지는 자동으로 압축됩니다

### 파일 전송

#### 단일 파일 보내기
1. VNC 세션에서 우클릭 메뉴
2. **파일 전송** 선택
3. 보낼 파일 선택
4. 전송 진행률이 표시됩니다

#### 여러 파일 보내기
1. 여러 파일을 선택합니다
2. 자동으로 ZIP 압축되어 전송됩니다
3. 클라이언트에서 압축 해제

**제한사항**:
- 최대 파일 크기: 2GB
- 대용량 파일은 시간이 걸릴 수 있습니다

### 화면 녹화

#### 녹화 시작
1. 메뉴 → **녹화** → **녹화 시작**
2. 또는 `Ctrl+Shift+R` 단축키
3. 상태 표시줄에 "🔴 녹화 중" 표시

#### 녹화 중지
1. 메뉴 → **녹화** → **녹화 중지**
2. 또는 다시 `Ctrl+Shift+R`
3. 녹화 파일이 저장됩니다

#### 녹화 설정
1. **설정** → "녹화" 탭
2. 프레임레이트 설정 (15-60 FPS)
3. 저장 위치 변경
4. 품질 설정 (1-100)

**저장 형식**:
- 각 프레임은 JPEG 이미지로 저장됩니다
- 모든 프레임은 ZIP 파일로 압축됩니다
- metadata.json에 녹화 정보가 포함됩니다

**녹화 파일 위치**:
```
%APPDATA%\VNCServer\Recordings\
예: C:\Users\사용자이름\AppData\Roaming\VNCServer\Recordings\
```

### 웹 관리 인터페이스

#### 웹 관리 활성화
1. **설정** → "웹 관리" 탭
2. "웹 관리 활성화" 체크
3. 웹 관리 포트 설정 (기본: 8080)
4. **저장** 및 재시작

#### 웹 대시보드 접속
1. 웹 브라우저를 엽니다
2. 주소창에 입력:
   ```
   http://localhost:8080
   ```
3. 원격에서 접속 시:
   ```
   http://서버IP:8080
   ```

#### 웹 대시보드 기능
- **실시간 통계**: 연결된 클라이언트 수, 데이터 전송량
- **서버 제어**: 시작/중지 버튼
- **설정 변경**: 주요 설정을 웹에서 변경
- **클라이언트 목록**: 연결된 클라이언트 정보
- **로그 조회**: 최근 접속 이력

**REST API 엔드포인트**:
```
GET  /api/status         - 서버 상태
GET  /api/settings       - 설정 조회
PUT  /api/settings       - 설정 변경
POST /api/server/start   - 서버 시작
POST /api/server/stop    - 서버 중지
GET  /api/clients        - 클라이언트 목록
GET  /api/statistics     - 통계 조회
GET  /api/logs           - 로그 조회
```

### 오디오 스트리밍

#### 오디오 전송 활성화
1. **설정** → "오디오" 탭
2. "오디오 스트리밍 활성화" 체크
3. 오디오 설정:
   - 샘플레이트: 44100 Hz (권장)
   - 채널: 스테레오 (2) 또는 모노 (1)
4. **저장** 및 재시작

#### 오디오 소스 선택
- **시스템 사운드**: 컴퓨터에서 재생되는 모든 소리
- **마이크**: 마이크 입력 (옵션)

**성능 팁**:
- 저속 네트워크에서는 모노 + 22050 Hz 사용
- 고속 네트워크에서는 스테레오 + 44100 Hz 사용

### 비디오 코덱

#### 하드웨어 가속 활성화
1. **설정** → "비디오" 탭
2. "비디오 코덱 활성화" 체크
3. 코덱 선택:
   - **H.264**: 가장 호환성이 좋음 (권장)
   - **H.265**: 더 나은 압축률 (최신 하드웨어 필요)
4. 비디오 품질 선택:
   - **낮음**: 저속 네트워크
   - **중간**: 균형잡힌 설정 (권장)
   - **높음**: 고속 네트워크
   - **매우 높음**: 거의 무손실
5. **저장** 및 재시작

#### 하드웨어 인코더 확인
애플리케이션이 자동으로 다음을 감지합니다:
- Intel Quick Sync Video (QSV)
- NVIDIA NVENC
- AMD VCE

**사용 가능한 인코더**:
- 로그 파일에서 "Available encoders" 확인
- 또는 웹 관리에서 "시스템 정보" 확인

### 터치 입력 지원

#### 터치 입력 활성화
1. **설정** → "입력" 탭
2. "터치 입력 활성화" 체크
3. 최대 터치 포인트 설정 (1-10, 기본: 10)
4. **저장**

#### 지원되는 제스처
- **탭**: 단일 터치
- **더블 탭**: 빠른 두 번 터치
- **롱 프레스**: 길게 누르기 (우클릭)
- **스와이프**: 드래그
- **핀치**: 두 손가락으로 확대/축소
- **로테이트**: 두 손가락으로 회전

**요구사항**:
- Windows 터치 지원 디바이스
- 터치 스크린 또는 터치패드
- Windows 8 이상

### 세션 재연결

#### 자동 재연결 활성화
1. **설정** → "세션" 탭
2. "세션 재연결 활성화" 체크
3. 타임아웃 설정 (분, 기본: 5분)
4. 최대 재연결 시도 (기본: 3회)
5. **저장**

#### 동작 방식
1. 클라이언트 연결이 끊어지면 세션 상태를 저장합니다
2. 5분 이내에 같은 클라이언트가 재연결하면:
   - 마지막 화면 상태 복원
   - 작업 중이던 내용 유지
   - 끊김 없이 계속 작업
3. 3번의 재연결 시도 후에도 실패하면 세션 종료

**사용 시나리오**:
- 네트워크 불안정
- Wi-Fi 끊김
- 컴퓨터 절전 모드
- 일시적인 연결 문제

## 문제 해결

### 연결 문제

#### 클라이언트가 연결할 수 없음
**증상**: "연결이 거부되었습니다" 또는 "타임아웃" 오류

**해결 방법**:
1. 서버가 실행 중인지 확인
   - 시스템 트레이 아이콘 확인
   - 상태 표시줄에 "서버 실행 중" 표시 확인
2. 방화벽 설정 확인
   - Windows 방화벽에서 VNC Server 허용
   - 안티바이러스 프로그램 예외 추가
3. 포트 확인
   - 올바른 포트 번호 사용 (기본: 5900)
   - `netstat -an | findstr 5900` 명령으로 포트 사용 확인
4. IP 주소 확인
   - `ipconfig` 명령으로 로컬 IP 확인
   - 같은 네트워크에 있는지 확인

#### 외부에서 연결할 수 없음
**증상**: 로컬에서는 되지만 외부에서 안 됨

**해결 방법**:
1. 라우터 포트 포워딩 확인
   - UPnP가 활성화되어 있는지 확인
   - 수동 포트 포워딩 규칙 확인
2. 외부 IP 주소 확인
   - https://www.whatismyip.com/ 방문
   - 라우터에서 확인
3. ISP 제한 확인
   - 일부 ISP는 특정 포트를 차단합니다
   - 다른 포트(예: 5901)로 시도

### 성능 문제

#### 화면이 느리게 업데이트됨
**증상**: 화면 갱신이 지연되거나 끊김

**해결 방법**:
1. 네트워크 속도 확인
   - 대역폭 테스트 실행
   - 다른 네트워크 트래픽 확인
2. 설정 조정
   - 이미지 품질 낮추기 (50 이하)
   - 프레임레이트 낮추기 (15 FPS)
   - 압축 레벨 높이기 (7-9)
3. 화면 영역 제한
   - 전체 화면 대신 특정 영역만 공유
   - 주 모니터만 공유

#### CPU 사용률이 높음
**증상**: VNC Server가 CPU를 많이 사용

**해결 방법**:
1. 프레임레이트 낮추기
   - 30 FPS → 15 FPS로 변경
2. 압축 비활성화 또는 낮추기
   - 로컬 네트워크에서는 압축 비활성화
3. 비디오 코덱 비활성화
   - H.264/H.265 인코딩이 CPU를 많이 사용
4. 다중 클라이언트 제한
   - 동시 연결 수 제한

### 오디오 문제

#### 오디오가 들리지 않음
**증상**: 화면은 보이지만 소리가 안 들림

**해결 방법**:
1. 오디오 스트리밍 활성화 확인
   - 설정 → 오디오 탭 확인
2. 오디오 장치 확인
   - Windows 사운드 설정
   - 기본 재생 장치 확인
3. 클라이언트 지원 확인
   - 일부 VNC 클라이언트는 오디오를 지원하지 않음
   - RealVNC 또는 TigerVNC 사용

#### 오디오가 끊김
**증상**: 소리가 뚝뚝 끊어짐

**해결 방법**:
1. 샘플레이트 낮추기
   - 44100 Hz → 22050 Hz
2. 모노로 변경
   - 스테레오 → 모노
3. 네트워크 대역폭 확인

### TLS/암호화 문제

#### TLS 연결 실패
**증상**: "SSL/TLS 핸드셰이크 실패" 오류

**해결 방법**:
1. 인증서 확인
   - 자체 서명 인증서는 클라이언트에서 수동 승인 필요
   - 유효한 CA 인증서 사용
2. 클라이언트 TLS 지원 확인
   - 모든 VNC 클라이언트가 TLS를 지원하는 것은 아님
   - RealVNC, TigerVNC 권장
3. TLS 버전 확인
   - TLS 1.2 이상 사용

### UPnP 문제

#### UPnP 포트 매핑 실패
**증상**: "UPnP 게이트웨이를 찾을 수 없습니다" 오류

**해결 방법**:
1. 라우터 UPnP 활성화
   - 라우터 관리 페이지 접속
   - UPnP 설정 활성화
2. 방화벽 확인
   - UDP 1900 포트 허용 (SSDP)
3. 수동 포트 포워딩 사용
   - UPnP 대신 수동 설정

### 로그 파일 확인

#### 로그 위치
```
%APPDATA%\VNCServer\vnc-server.log
예: C:\Users\사용자이름\AppData\Roaming\VNCServer\vnc-server.log
```

#### 로그 확인 방법
1. Windows 탐색기 열기
2. 주소창에 `%APPDATA%\VNCServer` 입력
3. `vnc-server.log` 파일 열기

#### 상세 로깅 활성화
1. **설정** → "로깅" 탭
2. "상세 로깅 활성화" 체크
3. 로그 레벨 선택:
   - **정보**: 일반 정보
   - **디버그**: 상세 정보 (문제 해결 시)
   - **추적**: 모든 이벤트 (성능 저하 가능)

## FAQ

### 일반 질문

**Q: VNC Server를 여러 컴퓨터에 설치할 수 있나요?**
A: 네, 라이선스에 따라 제한 없이 설치할 수 있습니다.

**Q: 모바일에서 연결할 수 있나요?**
A: 네, VNC Viewer 앱(iOS/Android)을 사용하여 연결할 수 있습니다.

**Q: 여러 클라이언트가 동시에 연결할 수 있나요?**
A: 네, 동시에 여러 클라이언트가 연결하여 화면을 공유할 수 있습니다.

**Q: 비밀번호를 잊어버렸어요. 어떻게 하나요?**
A: 설정 파일을 삭제하면 기본값으로 재설정됩니다:
```
%APPDATA%\VNCServer\settings.json
```

**Q: 자동 시작을 설정할 수 있나요?**
A: Windows 시작 프로그램 폴더에 바로가기를 추가하세요:
```
shell:startup
```

### 보안 질문

**Q: VNC Server는 안전한가요?**
A: TLS 암호화와 강력한 비밀번호를 사용하면 안전합니다. 외부 노출 시 추가 보안 조치가 권장됩니다.

**Q: 방화벽 뒤에서 작동하나요?**
A: 네, 방화벽에서 VNC 포트를 허용해야 합니다.

**Q: VPN을 통해 사용할 수 있나요?**
A: 네, VPN 연결을 통해 더 안전하게 사용할 수 있습니다.

### 성능 질문

**Q: 최대 해상도는?**
A: 시스템 해상도를 따릅니다. 4K(3840x2160)까지 테스트되었습니다.

**Q: 최대 프레임레이트는?**
A: 60 FPS까지 지원하지만 네트워크와 하드웨어에 따라 다릅니다.

**Q: 게임을 할 수 있나요?**
A: 간단한 게임은 가능하지만 FPS 게임 등 빠른 반응이 필요한 게임은 지연이 있을 수 있습니다.

### 호환성 질문

**Q: 어떤 VNC 클라이언트를 사용할 수 있나요?**
A: 대부분의 RFB 3.8 호환 클라이언트:
- TightVNC Viewer
- RealVNC Viewer
- TigerVNC
- UltraVNC
- VNC Viewer (모바일)

**Q: Linux/Mac에서 연결할 수 있나요?**
A: 네, VNC는 크로스 플랫폼 프로토콜입니다.

**Q: Windows Server에서 작동하나요?**
A: 네, Windows Server 2016 이상에서 작동합니다.

### 문제 해결 질문

**Q: "포트가 이미 사용 중입니다" 오류가 나요.**
A: 다른 포트(예: 5901)를 사용하거나 다른 VNC 서버를 종료하세요.

**Q: 화면이 검은색으로 표시됩니다.**
A: 그래픽 드라이버를 업데이트하거나 하드웨어 가속을 비활성화하세요.

**Q: 클립보드가 동기화되지 않습니다.**
A: 클립보드 동기화 설정이 활성화되어 있는지 확인하세요.
