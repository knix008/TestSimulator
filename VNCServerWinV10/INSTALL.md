# VNC Server MSI 설치 가이드

## 설치 전 확인사항

### 시스템 요구사항
- **OS**: Windows 10 (64-bit) 이상
- **메모리**: 2GB RAM 이상
- **디스크 공간**: 50MB 이상
- **.NET 런타임**: .NET 8.0 Runtime (설치 시 자동 확인)

### 방화벽 설정
VNC Server는 네트워크 통신을 위해 방화벽 예외가 필요합니다:
- 기본 포트: **5900** (TCP)
- 설치 후 Windows 방화벽에 자동으로 규칙 추가 권장

## 설치 방법

### 1. MSI 파일 다운로드
릴리스 페이지에서 `VNCServerSetup.msi` 다운로드

### 2. 설치 실행
1. `VNCServerSetup.msi` 파일을 더블클릭
2. "알 수 없는 게시자" 경고가 나타날 수 있음
   - "실행" 클릭 (또는 "추가 정보" → "실행")

### 3. 설치 마법사
![VNC Server Setup Wizard]

#### 환영 화면
- "Next" 클릭

#### 설치 위치 선택
- 기본값: `C:\Program Files\VNCServer`
- 변경하려면 "Change" 클릭

#### 기능 선택
다음 옵션을 선택할 수 있습니다:
- ✅ **VNC Server** (필수, 항상 설치됨)
- ☐ **Desktop Shortcut** - 바탕화면에 바로가기 생성
- ☐ **Start Menu Shortcut** - 시작 메뉴에 바로가기 생성

권장: 두 옵션 모두 체크

#### 설치 진행
- "Install" 클릭
- 관리자 권한 요청 시 "예" 클릭
- 진행률 표시줄이 100%가 될 때까지 대기

#### 완료
- "Finish" 클릭
- 선택적으로 "Launch VNC Server" 체크 시 자동 실행

## 첫 실행 설정

### 1. 프로그램 실행
- 바탕화면 바로가기를 더블클릭
- 또는 시작 메뉴에서 "VNC Server" 검색

### 2. 초기 설정
프로그램 실행 후 설정 화면에서:

#### 기본 설정
1. **포트 번호**: 5900 (기본값, 변경 가능)
2. **비밀번호 설정**: 
   - "비밀번호 요구" 체크
   - 강력한 비밀번호 입력 (8자 이상 권장)
3. **원격 입력 허용**:
   - 마우스 제어 허용 (기본값: 체크)
   - 키보드 제어 허용 (보안상 기본값: 해제)

#### 고급 설정 (선택사항)
- **화면 품질**: 75 (1-100, 높을수록 고품질)
- **압축 레벨**: 6 (0-9, 높을수록 강한 압축)
- **프레임레이트**: 30 FPS (1-60)
- **클립보드 동기화**: 체크 (권장)
- **TLS/SSL**: 인터넷 통신 시 권장

### 3. 서버 시작
1. "서버 시작" 버튼 클릭
2. 상태가 "실행 중"으로 변경
3. 시스템 트레이에 아이콘 표시

### 4. 방화벽 설정
Windows Defender 방화벽 경고가 표시되면:
- ☑ 개인 네트워크 (홈/직장 네트워크)
- ☑ 공용 네트워크 (필요 시, 보안 주의)
- "액세스 허용" 클릭

## 클라이언트 접속

### 로컬 네트워크 접속
1. 서버 IP 주소 확인:
   ```powershell
   ipconfig
   ```
   예: `192.168.1.100`

2. VNC 클라이언트에서 접속:
   - **주소**: `192.168.1.100:5900`
   - **비밀번호**: 설정한 비밀번호 입력

### 인터넷을 통한 접속 (고급)
1. 공인 IP 확인
2. 라우터에서 포트 포워딩 설정:
   - 외부 포트: 5900
   - 내부 IP: 서버 PC IP
   - 내부 포트: 5900
3. 공인 IP로 접속

⚠️ **보안 경고**: 인터넷 노출 시 반드시:
- 강력한 비밀번호 사용
- TLS/SSL 활성화
- VPN 사용 권장

## 자동 시작 설정

### 방법 1: 프로그램 내 설정
1. VNC Server 실행
2. "자동 시작" 옵션 체크
3. 설정 저장

### 방법 2: Windows 작업 스케줄러
1. 작업 스케줄러 실행 (`Win + R` → `taskschd.msc`)
2. "작업 만들기" 클릭
3. 트리거: "로그온 시"
4. 동작: `C:\Program Files\VNCServer\VNCServer.exe`

### 방법 3: 시작 프로그램 폴더
1. `Win + R` → `shell:startup`
2. VNC Server 바로가기 복사

## 제거 (삭제)

### 방법 1: Windows 설정
1. `Win + I` → "앱" → "설치된 앱"
2. "VNC Server" 검색
3. "..." → "제거" 클릭
4. 확인

### 방법 2: 제어판
1. `Win + R` → `appwiz.cpl`
2. "VNC Server" 선택
3. "제거" 클릭

### 방법 3: MSI 파일 사용
```powershell
msiexec /x VNCServerSetup.msi
```

### 설정 파일 완전 삭제
제거 후에도 설정 파일이 남아있습니다:
```
%APPDATA%\VNCServer\
```
완전 삭제하려면 해당 폴더를 수동으로 삭제하세요.

## 문제 해결

### 설치 실패
**오류**: "설치 실패 - 관리자 권한 필요"
- 해결: MSI 파일 우클릭 → "관리자 권한으로 실행"

**오류**: ".NET Runtime이 설치되지 않음"
- 해결: .NET 8.0 Runtime 다운로드 및 설치
  ```
  https://dotnet.microsoft.com/download/dotnet/8.0
  ```

### 서버 시작 실패
**오류**: "포트가 이미 사용 중"
- 원인: 다른 프로그램이 포트 5900 사용 중
- 해결: 
  - 다른 VNC 서버 종료
  - 설정에서 다른 포트 번호 사용 (예: 5901)

**오류**: "액세스 거부됨"
- 해결: 프로그램을 관리자 권한으로 실행

### 클라이언트 연결 실패
**증상**: 클라이언트가 연결되지 않음
- 체크리스트:
  - [ ] 서버가 실행 중인가?
  - [ ] 방화벽이 5900 포트를 허용하는가?
  - [ ] IP 주소가 정확한가?
  - [ ] 같은 네트워크에 있는가?

**증상**: "인증 실패"
- 원인: 비밀번호 불일치
- 해결: 서버 설정에서 비밀번호 확인

### 화면이 느림
- 해결책:
  - 프레임레이트 낮추기 (30 → 15)
  - 이미지 품질 낮추기 (75 → 50)
  - 압축 레벨 높이기 (6 → 9)
  - 선택 영역만 공유 사용

### 로그 확인
문제 진단을 위한 로그 파일:
```
%APPDATA%\VNCServer\vnc-server.log
```
