# ImageMakerGTKV10

GTK3 기반 데스크톱 프로그램으로, 여러 이미지를 레이어로 올려 합성하고 PNG로 저장할 수 있습니다.  
레이어마다 **객체 주위를 드래그**해 전경(객체)만 남기고 배경은 투명하게 처리할 수 있으며, **선택이 없는 맨 아래 레이어**는 자동으로 배경이 됩니다.

## 요구 사항

- Linux 또는 macOS
- GCC (C11)
- GTK 3 (`gtk+-3.0`, pkg-config)

Linux에서 `make` 실행 시 패키지가 없으면 다음이 자동 설치됩니다(기본값).

- `build-essential`
- `pkg-config`
- `libgtk-3-dev`

macOS는 Homebrew로 `gtk+3`, `pkg-config`를 설치합니다.

## 빌드 및 실행

```bash
cd ImageMakerGTKV10
make          # 의존성 확인/설치 → 빌드
./imagemaker
```

| 명령 | 설명 |
|------|------|
| `make` | 의존성 확인 후 `imagemaker` 빌드 |
| `make clean` | `build/`, 실행 파일 제거 |
| `make CC_AUTO_INSTALL=0` | 자동 패키지 설치 없이 빌드만 |

## 사용 방법

1. **이미지 추가** — 툴바에서 여러 파일을 한 번에 추가할 수 있습니다.
2. **레이어 선택** — 왼쪽 목록에서 편집할 레이어를 고릅니다.
3. **객체 선택** — 캔버스 빈 곳을 드래그해 객체를 추출합니다. 사각형은 검색 범위이며, 내부에서 전경만 남깁니다.
4. **배치** — 추출된 객체(초록 테두리)를 **드래그해 이동**, **모서리 핸들**로 크기 조절, **상단 핸들**로 회전, 또는 하단 **객체 X/Y/너비/높이/각도**로 배치합니다.
5. **불투명도** — 레이어 단위로 조절합니다.
6. **레이어 순서** — **위로** / **아래로**로 겹침 순서를 바꿉니다.
7. **선택 지우기** — 현재 레이어의 모든 객체 선택을 제거합니다.
8. **PNG 저장** — 합성 결과를 저장합니다.

### 배경 규칙

- **선택이 하나도 없는** 레이어 중 **목록 맨 아래(가장 먼저 그려지는) 레이어**가 `[배경]`이 됩니다.
- 배경은 캔버스 (0, 0)에 **전체 이미지**로 그려지며, 마스크를 적용하지 않습니다.
- 배경이 있으면 캔버스 크기가 배경 이미지 크기에 맞춰집니다.
- **모든 레이어에 선택이 있으면** 배경 없이 흰 캔버스 위에 마스크 레이어만 합성됩니다.

### 레이어 목록 표시

| 표시 | 의미 |
|------|------|
| `[배경]` | 선택 없음, 배경 레이어 |
| `[선택]` | 하나 이상의 영역 선택 있음 |
| (이름만) | 선택 없음, 배경이 아닌 레이어 |

## 프로젝트 구조

```
ImageMakerGTKV10/
├── Makefile
├── README.md
├── include/
│   ├── layer.h          # 레이어·프로젝트·선택 영역
│   ├── selection_geom.h # 객체 배치·회전 좌표 변환
│   ├── layer_mask.h     # 마스크(투명 처리)
│   ├── composite.h      # 합성·PNG 저장
│   ├── canvas_view.h    # 캔버스 미리보기·드래그 선택 (GTK)
│   └── main_window.h    # 메인 창 (GTK)
└── src/
    ├── main.c
    ├── layer.c
    ├── selection_geom.c
    ├── layer_mask.c
    ├── composite.c
    ├── canvas_view.c
    └── main_window.c
```

GTK 위젯은 `canvas_view`, `main_window`, `main`에 두고, 레이어·마스크·합성 로직은 `gtk.h` 없이 GdkPixbuf·Cairo만 사용합니다.

## 객체 추출 방식

드래그한 사각형은 **검색 범위(ROI)** 입니다. ROI 안에서 다음을 수행합니다.

1. **배경** — 사각형 테두리와 비슷한 색의 연결 영역
2. **전경** — 사각형 중심과 비슷한 색의 연결 영역
3. **객체** — 전경이면서 배경이 아닌 픽셀 (객체가 테두리에 닿으면 중심 전경만 사용)

단색·대비가 큰 배경에서 가장 잘 동작합니다. 객체가 ROI 중심에 오도록 드래그하는 것이 좋습니다.

## 합성 흐름

1. 배경 레이어(선택 없는 맨 아래 레이어)를 먼저 그립니다.
2. 나머지 레이어를 순서대로 그립니다.
   - 선택 있음 → 드래그 범위 안에서 추출한 객체만 불투명, 나머지 투명
   - 선택 없음(배경 제외) → 전체 이미지를 (x, y)에 배치

## 지원 이미지 형식

PNG, JPEG, BMP, GIF, WebP (GdkPixbuf 로더 지원 범위)
