# 사용법

12키 천지인 자판으로 한글을 조합합니다. 이 문서는 프로그램 안의
`도움말 > 사용법`(F1) 과 같은 내용에 화면 설명을 더한 것입니다.

## 화면

```
┌────────────────────────────────────┐
│ 파일  편집  입력  설정  도움말      │  메뉴
├────────────────────────────────────┤
│ 🗋 🗀 🖫 ⧉ 📋 🗑 ↻ 🎨 🌐 ⚙   ⓘ  │  툴바
├────────────────────────────────────┤
│                                    │
│  안녕하세요                        │  편집 영역
│                                    │
├────────────────────────────────────┤
│ 한글   조합 ㄱ + ㅏ + -   5자      │  상태줄
├────────────────────────────────────┤
│   ㅣ      ·      ㅡ                │
│  ㄱㅋ    ㄴㄹ   ㄷㅌ                │  천지인 키패드
│  ㅂㅍ    ㅅㅎ   ㅈㅊ                │
│  . ,     ㅇㅁ   ? !                │
│ 모드 ← 스페이스 → ↵ ⌫              │  기능 버튼
└────────────────────────────────────┘
```

**상태줄**은 지금 무슨 모드인지, 어떤 낱자를 조합하고 있는지, 몇 자를
썼는지를 보여 줍니다. `조합 ㄱ + ㅏ + -` 는 초성 ㄱ, 중성 ㅏ, 받침 없음이라는
뜻입니다.

**툴바**는 왼쪽부터 새로 만들기 · 열기 · 저장 · 복사 · 붙여넣기 ·
전체 지우기 · 입력 모드 · 테마 · 언어 · 설정이고, 맨 오른쪽이 프로그램
정보입니다. 단추 위에 잠깐 머무르면 무엇인지 알려 줍니다.

툴바와 상태줄은 `설정` 메뉴에서 감출 수 있습니다.

## 편집 영역에서 할 수 있는 것

편집 영역은 **직접 타이핑할 수 없습니다.** 모든 글자는 천지인 키패드나
그에 대응하는 물리 키를 거쳐 들어옵니다. 조합 규칙을 프로그램이 온전히
쥐고 있어야 원본과 결과가 같기 때문입니다.

다만 **마우스로 찍어 커서를 옮기는 것**은 됩니다. 찍으면 조합 중이던
글자는 확정됩니다.

## 파일

`파일 > 저장`(Ctrl+S)은 UTF-8 텍스트 파일로 저장하되 맨 앞에 BOM 을
붙입니다. 그래야 Windows 메모장이 한글을 제대로 읽습니다.
`파일 > 열기`(Ctrl+O)는 BOM 이 있으면 떼고 읽습니다.

한 번에 담을 수 있는 것은 4095자입니다. 그보다 긴 파일은 앞에서부터
그만큼만 읽습니다.

## 설정

`설정 > 설정...`(F4) 에서 바꿀 수 있습니다.

| 항목 | 무엇 | 기본값 |
|---|---|---|
| 테마 | 라이트 · 다크 · 세피아 · 고대비 | 라이트 |
| 언어 | 한국어 · English | 운영체제를 따름 |
| 글꼴 크기 | 편집 영역 글자 크기 | 21 px |
| 연타 유지 시간 | 같은 키 순환이 유지되는 시간 | 0.8초 |
| 시작 입력 모드 | 프로그램을 켤 때의 모드 | 한글 |
| 툴바 · 상태줄 | 보일지 말지 | 보임 |

고르는 즉시 화면에 반영되므로 미리 볼 수 있습니다. `취소` 를 누르면
열 때의 값으로 되돌아갑니다. `기본값` 은 언어만 그대로 두고 나머지를
처음 값으로 돌립니다.

설정은 아래 자리에 JSON 파일로 저장됩니다.

| 운영체제 | 자리 |
|---|---|
| Windows | `%AppData%\Chunjiin\settings.json` |
| macOS | `~/Library/Application Support/Chunjiin/settings.json` |
| Linux | `~/.config/Chunjiin/settings.json` |

칸 이름과 값은 Rust 판과 같으므로 두 판이 설정을 나눠 써도 됩니다.

## 웹 판

`python -m chunjiin.web` 으로 띄우면 브라우저에서 같은 화면을 씁니다.
자판 · 테마 · 언어가 데스크톱 판과 같고, 조합도 같은 파이썬 엔진이
맡으므로 결과가 어긋나지 않습니다.

브라우저 탭마다 글이 따로 있습니다. 같은 서버에 여러 사람이 붙어도
서로의 글이 섞이지 않습니다.

아래는 프로그램 안의 `도움말 > 사용법`(F1) 과 글자 그대로 같은 내용입니다.

```
[ 키패드 ]

    ㅣ      ·      ㅡ
    ㄱㅋ   ㄴㄹ   ㄷㅌ
    ㅂㅍ   ㅅㅎ   ㅈㅊ
    . ,    ㅇㅁ   ? !


[ 모음 ]

  ㅣ 와 · 와 ㅡ 를 이어서 모든 모음을 만듭니다.

  ㅏ = ㅣ+·        ㅑ = ㅣ+·+·        ㅐ = ㅏ+ㅣ
  ㅓ = ·+ㅣ        ㅕ = ·+·+ㅣ        ㅔ = ㅓ+ㅣ
  ㅗ = ·+ㅡ        ㅛ = ·+·+ㅡ        ㅚ = ㅗ+ㅣ
  ㅜ = ㅡ+·        ㅠ = ㅡ+·+·        ㅟ = ㅜ+ㅣ
  ㅡ = ㅡ          ㅣ = ㅣ            ㅢ = ㅡ+ㅣ
  ㅘ = ㅚ+·        ㅙ = ㅘ+ㅣ         ㅝ = ㅠ+ㅣ


[ 자음 ]

  같은 키를 연달아 누르면 순환합니다.

  ㄱ → ㅋ → ㄲ      ㄷ → ㅌ → ㄸ      ㅂ → ㅍ → ㅃ
  ㅅ → ㅎ → ㅆ      ㅈ → ㅊ → ㅉ      ㄴ → ㄹ      ㅇ → ㅁ

  받침 뒤에 모음을 누르면 자동으로 연음됩니다.   간 + ㅏ → 가나
  겹받침은 자음을 이어 누르면 합쳐집니다.        값 = ㄱ ㅏ ㅂ ㅅ
  첫 타에 안 붙는 겹받침은 한 번 더 누르면 합쳐집니다.   만 → 만ㅅ → 많


[ 같은 키를 연달아 써야 할 때 ]

  "안녕" 처럼 ㄴ 을 두 번 눌러야 하면 사이에 오른쪽 화살표 키를 누르거나
  잠시 기다리세요. 순환이 끊기고 새 글자가 시작됩니다.


[ 물리 키보드 ]

  한글 모드에서 숫자열이 키패드에 대응합니다.

    1 2 3  =  ㅣ · ㅡ            7 8 9  =  ㅂㅍ ㅅㅎ ㅈㅊ
    4 5 6  =  ㄱㅋ ㄴㄹ ㄷㅌ      - 0 =  =  . ,  ㅇㅁ  ? !

    Space  띄어쓰기          Backspace  한 단계 지우기
    Enter  줄바꿈            Esc        조합 확정
    ← →    커서 이동         Home End   줄 처음 · 끝

    F1  도움말      F2  입력 모드      F3  테마      F4  설정

    Ctrl+N 새로   Ctrl+O 열기   Ctrl+S 저장
    Ctrl+C 복사   Ctrl+V 붙여넣기


[ 영문 · 숫자 · 기호 ]

  모드 버튼(F2)으로 한글, 영문 abc, 영문 ABC, 숫자, 기호 순으로 바뀝니다.
  영문·숫자·기호 모드에서는 물리 키보드로 그냥 타이핑해도 됩니다.

    abc  def  ghi        알파벳 26자가 위 3x3 아홉 키에 들어갑니다.
    jkl  mno  pqr        마지막 줄 세 키는 자주 쓰는 기호입니다.
    stu  vwx  yz         나머지 기호는 기호 모드에 36개가 있습니다.


[ 설정 ]

  설정 > 설정...(F4) 에서 테마, 글꼴 크기, 연타 유지 시간,
  시작 입력 모드, 툴바 · 상태줄 표시를 바꿀 수 있습니다.
```
