# MyDiff Win V10 — 사용자 가이드

MyDiff는 Windows용 2-way 줄 단위 diff 뷰어입니다. 왼쪽/오른쪽 두 파일을 나란히 비교하고 추가/삭제/변경된 줄을 색으로 구분해서 보여줍니다. 독립 실행 외에도 `git difftool`이나 MyGitWinV10의 외부 diff 도구로 등록해서 쓸 수 있습니다.

## 시작하기

### 실행 방법

- **개발 빌드:** `dotnet run --project MyDiffWinV10.App`
- **설치본:** 시작 메뉴 또는 바탕화면의 **MyDiff Win V10** 바로 가기

### .NET 런타임

프레임워크 종속(framework-dependent) 빌드를 사용하는 경우 [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)이 필요합니다.

### 마지막 세션 자동 복원

독립 실행 모드(인수 없이 실행)에서는 마지막으로 비교했던 왼쪽/오른쪽 파일 경로가 다음 실행 시 자동으로 다시 열립니다. 두 파일 중 하나라도 없어졌으면 복원하지 않습니다.

## 화면 구성

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  [메뉴: 파일 | 보기 | 도움말]   [도구 모음]   [글꼴 크기]   [정보]          │
├──────────────────────────────────┬──────────────────────────────────────────┤
│  왼쪽                              │  오른쪽                                │
│  [줄번호 | 내용 | 위치 표시줄]    │  [줄번호 | 내용 | 위치 표시줄]         │
├──────────────────────────────────┴──────────────────────────────────────────┤
│  상태 표시줄 (파일명, 추가/삭제/변경 줄 수)                                 │
└─────────────────────────────────────────────────────────────────────────────┘
```

| 영역 | 설명 |
|------|------|
| **왼쪽 패널** | LEFT 파일 내용 (읽기 전용) |
| **오른쪽 패널** | RIGHT 파일 내용 (읽기 전용) |
| **위치 표시줄** | 각 패널 오른쪽의 좁은 띠 — 파일 전체에서 차이가 어디에 있는지 보여주는 미니맵 |

- 두 패널은 **세로 스크롤이 동기화**됩니다 (한쪽을 스크롤하면 다른 쪽도 같은 줄로 이동).
- 각 패널 왼쪽에 **줄 번호**가 표시됩니다.

### 줄 배경색 의미

| 색상 | 의미 |
|------|------|
| 흰색 / 연한 회색 (교차) | 차이가 없는 동일한 줄 (zebra striping) |
| 연한 빨강 | **삭제됨** — 왼쪽에만 있고 오른쪽에는 없는 줄 |
| 연한 녹색 | **추가됨** — 오른쪽에만 있고 왼쪽에는 없는 줄 |
| 연한 노랑/주황 | **변경됨** — 같은 위치인데 내용이 다른 줄 |

양쪽 패널 헤더는 왼쪽(슬레이트색)/오른쪽(파란색)으로 구분되는 파스텔 톤 배경으로 표시됩니다.

## 파일 열기

### 명령줄에서 열기 (가장 흔한 사용 방식)

```
MyDiffWinV10.App.exe                  # 대화상자로 왼쪽/오른쪽 파일 선택
MyDiffWinV10.App.exe <LEFT> <RIGHT>   # 두 파일을 바로 비교
```

`git difftool`이나 MyGitWinV10의 외부 diff 도구로 등록하면, Git/MyGitWinV10이 자동으로 이 두 번째 형태로 앱을 실행합니다. 자세한 등록 방법은 [git 연동](#git-연동)을 참고하세요.

### 앱에서 직접 열기

- **파일 → 왼쪽 파일 열기...** / **오른쪽 파일 열기...** — 한쪽 파일만 바꿔서 다시 비교
- **파일 → 다시 비교** — 두 파일을 디스크에서 다시 읽어 새로 비교 (파일이 바뀐 후 갱신할 때)

## 차이 탐색

| 동작 | 방법 |
|------|------|
| 다음 차이로 이동 | 도구 모음 **다음 차이** 버튼, **보기 → 다음 차이**, 또는 **F3** |
| 이전 차이로 이동 | 도구 모음 **이전 차이** 버튼, **보기 → 이전 차이**, 또는 **Shift+F3** |
| 특정 위치로 바로 이동 | [위치 표시줄](#diff-위치-표시줄-overview-bar) 클릭 |
| 선택한 줄 복사 | **보기 → 복사**, 패널 우클릭 → **복사** |

## diff 위치 표시줄 (Overview Bar)

각 패널의 스크롤바 옆에는 좁은 색상 띠가 있습니다.

- **빨강 / 녹색 / 주황** 구간: 파일 전체에서 삭제/추가/변경된 줄의 위치를 비율로 표시
- **회색 사각형**: 지금 화면에 보이는 범위 (스크롤하면 함께 움직임)
- **클릭**: 그 비율 위치로 두 패널이 함께 이동

스크롤을 시작하기 전에 파일 전체에서 차이가 어디에 몰려 있는지 한눈에 파악할 수 있습니다.

## 환경 설정 (Preferences)

**파일 → 환경 설정...**

| 항목 | 설명 |
|------|------|
| **패널 글꼴 크기** | 좌우 패널의 고정폭 글꼴 크기 (6.0 ~ 18.0pt) |
| **좌우 패널 자동 줄 바꿈** | 긴 줄을 패널 너비에 맞춰 줄 바꿈 |
| **언어** | **한국어**(기본) 또는 **English** — 메뉴, 도구 모음, 대화상자, 상태 표시줄 등 UI 전체에 적용. 확인 즉시 반영 |

도구 모음의 **글꼴 크기** 숫자 상자로도 글꼴 크기를 바꿀 수 있으며, 변경 내용은 설정 파일에 자동 저장됩니다.

### 파일

| 메뉴 | 설명 |
|------|------|

### 보기

| 메뉴 | 설명 |
|------|------|
| 자동 줄 바꿈 | 좌우 패널 줄 바꿈 토글 (체크 표시) |

| 메뉴 | 설명 |
|------|------|
| MyDiff 정보 | 버전 및 저작권 정보 |

### 도구 모음

왼쪽/오른쪽 파일 열기, 다시 비교, 이전/다음 차이, 자동 줄 바꿈, **글꼴 크기** 조절, **정보** 버튼이 포함됩니다. 모든 메뉴/메뉴 항목/도구 모음 버튼에는 마우스를 올리면 설명 툴팁이 표시됩니다.

## git 연동

### `git difftool`로 등록

```powershell
git config --global difftool.mydiff.cmd '"C:\\Path\\To\\MyDiffWinV10.App.exe" "$LOCAL" "$REMOTE"'
git difftool -t mydiff
```

### MyGitWinV10의 외부 diff 도구로 등록

MyGitWinV10에서 **파일 → 환경 설정... → 외부 diff 도구**:

- 경로: 빌드된 `MyDiffWinV10.App.exe`
- 인자: `"{left}" "{right}"`

이렇게 설정하면 MyGitWinV10의 커밋 상세에서 변경된 파일을 더블클릭할 때 MyGitWinV10 내부 diff 패널 대신 MyDiff가 열립니다.

> MyDiff는 **읽기 전용 diff 뷰어**입니다. 3-way 병합 충돌 해결이 필요하면 형제 앱인 **DiffMergeWinV10**을 `git mergetool`로 등록해서 사용하세요 — MyDiff는 의도적으로 `mergetool`에는 등록하지 않습니다.

## 오류 보고

파일을 열지 못하거나 예기치 않은 오류가 발생하면 팝업 대화상자가 표시됩니다.

- 오류 **유형**, **메시지**, **소스**, **스택 추적**이 모두 표시됩니다.
- **내용 복사** 버튼으로 전체 내용을 클립보드에 복사할 수 있습니다 (복사 시 텍스트가 반전되어 보이지 않습니다).
- **확인**을 눌러 닫습니다.

## 설정 및 데이터 저장 위치

| 항목 | 위치 |
|------|------|
| 사용자 설정 | `%AppData%\MyDiffWinV10\settings.json` |

설정 파일에 저장되는 내용:

- 창 크기
- 패널 글꼴 크기, 자동 줄 바꿈
- UI 언어 (기본값: 한국어)
- 마지막으로 비교한 왼쪽/오른쪽 파일 경로 (독립 실행 시 복원)

비교 대상 **파일 내용**은 설정 파일에 저장되지 않습니다. 경로만 기억됩니다.

## MSI 설치 (관리자용 요약)

App 프로젝트(또는 솔루션)를 **Release**로 빌드하면 MSI가 자동으로 생성됩니다.

| 항목 | 내용 |
|------|------|
| 빌드 명령 | `dotnet build MyDiffWinV10.App/MyDiffWinV10.App.csproj -c Release` |
| MSI 출력 | `installer\bin\Release\MyDiffWinV10Setup.msi` |
| 설치 위치 | `Program Files\MyDiffWinV10` |
| 기능 선택 | 시작 메뉴 바로가기, 바탕화면 바로가기 (설치 마법사에서 각각 켜고 끌 수 있음, 기본은 둘 다 켜짐) |

두 바로가기 모두 프로그램 아이콘을 사용합니다.

## 문제 해결

### 앱이 시작되지 않음

- [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)이 설치되어 있는지 확인하세요.

### 마지막 세션이 복원되지 않음

- 이전에 열었던 파일이 이동되거나 삭제되었을 수 있습니다. 파일을 다시 열어 보세요.

### git difftool로 실행했는데 빈 화면이 보임

- `$LOCAL`/`$REMOTE` 인자가 올바르게 전달되는지 `git config --get difftool.mydiff.cmd`로 확인하세요.

### 글꼴 크기를 바꿨는데 레이아웃이 어색함

- 창 크기를 조금 변경하면 줄 배경이 다시 맞춰집니다.

### 영어 UI로 전환

**파일 → 환경 설정... → 언어 → English → 확인**

### Release 빌드에서 MSI가 생성되지 않음

- 실행 중인 `MyDiffWinV10.App.exe`가 있으면 종료 후 다시 빌드하세요.
- 앱 프로젝트만 빌드해도 MSI가 만들어지지 않으면 `dotnet build installer\MyDiffWinV10.Installer.wixproj -c Release -p:Platform=x64 -p:BuildMsiPackage=true`로 직접 빌드해 보세요.
