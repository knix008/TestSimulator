# MyDeskSearch 사용자 가이드

MyDeskSearch는 Linux, macOS, Windows에서 파일과 폴더 **이름**을 찾는 검색창입니다.

```bash
cargo run -p mydesksearch
```

이미 실행 중이면 새 창 대신 기존 검색창이 다시 나타납니다. 창을 닫으면 트레이에 남습니다. 완전히 끝내려면 메뉴 또는 트레이에서 **종료**를 선택하세요.

## 설치

설치 화면에서 **한국어** 또는 **English**를 고릅니다. 이어서 바탕화면과 시작 메뉴에 바로가기를 만들지도 묻습니다. 만들면 바로가기 아이콘은 프로그램 아이콘과 같습니다. 이 언어는 처음 실행할 때 쓰이고, 나중에는 설정의 **언어**에서 바꿀 수 있습니다. 설정 창을 연 동안 화면 언어가 바로 바뀌고, 저장하면 다음 실행에도 유지됩니다.

이미 MyDeskSearch가 있으면 설치 프로그램이 프로그램 파일을 지운 뒤 새 파일을 설치합니다. 이때 설정과 검색 인덱스를 삭제할지 물어 봅니다.

- **유지**: 검색 인덱스와 설정을 남깁니다. 앱에 저장해 둔 언어도 바뀌지 않습니다.
- **삭제**: 설정과 검색 인덱스를 지우고, 설치할 때 고른 언어로 다시 시작합니다.

시작 메뉴나 응용 프로그램 목록의 MyDeskSearch 제거도 같은 질문을 합니다.

## 검색

검색창에 이름을 입력합니다. 인덱싱이 끝나기 전에도, 이미 인덱싱된 항목은 찾을 수 있습니다. 일치 항목이 없으면 **일치하는 항목이 없습니다.** 가 표시됩니다.

| 입력 | 의미 |
|------|------|
| `report` | 이름에 `report`가 연속으로 포함 |
| `budget * 2024` | 둘 다 포함 (AND) |
| `doc + pdf` | 하나라도 포함 (OR) |
| `*.pdf` | `.pdf`로 끝나는 이름 |
| `file?.txt` | `file`와 `.txt` 사이에 한 글자 |

`*`와 `+`는 앞뒤에 공백이 있을 때만 연산자입니다. 설정에서 **정규식 사용**을 켜면 각 조각이 정규식이 됩니다. 예: `\.pdf$`, `^2024`.

파일은 한 번 클릭하면 파일 관리자에서 위치를 보여주고, 더블클릭하면 기본 프로그램으로 엽니다. 폴더는 클릭하면 열립니다. 결과에서 우클릭하면 열기, 폴더에서 보기, 경로 복사, 이름 복사를 할 수 있습니다.

Enter는 선택한 결과를 엽니다. Esc는 검색어와 결과를 지웁니다.

## 창

`≡`을 드래그하면 이동합니다. 좌우 가장자리로 너비를 280~720px 사이에서 조절합니다. 위치와 크기는 데이터 폴더의 `settings.json`에 저장됩니다.

## 설정

톱니 버튼에서 언어, 대소문자, 정규식, 정렬, 인덱싱 범위, 재인덱싱 주기, 시스템 시작 시 자동 실행, 시스템 트레이 아이콘, 색, 불투명도, 항상 위를 바꿉니다.

- **언어**는 설정 창을 연 동안 바로 바뀝니다. 저장하면 다음 실행에도 유지되고, 취소하면 되돌아갑니다.
- **인덱싱**은 `index.building.db`를 지우고 처음부터 다시 만듭니다.
- **멈춤**은 진행 중인 building DB를 남깁니다.
- **초기화**는 인덱스만 지우거나, 인덱스와 설정을 함께 기본값으로 되돌립니다.
- 범위가 바뀐 뒤 저장하면 인덱스를 다시 만듭니다.

데이터 폴더:

| OS | 위치 |
|----|------|
| Windows | `%APPDATA%\MyDeskSearch` |
| macOS | `~/Library/Application Support/MyDeskSearch` |
| Linux | `~/.config/MyDeskSearch` |

`index.db`가 있으면 재인덱싱 중에도 그 인덱스로 검색합니다. 재인덱싱이 모두 성공하면 새 인덱스로 바뀝니다. 일부 폴더를 읽지 못하면 그 인덱스로 교체하지 않고 잠시 후 다시 시도합니다.

화면 언어와 관계없이 한국어, 영어, 일본어, 중국어 파일 이름을 검색할 수 있습니다.
