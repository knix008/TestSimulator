# My3DObjects 사용 설명서 (요약)

그림이 들어간 전체 설명서는 **`doc/Guide.html`**(한국어) · **`doc/Guide.en.html`**(English) 이며,
프로그램 툴바 오른쪽의 **[사용 설명서]** 버튼으로 엽니다.

## 1. 처음 실행

1. 설치 파일을 실행하고 프로그램을 엽니다.
2. 엔진이 자동으로 설치됩니다(Python · PyTorch · 모델, 수 분~수십 분). 과정은 아래 **로그 패널**에 보입니다.
3. 상태 표시줄 오른쪽에 **준비됨 · (장치)** 가 나오면 쓸 수 있습니다.
4. Stable Fast 3D · SPAR3D 는 Hugging Face 약관 동의와 토큰이 필요합니다 → 설정 → 엔진 → Hugging Face 토큰.
   토큰 없이 바로 쓰려면 모델을 **TripoSR** 나 **TRELLIS** 로 바꿉니다.

## 2. 이미지를 3D로

1. **이미지 열기**(Ctrl+O) 또는 창에 끌어다 놓기. 시작 화면 · 파일 메뉴의 **예제**에 바로 써 볼 그림 44장이 있습니다.
2. 툴바의 **모델** 드롭다운에서 고릅니다.

   | 모델 | 이럴 때 |
   | --- | --- |
   | Stable Fast 3D | 빠르게(GPU 약 1초), 텍스처가 있는 결과 |
   | SPAR3D | SF3D 와 같은 텍스처 결과에 뒷면이 더 정확하게 |
   | TripoSR | 가볍게, CPU 로도, 라이선스 걱정 없이(MIT) |
   | TRELLIS | 가장 정교한 모양과 색(정점 색). GPU 메모리 12 GB 이상 권장 |
   | Hunyuan3D | 색 없는 정밀한 형상(버전 선택, 지역 제한 라이선스) |

3. **3D로 변환**(F5). 취소는 Esc.
4. 결과를 살펴보고 **저장**(Ctrl+S, GLB, 파일 버튼 오른쪽) 또는 **내보내기**(Ctrl+Shift+S) — GLB · glTF · OBJ · STL · PLY · USDZ · 3MF · AMF · DAE · VRML · VTK · PCD · XYZ · PNG.
5. **3D 프린트용 저장**(Ctrl+Shift+P) — 아래 5장.
6. **인쇄**(Ctrl+P, 종이에): 한 방향 · 4방향 · 6방향 · 방향별 한 장, 미리 보기를 보며 프린터 · 매수 · 방향을 고릅니다.

처음이라면 **튜토리얼**(시작 화면의 [튜토리얼] 또는 도움말 버튼 옆 ▾)이 예제로 단계별로 안내합니다.
시작할 때 튜토리얼을 물을지는 설정 → 화면 → 튜토리얼에서 바꿉니다.

GPU 가 있으면 GPU, 없으면 CPU 를 씁니다. GPU 에서 실패하면 자동으로 CPU 에서 다시 합니다.

## 3. 3D 화면

| 조작 | 동작 |
| --- | --- |
| 왼쪽 끌기 / 오른쪽 끌기 / 휠 | 회전 / 이동 / 확대 |
| F | 화면 맞춤 |
| 방향 큐브 클릭 | 그 방향에서 보기 |
| 광원 공 끌기 | 광원 이동 (축 화살표 · 평면 사각형으로 제한) |

- 바닥은 **5×5 로 나뉜 무한 격자**, X(빨강) · Y(초록) · Z(파랑) **좌표축**, 길이가 쓰인 **눈금자**.
- 오른쪽 **설정 패널**: 변환 · 장면 · 광원 · 재질 · 모델 · 카메라.
- 오른쪽 클릭(끌지 않고)으로 컨텍스트 메뉴 — 보기 방향, 저장, 3D 프린트용 저장, 인쇄, 스크린샷 등.
- 창에는 제목 표시줄이 없습니다. 툴바의 빈 곳을 끌어 창을 옮기고, 두 번 눌러 최대화합니다.

## 4. 3D 파일 열기 · 형식 변환

**3D 파일 열기**(Ctrl+Shift+O): GLB · glTF · OBJ(+MTL) · STL · PLY · FBX · DAE · 3MF · 3DS · USDZ · VRML · VTK · AMF · PCD · XYZ · KMZ · LWO.
열린 모델을 다른 형식으로 저장하면 형식 변환이 됩니다. 모델 탭의 회전 · 배율이 함께 적용됩니다.

## 5. 3D 프린터로 뽑기

**파일 → 3D 프린트용 저장**(Ctrl+Shift+P, 내보내기 메뉴 · 오른쪽 클릭 메뉴에도 있음).

| 항목 | 뜻 |
| --- | --- |
| 크기 (mm) · 크기 기준 | **높이** 또는 **가장 긴 변**을 이 길이로 맞춥니다 (30 · 50 · 100 · 150 · 200 mm 단추). 비율은 그대로 |
| 파일 형식 | **3MF** — 단위(mm)와 색이 들어가는 권장 형식. **STL** — 바이너리, 색 없음, 거의 모든 슬라이서 |
| 구멍 메우기 | 열린 가장자리를 막아 닫힌(수밀) 물체로 만듭니다 |
| 색 넣기 (3MF) | 정점 색 · 텍스처 색을 3MF 에 넣어 여러 색 프린터(AMS · MMU)에서 칠합니다 |

저장할 때는 화면에 보이는 그대로(모델 탭의 회전 · 배율 포함) **Z 축이 위, 앞면이 프린터 앞(−Y), 바닥 가운데(Z = 0)** 에 놓고,
겹친 정점을 합치고 · 잘못된 면을 지우고 · 구멍을 메우고 · 면 방향을 맞추고 · 안팎을 바로잡습니다.
오른쪽 **프린트 점검**에 결과가 나옵니다: 닫힌 메시인지(수밀), 크기(X × Y × Z mm), 삼각형 수, 부피, 꽉 채웠을 때의 PLA 무게(최대값), 고친 것.

- 물체가 바닥에 잘 서도록 먼저 모델 탭에서 돌려 두세요(예: 누운 물체는 X 회전 −90°).
- 닫히지 않음이 남으면 슬라이서의 수리(PrusaSlicer "Fix through Netfabb", Bambu Studio "Repair")로 마저 고칩니다.
- Hunyuan3D 결과는 색이 없어 STL 로 충분합니다. 얇은 부분(꼬리 · 깃털)은 크게 뽑거나 서포트를 씁니다.

## 6. 웹 버전

```bash
npm run web      # http://localhost:5196 + 엔진
```

## 7. 데이터

- 설정: `%APPDATA%\My3DObjects\settings.json`
- 엔진: `%LOCALAPPDATA%\My3DObjects\engine` (다시 설치: 설정 → 엔진)
  - 모델 코드: `engine\models\<모델>\src` (SPAR3D 의 AlphaCLIP · CLIP 가중치, TRELLIS 의 DINOv2 도 각 모델 폴더에)
- 모델 가중치: `~/.cache/huggingface` (공용 캐시)

## 8. 유료 API

Stability AI API 는 **기본으로 꺼져 있습니다**. 설정 → 엔진 → 변환 방법에서 고르면 확인을 받고, API 키가 필요하며,
변환마다 크레딧이 차감되고 이미지가 전송됩니다.
