# 마이 캘린더 사용 설명서

마이 캘린더는 바탕화면 위에 두는 투명한 달력입니다. 공휴일, 음력, 일정, 알림을 한 화면에서 볼 수 있습니다.

## 1. 시작하기

### 설치

| 운영체제 | 방법 |
|---|---|
| Windows | 설치 파일(`My Calendar_x.y.z_x64-setup.exe`)을 실행합니다. 설치 전에 한국어와 English 중 하나를 고릅니다. |
| macOS | `dmg`를 열어 앱을 응용 프로그램 폴더로 옮기거나, `installer/macos/install.command`를 실행합니다. |
| Linux | `deb`, `rpm`, `AppImage` 중 하나를 설치하거나, `installer/linux/install.sh`를 실행합니다. |
| 웹 | 배포된 주소를 브라우저로 엽니다. |

### 다시 설치하기

이미 설치되어 있으면 설치 프로그램이 기존 프로그램을 완전히 삭제한 뒤 새로 설치합니다. 그 전에 일정과 설정 같은 사용자 데이터도 지울지 묻습니다.

- **예:** 사용자 데이터까지 지우고 처음 상태로 설치합니다.
- **아니요 (기본값):** 사용자 데이터는 남겨 두고 프로그램만 다시 설치합니다.
- **취소:** 아무것도 바꾸지 않고 설치를 그만둡니다.

Linux와 macOS 설치 스크립트는 같은 질문을 `[y/N]`으로 묻습니다. Windows에서 `/S`(조용히 설치)나 `/P`(진행 표시만)로 실행하면 묻지 않고 사용자 데이터를 남겨 둡니다.

### 언어 고르기

- 처음 실행하면 한국어와 English 중 하나를 고릅니다. 설치할 때 이미 골랐다면 그 언어로 바로 열립니다.
- 언어는 나중에 설정 › 일반이나 트레이 메뉴에서 바꿀 수 있습니다.

### 트레이에서 실행

- 데스크톱 앱은 작업 표시줄 대신 시스템 트레이(알림 영역)에 아이콘으로 나타납니다.
- 트레이 아이콘을 클릭하면 캘린더를 보이거나 숨깁니다.
- 창의 닫기 버튼(×)이나 ESC는 캘린더를 트레이로 숨길 뿐 종료하지 않습니다. 완전히 끝내려면 트레이 메뉴에서 **종료**를 누릅니다.

## 2. 화면 구성

```
┌─────────────────────────────────────────────┐
│ 🗓 마이 캘린더  ‹ 2026년 10월 › 📅    ⚙ – □ × │  ← 툴바
│  일   월   화   수   목   금   토             │  ← 요일
│  27   28   29   30    1    2    3            │
│  …                                          │  ← 날짜 칸
│ ● 대한민국 실시간 확인됨  확인 시각 …    ⟳  ˄ │  ← 상태 줄
│ 2026년 10월 7일 수요일  음력 8월 27일   + ≡  │  ← 선택한 날짜
│ 일정 없음 / 이번 달 공휴일·일정               │  ← 일정 목록
└─────────────────────────────────────────────┘
```

**툴바**
- 맨 왼쪽에는 프로그램 아이콘이 있습니다. 창을 넓히면 아이콘 옆에 프로그램 이름(마이 캘린더 / My Calendar)이 저절로 나타납니다.
  - 이름이 다 들어갈 자리가 없으면 아이콘만 표시합니다. 이름이 잘린 채로 보이지는 않습니다.
  - 이름은 창의 최소 폭에 들어가지 않으므로, 아이콘만 남을 때까지 창을 좁힐 수 있습니다.
- 연도와 달을 쓰는 방법은 설정의 **달력 → 연월 표기**에서 바꿉니다. 짧은 표기일수록 창을 더 좁게 줄일 수 있습니다.
- 이전 달(‹), 다음 달(›) 버튼으로 달을 옮깁니다. 그 옆의 **오늘** 버튼(오늘 날짜에 점이 찍힌 달력 아이콘)을 누르면 오늘로 돌아옵니다. 마우스를 올리면 "오늘"이라고 나옵니다. 데스크톱에서는 설정, 최소화, 전체 화면, 닫기 버튼도 있습니다. 최소화하면 작업 표시줄에 나타나지 않고 트레이로 들어갑니다. 트레이 아이콘을 누르면 다시 열립니다.
- 툴바를 끌면 창이 움직입니다.

**날짜 칸**
- 일요일과 공휴일은 빨간색, 토요일은 파란색으로 표시됩니다. 오늘은 테두리로 표시됩니다.
- 공휴일이 있는 날에는 빨간 점이 찍힙니다.
- 일정이 있는 날에는 일정마다 그 일정의 색깔 점이 날짜 아래에 가로로 늘어섭니다.
  - 한 줄이 다 차면 그때 다음 줄로 넘어갑니다. 칸에 들어가지 않는 줄은 표시하지 않으며, 날짜 숫자를 가리지 않습니다.
  - 공휴일에 일정이 있으면 공휴일의 빨간 점이 맨 앞에 옵니다.
  - 음력이나 절기가 날짜 아래에 적힌 날에는 점이 날짜 위로 갑니다. 첫 줄이 날짜 바로 위에 오고, 다음 줄은 그 위로 쌓입니다.
- 음력 달이 바뀌는 날, 양력 1일, 24절기에는 날짜 아래에 음력이나 절기 이름이 작게 나옵니다.
- 6주에 걸치는 달은 마지막 줄 칸 하나를 대각선으로 나눠 두 날짜를 함께 보여 줍니다 (예: 23/30).

**상태 줄**
- 공휴일 국가와 확인 상태(실시간 확인됨, 마지막 확인 내용, 내장 공휴일)를 보여 줍니다.
- ⟳ 버튼은 공휴일을 다시 확인합니다. ˄ 버튼은 아래 일정 목록을 접거나 펼칩니다.

**일정 목록**
- 선택한 날짜의 일정과 이번 달 공휴일·일정을 보여 줍니다.
- 항목을 누르면 그 날짜로 이동하거나 일정을 편집합니다.

**크기 조절**
- 오른쪽 아래 모서리나 창의 가장자리를 끌어 크기를 바꿉니다.
- 날짜 글자는 창 폭에 맞춰 함께 커지고 작아집니다. 정한 크기는 다음 실행 때도 유지됩니다.

## 3. 키보드 단축키

캘린더 창에서 쓸 수 있습니다.

| 키 | 동작 |
|---|---|
| ← → | 하루 전, 하루 뒤 |
| ↑ ↓ | 일주일 전, 일주일 뒤 |
| Page Up / Page Down | 이전 달, 다음 달 |
| T | 오늘로 이동 |
| N | 선택한 날짜에 일정 추가 |
| Delete | 일정 목록에서 초점이 있는 일정 삭제 (확인 후) |
| Ctrl+, (macOS: ⌘+,) | 설정 열기 |
| Ctrl+P (macOS: ⌘+P) | 인쇄 미리 보기 열기 (미리 보기 창에서는 바로 인쇄) |
| ESC | 전체 화면이면 원래 크기로, 아니면 트레이로 숨기기. 별도 창이나 대화상자에서는 그 창을 닫습니다. |

## 4. 우클릭 메뉴

**날짜 칸을 우클릭할 때**
- 이 날에 일정 추가, 그날 일정 편집
- 오늘로 이동, 일정 관리, 인쇄, 설정

**타이틀 바나 빈 곳을 우클릭할 때**
- 이전 달, 다음 달, 오늘로 이동
- 일정 추가, 일정 관리, 인쇄, 설정
- 데스크톱에서만: 다른 창보다 위에 두기(체크 표시), 최소화, 최대화(전체 화면), 트레이로 숨기기

메뉴는 방향키로 고르고 Enter로 실행할 수 있습니다. ESC를 누르면 닫힙니다.

## 5. 일정

### 일정 추가

다음 중 편한 방법을 씁니다.
- 일정이 없는 날짜 칸을 더블클릭합니다.
- 날짜를 고르고 N 키를 누릅니다.
- 일정 목록 옆의 + 버튼을 누릅니다.
- 우클릭 메뉴에서 "이 날에 일정 추가"를 고릅니다.

데스크톱에서는 일정 입력 창이 캘린더와 따로 열립니다. 캘린더를 작게 줄여 두어도 입력 칸이 가려지지 않습니다.
- 입력 창의 높이는 입력 칸에 딱 맞춰집니다. 반복이나 음력을 고르면 칸이 늘어나는 만큼 창도 길어지고, 되돌리면 다시 줄어듭니다.
- 입력 창은 끌어서 옮길 수 있고, 오른쪽 아래 모서리로 폭을 바꿀 수 있습니다.
- 화면보다 길어지면 내용이 스크롤되고, **취소**와 **저장** 버튼은 늘 아래에 보입니다.
- 입력 창이 열린 채로 다른 일정을 고르면 그 일정으로 바뀝니다.
- 웹 버전에서는 같은 양식이 페이지 안에 겹쳐 열립니다.

### 일정 항목

| 항목 | 설명 |
|---|---|
| 제목 | 꼭 입력해야 합니다. |
| 날짜 기준 | 양력과 음력 중에 고릅니다. 기본은 양력입니다. |
| 날짜 | 일정 날짜. 반복 일정이면 첫 날짜입니다. 음력을 고르면 연도·월·일을 따로 고르고, 옆에 해당하는 양력 날짜가 나옵니다. 윤달이 있는 해에는 "윤6월"처럼 월 목록에 함께 나옵니다. |
| 시간 | 비워 두면 종일 일정입니다. |
| 반복 | 안 함, 매주, 매월, 매년. "2주마다"처럼 간격(1~99)과 종료일을 정할 수 있습니다. 종료일을 비우면 계속 반복합니다. |
| 색상 | 기본 8색이나 사용자 지정 색 |
| 알림 | 알림 없음, 일정 시간에, 5분·10분·15분·30분 전, 1·2시간 전, 1·2일 전, 1주 전 |

### 편집과 삭제

- 일정 목록에서 일정을 누르면 편집 창이 열립니다.
- 일정이 있는 날짜 칸을 더블클릭하면 일정 관리 창이 그날의 일정만 모아 보여 줍니다. 반복 일정도 그날에 해당하면 나옵니다. 여기서 편집, 삭제, 그날에 새 일정 추가를 할 수 있고, **모든 일정**을 누르면 전체 목록으로 돌아갑니다.
- 일정 오른쪽의 휴지통 버튼을 누르거나, 일정에 초점을 두고 `Delete` 키를 누르면 메인 창에서 바로 지울 수 있습니다. 확인 줄에서 `ESC`나 **취소**를 누르면 지우지 않습니다.
- 반복 일정을 지울 때는 **이 날만 삭제**와 **전체 삭제** 중에서 고릅니다.
- 음력으로 넣은 일정은 매월·매년 반복할 때 음력 날짜를 따라갑니다. 음력 30일은 29일까지만 있는 달의 마지막 날에, 윤달은 그 윤달이 없는 해의 같은 달에 들어갑니다. 일정 관리 창에서는 음력 날짜로 보여 줍니다.
- 삭제하기 전에 한 번 더 확인합니다.

### 일정 관리 창

트레이 메뉴, 일정 목록의 ≡ 버튼, 우클릭 메뉴의 **일정 관리**로 엽니다.
- 모든 일정을 보고, 검색하고, 일정마다 편집하거나 삭제합니다.
- **새 일정의 기본 알림**을 여기서 정합니다.

## 6. 알림

- 캘린더가 실행 중이면, 일정에 정한 알림 시각에 화면 오른쪽 아래에 알림 창이 뜹니다. 웹에서는 페이지 오른쪽 아래에 뜹니다.
- **5분 후 다시**를 누르면 5분 뒤에 다시 알립니다. **확인**은 그 알림을, **모두 닫기**는 모든 알림을 닫습니다.
- 종일 일정은 그날 오전 9시를 기준으로 알립니다.
- 컴퓨터가 꺼져 있거나 앱이 실행 중이 아니어서 놓친 알림은, 일정 시작 후 1시간까지는 늦게라도 뜹니다.

## 7. 전체 화면 (배경화면 모드)

툴바의 □ 버튼이나 우클릭 메뉴의 **최대화**를 누르면 캘린더가 화면 전체에 펼쳐집니다.

- 캘린더는 다른 모든 창의 아래에 깔려 배경화면처럼 보입니다. 다른 프로그램을 쓰는 데 방해가 되지 않습니다.
- 툴바 띠와 창 테두리가 사라지고, 요일과 날짜가 화면 크기에 맞게 커집니다.
- **ESC**를 누르거나 버튼을 다시 누르면, 전체 화면 전의 크기와 위치로 돌아옵니다.
- 전체 화면용 날짜 글꼴을 따로 정해 둘 수 있습니다 ([8. 설정](#8-설정)의 "날짜 글꼴" 참고).
- Win+↑ 키나 창을 화면 위쪽 끝으로 끌어 최대화해도 같은 모드가 됩니다.

다른 위젯 프로그램(시계, 아이콘 정리 프로그램 등)은 캘린더보다 위에 표시됩니다.

## 8. 설정

툴바의 ⚙ 버튼, 우클릭 메뉴, 트레이 메뉴, Ctrl+,로 엽니다. 위쪽의 네 탭(일반, 모양, 달력, 정보) 중 선택한 탭만 색과 테두리로 표시됩니다. 설정 창은 어느 탭을 열어도 크기가 같고, 내용이 스크롤 없이 다 보입니다. 설정 내용의 글자는 모두 같은 크기이고, 드롭다운과 검색 칸도 그 글자에 맞춘 높이입니다. 바꾼 내용은 바로 적용되고 자동으로 저장됩니다. 수치를 정하는 항목에는 슬라이더 양옆에 − / + 버튼이 있습니다.

### 일반

- **언어:** 한국어, English
- **다른 창보다 위에 두기:** 캘린더를 항상 다른 창 위에 둡니다. 전체 화면에서는 이 설정과 관계없이 맨 아래에 깔립니다.
- **시스템 시작 시 자동 실행:** 컴퓨터를 켜면 캘린더가 트레이에서 시작됩니다.

#### 공휴일

- 공휴일을 표시할 국가를 검색해 고릅니다. 약 200개 나라를 지원합니다.
- 공휴일은 인터넷(Nager.Date)에서 확인합니다.
  - 연결이 안 되면 마지막으로 확인한 내용을 보여 줍니다.
  - 그것도 없으면 내장된 계산 규칙으로 보여 줍니다.
- 한국어 화면에서는 그 나라의 현지 공휴일 이름을, English 화면에서는 영어 이름을 씁니다.

#### 배경

고른 그림을 메인 캘린더 창의 배경에 깝니다. 글자와 버튼은 그림 위에 그대로 보입니다.

- **배경 이미지:** 고른 그림을 미리 보기로 보여 줍니다.
  - **이미지 선택…:** PNG, JPEG, WebP, GIF, BMP 파일을 고릅니다. 긴 변이 2560픽셀보다 크면 줄여서 JPEG로 저장합니다.
  - **다른 이미지… / 제거:** 그림을 바꾸거나 없앱니다.
- **배경 이미지 투명도:** 0~100%. 값이 클수록 그림이 옅어지고 테마 색이 더 보입니다. 100%면 그림이 보이지 않습니다. 처음 값은 50%입니다.
- 일정 관리, 일정 입력, 인쇄 미리 보기, 알림, 설정 창에는 그림을 넣지 않습니다. 인쇄한 종이에도 그림은 나오지 않습니다.
- 그림은 이 컴퓨터에만 저장됩니다. 너무 커서 저장하지 못하면 안내 문구가 나옵니다.

### 모양

- **투명도:** 0~100%. 값이 클수록 배경이 더 투명해집니다. − / + 버튼은 5%씩 바꿉니다.
- **테마:** 라이트 20종과 다크 20종을 위아래 두 묶음으로 한 번에 보여 줍니다. 견본을 누르면 바로 바뀌고, 고른 테마는 강조색으로 표시됩니다.

### 달력

- **연월 표기:** 툴바에 연도와 달을 쓰는 방법을 고릅니다. 한국어와 English의 선택은 따로 기억합니다.

  | 한국어 | English |
  |---|---|
  | 2026년 10월 (기본) | October 2026 (기본) |
  | 26년 10월 | Oct 2026 |
  | 2026年 10月 | Oct '26 |
  | 2026. 10. | OCT 2026 |
  | 2026.10 | 10/2026 |
  | 2026-10 | 10.2026 |
  | 2026/10 | 2026-10 |
  | 10월 (연도 생략) | October (연도 생략) |

- **한 주의 시작:** 달력의 첫 번째 열이 될 요일을 고릅니다.
- **음력과 절기 표시:** 날짜 아래 음력과 24절기 표시를 켜거나 끕니다.
- **날짜 글꼴**
  - **적용 (데스크톱만):** **창**과 **전체 화면** 중 어느 쪽 글꼴을 바꿀지 고릅니다.
    - 두 글꼴은 따로 기억됩니다.
    - 전체 화면일 때 설정을 열면 처음부터 **전체 화면**이 선택되어 있습니다.
  - **글자 크기:** 60~180%. 창 크기에 맞춘 기본 크기에서 이 비율만큼 더 크거나 작게 표시합니다.
  - **글꼴:** 기본, 고딕, 명조, 둥근 글꼴, 고정폭
  - **굵기:** 보통, 굵게, 아주 굵게
  - **기울임꼴**
  - **미리 보기**와 **기본값으로** 버튼이 있습니다. 기본값으로는 선택한 쪽 글꼴만 되돌립니다.

### 정보

프로그램 버전, 지원 환경, 공휴일 출처를 보여 줍니다. 트레이 메뉴의 **프로그램 정보**를 누르면 이 탭이 열립니다.

## 9. 인쇄

Ctrl+P, 우클릭 메뉴의 **인쇄**, 날짜 칸 메뉴의 **인쇄**로 인쇄 미리 보기를 엽니다. 지금 보고 있는 달부터 시작합니다.

**페이지 설정 (왼쪽)**

| 항목 | 선택 |
|---|---|
| 시작 달 | ‹ › 버튼으로 바꿉니다. |
| 개월 수 | 1~12개월. 한 달이 한 쪽입니다. |
| 용지 | A4, A3, A5, B5, Letter, Legal |
| 방향 | 세로, 가로 |
| 여백 | 없음, 좁게, 보통, 넓게 |
| 인쇄할 내용 | 날짜 칸에 일정 표시, 달마다 일정 목록 추가, 공휴일 이름, 음력과 절기, 흑백으로 인쇄 |

**미리 보기 (오른쪽)**
- 실제 용지 비율로 페이지를 보여 줍니다.
- − / + 버튼으로 확대·축소하고, 가운데 % 버튼을 누르면 창에 맞춘 크기로 돌아갑니다.

**인쇄** 버튼을 누르면 운영체제의 프린터 선택 창이 열립니다. PDF로 저장하려면 그 창에서 "PDF로 저장"(또는 Microsoft Print to PDF)을 고릅니다. 페이지 설정은 다음에도 그대로 기억됩니다.

트레이 아이콘을 우클릭하면 다음 메뉴가 열립니다.

## 11. 웹 버전에서 다른 점

- 설정, 일정 관리, 인쇄 미리 보기, 일정 입력이 별도 창 대신 페이지 안의 대화상자로 열립니다.
- 트레이, 자동 실행, 다른 창보다 위에 두기, 전체 화면(배경화면 모드)은 데스크톱 앱에서만 됩니다.
- 페이지 뒤 배경은 투명도를 보여 주기 위한 예시 그림입니다.

## 12. 데이터

- 설정, 일정, 공휴일 캐시는 이 컴퓨터의 앱 데이터에만 저장됩니다. 계정이나 서버로 보내지 않습니다.
- 인터넷은 공휴일과 국가 목록을 확인할 때만 씁니다 (`date.nager.at`).
- 웹 버전은 브라우저마다 데이터를 따로 저장합니다. 브라우저의 사이트 데이터를 지우면 일정도 지워집니다.

## 13. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 캘린더가 보이지 않습니다. | 트레이 아이콘을 클릭하세요. 전체 화면이면 다른 창 아래에 있으니, 바탕 화면 보기(Win+D)로 확인하거나 트레이에서 다시 여세요. |
| 공휴일이 "마지막 확인 내용"이나 "내장 공휴일"로 나옵니다. | 인터넷 연결을 확인한 뒤 상태 줄의 ⟳ 버튼을 누르세요. |
| 알림이 뜨지 않습니다. | 캘린더가 실행 중이어야 합니다(트레이에 아이콘이 있어야 함). 일정의 알림 항목이 "알림 없음"이 아닌지 확인하세요. |
| 음력 날짜가 나오지 않습니다. | 일부 환경은 음력 계산을 지원하지 않아 절기만 표시합니다. 설정 › 달력에서 안내를 확인하세요. |
| 창이 너무 크거나 작게 열립니다. | 원하는 크기로 한 번 조절하면 그 크기가 기억됩니다. |
