# 사용자 가이드 — TTS Multi OS

## 시작하기

### 데스크톱 앱 실행
```bash
npm start
```

### 웹 브라우저 미리보기
```bash
npm run web
# 브라우저에서 http://localhost:3000 열기
```

---

## 기본 사용법

### 텍스트 읽기

1. 텍스트 입력란에 읽을 내용을 입력합니다.
2. 우측 패널에서 **언어**를 선택합니다 (한국어 / English).
3. **모델**을 선택합니다.
4. 상단 **▶ 읽기** 버튼을 클릭합니다.
5. 화면 하단 **파형 패널**에 파형이 표시되며 음성이 재생됩니다.

### 파일 열기

- 텍스트 입력란 상단의 **📂 파일 열기** 버튼을 클릭합니다.
- `.txt` 또는 `.md` 파일을 선택하면 내용이 입력란에 자동 로드됩니다.
- `samples/` 폴더에 예제 파일이 있습니다.

### 예제 파일 (samples/ 디렉토리)

| 파일 | 내용 |
|------|------|
| korean_greeting.txt | 한국어 인사말 |
| korean_news.txt | 한국어 뉴스 스타일 문장 |
| korean_story.txt | 한국어 이야기 |
| english_greeting.txt | 영어 인사말 |
| english_story.txt | 영어 이야기 |
| english_tech.txt | 영어 기술 설명 |

## 모델 관리

### 모델 다운로드

1. **모델** 드롭다운에서 다운로드할 모델을 선택합니다.
2. **↓ 다운로드** 버튼을 클릭합니다.
3. 우측 상태 카드에서 다운로드 진행률을 확인합니다.
4. 완료 후 모델 이름 옆에 **✓ 설치됨** 표시가 나타납니다.

> **참고**: 모델은 `%APPDATA%\TTSMultiOSV10\models\` (Windows) 또는  
> `~/TTSMultiOSV10/models/` (macOS/Linux)에 저장됩니다.

### 모델별 특징

| 모델 | 언어 | 특징 |
|------|------|------|
| Piper KSS | 한국어 | 경량, 빠른 응답 |
| Supertonic INT8 | 한국어 | 한국어+영어 동시 지원, 높은 품질 |
| MMS TTS | 한국어 | Meta 개발, Transformers.js 호환 |
| Kokoro 82M | 영어 | 고품질 영어 TTS |

## 음성 파라미터 조절

우측 패널의 슬라이더로 음성을 조절합니다:

- **볼륨**: 0%–200% (기본 100%)
- **속도**: 0.25×–4.0× (기본 1.0×)
- **피치**: -12 ~ +12 반음 (기본 ±0)

---

## WAV 파일 내보내기

1. 텍스트를 읽은 후 상단 **📄 WAV 저장** 버튼을 클릭합니다.
2. 저장 경로를 선택합니다.
3. WAV 파일이 선택한 경로에 저장됩니다.

---

## 테마 전환

상단 우측의 **🌙 / ☀️** 버튼으로 다크/라이트 테마를 전환합니다.  
선택한 테마는 자동으로 저장됩니다.

---

## 오류 처리

오류 발생 시 팝업이 표시됩니다:
- **⧉ 복사** 버튼으로 오류 내용을 클립보드에 복사할 수 있습니다.
- 오류 내용을 개발자에게 전달할 때 유용합니다.

## 빌드 (설치 파일 생성)

```bash
# Windows NSIS 인스톨러
npm run build:win

# macOS DMG
npm run build:mac

# Linux AppImage + deb
npm run build:linux
```

빌드 결과물: `dist/` 폴더

### Windows 설치 시
NSIS 인스톨러가 열리며 다음을 선택할 수 있습니다:
- 설치 디렉토리
- 바탕화면 바로가기 생성 여부 (기본 선택됨)
- 시작 메뉴 바로가기 (자동 생성)
