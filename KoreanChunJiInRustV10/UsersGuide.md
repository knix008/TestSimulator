# 사용 설명서

## 화면

```
┌────────────────────────────────────┐
│ 파일  편집  입력  설정  도움말        │  메뉴
├────────────────────────────────────┤
│ 🗎 📂 💾 ⧉ 📋 🗑 ⟳ 🎨 🌐     ℹ ⚙ │  툴바
├────────────────────────────────────┤
│                                    │
│  안녕하세요|                        │  편집 영역
│                                    │
├────────────────────────────────────┤
│ 한글    조합 ㅅ + ㅔ + -    5자      │  상태줄
├────────────────────────────────────┤
│   ㅣ      ·      ㅡ                │
│   ㄱㅋ   ㄴㄹ   ㄷㅌ                │  천지인 12키
│   ㅂㅍ   ㅅㅎ   ㅈㅊ                │
│   . ,    ㅇㅁ   ? !                │
│  모드 ← 스페이스 → 줄바꿈 지우기     │  기능 버튼
└────────────────────────────────────┘
```

툴바 오른쪽 끝은 **정보(ℹ) · 설정(⚙)** 입니다. 정보가 설정 왼쪽입니다.

**컴팩트 모드**를 켜면 툴바에서 정보 단추가 빠지고 창이 조금 좁아집니다.
설정 단추는 그대로 둡니다. 정보는 편집 영역을 오른쪽 단추로 눌렀을 때
나오는 메뉴와 `도움말 > 정보` 에서 엽니다.

편집 영역 오른쪽 단추 메뉴: 복사 · 붙여넣기 · 설정 · 정보 · 사용법.

**상태줄**은 지금 모드, 조합 중인 낱자, 글자 수를 보여 줍니다.
버튼에 마우스를 올리면 그 버튼의 설명이 잠깐 나옵니다.

**커서**는 늘 편집 영역에 있습니다. 키패드를 눌러도 초점이 옮겨 가지 않으므로,
어디에 글자가 들어갈지 언제나 보입니다.

## 자판

```
  ㅣ     ·      ㅡ
  ㄱㅋ   ㄴㄹ   ㄷㅌ
  ㅂㅍ   ㅅㅎ   ㅈㅊ
  . ,    ㅇㅁ   ? !
```

## 모음

`ㅣ` 와 `·`(아래아) 와 `ㅡ` 세 개를 이어서 모든 모음을 만듭니다.

| 모음 | 누르는 차례 | 모음 | 누르는 차례 | 모음 | 누르는 차례 |
|---|---|---|---|---|---|
| ㅏ | ㅣ · | ㅑ | ㅣ · · | ㅐ | ㅣ · ㅣ |
| ㅓ | · ㅣ | ㅕ | · · ㅣ | ㅔ | · ㅣ ㅣ |
| ㅗ | · ㅡ | ㅛ | · · ㅡ | ㅚ | · ㅡ ㅣ |
| ㅜ | ㅡ · | ㅠ | ㅡ · · | ㅟ | ㅡ · ㅣ |
| ㅡ | ㅡ | ㅣ | ㅣ | ㅢ | ㅡ ㅣ |
| ㅘ | · ㅡ ㅣ · | ㅙ | · ㅡ ㅣ · ㅣ | ㅝ | ㅡ · · ㅣ |
| ㅒ | ㅣ · · ㅣ | ㅖ | · · ㅣ ㅣ | ㅞ | ㅡ · · ㅣ ㅣ |

`ㅝ` 는 `ㅠ` 다음에 `ㅣ` 를 눌러 만듭니다.
`ㅠㅣ` 라는 모음이 없으므로 그 자리를 `ㅝ` 가 씁니다.

**아래아 중간 상태**는 화면에 그대로 보입니다.
`·` 만 한 번 누르면 `·` 가, 두 번 누르면 `‥` 가 보입니다.
거기서 `ㅣ` 나 `ㅡ` 를 누르면 모음이 완성됩니다.

## 자음

같은 키를 연달아 누르면 순환합니다.

| 키 | 순환 |
|---|---|
| ㄱㅋ | ㄱ → ㅋ → ㄲ → ㄱ … |
| ㄴㄹ | ㄴ → ㄹ → ㄴ … |
| ㄷㅌ | ㄷ → ㅌ → ㄸ → ㄷ … |
| ㅂㅍ | ㅂ → ㅍ → ㅃ → ㅂ … |
| ㅅㅎ | ㅅ → ㅎ → ㅆ → ㅅ … |
| ㅈㅊ | ㅈ → ㅊ → ㅉ → ㅈ … |
| ㅇㅁ | ㅇ → ㅁ → ㅇ … |

거센소리와 된소리가 모두 순환에 들어 있으므로 획추가 · 쌍자음 키가 따로
없습니다. 그 자리에 문장부호 키를 두었습니다.

### 연음

받침 뒤에 모음을 누르면 자동으로 넘어갑니다.

```
간 + ㅏ  →  가나
값 + ㅏ  →  갑사      (겹받침은 둘째 자음만 넘어간다)
```

### 겹받침

자음을 이어 누르면 합쳐집니다.

```
값 = ㄱ ㅏ ㅂ ㅅ
닭 = ㄷ ㅏ ㄹ ㄱ
```

첫 타에 붙지 않는 겹받침은 **한 번 더 누르면** 합쳐집니다.

```
만 + ㅅㅎ 키   →  만ㅅ      (ㄴ+ㅅ 은 겹받침이 아니다)
     ㅅㅎ 키   →  많        (ㄴ+ㅎ 은 ㄶ 이므로 도로 합친다)
```

`많 삶 핥 옳` 처럼 `ㄶ ㄻ ㄾ ㅀ` 이 들어간 글자는 이렇게 입력합니다.

## 같은 키를 연달아 써야 할 때

`안녕` 은 `ㄴ` 을 두 번 눌러야 합니다. 그냥 두 번 누르면 순환해서
`ㄹ` 이 됩니다. 둘 중 하나를 하세요.

- 사이에 `→` 버튼(또는 오른쪽 화살표 키)을 누른다
- 잠시 기다린다 (기본 0.8초, 설정에서 바꿀 수 있음)

순환이 끊기고 새 글자가 시작됩니다.

## 낱말 입력 예

| 낱말 | 누르는 차례 |
|---|---|
| 안녕 | ㅇㅁ ㅣ · ㄴㄹ → ㄴㄹ · · ㅣ ㅇㅁ |
| 한글 | ㅅㅎ ㅅㅎ ㅣ · ㄴㄹ → ㅡ → ㄴㄹ ㄴㄹ |
| 좋아요 | ㅈㅊ ㅣ ㅡ ㅅㅎ ㅅㅎ ㅇㅁ ㅣ · ㅇㅁ · · ㅡ |
| 감사합니다 | ㄱㅋ ㅣ · ㅇㅁ ㅇㅁ ㅅㅎ ㅣ · ㅅㅎ ㅅㅎ ㅣ · ㅂㅍ ㄴㄹ ㅣ ㄷㅌ ㅣ · |

## 영문 · 숫자 · 기호

`모드` 버튼(또는 F2)으로 다섯 모드를 돕니다.

```
한글  →  영문 abc  →  영문 ABC  →  숫자 123  →  기호 !@#  →  한글 …
```

영문 · 숫자 · 기호 모드에서는 **물리 키보드로 그냥 타이핑해도 됩니다.**

### 영문

```
  abc   def   ghi
  jkl   mno   pqr
  stu   vwx   yz
  .,?   !'"   -:@
```

알파벳 26자가 위 3×3 아홉 키에 들어갑니다.
같은 키를 연달아 누르면 그 키의 글자를 돕니다(`a` → `b` → `c` → `a` …).
마지막 줄 세 키는 자주 쓰는 기호입니다.

### 숫자

키마다 숫자 하나씩입니다. 순환하지 않습니다.

```
  1  2  3
  4  5  6
  7  8  9
  *  0  #
```

### 기호

한 키에 세 개씩, 12키로 36개를 덮습니다.

```
  .,:   ?!;   '"`
  -_~   +=*   /\|
  ()&   []^   {}%
  <>#   @$₩   ※…・
```

## 물리 키보드

### 한글 모드

숫자열이 키패드에 대응합니다.

```
  1 2 3  =  ㅣ · ㅡ            7 8 9  =  ㅂㅍ ㅅㅎ ㅈㅊ
  4 5 6  =  ㄱㅋ ㄴㄹ ㄷㅌ      - 0 =  =  . ,  ㅇㅁ  ? !
```

### 어느 모드에서나

| 키 | 하는 일 |
|---|---|
| `Space` | 띄어쓰기 |
| `Backspace` | 한 단계 지우기 (조합 중이면 낱자 단위로 되돌림) |
| `Delete` | 커서 뒤 한 글자 지우기 |
| `Enter` | 줄바꿈 |
| `Esc` | 조합 확정 |
| `←` `→` | 커서 이동 (`→` 는 연타 순환도 끊는다) |
| `Home` `End` | 줄 처음 · 끝 |
| `F1` | 사용법 |
| `F2` | 입력 모드 전환 |
| `F3` | 테마 전환 |
| `F4` | 설정 |
| `Ctrl+N` | 새로 만들기 |
| `Ctrl+O` | 열기 |
| `Ctrl+S` | 저장 |
| `Ctrl+C` | 복사 |
| `Ctrl+V` | 붙여넣기 |

> macOS 에서는 `Ctrl` 대신 `Cmd` 를 씁니다.

## 파일

**열기**와 **저장**은 UTF-8 텍스트 파일을 씁니다.
저장할 때 바이트 순서 표시(BOM)를 붙이므로 Windows 메모장에서도
한글이 깨지지 않습니다.

웹 판에서는 `열기` 가 파일 고르기 창을, `저장` 이 내려받기를 띄웁니다.

## 설정

`설정 > 설정...`(F4) 에서 바꿀 수 있습니다.
고르는 즉시 화면에 적용되고, `취소` 하면 열기 전으로 되돌아갑니다.

| 항목 | 고를 수 있는 것 | 기본값 |
|---|---|---|
| 테마 | 라이트 · 다크 · 세피아 · 고대비 | 라이트 |
| 언어 | 한국어 · English | 시스템 설정을 따름 |
| 글꼴 크기 | 16 · 18 · 21 · 24 · 28 · 32 px | 21 px |
| 연타 유지 시간 | 0.4 · 0.6 · 0.8 · 1.0 · 1.5 · 2.0 초 | 0.8 초 |
| 시작 입력 모드 | 다섯 모드 | 한글 |
| 툴바 보이기 | 켬 · 끔 | 켬 |
| 상태줄 보이기 | 켬 · 끔 | 켬 |
| 컴팩트 모드 | 켬 · 끔 | 끔 |

컴팩트 모드는 설정 창과 메뉴 `설정 > 컴팩트 모드` 에서 같게 바꿉니다.
켜면 툴바에서 정보 단추가 빠집니다. 정보는 편집 영역 오른쪽 단추 메뉴와
`도움말 > 정보` 에 있습니다.

`기본값` 단추는 언어를 빼고 모두 처음 값으로 되돌립니다.

설정이 저장되는 자리는 `도움말 > 정보` 에 나옵니다.

```
Windows  %AppData%\Chunjiin\settings.json
macOS    ~/Library/Application Support/Chunjiin/settings.json
Linux    ~/.config/Chunjiin/settings.json
웹       브라우저 localStorage
```

## 설치 프로그램

`chunjiin-setup` 을 실행하면 관리자 권한 없이 사용자 영역에 설치됩니다.
아래쪽에 **설치 · 제거 · 닫기** 가 보입니다.
시작 메뉴와 바탕화면 바로 가기는 설치 전에 고를 수 있습니다. 기본은 둘 다 켭니다.
설치·제거 동안 창이 멈추지 않고, 아래에 진행 글이 나옵니다.

이미 설치되어 있으면 덮어쓰지 않고, `설치` 또는 `제거` 를 눌렀을 때 묻습니다.

| 언제 | 단추 |
|---|---|
| 설치 프로그램을 켰을 때 이미 있음 | 지우기 · 그만두기 |
| 설치를 눌렀는데 그 자리에 이미 있음 | 지우기 후 설치 · 그만두기 |
| 제거 | 지우기 · 그만두기 |

같은 프로그램의 `제거` 단추로 되돌릴 수 있습니다.

## 자주 겪는 일

**같은 자음이 두 번 필요한데 순환해 버려요**
→ 사이에 `→` 를 누르거나 잠시 기다리세요.
   기다리는 시간은 설정에서 늘릴 수 있습니다.

**받침을 넣으려는데 다음 글자로 넘어가요**
→ `ㄸ ㅃ ㅉ` 은 받침이 될 수 없습니다. 순환에서 건너뜁니다.

**아래아를 눌렀는데 글자가 안 만들어져요**
→ `·` 나 `‥` 는 아직 모음이 아닙니다. 이어서 `ㅣ` 나 `ㅡ` 를 누르세요.
   그대로 두고 확정하면 `·` 가 글자로 남습니다. 지우려면 `Backspace` 를
   누르세요.

**웹 판에서 붙여넣기가 안 돼요**
→ 브라우저가 클립보드 읽기 권한을 물어봅니다. 허용하거나,
   `Ctrl+V` 를 편집 영역 안에서 누르세요.
