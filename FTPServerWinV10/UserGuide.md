## 1. 설치

### MSI로 설치 (권장)

1. `FTPServerWinV10_Setup.msi`를 실행합니다.
2. 설치 경로를 선택하고 마법사를 완료합니다.
3. 필요 시 **바탕화면**·**시작 메뉴** 바로가기를 선택합니다.

### 개발 빌드로 실행

1. [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)이 설치되어 있어야 합니다.
2. `FTPServerWinV10.exe`를 실행합니다.

## 2. 화면 구성

| 영역 | 설명 |
|------|------|
| **헤더** | 제목, **▶ 시작** / **■ 중지** 버튼 |
| **프로파일** | 저장된 설정 목록, 저장·삭제 |
| **프로토콜** | FTP / FTPS / SFTP 체크 및 포트 |
| **서버** | 공유 폴더 목록, FTPS 인증서 경로·비밀번호 |
| **인증** | 익명 접속, 사용자 목록, 버퍼·스레드 |
| **상태** | 접속 클라이언트 수, 업/다운로드 통계 |
| **로그** | 실시간 이벤트 (`ftpserver.log`에도 기록) |

서버가 **실행 중**일 때는 프로토콜·폴더·인증 설정을 변경할 수 없습니다. 변경하려면 먼저 **중지**하세요.

## 3. 처음 사용하기

다음 순서로 진행하면 됩니다.

1. **공유 폴더 추가** — 가상 이름(예: `data`)과 Windows 실제 폴더 경로 지정
2. **프로토콜 선택** — FTP, FTPS, SFTP 중 사용할 항목 체크 (포트는 체크 시 기본값으로 자동 설정)
3. FTPS 사용 시 **PFX 인증서** 지정 또는 **인증서 생성**
4. 익명 접속을 끄는 경우 **사용자 추가**
5. **▶ 시작** 클릭

시작 전 검증에 실패하면 **설정 오류** 팝업이 표시됩니다. 내용을 확인한 뒤 수정하세요.

## 4. 공유 폴더

여러 물리 폴더를 FTP/SFTP 경로로 노출합니다.

| 항목 | 설명 |
|------|------|
| **가상 이름** | 클라이언트에서 보이는 경로 이름. 예: `data` → `/data/` |
| **실제 경로** | Windows 디렉터리 전체 경로 (존재하는 폴더만 등록 가능) |

- **추가**: 목록 아래 추가 버튼 → 대화상자에서 입력
- **삭제**: 항목 선택 후 삭제 버튼

클라이언트 예: 가상 이름 `pub`, 실제 `D:\Share\public` → `ftp://서버/pub/` 또는 SFTP `/pub/`

## 5. 프로토콜 (FTP / FTPS / SFTP)

**프로토콜** 그룹에서 각 프로토콜을 독립적으로 켜고 포트를 지정할 수 있습니다. **여러 프로토콜을 동시에** 실행할 수 있습니다.

| 프로토콜 | 기본 포트 | 설명 |
|----------|-----------|------|
| FTP | 21 | 평문 FTP |
| FTPS | 990 | Implicit SSL/TLS (연결 시부터 SSL). **PFX 인증서 필수** |
| SFTP | 22 | SSH 위 SFTP. 호스트 키는 사용자 프로필에 자동 생성 |

프로토콜 체크박스를 켜면 해당 **표준 포트**가 자동으로 입력됩니다. 필요하면 포트를 변경할 수 있습니다.

### 방화벽

Windows 방화벽에서 사용하는 포트(TCP)를 허용해야 외부에서 접속할 수 있습니다.

---

## 6. 인증 및 사용자

| 옵션 | 동작 |
|------|------|
| **익명 접속 허용** (체크) | 사용자 목록 없이도 접속 가능 |
| **익명 접속 거부** | **사용자** 목록에 등록된 ID/비밀번호만 허용 |

- **사용자 추가**: 아이디·암호 입력
- 목록의 암호는 `*`로만 표시됩니다

### 버퍼·스레드 (FTP/FTPS)

- **버퍼 크기 (KB)**: 전송 버퍼
- **최대 스레드**: 동시 처리 스레드 수 상한

---

## 7. SSL 인증서 (FTPS)

FTPS를 사용하려면 **PFX** 파일이 필요합니다.

### 기존 인증서 사용

1. FTPS 체크
2. **찾기**로 `.pfx` 파일 선택
3. PFX 비밀번호 입력

### 자체 서명 인증서 생성

1. **인증서 생성** 클릭
2. **CN**(서버 이름): 호스트명 또는 IP (예: `myserver.local`)
3. 유효 기간·저장 경로·PFX 비밀번호 지정
4. 생성 후 경로가 자동으로 채워집니다

> 테스트·내부망용으로 적합합니다. 공인 서비스에는 공인 CA 인증서를 사용하세요.

---

## 8. 서버 시작·중지

1. **▶ 시작** — 선택한 프로토콜이 순서대로 기동됩니다.
2. 로그에 `FTP 서버 시작`, `FTPS 서버 시작`, `SFTP 서버 시작` 등이 표시됩니다.
3. **■ 중지** — 모든 프로토콜을 중지합니다.

시작 실패 시 **서버 시작 오류** 팝업에 프로토콜·포트·공유 폴더·예외 정보가 표시됩니다.

### 상태 표시

- **● 클라이언트**: 현재 접속 수 (FTP+FTPS+SFTP 합계)
- **↑ 업로드 / ↓ 다운로드**: 파일 수·누적 용량 (FTP/FTPS 기준)

## 9. 프로파일

여러 환경(예: `개발`, `테스트`) 설정을 이름으로 보관합니다.

| 동작 | 방법 |
|------|------|
| 저장 | 프로파일 이름 선택 또는 입력 후 **저장** |
| 불러오기 | 콤보에서 이름 선택 |
| 삭제 | 이름 선택 후 **삭제** (확인 대화상자) |

프로파일 파일: 실행 폴더의 `profiles\이름.json`

---

## 10. 설정 저장·단축키

| 키 | 동작 |
|----|------|
| **F5** | 현재 UI 설정을 `server_settings.json`에 저장 |
| **F6** | `server_settings.json`에서 불러오기 |

앱을 **종료**할 때도 현재 설정이 `server_settings.json`에 자동 저장됩니다.

## 11. 오류 메시지

설정 오류, 파일 읽기/쓰기 실패, 서버 시작 실패 등은 **상세 오류 창**으로 표시됩니다.

| 기능 | 설명 |
|------|------|
| 요약 | 창 상단에 짧은 설명 |
| 상세 영역 | 경로, 프로토콜, 예외 타입·메시지·스택 트레이스 |
| **전체 복사** | 클립보드에 전체 텍스트 복사 (지원·보고 시 유용) |
| **확인** | 창 닫기 |

텍스트는 마우스로 드래그해 선택하거나 **Ctrl+A**로 전체 선택할 수 있습니다.

동시에 **로그** 목록에도 같은 내용이 요약되어 기록됩니다.

## 12. 클라이언트 연결 예시

서버 PC IP를 `192.168.1.10`, 가상 폴더 `data`라고 가정합니다.

### FTP (FileZilla 등)

- 호스트: `192.168.1.10`
- 포트: `21`
- 프로토콜: FTP (암호화 없음)
- 로그온: 익명 또는 등록 사용자

### FTPS (Implicit)

- 호스트: `192.168.1.10`
- 포트: `990`
- 암호화: **FTP over TLS (Implicit)** / Explicit 아님
- 인증서 경고: 자체 서명인 경우 클라이언트에서 신뢰 필요

### SFTP

- 호스트: `192.168.1.10`
- 포트: `22`
- 프로토콜: SFTP (SSH 파일 전송, FTP 아님)
- 첫 접속 시 호스트 키 확인 메시지 표시 (정상)

Windows 탐색기: `ftp://192.168.1.10/` (FTP만, FTPS/SFTP는 전용 클라이언트 권장)

## 13. 문제 해결

| 증상 | 확인 사항 |
|------|-----------|
| 서버가 시작되지 않음 | 공유 폴더 1개 이상, 프로토콜 1개 이상, FTPS 시 PFX 경로·비밀번호 |
| 포트 사용 중 오류 | 다른 FTP/SSH 서비스(IIS FTP 등) 중지 또는 포트 변경 |
| FTPS 연결 실패 | 포트 **990**, Implicit SSL 설정, 방화벽 |
| SFTP만 실패 | 방화벽 TCP 22, 공유 폴더 여러 개 시 **관리자 권한**으로 앱 실행 |
| 실제 경로 오류 | 폴더 존재·드라이브 연결·경로 오타 |
| 설정이 안 불러와짐 | `server_settings.json` 손상 시 백업 후 삭제, F6 재시도 |
| 프로파일 읽기 실패 | `profiles\*.json` 형식 확인, 오류 팝업의 파일 경로 참고 |

오류 팝업의 **전체 복사** 내용을 보관하면 원인 분석에 도움이 됩니다.

### 로그 파일

실행 파일과 같은 폴더의 `ftpserver.log` — 시간순 이벤트 기록

### SFTP 호스트 키

`%LocalAppData%\FTPServerWinV10\ssh_host_rsa.pem`  
키를 바꾸려면 앱 종료 후 해당 파일을 삭제하고 다시 시작하면 새 키가 생성됩니다.

## 14. 제한 사항

| 항목 | 내용 |
|------|------|
| FTPS 모드 | **Implicit SSL (990)** 만 지원. 포트 21 + Explicit (`AUTH TLS`) 미지원 |
| FTPS 데이터 채널 | 제어 채널만 SSL일 수 있음. 전 구간 암호화(`PROT P`) 미구현 |
| SFTP | SSH 셸·포트 포워딩 없음. SFTP 파일 전송만 |
| SFTP 다중 폴더 | 임시 junction 루트 사용 — Windows에서 `mklink /J` 권한 필요할 수 있음 |
| 동시 편집 | 파일 잠금·버전 관리 없음 — 일반 파일 서버 수준 |
