## 1. 설치

### MSI로 설치 (권장)

1. `FTPServerWinV10_Setup.msi`를 실행합니다.
2. 설치 경로를 선택하고 마법사를 완료합니다.
3. 필요 시 **바탕화면**·**시작 메뉴** 바로가기를 선택합니다.

### 개발 빌드로 실행

1. [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)이 설치되어 있어야 합니다.
2. `FTPServerWinV10.exe`를 실행합니다.

## 2. 화면 구성

| 영역 | 설명 |
|------|------|
| **헤더** | 제목, **▶ 시작** / **■ 중지** 버튼 |
| **프로파일** | 저장된 설정 목록, 저장·삭제 |
| **프로토콜** | FTP / FTPS / SFTP 체크 및 포트 (각각 독립) |
| **서버 설정** | 공유 폴더, **FTPS SSL 인증서**, **SFTP 호스트 키** |
| **인증 및 성능** | 익명 접속, 사용자·권한, 버퍼·스레드 |
| **상태** | 현재/총 접속 수, 업·다운로드 통계 |
| **로그** | 실시간 이벤트, **전체 복사**, **로그 저장** |

### 서버 설정 — 보안 항목 구분

서버 설정 하단에는 프로토콜별로 **두 종류의 보안 설정**이 나뉘어 있습니다.

| 구분 | 제목 (화면) | 용도 |
|------|-------------|------|
| **FTPS** | `FTPS (990) — SSL/TLS 인증서` | FTPS 전용. `.pfx` 형식 파일 |
| **SFTP** | `SFTP (22) — SSH 호스트 키 · PEM` | SFTP 전용. `.pem` 파일 (인증서 아님) |

- **FTPS**를 체크했을 때만 SSL 인증서 관련 항목이 활성화됩니다.
- **SFTP**를 체크했을 때만 호스트 키 관련 항목이 활성화됩니다.

각 항목에 마우스를 올리면 **툴팁**으로 자세한 설명이 표시됩니다.

> 서버가 **실행 중**일 때는 프로토콜·폴더·인증·보안 설정을 변경할 수 없습니다. 변경하려면 먼저 **■ 중지**하세요.

## 3. 처음 사용하기

권장 순서는 다음과 같습니다.

1. **공유 폴더 추가** — 가상 이름(예: `data`)과 Windows 실제 폴더 경로
2. **프로토콜 선택** — FTP / FTPS / SFTP 중 사용할 항목 체크 (체크 시 기본 포트 자동 입력)
3. **FTPS** 사용 시 → **인증서 파일** 지정 또는 **인증서 생성**
4. **SFTP** 사용 시 → **키 생성** 또는 기존 PEM 확인 (없으면 시작 시 자동 생성)
5. **익명 접속** 여부 결정, 필요 시 **사용자 추가** (읽기·쓰기 권한)
6. **▶ 시작**

시작 전 검증에 실패하면 **설정 오류** 팝업이 표시됩니다. 내용을 확인한 뒤 수정하세요.

## 4. 공유 폴더

여러 물리 폴더를 FTP·SFTP에서 **같은 가상 경로 규칙**으로 노출합니다.

| 항목 | 설명 |
|------|------|
| **가상 이름** | 클라이언트 경로 이름. 예: `data` → `/data/` |
| **실제 경로** | Windows 폴더 전체 경로 (존재하는 폴더만 등록) |

- **추가** / **제거**: 목록 위 버튼

### 폴더가 하나일 때와 여러 개일 때

| 공유 폴더 수 | FTP/SFTP 루트(`/`)에서 보이는 내용 |
|--------------|-----------------------------------|
| **1개** | 해당 물리 폴더의 파일·하위 폴더가 바로 표시 |
| **2개 이상** | 루트에 **가상 이름** 폴더 목록 → 각 이름 아래에 실제 파일 |

예: 가상 `pub` → `D:\Share\public` 이면 SFTP `/pub/`, FTP `/pub/` 로 접근합니다.

## 5. 프로토콜 (FTP / FTPS / SFTP)

**프로토콜** 그룹에서 각 항목을 독립적으로 켜고 포트를 지정할 수 있습니다. **여러 프로토콜을 동시에** 실행할 수 있습니다.

| 프로토콜 | 기본 포트 | 설명 |
|----------|-----------|------|
| **FTP** | 21 | 평문 FTP |
| **FTPS** | 990 | Implicit SSL/TLS (연결 직후 SSL). **SSL 인증서 필수** |
| **SFTP** | 22 | SSH 위 SFTP. **호스트 키** 사용 (SSL 인증서 아님) |

체크박스를 켜면 표준 포트가 자동 입력됩니다. 필요 시 포트를 변경할 수 있습니다.

### 방화벽

사용하는 **TCP 포트**(21, 990, 22 등)를 Windows 방화벽에서 허용해야 외부 접속이 가능합니다.

FTP **수동(PASV) 모드**를 쓰는 경우, 데이터 연결용 추가 포트 범위가 필요할 수 있습니다(고급 FTP 클라이언트·방화벽 설정 참고).

## 6. 인증 및 사용자

| 옵션 | 동작 |
|------|------|
| **익명 접속 허용** (체크) | 사용자 목록 없이 `anonymous` 로 접속 가능 (**읽기만**) |
| **익명 접속 거부** | 등록된 사용자만 접속 |

### 사용자 목록

- **추가**: 아이디·비밀번호·**읽기**·**쓰기** 체크
- 목록에 **권한** 열로 표시 (읽기 / 쓰기 / 읽기+쓰기)
- 암호는 `*`로만 표시

| 권한 | FTP/FTPS/SFTP |
|------|----------------|
| 읽기 | 목록 조회, 다운로드 |
| 쓰기 | 업로드, 삭제, 이름 변경, 폴더 생성 등 |
| 둘 다 해제 | 해당 사용자로 로그인 불가 |

### 버퍼·스레드 (FTP/FTPS)

- **버퍼 크기 (KB)**: 전송 버퍼
- **최대 스레드**: 동시 처리 스레드 상한

## 7. FTPS SSL 인증서

FTPS는 **SSL/TLS 인증서**가 필요합니다. Windows에서는 보통 **`.pfx` 확장자** 파일로 저장·불러옵니다. (PFX는 그 파일 형식의 기술 이름이며, 화면에서는 **인증서**로 표시합니다.)

SFTP **호스트 키**와는 **완전히 별개**입니다.

### 기존 인증서 사용

1. **FTPS** 체크
2. **찾기**로 `.pfx` 인증서 파일 선택
3. **인증서 암호** 입력

### 자체 서명 인증서 생성

1. **인증서 생성** 클릭
2. **CN**(서버 이름): 호스트명 또는 IP (예: `192.168.1.10`)
3. 유효 기간·저장 경로·암호 지정
4. 생성 후 경로가 자동으로 채워집니다

> 내부망·테스트용에 적합합니다. 공인 서비스에는 공인 CA 발급 인증서를 사용하세요.

## 8. SFTP SSH 호스트 키 (PEM)

SFTP는 FTPS용 **SSL 인증서가 아니라** SSH **호스트 키**로 서버를 식별합니다.

| 항목 | 설명 |
|------|------|
| **키(.pem)** | RSA 개인키 파일 경로 (읽기 전용 표시) |
| **키 생성** | 새 RSA 호스트 키 생성 (기존 파일 덮어쓰기 전 확인) |
| **키 폴더** | 키가 저장된 폴더를 탐색기로 열기 |
| **SHA256 지문** | 클라이언트에 표시되는 지문과 비교 |

### 기본 저장 위치

```
%LocalAppData%\FTPServerWinV10\ssh_host_rsa.pem
```

서버 **첫 시작** 시 파일이 없으면 **자동 생성**됩니다.

### 첫 접속 시 클라이언트

FileZilla, WinSCP 등은 처음 접속할 때 **새 호스트 키 신뢰** 대화상자를 표시합니다. 앱에 표시된 **SHA256 지문**과 클라이언트 지문이 같으면 **신뢰**해도 됩니다.

### 키를 바꾼 경우

**키 생성**으로 키를 다시 만들면, 이미 접속했던 클라이언트는 **호스트 키 변경** 경고를 표시합니다. 의도한 변경이면 새 지문을 신뢰하세요.

## 9. 서버 시작·중지

1. **▶ 시작** — 선택한 프로토콜이 기동됩니다.
2. 로그 예: `FTP 서버 시작`, `FTPS 서버 시작`, `SFTP 서버 시작`, `SFTP: FXP_INIT -> FXP_VERSION 3`
3. **■ 중지** — 모든 프로토콜 중지

시작 실패 시 **서버 시작 오류** 팝업에 프로토콜·포트·공유 폴더·예외 정보가 표시됩니다.

### 상태 표시

| 표시 | 의미 |
|------|------|
| **현재 접속** | 지금 연결된 클라이언트 수 (FTP+FTPS+SFTP 합계) |
| **총 접속** | 이번 실행 동안 누적 접속 횟수 |
| **↑ 업로드 / ↓ 다운로드** | 파일 수·용량 (FTP/FTPS 전송 기준) |

## 10. 프로파일

여러 환경(예: `개발`, `테스트`) 설정을 이름으로 보관합니다.

| 동작 | 방법 |
|------|------|
| 저장 | 프로파일 이름 선택 또는 입력 후 **저장** |
| 불러오기 | 콤보에서 이름 선택 |
| 삭제 | 이름 선택 후 **삭제** |

파일 위치: 실행 폴더의 `profiles\이름.json`

### 프로파일에 저장되는 항목

프로파일 **저장** 시 화면의 **모든 설정**이 JSON으로 기록됩니다.

| 항목 | 내용 |
|------|------|
| 공유 폴더 | 가상 이름·실제 경로 목록 전체 |
| 프로토콜 | FTP/FTPS/SFTP 사용 여부 및 포트 |
| FTPS | SSL 인증서 경로·암호 |
| SFTP | 호스트 키 파일 경로 |
| 인증 | 익명 허용 여부 |
| **사용자** | 아이디·암호·**읽기/쓰기 권한** 목록 전체 |
| 성능 | 버퍼 크기(KB), 최대 스레드 |

저장 시 `server_settings.json`에도 동일 내용이 반영되어, F5·종료 시 설정과 맞춰집니다.

로그에 `공유 N개, 사용자 M명` 요약이 표시되므로 저장 결과를 확인할 수 있습니다.

### 사용자 목록

- **더블 클릭**: 선택한 사용자 **편집** (아이디·암호·권한)
- 프로파일 저장 전에 목록에 사용자가 보이는지 확인하세요.

## 14. 클라이언트 연결 예시

서버 IP `192.168.1.10`, 가상 폴더 `data` 가정.

### FTP (FileZilla 등)

| 항목 | 값 |
|------|-----|
| 호스트 | `192.168.1.10` |
| 포트 | `21` |
| 암호화 | 없음 (평문 FTP) |
| 로그온 | 익명 또는 등록 사용자 |

### FTPS (Implicit)

| 항목 | 값 |
|------|-----|
| 호스트 | `192.168.1.10` |
| 포트 | `990` |
| 암호화 | **FTP over TLS (Implicit)** — Explicit(21+AUTH) 아님 |
| 인증서 | 자체 서명 인증서면 클라이언트에서 신뢰 필요 |

### SFTP

| 항목 | 값 |
|------|-----|
| 호스트 | `192.168.1.10` |
| 포트 | `22` |
| 프로토콜 | **SFTP** (SSH 파일 전송). 일반 FTP 아님 |
| 로그온 | `anonymous` + 임의 비밀번호(익명 허용 시) 또는 등록 사용자 |
| 호스트 키 | 첫 접속 시 신뢰 확인 — 정상 |

**Windows 탐색기** `ftp://...` 는 **FTP(평문)** 용입니다. FTPS·SFTP는 FileZilla, WinSCP 등 전용 클라이언트를 사용하세요.

## 15. 문제 해결

| 증상 | 확인 사항 |
|------|-----------|
| 서버가 시작되지 않음 | 공유 폴더 1개 이상, 프로토콜 1개 이상, FTPS 시 인증서·암호 |
| 포트 사용 중 | IIS FTP, OpenSSH 등 다른 서비스 중지 또는 포트 변경 |
| FTPS 연결 실패 | 포트 **990**, **Implicit** SSL, 방화벽, 인증서·암호 |
| SFTP `did not receive FXP_VERSION` | 서버 최신 빌드·재시작, 로그에 `FXP_INIT -> FXP_VERSION` 있는지 확인 |
| SFTP 목록·다운로드 실패 | 읽기 권한, 공유 폴더 경로, 로그 `SFTP: OPENDIR` / 오류 메시지 |
| SFTP 호스트 키 경고 | 의도한 키 변경인지 확인, 지문 일치 후 신뢰 |
| 550 / 파일 없음 | 가상 경로·파일명(목록에 보이는 이름과 동일한지) |
| 익명으로 쓰기 안 됨 | 익명은 **읽기 전용** — 사용자 계정에 쓰기 권한 부여 |
| 설정 불러오기 실패 | `server_settings.json` 손상 시 백업 후 삭제, F6 재시도 |

오류 팝업 **전체 복사** 또는 `ftpserver.log`를 보관하면 원인 분석에 도움이 됩니다.

### 자주 묻는 구분

| 질문 | 답 |
|------|-----|
| SFTP에도 SSL 인증서가 필요한가? | **아니요.** SFTP는 **호스트 키(.pem)** 만 사용합니다. |
| FTPS에 호스트 키가 필요한가? | **아니요.** FTPS는 **SSL 인증서(.pfx)** 만 사용합니다. |
| 익명으로 업로드가 안 됨 | 정상 동작입니다. 쓰기가 필요하면 사용자를 추가하세요. |

## 16. 제한 사항

| 항목 | 내용 |
|------|------|
| FTPS | **Implicit SSL (990)** 만 지원. Explicit (`AUTH TLS` on 21) 미지원 |
| FTPS 데이터 | 제어 채널 SSL 위주. `PROT P`(데이터 채널 암호화) 미구현 |
| SFTP | **비밀번호·익명** 인증. 공개키 인증 미지원 |
| SFTP | SSH **셸·exec** 미지원 — 파일 전송(SFTP subsystem)만 |
| SFTP 키 | 자체 RSA PEM. 공인 CA SSH 인증서 체계 아님 |
| 일반 | 파일 잠금·버전 관리 없음 — 일반 파일 서버 수준 |
