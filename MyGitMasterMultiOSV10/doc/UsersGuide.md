# My Git Master V1.0.0 — 사용자 가이드

My Git Master는 커밋 그래프, 변경 파일, diff, 브랜치, 태그, GitHub Release를 한 화면에서 보는 Git 클라이언트입니다. 로컬 저장소에서는 Git Add, Reset, Discard, Commit, Fetch, Pull, Push, Stash도 할 수 있습니다.

데스크톱 앱(Windows, macOS, Linux)과 웹 브라우저에서 같은 화면을 씁니다. 데스크톱 앱은 Tauri로 만들었고, 설치본에 실행에 필요한 모든 것이 들어 있습니다.

기본 언어는 한국어입니다. Git 명령 이름(Git Add, Git Commit, Git Fetch 등)은 한국어와 English 모두에서 영어로 표시됩니다.

<a id="getting-started"></a>
## 시작하기

<a id="install"></a>
### 설치본

프로젝트 루트의 `My Git Master_1.0.0_x64-setup.exe`(Windows)를 실행합니다. 설치 마법사의 첫 화면에서 한국어 또는 English를 고릅니다. 현재 사용자용으로 설치되므로 관리자 권한이 필요 없습니다. 이 컴퓨터에 Git이 설치되어 있어야 합니다. Node.js는 필요 없습니다.

제거할 때 사용자 데이터(설정, 로그인 정보, 원격 저장소 캐시)가 있으면 함께 지울지 묻습니다. **아니요**를 고르면 다음 설치 때 그대로 이어서 씁니다.

<a id="dev-run"></a>
### 개발 실행

프로젝트 루트에서 실행합니다.

```powershell
npm install
npm start
```

데스크톱 창이 열리고, 운영체제의 폴더 선택 대화상자를 사용할 수 있습니다. 화면 코드를 고치면 창에 바로 반영됩니다.

<a id="web"></a>
### 웹

```powershell
npm run dev:web
```

터미널에 표시되는 주소(기본 http://127.0.0.1:5173)를 브라우저에서 엽니다. 웹에서는 폴더 대화상자 대신 경로를 입력합니다. 포트가 사용 중이면 다음 빈 포트를 고릅니다.

설치 파일 만들기와 다른 명령은 [README.md](../README.md)를 참고하세요.

<a id="last-session"></a>
### 마지막 세션

마지막으로 연 저장소가 다음 실행 때 다시 열립니다. Open, Clone, Browse Remote 중 마지막에 성공한 것이 복원됩니다. **시작할 때 시작 화면 보기**가 켜져 있으면 저장소는 뒤에서 열리고 시작 화면이 먼저 보입니다.

<a id="program-icon"></a>
### 프로그램 아이콘

주황에서 보라로 이어지는 둥근 사각형 위에 흰색 Git 브랜치가 그려진 아이콘입니다. 설치 파일, 작업 표시줄, 창 제목, 정보 창에 같은 아이콘이 쓰입니다.

<a id="start-screen"></a>
## 시작 화면

저장소가 열려 있지 않을 때, 그리고 **시작할 때 시작 화면 보기**가 켜져 있으면 프로그램을 시작할 때 시작 화면이 나타납니다. 시작 화면에서도 위쪽의 메뉴 막대와 도구 모음은 그대로 쓸 수 있습니다.

<a id="start-toggle"></a>
### 시작 버튼

메뉴 막대의 프로그램 이름과 버전 바로 오른쪽에 **시작** 버튼이 있습니다. 누를 때마다 시작 화면과 작업 화면이 번갈아 보입니다. 시작 화면이 보이는 동안 버튼은 강조 색으로 눌린 상태가 됩니다. 다른 저장소를 열면 작업 화면으로 돌아갑니다.

<a id="start-cards"></a>
### 카드

시작 화면은 여러 카드로 되어 있습니다.

| 카드 | 내용 |
|------|------|
| **시작** | 사용자 설명서, 튜토리얼, 열기, 복제, 원격 탐색 |
| **메뉴** | 저장소 열기, 폴더 열기, 복제, 원격 탐색, 터미널, 테마 설정, 언어, 환경설정, 시작 화면 설정, 사용자 설명서, 튜토리얼, 정보, 종료. 모두 컬러 아이콘과 이름이 함께 있습니다. |
| **최근 저장소** | 누르면 다시 엽니다. 하나씩 지우거나 모두 지울 수 있습니다. |
| **최근 URL** | 복제하거나 원격 탐색합니다. 목록에서 지울 수 있습니다. |
| **테마** | 내 테마와 설정 버튼, 그 아래 Dark, Light 테마 |
| **배경** | 움직이는 3D 배경 20가지와 속도·투명도 |

카드는 제목 부분을 끌어 옮기고, 모서리를 끌어 크기를 바꿉니다. 배치는 저장되며, **환경설정 → 시작 화면 → 카드 배치 초기화**로 처음 배치로 돌아갑니다.

<a id="start-background"></a>
### 배경

배경 카드나 **환경설정 → 시작 화면**에서 배경 20가지 중 하나를 고릅니다. 각 배경은 컬러 아이콘으로 표시되고, 고른 배경은 강조 색 테두리로 보입니다. **섞기**를 켜면 정해진 시간마다 배경이 바뀝니다.

속도와 투명도는 한 줄에 놓인 작은 **−** / **+** 단추로 조절합니다. 속도는 배경이 움직이는 빠르기, 투명도는 배경 위 카드의 불투명한 정도입니다. 운영체제에서 동작 줄이기를 켜 두면 기본 속도가 느려집니다.

<a id="tutorial"></a>
## 튜토리얼

처음 실행하면 시작 화면에 튜토리얼 안내 카드가 나타납니다. **시작**을 누르면 화면의 각 부분을 차례로 짚어 주는 안내가 시작되고, 단계에 따라 시작 화면과 작업 화면이 알아서 바뀝니다.

- 안내 카드는 시작 화면에서만 보입니다. 작업 화면으로 바꾸면 사라졌다가 시작 화면으로 돌아오면 다시 보입니다.
- 카드를 닫거나 **나중에**를 누르면 다음 실행 때까지 나타나지 않습니다.
- 카드의 **시작할 때 보기**를 끄면 더 이상 자동으로 나타나지 않습니다. 같은 설정이 **환경설정 → 일반 → 시작할 때 튜토리얼 보기**에도 있습니다.
- 언제든 **도움말 → 튜토리얼**로 다시 볼 수 있습니다.

│ Files                      │ Commit History                              │

<a id="open-clone-browse"></a>
## 저장소 열기 · 복제 · 원격 탐색

<a id="open-local"></a>
### 로컬 저장소 열기

1. **파일 → 열기...** 또는 도구 모음 **열기**. 웹에서는 `Ctrl+O`도 같은 동작입니다.
2. 데스크톱은 폴더를 고릅니다. 웹은 경로를 입력합니다.
3. `.git`이 있는 폴더면 브랜치, 파일, 커밋 히스토리가 열립니다.

<a id="clone"></a>
### 복제

1. **파일 → 복제...** 또는 도구 모음 **복제**
2. 저장소 URL과 대상 폴더를 입력합니다.
3. 비공개 HTTPS 저장소는 사용자 이름과 Personal Access Token을 입력합니다.
4. 복제가 끝나면 그 폴더가 열립니다. 원격 URL에는 토큰이 저장되지 않습니다.

진행 중에는 도구 모음 **중지**로 취소할 수 있습니다.

<a id="browse-remote"></a>
### 원격 탐색

로컬 작업 폴더를 만들지 않고 히스토리만 볼 때 사용합니다.

1. **파일 → 원격 탐색...**
2. URL을 입력하고 확인합니다.
3. bare 캐시에서 읽기 전용으로 열립니다.

이 모드에서는 Checkout, Git Add, Commit, Push가 동작하지 않습니다.

<a id="recent"></a>
### 최근 항목

- **파일** 메뉴 아래에 최근 저장소가 있습니다.
- Clone과 Browse Remote에 쓴 URL은 설정에 기억됩니다. 최대 10개입니다.

<a id="files-panel"></a>
## Files 패널

제목 옆에 이 컴퓨터의 드라이브와 **폴더 열기**가 있습니다.

| 동작 | 결과 |
|------|------|
| 드라이브 클릭 | 그 드라이브의 폴더를 나열합니다. 드라이브 루트를 Git 저장소로 열지는 않습니다. |
| **폴더 열기** | Git 저장소면 저장소를 엽니다. 아니면 그 폴더를 탐색합니다. |
| Files 제목 클릭 | 폴더를 탐색 중이고 저장소가 열려 있으면 저장소 파일로 돌아갑니다. |
| 폴더 클릭 | 하위 항목을 펼치거나 접습니다. |
| 파일 더블클릭 | 운영체제 기본 앱으로 엽니다. |

<a id="status-badges"></a>
### 상태 배지

| 배지 | 의미 |
|------|------|
| `U` | 추적되지 않은 파일 |
| `±` | 수정됨 |
| `D` | 삭제됨 |
| `R` | 이름 변경 |
| `T` | 종류 변경 |
| `!` | 충돌 |
| `X` | `.gitignore`로 무시됨 |
| `P` | 커밋됐지만 아직 push되지 않음 |

폴더 배지는 그 안의 변경을 모아서 보여 줍니다. 다른 프로그램에서 파일을 바꾸면 잠시 후 목록이 다시 읽힙니다.

<a id="files-context-menu"></a>
### 저장소 파일에서 우클릭

| 메뉴 | 동작 |
|------|------|
| **충돌 해결...** | 충돌한 파일에서만 보입니다. 기본 merge 도구로 엽니다. |
| **Show Log** | 그 경로의 커밋만 히스토리에 표시 |
| **Copy Path** | 저장소 기준 경로 복사 |
| **Show All Commits** | 경로 필터 해제 |
| **Git Add / Git Reset / Discard Changes** | 선택 항목에 대한 Git 작업 |
| **Git Commit / Git Fetch / Git Pull / Git Push / Git Stash / Git Stash Pop / Git Status** | 저장소 전체에 대한 Git 작업. **저장소** 메뉴와 같습니다. |
| **새 파일... / 새 폴더...** | 선택 위치 아래에 만들기 |
| **삭제** | 디스크에서 삭제 |
| **.gitignore에 추가 / 제거** | 무시 규칙 변경 |

파일과 폴더의 메뉴는 같습니다. Git Add, Git Reset, Discard Changes, Show Log는 고른 경로에만 적용되고, Commit과 Fetch / Pull / Push / Stash는 저장소 전체에 적용됩니다.

폴더 탐색 중일 때의 메뉴는 **폴더 열기**와 **경로 복사**입니다.

<a id="repository-panel"></a>
## Repository 패널

왼쪽 아래에 있습니다.

| 구역 | 내용 |
|------|------|
| **Local Branches** | 로컬 브랜치. 현재 브랜치가 표시됩니다. |
| **Remotes** | 원격 브랜치 |
| **Tags** | 태그 |
| **Releases** | `github.com/owner/repo` 형태의 원격이 있을 때 GitHub Release |

로컬 브랜치를 우클릭하면 **Checkout**, **이름 복사**, **요약 내보내기**가 있습니다. Checkout은 작업 폴더가 있는 저장소에서만 됩니다.

원격과 태그는 이름이나 SHA를 복사할 수 있습니다.

<a id="commit-history"></a>
## Commit History

각 레인은 브랜치와 머지 경로입니다. 행을 클릭하면 오른쪽 상세와 diff가 바뀝니다. 특정 파일의 로그만 볼 때는 그래프가 한 줄로 펴집니다.

우클릭:

| 메뉴 | 동작 |
|------|------|
| **SHA 복사** | 전체 해시 |
| **메시지 복사** | 커밋 메시지 |
| **커밋 스냅샷 내보내기** | 그 커밋의 파일을 폴더로 저장 |

**히스토리 → 모든 커밋 보기**는 경로 필터를 해제합니다.

<a id="commit-details"></a>
## Commit Details와 Diff

선택한 커밋의 작성자, 날짜, 메시지와 변경 파일 목록이 표시됩니다.

- 변경 파일을 클릭하면 diff가 열립니다.
- 더블클릭하거나 우클릭 **내장 Diff 도구**는 좌우 비교 창을 별도로 띄웁니다.
- 우클릭 **외부 Diff 도구**는 환경설정의 외부 diff 도구를 실행합니다. 도구가 없으면 오류 대화상자에 이유가 표시됩니다.
- Diff 우클릭에서 **복사**와 **줄 바꿈**을 사용할 수 있습니다. 줄 바꿈은 기본으로 켜져 있습니다.

<a id="git-actions"></a>
## Git 작업

작업 폴더가 있는 저장소에서만 됩니다. Browse Remote에서는 비활성화됩니다.

**저장소** 메뉴 또는 Files 우클릭에서 실행합니다.

| 메뉴 | 동작 |
|------|------|
| **Git Add** | 선택 경로를 stage. 먼저 들어갈 경로를 확인합니다. |
| **Git Reset (Unstage)** | stage 취소 |
| **Discard Changes** | 작업 트리 변경을 되돌림. 추적되지 않은 파일은 지워질 수 있습니다. |
| **Git Commit** | stage된 내용을 커밋 |
| **Git Fetch** | `origin`에서 가져오기 |
| **Git Pull** | fast-forward로 합치기 |
| **Git Push** | 업스트림이 없으면 `origin`의 현재 브랜치로 push |
| **Git Stash / Git Stash Pop** | 변경을 잠시 보관했다가 되돌리기 |
| **Git Status** | `git status` 내용 표시 |
| **충돌 해결...** | 충돌한 파일을 merge 도구로 엽니다. 선택한 파일이 충돌 상태가 아니면 첫 충돌 파일을 씁니다. |

<a id="conflicts"></a>
### 충돌 해결

Pull이나 Merge가 충돌로 멈추면 Files 패널의 그 파일에 충돌 배지가 붙습니다. **저장소 → 충돌 해결...**, 도구 모음 **충돌 해결**, 또는 그 파일 우클릭 **충돌 해결...**로 엽니다.

기본값은 **내장 Diff & Merge**이고 별도 창으로 열립니다.

- 충돌 덩어리마다 Base, Local, Remote 세 열이 나란히 보입니다.
- **Base / Local / Remote / 양쪽** 중 하나를 고르면 그 덩어리가 해결 처리됩니다.
- 위쪽에 해결한 개수 / 전체 개수가 표시되고, 전부 고른 다음에만 **저장**이 켜집니다.
- **저장**은 작업 트리 파일을 쓰고 `git add`까지 합니다. 그다음 커밋하면 됩니다.
- 충돌이 없는 파일을 이 창으로 열면 오류 대화상자가 열립니다.

환경설정에서 외부 merge 도구를 고르면 같은 메뉴가 그 도구를 실행합니다.

<a id="commit-message"></a>
### 커밋 메시지

```
[분류] 제목

본문 (선택)
```

분류 기본값은 기능추가, 기능변경, 기능삭제, 버그수정, 문서, 리팩토링, 성능개선, 테스트, 기타입니다. **관리...**에서 목록을 고치면 설정에 저장됩니다.

커밋하려면 `user.name`과 `user.email`이 그 저장소 또는 전역 Git 설정에 있어야 합니다.

```powershell
git config user.name "Your Name"
git config user.email "you@example.com"
```

<a id="https-credentials"></a>
### HTTPS 자격 증명

Fetch, Pull, Push에서 인증이 필요하면 사용자 이름과 토큰을 묻습니다. 성공하면 토큰이 암호화되어 저장되고, 다음부터는 다시 묻지 않습니다. 인증에 실패하면 저장된 값을 지우지 않고, 다음에 대화상자가 다시 나타납니다.

GitHub는 계정 비밀번호 대신 Personal Access Token을 사용합니다. Organization SSO가 필요한 저장소는 토큰을 그 조직에 승인한 뒤 다시 시도합니다.

### 환경설정 창

**파일 → 환경설정...**이나 도구 모음의 톱니바퀴로 엽니다. 환경설정은 별도 창이고, 크기를 바꿀 수 있으며(최소 640×420), 메인 창 밖으로 옮길 수도 있습니다. 탭은 왼쪽에 세로로 놓여 있고, 바꾼 내용은 저장 단추 없이 바로 적용됩니다.

| 탭 | 내용 |
|----|------|
| **일반** | UI 언어, 터미널 기본 셸, 시작할 때 튜토리얼 보기 |
| **테마** | 내 테마, Dark, Light 테마와 내 테마 편집기 |
| **시작 화면** | 시작할 때 시작 화면 보기, 시작할 때 튜토리얼 보기, 배경, 속도·투명도, 지금 시작 화면 보기, 카드 배치 초기화, 시작 화면 설정 초기화 |
| **프롬프트** | 터미널 프롬프트의 미리 보기, 프리셋, 내 프롬프트, 빠른 설정 ([프롬프트](#prompt) 참고) |
| **프롬프트 편집** | 프롬프트 구역(세그먼트)을 하나씩 편집 |
| **도구** | 외부 diff·merge 도구 |

**도구** 탭의 항목:

- 외부 diff 도구 경로
- 인수 템플릿. 기본값은 `"{left}" "{right}"`
- Merge 도구. 기본값은 **내장 Diff & Merge (기본)**이고, 목록에서 설치된 외부 도구를 고르거나 경로를 직접 적을 수 있습니다.
- Merge 인수 템플릿. 기본값은 `"{base}" "{local}" "{remote}" "{merged}"`

`{left}`와 `{right}`는 비교할 임시 파일 경로로 바뀝니다. `{base}`, `{local}`, `{remote}`는 충돌한 세 버전의 임시 파일이고 `{merged}`는 작업 트리의 파일입니다. 내장 Diff & Merge를 고르면 경로와 인수 칸은 쓰이지 않습니다.

**기본값 복원**은 언어, 테마, 셸, 도구, 시작 화면, 튜토리얼, 프롬프트 설정을 처음으로 돌립니다. 내 테마와 내 프롬프트는 남습니다.

<a id="prompt"></a>
### 프롬프트

터미널 프롬프트의 모양은 **환경설정 → 프롬프트 / 프롬프트 편집**에서 바꿉니다. 바꾼 내용은 다음 프롬프트부터 바로 보입니다.

- **미리 보기**: 깨끗한 저장소, 변경이 있는 저장소, 저장소 밖의 세 경우를 보여 줍니다.
- **프리셋**: 카드를 누르면 그 모양이 바로 적용됩니다.
- **내 프롬프트**: 지금 프롬프트를 이름을 붙여 저장하고, 다시 저장하거나 지웁니다. 기본값 복원을 해도 남습니다.
- **빠른 설정**: 보일 구역(OS, 세션, 셸, 경로, git, 실행 시간, 상태, 시각), 모양(파워라인 / 평범 / 둥근 모양), 경로 표시 방식, 두 줄, git 표시(끄기 / 브랜치 / 상태), git 상태 색
- **프롬프트 편집**: 왼쪽 목록에서 구역을 고르고 오른쪽에서 종류, 모양, 색, 템플릿을 바꿉니다.

프롬프트의 화살표와 경로 구분 기호는 터미널이 직접 그리므로 따로 글꼴을 설치할 필요가 없습니다.

| bash (Git Bash, MSYS, Cygwin) | 모두 지원. 평소 시작 파일도 그대로 읽습니다 |

| WSL | WSL의 원래 프롬프트를 씁니다 |

<a id="windows"></a>
## 창과 팝업

데스크톱 앱에서는 메뉴, 테마 목록, 대화상자(열기, 복제, 원격 탐색, 로그인, 커밋, 환경설정, 정보, 오류, 확인, 보고서, 내보내기), 인쇄 미리 보기, 진행 상태 창이 모두 별도 창으로 열립니다. 메인 창 밖으로 옮기거나 넘어가도 잘리지 않습니다. 웹 브라우저에서는 같은 내용이 페이지 안에 나타납니다.

- 모든 팝업 창 맨 위에는 아이콘과 제목, 닫기(×) 단추가 있습니다. 제목 줄을 끌어 옮기고, `Esc`로 닫습니다.
- 인쇄 미리 보기와 환경설정 창은 크기를 바꿀 수 있습니다. 인쇄는 미리 보기 창 안에서 합니다.

<a id="progress-popup"></a>
### 진행 상태 창

복제, Fetch, Pull, Push, 원격 탐색처럼 시간이 걸리는 작업이 0.4초를 넘기면 진행 상태 창이 나타납니다. 작업 이름과 아이콘, Git이 출력한 마지막 진행 줄, 움직이는 막대, 지난 시간이 보이며, **취소**로 작업을 멈춥니다. 작업이 끝나면 저절로 닫힙니다.

<a id="guide-window"></a>
### 사용자 설명서 창

`F1` 또는 **도움말 → 사용자 설명서**로 엽니다. 크기를 바꿀 수 있는 별도 창입니다.

- 왼쪽 목차를 누르면 그 부분으로 갑니다. 읽는 위치가 목차에 표시됩니다.
- 위의 검색 칸에 단어를 넣으면 찾은 곳이 강조됩니다. `Enter`는 다음 위치, `Esc`는 검색 지우기입니다.
- 언어 단추는 바꿀 언어를 보여 줍니다. 한국어 설명서에서는 영국 국기와 **영어**, 영어 설명서에서는 태극기와 **한국어**가 보입니다.
- **−** / **+** 로 글자 크기를 바꿉니다.

| Linux | `~/.config/MyGitMaster/settings.json` | `~/.cache/MyGitMaster/remote-cache/` |

예전 MyGitJS를 쓰던 컴퓨터에서는 처음 실행할 때 `MyGitJS` 폴더의 설정과 토큰 키를 한 번 복사해 옵니다. 데스크톱 창의 위치와 크기도 이 파일의 `window` 항목에 저장됩니다.

같은 폴더의 `.key`가 토큰 암호화에 쓰입니다. `settings.json`을 열어도 토큰 원문은 보이지 않습니다. 최근 저장소와 최근 URL은 각각 최대 10개입니다.

<a id="troubleshooting"></a>
## 문제 해결

<a id="ts-git-missing"></a>
### Git을 찾을 수 없음

화면 위에 Git이 없다는 안내가 나오면, `git`이 터미널에서 실행되는지 확인한 뒤 앱을 다시 시작합니다.

<a id="ts-open-failed"></a>
### 저장소를 열 수 없음

폴더 안에 `.git`이 있는지 확인합니다. Git 저장소가 아닌 폴더는 **폴더 열기**로 목록만 볼 수 있습니다. 오류 창의 상세를 복사해 두면 원인을 구분하기 쉽습니다.

<a id="ts-clone-failed"></a>
### 복제 또는 원격 탐색 실패

- URL이 `https://` 또는 `file://` 형태인지 확인합니다.
- 비공개 GitHub 저장소는 PAT를 사용합니다.
- 복제 대상 폴더는 비어 있거나 아직 없어야 합니다.
- 캐시가 꼬이면 해당 URL의 캐시 폴더를 지운 뒤 다시 탐색합니다. Windows에서는 `%LocalAppData%\MyGitMaster\remote-cache\`입니다.

<a id="ts-commit-push-failed"></a>
### 커밋 또는 push 실패

- `user.name`, `user.email`을 확인합니다.
- Commit 전에 Git Add로 stage했는지 확인합니다.
- push는 `origin`이 있어야 합니다.
- 403이 반복되면 토큰의 조직 SSO 승인을 확인합니다.

<a id="ts-external-diff"></a>
### 외부 diff가 열리지 않음

**파일 → 환경설정...**에서 도구 경로를 지정합니다. 지정 전에는 오류 대화상자가 열립니다.

<a id="ts-tool-window"></a>
### 도구 창이 열리지 않음

웹 브라우저에서 팝업이 차단되면 내장 Diff나 내장 Diff & Merge 창이 열리지 않고 그 이유가 표시됩니다. 이 주소의 팝업을 허용해 주세요. 데스크톱 앱에서는 Diff 창과 Merge 창을 직접 열고, 이미 열려 있으면 그 창에 새 파일을 보여 줍니다.

<a id="ts-terminal-prompt"></a>
### 터미널 프롬프트가 기본 모양으로 보임

cmd에서는 터미널을 연 뒤 바꾼 프롬프트 설정이 보이지 않습니다. 새 터미널 탭을 엽니다. WSL은 항상 WSL의 프롬프트를 씁니다. 다른 셸에서 프롬프트가 단순한 모양으로만 나오면 프로그램과의 연결이 끊긴 것이므로 터미널 탭을 닫고 다시 엽니다.

<a id="ts-release-empty"></a>
### Release가 비어 있음

원격 URL이 GitHub `owner/repo` 형태인지, 인터넷이 연결돼 있는지 확인합니다. 공개 저장소는 토큰 없이 조회합니다.
