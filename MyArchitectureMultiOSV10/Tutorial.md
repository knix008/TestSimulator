# MyArchitecture 10.0 튜토리얼

> 평면도를 그리면 곧바로 3D 건물이 되는 건축 설계 프로그램 **MyArchitecture 10.0** 의 모든 기능을, 프로그램을 옆에 켜 놓고 한 단계씩 따라 하며 익히는 안내서입니다.
>
> 이 문서는 프로그램 안의 **따라 하는 튜토리얼**(도움말 → 따라 하는 튜토리얼, 16개 레슨·83단계)과 같은 순서, 같은 좌표로 진행합니다. 프로그램 튜토리얼을 **보기** 모드로 틀어 두고 이 문서를 읽거나, **따라 하기** 모드로 직접 해 보면서 이 문서의 설명과 팁을 함께 보면 가장 빨리 익힐 수 있습니다. 튜토리얼 레슨에서 다루지 않는 기능(내보내기 옵션, 설정 항목, 3D 그리드, 최근 파일, 인쇄 등)도 모두 이 문서에 넣었습니다.

### 이 문서를 읽는 법

- **굵은 글씨**는 프로그램 화면에 보이는 이름 그대로입니다. 예: **빌드 → 맨 위층 지붕**은 메뉴 막대의 **빌드** 메뉴에서 **맨 위층 지붕**을 누르라는 뜻입니다.
- `W`, `Ctrl+Z` 처럼 상자 안 글자는 키보드 키입니다. macOS 에서는 `Ctrl` 대신 `Cmd` 를 눌러도 됩니다.
- 길이 단위는 기본적으로 **mm** 입니다. 좌표 (5000, 0) 은 원점에서 오른쪽으로 5 m 인 점입니다.
- 각 레슨은 **목표 → 따라 하기 → 이렇게 보여야 합니다 → 팁 → 자주 하는 실수 → 확인** 순서입니다.
- 레슨 2–13 은 **하나의 작은 집**을 계속 이어서 만듭니다. 중간 레슨부터 시작하고 싶다면 프로그램 튜토리얼에서 그 레슨을 고르세요. 앞 레슨의 결과를 자동으로 빠르게 만들어 줍니다.

## 레슨 0. 준비: 설치, 실행, 시작 페이지

### 목표
프로그램을 설치해 실행하고, 시작 페이지와 환영 창에서 할 수 있는 일을 알아봅니다.

### 따라 하기

1. **설치합니다.**
   - Windows: `MyArchitecture-Setup-10.0.0.exe` 를 실행합니다. 설치 위치를 고를 수 있고, 설치가 끝나면 `.myarch` 파일이 MyArchitecture 와 연결됩니다(파일을 두 번 클릭하면 열립니다).
   - macOS: `.dmg` 를 열어 앱을 응용 프로그램 폴더로 끌어 놓습니다.
   - Linux: `AppImage` 를 실행하거나 `.deb` 패키지를 설치합니다.
   - 웹 버전: 브라우저에서 바로 열립니다. 기능은 같고, 파일 저장은 브라우저의 다운로드로 처리됩니다.
   - 설치 프로그램을 소스에서 직접 만들려면 프로젝트 폴더에서 `npm run build:win`(Windows NSIS 설치 프로그램), `npm run build:mac`(dmg, zip), `npm run build:linux`(AppImage, deb, tar.gz), 또는 세 가지를 한 번에 `npm run build:all` 을 실행합니다.
2. **실행합니다.** 처음 실행하면 **MyArchitecture 10.0에 오신 것을 환영합니다** 창이 뜹니다. 네 단계(1. 벽 그리기 / 2. 방, 계단, 지붕 / 3. 가구 배치 / 4. 3D로 보고 공유하기)가 짧게 소개되어 있습니다.
   - **예제 열기**: 예제 목록을 엽니다.
   - **새 프로젝트 시작**: 빈 평면도로 바로 갑니다.
   - **확인**: 창을 닫고 시작 페이지를 봅니다. 이 문서를 따라 할 때는 **확인**을 누르세요.
3. **시작 페이지를 살펴봅니다.**

![시작 페이지: 튜토리얼, 새 프로젝트, 열기, 가져오기, 예제 카드, 최근 파일](docs/images/ko/start-page.webp)

*시작 페이지: 튜토리얼, 새 프로젝트, 열기, 가져오기, 예제 카드, 최근 파일*

   시작 페이지 왼쪽의 카드는 다음과 같습니다.

   | 카드 | 하는 일 |
   |---|---|
   | **따라 하는 튜토리얼** | 모든 기능을 단계별로 보여 주거나 직접 연습하게 합니다 (레슨 18) |
   | **새 프로젝트** | 빈 평면도 (`Ctrl+N`) |
   | **프로젝트 열기…** | 디스크의 .myarch 파일 (`Ctrl+O`) |
   | **가져오기…** | DXF, IFC, SVG, 3D 모델, 이미지 (`Ctrl+I`) |
   | **예제 둘러보기** | 미리 만든 주택과 아파트 9가지 |
   | **사용 설명서** | 단계별 안내 (`F1`) |
   | **단축키** | 더 빠르게 작업하기 (`Ctrl+/`) |

   가운데에는 **예제** 카드(미리보기 그림이 움직입니다), 아래에는 **최근** 파일 목록이 있습니다(설정의 **기억할 최근 파일 수**만큼, 기본 10개). 최근 파일 줄 끝의 ✕ 는 **목록에서 제거**, **목록 지우기**는 목록 전체를 비웁니다(파일 자체는 지워지지 않습니다).
4. **예제를 하나 열어 봅니다.** 예제 카드 중 **2층 주택**을 누릅니다. 평면도 탭으로 바뀌고 "예제 … 을(를) 열었습니다. 바꾼 내용을 남기려면 새 이름으로 저장하세요." 알림이 뜹니다.

- 프로그램이 비정상 종료되면 다음 실행 때 **작업 복구** 창이 "…의 저장되지 않은 프로젝트를 복구했습니다. 복원할까요?" 하고 묻습니다. **복원**을 누르면 마지막 자동 저장본이 열립니다(레슨 16 의 자동 저장 설정).

## 레슨 1. 화면 둘러보기

### 목표
화면의 각 부분 이름을 익히고, 확대·이동, 층 바꾸기, 3D 보기와 평면도 오가기, 명령 검색을 해 봅니다. (프로그램 튜토리얼 레슨 1)

### 화면 구성

![평면도 화면: 메뉴·탭·도구 모음, 왼쪽 가구 라이브러리, 가운데 도면, 오른쪽 속성, 아래 상태 표시줄](docs/images/ko/overview-plan.webp)

*평면도 화면: 메뉴·탭·도구 모음, 왼쪽 가구 라이브러리, 가운데 도면, 오른쪽 속성, 아래 상태 표시줄*

| 위치 | 이름 | 내용 |
|---|---|---|
| 맨 위 왼쪽 | **메뉴 막대** | 파일 · 편집 · 보기 · 빌드 · BIM · 도움말. 그리기·3D 명령은 메뉴 없이 도구 모음에 있습니다 |
| 메뉴 바로 오른쪽 | **보기 탭** | 시작 · 평면도(`F2`) · 3D 보기(`F3`). 평면도 탭에는 모델 검사의 오류·경고 개수가 배지로 붙습니다 |
| 탭 오른쪽 | **돋보기 단추** | 누르거나 `Ctrl+K` 로 명령 팔레트를 엽니다. 단추에 마우스를 올리면 "명령, 방, 가구 검색… (Ctrl+K)" 이 보입니다 |
| 가운데 | 문서 제목 | 프로젝트 제목, 저장하지 않은 변경이 있으면 ● 표시, 파일 이름 |
| 맨 위 오른쪽 | 팔레트 · ▾ · 국기 · 톱니 · ⓘ | 무작위 테마 · 테마 선택 · 언어 바꾸기(한국어↔English) · 설정… · MyArchitecture 정보 |
| 둘째 줄 | **도구 모음** | 새로·열기·저장, ↶ 되돌리기 · ↷ 다시 실행, 그리고 지금 탭에 맞는 도구들 |
| 왼쪽 | **가구 라이브러리** (3D 에서는 3D 보기 옵션) | 접으면 아이콘과 제목만 남습니다 |
| 가운데 | **도면(캔버스)** | 왼쪽 아래에 **층 탭**, 가장자리에 눈금자 |
| 오른쪽 | **속성** + **모델 검사** | 고른 요소의 속성, 아무것도 고르지 않으면 지금 층의 속성 |
| 맨 아래 | **상태 표시줄** | 힌트, 좌표, 층, 격자, 스냅, 직교, 축척, 단위, 선택 수, 검사. 오른쪽 끝에 창 크기 조절 손잡이 |

> 제목 표시줄의 메뉴, 탭, 단추는 어떤 경우에도 숨겨지지 않습니다. 창은 이것들이 모두 보이는 너비보다 좁아지지 않고, 화면 자체가 아주 좁으면 제목 표시줄이 두 줄로 나뉩니다. 도구 모음도 마찬가지로 모든 단추가 보이도록 창의 최소 너비가 정해집니다.

### 따라 하기

1. **예제 열기.** **파일 → 예제 열기…** 에서 **2층 주택**을 고릅니다. (레슨 0 에서 이미 열었다면 그대로 둡니다.)
2. **전체 보기.** `Home` 키를 누릅니다. 도면 전체가 화면에 맞춰집니다. 도구 모음 오른쪽 끝의 **화면에 맞추기** 단추도 같습니다.
3. **확대·축소.** 마우스 휠을 굴립니다. 커서가 있는 곳을 중심으로 확대·축소됩니다. `Ctrl+=` / `Ctrl+-` 나 도구 모음의 **확대** / **축소** 단추도 됩니다.
4. **화면 이동.** 도면의 빈 곳을 마우스 왼쪽 버튼으로 끕니다. 도면이 손을 따라 움직입니다.
   - 가운데 버튼이나 오른쪽 버튼으로 끌어도, `Space` 를 누른 채 끌어도 이동합니다.
   - `Shift`+끌기는 이동이 아니라 **영역 선택**입니다(레슨 6).
5. **층 바꾸기.** 도면 왼쪽 아래의 층 탭에서 **2F** 를 누릅니다. 2층이 편집 대상이 되고, 아래층(1F)은 흐리게 겹쳐 보입니다.

![층 탭: 층을 고르고(+ 로 추가), 아래층은 흐리게 겹쳐 보입니다](docs/images/ko/levels.webp)

*층 탭: 층을 고르고(+ 로 추가), 아래층은 흐리게 겹쳐 보입니다*

6. **3D 보기.** `F3` 을 누르거나 제목 표시줄의 **3D 보기** 탭을 누릅니다. 건물이 3D 로 나타납니다.
   - 왼쪽 버튼으로 끌기: 회전(궤도 회전)
   - 오른쪽 버튼으로 끌기: 이동
   - 휠: 확대·축소

![3D 보기: 왼쪽에 장면·층·표시·단면·태양, 오른쪽에 고른 요소의 속성](docs/images/ko/overview-3d.webp)

*3D 보기: 왼쪽에 장면·층·표시·단면·태양, 오른쪽에 고른 요소의 속성*

7. **평면도로 돌아가기.** `F2` 를 누르거나 **평면도** 탭을 누른 뒤, 층 탭에서 **1F** 를 누릅니다.
8. **명령 검색.** `Ctrl+K` 를 누르거나 제목 표시줄의 **돋보기** 단추를 누릅니다. **명령 팔레트**가 열리면 `지붕` 이라고 입력해 보세요. 메뉴 명령뿐 아니라 프로젝트의 방 이름, 층(예: "층 2F")도 함께 검색됩니다. 항목을 고르고 Enter 를 누르면 실행되거나 그곳으로 이동합니다. Esc 로 닫습니다.

![명령 팔레트(Ctrl+K): 모든 명령·방·층·가구를 검색합니다](docs/images/ko/command-palette.webp)

*명령 팔레트(Ctrl+K): 모든 명령·방·층·가구를 검색합니다*

### 이렇게 보여야 합니다
- `Home` 뒤에는 건물 전체가 화면 가운데에 꽉 차게 보입니다.
- 2F 탭을 누르면 탭이 강조색으로 바뀌고, 1층 벽이 옅은 선으로 비칩니다.
- 3D 보기의 왼쪽 패널에는 **장면, 층, 표시, 단면과 단계, 일조 분석** 이 있습니다.

### 팁
- 도구를 고르면 도면 아래쪽과 상태 표시줄 왼쪽 칸에 **힌트**가 나타나 다음에 할 일을 알려 줍니다. 처음에는 힌트를 꼭 읽으세요.
- 무엇이든 **마우스 오른쪽 버튼**으로 클릭하면 그 요소에 쓸 수 있는 명령이 나옵니다. 메뉴 맨 위에는 항상 **되돌리기 / 다시 실행**이 있습니다.
- 찾는 명령이 어느 메뉴에 있는지 모를 때는 `Ctrl+K` 로 이름 일부만 입력하면 됩니다.
- 방이나 문, 가구를 이름으로 찾아 그곳으로 가려면 **편집 → 찾기…**(`Ctrl+F`)를 씁니다.

### 자주 하는 실수
- 끌었는데 화면이 움직이지 않고 상자가 그려진다: `Shift` 를 누르고 있거나, **설정 → 단위와 격자 → 빈 캔버스에서 왼쪽 끌기**가 **상자 선택**으로 되어 있습니다.
- 끌었더니 벽이 생긴다: 벽 도구가 켜져 있습니다. `Esc` 를 한두 번 눌러 **선택** 도구로 돌아오세요.

### 확인
- [ ] `Home`, 휠, 빈 곳 끌기로 화면을 자유롭게 다룬다.
- [ ] 층 탭으로 층을 바꿀 수 있다.
- [ ] `F2` / `F3` 으로 평면도와 3D 를 오간다.
- [ ] `Ctrl+K` 또는 돋보기 단추로 명령을 찾아 실행할 수 있다.

## 레슨 2. 벽 그리기

### 목표
새 프로젝트에 9000 × 6000 mm 의 외벽 네 개와 x = 5000 의 칸막이 벽을 그리고, 길이 입력, 두께 변경, 벽 옮기기, 되돌리기를 익힙니다. (프로그램 튜토리얼 레슨 2)

### 따라 하기

1. **새 프로젝트.** `Ctrl+N` 을 누릅니다(도구 모음의 **새 프로젝트** 단추도 같습니다). 저장하지 않은 변경이 있으면 **저장하지 않은 변경 사항** 창이 뜹니다. 예제를 연 상태라면 **저장 안 함**을 누르세요. "새 프로젝트입니다. W를 눌러 벽을 그리세요." 알림과 함께 빈 평면이 열립니다. 단위는 mm 입니다.
2. **외벽 네 개.** `W` 를 누릅니다(도구 모음의 **벽** 단추).
   1. 원점 (0, 0) 을 클릭합니다. 상태 표시줄 좌표가 `X 0 mm  Y 0 mm` 인 곳입니다.
   2. 오른쪽으로 (9000, 0) 을 클릭합니다.
   3. 아래로 (9000, 6000) 을 클릭합니다.
   4. 왼쪽으로 (0, 6000) 을 클릭합니다.
   5. 처음 점 (0, 0) 을 다시 클릭합니다. 윤곽이 닫히면서 그리기가 끝납니다.

![벽 그리기(W): 클릭할 때마다 벽이 이어지고 길이·각도가 표시됩니다](docs/images/ko/walls-chain.webp)

*벽 그리기(W): 클릭할 때마다 벽이 이어지고 길이·각도가 표시됩니다*

   - 그리는 동안 벽 옆에 길이와 각도가 표시됩니다.
   - 각도는 45° 단위로(직교 그리기), 점은 격자(기본 100 mm)와 벽 끝·벽 위에 달라붙습니다(스냅).
3. **칸막이 벽.** `W` 를 누르고 위쪽 벽의 (5000, 0) 을 클릭한 다음 아래쪽 벽의 (5000, 6000) 을 클릭하고 `Esc` 를 누릅니다. 벽 끝이 다른 벽 위에 놓이면 T 자로 깔끔하게 이어집니다.

![벽 이음: 모서리는 자동으로 맞물리고, T 자·십자 이음도 깨끗하게 그려집니다](docs/images/ko/walls-joints.webp)

*벽 이음: 모서리는 자동으로 맞물리고, T 자·십자 이음도 깨끗하게 그려집니다*

4. **길이를 입력해 그리기.** 이번에는 왼쪽 공간을 위아래로 나누는 벽을 정확한 길이로 그립니다.
   1. `W` 를 누르고 왼쪽 벽의 (0, 3000) 을 클릭합니다.
   2. 마우스를 오른쪽으로 옮겨 방향을 정합니다(클릭하지 않습니다).
   3. 키보드로 `5000` 을 칩니다. 첫 숫자를 누르는 순간 커서 옆에 **길이(mm, 3.6m, 3600<90)** 입력 칸이 열립니다.
   4. `Enter` 를 누르면 정확히 5000 mm 벽이 놓입니다. `Esc` 로 끝냅니다.

![길이 입력: 그리는 중에 숫자를 치면 정확한 길이(예: 4500, 3.6m, 3600<90)로 벽이 놓입니다](docs/images/ko/walls-typed-length.webp)

*길이 입력: 그리는 중에 숫자를 치면 정확한 길이(예: 4500, 3.6m, 3600<90)로 벽이 놓입니다*

   입력할 수 있는 형식:

   | 입력 | 뜻 |
   |---|---|
   | `4500` | 4500 mm (단위가 없으면 mm) |
   | `3.6m` | 3.6 m = 3600 mm |
   | `360cm` | 360 cm = 3600 mm |
   | `3600<90` | 길이 3600 mm, 각도 90° (`<` 뒤는 각도, 0° = 오른쪽, 90° = 위쪽) |
   | `12'6"` , `40in` | 피트·인치 |

5. **벽 두께.** `Esc` 로 선택 도구로 돌아와 위쪽 벽의 (4000, 0) 근처를 클릭합니다. 오른쪽 **속성** 패널에 벽 정보가 나옵니다. **두께** 옆의 **+** 를 한 번 누르면 10 mm 두꺼워집니다. 숫자 칸을 클릭해 직접 입력해도 됩니다.

![벽을 고르면 오른쪽에서 두께·높이·벽 타입·재료·단계 등을 바로 고칩니다](docs/images/ko/walls-inspector.webp)

*벽을 고르면 오른쪽에서 두께·높이·벽 타입·재료·단계 등을 바로 고칩니다*

   벽 속성 패널의 항목: **벽 타입**, **길이**, **두께**, **높이**, **재료**, 그리고 단추 **문 추가 / 창문 추가 / 가운데에서 나누기 / 삭제**, 아래 **BIM** 구역(**단계, 분류, IFC 클래스, GlobalId, 속성 (n)…, 비슷한 요소 선택**).
6. **벽 옮기기와 되돌리기.** 가운데 칸막이 벽(x = 5000)의 (5000, 1500) 을 잡고 오른쪽으로 600 mm 정도 끕니다. 이어진 벽들이 따라 늘어납니다. 이제 `Ctrl+Z` 를 누르면 원래 자리로 돌아오고, `Ctrl+Y` 를 누르면 다시 옮겨집니다. 마지막에 `Ctrl+Z` 로 x = 5000 으로 되돌려 두세요.
7. **되돌리기·다시 실행 단추.** 도구 모음의 **↷ 다시 실행**을 누른 다음 **↶ 되돌리기**를 누릅니다. 단추에 마우스를 올리면 "되돌리기: 이동"처럼 무엇이 되돌려질지 보여 줍니다. 되돌릴 것이 없으면 단추가 흐려집니다.

![오른쪽 클릭 메뉴: 맨 위에 되돌리기/다시 실행, 그 아래 고른 요소에 맞는 명령](docs/images/ko/context-menu.webp)

*오른쪽 클릭 메뉴: 맨 위에 되돌리기/다시 실행, 그 아래 고른 요소에 맞는 명령*

   **되돌리기 / 다시 실행**은 평면도 오른쪽 클릭 메뉴, 층 탭 오른쪽 클릭 메뉴, 3D 화면 오른쪽 클릭 메뉴의 맨 위에도 있습니다.

### 이렇게 보여야 합니다
- 9 m × 6 m 사각형 안이 x = 5000 벽으로 좌우로 나뉘고, 왼쪽 칸은 y = 3000 벽으로 위아래로 나뉩니다. 공간이 세 개 생겼습니다.
- 모든 모서리와 T 자 이음은 선이 겹치지 않고 하나의 덩어리처럼 칠해집니다.

### 팁
- 그리는 중 `Backspace` 는 마지막 모서리만 취소합니다. `Shift` 를 누르고 있으면 45° 단위가 아닌 임의 각도로 그립니다.
- `Enter`, `Esc`, 두 번 클릭 모두 그리기를 끝냅니다. `Esc` 를 한 번 더 누르면 **선택** 도구로 돌아갑니다.
- 벽 끝점을 끌면 그 끝만 움직이고, 벽 가운데를 끌면 벽 전체가 평행 이동합니다. `Alt`+끌기는 이어진 벽을 늘리지 않고 이 벽만 옮깁니다.
- 벽을 오른쪽 클릭하면 **여기에 문 추가 / 여기에 창문 추가 / 여기서 벽 나누기 / 일직선 벽 합치기** 같은 명령이 있습니다.
- 상태 표시줄의 **Y** 좌표는 위쪽이 + 입니다. 이 문서에서 "아래쪽 벽 (y = 6000)" 은 상태 표시줄에는 `Y -6000 mm` 로 나옵니다.
- 화살표 키는 선택한 것을 격자 한 칸씩, `Shift`+화살표는 열 칸씩 옮깁니다.

### 자주 하는 실수
- 숫자를 쳤는데 아무 일도 없다: 첫 점을 클릭하기 **전**에는 길이 입력이 되지 않습니다. 첫 점을 찍고 마우스로 방향을 잡은 뒤 숫자를 치세요.
- 벽이 비스듬히 그려진다: 상태 표시줄의 **직교 ✓** 가 꺼져(—) 있습니다. 눌러서 켜거나 `F8`.
- 점이 원하는 곳에 딱 붙지 않는다: **스냅 ✓** 가 꺼져 있거나 격자가 너무 큽니다. `F9` 또는 상태 표시줄의 **격자 100 mm** 칸을 눌러 바꾸세요.

### 확인
- [ ] `W` 와 클릭으로 닫힌 외벽을 그렸다.
- [ ] 칸막이 벽이 T 자로 붙었다.
- [ ] `5000` + `Enter` 로 정확한 길이의 벽을 그렸다.
- [ ] 오른쪽 패널에서 벽 두께를 바꿨다.
- [ ] `Ctrl+Z` / `Ctrl+Y` 와 도구 모음 단추로 되돌리고 다시 실행했다.

## 레슨 3. 문과 창문

### 목표
현관문 하나, 창문 두 개, 안쪽 문 두 개를 넣고 여는 방향과 폭을 바꿉니다. (프로그램 튜토리얼 레슨 3)

### 따라 하기

1. **현관문.** `D` 를 누릅니다(도구 모음의 **문** 단추). 아래쪽 벽의 (2000, 6000) 을 클릭합니다. 문은 **커서가 있는 쪽**으로 열리므로, 집 안쪽으로 열리게 하려면 벽보다 약간 위(집 안쪽)에 커서를 두고 클릭하세요.
2. **창문 두 개.** `N` 을 누르고(도구 모음의 **창문** 단추) 위쪽 벽의 (2500, 0) 과 (7000, 0) 을 클릭한 뒤 `Esc`.
3. **안쪽 문.** `D` 를 누르고 칸막이 벽의 (5000, 1500) 과 가로 벽의 (2500, 3000) 을 클릭한 뒤 `Esc`.

![문(D)·창(N): 벽 위를 클릭하면 들어가고, X 로 여는 방향, H 로 경첩을 바꿉니다](docs/images/ko/doors-windows.webp)

*문(D)·창(N): 벽 위를 클릭하면 들어가고, X 로 여는 방향, H 로 경첩을 바꿉니다*

4. **여는 방향 바꾸기.** `Esc` 로 선택 도구로 돌아와 현관문을 클릭합니다. `X` 를 누르면 열리는 쪽(안/밖)이, `H` 를 누르면 경첩 쪽(왼/오른)이 바뀝니다. 오른쪽 패널의 **열림 방향 뒤집기 / 경첩 바꾸기** 단추도 같습니다.
5. **문 폭.** 현관문이 선택된 상태에서 오른쪽 패널 **폭** 의 **+** 를 누릅니다. 한 번에 50 mm 씩 넓어집니다.

### 문·창문 속성

오른쪽 패널(또는 두 번 클릭/`E` 로 여는 **문 속성 / 창문 속성** 창)에서 바꿀 수 있는 것:

| 항목 | 값 |
|---|---|
| **종류** | 문 / 창문 / 개구부(문짝 없는 구멍) |
| **유형** | 문: 외여닫이, 양개, 미닫이, 차고 · 창문: 여닫이창, 고정, 미닫이 |
| **폭 / 높이 / 창대 높이** | mm, 50 mm 단위 |
| **위치** | 벽 시작점에서의 거리 |
| **여닫는 쪽 / 경첩** | 벽 왼쪽·오른쪽 / 벽 시작점에서·벽 끝에서 (속성 창) |
| **태그** | D1, W1 처럼 자동으로 붙는 번호. 직접 바꿀 수 있습니다 |

### 이렇게 보여야 합니다
- 문은 문짝과 열리는 호(1/4 원)로, 창문은 벽 속의 가는 이중선으로 그려집니다.
- 문 옆에 D1, D2 … 창문 옆에 W1, W2 … 태그가 붙습니다(**설정 → 평면도 → 문·창문 태그**).

### 팁
- 새로 넣는 문·창문의 기본 크기는 **빌드 → 기본 크기 (벽, 문, 창문)…** 에서, 또는 아무것도 선택하지 않았을 때 오른쪽 패널 **새 항목** 구역의 **문 폭 / 창문 폭 / 창대**에서 정합니다.
- 문이나 창문을 벽을 따라 끌면 위치가 바뀝니다.
- 벽을 선택하고 오른쪽 패널의 **문 추가** / **창문 추가** 를 눌러도 됩니다.

### 자주 하는 실수
- "이 벽은 너무 짧아 넣을 수 없습니다.": 문 폭보다 벽이 짧습니다. 폭을 줄이거나 긴 벽에 넣으세요.
- "그 자리에 이미 문이나 창문이 있습니다.": 다른 개구부와 겹칩니다. 조금 옆을 클릭하세요.
- 문이 바깥으로 열린다: 문을 선택하고 `X`.

### 확인
- [ ] 문 3개, 창문 2개가 들어갔다.
- [ ] `X`, `H` 로 여는 방향을 바꿨다.
- [ ] 문 폭을 + 로 넓혔다.

## 레슨 4. 방과 면적

### 목표
벽으로 둘러싸인 세 공간을 방으로 만들고, 이름과 번호를 붙입니다. (프로그램 튜토리얼 레슨 4)

### 따라 하기

1. **벽 안을 클릭해 방 만들기.** `A` 를 누르고(도구 모음의 **방** 단추) 세 공간 안쪽 (2500, 1500), (2500, 4500), (7000, 3000) 을 차례로 클릭한 뒤 `Esc`. 클릭할 때마다 "방 … 을(를) 추가했습니다: … m². 두 번 클릭하면 이름을 바꿀 수 있습니다." 알림이 뜹니다. 면적은 **벽 안쪽** 기준(순면적)입니다.

![방(A): 벽으로 둘러싸인 곳을 클릭하면 방이 생기고 이름과 면적이 붙습니다](docs/images/ko/rooms.webp)

*방(A): 벽으로 둘러싸인 곳을 클릭하면 방이 생기고 이름과 면적이 붙습니다*

2. **방 이름 바꾸기.** 오른쪽 큰 방의 (7000, 2200) 을 두 번 클릭합니다. **방 속성** 창이 열립니다. **이름** 칸에 `거실` 을 입력하고(목록에서 거실·침실·주방·식당·욕실·현관… 을 골라도 됩니다) **확인**.
3. **방 번호.** 왼쪽 위 방 (2500, 1500) 을 클릭하고 오른쪽 패널 **번호** 칸에 `101` 을 입력한 뒤 `Enter`.

### 방 속성

| 항목 | 설명 |
|---|---|
| **이름** | 도면에 큰 글씨로 표시 |
| **번호** | 실 번호. BIM(IFC)과 집계표에 쓰임 |
| **부서** | 용도/부서 이름 |
| **바닥** | 바닥 재료(오크 마루, 타일, 카펫 …) — 3D 에도 반영 |
| **텍스트 크기** | 이름 글씨 크기 |
| **면적 표시** | 끄면 면적 숫자를 숨김 |

오른쪽 패널 제목 아래에는 면적과 **둘레**가 표시됩니다.

### 팁
- 벽을 다 그린 뒤 한꺼번에 방을 만들려면 **빌드 → 벽에서 방 감지**(도구 모음 단추, 빈 곳 오른쪽 클릭 → **방 감지**). "방 n개를 만들었습니다." 가 뜹니다.
- 벽이 없는 곳에 방을 그리려면 `A` 상태에서 `Shift`+클릭으로 모서리를 찍고 `Enter`.
- 방 모서리를 끌면 모양이 바뀝니다.

### 자주 하는 실수
- "새로 닫힌 공간을 찾지 못했습니다.": 벽이 완전히 닫혀 있지 않습니다. 벽 끝이 다른 벽에 닿았는지 확대해서 보세요.
- 면적이 예상보다 작다: 정상입니다. 벽 두께를 뺀 안쪽 면적입니다. 바깥 기준 면적은 집계표의 **총면적**에 있습니다.

### 확인
- [ ] 방 3개가 생기고 면적이 보인다.
- [ ] 큰 방 이름이 "거실" 이다.
- [ ] 왼쪽 위 방 번호가 101 이다.

## 레슨 5. 가구 배치

### 목표
라이브러리와 검색으로 가구를 놓고, 돌리고, 옮기고, 속성 창을 써 봅니다. (프로그램 튜토리얼 레슨 5)

### 따라 하기

1. **라이브러리에서 고르기.** 왼쪽 **가구 라이브러리**에서 **소파 (3인)** 을 누르고 거실의 (7000, 3500) 을 클릭합니다. 항목을 도면으로 끌어다 놓아도 됩니다.

![가구 라이브러리: 분류·검색 후 끌어다 놓거나 눌러서 배치합니다](docs/images/ko/furniture-library.webp)

*가구 라이브러리: 분류·검색 후 끌어다 놓거나 눌러서 배치합니다*

   - 위쪽 **검색 (소파, 침대, 변기…)** 칸에 입력하면 목록이 좁혀지고, `Enter` 를 누르면 첫 항목이 골라집니다.
   - 분류 칩: **전체 · 거실 · 침실 · 식사 · 주방 · 욕실 · 사무실 · 실외 · 기타**. 맨 위에는 **최근 사용** 묶음이 생깁니다.
   - 가구를 고른 동안에는 클릭할 때마다 하나씩 놓입니다. 그만 놓으려면 `Esc`.
2. **회전.** 소파가 선택된 상태에서 `R` 을 누르면 90° 돌아갑니다. `Shift+R` 은 반대 방향으로 15° 씩 돌립니다. 놓기 전 미리보기도 `R` 로 돌릴 수 있습니다.
3. **검색해서 놓기.** `F` 를 누릅니다. **가구 — 이름을 입력하세요** 창이 열리면 `더블` 을 입력하고 **더블 침대**에서 `Enter`, 왼쪽 위 방 (2500, 1400) 을 클릭합니다.

![F 키: 가구를 이름으로 찾아 바로 배치합니다](docs/images/ko/furniture-picker.webp)

*F 키: 가구를 이름으로 찾아 바로 배치합니다*

4. **끌어서 옮기기.** `Esc` 로 선택 도구로 돌아와 소파를 위로 (7000, 3000) 까지 끕니다. 격자 반 칸 단위로 움직이고, `Shift` 를 누르면 가로·세로로만 움직입니다.
5. **속성 창.** 소파를 두 번 클릭합니다(또는 선택하고 `E`). 속성 창에서 **이름, 종류, 폭, 깊이, 높이, 바닥 높이, 회전, 색상**을 바꿀 수 있습니다. **확인**을 누릅니다.

![더블클릭(또는 E): 요소의 모든 속성을 한 창에서 고칩니다](docs/images/ko/properties-dialog.webp)

*더블클릭(또는 E): 요소의 모든 속성을 한 창에서 고칩니다*

### 팁
- 오른쪽 패널에서도 가구의 **X, Y, 회전, 폭, 깊이, 높이, 바닥 높이, 색상**을 바로 고칠 수 있고, **3D에서 보기** 단추로 3D 위치를 확인합니다.
- 가져온 3D 모델(OBJ, FBX, GLB …)도 가구처럼 라이브러리의 **가져온 3D 모델** 묶음에 나옵니다(레슨 15). 라이브러리 제목 오른쪽 단추가 **3D 모델 가져오기**입니다.
- `X` / `Y` 는 선택한 가구를 좌우 / 상하 대칭합니다.
- 가구가 벽에 박히거나 다른 가구와 겹치면 모델 검사가 경고합니다(레슨 13).

### 자주 하는 실수
- 클릭할 때마다 가구가 계속 생긴다: 가구 도구가 켜진 상태입니다. `Esc`.
- `R` 을 눌렀는데 아무 일도 없다: 가구가 선택되지 않았습니다. 먼저 클릭하세요.

### 확인
- [ ] 소파와 더블 침대가 놓였다.
- [ ] `R` 로 회전했다.
- [ ] 끌어서 옮기고 속성 창을 열었다.

## 레슨 6. 편집: 선택, 복사, 그룹, 되돌리기

### 목표
영역 선택, 복제와 삭제, 되돌리기 기록, 그룹, 크기 조정을 익힙니다. (프로그램 튜토리얼 레슨 6)

### 따라 하기

1. **영역 선택.** `Esc` 로 선택을 비웁니다. `Shift` 를 누른 채 건물 바깥 왼쪽 위 (-800, -800) 에서 시작해 침대를 감싸도록 (4200, 2800) 까지 끕니다.

![상자 선택: Shift+끌기(왼→오른쪽은 완전히 포함, 오른→왼쪽은 걸친 것)](docs/images/ko/select-box.webp)

*상자 선택: Shift+끌기(왼→오른쪽은 완전히 포함, 오른→왼쪽은 걸친 것)*

   - 왼쪽 → 오른쪽으로 끌면: 상자 안에 **완전히** 들어간 것만 선택됩니다.
   - 오른쪽 → 왼쪽으로 끌면: 상자에 **걸친** 것까지 선택됩니다.
   - 여러 개를 고르면 오른쪽 패널에 "항목 n개 선택됨" 과 **회전 / 대칭 / 복제 / 삭제 / 그룹 / 크기 조정…** 단추가 나옵니다. 벽만 여러 개 골랐으면 두께와 재료를 한꺼번에 바꿀 수 있습니다.
2. **복제와 삭제.** `Ctrl+D` 로 복제한 다음 `Del` 로 지웁니다.
   - `Ctrl+C` / `Ctrl+V` 는 복사 / 붙여넣기, `Ctrl+X` 는 잘라내기, `Ctrl+A` 는 지금 층 모두 선택.
   - 빈 곳을 오른쪽 클릭 → **붙여넣기** 는 클릭한 위치에 붙여 넣습니다.
3. **되돌리기 기록.** **편집 → 되돌리기 기록…** 을 엽니다. 지금까지의 작업이 최신 것부터 나열됩니다. 줄을 클릭하면 그 단계 **이전까지** 한 번에 되돌립니다. 지금은 보기만 하고 창을 닫으세요.

![되돌리기 기록: 지난 작업 목록에서 원하는 시점으로 돌아갑니다](docs/images/ko/undo-history.webp)

*되돌리기 기록: 지난 작업 목록에서 원하는 시점으로 돌아갑니다*

4. **그룹 만들기.** 소파 (7000, 3000) 을 클릭하고, `Shift` 를 누른 채 침대 (2500, 1400) 을 클릭해 둘을 함께 고른 뒤 `Ctrl+G`. "항목 2개를 그룹으로 묶었습니다…" 알림이 뜹니다. 이제 `Esc` 후 소파만 클릭해도 침대까지 함께 선택되고 함께 움직입니다.
   - 그룹 안의 하나만 고르려면 `Alt`+클릭.
5. **그룹 풀기.** 그룹이 선택된 상태에서 `Ctrl+Shift+G`(**편집 → 그룹 해제**).
6. **크기 조정.** 침대만 클릭하고 **편집 → 크기 조정…** 에서 `0.9` 를 입력하고 **확인**. 침대가 90 % 크기가 됩니다(가구는 높이까지). `50%` 처럼 퍼센트로 입력해도 됩니다.

### 편집 메뉴 한눈에 보기

| 명령 | 키 | 설명 |
|---|---|---|
| 되돌리기 / 다시 실행 | `Ctrl+Z` / `Ctrl+Y` (`Ctrl+Shift+Z`) | 도구 모음 ↶ ↷ 단추, 오른쪽 클릭 메뉴 맨 위에도 있음 |
| 되돌리기 기록… | | 여러 단계를 한 번에 |
| 잘라내기 / 복사 / 붙여넣기 / 복제 / 삭제 | `Ctrl+X` / `Ctrl+C` / `Ctrl+V` / `Ctrl+D` / `Del` | |
| 모두 선택 | `Ctrl+A` | 지금 층의 모든 요소 |
| 찾기… | `Ctrl+F` | 방, 문, 창문, 가구, 텍스트, 층을 찾아 그곳으로 이동 |
| 90° 회전 | `R` (`Shift+R` 반대로 15°) | |
| 좌우 대칭 / 문 뒤집기 | `X` | 문이면 열림 방향 뒤집기 |
| 상하 대칭 | `Y` | |
| 크기 조정… | | 배율(1.5, 50%) |
| 간격 띄우기… | | 방, 매스, 지붕, 닫힌 선을 거리만큼 키우거나(+) 줄임(−) |
| 그룹 / 그룹 해제 | `Ctrl+G` / `Ctrl+Shift+G` | |
| 속성… | `E` 또는 두 번 클릭 | 아무것도 고르지 않았으면 프로젝트 속성 |

### 팁
- 그룹에 속한 요소를 선택하면 오른쪽 패널에 "그룹의 일부(n개 항목). Alt+클릭으로 하나만 선택합니다." 와 **그룹 해제** 단추가 나옵니다.
- 작업할 때마다 되돌리기 단계가 하나씩 쌓입니다. 숫자 칸을 + 로 여러 번 누르면 단계도 여러 개 생깁니다.

### 자주 하는 실수
- `Shift`+끌기로 상자를 그렸는데 아무것도 선택되지 않는다: 왼쪽→오른쪽으로 끌면 완전히 들어간 것만 잡힙니다. 오른쪽→왼쪽으로 끌어 보세요.
- `Ctrl+G` 를 눌렀더니 "그룹으로 묶을 항목을 두 개 이상 선택하세요.": 하나만 선택되어 있습니다.

### 확인
- [ ] 영역 선택의 두 방향 차이를 안다.
- [ ] 복제·삭제·되돌리기 기록을 써 봤다.
- [ ] 그룹을 만들고 풀었다.
- [ ] 크기 조정으로 침대를 줄였다.

## 레슨 7. 치수, 텍스트, 그리드, 선

### 목표
자동 치수와 직접 치수, 텍스트, 측정, 구조 그리드, CAD 선을 그립니다. (프로그램 튜토리얼 레슨 7)

### 따라 하기

1. **자동 치수.** **빌드 → 외벽 치수 넣기**를 누릅니다. 건물 바깥에 전체 길이와 벽 사이 치수가 두 줄로 그려지고 "건물 둘레에 치수를 넣었습니다." 가 뜹니다.
2. **치수 직접 넣기.** `K` 를 누르고(도구 모음의 **치수** 단추) (0, 6000) 과 (5000, 6000) 을 클릭한 뒤, 마우스를 아래로 내려 (2500, 7000) 을 클릭합니다. 세 번째 클릭이 치수선의 위치(간격)입니다. `Esc`.
3. **텍스트.** `T` 를 누르고(도구 모음의 **텍스트** 단추) (500, 7600) 을 클릭해 `현관` 을 입력하고 `Enter`, `Esc`.

![치수(K)·글자(T)·선(L)·줄자(M): 자동 치수는 바깥 벽을 한 번에 잽니다](docs/images/ko/dimensions-text.webp)

*치수(K)·글자(T)·선(L)·줄자(M): 자동 치수는 바깥 벽을 한 번에 잽니다*

4. **거리 재기.** `M` 을 누르고(도구 모음의 **측정** 단추) 대각선 모서리 (0, 0) 과 (9000, 6000) 을 클릭합니다. 거리(약 10817 mm)가 표시됩니다. 도면에는 남지 않습니다. `Esc` 로 지웁니다.
5. **구조 그리드.** `G` 를 누르고(도구 모음의 **그리드 선** 단추) 각 선의 양 끝을 클릭합니다.
   - (0, -1500) → (0, 7500): 세로선 **1**
   - (9000, -1500) → (9000, 7500): 세로선 **2**
   - (-1500, 0) → (10500, 0): 가로선 **A**
   - `Esc`.

![구조 그리드(G): A, B, C … / 1, 2, 3 … 그리드 선과 버블](docs/images/ko/grids.webp)

*구조 그리드(G): A, B, C … / 1, 2, 3 … 그리드 선과 버블*

   세로선은 1, 2, 3 …, 가로선은 A, B, C … 로 자동 번호가 붙고, 그리드는 **모든 층에** 나타납니다. 번호는 오른쪽 패널 **레이블**에서 바꿉니다. 선이 500 mm 보다 짧으면 만들어지지 않습니다.
6. **CAD 선.** `L` 을 누르고(도구 모음의 **선** 단추) (10500, 2000), (12000, 2000), (12000, 3500) 을 클릭한 뒤 `Enter`, `Esc`. 선은 CAD 레이어에 그려지고 DXF 로 내보내집니다.

### 팁
- 치수를 선택하면 오른쪽 패널에서 **간격 띄우기**(치수선 거리)와 **텍스트 재정의**(숫자 대신 보일 글)를 바꿉니다.
- 텍스트는 **크기, 회전, 정렬(왼쪽·중앙·오른쪽)** 을 바꿀 수 있고, 여러 줄도 됩니다.
- 선은 처음 점을 다시 클릭하면 닫힌 도형이 됩니다. 어느 레이어에 그릴지는 왼쪽 **CAD 레이어** 패널에서 레이어 줄을 클릭해 정합니다(레슨 14).
- 빈 곳 오른쪽 클릭 → **자동 치수**, **그리드 선**도 됩니다.
- 치수 표시는 **보기 → 치수 표시**로 켜고 끕니다.

### 자주 하는 실수
- 치수가 두 점 사이에 바로 붙어 버린다: 세 번째 클릭(치수선 위치)을 두 점과 같은 곳에 했습니다. 마우스를 떨어뜨린 뒤 클릭하세요.
- `G` 를 눌렀는데 격자가 꺼졌다 켜졌다 한다: 3D 보기에서는 `G` 가 **3D 격자** 켜기/끄기입니다. 평면도(`F2`)에서 누르세요.

### 확인
- [ ] 자동 치수와 직접 치수가 있다.
- [ ] "현관" 텍스트가 있다.
- [ ] 측정으로 대각선 길이를 쟀다.
- [ ] 그리드 1, 2, A 가 있다.
- [ ] CAD 선을 하나 그렸다.

## 레슨 8. 층과 계단

### 목표
계단을 놓고 위층을 추가하고 층 속성을 바꿉니다. (프로그램 튜토리얼 레슨 8)

### 따라 하기

1. **계단.** `S` 를 누르고(도구 모음의 **계단** 단추) 거실 아래쪽의 (5600, 5350) 을 클릭(계단 시작, 아래쪽 끝)한 다음 (8600, 5350) 을 클릭(계단 끝, 위쪽 끝)합니다. `Esc`. 단 수는 층 높이에 맞춰 자동으로 정해집니다.

![계단(S)과 기둥(C): 계단은 두 점으로, 기둥은 한 번 클릭으로 놓습니다](docs/images/ko/stairs-columns.webp)

*계단(S)과 기둥(C): 계단은 두 점으로, 기둥은 한 번 클릭으로 놓습니다*

   계단을 선택하면 오른쪽 패널에 "n단 · 단높이 r mm · 단너비 g mm" 가 나오고 **단 수, 폭, 길이, 회전, 재료**를 바꿀 수 있습니다. 단높이가 200 mm 를 넘으면 "챌판이 200 mm를 넘으면 가파릅니다. 단을 늘리세요." 경고가 뜹니다.
2. **위층 추가.** 도면 왼쪽 아래 층 탭 맨 위의 **+** 를 누릅니다(**빌드 → 맨 위에 층 추가**). "… m 높이에 층 2F을(를) 추가했습니다." 가 뜨고 2F 탭으로 바뀝니다. 맨 위층의 벽(안쪽 칸막이 벽 포함)과 창문이 복사됩니다. 문은 복사되지 않습니다.
3. **층 속성.** **빌드 → 층 속성…** 을 엽니다. **이름, 바닥 높이(FL), 높이(층고), 바닥 슬래브** 두께를 바꿀 수 있습니다. **확인**.
4. **아래층으로.** 층 탭의 **1F** 를 누릅니다.

### 층 다루기

| 하는 일 | 방법 |
|---|---|
| 층 선택 | 층 탭 클릭 |
| 이름 바꾸기 | 층 탭 두 번 클릭 → 입력 → `Enter` |
| 층 속성 | 층 탭 오른쪽 클릭 → **층 속성…**, **빌드 → 층 속성…**, 상태 표시줄의 층 이름 칸 클릭, 또는 아무것도 선택하지 않은 상태의 오른쪽 패널 |
| 층 복제 (벽, 문, 창문, 방까지) | 층 탭 오른쪽 클릭 → **층 복제(벽, 문, 창문)** |
| 층 삭제 | 층 탭 오른쪽 클릭 → **층 삭제** (그 층의 모든 요소가 지워짐, 확인 창이 뜸) |
| 되돌리기 / 다시 실행 | 층 탭 오른쪽 클릭 메뉴 맨 위 |

### 팁
- 층 탭에는 층 이름과 바닥 높이(예: `2F  3.00 m`)가 함께 보입니다. 아래층은 흐리게 겹쳐 보이며 **보기 → 아래층 표시**로 끌 수 있습니다.
- 벽은 자기 높이를 따로 정하지 않으면 층 높이를 씁니다. 층을 위아래로 옮기면 그 층의 모든 것이 3D 에서 함께 움직입니다.

### 자주 하는 실수
- 위층 추가 후 문이 없다: 정상입니다. 창문만 위층에 반복되고, 문은 직접 넣어야 합니다.
- 맨 위층에 계단을 놓으면 "맨 위층의 계단이 어디로도 이어지지 않습니다." 경고가 뜹니다.

### 확인
- [ ] 1층에 계단이 있다.
- [ ] 2F 층이 생겼다.
- [ ] 층 속성 창을 열어 봤다.

## 레슨 9. 지붕과 기둥

### 목표
맨 위층에 지붕을 자동으로 올리고 모양을 바꾸고, 기둥을 놓습니다. (프로그램 튜토리얼 레슨 9)

### 따라 하기

1. **지붕 자동 생성.** **빌드 → 맨 위층 지붕**을 누릅니다. 맨 위층(2F) 외벽 윤곽 위에 박공지붕이 올라가고 지붕이 선택됩니다.

![지붕(O): 맨 위층 위에 박공·모임·외쪽·평지붕을 얹습니다](docs/images/ko/roof-plan.webp)

*지붕(O): 맨 위층 위에 박공·모임·외쪽·평지붕을 얹습니다*

2. **모임지붕으로.** 지붕이 선택된 상태에서 오른쪽 패널 **모양**을 **모임**으로 바꿉니다.

   | 항목 | 값 |
   |---|---|
   | **모양** | 박공 · 모임 · 외쪽 · 평 |
   | **경사** | 0–75°, 5° 단위 |
   | **처마 내밀기** | 벽 밖으로 나오는 길이 |
   | **두께** | 지붕 두께 |
   | **용마루 방향** | 긴 변을 따라 / 가로질러 |
   | **재료** | 지붕 기와, 금속 지붕, 슬레이트 … |

3. **기둥.** 1F 탭을 누르고 `C` 를 누른 뒤(도구 모음의 **기둥** 단추) 오른쪽 아래 모서리 (9000, 6000) 을 클릭합니다. 기둥은 벽 모서리에 달라붙습니다. `Esc`. 오른쪽 패널에서 **모양(사각형/원형), 폭, 깊이, 회전, 재료**를 바꿉니다.
4. `F3` 을 눌러 지붕을 3D 로 확인하고 `F2` 로 돌아옵니다.

![지붕과 2층이 3D 로 바로 만들어집니다](docs/images/ko/roof-3d.webp)

*지붕과 2층이 3D 로 바로 만들어집니다*

### 팁
- `O` 는 지붕 도구입니다. 건물 안을 클릭하면 그 윤곽에 지붕을, `Shift`+클릭으로 지붕 윤곽을 직접 찍고 `Enter` 로 끝냅니다.
- 새 지붕의 기본 모양은 **설정 → 평면도 → 새 지붕**에서 정합니다.
- 평면에서 지붕은 점선으로 표시됩니다(**설정 → 평면도 → 지붕 (점선)**).

### 자주 하는 실수
- "맨 위층에 닫힌 벽 윤곽이 없습니다.": 맨 위층 외벽이 닫혀 있지 않습니다. 위층을 추가하지 않았다면 1층에 지붕이 올라갑니다.
- 기둥이 문이나 창문을 막으면 "간섭: 기둥이 …을(를) 막고 있습니다." 경고가 납니다.

### 확인
- [ ] 2F 위에 모임지붕이 있다.
- [ ] 1F 오른쪽 아래 모서리에 기둥이 있다.

## 레슨 10. 3D 보기 기본

### 목표
3D 보기의 화면, 탐색, 시점, 3D 그리드, 오른쪽 클릭 메뉴, 평면과의 상호 선택을 익힙니다. (프로그램 튜토리얼 레슨 1, 13)

### 3D 도구 모음

`F3` 을 누르면 도구 모음이 3D 용으로 바뀝니다.

| 묶음 | 단추 |
|---|---|
| 탐색 | **궤도 회전** · **이동 (P)** · **걷기 (V)** |
| 스케치업 도구 | **밀기/끌기** · **페인트 통** · **줄자** (레슨 11) |
| 시점 | **등각(1) · 위(2) · 정면(3) · 배면(4) · 좌측면(5) · 우측면(6) · 조감도(7)** |
| 표시 | **직교 투영 (O)** · **정면 입면** · **현재 층에서 단면 (X)** · **문 열기** · **가구** · **지붕** · **안개** |
| 스타일 | **스타일** 목록: 사실적 · 흰색 모형 · 선 그림 · X-레이 |
| 보조 | **격자 (G)** · **건물 치수** · **화면에 맞추기** |
| 출력 | **3D 이미지 저장 (PNG)…** · **3D 모델 내보내기** |

메뉴 막대에는 **3D** 메뉴가 없습니다. 3D 명령은 모두 위 3D 도구 모음에 있고, 장면 추가·장면 애니메이션 재생은 3D 보기 왼쪽의 **장면** 패널에 있습니다.

### 따라 하기

1. `F3` 을 누릅니다. 처음에는 등각 시점으로 건물 전체가 보입니다.
2. **회전·이동·확대.** 왼쪽 끌기로 돌리고, 오른쪽 끌기로 옮기고, 휠로 확대합니다. 모델 위를 **두 번 클릭**하면 그 점으로 다가갑니다.
3. **시점.** 숫자 키 `2` 를 눌러 위에서 본 시점, `1` 을 눌러 등각으로 돌아옵니다. 도구 모음의 **위**, **등각** 단추도 같습니다.
4. **키보드로 돌리기.** 화살표 키는 7.5° 씩 회전, `Shift`+화살표는 이동합니다.
5. **이동 모드.** `P` 를 누르면 왼쪽 끌기가 이동이 됩니다(오른쪽 끌기는 회전). 다시 `P` 또는 `Esc` 로 궤도 회전으로 돌아옵니다.
6. **3D 그리드.** 지면에 그려진 격자를 확대·축소하며 봅니다.

![3D 그리드: 2D 처럼 5칸마다 또렷한 선(5×5), 확대·축소해도 같은 간격으로 보입니다](docs/images/ko/grid-3d.webp)

*3D 그리드: 2D 처럼 5칸마다 또렷한 선(5×5), 확대·축소해도 같은 간격으로 보입니다*

   - 평면도의 격자처럼 **5칸마다 또렷한 선**이 있어 5 × 5 블록으로 보입니다.
   - 확대·축소하면 칸 크기가 ×5 / ÷5 로 바뀌어(… 0.2 m, 1 m, 5 m, 25 m …) 화면에서는 늘 비슷한 간격으로 보입니다. 또렷한 선은 너무 진하지 않은 1.5 px 로, 화면에서 일정합니다.
   - 격자는 카메라가 바라보는 곳을 중심으로 다시 그려집니다.
   - `G` 또는 도구 모음 **격자 (G)**, 왼쪽 **표시 → 격자**로 켜고 끕니다. 단위는 **설정 → 3D 보기 → 3D 측정 단위**(미터/피트), 시작할 때 켤지는 **시작 시 표시 → 축척 표시 격자**에서 정합니다.
7. **오른쪽 클릭 메뉴.** 모델 위에서 오른쪽 버튼을 **끌지 않고** 클릭합니다.

![3D 오른쪽 클릭 메뉴: 되돌리기/다시 실행, 보기 방향, 도구](docs/images/ko/context-menu-3d.webp)

*3D 오른쪽 클릭 메뉴: 되돌리기/다시 실행, 보기 방향, 도구*

   맨 위에 (요소를 집었다면) **평면에서 보기**, 그 아래 **되돌리기 / 다시 실행**, 그리고 시점, 걷기, 단면, 직교 투영, 문 열기, 밀기/끌기, 페인트 통, 줄자, 장면 추가, 3D 이미지 저장이 있습니다.
8. **3D 에서 선택.** 도구 모음 **궤도 회전**이 켜진 상태에서 오른쪽 외벽 (9000, 3000) 쯤을 클릭합니다. 오른쪽 패널에 "벽 · 1F · 높이 …" 와 **평면에서 보기 / 속성…** 단추가 나옵니다. `F2` 를 누르면 평면에서도 그 벽이 선택되어 있습니다. 반대로 평면에서 고른 것은 3D 에서 강조됩니다.

### 팁
- 왼쪽 **층** 패널의 체크를 끄면 그 층을 3D 에서 숨깁니다. 위층을 숨기면 아래층 내부가 보입니다.
- 왼쪽 **표시** 패널: 가구, 지붕, 매스 모델, 문 열기, 지면, 격자, 축, 건물 치수, 방향 표시기, 안개.
- 왼쪽 아래 작은 정보 줄은 "메시 n개 · 삼각형 nk개" 입니다. 상태 표시줄에도 삼각형 수가 나옵니다.
- 평면과 3D 의 상호 선택은 **설정 → 평면도 → 평면·3D 연동 선택**에서 끌 수 있습니다.

### 자주 하는 실수
- 오른쪽 클릭했는데 메뉴가 안 나온다: 마우스가 조금이라도 움직이면 이동(팬)으로 처리됩니다. 가만히 클릭하세요.
- 3D 가 텅 비어 보인다: 왼쪽 **층** 체크가 모두 꺼졌거나 단면 높이가 너무 낮습니다. `Home` 으로 화면에 맞추세요.

### 확인
- [ ] 1–7 키로 시점을 바꿨다.
- [ ] 3D 그리드가 5칸마다 또렷한 선이고 확대해도 간격이 유지된다.
- [ ] 3D 에서 클릭한 벽이 평면에서도 선택된다.

## 레슨 11. 매스 모델링 (스케치업 방식)

### 목표
평면에서 매스(상자, 원기둥, 다각형)를 그리고, 3D 에서 밀기/끌기, 페인트 통, 줄자, 장면을 씁니다. (프로그램 튜토리얼 레슨 10)

### 따라 하기

1. `F2` 로 평면도로 가서 집 오른쪽 빈 곳이 보이도록 화면을 옮깁니다.
2. **매스 상자.** `B` 를 누르고(도구 모음의 **매스 상자** 단추) 마주 보는 두 모서리 (11000, 1000) 과 (14000, 4000) 을 클릭합니다. `Esc`.
3. **높이와 테이퍼.** 매스 (12500, 2500) 을 클릭합니다. 오른쪽 패널의 **높이** + 를 누르면 100 mm 씩 높아집니다.

   | 항목 | 설명 |
   |---|---|
   | **이름** | 매스 이름 |
   | **높이** | 매스 높이 (기본 3000 mm) |
   | **기준 높이** | 바닥에서 띄우는 높이 (위에 쌓을 때) |
   | **테이퍼** | 위쪽 크기 비율. 100 % = 그대로, 0 % = 피라미드·원뿔 |
   | **재료** | 벽·지붕 재료 |
   | **3D에서 밀기/끌기** | 3D 로 가서 밀기/끌기 도구를 켬 |

4. **원기둥 매스.** `U` 를 누르고(도구 모음의 **매스 원기둥** 단추) 중심 (12500, 6500) 과 원 위의 점 (13500, 6500) 을 클릭합니다. `Esc`.
5. **다각형 매스.** 도구 모음의 **매스 다각형** 단추(세 번째 매스 단추, 단축키 없음)를 고르고 모서리를 차례로 클릭한 뒤 `Enter` 또는 첫 점을 클릭하면 그 모양대로 솟아오릅니다. (튜토리얼에는 없는 단계이니 원하는 모양으로 해 보세요.)

![매스(B 상자 · U 원기둥 · 다각형): 평면에서 그리고 높이·테이퍼를 정합니다](docs/images/ko/massing-plan.webp)

*매스(B 상자 · U 원기둥 · 다각형): 평면에서 그리고 높이·테이퍼를 정합니다*

6. **밀기/끌기.** `F3` 으로 3D 에 가서 도구 모음 **밀기/끌기**를 누릅니다. 상자 매스의 **윗면**을 잡고 위로 끕니다. 50 mm 단위로 높이가 바뀌며 힌트에 "높이: n.nn m" 가 표시됩니다. 벽의 윗면도 같은 방법으로 높이를 바꿀 수 있습니다. 놓으면 되돌리기 한 단계로 기록됩니다.

![밀기/끌기: 매스나 벽의 윗면을 위아래로 끌어 높이를 바꿉니다](docs/images/ko/pushpull.webp)

*밀기/끌기: 매스나 벽의 윗면을 위아래로 끌어 높이를 바꿉니다*

7. **페인트 통.** 도구 모음 **페인트 통**을 누릅니다. 왼쪽에 재료 견본(팔레트)이 나타납니다. **벽돌**을 고르고 상자 매스의 옆면을 클릭합니다. 벽, 방 바닥, 지붕, 매스, 가구(색)를 칠할 수 있습니다(문·창문은 칠해지지 않습니다).

![페인트 통: 왼쪽 팔레트에서 재료를 고르고 벽·바닥·지붕·매스를 클릭합니다](docs/images/ko/paint-bucket.webp)

*페인트 통: 왼쪽 팔레트에서 재료를 고르고 벽·바닥·지붕·매스를 클릭합니다*

8. **줄자.** 도구 모음 **줄자**를 누르고 매스 옆면 아래쪽의 두 점을 클릭합니다. 모델 위에 거리가 표시되고 "거리: n.nnn m" 알림이 뜹니다. `Esc` 로 지웁니다.

![줄자: 3D 모델 위 두 점 사이의 거리](docs/images/ko/tape-measure.webp)

*줄자: 3D 모델 위 두 점 사이의 거리*

9. **장면 저장과 재생.** `Esc` 로 도구를 끄고, 왼쪽 **장면** 패널의 **+**(장면 추가)를 누릅니다. "장면 1" 이 생깁니다. 숫자 `3` 으로 정면 시점으로 바꾸고 **+** 를 한 번 더 누릅니다. 이제 "장면 1" 을 누르면 카메라가 그 시점으로 날아가고, **▶**(장면 재생)를 누르면 장면을 차례로 계속 돌아봅니다. 다시 누르면 멈춥니다.

![장면: 지금 시점을 저장하고(+), 눌러서 이동하고, ▶ 로 차례로 재생합니다](docs/images/ko/scenes.webp)

*장면: 지금 시점을 저장하고(+), 눌러서 이동하고, ▶ 로 차례로 재생합니다*

### 이렇게 보여야 합니다
- 집 옆에 벽돌로 칠한 높은 상자와 원기둥이 서 있습니다.
- 장면 목록에 장면 1, 장면 2 가 있고 누르면 시점이 부드럽게 바뀝니다.

![매스 스터디 예제의 3D 모습](docs/images/ko/massing-3d.webp)

*매스 스터디 예제의 3D 모습*

### 팁
- 장면은 **카메라, 스타일, 단면, 단계 보기**를 함께 저장합니다. 선 그림 스타일의 입면 장면, 단면 장면을 따로 만들어 두면 발표 때 편합니다.
- 장면 줄의 ✕ 는 장면 삭제입니다.
- 매스는 평면에서 끌어 옮기고, `R` 로 돌리고, 편집 → **간격 띄우기…** 로 키우거나 줄일 수 있습니다. 여러 매스를 `Ctrl+G` 로 묶어 함께 움직이세요.
- 3D 도구를 다시 누르거나 `Esc` 를 누르면 도구가 꺼집니다.

### 자주 하는 실수
- 밀기/끌기로 끌었는데 화면만 돈다: 윗면이 아닌 옆면이나 빈 곳을 잡았습니다. 윗면을 잡으세요.
- 페인트 통이 칠해지지 않는다: 문·창문은 칠할 수 없습니다. 걷기 모드에서는 도구가 꺼집니다.
- ▶ 를 눌렀더니 "먼저 장면을 추가하세요…": 장면이 하나도 없습니다.

### 확인
- [ ] 매스 상자와 원기둥을 만들었다.
- [ ] 밀기/끌기로 높이를 바꿨다.
- [ ] 페인트 통으로 벽돌을 칠했다.
- [ ] 줄자로 쟀다.
- [ ] 장면 두 개를 만들고 재생했다.

## 레슨 12. 스타일, 단면, 입면, 걷기, 일조 분석

### 목표
표현 스타일, 단면, 직교 투영과 입면, 1인칭 걷기, 일조 분석을 익힙니다. (프로그램 튜토리얼 레슨 13)

### 따라 하기

1. **표현 스타일.** 도구 모음의 **스타일** 목록을 **흰색 모형**, **선 그림**, **X-레이** 로 차례로 바꿔 보고 **사실적**으로 돌아옵니다. 왼쪽 **단면과 단계 → 렌더 스타일**도 같습니다.

![표현 스타일: 흰색 모형](docs/images/ko/style-white.webp)

*표현 스타일: 흰색 모형*

![표현 스타일: 선 그림](docs/images/ko/style-lines.webp)

*표현 스타일: 선 그림*

![표현 스타일: X-레이](docs/images/ko/style-xray.webp)

*표현 스타일: X-레이*

2. **단면.** `X` 를 누릅니다(도구 모음 **현재 층에서 단면 (X)**). 평면도에서 고른 층의 바닥에서 1.2 m 위가 잘려 3D 평면처럼 보입니다. 왼쪽 **단면과 단계 → 절단 높이**를 − / + 로 100 mm 씩 바꿀 수 있습니다. `X` 를 한 번 더 누르면 단면이 사라집니다.

![단면(X): 지금 층을 바닥에서 1.2 m 높이로 잘라 내부를 보여 줍니다](docs/images/ko/section-cut.webp)

*단면(X): 지금 층을 바닥에서 1.2 m 높이로 잘라 내부를 보여 줍니다*

3. **직교 투영과 입면.** 도구 모음의 **정면 입면** 단추를 누릅니다. 직교 투영 + 선 그림 스타일 + 정면 시점이 한 번에 켜져 입면도가 됩니다. `O` 로 직교 투영을 끄고, 스타일을 **사실적**으로, `1` 로 등각으로 돌아옵니다.

![정면도: 평행 투영(O)으로 입면을 그대로 봅니다](docs/images/ko/elevation-ortho.webp)

*정면도: 평행 투영(O)으로 입면을 그대로 봅니다*

   - 다른 방향 입면: `O` 를 켠 뒤 `4`(배면), `5`(좌측면), `6`(우측면).
   - 상태 표시줄에 **원근 투영** / **평행 투영** 이 표시되고, 눌러서 바꿀 수 있습니다.
4. **걸어서 둘러보기.** `V` 를 누릅니다(도구 모음 **걷기 (V)**). 가장 낮은 보이는 층에서 눈높이 1.6 m 로 서게 됩니다.

![걷기(V): 사람 눈높이에서 W/A/S/D 로 걸어 다닙니다](docs/images/ko/walk-mode.webp)

*걷기(V): 사람 눈높이에서 W/A/S/D 로 걸어 다닙니다*

   | 키 / 동작 | 하는 일 |
   |---|---|
   | `W` / `S` 또는 `↑` / `↓` | 앞 / 뒤로 걷기 |
   | `A` / `D` | 왼쪽 / 오른쪽 옆걸음 |
   | `←` / `→` | 제자리에서 돌기 |
   | `E` / `Q` (`PgUp` / `PgDn`) | 올라가기 / 내려가기 |
   | `Shift` | 달리기 |
   | 끌기 | 둘러보기 |
   | 휠 | 앞뒤로 한 걸음씩 |
   | `Esc` | 걷기 끝 (궤도 회전으로) |

5. **일조 분석.** 왼쪽 **일조 분석** 패널의 **대지·날짜·시각으로 해 위치**를 켭니다. **월, 일, 시각**(30분 단위)이 나타나고, 그 아래에 "위도°, 경도° · 방위각 · 고도 · 일출 · 일몰" 이 표시됩니다. 시각을 바꾸면 그림자가 실제처럼 움직입니다. 확인했으면 다시 끕니다.

![태양 분석: 대지 위치와 날짜·시각으로 실제 그림자를 봅니다](docs/images/ko/sun-study.webp)

*태양 분석: 대지 위치와 날짜·시각으로 실제 그림자를 봅니다*

   - 끈 상태에서는 **태양 방위각 / 태양 고도**를 직접 정합니다.
   - **대지 위치…** 단추(또는 **BIM → 대지 위치 (일조 분석)…**)는 **프로젝트 속성** 창을 엽니다. 여기서 **위도, 경도, 시간대 (UTC+), 북쪽**(도면의 북쪽 방향)을 정합니다. 기본값은 서울(37.57°, 126.98°, UTC+9)입니다.

![프로젝트 속성: 제목·주소·대지 위도/경도·시간대·분류 체계](docs/images/ko/project-properties.webp)

*프로젝트 속성: 제목·주소·대지 위도/경도·시간대·분류 체계*

   프로젝트 속성에는 그 밖에 **제목, 건축주, 주소, 작성자, 회사, 개정, 날짜, 도면 축척, 분류 체계, 설명**이 있으며 인쇄할 때 표제란에 쓰입니다.

### 그 밖의 3D 옵션
- **문 열기**: 3D 에서 문짝을 열어 보여 줍니다.
- **안개**: 먼 곳을 흐리게.
- **건물 치수**: 건물 외곽 치수를 3D 에 표시.
- **3D 이미지 저장 (PNG)…**: 지금 화면을 PNG 로 저장.
- 설정 → 3D 보기: **3D 배경(하늘/테마 색), 3D 그림자, 시야각, 회전 속도**.

### 자주 하는 실수
- `X` 를 눌렀는데 평면도에서 문 방향이 바뀌었다: 평면도에서는 `X` 가 대칭/문 뒤집기입니다. 3D(`F3`)에서 누르세요. `O`, `G`, `V` 도 3D 와 평면에서 뜻이 다릅니다.
- 일조 분석 시각에 해가 안 보인다: 그 시각에 해가 지평선 아래입니다(고도 "<0").

### 확인
- [ ] 네 가지 스타일을 바꿔 봤다.
- [ ] 단면을 켜고 높이를 바꿨다.
- [ ] 정면 입면을 만들었다.
- [ ] 걷기로 집 안을 돌아다녔다.
- [ ] 일조 분석으로 그림자를 움직였다.

## 레슨 13. BIM: 벽 타입, 속성, 단계, 집계, 모델 검사

### 목표
다층 벽 타입, BIM 속성, 시공 단계, 비슷한 요소 선택, 집계와 공사비, 모델 검사를 익힙니다. (프로그램 튜토리얼 레슨 11, 12)

![BIM 메뉴](docs/images/ko/menu-bim.webp)

*BIM 메뉴*

**BIM** 메뉴: **벽 타입…, 선택 요소의 BIM 속성…, 비슷한 요소 선택, 공사비…, 대지 위치 (일조 분석)…, IFC 내보내기(BIM)…, IFC 가져오기(BIM)…**

### 따라 하기

1. **벽 타입.** `F2` 로 평면도에 가서 **BIM → 벽 타입…** 을 엽니다. 왼쪽에 타입 목록(이름 · 두께 · 레이어 수 · 쓰는 벽 수), 오른쪽에 고른 타입의 레이어 표가 있습니다.

![벽 타입: 재료 층(구조·단열·마감)으로 두께를 정하고 벽에 지정합니다](docs/images/ko/wall-types.webp)

*벽 타입: 재료 층(구조·단열·마감)으로 두께를 정하고 벽에 지정합니다*

   - 레이어마다 **용도**(마감·단열재·구조·공기층), **재료**, **두께**를 정합니다. 레이어 순서는 바깥 → 안이고, 위의 색 띠가 단면 모양을 보여 줍니다. **두께는 레이어의 합**입니다.
   - **새 타입 / 복제 / 삭제**, **레이어 추가**, 위로 이동(↑), 레이어 삭제. **외벽** 체크.
   - 지금은 둘러보고 **확인**을 누릅니다.
2. **벽에 타입 지정.** 1F 의 위쪽 벽 중 창문이 없는 (4400, 0) 을 클릭하고, 오른쪽 패널 **벽 타입**에서 벽돌 벽 타입을 고릅니다. 두께가 300 mm 로 바뀌고 평면에 레이어 경계선이 그려집니다.
   - 새로 그리는 벽에 타입을 미리 정하려면, 아무것도 선택하지 않은 상태의 오른쪽 패널 **새 항목 → 벽 타입**.
3. **BIM 속성.** 그 벽이 선택된 상태에서 **BIM → 선택 요소의 BIM 속성…** 을 엽니다. **속성 추가**를 누르고 **속성** 칸에 `FireRating`, **값** 칸에 `REI 60` 을 입력한 뒤 **확인**. 속성 이름은 FireRating, AcousticRating, ThermalTransmittance, LoadBearing, Manufacturer, Model, Cost, Mark, Comments 중에서 고를 수도 있습니다.

![BIM 속성 창: 고른 요소에 내화 등급 같은 속성을 붙입니다](docs/images/ko/bim-properties.webp)

*BIM 속성 창: 고른 요소에 내화 등급 같은 속성을 붙입니다*

   - 여러 요소를 고르고 열면 "속성이 선택한 요소 n개 모두에 기록됩니다."
   - IFC 로 내보낼 때 속성 세트 `MyArchitecture_Properties` 로 들어갑니다. `true` / `false` 와 숫자는 그 형식으로 저장됩니다.
4. **시공 단계.** 가운데 칸막이 벽 (5000, 4000) 을 클릭하고 오른쪽 패널 **BIM → 단계**를 **철거**로 바꿉니다. 벽이 빨간 점선으로 바뀝니다.

![BIM 속성: 단계, 분류 코드, IFC 클래스, GlobalId, 사용자 속성](docs/images/ko/bim-inspector.webp)

*BIM 속성: 단계, 분류 코드, IFC 클래스, GlobalId, 사용자 속성*

   - **단계**: 신축(기본) · 기존(옅게) · 철거(빨간 점선).
   - **분류**: Uniclass 2015 같은 분류 코드(분류 체계 이름은 프로젝트 속성에서).
   - **IFC 클래스**(IfcWall 등)와 **GlobalId** 는 읽기 전용이며, GlobalId 를 클릭하면 복사됩니다.
   - 새로 그리는 요소의 단계는 오른쪽 패널 **새 항목 → 단계**에서 정합니다.
   - **보기 → 단계: 새 설계**를 누르면 철거 벽이 사라진 공사 후 모습, **단계: 기존 건물**은 공사 전 모습, **단계: 모두 보기**는 전부를 보여 줍니다. 3D 의 **단면과 단계 → 단계**도 같습니다.
   - 확인했으면 `Ctrl+Z` 로 철거를 되돌립니다.

![단계: 기존(회색)·철거(빨간 점선)·신축 벽을 함께 그리고, 보기 → 단계 로 전후를 비교합니다](docs/images/ko/bim-renovation.webp)

*단계: 기존(회색)·철거(빨간 점선)·신축 벽을 함께 그리고, 보기 → 단계 로 전후를 비교합니다*

5. **비슷한 요소 선택.** 오른쪽 외벽 (9000, 3000) 을 클릭하고 **BIM → 비슷한 요소 선택**. 같은 종류·타입의 요소가 모두 선택되고 "비슷한 항목 n개를 선택했습니다." 가 뜹니다.
6. **집계와 수량, 공사비.** **빌드 → 집계와 수량…** 을 엽니다. (**BIM → 공사비…** 는 같은 창을 처음부터 **공사비** 탭으로 엽니다.)

![일람표: 방 · 문과 창 · 벽 타입 · 공사비 · 층 — CSV 로 내보냅니다](docs/images/ko/schedules.webp)

*일람표: 방 · 문과 창 · 벽 타입 · 공사비 · 층 — CSV 로 내보냅니다*

   | 탭 | 내용 |
   |---|---|
   | **방** | 층, 방, m², 둘레 (m), 바닥 |
   | **문과 창문** | 태그, 종류, 유형, 층, 폭, 높이, 창대 높이 |
   | **벽 타입** | 벽 타입, 두께, 레이어, 벽 수, 길이 (m), 벽 면적 (m²) |
   | **층** | 층별 벽 수·길이·면적, 방 수·면적, 총면적, 문·창문 수 |
   | **공사비** | 항목, 수량, 단위, 단가, 금액과 예상 합계 |

   **공사비** 탭을 누릅니다. 위쪽의 **벽 m²당, 바닥 m²당, 지붕 m²당, 문 개당, 창문 개당, 개구부 개당, 계단 개당, 기둥 개당** 단가를 바꾸면 금액이 바로 다시 계산되고, 창을 닫을 때 단가가 프로젝트에 저장됩니다.

![공사비 탭: 단가 × 수량으로 개략 공사비를 냅니다](docs/images/ko/schedules-cost.webp)

*공사비 탭: 단가 × 수량으로 개략 공사비를 냅니다*

   아래쪽 단추 **방 CSV… / 문·창문 CSV… / 벽 타입 CSV… / 공사비 CSV… / 층 CSV…** 로 엑셀에서 열 수 있는 CSV 를 저장합니다. 창 아래에는 전체 합계(방 면적, 연면적, 문·창문 수, 벽 길이와 부피)가 나옵니다.
7. **모델 검사 — 문제 만들어 보기.** 상태 표시줄의 **스냅 ✓** 를 눌러 스냅을 끄고, `W` 로 (1000, 4000) 에서 (1080, 4000) 까지 80 mm 짜리 아주 짧은 벽을 그린 뒤 `Esc`. 스냅을 다시 켭니다.
8. **검사 실행.** `F5` 를 누릅니다(**빌드 → 모델 검사**, 도구 모음 단추, 상태 표시줄 **검사** 칸). "모델 검사: 오류 n개, 경고 n개" 알림이 뜨고, 오른쪽 **모델 검사** 패널에 "벽 길이가 80 mm밖에 되지 않습니다." 가 나옵니다. 그 줄을 클릭하면 문제 위치로 확대됩니다.

![모델 검사(F5): 겹친 벽, 막힌 문, 간섭(가구·계단·기둥) 등을 찾고 눌러서 그곳으로 갑니다](docs/images/ko/model-check.webp)

*모델 검사(F5): 겹친 벽, 막힌 문, 간섭(가구·계단·기둥) 등을 찾고 눌러서 그곳으로 갑니다*

9. **고치기.** `Ctrl+Z` 로 짧은 벽을 없앱니다. 경고가 사라집니다.

### 모델 검사 항목

| 코드 | 검사 내용 |
|---|---|
| wall-short | 두께보다 짧은 벽 |
| wall-duplicate | 겹친 벽 |
| opening-outside | 벽 끝을 벗어난 개구부 |
| opening-overlap | 겹친 개구부 |
| opening-tall | 벽보다 높은 개구부 |
| door-blocked | 가구가 문 열림을 막음 |
| furniture-wall | 벽 안에 놓인 가구 |
| room-small | 아주 작은 방 |
| room-overlap | 겹친 방 |
| room-no-door | 문이나 개구부가 없는 방 |
| stair-top | 맨 위층의 계단 |
| clash-furniture | 간섭: 가구끼리 |
| clash-stair | 간섭: 계단과 벽 |
| clash-column | 간섭: 문이나 창문 안의 기둥 |

### 팁
- 모델 검사는 그리는 동안에도 자동으로 돌며(**설정 → 평면도 → 그리는 동안 모델 검사 실행**), 평면도 탭과 상태 표시줄에 개수가 표시됩니다. 패널 제목의 ↻ 는 다시 실행입니다.
- 오른쪽 패널을 접어 두어도 접힌 레일에 오류·경고 개수 배지가 보입니다.

### 자주 하는 실수
- BIM 속성 창이 "먼저 요소를 하나 이상 선택하세요." 하고 안 열린다: 선택이 없거나 치수·텍스트·선·밑그림만 골랐습니다.
- 벽 두께를 직접 바꾸면 벽 타입이 "(타입 없음)" 으로 풀립니다. 타입을 유지하려면 벽 타입 창에서 레이어 두께를 바꾸세요.
- 쓰고 있는 벽 타입은 삭제할 수 없습니다(삭제 단추가 흐림).

### 확인
- [ ] 벽 타입 창을 열고 벽에 타입을 지정했다.
- [ ] FireRating = REI 60 속성을 붙였다.
- [ ] 단계를 철거로 바꾸고 보기 → 단계로 비교했다.
- [ ] 집계와 수량의 공사비 탭을 봤다.
- [ ] `F5` 로 문제를 찾고 고쳤다.

## 레슨 14. CAD 따라 그리기: DXF, 레이어, 이미지 밑그림

### 목표
AutoCAD DXF 도면이나 스캔 이미지를 밑그림으로 가져와 그 위에 벽을 따라 그리고, CAD 레이어를 관리합니다. (프로그램 튜토리얼 레슨 14, 16)

### 따라 하기

1. **DXF 가져오기.** **파일 → 가져오기(DXF, IFC, 3D 모델, 이미지…)…**(`Ctrl+I`) 또는 **파일 → 가져오기 ▸ → DXF 도면 가져오기…** 에서 `.dxf` 파일을 고릅니다. DXF 파일이 없으면 레슨 15 의 DXF 내보내기로 하나 만들어 쓰세요.

![가져오기: DXF·SVG·IFC·3D 모델·이미지](docs/images/ko/import-picker.webp)

*가져오기: DXF·SVG·IFC·3D 모델·이미지*

2. **DXF 도면 가져오기** 창에서 정합니다.
   - **파일의 단위**: 자동 감지 · mm · cm · m · 인치 · 피트
   - **층**: 도면을 놓을 층
   - **도면을 평면 원점으로 옮기기**: 좌표가 원점에서 멀리 떨어진 도면이면 켭니다.
   - **가져오기**를 누르면 "… 가져옴: 도면 요소 n개, 텍스트 n개" 가 뜨고 화면이 도면에 맞춰집니다. 선, 폴리선, 호, 원, 스플라인, 텍스트, 블록, 해치 윤곽이 **원래 CAD 레이어 그대로** 들어옵니다. 주의할 점이 있으면 **가져오기 메모** 창이 뜹니다.
3. **따라 그리기.** `W` 로 가져온 선 위에 벽을 그립니다. 스냅이 CAD 선의 끝점에도 붙습니다.

![DXF 따라 그리기: 가져온 CAD 선을 레이어별로 보이고 그 위에 벽을 그립니다](docs/images/ko/cad-tracing.webp)

*DXF 따라 그리기: 가져온 CAD 선을 레이어별로 보이고 그 위에 벽을 그립니다*

4. **레이어 켜고 끄기.** 왼쪽 가구 라이브러리 아래에 **CAD 레이어** 패널이 생깁니다. 줄 앞의 **눈** 아이콘을 누르면 그 레이어를 숨기거나 보입니다. 레이어 줄 자체를 클릭하면 그 레이어가 **선 도구(`L`)로 그릴 레이어**가 됩니다.
5. **CAD 레이어 창.** 패널 제목의 톱니(또는 **빌드 → CAD 레이어…**)를 누르면 레이어마다 표시 체크, **색상**, 항목 수, **삭제**(비어 있는 레이어만)를 한 창에서 다룹니다.

![CAD 레이어 창: 레이어별 표시·색·잠금](docs/images/ko/cad-layers.webp)

*CAD 레이어 창: 레이어별 표시·색·잠금*

6. **다 그렸으면** **보기 → 밑그림과 CAD 레이어 표시**를 꺼서 가져온 선을 한꺼번에 숨깁니다.

### 이미지 밑그림

1. **파일 → 가져오기 ▸ → 이미지를 트레이싱 밑그림으로 가져오기…** 에서 PNG·JPG·WebP·GIF·BMP 를 고릅니다(이미지를 창에 끌어다 놓아도 됩니다).
2. **평면에서의 이미지 폭**(mm)과 **불투명도**를 정하고 **가져오기**.
3. 밑그림을 선택하면 오른쪽 패널에서 **X, Y, 폭, 회전, 불투명도**를 바꿉니다.
4. 축척 맞추기: `M` 으로 이미지 위의 알고 있는 길이(예: 문 폭)를 재고, 실제 길이와 비율이 같아지도록 **폭**을 고칩니다.
5. 그 위에 `W` 로 벽을 따라 그리고, 다 되면 **보기 → 밑그림과 CAD 레이어 표시**로 숨깁니다.

### SVG 도면
**파일 → 가져오기 ▸ → SVG 도면 가져오기…** 는 경로, 도형, 텍스트를 **SVG** 레이어로 가져옵니다. 옵션은 DXF 와 같습니다.

### 팁
- **DXF 도면 따라 그리기** 예제(레슨 17)에서 가져온 AutoCAD 도면과 일부 따라 그린 벽을 바로 볼 수 있습니다.
- 가져온 CAD 선을 선택하면 오른쪽 패널에서 **레이어**와 **색상**을 바꿀 수 있습니다.
- DWG(AutoCAD R13 ~ 2025 가 저장한 파일)도 DXF 와 똑같이 **파일 → 가져오기…** 로 바로 가져옵니다. 도면 공간(레이아웃)과 외부 참조는 들어오지 않습니다.

### 자주 하는 실수
- 가져왔는데 아무것도 안 보인다: 단위가 잘못되어 도면이 아주 작거나 큽니다. `Home` 을 누르거나, 단위를 직접 골라 다시 가져오세요.
- 도면이 엉뚱한 층에 있다: 가져오기 창의 **층**을 확인하세요.

### 확인
- [ ] DXF 를 가져와 레이어별로 보이고 숨겼다.
- [ ] 이미지를 밑그림으로 놓고 폭을 맞췄다.
- [ ] 그 위에 벽을 따라 그렸다.

## 레슨 15. 파일 주고받기: 저장, 최근 파일, 가져오기, 내보내기, 인쇄

### 목표
프로젝트 저장과 최근 파일, 3D 모델·IFC 가져오기, DXF·IFC·3D·이미지 내보내기, 인쇄와 PDF 를 익힙니다. (프로그램 튜토리얼 레슨 14)

### 저장과 열기

1. **저장.** `Ctrl+S`(**파일 → 저장**). 처음이면 파일 이름을 묻고 `.myarch` 로 저장합니다. 모든 것(가져온 3D 모델과 밑그림 이미지 포함)이 하나의 JSON 파일에 들어갑니다. "…을(를) 저장했습니다" 가 뜨고 제목의 ● 가 사라집니다.
2. **다른 이름으로 저장.** `Ctrl+Shift+S`.
3. **열기.** `Ctrl+O`. 프로젝트뿐 아니라 가져올 수 있는 모든 형식을 고를 수 있습니다. 파일을 창에 끌어다 놓아도 열리거나 가져와집니다.
4. **최근 파일.** **파일 → 최근 파일…** 을 엽니다.

![최근 파일: 10개까지 기억하고 하나씩 지우거나 목록을 비웁니다](docs/images/ko/recent-files.webp)

*최근 파일: 10개까지 기억하고 하나씩 지우거나 목록을 비웁니다*

   - 열거나 저장한 파일을 최신 순으로 **10개**까지 기억합니다(**설정 → 일반 → 기억할 최근 파일 수**에서 1–30).
   - 줄을 누르면 그 파일을 엽니다. 줄 끝 ✕ 는 **목록에서 제거**.
   - **목록 지우기**(또는 **파일 → 최근 파일 지우기**)는 목록을 비웁니다. "최근 파일 목록을 지웠습니다." 파일은 디스크에 그대로 있습니다.
   - 없어진 파일을 열려고 하면 오류 알림과 함께 목록에서 자동으로 빠집니다.
   - 시작 페이지의 **최근** 목록과 같은 목록입니다.

### 가져오기

| 형식 | 명령 | 결과 |
|---|---|---|
| DXF, SVG | 가져오기 ▸ DXF 도면 / SVG 도면 | CAD 레이어 (레슨 14) |
| IFC | **BIM → IFC 가져오기(BIM)…** | 층, 벽, 문, 창문, 방 … 으로 된 **새 프로젝트** (지금 프로젝트를 바꿈) |
| OBJ, FBX, GLB/glTF, STL, DAE, 3MF, 3DS, PLY, WRL, AMF | 가져오기 ▸ **3D 모델 가져오기(OBJ, FBX, GLB, STL…)…** | 가구처럼 배치되는 모델 |
| PNG, JPG, WebP, GIF, BMP | 가져오기 ▸ 이미지를 트레이싱 밑그림으로 가져오기… | 밑그림 (레슨 14) |

**3D 모델 가져오기**: **파일의 단위**(자동 감지 …)와 **위쪽 축**(자동 / Y가 위쪽 / Z가 위쪽)을 고르고 **가져오기**. 모델이 화면 가운데(끌어다 놓았으면 놓은 곳)에 가구로 놓이고 "… 가져옴: 폭 × 깊이 × 높이 mm" 가 뜹니다. OBJ 옆에 같은 이름의 MTL 이 있으면 재질도 읽습니다. 모델은 프로젝트 파일 안에 저장되며 라이브러리의 **가져온 3D 모델**에서 다시 놓을 수 있습니다.

닫힌 형식(SKP, RVT, PLN, 3DM)을 열면 **지원하지 않는 형식** 창이 각 프로그램에서 무엇으로 내보내면 되는지(예: SketchUp → DAE/OBJ/glTF, Revit·ArchiCAD → IFC) 알려 줍니다.

![지원 형식: 열기·가져오기·내보내기 형식 목록](docs/images/ko/formats.webp)

*지원 형식: 열기·가져오기·내보내기 형식 목록*

전체 목록은 **도움말 → 지원 파일 형식…** 에 있습니다.

### 내보내기

**파일 → 내보내기 ▸** 를 누르면 내보내기 목록이 뜹니다: **DXF 내보내기(AutoCAD)…, IFC 내보내기(BIM)…, 3D 모델 내보내기…, 평면을 PDF로 내보내기…, 평면을 SVG로 내보내기, 평면을 PNG 이미지로 내보내기, 집계표 내보내기(CSV)…**

1. **DXF.** **DXF 내보내기(AutoCAD)…** 에서 **층**을 고르거나 **층마다 파일 하나**를 켜고 **내보내기**. AutoCAD R12 DXF, mm 단위, 표준 레이어(A-WALL, A-DOOR, A-GLAZ, A-AREA, A-FURN, A-ANNO-DIMS …)로 저장되어 어떤 CAD 프로그램에서도 열립니다.
2. **IFC.** **BIM → IFC 내보내기(BIM)…** 에서 **IFC 버전**을 고릅니다.

![IFC 내보내기: IFC4 또는 IFC2X3](docs/images/ko/export-ifc.webp)

*IFC 내보내기: IFC4 또는 IFC2X3*

   - **IFC4 (Reference View)** 또는 **IFC2X3 (Coordination View 2.0)**.
   - 층, 개구부가 있는 벽, 문, 창문, 공간(방), 바닥 슬래브, 지붕, 계단, 기둥, 가구가 들어가고 벽 타입, BIM 속성, 단계, 그리드도 포함됩니다. Revit, ArchiCAD, BIMcollab, Solibri 등에서 열 수 있습니다. 작성자와 회사는 프로젝트 속성에서 가져옵니다.
3. **3D 모델.** **3D 모델 내보내기** 창(3D 도구 모음 단추, **3D** 메뉴)에서 형식과 단위를 고릅니다.

![3D 내보내기: GLB·glTF·OBJ·STL·DAE·3MF·USDZ·PLY, 단위 선택](docs/images/ko/export-3d.webp)

*3D 내보내기: GLB·glTF·OBJ·STL·DAE·3MF·USDZ·PLY, 단위 선택*

   | 형식 | 쓰임 |
   |---|---|
   | GLB (glTF binary) | Blender, Unity, Unreal, 웹 뷰어, Windows 3D 뷰어 — 색과 텍스처 |
   | glTF (JSON) | GLB 와 같지만 데이터가 내장된 텍스트 파일 |
   | OBJ + MTL (ZIP) | 거의 모든 3D 프로그램 |
   | Collada (DAE) | SketchUp, 3ds Max, Blender |
   | FBX | 직접 쓰지 않음: GLB 나 DAE 를 Blender 에서 열어 FBX 로 저장 |
   | STL | 3D 프린팅, 기계 CAD — 형상만 |
   | 3MF | 색상 포함 3D 프린팅 |
   | PLY | 메시 교환(MeshLab, CloudCompare) |
   | USDZ | Apple AR Quick Look (iPhone, iPad, Mac) |

   **단위**: 미터(glTF 표준) 또는 밀리미터(3D 프린팅, CAD). **3D 보기에 보이는 것만** 내보냅니다. 숨긴 층, 가구, 지붕은 빠집니다.
4. **이미지.** **평면을 PNG 이미지로 내보내기**, **평면을 SVG로 내보내기**는 지금 층의 평면을 저장합니다. 3D 화면은 **3D 이미지 저장 (PNG)…**.
5. **CSV.** **집계표 내보내기(CSV)…** 는 집계와 수량 창을 엽니다(레슨 13).

### 인쇄와 PDF

1. `Ctrl+P`(**파일 → 인쇄 / PDF…**)를 누릅니다. **인쇄 창**이 열립니다. 제목 막대에 프로그램 아이콘과 “인쇄”가 있고, 왼쪽은 페이지 설정, 오른쪽은 실제 시트 미리 보기입니다.

![인쇄 창: 왼쪽은 프린터·용지·여백·축척·내용 설정, 오른쪽은 실제 시트 미리 보기, [인쇄] 는 바로 인쇄](docs/images/ko/print-preview.webp)

*인쇄 창: 왼쪽은 프린터·용지·여백·축척·내용 설정, 오른쪽은 실제 시트 미리 보기, [인쇄] 는 바로 인쇄*

2. **프린터**: 프린터(처음엔 기본 프린터), **매수**, **색상 / 흑백**.
3. **페이지**: **용지 크기**(A4–A0, A5, Letter, Legal, Tabloid, 사용자 지정 크기), **방향**(가로/세로 — 미리 보기 종이가 바로 돌아갑니다), **여백**(없음·좁게·보통·넓게·사용자 지정, 미리 보기에 점선으로 표시).
4. **도면**: **축척**(페이지에 맞춤, 1:20 … 1:1000, 사용자 지정), **페이지 가운데에 배치**, **층(층마다 시트 한 장)**, **페이지 범위**(예: `1-2, 4`).
5. **표시할 내용**(가구, 치수, 방 면적, 지붕, CAD 레이어, 텍스트, 구조 그리드)과 **시트 구성**(테두리, 표제란, 방위표와 축척 막대, 머리글, 바닥글)을 고릅니다. 여러 장이면 미리 보기 위쪽 ◀ ▶ 로 넘기고 − / + / **맞춤** 으로 확대합니다.
6. **인쇄** 를 누르면 다른 창 없이 고른 프린터로 곧바로 인쇄됩니다. **PDF로 저장…**(데스크톱 앱), **SVG로 저장…**(시트마다 SVG)도 있습니다. **파일 → 내보내기 ▸ → 평면을 PDF로 내보내기…** 는 같은 창을 PDF 저장 위주로 엽니다.

### 팁
- 기본 용지는 **설정 → 출력 → 기본 용지**에서 정합니다.
- 프로젝트 속성의 **도면 축척**이 인쇄 창의 기본 축척이 됩니다.

### 자주 하는 실수
- "층을 하나 이상 선택하세요": 목차 탭에서 층 체크가 모두 꺼졌습니다.
- IFC 를 가져왔더니 지금 프로젝트가 사라졌다: IFC 가져오기는 새 프로젝트로 엽니다. 먼저 저장하라는 질문에 **저장**을 고르세요.

### 확인
- [ ] 프로젝트를 저장하고 최근 파일 목록에서 다시 열었다.
- [ ] 최근 파일 하나를 목록에서 지웠다.
- [ ] DXF, IFC, 3D 모델 내보내기 창을 열어 봤다.
- [ ] 인쇄 미리보기에서 용지와 축척을 바꿨다.

### 목표

### 따라 하기

1. **설정.** `Ctrl+,`(**도움말 → 설정…**, 제목 표시줄 톱니)를 엽니다. 탭을 차례로 눌러 봅니다. 숫자는 − / + 로 바꿉니다.

*설정(Ctrl+,): 일반·도면·벽·3D·출력 등 탭, 숫자는 − / + 로 조절*

   | **단위와 격자** | 단위(mm/cm/m/피트·인치), 격자(10–1000 mm), 격자 모양(선 (5 × 5) / 점), 격자 표시, 눈금자, 스냅, 그리기(45° 단위), 빈 캔버스에서 왼쪽 끌기(보기 이동 / 상자 선택), 휠 확대/축소 속도 |
   | **평면도** | 벽 그리기(채우기 (포셰) / 해치 / 윤곽선만), 표시(치수, 가구, 방 면적, 문·창문 태그, 아래층 (흐리게), 지붕 (점선), 이미지 밑그림, CAD 레이어), 검사 항목(그리는 동안 모델 검사 실행), 평면·3D 연동 선택(평면에서 고른 것을 3D 에서 강조, 그 반대도), 새 지붕 |

![테마: 다크·라이트 40가지와 사용자 테마](docs/images/ko/themes.webp)

*테마: 다크·라이트 40가지와 사용자 테마*

   - **어두운 테마**, **밝은 테마** 40가지, **사용자 테마**(**새 사용자 테마…** 로 이름·유형·강조색·배경·패널·텍스트 색을 정해 저장, ✕ 로 삭제), **자동 → 시스템 설정 따르기**.
   - 설정 → 모양 → **테마…** 는 견본을 크게 보여 주는 테마 창입니다.
   - 평면 캔버스와 3D 배경도 테마를 따릅니다.

![라이트 테마의 평면도](docs/images/ko/light-theme.webp)

*라이트 테마의 평면도*

3. **언어.** 제목 표시줄의 국기 단추로 한국어 ↔ English 를 바로 바꿉니다.
4. **단위.** 상태 표시줄의 **mm** 칸을 누를 때마다 mm → cm → m → ft 로 바뀝니다. 좌표와 길이 표시가 따라 바뀝니다. 다시 mm 로 돌려 두세요.
5. **상태 표시줄과 창 크기.** 상태 표시줄을 왼쪽부터 살펴봅니다.

![상태 표시줄: 좌표·층·격자·스냅·직교·축척·단위·선택·검사, 오른쪽 끝은 창 크기 조절 표시](docs/images/ko/status-bar.webp)

*상태 표시줄: 좌표·층·격자·스냅·직교·축척·단위·선택·검사, 오른쪽 끝은 창 크기 조절 표시*

   평면도에서:

   | 칸 | 눌렀을 때 |
   |---|---|
   | 힌트 (또는 "준비") | — |
   | `X … Y …` 커서 좌표 | — |
   | 층 이름 | **층 속성…** 창 |
   | **격자 100 mm** | 격자 크기 메뉴(10, 25, 50, 100, 250, 500, 1000 mm) |
   | **스냅 ✓/—** | 스냅 켜기/끄기 (`F9`) |
   | **직교 ✓/—** | 45° 단위 그리기 켜기/끄기 (`F8`) |

   | n개 선택 | — |

![패널 접기(Ctrl+1 / Ctrl+2): 접힌 패널은 아이콘과 제목으로 남습니다](docs/images/ko/panels-collapsed.webp)

*패널 접기(Ctrl+1 / Ctrl+2): 접힌 패널은 아이콘과 제목으로 남습니다*

   패널과 도면 사이 경계선을 끌면 패널 너비(200–520 px)가 바뀌고 기억됩니다.

## 레슨 17. 예제로 고급 기능 익히기

### 목표
미리 만든 예제로 단계, 장면, 다층 단면, DXF 따라 그리기를 살펴봅니다. (프로그램 튜토리얼 레슨 16)

### 따라 하기

1. **리모델링: 단계와 벽 타입.** **파일 → 예제 열기…** 에서 **리모델링 (BIM 단계)** 를 엽니다. **보기 → 단계: 기존 건물**, **단계: 새 설계**, **단계: 모두 보기**를 차례로 눌러 공사 전후를 비교합니다(화면 위 사진은 레슨 13 의 단계 그림). 벽을 클릭해 다층 벽 타입과 단계, 방을 클릭해 실 번호를, **빌드 → 집계와 수량…** 의 **공사비** 탭을 확인합니다.
2. **매스 스터디: 장면 재생.** **매스 스터디** 예제를 열고 `F3`. 왼쪽 **장면** 목록의 장면을 눌러 이동하고, **▶** 로 장면 애니메이션을 재생합니다. 포디움, 타워, 원형 매스, 테이퍼 지붕을 밀기/끌기로 바꿔 보세요(레슨 11 의 매스 스터디 그림).
3. **공동주택: 3개 층과 단면.** `F2` 후 **3층 공동주택** 예제를 열고 `F3`. 장면 목록의 두 번째 장면 **2F 단면**을 누르면 2층이 잘려 내부가 보입니다. 왼쪽 **층** 체크로 층을 숨겨 보세요. 평면도에서는 구조 그리드 위의 기둥과 실 번호를 확인합니다.
4. **DXF 따라 그리기.** `F2` 후 **DXF 도면 따라 그리기** 예제를 엽니다. 왼쪽 **CAD 레이어** 목록에서 눈 아이콘으로 레이어 하나를 숨겨 봅니다(레슨 14 의 그림).

### 나머지 예제도 열어 보기
- **원룸**: 가구 배치와 평지붕.
- **방 두 개 아파트**: 집계와 수량 창으로 방 집계를 봅니다.
- **2층 주택**: 계단과 박공지붕, 마당의 나무와 자동차.
- **소규모 사무실**: 유리 벽, 기둥, 회의실.
- **목조 오두막**: 목재 외장재와 외쪽지붕 — 페인트 통으로 재료를 바꿔 보세요.

### 팁
- 예제를 고친 뒤 남기려면 **다른 이름으로 저장…**.
- 예제를 열 때 지금 프로젝트에 저장하지 않은 변경이 있으면 저장할지 묻습니다.

### 확인

- [ ] 매스 스터디의 장면을 재생했다.
- [ ] 공동주택의 2F 단면 장면을 봤다.
- [ ] DXF 예제에서 레이어를 숨겼다.

## 레슨 18. 따라 하는 튜토리얼과 동영상

### 목표
프로그램 안의 튜토리얼을 **보기** 모드와 **따라 하기** 모드로 쓰고, 녹화된 동영상을 봅니다.

### 튜토리얼 열기

1. **도움말 → 따라 하는 튜토리얼**을 누릅니다. 시작 페이지의 **따라 하는 튜토리얼** 카드, 도구 모음 오른쪽 끝의 튜토리얼 단추도 같습니다. 지금 프로젝트에 저장하지 않은 변경이 있으면 먼저 저장할지 묻습니다(튜토리얼은 지금 프로젝트를 바꿉니다).
2. 화면 오른쪽 아래에 **튜토리얼** 패널이 뜹니다. 제목 줄을 끌어 다른 곳으로 옮길 수 있습니다.
   - 제목 줄: **레슨 선택** 목록(1. 화면 둘러보기 … 16. 예제로 고급 기능 익히기), **튜토리얼 끝내기**(✕).
   - 모드: **보기** / **따라 하기**.
   - 진행 막대, "단계 n / m", 단계 제목과 설명.

### 보기 모드

![튜토리얼 보기 모드: 프로그램이 직접 각 단계를 실행합니다](docs/images/ko/tutorial-watch.webp)

*튜토리얼 보기 모드: 프로그램이 직접 각 단계를 실행합니다*

- 프로그램이 마우스 커서를 움직이고, 누르는 키를 화면에 띄우며, 각 단계를 **실제로** 실행합니다.
- 단추: **이전 단계**, **자동 재생** / **일시 정지**, **다음 단계 실행**, **속도**(0.5× · 1× · 2× · 4×).
- 처음 열면 "▶ 자동 재생을 누르거나, 한 단계씩 '다음'을 누르세요." 가 보입니다.
- 단계가 예상대로 끝나지 않으면 "이 단계가 예상대로 끝나지 않았습니다" 와 **다시 시도 / 건너뛰기**가 나옵니다.

### 따라 하기 모드

![튜토리얼 따라 하기 모드: 할 곳이 표시되고, 직접 하면 자동으로 확인합니다](docs/images/ko/tutorial-practice.webp)

*튜토리얼 따라 하기 모드: 할 곳이 표시되고, 직접 하면 자동으로 확인합니다*

- **직접 해 보세요:** 아래에 할 일이 나오고, 도면에는 클릭할 지점이, 화면에는 누를 단추가 표시됩니다(이 문서의 좌표와 같습니다).
- 직접 해내면 프로그램이 자동으로 확인해 **✓ 잘했습니다!** 를 띄우고 다음 단계로 넘어갑니다.
- 막히면 **보여 주기**를 누르면 프로그램이 그 단계를 대신 해 보여 줍니다. **건너뛰기**는 그 단계를 넘깁니다. 설명만 있는 단계("살펴보기:")는 **다음**으로 넘어갑니다.
- 파일이 없어 할 수 없는 단계(DXF·3D 모델·이미지 가져오기)는 **건너뛰기**를 누르세요.

### 중간 레슨부터 시작하기
레슨 선택 목록에서 원하는 레슨을 고르면 "앞 레슨의 결과를 빠르게 만드는 중…" 이 잠시 보인 뒤, 앞 레슨들의 결과(외벽, 문, 방 …)가 만들어진 상태에서 시작합니다. 레슨 1, 2, 16 은 새 프로젝트나 예제에서 시작하므로 따로 준비가 필요 없습니다.

### 튜토리얼을 끝내면
- 마지막 레슨을 마치면 "모든 레슨을 마쳤습니다. 만든 프로젝트는 그대로 열려 있으니 저장하거나 계속 고쳐 보세요." 가 나옵니다.
- 튜토리얼은 시작할 때 설정을 기본값으로 맞추고(격자, 스냅, 패널 등), ✕ 로 끝내면 **원래 설정으로 되돌립니다**.

### 녹화된 동영상
프로젝트(소스) 폴더의 **`MyArchitecture-Tutorial.mp4`** 는 이 튜토리얼 전체를 보기 모드, 한국어, 보통 속도로 녹화한 동영상(1600 × 900, 25 fps)입니다. 프로그램을 켜지 않고도 모든 레슨을 처음부터 끝까지 볼 수 있습니다. 설치 프로그램에는 들어 있지 않습니다. 프로젝트 폴더에서 `npm run record:tutorial` 로 다시 녹화할 수 있습니다(ffmpeg 필요, `--lang en` 으로 영어판).

### 이 문서와 함께 쓰는 방법
1. 동영상이나 보기 모드로 레슨 하나를 먼저 봅니다.
2. 같은 레슨을 따라 하기 모드로 직접 해 봅니다.
3. 이 문서의 해당 레슨에서 **팁**과 **자주 하는 실수**, 튜토리얼에 없는 추가 기능을 읽습니다.
4. **확인** 목록을 체크합니다.

### 확인
- [ ] 도움말 → 따라 하는 튜토리얼을 열었다.
- [ ] 보기 모드로 레슨 하나를 재생했다.
- [ ] 따라 하기 모드로 한 단계를 직접 해 ✓ 를 받았다.
- [ ] MyArchitecture-Tutorial.mp4 를 찾았다.
