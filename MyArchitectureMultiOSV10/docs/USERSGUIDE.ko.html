    MyArchitecture 10.0 사용자 가이드

    사용 설명서 · MyArchitecture 10.0

    MyArchitecture v10.0.0 · 저작자: SHKWON (knix008@naver.com)

    평면도를 그리면 바로 3D 건물이 되는 건축 설계 프로그램입니다. 벽·문·창·방·계단·지붕·기둥으로 평면을 그리고, 스케치업식 매스로 볼륨을 잡고, 3D 에서 해와 그림자·걷기·단면·입면을 보고, 벽 타입·단계·분류·IFC 속성 같은 BIM 정보를 붙이고, 일람표와 공사비를 뽑고, DXF·IFC·glTF/GLB·OBJ·PDF 등으로 주고받는 일을 한 창에서 합니다.

    이 문서는 모든 기능의 참조 설명서입니다. 처음이라면 1장과 3장을 차례로 읽고, 나머지는 필요할 때 찾아보세요. 프로그램 안의 따라 하는 튜토리얼(9장)로 같은 내용을 직접 해 볼 수도 있습니다.

    표기 약속

    • 메뉴는 파일 → 예제 열기… 처럼 화면에 보이는 한국어 이름 그대로 씁니다. 영어 화면을 쓰는 분을 위해 필요한 곳에는 영어 이름을 괄호로 덧붙였습니다.
    • 키는 Ctrl+Z 처럼 씁니다. macOS 에서는 Ctrl 대신 ⌘(Command)도 됩니다.
    • 길이 단위는 따로 말하지 않으면 mm 입니다. 프로그램 내부도 모두 mm 로 계산합니다.

    1. 시작하기

    1.1 설치

    환경방법
    WindowsMyArchitecture-Setup-10.0.0.exe 실행 → 설치 언어(한국어/English) 선택 → 이미 설치된 MyArchitecture 가 있으면 “이미 설치된 MyArchitecture 가 있습니다… 기존 프로그램을 완전히 삭제합니다” 안내(확인 = 이전 설치를 지우고 계속, 취소 = 설치 중단) → %APPDATA%\MyArchitecture 에 이전 데이터가 있으면 “저장한 데이터(설정, 자동 저장)가 있습니다. 삭제하시겠습니까?”(예/아니요) → 설치 폴더 선택. 바탕 화면·시작 메뉴 바로 가기와 .myarch 파일 연결이 만들어집니다.
    macOSdmg 를 열고 응용 프로그램 폴더로 끌어 놓습니다. 서명이 없으므로 처음 한 번은 Control-클릭 → 열기.
    LinuxAppImage(chmod +x 후 실행), .deb(sudo apt install ./MyArchitecture-…deb), .tar.gz
    웹소스 폴더에서 npm run serve 후 브라우저로 http://localhost:8642 (다른 포트: PORT=9000 npm run serve). file:// 로 직접 열면 동작하지 않습니다.
    소스Node.js 22 이상, npm install, npm start
    설치 프로그램 만들기npm run build:win(Windows NSIS), npm run build:mac(dmg·zip), npm run build:linux(AppImage·deb·tar.gz), npm run build:all(웹판 + 세 운영 체제 모두)

    1.2 실행과 저장 위치

    • MyArchitecture 는 한 번에 하나만 실행됩니다. 이미 실행 중일 때 .myarch 파일(또는 연결된 DXF·IFC·3D 모델 파일)을 더블클릭하면 열려 있는 창에서 열립니다.
    • 설정 파일 settings.json 위치: Windows %APPDATA%\MyArchitecture, macOS ~/Library/Application Support/MyArchitecture, Linux ~/.config/MyArchitecture. 웹판은 브라우저 localStorage 에 저장합니다.
    • 자동 저장(복구용 사본)은 프로젝트 파일과 별개입니다. 비정상 종료 뒤 다음 실행 때 “…의 저장되지 않은 프로젝트를 복구했습니다. 복원할까요?”라고 묻습니다(7.2절).
    • 처음 실행하면 MyArchitecture 10.0에 오신 것을 환영합니다 창이 뜹니다. 네 단계 요약(벽 그리기 → 방·계단·지붕 → 가구 배치 → 3D 로 보고 공유하기)과 예제 열기 / 새 프로젝트 시작 / 확인 단추가 있습니다. 다시 보려면 도움말 → 빠른 둘러보기, 시작할 때마다 보려면 설정 → 일반 → 시작할 때 환영 창 표시.
    • 프로그램 폴더에는 튜토리얼 전체를 녹화한 동영상 MyArchitecture-Tutorial.mp4 가 들어 있습니다(9.4절).

    자세한 내용은 2장에 있습니다.

    1.4 시작 페이지

    프로그램을 켜면 시작 탭이 열립니다(설정 → 일반 → 시작할 때를 마지막 프로젝트 다시 열기로 바꾸면 데스크톱판은 마지막 파일을 바로 엽니다). 뒤에서는 2층 주택 예제가 3D 로 천천히 돌아갑니다(설정 → 모양 → 애니메이션을 끄면 정지 그림).

    왼쪽 시작 카드:

    카드하는 일
    따라 하는 튜토리얼모든 기능을 단계별로 보여 주거나 직접 연습(9장)
    새 프로젝트빈 평면도(Ctrl+N)
    프로젝트 열기…디스크의 .myarch 파일(Ctrl+O)
    가져오기…DXF, IFC, SVG, 3D 모델, 이미지(Ctrl+I)
    예제 둘러보기미리 만든 주택과 아파트(예제 목록 창)
    사용 설명서단계별 안내(F1)
    단축키더 빠르게 작업하기(Ctrl+/)

    그 아래 최근 목록에는 최근에 열거나 저장한 파일이 설정 → 일반 → 최근 파일 기억 개수만큼(기본 10개, 최대 30개) 보입니다. 항목을 누르면 열리고, 오른쪽 ×(목록에서 제거)는 그 항목만 목록에서 지웁니다(파일은 디스크에 그대로). 목록 지우기는 목록을 비웁니다. 맨 아래에는 날마다 바뀌는 팁이 하나 나옵니다.

    오른쪽 예제 카드는 평면 그림으로 먼저 그려졌다가 잠시 뒤 3D 그림으로 바뀝니다. 카드를 누르면 그 예제가 열립니다.

    시작 탭에서 도구 모음은 따라 하는 튜토리얼 · 예제 열기… · 가져오기… · 사용 설명서 글자 단추를 보여 줍니다. 평면도와 3D 보기로는 제목 표시줄의 보기 탭(F2 / F3)으로 갑니다.

    2. 화면과 조작

    2.1 제목 표시줄

    제목 표시줄에는 왼쪽부터 다음이 있습니다. 보기 탭을 위한 별도의 탭 줄은 없습니다(열린 도면마다 생기는 문서 탭은 아래 “문서 탭” 참고).

    • 메뉴: 파일 · 편집 · 보기 · 빌드 · BIM · 도움말. 메뉴 하나를 연 채 다른 메뉴 이름 위로 마우스를 옮기면 그 메뉴가 바로 열립니다.
    • 보기 탭: 시작 · 평면도(F2) · 3D 보기(F3). 평면도 탭에는 모델 검사 결과가 배지로 붙습니다 — 오류가 있으면 오류 개수(빨강), 오류 없이 경고만 있으면 경고 개수(노랑).
    • 문서 제목: 프로젝트 제목(프로젝트 속성의 제목), 저장하지 않은 변경이 있으면 ●, 그 뒤에 파일 이름. 창 제목도 ● 파일이름 — MyArchitecture 10.0 형식입니다.
    • 돋보기 단추: 명령 팔레트를 엽니다(Ctrl+K). 툴팁은 “명령, 방, 가구 검색… (Ctrl+K)”. 검색 입력 칸은 팔레트 안에 있습니다(2.6절).
    • 오른쪽 단추: 팔레트 아이콘(무작위 테마) + ▾(테마 선택 목록), 국기(한국어 화면에서는 영국 국기 = English 로, 영어 화면에서는 태극기 = 한국어로), 톱니바퀴(설정…), ⓘ(MyArchitecture 정보).

    제목 표시줄의 어느 것도 숨겨지지 않습니다. 창의 최소 폭이 모든 메뉴·탭·단추가 보이도록 정해지고, 화면이 아주 좁으면 제목 표시줄이 두 줄로 나뉩니다.

    문서 탭 (여러 도면 함께 작업하기)

    열어 둔 도면마다 문서 탭이 하나씩 생깁니다. 문서 탭 줄은 도구 모음 아래, 가운데 작업 영역(평면도·3D·시작 페이지) 바로 위에만 있습니다 — 왼쪽·오른쪽 패널은 도구 모음에 바로 붙어 있습니다.

    • 새 프로젝트(Ctrl+N), 열기(Ctrl+O), 예제 열기, 최근 파일, 탐색기에서 연 파일, 창에 끌어다 놓은 .myarch 파일은 모두 새 탭으로 열립니다. 지금 탭이 손대지 않은 빈 “제목 없음”이면 그 탭을 그대로 씁니다. 이미 열려 있는 파일을 다시 열면 그 탭으로 갑니다. DXF·IFC·3D 모델·이미지 가져오기는 지금 탭의 도면으로 들어갑니다.
    • 탭에는 파일 이름이 보이고, 저장하지 않은 변경이 있으면 ● 가 붙습니다. 탭 위에 마우스를 올리면 프로젝트 제목과 파일 전체 경로가 나옵니다. 창 제목은 지금 탭을 따릅니다.
    • 탭을 누르면 그 도면으로 바뀝니다. 도면마다 되돌리기/다시 실행 기록, 파일 이름, 보던 층·확대 배율·화면 위치, 3D 시점, 모델 검사 결과가 따로 기억됩니다(선택은 풀립니다). 평면도/3D 보기는 그대로 유지됩니다.
    • × 또는 가운데 단추 클릭, Ctrl+W, 파일 → 탭 닫기로 탭을 닫습니다. 저장하지 않은 변경이 있으면 저장할지 먼저 묻습니다. 마지막 탭을 닫으면 빈 “제목 없음” 탭과 시작 페이지가 남습니다. 탭을 오른쪽 클릭하면 다른 탭 닫기, 오른쪽 탭 닫기도 있습니다.
    • Ctrl+Tab / Ctrl+Shift+Tab(또는 Ctrl+PageDown / PageUp)으로 다음/이전 탭으로 옮겨 갑니다. 탭을 옆으로 끌면 순서가 바뀝니다.
    • 탭이 많아 줄에 다 들어가지 않으면 탭 줄이 옆으로 스크롤됩니다. 오른쪽 끝의 < / > 단추는 탭을 하나씩 왼쪽/오른쪽으로 옮겨 보여 주고, 끝에 닿으면 흐리게 꺼집니다. 마우스 휠로도 스크롤됩니다. + 는 새 프로젝트, ▾ 는 열린 도면 전체 목록입니다.
    • 창을 닫을 때는 저장하지 않은 탭마다 차례로 저장할지 묻습니다. 자동 저장(복구)도 저장하지 않은 모든 탭을 담고, 복구하면 도면마다 탭으로 열립니다. 대화형 튜토리얼은 자기 탭에서 진행되어 다른 탭의 도면을 건드리지 않습니다.

    2.4 패널

    • 왼쪽 패널(Ctrl+1, 보기 → 라이브러리 패널 표시)과 오른쪽 패널(Ctrl+2, 보기 → 속성 패널 표시)은 패널 제목의 < / > 단추(패널 숨기기)로도 접습니다.
    • 접힌 패널은 사라지지 않고 아이콘과 세로 제목이 있는 좁은 띠로 남습니다(“가구 라이브러리”, “3D 보기 옵션”, “속성과 모델 검사”, “속성”). 띠를 누르면 다시 펼쳐집니다. 오른쪽 띠에는 모델 검사 오류·경고 개수 배지가 붙습니다.
    • 패널과 도면 사이의 경계선을 끌면 폭이 200 ~ 520 px 사이에서 바뀌고, 다음 실행 때도 기억됩니다.
    • 시작 탭에서는 양쪽 패널이 없습니다.

    오른쪽 패널(속성)의 숫자는 모두 스테퍼입니다: 왼쪽 −, 오른쪽 +, 가운데 값은 직접 입력하고 Enter. 단추를 누르고 있으면 반복되고, 값 칸에서 방향키로도 한 단계씩 바뀝니다. 오른쪽 패널에서 바꾼 값은 하나하나가 되돌리기 한 단계입니다.

    2.5 상태 표시줄과 창 크기

    맨 왼쪽 넓은 칸은 지금 도구의 힌트(없으면 “준비”)입니다. 그 뒤 칸들은 보고 있는 페이지에 따라 다르고, 단추처럼 생긴 칸은 눌러서 바꿀 수 있습니다.

    페이지칸 (왼쪽 → 오른쪽)
    평면도커서 좌표 X … Y …(지금 단위, Y 는 위쪽이 +) · 층(누르면 층 속성…) · 격자 100 mm(누르면 10/25/50/100/250/500/1000 mm 중 선택) · 스냅 ✓/—(누르면 전환, F9) · 직교 ✓/—(누르면 전환, F8) · 화면 축척 1:…(96 dpi 기준 근사) · 단위(누르면 mm → cm → m → ft → mm 순환) · n개 선택(고른 것이 있을 때) · 검사
    3D 보기탐색 방식(궤도 회전/이동/걷기 — 누르면 걷기 켜기·끄기) · 원근 투영/평행 투영(누르면 전환) · 단면 ✓/—(누르면 전환) · 표현 스타일 이름 · 삼각형 n개 · n개 선택 · 검사

    창 크기 조절 손잡이: 상태 표시줄 오른쪽 아래 모서리의 점 무늬를 끌면 창 크기가 바뀝니다(툴팁 “끌어서 창 크기 변경”). 데스크톱판에서만 보이며, 창이 최대화·전체 화면일 때는 숨습니다.

    2.6 명령 팔레트와 찾기

    • 명령 팔레트(Ctrl+K 또는 제목 표시줄 돋보기): 모든 명령, 프로젝트의 모든 방(누르면 평면에서 그 방을 선택하고 가운데로), 모든 층(누르면 그 층으로)을 한 목록에서 찾습니다. 입력하면 바로 좁혀지고, ↑/↓ 와 Enter 로 실행, Esc 로 닫습니다. 보기 메뉴 끝의 테마·언어 명령(테마…, 어두운 테마, 밝은 테마, 시스템 테마, 한국어, English)도 여기서 실행할 수 있습니다.
    • 찾기…(Ctrl+F, 편집 메뉴): 방, 문·창문(태그로), 가구, 텍스트, 층을 찾아 그 자리로 갑니다.

    2.7 확대·축소와 화면 이동 (평면도)

    동작방법
    확대/축소마우스 휠(커서 기준), 트랙패드 핀치(Ctrl+휠), Ctrl+= / Ctrl+-, 도구 모음 확대·축소. 한 칸 배율은 설정 → 단위와 격자 → 휠 확대/축소 속도(× 0.5 ~ × 3)
    전체 보기Home, 도구 모음 화면에 맞추기, 빈 곳 오른쪽 클릭 메뉴
    화면 이동빈 곳을 왼쪽 버튼으로 끌기(기본), 가운데 버튼 끌기, 오른쪽 버튼 끌기, Space+끌기, Shift+휠(가로 이동), 두 손가락 터치
    손(이동) 도구보기 → 이동 (손) 또는 도구 모음 손 단추. 켜져 있으면 요소 위에서도 왼쪽 끌기가 화면 이동입니다. Esc 나 단추로 끕니다

    가운데 끌기·오른쪽 끌기·Space+끌기는 어떤 도구를 쓰는 중에도 항상 화면 이동입니다. 오른쪽 버튼을 움직이지 않고 떼면 오른쪽 클릭 메뉴가 열립니다.

    설정 → 단위와 격자 → 빈 캔버스에서 왼쪽 끌기를 상자 선택으로 바꾸면 빈 곳 끌기가 상자 선택이 되고, 이동은 가운데·오른쪽·Space 끌기로 합니다.

    2.8 격자와 눈금자

    • 격자: 기본은 선 (5 × 5) — 가는 선과 5칸마다 또렷한 선. 격자 간격(스냅 간격)은 설정 → 단위와 격자 → 격자, 또는 상태 표시줄의 격자 칸에서 10 / 25 / 50 / 100 / 250 / 500 / 1000 mm 로 바꿉니다(기본 100 mm). 격자 모양은 선(5 × 5)/점. 도구 모음·보기 메뉴의 격자 표시로 켜고 끕니다.
    • 눈금자: 도면 위·왼쪽 가장자리에 지금 단위로 표시되고, 커서 위치가 주황색으로 표시됩니다. 눈금자 표시로 켜고 끕니다.

    동작결과

    Alt+클릭그룹 안에서 하나만 선택

    2.10 되돌리기와 다시 실행

    • 되돌리기 Ctrl+Z, 다시 실행 Ctrl+Y 또는 Ctrl+Shift+Z. 실행하면 “되돌리기: 벽 추가”처럼 잠깐 알림이 뜹니다.
    • 같은 명령이 도구 모음(툴팁에 단계 이름), 편집 메뉴, 그리고 평면 도면·층 탭·3D 화면의 오른쪽 클릭 메뉴 맨 위에 있습니다.
    • 한 번 끌기(이동, 모양 바꾸기, 밀기/끌기)는 되돌리기 한 단계입니다. 최대 200 단계까지 기억합니다.
    • 편집 → 되돌리기 기록…: 지난 작업 목록(맨 위가 최신)에서 한 항목을 누르면 그 작업 이전까지 한 번에 되돌립니다.
    • 입력 칸에 글자를 쓰는 중에는 Ctrl+Z 가 그 칸의 글자 되돌리기로 동작합니다.

    • Shift 를 누른 채 그리면 그 순간만 자유 각도입니다.

    3.3 벽

    1. W 를 누르고 시작점을 클릭합니다.
    2. 모서리마다 클릭합니다. 커서 옆에 지금 벽의 길이와 각도(화면 기준 반시계 방향, 0° = 오른쪽)가 표시되고, 두께만큼의 파란 미리 보기가 따라옵니다.
    3. 끝내기: Enter, Esc, 더블클릭, 같은 점을 다시 클릭, 또는 첫 점을 클릭(외곽선이 닫히며 끝남). 오른쪽 클릭도 그리기를 끝냅니다.
    4. Backspace 는 그리는 중에 마지막 모서리(벽)를 되돌립니다.

    다 그리면 방금 그린 벽들이 선택되고 “벽 n개를 그렸습니다. A를 누르고 그 안쪽을 클릭하면 방이 만들어집니다.”라고 안내합니다.

    새 벽의 두께·재료·벽 타입·단계는 다음을 따릅니다.

    • 오른쪽 패널(아무것도 고르지 않았을 때)의 새 항목 칸: 벽 타입, 단계, 벽 두께(그리고 문 폭, 창문 폭, 창대).
    • 빌드 → 기본 크기 (벽, 문, 창문)… 의 벽 두께·벽 재료.
    • 벽 타입을 고르면 두께는 그 타입 레이어 두께의 합입니다.
    • 새 벽의 높이는 따로 정하지 않으면 층 높이를 따릅니다.

    길이 입력

    벽(또는 선)을 그리는 중에 숫자나 . 을 치면 커서 옆에 길이 입력 칸(“길이(mm, 3.6m, 3600<90)”)이 열립니다. 입력하고 <kbd>Enter 를 누르면 지금 커서 방향으로 정확한 길이의 벽이 놓이고 그리기는 계속됩니다.

    입력 예뜻
    36003600 mm (단위가 없으면 mm)
    3.6m3.6 m = 3600 mm
    360cm360 cm
    3600mm3600 mm
    120in, 120"120 인치
    12'6", 12'6, 12'12 피트 6 인치 / 12 피트
    3600<90길이 3600, 각도 90°(화면 기준 반시계 방향: 0° 오른쪽, 90° 위, 180° 왼쪽, 270° 아래)
    3,6m쉼표도 소수점으로 읽습니다

    각도를 주지 않으면 지금 커서가 있는 방향(직교가 켜져 있으면 45° 단위로 맞춘 방향)으로 놓입니다.

    벽 이음

    벽 끝이 다른 벽의 끝이나 중심선에 닿으면 L 자, T 자, 십자 이음이 자동으로 깔끔하게 그려집니다(벽을 잘라 붙일 필요가 없습니다). 칸막이 벽은 끝을 외벽 위에 놓기만 하면 됩니다.

    벽 고치기

    벽을 선택하면 오른쪽 패널 제목에 길이 · 각도 · 개구부 수가 보이고, 다음 칸이 있습니다.

    칸설명
    벽 타입(타입 없음) 또는 벽 타입 목록. 고르면 두께가 레이어 합으로 바뀜
    길이바꾸면 끝점이 움직이고 그 끝에 이어진 벽도 따라감
    두께직접 바꾸면 벽 타입이 풀림
    높이층 높이와 같으면 층 높이를 따름(층 높이를 바꾸면 함께 바뀜)
    재료벽 재료(12.3절)

    단추: 문 추가, 창문 추가(누른 뒤 벽을 클릭), 가운데에서 나누기, 삭제. 그 아래 BIM 칸(6장).

    • 벽 끝 손잡이(작은 네모)를 끌면 그 끝만 움직입니다. 벽 몸통을 끌면 벽 전체가 움직이고 이어진 벽들이 늘어나며 따라옵니다(Alt+끌기는 이어진 벽을 늘리지 않고 이동).
    • 벽 위 오른쪽 클릭 메뉴: 여기에 문 추가, 여기에 창문 추가, 여기서 벽 나누기, 일직선 벽 합치기(지금 층에서 한 줄로 이어진 벽들을 하나로).
    • 더블클릭(또는 E)하면 벽 속성 창: 길이, 두께, 높이(+ 층 높이와 같게), 재료.

    3.4 방

    • A 를 누르고 닫힌 벽 안쪽을 클릭하면 벽 안쪽 면을 따라 방이 생깁니다. 이름은 크기에 맞게 자동으로 붙고(예: 거실, 침실, 욕실 …), 면적이 알림으로 나옵니다(“방 "…"을(를) 추가했습니다: … m². 두 번 클릭하면 이름을 바꿀 수 있습니다.”).
    • Shift+클릭으로 시작하면 모서리를 직접 찍어 그립니다. 첫 점을 다시 클릭하거나 Enter 로 끝냅니다. 그리는 동안 면적이 커서 옆에 보입니다.
    • 빌드 → 벽에서 방 감지(빈 곳 오른쪽 클릭 → 방 감지): 지금 층에서 닫힌 공간 중 아직 방이 없는 곳을 모두 방으로 만듭니다.
    • 바닥 재료는 기본 오크 마루(기본 크기 창의 바닥 재료로 바꿈).

    방을 선택하면 오른쪽 패널에 면적·둘레가 보이고, 이름, 번호(실 번호), 부서(용도), 바닥(재료), 텍스트 크기, 면적 표시 칸이 있습니다. 꼭짓점 손잡이를 끌면 모양이 바뀝니다(방 하나만 골랐을 때). 더블클릭하면 방 속성 창(이름은 거실·침실·주방·식당·욕실·변기·홀·현관·서재·다용도실·창고·드레스룸·발코니·차고·사무실·회의실·복도·계단 목록에서 고르거나 직접 입력).

    3.5 문과 창문

    • D(문) 또는 N(창문)을 누르고 벽 위로 커서를 옮기면 미리 보기와 폭이 나옵니다. 클릭하면 들어갑니다.
    • 위치는 벽을 따라 격자의 반 칸 단위로 맞춰지고, 벽 끝을 넘지 않도록 조정됩니다.
    • 문은 커서가 있는 쪽으로 열리고, 경첩은 클릭한 곳에 가까운 쪽 끝에 붙습니다.
    • 벽이 너무 짧으면 “이 벽은 너무 짧아 넣을 수 없습니다.”, 이미 문·창이 있으면 “그 자리에 이미 문이나 창문이 있습니다.”
    • 새 문·창의 크기와 종류: 기본 크기 창(문 폭 900, 문 높이 2100, 창문 폭 1200, 창문 높이 1200, 창대 900 이 처음 값), 오른쪽 패널의 새 항목 칸.

    선택한 문·창:

    키·단추하는 일
    X / 열림 방향 뒤집기문이 열리는 쪽(벽의 어느 면) 바꾸기
    H / 경첩 바꾸기경첩을 반대쪽 끝으로
    벽 선택이 문·창이 달린 벽 선택

    오른쪽 패널 칸: 종류(문 / 창문 / 개구부), 유형(문: 외여닫이·양개·미닫이·차고, 창문: 여닫이창·고정·미닫이), 폭, 높이, 창대 높이, 위치(벽 시작점에서 중심까지 거리), 태그. 태그는 비워 두면 문 D01, D02…, 창 W01…, 개구부 O01… 이 층·위치 순서로 자동으로 붙습니다. 더블클릭하면 문 속성 / 창문 속성 창(위 항목 + 여닫는 쪽 “벽 왼쪽/벽 오른쪽”, 경첩 “벽 시작점에서/벽 끝에서”).

    문·창은 벽에 붙어 있으므로 벽을 옮기거나 늘이면 함께 움직입니다. 벽을 지우면 그 벽의 문·창도 지워집니다.

    3.6 가구

    가구 라이브러리(왼쪽 패널):

    • 위쪽 검색 칸(“검색 (소파, 침대, 변기…)”)과 분류 칩: 전체 · 거실 · 식사 · 침실 · 주방 · 욕실 · 사무실 · 실외 · … · 조명 · 기타. 검색 칸에서 Enter 를 누르면 첫 항목을 고릅니다.
    • 검색어도 분류도 없을 때는 맨 위에 최근 사용 가구(최대 10개)가 나옵니다.
    • 항목마다 평면 모양 그림과 폭 × 깊이 × 높이.
    • 항목을 누른 뒤 도면을 클릭하거나, 항목을 도면으로 끌어다 놓으면 배치됩니다.
    • 가져온 3D 모델(7.4절)도 목록 아래에 나와 같은 방법으로 놓습니다. 패널 제목의 3D 모델 단추는 3D 모델 가져오기(OBJ, FBX, GLB, STL…)….

    F(가구 검색): “가구 — 이름을 입력하세요(소파, 침대, 싱크대, 자동차 …)” 창에서 이름을 치고 Enter → 도면을 클릭. 최근에 쓴 가구가 위쪽에 옵니다.

    놓는 중에는:

    키하는 일
    R미리 보기를 90° 회전
    Shift+R15° 회전
    Shift+클릭놓고 나서도 같은 가구를 계속 놓기
    Esc놓기 멈춤

    가구는 격자의 반 칸 단위로 놓이고 움직입니다(끌 때 Shift 를 누르면 가로·세로로만). 선택하면 오른쪽 패널에 X, Y, 회전, 폭, 깊이, 높이, 바닥 높이(바닥에서 띄운 높이), 색상 칸과 3D에서 보기 단추가 있습니다. 더블클릭하면 이름·종류(다른 가구로 바꾸기)까지 바꿀 수 있습니다. 전체 목록은 12.3절.

    조명

    조명 기구는 라이브러리 조명 분류의 가구입니다: 천장등, 펜던트 조명, 매입 다운라이트, 스포트라이트, 레일 조명 (스포트 3개), 벽부등, 테이블 램프 — 그리고 스탠드 조명(거실)과 가로등(실외)도 조명입니다. 평면 도구 모음의 조명 기구 단추는 마지막에 쓴 조명(처음에는 천장등)을 놓습니다.

    • 놓기: 다른 가구와 같습니다 — 라이브러리에서 고른 뒤 평면을 클릭하거나, 평면으로 끌어다 놓습니다. 천장 조명은 현재 층의 천장 아래에 저절로 매달립니다(바닥 높이 = 층 높이 − 기구 높이). 벽부등은 1.8 m 높이, 테이블 램프는 바닥에 놓이므로 탁자 위에 두려면 바닥 높이를 올립니다.
    • 마우스로 옮기기: 평면에서 가구처럼 끌면 됩니다(격자 반 칸 단위). 3D에서는 조명을 클릭해 선택한 뒤 끌면 그 높이 그대로 미끄러지듯 움직이고(천장등은 천장 아래에 그대로), 놓는 순간 평면도 따라 바뀝니다 — 되돌리기 한 번.
    • 평면 기호: 기구 위에 X 표시가 든 원. 켜져 있으면 노란색으로 채워지고 빛살이 그려지며, 꺼지면 속이 빈 원입니다. 조명은 아래 가구 위에 그려지고, 클릭하면 아래 탁자보다 조명이 먼저 잡힙니다.
    • 켜기 / 끄기: 오른쪽 패널의 켜짐 스위치, 오른쪽 클릭 메뉴(평면·3D)의 조명 끄기 / 켜기, 또는 3D에서 조명을 두 번 클릭. 모든 조명 켜기 / 끄기(평면·3D 도구 모음의 전구 단추, 3D 오른쪽 클릭 메뉴)는 모든 조명을 한꺼번에 바꾸며, 하나라도 켜져 있으면 단추가 켜진 상태로 보입니다. 스위치 한 번이 되돌리기 한 단계이고 프로젝트에 저장됩니다.
    • 설정(오른쪽 패널 조명 아래): 밝기 (lm), 색온도(전구색 2700 K / 온백색 3000 K, 주백색 4000 K, 주광색 5000 K, 주광 6500 K), 빛 색(아무 색), 그리고 다운라이트·스포트라이트·레일 조명·가로등은 빔 각도.
    • 3D: 켜진 조명은 빛나고 주변을 밝히며, 꺼진 조명은 어둡습니다. 야간 보기 (실내 조명)(3D 도구 모음의 달 단추, 또는 왼쪽 패널 표시 목록의 야간)는 해를 끄고 하늘을 어둡게 해 조명만으로 장면을 비춥니다 — 위에서 들여다보려면 지붕이나 위층을 숨기거나 단면을 쓰세요.
    • 성능: 큰 모델도 부드럽게 돌도록 실제 광원은 한 번에 점광원 12개, 스포트 8개까지만 씁니다 — 보이는 층(단면 아래)에서 카메라에 가장 가까운 조명들입니다. 나머지도 빛나 보이기는 합니다. 조명은 그림자를 만들지 않습니다. 조명을 켜고 끄거나 설정을 바꿔도 3D 모델을 다시 만들지 않습니다.
    • 모델 검사는 천장 조명(2 m 이상)을 충돌 검사에서 빼고, 벽부등은 벽에 닿아도 됩니다.

    3.7 계단

    • S 를 누르고 계단 아래쪽을 클릭, 그다음 위쪽을 클릭합니다(직교가 켜져 있으면 45° 단위). 600 mm 보다 짧으면 만들어지지 않습니다.
    • 단 수는 층 높이(+ 슬래브)를 약 175 mm 로 나눠 자동으로 정해집니다(최소 3단). 폭은 기본 크기의 계단 폭(처음 1000 mm).
    • 선택하면 제목에 “n단 · 단높이 … mm · 단너비 … mm” 가 보이고, 단 수, 폭, 길이, 회전, 재료 칸이 있습니다. 단높이가 200 mm 를 넘으면 “챌판이 200 mm를 넘으면 가파릅니다. 단을 늘리세요.” 경고가 나옵니다.
    • 평면에는 진행 방향 화살표와 “올라감” 글자가 그려지고, 3D 에서는 디딤판으로 만들어집니다.

    3.8 기둥

    • C 를 누르고 클릭합니다. 벽 끝(모서리)에 잘 붙습니다. 놓기 전에 R 로 돌릴 수 있습니다.
    • 크기는 프로젝트 기본 400 × 400 mm. 선택하면 모양(사각형/원형), 폭, 깊이, 회전, 재료. 높이는 층 높이를 따릅니다.

    3.9 지붕

    지붕을 만드는 세 가지 방법:

    1. 빌드 → 맨 위층 지붕: 맨 위층의 닫힌 외벽 윤곽마다 지붕을 얹습니다(모양은 설정 → 평면도 → 새 지붕, 기본 박공, 경사 30°, 처마 500). 다시 실행하면 이전에 자동으로 만든 지붕을 바꿔 줍니다. 닫힌 윤곽이 없으면 “맨 위층에 닫힌 벽 윤곽이 없습니다.”
    2. O 를 누르고 건물 안을 클릭: 그 층 외벽 윤곽 위에 지붕(처마 400).
    3. O 다음 Shift+클릭으로 지붕 외곽선을 직접 그리기(Enter 로 마침).

    지붕은 그 층 벽 위에 얹힙니다. 평면에서는 점선으로 표시됩니다(설정 → 평면도 → 지붕 (점선)).

    선택하면: 모양(박공 / 모임 / 외쪽 / 평), 경사(0 ~ 75°), 처마 내밀기, 두께, 용마루 방향(긴 변을 따라 / 가로질러), 재료(지붕 기와·슬레이트·금속 지붕·콘크리트). 꼭짓점 손잡이로 모양을 바꿉니다.

    3.10 층

    도면 왼쪽 아래에 층 탭이 아래층부터 위로 쌓여 있습니다(1F 0.00 m 처럼 이름과 바닥 높이).

    동작결과
    탭 클릭그 층 편집. 그리기는 지금 층에만 됩니다
    탭 더블클릭이름 바꾸기
    + 탭맨 위에 층 추가 — 맨 위층의 벽과 창문을 복사(문은 복사하지 않음)
    탭 오른쪽 클릭되돌리기 · 다시 실행 / 층 이름 바꾸기… · 층 속성… · 층 복제(벽, 문, 창문) / 층 삭제
    • 빌드 → 맨 위에 층 추가는 + 탭과 같습니다. 새 층 이름은 2F, 3F…, 바닥 높이는 아래층 높이 + 층고.
    • 층 복제(벽, 문, 창문) 는 그 층의 벽·문·창·방을 복사해 맨 위에 새 층을 만듭니다.
    • 층 삭제는 그 층과 그 위의 모든 요소를 지웁니다(확인을 묻고, 층이 하나뿐이면 지울 수 없음).
    • 층 속성…(빌드 메뉴, 상태 표시줄 층 칸): 이름, 바닥 높이, 높이(층고, 최소 1000), 바닥 슬래브. “높이를 따로 지정하지 않은 벽은 층 높이를 사용합니다. 층을 위아래로 옮기면 그 층의 모든 요소가 3D에서 함께 움직입니다.” 아무것도 선택하지 않았을 때 오른쪽 패널에도 같은 칸이 있고 층 요약(벽·방 수, 방 면적, 연면적)이 나옵니다.
    • 아래층은 흐리게 겹쳐 보입니다(보기 → 아래층 표시).
    • 구조 그리드 선은 모든 층에 공통입니다.

    3.11 치수, 텍스트, 선, 측정

    • 치수 K: 두 점을 클릭하고, 마우스를 움직여 치수선 위치(간격, 50 mm 단위)를 정한 뒤 한 번 더 클릭. 점은 벽 끝·벽에 붙습니다. 선택하면 간격과 텍스트 재정의(숫자 대신 쓸 글자), 끝 손잡이로 점 이동.
    • 빌드 → 외벽 치수 넣기(빈 곳 오른쪽 클릭 → 자동 치수): 지금 층 건물의 전체 가로·세로 치수와 벽 사이 치수 줄을 바깥에 넣습니다. 다시 실행하면 이전 자동 치수를 바꿔 줍니다.
    • 텍스트 T: 클릭한 곳에 입력 칸이 열립니다. Enter 로 확정. 선택하면 글자(여러 줄), 크기, 회전, 정렬(왼쪽/중앙/오른쪽).
    • 선 L: CAD 레이어에 작도선(폴리선). 점을 차례로 클릭, Enter·더블클릭으로 끝, 첫 점을 클릭하면 닫힘. 왼쪽 CAD 레이어 목록에서 누른 레이어(강조된 줄)에 그려지고 DXF 로 내보내집니다. 선택하면 레이어, 색상.
    • 측정 M: 두 점을 클릭하면 “거리: … (… m)” 알림. 도면에는 남지 않습니다. 세 번째 클릭은 새 측정, Esc 로 지움.

    보기 → 치수 표시로 치수를 숨길 수 있습니다(인쇄 옵션은 따로).

    3.12 구조 그리드

    • G(빈 곳 오른쪽 클릭 → 그리드 선)를 누르고 그리드 선의 두 끝을 클릭합니다(500 mm 이상).
    • 세로선은 1, 2, 3 …, 가로선은 A, B, C …(26개 넘으면 A1, A2…)로 비어 있는 다음 번호가 붙고, 양 끝에 버블이 그려집니다. 모든 층에 나타납니다.
    • 선택하면 레이블을 바꿀 수 있고, 끝 손잡이로 길이를 조정합니다. IFC 로 IfcGrid 로 내보내집니다.

    3.13 매스 (스케치업식 매스 모델)

    벽·바닥이 없는 덩어리로 볼륨을 검토할 때 씁니다.

    도구그리는 법
    매스 상자 B마주 보는 두 모서리 클릭
    매스 원기둥 U중심 클릭, 원 위의 점 클릭(32각형)
    매스 다각형모서리를 차례로 클릭, Enter 나 첫 점 클릭으로 돌출

    새 매스는 높이 3000 mm, 재료 콘크리트, 단계 신축으로 만들어집니다. 선택하면:

    칸설명
    이름매스 이름
    높이매스 높이
    기준 높이층 바닥에서 띄운 높이(포디움 위 타워 등)
    테이퍼윗면 크기 비율 0 ~ 100%. 100% = 수직, 0% = 피라미드/원뿔
    재료벽·지붕 재료

    3D에서 밀기/끌기 단추는 3D 탭으로 가서 밀기/끌기 도구를 켭니다(5.9절). 매스도 이동·회전·대칭·크기 조정·간격 띄우기·그룹이 됩니다.

    3.14 이미지 밑그림과 CAD 도면 따라 그리기

    • 스캔한 도면 이미지를 이미지 밑그림으로 가져와(7.4절) 그 위에 벽을 그립니다. 밑그림을 선택하면 X, Y, 폭, 회전, 불투명도 칸과 팁(“M으로 이미지에서 길이를 아는 부분을 잰 다음, 그 길이에 맞도록 폭을 설정하세요.”)이 있습니다.
    • DXF/SVG 도면은 CAD 레이어로 들어옵니다(7.4절). 그 위에 W 로 벽을 따라 그리고 레이어를 숨기세요.
    • 보기 → 밑그림과 CAD 레이어 표시로 둘 다 한 번에 숨기고 보입니다.

    CAD 레이어 목록(왼쪽 패널, 도면이 있거나 레이어가 2개 이상일 때): 눈 아이콘으로 표시/숨기기, 색 견본, 이름, 요소 수. 줄을 누르면 그 레이어가 선 도구로 그릴 레이어가 됩니다. 톱니바퀴(또는 빌드 → CAD 레이어…)는 레이어 창을 엽니다.

    CAD 레이어 창: 레이어마다 표시 체크, 색상, 항목 수, 삭제(요소가 없는 레이어만, 레이어 0 은 지울 수 없음). 10개씩 쪽으로 나뉩니다.

    3.15 건물 요소 (슬래브, 천장, 보, 난간, 경사로, 샤프트, 커튼월)

    모델은 Revit·ArchiCAD 모델이 담는 건물 요소를 그대로 담으므로, 그 프로그램 없이도 설계할 수 있습니다. 도구는 평면 도구 모음에 있으며, 관련 도구는 분할 버튼으로 묶입니다 — 버튼은 첫 도구를, 옆의 작은 ▾는 나머지를 보여 줍니다(숨겨진 도구 없이 모두 한 번 클릭 거리입니다).

    분할 버튼도구
    벽 ▾벽(W), 커튼월(V)
    기둥 ▾기둥(C), 보(J), 선택한 슬래브나 실에 보 시스템…
    계단 ▾계단(S)과 모양 직선, ㄱ자(꺾임 계단참), ㄷ자(되돌림 계단참), 나선; 경사로; 난간(I)
    바닥 슬래브 ▾바닥 슬래브(P), 천장, 샤프트 개구부, 슬래브·천장·지붕 개구부, 모든 층에 바닥 슬래브, 이 층의 모든 실에 천장
    타입 카탈로그 ▾타입 카탈로그 (패밀리)…, 설계 대안…, 배열 (직선 / 원형)…, 재료와 열 성능…

    바닥 슬래브와 기초. 벽 안을 클릭하면 건물 외곽 아래에 슬래브가 생기고, Shift+클릭으로 어떤 외곽이든 그릴 수 있습니다(Enter나 첫 점에서 끝). 오른쪽에서 슬래브 타입(Concrete floor 250, Insulated floor 300, Raft foundation 400 같은 층 구성 타입. 두께와 열관류율은 층에서 계산), 윗면 높이 차이(올리거나 내린 바닥), 경사와 경사 방향(가장 낮은 모서리에서부터 올라감), 마감을 정합니다. 개구부 추가로 두 모서리를 찍어 구멍을 냅니다. 개구부는 평면·3D·IFC 모두에서 뚫립니다. 슬래브 위의 실은 바닥 마감만 남깁니다.

    천장. 실 안을 클릭하면 그 위에 천장이 생깁니다(Shift+클릭으로 외곽). 높이 기본값은 위층 바닥에서 300 mm 아래이고, 천장 타입은 석고보드와 흡음 천장재 600×600입니다. 평면에는 일점쇄선 외곽과 높이("CLG +2.50")로 나타납니다.

    보와 가새. 양 끝을 클릭합니다. 기둥과 벽 끝에 맞춰집니다. 윗면은 층의 맨 위에 놓이고, 시작점 / 끝점 윗면 높이를 다르게 하면 경사진 보(가새)가 됩니다. 단면: 직사각형, I형강, T형, 원형. 보는 절단면 위에 있으므로 점선으로 그려집니다. 보 시스템…은 선택한 슬래브나 실을 입력한 간격과 방향(예: 1200 90)의 평행한 보로 채웁니다.

    난간. 경로의 점을 클릭하고 Enter로 끝냅니다. 높이, 밑면 높이, 형식(난간동자, 유리 패널, 막힌 패널), 난간동자 간격, 재료 — 또는 난간 타입을 고릅니다. 계단 난간은 계단의 난간 칸(없음, 왼쪽, 오른쪽, 양쪽)에서 정하며, 새 계단은 양쪽에 생깁니다.

    형식별 계단. 계단의 모양: 직선, ㄱ자(꺾임 계단참, 두 번째 계단 길이), ㄷ자(되돌림 계단참, 계단참 깊이, 계단 사이 간격), 나선(안쪽 반지름, 회전 각도. 중심을 클릭한 뒤 바깥 가장자리를 클릭해 그림). 단높이는 모두 같고 마지막 디딤판은 위층 바닥과 같은 높이이며, 속성에 "8 + 8단, 단높이 175 mm"처럼 나옵니다. 예전 직선 계단은 그대로 열립니다.

    경사로. 중심선을 아래에서 위로 클릭합니다. 오를 높이는 따로 정하지 않으면 위층까지이고, 평면에 기울기("8.3% 1:12")가 나오며 1:12보다 가파르면 모델 검사가 경고합니다.

    샤프트. 수직 개구부의 두 모서리를 클릭합니다. 아래 층부터 위 층까지 모든 층의 슬래브·천장·지붕을 뚫고, 각 층에 대각선 두 개로 그려집니다.

    커튼월. 벽처럼 그리며 커튼월 타입을 따릅니다: 가로·세로 그리드 간격(같은 크기 칸 또는 고정 간격), 멀리언 폭과 깊이, 패널과 프레임 재료, 스팬드럴 패널. 커튼월마다 간격을 따로 바꿀 수 있습니다. 커튼월에 넣은 문과 창은 덮는 패널을 대신합니다.

    벽: 윤곽과 붙이기. 벽의 끝점 높이는 윗면을 기울이고, 밑면 높이 차이는 아래를 들어 올리며, 윗면 붙이기는 위의 지붕(또는 슬래브)까지 올라가게 합니다 — 박공 아래에서는 지붕을 따라갑니다. 빌드 → 선택한 벽을 위의 지붕이나 슬래브에 붙이기로 여러 벽을 한 번에 붙입니다.

    변마다 경사 지붕. 변마다 경사 (외곽 지붕)를 켜면 변마다 경사 켜기/끄기, 경사각, 처마 길이를 정합니다(모든 변 경사 = 모임지붕, 마주 보는 두 변 박공 = 박공지붕, 하나 = 외쪽지붕). 개구부 추가로 천창과 도머 구멍을 냅니다.

    타입 (패밀리). 타입 카탈로그에는 문·창·기둥·보·가구·난간 타입과 그 타입 매개변수(크기, 개폐 방식, 틀 폭과 깊이, 단면, 재료, 기본 창대 높이 …), 커튼월 타입과 바닥·천장 타입, 그리고 모든 재료의 열전도율 λ·밀도·비열과 층 구성 타입의 열관류율이 나오는 재료 페이지가 있습니다. 카탈로그 타입이 정해진 인스턴스는 타입 매개변수를 따르며(인스턴스에서는 흐리게 잠김), 타입을 고치면 모든 인스턴스가 따라 바뀝니다. 인스턴스 모두 선택, 선택한 요소로 타입 만들기, 선택한 요소에 적용은 카탈로그, 속성, 오른쪽 클릭 메뉴에 있습니다. 기본 제공 타입은 늘 있고, 만들거나 바꾼 타입만 파일에 저장됩니다.

    설계 대안. 설계 대안…에서 대안 묶음(예: "로비"와 대안 A, B)을 만듭니다. 선택한 요소를 대안에 넣으면, 각 묶음에서 활성 대안만 그려지고, 3D로 지어지고, 검사·집계·내보내기됩니다. 활성 대안 확정은 그 대안을 주 모델로 만들고 나머지를 지웁니다.

    배열과 그룹. 배열…은 선택한 요소를 직선(X / Y 간격)이나 원형(전체 각도, 중심)으로 반복하며, 사본마다 그룹으로 묶을 수 있습니다(그룹: 4.7절).

    집계와 교환. 일람표와 수량에 건물 요소(모든 슬래브·천장·보·가새·난간·경사로·샤프트·커튼월의 길이·면적·부피·열관류율과 합계)와 타입(타입별 인스턴스 수) 페이지가 있고, 벽 타입 페이지에 열관류율이 나오며, 공사비 견적에 슬래브·천장·보·난간·경사로·커튼월이 들어갑니다. IFC 내보내기는 IfcSlab, IfcCovering, IfcBeam/IfcMember, IfcRailing, IfcRamp, 계단판과 계단참이 있는 IfcStair, IfcMember·IfcPlate로 된 IfcCurtainWall, 샤프트의 IfcOpeningElement를 씁니다. DXF는 A-FLOR-SLAB, A-CLNG, S-BEAM, A-FLOR-HRAL, A-FLOR-RAMP, A-SHFT, A-GLAZ-CWMG 레이어에 넣습니다.

    링크 모델(Revit 링크, ArchiCAD 핫링크·모듈)은 지원하지 않습니다. 다른 모델의 요소는 IFC 가져오기로 이 프로젝트에 들여오세요.

    4. 편집

    편집 명령은 대부분 평면도 탭에서 동작합니다.

    4.1 상자 선택

    Shift+끌기(또는 Ctrl+끌기, 설정에 따라 그냥 끌기):

    • 왼쪽 → 오른쪽(파란 실선 상자): 상자 안에 완전히 들어간 것만(윈도 선택).
    • 오른쪽 → 왼쪽(초록 점선 상자): 상자에 걸친 것까지(크로싱 선택).
    • 상자 선택은 지금 선택에 더해집니다.

    4.2 이동

    • 선택한 것을 끌면 이동합니다. 이동 거리는 격자 단위(가구는 반 칸)로 맞춰지고, Shift 를 누르면 가로 또는 세로로만.
    • 벽을 옮기면 이어진 벽이 늘어나며 따라오고, 그 벽의 문·창은 벽 안에 남습니다. Alt+끌기는 이어진 벽을 늘리지 않습니다.
    • 방향키: 격자 한 칸, Shift+방향키: 열 칸.
    • 손잡이 끌기는 이동이 아니라 모양 바꾸기(벽 끝, 방·지붕 꼭짓점, 치수·그리드 끝)입니다.

    4.3 복사, 잘라내기, 붙여넣기, 복제, 삭제

    명령키설명
    복사Ctrl+C“n개 항목을 복사했습니다”
    잘라내기Ctrl+X복사 후 삭제
    붙여넣기Ctrl+V커서 위치(격자에 맞춤)에 붙여 넣음. 커서가 도면 밖이면 원래 자리에서 1 m 비켜서. 지금 층에 들어갑니다(다른 층으로 복사할 때 유용)
    복제Ctrl+D1 m 오른쪽 아래에 사본
    삭제Del 또는 Backspace벽을 지우면 그 벽의 문·창도 지워짐

    빈 곳 오른쪽 클릭 메뉴의 붙여넣기는 오른쪽 클릭한 자리에 붙여 넣습니다.

    4.5 크기 조정

    편집 → 크기 조정…(여러 개 선택 시 오른쪽 패널 크기 조정… 단추): “배율 (예: 1.5 또는 50%)”을 입력하면 선택을 그 중심 기준으로 키우거나 줄입니다. 50% 처럼 퍼센트도 됩니다. 가구는 높이까지 바뀝니다.

    4.6 간격 띄우기

    편집 → 간격 띄우기…: “간격 띄우기 거리(mm, 음수 = 안쪽)”를 입력하면 선택한 방, 매스, 지붕, 닫힌 선의 평행한 사본을 만듭니다. 양수는 바깥, 음수는 안쪽입니다. 다른 요소에는 쓸 수 없습니다(“간격을 띄울 방, 매스, 지붕 또는 닫힌 선을 선택하세요.”).

    4.7 그룹

    • 그룹 Ctrl+G: 두 개 이상 골라 묶습니다(문·창과 그리드 선은 그룹에 들어가지 않음). 그 뒤 아무 항목이나 클릭하면 그룹 전체가 선택되고 함께 움직입니다. Alt+클릭은 하나만.
    • 그룹 해제 Ctrl+Shift+G.
    • 그룹 요소를 선택하면 오른쪽 패널에 “그룹의 일부입니다 (n개 항목)…”와 그룹 해제 단추가 나옵니다.

    4.8 여러 개 선택했을 때

    오른쪽 패널에 “항목 n개 선택됨”, 종류별 개수와 회전 · 대칭 · 복제 · 삭제 · 그룹 · 크기 조정… 단추가 나옵니다. 벽만 골랐다면 두께와 재료를 한꺼번에 바꿀 수 있습니다.

    4.9 비슷한 요소 선택

    BIM → 비슷한 요소 선택(오른쪽 클릭 메뉴, BIM 칸 단추): 지금 층에서 처음 고른 요소와 같은 것을 모두 고릅니다.

    • 벽: 같은 벽 타입이면서 같은 두께
    • 가구: 같은 종류
    • 문·창: 같은 종류, 같은 폭
    • 그 밖: 같은 종류 전부(그리드 선은 전체)

    4.10 속성 창

    선택 도구에서 요소를 더블클릭하거나 하나를 고르고 E(편집 → 속성…)를 누르면 속성 창이 열립니다. 창 안에서 바꾼 것은 확인을 누를 때 한 번에(되돌리기 한 단계로) 적용됩니다. 아무것도 고르지 않고 속성…을 실행하면 프로젝트 속성이 열립니다.

    요소창 이름항목
    벽벽 속성길이, 두께, 높이, 층 높이와 같게, 재료
    문·창문 속성 / 창문 속성종류, 유형, 폭, 높이, 창대 높이, 위치, 여닫는 쪽, 경첩, 태그
    방방 속성이름(목록), 바닥, 면적(읽기 전용), 텍스트 크기, 면적 표시
    가구(가구 이름)이름, 종류, 폭, 깊이, 높이, 바닥에서 높이, 회전, 색상
    계단계단 속성단 수, 폭, 길이, 회전, 재료
    지붕지붕 속성모양, 경사, 처마 내밀기, 두께, 재료
    기둥기둥 속성모양, 폭, 깊이, 회전
    텍스트텍스트글자, 크기, 회전
    그 밖(매스, 치수, 그리드, 선, 밑그림)—“오른쪽에서 편집하세요.” — 오른쪽 패널에서 고칩니다

    4.11 오른쪽 클릭 메뉴 (평면)

    선택 도구에서 마우스 오른쪽 버튼을 움직이지 않고 누르면 메뉴가 열립니다. (그리는 중이면 오른쪽 클릭은 그리기를 끝내고, 다른 도구일 때는 선택 도구로 돌아갑니다.)

    요소 위(그 요소가 선택됨):

    1. 되돌리기 · 다시 실행
    2. 속성… (E)
    3. 벽이면: 여기에 문 추가 · 여기에 창문 추가 · 여기서 벽 나누기 · 일직선 벽 합치기
    4. 문·창이면: 열림 방향 뒤집기 (X) · 경첩 바꾸기 (H)
    5. 비슷한 요소 선택 · BIM 속성…
    6. 회전 (R) · 복제 (Ctrl+D) · 복사 (Ctrl+C) · 3D에서 보기
    7. 삭제 (Del)

    빈 곳: 되돌리기 · 다시 실행 / 붙여넣기 · 방 감지 · 자동 치수 · 모두 선택 · 그리드 선 / 화면에 맞추기.

    층 탭: 3.10절. 3D: 5.14절.

    5. 3D 보기

    3D 보기 탭(F3, F4 도 같음)은 평면에서 그린 것을 바로 3D 건물로 보여 줍니다. 평면을 고치면 3D 도 곧 다시 만들어집니다. 처음 열 때 등각 보기로 건물 전체를 맞춥니다.

    5.1 3D 도구 모음

    도구 모음은 아이콘만 보여 줍니다. 이름과 단축키는 마우스를 올리면 툴팁으로 나옵니다. 창이 좁아 한 줄에 다 들어가지 않으면 도구 모음이 두 줄로 나뉘고, 어떤 단추도 숨겨지지 않습니다.

    눈금 있는 축 (X, Y, Z) 단추(기본 켜짐, 왼쪽 표시 → 축과 같음)는 원점에서 빨강 X · 파랑 Y · 초록 Z 축을 그리고 각 축에 눈금과 숫자를 붙입니다. 눈금 간격은 격자처럼 확대·축소에 따라 바뀝니다(멀리서는 5 m · 1 m, 가까이에서는 0.2 m …). 축과 숫자도 다른 숫자처럼 건물 뒤에서는 가려지고 X-레이 스타일에서만 비쳐 보입니다.

    5.5 평행 투영과 입면

    • O(직교 투영)는 원근 없이 평행하게 봅니다. 상태 표시줄에는 “평행 투영 / 원근 투영”으로 표시됩니다.
    • 도구 모음의 정면 입면 단추는 평행 투영 + 선 그림 스타일 + 정면 시점을 한 번에 켜서 입면도처럼 보여 줍니다. 그 상태에서 4 ~ 6 으로 다른 입면을 봅니다.

    5.7 단면

    • X(도구 모음의 현재 층에서 단면 단추, 상태 표시줄 단면 칸)는 평면에서 편집 중인 층의 바닥 + 1.2 m 높이에서 건물을 수평으로 잘라 위를 걷어 냅니다. 3D 평면도처럼 내부가 보입니다. 다시 누르면 꺼집니다.
    • 왼쪽 단면과 단계 패널: 단면 체크, 절단 높이 스테퍼(0.1 m 단위)로 높이를 바꿉니다.
    • 잘려 나간 부분은 클릭해도 선택되지 않습니다.

    5.8.1 3D 격자

    3D 격자는 평면의 격자처럼 그려집니다.

    • 가는 선 한 칸, 5칸마다 또렷한 선(5 × 5 블록).
    • 확대·축소하면 칸 크기가 ×5 / ÷5 로 바뀝니다(… 0.2 m · 1 m · 5 m · 25 m …). 그래서 어떤 거리에서 보아도 화면에서 고른 간격을 유지하고, 또렷한 선은 너무 진하지 않은 1.5 px 로, 화면 기준으로 일정합니다.
    • 격자는 지금 보는 곳(걷기에서는 서 있는 곳)을 중심으로 펼쳐지고, 또렷한 선을 따라 거리 눈금(m 또는 ft — 설정 → 3D 보기 → 3D 측정 단위)이 붙습니다.
    • G, 도구 모음 격자 단추, 표시 패널로 켜고 끕니다. 3D 를 처음 열 때 켜져 있을지는 설정 → 3D 보기 → 시작 시 표시: 축척 표시 격자.

    5.9 밀기/끌기

    밀기/끌기(도구 모음, 매스의 3D에서 밀기/끌기 단추)를 켜고 매스나 벽의 윗면을 위아래로 끌면 높이가 50 mm 단위로 바뀝니다(매스 최소 100 mm, 벽 최소 300 mm). 끄는 동안 힌트 칸에 높이: … m 가 보입니다. 한 번 끌기가 되돌리기 한 단계입니다. 같은 단추를 다시 누르거나 Esc 로 도구를 끝냅니다.

    5.10 페인트 통

    페인트 통을 켜면 왼쪽에 재료 견본(벽·바닥·지붕 재료 전부)이 나옵니다. 견본을 고르고(“재료: …”) 모델을 클릭하면:

    클릭한 것바뀌는 것
    벽, 지붕, 매스, 기둥, 계단재료
    방 바닥바닥 재료

    5.11 줄자

    줄자를 켜고 모델 위 두 점을 클릭하면 두 점 사이에 노란 선과 거리 글자가 남고 “거리: … m” 알림이 뜹니다. 여러 개를 잴 수 있고, Esc(도구 끄기) 때 지워집니다.

    5.12 일조 분석

    왼쪽 일조 분석 패널:

    • 대지·날짜·시각으로 해 위치를 끄면: 태양 방위각(15° 단위)과 태양 고도(5° 단위)를 직접 정합니다(기본 135°, 45°).
    • 켜면: 월, 일, 시각(30분 단위)으로 실제 해 위치를 계산합니다. 아래에 위도·경도, 방위각, 고도, 일출·일몰 시각이 표시되고, 해가 지평선 아래면 고도가 <0 으로 나옵니다. 대지 위치… 단추는 프로젝트 속성을 엽니다(위도, 경도, 시간대, 북쪽 방향 — 6.8절).
    • 방위각은 북쪽에서 시계 방향이며, 프로젝트의 북쪽 회전이 반영됩니다.
    • 그림자는 설정 → 3D 보기 → 3D 그림자: 태양 그림자로 켜고 끕니다(선 그림 스타일에서는 그림자 없음).

    5.13 장면

    • 장면 패널의 +(또는 3D 오른쪽 클릭 메뉴)는 지금 카메라·투영·표현 스타일·단면 높이·단계 보기를 “장면 1, 장면 2…”로 프로젝트에 저장합니다.
    • 장면 이름을 누르면 그 시점으로 부드럽게 날아갑니다. × 로 지웁니다.
    • ▶(장면 애니메이션 재생)은 장면을 차례로 돌며 계속 재생합니다(장면마다 약 2.5초). 다시 누르면(■ 정지) 멈춥니다. 장면이 없으면 “먼저 장면을 추가하세요…”.

    5.14 3D 에서 선택과 오른쪽 클릭

    • 벽, 문, 창, 방 바닥, 가구 등을 클릭하면 파랗게 강조되고, 평면에서도 선택됩니다. 오른쪽 패널에 이름, 층, 클릭한 높이와 평면에서 보기 / 속성… 단추가 나옵니다.
    • 평면의 요소에서 3D에서 보기(오른쪽 클릭, 가구 속성 단추)를 누르면 3D 탭에서 강조됩니다.

    오른쪽 버튼을 움직이지 않고 떼면 메뉴: (요소를 클릭한 상태면 맨 위에 평면에서 보기) · 되돌리기 · 다시 실행 / 등각 보기 · 평면 보기 · 정면 입면 / 걷기 (1인칭) · 현재 층에서 단면 · 직교 투영 · 문 열기 / 밀기/끌기 · 페인트 통 · 줄자 / 장면 추가 · 3D 이미지 저장 (PNG)…. 오른쪽 끌기는 여전히 화면 이동입니다.

    추정 (스냅)

    도구는 클릭-이동-클릭으로 씁니다(왼쪽 끌기는 그대로 화면 회전). 포인터가 끝점(초록), 중점(하늘색), 모서리 위(빨강), 면 위(파랑), 보조선(주황)에 붙고, 앞 점에서 빨간/초록/파란 축 방향으로 붙습니다. Shift 를 누르고 있으면 지금 방향이 고정되고, 화살표 키는 축을 고정합니다(→ 빨강, ← 초록, ↑↓ 파랑). 커서 옆에 무엇에 붙었는지가 표시됩니다.

    측정값 입력: 도구를 쓰는 중에 숫자를 치고 Enter. 3000(mm), 3m, 30cm, 사각형은 4000,3000, 원·다각형은 반지름 또는 32s(변의 수), 회전은 각도, 크기 조절은 2 또는 1,1,2, 복사 뒤에는 5x(배열)·/5(등분). 입력 중인 값은 상태 표시줄에 보입니다.

    그리기와 밀기/끌기

    • 선: 점을 차례로 클릭합니다. 시작점을 다시 클릭하면 면이 닫힙니다. 매스의 면 위에 그린 닫힌 도형은 그 면의 일부(따로 밀고 당길 수 있는 면)가 되고, 면의 한 가장자리에서 다른 가장자리까지 그은 선은 면을 둘로 나눕니다. 빈 곳에 그린 닫힌 도형은 두께 없는 새 면, 닫히지 않은 선은 선(모서리) 으로 남아 추정과 따라가기 경로에 쓰입니다. Esc 나 두 번 클릭으로 끝냅니다.
    • 사각형 / 원 / 다각형 / 호: 면 위에서 시작하면 그 면에, 아니면 현재 층 바닥에 그립니다.
    • 밀기/끌기: 어느 면이든 끌거나(끌기) 클릭-이동-클릭으로 밉니다. 이웃 면이 모두 직각이면 면이 그대로 움직이고(상자의 윗면·옆면), 그렇지 않으면 새 옆면이 생깁니다. 닫힌 매스 안쪽으로 밀면 그만큼 파이고, 끝까지 밀면 구멍이 뚫립니다. Ctrl 은 항상 새 면을 만들며 밉니다. 평면에서 만든 매스의 윗면은 예전처럼 높이만 바뀝니다.
    • 간격 띄우기: 면을 클릭하고 안쪽으로 움직이면 가장자리를 따라 안쪽 윤곽이 생깁니다(창 프레임, 테라스 난간 띠). 그 안쪽 면을 밀면 오목하게, 당기면 튀어나옵니다.
    • 따라가기: 단면 형상 면(경로 시작점에 세워 그린 면)을 클릭한 뒤 경로를 클릭합니다. 경로는 그린 선이나 면(그 가장자리를 한 바퀴)입니다. 지붕 처마 돌림띠, 걸레받이, 난간, 회전체 기둥을 만듭니다. 모서리는 각을 이등분해 꺾입니다.

    이동, 복사, 배열, 회전, 크기

    • 이동: 선택한 것(또는 클릭한 것)의 한 점을 클릭하고 옮길 곳을 클릭합니다. 높이 방향으로도 움직입니다(매스와 가구). Ctrl 은 복사 — 복사한 직후 4x 를 치면 같은 간격으로 네 개, /4 는 사이를 네 칸으로 나눈 배열이 됩니다.
    • 회전: 중심(면 위를 클릭하면 그 면의 법선이 회전축), 시작 방향, 각도를 클릭합니다. 15°마다 붙습니다. 수직축이면 모든 요소가, 다른 축이면 매스만 기울어집니다. Ctrl 복사 뒤 6x 는 원형 배열.
    • 크기 조절: 고정점, 기준점, 그리고 배율. 기준점을 축 방향으로 잡으면 그 축만 늘어납니다. 벽·실 같은 평면 요소는 균일하게만 바뀝니다.
    • 3D 에서 Shift+클릭으로 여러 개를 고릅니다.

    솔리드 도구

    닫힌 매스(또는 컴포넌트) 두 개를 선택 순서대로 고른 뒤 솔리드 도구 ▾ 에서: 합치기, 빼기(두 번째를 첫 번째에서 잘라내고 두 번째는 사라짐), 잘라내기(빼기와 같지만 자르는 쪽이 남음), 교차(겹친 부분만), 나누기(세 부분), 외곽 쉘(모두 합치기). 면 교차는 매스가 만나는 곳에 모서리만 넣어, 나뉜 면을 따로 칠하거나 밀 수 있게 합니다. 같은 평면에 붙은 면, 겹친 면, 같은 매스끼리도 깨끗한 면으로 합쳐집니다. 재료는 면마다 따라옵니다.

    컴포넌트

    • 컴포넌트 만들기: 매스를 골라 솔리드 도구 ▾ → 컴포넌트 만들기…(또는 컴포넌트 패널의 +). 이름과 개구부를 뚫음(창처럼 벽에 붙음)을 정합니다. 매스는 하나의 정의와 그 자리에 놓인 인스턴스가 됩니다.
    • 배치: 컴포넌트 패널에서 정의의 + → 3D 에서 놓을 곳을 클릭. 개구부를 뚫는 컴포넌트는 클릭한 벽에 붙어 벽에 구멍을 내고 그 안을 채웁니다(평면에서는 개구부로 보이고 벽을 따라 움직입니다).
    • 제자리 편집: 인스턴스를 두 번 클릭하면 파란 상자로 표시되며 편집 중이 됩니다. 이때 밀기/끌기, 페인트, 그리기, 간격 띄우기가 정의를 바꾸고 모든 복사본이 함께 바뀝니다. Esc 로 닫습니다.
    • 고유하게 만들기: 선택한 인스턴스에 정의의 복사본을 줍니다. 분해: 인스턴스를 보통 매스로 되돌립니다. 다음으로 바꾸기: 개체 정보에서 다른 정의로 바꿉니다.
    • 가져온 3D 모델과 기본 가구도 정의처럼 다룹니다: 같은 모델·같은 종류가 한 정의의 인스턴스이고, 컴포넌트 패널에서 개수를 보고 인스턴스 선택, 가구는 모든 인스턴스에 적용(이것의 크기·색을 모두에게)이 됩니다.

    태그, 아웃라이너, 숨기기

    • 태그 패널: 태그(스케치업의 레이어)마다 보이기 체크, 색, 항목 수. + 로 새 태그, 행의 태그 아이콘으로 선택 항목을 그 태그에 지정합니다(개체 정보의 태그 상자도 같음). 체크를 끄면 3D 에서 그 항목이 사라지고, 장면이 어떤 태그가 보이는지 기억합니다. 스타일의 태그별 색상은 항목을 태그 색으로 칠합니다.
    • 아웃라이너: 층 → 그룹 → 항목의 목록. 이름으로 거르고, 클릭하면 선택, 눈 아이콘으로 3D 에서 숨기기/보이기. 명령 선택 항목을 3D 에서 숨기기 / 모두 다시 보이기.

    재료

    페인트 통을 고르면 왼쪽에 기본 재료와 재료 패널이 나옵니다. + 로 새 재료: 이름, 색, 질감 이미지(PNG/JPG), 질감 크기(한 장이 덮는 mm), 불투명도. ⚙ 는 고른 재료(기본 재료 포함)를 편집합니다. 형태를 바꾼(메시) 매스는 면마다 칠해지고, Ctrl+클릭은 매스 전체를 칠합니다. Alt+클릭은 클릭한 면의 재료를 집어 옵니다. 질감과 재료는 프로젝트 파일에 들어갑니다.

    단면

    단면 도구로 면을 클릭하면 그 면에 단면이 놓이고(화살표가 남는 쪽을 가리킴) 모델이 잘립니다. 잘린 면은 단면 채우기 색으로 채워집니다. 단면 패널: 이름(두 번 클릭해 바꾸기), 클릭으로 활성 단면 바꾸기(다시 클릭하면 끔), 100 mm 씩 이동, 뒤집기, 삭제, 단면 평면 보기 / 단면 자르기 보기 / 단면 채우기. 여러 단면을 두고 장면마다 다른 단면을 쓸 수 있습니다. 바닥과 격자는 잘리지 않습니다.

    스타일

    스타일 패널: 면(사실적·흰색 모델·선화·투시), 모서리와 모서리 색, 윤곽선(실루엣을 굵게, 굵기), 태그별 색상, 하늘·지평선·배경·지면 색, 단면 채우기 색, 안개 밀도, 워터마크(문구와 위치 — 화면과 저장한 이미지·애니메이션에 들어감). 스타일은 프로젝트에 저장되고 장면마다 다르게 둘 수 있습니다.

    그림자, 카메라

    • 그림자 켜기/끄기와 날짜·시각(일조 분석, 5.12절)은 장면에 저장됩니다.
    • 카메라 위치: 설 곳을 클릭하면 눈높이에서 걷기 모드로 들어갑니다. 둘러보기: 제자리에서 끌어 둘러보기. 2점 투시: 수직선이 수직으로 남는 건축 투시. 시야각은 카메라 패널에서 바꿉니다.

    보조선, 각도기, 3D 치수와 문자, 축

    • 줄자에 Ctrl(또는 패널의 보조선 만들기)를 쓰면 두 점을 지나는 보조선이 생기고, 길이를 입력하면 그 거리의 보조점이 생깁니다. 각도기는 꼭짓점·기준선·각도로 기운 보조선을 만듭니다. 보조선은 추정의 대상입니다. 명령 보조선 모두 삭제.
    • 3D 치수: 두 점, 그리고 치수선이 놓일 곳. 3D 문자: 점을 클릭하고 글자를 입력하면 지시선과 함께 놓입니다.
    • 작도 축: 원점과 빨간 축 방향을 클릭하면 추정·사각형이 그 축을 따릅니다.
    • 지우개: 요소와 보조선, 3D 치수·문자, 단면을 클릭해 지웁니다.

    샌드박스 (지형)

    • 새 지형…: 폭·깊이·격자 칸을 정하면 모델 아래에 삼각형 격자 지형이 생깁니다.
    • 등고선 지형: 평면에서 등고선(폴리선; DXF 에서 가져온 높이 z/elevation, 없으면 1 m 간격)을 고른 뒤 실행하면 등고선 사이를 보간한 지형이 생깁니다.
    • 스무브: 지형을 위아래로 끌어 언덕과 골을 만듭니다(반지름은 왼쪽 패널).

    장면과 애니메이션

    장면은 카메라와 스타일 외에 보이는 태그, 활성 단면, 스타일 설정, 그림자·날짜·시각, 시야각, 2점 투시를 저장합니다. 애니메이션 패널에서 전환·머무름 시간을 정하고 애니메이션 내보내기… 로 장면 순회를 WebM 영상 또는 PNG 프레임(ZIP) 으로 저장합니다.

    개체 정보

    3D 에서 요소를 클릭하면 오른쪽에 개체 정보: 태그, 숨기기, 매스의 부피·겉넓이(닫힌 솔리드인지), 클릭한 면의 넓이, 컴포넌트의 정의와 인스턴스 수와 편집·고유하게·분해·바꾸기. 모델 정보(단위, 대지 위치)는 파일 → 프로젝트 속성 과 설정에 있습니다.

    내보내기

    메시 매스와 컴포넌트, 지형은 glTF/GLB, OBJ, STL, PLY, USDZ, COLLADA, 3MF 로 그대로 나가고(7.5절), IFC 에는 면 Brep(열린 면은 면 모델)으로, 평면 DXF 에는 윤곽으로 나갑니다. IFC 로 내보낸 메시 매스는 다시 가져오면 그대로 돌아옵니다.

    예제 15 문화 단지 (스케치업 스타일) 에 컴포넌트, 태그, 질감 재료, 보조선, 3D 치수·문자, 단면 두 개, 지형과 이 기능을 쓰는 장면들이 들어 있습니다.

    6. BIM

    평면의 요소(벽, 문·창, 방, 기둥, 계단, 가구, 지붕, 매스, 그리드)는 BIM 정보를 함께 가집니다. 요소를 고르면 오른쪽 패널 아래 BIM 칸에 나옵니다.

    칸설명
    단계기존 / 신축 / 철거 (그리드에는 없음)
    분류분류 코드(예: Uniclass 2015 코드). 분류 체계 이름은 프로젝트 속성에서
    IFC 클래스내보낼 IFC 클래스(읽기 전용) — 벽 IfcWall, 문·창 IfcDoor / IfcWindow, 방 IfcSpace, 기둥 IfcColumn, 계단 IfcStair, 가구 IfcFurniture, 지붕 IfcRoof, 그리드 IfcGrid, 매스 IfcBuildingElementProxy
    GlobalIdIFC GlobalId(22자). 누르면 클립보드에 복사
    속성 (n)…사용자 속성 창(6.4절)
    비슷한 요소 선택4.9절

    6.1 벽 타입

    BIM → 벽 타입…(도구 모음 벽 타입 단추):

    • 왼쪽 목록: 타입마다 전체 두께 · 레이어 수 · 그 타입을 쓰는 벽 수. 새 타입, 복제, 삭제(타입이 2개 이상이고 쓰는 벽이 없을 때만).
    • 오른쪽: 이름, 용도: 외벽 체크, 레이어 단면 그림(바깥이 왼쪽), 레이어 표 — 용도(마감 / 단열재 / 구조 / 공기층), 재료(벽 재료 + 단열재·공기층), 두께(5 mm 단위 스테퍼), 위로 이동, 삭제. 레이어 추가.
    • “레이어(바깥 → 안) — 합계 … mm”. 확인을 누르면 그 타입을 쓰는 모든 벽의 두께가 새 합계로 바뀝니다.

    새 프로젝트에 들어 있는 벽 타입:

    이름레이어 (바깥 → 안)합계
    Exterior brick cavity 300벽돌 100 · 단열재 80 · 콘크리트 100 · 회반죽 20300
    Exterior rendered 250회반죽 20 · 단열재 60 · 콘크리트 150 · 회반죽 20250
    Exterior timber frame 200목재 외장재 25 · 단열재 150 · 회반죽 25200
    Interior block 150회반죽 15 · 콘크리트 120 · 회반죽 15150
    Interior drywall 100흰색 페인트 13 · 단열재 74 · 흰색 페인트 13100
    Concrete 200콘크리트 200200

    벽에 타입 지정: 벽을 고르고 오른쪽 패널 벽 타입에서 선택(여러 벽은 고른 뒤 비슷한 요소 선택 등으로). 평면에는 레이어 경계선이 그려집니다. 새로 그릴 벽의 타입은 아무것도 고르지 않았을 때 오른쪽 패널 새 항목 → 벽 타입. 벽의 두께를 직접 바꾸면 타입이 풀립니다.

    6.2 단계 (리모델링)

    • 요소마다 단계: 기존(옅게), 신축(보통), 철거(빨간 점선 윤곽).
    • 새로 그릴 요소의 단계: 오른쪽 패널 새 항목 → 단계.
    • 보기 → 단계: 모두 보기 / 단계: 새 설계 / 단계: 기존 건물(3D 왼쪽 패널 단계도 같음):
    단계 보기보이는 것
    모든 단계전부
    새 설계 (철거 없음)기존 + 신축 (공사 후 모습)
    기존(공사 전)기존 + 철거 (공사 전 모습)
    • 공사비에는 신축만 들어갑니다(기존은 0, 철거는 제외).

    6.3 분류와 IFC

    • 분류 칸에 분류 코드를 적고, 프로젝트 속성 → 분류 체계(기본 Uniclass 2015)에 체계 이름을 적으면 IFC 의 분류 참조로 나갑니다.
    • 단계, 벽 타입(레이어 재료), 그리드, 사용자 속성은 모두 IFC 내보내기에 포함됩니다(7.5절).

    6.4 사용자 속성 (BIM 속성)

    BIM → 선택 요소의 BIM 속성…(오른쪽 클릭 BIM 속성…, BIM 칸 속성 (n)…):

    6.7 모델 검사

    모델 검사는 회로 설계의 ERC/DRC 에 해당하는 건축 검사입니다.

    • 기본으로 그리는 동안 계속 실행됩니다(설정 → 평면도 → 그리는 동안 모델 검사 실행).
    • F5(빌드 → 모델 검사, 도구 모음, 상태 표시줄 검사 칸)는 지금 검사하고 “모델 검사: 오류 n개, 경고 n개” 또는 “모델 검사 통과 — 문제가 없습니다.”를 알리며 오른쪽 패널을 엽니다.
    • 오른쪽 패널 아래 모델 검사 목록: 오류·경고 개수 알약, 항목마다 메시지와 코드 · 층. 항목을 누르면 그 층으로 가서 문제 위치를 확대하고 주황 원으로 깜박이며 관련 요소를 선택합니다. ↻ 단추는 다시 검사.
    • 문제 위치는 평면에도 표시됩니다. 평면도 탭과 접힌 오른쪽 패널에 개수 배지가 붙습니다.

    검사 규칙 전체(메시지는 화면에 나오는 그대로)는 12.2절에 있습니다.

    6.9 도면화: 뷰, 시트, 일람표

    Revit의 프로젝트 탐색기나 ArchiCAD의 내비게이터처럼, 프로젝트 하나에 뷰(평면도·천장도·단면도·입면도·상세·제도 뷰·범례·3D·일람표)와 시트(표제란이 있는 도면 한 장)가 함께 저장됩니다. 모든 뷰는 모델에서 바로 만들어지므로 벽을 고치면 단면도·입면도·시트가 함께 바뀝니다.

    • 프로젝트 탐색기: 왼쪽 패널 맨 위(평면도·3D 탭)와 뷰와 시트 탭(F6)의 왼쪽 패널 전체. 평면도·천장도·단면도·입면도·상세 뷰·제도 뷰·범례·3D 뷰·일람표·시트(배치된 뷰 포함)·뷰 템플릿·개정·출판 세트가 나무 구조로 나옵니다. 누르면 열고, 우클릭하면 속성·가시성·이름 바꾸기·복제·시트에 배치·DXF·삭제 메뉴가 나옵니다. 뷰를 끌어 열린 시트 위에 놓으면 배치됩니다.
    • 열리는 곳: 평면도는 평면도 탭, 3D 뷰(장면)는 3D 탭, 나머지는 뷰와 시트 탭에 열립니다. 이 탭 위쪽 띠에 열어 둔 뷰가 탭처럼 남고, 문서 탭(파일)마다 따로 기억됩니다.
    • 메뉴: 도면 메뉴에 모든 명령이 있고, 평면 도구 모음에는 뷰 분할 단추(단면·입면·콜아웃·외부/내부 입면·천장도)와 주석 분할 단추가 있습니다.
    • 예전 파일을 열면 층마다 평면도·천장도와, 층마다 평면 한 장씩인 시트(A101, A102 …)가 자동으로 생깁니다 — 이전의 인쇄와 같은 구성입니다.

    6.10 단면도와 입면도

    • 단면도: 평면 도구 모음의 뷰 ▾ → 단면도, 또는 도면 → 단면도. 단면선의 시작점과 끝점을 클릭하면 됩니다. 그린 방향의 왼쪽을 바라보며(동쪽으로 그리면 북쪽을 봄), 기호 우클릭 → 보는 방향 뒤집기로 바꿉니다. 평면에 단면 기호(머리의 위 칸 = 시트 위 상세 번호, 아래 칸 = 시트 번호)가 생기고, 더블클릭하면 열립니다. 기호 끝점을 끌어 단면선을 옮기면 뷰가 바로 다시 만들어집니다.
    • 입면도: 뷰 ▾ → 입면도 후 기호 위치를 클릭하면 건물 쪽(90° 단위)을 바라봅니다. 외부 입면도 (북·남·동·서) 는 네 개를 한 번에, 실 내부 입면도는 선택한 실 안쪽 네 벽(A–D)을 만듭니다.
    • 도면 내용: 절단면에 걸린 요소는 단면(포셰) 으로 채워지고 재료별 해치(콘크리트 점·벽돌 사선·단열재 지그재그·목재 결 …)가 들어가며, 그 너머의 요소는 숨은선을 제거한 투영선으로 그려집니다. 층 높이마다 레벨선과 머리(이름, ±0.000 표고), 단면을 지나는 그리드선과 번호 원이 자동으로 붙습니다. 벽·슬래브·지붕·계단·기둥·가구, 그리고 새로 추가되는 모든 요소 종류가 3D 모델 그대로 잘리고 투영됩니다.
    • 상세 수준: 개략 = 검은 단면, 보통 = 벽 구조 재료 하나의 해치, 상세 = 벽 유형의 레이어마다 띠와 해치·경계선.
    • 자르기 영역(점선 사각형, 모서리 손잡이로 크기 조절)과 먼 쪽 자르기 깊이(뷰 속성)로 보이는 범위를 정합니다.

    6.11 천장도, 콜아웃, 제도 뷰, 범례

    • 천장도: 층마다 있습니다(프로젝트 탐색기 → 천장도, 또는 현재 층 천장도). 절단 높이(기본 2300 mm)에서 위를 본 모습을 평면 방향 그대로 그리고, 실 이름과 천장 높이(CH), 조명 기호를 붙입니다.
    • 콜아웃(상세 뷰): 콜아웃 도구로 평면이나 단면 위에 영역을 끌면 그 부분을 큰 축척(기본 1:20, 상세)으로 보여 주는 상세 뷰가 생기고, 원본 뷰에 콜아웃 기호가 그려집니다.
    • 제도 뷰: 모델 없이 선·영역·글자만 그리는 빈 뷰(표준 상세 등).
    • 범례: 벽 유형(레이어 띠와 두께)이나 벽 재료 목록을 그립니다.

    6.12 뷰 속성, 가시성/그래픽, 뷰 템플릿

    • 뷰 조절 막대(뷰 아래): 축척, 상세 수준, 자르기 켜기/보이기, 가시성/그래픽, 사용 중인 템플릿과 생성 상태.
    • 뷰 속성…: 이름, 참조 번호, 축척, 상세 수준, 단계 필터(전체 / 신축 / 기존), 뷰 템플릿, 절단 높이(평면·천장도 — 평면에서는 절단 높이보다 높은 창은 빠지고 그 위의 가구는 점선), 먼 쪽 자르기 깊이, 단면 방향 뒤집기, 자르기.
    • 가시성 / 그래픽…: 범주별 보이기/숨기기(벽·문·창·실·기둥·계단·가구·조명·지붕·매스·슬래브 … 그리고 치수·글자·태그·그리드·레벨·뷰 기호·상세선·채움 영역·개정 구름·기호), 단면·입면에서는 범주별 단면 채움 색 재지정.
    • 뷰 템플릿…: 축척·상세 수준·단계·숨길 범주를 묶어 여러 뷰에 한꺼번에 적용합니다(“적용할 뷰” 체크). 템플릿이 있는 뷰는 그 값이 우선합니다. 기본 템플릿 4개: 건축 평면 1:100, 가구 평면 1:50, 시공 단면 1:50, 프레젠테이션 입면 1:100.

    6.13 주석

    6.14 시트와 출판

    • 새 시트: 번호가 A101, A102 … 처럼 이어집니다. 뷰 배치… 로 고르거나, 탐색기에서 뷰를 끌어 놓으면 빈 곳에 그 뷰의 축척으로 배치됩니다. 뷰포트를 끌어 옮기고, 더블클릭하면 그 뷰가 열립니다. 평면·천장도·단면·입면·상세·범례·3D(숨은선 액소노메트릭)·일람표를 놓을 수 있고, 일반 뷰는 시트 하나에만 놓입니다(다른 시트용은 복제).
    • 뷰포트 아래에는 상세 번호·뷰 이름·축척 제목이, 오른쪽에는 표제란(회사, 프로젝트, 건축주·주소, 개정표, 작성/검토/승인, 날짜, 축척 — 서로 다르면 “도면 표기”, 상태, 시트 이름, 시트 번호, 현재 개정)이 그려집니다. 필드는 시트 속성…, 프로젝트 정보는 파일 → 프로젝트 속성에서 고칩니다.
    • 개정…: 순번·이름·날짜·설명·수신·발행자·발행 여부. 시트에 체크했거나 그 시트의 뷰에 개정 구름이 있으면 개정표에 올라갑니다.
    • 시트 목록(도면 목록): 시트 번호·이름·현재 개정·날짜의 일람표 — 표지 시트에 놓습니다.
    • 출판…: 시트를 골라(또는 저장한 출판 세트로) 인쇄 / PDF(인쇄 창이 “시트” 모드로 열려 시트마다 자기 용지 크기로 인쇄), SVG, DXF(시트마다 파일 하나)로 내보냅니다. 인쇄 창에서도 인쇄: 층별 평면 / 시트를 고를 수 있습니다.
    • 뷰 또는 시트를 DXF로 내보내기…: 뷰는 건물 1:1 mm, 시트는 용지 mm(AutoCAD R12). 선 굵기별 레이어 A-HEAVY / A-MEDIUM / A-THIN, 글자는 A-TEXT.

    6.15 일람표 뷰

    새 일람표… 에서 범주(실, 문, 창, 벽, 가구, 기둥, 층, 시트, 뷰)를 고르면 표가 뷰로 열립니다.

    • 필드, 필터, 정렬…: 필드 고르기와 순서, 필터(=, ≠, >, <, ≥, ≤, 포함), 정렬 두 단계, 그룹(소계 포함), 총계, 계산 값(예: area * 1.1 — 필드 키와 + − * / 괄호).
    • 열 머리를 누르면 정렬, 편집 가능한 셀(이름, 번호, 문 크기, 창대, 층 높이, 사용자 속성 …)은 더블클릭해 고치면 모델이 바뀝니다.
    • CSV 내보내기…(Excel용 UTF-8), 시트에 표로 배치.

    • 파일 → 최근 파일…: 이름·경로·시각 목록. 누르면 열고, ×(목록에서 제거)는 하나만 지우고, 목록 지우기는 전부 지웁니다. 파일 자체는 지워지지 않습니다.
    • 파일 → 최근 파일 지우기, 시작 페이지 목록 지우기도 같습니다(“최근 파일 목록을 지웠습니다.”).
    • 열 수 없는 파일(옮겨졌거나 지워짐)은 열려고 할 때 목록에서 빠집니다.

    7.4 가져오기

    파일 → 가져오기(DXF, IFC, 3D 모델, 이미지…)…(Ctrl+I)는 지원하는 모든 파일을 고르는 창을 엽니다. 파일 → 가져오기 ▸ 는 형식별 명령 목록입니다: 가져오기(전체) · DXF 도면 가져오기… · IFC 가져오기(BIM)… · Sweet Home 3D, gbXML 또는 IFC ZIP 가져오기… · 3D 모델 가져오기(OBJ, FBX, GLB, STL…)… · SVG 도면 가져오기… · 이미지를 트레이싱 밑그림으로 가져오기….

    형식가져오는 방법
    DXF (.dxf)DXF 도면 가져오기 창: 파일의 단위(자동 감지 / mm / cm / m / 인치 / 피트), 층(넣을 층), 도면을 평면 원점으로 옮기기. 선, 폴리선, 호, 원, 스플라인, 텍스트, 블록, 해치 윤곽이 각자의 CAD 레이어로 들어옵니다. 텍스트(ASCII) DXF 와 바이너리 DXF(AutoCAD 의 DXFOUT 바이너리 옵션, R12 ~ 2018)를 모두 읽습니다. 끝나면 “… 가져옴: 도면 요소 n개, 텍스트 n개 (단위)”, 주의할 점이 있으면 가져오기 메모 창
    DWG (.dwg)DXF 와 같은 DWG 도면 가져오기 창. AutoCAD R13 ~ 2025 가 저장한 파일(DWG R13·R14·2000·2004·2007·2010·2013·2018 형식)을 직접 읽습니다. 모형 공간의 선, 폴리선, 호, 원, 타원, 스플라인, 텍스트·MTEXT, 블록(중첩·축척·회전), 치수, 해치 윤곽, 지시선이 원래 레이어(색·켜짐/꺼짐 포함)로 들어옵니다. 그 밖에: 다중 지시선(지시선·화살촉·연결선·문자), 표(표의 익명 블록, 없으면 셀 격자와 셀 문자), 다중선, 나선, 호 길이 치수·공차, 무한선·광선(도면 범위의 두 배에서 자름), 와이프아웃(윤곽), 래스터 이미지(그림 파일이 도면 옆에 있으면 트레이싱 밑그림, 없으면 테두리), 영역·3D 솔리드·바디(ACIS 모형의 모서리: 직선·원·호·타원, 스플라인 모서리는 직선으로), R2018 여러 줄 속성, 그리고 읽는 법이 따로 없는 객체(메시, 서피스, 프록시·타사 객체 등)는 파일에 저장된 프록시 그래픽으로 그립니다. 파일에 레이아웃(도면 공간)이 있으면 창에 공간이 나옵니다: 모델 공간(기본) / 레이아웃: 이름(그 레이아웃의 객체와, 뷰포트마다 축척·잘라 낸 모델; 뷰포트에서 동결한 레이어는 빼고) / 모든 레이아웃을 나란히(모델 오른쪽에 레이아웃을 차례로, 레이어는 `레이아웃레이어). **외부 참조**(XREF)는 참조한 .dwg/.dxf 가 가져오는 도면과 같은 폴더에 있으면(데스크톱) 읽어서 그 자리에 XREF레이어` 레이어로 넣고, 없으면 메모에 알립니다. 빛(LIGHT)·OLE 객체·PDF 밑그림처럼 그릴 것이 없는 객체만 건너뛰고 가져오기 메모에 개수를 알려 줍니다. R12 이전 파일과 암호가 걸린 도면은 열 수 없습니다
    SVG (.svg)SVG 도면 가져오기 창(위와 같은 항목). 경로, 도형, 텍스트가 SVG 레이어로 들어옵니다. <use>·<symbol> 은 펼쳐 넣고, 경로 위 텍스트(<textPath>)는 경로 시작점에서 경로 방향으로 놓인 한 줄 텍스트가 됩니다. 들어 있는 이미지(<image>)는 SVG 의 위치·크기·회전 그대로 밑그림(이미지를 가져올 때와 같음)이 됩니다 — data: 로 들어 있는 이미지는 어디서나, SVG 옆 폴더의 이미지 파일(상대 경로)은 데스크톱판에서 읽습니다. 웹 주소로 연결된 이미지, 클리핑 경로·마스크(잘리지 않은 채로 들어옴)는 가져오기 메모에 적힙니다
    IFC (.ifc)지금 프로젝트를 바꿉니다(저장 확인). 층, 벽, 문·창, 방, 슬래브, 지붕, 계단, 기둥, 가구를 읽어 새 프로젝트(이름 파일이름.myarch, 저장 안 된 상태)로 엽니다. “… 가져옴: 층 n개, 벽 n개, 문/창문 n개, 방 n개.”
    Sweet Home 3D (.sh3d)IFC 처럼 지금 프로젝트를 바꿉니다. 모든 버전의 파일을 읽습니다: 5.3 이후는 Home.xml, 그 전 파일은 Java 직렬화된 집 데이터. 층, 벽(곡선 벽은 짧은 직선으로, 바깥 면의 색이나 텍스처), 문·창문(우리 개구부로), 바닥 텍스처·색이 있는 방, 치수선, 글자, 폴리라인, 방위표를 읽습니다. 가구·조명·지붕을 어떻게 가져올지 대화상자에서 고릅니다: 파일의 3D 모델 사용(기본) — 가구마다 파일에 들어 있는 OBJ / DAE / 3DS 모델과 텍스처, 모델 회전, 대칭, 크기, 높이, 색·재질 바꿈을 그대로 살린 모델 가구가 되고, 같은 모델을 쓰는 가구는 프로젝트에 저장된 모델 하나를 함께 씁니다(라이브러리의 가져온 3D 모델). Sweet Home 3D 지붕(가구로 되어 있음)도 모델로 들어옵니다 — 또는 MyArchitecture 가구 모양 사용: 이름으로 라이브러리의 가장 가까운 항목에 맞추고(없으면 크기·색이 같은 상자), 계단은 계단으로, 지붕 가구는 외곽선으로 만든 우리 지붕이 됩니다. 벽·바닥 텍스처는 그림을 담은 프로젝트 재료가 됩니다(그림이 없으면 가장 가까운 기본 재료). 조명은 빛 없이 들어오고(빛은 라이브러리 조명으로), 천장 텍스처는 가져오지 않으며, 벽은 양면에 마감 하나만 보입니다
    gbXML (.gbxml, .xml)Revit, ArchiCAD, Vectorworks, OpenStudio 의 에너지 분석용 모델. IFC 처럼 지금 프로젝트를 바꿉니다. 층, 벽, 문·창문, 공간(→ 방), 지붕을 읽습니다. 벽 두께는 구성 재료에서, 없으면 200 mm. 한 벽이 공간마다 여러 면으로 나뉘어 있으면(같은 CADObjectId) 다시 벽 하나로 잇습니다. 평지붕은 공간마다 나뉜 조각을 한 지붕으로 합치고, 경사 지붕은 이어진 면끼리 묶어 면마다 기울기·방향을 재서 박공·모임·외쪽 지붕(물매, 윤곽, 처마 내밀기, 높이, 방향)으로 다시 만듭니다. 세 가지 중 어느 것에도 맞지 않는 지붕(ㄱ자·골이 있는 지붕, 물매가 다른 지붕 등)은 그 경사면 그대로의 매스가 되어 3D 모양이 맞게 보입니다. 박공 끝의 삼각형 면은 벽이 아니라 지붕이 그립니다. UTF-16 파일도 읽습니다
    ifcXML (.ifcxml, .xml)XML 로 쓴 IFC. IFC4 ifcXML(<ifcXML>)과 IFC2x3 ifcXML(<iso_10303_28>)을 모두 읽어 .ifc 와 똑같이 가져옵니다(층, 벽, 문·창, 방, 슬래브, 지붕, 계단, 기둥, 가구, 벽 타입, 속성)
    IFC ZIP (.ifczip)압축을 풀어 안의 .ifc 또는 .ifcxml 을 IFC 와 똑같이 가져옵니다
    3D 모델 (.obj .fbx .glb .gltf .stl .dae .3mf .3ds .ply .wrl .amf)3D 모델 가져오기 — 이름 창: 파일의 단위(자동 감지 …), 위쪽 축(자동 / Y가 위쪽 / Z가 위쪽). 모델은 가구 하나가 되어 지금 층의 화면 가운데(또는 놓은 자리)에 들어오고 프로젝트 파일 안에 저장됩니다. 가구 라이브러리 “가져온 3D 모델”에서 몇 번이든 다시 놓을 수 있습니다. OBJ 는 같은 폴더의 같은 이름 .mtl 재질도 읽습니다
    Rhino 3DM (.3dm)먼저 Rhino 3DM 가져오기 창에서 고릅니다. 3D 모델: 위의 3D 모델처럼 가구 하나가 됩니다. 파일의 단위(ModelUnitSystem)를 그대로 쓰고, 서피스·폴리서피스·돌출(Extrusion)·메시·SubD 를 레이어와 재질 색으로, 블록(InstanceDefinition)은 변환을 적용해 펼쳐 넣습니다. 파일에 렌더 메시가 저장되어 있으면 그대로 쓰고, 없으면(“작게 저장”, 스크립트로 만든 파일) 평평한 면은 정확히, 굽은 면은 근사로 삼각형을 만듭니다. 숨긴 레이어·객체, 커브·점·문자·치수·해치·조명은 넣지 않고 가져오기 메모에 개수를 적습니다. 평면 도면: DXF 와 같은 창(단위·층·원점으로 옮기기, 서피스·폴리서피스·메시의 모서리도 포함)으로, 위에서 본 모습 — 커브, 서피스·메시 모서리와 윤곽, 점(작은 ×), 문자·텍스트 점 — 이 Rhino 레이어마다 CAD 레이어 하나로(레이어 색·숨김 그대로) 들어와 그 위에 벽을 따라 그릴 수 있습니다. 원·호는 원·호로 남고, 위에서 겹쳐 보이는 모서리는 하나로 합칩니다. Rhino 2 ~ 8 파일을 읽으며, 읽기 엔진(McNeel 의 openNURBS/rhino3dm, WebAssembly 약 2.7 MB)은 .3dm 을 처음 가져올 때만 불러옵니다
    이미지 (.png .jpg .jpeg .webp .gif .bmp)이미지를 트레이싱 밑그림으로 가져오기 창: 평면에서의 이미지 폭(mm), 불투명도(10 ~ 100%). 지금 층에 밑그림으로 깔립니다

    7.6 인쇄와 PDF

    ![인쇄 창: 왼쪽은 프린터·용지·여백·축척·내용 설정, 오른쪽은 실제 시트 미리 보기, [인쇄] 는 바로 인쇄](docs/images/ko/print-preview.webp) 인쇄 창: 왼쪽은 프린터·용지·여백·축척·내용 설정, 오른쪽은 실제 시트 미리 보기, [인쇄] 는 바로 인쇄

    파일 → 인쇄 / PDF…(Ctrl+P)는 인쇄 창을 엽니다. 창 맨 위 제목 막대에는 프로그램 아이콘과 “인쇄”, 닫기 단추(✕)가 있고, 창은 편집기의 대부분을 차지합니다(오른쪽 아래 모서리를 끌어 크기를 바꿀 수 있습니다). 왼쪽에서 페이지를 자세히 설정하면 오른쪽 미리 보기의 실제 시트가 바로 바뀝니다.

    왼쪽 설정(제목을 눌러 접고 펼 수 있고, 길면 이 칸만 스크롤됩니다):

    • 프린터(데스크톱판)
      • 프린터: 이 컴퓨터의 프린터 목록. 처음에는 운영 체제의 기본 프린터가 골라져 있고, 마지막에 쓴 프린터를 기억합니다.
      • 매수: 1–99부.
      • 색상: 색상 / 흑백. 흑백은 시트를 검정·회색으로 그리고 프린터에도 흑백으로 보냅니다.
    • 페이지
      • 용지 크기: A4, A3, A2, A1, A0, A5, Letter, Legal, Tabloid, 사용자 지정 크기(너비 × 높이 mm, 50–2000).
      • 방향: 가로 / 세로. 미리 보기의 종이 모양이 바로 바뀝니다.
      • 여백: 없음, 좁게(5 mm), 보통(10 mm), 넓게(20 mm), 사용자 지정(위·아래·왼쪽·오른쪽 mm). 미리 보기에는 여백이 파란 점선으로 보입니다(인쇄되지 않음).
    • 도면
      • 축척: 페이지에 맞춤, 1:20 … 1:1000, 사용자 지정(1 : N). 기본은 프로젝트의 도면 축척입니다. 고른 축척에서 도면이 종이를 벗어나면 미리 보기 아래에 “1:N 축척에서는 도면이 페이지를 벗어납니다.” 가 나오고, 벗어난 부분은 잘립니다.
      • 페이지 가운데에 배치: 끄면 도면을 왼쪽 위에 맞춥니다.
      • 층(층마다 시트 한 장): 인쇄할 층(기본은 지금 층), 모두 선택. 하나도 없으면 “층을 하나 이상 선택하세요”.
      • 페이지 범위: 모든 페이지 / 페이지 지정(예: 1-2, 4).
    • 표시할 내용: 가구, 치수, 방 면적, 지붕 (점선), CAD 레이어, 텍스트와 라벨, 구조 그리드.
    • 시트 구성: 도면 테두리, 표제란, 방위표와 축척 막대, 머리글(프로젝트 이름과 날짜), 바닥글(페이지 번호). 표제란 내용은 파일 → 프로젝트 속성에서 가져옵니다.

    오른쪽 미리 보기: 위쪽 막대의 ◀ ▶ 로 페이지를 넘기고(“1 / 2 페이지”), − / + 로 확대·축소, 맞춤 으로 창에 맞춥니다. 아래 줄에 장 수, 용지, 방향, 축척, 색상, 매수가 요약됩니다.

    시트에는 테두리, 오른쪽 아래 표제란(제목, 건축주·주소, 도면 “평면도 — 층”, 축척, 도면 번호 n / 전체, 작성자, 날짜, 개정), 왼쪽 아래 방위표(북쪽 회전 반영)와 축척 막대가 들어갑니다(각각 끌 수 있음).

    8.2 테마

    • 제목 표시줄 팔레트 단추: 무작위 테마(“테마: 이름” 알림).
    • ▾ (테마 선택): 어두운 테마 20 · 밝은 테마 20 · 사용자 테마 세 열. 지금 테마가 강조됩니다. 새 사용자 테마…, 사용자 테마의 ×(삭제), 자동 → 시스템 설정 따르기.
    • 테마 갤러리(설정 → 모양 → 테마…, 명령 팔레트 “테마…”): 견본 카드 갤러리와 “시스템의 밝은/어두운 설정을 따릅니다(마지막으로 고른 어두운 테마와 밝은 테마 사용)” 체크.
    • 사용자 테마 창: 이름, 유형(어둡게/밝게), 강조색, 배경, 패널, 텍스트 색. 바꾸는 즉시 프로그램 전체와 평면 캔버스에 미리 적용됩니다. 테마 저장.
    • 평면 도면과 3D 배경(하늘 그라데이션)도 테마의 밝기를 따릅니다.

    보기 메뉴 끝의 테마…, 어두운 테마, 밝은 테마, 시스템 테마(그리고 명령 팔레트)로도 바로 바꿀 수 있습니다.

    9. 튜토리얼

    도움말 → 따라 하는 튜토리얼(시작 페이지 첫 카드, 도구 모음의 플라스크 단추)은 실제 프로그램을 움직이며 모든 기능을 가르칩니다. 지금 프로젝트를 바꾸므로 저장하지 않은 변경이 있으면 먼저 저장 여부를 묻습니다.

    9.1 두 가지 모드

    • 보기: 프로그램이 커서를 움직이며 각 단계를 직접 실행합니다. ▶ 자동 재생 / ■ 일시 정지, 이전 단계, 다음 단계 실행, 속도 0.5× · 1× · 2× · 4×.
    • 따라 하기: “직접 해 보세요:” 아래 할 일이 나오고, 눌러야 할 곳이 화면에 표시됩니다. 해내면 자동으로 확인하고(“✓ 잘했습니다!”) 잠시 뒤 다음 단계로 넘어갑니다. 막히면 보여 주기(프로그램이 대신 실행), 할 일이 없는 설명 단계는 다음, 건너뛰려면 건너뛰기.

    튜토리얼 창은 제목 부분을 끌어 옮길 수 있고, 위쪽 목록에서 레슨을 바로 고를 수 있습니다. 진행 막대와 “단계 n / 전체”가 보입니다. 앞 레슨의 결과가 필요한 레슨을 바로 고르면 “앞 레슨의 결과를 빠르게 만드는 중…” 후에 시작합니다. 단계가 예상대로 끝나지 않으면 다시 시도 / 건너뛰기를 고릅니다.

    11. 문제 해결과 FAQ

    프로그램이 열리지 않거나 두 번째 창이 안 열립니다. MyArchitecture 는 하나만 실행됩니다. 이미 실행 중이면 그 창이 앞으로 나오고 파일이 그 창에서 열립니다. 작업 표시줄에서 기존 창을 찾아 보세요.

    벽이 원하는 각도로 안 그려집니다 / 길이가 100 단위로만 바뀝니다. 직교(F8)가 켜져 있으면 45° 단위·격자 단위로 맞춰집니다. Shift 를 누른 채 그리거나, 직교·스냅(F9)을 끄거나, 격자 간격을 줄이거나, 숫자로 길이와 각도(3600<30)를 입력하세요.

    A 로 클릭했는데 방이 안 생깁니다. 벽이 완전히 닫혀 있어야 합니다. 벽 끝이 서로(또는 다른 벽 위에) 정확히 닿았는지 확인하세요 — 벽을 그릴 때 끝점(주황 네모)이나 벽(초록 삼각형) 스냅 표시가 떠야 닿은 것입니다. 닫히지 않은 곳은 Shift+클릭으로 모서리를 직접 그려 방을 만들 수 있습니다. 너무 작은 영역(0.01 m² 미만)은 무시됩니다.

    문을 넣으려는데 “이 벽은 너무 짧아 넣을 수 없습니다.” 벽 길이가 문 폭 + 20 mm 보다 짧습니다. 오른쪽 패널 새 항목 → 문 폭을 줄이거나 벽을 늘리세요. 벽이 여러 조각으로 나뉘어 있으면 오른쪽 클릭 → 일직선 벽 합치기.

    빈 곳을 끌었는데 상자 선택이 아니라 화면이 움직입니다. 기본값입니다. Shift+끌기를 쓰거나, 설정 → 단위와 격자 → 빈 캔버스에서 왼쪽 끌기 → 상자 선택으로 바꾸세요.

    요소를 끌었는데 화면만 움직입니다. 손(이동) 모드가 켜져 있습니다. Esc 나 도구 모음의 손 단추로 끄세요.

    3D 가 비어 있거나 일부가 안 보입니다. 3D 왼쪽 패널의 층 체크, 표시(가구·지붕·매스 모델), 단계 보기, 단면을 확인하세요. 탐색이 꼬였으면 1(등각) 또는 Home. “3D 보기를 사용할 수 없습니다”가 나오면 그래픽 드라이버(WebGL)를 확인하세요.

    3D 에서 클릭해도 선택이 안 됩니다. 밀기/끌기·페인트 통·줄자 도구가 켜져 있으면 클릭이 도구로 갑니다. Esc 로 끄세요. 단면으로 잘려 나간 부분은 선택되지 않습니다.

    모델 검사 경고를 무시하고 싶습니다. 경고는 작업을 막지 않습니다. 그리는 동안 계속 검사하는 것이 거슬리면 설정 → 평면도 → 그리는 동안 모델 검사 실행을 끄고 필요할 때 F5 를 누르세요.

    가져온 DXF 가 너무 크거나 작습니다 / 엉뚱한 곳에 있습니다. 가져오기 창에서 파일의 단위를 직접 고르고, 도면을 평면 원점으로 옮기기를 체크하세요. 그다음 Home.

    가져온 3D 모델 크기가 이상합니다 / 누워 있습니다. 가져오기 창의 파일의 단위와 위쪽 축(Y가 위쪽 / Z가 위쪽)을 바꿔 다시 가져오세요. 들어온 뒤에도 오른쪽 패널에서 폭·깊이·높이를 바꾸거나 크기 조정…을 쓸 수 있습니다.

    DWG 파일을 열고 싶습니다. 파일 → 가져오기… 로 바로 가져옵니다(AutoCAD R13 ~ 2025 가 저장한 파일). 레이아웃은 가져오기 창의 공간에서 고르고, 외부 참조와 이미지는 같은 폴더에 두면 함께 들어옵니다. DWG 로 내보내려면 파일 → 내보내기 ▸ → DWG 내보내기 (AutoCAD 2000)…. R12 이전 파일은 AutoCAD 에서 DXF 로 저장해 가져오세요.

    SKP / RVT / PLN 파일을 열고 싶습니다. 직접 읽을 수 없습니다. 7.7절처럼 DAE·OBJ·glTF / IFC·gbXML 로 바꿔서 가져오세요.

    모델을 에너지 해석 프로그램(OpenStudio, DesignBuilder, IES VE…)으로 보내려면? 방을 그린(또는 방 감지) 뒤 파일 → 내보내기 ▸ → gbXML 내보내기(에너지 해석)… 를 쓰세요(7.5절). 방이 공간, 벽·바닥·지붕이 양쪽 공간이 붙은 면, 문·창문이 개구부가 됩니다. 예전 프로그램이 7.03 을 못 읽으면 gbXML 버전을 6.01 로 고르세요.

    gbXML 로 가져온 경사 지붕이 매스로 들어왔습니다. 박공·모임·외쪽 지붕으로 맞출 수 없는 지붕(ㄱ자 지붕, 골이 있거나 물매가 서로 다른 지붕)은 원래 경사면 그대로의 매스로 가져와 3D 모양을 지킵니다. 필요하면 매스를 지우고 지붕 도구로 다시 그리세요.

    웹판에서 PDF 로 저장하려면? 인쇄 창의 PDF로 저장… 을 누르세요. 웹판도 시트를 벡터 PDF 한 파일로 바로 내려받습니다(7.6절). 한글이 네모로 보이면 PDF 보기 프로그램에 한글 글꼴이 없는 것입니다 — 다른 보기 프로그램(브라우저, Acrobat Reader)으로 열거나 SVG로 저장… 을 쓰세요.

    저장 안 하고 꺼졌습니다. 자동 저장이 켜져 있었다면 다음 실행 때 작업 복구 창에서 복원을 누르세요(7.2절).

    튜토리얼을 하고 나니 격자·단위 설정이 바뀌었습니다. 튜토리얼은 닫을 때 설정을 되돌립니다. 튜토리얼 창의 ✕(튜토리얼 끝내기)로 닫았는지 확인하세요. 프로그램을 강제로 껐다면 설정 창에서 다시 맞추세요.

    화면이 너무 작거나 큽니다 / 창을 더 좁힐 수 없습니다. 설정 → 모양 → 화면 크기를 바꾸세요. 창의 최소 크기는 메뉴·탭·도구 모음 단추가 하나도 가려지지 않도록 정해지므로, 화면 크기를 줄이면 창도 더 좁힐 수 있습니다.

    설정을 처음으로 돌리고 싶습니다. 설정 → 기본값으로 재설정. 완전히 지우려면 프로그램을 끄고 settings.json(1.2절 위치)을 지우세요.

    F1 을 눌렀는데 설명서가 안 열립니다. F1 은 프로그램 폴더의 docs/USERSGUIDE.ko.html(영어 화면에서는 USERSGUIDE.en.html)을 별도 창으로 엽니다. 이 HTML 은 이 문서(UsersGuide.md)로 만들어지므로, 열리지 않으면 UsersGuide.md 를 직접 열어도 같은 내용입니다.
