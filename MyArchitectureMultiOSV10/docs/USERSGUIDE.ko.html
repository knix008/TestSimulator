    MyArchitecture 10.0 사용자 가이드

    사용 설명서 · MyArchitecture 10.0

    MyArchitecture v10.0.0 · 저작자: SHKWON (knix008@naver.com)

    평면도를 그리면 바로 3D 건물이 되는 건축 설계 프로그램입니다. 벽·문·창·방·계단·지붕·기둥으로 평면을 그리고, 스케치업식 매스로 볼륨을 잡고, 3D 에서 해와 그림자·걷기·단면·입면을 보고, 벽 타입·단계·분류·IFC 속성 같은 BIM 정보를 붙이고, 일람표와 공사비를 뽑고, DXF·IFC·glTF/GLB·OBJ·PDF 등으로 주고받는 일을 한 창에서 합니다.

    이 문서는 모든 기능의 참조 설명서입니다. 처음이라면 1장과 3장을 차례로 읽고, 나머지는 필요할 때 찾아보세요. 프로그램 안의 따라 하는 튜토리얼(9장)로 같은 내용을 직접 해 볼 수도 있습니다.

    표기 약속

    • 메뉴는 파일 → 예제 열기… 처럼 화면에 보이는 한국어 이름 그대로 씁니다. 영어 화면을 쓰는 분을 위해 필요한 곳에는 영어 이름을 괄호로 덧붙였습니다.
    • 키는 Ctrl+Z 처럼 씁니다. macOS 에서는 Ctrl 대신 ⌘(Command)도 됩니다.
    • 길이 단위는 따로 말하지 않으면 mm 입니다. 프로그램 내부도 모두 mm 로 계산합니다.

    1. 시작하기

    1.1 설치

    환경방법
    WindowsMyArchitecture-Setup-10.0.0.exe 실행 → 설치 언어(한국어/English) 선택 → 이미 설치된 MyArchitecture 가 있으면 “이미 설치된 MyArchitecture 가 있습니다… 기존 프로그램을 완전히 삭제합니다” 안내(확인 = 이전 설치를 지우고 계속, 취소 = 설치 중단) → %APPDATA%\MyArchitecture 에 이전 데이터가 있으면 “저장한 데이터(설정, 자동 저장)가 있습니다. 삭제하시겠습니까?”(예/아니요) → 설치 폴더 선택. 바탕 화면·시작 메뉴 바로 가기와 .myarch 파일 연결이 만들어집니다.
    macOSdmg 를 열고 응용 프로그램 폴더로 끌어 놓습니다. 서명이 없으므로 처음 한 번은 Control-클릭 → 열기.
    LinuxAppImage(chmod +x 후 실행), .deb(sudo apt install ./MyArchitecture-…deb), .tar.gz
    웹소스 폴더에서 npm run serve 후 브라우저로 http://localhost:8642 (다른 포트: PORT=9000 npm run serve). file:// 로 직접 열면 동작하지 않습니다.
    소스Node.js 22 이상, npm install, npm start
    설치 프로그램 만들기npm run build:win(Windows NSIS), npm run build:mac(dmg·zip), npm run build:linux(AppImage·deb·tar.gz), npm run build:all(웹판 + 세 운영 체제 모두)

    1.2 실행과 저장 위치

    • MyArchitecture 는 한 번에 하나만 실행됩니다. 이미 실행 중일 때 .myarch 파일(또는 연결된 DXF·IFC·3D 모델 파일)을 더블클릭하면 열려 있는 창에서 열립니다.
    • 설정 파일 settings.json 위치: Windows %APPDATA%\MyArchitecture, macOS ~/Library/Application Support/MyArchitecture, Linux ~/.config/MyArchitecture. 웹판은 브라우저 localStorage 에 저장합니다.
    • 자동 저장(복구용 사본)은 프로젝트 파일과 별개입니다. 비정상 종료 뒤 다음 실행 때 “…의 저장되지 않은 프로젝트를 복구했습니다. 복원할까요?”라고 묻습니다(7.2절).
    • 처음 실행하면 MyArchitecture 10.0에 오신 것을 환영합니다 창이 뜹니다. 네 단계 요약(벽 그리기 → 방·계단·지붕 → 가구 배치 → 3D 로 보고 공유하기)과 예제 열기 / 새 프로젝트 시작 / 확인 단추가 있습니다. 다시 보려면 도움말 → 빠른 둘러보기, 시작할 때마다 보려면 설정 → 일반 → 시작할 때 환영 창 표시.
    • 프로그램 폴더에는 튜토리얼 전체를 녹화한 동영상 MyArchitecture-Tutorial.mp4 가 들어 있습니다(9.4절).

    2. 화면과 조작

    2.1 제목 표시줄

    제목 표시줄에는 왼쪽부터 다음이 있습니다. 별도의 탭 줄은 없습니다.

    • 메뉴: 파일 · 편집 · 보기 · 그리기 · 빌드 · BIM · 3D · 도움말. 메뉴 하나를 연 채 다른 메뉴 이름 위로 마우스를 옮기면 그 메뉴가 바로 열립니다.
    • 보기 탭: 시작 · 평면도(F2) · 3D 보기(F3). 평면도 탭에는 모델 검사 결과가 배지로 붙습니다 — 오류가 있으면 오류 개수(빨강), 오류 없이 경고만 있으면 경고 개수(노랑).
    • 문서 제목: 프로젝트 제목(프로젝트 속성의 제목), 저장하지 않은 변경이 있으면 ●, 그 뒤에 파일 이름. 창 제목도 ● 파일이름 — MyArchitecture 10.0 형식입니다.
    • 돋보기 단추: 명령 팔레트를 엽니다(Ctrl+K). 툴팁은 “명령, 방, 가구 검색… (Ctrl+K)”. 검색 입력 칸은 팔레트 안에 있습니다(2.6절).
    • 오른쪽 단추: 팔레트 아이콘(무작위 테마) + ▾(테마 선택 목록), 국기(한국어 화면에서는 영국 국기 = English 로, 영어 화면에서는 태극기 = 한국어로), 톱니바퀴(설정…), ⓘ(MyArchitecture 정보).

    제목 표시줄의 어느 것도 숨겨지지 않습니다. 창의 최소 폭이 모든 메뉴·탭·단추가 보이도록 정해지고, 화면이 아주 좁으면 제목 표시줄이 두 줄로 나뉩니다.

    2.4 패널

    • 왼쪽 패널(Ctrl+1, 보기 → 라이브러리 패널 표시)과 오른쪽 패널(Ctrl+2, 보기 → 속성 패널 표시)은 패널 제목의 < / > 단추(패널 숨기기)로도 접습니다.
    • 접힌 패널은 사라지지 않고 아이콘과 세로 제목이 있는 좁은 띠로 남습니다(“가구 라이브러리”, “3D 보기 옵션”, “속성과 모델 검사”, “속성”). 띠를 누르면 다시 펼쳐집니다. 오른쪽 띠에는 모델 검사 오류·경고 개수 배지가 붙습니다.
    • 패널과 도면 사이의 경계선을 끌면 폭이 200 ~ 520 px 사이에서 바뀌고, 다음 실행 때도 기억됩니다.
    • 시작 탭에서는 양쪽 패널이 없습니다.

    오른쪽 패널(속성)의 숫자는 모두 스테퍼입니다: 왼쪽 −, 오른쪽 +, 가운데 값은 직접 입력하고 Enter. 단추를 누르고 있으면 반복되고, 값 칸에서 방향키로도 한 단계씩 바뀝니다. 오른쪽 패널에서 바꾼 값은 하나하나가 되돌리기 한 단계입니다.

    2.5 상태 표시줄과 창 크기

    맨 왼쪽 넓은 칸은 지금 도구의 힌트(없으면 “준비”)입니다. 그 뒤 칸들은 보고 있는 페이지에 따라 다르고, 단추처럼 생긴 칸은 눌러서 바꿀 수 있습니다.

    페이지칸 (왼쪽 → 오른쪽)
    평면도커서 좌표 X … Y …(지금 단위, Y 는 위쪽이 +) · 층(누르면 층 속성…) · 격자 100 mm(누르면 10/25/50/100/250/500/1000 mm 중 선택) · 스냅 ✓/—(누르면 전환, F9) · 직교 ✓/—(누르면 전환, F8) · 화면 축척 1:…(96 dpi 기준 근사) · 단위(누르면 mm → cm → m → ft → mm 순환) · n개 선택(고른 것이 있을 때) · 검사
    3D 보기탐색 방식(궤도 회전/이동/걷기 — 누르면 걷기 켜기·끄기) · 원근 투영/평행 투영(누르면 전환) · 단면 ✓/—(누르면 전환) · 표현 스타일 이름 · 삼각형 n개 · n개 선택 · 검사
    시작최근 파일 n개 · 테마: … · 벽 n개(또는 “빈 프로젝트”) · 검사

    검사 칸은 검사 ✓(문제 없음), 검사 ⚠ n(경고), 검사 ✖ n(오류)으로 보이며 누르면 모델 검사(F5)를 실행합니다(평면도로 이동).

    창 크기 조절 손잡이: 상태 표시줄 오른쪽 아래 모서리의 점 무늬를 끌면 창 크기가 바뀝니다(툴팁 “끌어서 창 크기 변경”). 데스크톱판에서만 보이며, 창이 최대화·전체 화면일 때는 숨습니다.

    2.6 명령 팔레트와 찾기

    • 명령 팔레트(Ctrl+K 또는 제목 표시줄 돋보기): 모든 명령, 프로젝트의 모든 방(누르면 평면에서 그 방을 선택하고 가운데로), 모든 층(누르면 그 층으로)을 한 목록에서 찾습니다. 입력하면 바로 좁혀지고, ↑/↓ 와 Enter 로 실행, Esc 로 닫습니다. 보기 메뉴 끝의 테마·언어 명령(테마…, 어두운 테마, 밝은 테마, 시스템 테마, 한국어, English)도 여기서 실행할 수 있습니다.
    • 찾기…(Ctrl+F, 편집 메뉴): 방, 문·창문(태그로), 가구, 텍스트, 층을 찾아 그 자리로 갑니다.

    2.7 확대·축소와 화면 이동 (평면도)

    동작방법
    확대/축소마우스 휠(커서 기준), 트랙패드 핀치(Ctrl+휠), Ctrl+= / Ctrl+-, 도구 모음 확대·축소. 한 칸 배율은 설정 → 단위와 격자 → 휠 확대/축소 속도(× 0.5 ~ × 3)
    전체 보기Home, 도구 모음 화면에 맞추기, 빈 곳 오른쪽 클릭 메뉴
    화면 이동빈 곳을 왼쪽 버튼으로 끌기(기본), 가운데 버튼 끌기, 오른쪽 버튼 끌기, Space+끌기, Shift+휠(가로 이동), 두 손가락 터치
    손(이동) 도구보기 → 이동 (손) 또는 도구 모음 손 단추. 켜져 있으면 요소 위에서도 왼쪽 끌기가 화면 이동입니다. Esc 나 단추로 끕니다

    가운데 끌기·오른쪽 끌기·Space+끌기는 어떤 도구를 쓰는 중에도 항상 화면 이동입니다. 오른쪽 버튼을 움직이지 않고 떼면 오른쪽 클릭 메뉴가 열립니다.

    설정 → 단위와 격자 → 빈 캔버스에서 왼쪽 끌기를 상자 선택으로 바꾸면 빈 곳 끌기가 상자 선택이 되고, 이동은 가운데·오른쪽·Space 끌기로 합니다.

    2.8 격자와 눈금자

    • 격자: 기본은 선 (5 × 5) — 가는 선과 5칸마다 또렷한 선. 격자 간격(스냅 간격)은 설정 → 단위와 격자 → 격자, 또는 상태 표시줄의 격자 칸에서 10 / 25 / 50 / 100 / 250 / 500 / 1000 mm 로 바꿉니다(기본 100 mm). 격자 모양은 선(5 × 5)/점. 도구 모음·보기 메뉴의 격자 표시로 켜고 끕니다.
    • 눈금자: 도면 위·왼쪽 가장자리에 지금 단위로 표시되고, 커서 위치가 주황색으로 표시됩니다. 눈금자 표시로 켜고 끕니다.

    2.9 선택

    동작결과
    클릭하나 선택. 그룹에 속한 요소는 그룹 전체가 선택됨
    Alt+클릭그룹 안에서 하나만 선택
    Shift+클릭 또는 Ctrl+클릭선택에 넣기/빼기
    Shift+끌기 또는 Ctrl+끌기상자 선택(4.1절)
    빈 곳 클릭선택 해제(Esc 도 같음)
    Ctrl+A지금 층의 모두 선택
    더블클릭속성 창(4.10절)

    마우스를 요소 위에 올리면 강조되고, 커서가 이동(✥) 모양이 됩니다. 손잡이(벽 끝, 방·지붕 꼭짓점, 치수·그리드 끝) 위에서는 십자 커서가 됩니다.

    평면·3D 연동 선택: 평면에서 고르면 3D 에서 같은 요소가 파랗게 강조되고, 3D 에서 클릭하면 평면에서 선택됩니다. 설정 → 평면도 → 평면·3D 연동 선택(“평면에서 선택하면 3D에서 강조되고, 그 반대도 마찬가지”)으로 켜고 끕니다.

    2.10 되돌리기와 다시 실행

    • 되돌리기 Ctrl+Z, 다시 실행 Ctrl+Y 또는 Ctrl+Shift+Z. 실행하면 “되돌리기: 벽 추가”처럼 잠깐 알림이 뜹니다.
    • 같은 명령이 도구 모음(툴팁에 단계 이름), 편집 메뉴, 그리고 평면 도면·층 탭·3D 화면의 오른쪽 클릭 메뉴 맨 위에 있습니다.
    • 한 번 끌기(이동, 모양 바꾸기, 밀기/끌기)는 되돌리기 한 단계입니다. 최대 200 단계까지 기억합니다.
    • 편집 → 되돌리기 기록…: 지난 작업 목록(맨 위가 최신)에서 한 항목을 누르면 그 작업 이전까지 한 번에 되돌립니다.
    • 입력 칸에 글자를 쓰는 중에는 Ctrl+Z 가 그 칸의 글자 되돌리기로 동작합니다.

    3. 평면 그리기

    평면도 탭(F2)에서 그립니다. 도구 키를 누르거나 도구 모음·그리기 메뉴에서 고르면 도구가 바뀌고, 상태 표시줄(그리고 도면 아래쪽)에 그 도구의 힌트가 나옵니다. Esc 는 그리던 것을 끝내고, 한 번 더 누르면 선택 도구로 돌아갑니다.

    십자격자점 또는 직교 방향 위의 점
    주황 점선다른 벽 끝과 가로·세로로 줄이 맞음(정렬 안내선)
    • 스냅(F9, 보기 → 격자와 벽에 스냅, 상태 표시줄): 끝점·꼭짓점 → 벽 → 격자 순서로 붙습니다. 끄면 커서 위치 그대로입니다.
    • 직교(F8, 보기 → 직교 그리기 (45° 단위)): 벽·선·방·지붕·계단을 그릴 때 방향이 45° 단위로, 길이가 격자 단위로 맞춰집니다. 그 방향으로 가다 다른 벽의 중심선과 만나면 정확히 그 위에서 끝납니다.
    • Shift 를 누른 채 그리면 그 순간만 자유 각도입니다.

    3.3 벽

    1. W 를 누르고 시작점을 클릭합니다.
    2. 모서리마다 클릭합니다. 커서 옆에 지금 벽의 길이와 각도(화면 기준 반시계 방향, 0° = 오른쪽)가 표시되고, 두께만큼의 파란 미리 보기가 따라옵니다.
    3. 끝내기: Enter, Esc, 더블클릭, 같은 점을 다시 클릭, 또는 첫 점을 클릭(외곽선이 닫히며 끝남). 오른쪽 클릭도 그리기를 끝냅니다.
    4. Backspace 는 그리는 중에 마지막 모서리(벽)를 되돌립니다.

    다 그리면 방금 그린 벽들이 선택되고 “벽 n개를 그렸습니다. A를 누르고 그 안쪽을 클릭하면 방이 만들어집니다.”라고 안내합니다.

    새 벽의 두께·재료·벽 타입·단계는 다음을 따릅니다.

    • 오른쪽 패널(아무것도 고르지 않았을 때)의 새 항목 칸: 벽 타입, 단계, 벽 두께(그리고 문 폭, 창문 폭, 창대).
    • 빌드 → 기본 크기 (벽, 문, 창문)… 의 벽 두께·벽 재료.
    • 벽 타입을 고르면 두께는 그 타입 레이어 두께의 합입니다.
    • 새 벽의 높이는 따로 정하지 않으면 층 높이를 따릅니다.

    길이 입력

    벽(또는 선)을 그리는 중에 숫자나 . 을 치면 커서 옆에 길이 입력 칸(“길이(mm, 3.6m, 3600<90)”)이 열립니다. 입력하고 <kbd>Enter 를 누르면 지금 커서 방향으로 정확한 길이의 벽이 놓이고 그리기는 계속됩니다.

    3.6m3.6 m = 3600 mm
    360cm360 cm
    3600mm3600 mm

    벽 이음

    벽 끝이 다른 벽의 끝이나 중심선에 닿으면 L 자, T 자, 십자 이음이 자동으로 깔끔하게 그려집니다(벽을 잘라 붙일 필요가 없습니다). 칸막이 벽은 끝을 외벽 위에 놓기만 하면 됩니다.

    벽 고치기

    벽을 선택하면 오른쪽 패널 제목에 길이 · 각도 · 개구부 수가 보이고, 다음 칸이 있습니다.

    칸설명
    벽 타입(타입 없음) 또는 벽 타입 목록. 고르면 두께가 레이어 합으로 바뀜
    길이바꾸면 끝점이 움직이고 그 끝에 이어진 벽도 따라감
    두께직접 바꾸면 벽 타입이 풀림
    높이층 높이와 같으면 층 높이를 따름(층 높이를 바꾸면 함께 바뀜)
    재료벽 재료(12.3절)

    단추: 문 추가, 창문 추가(누른 뒤 벽을 클릭), 가운데에서 나누기, 삭제. 그 아래 BIM 칸(6장).

    • 벽 끝 손잡이(작은 네모)를 끌면 그 끝만 움직입니다. 벽 몸통을 끌면 벽 전체가 움직이고 이어진 벽들이 늘어나며 따라옵니다(Alt+끌기는 이어진 벽을 늘리지 않고 이동).
    • 벽 위 오른쪽 클릭 메뉴: 여기에 문 추가, 여기에 창문 추가, 여기서 벽 나누기, 일직선 벽 합치기(지금 층에서 한 줄로 이어진 벽들을 하나로).
    • 더블클릭(또는 E)하면 벽 속성 창: 길이, 두께, 높이(+ 층 높이와 같게), 재료.

    3.4 방

    • A 를 누르고 닫힌 벽 안쪽을 클릭하면 벽 안쪽 면을 따라 방이 생깁니다. 이름은 크기에 맞게 자동으로 붙고(예: 거실, 침실, 욕실 …), 면적이 알림으로 나옵니다(“방 "…"을(를) 추가했습니다: … m². 두 번 클릭하면 이름을 바꿀 수 있습니다.”).
    • Shift+클릭으로 시작하면 모서리를 직접 찍어 그립니다. 첫 점을 다시 클릭하거나 Enter 로 끝냅니다. 그리는 동안 면적이 커서 옆에 보입니다.
    • 빌드 → 벽에서 방 감지(빈 곳 오른쪽 클릭 → 방 감지): 지금 층에서 닫힌 공간 중 아직 방이 없는 곳을 모두 방으로 만듭니다.
    • 바닥 재료는 기본 오크 마루(기본 크기 창의 바닥 재료로 바꿈).

    방을 선택하면 오른쪽 패널에 면적·둘레가 보이고, 이름, 번호(실 번호), 부서(용도), 바닥(재료), 텍스트 크기, 면적 표시 칸이 있습니다. 꼭짓점 손잡이를 끌면 모양이 바뀝니다(방 하나만 골랐을 때). 더블클릭하면 방 속성 창(이름은 거실·침실·주방·식당·욕실·변기·홀·현관·서재·다용도실·창고·드레스룸·발코니·차고·사무실·회의실·복도·계단 목록에서 고르거나 직접 입력).

    3.5 문과 창문

    • D(문) 또는 N(창문)을 누르고 벽 위로 커서를 옮기면 미리 보기와 폭이 나옵니다. 클릭하면 들어갑니다.
    • 위치는 벽을 따라 격자의 반 칸 단위로 맞춰지고, 벽 끝을 넘지 않도록 조정됩니다.
    • 문은 커서가 있는 쪽으로 열리고, 경첩은 클릭한 곳에 가까운 쪽 끝에 붙습니다.
    • 벽이 너무 짧으면 “이 벽은 너무 짧아 넣을 수 없습니다.”, 이미 문·창이 있으면 “그 자리에 이미 문이나 창문이 있습니다.”
    • 새 문·창의 크기와 종류: 기본 크기 창(문 폭 900, 문 높이 2100, 창문 폭 1200, 창문 높이 1200, 창대 900 이 처음 값), 오른쪽 패널의 새 항목 칸.

    선택한 문·창:

    키·단추하는 일
    X / 열림 방향 뒤집기문이 열리는 쪽(벽의 어느 면) 바꾸기
    H / 경첩 바꾸기경첩을 반대쪽 끝으로
    벽 선택이 문·창이 달린 벽 선택

    오른쪽 패널 칸: 종류(문 / 창문 / 개구부), 유형(문: 외여닫이·양개·미닫이·차고, 창문: 여닫이창·고정·미닫이), 폭, 높이, 창대 높이, 위치(벽 시작점에서 중심까지 거리), 태그. 태그는 비워 두면 문 D01, D02…, 창 W01…, 개구부 O01… 이 층·위치 순서로 자동으로 붙습니다. 더블클릭하면 문 속성 / 창문 속성 창(위 항목 + 여닫는 쪽 “벽 왼쪽/벽 오른쪽”, 경첩 “벽 시작점에서/벽 끝에서”).

    문·창은 벽에 붙어 있으므로 벽을 옮기거나 늘이면 함께 움직입니다. 벽을 지우면 그 벽의 문·창도 지워집니다.

    3.6 가구

    가구 라이브러리(왼쪽 패널):

    • 위쪽 검색 칸(“검색 (소파, 침대, 변기…)”)과 분류 칩: 전체 · 거실 · 식사 · 침실 · 주방 · 욕실 · 사무실 · 실외 · 기타. 검색 칸에서 Enter 를 누르면 첫 항목을 고릅니다.
    • 검색어도 분류도 없을 때는 맨 위에 최근 사용 가구(최대 10개)가 나옵니다.
    • 항목마다 평면 모양 그림과 폭 × 깊이 × 높이.
    • 항목을 누른 뒤 도면을 클릭하거나, 항목을 도면으로 끌어다 놓으면 배치됩니다.
    • 가져온 3D 모델(7.4절)도 목록 아래에 나와 같은 방법으로 놓습니다. 패널 제목의 3D 모델 단추는 3D 모델 가져오기(OBJ, FBX, GLB, STL…)….

    F(가구 검색): “가구 — 이름을 입력하세요(소파, 침대, 싱크대, 자동차 …)” 창에서 이름을 치고 Enter → 도면을 클릭. 최근에 쓴 가구가 위쪽에 옵니다.

    놓는 중에는:

    키하는 일
    R미리 보기를 90° 회전
    Shift+R15° 회전
    Shift+클릭놓고 나서도 같은 가구를 계속 놓기
    Esc놓기 멈춤

    가구는 격자의 반 칸 단위로 놓이고 움직입니다(끌 때 Shift 를 누르면 가로·세로로만). 선택하면 오른쪽 패널에 X, Y, 회전, 폭, 깊이, 높이, 바닥 높이(바닥에서 띄운 높이), 색상 칸과 3D에서 보기 단추가 있습니다. 더블클릭하면 이름·종류(다른 가구로 바꾸기)까지 바꿀 수 있습니다. 전체 목록은 12.3절.

    3.7 계단

    • S 를 누르고 계단 아래쪽을 클릭, 그다음 위쪽을 클릭합니다(직교가 켜져 있으면 45° 단위). 600 mm 보다 짧으면 만들어지지 않습니다.
    • 단 수는 층 높이(+ 슬래브)를 약 175 mm 로 나눠 자동으로 정해집니다(최소 3단). 폭은 기본 크기의 계단 폭(처음 1000 mm).
    • 선택하면 제목에 “n단 · 단높이 … mm · 단너비 … mm” 가 보이고, 단 수, 폭, 길이, 회전, 재료 칸이 있습니다. 단높이가 200 mm 를 넘으면 “챌판이 200 mm를 넘으면 가파릅니다. 단을 늘리세요.” 경고가 나옵니다.
    • 평면에는 진행 방향 화살표와 “올라감” 글자가 그려지고, 3D 에서는 디딤판으로 만들어집니다.

    3.8 기둥

    • C 를 누르고 클릭합니다. 벽 끝(모서리)에 잘 붙습니다. 놓기 전에 R 로 돌릴 수 있습니다.
    • 크기는 프로젝트 기본 400 × 400 mm. 선택하면 모양(사각형/원형), 폭, 깊이, 회전, 재료. 높이는 층 높이를 따릅니다.

    3.9 지붕

    지붕을 만드는 세 가지 방법:

    1. 빌드 → 맨 위층 지붕: 맨 위층의 닫힌 외벽 윤곽마다 지붕을 얹습니다(모양은 설정 → 평면도 → 새 지붕, 기본 박공, 경사 30°, 처마 500). 다시 실행하면 이전에 자동으로 만든 지붕을 바꿔 줍니다. 닫힌 윤곽이 없으면 “맨 위층에 닫힌 벽 윤곽이 없습니다.”
    2. O 를 누르고 건물 안을 클릭: 그 층 외벽 윤곽 위에 지붕(처마 400).
    3. O 다음 Shift+클릭으로 지붕 외곽선을 직접 그리기(Enter 로 마침).

    지붕은 그 층 벽 위에 얹힙니다. 평면에서는 점선으로 표시됩니다(설정 → 평면도 → 지붕 (점선)).

    선택하면: 모양(박공 / 모임 / 외쪽 / 평), 경사(0 ~ 75°), 처마 내밀기, 두께, 용마루 방향(긴 변을 따라 / 가로질러), 재료(지붕 기와·슬레이트·금속 지붕·콘크리트). 꼭짓점 손잡이로 모양을 바꿉니다.

    3.10 층

    도면 왼쪽 아래에 층 탭이 아래층부터 위로 쌓여 있습니다(1F 0.00 m 처럼 이름과 바닥 높이).

    동작결과
    탭 클릭그 층 편집. 그리기는 지금 층에만 됩니다
    탭 더블클릭이름 바꾸기
    + 탭맨 위에 층 추가 — 맨 위층의 벽과 창문을 복사(문은 복사하지 않음)
    탭 오른쪽 클릭되돌리기 · 다시 실행 / 층 이름 바꾸기… · 층 속성… · 층 복제(벽, 문, 창문) / 층 삭제
    • 빌드 → 맨 위에 층 추가는 + 탭과 같습니다. 새 층 이름은 2F, 3F…, 바닥 높이는 아래층 높이 + 층고.
    • 층 복제(벽, 문, 창문) 는 그 층의 벽·문·창·방을 복사해 맨 위에 새 층을 만듭니다.
    • 층 삭제는 그 층과 그 위의 모든 요소를 지웁니다(확인을 묻고, 층이 하나뿐이면 지울 수 없음).
    • 층 속성…(빌드 메뉴, 상태 표시줄 층 칸): 이름, 바닥 높이, 높이(층고, 최소 1000), 바닥 슬래브. “높이를 따로 지정하지 않은 벽은 층 높이를 사용합니다. 층을 위아래로 옮기면 그 층의 모든 요소가 3D에서 함께 움직입니다.” 아무것도 선택하지 않았을 때 오른쪽 패널에도 같은 칸이 있고 층 요약(벽·방 수, 방 면적, 연면적)이 나옵니다.
    • 아래층은 흐리게 겹쳐 보입니다(보기 → 아래층 표시).
    • 구조 그리드 선은 모든 층에 공통입니다.

    3.11 치수, 텍스트, 선, 측정

    • 치수 K: 두 점을 클릭하고, 마우스를 움직여 치수선 위치(간격, 50 mm 단위)를 정한 뒤 한 번 더 클릭. 점은 벽 끝·벽에 붙습니다. 선택하면 간격과 텍스트 재정의(숫자 대신 쓸 글자), 끝 손잡이로 점 이동.
    • 빌드 → 외벽 치수 넣기(빈 곳 오른쪽 클릭 → 자동 치수): 지금 층 건물의 전체 가로·세로 치수와 벽 사이 치수 줄을 바깥에 넣습니다. 다시 실행하면 이전 자동 치수를 바꿔 줍니다.
    • 텍스트 T: 클릭한 곳에 입력 칸이 열립니다. Enter 로 확정. 선택하면 글자(여러 줄), 크기, 회전, 정렬(왼쪽/중앙/오른쪽).
    • 선 L: CAD 레이어에 작도선(폴리선). 점을 차례로 클릭, Enter·더블클릭으로 끝, 첫 점을 클릭하면 닫힘. 왼쪽 CAD 레이어 목록에서 누른 레이어(강조된 줄)에 그려지고 DXF 로 내보내집니다. 선택하면 레이어, 색상.
    • 측정 M: 두 점을 클릭하면 “거리: … (… m)” 알림. 도면에는 남지 않습니다. 세 번째 클릭은 새 측정, Esc 로 지움.

    보기 → 치수 표시로 치수를 숨길 수 있습니다(인쇄 옵션은 따로).

    3.12 구조 그리드

    • G(빈 곳 오른쪽 클릭 → 그리드 선)를 누르고 그리드 선의 두 끝을 클릭합니다(500 mm 이상).
    • 세로선은 1, 2, 3 …, 가로선은 A, B, C …(26개 넘으면 A1, A2…)로 비어 있는 다음 번호가 붙고, 양 끝에 버블이 그려집니다. 모든 층에 나타납니다.
    • 선택하면 레이블을 바꿀 수 있고, 끝 손잡이로 길이를 조정합니다. IFC 로 IfcGrid 로 내보내집니다.

    3.13 매스 (스케치업식 매스 모델)

    벽·바닥이 없는 덩어리로 볼륨을 검토할 때 씁니다.

    도구그리는 법
    매스 상자 B마주 보는 두 모서리 클릭
    매스 원기둥 U중심 클릭, 원 위의 점 클릭(32각형)
    매스 다각형모서리를 차례로 클릭, Enter 나 첫 점 클릭으로 돌출

    새 매스는 높이 3000 mm, 재료 콘크리트, 단계 신축으로 만들어집니다. 선택하면:

    칸설명
    이름매스 이름
    높이매스 높이
    기준 높이층 바닥에서 띄운 높이(포디움 위 타워 등)
    테이퍼윗면 크기 비율 0 ~ 100%. 100% = 수직, 0% = 피라미드/원뿔
    재료벽·지붕 재료

    3D에서 밀기/끌기 단추는 3D 탭으로 가서 밀기/끌기 도구를 켭니다(5.9절). 매스도 이동·회전·대칭·크기 조정·간격 띄우기·그룹이 됩니다.

    3.14 이미지 밑그림과 CAD 도면 따라 그리기

    • 스캔한 도면 이미지를 이미지 밑그림으로 가져와(7.4절) 그 위에 벽을 그립니다. 밑그림을 선택하면 X, Y, 폭, 회전, 불투명도 칸과 팁(“M으로 이미지에서 길이를 아는 부분을 잰 다음, 그 길이에 맞도록 폭을 설정하세요.”)이 있습니다.
    • DXF/SVG 도면은 CAD 레이어로 들어옵니다(7.4절). 그 위에 W 로 벽을 따라 그리고 레이어를 숨기세요.
    • 보기 → 밑그림과 CAD 레이어 표시로 둘 다 한 번에 숨기고 보입니다.

    CAD 레이어 목록(왼쪽 패널, 도면이 있거나 레이어가 2개 이상일 때): 눈 아이콘으로 표시/숨기기, 색 견본, 이름, 요소 수. 줄을 누르면 그 레이어가 선 도구로 그릴 레이어가 됩니다. 톱니바퀴(또는 빌드 → CAD 레이어…)는 레이어 창을 엽니다.

    CAD 레이어 창: 레이어마다 표시 체크, 색상, 항목 수, 삭제(요소가 없는 레이어만, 레이어 0 은 지울 수 없음). 10개씩 쪽으로 나뉩니다.

    4. 편집

    편집 명령은 대부분 평면도 탭에서 동작합니다.

    4.1 상자 선택

    Shift+끌기(또는 Ctrl+끌기, 설정에 따라 그냥 끌기):

    • 왼쪽 → 오른쪽(파란 실선 상자): 상자 안에 완전히 들어간 것만(윈도 선택).
    • 오른쪽 → 왼쪽(초록 점선 상자): 상자에 걸친 것까지(크로싱 선택).
    • 상자 선택은 지금 선택에 더해집니다.

    4.2 이동

    • 선택한 것을 끌면 이동합니다. 이동 거리는 격자 단위(가구는 반 칸)로 맞춰지고, Shift 를 누르면 가로 또는 세로로만.
    • 벽을 옮기면 이어진 벽이 늘어나며 따라오고, 그 벽의 문·창은 벽 안에 남습니다. Alt+끌기는 이어진 벽을 늘리지 않습니다.
    • 방향키: 격자 한 칸, Shift+방향키: 열 칸.
    • 손잡이 끌기는 이동이 아니라 모양 바꾸기(벽 끝, 방·지붕 꼭짓점, 치수·그리드 끝)입니다.

    4.3 복사, 잘라내기, 붙여넣기, 복제, 삭제

    명령키설명
    복사Ctrl+C“n개 항목을 복사했습니다”
    잘라내기Ctrl+X복사 후 삭제

    복제Ctrl+D1 m 오른쪽 아래에 사본
    삭제Del 또는 Backspace벽을 지우면 그 벽의 문·창도 지워짐

    빈 곳 오른쪽 클릭 메뉴의 붙여넣기는 오른쪽 클릭한 자리에 붙여 넣습니다.

    4.5 크기 조정

    편집 → 크기 조정…(여러 개 선택 시 오른쪽 패널 크기 조정… 단추): “배율 (예: 1.5 또는 50%)”을 입력하면 선택을 그 중심 기준으로 키우거나 줄입니다. 50% 처럼 퍼센트도 됩니다. 가구는 높이까지 바뀝니다.

    4.6 간격 띄우기

    편집 → 간격 띄우기…: “간격 띄우기 거리(mm, 음수 = 안쪽)”를 입력하면 선택한 방, 매스, 지붕, 닫힌 선의 평행한 사본을 만듭니다. 양수는 바깥, 음수는 안쪽입니다. 다른 요소에는 쓸 수 없습니다(“간격을 띄울 방, 매스, 지붕 또는 닫힌 선을 선택하세요.”).

    4.7 그룹

    • 그룹 Ctrl+G: 두 개 이상 골라 묶습니다(문·창과 그리드 선은 그룹에 들어가지 않음). 그 뒤 아무 항목이나 클릭하면 그룹 전체가 선택되고 함께 움직입니다. Alt+클릭은 하나만.
    • 그룹 해제 Ctrl+Shift+G.
    • 그룹 요소를 선택하면 오른쪽 패널에 “그룹의 일부입니다 (n개 항목)…”와 그룹 해제 단추가 나옵니다.

    4.8 여러 개 선택했을 때

    오른쪽 패널에 “항목 n개 선택됨”, 종류별 개수와 회전 · 대칭 · 복제 · 삭제 · 그룹 · 크기 조정… 단추가 나옵니다. 벽만 골랐다면 두께와 재료를 한꺼번에 바꿀 수 있습니다.

    4.9 비슷한 요소 선택

    BIM → 비슷한 요소 선택(오른쪽 클릭 메뉴, BIM 칸 단추): 지금 층에서 처음 고른 요소와 같은 것을 모두 고릅니다.

    • 벽: 같은 벽 타입이면서 같은 두께
    • 가구: 같은 종류
    • 문·창: 같은 종류, 같은 폭
    • 그 밖: 같은 종류 전부(그리드 선은 전체)

    4.10 속성 창

    선택 도구에서 요소를 더블클릭하거나 하나를 고르고 E(편집 → 속성…)를 누르면 속성 창이 열립니다. 창 안에서 바꾼 것은 확인을 누를 때 한 번에(되돌리기 한 단계로) 적용됩니다. 아무것도 고르지 않고 속성…을 실행하면 프로젝트 속성이 열립니다.

    요소창 이름항목
    벽벽 속성길이, 두께, 높이, 층 높이와 같게, 재료
    문·창문 속성 / 창문 속성종류, 유형, 폭, 높이, 창대 높이, 위치, 여닫는 쪽, 경첩, 태그
    방방 속성이름(목록), 바닥, 면적(읽기 전용), 텍스트 크기, 면적 표시
    가구(가구 이름)이름, 종류, 폭, 깊이, 높이, 바닥에서 높이, 회전, 색상
    계단계단 속성단 수, 폭, 길이, 회전, 재료
    지붕지붕 속성모양, 경사, 처마 내밀기, 두께, 재료
    기둥기둥 속성모양, 폭, 깊이, 회전

    4.11 오른쪽 클릭 메뉴 (평면)

    선택 도구에서 마우스 오른쪽 버튼을 움직이지 않고 누르면 메뉴가 열립니다. (그리는 중이면 오른쪽 클릭은 그리기를 끝내고, 다른 도구일 때는 선택 도구로 돌아갑니다.)

    요소 위(그 요소가 선택됨):

    1. 되돌리기 · 다시 실행
    2. 속성… (E)
    3. 벽이면: 여기에 문 추가 · 여기에 창문 추가 · 여기서 벽 나누기 · 일직선 벽 합치기
    4. 문·창이면: 열림 방향 뒤집기 (X) · 경첩 바꾸기 (H)
    5. 비슷한 요소 선택 · BIM 속성…
    6. 회전 (R) · 복제 (Ctrl+D) · 복사 (Ctrl+C) · 3D에서 보기
    7. 삭제 (Del)

    빈 곳: 되돌리기 · 다시 실행 / 붙여넣기 · 방 감지 · 자동 치수 · 모두 선택 · 그리드 선 / 화면에 맞추기.

    층 탭: 3.10절. 3D: 5.14절.

    5.7 단면

    • 잘려 나간 부분은 클릭해도 선택되지 않습니다.

    5.8.1 3D 격자

    3D 격자는 평면의 격자처럼 그려집니다.

    • 가는 선 한 칸, 5칸마다 또렷한 선(5 × 5 블록).
    • 확대·축소하면 칸 크기가 ×5 / ÷5 로 바뀝니다(… 0.2 m · 1 m · 5 m · 25 m …). 그래서 어떤 거리에서 보아도 화면에서 고른 간격을 유지하고, 또렷한 선은 너무 진하지 않은 1.5 px 로, 화면 기준으로 일정합니다.
    • 격자는 지금 보는 곳(걷기에서는 서 있는 곳)을 중심으로 펼쳐지고, 또렷한 선을 따라 거리 눈금(m 또는 ft — 설정 → 3D 보기 → 3D 측정 단위)이 붙습니다.
    • G, 도구 모음 격자 단추, 표시 패널로 켜고 끕니다. 3D 를 처음 열 때 켜져 있을지는 설정 → 3D 보기 → 시작 시 표시: 축척 표시 격자.

    5.9 밀기/끌기

    밀기/끌기(도구 모음, 3D 메뉴, 매스의 3D에서 밀기/끌기 단추)를 켜고 매스나 벽의 윗면을 위아래로 끌면 높이가 50 mm 단위로 바뀝니다(매스 최소 100 mm, 벽 최소 300 mm). 끄는 동안 힌트 칸에 높이: … m 가 보입니다. 한 번 끌기가 되돌리기 한 단계입니다. 같은 단추를 다시 누르거나 Esc 로 도구를 끝냅니다.

    5.12 일조 분석

    왼쪽 일조 분석 패널:

    • 대지·날짜·시각으로 해 위치를 끄면: 태양 방위각(15° 단위)과 태양 고도(5° 단위)를 직접 정합니다(기본 135°, 45°).
    • 켜면: 월, 일, 시각(30분 단위)으로 실제 해 위치를 계산합니다. 아래에 위도·경도, 방위각, 고도, 일출·일몰 시각이 표시되고, 해가 지평선 아래면 고도가 <0 으로 나옵니다. 대지 위치… 단추는 프로젝트 속성을 엽니다(위도, 경도, 시간대, 북쪽 방향 — 6.8절).
    • 방위각은 북쪽에서 시계 방향이며, 프로젝트의 북쪽 회전이 반영됩니다.
    • 그림자는 설정 → 3D 보기 → 3D 그림자: 태양 그림자로 켜고 끕니다(선 그림 스타일에서는 그림자 없음).

    5.13 장면

    • 장면 패널의 +(또는 3D → 장면 추가, 3D 오른쪽 클릭 메뉴)는 지금 카메라·투영·표현 스타일·단면 높이·단계 보기를 “장면 1, 장면 2…”로 프로젝트에 저장합니다.
    • 장면 이름을 누르면 그 시점으로 부드럽게 날아갑니다. × 로 지웁니다.
    • ▶(장면 재생, 3D → 장면 애니메이션 재생)은 장면을 차례로 돌며 계속 재생합니다(장면마다 약 2.5초). 다시 누르면(■ 정지) 멈춥니다. 장면이 없으면 “먼저 장면을 추가하세요…”.

    5.14 3D 에서 선택과 오른쪽 클릭

    • 벽, 문, 창, 방 바닥, 가구 등을 클릭하면 파랗게 강조되고, 평면에서도 선택됩니다. 오른쪽 패널에 이름, 층, 클릭한 높이와 평면에서 보기 / 속성… 단추가 나옵니다.

    6.4 사용자 속성 (BIM 속성)

    • 값이 숫자면 숫자로, true/false 면 참/거짓으로 저장됩니다.
    • 여러 요소를 고르면 “속성이 선택한 요소 n개 모두에 기록됩니다.” 하나면 “IFC에 속성 세트 MyArchitecture_Properties로 내보냅니다.”

    6.7 모델 검사

    모델 검사는 회로 설계의 ERC/DRC 에 해당하는 건축 검사입니다.

    • 기본으로 그리는 동안 계속 실행됩니다(설정 → 평면도 → 그리는 동안 모델 검사 실행).
    • F5(빌드 → 모델 검사, 도구 모음, 상태 표시줄 검사 칸)는 지금 검사하고 “모델 검사: 오류 n개, 경고 n개” 또는 “모델 검사 통과 — 문제가 없습니다.”를 알리며 오른쪽 패널을 엽니다.
    • 오른쪽 패널 아래 모델 검사 목록: 오류·경고 개수 알약, 항목마다 메시지와 코드 · 층. 항목을 누르면 그 층으로 가서 문제 위치를 확대하고 주황 원으로 깜박이며 관련 요소를 선택합니다. ↻ 단추는 다시 검사.

    7.2 자동 저장과 복구

    • 설정 → 일반 → 자동 저장: 복구용 사본 보관(기본 켬), 자동 저장 간격(10초 ~ 10분, 기본 30초).
    • 저장하지 않은 변경이 있을 때만 복구용 사본을 씁니다. 정상적으로 저장하면 지워집니다.
    • 다음 실행 때 사본이 있으면 작업 복구 창: “…의 저장되지 않은 프로젝트를 복구했습니다. 복원할까요?” — 복원(변경 표시 ● 상태로 열림) / 버리기.

    7.3 최근 파일

    • 열거나 저장한 파일(가져온 DXF·3D 모델 등 포함)을 새것부터 10개까지 기억합니다(설정 → 일반 → 최근 파일 기억 개수, 1 ~ 30). 시작 페이지의 최근 목록에도 같은 개수가 보입니다.
    • 파일 → 최근 파일…: 이름·경로·시각 목록. 누르면 열고, ×(목록에서 제거)는 하나만 지우고, 목록 지우기는 전부 지웁니다. 파일 자체는 지워지지 않습니다.
    • 파일 → 최근 파일 지우기, 시작 페이지 목록 지우기도 같습니다(“최근 파일 목록을 지웠습니다.”).
    • 열 수 없는 파일(옮겨졌거나 지워짐)은 열려고 할 때 목록에서 빠집니다.

    형식가져오는 방법
    DXF (.dxf)DXF 도면 가져오기 창: 파일의 단위(자동 감지 / mm / cm / m / 인치 / 피트), 층(넣을 층), 도면을 평면 원점으로 옮기기. 선, 폴리선, 호, 원, 스플라인, 텍스트, 블록, 해치 윤곽이 각자의 CAD 레이어로 들어옵니다. 끝나면 “… 가져옴: 도면 요소 n개, 텍스트 n개 (단위)”, 주의할 점이 있으면 가져오기 메모 창
    SVG (.svg)SVG 도면 가져오기 창(위와 같은 항목). 경로, 도형, 텍스트가 SVG 레이어로 들어옵니다
    IFC (.ifc)지금 프로젝트를 바꿉니다(저장 확인). 층, 벽, 문·창, 방, 슬래브, 지붕, 계단, 기둥, 가구를 읽어 새 프로젝트(이름 파일이름.myarch, 저장 안 된 상태)로 엽니다. “… 가져옴: 층 n개, 벽 n개, 문/창문 n개, 방 n개.”
    3D 모델 (.obj .fbx .glb .gltf .stl .dae .3mf .3ds .ply .wrl .amf)3D 모델 가져오기 — 이름 창: 파일의 단위(자동 감지 …), 위쪽 축(자동 / Y가 위쪽 / Z가 위쪽). 모델은 가구 하나가 되어 지금 층의 화면 가운데(또는 놓은 자리)에 들어오고 프로젝트 파일 안에 저장됩니다. 가구 라이브러리 “가져온 3D 모델”에서 몇 번이든 다시 놓을 수 있습니다. OBJ 는 같은 폴더의 같은 이름 .mtl 재질도 읽습니다
    이미지 (.png .jpg .jpeg .webp .gif .bmp)이미지를 트레이싱 밑그림으로 가져오기 창: 평면에서의 이미지 폭(mm), 불투명도(10 ~ 100%). 지금 층에 밑그림으로 깔립니다

    11. 문제 해결과 FAQ

    프로그램이 열리지 않거나 두 번째 창이 안 열립니다. MyArchitecture 는 하나만 실행됩니다. 이미 실행 중이면 그 창이 앞으로 나오고 파일이 그 창에서 열립니다. 작업 표시줄에서 기존 창을 찾아 보세요.

    벽이 원하는 각도로 안 그려집니다 / 길이가 100 단위로만 바뀝니다. 직교(F8)가 켜져 있으면 45° 단위·격자 단위로 맞춰집니다. Shift 를 누른 채 그리거나, 직교·스냅(F9)을 끄거나, 격자 간격을 줄이거나, 숫자로 길이와 각도(3600<30)를 입력하세요.

    A 로 클릭했는데 방이 안 생깁니다. 벽이 완전히 닫혀 있어야 합니다. 벽 끝이 서로(또는 다른 벽 위에) 정확히 닿았는지 확인하세요 — 벽을 그릴 때 끝점(주황 네모)이나 벽(초록 삼각형) 스냅 표시가 떠야 닿은 것입니다. 닫히지 않은 곳은 Shift+클릭으로 모서리를 직접 그려 방을 만들 수 있습니다. 너무 작은 영역(0.01 m² 미만)은 무시됩니다.

    문을 넣으려는데 “이 벽은 너무 짧아 넣을 수 없습니다.” 벽 길이가 문 폭 + 20 mm 보다 짧습니다. 오른쪽 패널 새 항목 → 문 폭을 줄이거나 벽을 늘리세요. 벽이 여러 조각으로 나뉘어 있으면 오른쪽 클릭 → 일직선 벽 합치기.

    빈 곳을 끌었는데 상자 선택이 아니라 화면이 움직입니다. 기본값입니다. Shift+끌기를 쓰거나, 설정 → 단위와 격자 → 빈 캔버스에서 왼쪽 끌기 → 상자 선택으로 바꾸세요.

    요소를 끌었는데 화면만 움직입니다. 손(이동) 모드가 켜져 있습니다. Esc 나 도구 모음의 손 단추로 끄세요.

    3D 가 비어 있거나 일부가 안 보입니다. 3D 왼쪽 패널의 층 체크, 표시(가구·지붕·매스 모델), 단계 보기, 단면을 확인하세요. 탐색이 꼬였으면 1(등각) 또는 Home. “3D 보기를 사용할 수 없습니다”가 나오면 그래픽 드라이버(WebGL)를 확인하세요.

    3D 에서 클릭해도 선택이 안 됩니다. 밀기/끌기·페인트 통·줄자 도구가 켜져 있으면 클릭이 도구로 갑니다. Esc 로 끄세요. 단면으로 잘려 나간 부분은 선택되지 않습니다.

    모델 검사 경고를 무시하고 싶습니다. 경고는 작업을 막지 않습니다. 그리는 동안 계속 검사하는 것이 거슬리면 설정 → 평면도 → 그리는 동안 모델 검사 실행을 끄고 필요할 때 F5 를 누르세요.

    가져온 DXF 가 너무 크거나 작습니다 / 엉뚱한 곳에 있습니다. 가져오기 창에서 파일의 단위를 직접 고르고, 도면을 평면 원점으로 옮기기를 체크하세요. 그다음 Home.

    가져온 3D 모델 크기가 이상합니다 / 누워 있습니다. 가져오기 창의 파일의 단위와 위쪽 축(Y가 위쪽 / Z가 위쪽)을 바꿔 다시 가져오세요. 들어온 뒤에도 오른쪽 패널에서 폭·깊이·높이를 바꾸거나 크기 조정…을 쓸 수 있습니다.

    DWG / SKP / RVT 파일을 열고 싶습니다. 직접 읽을 수 없습니다. 7.7절처럼 DXF / DAE·OBJ·glTF / IFC 로 바꿔서 가져오세요.

    PDF 로 저장 단추가 없습니다. 웹판에는 없습니다. 인쇄… 를 누른 뒤 브라우저 인쇄 창에서 “PDF로 저장”을 고르세요. 또는 SVG로 저장….

    저장 안 하고 꺼졌습니다. 자동 저장이 켜져 있었다면 다음 실행 때 작업 복구 창에서 복원을 누르세요(7.2절).

    튜토리얼을 하고 나니 격자·단위 설정이 바뀌었습니다. 튜토리얼은 닫을 때 설정을 되돌립니다. 튜토리얼 창의 ✕(튜토리얼 끝내기)로 닫았는지 확인하세요. 프로그램을 강제로 껐다면 설정 창에서 다시 맞추세요.

    화면이 너무 작거나 큽니다 / 창을 더 좁힐 수 없습니다. 설정 → 모양 → 화면 크기를 바꾸세요. 창의 최소 크기는 메뉴·탭·도구 모음 단추가 하나도 가려지지 않도록 정해지므로, 화면 크기를 줄이면 창도 더 좁힐 수 있습니다.

    설정을 처음으로 돌리고 싶습니다. 설정 → 기본값으로 재설정. 완전히 지우려면 프로그램을 끄고 settings.json(1.2절 위치)을 지우세요.

    F1 을 눌렀는데 설명서가 안 열립니다. F1 은 프로그램 폴더의 docs/USERSGUIDE.ko.html(영어 화면에서는 USERSGUIDE.en.html)을 별도 창으로 엽니다. 이 HTML 은 이 문서(UsersGuide.md)로 만들어지므로, 열리지 않으면 UsersGuide.md 를 직접 열어도 같은 내용입니다.
