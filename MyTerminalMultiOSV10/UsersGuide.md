# MyTerminal 사용 가이드

대상: MyTerminal 1.0.0  
작성: SHKWON (`knix008@naver.com`)

## 1. 시작하기

### 데스크톱

1. `npm install`
2. `npm start`
3. 또는 설치본 실행

설치 파일 만들기:

```bash
npm run build:win      # Windows
npm run build:mac      # macOS
npm run build:linux    # Linux
npm run build:all      # 전 플랫폼
```

산출물은 `dist/` 폴더에 생성됩니다.

### 웹

```bash
npm run web
```

브라우저에서 로컬 셸(웹용)이 열립니다. SSH 원격 연결은 데스크톱 앱에서만 사용할 수 있습니다.

## 2. 화면 구성

| 영역 | 설명 |
|------|------|
| 툴바 | 편집·글꼴·테마·언어·투명도·배경 표시·설정·About·창 제어 |
| 탭 바 `+` / `▾` | `+`는 기본 명령 셸로 새 터미널, `▾`는 설치된 셸(cmd · PowerShell · Git Bash · WSL · bash · zsh …) 중 하나를 골라 새 터미널. 탭 이름은 항상 **실행 중인 셸 이름 + 번호**(예: `cmd 1`, `PowerShell 2`)입니다 |
| 탭 스크롤 `◀ ▶` | 탭이 화면 폭을 넘으면 탭 바 오른쪽에 나타나 탭을 좌우로 넘깁니다(마우스 휠로도 이동). `+`/`▾` 버튼은 스크롤과 무관하게 항상 오른쪽에 보이고, 활성 탭은 항상 보이는 위치로 스크롤됩니다 |
| 탭 바 | 세션 전환, **+**(새 세션), 닫기, 창 밖으로 드래그하여 분리(새 창 윤곽 미리보기), 다른 창으로 드래그하여 탭으로 합치기(대상 창에 가상 탭 표시) |
| 터미널 | MyShell 또는 SSH 출력 |
| 상태바 | 로컬/SSH · 명령 셸 이름, 세션명, 글꼴, 크기(열×행) — 설정에서 On/Off |

창 가장자리를 잡아 크기를 줄이면, 툴바 아이콘·라벨이 가려지지 않는 최소 폭까지만 줄어듭니다.

## 3. 툴바 기능

### 세션·연결

- **원격 SSH**: 연결 / 연결 중이면 해제
- **프롬프트**: 설정 창의 **프롬프트** 탭을 엽니다 (프리셋·간단 설정·고급 편집, 아래 4장 참고)
- **언어(국기 아이콘)**: 누를 때마다 한국어 ↔ English로 바로 전환됩니다. 아이콘은 **전환될 언어**의 국기입니다 — 한국어 UI에서는 영국 국기, English UI에서는 태극기.
- **지우기**: 화면 지우기(프롬프트 다시 표시)
- **복사 / 붙여넣기**: 선택 영역 복사, 시스템 클립보드 붙여넣기  
  - 복사: 툴바 버튼, `Ctrl+Shift+C`, `Ctrl+Insert`, 또는 선택 후 `Ctrl+C`  
  - 붙여넣기: 툴바 버튼, `Ctrl+V`, `Ctrl+Shift+V`, `Shift+Insert`

탭 바 오른쪽 **+** 를 누르면 새 로컬 세션 탭이 추가됩니다.

### 글꼴

- **A− / A+**: 크기 조절
- **글꼴 종류**: Cascadia, Consolas, D2Coding 등 목록에서 선택

### 테마·언어

- **테마**: Dark, Light, Midnight, Forest, Sunset, Ocean, Custom
- **언어**: English / 한국어 — 툴팁, 메뉴, 대화상자, 탭 제목 등에 즉시 반영

### 배경·투명도

- **창 전체 투명도 슬라이더 (0%–100%)**: **창 전체**(툴바·터미널·글자·배경 포함)의 투명도를 조절합니다.  
  - `0%` = 불투명  
  - `100%`에 가까울수록 바탕화면이 비쳐 보임(완전히 사라지지 않도록 최소 불투명도가 유지됨)
- **배경 표시**: 이미지 배치 방식 — 가득채움 / 맞춤 / 늘이기 / 가운데 / 패턴

배경 **이미지**의 진하기(이미지만의 투명도)는 **설정 → 배경 투명도** 슬라이더에서 따로 조절합니다.  
배경 이미지 자체도 **설정**에서 선택합니다.

### 설정·정보

- **설정(톱니바퀴)**: 터미널·테마·배경 상세 (변경 즉시 적용)
- **About**: 버전·작성자·연락처 및 **빌드 정보**(Electron·Chromium·Node.js·OS·빌드 날짜)
- **창 버튼**: 최소화 / 최대화·복원 / 닫기 (웹에서는 숨김)

우클릭하면 아이콘이 함께 표시되는 컨텍스트 메뉴가 열립니다: 복사 / 전체 복사 / 붙여넣기 · 모두 선택 / 지우기 · 글꼴 크게·작게 · 맨 아래로 이동(단축키 표시 포함).

## 4. 설정 대화상자

설정을 바꾸면 **적용 버튼 없이 바로 반영·저장**됩니다. 닫기만 누르면 됩니다.

설정 창은 **고정 크기**이며 내부에 스크롤바가 없습니다. 항목은 아홉 탭으로 나뉩니다: **일반 · 터미널 · 글꼴 · 테마 · 색상 · 배경 · SSH · 프롬프트 · 프롬프트 편집**. 창 크기는 가장 긴 탭에 맞춰 한 번 정해지고 그대로 유지됩니다.

숫자 항목(스크롤 기억 줄 수, 글꼴 크기, 터미널 크기, 포트, 프롬프트 옵션 등)은 직접 입력하거나 양옆의 **−/+** 버튼으로 바꿀 수 있습니다. 스크롤 기억 줄 수는 100단위로 움직입니다. 터미널 글꼴 크기의 기본값은 **13px**이며, 글꼴 설정은 터미널 화면에만 적용됩니다(다른 창·버튼의 글꼴은 바뀌지 않음).

### 일반

| 항목 | 설명 |
|------|------|
| 스크롤 기억 줄 수 | 스크롤로 되돌릴 줄 수 (100–100000, 기본 10,000) |
| 기본 터미널 크기 | 처음 실행할 때 창을 맞출 열 × 행 (기본 **120 × 25**). 바꾸면 이 창의 크기도 바로 맞춥니다. 창의 최소 폭은 툴바 폭이므로 터미널이 그보다 넓어질 수 있습니다 |
| 시작 디렉터리 | 새 로컬 세션의 시작 폴더 (비우거나 없으면 홈, `~` 지원) |
| 명령 셸 | 입력한 명령줄을 실행하는 프로그램 (아래 참고) |
| 상태바 표시 | 하단 상태바 On/Off |
| 시스템 트레이 아이콘 | 트레이에 아이콘 표시 (데스크톱). 아이콘 클릭 시 설정 창이 열리고 메뉴에서 창 보기·종료 가능. 마지막 창을 닫으면 트레이 아이콘과 무관하게 **프로그램이 종료**됩니다 |

#### 명령 셸

MyShell은 `cd`, `ls`, `cat`, `prompt` 같은 내장 명령을 직접 처리하고, 그 밖의 명령줄은 **선택한 명령 셸**에 넘겨 실행합니다. 설치된 셸을 자동으로 찾아 목록에 보여 주며, 기본값은 다음과 같습니다.

| 플랫폼 | 선택 가능 | 기본 |
|--------|-----------|------|
| Windows | Command Prompt(cmd.exe), Windows PowerShell, PowerShell 7(pwsh), Git Bash, WSL | **Command Prompt** |
| macOS | 로그인 셸($SHELL), bash, zsh, fish, sh … | **zsh** |
| Linux | 로그인 셸($SHELL), bash, zsh, fish, sh, dash … | **bash** |

**직접 지정…**을 고르면 임의의 셸 프로그램 경로를 입력할 수 있습니다. 명령줄마다 새 셸 인스턴스에서 실행되므로 셸 변수(`$x`, `set X=`)는 다음 줄로 이어지지 않습니다. 작업 디렉터리(`cd`)와 환경 변수는 MyShell이 유지합니다. 변경은 다음 명령줄부터 적용됩니다.

### 글꼴 · 테마 · 색상 · 배경

- **글꼴**: 글꼴 종류·크기·글자색, `ls`/`dir`의 디렉터리·파일 글자색
- **테마**: **다크 20 · 라이트 20**, 두 상자에 한 줄 5개씩 — 서로 다른 배경 색조와 강조색으로 한눈에 구분됩니다. 클릭하면 바로 적용. 툴바의 테마 버튼에서도 같은 목록(두 열)을 고를 수 있습니다.
  - 라이트 테마에서는 터미널 글자를 조금 굵게(600) 그리고, ANSI 색·`ls` 색·프롬프트 색을 배경과의 대비(WCAG 4.5:1 이상)에 맞춰 자동으로 진하게 조정해 잘 보이도록 합니다.
- **색상**: 터미널 배경·커서·선택 영역·강조색·툴바 배경. 바꾼 색은 **현재 테마에만** 저장되며(테마 카드에 ✎ 표시) 테마마다 다르게 둘 수 있습니다. **초기화** 버튼은 현재 테마의 색과 파일 목록 색만 원래대로 되돌리고, 다른 테마의 색·사용자 정의 프롬프트·배경 이미지·SSH 호스트 등 사용자가 추가한 것은 그대로 둡니다.
- **배경**: 배경 이미지 라이브러리(한 페이지 10장, ◀ ▶로 넘김)·표시 방법·배경 투명도

### 터미널 (프로필)

터미널 **크기(열 × 행)·글꼴·글꼴 크기·스크롤백·명령 셸**을 한 묶음으로 저장하는 프로필입니다. **추가**로 새 프로필을 만들거나 **현재 상태로**를 눌러 지금 창의 값으로 만들고, 목록에서 골라 편집·**삭제**합니다. **이 창에 적용**을 누르면 글꼴·크기·스크롤백·기본 셸이 바뀌고, 터미널이 정확히 그 열 × 행이 되도록 창 크기가 맞춰집니다(창의 최소 폭은 툴바 폭).


### SSH

자주 쓰는 SSH 접속 정보를 **호스트 프로필**로 보관합니다. **추가**로 항목을 만들고 이름·호스트·포트·사용자·개인키 경로를 입력하면 즉시 저장되며, 목록에서 고른 항목을 **삭제**로 개별 제거할 수 있습니다. 비밀번호와 키 암호는 저장하지 않습니다. 툴바의 **원격 SSH** 창 맨 위 **저장된 호스트** 목록에서 프로필을 고르면 입력란이 채워집니다.

### 프롬프트

로컬 셸의 프롬프트 테마입니다. 프롬프트는 **세그먼트**(경로, git, 사용자@호스트, 셸, OS, 시각, 종료 코드, 실행 시간, 관리자, 텍스트)의 나열이며, 각 세그먼트는 모양(파워라인 / 일반 / 다이아몬드), 글자색·배경색, Go 스타일 템플릿(`{{ .Path }}`, `{{ if gt .Ahead 0 }}…{{ end }}`)을 가집니다.

- **미리보기**: 현재 프롬프트를 세 상태(깨끗한 저장소 / 변경된 저장소 / 저장소 아님)로 보여 줍니다. 미리보기 영역은 크기가 고정되어 있습니다.
- **프리셋**: 기본·Powerline·Agnoster·Paradox·최소·단순 텍스트·버블·Robby Russell·Pure·Star·슬림·Material·클래식·레인보우·오션·모노·포레스트·선셋·노르드·개발자 — 카드를 클릭하면 바로 적용됩니다.
- **사용자 정의 프롬프트**: 현재 프롬프트를 이름을 붙여 저장하고, 목록에서 골라 다시 쓰거나 이름을 바꾸거나 지울 수 있습니다.
- **간단 설정**: 표시할 세그먼트, 모양, 경로 스타일(전체 / 폴더 이름만 / 축약 / 첫 글자), 두 줄, Git 상태(끄기 / 브랜치만 / 브랜치 + 변경), git 상태색.
- **git 상태색**: 브랜치(git) 블록만 저장소 상태에 따라 색이 바뀝니다 — 정상(푸시됨) 초록, 수정됨 빨강, add 됨 노랑, 커밋됨(푸시 필요) 주황, pull 필요 파랑, 충돌 진홍. 상태마다 색을 바꿀 수 있고, 끄면 테마 색을 그대로 씁니다.

### 프롬프트 편집

세그먼트 하나하나를 다듬는 고급 편집기입니다. 왼쪽 목록에서 세그먼트를 고르면 오른쪽에서 종류·모양·표시 여부, 글자색/배경색(색 고르기 또는 `accent` · `foreground` · `background` · `auto` · `transparent` 같은 이름), 템플릿, 배경색 템플릿(줄마다 하나, 처음 맞는 것), 종류별 옵션(경로 스타일·최대 깊이·폴더 구분자, 브랜치 아이콘, 성공 시 표시, 표시 최소 시간, OS 아이콘, 다이아몬드 앞/뒤 기호)을 바꿀 수 있습니다. 세그먼트 추가·순서 변경·삭제, 블록(줄) 추가·삭제도 여기서 합니다.

템플릿에서 쓸 수 있는 변수는 편집기 아래에 종류별로 표시됩니다 (예: 경로 `.Path .Folder`, git `.Branch .Ahead .Behind .Working.Changed`, 시각 `.CurrentDate | date "15:04"`). `[[icon:folder]]`, `[[icon:gitBranch]]`는 폴더·브랜치 아이콘으로 그려집니다.

툴바의 **Git 상태** 버튼은 프롬프트의 git 표시를 끄고 켜는 빠른 토글입니다.

설치 프로그램(Windows NSIS)에서도 **시스템 트레이 아이콘 사용 여부**를 선택할 수 있습니다. 설치 후 설정에서 다시 변경할 수 있습니다.

이미 MyTerminal이 설치되어 있으면, 설치 프로그램이 **기존 설치본·바로가기·앱 데이터까지 완전히 제거한 뒤** 새로 설치합니다. 수동 제거(프로그램 추가/제거) 시에도 앱 데이터가 삭제됩니다.

트레이가 켜진 상태에서 **창 닫기(×) 버튼**을 누르면 앱이 종료되지 않고 트레이로 숨겨집니다. 트레이 메뉴의 **종료**로 완전히 끝낼 수 있습니다.  
단, 마지막 터미널을 `exit`로 닫거나 마지막 탭을 닫으면 트레이 설정과 무관하게 앱이 **완전히 종료**됩니다.

앱은 **단일 인스턴스**로 실행됩니다. 이미 실행 중일 때 다시 실행하면 새 창이 뜨지 않고 기존 창이 앞으로 나옵니다.

### 테마 색상

터미널 배경색, 글자색, 커서, 선택, 강조색, 툴바 배경 등을 지정합니다.  
**초기화**는 사용자 지정 색상을 기본 다크 테마 기준으로 되돌립니다.

### 배경 이미지

설정에서 여러 배경 이미지를 라이브러리로 보관할 수 있습니다. 썸네일을 클릭해 적용하고, 각 항목의 ×로 개별 삭제할 수 있습니다. **사용 안 함**은 선택만 해제하며 목록은 유지됩니다.

1. **이미지 선택…** — PNG / JPG / JPEG / JFIF / GIF / WebP / AVIF / TIFF / BMP / SVG / ICO (**크기 제한 없음** — 대용량은 표시용으로 자동 축소)
2. 미리보기로 확인
3. **표시 방법** — 가득채움 / 맞춤 / 늘이기 / 가운데 / 패턴 (툴바와 동일 옵션)
4. **배경 투명도** — 배경 이미지의 진하기(0%–100%, 0 = 선명, 100 = 숨김). 범위(0~100)와 현재 값이 함께 표시됩니다.
5. **제거** — 배경 이미지 삭제

> 참고: 배경 이미지는 일반 CSS 배경으로 그려지므로 **내장 GPU만으로도, 세 OS(Windows·macOS·Linux) 모두 동일하게** 표시됩니다. 대용량·초고해상도 이미지는 자동 축소되어 어떤 그래픽 환경에서도 안정적으로 보입니다.

### 오류 창

오류가 나면(SSH 연결 실패, 셸 프로그램 실행 실패, 배경 이미지 오류, 예상치 못한 내부 오류 등) 한 줄 요약과 **자세한 내용**(스택·코드·경로)을 담은 오류 창이 열립니다. 내용은 선택해 복사할 수 있고 **복사** 버튼으로 전체를 클립보드에 넣을 수 있습니다. 같은 오류가 짧은 시간에 반복되면 창은 한 번만 열립니다.

설정·SSH·정보 창이 이미 열려 있을 때 툴바 버튼을 다시 누르면 새 창을 열지 않고 열려 있는 창을 앞으로 가져옵니다. 프로그램을 끝내거나 창을 닫으면(트레이로 숨길 때 포함) 열려 있던 팝업 창도 함께 닫힙니다.


## 5. 세션 탭

- 탭 클릭: 세션 전환
- 탭의 ×: 세션 닫기. **마지막 탭을 닫으면 앱이 종료됩니다.**
- 셸에서 `exit`(또는 `quit`) 입력: 해당 탭이 닫힙니다. **마지막 탭이면 앱이 종료됩니다.**
- **탭을 창 밖으로 드래그**: 해당 세션이 새 창으로 분리됩니다.
- **분리된 탭을 다른 MyTerminal 창 위로 드래그**: 대상 창의 탭으로 다시 합칩니다. 드래그하는 동안 대상 창 탭 바에 가상 탭이 표시되며, 마우스 위치에 따라 삽입 위치가 바뀝니다.

## 6. SSH 원격

1. 툴바 **원격 SSH** 클릭  
2. 호스트, 포트, 사용자, 비밀번호 또는 개인키 경로 입력  
3. **연결**  
4. 연결 중에는 같은 탭이 원격 셸로 전환됩니다.  
5. 다시 원격 버튼을 누르면 연결 해제 후 로컬로 돌아갑니다.

호스트·포트·사용자·키 경로는 기억될 수 있으나, 비밀번호는 저장하지 않습니다.

## 7. MyShell (로컬 셸)

데스크톱 로컬 세션은 시스템 cmd/bash 래퍼가 아니라 **내장 MyShell**입니다.  
내장 명령이 아닌 이름은 PATH의 프로그램으로 바로 실행됩니다 (`ipconfig`, `git status`, `notepad` 등). `run`은 선택 사항입니다.


주요 명령:

| 명령 | 설명 |
|------|------|
| `help` / `?` | 도움말 |
| `clear` / `cls` | 화면 지우기 |
| `pwd` | 현재 경로 |
| `cd` | 디렉터리 이동 |
| `ls` | 여러 열 목록. `ls -l` / `ls -al`은 권한 · 날짜 · **크기(우측 정렬)** · 이름 순으로 한 줄씩 |
| `dir` | Windows 스타일 목록 |
| `cat` / `type` | 파일 내용 |
| `mkdir` / `md` | 폴더 생성 |
| `rm` / `del` | 삭제 |
| `cp` / `copy`, `mv` / `move` | 복사·이동 |
| `echo`, `date`, `whoami`, `env` | 정보 출력 |
| `history` | 명령 기록 (재실행 후에도 유지) |
| `recent` | 최근 파일/폴더 목록 · `recent 3` / `recent cd 1` / `recent open 2` |
| `prompt` | 프롬프트 테마: `prompt show` / `prompt list` / `prompt set <프리셋>` / `prompt reset` (자세한 편집은 설정 → 프롬프트) |
| `run` / `exec` | 외부 프로그램 명시 실행 (선택). 내장 명령이 아니면 이름만 입력해도 PATH에서 실행됩니다 |
| `uname` / `sysinfo` | 시스템 정보 |
| `exit` / `quit` | 현재 세션(탭) 종료. 마지막 탭이면 앱 종료 |

내장 명령이 아닌 줄은 **설정 → 일반 → 명령 셸**에서 고른 셸(Windows 기본 Command Prompt, macOS zsh, Linux bash)이 실행합니다. 셸 고유 문법(PowerShell cmdlet, bash `$(…)` 등)을 그대로 쓸 수 있습니다.

프롬프트 테마(프리셋·세그먼트·git 상태색·Git 표시 옵션·사용자 정의 프롬프트)는 설정에 저장되며, 앱을 다시 실행해도 복원됩니다. 파워라인 화살표와 다이아몬드는 xterm의 내장 글리프로 그려지므로 별도의 Nerd Font가 필요 없습니다.

**Tab 자동완성:** 명령어 이름과 파일/폴더 경로를 보완합니다. 후보가 여러 개면 한 번 더 Tab을 눌러 목록을 볼 수 있습니다.

## 8. 단축·팁

- **Tab**: 명령/경로 자동완성 (두 번 누르면 후보 목록)
- 링크가 보이면 클릭하여 기본 브라우저로 열 수 있습니다.
- 툴바의 **창 전체 투명도**를 높이면 바탕화면이 비치는 터미널을 만들 수 있습니다. 배경 이미지의 진하기는 설정의 **배경 투명도**로 따로 조절합니다.
- 언어를 바꾸면 열려 있던 설정 창은 닫히고, 다시 열면 새 언어로 표시됩니다.
- 설정·글꼴·테마·시작 디렉터리·프롬프트·창 크기/위치는 앱을 다시 실행해도 유지됩니다.
- **시작 디렉터리**: 설정 → 터미널에서 새 탭의 시작 폴더를 지정할 수 있습니다 (비우면 홈 폴더).
- **최근 경로**: `cd` / `open` / `cat` 등으로 사용한 파일·폴더는 기억되며 `recent`로 다시 열 수 있습니다. 명령 `↑/↓` 기록도 유지됩니다.

## 9. 문제 해결

| 증상 | 확인 |
|------|------|
| 최근 UI 변경이 안 보임 | `npm start`로 재시작 (렌더러 번들 필요) |
| 배경 이미지가 안 보임 | 설정에서 이미지를 선택하고 표시 방식을 확인하세요. 대용량 이미지도 자동 축소되어 표시됩니다(전용 GPU 불필요) |
| 창 전체가 너무 투명함 | 툴바의 창 전체 투명도 슬라이더를 낮추세요 |
| SSH 실패 | 호스트/포트/계정·키·방화벽 확인 |
| 창이 너무 안 줄어듦 | 툴바가 잘리지 않도록 최소 폭이 제한되어 있습니다 |
| 웹에서 SSH 없음 | 정상입니다. 데스크톱 앱을 사용하세요 |
