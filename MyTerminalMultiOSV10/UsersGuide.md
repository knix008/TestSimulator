# MyTerminal 사용 가이드

대상: MyTerminal 1.0.0  
작성: SHKWON (`knix008@naver.com`)

## 1. 시작하기

### 데스크톱

1. `npm install`
2. `npm start`
3. 또는 설치본 실행

설치 파일 만들기:

```bash
npm run build:win      # Windows
npm run build:mac      # macOS
npm run build:linux    # Linux
npm run build:all      # 전 플랫폼
```

산출물은 `dist/` 폴더에 생성됩니다.

### 웹

```bash
npm run web
```

브라우저에서 로컬 셸(웹용)이 열립니다. SSH 원격 연결은 데스크톱 앱에서만 사용할 수 있습니다.

## 2. 화면 구성

| 영역 | 설명 |
|------|------|
| 툴바 | 편집·글꼴·테마·언어·투명도·배경 표시·설정·About·창 제어 |
| 탭 바 | 세션 전환, **+**(새 세션), 닫기, 창 밖으로 드래그하여 분리(새 창 윤곽 미리보기) |
| 터미널 | MyShell 또는 SSH 출력 |
| 상태바 | 로컬/SSH, 세션명, 글꼴, 크기(열×행) — 설정에서 On/Off |

창 가장자리를 잡아 크기를 줄이면, 툴바 아이콘·라벨이 가려지지 않는 최소 폭까지만 줄어듭니다.

## 3. 툴바 기능

### 세션·연결

- **원격 SSH**: 연결 / 연결 중이면 해제
- **프롬프트**: 로컬 셸 프롬프트 템플릿 편집
- **지우기**: 화면 지우기(프롬프트 다시 표시)
- **복사 / 붙여넣기**: 선택 영역 복사, 클립보드 붙여넣기

탭 바 오른쪽 **+** 를 누르면 새 로컬 세션 탭이 추가됩니다.

### 글꼴

- **A− / A+**: 크기 조절
- **글꼴 종류**: Cascadia, Consolas, D2Coding 등 목록에서 선택

### 테마·언어

- **테마**: Dark, Light, Midnight, Forest, Sunset, Ocean, Custom
- **언어**: English / 한국어 — 툴팁, 메뉴, 대화상자, 탭 제목 등에 즉시 반영

### 배경

- **이미지 투명도 슬라이더 (0%–100%)**: 배경 **이미지**의 투명도  
  - `0%` = 이미지 선명(완전 표시)  
  - `100%` = 이미지 숨김  
  - 배경색은 설정에서 따로 지정하며, 이미지 뒤에 깔립니다.
- **배경 표시**: 이미지 배치 방식  
  - 가득채움 / 맞춤 / 늘이기 / 가운데 / 패턴  

배경 이미지 자체는 **설정**에서 선택합니다. 이미지를 고르면 잘 보이도록 투명도가 최소 35%로 맞춰질 수 있습니다.

### 설정·정보

- **설정(톱니바퀴)**: 터미널·테마·배경 상세 (변경 즉시 적용)
- **About**: 버전·작성자·연락처
- **창 버튼**: 최소화 / 최대화·복원 / 닫기 (웹에서는 숨김)

## 4. 설정 대화상자

설정을 바꾸면 **적용 버튼 없이 바로 반영·저장**됩니다. 닫기만 누르면 됩니다.

### 터미널

| 항목 | 설명 |
|------|------|
| 스크롤 기억 줄 수 | 스크롤로 되돌릴 줄 수 (100–100000, 기본 1000) |
| 상태바 표시 | 하단 상태바 On/Off |
| 시스템 트레이 아이콘 | 트레이에 아이콘 표시 (데스크톱). 아이콘 클릭 시 설정 창이 열림 |

설치 프로그램(Windows NSIS)에서도 **시스템 트레이 아이콘 사용 여부**를 선택할 수 있습니다. 설치 후 설정에서 다시 변경할 수 있습니다.

트레이가 켜진 상태에서 창을 닫으면 앱이 종료되지 않고 트레이로 숨겨집니다. 트레이 메뉴의 **종료**로 완전히 끝냅니다.

### 테마 색상

터미널 배경색, 글자색, 커서, 선택, 강조색, 툴바 배경 등을 지정합니다.  
**초기화**는 사용자 지정 색상을 기본 다크 테마 기준으로 되돌립니다.

### 배경 이미지

1. **이미지 선택…** — png/jpg/jpeg/gif/webp/avif/tiff/bmp/svg/ico (최대 5MB)
2. 미리보기로 확인
3. **표시 방법** — 가득채움 / 맞춤 / 늘이기 / 가운데 / 패턴 (툴바와 동일 옵션)
4. **제거** — 배경 이미지 삭제

이미지가 잘 보이려면 툴바에서 투명도를 높이세요.

## 5. 세션 탭

- 탭 클릭: 세션 전환
- 탭의 ×: 세션 닫기 (마지막 하나일 때는 셸만 재시작)
- **탭을 창 밖으로 드래그**: 해당 세션이 새 창으로 분리됩니다.

## 6. SSH 원격

1. 툴바 **원격 SSH** 클릭  
2. 호스트, 포트, 사용자, 비밀번호 또는 개인키 경로 입력  
3. **연결**  
4. 연결 중에는 같은 탭이 원격 셸로 전환됩니다.  
5. 다시 원격 버튼을 누르면 연결 해제 후 로컬로 돌아갑니다.

호스트·포트·사용자·키 경로는 기억될 수 있으나, 비밀번호는 저장하지 않습니다.

## 7. MyShell (로컬 셸)

데스크톱 로컬 세션은 시스템 cmd/bash 래퍼가 아니라 **내장 MyShell**입니다.  
주요 명령:

| 명령 | 설명 |
|------|------|
| `help` / `?` | 도움말 |
| `clear` / `cls` | 화면 지우기 |
| `pwd` | 현재 경로 |
| `cd` | 디렉터리 이동 |
| `ls` | 여러 열 목록 |
| `dir` | Windows 스타일 목록 |
| `cat` / `type` | 파일 내용 |
| `mkdir` / `md` | 폴더 생성 |
| `rm` / `del` | 삭제 |
| `cp` / `copy`, `mv` / `move` | 복사·이동 |
| `echo`, `date`, `whoami`, `env` | 정보 출력 |
| `history` | 명령 기록 |
| `prompt` | 프롬프트 템플릿 (또는 툴바에서 설정) |
| `run` / `exec` | 외부 프로그램 실행 |
| `uname` / `sysinfo` | 시스템 정보 |

`prompt` 토큰 예: `{user}` `{host}` `{cwd}` `{cwd:short}` `{time}` `{date}` `{cyan}` `{yellow}` `{reset}` 등.

## 8. 단축·팁

- 링크가 보이면 클릭하여 기본 브라우저로 열 수 있습니다.
- 투명 창이므로, 배경 이미지 + 투명도를 조합하면 바탕화면이 비치는 터미널을 만들 수 있습니다.
- 언어를 바꾸면 열려 있던 설정 창은 닫히고, 다시 열면 새 언어로 표시됩니다.
- 설정·글꼴·테마·창 크기/위치는 앱을 다시 실행해도 유지됩니다.

## 9. 문제 해결

| 증상 | 확인 |
|------|------|
| 최근 UI 변경이 안 보임 | `npm start`로 재시작 (렌더러 번들 필요) |
| 배경 이미지가 안 보임 | 투명도를 올리고, 표시 방식을 바꿔 보세요 |
| SSH 실패 | 호스트/포트/계정·키·방화벽 확인 |
| 창이 너무 안 줄어듦 | 툴바가 잘리지 않도록 최소 폭이 제한되어 있습니다 |
| 웹에서 SSH 없음 | 정상입니다. 데스크톱 앱을 사용하세요 |
