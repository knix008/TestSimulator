# MyWorkForce 사용 설명서

MyWorkForce는 한 회사의 일을 한곳에서 다루는 프로그램입니다. **과제**와 **이슈**로 할 일을 계획하고 추적하며(보드, 백로그, 스프린트, 로드맵, 타임라인), **작업 공간**의 **페이지**에 알아야 할 내용을 함께 씁니다. 같은 회사 사람은 각자 계정으로 들어가 같은 자료를 봅니다. 함께 쓰는 대화 프로그램 **MyWorkForce Talk**도 들어 있습니다.

이 설명서는 왼쪽 목차의 장 순서대로 읽어도 되고, 필요한 장만 골라 읽어도 됩니다. 위쪽의 **찾기**로 낱말을 찾고, **−/+**로 글자 크기를 바꾸고(Ctrl + / Ctrl −), **한국어 / English**로 언어를 바꾸며, **인쇄**로 종이나 PDF로 남깁니다. 그림은 프로그램의 실제 화면이며, 누르면 창 가득 크게 보입니다.

## 시작하기

### 설치와 실행

설치 프로그램은 처음에 **한국어**와 **English** 가운데 설치 언어를 묻습니다. 고른 언어로 설치가 진행되고, 설치 뒤 처음 실행하면 MyWorkForce와 Talk, 알림 영역 메뉴가 모두 그 언어로 열립니다. 언어는 나중에 도구 막대의 언어 단추(Ctrl+Shift+L)로 바꿀 수 있습니다.

설치 프로그램으로 설치하면 시작 메뉴에 **MyWorkForce**와 **MyWorkForce Talk**이 함께 들어갑니다. 프로그램은 데이터 서비스(회사 안의 `1481` 포트)를 스스로 띄우므로 따로 실행할 것이 없습니다. 웹 브라우저로 쓸 때는 관리자가 알려 준 주소로 들어갑니다.

### 로그인

시작 화면 위쪽의 **로그인** 단추나 **시작** 카드의 **로그인**으로 로그인 창을 엽니다. 아이디와 암호를 넣고 들어갑니다.

- 로그인 창의 **닫기**(×)를 누르면 창이 닫히고 시작 화면을 계속 볼 수 있습니다. 로그인하지 않고 쓸 수 있는 것은 사용 설명서, 튜토리얼 문서, 시작 화면 배경 바꾸기, 언어 바꾸기, 프로그램 정보뿐입니다. 예제, 파일 열기·끌어 놓기, 단축키, 설정은 모두 로그인 창을 엽니다.
- 데이터 서비스에 연결된 데이터베이스가 없으면 아무도 로그인할 수 없습니다. 이때만 데이터 서비스가 도는 컴퓨터의 로그인 창에 **데이터베이스 설정**이 나타나 데이터베이스를 먼저 정합니다.
- 과제와 페이지를 열거나 튜토리얼을 시작하는 등 실제 작업을 하려면 반드시 로그인해야 합니다. 그때 로그인 창이 다시 열립니다.
- 관리자가 정해 준 암호는 임시 암호입니다. 처음 로그인할 때 자기 암호로 바꿔야 다른 화면을 쓸 수 있습니다. 암호는 6자 이상이며, 언제든 **파일 → 암호 바꾸기**에서 바꿉니다.
- 처음 설치했을 때의 관리자 계정은 `admin`입니다. 처음 로그인하면 새 암호를 정합니다.
- 로그인에 실패하면 로그인 창에 이유(암호가 맞지 않음, 등록되지 않은 사용자)와 잠기기까지 남은 횟수가 나옵니다.
- 한 계정이 **5번 연달아** 실패하면 그 계정은 정한 시간 동안(기본 10분) 로그인할 수 없습니다. 로그인 창에 남은 시간이 1초마다 줄어들며 나오고, 그동안은 맞는 암호도 받지 않습니다. 프로그램을 다시 시작해도 잠금은 그대로입니다.

### 시작 화면

시작 화면은 카드 몇 장으로 이루어져 있습니다.

| 부분 | 하는 일 |
| --- | --- |
| 위쪽 도구 줄 | **시작할 때 시작 화면 표시**, **시작 화면 설정**(보일 카드와 안내 창 고르기), **자동 정렬**(카드를 빈틈없이 다시 놓기) |
| 프로그램 카드 | 프로그램 이름과 버전, **사용 설명서**, **튜토리얼 문서**, **도움말** 메뉴, **튜토리얼 시작** |
| 시작 | 튜토리얼, 문서, 예제, 들어가기(또는 로그인), 시작 안내 창, 단축키, 언어, 프로그램 정보 |
| 과제 | 내가 참여하는 과제. 누르면 그 과제로 들어갑니다 |
| 예제 | 소프트웨어, 업무, 서비스 예제 30개. 누르면 그 예제로 바뀝니다 |
| 배경 | 움직이는 배경 24가지, 속도, 시작할 때 무작위, 자동으로 바꾸기 |

카드는 손잡이를 끌어 옮기고, 오른쪽 아래 모서리를 끌어 크기를 바꿉니다. 배경은 로그인하지 않아도 바꿀 수 있습니다.

## 화면 구성

| 부분 | 내용 |
| --- | --- |
| 메뉴 막대 | 시작, 파일, 편집, 보기, 이슈, 계획, 도움말, 관리자. 창 제목 역할도 하며, 오른쪽 끝(최소화 단추 왼쪽)에 왼쪽·오른쪽 패널을 열고 닫는 단추가 있습니다 |
| 도구 막대 | 과제 고르기, 검색칸, **돋보기**(전체 검색), 이동(Ctrl+K), 새 이슈, 알림, Talk, 로그인한 사람, 로그아웃, 언어, 테마, 프로그램 정보 |
| 왼쪽 탐색 | 분류별 구역: **회사**(팀, 과제, 문서, 근무 달력, 교차 계획), **작업 공간**(작업 공간과 그 페이지 트리, 새 작업 공간), **내 작업**(내 팀, 참여 과제), **이 과제**(열린 과제의 화면), **관리자 메뉴**. 구역 제목을 누르면 접히고 펴지며, 접은 상태는 다음에 열 때도 남습니다 |
| 가운데 | 고른 화면 |
| 오른쪽 패널 | 고른 이슈, 페이지, 작업 공간의 정보와 속성. 왼쪽과 같이 구역별로 나뉘고, 구역 제목을 누르면 접히며, 접은 상태는 다음에도 남습니다 |
| 상태 막대 | 이슈 수, 과제 종류, 로그인한 사람, 데이터베이스 |

도구 막대의 아이콘에 마우스를 올리면 이름과 단축키가 나옵니다. 왼쪽과 오른쪽 패널은 Ctrl+Shift+1, Ctrl+Shift+2로 접고 펼칩니다.

## 회사, 팀, 과제

MyWorkForce는 회사 하나를 다룹니다. 회사 안에는 여러 **팀**이 있고, 팀은 **과제**를 진행합니다.

### 팀

**회사 → 팀**에서 팀 카드를 보고, 카드를 열면 그 팀의 과제, 팀 페이지, 구성원이 나옵니다. 팀은 관리자가 만들고 지웁니다. 팀 이름과 구성원은 관리자와 팀장이 바꿉니다. 과제가 남아 있는 팀은 지울 수 없습니다.

### 과제 만들기와 열기

**새 과제**(Ctrl+Shift+N)에서 이름, 키(영문 대문자로 시작하는 2–10자), 종류(소프트웨어, 업무, 서비스), 팀을 정합니다. 만든 사람이 책임자가 됩니다. **과제** 목록의 행이나 팀 화면의 과제 카드는 **열기** 단추를 누르거나 **두 번 눌러** 엽니다.

### 관리 방법

과제마다 진행 방법을 고릅니다. 이슈 목록, 칸반, 스크럼, 로드맵, 릴리스, 서비스 대기열 가운데 필요한 것만 켜면 왼쪽 **이 과제**에 그 화면만 나옵니다. 로드맵을 켜면 **타임라인**도 함께 나옵니다.

### 사람과 권한

과제마다 사람을 넣고 **보기**(읽기만), **편집**(이슈와 페이지를 만들고 바꿈), **책임자**(사람, 권한, 설정 관리) 가운데 하나를 줍니다. 과제 삭제는 관리자만 할 수 있습니다.

## 이슈

### 만들기

도구 막대의 **+**나 Ctrl+N으로 만듭니다. 유형, 요약, 설명, 우선순위, 담당, 에픽, 스프린트, 포인트를 넣습니다. 하위 작업은 상위 이슈를 연 뒤에 만듭니다.

### 이슈 화면

요약을 바로 고치고, 설명은 Markdown으로 씁니다. 탭은 **설명, 의견, 작업 기록, 기록, 연결**입니다. 의견에 `@이름`을 쓰면 그 사람에게 알림이 갑니다. 작업 기록은 `90`, `1h 30m`, `1.5h`, `2d`처럼 적습니다(하루는 8시간).

오른쪽 패널에서 상태, 해결, 담당, 보고자, 에픽, 스프린트, 포인트, 추정, **시작**, **기한**, 라벨, 구성 요소, 수정 버전, 사용자 정의 필드를 바꿉니다. 관찰과 첨부(파일 하나에 700KB)도 거기 있습니다.

### 연결과 의존 관계

**연결** 탭에서 다른 이슈와 잇습니다. 종류는 **막음**, **관련**, **중복**, **복제**입니다. "A가 B를 막음"이면 B는 A가 끝나기를 기다립니다.

- 끝나지 않은 앞선 이슈가 있으면 이슈 화면 위에 **먼저 끝나야 할 이슈**가 붉게 나오고, 보드 카드에 자물쇠가 붙습니다.
- 서로를 기다리게 되는 연결(A가 B를 막고 B가 A를 막음)은 만들 수 없습니다.

### 목록과 한꺼번에 바꾸기

**이슈** 화면에서 칸 제목을 눌러 정렬하고, 여러 이슈를 골라 상태나 담당을 한 번에 바꿉니다. 화면 위의 검색칸과 분류(유형, 상태, 우선순위, 담당)로 좁힙니다. 질의칸에는 WQL을 쓸 수 있습니다(WQL 장 참고). CSV 가져오기도 여기 있습니다.

## 보드와 백로그

### 보드

스크럼 보드는 진행 중인 스프린트의 이슈만, 칸반 보드는 모든 이슈를 보여 줍니다. 카드를 다른 열로 끌어 상태를 바꿉니다. 열에 한도가 있으면 넘었을 때 테두리가 붉어집니다. **카드를 두 번 누르면** 그 이슈가 열립니다. 위쪽 고르기로 담당, 에픽, 우선순위별 레인을 나눕니다.

### 백로그와 스프린트

백로그에서 이슈를 스프린트로 끌어 넣고, 예정 스프린트를 **시작**합니다. 보드나 백로그에서 **완료**하면 끝내지 못한 이슈를 백로그나 다음 스프린트로 보냅니다. 백로그 행도 두 번 누르면 열립니다. 오른쪽 패널에서 에픽으로 좁힙니다.

## 로드맵과 타임라인

### 로드맵

에픽마다 안의 이슈가 얼마나 끝났는지 막대로 보여 줍니다.

### 타임라인

과제의 이슈를 시간 축에 막대로 놓습니다. 에픽 아래에 그 이슈가 모이고, 에픽 없는 이슈는 따로 모입니다.

- 막대는 이슈의 **시작**부터 **기한**까지입니다. 날짜가 없으면 스프린트 기간이나 만든 날부터 일주일로 어림하며, 그런 막대는 점선입니다.
- **막대를 끌면** 날짜가 옮겨지고, **양 끝을 끌면** 기간이 바뀝니다.
- 막대에 마우스를 올리면 오른쪽에 점이 나옵니다. 그 점을 **다른 막대로 끌어 놓으면** "막음" 연결이 생깁니다.
- 화살표는 의존 관계입니다. 앞선 이슈가 다음 이슈의 시작보다 늦게 끝나면 **화살표가 붉어지고** 위에 경고가 나옵니다.
- 위쪽에서 **일 / 주 / 월** 눈금, **오늘로**, **날짜 없는 이슈도**를 고릅니다. 이름을 누르면 이슈가 열립니다.

## 작업 공간과 페이지

알아야 할 내용은 **작업 공간**의 **페이지**에 씁니다. 회사 공용 작업 공간은 모두가, 팀 작업 공간은 그 팀원이, 과제 작업 공간은 그 과제의 사람이 봅니다.

### 작업 공간 만들기

왼쪽 탐색의 **회사 → 작업 공간** 아래에 볼 수 있는 작업 공간이 모두 나옵니다. **작업 공간** 앞의 화살표로 목록을 접고 펴고, 작업 공간마다 앞의 화살표로 그 페이지 트리를 접고 폅니다. 맨 아래 **새 작업 공간**(또는 **작업 공간** 줄의 **+**)을 누르면 이름 칸이 나오고, 이름을 적고 Enter를 누르면 만들어집니다(Esc는 취소). 키는 저절로 정해집니다.

작업 공간 이름을 누르면 가운데에 그 홈(설명, 페이지 찾기, 페이지, 최근 바뀐 페이지)이, 오른쪽 패널에 **작업 공간 속성**이 열립니다. 속성에서 이름, 설명, **보는 사람**(회사 전체, 한 팀, 한 과제)을 바꾸고, 키와 만든 사람, 페이지 수, 마지막 변경을 보며, **휴지통**의 페이지를 되돌리거나 영구 삭제하고, **작업 공간 삭제**를 합니다. 속성은 만든 사람과 관리자가 바꿉니다. **작업 공간 삭제**는 안의 페이지(휴지통 포함)를 모두 함께 지우며, 몇 개가 지워지는지 먼저 묻습니다. 되돌릴 수 없습니다.

### 오른쪽 클릭 메뉴와 삭제

왼쪽 탐색이나 하위 페이지 목록에서 **페이지를 오른쪽 클릭**하면 열기, 하위 페이지 만들기, 복사본 만들기, HTML로 내보내기, **휴지통으로 삭제**가 나옵니다. **작업 공간을 오른쪽 클릭**하면 열기, 새 페이지, 속성, **작업 공간 삭제**가 나옵니다. 페이지 위쪽 경로 줄 오른쪽의 휴지통 단추로도 지웁니다. 삭제 메뉴는 그럴 권한이 있는 사람(페이지는 편집할 수 있는 사람, 작업 공간은 만든 사람과 관리자)에게만 나옵니다.

페이지를 휴지통으로 옮기면 그 아래 하위 페이지도 함께 옮겨지고, 되돌리면 함께 돌아옵니다. 휴지통은 작업 공간 속성(오른쪽 패널)에 있으며, 거기서 되돌리거나 영구 삭제합니다.

### 페이지 만들기와 샘플

작업 공간 줄의 **+**는 새 페이지를, 페이지 줄의 **+**는 그 아래 하위 페이지를 만듭니다. 새 페이지를 만들면 **샘플** 창이 먼저 열립니다.

- 여덟 분류(회의, 기획·제품, 개발, 운영·IT, 프로젝트 관리, 인사·조직, 영업·마케팅·고객, 일반 업무)에 샘플 40개가 있습니다. 회의록, 회고, 제품 요구사항, 기술 설계 문서, 장애 보고서, 런북, 프로젝트 계획서, 위험 관리 대장, 온보딩, OKR, 캠페인 계획, FAQ, 업무 매뉴얼, 주간 업무 보고 등입니다.
- 샘플을 누르면 오른쪽에 미리 보이고, **이 샘플로 만들기**나 두 번 누르기로 그 내용이 든 페이지가 열립니다. **빈 페이지**는 제목만 있는 페이지입니다.

### 쓰기

페이지를 누르면 **바로 편집 상태로** 열립니다. 쓴 내용은 **저절로 저장**되고(편집기 아래에 "저장됨"이 나옵니다), **저장** 단추나 Ctrl+S로 바로 저장할 수도 있습니다. 다른 페이지로 옮기면 쓰던 내용은 먼저 저장됩니다. **미리 보기**는 읽는 사람이 보는 모양(이슈 목록과 언급이 살아 있는 모양)을 보여 줍니다.

서식 막대에는 실행 취소, 본문, 제목 1–3, 굵게, 기울임, 취소선, 코드, 목록, 번호 목록, 인용, 코드 블록, 구분선, 링크, 표, 목차, 하위 페이지 목록, **이슈 넣기**, **사람 언급**, 이미지, 파일이 있습니다. 오른쪽 끝 단추로 Markdown 원본을 직접 고칩니다.

### 이슈 넣기

**이슈 넣기**에서 **이슈 하나**를 고르고 키(예: `PAY-12`)를 적으면 그 이슈가 상태와 함께 칩으로 들어갑니다. **질의 목록**을 고르고 과제와 WQL(예: `status != done`)을 적으면 그 질의의 이슈가 표로 들어갑니다. 둘 다 볼 때마다 최신 상태로 나오고, 누르면 이슈가 열립니다. 글로는 `[[issue:PAY-12]]`, `[[issues:PAY | status != done]]`로 남습니다.

### 언급

본문이나 댓글에 `@`를 치면 사람 목록이 나옵니다. 화살표와 Enter로 고르면 `@이름`이 들어가고, 그 사람에게 알림이 갑니다. 그 페이지를 볼 수 있는 사람에게만 갑니다.

### 페이지 정보 패널

오른쪽 패널에 페이지 정보가 나옵니다. 작업 공간, 종류, 만든 사람, 마지막 수정, 조회, 판, 라벨, 상태(초안, 검토, 게시), 상위 페이지, 좋아요와 관찰, 권한과 공유(제한, 편집자, 읽는 사람, 공개 링크), 내보내기(HTML, 워드, PDF, Markdown), 복사본, 휴지통, **이전 판**이 있습니다.

### 이전 판과 비교

저장할 때마다 이전 판이 남습니다(한 사람이 10분 안에 저절로 저장한 것은 한 판으로 묶습니다). 이전 판의 **비교** 단추는 두 판의 차이를 보여 줍니다. 지운 줄은 붉게, 더한 줄은 푸르게 나오고, 위쪽에서 비교할 두 판을 고릅니다. **되돌리기**는 그 판으로 돌아갑니다.

## 댓글, 파일, 함께 쓰기

### 댓글과 답글

페이지 아래 **댓글**에 쓰고 **댓글 남기기**나 Ctrl+Enter로 남깁니다. 댓글마다 **답글**을 달 수 있고, 쓴 사람은 고치거나 지웁니다.

### 본문 댓글

본문에서 글을 고르면 **댓글** 단추가 나옵니다. 거기에 쓴 댓글은 그 부분과 이어져, 본문의 그 부분이 노랗게 칠해집니다. 칠한 부분을 누르면 그 댓글로, 댓글의 인용을 누르면 본문의 그 부분으로 갑니다. 논의가 끝나면 **해결**을 눌러 칠을 지우고, **다시 열기**로 되살립니다.

### 파일

페이지 아래 **파일**에 파일을 끌어 놓거나 **파일 추가**로 여러 개를 한 번에 넣습니다. 파일 하나는 700KB까지이며, 큰 파일은 이름을 알려 주고 건너뜁니다. 서식 막대의 이미지와 파일 단추는 본문 안에 넣습니다.

### 함께 쓰기

여러 사람이 같은 페이지를 동시에 열면 **함께 쓰기**가 됩니다. 경로 옆에 "○○ 님과 함께 쓰는 중"이 나오고, 다른 사람이 쓴 내용이 1초 남짓 사이에 내 화면에 들어옵니다. 서로 다른 줄을 고치면 둘 다 남고, 같은 줄을 동시에 다르게 고치면 두 내용이 모두 남아 정리할 수 있습니다. 쓰는 동안 커서는 그 자리에 머뭅니다.

## 전체 검색

도구 막대의 **돋보기**(Ctrl+Shift+F)는 **전체 검색**을 엽니다. 과제, 이슈, 작업 공간, 페이지, 문서, 댓글, 파일, 사람, 팀을 한 번에 찾아 분류별로 보여 줍니다.

- **전체** 탭은 분류마다 다섯 개씩, 다른 탭은 그 분류를 모두 보여 줍니다. 찾은 낱말은 노랗게 칠해집니다.
- 여러 낱말을 적으면 모두 들어 있는 것만 나옵니다. 볼 권한이 없는 것은 나오지 않습니다.
- 결과를 누르면 그 자리로 갑니다. 파일은 바로 내려받을 수 있습니다.
- 도구 막대 검색칸에 낱말을 적고 Enter를 눌러도 전체 검색이 열립니다. `status = done`처럼 WQL을 적으면 이슈 목록이 열립니다.

## 알림과 Talk

### 알림

도구 막대의 종에 읽지 않은 알림 수가 나옵니다. **알림** 화면에는 과제의 알림(담당, 의견, 상태 변경, 관찰하는 페이지)과 회사 알림(언급, 회사·팀 페이지의 변경)이 함께 나옵니다. 알림을 누르면 그 이슈나 페이지가 열리고, **모두 읽음**으로 정리합니다. 아래 **알림 설정**에서 과제, 페이지, 문서, 이슈마다 받을 일을 고릅니다.

### MyWorkForce Talk

도구 막대의 **대화** 단추가 Talk을 엽니다. 한 사람이나 여러 사람과 대화하고 파일을 보냅니다. 왼쪽 아이콘 줄은 알림, 대화, 사람, 초대, 내 정보, 언어, 작업 프로그램, 암호, 로그아웃입니다.

- 작업 알림은 사람마다 자기 **알림** 방에 쌓입니다. 알림 앞에 "회원님을 언급했습니다", "페이지 댓글"처럼 무슨 일인지가 나오고, 누르면 그 이슈나 페이지가 메인 창에 열립니다(페이지는 바로 편집 상태).
- 메시지에서도 `@`를 치면 사람 목록이 나오고, `@이름`은 강조됩니다.
- 한쪽에 로그인하면 다른 쪽도 같은 계정으로 들어가고, 한쪽에서 로그아웃하면 다른 쪽도 나갑니다.

## 문서

**문서** 화면의 양식으로 회의록, 결정, 명세, 요구사항, 시험 보고, 릴리스 노트, 회고, 진행 보고, 설계, 장애 보고, 절차, 인수인계, 주간 보고, 제안을 만듭니다. 문서는 만든 사람만 고치며, **나만**, **과제**, **모두**로 공유합니다. 이슈 키를 적으면 그 이슈와 함께 찾을 수 있고, HTML, 워드, PDF, Markdown으로 내보냅니다.

- 문서는 화면 전체를 씁니다. **공유**와 **내 문서**는 목록으로 보이며, 머리글을 눌러 정렬하고 가장자리를 끌어 폭을, 머리글을 끌어 순서를 바꿉니다.
- 문서를 열면 위쪽에 탭으로 열립니다. 여러 문서를 열어 두고 탭을 눌러 오가며, 오른쪽의 **<**, **>**로 이전·다음 문서로 갑니다. 탭의 ×로 닫습니다.
- 제목, 양식, 작성자, 수정 시각, 이슈, 공유는 편집 창 위쪽에 있습니다. 본문은 **편집**, **나란히**(왼쪽 Markdown, 오른쪽 미리보기), **미리보기**로 봅니다. 미리보기는 쓰는 대로 바뀝니다.
- **인쇄**는 인쇄 창을 엽니다.

## 살펴보기

- **대시보드**: 가젯(내 이슈, 활동, 스프린트, 분포, 생성과 해결)을 더하거나 뺍니다.
- **보고서**: 번다운, 속도, 누적 흐름, 생성과 해결, 분포, 시간, 스프린트, 제어 차트, 에픽 번다운.
- **필터**: 이슈 화면의 질의를 이름으로 남깁니다.
- **점검**: 상위 없는 하위 작업, 해결 없는 완료, 기한 초과, 막힌 이슈를 알려 줍니다.
- **대기열**: 서비스 과제의 요청을 기한(SLA)과 함께 봅니다.

## WQL

WQL은 이슈를 고르는 질의 언어입니다. **꼭 알아야 하는 것은 아닙니다.** 대부분은 화면 위의 검색칸과 분류 드롭다운, 전체 검색으로 충분합니다. 조건이 복잡할 때, 필터와 대기열을 저장할 때, 페이지에 질의 목록을 넣을 때 씁니다.

| 예 | 뜻 |
| --- | --- |
| `status != done` | 끝나지 않은 이슈 |
| `assignee = currentUser()` | 내게 맡겨진 이슈 |
| `type = bug AND priority = highest` | 가장 급한 결함 |
| `text ~ "환불"` | 요약이나 설명에 "환불"이 든 이슈 |
| `status != done ORDER BY due ASC` | 끝나지 않은 이슈를 기한 순으로 |

전체 문법은 **도움말 → WQL 설명서**에 있습니다.

| 암호 바꾸기, 로그아웃 | 내 계정 |

## 설정과 관리

### 계정과 사람

관리자는 **사용자** 화면에서 사람을 만들고 아이디와 임시 암호를 정합니다. 이름, 직급, 팀, 휴대폰, 메일, 사진은 사람 정보에 들어가며 저장소에 암호화되어 남습니다. **사용** 칸을 끄면 그 사람은 로그인할 수 없습니다.

- **관리자** 칸을 켜면 그 사람에게 관리자 권한을 줍니다. 관리자는 여러 명일 수 있고, 로그인할 수 있는 관리자가 마지막 한 명이면 권한을 빼거나 계정을 끌 수 없습니다.
- 처음 설치하면 관리자 계정은 `admin` / `admin`이며, 처음 로그인할 때 새 암호를 정합니다.
- 관리자도 자기 아이디를 바꿀 수 있습니다. **사용자** 화면에서 자기 줄의 연필을 눌러 아이디를 고치면 다음 로그인부터 새 아이디를 씁니다. 암호는 같은 창의 **내 암호 바꾸기** 또는 **파일 → 암호 바꾸기**에서 바꿉니다.

### 감사 로그

관리자 메뉴의 **감사 로그**에서 데이터베이스에 남은 기록을 봅니다. 기록 내용은 암호화되어 저장됩니다.

- **관리자 변경**: 첫 관리자 계정 생성, 관리자 권한 주기·빼기, 사용자 만들기·삭제, 아이디 바꾸기, 계정 사용·중지, 관리자가 정한 암호, 로그인 잠금 시간 변경·잠금 풀기, 데이터베이스 연결, 암호화 키 보기.
- **사용자 활동**: 로그인, 로그인 실패(이유와 남은 횟수), 로그인 잠김, 로그아웃, 자기 암호 바꾸기, 저장할 때 만들거나 바꾸거나 지운 과제·이슈·페이지.
- 분류, 사건, 한 사람(아이디), 기간, 찾을 말로 검색합니다. 결과는 목록으로 보이며 머리글을 누르면 정렬(다시 누르면 반대로), 머리글 오른쪽 가장자리를 끌면 열 폭, 머리글을 끌면 열 순서가 바뀝니다. 끄는 동안 열의 실루엣과 놓일 자리가 보입니다. 정렬·폭·순서는 이 컴퓨터에 기억됩니다.
- 행을 누르면 아래에 자세한 내용이 나오고, **CSV로 저장**은 보이는 순서대로 파일에 저장합니다.

### 인쇄 창

인쇄는 따로 열리는 인쇄 창에서 합니다. 왼쪽에서 정하면 오른쪽 미리보기가 바로 바뀝니다.

- **프린터**: 이 컴퓨터의 프린터 가운데서 고르고 **매수**를 정합니다. 고른 프린터로 바로 인쇄합니다. "PDF로 인쇄" 같은 파일 프린터를 고르면 PDF 파일로 저장합니다.
- **인쇄 범위**: 모두, 현재 쪽, 쪽 지정(예: 1-3, 5). 인쇄하지 않을 쪽은 미리보기에서 흐리게 보입니다.
- **페이지 설정**: 용지(A3, A4, A5, B4, B5, Letter, Legal, Tabloid), 방향(세로·가로), 여백(없음·좁게·보통·넓게·직접 정하기 — 위·오른쪽·아래·왼쪽을 mm로), 배율(30–300%), 컬러·흑백.
- **머리글과 바닥글**: 머리글에 제목, 바닥글에 쪽 번호와 날짜.
- 미리보기는 **<**, **>** 또는 PageUp/PageDown으로 넘기고, **폭 맞춤**과 **100%**로 크기를 바꿉니다. **PDF로 저장**은 같은 쪽을 PDF 파일로 만듭니다.

### 설정 화면

**설정**과 **프로그램 정보**는 메인 창과 따로 열리는 창입니다. 설정 창에서 바꾼 모양, 글꼴, 언어, 시작 화면은 메인 창에 바로 적용됩니다.


설정은 묶음별 카드로 보입니다. **일반**(시작 화면, 배경, 모양, 글꼴, 테마), **이 컴퓨터와 로그인**(부팅할 때 MyWorkForce와 Talk 실행, 자동 로그인, 로그인 잠금), **데이터**(데이터베이스와 스키마), **알림**(메일 서버)입니다.

- **로그인 잠금**(관리자): 5번 연달아 실패한 계정이 기다리는 시간을 10분, 20분, 30분, 1시간, 2시간, 3시간, 6시간, 12시간, 1일, 2일, 7일 가운데서 고르거나 **직접 정하기**로 분·시간·일 단위로 넣습니다. 10분보다 짧게는 정할 수 없고 가장 긴 시간은 30일입니다. **새로 고침**으로 지금 잠긴 계정을 보고 **잠금 풀기**로 바로 풀어 줍니다.
- **데이터베이스**: 기본은 이 컴퓨터의 SQLite이고, MySQL, MariaDB, SQL Server, PostgreSQL도 씁니다. 처음 연결할 때 표가 없으면 만들고 스키마를 최신으로 올립니다(**없으면 데이터베이스 만들기**를 켜면 데이터베이스도 만듭니다). 관리자는 **스키마** 카드에서 표 상태를 보고 DBA에게 줄 SQL을 받습니다.
  - **연결 시험**: 지금 쓰는 데이터베이스는 그대로 둔 채 넣은 설정으로 접속해 봅니다. 접속 여부와 걸린 시간, 연결이 TLS로 암호화되었는지, 스키마 상태(없는 표는 연결할 때 만듦), 암호화 키가 맞는지를 보여 줍니다.
  - **저장 데이터 암호화**: 과제, 문서, 페이지, 대화, 메일, 사람 정보는 데이터베이스에 넣기 전에 AES-256-GCM으로 암호화합니다. 다섯 종류 데이터베이스 모두 같습니다. 예전에 암호화 없이 저장된 데이터는 처음 연결할 때 암호화합니다.
  - **DB를 별도 서버에 둘 때**: 서버 데이터베이스는 기본으로 **TLS로 암호화해 연결**합니다. 공인 인증서라면 **서버 인증서 확인**도 켭니다. 데이터 서비스를 다시 설치하거나 하나 더 두면, 먼저 쓰던 데이터 서비스의 **저장 데이터 암호화 → 키 보기**에서 키를 복사해 새 쪽의 **암호화 키**에 넣고 연결합니다. 키는 그 데이터베이스용으로 기억됩니다. 키를 잃으면 데이터를 읽을 수 없으니 안전한 곳에 보관하세요.
- **메일**: 회사 밖 메일 서버(587은 STARTTLS, 465는 SSL)를 넣고 **시험 발송**으로 확인합니다.

### 과제 설정

과제 이름, 설명, 책임자, 관리 방법, 보관, 작업 흐름(상태와 전이), 사용자 정의 필드, 자동화 규칙(만들어지거나 상태가 바뀔 때 담당, 우선순위, 라벨, 관찰 바꾸기)을 정합니다. 쓰는 이슈가 있는 상태는 지울 수 없습니다.

## 단축키

글자를 입력하는 칸에서는 Ctrl 조합만 동작합니다. 전체 목록은 **도움말 → 단축키**(?)에서도 봅니다.

| 키 | 동작 |
| --- | --- |
| Ctrl+Shift+N | 새 과제 |
| Ctrl+N, C | 새 이슈 |
| Ctrl+O, Ctrl+S, Ctrl+Shift+S | 열기, 저장(페이지를 쓰는 중이면 페이지 저장), 다른 이름으로 저장 |
| Ctrl+Z, Ctrl+Y | 실행 취소, 다시 실행 |
| Ctrl+F, / | 도구 막대 검색칸 |
| Ctrl+Shift+F | 전체 검색 |
| Ctrl+K | 이슈로 이동 |
| Ctrl+1 … Ctrl+7 | 과제 홈, 보드, 백로그, 로드맵, 이슈, 대시보드, 보고서 |
| Ctrl+9 | 문서 |
| G 다음 H, B, A, I | 과제 홈, 보드, 백로그, 이슈 |
| J, K, Enter | 다음 이슈, 이전 이슈, 고른 이슈 열기 |
| Ctrl+D, Delete | 이슈 복제, 삭제 |
| Ctrl+Shift+T | 하위 작업 |
| Ctrl+Enter | 의견, 댓글, 답글 남기기 |
| Ctrl+Shift+P | 스프린트 만들기 |
| Ctrl+Shift+1, Ctrl+Shift+2 | 왼쪽, 오른쪽 패널 |
| Ctrl+Shift+L, Ctrl+Shift+B | 언어, 테마 바꾸기 |
| Ctrl+, | 설정 |
| F1, ?, Ctrl+Shift+A | 사용 설명서, 단축키, 프로그램 정보 |
| Esc | 창 닫기, 이슈에서 나가기 |

실행 취소는 작업 공간의 변경 40단계까지입니다. 언어와 테마는 취소 대상이 아닙니다.

## 문제 해결

| 증상 | 할 일 |
| --- | --- |
| 로그인 창이 계속 열립니다 | 과제나 페이지 같은 작업은 로그인해야 합니다. 시작 화면만 볼 때는 로그인 창의 닫기를 누르세요 |
| 로그인할 수 없고 남은 시간이 나옵니다 | 5번 연달아 실패해 잠겼습니다. 시간이 지나면 다시 로그인하거나, 관리자가 **설정 → 로그인 잠금**에서 풀어 줍니다 |
| "다른 데이터 서비스의 키로 암호화되어 있습니다" | 먼저 쓰던 데이터 서비스의 **키 보기**에서 키를 복사해 **암호화 키**에 넣고 연결하세요 |
| "DB 서버가 TLS를 지원하지 않습니다" | DB 서버에서 TLS를 켜세요. 꼭 필요할 때만 **TLS로 암호화해 연결**을 끕니다 |
| "다른 사람이 먼저 저장했습니다"가 나옵니다 | 다른 사람이 같은 자료를 먼저 저장해 최신 내용을 다시 열었습니다. 마지막 변경을 다시 하세요 |
| 페이지에 "저장 중…"이 오래 남습니다 | 데이터 서비스와의 연결을 확인하세요. 연결이 돌아오면 저절로 저장합니다 |
| 이슈 목록 표가 "볼 수 없음"으로 나옵니다 | 그 과제에 참여하지 않았거나 질의 문법이 틀렸습니다 |
| 파일이 들어가지 않습니다 | 파일 하나는 700KB까지입니다 |
| 데이터 서비스에 연결하지 못했습니다 | 설치본은 프로그램을 다시 실행하고, 웹은 관리자에게 서버 주소를 확인하세요 |
