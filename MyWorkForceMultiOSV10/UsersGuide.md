# 사용 설명서

MyWorkForce는 한 작업 공간 안의 프로젝트와 이슈를 다룹니다. 메뉴 막대가 창 제목입니다. 왼쪽에서 화면을 고르고, 오른쪽에서 이슈의 속성을 고칩니다.

## 시작

프로그램을 켜면 데이터베이스를 고르는 화면이 먼저 나옵니다. **이 컴퓨터**는 SQLite 파일입니다. **서버 데이터베이스**는 MySQL, MariaDB, SQL Server, PostgreSQL입니다. 지금은 개인용이라 데이터 서비스는 이 컴퓨터의 `127.0.0.1:1481`만 받습니다. 관리 프로그램은 나중에 같은 데이터베이스를 엽니다.

사람 화면에서 암호를 두면, 다음에 들어올 때 그 암호가 필요합니다. 브라우저에 남아 있던 작업 공간은 시작 화면에서 가져올 수 있습니다.

## 튜토리얼과 예제

시작 화면 위쪽 탭에서 튜토리얼, 사용 설명서, 작업 질의, 예제, 데이터베이스를 오갑니다.

**튜토리얼 시작**은 쇼핑몰 예제를 열고 화면 구석의 안내를 따라갑니다. 순서는 홈, 보드, 백로그, 질의, 로드맵, 지식 자료, 근무 달력, 보고서, 사용 설명서입니다. 마지막 단계에서 안내를 닫습니다.

예제는 20개가 넘습니다. 소프트웨어, 업무, 서비스가 섞여 있고, 카드의 문장이 그 작업 공간이 어떤 일을 담는지 알려 줍니다. 카드를 누르면 그 예제로 바뀝니다. 이미 프로젝트가 있으면 바꾸기 전에 묻습니다. 작업 공간 암호가 있으면 시작 화면의 암호칸에 적은 뒤에 엽니다.

홈의 **예제 고르기**는 같은 목록으로 돌아갑니다. **튜토리얼**은 안내를 다시 시작합니다.

## 파일

| 메뉴 | 하는 일 |
| --- | --- |
| 새 프로젝트 | 소프트웨어, 업무, 서비스 중 하나를 만듭니다. 키는 영문 대문자로 시작하는 2–10자입니다. |
| 열기 | `.mwf` 또는 JSON 작업 공간을 엽니다. |
| 저장 | 지금 경로에 저장합니다. 경로가 없으면 위치를 묻습니다. |
| 다른 이름으로 저장 | 새 파일로 저장합니다. |
| Markdown로 내보내기 | 이슈 목록을 표로 저장합니다. |
| CSV로 내보내기 | 같은 목록을 표 계산 프로그램용으로 저장합니다. |
| 이 프로젝트만 내보내기 | 프로젝트 하나와 관련 사람을 저장합니다. |

웹에서는 저장이 다운로드입니다. 열기는 파일 선택입니다. 파일을 창에 떨어뜨려도 엽니다. 작업은 이 기기에도 자동으로 남습니다.

홈의 **예제 고르기**는 시작 화면의 예제 목록으로 돌아갑니다. **빈 작업 공간**은 프로젝트 없는 상태로 바꿉니다.

## 이슈

**이슈** 버튼이나 Ctrl+N 으로 만듭니다. 유형, 요약, 설명, 우선순위, 담당, 에픽, 스프린트, 포인트를 넣습니다. 하위 작업은 상위 이슈가 열린 뒤에 만듭니다.

이슈 화면에서 요약을 고치고, 설명은 Markdown입니다. 미리 보기로 결과를 봅니다. 의견에서는 `@이름` 으로 그 사람에게 알립니다. 작업 기록은 `90`, `1h 30m`, `1.5h`, `2d` 처럼 적습니다. 하루는 8시간이라 `2d` 는 960분입니다.

오른쪽에서 상태, 해결, 담당, 포인트, 추정, 기한, 라벨, 구성 요소, 수정 버전, 사용자 정의 필드를 바꿉니다. 관찰과 첨부도 거기 있습니다. 첨부는 700KB 이하입니다.

이슈 목록에서 칸을 눌러 정렬하고, 여러 개를 골라 상태나 담당을 한 번에 바꿉니다. Ctrl+K 는 키나 요약으로 이슈를 찾습니다. J 와 K 는 화면에 보이는 이슈를 옮기고, Enter 는 고른 이슈를 엽니다.

## 계획

스크럼 보드는 진행 중인 스프린트만 보여 줍니다. 카드를 다른 열로 끌어 상태를 바꿉니다. 진행 열에 한도가 있으면 넘었을 때 테두리가 붉어집니다.

백로그에서 스프린트로 끌어 넣고, 예정 스프린트를 시작한 뒤 보드에서 완료합니다. 끝내지 못한 이슈는 백로그나 다음 스프린트로 갑니다.

로드맵은 에픽마다 완료 비율을 보여 줍니다. 릴리스에서 버전을 출시하고, 구성 요소는 이슈를 묶습니다.

## 살펴보기

대시보드는 가젯을 더하거나 뺍니다. 보고서는 번다운, 속도, 누적 흐름, 생성과 해결, 원그래프, 시간, 스프린트입니다. 점수가 있는 이슈가 하나라도 있으면 점수 없는 이슈는 0점으로 셉니다. 하나도 없으면 이슈마다 1입니다.

필터는 이슈 화면의 WQL을 이름으로 남깁니다. 점검은 상위 없는 하위 작업, 해결 없는 완료, 스프린트의 미배정, 기한 초과, 막힌 이슈를 알려 줍니다.

서비스 프로젝트에는 대기열이 있습니다. 알림은 담당, 의견, 상태 변경을 관찰자에게 남깁니다.

지식 자료는 공간으로 나뉩니다. 공간 안에는 페이지 트리와 소식이 있습니다. 페이지는 하위 페이지를 가질 수 있고, 소식은 한 장으로 남습니다. 본문은 Markdown입니다. 라벨로 찾고, 의견으로 토론합니다. 저장할 때마다 이전 판이 남아 그 판으로 되돌릴 수 있습니다. 관찰을 켜면 그 페이지가 바뀔 때 알림이 옵니다. 만든 사람이 제한을 켜면 그 사람만 페이지를 봅니다.

## 문서

문서 화면의 양식으로 회의록, 결정, 명세, 요구사항, 시험 보고, 릴리스 노트, 회고, 진행 보고, 설계, 장애 보고, 절차, 인수인계, 주간 보고, 제안을 만듭니다. 결과물 양식은 만든 산출물을 등록하는 칸입니다.

문서는 만든 사람만 고칩니다. 공유하기 전에는 그 사람만 봅니다. 프로젝트로 공유하면 그 프로젝트를 연 사람이 읽고, 모두로 공유하면 작업 공간의 누구나 읽습니다. 이슈 키를 적으면 그 이슈와 함께 찾을 수 있습니다.

## 설정

프로젝트 이름, 설명, 책임자, 보드에서 아무 상태로나 옮기기, 보관을 바꿉니다. 보관 중에는 보기와 관리만 됩니다.

작업 흐름에서 상태와 전이를 더합니다. 쓰는 이슈가 있는 상태는 지울 수 없습니다. 필드와 자동화 규칙도 여기서 더합니다. 규칙은 이슈가 만들어지거나 특정 상태로 바뀔 때 담당, 우선순위, 라벨, 관찰을 바꿉니다.

글자 크기와 사용자 정의 색도 여기 있습니다. 도구 막대의 KO / EN 과 해 아이콘은 언어와 테마입니다.
