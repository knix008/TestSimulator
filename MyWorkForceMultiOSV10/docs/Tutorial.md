# MyWorkForce 튜토리얼

이 문서는 **온라인 쇼핑몰** 예제로 MyWorkForce의 주요 기능을 처음부터 끝까지 따라 해 보는 안내서입니다. 장마다 순서대로 따라 하면 30분 정도 걸립니다. 프로그램 안의 **튜토리얼 시작**은 같은 내용을 화면 구석의 안내로 보여 줍니다.

> 예제를 열면 지금 작업 공간이 예제로 바뀝니다. 실제 자료가 있는 데이터베이스에서는 연습용 데이터베이스나 웹 데모에서 해 보세요.

## 1. 들어가기

1. MyWorkForce를 실행하면 시작 화면이 열립니다.
2. 위쪽의 **로그인**을 눌러 계정과 암호를 넣습니다. 처음이면 관리자 계정 `admin`으로 들어가 새 암호를 정합니다.
3. 로그인 창은 **닫기**로 언제든 닫을 수 있습니다. 시작 화면의 설명서, 배경, 언어는 로그인 없이 씁니다.
4. 시작 화면 위쪽 도구 줄에서 **시작 화면 설정**을 눌러 보일 카드를 고르고, **자동 정렬**로 카드를 가지런히 놓아 봅니다.

## 2. 예제 열기

1. **예제** 카드에서 **소프트웨어 → 온라인 쇼핑몰**을 누릅니다.
2. 바꿀지 묻는 창에서 **계속**을 누르면 쇼핑몰 작업 공간이 열립니다.
3. 왼쪽 탐색의 **내 작업 → 참여 과제**에 `SHOP` 과제가 보입니다.

> 예제는 소프트웨어, 업무, 서비스가 10개씩 모두 30개입니다. 하는 일에 가까운 예제를 열어 둘러보세요.

## 3. 과제 둘러보기

1. 왼쪽의 **이 과제 → 보드**를 엽니다. 진행 중인 스프린트의 카드가 열마다 놓여 있습니다.
2. 카드 하나를 **할 일**에서 **진행 중**으로 끌어 놓아 상태를 바꿉니다.
3. 카드를 **두 번 눌러** 이슈를 엽니다. 오른쪽 패널에서 담당과 우선순위를 바꿔 봅니다.
4. **백로그**를 열어 스프린트에 들어갈 이슈를 끌어 넣습니다.

## 4. 이슈 만들고 고치기

1. 도구 막대의 **+**(Ctrl+N)를 누르고 요약에 `쿠폰 적용 오류`를 적어 만듭니다.
2. 이슈 화면의 **의견** 탭에 `@이름`으로 동료를 부르고 Ctrl+Enter로 남깁니다.
3. 오른쪽 패널에서 **시작**과 **기한**을 정합니다.
4. **연결** 탭에서 종류를 **막음**으로 고르고 다른 이슈 키를 적어 잇습니다. 막힌 이슈에는 **먼저 끝나야 할 이슈**가 붉게 나옵니다.

## 5. 스프린트 계획하기

1. **백로그**에서 **스프린트**를 눌러 새 스프린트를 만듭니다.
2. 이슈를 그 스프린트로 끌어 넣고 **시작**을 누릅니다.
3. 일이 끝나면 **스프린트 완료**로 닫습니다. 끝내지 못한 이슈는 백로그나 다음 스프린트로 보냅니다.
4. **보고서**에서 번다운과 속도를 확인합니다.

## 6. 타임라인과 의존 관계

1. 왼쪽의 **타임라인**을 엽니다. 이슈가 에픽 아래에 막대로 놓입니다.
2. 막대를 끌어 날짜를 옮기고, 끝을 끌어 기간을 늘립니다.
3. 막대 오른쪽의 점을 다른 막대로 끌어 놓아 "막음" 연결을 만듭니다. 화살표가 생깁니다.
4. 앞선 이슈가 늦게 끝나도록 늘려 보면 화살표가 붉어지고 위에 경고가 나옵니다.

## 7. 작업 공간과 페이지

1. 왼쪽 탐색의 **회사 → 작업 공간** 아래 **새 작업 공간**을 누르고, 나온 칸에 `쇼핑몰 문서`를 적은 뒤 Enter를 누릅니다. 오른쪽 패널의 **작업 공간 속성**에서 설명과 보는 사람을 정합니다.
2. 그 작업 공간 줄의 **+**를 누르면 **샘플** 창이 열립니다. **회의 → 회의록**을 두 번 누릅니다.
3. 페이지가 바로 편집 상태로 열립니다. 표의 날짜와 참석자를 채웁니다. 내용은 저절로 저장됩니다.
4. 서식 막대의 **이슈 넣기**에서 **질의 목록**을 고르고 `SHOP`과 `status != done`을 넣습니다. **미리 보기**를 누르면 끝나지 않은 이슈가 표로 나옵니다.
5. 페이지 줄의 **+**로 하위 페이지를 만들어 장과 절처럼 나눠 봅니다.

## 8. 함께 쓰고 댓글 달기

1. 본문에서 문장을 골라 나오는 **댓글** 단추로 그 부분에 댓글을 답니다. 그 부분이 노랗게 칠해집니다.
2. 댓글의 **답글**로 대화를 이어 가고, 끝나면 **해결**을 누릅니다.
3. 페이지 아래 **파일**에 파일을 끌어 놓아 붙입니다.
4. 다른 사람이 같은 페이지를 열면 "함께 쓰는 중"이 나오고, 서로 쓴 내용이 곧바로 보입니다.
5. 오른쪽 패널의 **이전 판**에서 **비교**를 눌러 무엇이 바뀌었는지 봅니다.

## 9. 찾고 알림 받기

1. 도구 막대의 **돋보기**(Ctrl+Shift+F)를 누르고 `결제`를 찾습니다. 과제, 이슈, 페이지, 댓글, 파일이 분류별로 나옵니다.
2. 결과를 눌러 그 자리로 갑니다.
3. 동료가 나를 `@이름`으로 부르면 도구 막대의 종에 숫자가 붙습니다. **알림**에서 눌러 그 페이지로 갑니다.
4. **대화**로 MyWorkForce Talk을 열어 알림 방과 대화를 확인합니다.

## 10. 다음 단계

- **팀**과 **과제**를 실제로 만들고 사람과 권한을 줍니다.
- 과제의 **설정**에서 관리 방법, 작업 흐름, 자동화 규칙을 맞춥니다.
- 더 자세한 내용은 **사용 설명서**를, 질의 문법은 **WQL 설명서**를 봅니다.
- 시작 화면의 **튜토리얼 시작**으로 화면 안내를 다시 볼 수 있습니다.
