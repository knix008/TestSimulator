# 구조

MyWorkForce는 Vite로 묶는 브라우저 화면과 Tauri 2 데스크톱 껍질입니다. 이슈의 규칙과 질의는 `src/domain` 에 있고, 화면은 그 결과를 그리기만 합니다. 테스트는 Node로 도메인을 직접 불러옵니다.

## 화면

| 경로 | 역할 |
| --- | --- |
| `src/main.js` | 설정, 언어, 테마를 적용한 뒤 앱을 시작합니다. |
| `src/app.js` | 작업 공간, 실행 취소, 저장, 메뉴 동작, 끌어서 놓기. |
| `src/ui` | 메뉴 막대, 도구 막대, 왼쪽 탐색, 각 화면, 오른쪽 속성. |
| `src/themes.js` | 라이트 20종, 다크 20종, 시스템, 사용자 정의 색. |
| `src/platform` | 데스크톱이면 Tauri 명령, 아니면 브라우저 저장소. |

개발 서버 포트는 1480입니다. 웹 빌드의 기준 경로는 `./` 라서 `dist` 를 어느 폴더에서나 열 수 있습니다.

데이터 서비스는 `server/` 이고 포트는 1481입니다. 회사 안에서 다른 컴퓨터가 접속할 수 있도록 `0.0.0.0` 에서 받습니다. 화면은 로그인한 세션으로 작업 공간을 읽고 씁니다. 기본 엔진은 SQLite(`node:sqlite`)이며 MySQL과 MariaDB는 `mysql2`, PostgreSQL은 `pg`, SQL Server는 `mssql` 입니다. 저장할 때 개정 번호가 다르면 거절해서, 두 사람이 같은 문서를 덮어쓰지 않습니다. MyWorkForce Talk은 같은 데이터 서비스의 대화 표를 씁니다. 알림 확인은 사람마다 `chat_checks`에 남고, 세션은 `data/sessions.json`에 남아 두 프로그램이 같은 로그인을 씁니다. 설치본은 부팅 때 작업 창과 Talk 창을 함께 엽니다. 두 번째 실행은 이미 켜진 프로세스로 모이고, 트레이 아이콘은 하나이며, 창을 하나 닫으면 프로세스 전체가 끝납니다. 설치본은 작업 프로그램과 Talk을 함께 두고, `--talk` 로 Talk만 엽니다. 메일은 설정에 적은 외부 SMTP 서버로 나갑니다. 587은 STARTTLS, 465는 SSL이고, 계정 암호는 화면으로 다시 내려가지 않습니다. 같은 표에 지식 자료, 근무 달력, 승인, 웹훅, 메일 대기열, API 토큰, 계정, 이슈 색인을 남깁니다. 작업 공간 문서가 기준이고, 저장할 때마다 그 표도 다시 씁니다.

## 작업 공간

파일 형식은 `{ format: 'myworkforce', version: 1, kind: 'workspace' | 'project' }` 입니다. 확장자는 `.mwf` 입니다.

웹은 IndexedDB `myworkforce` 와, 크기가 작으면 `localStorage` 키 `myworkforce-workspace` 에 넣습니다. 데스크톱은 그에 더해 앱 데이터 폴더의 `workspace.mwf` 를 씁니다. 둘 다 있으면 `savedAt` 이 더 최근인 쪽을 엽니다. 파일 메뉴의 저장은 사용자가 고른 경로입니다.

설정(언어, 테마, 글자 크기, 최근 파일)은 `localStorage` 키 `myworkforce-settings` 입니다.

## 도메인

프로젝트 종류는 소프트웨어, 업무, 서비스입니다. 소프트웨어는 스크럼 보드와 칸반 보드를 갖고, 나머지는 칸반 보드만 갖습니다. 이슈 유형은 에픽, 스토리, 작업, 결함, 하위 작업, 개선, 새 기능, 장애, 서비스 요청입니다.

상태 전이는 이름 있는 전이 목록을 따릅니다. 프로젝트에서 허용하면 보드에서는 어떤 상태로든 옮길 수 있습니다. 완료로 들어가면 해결이 비어 있을 때 기본 해결을 채우고, 완료를 벗어나면 해결을 비웁니다.

역할은 관리자, 개발자, 테스터, 고객, 뷰어입니다. 책임자는 항상 관리자입니다. 보관된 프로젝트는 보기와 관리만 됩니다.

스프린트 보드에는 진행 중인 스프린트의 이슈만 나오고 에픽과 하위 작업은 빠집니다. 칸반에는 에픽과 하위 작업을 뺀 이슈가 상태별로 나뉩니다. 백로그로 떨어지면 스프린트가 비고, 할 일은 백로그 상태가 됩니다. 백로그에서 스프린트로 들어가면 백로그 상태는 할 일이 됩니다.

순위는 그 열 안에서만 `(순서 + 1) * 10` 입니다. 열마다 따로 정렬합니다.

장애와 서비스 요청의 기한은 우선순위에 따라 4, 8, 24, 72, 120시간입니다. 열려 있고 기한을 넘기면 `breached`, 기한 안에 닫히면 `met`, 기한을 넘겨 닫히면 `missed` 입니다.

질의 언어는 WQL입니다. `src/domain/query.js` 가 구문 분석과 실행을 맡습니다.

## 데스크톱

`src-tauri` 는 창, 파일 대화상자, 텍스트 읽기·쓰기, 자동 저장 경로, 설치 직후 언어와 설정 초기화를 담당합니다. 창 위치는 구성 폴더의 `window-state.json` 에 남습니다. 화면이 준비되면 창을 보여주고, 12초가 지나도 보이지 않으면 셸이 직접 보여 줍니다.

식별자는 `com.shkwon.myworkforce` 입니다.
