## 1. 설치와 실행

| 환경 | 방법 |
| --- | --- |
| Windows | `MyCircuit-Setup-10.0.0.exe` 실행 → 언어(한국어/English) 선택 → (이미 설치되어 있으면) “설치된 MyCircuit을 찾았습니다… 완전히 제거합니다” — **확인**이면 이전 설치를 조용히 완전히 제거, **취소**면 설치 중단 → (`%APPDATA%\MyCircuit`가 있으면) 이전 설정·자동 저장 삭제 여부(예/아니요) → 설치 폴더 선택. 바탕 화면/시작 메뉴 바로 가기와 `.mycircuit` 파일 연결이 만들어집니다. |
| macOS | dmg를 열고 응용 프로그램 폴더로 끌어 놓기. 서명이 없으므로 처음 한 번은 Control-클릭 → 열기 |
| Linux | AppImage(`chmod +x` 후 실행), `.deb`(`sudo apt install ./…deb`), `.tar.gz` |
| 웹 | `npm run serve` 후 http://localhost:8642 (반드시 HTTP로. `file://`은 동작하지 않음) |
| 소스 | Node 22+, `npm install`, `npm start` |

- MyCircuit은 하나만 실행됩니다. 실행 중에 `.mycircuit` 파일을 더블클릭하면 열려 있는 창에서 열립니다.
- 설정 파일 `settings.json` 위치: Windows `%APPDATA%\MyCircuit`, macOS `~/Library/Application Support/MyCircuit`, Linux `~/.config/MyCircuit`, 웹은 브라우저 `localStorage`.
- 자동 저장(30초마다, 저장하지 않은 변경이 있을 때)은 별도의 복구본이며, 비정상 종료 후 다음 실행 때 복원 여부를 묻습니다.

## 2. 화면 구성

- **타이틀 바**: 메뉴(파일·편집·보기·배치·배선·검사·도구·시뮬레이션·도움말), 문서 제목(변경 시 ●), 오른쪽에 팔레트 버튼(**무작위 테마**)과 ▾(**테마 선택** 목록), 국기 버튼(한국어 화면에서는 영국 국기, 영어 화면에서는 태극기 — 누르면 언어 전환), 설정, 정보
- **문서 탭**: 시작 · 회로도(`F2`) · PCB(`F3`) · 3D 보기(`F4`) · 시뮬레이션(`F6`). 회로도 탭 배지 = ERC 오류/경고 수, PCB 탭 배지 = DRC 오류 / 미배선 수 / 완료 ✓
- **도구 모음**: 탭마다 다른 도구. 마우스를 올리면 이름과 단축키. 오른쪽에 손(이동)·그리드·눈금자(PCB는 기판 크기도), 맨 끝에 튜토리얼·단축키·정보. **버튼은 절대 숨겨지지 않습니다** — 창 최소 폭이 가장 넓은 도구 모음을 따르고, 화면이 좁으면 글자 버튼이 아이콘으로 줄어들며(툴팁은 그대로), 그래도 넘치면 두 줄로 나뉩니다
- **왼쪽 패널**: 부품 라이브러리(회로도) / 배선 진행·레이어·넷(PCB) / 표시 옵션(3D) / 프로브(시뮬레이션) — `Ctrl+1`
- **오른쪽 패널**: 선택 항목 속성 편집과 ERC/DRC 문제 목록(클릭하면 위치로 이동) — `Ctrl+2`. 숫자 항목(기판 규칙, 풋프린트 X/Y/회전, 트랙 폭, 비아 지름/드릴, 구리 영역 간격/우선순위, 텍스트 크기 등)은 모두 **스테퍼**: 왼쪽 −, 오른쪽 +, 값은 가운데(직접 입력 후 `Enter`도 가능), 누르고 있으면 반복
- **상태 표시줄**: 도움말, 좌표, 그리드(클릭해 변경), 확대율, 활성 레이어, 배선 진행, 단위(클릭해 mm/mil 전환), ERC/DRC
- **명령 팔레트** `Ctrl+K`: 모든 명령, 부품, 넷을 검색해 실행·이동

### 화면 이동과 확대

| 동작 | 방법 |
| --- | --- |
| 이동 | **빈 캔버스 왼쪽 드래그**(기본), 가운데 드래그, 오른쪽 드래그, `Space`+드래그 — 가운데·오른쪽·`Space` 드래그는 어떤 도구에서도 항상 이동 |
| 박스 선택 | `Shift`+드래그 또는 `Ctrl`+드래그. 설정 → 단위·그리드 → **빈 캔버스 왼쪽 드래그** = **박스 선택**으로 바꾸면 그냥 드래그도 박스 선택 |
| 손(이동) 도구 | 도구 모음 오른쪽 손 버튼 / **보기 → 화면 이동(손)**. 켜져 있으면 항목 위에서도 왼쪽 드래그가 이동. `Esc`나 버튼으로 끔 |
| 확대 | 휠(커서 기준), `Ctrl`+휠/핀치, `Ctrl+=`/`Ctrl+-`. 한 칸 배율은 설정 → **휠 확대 속도**(× 0.5 ~ × 3) |
| 맞추기 / 상황 메뉴 | `Home` / 움직이지 않은 오른쪽 클릭 |

### 그리드와 눈금자

- 기본 그리드는 **5 × 5 선 그리드**(가는 선 + 5칸마다 굵은 선). 확대·축소하면 표시 칸이 ×5 단위로 바뀌어 어떤 배율에서도 고르게 보입니다(스냅은 회로도/PCB 그리드 설정을 따름). **그리드 표시** 버튼·보기 메뉴로 켜고 끄며, 설정 → 단위·그리드 → **그리드 모양**에서 선(5 × 5)/점 선택
- **눈금자**: 캔버스 위·왼쪽에 편집 단위(mm 또는 mil)로 표시, 커서 위치를 주황색으로 표시, 눈금 간격은 1-2-5 단계. **눈금자 표시** 버튼·보기 메뉴·설정에서 켜고 끔

### 테마, 정보 창, 튜토리얼

- **테마**: 다크 20 + 라이트 20(기본 Midnight). 팔레트 버튼 = 무작위, ▾ = 목록(현재 테마 강조, **시스템 설정 따르기**, **새 사용자 테마…** — 이름·종류·강조/배경/패널/글자 4색을 실시간 미리 보기로 만들어 저장, × 삭제). 설정 → 화면 → **테마…**는 견본 갤러리
- **정보 창**(도움말 → MyCircuit 정보): 왼쪽에 프로그램 아이콘(회로 기판을 위에서 똑바로 내려다본 그림), 오른쪽에 설명(“전자 회로 설계와 3D 도구” + 기능 네 줄), 아래에 항목/값 표(프로그램, 빌드 커밋·브랜치, 빌드 날짜, 저작자 **SHKWON (knix008@naver.com)**, 판, 운영 체제, 런타임, 3D 엔진, 라이브러리, 파일 형식, 언어/테마, 라이선스). **정보 복사** 버튼
- **대화형 튜토리얼**(도움말 → 대화형 튜토리얼, 도구 모음 플라스크 버튼): 14개 레슨, 모두 62단계. **보기** 모드는 프로그램이 커서를 움직이며 직접 실행(재생/일시 정지, 이전/다음, 0.5×~4×), **따라 하기** 모드는 직접 하면 자동으로 확인하고 넘어감(**보여 주기**로 대신 실행). 화면 이동·그리드·눈금자, 치수, 3D 조작, “고급 배선: 길이 맞춤, 차동 쌍, 밀어내기” 단계 포함

## 3. 빠른 시작 (LED 회로)

1. `Ctrl+N` 새 프로젝트, **파일 → 프로젝트 속성**에서 제목 입력(영문 권장 — 제조 파일 이름에 쓰임)
2. `A`로 `battery`, `R`, `led` 배치, `P`로 `GND` 두 개 배치. 값 글자를 더블클릭해 9 / 470 / Red 입력
3. `W`로 배선 — 핀에 닿으면 자동 종료, `/` 꺾임 방향, `Backspace` 꺾임 취소, 정션 자동
4. **참조 번호 부여** → ERC 통과 확인
5. **풋프린트 지정**: R1 = `R_Axial_P7.62mm`, D1 = `LED_D5.0mm`
6. `F8` **회로도에서 PCB 업데이트** — 풋프린트가 기판 오른쪽에 나타나고 래츠네스트 표시
7. `O`로 외곽선 사각형 드래그, 풋프린트를 기판 안으로 배치(`R` 회전)
8. `X`로 손 배선(45°, 간격 위반 시 빨간 미리 보기, `V` 비아, `W`/`Shift+W` 폭) → `Ctrl+Shift+A` 모두 자동 배선
9. **기판을 접지 영역으로 채우기** → GND 구리 영역(써멀 릴리프)
10. **DRC** 실행 → 오류 0 확인
11. `F4` 3D 확인(`1`–`7` 시점, `C` 부품 표시)
12. **시뮬레이션 → 동작점** — 회로도 배선 위에 전압 표시
13. **파일 → 제조 출력** — 거버/드릴/BOM/픽앤플레이스 ZIP 저장, 거버 뷰어로 미리 보기

## 4. 회로도 편집기 요점

- 단위 mil, 그리드 기본 50 mil(10/25/50/100). 시트 A4/A3/A2/Letter/Tabloid, 표제란은 프로젝트 속성에서
- 선택: 클릭, `Shift`/`Ctrl`+클릭, `Shift`/`Ctrl`+드래그 박스 — **왼쪽→오른쪽 = 완전히 포함된 것만(윈도)**, **오른쪽→왼쪽 = 걸친 것도(크로싱)**. 그냥 빈 곳 드래그는 화면 이동
- 이동: 드래그(붙은 배선이 따라오는 고무줄, 놓으면 L자로 정리), `Alt`+드래그는 배선을 두고 이동, 방향키 한 칸, 참조/값 글자만 끌어 위치 조정
- `R` 90° 회전, `Y`/`X` 좌우/상하 대칭, `Ctrl+C/X/V/D` 복사/잘라내기/붙여넣기(커서 위치)/복제, `Del` 삭제, `E` 또는 더블클릭 속성
- 레이블: `L` 넷 레이블(같은 페이지), `Ctrl+L` 글로벌 레이블(모든 페이지), 숫자로 끝나면 다음 이름 자동 증가
- 전원 포트 `P`: 값 이름의 넷(모든 페이지 공통). 커넥터로만 전원이 들어오면 `PWR_FLAG`
- `B` 버스(그림만), `Q` 연결 없음 플래그, `J` 정션, `T` 텍스트
- 교차하는 배선은 정션이 있어야 연결, 배선 끝이 다른 배선 중간에 닿으면(T자) 연결
- **여러 페이지**: 캔버스 왼쪽 아래 페이지 탭 — 클릭 열기, `+` 추가, 더블클릭 이름 변경, 오른쪽 클릭 이동/삭제. 도형은 페이지를 넘어 연결되지 않으며 페이지 사이 연결은 글로벌 레이블·전원 포트로. 인쇄는 페이지마다 한 장, SVG/PNG는 현재 페이지
- 참조 번호 부여는 페이지 순서대로, 각 페이지에서 위→아래, 왼쪽→오른쪽
- 교차 탐색: 회로도에서 고른 부품은 PCB·3D에서도 선택됨
- **측정** `M`: 두 점 클릭 → “28.40 mm (1118 mil) Δx … Δy …” (저장 안 됨, `Esc` 지움). **치수선** `D`: 클릭, 클릭, 마우스로 간격(25 mil 단위) 정하고 클릭 → “12.70 mm (500 mil)” 치수선이 페이지에 저장(`schematic.dimensions`), 선택·이동·삭제·인쇄·SVG/PNG 출력
- **계층 시트** `S`(배치 → 계층 시트): 사각형을 드래그(최소 600 × 400 mil)하고 시트 이름 입력 → 같은 이름의 새 페이지와 블록이 생김. 블록을 **더블클릭**하면 그 페이지로 이동. 그 페이지에 **계층 레이블** `H`를 두면 블록의 **시트 핀이 자동으로 맞춰짐**(추가·이름 변경·삭제, 이름순, 왼쪽/오른쪽 번갈아 100 mil 간격). 부모 페이지에서 핀 끝에 배선. 블록을 선택하면 속성 패널에서 이름(페이지 이름도 함께 바뀜)·가로·세로(− / + 스테퍼)를 바꾸고 시트 핀 목록을 보며, **시트 페이지 열기** 버튼으로 이동
- **벡터 레이블** `D[0..7]` = `D0`…`D7`(최대 256개). 글로벌 레이블이나 시트 핀 이름으로 쓰면 각 신호가 하나씩 연결됨. 굵은 버스 선은 여전히 그림
- **멀티 유닛 부품**: `LM358_DUAL`(A, B 연산 증폭기 + C 전원 8/4), `74HC00`(A~D NAND + E 전원 14/7). 배치 도구를 클릭할 때마다 다음 유닛(U?A → U?B …)이 놓이고 함께 놓은 유닛은 같은 참조 번호(U1A, U1B). 속성 패널의 **유닛** 선택 상자로 바꿈. PCB에는 풋프린트 하나로 나가며 같은 번호 핀은 한 넷

## 5. ERC (전기 규칙 검사)

그리는 동안 자동 실행. 한국어 화면에서는 메시지도 한국어로 표시됩니다.

| 코드 | 심각도 | 의미 → 해결 |
| --- | --- | --- |
| `unknown-symbol` | 오류 | 라이브러리에 없는 심볼 → 다시 배치/심볼 생성 |
| `unannotated` | 오류 | 참조 번호 `?` → 참조 번호 부여 |
| `duplicate-ref` | 오류 | 참조 번호 중복 → 번호 수정/다시 부여 |
| `no-footprint` | 경고 | 풋프린트 없음(PCB에 안 나감) → 풋프린트 지정 |
| `output-conflict` | 오류 | 출력 핀끼리 연결 → 배선 수정 |
| `power-undriven` | 오류 | 전원 입력 핀을 구동하는 전원 출력 없음 → `PWR_FLAG` 추가 |
| `unconnected-pin` | 경고 | 미연결 핀 → 연결 또는 연결 없음 플래그 |
| `nc-connected` | 경고 | 플래그 붙은 핀이 연결됨 |
| `no-driver` | 경고 | 입력 핀만 있는 넷 |
| `dangling-wire` | 경고 | 배선 끝이 떠 있음 |
| `single-label` | 경고 | 한 번만 쓴 레이블 |
| `stray-nc` | 경고 | 핀이 아닌 곳의 연결 없음 플래그 |
| `sheet-target` | 오류 | 시트 블록이 가리키는 페이지가 없음 → 블록을 지우고 다시 그리기 |
| `hier-unconnected` | 경고 | 계층 레이블에 맞는 시트 핀이 없음 → 그 페이지의 시트 블록을 만들거나 넷/글로벌 레이블 사용 |

계층 레이블과 벡터 레이블(`D[0..7]`)은 `single-label` 검사에서 빠집니다. 계층 레이블은 대신 `hier-unconnected`로 시트 핀과 짝이 맞는지 검사합니다.

- **배선 모드**(배선 메뉴 또는 설정 → 배선 → 배선 모드), 간격 위반 구간을 만날 때:
  - **충돌 표시**(기본): 그대로 놓고 빨갛게 표시, DRC가 보고
  - **밀어내기**: 같은 레이어의 다른 넷 **트랙**을 옆으로 밀어냄(평행 이동, 이웃과 공유한 끝은 미끄러지고 패드/비아에 붙은 끝은 45° 꺾임, 밀린 트랙이 다시 밀어냄 2단계). 패드·비아·NPTH 구멍·기판 가장자리는 움직이지 않으며 막히면 구간을 놓지 않음
  - **장애물에서 멈춤**: 위반 구간을 놓지 않음
- **기판 크기 표시**: 외곽선의 폭·높이를 치수선으로 실시간 표시(“40.00 mm”). **기판 크기 표시** 버튼·보기 메뉴·설정에서 켜고 끔. 그리드·눈금자는 회로도와 같음
- **길이 맞춤…**(배선 메뉴): 트랙이 있는 넷 목록(긴 순, 페이지당 8개)에서 넷을 체크 → 목표(**선택한 넷 중 가장 긴 것에 맞춤** 또는 **고정 길이**), 미앤더 모양(둥글게/45° 모따기/사각), 방향(양쪽/왼쪽/오른쪽), 간격 0.1~3 mm, 허용 오차 ±0.01~1 mm → **맞춤**. 각 넷의 가장 긴 직선 구간에 구불구불한 선을 넣고, 다른 넷·기판 가장자리와 간격이 안 되면 줄이거나 생략. 한 번의 실행 취소 단계, 남은 최대 길이 차(skew)를 알림으로 보고
- **차동 쌍 배선…**(배선 메뉴): 이름으로 짝지은 넷(`USB_D+`/`USB_D-`, `CLK_P`/`CLK_N` …)을 현재 길이 차와 함께 표시. 레이어·트랙 폭·간격을 정하고 **배선** → 두 넷의 기존 트랙을 지우고 일정한 간격의 평행 트랙 두 개로 배선(각 넷에 그 레이어의 패드 2개 필요), 두 길이와 차이를 보고

## 12. 시뮬레이션

| `Ctrl+,` | 설정 | `H` / `S` | 계층 레이블/계층 시트 | `M` / `D` | 측정/치수 |
| `Esc` | 손 도구 해제·취소 | `Shift`+드래그 | 박스 선택 | 3D `P` `G` `A` | 이동 모드/그리드/축 |

## 설정 창

**도구 → 설정…**(`Ctrl+,`)은 **9개 탭**: 일반 · 화면 · 단위·그리드 · 회로도 · PCB · 배선 · 3D 보기 · 시뮬레이션 · 출력. 창 크기는 모든 탭에서 같고 스크롤되지 않습니다. **모든 숫자는 스테퍼**(왼쪽 −, 가운데 값, 오른쪽 +, 누르고 있으면 반복, 포커스가 있으면 방향키). 주요 기본값: 단위 mm, 3D 단위 cm, 그리드 선(5 × 5), 그리드·눈금자·기판 크기 켬, 빈 캔버스 왼쪽 드래그 = 화면 이동, 휠 확대 속도 × 1, 회로도 그리드 50 mil, PCB 그리드 0.635 mm, 배선 모드 충돌 표시, 자동 배선 바깥 레이어만·격자 0.25 mm, 시야각 35°, 자동 저장 30초, 최근 파일 10개, 테마 Midnight. **기본값으로 되돌리기** 버튼. 전체 표는 설명서 17장.

## 17. 문제 해결

- 빈 곳을 드래그하면 박스 선택 대신 화면이 움직임 → 기본 동작. `Shift`/`Ctrl`+드래그, 또는 설정에서 **박스 선택**으로
- 왼쪽 드래그로 부품이 안 움직이고 화면만 움직임 → 손(이동) 도구가 켜져 있음, `Esc`
- “계층 레이블 …에 맞는 시트 핀이 없음” → 그 페이지를 보여 주는 시트 블록을 `S`로 만들기
- 밀어내기 배선에서 구간이 놓이지 않음 → 패드·비아·기판 가장자리가 막고 있음, 다른 경로로
- 배선이 연결되지 않음 → 핀 끝에 달라붙는 위치를 클릭, 교차점에는 정션
- 페이지 사이 신호가 안 이어짐 → 글로벌 레이블 또는 전원 포트 사용
- `power-undriven` → `PWR_FLAG`
- F8 후 부품이 없음 → 풋프린트 미지정 또는 DNP
- PCB에서 바꾼 풋프린트가 되돌아감 → 회로도에서 변경
- 시뮬레이션 “No GND net” → GND 심볼 추가
- 웹 화면이 비어 있음 → HTTP 서버로 열기
- 소스 실행 시 바로 종료 → `npm start` 사용(`ELECTRON_RUN_AS_NODE`)
- 제조 파일 이름이 `board-…` → 영문 프로젝트 제목
