MyCircuit 10.0 튜토리얼

회로도, PCB, 자동 배선, 3D, 시뮬레이션, 제조 출력까지 — 프로그램의 기능을 순서대로 쓰는 방법입니다.

그림은 모두 실제 실행 화면입니다. 그림을 클릭하면 크게 볼 수 있습니다. 검사 코드 전체 표, 심볼·풋프린트 목록, 단축키 전체 표는 사용 설명서(앱에서 도움말 → 사용 설명서, F1)에 있습니다. 앱 안에서 커서가 대신 눌러 주는 연습은 도움말 → 대화형 튜토리얼입니다.

이 문서를 따라가는 방법1장부터 15장까지 한 프로젝트를 이어서 만들면 전체 흐름이 남습니다. 이미 아는 단계는 목차에서 건너뛰어도 됩니다. 단축키의 Ctrl은 macOS에서 ⌘와 같습니다.

1처음 실행

데스크톱은 설치 프로그램 또는 npm start로, 웹은 npm run serve 뒤 http://localhost:8642로 엽니다. index.html을 file://로 직접 열면 동작하지 않습니다.

1.1환영 창과 시작 페이지

처음 실행하면 운영체제 언어가 한국어일 때 한국어로 시작하고, 환영 창이 네 단계를 보여 줍니다.

  1. 예제 열기 — 만들어 둔 예제 프로젝트를 고릅니다.
  2. 새 프로젝트 시작 — 빈 회로도로 갑니다.
  3. 튜토리얼 보기 — 앱이 마우스를 대신 움직이며 14개 레슨을 실행합니다.
  4. 확인 — 환영 창을 닫고 시작 페이지에 남습니다. 다음부터는 뜨지 않습니다. 다시 보려면 도움말 → 빠른 둘러보기.

시작 페이지에는 새 프로젝트, 열기, 예제, 대화형 튜토리얼, 최근 파일(데스크톱)이 있습니다. 문서 탭의 시작을 누르면 언제든 돌아옵니다.

2화면을 움직이는 법

2.1메뉴, 팔레트, 패널

위쪽 문서 탭이 작업 공간입니다. F2 회로도, F3 PCB, F4 3D, F6 시뮬레이션. 회로도 탭의 숫자는 ERC 문제 수, PCB 탭의 숫자는 DRC·미배선 수이고, 배선을 마치면 초록 체크가 됩니다.

메뉴를 열지 않아도 됩니다. Ctrl+K 명령 팔레트에 명령 이름, 부품 이름, 넷 이름을 치면 그 자리로 가거나 명령을 실행합니다. Ctrl+F는 부품·넷 찾기입니다.

  • Ctrl+1 왼쪽 패널(회로도는 부품 라이브러리, PCB는 레이어·넷, 3D는 표시 옵션, 시뮬레이션은 프로브).
  • Ctrl+2 오른쪽 패널. 선택한 것의 속성과 ERC/DRC 목록. 숫자 칸은 왼쪽 −, 오른쪽 +로 바꿉니다.
  • 도구 모음 버튼은 숨기지 않습니다. 창이 좁으면 글자가 아이콘으로 줄고, 더 좁으면 두 줄이 됩니다. 마우스를 올리면 이름과 단축키가 나옵니다.

그리드 버튼과 보기 → 그리드 표시로 격자를 켜고 끕니다. 모양(선 / 점)은 설정 → 단위·그리드. 눈금자도 같은 식으로 켜고 끕니다. 스냅 간격은 화면 격자와 따로이며, 상태 표시줄의 그리드 칸을 눌러 바꿉니다(회로도 10/25/50/100 mil, PCB는 mm).

2.3테마, 언어, 정보, 단축키

  1. 제목 줄 오른쪽 팔레트 버튼은 테마를 무작위로 바꿉니다. 옆의 ▾는 다크 20종, 라이트 20종, 시스템 설정 따르기, 사용자 테마 목록입니다.
  2. 국기 버튼은 한국어와 영어를 바꿉니다. 메뉴 이름, 대화상자, ERC/DRC 문장이 함께 바뀝니다.
  3. 도움말 → 단축키(Ctrl+/)에서 지금 탭에서 쓰는 키를 봅니다.
  4. 도움말 → MyCircuit 정보에서 버전, 빌드, 저작자를 확인하고 정보 복사로 붙입니다.

3프로젝트 만들기

  1. 파일 → 새 프로젝트(Ctrl+N). 빈 A4 회로도가 열립니다.
  2. 파일 → 프로젝트 속성…에서 제목, 작성자, 회사, 리비전, 날짜, 설명을 넣습니다. 제목은 시트 표제란과 제조 파일 이름에 쓰입니다. 파일 이름에는 영문·숫자·_ . -만 남으므로 제목은 영문을 권합니다.
  3. Ctrl+S로 저장합니다. 데스크톱은 한 번 경로를 정하면 다음 저장은 묻지 않습니다. 웹은 브라우저의 저장 창이나 다운로드입니다.
  4. 제목 줄의 ● 는 저장하지 않은 변경입니다. Ctrl+Z / Ctrl+Y로 취소·다시 실행하고, 편집 → 실행 취소 기록…에서 이전 단계로 점프합니다.

30초마다(설정에서 변경) 복구본이 남습니다. 비정상 종료 뒤 다시 열면 복원할지 묻습니다. 복구본은 프로젝트 파일을 대신하지 않으니 Ctrl+S는 따로 하세요. 기존 .mycircuit는 파일 → 열기…(Ctrl+O) 또는 창에 끌어 놓기로 엽니다. KiCad 파일은 파일 → KiCad 프로젝트 가져오기…입니다.

4회로도에 부품 놓기

  1. 회로도 탭(F2)에서 A를 누릅니다. 검색 칸에 battery, R, led처럼 이름·값·키워드를 넣고 Enter.
  2. 심볼이 커서를 따라다닙니다. R은 90° 회전, Y는 좌우 대칭, X는 상하 대칭. 시트를 클릭해 놓습니다. 같은 부품이 계속 붙어 다니므로 여러 개를 연달아 놓을 수 있습니다. Shift+클릭은 하나만 놓고 끝냅니다. Esc로 끝냅니다.
  3. 왼쪽 라이브러리에서도 됩니다. 검색하거나 분류 칩(수동 소자, 다이오드, 트랜지스터…)을 누르고, 줄을 클릭한 뒤 시트를 클릭하거나 시트로 끌어 놓습니다. 줄 위에 마우스를 올리면 아래에 미리 보기가 나옵니다.
  4. 값 글자를 더블클릭해 9V, 470, Red처럼 바꿉니다. 공학 표기(4k7, 100n, 10u)를 쓸 수 있습니다.

핀 끝의 작은 원은 아직 연결되지 않은 핀입니다. LM358_DUAL, 74HC00 같은 다중 유닛은 놓을 때마다 다음 유닛(U?A, U?B…)이 같은 참조 번호를 공유합니다. 속성 패널의 유닛에서 바꿉니다. PCB에는 풋프린트 하나로 나갑니다.

5배선과 전원

  1. W를 누르고 핀 끝을 클릭합니다. 가까이 가면 사각형 표시로 달라붙습니다.
  2. 꺾을 곳에서 한 번 클릭하고, 다음 핀을 클릭합니다. 핀이나 배선 끝에 닿으면 배선이 알아서 끝납니다.
  3. /는 가로 먼저/세로 먼저를 바꿉니다. Backspace는 마지막 꺾임 취소. Enter, Esc, 더블클릭, 오른쪽 클릭은 그 자리에서 끝냅니다.
  4. P로 전원 포트를 놓습니다. GND, VCC, +5V, +3V3 같은 이름은 모든 페이지에서 같은 넷입니다. 커넥터로만 전원이 들어오면 PWR_FLAG를 그 넷에 달아야 ERC의 “전원을 구동하는 핀 없음”이 사라집니다.

세 선이 만나는 곳에는 정션 점이 자동으로 생깁니다. T자로 배선 끝이 다른 배선 한가운데 닿아도 연결됩니다. 그냥 교차만 한 선은 연결되지 않습니다. 정션을 직접 찍으려면 J.

이름을 붙여 선을 생략할 수 있습니다.

  • L 넷 레이블 — 같은 페이지에서 같은 글자면 연결. 이름이 숫자로 끝나면 다음 레이블은 숫자가 1 증가합니다.
  • Ctrl+L 글로벌 레이블 — 모든 페이지에서 연결.
  • H 계층 레이블 — 계층 시트 블록의 핀이 됩니다(6.3).
  • D[0..7]처럼 쓰면 D0…D7 여덟 개로 펼쳐집니다. 버스 선(B) 자체는 그림이고, 실제 연결은 이 레이블이 합니다.
  • 연결하지 않을 핀은 Q(연결 없음). 설명이 필요하면 T로 글자를 놓습니다.

6회로도를 고치기

6.1선택, 이동, 속성

  1. 클릭으로 하나 선택. Shift 또는 Ctrl+클릭으로 추가. Ctrl+A는 모두.
  2. 빈 곳을 Shift+드래그. 왼쪽에서 오른쪽으로 끌면 상자 안에 다 들어온 것만, 오른쪽에서 왼쪽으로 끌면 걸친 것도 선택됩니다.
  3. 선택한 부품을 드래그하면 붙은 배선이 고무줄처럼 따라오고, 놓으면 L자로 정리됩니다. Alt+드래그는 배선을 두고 부품만 옮깁니다. 방향키는 한 칸.
  4. Ctrl+C / X / V 복사·잘라내기·붙여넣기(커서 위치). Ctrl+D는 바로 복제. Del은 삭제.
  5. 더블클릭 또는 E는 속성 대화상자(참조, 값, 풋프린트, 필드). 오른쪽 패널에서도 같은 항목을 바로 고칩니다. 참조 글자나 값 글자만 따로 끌어 위치를 바꿀 수 있습니다.

6.2페이지, 버스, 치수

  1. 캔버스 왼쪽 아래 +로 페이지를 추가합니다. 탭을 더블클릭해 이름을 바꿉니다. 오른쪽 클릭으로 순서 이동·삭제.
  2. 페이지끼리는 선이 이어지지 않습니다. Ctrl+L 글로벌 레이블이나 전원 포트로 연결합니다.
  3. B로 버스 선을 그어 여러 신호를 한눈에 정리합니다. 각 신호는 D0 레이블 또는 D[0..7]로 실제 연결합니다.
  4. M은 두 점을 찍어 거리를 재고(저장되지 않음, Esc로 지움), D는 두 점과 간격을 찍어 치수선을 시트에 남깁니다. 치수선은 선택·이동·삭제·인쇄·SVG에 포함됩니다.

6.3계층 시트

  1. S(배치 → 계층 시트)로 시트를 드래그합니다. 최소 약 600 × 400 mil. 이름을 넣으면 그 이름의 페이지와 블록이 생깁니다.
  2. 블록을 더블클릭하면 그 페이지로 들어갑니다. 그 페이지에서 H로 계층 레이블을 놓으면, 부모 블록의 핀이 이름에 맞춰 자동으로 늘고 줄고 바뀝니다.
  3. 부모 페이지에서 그 핀에 배선을 잇습니다. 블록을 선택하면 오른쪽에서 이름(페이지 이름도 함께), 가로·세로, 핀 목록을 보고 시트 페이지 열기로 이동합니다.

7참조 번호와 ERC

ERC는 그리는 동안 오른쪽 목록, 탭 배지, 캔버스의 깃발로 바로 알려 줍니다. 참조가 R?처럼 물음표이면 오류입니다.

  1. 도구 → 회로도 참조 번호 부여. 페이지 순서, 그 안에서는 위→아래, 왼쪽→오른쪽로 R1, R2…가 붙습니다. 이미 있는 번호는 유지합니다.
  2. 전부 다시 매기려면 도구 → 모든 부품 참조 번호 다시 부여.
  3. 상태 표시줄의 ERC 또는 검사 → 전기 규칙 검사로 결과를 확정합니다. 목록의 한 줄을 클릭하면 그 위치로 이동합니다.
  4. 검사 → 넷 목록…에서 넷과 핀을 확인하고 KiCad 넷리스트로 저장할 수 있습니다. 부품이나 배선을 클릭하면 그 넷이 강조됩니다.

8내 부품 만들기

심볼

  1. 도구 → 심볼 편집기…를 엽니다.
  2. 이름, 참조 접두사(U, R, J…), 값, 기본 풋프린트를 넣습니다.
  3. 핀 표에 번호, 이름, 종류(입력/출력/전원…), 변(왼쪽/오른쪽/위/아래)을 넣습니다. 텍스트로 5, SDA, bidir, right처럼 붙여 넣을 수도 있습니다.
  4. 오른쪽 미리 보기를 보고 프로젝트에 저장. 만든 심볼은 이 .mycircuit 파일 안에 들어 있어 파일만 복사하면 따라갑니다.

풋프린트

  1. 도구 → 풋프린트 마법사….
  2. 헤더, DIP, SOIC, QFP, 2패드 칩 중 고르거나 사용자 패드에서 패드를 직접 넣습니다. 핀 수, 간격, 패드 크기, 드릴을 바꾸면 미리 보기가 바로 바뀝니다.
  3. 프로젝트에 저장한 뒤, 심볼 속성이나 도구 → 풋프린트 지정…에서 그 이름을 고릅니다.

빈 항목에 첫 번째 추천 사용은 풋프린트가 비어 있는 부품에 추천을 한꺼번에 넣습니다. 스루홀로 납땜하려면 저항은 R_Axial_…, LED는 LED_D5.0mm처럼 고릅니다. 내장 목록 전체는 설명서 6장.

9PCB로 보내 배치하기

  1. 풋프린트가 있는 상태에서 F8(회로도에서 PCB 업데이트). PCB 탭으로 바뀌고 풋프린트가 기판 오른쪽 밖에 줄지어 나타납니다. 같은 넷은 가는 래츠네스트로 이어집니다.
  2. O로 기판 외곽선을 드래그합니다. 끄는 동안 가로×세로가 보이고, 놓으면 외곽선이 그 사각형이 됩니다. 모서리 둥글기와 복잡한 외곽선은 도구 → 기판 설정…의 외곽선 탭.
  3. 배선 → 기판 안에 풋프린트 정렬로 일단 기판 안에 올려 두고, 하나씩 끌어 래츠네스트가 짧아지게 옮깁니다.
  4. R 회전, F 앞뒤 뒤집기, L 잠금(잠긴 부품은 정렬·자동 이동에서 빠짐). 방향키는 한 칸.

회로도를 고친 뒤에는 다시 F8입니다. 추가된 부품만 밖에 나타나고, 이미 배치·배선한 것은 유지됩니다. 회로도에서 지운 부품은 기판에서도 빠집니다.

10손으로 배선하기

  1. X를 누르고 패드를 클릭합니다. 상태 표시줄에 넷 이름과 트랙 폭이 나옵니다.
  2. 미리 보기는 직선과 45°입니다. 둘레의 옅은 띠는 간격입니다. 다른 넷에 너무 가까우면 미리 보기가 빨갛게 됩니다.
  3. 같은 넷의 패드·트랙을 클릭하면 배선이 끝납니다. /로 꺾임 방향, V로 비아를 놓고 반대 면으로 넘어갑니다. Page Up / Page Down도 구리 층을 바꿉니다.
  4. W / Shift+W는 지금 그리는 트랙의 폭을 한 단계 키우거나 줄입니다. 넷 클래스 폭으로 되돌리려면 트랙을 고르고 속성의 넷 클래스 폭 사용.
  5. 배선 모드는 배선 메뉴에서 고릅니다. 충돌 표시는 빨강으로만 알리고, 밀어내기는 기존 트랙을 밀며, 장애물에서 멈춤은 간격이 막히면 더 진행하지 않습니다.

다른 PCB 도구:

  • V 비아를 빈 곳에 찍어 스티칭. 넷은 닿아 있는 구리를 따릅니다.
  • T 실크 글자, 선 도구로 실크·외곽 그래픽. 글자와 선은 선택한 층에 놓입니다.
  • M 두 점 거리(저장 안 됨), D 치수선(기판에 저장). 보드 크기 버튼은 외곽선의 가로·세로를 항상 보여 줍니다.
  • 검사 → 넷 길이 보고서…에서 넷별 길이를 비교합니다.
  • 패드나 트랙을 클릭하면 그 넷이 강조되고 래츠네스트도 그 넷만 남길 수 있습니다. 왼쪽 넷 목록의 한 줄을 눌러도 같습니다.

11자동 배선, 구리 영역, DRC

자동 배선

  1. 부품이 외곽선 안에 있고 서로 겹치지 않게 놓였는지 확인합니다. 잠긴 부품은 움직이지 않습니다.
  2. 모두 자동 배선(Ctrl+Shift+A). 바깥 두 구리 층, 또는 설정에 따라 모든 구리 층을 씁니다. 막힌 연결은 일부를 걷어 내고 다시 시도합니다.
  3. 한 넷만 맡기려면 그 넷을 강조한 뒤 배선 → 강조한 넷 자동 배선.
  4. 결과가 마음에 들지 않으면 배선 → 트랙과 비아 모두 제거 후 배치를 고치고 다시 실행합니다. 배선 → 트랙 정리는 겹친 구간과 불필요한 점을 걷어 냅니다.

접지 구리

  1. 기판을 접지 영역으로 채우기. 넷은 GND(또는 VSS 등)가 자동으로 고르고, 앞·뒷면이 켜져 있습니다. 만들기.
  2. 영역은 외곽선에서 간격만큼 들어갑니다. 다른 넷 주변은 비우고, 같은 넷 패드는 써멀(네 갈래)로 붙습니다. 간격을 0으로 하면 패드에 완전히 붙습니다.
  3. 모양을 직접 그리려면 영역 도구로 다각형을 만들고 대화상자에서 넷, 층, 간격, 우선순위를 정합니다. 우선순위가 높은 영역이 겹친 곳을 가져갑니다.

DRC와 기판 설정

  1. 방패 아이콘 또는 검사 → 설계 규칙 검사. 통과하면 “문제가 없습니다”. 항목을 클릭하면 그 위치로 갑니다. 한 번 실행한 뒤에는 편집할 때마다 다시 검사합니다.
  2. 도구 → 기판 설정…에서 층 수(2/4/6), 두께, 마스크 색, 표면 처리(ENIG/HASL/OSP), 외곽선, 간격·트랙·비아·드릴 규칙, 넷 클래스를 정합니다.
  3. 넷 클래스 “Power”에는 GND, VCC, +5V, +3V3 등이 들어 있고 트랙이 더 굵습니다. 넷을 클래스에 넣으면 다음 배선의 폭·간격·비아가 그 값을 따릅니다. 이미 그린 트랙 폭은 자동으로 바뀌지 않습니다.

DRC가 보는 항목(간격, 단락, 기판 가장자리, 구멍 간격, 애뉼러 링, 실크가 패드 위, 코트야드 겹침, 미배선 등)의 전체 표는 설명서 9장입니다.

12길이 맞춤, 차동 쌍, 여러 층

  1. 길이를 맞춰야 하는 넷(주소·데이터처럼 같이 도착해야 하는 선)을 먼저 대략 배선합니다.
  2. 배선 → 길이 맞춤…에서 목표 길이와 허용 오차, 구불구불한 진폭·간격을 넣고 적용합니다. 트랙에 미앤더가 들어갑니다.
  3. USB D+ / D− 처럼 짝인 넷은 배선 → 차동 쌍 배선…에서 두 넷, 간격, 폭을 정하고 쌍으로 긋습니다.
  4. 4층·6층은 기판 설정의 층 수에서 바꿉니다. 안쪽 층은 전원·접지 평면으로 쓰기 좋습니다. 층 목록에서 눈에 보이는 층과 활성 층을 고릅니다.

133D로 보기

  1. F4. 처음에는 3D 엔진을 불러오느라 잠시 걸립니다. PCB를 고치면 열려 있는 3D는 잠시 뒤 다시 그려집니다.
  2. 왼쪽 드래그는 회전, 오른쪽 드래그는 이동, 휠은 확대. P는 왼쪽 드래그를 이동으로 바꿉니다. 방향키는 7.5° 회전, Shift+방향키는 조금 이동. 더블클릭은 그 점으로 다가갑니다.
  3. 1~7은 등각, 위, 아래, 앞, 뒤, 왼쪽, 오른쪽. Home은 화면에 맞춤.
  4. G 그리드, A 좌표축, C 부품 표시. 왼쪽 패널이나 도구 모음에서 실크, 마스크, 구리, 영역, X-ray, 방향 표시, 보드 치수도 켜고 끕니다.
  5. 도구 모음의 cm/inch는 그리드·축·치수의 단위입니다. 마스크 색, 실크 색, 표면 처리, 두께는 왼쪽 아래 기판 외관에서 바꾸면 기판 설정에 저장됩니다.
  6. 부품을 클릭하면 회로도와 PCB에서도 같은 부품이 선택됩니다. 카메라 버튼은 PNG로 저장. 파일 → 3D 모델 내보내기…는 STL 또는 GLB입니다.

부품 모양은 풋프린트 종류(칩, 축저항, DIP, SOIC, LED, USB 등)로 만든 간단한 모델입니다. 축저항에는 값에 맞는 색띠가 칠해집니다. WebGL이 없으면 3D 탭만 안내를 보여주고 나머지 기능은 그대로입니다.

14시뮬레이션

회로도를 그대로 풉니다. 전원을 놓고, 프로브할 넷에 이름을 붙인 뒤 F6 또는 F5입니다.

  1. 시뮬레이션 → 동작점 (DC). 넷 전압과 부품 전류·전력 표가 나옵니다. F2로 돌아오면 배선 위에 전압이 겹쳐 보입니다. 끄려면 시뮬레이션 → 회로도 전압 표시 지우기 또는 보기 메뉴의 전압 표시.
  2. 과도 해석: 끝 시간과 간격(기본 10 ms, 10 µs). 그래프 위를 움직이면 그 시각의 값이 나옵니다. 범례를 클릭하면 신호를 숨깁니다. 왼쪽에서 프로브 넷을 고릅니다.
  3. AC (보드 선도): 시작·끝 주파수와 디케이드당 점 수. 표시는 dB, 크기(V), 위상. 입력은 교류 전원 하나(없으면 첫 전압원)에 1 V를 넣은 전달 함수입니다.
  4. DC 스윕: 소스(배터리, VSOURCE, ISOURCE)와 시작·끝·간격을 정하면 그 값을 바꾸며 동작점을 그립니다.
  5. 전압원 속성 필드에서 파형을 DC / sine / pulse 로 바꿉니다. 펄스는 진폭, 오프셋, 주기, 듀티. 예: 5 V, 주기 4m, 듀티 50.
  6. 시뮬레이션 → SPICE 넷리스트…에서 텍스트를 복사하거나 저장합니다. 파일 → SPICE 넷리스트 내보내기도 같습니다.

전원이 공급하는 전류는 음수로 나옵니다. SPICE에서 전원 전류의 양수 방향은 플러스 핀으로 들어가는 쪽이기 때문입니다. 접지(GND 등)가 하나도 없으면 풀 수 없습니다. NE555처럼 모델이 없는 부품은 회로도에 둘 수 있지만 시뮬레이션에는 빠집니다. 값에 쓰는 접두사는 f p n u m k Meg 입니다(M만 쓰면 메가가 아니라 밀리로 읽히지 않도록, 메가는 Meg).

15제조 파일, 그림, 인쇄

부품표와 좌표

  1. 도구 → 부품표… 또는 파일 → BOM 내보내기. 같은 값·풋프린트가 수량으로 묶입니다. 한 줄을 클릭하면 회로도·PCB·3D에서 그 부품이 선택됩니다. CSV로 저장합니다.
  2. 파일 → 픽앤플레이스 내보내기는 부품 중심 좌표, 회전, 면을 CSV로 저장합니다. 실장기가 이 파일을 씁니다.

거버와 드릴

  1. DRC를 한 번 보고, 파일 → 제조 출력 (거버, 드릴)…을 엽니다. 열 때 DRC가 다시 실행되어 위에 표시됩니다.
  2. 목록에 층별 거버(X2), 도금 구멍·비도금 구멍 드릴, BOM, 픽앤플레이스, IPC-356 넷리스트, 작업 파일, 설명이 있습니다.
  3. 거버 뷰어에서 미리 보기로 층을 겹쳐 확인합니다. 색과 투명도를 바꿔 가며 봅니다.
  4. ZIP 저장…으로 한 파일을 만들어 제조사에 올립니다.

이미 받은 거버 ZIP도 도구 → 거버 뷰어…에서 엽니다.

인쇄와 그림

  1. Ctrl+P. 회로도 페이지, PCB 층, 또는 둘 다. 용지, 방향, 흑백, 1:1 배율을 고르고 미리 보기로 넘깁니다. 데스크톱은 PDF로 저장할 수 있습니다.
  2. 파일 메뉴에서 회로도 SVG, 회로도 PNG(현재 페이지), PCB SVG를 보냅니다. PNG·SVG는 화면에 보이는 층과 배율을 따릅니다.

마지막에 Ctrl+S. 하나의 .mycircuit 파일에 회로도, PCB, 프로젝트 전용 라이브러리, 시뮬레이션 설정이 모두 들어 있습니다.

16계산기, 설정, 예제

계산기

도구 → 계산기…는 입력하는 즉시 결과가 바뀝니다. 4k7, 20m 같은 표기를 받습니다.

탭쓰는 때
색 코드저항값 ↔ 4색띠/5색띠, 가까운 E24·E96
LED / 옴전원·순방향 전압·전류로 직렬 저항과 저항 전력
분압기R1·R2로 Vout, 또는 목표 전압에 맞는 R2

설정

도구 → 설정…(Ctrl+,)은 적용 버튼 없이 바로 반영됩니다. 숫자 칸은 모두 − / + 입니다.

  • 일반 — 언어, 시작 시 시작 페이지 또는 마지막 파일, 최근 파일 수, 환영 창, 자동 저장 간격.
  • 화면 — 테마, UI 배율, 대화상자·메뉴·튜토리얼 애니메이션, 힌트 표시 시간.
  • 단위·그리드 — mm/mil, 회로도 그리드, PCB 그리드, 그리드 모양, 눈금자, 보드 크기, 빈 곳 드래그를 이동으로 할지 상자 선택으로 할지, 휠 속도, 3D 단위.
  • 배선 — 충돌 표시/밀어내기/멈춤, 자동 배선 층과 격자, 실시간 DRC, 래츠네스트, 코트야드, 패드 번호.
  • 3D — 그림자, 배경, 시야각, 회전 속도, 시작할 때 켤 그리드·축·치수.

예제로 더 보기

파일 → 예제 열기… 또는 시작 페이지의 카드. 예제는 ERC·배선·DRC가 깨끗한 상태로 들어 있습니다. 열면 원본 경로는 비우므로, 고친 뒤 저장하면 새 파일로 남습니다.

막힐 때명령이 안 보이면 Ctrl+K. 버튼이 회색이면 그 탭이 아닙니다(회로도 도구는 F2, 배선 도구는 F3). 저장 대화상자가 매번 뜨면 웹 버전입니다. 창이 바로 꺼지면 터미널의 ELECTRON_RUN_AS_NODE 때문입니다. npm start로 실행하세요.
