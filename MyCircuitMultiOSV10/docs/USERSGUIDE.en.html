            MyCircuit 10.0 User Manual

            Schematic capture · PCB layout · autorouting · 3D view · circuit simulation · Gerber/drill/BOM manufacturing outputs — in one window.

            The same program runs as a desktop app on Windows, macOS and Linux and as a web page in the browser. Open this manual inside the program with Help → User manual (F1), or open the file directly in a browser (the web version's manual window also has an Open in browser button; the desktop app keeps the manual inside its archive and shows no such button).

            How to read this manualIf you are new, follow chapter 3, the quick-start tutorial: it builds an LED circuit from schematic to Gerber files in about 15 minutes. To look something up, type a word into the search box above the table of contents (“via”, “ERC”, “Gerber”). Shortcuts are in chapter 16; every ERC and DRC message is explained in chapter 5 and chapter 9.

            1Introduction and installation

            1.1What MyCircuit is

            MyCircuit is an electronics design (EDA) program with a KiCad-like workflow. One project file (.mycircuit) holds the schematic, the board, a project-local part library and the simulation settings, so a single file is all you need to share a design.

            AreaWhat you can do
            Schematic editorPlace parts, orthogonal wiring (automatic junctions and wire ends), net/global/hierarchical labels, power ports, buses and vector labels (D[0..7]), no-connect flags, text, rubber-band dragging, rotate/mirror, copy/paste, annotation, live ERC, multi-page schematics and hierarchical sheets, multi-unit parts, measure and dimensions
            PCB editor2/4/6-layer boards, footprint placement/rotate/flip/lock, 45° interactive routing with a live clearance check and three routing modes (highlight / push and shove / stop at obstacles), vias and layer changes, net classes, copper zones (thermal reliefs, priority), board outline, silkscreen text and lines, measure/dimension, automatic board-size overlay, ratsnest, length tuning (meanders), differential pairs
            AutorouterA* maze router (outer layers or all copper layers) with rip-up-and-retry
            NavigationDrag empty canvas to pan, Shift+drag box selection, hand (pan) tool, 5×5 line grid, top/left rulers in mm or mil
            Checks12 ERC checks, 18 DRC checks (clearance, shorts, board edge, hole spacing, annular ring, courtyards, unrouted …)
            3D viewReal-time three.js board with component models, seven views, 5×5 grid, X/Y/Z axes with tick values, orientation gizmo and board dimensions in cm or inch, X-ray, PNG screenshot, STL/GLB export
            SimulationSPICE-style MNA + Newton-Raphson engine: operating point, transient, AC (Bode), DC sweep, voltages on the schematic, SPICE netlist export
            OutputsPrinting (preview, 1:1, black & white, PDF), schematic SVG/PNG, PCB SVG, KiCad netlist, SPICE, BOM, pick & place, Gerber X2 + Excellon + IPC-356 + job file ZIP, built-in Gerber viewer
            ToolsSymbol editor, footprint wizard, footprint assignment, calculators (colour code, LED/Ohm, divider, track width, 555/RC, units), KiCad project import
            Comfort40 themes (20 dark + 20 light) plus custom themes, Korean/English, a 9-tab settings window, a 14-lesson interactive tutorial (watch and practice)

            1.2Requirements

            • Desktop: Windows 10/11 64-bit, macOS (Intel/Apple Silicon), a current 64-bit Linux. The window opens at 1440 × 900 and cannot be made smaller than 1024 × 700.
            • Web: a current Chrome, Edge, Firefox or Safari with ES modules and WebGL, served over HTTP (1.6).
            • From source: Node.js 22+, npm install.
            • The 3D view needs WebGL; without it the 3D tab shows “3D view is not available” and everything else works.

            1.3Installing on Windows

            Run MyCircuit-Setup-10.0.0.exe (NSIS, x64):

            1. Language — pick 한국어 or English for the installer. The questions below use that language.
            2. Previous installation — if MyCircuit is already installed: “An installed MyCircuit was found. It will be removed completely before this version is installed.” OK runs the old uninstaller silently and removes it completely, so even reinstalling the same version replaces every file; Cancel quits the installer. Whether to delete user data is asked separately in the next step.
            3. Delete saved data? — if %APPDATA%\MyCircuit exists: “Saved data from the installed program was found (settings, autosave). Do you want to delete it?” Yes deletes settings.json and the window's Local Storage (including the autosave copy). Your .mycircuit files are never stored there and are not touched.
            4. Install location — not a one-click installer: you may change the folder. Default is a per-user install; elevation is offered when needed.
            5. Shortcuts and file association — desktop and Start-menu shortcuts named “MyCircuit”, and .mycircuit files open in MyCircuit with their own document icon.

            Only one MyCircuit runs per user-data folder. Double-clicking another .mycircuit while it runs brings the existing window forward and opens the file there (asking to save unsaved changes first).

            Uninstall from Settings → Apps. Settings in %APPDATA%\MyCircuit are kept (the next installer asks whether to delete them).

            1.4Installing on macOS

            Open MyCircuit-10.0.0-<arch>.dmg (or the .zip) and drag MyCircuit into Applications.

            The macOS build is not code-signed. If Gatekeeper reports an “unidentified developer”, Control-click → Open the app once in Finder.

            On macOS the traffic-light buttons stay at the top left, and every Ctrl shortcut also works with ⌘ Cmd.

            1.9First start

            On first start MyCircuit uses Korean when the OS language is Korean, otherwise English, and shows Welcome to MyCircuit 10.0 with the four steps of the workflow and three buttons: Open a sample, Start a new project, Got it. It does not appear again (unless Settings → General → Show the welcome window at start-up is on); reopen it with Help → Quick tour. The default theme is Midnight (dark). Set Settings → General → On start-up to Reopen the last project to open the last file automatically (desktop). Newcomers should also try Help → Interactive tutorial (2.16).

            2.6Right panel

            Properties edits the selection directly: change a value and press Enter or click elsewhere; each change is one undo step. With nothing selected it shows the project (schematic: title, counts, sheet size; PCB: board size, layers, default track width, clearance, via size/drill, mask colour, finish). Each click changes the value by the field's step and is one undo step; hold a button to repeat. The value stays typeable: click it, type a number and press Enter (or click elsewhere).

            Below is the ERC issues (schematic) or DRC issues (PCB) list with error/warning counts. Clicking an issue switches to its schematic page if needed, centres and zooms to it, selects the items involved and marks the spot with an expanding ring. The refresh button reruns the check.             2.12Files, undo and autosave

            • New project: an “Untitled” project with an empty A4 schematic (one page “Main”), a 60 × 40 mm two-layer board and default rules; opens the Schematic tab.
            • Open: opens a .mycircuit file and shows the Schematic tab (or PCB if the schematic is empty). Dropping a .mycircuit/.json file on the window, double-clicking it in the file manager, or passing it on the command line also work.
            • Save overwrites the known path without a dialog; the first save suggests the project title as file name. Save as is Ctrl+Shift+S. Opened samples have no path, so the first save asks for a new name.
            • A ● next to the title means unsaved changes; New/Open/Open sample/closing ask Cancel / Don't save / Save.
            • Undo: every edit is an undo step (up to 200). One drag, one wire, one dialog OK = one step. A short toast says what was undone. Edit → Undo history… lists the steps; click one to go back to before it. Opening a file clears the history.
            • Autosave (on by default): every 30 s while there are unsaved changes, a separate recovery copy of the whole project is stored (your file is not overwritten). Saving or New clears it; after a crash the next start offers to restore it.

            There is only one recovery copy. Choosing Discard in the recovery prompt deletes it for good.

            2.13Grid and rulers

            The default grid is a 5 × 5 line grid: thin lines per cell and a bold major line every 5 cells. When you zoom, the displayed cell re-spaces by ×5 so a cell is always 10–50 px on screen, and the 5×5 pattern keeps an even spacing at every zoom (snapping still uses the schematic/PCB grid setting). Toggle it with the Show grid toolbar button or View → Show grid; choose Lines (5 × 5) or Dots under Settings → Units & grid → Grid style.

            Rulers run along the top and left canvas edges in the editor unit (mm or mil, shown in the corner), with an orange marker for the cursor; the label step follows 1-2-5 as you zoom. Toggle with Show rulers (toolbar, View menu, or Settings → Show rulers on the canvas edges).

            2.14Themes

            20 dark themes (Midnight, Graphite, Nord, Dracula, Monokai, Solarized Dark, Gruvbox Dark, One Dark, Tokyo Night, Catppuccin Mocha, Oceanic, Forest, Crimson, Amethyst, Cyberpunk, Slate, Espresso, Deep Sea, Aurora, High Contrast Dark) and 20 light themes (Daylight, Paper, Solarized Light, Gruvbox Light, Nord Light, GitHub Light …). A theme names only a few key colours; all other UI colours and the schematic/PCB canvas palettes are derived from them, so every theme stays readable.

            • Click a name to apply it; the current theme is highlighted.
            • Follow the system (under Automatic) switches between the last dark and light themes you picked, following the OS setting.
            • New custom theme…: name, type (dark/light) and four colours — accent, background, panels, text — previewed live on the whole program; Save theme adds it under Custom themes (× deletes it). Custom themes are stored in the settings file.
            • Settings → Appearance → Themes… opens a gallery with swatches of all themes.

            3Quick-start tutorial — an LED circuit from scratch

            We build the simplest circuit — a 9 V battery, a 470 Ω resistor and a red LED — from schematic to Gerber files. Every picture is a real screenshot.

            3.1Create a project

            1. File → New project (Ctrl+N). The Schematic tab opens with an empty A4 sheet.
            2. File → Project properties…: set the title to LED Tutorial. The title appears in the title block, export file names and manufacturing files.

            Manufacturing file names keep only letters, digits and _ . -; a title without Latin letters becomes board.

            3.2Place the parts

            1. Press A, type battery, press Enter: a ghost follows the mouse. Click to place it.
            2. Place R and led the same way. While placing, R rotates by 90° and Y/X mirror. The tool stays active so you can place several; Esc or right-click stops. Shift+click places one and returns to Select.
            3. Press P, choose GND, place one under the battery and one under the LED.
            4. Double-click a value to edit it: battery 9, resistor 470, LED Red.

            You can also drag a part from the library onto the sheet, or click it in the list and then click the sheet. Small circles on pin tips mark unconnected pins.

            3.3Wire it

            1. Press W and click the battery's + pin tip. The cursor snaps to pins and wire ends (small square marker).
            2. Click once above it for a corner, then click the resistor's top pin. Reaching a pin ends the wire automatically. The dashed line previews the next segment; / toggles horizontal-first / vertical-first.
            3. Wire resistor → LED anode, LED cathode → GND and battery − → GND the same way.

            While wiring, Backspace removes the last corner; Enter, Esc, double-click or right-click end the wire. Junction dots appear automatically where three or more connections meet.

            3.4Annotate and run ERC

            ERC runs while you draw. Right now it reports “BT? is not annotated” etc., the Schematic tab shows a red badge and small red flags mark the problems.

            1. Click Annotate schematic on the toolbar: the parts become BT1, R1, D1 (top to bottom, left to right).
            2. Click the ERC button or the ERC cell in the status bar: “ERC passed — no problems found.”

            3.5Assign footprints

            Library symbols come with a default footprint (R_0805, LED_0805). For hand soldering we switch to through-hole parts.

            1. Click Assign footprints on the toolbar (Tools → Assign footprints…).
            2. Click R1 on the left and R_Axial_P7.62mm on the right; set D1 to LED_D5.0mm. ★ marks the symbol's suggestions; hovering previews the pads.
            3. Apply. (Use first suggestion for empty ones fills all empty parts at once.)

            3.6Update the PCB

            Press F8 (Update PCB from schematic). The PCB tab opens and the footprints appear in a column to the right of the board outline, joined by thin airwires (the ratsnest) that show what must be connected. A toast says “PCB updated — 3 added”.

            3.7Board outline and placement

            1. Press O and drag a rectangle: its size is shown while dragging and the outline is replaced when you release.
            2. Esc, then drag each footprint onto the board; its origin snaps to the grid (0.635 mm by default).
            3. Select the LED and press R to rotate it. Short, uncrossed airwires make routing easy.

            3.8Route — by hand and automatically

            1. Press X and click pad 1 of BT1. The hint reads “Routing net Net-(BT1-Pad1) — width 0.25 mm”.
            2. Move the mouse: a straight + 45° preview follows, with a faint clearance halo. It turns red when it would come too close to other copper.
            3. Click pad 1 of R1: reaching same-net copper ends the route.
            4. Click Autoroute all (Ctrl+Shift+A): “All connections routed (7 tracks, 0 vias) in 37 ms.” The PCB badge turns into a green ✓.

            The GND track is wider because the default “Power” net class (GND, VCC, +5V, +3V3, +12V, -12V, VBAT) uses 0.5 mm tracks (10.5).

            3.9Ground pour

            1. Click Fill board with ground zone (Route → Fill board with ground zone).
            2. GND is preselected with F.Cu and B.Cu ticked; click Create.
            3. Both sides get a GND zone inset from the board edge by (edge clearance + 0.2 mm). Other nets are cleared around; GND pads connect through four-spoke thermal reliefs.

            3.10DRC

            Click the shield-shaped DRC button: “DRC passed — the board is clean.” If there were problems, clicking an issue jumps to it. Once run, DRC reruns after every edit (9.1).

            3.11Check it in 3D

            F4 shows the board in an isometric view. Left-drag orbits, right-drag pans, the wheel zooms; 1–7 pick standard views and C toggles components. Clicking a part selects it everywhere.

            3.12Simulate

            1. Simulate → Operating point (DC): the Simulation tab shows net voltages and part currents/powers. The LED current is about 14.9 mA.
            2. F2 back to the schematic: voltage badges (9 V, 1.99 V, 0 V) sit on the wires.

            The battery current is negative (−14.9 mA) by SPICE convention: a source's current is measured flowing into its + pin, so a source that delivers power reads negative (12.6).

            3.13Gerber and drill files

            1. File → Fabrication outputs (Gerber, drill)…. DRC runs first and its result is shown on top.
            2. Check the file list (one Gerber per layer, PTH/NPTH drill, BOM, pick & place, IPC-356, job file, README) and sizes.
            3. Preview in Gerber viewer, or Save ZIP… to get LED_Tutorial-fabrication.zip — upload it to your board house as is.

            Save with Ctrl+S — done. The following chapters cover every feature in detail.

            4Schematic editor

            The Schematic tab (F2) defines what connects to what (the netlist). The board, the simulation and the BOM all start from here.

            4.1Units, grid and sheet

            • Schematic coordinates are mils (1/1000 inch). The status bar shows them in mm or mil.
            • Everything snaps to the schematic grid (50 mil by default; 10/25/50/100 via the status bar or Settings). Library pins are on a 100 mil pitch, so 50 mil is the right choice almost always.
            • The sheet has a border with column numbers and row letters. Choose A4 · A3 · A2 · Letter · Tabloid under Sheet size in the Properties panel with nothing selected.
            • The title block shows company, title, date, revision, comment, size, author and “Sheet: page/pages name”, edited in File → Project properties….
            • Grid display and style (dots/lines) are under View → Show grid and Settings.

            4.2Selecting

            • Click selects one item (hover highlights it). Overlapping items are picked in the order labels/texts → no-connects → junctions → wires → buses → parts.
            • Shift/Ctrl+click adds or removes.
            • Box selection: Shift (or Ctrl) + drag on empty space (adds to the selection):
              • Left → right (window, blue solid box): only items completely inside (wires: both ends).
              • Right → left (crossing, green dashed box): everything the box touches (wires: either end).
              A plain drag on empty space pans (2.9), unless Left-drag on empty canvas is set to Box select.
            • Ctrl+A selects everything on the current page.
            • Esc in order: leaves hand mode, clears a measurement, finishes a wire, cancels a drag, returns to Select, clears the net highlight, clears the selection.

            4.3Moving and rubber-band dragging

            • Drag a selection to move it on the grid (it starts after 4 px of movement); one drag is one undo step. Esc during a drag puts everything back.
            • Rubber-banding: wire ends attached to the pins or label anchors of moved items follow. Wires that became diagonal get a corner on release so they stay orthogonal (an originally horizontal wire stays horizontal).
            • Alt/Option+drag moves without dragging attached wires (connections may break).
            • Arrow keys nudge by one grid step (with rubber-banding).
            • Field dragging: drag just the reference (R1) or value (10k) text of a part to reposition the label. Rotating/mirroring the part resets field positions.

            4.4Rotate and mirror

            KeyAction
            RRotate 90° counter-clockwise (on screen); several items rotate about the grid-snapped centre of the selection
            YMirror horizontally (about a vertical axis)
            XMirror vertically (mirror + 180°)

            Attached wire ends follow the new pin positions and are straightened. The keys also work on the ghost while placing. The inspector's Rotation (0/90/180/270°) and Mirrored box do the same.

            4.5Copy, cut, paste, duplicate

            • Ctrl+C / Ctrl+X / Ctrl+V use an internal clipboard. Paste centres the items at the mouse position (grid-snapped); Paste on the empty-space context menu pastes where you clicked. You can paste onto another page.
            • Ctrl+D duplicates 200 mil down-right and selects the copy.
            • Pasted parts whose reference is already used become R? — annotate again.
            • Cut/copy/paste exist only in the schematic; on the PCB, Duplicate works on tracks, vias, zones, texts and graphics (footprints come from the schematic).

            4.6Deleting

            Del or Backspace (when not wiring). Afterwards the automatic clean-up removes junctions no longer needed and merges wires that now continue in a straight line.

            4.7Placing parts

            1. A (Place → Add part): type a name, value or keyword (English or Korean, e.g. “resistor”, “555”) and press Enter. Recently used parts are listed first.
            2. Drag a part from the library onto the sheet: places one and returns to Select.
            3. Click a part in the library, then click the sheet (Enter in the search box picks the first hit).

            Each click places one copy and the tool stays active; Shift+click places once and returns to Select (power ports stay active). New parts get R?-style references and the library's default value and footprint. Placed symbols go into the recently-used list (12).

            4.8Power ports

            P lists the power symbols: GND, VCC, +5V, +3V3, +12V, VBAT, -12V, PWR_FLAG.

            • A power symbol joins the net named by its value; all symbols with the same name are one net — without wires and across all pages.
            • Changing the value renames the net (e.g. VCC → +9V).
            • They get hidden references (#PWR01 …) and never appear on the board or in the BOM.
            • PWR_FLAG tells ERC that a net is powered from outside; use it to silence power-undriven when power comes in through a connector.
            • The simulation reference (0 V) is the GND (or 0, AGND) net — simulation needs a GND symbol.

            4.9Wires

            1. W, then click the start. Near a pin tip, wire end or label anchor (about 9 screen pixels) the point snaps there (square marker); otherwise to the grid (cross marker).
            2. Each further click adds a segment. Non-aligned points get one corner, horizontal first by default; / switches to vertical first.
            3. Auto-finish: touching a pin, another wire's end, a label or the middle of another wire ends the wire.
            4. To end elsewhere: Enter, Esc, double-click or right-click. Backspace removes the last segment.

            A whole wire is one undo step. After every edit the clean-up runs: removes zero-length and duplicate wires, merges collinear wires meeting end to end (when nothing else attaches there), splits wires at junctions on their middle, and keeps junction dots exactly where three or more connections meet (adding and removing them automatically).

            Unconnected wire ends get a small yellow circle; unconnected pin tips get a small circle when zoomed in.

            Two wires that merely cross are not connected — place a junction (J). A wire end or pin tip landing on the middle of a wire (a T) does connect (5.1).

            4.10Junctions

            J and click: the junction splits wires passing through and connects them. Junctions where fewer than three connections meet are removed by the clean-up.

            4.11Net labels and global labels

            • L (net label) or Ctrl+L (global label), click a wire end or pin tip, type the name, Enter (Esc cancels).
            • Auto-increment: if the previous name ended in a number the next label is pre-filled with it plus one (D0 → D1, ADDR07 → ADDR08).
            • Auto direction: on a wire end the label points away from the wire.
            • Equal net labels connect on the same page. Global labels with the same name connect across all pages (and also join a same-named net label on their own page).
            • Double-click to rename; the inspector edits name, type and rotation.
            • Labels also name nets: a labelled net is called by its label instead of Net-(R1-Pad2), and that name is used on the board, in probes and netlists.

            4.12Buses

            B, click corners, double-click to finish. A bus is a thick graphic line only — the connections come from the net labels on each signal (see sample “74HC595 LED bar”).

            4.13No-connect flags

            Q and click an unused pin tip: an × marks it as intentionally unconnected and the unconnected-pin warning disappears. Clicking elsewhere shows “Click on a pin end to place a no-connect flag.” Connecting a flagged pin later raises nc-connected.

            4.14Text

            T, click, type. Notes have no electrical meaning. Double-click to edit inline; the inspector edits multi-line text and size (mil, default 50).

            4.15Editing properties

            Inspector: for a part — Reference, Value, Footprint (symbol suggestions + More… = footprint assignment), Rotation, Mirrored, Do not populate, and a Simulation section for parts with simulation fields (wave = DC/Sine/Pulse, state = Open/Closed). Buttons: All properties…, Show in PCB. For a wire — net, length in mm, Highlight net, Add probe.

            Part properties dialog (double-click, E, or right-click → Properties…):

            • General: reference, value (with the parsed value shown, e.g. “= 4.7 k”), rotation, Mirrored / Do not populate / Hide value.
            • Footprint: name with auto-complete, suggestion chips, pad preview.
            • Fields: simulation fields and your own fields (MPN, Supplier …) via Add field. Empty fields are not saved.

            Double-clicking the value text of a part edits just the value in place; labels and texts are edited in place too. DNP parts are not added to the board, are excluded from simulation and are listed separately in the BOM.

            4.16Annotation

            • Tools → Annotate schematic numbers only references ending in ?, per prefix, skipping numbers in use, ordered page by page (page order), then top to bottom (100 mil rows), then left to right.
            • Tools → Re-annotate all parts renumbers everything.
            • Power symbols and flags are always renumbered #PWR01, #FLG01 …
            • F8 annotates unannotated parts automatically first.
            • The units of a multi-unit part share one reference and show a unit letter (U1A, U1B …; 4.25).

            4.17Net highlight and cross-probing

            • Clicking a wire highlights its whole net (wires, pins and same-named labels) in the schematic and on the board; also from the context menu, palette or Find. Esc clears it.
            • Cross-probing: selecting a part selects its footprint on the PCB and in 3D and vice versa. Show in PCB / 3D / schematic switch tab and centre the part (switching schematic page if needed). Clicking a BOM row selects those parts everywhere.

            4.18Context menu

            Right-click with the Select tool: on a part — Properties…, Show in PCB, Show in 3D; on a wire — Highlight net, Probe this net in simulation; with a selection — Rotate, Mirror H/V, Duplicate, Copy, Cut, Delete; on empty space — Paste, Add part…, Wire; always — Zoom to fit, Select all. With other tools, right-click returns to Select (or ends the wire).

            File → Project properties…: title, author, company, revision, date, comment. Used by the title block, printouts, the fabrication README and job file, and the KiCad netlist title block.

            4.23Hierarchical sheets

            A hierarchical sheet draws another page as a block; the sheet pins on its edges connect to hierarchical labels on that page.

            1. Press S (Place → Hierarchical sheet) and drag a rectangle (at least 600 × 400 mil).
            2. Type the sheet name (default “Sheet 1”) and press Enter. A new page of that name is created and added to the page tabs; a toast explains the next step.
            3. Double-click the block to open its page. Draw the circuit and put hierarchical labels (H, Place → Hierarchical label) on the signals that leave the page.
            4. The block's pins follow the labels automatically — added, renamed or removed labels update the pins (sorted by name, alternating left/right at 100 mil, the block grows as needed). Pins are derived data, so no undo step is recorded.
            5. Back on the parent page, wire to the pin ends — they are snap/connection points.
            • The block shows its name, the target page name and the pins; it can be selected, moved and deleted (the page stays).
            • A hierarchical label connects to the same-named pin of the block that shows its page.
            • ERC: sheet-target (block points to a missing page) and hier-unconnected (label without a matching pin), see 5.4.
            • KiCad hierarchical sheets import into the same structure (13.9).

            Select a sheet block to edit it in the Properties panel: Name (renames its page too), Width and Height (− / + steppers), the list of sheet pins, and an Open sheet page button.

            4.24Vector (bus) labels

            A label named NAME[a..b] stands for several signals: D[0..7] = D0 … D7 (up to 256). As a global label it joins every member across pages; as a sheet pin name (a D[0..7] hierarchical label on the sub-page) it joins D0…D7 of the parent page to D0…D7 of the sub-page member by member. The members themselves are connected with ordinary labels; thick bus lines remain graphics.

            5Connectivity rules and ERC

            5.1Connectivity rules

            1. A wire end connects to whatever sits exactly on it (pin tip, wire end, label anchor, junction).
            2. A wire end, pin tip, label anchor or junction on the middle of another wire connects to it (T joint).
            3. Crossing wires do not connect unless a junction sits on the crossing.
            4. Net labels with the same text are one net on their page; global labels on all pages.
            5. Power symbols join the net named by their value on all pages.
            6. Pins of one part with the same number (e.g. a tact switch's twin pads) are one net.
            7. Geometry never connects across pages.
            8. A hierarchical label connects to the same-named pin of the sheet block showing its page (4.23).
            9. Vector labels D[0..7] expand to D0…D7 on global labels and sheet pins (4.24).
            10. The units of a multi-unit part are one component: same-numbered pins are one net. Hidden power-input pins (e.g. KiCad logic parts) join the net named like the pin.
            11. Buses and texts carry no connectivity.

            5.2Net names

            Priority: power symbol name → global label → net label → automatic Net-(REF-PadN) from the lowest reference's pin. Duplicate names get _1, _2. Names are used on the board, in probes, netlists and the BOM — label important signals. Inspect → Net list… shows all nets.

Manually: Inspect → Electrical rules check (ERC), the toolbar button, the status-bar cell or the refresh button — a toast summarises the result and the right panel opens.

            6.4Pin numbers and pads

            A symbol pin connects to the footprint pad with the same number. Diodes and LEDs: 1 = cathode (K), 2 = anode (A); on through-hole footprints the square pad is 1 (cathode).

            Transistor pin numbers — the built-in transistor symbols follow common TO-92 parts: Q_NPN/Q_PNP are 1 = E, 2 = B, 3 = C (2N3904/2N3906 E-B-C), Q_NMOS/Q_PMOS are 1 = S, 2 = G, 3 = D (2N7000 S-G-D). The SOT-23_Q footprint puts B/G (numbered "2") on physical pad 1, E/S (numbered "1") on pad 2 and C/D on pad 3, so SOT-23 transistors wire correctly (plain SOT-23 keeps the numbers in pad order). For parts with other pin orders (e.g. BS170/BS250 are D-G-S) check the datasheet and, if needed, make a custom symbol with matching pin numbers.

            6.5Symbol editor

            Tools → Symbol editor… builds box symbols (ICs, modules) from a pin table.

            1. Enter the symbol name (spaces become _), description, category (becomes a library chip), reference prefix, default value and default footprint.
            2. Fill the pin table: number, name, type (input, output, bidir, tristate, passive, power_in, power_out, open_collector, no_connect, unspecified) and side (left/right/top/bottom). Add pin, Add 4 pins (alternating left/right), Sort by number, trash = delete.
            3. Many pins? Open Bulk import from text, paste one pin per line as number, name, type, side (comma, tab or semicolon) and click Import (defaults bidir / left).
            4. The preview updates as you type; pins are 100 mil apart and the box grows to fit the longest name.
            5. Save to project stores it in the project file, adds it to the library and starts placing it.

            Names of built-in symbols and duplicate pin numbers are rejected. Edit an existing custom symbol with Open existing…. Custom symbols have no simulation model.

            7.6Interactive routing

            1. Start (X): click a pad, via or track end (active-layer copper first). Its net becomes the route's net. Starting on an SMD pad switches the active layer to that pad's side; THT pads and vias route on the current active layer.
            2. Width starts at the net-class width (or the default). While routing, W steps wider and Shift+W narrower: 0.15 → 0.2 → 0.25 → 0.3 → 0.4 → 0.5 → 0.6 → 0.8 → 1.0 → 1.5 → 2.0 mm.
            3. 45° posture: the preview is a straight run then a 45° diagonal; / puts the diagonal first. The cursor snaps to same-net pads/vias/track ends, otherwise to the grid.
            4. Live clearance check: the faint halo is the clearance. If a preview segment comes closer to other-net copper than the rule (largest net-class value) or violates the edge clearance, it turns red and the hint says “Clearance violation — this segment is too close to other copper.” (You can still place it; DRC will flag it.)
            5. Corners: each click commits the preview; Backspace removes the last segment.
            6. Vias: V while routing commits to the cursor, drops a via (net-class size) and switches layer (F.Cu ↔ B.Cu; inner layers step to the next copper layer).
            7. Finish: reaching same-net copper ends the route automatically; or Enter, Esc, double-click, right-click. One route = one undo step.

            7.9Copper zones

            1. Make a copper layer active and press Z.
            2. Click the corners (grid-snapped).
            3. Double-click or Enter closes it (≥ 3 corners); Esc cancels.
            4. In New copper zone choose net (default GND/AGND/DGND/VSS if present), layer, clearance (0.3 mm), priority and thermal reliefs, then Create zone.
            • Other-net pads, tracks and vias are cleared by max(zone clearance, default clearance); unnetted pads and NPTH holes too.
            • Same-net pads inside the outline connect through thermal reliefs: a gap plus four spokes (width = max(0.3 mm, 0.45 × pad's short side, 0.8 × class width)); a spoke that would hit another net's track or via is dropped. With reliefs off, pads are flooded solid.
            • Same-net tracks and vias merge with the zone.
            • Priority: where zones of different nets overlap on a layer, the higher priority wins and the lower one clears around it; equal priorities are a DRC zone_overlap error.
            • Connectivity: a pad, track end or via inside a same-net zone outline counts as connected through the zone, so a GND pour removes the GND airwires.

            Connectivity only asks “is it inside the zone outline”. If other-net tracks cut the fill into islands, items may still count as connected — check narrow GND paths in 3D or the Gerber viewer.

            Select a zone near its outline; double-click (or context menu) edits it; the inspector edits net, layer, clearance, priority and reliefs.             8Autorouter

            8.1Running it

            • Route → Autoroute all (Ctrl+Shift+A), the toolbar button or the Routing panel: all unrouted connections.
            • Route → Autoroute highlighted net after clicking a pad/track; double-click a net in the net list; context menu → Route net automatically.

            The result is added as one undo step: “All connections routed (n tracks, m vias) in t ms.” or “Routed r connections, f could not be routed.”

            8.2How it works

            1. Routing nodes on the Settings → Routing → Autorouter grid (default 0.25 mm, 0.05–0.5 mm; coarsened on huge boards), obstacle maps at half that pitch so diagonal steps cannot clip pad corners.
            2. Obstacles: other-net pads/tracks/vias grown by clearance + half the width, the board edge (edge clearance), NPTH holes; one map set per net-class profile. Zones are not obstacles.
            3. A separate via map checks all copper layers, hole spacing and the edge; no vias in SMD pads; a via costs as much as 20 grid steps.
            4. Connections are routed shortest first with A* from any node of the source island to any node of the target island, 8 directions, with turn penalties (45° 0.35, 90° 0.9, 135° 6) and a mild preferred direction per layer.
            5. Paths are simplified into tracks and vias, snapped to pad/via centres and stamped into the maps immediately.
            6. Rip-up and retry: failures are routed first in a fresh pass (up to 3 passes); the better pass wins. Time limit 15 s.

            8.3Limits

            • By default uses only F.Cu and B.Cu; Settings → Routing → Autorouter layers = All copper layers also uses inner layers.
            • Grid-based: fine-pitch parts (e.g. 0.5 mm QFP) may be unreachable.
            • Existing tracks are kept and may block routes.
            • No differential pairs, length matching or impedance control.

            8.4Tips

            • Placement decides most of the result: keep airwires short and uncrossed.
            • Pour GND first — those connections then need no tracks.
            • Route critical or heavy nets by hand, autoroute the rest.
            • On failure: Remove all tracks, nudge parts, retry; then Clean up tracks and run DRC.

            12.5Ground and connectivity

            • The GND, 0 or AGND net is 0 V; without one you get “No GND net”.
            • Unconnected pins become private floating nodes (warning). Nets with no DC path to ground are held at 0 V by gmin (10−12 S, warning).
            • Non-converging operating points fall back to gmin stepping and source stepping; singular matrices name the offending net or part.

            12.6Sign conventions

            I(ref) is the current flowing into the part's main pin: R/C/L/SW/POT pin 1 (1 → 2 positive); D/LED anode; V/BATTERY + pin (SPICE convention — negative while delivering power); I + pin (reads −value); NPN/PNP collector; NMOS/PMOS drain; REG input; OPAMP output (negative while sourcing). Power = Σ V(pin) · I(into pin): positive absorbed, negative delivered.

            Simulate → Show SPICE netlist… (Copy, Save… as .cir) or File → Export → SPICE netlist.             12.10Limitations

            • No noise, distortion, temperature, Monte-Carlo or parameter sweeps; no digital simulation.
            • Simplified models (no junction capacitances, ideal pulse edges) — not accurate at high frequency.
            • Capacitor currents read 0 in the operating-point table.

            19Troubleshooting

            19.1FAQ

            Dragging empty space pans instead of box-selecting.
            That is the default; box selection is Shift/Ctrl+drag, or set Left-drag on empty canvas to Box select.
            Left-drag only moves the view, not parts.
            Hand (pan) mode is on — press Esc or the hand button.
            “Hierarchical label … has no matching sheet pin”.
            A sheet block must show that page; create one with S and put the labels on its page.
            A wire is reported as unconnected.
            Wire ends must land exactly on pin tips (look for the snap square). Crossing wires need a junction.
            Signals on different pages do not connect.
            Net labels are page-local; use global labels or power ports.
            “Power input … is not driven”.
            Add a PWR_FLAG to the net when power comes from a connector.
            Parts are missing after F8.
            No footprint or DNP — check Assign footprints.
            My footprint change on the PCB was undone.
            The schematic is the master; change it there.
            The autorouter leaves connections.
            See 8.4; it only uses F.Cu/B.Cu.
            The routing preview is red.
            Too close to other copper or the edge — change the path or narrow the track (Shift+W).
            “No GND net” in simulation.
            Add a GND symbol.
            An IC is ignored by the simulator.
            It has no model; use OPAMP or the regulator symbols.
            1M behaves like milli / mega.
            M = mega, m = milli; use Meg.
            The web page is blank.
            Serve it over HTTP, not file://.
            The app quits immediately from a terminal.
            ELECTRON_RUN_AS_NODE — use npm start.
            Double-clicking a file does not open a new window.
            Single instance — the running window opens it.
            Fabrication files are called board-….
            Give the project a title with Latin letters.
            The Gerber viewer cannot open a ZIP.
            Only uncompressed ZIPs; unzip and open the files.
            Undo does nothing.
            Opening a file clears history; with focus in a text field Ctrl+Z undoes the field — click the canvas first.
