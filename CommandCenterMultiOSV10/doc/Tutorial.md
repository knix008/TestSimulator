# Command Center 튜토리얼

시작 화면의 **튜토리얼** 버튼을 누르면 앱이 같은 순서로 화면을 짚어 가며 안내합니다. 이 문서는 그 안내를 글로 옮긴 것입니다. 안내는 파일을 지우거나 옮기지 않습니다.

진행은 **다음**, 뒤로 가기는 **이전**, 언제든 닫기는 **끝내기**입니다. 키보드로는 `→` 또는 `Enter`가 다음, `←`가 이전, `Esc`가 끝내기입니다.

## 1. 시작 화면

메뉴바에서 프로그램 아이콘과 이름 바로 오른쪽의 **홈**이 시작 화면을 엽니다. 다시 누르면 파일 패널로 돌아갑니다. 메인 창에는 따로 제목줄이 없고, 데스크톱에서는 이 줄 오른쪽에 최소화, 최대화, 닫기가 있습니다.

시작 화면에는 네 묶음이 있습니다.

- **시작하기.** 파일 관리는 두 패널로 돌아갑니다. 사용 설명, 홈 폴더, 새 폴더, 검색, 터미널, 설정, 프로그램 정보도 여기서 바로 엽니다. **사용 설명**은 기능을 그림과 함께 찾아보는 문서이고, 같은 페이지가 [index.html](index.html) 입니다.
- **작업.** 복사, 이동, 압축, 압축 해제, 이름 바꾸기, 폴더 비교, 보기, 인쇄, 즐겨찾기, 새 탭. 누르면 패널로 돌아가 그 명령을 실행합니다.
- **최근 폴더.** 두 패널에서 열었던 폴더입니다. 10개까지 보이며, 이름을 누르면 활성 패널에서 그 폴더가 열립니다. × 로 하나만 지우고, **폴더 기록 모두 지우기**로 비웁니다. 아래 팁은 하루에 하나씩 바뀝니다.
- **배경.** 계곡, 바다, 노을, 숲, 호수, 일출, 산맥, 모래 언덕, 비, 눈, 오로라, 별, 성운, 도시, 반딧불이, 꽃잎, 불씨, 보케, 리본, 도형. 스무 가지 3D 풍경이 스스로 움직이고, 고른 종류만 이 화면에 나타납니다. **투명도**는 숫자와 %로 보이며, 올리면 테마 색이 비칩니다. **속도**는 카메라와 물체와 하늘이 움직이는 빠르기입니다. 속도를 0으로 하면 멈춥니다. **초기화**는 투명도 0, 속도 20으로 되돌립니다. **시작 시 홈 보여주기**를 끄면 다음 실행부터 파일 패널로 시작합니다. 최근 폴더는 10개까지 보이며, 하나씩 또는 한꺼번에 지울 수 있습니다. 같은 설정은 설정의 시작 화면 탭에도 있습니다.

## 2. 파일 작업

### 두 개의 패널

왼쪽과 오른쪽에 폴더가 하나씩 열려 있습니다. 가운데 선을 끌면 너비가 바뀌고, 선을 더블클릭하면 반반이 됩니다. 툴바의 분할 버튼으로 위아래로도 놓을 수 있습니다.

### 활성 패널

테두리가 강조된 쪽이 활성 패널입니다. 패널을 클릭하거나 `Tab`으로 바꿉니다. 메뉴, 툴바, 단축키는 활성 패널에 적용됩니다.

### 선택과 열기

한 번 클릭은 선택만 합니다. 더블클릭이나 `Enter`는 폴더로 들어갑니다. 이미지, 동영상, 오디오는 미리 보기 창이 열리고, 그 밖의 파일은 연결된 프로그램으로 열리거나 실행됩니다. 설정에서 미리 보기를 끄면 더블클릭도 항상 연결 프로그램입니다. 메뉴의 미리 보기는 어떤 파일이든 내용 창을 엽니다.

### 펑션 키

| 키 | 동작 |
| --- | --- |
| F3 | 보기 |
| F4 | 편집 |
| F5 | 반대 패널로 복사 |
| F6 | 이동 |
| F7 | 새 폴더 |
| F8 | 삭제 |

`Ctrl+Z`와 `Ctrl+Y`는 방금 한 파일 작업을 되돌리고 다시 실행합니다.

## 3. 메뉴와 도구

### 메뉴바

아이콘과 이름 오른쪽의 홈, 그 다음 파일, 편집, 선택, 보기, 압축, 정보입니다. **정보**에는 프로그램 정보와 설정이 있습니다. 파일 메뉴 아래에는 최근 연 폴더가 있습니다.

### 툴바

아이콘만 있는 버튼입니다. 마우스를 올리면 설명이 나옵니다. 오른쪽 끝은 테마, 언어, 설정, 프로그램 정보입니다.

테마 버튼의 펼침은 **Dark** 한 열과 **Light** 한 열입니다. 같은 종류가 여러 열로 나뉘지 않습니다. 가장 아래 한 줄은 **사용자 정의 테마**이며, 설정에서 만든 테마를 그 줄에서 눌러 바로 적용합니다.

### 아래 패널

로그, 빠른 검색, 터미널이 있습니다. `Ctrl+\`` 로 여닫습니다. 터미널은 활성 패널의 폴더에서 셸을 띄우고, `+`로 탭을 더 엽니다.

### 설정

톱니 버튼입니다. 탭은 일반, 시작 화면, 패널, 테마, 파일 열기, 보기·편집, 터미널, 프롬프트입니다. 데스크톱에서는 그 내용에 맞는 크기로 바로 열리고, 프로그램 정보 창도 마찬가지입니다. 테마 탭은 어두운 것, 밝은 것, 사용자 정의가 나뉩니다. 시작 화면 탭에서 **시작 시 홈 보여주기**, 배경 종류, 투명도(숫자와 %), 속도, 최근 폴더를 바꿉니다. 값을 바꾸면 바로 적용되고, 취소하면 원래대로 돌아갑니다. 최근 폴더를 지운 것은 취소를 눌러도 남습니다.

## 4. 다시 시작 화면으로

홈으로 언제든 시작 화면으로 돌아올 수 있습니다. **파일 관리**를 누르면 패널로 갑니다.
