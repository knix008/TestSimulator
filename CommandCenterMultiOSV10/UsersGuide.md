# Command Center 사용 설명서

## 1. 화면 구성

```
┌ 메뉴바: 파일(F) 편집(E) 보기(V) 압축(C) ─────────────────────────────────┐
│ 툴바: [새 폴더] [새 파일] | [복사] [이동] [삭제] | [검색]   [🎨 테마 ▾] [🇬🇧] [⚙ 설정] | [ⓘ 정보] │
├──────────────────────────────┬──────────────────────────────────────────┤
│ [C:\ ▾] 🏠 왼쪽  C:\ › Home …  │ [D:\ ▾] 🏠 오른쪽  D:\ › Data …           │
│ 이름 ▲   권한  수정일  종류 크기│ 이름     권한  수정일  종류  크기        │
│ ↑ ..                         │ ↑ ..                                     │
│ 📁 폴더 …                     │ 📄 파일 …                                │
│ 폴더 3개, 파일 12개 | 합계 …  │ 폴더 1개, 파일 4개 선택됨 | 3.2 MB       │
├──────────────────────────────┴──────────────────────────────────────────┤
│ 상태 표시줄: 왼쪽 패널 활성 | C:\Home\…                                  │
└─────────────────────────────────────────────────────────────────────────┘
```

- **활성 패널**은 테두리가 강조됩니다. 패널 안을 클릭하거나 `Tab` 으로 바꿉니다. 메뉴·툴바·단축키는 활성 패널에 적용됩니다.
- 패널 사이의 **분할선**을 드래그하면 너비가 바뀌고 저장됩니다.

## 2. 이동하기

| 방법 | 설명 |
|---|---|
| 더블클릭 / Enter | 폴더로 들어갑니다. 파일이면 기본 앱으로 엽니다(분할 압축 파일은 압축 해제). |
| `..` 또는 Backspace | 상위 폴더 |
| 빵부스러기(경로 조각) 클릭 | 그 위치로 바로 이동 |
| 🏠 | 홈 폴더 |
| **[C:\ ▾] 드라이브 버튼** | 시스템의 모든 드라이브/볼륨 목록(Windows: 이름과 여유/전체 용량, 종류별 아이콘 — 고정·이동식·네트워크·CD; Linux/macOS: `/`, 마운트된 볼륨). 고르면 그 루트로 이동합니다. |
| **왼쪽 / 오른쪽** 라벨 클릭 | 폴더 트리를 펼칩니다. 홈, 드라이브(Windows) / `/`, `/tmp`, 마운트된 볼륨이 루트이며 현재 폴더까지 자동으로 펼쳐집니다. 폴더를 클릭하면 이동하고 트리는 닫힙니다. ▸ 를 누르면 하위 폴더를 펼칩니다. |
| 열 머리글 클릭 | 정렬(다시 클릭하면 역순). 폴더가 항상 먼저, `..` 은 맨 위. |
| 보기 → 숨김 파일 표시 | `.` 으로 시작하는 항목 표시 |

## 3. 파일 작업

| 작업 | 단축키 | 방법 |
|---|---|---|
| 반대 패널로 복사 | F5 | 선택 → 툴바 **복사** / 편집 메뉴 / 컨텍스트 메뉴 "→ 다른 패널로 복사" |
| 반대 패널로 이동 | F6 | 위와 같음 (같은 드라이브면 즉시, 다른 드라이브면 복사 후 삭제) |
| 새 폴더 / 새 파일 | F7 / — | 이름을 입력하면 활성 패널의 폴더에 만듭니다 |
| 이름 바꾸기 | F2 | 파일이면 확장자 앞부분이 선택된 채 열립니다 |
| 삭제 | F8, Delete | 확인 후 **영구 삭제** |
| 휴지통으로 이동 | — | 컨텍스트 메뉴 (Windows/macOS/Linux 데스크톱, 웹은 Linux/macOS) |
| 클립보드 복사 / 붙여넣기 | Ctrl+C / Ctrl+V | 파일 목록을 `file://` URI 로 복사합니다. 탐색기/Finder 등에서 복사한 경로 목록도 붙여넣을 수 있습니다. |
| 모두 선택 | Ctrl+A | |
| 속성 | — | 이름·경로·종류·크기(폴더는 하위 합계)·수정일·권한 |

### 같은 이름이 있을 때

복사/이동/붙여넣기 중 대상에 같은 이름이 있으면 **덮어쓰기 / 건너뛰기 / 취소** 를 묻습니다.
"이후 항목에도 동일하게 적용"을 켜면 남은 충돌에 같은 답을 씁니다. 폴더끼리는 병합되고, 병합 중 파일 충돌은 다시 묻습니다.

### 진행률 창

복사·이동·삭제·압축·해제·검색은 진행률 창에 현재 항목과 % 가 표시되며 **취소** 할 수 있습니다.
작업 중에는 패널의 자동 새로고침이 잠시 멈추고, 끝나면 두 패널이 새로고침됩니다.

## 4. 압축

압축 → 압축 (선택 항목이 있을 때) 또는 컨텍스트 메뉴 → 압축.

| 항목 | 설명 |
|---|---|
| 파일 이름 | 확장자 없이 입력 (첫 선택 항목의 이름이 제안됨) |
| 형식 | `.tar.gz` / `.tar.bz2` / `.zip` |
| 분할 압축 | 켜면 분할 크기(KB/MB/GB, 기본 10 MB)로 잘라 저장 |

분할 압축 파일 이름:

| 형식 | 파일 |
|---|---|
| ZIP | `이름.zip`, `이름.z01`, `이름.z02`, … |
| tar.gz | `이름.tgz`, `이름.tgz.001`, `이름.tgz.002`, … |
| tar.bz2 | `이름.tbz2`, `이름.tbz2.001`, … |

**압축 해제**: 압축 파일(또는 분할 조각 중 아무거나)을 하나 선택하고 압축 → 압축 해제, 또는 분할 파일을 더블클릭.
해제할 폴더 이름을 물은 뒤 활성 패널의 폴더 안에 만듭니다. 분할 조각은 자동으로 결합됩니다.
GNU `split` 로 자른 `이름.tar.gz.aa`, `.ab` … 도 인식합니다. 다른 프로그램에서 열려면 조각을 이어 붙이세요:

```sh
cat 이름.zip 이름.z01 이름.z02 > 이름-full.zip
```

지원 해제 형식: `.zip` `.tar` `.tar.gz` `.tgz` `.tar.bz2` `.tbz2` `.gz` `.bz2` (xz 는 지원하지 않음).

## 5. 검색 (F9)

활성 패널의 폴더 아래를 재귀적으로 찾습니다.

- **파일 이름**: `*`, `?` 와일드카드 (대소문자 무시). 예: `*.txt`, `report_??.xlsx`
- **내용 검색**: 켜면 입력한 문자열을 포함하는 파일만 (64 MB 이하, 대소문자 무시)
- 결과를 **더블클릭**하면 그 파일이 있는 폴더로 이동하고 파일이 선택됩니다.
- 검색 창은 모달이 아니므로 열어 둔 채 패널을 쓸 수 있습니다. **중지** 로 취소합니다.

## 6. 테마 · 언어 · 정보

툴바 오른쪽:

- **🎨 테마 이름** — 클릭하면 다음 테마로 바뀝니다. 옆의 **▾** 를 누르면 16가지 테마 목록에서 고릅니다.
  (미드나이트 · 데이라이트 · 그라파이트 · 오션 · 포레스트 · 선셋 · 고대비 · 노르드 · 드라큘라 · 솔라라이즈드 다크/라이트 · 모노카이 · 로즈 · 라벤더 · 민트 · 커피)
- **국기** — 전환할 언어의 국기가 표시됩니다. 한국어일 때 🇬🇧(영어로), 영어일 때 🇰🇷(한국어로).
- **⚙ 설정** — 언어, 테마, 글꼴 크기, 분할 압축 기본 크기, 숨김 파일 표시, 삭제 전에 확인, 시작할 때 마지막 폴더 복원(끄면 홈에서 시작), 폴더 변경 자동 새로고침.
- **ⓘ 정보** — 버전, 빌드 시각, 실행 환경(데스크톱/웹).

팝업 창의 **닫기**(제목줄의 ✕ 와 닫기 버튼)는 마우스를 올리면 붉게 표시됩니다.

## 7. 오류가 났을 때

모든 오류는 팝업으로 표시됩니다: 메시지와 **자세한 내용**(오류 코드, 경로, 발생한 프로세스의 스택).
**자세한 내용 복사** 를 누르면 전체 내용이 클립보드로 복사되어 그대로 붙여넣어 문의할 수 있습니다.

## 8. 웹 버전

```bash
npm run web                    # http://127.0.0.1:5186
```

브라우저 안에서 같은 화면이 뜨며, **서버가 실행되는 컴퓨터**의 파일을 관리합니다. 차이점:

- "열기"(기본 앱 실행)는 없습니다.
- 휴지통은 서버가 Linux/macOS 일 때만 동작합니다(Windows 서버는 삭제만).
- 폴더 변경 감지는 2초 간격 폴링입니다.
- 다른 PC 에서 접속하려면 `--host 0.0.0.0 --token 비밀값` 으로 실행하고 `http://서버:포트/?token=비밀값` 으로 엽니다.

## 9. 설정 파일

| 환경 | 위치 |
|---|---|
| Windows | `%APPDATA%\Command Center\session.json` |
| macOS | `~/Library/Application Support/Command Center/session.json` |
| Linux | `~/.config/Command Center/session.json` |
| 웹 서버 | `~/.config/CommandCenter/session.json` (Windows: `%APPDATA%\CommandCenter`) |

좌/우 경로, 분할 위치, 정렬, 테마, 언어, 숨김 파일 표시, 글꼴 크기, 삭제 확인, 분할 기본 크기, 마지막 폴더 복원, 자동 새로고침, 창 위치가 저장됩니다.
