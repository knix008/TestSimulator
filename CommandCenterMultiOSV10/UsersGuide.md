# Command Center 사용 설명서

## 1. 화면 구성

```
┌ 메뉴바: 파일(F) 편집(E) 보기(V) 압축(C) ─────────────────────────────────┐
│ 툴바: [새 폴더] [새 파일] | [복사] [이동] [삭제] | [검색] | [터미널]   [🎨 테마 ▾] [🇬🇧] [⚙ 설정] | [ⓘ 정보] │
├──────────────────────────────┬──────────────────────────────────────────┤
│ [C:\ ▾] 🏠 왼쪽  C:\ › Home …  │ [D:\ ▾] 🏠 오른쪽  D:\ › Data …           │
│ 이름 ▲   권한  수정일  종류 크기│ 이름     권한  수정일  종류  크기        │
│ ↑ ..                         │ ↑ ..                                     │
│ 📁 폴더 …                     │ 📄 파일 …                                │
│ 폴더 3개, 파일 12개 | 합계 …  │ 폴더 1개, 파일 4개 선택됨 | 3.2 MB       │
├──────────────────────────────┴──────────────────────────────────────────┤
│ [≡ 로그] [▣ PowerShell 1 ×] [▣ Git Bash 2 ×] [+ ▾]                     ✕ │  ← 하단 패널 (Ctrl+`)
│ [📁 D:\Home]▶[⎇ main ↑ ~]▶ git status                                     │
│ …                                                                        │
│ [📁 D:\Home]▶[⎇ main]▶ █                                                  │
├─────────────────────────────────────────────────────────────────────────┤
│ 상태 표시줄: 왼쪽 패널 활성 | C:\Home\…                                  │
└─────────────────────────────────────────────────────────────────────────┘
```

- **활성 패널**은 테두리가 강조됩니다. 패널 안을 클릭하거나 `Tab` 으로 바꿉니다. 메뉴·툴바·단축키는 활성 패널에 적용됩니다.
- 패널 사이의 **분할선**을 드래그하면 너비가 바뀌고 저장됩니다.
- 패널 아래의 **하단 패널**(로그 · 터미널)은 툴바의 **터미널** 버튼, 보기 메뉴, 또는 ``Ctrl+` `` 로 열고 닫습니다 (→ 7장). 위쪽 가장자리를 드래그하면 높이가 바뀌고 저장됩니다.

## 2. 이동하기

| 방법 | 설명 |
|---|---|
| 더블클릭 / Enter | 폴더로 들어갑니다. 파일이면 기본 앱으로 엽니다(분할 압축 파일은 압축 해제). |
| `..` 또는 Backspace | 상위 폴더 |
| 빵부스러기(경로 조각) 클릭 | 그 위치로 바로 이동 |
| 🏠 | 홈 폴더 |
| **[C:\ ▾] 드라이브 버튼** | 시스템의 모든 드라이브/볼륨 목록(Windows: 이름과 여유/전체 용량, 종류별 아이콘 — 고정·이동식·네트워크·CD; Linux/macOS: `/`, 마운트된 볼륨). 고르면 그 루트로 이동합니다. |
| **왼쪽 / 오른쪽** 라벨 클릭 | 폴더 트리를 펼칩니다. 홈, 드라이브(Windows) / `/`, `/tmp`, 마운트된 볼륨이 루트이며 현재 폴더까지 자동으로 펼쳐집니다. 폴더를 클릭하면 이동하고 트리는 닫힙니다. ▸ 를 누르면 하위 폴더를 펼칩니다. |
| 열 머리글 클릭 | 정렬(다시 클릭하면 역순). 폴더가 항상 먼저, `..` 은 맨 위. |
| 보기 → 숨김 파일 표시 | `.` 으로 시작하는 항목 표시 |

## 3. 파일 작업

|---|---|---|
| 반대 패널로 복사 | F5 | 선택 → 툴바 **복사** / 편집 메뉴 / 컨텍스트 메뉴 "→ 다른 패널로 복사" |
| 반대 패널로 이동 | F6 | 위와 같음 (같은 드라이브면 즉시, 다른 드라이브면 복사 후 삭제) |
| 새 폴더 / 새 파일 | F7 / — | 이름을 입력하면 활성 패널의 폴더에 만듭니다 |

| 휴지통으로 이동 | — | 컨텍스트 메뉴 (Windows/macOS/Linux 데스크톱, 웹은 Linux/macOS) |
| 클립보드 복사 / 붙여넣기 | Ctrl+C / Ctrl+V | 파일 목록을 `file://` URI 로 복사합니다. 탐색기/Finder 등에서 복사한 경로 목록도 붙여넣을 수 있습니다. |
| 모두 선택 | Ctrl+A | |
| 속성 | — | 이름·경로·종류·크기(폴더는 하위 합계)·수정일·권한 |
| 실행 취소 / 다시 실행 | Ctrl+Z / Ctrl+Y | 툴바 왼쪽 끝의 ↶ ↷ 버튼, 편집 메뉴. 버튼에 마우스를 올리면 되돌릴 작업이 툴팁에 표시됩니다 |

### 실행 취소 / 다시 실행

새 폴더 · 새 파일 · 이름 바꾸기 · 복사 · 이동 · 압축 · 압축 해제를 최근 50개까지 되돌릴 수 있습니다.
복사·압축·압축 해제를 되돌리면 그 작업이 **만든** 항목을 영구 삭제하므로, 설정의 "삭제 전에 확인"이 켜져 있으면 먼저 묻습니다.
새 폴더·새 파일은 비어 있으면 바로 지우고, 내용이 생겼으면 확인합니다. 덮어쓰기·병합된 항목과 영구 삭제·휴지통 이동은 되돌릴 수 없습니다.

### 같은 이름이 있을 때

복사/이동/붙여넣기 중 대상에 같은 이름이 있으면 **덮어쓰기 / 건너뛰기 / 취소** 를 묻습니다.
"이후 항목에도 동일하게 적용"을 켜면 남은 충돌에 같은 답을 씁니다. 폴더끼리는 병합되고, 병합 중 파일 충돌은 다시 묻습니다.

### 진행률 창

복사·이동·삭제·압축·해제·검색은 진행률 창에 현재 항목과 % 가 표시되며 **취소** 할 수 있습니다.
작업 중에는 패널의 자동 새로고침이 잠시 멈추고, 끝나면 두 패널이 새로고침됩니다.

## 4. 압축

압축 → 압축 (선택 항목이 있을 때) 또는 컨텍스트 메뉴 → 압축.

| 항목 | 설명 |
|---|---|
| 파일 이름 | 확장자 없이 입력 (첫 선택 항목의 이름이 제안됨) |
| 형식 | `.tar.gz` / `.tar.bz2` / `.zip` |
| 분할 압축 | 켜면 분할 크기(KB/MB/GB, 기본 10 MB)로 잘라 저장 |

분할 압축 파일 이름:

| 형식 | 파일 |
|---|---|
| ZIP | `이름.zip`, `이름.z01`, `이름.z02`, … |
| tar.gz | `이름.tgz`, `이름.tgz.001`, `이름.tgz.002`, … |
| tar.bz2 | `이름.tbz2`, `이름.tbz2.001`, … |

**압축 해제**: 압축 파일(또는 분할 조각 중 아무거나)을 하나 선택하고 압축 → 압축 해제, 또는 분할 파일을 더블클릭.
해제할 폴더 이름을 물은 뒤 활성 패널의 폴더 안에 만듭니다. 분할 조각은 자동으로 결합됩니다.
GNU `split` 로 자른 `이름.tar.gz.aa`, `.ab` … 도 인식합니다. 다른 프로그램에서 열려면 조각을 이어 붙이세요:

```sh
cat 이름.zip 이름.z01 이름.z02 > 이름-full.zip
```

지원 해제 형식: `.zip` `.tar` `.tar.gz` `.tgz` `.tar.bz2` `.tbz2` `.gz` `.bz2` (xz 는 지원하지 않음).

## 5. 검색 (F9)

툴바의 **검색** 버튼(또는 F9, 보기 › 검색)을 누르면 **검색 창**이 열립니다. 창은 제목줄을 끌어 옮길 수 있고, 열어 둔 채로 패널을 계속 쓸 수 있습니다. 활성 패널의 현재 폴더와 **그 아래 모든 하위 폴더**에서 폴더와 파일을 찾습니다.

- **파일 이름**: `*`, `?` 와일드카드 (대소문자 무시). 예: `*.txt`, `report_??.xlsx`. Enter 또는 **검색 시작**. 폴더도 이름이 맞으면 결과에 나옵니다.
- **내용 검색**: 켜면 입력한 문자열을 포함하는 파일만 (64 MB 이하, 대소문자 무시; 파일만).
- 결과는 이름 · 검색 루트 기준 상대 폴더 · 크기로 나열됩니다. 클릭 / Ctrl+클릭 / Shift+클릭 / 방향키로 여러 개를 선택할 수 있습니다(Ctrl+A 모두).
- **Enter 또는 더블클릭**: **폴더**는 왼쪽 패널에 열리고, **파일**은 시스템에 지정된 기본 프로그램으로 실행됩니다.
- **복사·붙여넣기**: 선택한 항목을 **Ctrl+C**(또는 **복사** 버튼)로 클립보드에 복사한 뒤, 원하는 패널에서 **Ctrl+V** 로 붙여넣으면 그 폴더로 복사됩니다. **→ 왼쪽 패널로 복사 / → 오른쪽 패널로 복사** 버튼(우클릭 메뉴에도 있음)은 선택 항목을 해당 패널의 현재 폴더로 바로 복사합니다(같은 이름이 있으면 덮어쓰기/건너뛰기를 물음).
- 우클릭 메뉴: 열기 · 왼쪽 패널에서 열기(파일이면 그 파일이 있는 폴더) · 복사 · 왼쪽/오른쪽 패널로 복사.
- 검색 중에는 **중지** 로 취소, **결과 지우기** 로 목록을 비웁니다. ✕, 닫기 또는 Esc 로 닫습니다.

## 6. 테마 · 언어 · 정보

툴바 오른쪽:

- **🎨 테마 이름** — 클릭하면 다음 테마로 바뀝니다. 옆의 **▾** 를 누르면 16가지 테마 목록에서 고릅니다.
  (미드나이트 · 데이라이트 · 그라파이트 · 오션 · 포레스트 · 선셋 · 고대비 · 노르드 · 드라큘라 · 솔라라이즈드 다크/라이트 · 모노카이 · 로즈 · 라벤더 · 민트 · 커피)
- **국기** — 전환할 언어의 국기가 표시됩니다. 한국어일 때 🇬🇧(영어로), 영어일 때 🇰🇷(한국어로).
- **⚙ 설정** — **일반** 탭: 언어, 테마, 글꼴 크기, 분할 압축 기본 크기, 숨김 파일 표시, 삭제 전에 확인, 시작할 때 마지막 폴더 복원(끄면 홈에서 시작), 폴더 변경 자동 새로고침. **터미널** 탭: 기본 셸, 시작 디렉터리(→ 7장).
- **ⓘ 정보** — 버전, 빌드 시각, 실행 환경(데스크톱/웹).

팝업 창의 **닫기**(제목줄의 ✕ 와 닫기 버튼)는 마우스를 올리면 붉게 표시됩니다.

## 7. 하단 패널: 로그와 터미널

파일 목록 아래의 하단 패널은 탭으로 되어 있습니다. 첫 탭은 항상 **로그**, 그 뒤로 여는 만큼 **터미널** 탭이 붙습니다.
툴바의 **터미널** 버튼, **보기 › 하단 패널**, 또는 ``Ctrl+` `` 로 열고 닫으며, 오른쪽 끝의 ✕ 로도 닫힙니다.
위쪽 가장자리를 드래그하면 높이가 바뀝니다(저장됨).

### 로그

상태 표시줄에 잠깐 지나가는 모든 메시지(복사·이동·삭제·압축 결과, 검색, 터미널 시작/종료 …)와 오류 팝업의 내용이 시각과 함께 쌓입니다.
오류는 붉게 표시되고, 로그 탭이 보이지 않는 동안 오류가 생기면 탭 이름 옆에 붉은 점이 찍힙니다.
**로그 복사**는 전체 내용을 클립보드로(한 줄에 ISO 시각 · 수준 · 메시지), **로그 지우기**는 비웁니다. 최근 2,000줄을 유지합니다.

### 터미널

MyEditor 의 터미널 패널과 같은 콘솔입니다.

**열기** — **+** 를 누르면 활성 패널의 현재 폴더에서 기본 셸이 시작됩니다. 옆의 **▾** 로 이번 한 번만 다른 셸을 고를 수 있습니다:
Windows — PowerShell · Command Prompt · PowerShell 7(설치된 경우) · Git Bash(설치된 경우), macOS/Linux — 로그인 셸 · bash · zsh · sh.
``Ctrl+Shift+` `` 은 기본 셸로 새 터미널을 엽니다. 터미널은 몇 개든 열 수 있고, 각 탭은 서로 독립된 셸 프로세스입니다.
탭의 **×**(또는 가운데 버튼 클릭)로 닫으면 셸 프로세스가 종료됩니다. 셸 프로세스가 끝나면(오류 등; `exit` 는 셸이 아니라 그 명령의 스크립트만 끝냄) 탭이 기울임꼴로 바뀌고 더는 입력할 수 없습니다.

**설정** — **설정 › 터미널** 탭에서 **기본 셸**과 **시작 디렉터리**를 정합니다. 시작 디렉터리를 비우면 활성 패널에 열린 폴더에서, 지정하면 항상 그 폴더에서 시작합니다(데스크톱에서는 **찾아보기…** 로 선택, 웹에서는 경로 입력). 지정한 폴더가 없으면 활성 패널 폴더로 대신하고 로그에 남깁니다.

**프롬프트** — 출력 끝에 oh-my-posh 스타일 프롬프트가 그려지고 그 바로 뒤에서 명령을 입력합니다(터미널 영역을 클릭하면 입력 위치가 잡힘):

| 세그먼트 | 뜻 |
|---|---|
| `📁 D:\Home\…` (테마 강조색) | 셸의 현재 폴더 전체 경로 |
| `⎇ main ↑ + ~ ?` | Git 저장소 안일 때만(MyEditor 의 터미널과 같은 규칙). 브랜치 이름(분리된 HEAD 는 `(detached)`)부터 한 블록이 **저장소 상태의 색**으로 칠해집니다 — 먼저 해당하는 것: 충돌 **진홍** · add 됨 **노랑** · 수정됨 **빨강** · 커밋됨(푸시 전) **노랑** · 원격에 새 커밋(pull 필요) **파랑** · 변경 없음·푸시됨 **밝은 녹색**. 추적 안 함 파일은 색에 영향을 주지 않습니다(git 이 아직 모르는 새 파일이라 `?` 기호로만 표시 — 그렇지 않으면 커밋·푸시를 마쳐도 계속 빨강일 테니까요). 브랜치 뒤에는 해당하는 상태의 기호가 굵게, 숫자 없이: `↑` 앞선 커밋 · `↓` 뒤진 커밋 · `+` add 됨 · `~` 수정됨 · `?` 추적 안 함 · `!` 충돌. 마우스를 올리면 상태와 개수가 툴팁으로 |

예: 파일을 고치면 빨강 `main ~`, add 하면 노랑 `main +`, commit 하면 노랑 `main ↑`, push 하면 녹색 `main`. 세그먼트에 마우스를 올리면 상태 설명과 개수(앞선/뒤진 커밋, 스테이지, 수정, 추적 안 함, 충돌)가 툴팁으로 보입니다.
프롬프트는 명령이 끝날 때마다, `cd` 로 폴더가 바뀔 때마다 갱신되고(같은 폴더면 먼저 마지막 상태로 즉시 그려진 뒤 새 상태가 다르면 색만 바뀜), 실행한 명령은 그 순간의 프롬프트와 함께 기록에 남습니다. 서브모듈 안에서 바뀐 파일(빌드 산출물 등)은 세지 않습니다 — 서브모듈이 다른 커밋을 가리키게 된 경우만 '수정됨'입니다. 출력의 ANSI 색(예: `ls --color`)도 그대로 표시됩니다.

**입력** —

| 키 | 동작 |
|---|---|
| Enter | 실행 |
| Tab | 자동 완성 — 첫 단어는 셸 내장 명령 + PATH 의 실행 파일, 그 밖의 단어는 파일·폴더 이름. 후보가 하나면 바로 채우고(파일·명령 뒤엔 공백, 폴더 뒤엔 없이 이어서), 여럿이면 공통 부분까지 채우며, 더 채울 게 없으면 후보를 아래에 나열 |
| ↑ ↓ | 이전 / 다음 명령 |
| Ctrl+L, `clear`, `cls` | 화면 지우기 |
| Esc | 입력 취소 |
| Ctrl+C | 출력에서 드래그해 선택한 글자 복사 |

여러 줄을 붙여넣으면 줄마다 차례로 실행됩니다. 기록은 최근 10,000줄을 유지하므로 긴 `git log` 도 위로 스크롤해 다 볼 수 있습니다.

**실행 중** — 명령이 실행되는 동안에는 프롬프트가 사라지고, 그동안 치는 줄은 Enter 로 그 프로그램의 입력(stdin)으로 들어갑니다 —
`Read-Host`, `read`, `set /p`, `python`, `npm init` 같이 묻는 프로그램에 답할 수 있습니다. 명령이 끝나면 프롬프트가 돌아옵니다.

**한계** — 터미널은 의사 터미널(pty)이 아니라 **줄 단위 콘솔**입니다. `vim` `top` `less` 같은 전체 화면 프로그램, 비밀번호 가리기, `Ctrl+C` 중단은 되지 않습니다(끝나지 않는 명령은 탭을 닫아 중단). 대신 한글 파일명·경로·입력이 Windows 의 세 셸 모두에서 그대로 동작합니다.
각 명령은 셸이 읽어 들이는(source) 작은 스크립트 파일로 실행되므로 `cd`, 변수, 함수 정의는 셸에 남습니다. `exit` 는 셸이 아니라 그 스크립트만 끝냅니다.
웹 버전에서는 터미널이 **서버 컴퓨터**에서 실행되며 셸 목록도 서버 OS 기준입니다.

## 8. 오류가 났을 때

모든 오류는 팝업으로 표시됩니다: 메시지와 **자세한 내용**(오류 코드, 경로, 발생한 프로세스의 스택).
**자세한 내용 복사** 를 누르면 전체 내용이 클립보드로 복사되어 그대로 붙여넣어 문의할 수 있습니다.

## 9. 웹 버전

```bash
npm run web                    # http://127.0.0.1:5186
```

브라우저 안에서 같은 화면이 뜨며, **서버가 실행되는 컴퓨터**의 파일을 관리합니다. 차이점:

- 더블클릭 / Enter 로 여는 파일은 **서버 컴퓨터**에서 기본 앱으로 실행됩니다. 기본값(127.0.0.1)에서는 바로 동작하고, 다른 인터페이스에 바인딩할 때는 `--allow-open`(또는 `CC_ALLOW_OPEN=1`)을 줘야 켜집니다.
- 휴지통은 서버가 Linux/macOS 일 때만 동작합니다(Windows 서버는 삭제만).
- 폴더 변경 감지는 2초 간격 폴링입니다. 터미널 출력은 롱폴링으로 생기는 즉시 전달됩니다.
- 터미널은 서버 컴퓨터의 셸입니다. 다른 PC 에 공개할 때는 반드시 `--token` 을 쓰세요 — 터미널은 서버에서 임의의 명령을 실행합니다.
- 다른 PC 에서 접속하려면 `--host 0.0.0.0 --token 비밀값` 으로 실행하고 `http://서버:포트/?token=비밀값` 으로 엽니다.

## 10. 설정 파일

| 환경 | 위치 |
|---|---|
| Windows | `%APPDATA%\Command Center\session.json` |
| macOS | `~/Library/Application Support/Command Center/session.json` |
| Linux | `~/.config/Command Center/session.json` |
| 웹 서버 | `~/.config/CommandCenter/session.json` (Windows: `%APPDATA%\CommandCenter`) |

좌/우 경로, 분할 위치, 정렬, 테마, 언어, 숨김 파일 표시, 글꼴 크기, 삭제 확인, 분할 기본 크기, 마지막 폴더 복원, 자동 새로고침, 창 위치, 하단 패널 표시 여부와 높이, 터미널 기본 셸과 시작 디렉터리가 저장됩니다.
