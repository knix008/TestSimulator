# Command Center — 기능 명세 (2026-09-16 기준)

> 본 문서는 구현된 기능의 인벤토리입니다. 새 기능이 추가되면 함께 갱신합니다.

Windows · macOS · Linux · 웹용 듀얼 패널 파일 관리자 **Command Center V1.0** 에 현재 구현되어 있는 기능의 전체 목록입니다.
사용법은 [UsersGuide.md](UsersGuide.md), 내부 구조는 [Architecture.md](Architecture.md)를 보세요.

## 1. 화면 구성

| 요소 | 내용 |
|---|---|
| 메뉴바 | 파일(F) · 편집(E) · 선택(M) · 보기(V) · 압축(C). 제목과 모든 항목에 아이콘, 단축키 표시, 상황에 따라 비활성 |
| 툴바 | **아이콘 전용 버튼 + 툴팁**(레이블 없음). 실행 취소 · 다시 실행 │ 보기 · 편집 │ 새 폴더 · 새 파일 │ 복사 · 이동 · 이름 바꾸기 · 다중 이름 바꾸기 · 삭제 · 휴지통 │ 클립보드 복사 · 붙여넣기 │ 압축 · 압축 해제 │ 검색 · 폴더 비교 · 패널 바꾸기 · 새로고침 · 숨김 파일 · 속성 │ 터미널 … 테마(분할 버튼) · 언어(국기) · 설정 │ 정보. 선택 상태에 따라 버튼이 비활성화되고, 토글 버튼(숨김 파일·터미널)은 켜짐 표시 |
| 듀얼 패널 | 좌/우 패널, 활성 패널 테두리 강조, 분할선 드래그(20~80 %), `Tab` 으로 전환 |
| 창 최소 크기 | 1000 × 600 — 툴바의 모든 버튼이 한국어/영어 어느 쪽에서도 가려지지 않는 폭. 언어를 바꿔도 창 크기는 변하지 않음 |
| 패널 경로 표시줄 | 드라이브 버튼(모든 드라이브/볼륨 — 종류 아이콘 · 이름 · 여유/전체 용량) · 홈 · **폴더 기록(🕘)** · **즐겨찾기(★)** · 패널 이름(→ 폴더 트리) · 빵부스러기 경로 |
| 파일 목록 | 이름 · 권한 · 수정일 · 종류 · 크기 열, 열 머리글 정렬(폴더 우선, `..` 고정, 자연 정렬), 커서와 다중 선택, 숨김 파일 흐리게, 폴더 변경 자동 새로고침(데스크톱: 파일 감시, 웹: 2초 폴링) |
| 패널 상태줄 | 폴더/파일 수와 합계 크기, 선택 시 선택 항목의 수와 크기(Space 로 잰 폴더 크기 포함) |
| 펑션 키 바 | 창 아래 `F3 보기 · F4 편집 · F5 복사 · F6 이동 · F7 새 폴더 · F8 삭제 · Alt+F4 종료` (보기 메뉴에서 숨김 가능) |
| 하단 패널 | 로그 탭 + 터미널 탭(``Ctrl+` ``), 위 가장자리 드래그로 높이 조절 |
| **별도 창** | 보기(F3) · 편집(F4) · 다중 이름 바꾸기(Ctrl+M) · 검색(F9) · 설정은 **독립된 창**으로 열립니다 — 위치·크기를 자유롭게 바꾸고(종류별로 기억), 여러 개 동시에 열 수 있으며, 프로그램을 끝내면 함께 닫힙니다. 설정 › 창에서 끄면 앱 안의 대화상자로 열립니다. 웹 버전은 브라우저 팝업 창(팝업 허용 필요) |
| 상태 표시줄 | 마지막 상태 메시지 (로그에도 기록) |

## 2. 이동

| 기능 | 조작 |
|---|---|
| 폴더 열기 / 상위 폴더 | 더블클릭 · Enter / `..` · Backspace · Ctrl+PgUp |
| 드라이브 루트 | Ctrl+\ |
| 드라이브 목록 | 드라이브 버튼, Alt+F1(왼쪽) · Alt+F2(오른쪽) |
| 홈 폴더 | 🏠 버튼 |
| 빵부스러기 | 경로 조각 클릭으로 바로 이동 |
| 폴더 트리 | 패널 이름 클릭 — 홈 · 드라이브/루트 · /tmp · 마운트 볼륨이 루트, 현재 폴더까지 자동 펼침 |
| 폴더 기록 | 🕘 버튼 · Alt+↓ — 패널별 최근 30개 |
| 즐겨찾는 폴더 | ★ 버튼 · Ctrl+D — 현재 폴더 추가/제거, 양쪽 패널 공유, 세션에 저장 |
| 패널 바꾸기 | Ctrl+U — 좌/우 폴더(정렬 포함) 교환 |
| 대상 = 원본 | Ctrl+← / Ctrl+→ — 커서의 폴더(폴더가 아니면 현재 폴더)를 왼쪽/오른쪽 패널에 열기 |
| 빠른 검색 | 패널에서 글자 입력 → 그 글자로 시작하는 항목으로 커서 이동(입력 중인 글자 표시, 1.2초 후 초기화, Backspace 로 지움) |
| 새로고침 | Ctrl+R · 툴바 · 보기 메뉴 |

## 3. 선택

| 기능 | 조작 |
|---|---|
| 단일 / 다중 선택 | 클릭, Ctrl+클릭(토글), Shift+클릭(범위), 방향키 · Shift+방향키 |
| 커서 항목 토글 | **Insert**(토글 후 한 칸 아래), **Space**(토글) |
| 폴더 크기 계산 | **Space** 를 폴더에서 누르면 하위 합계를 계산해 `<DIR>` 대신 크기를 표시 |
| 패턴으로 선택 / 해제 | **Num +** / **Num −** (일반 키보드의 `+` `−` 도 가능) — `*.txt;*.md` 형태, 마지막 패턴 기억 |
| 선택 반전 | **Num \*** |
| 모두 선택 / 모두 해제 | Ctrl+A · Ctrl+Num + / Ctrl+Num − |
| 같은 확장자 선택 / 해제 | Alt+Num + / Alt+Num − |
| 폴더 비교 | **Shift+F2** — 양쪽 패널에서 상대편에 없거나, 크기가 다르거나, 더 새로운(2초 이상) 파일을 선택. 결과 개수를 상태줄에 표시 |

## 4. 파일 작업

| 기능 | 조작 | 비고 |
|---|---|---|
| 반대 패널로 복사 | F5 · 툴바 · 메뉴 | 같은 이름이 있으면 덮어쓰기/건너뛰기/취소(+ 이후 항목에도 적용), 폴더는 병합 |
| 반대 패널로 이동 | F6 | 같은 드라이브는 즉시, 다른 드라이브는 복사 후 삭제 |
| 새 폴더 / 새 파일 | F7 / Shift+F4 | 이름 입력(파일은 확장자 앞부분 선택) |
| 이름 바꾸기 | F2 · Shift+F6 | 대소문자만 바꾸기 가능(Windows) |
| **다중 이름 바꾸기** | Ctrl+M | § 5 참고 |
| 삭제 | F8 · Delete | 확인 후 **영구 삭제**(설정에서 확인 끔 가능) |
| 휴지통으로 이동 | 컨텍스트 메뉴 · 툴바 | 데스크톱 전 OS, 웹은 Linux/macOS 서버만 |
| 클립보드 복사 / 붙여넣기 | Ctrl+C / Ctrl+V | `file://` URI 목록으로 복사, 탐색기/Finder 에서 복사한 경로 목록도 붙여넣기 가능 |
| 열기 | Enter · 더블클릭 | 시스템 기본 앱(분할 압축 파일은 자동 결합 해제). 웹은 `--allow-open` 필요. Electron 의 열기가 실패하는 연결(Windows 11 스토어 앱 등)은 셸 명령(PowerShell `Invoke-Item` / `open` / `xdg-open`)으로 다시 시도 |
| 텍스트 파일 열기 규칙 | 설정 › 파일 열기 | 확장자 목록에 있는 텍스트 파일은 **시스템 기본 프로그램 / 내장 뷰어 / 내장 편집기 / 지정한 프로그램**(찾아보기로 선택) 중 설정한 방법으로 열림 |
| **보기** | F3 | § 6 내장 뷰어 |
| **편집** | F4 | § 6 내장 편집기 |
| 속성 | Alt+Enter · 메뉴 | 이름 · 경로 · 종류 · 크기(폴더는 하위 합계와 개수) · 수정일 · 권한 · 링크 대상 |
| 진행률 창 | 모든 긴 작업 | 현재 항목 · % · 취소. 작업 중 자동 새로고침 일시 정지 |

### 실행 취소 / 다시 실행

| 항목 | 내용 |
|---|---|
| 조작 | Ctrl+Z / Ctrl+Y(Ctrl+Shift+Z) · 툴바 ↶ ↷ · 편집 메뉴. 툴팁과 상태줄에 되돌릴 작업이 표시됨 |
| 되돌릴 수 있는 작업 | 새 폴더 · 새 파일 · 이름 바꾸기 · 다중 이름 바꾸기 · 복사 · 붙여넣기 · 이동 · 압축 · 압축 해제 (최근 50개) |
| 규칙 | 복사/압축/해제의 되돌리기는 그 작업이 **만든** 항목만 영구 삭제("삭제 전에 확인" 설정 존중). 새 폴더/파일은 비어 있으면 바로, 내용이 생겼으면 확인. 덮어쓰기·병합된 항목, 영구 삭제, 휴지통 이동은 되돌릴 수 없음(다시 실행 목록만 비움). 되돌리기가 실패하면 그 항목은 목록에서 제거되고 오류 팝업 |

## 5. 다중 이름 바꾸기 (Ctrl+M)

| 항목 | 내용 |
|---|---|
| 이름 마스크 / 확장자 마스크 | `[N]` 이름 전체, `[N2-5]` 2~5번째 글자, `[N3-]` 3번째부터 끝, `[N4]` 4번째 글자, `[E]` 확장자, `[C]` 카운터, `[P]` 상위 폴더 이름 (버튼으로 삽입) |
| 찾기 / 바꾸기 | 일반 문자열 또는 정규식, 대소문자 무시 옵션 |
| 카운터 | 시작 · 증가 · 자릿수 |
| 대소문자 | 그대로 · 소문자 · 대문자 · 첫 글자만 대문자 · 단어마다 첫 글자 대문자 |
| 미리보기 | 기존 이름 → 새 이름 실시간 표시, 바뀌는 항목 강조, 중복/잘못된 이름 표시 시 시작 버튼 잠금 |
| 실행 | 임시 이름을 거치는 **2단계 이름 변경**(`a↔b` 맞바꾸기 가능), 실패 시 롤백, 전체가 실행 취소 1회 |

## 6. 내장 뷰어 · 편집기

### 뷰어 (F3)

| 항목 | 내용 |
|---|---|
| 텍스트 | UTF-8 · UTF-8 BOM · UTF-16 LE/BE · Latin-1 자동 감지, 줄 수·크기 표시, 줄 바꿈 토글(Ctrl+W), 16진수 보기 토글(Ctrl+H), 8 MB 까지(초과 시 앞부분만) |
| 이미지 | png · jpg · gif · webp · bmp · svg · ico · avif, 창 맞춤 / 원본 크기, 24 MB 까지 |
| 이진 파일 | 16진수 덤프(오프셋 · 바이트 · ASCII), 256 KB 까지 |
| 버튼 | 연결 프로그램으로 열기 · 편집(F4 → 편집기로 전환) · 닫기(F3 · Esc) |

### 편집기 (F4)

| 항목 | 내용 |
|---|---|
| 편집 | 고정폭 텍스트 영역, Tab 입력 유지, 줄 수·크기 실시간 표시 |
| 저장 | Ctrl+S · 저장 버튼 — 항상 UTF-8(원본이 다른 인코딩이면 안내), 저장 후 패널 새로고침 |
| 닫기 | 저장하지 않은 변경이 있으면 버릴지 확인 |
| 제한 | 텍스트 파일만, 8 MB 이하 |

## 7. 압축

| 항목 | 내용 |
|---|---|
| 생성 | `.tar.gz` · `.tar.bz2` · `.zip` (Alt+F5 · 압축 메뉴 · 툴바 · 컨텍스트 메뉴), 파일 이름·형식 선택 |
| 분할 압축 | 분할 크기 지정(KB/MB/GB, 기본 10 MB, 설정 가능). zip → `.zip` `.z01` `.z02` …, tar.gz → `.tgz` `.tgz.001` …, tar.bz2 → `.tbz2` `.tbz2.001` … (GTK 판과 호환) |
| 해제 | Alt+F9 · 메뉴 · 분할 파일 더블클릭. `.tar.gz` `.tgz` `.tar.bz2` `.tbz2` `.tar` `.zip` `.gz` `.bz2`, 분할 조각 자동 결합, GNU `split` 조각(`.aa` `.ab` …) 인식, ZIP 한글 파일명(EUC-KR) 복원 |
| 구현 | tar 자체 구현(pax 헤더), bzip2 는 워커 스레드, 모든 작업 진행률·취소 |

## 8. 검색 (F9)

| 항목 | 내용 |
|---|---|
| 창 | 별도 창(제목줄 드래그, 열어 둔 채 패널 사용 가능) |
| 조건 | 활성 패널 폴더와 하위 전체, 이름 패턴(`*.txt`), 파일 내용 문자열 |
| 결과 | 진행 중 개수 표시, 중지, 결과 지우기. Enter/더블클릭 — 폴더는 왼쪽 패널에 열기, 파일은 기본 프로그램 실행. 여러 개 선택해 Ctrl+C(패널에 Ctrl+V), 버튼/우클릭으로 왼쪽·오른쪽 패널 폴더에 바로 복사 |

## 9. 하단 패널: 로그 · 터미널

| 항목 | 내용 |
|---|---|
| 로그 탭 | 모든 상태 메시지와 오류가 시각과 함께 누적(최근 2,000줄), 복사 · 지우기 |
| 터미널 탭 | 여러 개 열기(Ctrl+Shift+`), Windows: PowerShell · Command Prompt · PowerShell 7 · Git Bash, macOS/Linux: 로그인 셸 · bash · zsh · sh. 활성 패널 폴더 또는 설정한 시작 디렉터리에서 시작 |
| 프롬프트 | oh-my-posh 스타일 `[📁 경로]▶[⎇ 브랜치 ↑↓ + ~ ? !]▶`, git 상태 색상(충돌 · add 됨 · 수정됨 · pull 필요 · 변경 없음) |

| 한계 | 줄 단위 콘솔(pty 아님) — 전체 화면 프로그램 · 비밀번호 가리기 · Ctrl+C 중단 불가 |

## 10. 테마 · 언어 · 설정

| 항목 | 내용 |
|---|---|
| 테마 | 16가지(툴바 분할 버튼: 클릭 = 다음 테마, ▾ = 목록과 색 견본; 툴팁에 현재/다음 테마) |
| 언어 | 한국어 / English — 전환할 언어의 국기 버튼, 모든 UI · 툴팁 · 메시지 |
| 설정 — 즉시 적용 | 값을 바꾸는 순간 바로 적용됩니다(확인 = 유지, 취소 = 원래 값으로 복원). 기본값 버튼 |
