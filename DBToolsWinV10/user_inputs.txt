[DBToolsWinV10 프로젝트 - 사용자 입력 내역]
==============================================

[1]
DB의 테이블을 설계하는 도구를 만들고 싶습니다. C#으로 구현해야 하고, 모든 GUI항목들을 전부 Visual Studio 2026 Designer에서 편집할 수 있어야 합니다.
- WinForms 기반 (.NET 10)
- 좌측: 도구 패널 (ToolBox)
- 중앙: 다이어그램 캔버스 (DiagramCanvas) - 테이블을 시각적으로 배치, 드래그·이동
- 우측: TreeView (상단), MiniMap (중간), PropertyGrid (하단)
- 테이블 간 관계 지원: 1:1, 1:N, N:M (Crow's Foot 표기법)
- 1NF/2NF/3NF 정규화 분석 기능
- SQL DDL 내보내기 및 JSON 직렬화 지원

또한, project 파일을 저장하고 복구할 수 있어야 합니다. 확장자는 mdprj 입니다. 설치해 해당 확장자를 클릭하면 애플리케이션이 자동으로 열려야 합니다.
메뉴와 툴바가 있어야하고, 각각의 메뉴와 툴바에는 아이콘 그림과 같이 보여야 합니다.
모든 메뉴와 툴바 버튼에는 Tooltip도 표시가 되어야 합니다.
파일 메뉴에는 프로젝트 불러오기와 저장, 최근에 사용한 프로젝트 파일들이 10개까지 나열될 수 있어야 합니다.
툴바의 우측에는 프로그램의 정보를 표현하는 버튼이 있어야 합니다.
