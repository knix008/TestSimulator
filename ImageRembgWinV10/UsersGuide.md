# Image Rembg 사용자 가이드

Image Rembg는 이미지에서 객체를 분리하고 배경을 제거하는 Windows 프로그램입니다. rembg AI 또는 OpenCV 알고리즘을 선택해 사용할 수 있습니다.

## 시작하기

### 프로그램 실행

- 설치한 경우: 시작 메뉴 또는 바탕화면의 **Image Rembg** 바로가기 실행
- 개발 환경: `dotnet run`으로 실행

### 첫 실행 (rembg2 AI, 기본 알고리즘)

기본 알고리즘 **rembg2 (AI, RMBG-2.0)** 은 Hugging Face의 라이선스 동의가 필요한 모델이라 자동으로 다운로드되지 않습니다.

1. [briaai/RMBG-2.0 (onnx)](https://huggingface.co/briaai/RMBG-2.0/tree/main/onnx)에서 라이선스(비상업적 용도)에 동의한 뒤 onnx 파일을 받습니다.
2. **알고리즘** 메뉴/툴바에서 rembg2를 선택하면 모델이 없다는 안내 대화상자가 표시됩니다. **예**를 누르고 받은 파일을 선택하면 `%LOCALAPPDATA%\ImageRembgWinV10\models\rembg2.onnx`로 자동 복사됩니다 (관리자 권한 불필요, MSI로 설치한 경우에도 동작).
3. 직접 배치하려면 위 경로에 "rembg2.onnx"로 저장하거나, (개발/포터블 빌드에서만) `Assets\Models\rembg2.onnx`에 저장해도 인식됩니다 (자세한 안내는 `Assets\Models\README.txt`).
4. 처음 추론을 실행할 때 모델을 메모리에 올리는 동안 **진행률 대화상자**가 표시됩니다 (모델이 커서 다소 시간이 걸릴 수 있습니다).

### rembg (U2Net) — 보조 알고리즘

**알고리즘** 메뉴 또는 툴바에서 **rembg (AI, U2Net)** 로 전환하면 처음 **외곽선 미리보기** 또는 **배경 제거** 시 AI 모델(약 176MB)을 자동으로 다운로드합니다.

- 상태 표시줄과 진행률 대화상자에 다운로드 진행률이 표시됩니다.
- 인터넷 연결이 필요합니다.
- 이후에는 캐시된 모델을 사용하므로 다시 다운로드하지 않습니다.

오프라인 환경에서는 `Assets\Models\README.txt` 안내에 따라 `u2net.onnx` 파일을 직접 배치할 수 있습니다.

### UI 언어

- **파일 → 환경설정...** 에서 **한국어** 또는 **English**를 선택합니다.
- 선택한 언어는 `%LOCALAPPDATA%\ImageRembgWinV10\settings.json`에 저장되며, 다음 실행 시 자동 적용됩니다.
- 메뉴, 툴바, 상태 표시줄, 대화상자 등 UI 전체에 즉시 반영됩니다.

## 기본 작업 흐름

```
이미지 열기 → 영역 선택 → 외곽선 미리보기 → 배경 제거 → 저장
```

### 1. 이미지 열기

- **파일 → 열기** (`Ctrl+O`) 또는 툴바 **열기** 버튼
- 지원 창에 이미지 파일을 **드래그 앤 드롭**

**지원 형식:** WebP, AVIF, PNG, GIF, JPEG, BMP, TIFF, HEIC, HEIF

### 2. 영역 선택

1. **자유 선택** 또는 **사각형 선택** 모드 선택 (툴바 또는 **도구** 메뉴)
2. 객체를 포함하도록 이미지 위에서 드래그 (자유 선택은 윤곽을 따라 그리고, 사각형 선택은 드래그로 박스를 만듦)
3. 선택 영역은 화면에 점선 외곽선으로 표시됩니다.
4. 두 도구를 **번갈아 사용**하면 영역이 합쳐집니다 — 여러 객체를 한 번에 선택한 뒤 배경 제거를 실행하면 선택한 모든 영역에 대해 함께 처리됩니다.
5. 처음부터 다시 선택하려면 **초기화** 또는 **실행 취소**(`Ctrl+Z`)를 사용하세요.

> AI 알고리즘(rembg2, rembg)은 전체 이미지를 분석하지만, 선택 영역 안의 결과만 사용합니다. 여러 객체가 있을 때 원하는 대상만 지정하는 데 유용합니다.

### 3. (선택) 전/배경 표시

결과를 더 정확하게 조정하려면:

| 모드 | 용도 |
|------|------|
| **전경 표시(녹색)** | 반드시 남겨야 할 부분 클릭 |
| **배경 표시(적색)** | 제거해야 할 배경 부분 클릭 |

OpenCV 알고리즘(GrabCut, 색상 키잉 등)에서 특히 효과적입니다. rembg AI에서도 결과 보정에 사용할 수 있습니다.

### 4. 외곽선 미리보기

- **편집 → 외곽선 미리보기** 또는 툴바 **외곽선 미리보기** 버튼
- 객체 외곽선과 마스크가 화면에 표시됩니다.
- 결과가 마음에 들지 않으면 영역·표시 점·알고리즘을 바꾼 뒤 다시 미리보기하세요.

### 5. 배경 제거

- **편집 → 배경 제거** 또는 툴바 **배경 제거** 버튼
- 미리보기 없이 실행하면 확인 대화상자가 나타납니다.
- 완료 후 **결과 보기** 체크박스로 원본/결과를 전환할 수 있습니다.

### 6. 저장

- **파일 → 저장** (`Ctrl+S`) 또는 툴바 **저장** 버튼

| 형식 | 배경 처리 |
|------|-----------|
| PNG, WebP, GIF, TIFF | 투명 배경 |
| JPEG, BMP | 흰색 배경 |

## 알고리즘 선택

**알고리즘** 메뉴 또는 툴바 콤보박스에서 선택합니다.

| 알고리즘 | 설명 | 추천 상황 |
|----------|------|-----------|
| **rembg2 (AI, RMBG-2.0)** *(기본)* | RMBG-2.0 딥러닝 모델 (별도 모델 파일 필요) | 사람·제품·사물 등 일반 사진, 비상업적 용도 |
| **rembg (AI, U2Net)** | rembg U2Net 딥러닝 모델 | 사람, 제품 등 일반 사진 |
| **GrabCut (범용)** | 영역·전/배경 표시 기반 | 대화형으로 세밀하게 조정 |
| **색상 키잉** | HSV 색상 기반 | 단색·유사색 배경 |
| **윤곽선 채우기** | Canny 윤곽선 | 외곽선이 뚜렷한 객체 |
| **임계값 (Otsu)** | 명암 이진화 | 전경/배경 대비가 큰 이미지 |

알고리즘을 변경하면 기존 미리보기는 초기화됩니다.

## 실행 취소 / 다시 실행

| 기능 | 단축키 | 위치 |
|------|--------|------|
| 실행 취소 | `Ctrl+Z` | **편집** 메뉴 또는 툴바 |
| 다시 실행 | `Ctrl+Y` | **편집** 메뉴 또는 툴바 |

영역 선택, 전/배경 표시, 외곽선 미리보기, 배경 제거 결과를 포함한 작업을 단계별로 되돌리거나 다시 적용할 수 있습니다.

## 초기화

**편집 → 초기화** 또는 툴바 **초기화**로 선택 영역, 표시 점, 미리보기, 결과를 모두 지웁니다. 열린 이미지는 유지됩니다. (실행 취소 기록은 별도로 유지되며, 초기화 자체도 실행 취소할 수 있습니다.)

## 오류 발생 시

오류 대화상자에 요약과 상세 내용이 표시됩니다.

- **내용 복사** 버튼으로 오류 정보를 클립보드에 복사할 수 있습니다.
- rembg 모델 다운로드 실패: 네트워크 연결 확인 후 재시도
- 객체를 찾지 못함: 선택 영역 확대, 다른 알고리즘 시도, 전/배경 표시 추가

## MSI 설치 (관리자용 요약)

Visual Studio에서 **`ImageRembgWinV10.sln`** 을 **Release**로 **솔루션 빌드**하면 MSI가 생성됩니다. 자세한 방법은 [INSTALLER.md](INSTALLER.md)를 참고하세요.

설치 마법사 **기능 선택** 화면에서 다음을 선택할 수 있습니다.

- **Start Menu shortcut** — 시작 메뉴 바로가기
- **Desktop shortcut** — 바탕화면 바로가기

| 항목 | 내용 |
|------|------|
| 기본 MSI | **한국어** — `ImageRembgWinV10.Installer\bin\x64\Release\ImageRembgWinV10.msi` |
| English MSI | `ImageRembgWinV10.en-US.msi` (같은 폴더) |
| 설치 위치 | `Program Files\Image Rembg` |
| 런타임 | .NET 10 Desktop Runtime (x64) 필요 |

앱 프로젝트만 단독 빌드하면 EXE/DLL만 생성되고 MSI는 만들어지지 않습니다.

## 자주 묻는 질문

### rembg 모델은 어디에 저장되나요?

`%LOCALAPPDATA%\ImageRembgWinV10\models\u2net.onnx`

### rembg2를 선택했는데 오류가 납니다

rembg2(RMBG-2.0)는 라이선스 동의가 필요한 모델이라 자동 다운로드/설치 프로그램에 포함되지 않습니다. [Hugging Face](https://huggingface.co/briaai/RMBG-2.0/tree/main/onnx)에서 라이선스에 동의한 뒤 받은 onnx 파일을, rembg2 선택 시 표시되는 안내 대화상자에서 선택하세요 (자동으로 `%LOCALAPPDATA%\ImageRembgWinV10\models\rembg2.onnx`에 복사됩니다).

### rembg2를 적용하면 프로그램이 멈춘 것처럼 보여요

모델이 커서(500MB 이상) 처음 불러올 때 다소 시간이 걸립니다. 작업은 백그라운드에서 진행되며 진행률 대화상자가 표시됩니다 — 창이 잠시 응답하지 않아도 기다리면 완료됩니다.

### 미리보기 없이 바로 배경을 제거할 수 있나요?

가능합니다. **배경 제거** 시 확인 대화상자에서 **예**를 선택하면 미리보기를 자동 실행한 뒤 배경을 제거합니다.

### HEIC/AVIF 파일이 열리지 않아요

.NET 10 Desktop Runtime과 LibHeif 네이티브 라이브러리가 포함된 빌드를 사용해야 합니다. MSI 또는 `dotnet run`으로 빌드된 프로그램을 사용하세요.

### AI 결과가 선택 영역 밖까지 나옵니다

rembg는 전체 이미지를 분석합니다. 선택 영역과 교차하는 부분만 최종 결과에 반영되므로, 영역을 객체에 맞게 조정해 보세요.

### Release 빌드에서 MSI가 생성되지 않음

- **`ImageRembgWinV10.sln`** 을 연 뒤 **솔루션 빌드** (Release)를 사용하세요.
- [INSTALLER.md](INSTALLER.md)의 문제 해결 표를 참고하세요.
