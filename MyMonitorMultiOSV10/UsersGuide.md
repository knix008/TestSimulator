# MyMonitor MultiOS — 사용자 가이드

CPU, RAM, Disk, Load, Network를 실시간 그래프와 로그로 봅니다.
로컬 PC, 원격 서버/장비(Ethernet · Serial), RTOS 시뮬레이터를 한 창에서 붙일 수 있습니다.

## 설치와 제거

### Windows

루트에 복사된 `MyMonitor-Setup-10.0.0.exe`를 실행합니다.

| 단계 | 내용 |
|---|---|
| 설치 위치 | 원하는 폴더를 고를 수 있습니다 |
| 바로가기 | 바탕화면 · 시작 메뉴 |
| 제거 | Windows 설정 › 앱 › MyMonitor › 제거 |

설치 파일은 빌드할 때 저장소 루트에 **하나만** 둡니다.

### macOS / Linux

- macOS: `MyMonitor-*.dmg`를 열고 Applications로 끕니다.
- Linux: `MyMonitor-*.AppImage`에 실행 권한을 주고 실행합니다.

소스에서 만들 때:

```bash
npm run build:win
npm run build:mac
npm run build:linux
```

## 실행

필요: Node.js 18+ (소스 실행 시), 또는 위 설치 파일.

저장소 루트에서:

```bash
npm start          # Electron 모니터
npm run web        # 브라우저 http://127.0.0.1:9520/
npm run agent      # Windows 에이전트 :9510 수신
```

타이틀 바에는 프로그램 이름과 버전(`MyMonitor MultiOS v10.0.0`)이 같이 보입니다.
메뉴바 왼쪽에는 아이콘/이름을 두지 않습니다.

처음 켜면 **로컬 Agent**가 이 PC 자원을 수집하기 시작합니다.

## 대상 연결

툴바 **연결** 또는 왼쪽 **추가**, 메뉴 **연결 › 연결 추가**.

### 로컬 Agent

이 컴퓨터의 CPU, RAM, Disk, Network를 수집합니다. 툴바 **로컬**과 같습니다.

### Ethernet — TCP 접속

원격에서 에이전트가 `--listen 0.0.0.0:9510`으로 기다리는 경우입니다.

1. 종류: **Ethernet — TCP 접속**
2. 호스트: 대상 IP (예: `192.168.0.20`)
3. 포트: `9510`
4. 프로토콜: 보통 **MMON 바이너리**

### Ethernet — TCP 수신

모니터가 먼저 듣고, 에이전트가 `--connect 모니터IP:9510`으로 붙는 경우입니다.

### Ethernet — HTTP 폴링

에이전트가 `--http 0.0.0.0:9511`로 JSON을 제공하는 경우입니다. 방화벽에서 9511을 허용하세요.

1. 종류: **Ethernet — HTTP 폴링**
2. URL: `http://192.168.0.20:9511/metrics` (경로가 없으면 `/metrics`를 붙입니다)
3. 주기를 정한 뒤 연결

웹 모니터에서도 HTTP는 `fetch`로 동작합니다. CORS는 에이전트가 `Access-Control-Allow-Origin: *`를 보냅니다.

### Serial

UART/COM. 포트와 Baud(기본 115200)를 고르고 프로토콜을 MMON으로 둡니다.
Windows에서 Serial native 모듈이 없어도 TCP/로컬/시뮬레이터는 됩니다.

### 시뮬레이터

실장비 없이 UI를 볼 때 씁니다.

- **RTOS**: heap, tasks, temperature
- **서버**: CPU, RAM, Disk, Load, Network, 프로세스 수

### 연결 종료

대상을 선택한 뒤 툴바 **종료** 또는 대시보드 **연결 종료**.

## 그래프와 카드

선택 대상이 OS/RTOS냐에 따라 카드가 달라집니다.

| 카드 | 서버 | RTOS |
|---|---|---|
| CPU | % | % |
| RAM | used / total | Heap / RAM |
| Disk | used / total | 없는 경우가 많음 |
| Load | 1/5/15분 | — |
| Network | RX/TX 속도 | RX/TX 속도 |
| 기타 | 프로세스, uptime | tasks, temp |

그래프: CPU/Load, Memory/Heap, Disk, Network. 샘플은 시간에 따라 누적됩니다. 화면에 보이는 시간 길이는 툴바 **구간**에서 좌·우 버튼으로 줄이거나 늘리고, 초 단위로 직접 입력할 수도 있습니다. 범위 10–600초. 구간을 바꿔도 이미 쌓인 값은 그대로 두고, 보이는 폭만 바뀝니다. 갱신 주기는 툴바 **주기**에서 좌·우 버튼으로 줄이거나 늘리고, 숫자를 직접 입력할 수도 있습니다. 범위 200–10000 ms. 수집은 백그라운드에서 돌아가므로 주기를 짧게 해도 메뉴·버튼은 바로 반응합니다.

## 설정

툴바 톱니, 또는 파일 › **언어 · 테마 · 주기 · 구간**.
설정은 메인과 별도 창으로 열리며, 제목 표시줄을 드래그해 옮길 수 있습니다. 스크롤바 없이 **일반**과 **테마** 탭으로 나뉩니다. 메인을 가리지 않습니다.

| 항목 | 설명 |
|---|---|
| 언어 | 한국어 / English. 툴바 국기와 같습니다. 영국 국기는 English, 태극기는 한국어로 바꿉니다 |
| 테마 | Dark 10, Light 10. 스와치를 누르면 바로 적용됩니다 |
| 실시간 갱신 주기 | 로컬 · 시뮬레이터 · 원격 구독에 같이 적용. 좌·우 버튼 또는 직접 입력 |
| 그래프 시간 창 | 그래프에 누적해 보여주는 시간. 10–600초. 툴바 **구간**과 같습니다 |

설정은 데스크톱에서는 사용자 데이터 폴더, 웹에서는 브라우저에 남습니다.

## 원격 에이전트

대상 머신에서 C 에이전트를 띄운 뒤 모니터에서 TCP/HTTP/Serial로 붙습니다.

Windows 콘솔:

```bat
npm run agent
```

또는

```bat
agent\windows\listen.bat
```

```bat
agent\windows\http.bat
```

HTTP JSON은 포트 **9511**, 경로 `/metrics`입니다.

이 PC가 모니터로 나가는 경우:

```bat
agent\windows\connect.bat 192.168.0.10:9510
```

Windows 서비스(관리자):

```bat
agent\windows\install-service.bat
agent\windows\uninstall-service.bat
```

서비스 이름: `MyMonitorAgent`, 포트 9510, 자동 시작.

Linux / macOS:

```bash
./agent/build/mmon-agent --listen 0.0.0.0:9510
```

프로토콜만 확인하려면 `--demo`를 붙입니다.

RTOS는 `agent/rtos/README.md`처럼 UART 또는 TCP로 같은 MMON 프레임을 보내면 됩니다.

## 문제 해결

| 증상 | 확인 |
|---|---|
| `npm start`가 루트에서 안 됨 | 이 폴더의 `package.json`에서 실행했는지 |
| Serial 포트가 비어 있음 | `app`에서 native 모듈 설치. TCP/로컬은 그대로 사용 |
| 원격이 안 붙음 | 에이전트가 `:9510` listen인지, 방화벽, 프로토콜이 MMON인지 |
| 주기를 짧게 했더니 화면이 멈춤 | 수집은 백그라운드입니다. 앱을 다시 켠 뒤에도 같으면 로그의 오류를 보세요 |
| 그래프가 멈춤 | 주기 값, 대상이 online인지, 로그의 오류 |
| 웹에서 TCP 오류 | 정상입니다. HTTP, Electron, 또는 시뮬레이터를 사용 |
| 테스트가 오래 걸림 | `npm test`로 전체 확인. 로컬 수집은 즉시 샘플입니다 |

자세한 구조는 [ARCHITECTURE.md](ARCHITECTURE.md), 프레임 형식은 [docs/protocol.md](docs/protocol.md)입니다.
