## 1. 시작하기

프로그램을 실행하면 아래와 같은 화면이 나타납니다.

- **좌측 패널** — 원본 이미지를 표시합니다.
- **우측 패널** — 변환된 ASCII 아트를 표시합니다.
- **하단 설정 패널** — 문자 집합, 출력 크기, 폰트, 변환 옵션을 설정합니다.
- **상태바** — 현재 작업 상태, 이미지 정보, 출력 정보를 표시합니다.

---

## 2. 이미지 불러오기

### 방법 1 — 메뉴 사용
`파일(F)` → `이미지 열기(O)...` 또는 단축키 **Ctrl+O**

### 방법 2 — 툴바 버튼
툴바의 **📂 이미지 열기** 버튼 클릭

### 방법 3 — 드래그 앤 드롭
이미지 파일을 좌측 패널에 직접 끌어다 놓습니다.

### 방법 4 — 더블클릭
좌측 패널을 더블클릭하면 파일 열기 대화상자가 나타납니다.

### 지원 형식
`BMP`, `JPG`, `JPEG`, `PNG`, `GIF`, `TIFF`, `TIF`, `ICO`

---

## 3. 변환 설정

하단 설정 패널에서 4가지 그룹을 조정할 수 있습니다.

### 문자 집합

| 선택지 | 내용 | 용도 |
|--------|------|------|
| **상세 (70단계)** | `$@B%8&WM#*oahkbdpqwm...` | 사진, 복잡한 이미지 |
| **표준 (10단계)** | `@#S%?*+;:,.` | 일반 이미지 (기본값) |
| **단순 (5단계)** | `@#*. ` | 로고, 단순한 그림 |
| **블록 문자** | `█▓▒░ ` | 선명한 블록 스타일 |
| **사용자 정의** | 직접 입력 | 원하는 문자로 표현 |

> **사용자 정의 문자 입력 방법**: 라디오 버튼을 선택하면 입력창이 활성화됩니다.  
> 왼쪽(어두운 문자)부터 오른쪽(밝은 문자/공백) 순서로 입력하세요.  
> 예시: `@#*+:. ` — 7단계 그레이스케일

### 출력 크기

| 항목 | 설명 |
|------|------|
| **너비 (열)** | 출력할 문자 열의 수 (10~500). 숫자가 클수록 세밀한 표현 |
| **높이 (행)** | 출력할 문자 행의 수 (5~500). "자동 조정" 해제 시 활성화 |
| **비율에 맞게 높이 자동 조정** | 체크 시, 원본 이미지 가로세로 비율을 유지하며 높이 자동 계산 |

> 고정폭 폰트는 글자 높이가 너비의 약 2배이므로, 자동 조정 시 높이에 0.45 보정 계수를 적용합니다.

### 출력 폰트

| 항목 | 설명 |
|------|------|
| **폰트** | Consolas, Courier New, NSimSun 등 설치된 고정폭 폰트 선택 |
| **크기** | 출력 텍스트 글자 크기 (0.5~24pt) |
| **컬러 출력** | 체크 시 원본 이미지 색상이 텍스트에 반영됩니다 |

> 블록 문자(█▓▒░)나 특수 기호를 사용할 때는 **NSimSun**, **MS Gothic**, **Consolas** 폰트를 권장합니다.

### 변환 옵션

| 항목 | 설명 |
|------|------|
| **밝기 반전** | 밝은 영역↔어두운 영역을 반전. 흰 배경의 이미지에 유용 |
| **윤곽선 강조** | 이미지의 경계선을 강조하여 변환 |
| **대비** | -100 ~ +100. 오른쪽으로 이동할수록 대비 증가 |
| **밝기** | -100 ~ +100. 오른쪽으로 이동할수록 밝아짐 |

## 4. ASCII 아트 변환

설정 완료 후 아래 방법 중 하나로 변환합니다.

- **키보드**: **F5**
- **버튼**: 하단 우측의 **[변환 (F5)]** 버튼 클릭
- **툴바**: **▶ 변환 (F5)** 버튼 클릭

변환 중 상태바의 진행률이 표시되며, 완료 후 우측 패널에 결과가 나타납니다.

---

## 5. 결과 보기 및 편집

### 글자 크기 조정 (보기 전용)

우측 패널 상단의 버튼으로 출력 텍스트 크기를 조정합니다.

| 버튼 | 단축키 | 설명 |
|------|--------|------|
| **A+ 크게** | Ctrl+= | 글자 크기 +0.5pt |
| **A- 작게** | Ctrl+- | 글자 크기 -0.5pt |
| **초기화** | Ctrl+0 | 설정 패널의 크기로 초기화 |

> 보기 크기 조정은 화면 표시에만 영향을 주며, 내보내기 시에는 설정 패널의 크기가 사용됩니다.

### 편집 모드

기본적으로 결과는 **읽기 전용**입니다. 직접 수정하려면 편집 모드로 전환하세요.

- **키보드**: **F2**
- **메뉴**: `편집(E)` → `편집 모드 켜기/끄기`
- **툴바**: **✏ 편집 모드** 버튼 클릭

편집 모드가 켜지면 상태바에 **편집 가능** (녹색)이 표시됩니다.

## 6. 텍스트 파일 불러오기 및 편집

기존에 저장된 ASCII 아트 텍스트 파일을 불러와 편집할 수 있습니다.

1. `파일(F)` → `텍스트 파일 열기(T)...` 또는 **Ctrl+Shift+O**
2. `.txt` 또는 `.asc` 파일을 선택합니다.
3. 파일이 로드되면 자동으로 **편집 모드**가 활성화됩니다.
4. 우측 패널에서 직접 내용을 수정합니다.
5. 수정 후 **Ctrl+S** 로 저장합니다.

> 모든 유니코드 문자(한글, 특수기호, 블록문자 등)는 **UTF-8** 인코딩으로 처리됩니다.  
> 블록 문자(█▓▒░) 등이 깨져 보이면 폰트를 **NSimSun** 또는 **MS Gothic** 으로 변경해 보세요.

## 7. 저장 및 내보내기

### 텍스트로 저장

`파일(F)` → `텍스트로 저장(S)...` 또는 **Ctrl+S**

- 형식: `.txt`, `.asc`
- 인코딩: UTF-8

### 내보내기

`파일(F)` → `내보내기(E)` 하위 메뉴에서 선택합니다.

| 형식 | 설명 |
|------|------|
| **HTML** | 웹 브라우저에서 볼 수 있는 HTML 파일. 컬러 출력 정보가 포함됩니다. |
| **PDF** | 문서 공유용 PDF 파일. 흑백 고정폭 레이아웃으로 저장됩니다. |
| **Word (.docx)** | Microsoft Word에서 편집 가능한 문서 파일로 저장됩니다. |
| **이미지** | ASCII 아트를 PNG, BMP, JPEG 이미지로 렌더링하여 저장합니다. |

> 마지막으로 사용한 저장 디렉토리가 기억되어 다음 번 저장 시 자동으로 해당 경로가 열립니다.

## 9. 상태바 안내

화면 맨 아래 상태바에는 5가지 정보가 표시됩니다.

| 영역 | 표시 내용 |
|------|---------|
| **메시지** | 현재 작업 상태 ("변환 완료", "저장 완료" 등) |
| **이미지 정보** | 원본 이미지 크기 (예: `이미지: 1920×1080px  2.3MB`) |
| **출력 정보** | ASCII 아트 행×열 (예: `출력: 60행 × 120열`) |
| **편집 모드** | `읽기 전용` (회색) 또는 `편집 가능` (녹색) |
| **파일명** | 현재 열려 있는 파일 이름 |

## 10. 문제 해결

### 블록 문자(█▓▒░)가 깨져 보입니다
출력 폰트를 **NSimSun**, **MS Gothic**, **Consolas** 중 하나로 변경하세요.  
글자 크기를 키우면 더 선명하게 보입니다.

### 결과가 너무 크거나 작습니다
- **너비** 값을 줄이거나 늘려서 조정하세요.
- 기본값 120열이 대부분의 경우에 적합합니다.
- 매우 큰 이미지는 변환 시간이 길어질 수 있습니다.

### 변환 결과가 찌그러져 보입니다
- **비율에 맞게 높이 자동 조정**이 체크되어 있는지 확인하세요.
- 고정폭 폰트를 사용하고 있는지 확인하세요 (비례 폰트 사용 시 찌그러짐).

### 컬러 출력이 느립니다
컬러 출력은 각 문자마다 색상을 개별 처리하므로 일반 변환보다 느립니다.  
출력 너비를 줄이면 속도가 빨라집니다.

### PDF/Word 내보내기 오류
- 대용량 ASCII 아트(너비 300 이상)는 PDF 처리 시간이 길어질 수 있습니다.
- Word 파일은 Microsoft Word 또는 LibreOffice Writer로 열 수 있습니다.

### 설정이 초기화됩니다
설정은 `%AppData%\Image2TextWin\settings.json`에 저장됩니다.  
이 파일이 손상된 경우 삭제하면 기본값으로 초기화됩니다.
