# Image to ASCII Art 변환기

BMP, JPG, PNG, GIF, TIFF, ICO 등 다양한 형식의 이미지를 텍스트 기반 ASCII 아트로 변환하는 Windows Forms 애플리케이션입니다.

## 주요 기능

- **다양한 이미지 형식 지원** — BMP, JPG, JPEG, PNG, GIF, TIFF, ICO
- **5가지 문자 집합** — 상세(70단계), 표준(10단계), 단순(5단계), 블록 유니코드(█▓▒░), 사용자 정의
- **컬러 출력** — 원본 이미지 색상을 ASCII 아트에 반영
- **이미지 보정** — 밝기, 대비, 밝기 반전, 윤곽선 강조
- **텍스트 파일 편집** — 기존 ASCII 텍스트 파일을 불러와 직접 편집
- **다양한 내보내기** — TXT, HTML, PDF, Word(.docx), 이미지(PNG/BMP/JPG)
- **설정 영속화** — 마지막 사용 디렉토리, 변환 옵션 자동 저장
- **드래그 앤 드롭** — 이미지 파일을 창에 바로 드래그하여 열기

## 요구 사항

- Windows 10 이상
- [.NET 8 Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) (x64)

## 빌드

```
dotnet build Image2TextWin/Image2TextWin.csproj
```

## 실행

```
dotnet run --project Image2TextWin/Image2TextWin.csproj
```

또는 빌드 후 `bin/Debug/net8.0-windows/Image2TextWin.exe` 직접 실행.

```
│  메뉴바  (파일 / 편집 / 보기)                              │

├───────────────────────┬──────────────────────────────────┤
│                       │                                  │
│    원본 이미지 미리보기  │     ASCII 아트 출력              │
│    (좌측 패널)         │     (우측 패널, 편집 가능)        │
│                       │                                  │
├───────────────────────┴──────────────────────────────────┤
│  설정: 문자집합 / 출력크기 / 폰트 / 변환옵션  │  [변환] 버튼  │
├──────────────────────────────────────────────────────────┤
│  상태바: 메시지 │ 이미지 크기 │ 출력 크기 │ 편집모드 │ 파일명 │
└──────────────────────────────────────────────────────────┘
```
