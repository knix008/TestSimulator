# 사용 설명

명령은 출근, 퇴근, 경비, 해제이다. `무음`은 명령이 아닌 소리를 거절하려고 항상 함께 둔다. 한 번에 한 단계만 할 수 있다. 학습을 다시 하지 않아도, 이미 있는 학습 결과로 인식할 수 있다.

처음 실행하면 `scripts/setup_python.bat`이 Python 3.13 가상환경을 만든다. 3.13이 없으면 3.12를 쓴다. 시스템 Python 3.14에는 이 프로젝트의 PyTorch 휠이 없을 수 있다.

## 화면에서 각각 실행

`run.bat` 또는 `run_gui.bat`으로 연다.

| 하고 싶은 일 | 화면 | 결과 |
| --- | --- | --- |
| 합성 데이터만 만들기 | 데이터 | `data/synth/train`, `data/synth/test` |
| 내 목소리 녹음 | 데이터 | `data/audio/명령/*.wav` |
| 처음부터 학습 | 학습 | 합성 데이터(+내 녹음)로 `models/latest`. 인식 화면으로 넘어가지 않는다 |
| 추가 학습 | 학습 | 고른 결과에서 이어서 내 녹음으로 `models/speaker` |
| 인식만 | 실시간 테스트 | 고른 학습 결과로 판정 |
| 인식 성능 평가 | 평가 | 명령별 인식률, 혼동표, 추천 임계값. 마이크 시험 음성은 `data/eval/날짜_시각` |
| ONNX만 다시 저장 | 내보내기 | 고른 결과 폴더의 `command_kws.onnx` |

학습 결과가 이미 있으면 실시간 테스트 탭이 먼저 열린다. 화면 위의 학습 결과 목록에 폴더 이름이 나온다. 현재 저장소에는 `models/synth_eval`이 있다. 그 항목을 고르면 다시 학습하지 않고 실시간 테스트, 평가, 내보내기를 할 수 있다.

다른 폴더에 있는 결과는 다른 폴더 버튼으로 고른다. 폴더 안에 `meta.json`과 `command_kws.onnx` 또는 `model.pt`가 있어야 한다.

판정 규칙은 학습 결과와 관계없이 같다. 1등이 `무음`이거나 최대 확률이 임계값보다 낮으면 화면에 `대기`가 나온다. 기본 임계값은 0.70이고, 슬라이더는 0.40에서 0.95까지다.

### 학습 데이터

학습 데이터는 두 곳에 따로 있다. 데이터 탭의 명령 목록에 `출근    내 녹음 3개 · 합성 35개`처럼 둘 다 나온다.

| 데이터 | 위치 | 만드는 방법 |
| --- | --- | --- |
| 합성 데이터 | `data/synth/train` | 합성 데이터 생성 버튼. 없으면 학습 시작 때 물어보고 만든다 |
| 내 녹음 | `data/audio` | 명령 녹음, 무음 녹음, WAV 가져오기 |

합성 데이터는 지금 등록된 명령마다 Windows 한국어 음성(Microsoft Heami)으로 말하기 속도 5가지 × 높이 5가지와 소음 섞인 음을 만든다. 명령 하나당 35개이다. 무음에는 다른 말 45개와 소음 6개, 모두 51개가 들어간다. 다시 만들면 지금 명령으로 새로 만들고, 내 녹음은 건드리지 않는다. 같은 때 학습에 쓰지 않은 속도의 평가 음도 `data/synth/test`에 생긴다.

한국어 음성이 없으면 Windows 설정 > 시간 및 언어 > 음성에서 추가한다.

내 녹음 방법은 다음과 같다.

1. 데이터 탭에서 명령을 고른다.
2. 횟수를 정하고 명령 녹음을 누른다. 삐 소리 뒤에 그 명령만 말한다. 한 번은 1.2초이다.
3. 무음 녹음으로 말하지 않는 상태와 생활 소음을 넣는다.
4. 추가 학습에는 명령마다 4–10개면 충분하다. 속도, 거리, 크기를 조금씩 바꾼다.
5. 이미 있는 WAV는 WAV 가져오기로 넣는다. 16 kHz가 아니면 가져올 때 맞춘다.

### 학습

학습 탭에서 데이터와 방식을 고른 뒤 학습 시작을 누른다.

| 방식 | 시작 가중치 | 기본 데이터 | 기본값 | 저장 이름 |
| --- | --- | --- | --- | --- |
| 처음부터 학습 | 무작위 | 합성 데이터 + 내 녹음(있으면) | 40에폭, 학습률 0.002 | `latest` |
| 추가 학습 | 위에서 고른 학습 결과 | 합성 데이터 + 내 녹음 | 15에폭, 학습률 0.0005 | `speaker` |

- 처음 쓸 때는 녹음 없이 학습 시작만 누르면 된다. 합성 데이터가 없으면 만들지 묻고, 만든 뒤 이어서 학습한다.
- 추가 학습은 실제 사용할 사람의 발음에 맞추는 단계이다. 고른 결과의 가중치와 특징 정규화 값을 그대로 이어받는다. 내 녹음은 내 녹음 반복 값(기본 3)만큼 에폭마다 여러 번 써서 비중을 높인다. 합성 데이터를 함께 써야 기존 명령 구분을 잊지 않는다.
- 추가 학습에는 내 녹음이 하나 이상 있어야 한다. 명령 구성이 기존 결과와 같아야 한다. 명령을 바꿨으면 처음부터 학습한다.
- 저장 이름을 바꾸면 `models/이름`에 저장된다. 추가 학습 결과를 `speaker`에 두면 기반 결과(`latest`)와 평가 탭에서 비교할 수 있다.
- 검증 정확도가 15에폭 동안 오르지 않으면 그 전에 멈춘다. 가장 좋았던 가중치와 ONNX가 저장된다.
- 데이터를 합해 클래스마다 WAV가 4개보다 적으면 학습이 시작되지 않는다.

### 학습이 제대로 됐는지 확인

검증 정확도만으로는 알기 어렵다. 검증 음성은 학습 음성과 같은 목소리, 같은 속도에서 일부를 떼어 낸 것이라 실제보다 높게 나온다. 학습이 끝나면 로그에 다음이 차례로 나온다.

1. 출처별 검증 정확도. 예: `검증 정확도 92.0% (합성 95.0%, 내 녹음 80.0%)`. 내 녹음이 낮으면 내 발음은 아직 잘 못 맞힌다는 뜻이다.
2. 추가 학습이면 학습 전 정확도. 예: `추가 학습 전 합성 94%, 내 녹음 60%`. 내 녹음 값이 올랐고 합성 값이 크게 떨어지지 않았으면 추가 학습이 효과가 있다.
3. 학습에 쓰지 않은 음성으로 채점한 결과. 합성 평가 음원(`data/synth/test`, 학습에 없는 속도)과 마이크 시험 음성(`data/eval`)의 명령 인식률, 놓침, 오인식, 오수락이다.

가장 믿을 만한 숫자는 3번의 마이크 시험 결과이다. 순서는 다음을 권한다.

1. 처음부터 학습한 뒤 평가 탭에서 마이크 시험을 한 번 한다. 이 음성은 `data/eval`에 남고 학습에는 쓰이지 않는다.
2. 데이터 탭에서 내 목소리를 녹음하고 추가 학습을 한다.
3. 학습 로그의 마이크 시험 음성 점수가 1번보다 올랐는지 본다. 평가 탭에서 `latest`와 `speaker`를 번갈아 골라 같은 폴더를 폴더 평가해도 된다.

놓침이 많으면 확률이 임계값에 못 미치는 것이다. 평가 탭의 임계값별 표를 보고 임계값을 낮추거나 녹음을 더 넣는다. 오수락이 많으면 무음 녹음(생활 소음, 다른 말)을 더 넣는다.

### 인식

실시간 테스트에서 학습 결과를 고른 뒤 다음 중 하나만 하면 된다.

- 마이크 테스트 시작. 약 0.2초마다 직전 1초를 판정한다.
- WAV 인식. 파일 하나의 결과를 큰 글씨로 보여 준다.

엔진은 ONNX 또는 PyTorch이다. 고른 폴더에 있는 파일만 선택할 수 있다. `synth_eval`에는 둘 다 있다.

### 평가

실시간 테스트는 한 번씩 확인하는 화면이라 잘 되는지 숫자로 알기 어렵다. 평가 탭은 정답을 아는 음성을 여러 개 판정해 점수를 낸다.

- 마이크 시험. 명령마다 횟수를 정하고 누른다. 화면에 `「출근」 말하세요`, `조용히 계세요`, `다른 말 (예: 안녕하세요)`가 섞인 순서로 나온다. 삐 소리 뒤에 말하면 바로 `✓ 출근 → 출근`처럼 채점한다. 녹음은 `data/eval/날짜_시각/명령/`에 남으므로, 다시 학습한 뒤 폴더 평가로 같은 음성을 다시 채점할 수 있다. 학습 데이터(`data/audio`)에는 들어가지 않는다.
- 폴더 평가. 정답은 폴더 이름으로 정한다. `출근/`, `퇴근/`처럼 명령 이름 폴더는 그 명령, `무음/`, `다른말/`, `소음/`은 거절해야 하는 소리다. 하위 폴더 깊이는 상관없다. 정답을 알 수 없는 파일은 건너뛰고 개수만 알려 준다.
- 합성 평가 음원. `data/synth/test`를 폴더 평가로 연다.

결과는 네 가지로 나뉜다.

| 결과 | 뜻 |
| --- | --- |
| 정답 | 명령을 그 명령으로, 또는 명령이 아닌 소리를 대기로 판정 |
| 놓침 | 명령인데 대기 (확률이 임계값보다 낮음) |
| 오인식 | 명령인데 다른 명령으로 판정 |
| 오수락 | 명령이 아닌 소리를 명령으로 판정. 경비 해제 같은 명령에서는 가장 위험하다 |

오른쪽에는 전체 정답률, 명령별 인식률, 혼동표(행은 정답, 열은 인식 결과)가 나온다. 임계값을 0.40부터 0.95까지 바꿨을 때의 명령 인식률과 오수락률, 그리고 추천 임계값도 나온다. 추천값은 오수락이 가장 적은 값들 중에서 인식률이 가장 높은 값이다. 임계값 슬라이더를 움직이면 다시 판정하지 않고 즉시 다시 센다.

임계값 오른쪽의 파란 글씨가 지금 평가의 정확도(정답 수 / 전체)이다. 마이크 시험 중에는 한 번 말할 때마다 바로 갱신된다. 실시간 테스트 탭의 마이크 정확도 시험 버튼도 같은 시험을 시작한다.

학습 데이터로 저장은 평가에 쓴 사람 음성을 정답 명령의 학습 데이터(`data/audio`)로 복사한다. 줄을 하나 골랐으면 그 하나만, 아니면 표에 보이는 줄을 모두 복사한다. 틀린 것만을 켜고 누르면 모델이 틀린 내 발음만 넣을 수 있다. 다른말·소음은 무음으로 들어간다. 복사한 뒤 추가 학습을 하면 된다. 같은 음성으로 다시 평가하면 점수가 실제보다 높게 나오므로, 확인은 새 마이크 시험으로 한다.

틀린 것만을 켜면 틀린 줄만 남는다. 줄을 고르면 아래에 명령별 확률과 임계값 선(점선)이 나오고, 두 번 누르거나 듣기를 누르면 그 소리를 들을 수 있다. CSV 저장은 파일별 정답, 인식, 결과, 모든 클래스의 확률을 Excel에서 열 수 있게 저장한다.

같은 기능을 `run_eval.bat 폴더 --model models\latest --threshold 0.70 --csv 결과.csv`로도 실행할 수 있다. 폴더를 생략하면 `data/synth/test`를 쓴다.

### 내보내기

내보내기 탭은 선택한 학습 결과의 `model.pt`로 ONNX를 다시 쓴다. INT8도 저장을 켜면 `command_kws.int8.onnx`가 함께 생긴다. 인식만 할 때는 이미 있는 `command_kws.onnx`로 충분하다.

## 스크립트로 각각 실행

GUI 없이 한 단계만 실행할 때 쓴다.

| 스크립트 | 하는 일 |
| --- | --- |
| `run_record.bat 출근 5` | 출근을 5번 녹음. `무음`도 같은 형식 |
| `run_train.bat` | 합성 데이터(있으면)와 `data/audio`로 처음부터 학습해 `models/latest`에 저장. `--no-synth`, `--no-recordings`로 끌 수 있음 |
| `run_train.bat --finetune models\latest` | 추가 학습. 기본 15에폭, 학습률 0.0005, `models/speaker`에 저장. `--out 이름`, `--repeat 3` |
| `run_export.bat` | 저장된 가중치를 ONNX로 다시 저장. `--no-int8`이면 실수형만 |
| `run_test.bat 파일.wav 0.70` | WAV 하나를 Python으로 판정 |
| `run_synth_test.bat` | 합성 음을 만들고 `models/synth_eval`에 따로 학습 |
| `run_eval.bat [폴더]` | 폴더의 WAV를 한꺼번에 판정해 인식률, 혼동표, 틀린 파일 출력 |
| `run_selftest.bat` | 특징, 학습, ONNX, C++ 특징 검사 |
| `run_tests.bat` | `test` 폴더의 전체 테스트 실행. `ONNXRUNTIME_ROOT`가 없으면 `kws_infer` 비교만 건너뜀 |
| `build_cpp.bat` | ONNX Runtime 없이 `test_logmel` 빌드 |
| `build_cpp.bat C:\path\to\onnxruntime` | `kws_infer`까지 빌드 |
| `run_cpp.bat 파일.wav 0.70` | C++로 WAV 판정 |

학습만 한 결과는 `models/latest`에 있다. 인식만 하려면 그 폴더 또는 `models/synth_eval`을 넘긴다.

```bat
run_test.bat data\synth\test\깨끗\경비\0000_p0.93.wav 0.70
run_cpp.bat data\synth\test\깨끗\경비\0000_p0.93.wav 0.70
```

C++ 예제는 모델 폴더와 WAV를 받는다. `run_cpp.bat`은 `models/latest`를 본다. `synth_eval`만 있을 때는 `cpp\build\Release\kws_infer.exe models\synth_eval 파일.wav 0.70`처럼 폴더를 직접 지정한다. `onnxruntime.dll`을 exe 옆에 둔다.

장치에 복사하는 파일은 `command_kws.onnx`, `mel_filters.bin`, `window.bin`, `norm.bin`, `labels.txt`, `frontend.txt`이다. 합계는 138,549바이트이다. 메모리와 CPU 클록은 [Architecture.md](Architecture.md)에 있다.

## 판정 결과

프로그램이 성공하면 종료 코드는 0이다. 명령을 거절해도 종료 코드는 0이다.

```text
ACCEPTED=0 또는 1
LABEL=대기 또는 명령
TOP_LABEL=가장 높은 클래스
TOP_CONFIDENCE=0에서 1
ENGINE=onnx 또는 pytorch
```

`ACCEPTED=1`일 때만 명령을 실행한다.
