# PACS — DICOM 네트워크

**도구 › PACS (DICOM 네트워크)…** — 병원 PACS 나 장비와 DICOM 으로 주고받습니다. 웹 페이지는 네트워크 연결을 열 수 없으므로 **데스크톱 앱에서만** 동작합니다.

![PACS 창](images/help-pacs.jpg)

## 1. 원격 노드 등록

PACS 관리자에게 받은 **AE 타이틀**(대소문자 구분), **호스트**(IP 또는 이름), **포트**(보통 104 또는 11112)를 넣고 이름을 붙여 **저장** 합니다. 여러 노드를 목록에 두고 고릅니다.

## 2. 연결 확인 (C-ECHO)

**연결 확인** 을 눌러 응답 시간이 나오면 연결된 것입니다.

## 3. 검사 검색 (C-FIND)

환자 이름(`DOE^*` 처럼 `*` · `?` 와일드카드), 환자 ID, 날짜 범위, 장비(CT, MR …), 접수 번호를 넣고 **검색** 합니다. 검사를 누르면 그 검사의 시리즈가 아래에 나옵니다.

## 4. 가져오기

| 방법 | 설명 |
| --- | --- |
| **C-GET** | 같은 연결로 바로 받습니다. 대부분의 PACS(Orthanc, dcm4chee …)가 지원하며 따로 등록할 필요가 없습니다 |
| **C-MOVE** | PACS 가 우리 수신 포트로 보내 줍니다. **PACS 에 우리 AE 타이틀 · 이 컴퓨터 주소 · 수신 포트가 목적지로 등록** 되어 있어야 합니다. 누르면 수신이 자동으로 켜집니다 |

시리즈를 고르지 않으면 검사 전체를 가져옵니다. 받은 파일은 `내 폴더/MyDCMViewer/PACS/<날짜-시각>/` 에 저장되고, 끝나면 그 폴더가 트리에 열리며 시리즈로 정렬됩니다. 상대가 압축 영상을 보내지 못하면 자동으로 비압축으로 바꿔 받습니다.

## 5. 보내기 (C-STORE)

지금 연 파일(정렬된 시리즈라면 시리즈 전체)을 고른 노드로 보냅니다. 상대가 압축 형식을 받지 않으면 비압축으로 바꿔 보냅니다.

## 6. 받기 (Storage SCP)

**이 컴퓨터** 의 *우리 AE 타이틀* (기본 `MYDCMVIEWER`)과 *수신 포트* (기본 11112)를 정하고 **수신 시작** 을 누르면, 다른 장비가 보내는 영상을 받아 같은 폴더에 저장합니다. PACS 창을 닫으면 수신도 멈춥니다.

## 시험해 보기

PACS 가 없어도 `npm run mini-pacs` 로 samples/ 의 영상을 가진 작은 PACS(AE `MINIPACS`, 포트 11113)를 띄워 모든 기능을 시험할 수 있습니다. C-MOVE 를 시험하려면 `node scripts/mini-pacs.cjs --dest MYDCMVIEWER=127.0.0.1:11112` 처럼 목적지를 알려 줍니다.

| 문제 | 확인할 것 |
| --- | --- |
| 연결 확인 실패 | 호스트 · 포트 · AE 타이틀, 방화벽, PACS 에 우리 AE 가 허용되어 있는지 |
| C-MOVE 로 아무것도 오지 않음 | PACS 의 목적지 등록(AE · 주소 · 포트), 이 컴퓨터 방화벽의 수신 포트. 어렵다면 C-GET |
