# 문제 해결

| 증상 | 확인할 것 |
| --- | --- |
| 데스크톱 창이 비어 있음 | Windows 에는 WebView2 런타임이 필요합니다. 설치 프로그램이 없으면 내려받아 설치합니다 |
| 압축 DICOM 이 열리지 않음 | 정보 패널의 *전송 구문* 을 확인하세요. 코덱은 처음 쓸 때 페이지 옆의 `vendor/` 에서 읽습니다 |
| DICOM 동영상이 재생되지 않음 | MPEG-2 는 브라우저 엔진이 풀지 못합니다. HEVC 는 컴퓨터에 HEVC 디코더가 있어야 합니다. **동영상 추출** 로 저장해 동영상 플레이어에서 보세요 |
| 방향 표시가 없음 | Image Orientation (Patient) · Patient Orientation 이 없는 파일입니다 |
| MPR · 3D 에서 "먼저 시리즈로 정렬" | 시네 › 폴더를 DICOM 시리즈로 정렬 후 다시 실행하세요. 슬라이스 크기가 모두 같아야 합니다 |
| 3D 창에 "WebGL2 를 쓸 수 없음" | 그래픽 드라이버를 업데이트하세요 |
| 동기 스크롤 · 기준선이 동작하지 않음 | 두 영상 모두 위치 정보(Image Position · Orientation)가 있어야 합니다 |
| 영상 융합이 늘려 겹침으로 나옴 | 서로 다른 촬영이라 환자 좌표가 겹치지 않거나 위치 정보가 없습니다 |
| PACS 연결 확인 실패 | 호스트 · 포트 · AE 타이틀(대소문자), 방화벽, PACS 에 우리 AE 가 허용되어 있는지 |
| C-MOVE 로 아무것도 오지 않음 | PACS 의 목적지 등록(우리 AE · 주소 · 수신 포트). 어렵다면 C-GET |
| 일괄 변환 결과가 ZIP 으로 내려옴 (웹) | 읽기 전용 폴더입니다. Chrome · Edge 에서 폴더 열기 → 쓰기 허용 |
| HEIC 로 내보낼 수 없음 | 브라우저 엔진에 HEVC 인코더가 있어야 합니다. AVIF 나 JPEG XL 을 쓰세요 |
| 측정이 화소로 나옴 | 화소 간격이 없는 파일입니다. *이 길이를 실측값으로 보정* 하세요 |
