# 측정 도구

도구 모음이나 **도구** 메뉴에서 고르고, 숫자 키로도 고릅니다. 측정한 점은 어느 도구에서나 끌어서 옮길 수 있습니다.

![측정](images/help-measure.jpg)

| 도구 | 키 | 하는 일 |
| --- | --- | --- |
| 이동 | 1 | 끌어서 이동, 더블 클릭으로 화면 맞춤 |
| 윈도우 / 레벨 | 2 | 끌어서 W/L |
| 확대 / 축소 | 3 | 위아래로 끌기 |
| 프레임 / 슬라이스 스크롤 | 4 | 휠 · 끌기로 프레임이나 시리즈 파일 넘기기 |
| 픽셀 값 조사 | 5 | 마우스 아래의 좌표 · 값(HU) · 원래 값 |
| 길이 | 6 | 두 점 사이 거리 — 화소 간격이 있으면 mm / cm |
| 각도 | 7 | 세 점(두 번째가 꼭짓점) |
| Cobb 각 | Shift+7 | 선 두 개(척추 끝판) 사이의 각도 |
| 사각형 · 타원 ROI | 8 · 9 | 면적, 화소 수, 평균, 표준편차, 최소, 최대 |
| 다각형 ROI | Shift+8 | 눌러서 꼭짓점, 두 번 누르거나 `Enter` 로 닫기 — 면적 · 둘레 · 통계 |
| 자유곡선 ROI | Shift+9 | 끌어서 윤곽 — 다각형과 같은 통계 |
| 점 | Shift+5 | 그 자리의 값 |
| 화살표 | Shift+0 | 화살표와 이름표 |
| 텍스트 | 0 | 글 상자 |
| 돋보기 | Q | 누르고 있는 동안 그 자리를 3배로 |

## 지우기 · 되돌리기

- **마지막 측정 삭제** (`Backspace`), **측정 모두 지우기** (`Del`), **실행 취소** (`Ctrl+Z`).

## 실측 보정

화소 간격(Pixel Spacing)이 없는 그림은 길이가 화소로 나옵니다. 길이를 아는 곳에 길이 선을 그린 뒤 **도구 › 이 길이를 실측값으로 보정** 에서 실제 길이(예: `5 cm`)를 넣으면, 그 뒤의 측정 · 눈금자 · 격자에 그 비율이 쓰입니다. **실측 보정 지우기** 로 되돌립니다.

## 내보내기

- **파일 › 이미지 내보내기 › 측정값 (CSV)**: 모든 측정의 종류 · 값 · 단위 · 통계.
- **보기 › 내보내기에 주석 포함** 이 켜져 있으면 내보내는 그림에 측정이 그려집니다.
- 측정 색은 **설정 › 뷰어** 에서 바꿉니다.
