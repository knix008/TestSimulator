# 시네 재생 · DICOM 동영상 · 시리즈

## 여러 프레임 영상 재생

초음파 · 혈관 조영 · 심장 MR 처럼 프레임이 여럿인 파일은 영상 아래에 **프레임 막대** 가 나타납니다.

![프레임 막대](images/help-cine.jpg)

| 단추 | 키 | 하는 일 |
| --- | --- | --- |
| ⏮ 첫 프레임 | `Home` | 맨 앞으로 |
| ◀ 이전 프레임 | `↑` | 한 프레임 뒤로 |
| ▶ 재생 | `Space` | 재생 — 재생 중에는 단추가 강조됩니다 |
| ⏸ 잠시 멈춤 | `Space` | 지금 프레임에서 멈춥니다 |
| ⏹ 멈춤 | `S` | 멈추고 첫 프레임으로 돌아갑니다 |
| ▶ 다음 프레임 | `↓` | 한 프레임 앞으로 |
| ⏭ 마지막 프레임 | `End` | 맨 뒤로 |
| 슬라이더 | | 원하는 프레임으로 |
| fps · 반복 | | 재생 속도와 반복 재생 |

같은 명령이 **시네** 메뉴에도 있습니다. fps 의 처음 값은 파일의 Frame Time · Cine Rate 입니다.

## DICOM 동영상

MPEG-4 AVC(H.264) · HEVC(H.265) · MPEG-2 로 저장된 DICOM 동영상(내시경, 초음파, 수술 영상 등)도 엽니다.

![DICOM 동영상](images/help-video.jpg)

- **H.264 · HEVC**: 컴퓨터의 동영상 엔진으로 그대로 **재생 · 잠시 멈춤 · 멈춤** 하고, 한 프레임씩 넘기며 측정 · 내보내기를 할 수 있습니다. 재생 속도는 fps 칸으로 바꿉니다.
- **MPEG-2** 처럼 브라우저 엔진이 풀지 못하는 형식(또는 HEVC 디코더가 없는 컴퓨터)은 정보 화면이 나오고, **동영상 추출** 로 `.m2v` · `.mp4` 파일을 저장해 VLC 같은 동영상 플레이어에서 봅니다.
- **도구 › DICOM 동영상 추출** 은 H.264 · HEVC 는 MP4 로, MPEG-2 는 원래 스트림으로 저장합니다.

![재생할 수 없는 동영상](images/help-video-mpeg2.jpg)

## 시리즈 넘기기

폴더에 파일이 여럿이면 **시리즈 막대** 가 나타납니다. `←` `→` · `PgUp` `PgDn` · 시리즈 슬라이더로 넘기고, 넘길 때 확대 · 이동 · 윈도우가 그대로 유지됩니다. 프레임이 하나뿐인 시리즈에서 재생하면 파일을 차례로 넘깁니다.
