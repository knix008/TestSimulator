# 영상 필터 · 영상 융합

## 영상 필터

**도구 › 영상 필터** 에서 하나를 바로 고르거나, **필터 연결…** 창에서 여러 필터를 차례로 잇고 값을 조절합니다.

![영상 필터](images/help-filters.jpg)

| 필터 | 설명 |
| --- | --- |
| 부드럽게 (가우스) | 잡음을 줄입니다 — 시그마 |
| 선명하게 (언샤프 마스크) | 경계를 또렷하게 — 세기 · 반경 |
| 잡음 제거 (양방향) | 경계는 두고 잡음만 |
| 중앙값 | 점 잡음 제거 — 3×3 · 5×5 |
| 윤곽선 (소벨) · 라플라시안 | 경계 강조 |
| 엠보스 | 입체감 |
| 히스토그램 평활화 | 대비를 고르게 펼칩니다 |
| 값 반전 · 임계값 | 값 뒤집기, 흑백 나누기 |

- 회색조 영상은 **창 조절 전에 화소 값(HU 등)에** 적용되어 W/L 을 바꿔도 다시 계산하지 않습니다. 컬러 영상은 그림에 적용됩니다.
- 내보내기 · 인쇄 · 복사에도 필터가 들어갑니다. 파일 자체는 바뀌지 않습니다. *필터 없음* 으로 되돌립니다.

## 영상 융합 (PET/CT)

![영상 융합](images/help-fusion.jpg)

두 번째로 연 DICOM 영상(PET, SPECT, RT 선량, MR …)을 현재 영상 위에 컬러맵으로 겹칩니다. **도구 › 영상 융합**.

1. 바탕 영상(CT 등)과 겹칠 영상(PET 등)을 둘 다 엽니다.
2. 바탕 영상 탭에서 *영상 융합* 을 열고 **겹칠 영상** 을 고릅니다.
3. **컬러맵 · 불투명도 · 임계값**(이보다 어두운 값은 투명)을 조절합니다.

- 두 영상에 위치 정보가 있으면 **환자 좌표로 재표본화** 하고, 여러 프레임 영상은 현재 단면에 가장 가까운 프레임을 씁니다.
- 위치 정보가 없거나 서로 겹치지 않는 다른 촬영이면 크기에 맞춰 늘려 겹치고 그 사실을 표시합니다.
