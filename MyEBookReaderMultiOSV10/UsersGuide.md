# MyEBookReader 사용 설명서

EPUB · PDF · DJVU · MOBI · **AZW3(KF8)** · FB2 · CBZ · Markdown · HTML · 텍스트와
JPG · PNG · GIF · WEBP · TIFF · DICOM 그림을 한 프로그램에서 봅니다.
Windows · macOS · Linux 설치본과 웹 브라우저에서 동일하게 동작합니다.

## 2. 책 열기

| 방법 | 설명 |
| --- | --- |
| 툴바 **열기** (Ctrl+O) | 파일 선택 창. 여러 권을 한꺼번에 고를 수 있습니다 |
| **끌어다 놓기** | 탐색기에서 책을 창 안으로 끌어다 놓습니다. 여러 권을 한꺼번에 놓으면 각각 탭으로 열리고, **폴더를 놓으면** 그 폴더가 왼쪽 서재 패널에 열립니다. 위치만 넘겨 주는 프로그램(브라우저 등)에서 끌어다 놓아도 열리며, 열 수 있는 것이 없으면 그렇다고 알려 줍니다 |
| **파일▾ → URL 열기** | 인터넷 주소에서 내려받아 엽니다 |
| **서재 패널** | 폴더를 지정하면 하위 폴더와 책이 트리로 보입니다. 맨 위에는 **드라이브** 줄이 있어 내 폴더와 이 컴퓨터의 드라이브(C: · D: …)를 바로 고를 수 있습니다 — 길을 아는 폴더가 없어도 위에서부터 훑어 내려갈 수 있습니다 |
| **압축 파일** | `.zip` · `.tar` · `.gz` · `.tgz` 를 열면 그 자리에서만 풀어서, 안의 책과 그림을 서재에 폴더처럼 보여 줍니다. 디스크에는 풀리지 않으며, RAR(`.rar`, `.cbr`)과 7-Zip은 읽지 않습니다 |
| **최근 파일** | 파일 메뉴 아래쪽, 또는 서재 패널. 최대 10개 — 하나씩 지우거나 전체 삭제. **한 줄에 한 권**이고 폴더가 이름 옆자리를 가져가지 않으므로 이름이 그만큼 길게 보이며, 줄을 넘치면 끝이 `…` 로 줄어듭니다. **마우스를 올리면 전체 경로**가 나옵니다 |
| **탐색기에서 두 번 클릭** | 설치 시 등록된 `.ebkr`, 또는 [연결 프로그램]으로 지정한 책 형식 |

오래 걸리는 파일은 진행률 창이 뜹니다. 열 수 없는 파일은 **무엇을 하다가 왜
실패했는지**를 담은 오류 창이 뜨고, 그 내용을 한 번에 복사할 수 있습니다.

## 3. 읽기

| 동작 | 방법 |
| --- | --- |
| 다음 / 이전 쪽 | `PageDown` `PageUp`, `Space`, `←` `→` — 한 쪽씩 보기에서는 단 단위로 넘어갑니다. 장의 끝까지 본 뒤에야 다음 장으로 넘어가고, **이전 쪽으로 돌아가면 앞 장의 맨 끝**에 도착합니다(맨 앞이 아니라) — 그래서 뒤로도 빠뜨리는 곳 없이 읽어 나갈 수 있습니다 |
| 마우스 휠로 넘기기 | **한 쪽씩 · 한 장씩 보기에서는 휠로 쪽을 넘깁니다**(아래로 다음 쪽, 위로 이전 쪽). 창보다 큰 쪽은 먼저 그 쪽을 다 훑은 다음에 넘어가고, 한 번의 휠 동작이 여러 쪽을 넘기지는 않습니다. 이어보기에서는 휠이 그대로 스크롤입니다 |
| 다음 / 이전 장 | 툴바의 `◀` `▶`, 또는 읽기 메뉴 |
| 특정 장으로 | 툴바 가운데 상자에 번호를 넣고 Enter, 또는 목차에서 선택 |
| 처음 / 끝 | Ctrl+Home / Ctrl+End |
| 글자 크게 / 작게 | 툴바의 **− / 현재 크기 / +** 버튼, **Ctrl+휠**, Ctrl `+` / `−`. 가운데 버튼(또는 Ctrl+0)은 100 %로 되돌립니다 |
| 한 장 / 두 장씩 | 툴바의 쪽 배치 버튼, 또는 보기 메뉴 — PDF · 만화 · 그림에서 두 쪽을 나란히 폅니다 |
| 넘김 효과 | 설정 → 읽기, 또는 툴바의 넘김 효과 단추: 없음 · 밀기 · 책장 넘김. **한 장씩 보기와 두 장씩 보기에서만** 쓸 수 있습니다 — 이어보기에서는 넘어가는 쪽이 없으므로 단추가 흐리게 남습니다 |
| 전체 쪽 수 · 현재 쪽 | 상태 바가 **쪽 12 / 47** 로 알려 줍니다. PDF·만화·그림은 파일이 가진 쪽을 그대로 세고, 글(EPUB 등)은 **글자 수로 잰 어림셈**(`≈` 표시)입니다 — 책 자신의 수치라서 **창 크기나 글자 크기를 바꾸어도 전체 쪽 수도 현재 쪽도 달라지지 않습니다**(글자를 키우면 한 쪽이 여러 화면이 될 뿐입니다). 장 안에서의 위치는 그 옆에 따로 나옵니다 |
| 넘기기 방식 | 툴바 아이콘으로 **이어보기 ↔ 한 쪽씩** 전환. 글(EPUB · MOBI · FB2 · MD · HTML · TXT)과 쪽(PDF · 만화 · 그림)은 이 방식을 **따로 기억**합니다 — 글은 기본이 이어보기, 쪽은 기본이 한 장씩이며, 설정 창 → 읽기에서 각각 고를 수 있습니다 |
| 쪽 이어보기 | PDF · 만화도 이어보기로 바꾸면 쪽이 위아래로 이어지고, 스크롤하는 대로 쪽 번호가 따라옵니다. 보이지 않는 쪽은 자리만 잡아 두고 그리지 않으므로 수천 장짜리 PDF도 가볍게 넘길 수 있습니다 |
| 본문 모양 | 오른쪽 패널 → 읽기 설정: 글꼴 · 크기 · 줄 간격 · 폭 · 문단 간격 · 자간 · 굵게/기울임/밑줄 · 양쪽 정렬 · 들여쓰기 |
| PDF · 만화 · 그림 | 확대/축소, 너비 맞춤 · 페이지 맞춤 · 실제 크기, 90° 회전(만화 · 그림 · TIFF · DICOM도 함께 돌아갑니다), 한 장/두 장씩 (보기 메뉴) |
| 열었을 때 크기 | 파일을 열면 언제나 쪽 전체가 **창 크기에 맞게** 표시됩니다. 앞서 보던 파일의 확대 비율이나 회전은 따라오지 않습니다(읽기 파일 `.ebkr` 에 저장해 둔 보기 설정은 그대로 살립니다) |
| 야간 보기 | 보기 메뉴 → 색 반전 |

읽던 위치는 책마다 기억되어 다음에 열 때 그 자리에서 시작합니다.

## 4. 표시하기 — 책갈피 · 형광펜 · 메모

| 기능 | 방법 |
| --- | --- |
| 책갈피 | 툴바 책갈피 버튼 또는 **Ctrl+B**. 글을 선택한 상태면 그 문장이 이름이 됩니다. 옆의 화살표를 누르면 지금까지 만든 책갈피가 **별도 창 목록**으로 열리고, 왼쪽 패널에서도 지우거나 이동할 수 있습니다 |
| 형광펜 | 글을 선택하고 **Ctrl+H** — 오른쪽 패널 "메모" 탭에 모입니다 |
| 메모 | 툴바 메모 버튼 — 선택한 문장을 인용한 채 메모를 답니다 |
| 복사 | **Ctrl+C** (선택한 글), 바로가기 메뉴의 "이 장 전체 복사" |
| 붙여넣기 | **Ctrl+V** — 클립보드의 글이 메모가 됩니다 |
| 되돌리기 | **Ctrl+Z** / **Ctrl+Y** — 모든 표시 작업이 대상입니다 |

> **원본 책 파일은 절대 고쳐 쓰지 않습니다.** 표시한 내용은 **Ctrl+S** 로
> `책이름.ebkr` 독서 파일에 저장됩니다. 이 파일을 두 번 클릭하면 책과 표시,
> 읽던 위치가 한꺼번에 복원됩니다. 저장하지 않은 표시가 있으면 프로그램을 닫을 때
> 저장할지 물어봅니다.

## 5. 찾기

1. 툴바 **찾기**(Ctrl+F) → 왼쪽 패널이 찾기로 바뀝니다
2. 단어를 넣고 Enter — 책 전체를 훑습니다 (긴 책도 화면이 멈추지 않습니다)
3. 결과를 누르면 그 장으로 이동하고, 본문에서 그 단어가 **강조**됩니다
4. **F3 / Shift+F3** 로 다음·이전 결과

## 6. 인쇄

툴바 **인쇄**(Ctrl+P)를 누르면 별도 창이 열립니다.

* **범위** — 전체 · 현재 장(쪽) · 사용자 지정(`1-4, 9, 12-`)
* **페이지 설정** — 용지(A4 · Letter · A5 · B5 · Legal · A3) · 세로/가로 · 여백
* **미리보기** — 고른 설정 그대로 보여 주고, `◀` `▶` 로 넘겨 봅니다
* **인쇄** — 시스템 인쇄 창으로 넘어갑니다

PDF와 만화책은 쪽 그림으로, 글 책은 장별로 쪽을 나누어 인쇄합니다.

## 7. 모양 바꾸기

| 항목 | 방법 |
| --- | --- |
| 메뉴 바 | 제목 표시줄 아래에 **파일 · 읽기 · 보기 · 표시·편집 · 프로그램** 메뉴 바가 있습니다. 이름을 누르면 툴바와 똑같은 메뉴가 열리고, 열린 채로 옆 이름 위를 지나가면 그 메뉴로 바뀝니다. 보기 메뉴의 **메뉴 바 표시**로 감출 수 있습니다 |
| 쪽 넘김 | 본문 좌우 가장자리에 떠 있는 **‹ ›** 단추로 넘깁니다(PageUp/PageDown과 같습니다). 넘길 때 화면이 깜빡이지 않고, 두 장씩 보기에서는 두 쪽이 함께 넘어갑니다. 움직이는 것은 **읽던 쪽**입니다 — 읽던 쪽이 넘어가며 사라지고, 그 밑에 이미 있던 새 쪽이 남습니다. 새 쪽은 움직이지 않습니다 |
| 넘김 효과 단추 | 툴바의 단추를 누르면 **없음 · 밀기 · 책장 넘김** 목록이 열리고, 지금 쓰는 것에 체크가 붙습니다 — 원하는 것을 바로 고르면 됩니다. 이어보기에서는 넘길 쪽이 없으므로 흐리게 남습니다 |
| 툴바의 한 쪽씩 / 이어보기 | 두 아이콘이 확실히 다릅니다 — **모서리를 접은 낱장**이면 한 쪽씩 보기, **이어진 두 장과 아래 화살표**면 이어보기. 누르면 다른 쪽으로 바뀝니다 |
| 툴바의 "읽기" 단추 | 없앴습니다. 그 메뉴에 있던 것(장 이동·글자 크기·한 쪽씩/이어보기)이 모두 바로 옆에 단추로 나와 있어 같은 기능이 두 벌이었습니다. 메뉴 바의 **읽기**는 그대로 있습니다 |
| 쪽 번호 | 툴바 가운데의 **현재 쪽 / 전체 쪽**은 상자 안에서 가운데로 맞춰 표시됩니다 |
| 왼쪽 패널 | 목차 · 서재 · 책갈피 · 찾기가 패널 **왼쪽 가장자리를 세로로 가득 채우는 레일**에 놓이고(세워 둔 도구 모음입니다), 고른 도구의 내용이 **그 오른쪽**에 펼쳐집니다 — 레일과 내용이 한 패널입니다. 레일은 아이콘만 쓰고 이름은 마우스를 올리면 나옵니다 |
| 한 장 / 두 장 아이콘 | 툴바의 쪽 배치 단추는 **지금 어느 쪽인지를 그림으로** 보여 줍니다 — 낱장 한 장이면 한 장 보기, 제본선을 두고 마주 본 두 장이면 두 장씩 보기. 누르면 다른 쪽으로 바뀝니다 |
| 그림 고르기 | 그림을 **마우스로 누르면** 강조색 테두리가 둘리고, 상태 바에 **"그림 선택됨 폭×높이"** 칸이 나타나 무엇이 골라졌는지 알려 줍니다. 그 뒤 **Ctrl+Shift+C** 는 고른 그림을 복사합니다. 다른 곳을 누르면 테두리와 상태 바 칸이 함께 사라집니다. PDF 쪽도 쪽 위를 누르면 골라지며, **글자 위를 누른 때는 글 선택**이므로 쪽이 골라지지 않습니다 |
| 글 선택 | 본문(EPUB · MOBI · FB2 · Markdown · HTML · TXT)과 **PDF 쪽의 글자**는 끌어서 선택하고 **Ctrl+A** 로 전체를 고를 수 있습니다. 상태 바가 고른 글자 수를 셉니다. 만화 · 그림 · TIFF · DICOM 처럼 글자가 없는 형식에서 Ctrl+A 를 누르면 **"선택할 글자가 없습니다"** 라고 알려 줍니다 |
| 오른쪽 패널의 숫자 | 글자 크기 · 줄 간격 · 문단 간격 · 자간은 **− 값 +** 한 줄입니다. 칸에 값을 직접 넣고 Enter를 누르거나, − · + 로 한 단위씩 움직이거나, 위·아래 화살표 키를 씁니다. 범위를 벗어난 값은 범위 안으로 맞춰집니다 |
| 책 정보의 표지 | 표지가 있는 책은 표지를, **표지가 없는 책은 첫 쪽**을 보여 줍니다 — 그림책의 첫 그림, PDF의 1쪽, 글 책이면 첫 장의 첫머리. 아이콘만 덩그러니 놓이지 않으며, 어느 쪽이든 원래 비율 그대로 줄여 보여 줍니다 |
| 패널 폭 | 왼쪽·오른쪽 패널은 **항상 지정한 폭을 지킵니다**. 담긴 내용이나 여는 파일이 폭에 영향을 주지 않으며, 스크롤바 자리를 미리 비워 두어 내용이 옆으로 밀리지도 않습니다 |
| 여기에 책갈피 | 본문에서 **오른쪽 단추 → 여기에 책갈피**. 누른 자리에 표시가 찍히고, 책갈피 목록에서 고르면 그 자리로 돌아옵니다. **Ctrl+B** 는 지금 읽는 자리를 책갈피합니다 |
| 설정 창의 숫자 | 설정 창에서 숫자로 정하는 것도 모두 **− 값 +** 한 줄입니다. 가운데 값을 누르면 기본값으로 돌아갑니다 |
| 책장 넘김 | 낱장 한 장이 제본선을 축으로 넘어갑니다. 앞면은 방금까지 보던 쪽, 뒷면은 넘긴 뒤의 쪽이라 넘어가는 동안 반대쪽을 덮으며 지나갑니다. 두 장씩 볼 때 **다음 쪽은 오른쪽 장이, 이전 쪽은 왼쪽 장이** 넘어갑니다 |
| 넘김 효과가 안 보일 때 | Windows의 **설정 → 접근성 → 시각 효과 → 애니메이션 효과**가 꺼져 있으면 보통 모든 애니메이션이 멈춥니다. 읽기 설정에서 **밀기**나 **책장 넘김**을 직접 고른 경우에는 그래도 동작하게 해 두었습니다 |
| 창 맞춤 | 툴바의 네 단추 — **창 맞춤**(쪽 전체), **가로 맞춤**, **세로 맞춤**, **원본 크기**. 창 크기를 바꾸면 쪽이 따라 맞춰지고, 쪽은 언제나 창 가운데에 놓입니다 |
| 갤러리 | 툴바의 서가 단추(또는 **Ctrl+Shift+G**)로 지금까지 읽은 책을 모아 봅니다. **큰 아이콘**은 표지와 진행 막대, **자세히**는 제목·지은이·형식·크기·진행·마지막 읽음·위치를 표로 보여 줍니다. 위쪽에서 찾고 정렬하며, 책마다 ✕로 빼거나 휴지통으로 전부 비웁니다 |
| 그림 복사 | 툴바의 그림 단추(또는 **Ctrl+Shift+C**)는 보고 있는 쪽 그림을 클립보드에 넣습니다. 본문 안의 그림은 **그 그림 위에서 오른쪽 단추**를 누른 뒤 복사하면 그 그림이 복사됩니다 |
| 테마 | 툴바 🎨 를 누르면 다음 테마, 옆 화살표를 누르면 **별도 창의 목록**에서 고릅니다. 목록과 설정 창 모두 **어두운 테마 20종 / 밝은 테마 20종** 두 묶음으로 나뉘어 있고, 묶음 오른쪽에 개수가 붙습니다. 목록이 화면보다 길면 단을 나눠 한 화면에 보여 줍니다 |
| 언어 | 툴바 국기 — 국기는 **누르면 바뀔 언어**를 보여 줍니다 |
| UI 글꼴 | 설정 → 모양: 시스템 글꼴 전체, 크기(10–24px), 굵게 · 기울임 · 밑줄 |
| 배경 이미지 | 설정 → 보기: 그림을 고르고 투명도와 맞추기(채우기 · 맞춤 · 바둑판 · 가운데) |
| 패널 | F9 / F10, 또는 툴바 오른쪽의 패널 버튼. 구분선을 끌어 너비를 조절합니다 |
| 툴바 이름 표시 | 설정 → 보기: 아이콘 옆에 이름을 함께 표시 |

설정 창은 **고정 크기의 독립된 창**(860×570)이며, 탭으로 나뉘어 있어 내부 스크롤이
없습니다. 바꾼 설정은 **즉시 적용**되므로 "저장"이 따로 없고, 창 아래에 두 단추가
있습니다 — 왼쪽 **모든 설정 초기화**(최근 파일 목록은 남습니다), 오른쪽 **확인**(창을
닫습니다). 오른쪽 위 **✕** 로도 닫히며, 마우스를 올리면 붉게 바뀝니다.

## 8. 메뉴와 바로가기 메뉴

툴바의 **파일 · 읽기 · 보기 · 표시 · 프로그램** 메뉴와 본문 위 **오른쪽 클릭** 메뉴는
모두 **독립된 창**으로 열립니다. 그래서 목록이 길어도 프로그램 창 밖까지 펼쳐지며,
여러 열로 접히지 않고 **한 줄에 한 항목**씩, 아이콘·이름·단축키가 함께 표시됩니다.

## 10. 설치

Windows 설치 파일(`MyEBookReader Setup 1.0.0.exe`)을 실행하면

1. **설치 언어**를 한국어와 영어 중에서 고릅니다
2. 이전 버전이 있으면 **완전히 제거한 뒤** 새로 설치합니다
3. 예전 설정·독서 데이터가 남아 있으면 **지울지 물어봅니다** (아니요 = 그대로 이어서 사용)
4. 바탕화면·시작 메뉴 바로가기와 파일 연결을 고릅니다
5. `.ebkr` 형식이 **전용 아이콘**과 함께 등록되고, 책 형식들의 [연결 프로그램]에 추가됩니다

macOS는 `.dmg`, Linux는 `.AppImage` 와 `.deb` 를 제공합니다.

## 11. 문제가 생기면

오류 창에는 **무슨 작업 중이었는지 · 구체적인 내용 · 기술 상세(스택)** 가 함께 나옵니다.
[오류 내용 복사]를 누르면 전체가 클립보드에 들어가므로 그대로 문의에 붙여넣을 수 있습니다.

| 증상 | 확인할 것 |
| --- | --- |
| `.azw3` · `.azw` 가 열리지 않음 | **DRM이 걸린 파일은 열지 않습니다** — Amazon에서 구입한 파일 대부분이 여기 해당하고, 오류 창이 그 이유를 말해 줍니다. DRM이 없는 `.azw3`(예: Calibre가 만든 것)는 그대로 열립니다 |
| `.azw3` 의 글이 뒤섞여 보임 | 이 버전에서 KF8 재조립을 구현했으므로 더 이상 그렇지 않아야 합니다. 그래도 그렇다면 오류 내용을 복사해 알려 주세요 |
| TIFF가 "compression" 오류 | JPEG-in-TIFF 등 일부 압축은 읽지 않습니다. PNG로 변환해 보세요 |
| DICOM이 "transfer syntax" 오류 | JPEG 2000 · JPEG-LS · RLE 로 압축된 영상은 읽지 않습니다 |
| HEIC/HEIF가 열리지 않음 | 시스템 코덱이 있어야 합니다. JPG나 PNG로 변환해 여세요 |
| `.cbr` 만화가 열리지 않음 | RAR 압축입니다. `.cbz`(ZIP)로 다시 저장하세요 |
| DRM 오류 | 보호된 책은 복호화하지 않습니다 |
| 그림이 보이지 않음 | 책 안에 그림 자원이 없거나 경로가 어긋난 파일입니다 |
| 웹에서 폴더 탐색이 안 됨 | 브라우저에는 파일 시스템 접근 권한이 없습니다. 데스크톱 앱을 쓰세요 |
