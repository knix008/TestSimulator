# MyEBookReader

여러 형식의 전자책과 그림을 한 프로그램에서 읽고 보는 **다중 플랫폼 전자책 리더**입니다.
하나의 코드베이스로 **웹 브라우저 · Windows · macOS · Linux** 에서 동작하며,
각 플랫폼용 설치 파일을 만들 수 있습니다.

제작자: **SHKWON(knix008@naver.com)**

## 읽을 수 있는 형식

| 형식 | 확장자 | 구현 |
| --- | --- | --- |
| EPUB 2 / 3 | `.epub` | 자체 ZIP·DEFLATE 구현 + OPF·NCX·NAV 해석 (목차 · 표지 · 그림 · 내부 링크) |
| PDF | `.pdf` | pdf.js — 쪽 단위 캔버스 렌더링, 선택 가능한 텍스트 층, 문서 목차 |
| MOBI / AZW | `.mobi` `.prc` `.azw` `.azw3` | Palm 데이터베이스 + PalmDOC(LZ77) 해제, EXTH 메타데이터, 내장 그림 |
| FictionBook | `.fb2` | XML 본문을 HTML로 변환, `<binary>` 그림 복원 |
| 만화책 | `.cbz` | ZIP 안의 그림을 쪽 단위로 (자연 정렬: page2 → page10) |
| Markdown | `.md` | 자체 렌더러 (제목 · 목록 · 표 · 코드 · 인용 · 링크 · 그림) |
| HTML | `.html` `.htm` `.xhtml` | 제목 기준으로 장 분리 |
| 텍스트 | `.txt` | 장 제목("제3장", "Chapter 3") 또는 크기로 분리, 인코딩 자동 판별 |
| 그림 | `.jpg` `.png` `.gif` `.webp` `.bmp` `.avif` `.svg` `.ico` `.heic` | 브라우저가 직접 그립니다 (HEIF는 플랫폼에 따라 다름) |
| TIFF | `.tif` `.tiff` | 자체 디코더 — 8/16비트, 흑백·팔레트·RGB(A), 무압축·PackBits·LZW·Deflate |
| DICOM | `.dcm` | 자체 파서 — 태그·전송 구문 해석, 윈도 레벨 적용, 환자·검사 정보 표시 |
| 독서 파일 | `.ebkr` | 이 프로그램의 **문서 형식** — 책갈피 · 형광펜 · 메모 · 읽던 위치 |

> 외부 의존성은 PDF를 위한 `pdfjs-dist` 하나뿐입니다. ZIP · DEFLATE · MOBI ·
> FB2 · Markdown 해석기는 모두 이 저장소 안에 있습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 읽기 | **이어보기(스크롤)** 와 **한 쪽씩 보기**(CSS 단 나눔), 두 단 보기, 본문 폭 · 글꼴 · 크기 · 줄 간격 · 자간 · 양쪽 정렬 · 들여쓰기 |
| 쪽 배치 | PDF·만화·그림을 **한 장 보기 / 두 장씩 보기(펼침)** 로 — 펼침에서는 한 번에 두 쪽씩 넘어갑니다 |
| 넘김 효과 | 쪽을 넘길 때 **없음 · 밀기 · 책장 넘김** 중에서 고릅니다. 책장 넘김은 **낱장 한 장이 실제로 넘어갑니다** — 앞면은 보고 있던 쪽, 뒷면은 넘긴 뒤의 쪽이고, 제본선을 축으로 끝까지 돌아 반대쪽 위에 내려앉습니다. 두 장씩 보기에서는 **다음은 오른쪽, 이전은 왼쪽** 낱장이 넘어가고 가운데는 붙어 있습니다. 고른 효과는 시스템이 '애니메이션 줄이기'여도 동작합니다 |
| 글자 크기 | 툴바에 **축소 · 현재 크기 · 확대** 세 버튼 — 가운데 버튼을 누르면 100 %로 돌아갑니다 |
| 확대 | 본문은 **Ctrl+휠**로 글자 크기(60 %–300 %), PDF·만화·그림은 확대 비율(50 %–800 %) · 너비/페이지 맞춤 · 회전 |
| 책 탭 | 여러 책을 **탭**으로 동시에. 탭이 많으면 오른쪽 `<` `>` 로 이동 (Ctrl+Tab / Ctrl+W) |
| 목차 | EPUB 3 NAV · EPUB 2 NCX · PDF 목차 · MOBI/FB2/MD 제목에서 자동 생성, 트리로 표시 |
| 책갈피 | **Ctrl+B** 로 추가하고, 툴바의 책갈피 목록(별도 창) · 왼쪽 패널 · 상태 바 개수로 관리합니다 |
| 표시 | 형광펜(Ctrl+H) · 메모 · 복사 클립. **원본 책은 절대 고쳐 쓰지 않고** `.ebkr` 독서 파일에 저장 |
| 실행 취소 / 다시 실행 | 모든 표시 작업을 최대 100단계 (Ctrl+Z / Ctrl+Y) |
| 찾기 | 책 전체 검색 — 결과 목록에서 해당 장으로 이동하고 본문에서 **강조** (F3 / Shift+F3) |
| 인쇄 | **전체 · 현재 장 · 사용자 지정 범위**(`1-4, 9, 12-`), **미리보기와 페이지 설정**(용지 · 방향 · 여백)을 같은 창에서 (Ctrl+P). 미리보기는 고른 용지의 **실제 비율과 여백**으로 그려지므로 설정을 바꾸면 바로 보입니다 |
| 내보내기 | 책 전체를 `.txt` 또는 `.html` 로 |
| 메뉴 바 | 제목 표시줄 아래 **파일 · 읽기 · 보기 · 표시 · 프로그램** 메뉴 바. 툴바와 같은 메뉴를 열고, Alt+F·Alt+R 처럼 글자로도 열립니다 (보기 메뉴에서 감출 수 있음) |
| 쪽 넘김 단추 | 본문 위 좌우에 **이전 쪽 · 다음 쪽** 단추가 떠 있습니다 |
| 창 맞춤 | 툴바에서 **창 맞춤 · 가로 맞춤 · 세로 맞춤 · 원본 크기**를 바로 고릅니다. 창 크기가 바뀌면 쪽도 따라 맞춰지고, 쪽은 항상 가운데 놓입니다 |
| 메뉴 | 모든 메뉴가 **독립된 창**으로 열려 본체 밖까지 펼쳐지고, 한 줄에 한 항목씩 **아이콘 + 이름 + 단축키**로 표시됩니다. 화면보다 긴 메뉴(40종 테마 목록)는 잘리지 않고 **여러 단으로 나뉘어** 보입니다 |
| 대화상자 | 설정 · 정보 · 오류 · 진행 · 인쇄 · 속성 · 단축키 모두 **별도 창** — 고정 크기, 내부 스크롤 없음, 본체를 닫으면 함께 닫힘 |
| 패널 | 왼쪽=도구(목차 · 서재 · 책갈피 · 찾기), 오른쪽=속성(책 정보 · 읽기 설정 · 메모). 구분선을 끌어 너비 조절 (F9 / F10) — **탭 이름이 잘리는 폭까지는 좁아지지 않습니다** |
| 테마 | **40가지 — 어두운 테마 20종과 밝은 테마 20종**. 설정 창과 목록에서 두 묶음으로 나뉘어 보입니다. 버튼으로 다음 테마, 화살표로 목록(별도 창) |
| 언어 | 한국어 · English. 툴바 국기는 **바꿀 언어**를 보여 줍니다 |
| 글꼴 | 시스템에 설치된 **모든 글꼴**(UI · 본문 각각), 크기 · 굵게 · 기울임 · 밑줄 |
| 배경 | 읽기 화면 뒤에 **배경 이미지**(크기 제한 없음) + 투명도 · 맞추기 방식 |
| 갤러리 | 읽은 책을 모아 보여 줍니다 — **큰 아이콘**(표지)과 **자세히**(제목·지은이·형식·크기·진행·마지막 읽음·위치)를 오가고, 찾기·정렬·개별 삭제·비우기 (Ctrl+Shift+G). **10만 권도 20 ms 안에** 펼쳐집니다 |
| 최근 파일 | 최대 10개, 개별 삭제 · 전체 삭제, 최근 폴더 기억, 책마다 **읽던 위치** 기억 |
| 끌어다 놓기 | 탐색기에서 책을 창 안으로 끌어다 놓으면 열립니다 |
| 클립보드 | 선택한 글 **Ctrl+C**, 이 장 전체 복사, 보고 있는(또는 오른쪽 클릭한) **그림 복사 Ctrl+Shift+C**, Ctrl+V 로 붙여넣어 메모 만들기 |
| 오류 처리 | 무슨 작업 중이었는지 + 구체적 내용 + 기술 상세를 팝업으로, **한 번에 복사** |
| 진행 표시 | 열기 · 저장 · 내려받기 · 인쇄 등 오래 걸리는 작업의 진행률 팝업 |
| 상태 바 | 상태 · 책 · 폴더 · 장 번호 · 진행률 · 형식 · 크기 · 선택 · 편집 기록 · 책갈피 수 · 저장 여부 |
| 설정 유지 | 테마 · 언어 · 글꼴 · 읽기 방식 · 쪽 배치 · 넘김 효과 · 패널 · 최근 파일 · 폴더를 다음 실행 때 복원 |

### 파일 형식 등록

설치 프로그램이 `.ebkr`(독서 파일)을 **전용 아이콘과 함께** 시스템에 등록하고,
`.epub` `.pdf` `.mobi` `.azw3` `.fb2` `.cbz` 의 **[연결 프로그램]** 목록에 MyEBookReader를 추가합니다.
원하면 EPUB의 기본 프로그램으로 지정할 수도 있습니다.

## 실행

```bash
npm install          # 의존성 설치 (샘플 책·아이콘·빌드 정보도 준비)
npm start            # 데스크톱(Electron) 개발 실행
npm run web          # 웹 브라우저용 개발 서버 (http://localhost:5183)
npm test             # 전체 테스트 (종류별 분류 + 요약 표)
npm run smoke        # 실제 Electron 창에서 GUI 스모크 테스트
npm run generate:samples   # samples/ 에 형식별 샘플 책·그림 생성
npm run shoot:dialog -- settings out.png   # 팝업 창 하나를 그대로 촬영(레이아웃 점검용)
```

## 설치 파일 만들기

```bash
npm run build:win    # release/MyEBookReader Setup 1.0.0.exe  (NSIS, 한국어/영어)
npm run build:mac    # release/MyEBookReader-1.0.0.dmg
npm run build:linux  # release/MyEBookReader-1.0.0.AppImage + .deb
npm run build        # 웹 배포용 정적 번들 (dist/)
```

설치 파일은 빌드가 끝나면 프로젝트 루트에도 복사됩니다.
설치 프로그램은 **한국어와 영어 중에서 고를 수 있고**, 이전 버전이 있으면 완전히
제거한 뒤 새로 설치하며, 예전 설정·독서 데이터가 남아 있으면 **지울지 물어봅니다**.

## 테스트

```
npm test
```

결과는 **책 형식 · 핵심 엔진 · 설정/상태 · GUI 동작 · 언어 · 빌드/패키징** 으로
분류되어 출력되고, 마지막에 **세로로 줄이 맞는 요약 표**(분류 · 통과 · 전체 · 시간 · 결과)와
전체 합계가 나옵니다. 한글과 영문이 섞여도 칸이 어긋나지 않도록 터미널이 실제로
그리는 폭으로 정렬합니다.
GUI 항목은 실제 컴포넌트를 렌더링해 버튼 · 메뉴 · 패널 · 대화상자 · 단축키를
눌러 가며 확인하고, `npm run smoke` 는 같은 일을 **진짜 Electron 창**에서 합니다.
