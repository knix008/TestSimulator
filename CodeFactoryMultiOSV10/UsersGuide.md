# CodeFactory 사용자 가이드

CodeFactory는 소스 코드를 읽어 **무엇이 어디에 있고, 무엇이 위험한지**를 보여 주는 도구입니다.
이 문서는 화면 구성과 조작 방법을 다룹니다. 숫자를 어떻게 해석할지는
[CodeAnalysisGuide.md](CodeAnalysisGuide.md)를 보세요.

---

## 1. 화면 구성

```
┌──────────────────────────────────────────────────────────────────────┐
│ CodeFactory                        (창 이동 영역)      ⓘ  ─  □  ✕ │  ← 타이틀 표시줄
├──────────────────────────────────────────────────────────────────────┤
│ 파일 │ 🔎뷰 [뷰▼] [🔍검색...] │ ▶분석 │ 보고서 그림 CSV 패널 🎨▾ … ⚙설정 (한)  ⓘ정보 │  ← 툴바
├──────────────┬───────────────────────────────────────────────────────┤
│ 분석 대상    │                                                  │
│  루트 디렉터리│                 현재 뷰                          │
│  프로그래밍   │            (우클릭 → 컨텍스트 메뉴)              │
│   언어        │                                                  │
│  하위 디렉터리│                                                  │
│  [분석 실행] │                                                  │
├──────────────┴──────────────────────────────────────────────────┤
│ 상태 메시지                    진행률   파일·함수·LOC   Electron │  ← 상태 바
└─────────────────────────────────────────────────────────────────┘
```

**타이틀 표시줄**에는 앱 이름과, 오른쪽 끝에 **프로그램 정보(ⓘ)** · **최소화 · 최대화 · 닫기**만
있습니다. 빈 영역을 끌면 창이 움직입니다.

**툴바**에 나머지가 모두 모여 있습니다.

| 위치 | 내용 |
|------|------|
| 왼쪽 | **파일** 메뉴 |
| 가운데 | **뷰** 선택기, **검색**(돋보기), **분석 실행**, 보고서·다이어그램·CSV 내보내기, 패널 토글, 테마 |
| 오른쪽 | **설정** · **화면 언어** · **정보** — 순서대로 |

툴바는 항상 **한 줄**이고, **모든 버튼의 글자 라벨이 항상 보입니다.**
창을 좁혀도 라벨이 숨지 않도록 창의 최소 폭(1160px)이 툴바가 필요로 하는 폭에
맞춰져 있습니다. 모든 버튼에 툴팁도 있습니다.

**뷰**는 드롭다운 하나로 고릅니다(같은 15개를 나열하던 메뉴는 없앴습니다).

## 2. 분석 실행

### 2.1 루트 디렉터리 선택

- **데스크톱**: `찾아보기...`(테마마다 다른 보조 강조색 버튼) → 폴더 선택 대화상자
- **브라우저**: `찾아보기...`(Chrome·Edge의 폴더 선택 API) 또는 `폴더 업로드`(모든 브라우저)

> 브라우저에서 고른 폴더는 **브라우저 안에서만** 읽힙니다. 파일이 서버로 전송되지 않습니다.

### 2.2 프로그래밍 언어

처음에는 12종이 **모두 선택**된 상태입니다. 폴더를 고르고 **분석할 하위 디렉터리를
체크하면, 그 디렉터리에 실제로 있는 언어가 자동으로 선택됩니다.** 디렉터리 체크를
바꿀 때마다 다시 계산되므로, 폴더를 하나 더 넣으면 그 언어도 따라 들어옵니다.

각 언어 오른쪽 숫자는 **선택한 디렉터리 안에서** 발견된 파일 수이고,
발견되지 않은 언어는 흐리게 표시됩니다.

| 버튼 | 동작 |
|------|------|
| `전체 선택` | 12종 모두 켭니다 |
| `전체 해제` | 모두 끕니다 (이 상태에서는 분석을 실행할 수 없습니다) |
| `자동 감지` | 이 폴더에서 발견된 언어만 남깁니다 |

한 번이라도 직접 체크를 바꾸면 그 선택이 존중되어, 다음에 폴더를 바꿔도 자동 감지가
덮어쓰지 않습니다. 다시 맡기려면 `자동 감지`를 누르세요.

### 2.3 하위 디렉터리

트리에서 분석할 폴더를 고릅니다.

- `bin`, `obj`, `.git`, `node_modules`, `dist`, `build`, `target`, `venv`, `vendor` 등은
  **기본으로 꺼져** 있습니다.
- 폴더 체크박스를 누르면 **하위 트리 전체**가 함께 켜지거나 꺼집니다.
- 최소 한 개는 선택해야 분석이 시작됩니다.

### 2.4 실행과 취소

**툴바의 `분석 실행` 버튼**을 누릅니다(분석을 한 번 마친 뒤에는 `다시 분석`으로 바뀝니다).
왼쪽 패널은 *무엇을* 분석할지만 정하고, 실행 버튼은 툴바에 있습니다.

상태 바에 단계와 진행률이 표시됩니다.
분석이 **0.7초를 넘기면 진행률 팝업 창**이 뜹니다 — 단계 설명, 진행률 막대와 백분율,
그리고 `취소` 버튼이 있습니다. 짧은 분석에서는 창이 깜박이지 않도록 뜨지 않습니다.

```
소스 파일을 읽는 중 → 함수·타입 추출 → 호출 그래프 → 코드 메트릭 →
전역 변수 → DB 스키마·접근 → 중복 코드 → 버그 위험·보안 → 아키텍처
```

분석 중에는 툴바 버튼이 `취소`로 바뀝니다. 진행률 팝업에도 `취소`가 있습니다.
취소하면 작업 스레드가 즉시 종료됩니다.

## 3. 뷰

툴바 왼쪽 선택기, **뷰** 메뉴, 또는 우클릭 컨텍스트 메뉴로 전환합니다.

뷰를 바꿀 때 그릴 내용이 많으면 **"뷰를 그리는 중" 팝업**이 잠시 뜹니다.
화면이 멈춘 것처럼 보이지 않도록 하는 표시이며, 다 그려지면 저절로 사라집니다.

### 3.1 다이어그램 공통 조작

| 동작 | 방법 |
|------|------|
| 이동(팬) | 빈 공간을 끌기 |
| 확대·축소 | 마우스 휠, 또는 `+` / `−` 버튼 |
| 화면 맞춤 | `화면 맞춤` 버튼 |
| 원래 크기 | `원래 크기` 버튼 |
| 소스 열기 | 노드 더블클릭 |
| 내보내기 | 툴바 다이어그램 버튼 → PNG / WebP / JPEG / GIF / SVG / PDF (투명 배경·해상도 선택) |

다이어그램을 **처음 열 때는 가로 가운데, 세로 위쪽**에 맞춰집니다 — 그래프는 위에서
아래로 읽으므로 뿌리가 화면 한가운데가 아니라 상단에 오는 편이 찾기 쉽습니다.

> **확대 상태는 유지됩니다.** 두 가지 모두에서:
> - 노드를 **펼치거나 접어도** 확대·축소 비율과 위치가 그대로 남습니다.
> - **다른 뷰에 다녀와도** 그 뷰를 떠날 때의 확대·축소와 위치로 되돌아옵니다.
>   뷰마다 따로 기억하므로, 호출 그래프를 크게 보고 ERD를 작게 본 상태가 각각 유지됩니다.
>
> 진입점·방향·검색어를 바꿔 **그림 자체가 달라질 때만** 다시 화면에 맞춰집니다.
> 새로 분석하면 기억한 상태는 지워집니다.

### 3.2 분석 Summary

- **코드 건강 점수** (0~100, 등급 A~F)와 8개 항목별 점수
- **우선 조치** — 같은 노력으로 가장 많은 위험을 줄일 수 있는 순서
- 파일·함수·타입·중복·버그 위험·보안·테이블·전역 변수 요약 카드
- **프로그래밍 언어 구성**과 **검사 항목별 결과**
- 건너뛴 파일과 그 이유

### 3.3 호출 그래프

왼쪽 트리와 오른쪽 다이어그램이 **같은 펼침 상태**를 공유합니다.

왼쪽 트리는 부모–자식 사이에 **연결선**이 그려진 트리뷰입니다.

- 진입점 선택기: `main`, `Main`, `WinMain` 등 언어 관례를 먼저 찾고,
  없으면 아무도 호출하지 않는 함수를 연결 수 순으로 나열합니다.
- 진입점을 고르면 **처음부터 모두 펼쳐진 상태**로 열립니다(최대 8단계).
- 다이어그램 툴바의 `모두 펼치기` / `모두 접기` 버튼으로 언제든 바꿀 수 있습니다.
- `↻` 표시는 재귀(순환) 지점이며 더 이상 펼치지 않습니다.
- 노드 오른쪽 아래 원형 버튼으로 그 자리에서 펼치고 접을 수 있습니다.
- 방향: `좌→우` / `위→아래`

### 3.4 클래스 · 상속 다이어그램

- UML 박스에 스테레오타입(«interface» 등), 속성, 연산을 표시
- 실선 + 속 빈 삼각형 = 상속, 점선 + 삼각형 = 인터페이스 구현
- God 타입·낮은 응집도 타입은 테두리가 경고색으로 바뀝니다
- 타입이 많으면 `+80` 버튼으로 더 불러옵니다
- 검색어를 입력하면 일치하는 타입만 남습니다

### 3.5 시퀀스 다이어그램

진입점에서 시작하는 호출 흐름을 파일 단위 라이프라인으로 그립니다.
메시지가 많으면 페이지로 나뉘며(`◀` `▶`), 한도를 넘으면 `truncated` 배지가 붙습니다.

### 3.6 데이터/제어 흐름

한 함수를 고르면 **입력**(호출자, 읽는 전역 변수, 읽는 테이블)과
**출력**(호출 대상, 쓰는 전역 변수, 쓰는 테이블)을 양쪽에 배치합니다.
전역 변수는 주황, 테이블은 파랑 테두리입니다.

### 3.7 파일 관계 · 디렉터리 관계

호출 그래프를 파일/디렉터리 단위로 축약합니다. 선 두께는 호출 횟수에 비례하고,
노드를 클릭하면 그 노드와 연결된 선만 강조됩니다.

### 3.8 코드 메트릭

5개 탭 — **파일 · 함수 · 타입 · 패키지 · 아키텍처**.

- 열 머리글을 클릭하면 정렬(내림차순 → 오름차순 → 해제)
- 임계값을 넘은 값은 **주황(경고)** 또는 **빨강(심각)** 으로 표시
- 행을 더블클릭하면 소스 위치로 이동
- **아키텍처** 탭은 인사이트별로 요약 · 조치 방법 · 해당 항목 목록을 보여 줍니다

표시할 탭은 `설정 → 분석 항목 → 표시할 탭`에서 끌 수 있습니다.

### 3.9 중복 코드

그룹을 고르면 아래에 **모든 발생 위치**(칩 버튼)와 **중복된 원문**이 나옵니다.
칩을 누르면 해당 위치로 이동합니다. 최소 줄 수는 설정에서 바꿉니다(기본 10줄).

### 3.10 전역 변수

전역·정적 변수 목록과 읽기/쓰기 횟수. 상수가 아닌데 두 곳 이상에서 쓰는 변수는
쓰기 열이 경고색이 됩니다. 행을 고르면 아래에 접근 함수 목록이 나옵니다.

### 3.11 DB ERD

테이블 박스에 컬럼·자료형·키를 표시합니다. 🔑 는 기본 키, ↗ 는 외래 키입니다.
실선은 선언된 외래 키, 점선은 `*_id` 규칙으로 **추정한** 참조입니다.

### 3.12 DB 테이블 접근

3개 탭 — **테이블 · 컬럼 · DB**.

- 테이블 탭에서 행을 고르면 아래에 **컬럼 목록**과 **접근 함수**가 나란히 나옵니다
- CRUD 열은 검출된 동작을 `CRUD` 문자로 표시합니다 (예: `R`, `CU`, `CRUD`)
- DB 탭은 연결 문자열·SQLite 파일에서 찾은 데이터베이스 인스턴스 목록입니다

### 3.13 버그 위험 분석

분류 칩으로 걸러 봅니다. 각 행은 심각도 · 분류 · 파일 · 줄 · 함수 · 내용 · 코드 조각을 담습니다.

### 3.14 정보 보호 및 보안

규칙 칩을 고르면 그 규칙의 **조치 방법**이 위에 표시되고 아래에 해당 위치가 나열됩니다.

## 4. 검색

**Ctrl+F** 또는 툴바의 **돋보기 검색 상자**. 현재 뷰에 맞게 동작합니다.

- 표: 이름·파일·내용에서 부분 일치하는 행만 남김
- 다이어그램: 일치하는 노드를 강조(클래스 다이어그램·ERD는 일치 항목만 표시)
- 호출 그래프: 일치하는 함수 이름을 강조색으로 표시

## 5. 내보내기

### 5.1 분석 보고서

툴바의 보고서 버튼 → 형식과 절을 고르고 `보고서 생성`.

| 형식 | 특징 |
|------|------|
| **HTML** | 단일 파일, 스타일 내장, 현재 테마 색상, 목차 포함 |
| **Markdown** | 표·막대그래프 포함, 문서 저장소에 그대로 커밋 가능 |
| **Word (.docx)** | 표와 제목 스타일 포함, 외부 도구 없이 생성 |
| **PDF** | 데스크톱은 바로 저장, 브라우저는 인쇄 대화상자에서 "PDF로 저장" |

절은 13개 중 필요한 것만 고를 수 있습니다. 보고서 본문 언어는 화면 언어를 따릅니다.

### 5.2 다이어그램

다이어그램 뷰에서만 활성화됩니다.

| 형식 | 투명 배경 | 비고 |
|------|:--------:|------|
| **PNG** | O | 무손실 래스터. 문서·슬라이드에 얹기 좋습니다 |
| **WebP** | O | PNG와 같은 그림을 1/3 이하 용량으로 |
| **JPEG** | X | 사진용 손실 압축. 알파 채널이 없어 테마 배경색이 칠해집니다 |
| **GIF** | O | 256색으로 줄여 저장. 투명은 한 색상만 지정됩니다 |
| **SVG** | O | 벡터 원본 (테마 색상이 실제 값으로 구워져 어디서 열어도 같게 보입니다) |
| **PDF** | X | 인쇄용 페이지 (가로/세로는 다이어그램 비율에 따라 자동) |

내보내기 창에서 세 가지를 고릅니다.

- **형식** — 위 6가지
- **배경** — `투명 배경으로 내보내기`. 알파 채널이 없는 JPEG·PDF에서는 이 항목이
  비활성화됩니다. 켤 수 없는 것을 켜 놓고 검은 배경이 나오는 편보다 낫습니다
- **해상도** — 래스터 형식만. 1× ~ 4×, 기본 2×

> **이미지는 항상 도형 전체를 담는 최소 크기입니다.** 화면에서 얼마나 확대·축소해
> 놓았는지, 캔버스 여백이 얼마나 남아 있는지와 무관하게 도형의 실제 경계(+8px 여백)로
> 잘라 저장합니다.

### 5.3 메트릭 CSV

함수 하나당 한 행, 25개 열 + `warnings` 열(걸린 검사 항목 이름).
UTF-8 BOM이 붙어 Excel에서 한글이 깨지지 않습니다.

## 6. 설정

툴바 오른쪽의 **설정** 버튼.

> **팝업 창은 모두 진짜 창입니다.** 설정·프로그램 정보·보고서·다이어그램 내보내기는
> 각각 별도의 OS 창으로 열리므로 **앱 창 밖으로 끌어낼 수 있습니다.**
> 다만 별도의 프로그램은 아니어서, **앱 창을 닫으면 함께 닫힙니다.**
> 테마와 화면 언어도 열려 있는 팝업 창에 즉시 반영됩니다.
> (웹 판은 브라우저 탭이라 창을 만들 수 없어 페이지 안에서 열립니다.)

### 6.1 분석 항목

44개 검사 항목을 개별로 켜고 끕니다. 임계값이 있는 항목은 오른쪽에서 값을 바꿉니다.
항목 위에 마우스를 올리면 그 항목이 무엇을 뜻하는지 툴팁이 나옵니다.

그룹 제목 옆 `✓` / `✕` 로 그룹 전체를 한 번에 켜고 끌 수 있습니다.

> 끈 항목은 **계산 자체를 건너뜁니다.** 예를 들어 `DB 스키마`를 끄면
> ERD·테이블 접근·DB 인스턴스 분석이 모두 생략되어 분석이 빨라집니다.

`기본값` 버튼은 모든 설정을 처음 상태로 되돌립니다. `적용`을 눌러야 저장되고 창이 닫힙니다.

> 설정 창에는 **분석 항목만** 있습니다. 테마와 화면 언어는 눈으로 보고 고르는 설정이라
> 누르는 즉시 적용되도록 툴바로 옮겼습니다.

### 6.2 테마 (툴바)

툴바 오른쪽 끝의 **팔레트 버튼**입니다. 두 부분으로 나뉩니다.

| 부분 | 동작 |
|------|------|
| 🎨 팔레트 | **누를 때마다 다음 테마로** 바뀝니다 (6종을 순환) |
| ▾ 화살표 | 테마 목록을 열어 **직접 고릅니다** — 각 항목에 그 테마의 실제 색이 미리 보입니다 |

어느 쪽이든 **누르는 즉시** 적용됩니다. `적용` 버튼을 거치지 않으며, 선택은 바로 저장됩니다.
테마를 바꾸면 UI뿐 아니라 다이어그램 색과 내보내는 HTML 보고서 색까지 함께 바뀝니다.

### 6.3 화면 언어 (툴바)

설정 버튼 오른쪽의 버튼입니다. 아이콘이 **지금 켜져 있는 언어**를 보여 줍니다 —
한국어일 때는 **(한)**, 영어일 때는 **(EN)**. 누르면 즉시 전환되고 아이콘도 함께 바뀌며,
열려 있는 팝업 창의 언어도 따라갑니다. 툴팁에 지금 언어와 바뀔 언어가 함께 나옵니다.

## 9. 문제 해결

| 증상 | 원인과 해결 |
|------|-------------|
| `찾아보기...`가 비활성 | 브라우저가 폴더 선택 API를 지원하지 않습니다. `폴더 업로드`를 쓰세요 |
| 분석 결과가 비어 있음 | 하위 디렉터리를 하나도 고르지 않았거나, 고른 언어의 파일이 없습니다 |
| `분석 실행`이 눌리지 않음 | 폴더·하위 디렉터리·프로그래밍 언어가 각각 최소 1개씩 선택되어야 합니다 |
| 함수가 안 잡힘 | 매크로·전처리기·동적 정의는 정적 분석이 놓칠 수 있습니다 |
| Git 변경 열이 모두 0 | 분석 대상이 Git 저장소가 아니거나 `git`이 PATH에 없습니다 (브라우저는 항상 0) |
| 테이블 접근이 비어 있음 | 런타임에 조립되는 SQL은 추적되지 않습니다 |
| 분석이 오래 걸림 | 진행률 팝업의 `취소`로 중단하고, 하위 디렉터리 범위를 좁히거나 `중복 코드`·`DB 스키마` 검사를 끄세요 |
| 오류 화면이 나타남 | 화면을 그리다 오류가 나면 흰 화면 대신 오류 내용과 `다시 시도`·`새로 고침`·`오류 복사` 버튼이 표시됩니다. 내용을 복사해 알려 주세요 |
| 큰 파일이 빠짐 | 2 MB 초과 파일과 바이너리는 건너뜁니다 (Summary에 이유가 표시됩니다) |
