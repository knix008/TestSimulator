# EaxyMD — 마크다운 편집기

실시간 미리보기와 문서 구조 사이드바를 갖춘 Windows 마크다운 편집기입니다.

## 화면 구성

```
┌─────────────────────────────────────────────────────────────┐
│  파일(F)  도움말(H)                                          │
│  ☰ | H1 H2 H3 | B I S̶ | `코드` ```블록``` | 링크 이미지 … │
├──────────────┬──────────────────────┬────────────────────────┤
│ 문서 구조  ◀ │                      │                        │
│──────────────│   마크다운 편집 창   │   HTML 미리보기 창     │
│ # 제목       │                      │                        │
│   ## 소제목  │                      │                        │
│     ### 항목 │                      │                        │
└──────────────┴──────────────────────┴────────────────────────┘
```

## 주요 기능

- **실시간 미리보기** — 마크다운 입력 즉시 HTML로 렌더링 (300ms 디바운스)
- **문서 구조 사이드바** — H1~H6 제목을 계층형 트리로 표시, 클릭 시 해당 위치로 이동
- **사이드바 접기/펼치기** — 툴바의 ☰ 버튼 또는 사이드바의 ◀ 버튼으로 토글
- **마크다운 툴바** — 클릭으로 기호 삽입 (제목, 굵게, 기울임, 취소선, 코드, 링크, 이미지, 목록, 인용, 표, 구분선)
- **파일 저장/열기** — `.md`, `.txt` 지원, 저장 여부 확인 포함

## 단축키

| 단축키 | 기능 |
| --- | --- |
| Ctrl+N | 새 파일 |
| Ctrl+O | 열기 |
| Ctrl+S | 저장 |
| Ctrl+Shift+S | 다른 이름으로 저장 |
| F1 | 프로그램 정보 |

## 개발 환경

- .NET 8 Windows Forms
- [Markdig](https://github.com/xoofx/markdig) — 마크다운 파싱
- [Microsoft WebView2](https://developer.microsoft.com/microsoft-edge/webview2/) — HTML 미리보기

## 실행 방법

```bash
dotnet run
```

> WebView2 런타임이 필요합니다. Microsoft Edge가 설치되어 있으면 별도 설치가 필요하지 않습니다.
