| 영역 | 설명 |
|------|------|
| 툴바 | OS 타이틀바를 대신합니다. 앱 이름, **프로파일**(선택 · 💾 저장 · 🗑 삭제), 테마(클릭 = 다음 테마, ▾ = 16개 목록), 언어 국기(전환할 언어의 국기), 설정, 정보, 데스크톱 앱에서는 **─ 최소화 · □ 최대화/복원 · ✕ 닫기**. 빈 곳을 드래그하면 창이 움직이고 더블클릭하면 최대화/복원됩니다 |
| 제어 바 | **▶ 시작 / ■ 중지**, 프로토콜 스위치(FTP · FTPS · SFTP)와 포트, 실행 중에는 프로토콜별 **현재 접속 수**, 「FTP에 AUTH TLS 허용」, 오른쪽에 통계(현재/총 접속, 업로드 수·용량, 다운로드 수·용량). 이 줄은 **항상 한 줄**입니다 — 창의 최소 크기가 언어·글꼴 크기·숫자 자릿수에 맞춰 자동으로 정해지므로 통계가 다음 줄로 밀리거나 가려지지 않습니다(브라우저에서는 대신 가로 스크롤) |
| 공유 폴더 | 가상 이름 → 실제 폴더 표. 폴더가 없으면 빨간 「폴더 없음」 표시. 실제 경로 옆 ↗ 로 탐색기에서 열기(데스크톱) |
| 보안 | FTPS 용 **SSL/TLS 인증서**(.pem/.pfx, 개인키, 암호, 찾기, 인증서 생성)와 SFTP 용 **SSH 호스트 키**(경로, 키 생성, 키 폴더, SHA256 지문 복사). 해당 프로토콜이 꺼져 있으면 흐리게 표시됩니다. 「네트워크 · 성능」과 같은 행에 놓여 상단이 항상 나란합니다 |
| 인증 | 「익명 접속 허용」 스위치와 사용자 표(이름 · 가려진 암호 · 권한) |
| 폴더 트리 (왼쪽) | 클라이언트가 보는 트리: `/` 아래 공유 폴더, 그 아래 실제 폴더와 파일(크기). ▸ 로 펼치고 접기, ← → ↑ ↓ 이동, 더블클릭/Enter = 탐색기에서 열기, F5 새로 고침. 툴바의 🗔 버튼(삭제 오른쪽)이나 패널의 ‹ 로 완전히 숨기고 다시 엽니다. 경계선을 끌어 폭 조절 |
| 네트워크 · 성능 | 버퍼, 최대 접속, PASV 포트 범위·외부 주소, 바인드 주소 (숫자 칸은 좌우 −/+ 버튼) |
| 로그 / 접속 주소 | 아래쪽 패널의 두 탭. **접속 주소**는 클라이언트가 쓸 URL 목록(프로토콜 × 네트워크 인터페이스, 행마다 ⧉ 복사, 전체 복사) |
| 로그 | 시간이 붙은 이벤트 기록. 「프로토콜 상세」를 끄면 명령/응답 줄(흐린 글씨)이 숨겨집니다. ⧉ 전체 복사, 💾 로그 저장, ⌫ 지우기. 위의 가로 바를 드래그하면 높이 조절 |
| 상태 표시줄 | 왼쪽에 **서버 상태**(● 실행 중 / ○ 중지됨 / 시작 중… — 다른 메시지가 떠도 남아 있음), 현재 상태 메시지, 실행 중이면 **가동 시간**, 오른쪽 끝 **⠿ 크기 조절 마커**(창 가장자리도 드래그 가능). 웹 버전은 「웹 브라우저」 표시 |

> 서버가 **실행 중일 때는 모든 설정이 잠깁니다**. 바꾸려면 먼저 ■ 중지하세요. 접속자가 있으면 중지 전에 확인 창이 뜹니다(설정에서 끌 수 있음).

## 2. 처음 시작하기 (5 단계)

1. **공유 폴더 → 추가**: 가상 이름(예: `data`)과 실제 폴더를 지정합니다. 「찾기」로 폴더를 고르면 폴더 이름이 가상 이름으로 자동 제안됩니다. 클라이언트는 이 폴더를 `/data/` 로 봅니다. 여러 개를 등록하면 루트 `/` 에 가상 이름들이 폴더로 나열됩니다.
2. **프로토콜**을 켭니다. 체크하면 표준 포트(FTP 21, FTPS 990, SFTP 22)가 채워집니다. Linux/macOS 에서 1024 미만 포트는 관리자 권한이 필요하므로 개발 중엔 2121 / 2990 / 2222 를 권장합니다.
3. **인증**: 기본은 「익명 접속 허용」(읽기 전용). 업로드·삭제가 필요하면 **추가**로 사용자를 만들고 「쓰기」를 체크합니다.
4. FTPS 나 「FTP에 AUTH TLS 허용」을 쓰려면 **보안 → 인증서 생성**(자체 서명), SFTP 는 호스트 키가 없으면 **시작 시 자동 생성**됩니다.
5. **▶ 시작**. 버튼이 **■ 중지**로 바뀌고 상태 표시줄에 「● 실행 중」이 켜지며 로그에 `서버 시작 완료 — FTP:2121, SFTP:2222` 가 찍힙니다. 아래 패널의 **접속 주소** 탭에서 ⧉ 로 주소를 복사해 클라이언트에 붙여 넣으세요. 서버가 도는 동안 설정 칸은 잠기고 상태 표시줄에 「🔒 설정 잠김」이 표시됩니다.

설정은 바꿀 때마다 자동으로 `server_settings.json` 에 저장되므로 다음 실행 때 그대로 복원됩니다.

## 3. 공유 폴더

| 항목 | 내용 |
|------|------|
| 가상 이름 | 클라이언트에 보이는 폴더 이름. `/` 나 `\` 를 포함할 수 없고, 대소문자를 구분하지 않으며, 중복 불가 |
| 실제 경로 | 서버 컴퓨터의 폴더. 존재하지 않으면 표에 「폴더 없음」이 뜨고, 시작 시 그 항목은 건너뜁니다(모두 없으면 시작 거부) |

- 공유가 **하나뿐이면** `/a/b` 처럼 가상 이름을 생략한 경로도 그 공유로 해석됩니다(원본과 동일).
- 클라이언트는 공유 밖으로 나갈 수 없습니다: `/data/../..` 는 루트 `/` 로 잘리고, 루트에는 파일을 만들거나 공유 자체를 지울 수 없습니다.
- 더블클릭 / Enter = 편집, Delete = 제거, ↑↓ 로 선택 이동.

## 4. 인증과 권한

| 계정 | 접속 | 권한 |
|------|------|------|
| `anonymous` | 「익명 접속 허용」이 켜져 있을 때, 암호는 아무 값(SFTP 는 암호 없이) | **읽기 전용** — 목록·다운로드만. 업로드·폴더 생성·삭제·이름 변경은 `550 Permission denied (write not allowed)` (SFTP: Permission denied) 로 거부됩니다 |
| 등록 사용자 | 이름은 대소문자 무시, 암호는 정확히 일치 | 「읽기」/「쓰기」 체크 조합. 쓰기만 있는 계정은 목록·다운로드가 거부됩니다 |

- 사용자 이름으로 `anonymous` 는 쓸 수 없습니다. 편집 중에는 이름을 바꿀 수 없습니다(원본과 동일).
- 거부된 로그인·읽기·쓰기는 로그에 `로그인 실패` / `읽기 거부` / `쓰기 거부` 로 남습니다.
- 암호는 설정 파일에 `b64:` 접두 base64 로만 감춰집니다(암호화 아님).

## 5. 프로토콜

### FTP (기본 21)
평문 FTP. PASV / EPSV(수동) 와 PORT / EPRT(능동) 모두 지원하고, `REST` 이어받기, `RNFR/RNTO`, `MLSD/MLST`, `MDTM`, `SIZE`, `APPE` 를 처리합니다. `TYPE A` 는 바이너리로 처리하며 `SITE` 는 지원하지 않습니다.

### FTPS
| 방식 | 설정 | 클라이언트 설정 |
|------|------|-----------------|
| **Explicit** (AUTH TLS) | FTP 를 켜고 「FTP에 AUTH TLS 허용」 체크 + 인증서 지정 | "명시적 FTP over TLS", 포트는 FTP 포트. `PROT P` 로 데이터 채널도 암호화 |
| **Implicit** (기본 990) | FTPS 를 켜고 인증서 지정 | "암시적 FTP over TLS", 처음부터 TLS |

인증서가 없거나 읽지 못하면 FTPS 는 **시작이 거부**되고(설정 오류 팝업), Explicit 만 쓰는 FTP 는 경고만 남기고 평문으로 시작합니다. 자체 서명 인증서이므로 클라이언트에서 "인증서 신뢰" 를 한 번 확인해야 합니다.

### SFTP (기본 22)
SSH 의 sftp 하위 시스템만 제공합니다 — 셸·exec·포트 포워딩·공개키 인증은 거부됩니다. 클라이언트(FileZilla, WinSCP, `sftp`)가 처음 접속할 때 보여 주는 호스트 키 지문은 **보안 → SHA256 지문**과 같은 값이어야 합니다.

## 6. 보안: 인증서와 호스트 키

**인증서 생성** (보안 → FTPS)
- CN(기본: 컴퓨터 이름), 유효 기간(1~30년, 기본 5), 키 길이(RSA 2048/4096), 저장 경로를 지정하면 `server_cert.pem` 과 `server_cert_key.pem` 이 생성되고 「인증서 파일」에 자동으로 채워집니다. 완료 창에 SHA-256 지문이 표시됩니다.
- 기존 인증서를 쓰려면 「찾기」로 `.pem` / `.crt` / `.cer` / `.pfx` / `.p12` 를 고릅니다. PEM 에 개인키가 없으면 「개인키 파일」을 지정하거나 같은 이름의 `_key.pem` / `.key` 를 옆에 두세요. `.pfx` 와 암호화된 키는 「인증서 암호」가 필요합니다.
- 인증서 파일 아래에 주체와 만료일(또는 오류)이 표시됩니다.

**호스트 키** (보안 → SFTP)
- 비워 두면 설정 폴더의 `ssh_host_rsa.pem` 을 쓰고, 없으면 첫 시작 때 자동 생성합니다.
- **키 생성**은 새 RSA 키로 **교체**합니다(기존 키가 있으면 확인). 교체하면 클라이언트마다 "호스트 키가 바뀌었다" 는 경고가 뜨므로 꼭 필요할 때만 쓰세요.
- **키 폴더**는 키 파일이 있는 폴더를 엽니다(웹 버전은 경로만 안내). ⧉ 로 지문을 복사해 사용자에게 알려 줄 수 있습니다.

## 7. 네트워크 · 성능

| 항목 | 내용 |
|------|------|
| 버퍼 (KB) | FTP/FTPS 전송 버퍼. 4 ~ 4096, 기본 64 |
| 최대 접속 | **프로토콜별** 동시 접속 상한(0 = 무제한). 초과하면 FTP 는 `421`, SFTP 는 연결 종료, 로그에 「최대 접속 수 초과」 |
| PASV 포트 범위 | 수동 모드 데이터 연결에 쓸 포트 범위(비우면 임의 포트). **방화벽/공유기에서 FTP 포트와 함께 이 범위를 열어야** 외부에서 목록·전송이 됩니다 |
| PASV 외부 주소 | NAT 뒤에서 PASV 응답에 알릴 공인 IPv4. 같은 사설망의 클라이언트에는 자동으로 로컬 주소를 알려 줍니다 |
| 바인드 주소 | 수신할 로컬 IP(비우면 모든 인터페이스). 예: `127.0.0.1` 은 같은 컴퓨터만 |
| 접속 주소 (로그 옆 탭) | 이 컴퓨터의 IPv4(네트워크 인터페이스 이름과 함께) × 켜진 프로토콜마다 `ftp://` `ftps://` `sftp://` URL 한 줄. 바인드 주소를 지정하면 그 주소만. 행의 ⧉ 또는 「전체 복사」. 쓸모없는 주소(가상 어댑터 등)는 행의 🗑 또는 「전체 삭제」로 지울 수 있고(다음 실행에도 유지) 「복원」으로 모두 되돌립니다 |

## 8. 프로파일

- **💾 저장**: 현재 설정 전체(공유·프로토콜·사용자·보안·네트워크)를 이름으로 저장합니다. 같은 이름이면 덮어씁니다.
- 목록에서 고르면 그 프로파일이 불러와져 현재 설정이 됩니다. 마지막에 고른 프로파일은 다음 실행 때 표시됩니다.
- **🗑 삭제**: 선택한 프로파일 파일을 지웁니다(현재 설정은 유지).
- 원본(FTPServerWinV10)이 저장한 PascalCase JSON 도 그대로 읽힙니다.

## 9. 로그와 통계

- 로그는 메모리(최근 3000줄)와 `ftpserver.log` 파일 양쪽에 남습니다. 파일에는 「프로토콜 상세」 줄이 기록되지 않습니다.
- 로그 위의 분할 바로 로그 높이를 바꿀 수 있습니다. 위쪽 패널(보안·네트워크)이 가려지지 않는 높이까지만 늘어납니다.
- **전체 복사**는 현재 보이는 줄을 클립보드로, **로그 저장**은 파일로(데스크톱: 저장 대화상자, 웹: 브라우저 다운로드) 내보냅니다. ⌫ 는 화면만 비웁니다.
- 제어 바의 통계는 서버를 시작한 뒤부터의 값이며 중지하면 0 으로 돌아갑니다. 업·다운로드는 FTP/FTPS/SFTP 모두 집계합니다.

## 10. 설정 (툴바 ⚙)

고정 크기 창에 탭 두 개 — **일반**(언어·테마·글꼴 크기)과 **동작**(아래 스위치 4개, 각 항목에 설명 한 줄). 테마는 고르는 즉시 미리 보이고 「취소」하면 원래 테마로 돌아갑니다. 「기본값」은 보고 있는 탭의 항목만 기본값으로 되돌립니다.

| 항목 | 탭 | 내용 |
|------|----|------|
| 언어 | 일반 | 한국어 / English (툴바의 국기 버튼과 같음; 로그 메시지 언어도 바뀜) |
| 테마 | 일반 | 16가지 (어두운 10, 밝은 6) |
| 글꼴 크기 | 일반 | px 단위 |
| 접속자가 있을 때 중지 전 확인 | 동작 | 끄면 바로 중지 |
| 앱 시작 시 서버 자동 시작 | 동작 | 켜면 앱을 열자마자 저장된 설정으로 시작 |
| 창을 닫아도 서버 유지 (트레이로 최소화) | 동작 | 서버가 실행 중일 때 ✕ 를 누르면 트레이로 숨고 계속 서비스. 트레이 아이콘 클릭 = 창 표시, 우클릭 → 종료 |
| 시작/오류 알림음 | 동작 | 시작 성공(두 음), 오류(낮은 음) |

## 10a. 창 크기

- 처음 실행하면 **세 단(위쪽 표 두 개 / 보안·네트워크 / 로그)의 높이가 같도록** 창 높이가 정해지고(화면 높이를 넘지 않음), 이후에는 닫을 때의 크기·위치를 기억합니다.
- 창의 **최소 크기**는 툴바와 컨트롤 바의 버튼이 하나도 가려지지 않는 폭입니다. 한국어·영어 두 언어의 라벨과 가장 긴 테마 이름, 시작/중지/시작 중… 버튼까지 계산에 넣으므로 **언어나 테마를 바꿔도, 서버를 시작·중지해도 창 크기는 변하지 않습니다.**
- 오른쪽 아래 ⠿ 그립이나 창 가장자리로 크기를 조절합니다.

## 11. 키보드 단축키

| 키 | 동작 |
|----|------|
| F5 | 현재 설정을 `server_settings.json` 에 저장 (로그에 「설정 저장 완료」) |
| F6 | `server_settings.json` 다시 불러오기 |
| Esc | 대화상자 닫기 |
| ↑ ↓ / Enter / Delete | 공유·사용자 표에서 선택 이동 / 편집 / 제거 |

## 12. 웹 버전

```bash
npm run web                                          # http://127.0.0.1:5190 — 같은 컴퓨터에서만
node server/server.js --host 0.0.0.0 --port 8080 --token 비밀값 --no-open --autostart
node server/server.js --config /srv/myftp            # 설정 폴더 지정
```

- FTP/FTPS/SFTP 리스너는 **`node server/server.js` 를 실행한 컴퓨터**에서 돌고, 브라우저는 원격 제어판입니다. 공유 폴더·인증서·키 경로는 모두 그 컴퓨터 기준이며, 「찾기」는 그 컴퓨터의 파일 시스템을 보여 주는 내장 탐색기로 대체됩니다.
- 다른 컴퓨터에서 관리하려면 반드시 `--token` 을 주고 `http://주소:포트/?token=비밀값` 으로 접속하세요. API 로 공유 폴더와 사용자를 바꿀 수 있기 때문입니다.
- `--autostart` 는 서버 프로세스가 뜨자마자 저장된 설정으로 리스너를 시작합니다(NAS·부팅 스크립트용).
- 로그·통계는 0.7초(접속자가 있으면 0.25초) 간격으로 갱신됩니다. 「탐색기에서 열기」·「키 폴더」는 경로만 안내하고, 「로그 저장」은 브라우저 다운로드로 대체됩니다.

## 13. 데이터 파일과 문제 해결

설정 폴더는 「정보」 대화상자에 표시됩니다: Windows `%APPDATA%\My FTP Server`, macOS `~/Library/Application Support/My FTP Server`, Linux `~/.config/My FTP Server` (웹: `--config`).

| 파일 | 내용 |
|------|------|
| `server_settings.json` | 서버 설정(자동 저장) |
| `profiles/*.json` | 프로파일 |
| `session.json` | 언어·테마·글꼴·창 위치 등 UI 환경설정 |
| `ftpserver.log` | 서버 로그 |
| `server_cert.pem` / `server_cert_key.pem` | 생성한 FTPS 인증서·키(기본 경로) |
| `ssh_host_rsa.pem` | SFTP 호스트 키 |

| 증상 | 확인할 것 |
|------|-----------|
| 「포트 N이(가) 이미 사용 중」 | 같은 포트를 쓰는 다른 프로그램(IIS FTP, OpenSSH 서버, 다른 인스턴스)을 중지하거나 포트 변경. 두 프로토콜에 같은 포트를 주면 「두 프로토콜이 같은 포트를 사용합니다」 |
| 「바인드할 권한이 없습니다」 | Linux/macOS 의 1024 미만 포트 — `sudo` 로 실행하거나 2121/2990/2222 사용 |
| 「공유 폴더가 없습니다」 | 공유가 없거나 모든 실제 경로가 존재하지 않음 |
| FTPS 시작 거부 | 인증서 경로·개인키·암호 확인. 보안 패널의 인증서 줄에 원인이 표시됨 |
| 접속은 되는데 목록/전송이 안 됨 | 방화벽에서 PASV 포트 범위 허용, NAT 뒤라면 PASV 외부 주소 지정. 15초 안에 데이터 연결이 없으면 `425` |
| 익명으로 업로드가 안 됨 | 정상입니다(읽기 전용). 쓰기 권한이 있는 사용자를 추가하세요 |
| SFTP 클라이언트가 호스트 키 경고 | 「키 생성」으로 키를 교체했기 때문. 클라이언트의 known_hosts 항목을 갱신 |
| 창을 닫았는데 서버가 계속 돔 | 「창을 닫아도 서버 유지」가 켜진 상태. 트레이 아이콘 우클릭 → 종료 |

- 시작·설정 오류는 **상세 팝업**(코드 · 경로 · 스택, 「자세한 내용 복사」)으로 표시되고, 로그에도 `서버 시작 실패` 로 남습니다.
- Windows 재설치 시 설치 프로그램이 이전 데이터를 지울지 물어봅니다. Linux/macOS 에서는 위 폴더를 지우면 초기화됩니다.
