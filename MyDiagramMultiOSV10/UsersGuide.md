# MyDiagram 사용 설명서

MyDiagram은 Microsoft Visio와 비슷한 방식으로 순서도·조직도·네트워크 구성도·UML·데이터베이스 모델·평면도 같은 다이어그램을 그리고, 도형에 데이터를 붙여 보고서로 정리하는 프로그램입니다. Windows · macOS · Linux 데스크톱 앱과 웹 브라우저에서 같은 화면으로 동작합니다.

이 설명서는 하는 일 순서로 정리되어 있습니다. 화면의 메뉴·명령 이름은 프로그램에 표시되는 이름 그대로 적었습니다(예: **삽입 › 텍스트 상자 삽입**은 "삽입" 메뉴의 "텍스트 상자 삽입" 명령). 그림은 튜토리얼 화면을 캡처한 것입니다.

> English version: [UsersGuide.en.md](UsersGuide.en.md)

## 시작하기

### 처음 실행

처음 실행하면 **MyDiagram에 오신 것을 환영합니다** 창이 뜹니다.

| 버튼 | 하는 일 |
|---|---|
| **튜토리얼 시작** | 예제 드로잉으로 도형 그리기부터 연결·서식·정렬·페이지·데이터·인쇄·설정까지 모든 기능을 차례로 보여 주는 튜토리얼을 시작합니다 |
| **예제 열기** | "온라인 쇼핑몰 운영" 예제 드로잉을 엽니다 |
| **나중에** | 창을 닫습니다. 튜토리얼은 언제든 **도움말 › 튜토리얼**(F11)로 볼 수 있습니다 |

MyDiagram은 한 번에 하나만 실행됩니다. 이미 실행 중일 때 다시 실행하면 오류 창이 뜨고 새 실행은 끝납니다([문제 해결](#문제-해결) 참고).

드로잉을 열지 않았을 때(또는 메뉴 막대 맨 앞의 **홈** 버튼, `Ctrl+Shift+H`) 보이는 화면입니다. 뒤에서는 배경이 계속 움직입니다.

### 예제 드로잉

**예제 드로잉**의 "온라인 쇼핑몰"을 열면 세 페이지짜리 드로잉이 열립니다. 첫 페이지는 고객·쇼핑몰·물류 센터 스윔레인으로 나눈 주문 처리 순서도(도형 데이터·메모·하이퍼링크·"메모" 레이어 포함), 둘째는 조직도, 셋째는 서버 구성도입니다. 모든 페이지는 제목 칸이 있는 배경 페이지를 씁니다.

![예제 드로잉](docs/tutorial/images/06-sample.jpg)

설치 폴더의 `samples`에는 이 밖에 주문 순서도 · 회사 조직도 · 사무실 네트워크 · 쇼핑몰 데이터베이스 드로잉, 브레인스토밍 템플릿(`.mdgt`), 그리고 Visio 형식으로 저장한 온라인 쇼핑몰(`.vsdx`)이 한국어·영어로 들어 있습니다.

### 튜토리얼

**도움말 › 튜토리얼**(F11), 툴바의 학사모 버튼, 시작 페이지의 **튜토리얼 시작**으로 시작합니다. 예제 드로잉을 띄워 놓고 56단계로 기능을 하나씩 보여 줍니다.

- **다음** · **이전 단계** 버튼, **자동 재생**(▶)으로 넘깁니다. 마지막 단계에서는 **마치기**를 누릅니다.
- **장 고르기** 목록으로 시작 · 도형 그리기 · 연결하기 · 서식 · 정렬과 배치 · 페이지와 레이어 · 데이터와 보고서 · 파일과 인쇄 · 사용자 설정 · 도움말 중 원하는 장으로 갑니다.
- 안내 상자는 끌어서 옮길 수 있습니다. **Esc**나 ✕(**튜토리얼 끝내기 (Esc)**)로 끝냅니다.
- 내 파일은 바뀌지 않고, 튜토리얼이 바꾼 설정(테마·언어·배경 등)은 끝날 때 원래대로 돌아갑니다.

**튜토리얼 문서** — 튜토리얼의 모든 단계를 화면과 함께 정리한 문서는 프로그램 안에서 읽을 수 있습니다. 시작 페이지의 **도움말 › 튜토리얼 문서** 또는 메뉴의 **도움말 › 튜토리얼 문서**로 열면 가운데에 문서가 나타나고, 위쪽 막대에서 **장으로 이동** · 한국어/English 전환 · **튜토리얼 시작** · **브라우저로 열기**를 할 수 있습니다. **홈** 버튼으로 돌아갑니다.

![튜토리얼 문서](docs/tutorial/images/55-tutorialDoc.jpg)

## 화면 구성

![화면 구성](docs/tutorial/images/07-layout.jpg)

창에는 운영 체제의 제목 표시줄이 없습니다. 맨 위 **메뉴 막대** 줄에 프로그램 아이콘·이름·버전, 조금 띄워서 지금 드로잉의 이름, 메뉴가 있고, 오른쪽 끝에 **최소화 · 최대화 · 닫기** 버튼이 있습니다. 메뉴 막대의 빈 곳을 끌면 창이 움직이고 두 번 클릭하면 최대화됩니다. 그 아래 **툴바**(한 줄), 왼쪽에 **도형** 패널, 오른쪽에 **속성** 패널이 있습니다. 두 패널 사이 가운데에는 **보기**(드로잉일 때는 위쪽 페이지 탭과 눈금자, 페이지)가 있고, 맨 아래는 **상태 표시줄**입니다. 패널 사이의 구분자를 끌면 너비가 바뀌고, 창 오른쪽 아래 모서리를 끌면 창 크기가 바뀝니다. 창은 툴바 버튼과 메뉴가 가려지지 않는 폭보다 좁아지지 않습니다.

**채우기 색** · **선 색** 버튼의 왼쪽 반쪽은 마지막으로 고른 색(아래 색 막대)을 선택한 도형에 바로 칠하고, ▾는 테마 색 · 표준 색 · **없음** · **다른 색…**이 있는 색 고르기 창을 엽니다. **내보내기** 버튼은 그림으로 내보내기 창(PNG · JPEG · WebP · BMP · TIFF · SVG, 투명 배경은 지원하는 형식에서만 고를 수 있음)을 열고, ▾는 Visio · PDF · SVG · 그림 · HTML · 도형 데이터(CSV) 중 내보낼 형식을 고르게 합니다. 모든 버튼에 툴팁이 있습니다. 실행 취소·다시 실행 버튼의 툴팁은 무엇을 되돌리는지 알려 줍니다(예: "실행 취소: 크기 변경").

### 드로잉 이름 (여러 드로잉)

드로잉은 탭으로 나오지 않습니다. 메뉴 막대의 프로그램 이름 옆에 지금 드로잉의 이름이 보이고, 저장하지 않은 변경이 있으면 ●가, 여러 개를 열었으면 그 개수가 붙습니다. 이름을 누르면 열린 드로잉 목록(눌러서 바꾸기)과 저장 · 다른 이름으로 저장… · 템플릿으로 저장… · 문서 속성… · 인쇄… · 탭 닫기 · 모든 탭 닫기 · 새 드로잉이 나옵니다. `Ctrl+Tab` · `Ctrl+Shift+Tab`으로 다음 · 이전 드로잉으로 갑니다.

### 도형 놓기

![도형 놓기](docs/tutorial/images/09-dropShape.jpg)

- 스텐실의 도형을 페이지로 끌어다 놓거나, 한 번 클릭하면 화면 가운데에 놓입니다. 격자와 다른 도형에 맞춰집니다.
- 스텐실 도형을 오른쪽 클릭해 **페이지에 추가**를 눌러도 됩니다.
- 컨테이너 위에 놓은 도형은 그 컨테이너에 들어가, 컨테이너를 옮기면 함께 움직입니다.
- 새 도형은 활성 레이어가 있으면 그 레이어에 들어갑니다([레이어](#레이어) 참고).

### 도형 검색

![도형 검색](docs/tutorial/images/10-search.jpg)

도형 패널 위쪽의 **도형 검색** 칸에 이름을 쓰면 열려 있지 않은 스텐실까지 모든 스텐실에서 도형을 찾아 "검색 결과 n개"로 보여 줍니다. 한국어와 영어 이름 모두 됩니다(예: "서버", "server").

### 그리기 도구

![그리기 도구](docs/tutorial/images/11-tools.jpg)

도형 패널의 도구 줄, 툴바, **삽입 › 그리기 도구**에서 고릅니다.

| 도구 | 단축키 | 쓰는 법 |
|---|---|---|
| **포인터** | `Ctrl+1` | 선택·이동·크기 변경(기본) |
| **화면 이동** | `Ctrl+Shift+Space` | 끌어서 화면을 옮김 |
| **연결선** | `Ctrl+3` | 도형에서 도형으로 끌면 붙은 연결선 |
| **텍스트** | `Ctrl+2` | 클릭하거나 끌어서 텍스트 상자를 만들고 바로 입력 |
| **사각형** · **타원** | `Ctrl+8` · `Ctrl+9` | 끌어서 그림. `Shift`: 정사각형·원 |
| **선** | `Ctrl+6` | 끌어서 직선. `Shift`: 가로·세로로만 |
| **연필 (자유형)** | `Ctrl+4` | 끄는 대로 자유 곡선 |
| **다각선** | `Ctrl+5` | 클릭할 때마다 꼭짓점. 두 번 클릭·Enter·오른쪽 클릭으로 끝냄. 첫 점을 다시 클릭하면 닫힌 도형 |

포인터가 아닌 도구를 쓰는 동안 상태 표시줄에 도구 이름이 보입니다. **Esc**를 누르면(또는 상태 표시줄의 도구 이름을 누르면) 포인터로 돌아갑니다.

### 선택

- 클릭하면 선택, `Shift`+클릭이나 `Ctrl`+클릭으로 더하거나 뺍니다. 빈 곳에서 끌면 사각형 안의 도형을 고릅니다.
- **편집 › 선택**: **모두 선택**(`Ctrl+A`) · **도형만 선택** · **연결선만 선택** · **같은 종류의 도형 선택** · **선택 해제**(`Esc`).
- 그룹 안의 도형은 그룹을 선택한 뒤 한 번 더 클릭해 고릅니다.
- 숨긴 레이어나 잠근 레이어의 도형은 고를 수 없습니다.

### 이동·크기·회전

![이동·크기·회전](docs/tutorial/images/13-moveResize.jpg)

| 하는 일 | 방법 |
|---|---|
| 이동 | 끌기. 분홍 스마트 안내선이 다른 도형과 맞는 곳을 보여 줌. `Shift`: 가로·세로로만, `Alt`: 맞추기 없이 |
| 복사하며 이동 | 선택한 도형을 `Ctrl`+끌기 |
| 조금씩 이동 | 방향키(격자 한 칸), `Shift`+방향키(1픽셀) |
| 크기 | 흰 사각형 손잡이. `Shift`: 비율 유지, `Alt`: 가운데 기준 |
| 회전 | 위쪽 동그라미 손잡이. `Shift`: 15°씩 |
| 모양 조절 | 노란 마름모 손잡이(모서리 둥글기, 화살표 머리 길이, 설명선 꼬리 위치 등). 속성 패널의 슬라이더로도 조절 |
| 정확한 값 | 속성 패널의 **크기 및 위치**(X · Y · 너비 · 높이 · 각도), **정렬 › 크기 및 위치…** |

값은 드로잉의 측정 단위(mm · cm · in · pt · px)로 입력합니다. 단위를 붙여 `25 mm`, `1in`처럼 써도 됩니다. 이동하면 상태 표시줄에 이동한 거리가 표시됩니다.

### 텍스트 입력

![텍스트 입력](docs/tutorial/images/12-text.jpg)

- 도형을 두 번 클릭하거나 `F2`를 누르면 그 자리에서 텍스트를 고칩니다.
- 도형을 선택하고 바로 타이핑해도 됩니다. 입력한 글자가 원래 텍스트를 바꿉니다.
- 편집 중 **Enter**는 줄 바꿈, **Ctrl+Enter**·**Esc**·바깥 클릭으로 끝냅니다.
- 속성 패널의 **텍스트** 칸에서도 고칩니다.
- **삽입 › 텍스트 상자 삽입**은 화면 가운데에 텍스트 상자를 넣고 바로 입력하게 합니다.

### 그림·컨테이너·설명선

| 명령 | 하는 일 |
|---|---|
| **삽입 › 그림 삽입…** | PNG · JPEG · GIF · WebP · BMP · SVG 그림을 도형으로 넣습니다(최대 420×320 크기로 맞춤). 그림은 드로잉 파일 안에 들어갑니다. 속성 패널의 **그림 바꾸기…**로 바꿉니다 |
| **삽입 › 컨테이너 삽입** | 선택한 도형들을 둘러싸는 컨테이너를 그 뒤에 넣습니다(선택이 없으면 빈 컨테이너). 컨테이너를 옮기면 안의 도형도 함께 움직입니다 |
| **삽입 › 설명선 삽입** | 선택한 도형 오른쪽 위에 꼬리가 그 도형을 가리키는 둥근 설명선을 넣습니다 |

컨테이너와 스윔레인은 머리글 띠나 테두리를 클릭해야 선택됩니다. 안쪽을 클릭하면 안에 있는 도형을 고르게 됩니다.

### 내 도형

자주 쓰는 도형(여러 개도 가능)을 저장해 두고 모든 드로잉에서 씁니다.

- 도형을 선택하고 **삽입 › 선택을 내 도형으로 저장…**을 누르면 이름을 묻고 **내 도형** 스텐실에 추가합니다.
- **삽입 › 내 도형 관리…**에서 이름을 바꾸고, **삽입**하거나 **삭제**합니다.
- 내 도형은 프로그램의 저장소에 보관되어 다른 창·다른 드로잉에서도 보입니다.

### 실행 취소와 복사·붙여넣기

![실행 취소](docs/tutorial/images/14-undo.jpg)

- 모든 편집은 `Ctrl+Z`로 되돌리고 `Ctrl+Y`(또는 `Ctrl+Shift+Z`)로 다시 실행합니다. 탭(드로잉)마다 기록이 따로 있고 200번까지 되돌릴 수 있습니다.
- `Ctrl+C` · `Ctrl+X` · `Ctrl+V`로 도형(연결선·서식·데이터 포함)을 복사·이동합니다. 같은 것을 다시 붙여넣을 때마다 조금씩 옆으로 놓입니다.
- **복제**(`Ctrl+D`)는 선택한 도형을 바로 옆에 복사합니다.
- 다른 프로그램에서 복사한 글자를 붙여넣으면 텍스트 상자가 됩니다. 복사한 도형은 다른 프로그램에 그 텍스트로 붙여넣어집니다.
- **삭제**(`Delete` 또는 `Backspace`)는 선택한 도형을 지웁니다. 지운 도형에 붙어 있던 연결선도 함께 지워집니다. **삭제 금지**로 보호한 도형은 지워지지 않습니다.

## 연결선

### 연결선 그리기

![연결선 그리기](docs/tutorial/images/15-connector.jpg)

- **연결선** 도구(`Ctrl+3`)로 도형에서 도형으로 끌면 양쪽이 붙은 연결선이 생깁니다.
- 도형이 움직이면 연결선이 따라오고, 직각 연결선은 다른 도형을 피해 길을 찾습니다(**연결선이 도형 피해 가기**).
- 빈 곳에서 끌면 끝이 붙지 않은 연결선이 됩니다. `Shift`로 가로·세로로만 그립니다.
- 연결선을 두 번 클릭하거나 선택하고 `F2`를 누르면 레이블(텍스트)을 씁니다. 레이블은 선의 가운데에 놓입니다.

### 자동 연결

![자동 연결](docs/tutorial/images/16-autoConnect.jpg)

포인터 도구로 도형 위에 마우스를 올리면 네 방향에 파란 화살표가 나옵니다.

- **클릭**: 그 방향에 같은 도형(서식·레이어 포함)을 만들어 연결합니다. 그 자리에 이미 도형이 있으면 그 도형에 연결합니다.
- **끌기**: 원하는 곳이나 다른 도형까지 연결선을 그립니다.

**보기 › 맞추기·붙이기 › 자동 연결 화살표**(또는 **설정 › 드로잉**)로 끄고 켭니다. 컨테이너·텍스트·선 도형에는 나오지 않습니다.

### 연결점과 붙이기

![연결점과 붙이기](docs/tutorial/images/18-glue.jpg)

- 도형의 연결점(파란 ×)에 연결선 끝을 놓으면 그 점에 붙습니다. 연결선은 그 점이 있는 쪽으로 곧게 나갑니다.
- 도형 위(점이 아닌 곳)에 놓으면 **도형 전체에 붙어(동적 붙이기)** 도형이 움직일 때마다 서로 마주 보는 가장 가까운 점으로 바뀝니다.
- 초록 끝점은 붙어 있다는 뜻입니다. 끝점을 끌어 다른 도형으로 옮기고, `Alt`를 누른 채 놓으면 붙이지 않습니다.
- **보기 › 표시 › 연결점 표시**로 연결점을 보이거나 숨기고, **도형에 붙이기 (연결점)**(보기 › 맞추기·붙이기, 디자인 메뉴)로 붙이기를 끕니다.
- 속성 패널의 **시작** · **끝**에 무엇에 붙어 있는지("연결점 2", "도형 전체 (동적)", "붙지 않음")가 보입니다.

### 연결선 모양과 꺾기

![연결선 모양](docs/tutorial/images/17-routes.jpg)

| 모양 | 하는 일 |
|---|---|
| **직각 연결선** | 가로·세로 선분으로 꺾이며 도형을 피해 감(기본) |
| **직선 연결선** | 두 끝을 곧게 이음 |
| **곡선 연결선** | 부드러운 곡선 |

- 선택한 연결선의 모양은 속성 패널의 **연결선 모양**, **서식 › 연결선**, 오른쪽 클릭 메뉴에서 바꿉니다. 아무것도 선택하지 않고 고르면 그 드로잉의 새 연결선 모양이 바뀝니다(상태 표시줄에 "새 연결선 모양: 직각").
- 선택한 연결선의 가운데 사각형 손잡이를 끌면 직접 꺾을 수 있습니다. 꺾은 점을 두 번 클릭하면 지워지고, **연결선 꺾임 지우기**는 모두 지워 자동 경로로 돌립니다.
- **연결선 방향 바꾸기**는 시작과 끝(화살표 방향)을 바꿉니다.
- **선 점프 (교차점 표시)**를 켜면 나중에 그린 연결선이 먼저 그린 연결선과 교차하는 곳에 작은 반원이 그려집니다. 연결선 하나만 끄려면 속성 패널의 **이 연결선에 선 점프**를 끕니다. 점프 크기는 **페이지 설정 › 레이아웃·연결선 › 선 점프 크기**에서 정합니다.

### 화살표와 선 모양

| 항목 | 고를 수 있는 것 |
|---|---|
| **시작 화살표** · **끝 화살표** | 없음 · 채운 화살표 · 열린 화살표 · 날렵한 화살표 · 빈 삼각형 (상속) · 채운 마름모 (합성) · 빈 마름모 (집합) · 채운 원 · 빈 원 · 막대 · 하나 (ERD) · 여럿 (까마귀발) · 하나 이상 (ERD) · 0개 이상 (ERD) · 0 또는 1 (ERD) · 하나만 (ERD) — 모두 16가지 |
| **화살표 크기** | 60% ~ 200% (도형 서식 창에서는 0.4 ~ 3배) |
| **선 모양** | 실선 · 파선 · 점선 · 일점쇄선 · 긴 파선 · 이점쇄선 |
| **선 두께** | 0.5 ~ 8 px (도형 서식 창에서는 0 ~ 30 px) |

UML 상속·합성·집합, ERD의 관계 차수(까마귀발 표기)를 화살촉으로 바로 표현할 수 있습니다.

## 텍스트와 서식

### 테마와 변형

![테마와 변형](docs/tutorial/images/22-design.jpg)

**디자인 › 테마·변형…**(또는 속성 패널 **드로잉**의 **테마**)에서 드로잉 전체의 색·선·글꼴 모양을 고릅니다.

- 16가지 테마: 오피스 · 선형 · 패싯 · 통합 · 이온 · 회고 · 조각 · 위스프 · 유기적 · 버블 · 시퀀스 · 광채 · 단색 · 청사진 · 자정 · 칠판. 청사진·자정·칠판은 어두운 페이지를 씁니다.
- 테마마다 4가지 **변형**(색 배열)이 있습니다. **디자인 › 다음 변형**은 다음 변형으로 넘깁니다.
- 테마를 바꾸면 직접 서식을 바꾸지 않은 모든 도형의 색·선·글꼴이 함께 바뀝니다.
- **서식 › 서식 지우기 (테마로)**는 선택한 도형의 직접 서식을 지워 테마를 따르게 합니다.

(이 테마는 드로잉의 디자인입니다. 프로그램 화면의 색은 [꾸미기](#꾸미기-테마디자인설정시작-화면배경-애니메이션)의 테마로 따로 정합니다.)

### 빠른 스타일

![빠른 스타일](docs/tutorial/images/20-quickStyle.jpg)

테마 색 6가지와 채우기 방식을 골라 도형을 한 번에 꾸밉니다. 속성 패널의 **빠른 스타일** 구역이나 **서식 › 빠른 스타일…**(디자인 창의 **빠른 스타일** 탭)에서 고릅니다.

| 방식 | 모양 |
|---|---|
| **채우기** | 테마 색으로 채움 |
| **연하게** | 옅은 색 채우기, 진한 테두리 |
| **윤곽선** | 채우기 없이 색 테두리 |
| **진하게** | 진한 채우기, 굵은 강조 |
| **그라데이션** | 위에서 아래로 밝아지는 그라데이션 |
| **텍스트만** | 채우기·테두리 없이 글자만 (디자인 창에만 있음) |

빠른 스타일은 테마 색을 가리키므로 테마나 변형을 바꾸면 함께 바뀝니다.

### 속성 패널에서 서식

도형을 선택하면 속성 패널에서 바로 고칩니다.

| 구역 | 항목 |
|---|---|
| **채우기** | 색, 채우기 방식(단색 · 선형 그라데이션 · 방사형 그라데이션 · 빗금 · 격자 무늬 · 점 무늬 · 채우기 없음), 두 번째 색(그라데이션·무늬일 때), 불투명도 |
| **선** | 색, 두께, 선 모양, 모서리(둥글기) |
| **텍스트** | 글꼴, 크기, 글자 색, 굵게 · 기울임 · 밑줄 · 취소선, 왼쪽 · 가운데 · 오른쪽 정렬, 위쪽 · 중간 · 아래쪽 정렬, 텍스트 방향(0° · 90° · 180° · 270°) |
| **효과** | 그림자, 투명도 (전체) |

툴바의 채우기 색·선 색 버튼, **서식** 메뉴의 텍스트·선 하위 메뉴, 단축키(`Ctrl+B` · `Ctrl+I` · `Ctrl+U`, `Ctrl+Shift+>` · `Ctrl+Shift+<`)로도 바꿉니다.

### 도형 서식 창

![도형 서식](docs/tutorial/images/21-formatDialog.jpg)

**서식 › 도형 서식…**(속성 패널의 **자세히…**)은 서식을 자세히 정하는 창입니다. 여러 도형을 선택하고 열면 **바꾼 항목만** 모든 도형에 적용됩니다.

| 탭 | 항목 |
|---|---|
| **채우기** | 채우기 없음, 색과 견본, 채우기 방식, 두 번째 색, 그라데이션 각도, 불투명도 |
| **선** | 선 없음, 색, 두께(0 ~ 30 px), 선 모양, 모서리, 선 불투명도 |
| **텍스트** | 글꼴, 크기(4 ~ 200), 글자 색, 글꼴 스타일, 가로 정렬, 세로 정렬, 텍스트 방향, 줄 간격, 텍스트 여백 |
| **효과** | 그림자, 투명도 (전체) |
| **크기 및 위치** | X, Y, 너비, 높이, 각도, 좌우 대칭, 상하 대칭 |
| **보호** | 이동 금지 · 크기 변경 금지 · 회전 금지 · 삭제 금지 · 텍스트 편집 금지 · 가로세로 비율 고정 |

연결선을 선택하고 열면 **선** · **화살표** · **텍스트** 탭이 나옵니다. **정렬 › 크기 및 위치…**와 **정렬 › 도형 보호…**는 이 창을 해당 탭으로 엽니다.

### 서식 복사

![서식 복사](docs/tutorial/images/23-formatPainter.jpg)

도형을 선택하고 **서식 복사**(`Ctrl+Shift+C`, 툴바·편집 메뉴)를 누른 뒤 다른 도형을 클릭하면 같은 서식이 됩니다. **Esc**로 취소합니다.

### 필드

**삽입 › 필드 삽입**은 도형 텍스트에 자동으로 채워지는 값을 넣습니다. 도형을 선택하지 않았으면 필드가 든 텍스트 상자를 새로 만듭니다.

| 필드 | 표시되는 값 |
|---|---|
| `{page}` · `{pages}` · `{pageName}` | 페이지 번호 · 페이지 수 · 페이지 이름 |
| `{title}` · `{author}` · `{subject}` · `{company}` | 문서 속성의 제목 · 작성자 · 주제 · 회사 |
| `{date}` · `{time}` | 오늘 날짜 · 현재 시각 |
| `{name}` · `{master}` · `{width}` · `{height}` | 도형 이름 · 도형 종류 · 도형 너비 · 도형 높이 |
| `{data:이름}` | 그 도형의 도형 데이터 값(예: `{data:비용}`) |

텍스트에 중괄호 코드를 직접 써도 됩니다. 배경 페이지에 넣은 필드는 그 배경을 쓰는 각 페이지의 값으로 바뀝니다([배경 페이지](#배경-페이지) 참고).

### 하이퍼링크와 메모

- **삽입 › 하이퍼링크…**(`Ctrl+K`): **연결 대상**으로 **웹 주소·파일** 또는 **이 드로잉의 페이지**를 고릅니다. 속성 패널의 **하이퍼링크 › 주소** 칸에 `https://…`나 `page:페이지 이름`을 직접 써도 됩니다. 링크가 있는 도형은 `Ctrl`+클릭하거나 프레젠테이션 모드에서 클릭하면 열립니다. **링크 삭제**로 지웁니다.
- **삽입 › 메모 달기**는 속성 패널의 **메모** 구역을 엽니다. 도형을 선택했으면 그 도형에, 아니면 페이지에 메모를 씁니다(**메모 추가** 또는 `Ctrl+Enter`). 메모마다 작성자·시각이 붙고, **해결됨으로 표시** · **다시 열기** · **메모 삭제**를 할 수 있습니다. 작성자는 문서 속성의 작성자(없으면 "나")입니다.

## 페이지·배경·레이어

### 여러 페이지

![여러 페이지](docs/tutorial/images/28-pageTabs.jpg)

드로잉 위쪽의 페이지 탭으로 페이지를 다룹니다.

- 탭을 눌러 페이지를 바꾸고, **+**(**페이지 추가**, `Shift+F11`)로 추가합니다. 새 페이지는 현재 페이지의 크기·배경을 따릅니다.
- 탭을 두 번 클릭하면 이름을 바꾸고, 끌어서 순서를 바꿉니다.
- 양 끝의 화살표나 `Ctrl+PageUp` · `Ctrl+PageDown`으로 이전·다음 페이지로 갑니다. **페이지로 이동**(`Ctrl+G`, 상태 표시줄의 페이지 번호)은 페이지 목록을 보여 줍니다.
- **페이지 › 페이지 복제**는 도형·레이어까지 복사하고, **페이지 삭제**는 도형이 있으면 묻습니다. 마지막 남은 페이지는 지울 수 없습니다.
- 배경 페이지는 탭 줄의 구분선 뒤에 따로 보입니다.

### 페이지 개요

![페이지 개요](docs/tutorial/images/32-pagesView.jpg)

**페이지 › 페이지 개요**(보기 전환 › **페이지 개요**)는 모든 페이지를 축소판으로 보여 줍니다(일반 페이지 다음에 배경 페이지). 축소판마다 크기와 도형 수가 보이고, 클릭하면 그 페이지가 현재 페이지가 되며, 두 번 클릭하면 드로잉으로 갑니다. 끌어서 순서를 바꾸고, 버튼으로 **페이지 복제** · **페이지 이름 바꾸기…** · **페이지 삭제**, 아래의 **페이지 추가** · **배경 페이지 추가**를 합니다.

### 배경 페이지

![배경 페이지](docs/tutorial/images/29-backgroundPage.jpg)

배경 페이지는 다른 페이지 뒤에 깔리는 페이지입니다. 배경 페이지에 그린 테두리·로고·제목 칸은 그 배경을 쓰는 모든 페이지에 나타나고, 거기서는 고를 수 없습니다.

- **페이지 › 배경 페이지 추가**로 만들거나, 속성 패널(또는 페이지 설정)의 **배경 페이지**를 켜서 지금 페이지를 배경 페이지로 바꿉니다.
- 페이지마다 **페이지 › 배경 페이지 지정**(속성 패널의 **배경**)으로 쓸 배경을 고릅니다. 배경 페이지도 다른 배경 페이지를 쓸 수 있습니다.
- **삽입 › 테두리와 제목 (배경 페이지)**은 "배경-1" 배경 페이지에 테두리와 제목 칸(`{title}`, `{pageName} · {page}/{pages} · {date}`)을 만들고, 배경이 없는 모든 페이지에 지정합니다.
- 배경 페이지는 인쇄·PDF·프레젠테이션에서 따로 한 장으로 나오지 않습니다.

### 페이지 설정

![페이지 설정](docs/tutorial/images/31-pageSetup.jpg)

**페이지 › 페이지 설정…**(속성 패널 **페이지**의 **자세히…**)

| 탭 | 항목 |
|---|---|
| **페이지 크기** | 용지(A3 · A4 · A5 · B4 · B5 · Letter · Legal · Tabloid · Ledger · Screen · Wide · 사용자 지정), 방향(세로 · 가로), 너비, 높이, **페이지 자동 크기** |
| **페이지 속성** | 페이지 이름, 배경 페이지, 배경, 페이지 색(**테마 색으로**), 격자 표시, 격자 간격 (0 = 자동) |
| **레이아웃·연결선** | 연결선 모양, 선 점프 (교차점 표시), 선 점프 크기, 연결선이 도형 피해 가기, 도형에 붙이기 (연결점), 이 드로잉에서 격자에 맞추기, 이 드로잉에서 도형에 맞추기, 모든 도형에 데이터 표시, 측정 단위 |

캔버스는 끝이 없습니다. 격자는 어느 방향으로나 계속 이어지고, 가장자리 가까이 스크롤하면 빈 캔버스가 계속 늘어나므로 페이지 왼쪽·위쪽(음수 좌표)에도 도형을 그릴 수 있습니다. 페이지는 한 장에 인쇄되는 범위를 보여 주는 테두리로만 표시됩니다. 그림·SVG·PDF·HTML로 내보내거나 인쇄할 때는 **도형이 있는 영역만** 저장합니다.

**페이지 자동 크기**를 켜면 도형이 페이지 밖으로 나갈 때 페이지가 한 장씩 늘어납니다. **보기 › 표시 › 페이지 나눔**은 늘어난 페이지의 용지 경계를 보여 줍니다. 격자 간격을 0으로 두면 **설정 › 드로잉**의 격자 크기를 따르고 확대 비율에 맞춰 바뀝니다.

### 레이어

![레이어](docs/tutorial/images/30-layers.jpg)

**페이지 › 레이어…**는 현재 페이지의 레이어를 관리합니다.

| 열 | 뜻 |
|---|---|
| **활성** | 새 도형이 들어갈 레이어(하나만). **활성 레이어 없음**도 고를 수 있습니다 |
| **이름** | 레이어 이름 |
| **보이기** | 끄면 그 레이어의 도형이 화면에서 숨습니다 |
| **인쇄** | 끄면 인쇄·PDF에 나오지 않습니다 |
| **잠금** | 켜면 그 레이어의 도형을 고르거나 고칠 수 없습니다 |
| **색** | 레이어 색은 그 레이어 도형의 선과 글자 색을 바꿉니다. **레이어 색 지우기**로 되돌립니다 |
| **도형** | 그 레이어에 있는 도형 수 |

**레이어 추가** · **레이어 삭제**로 레이어를 늘리고 줄입니다. 도형을 선택하고 창을 열면 아래에 **선택한 도형 n개를** [레이어] **이 레이어에만** · **추가** · **빼기** **적용** 줄이 나옵니다. 한 도형이 여러 레이어에 들어갈 수 있습니다. 속성 패널의 **레이어** 구역에서도 도형의 레이어를 체크하고, 아무것도 선택하지 않았을 때는 레이어마다 보이기·잠금을 바로 바꿉니다.

## 도형 데이터와 필드

### 도형 데이터

![도형 데이터](docs/tutorial/images/33-shapeData.jpg)

도형마다 이름과 값으로 된 데이터 필드를 붙입니다. **데이터 › 도형 데이터…**(`Ctrl+Shift+D`, 속성 패널의 **데이터 편집**)

| 항목 | 내용 |
|---|---|
| **이름** | 필드 이름(예: 담당, 비용, IP) |
| **종류** | 텍스트 · 숫자 · 통화 · 날짜 · 예/아니요 · 목록 |
| **값** | 종류에 맞는 입력 칸(날짜는 달력, 예/아니요·목록은 고르기) |
| **목록 항목** | 목록 종류일 때 고를 값들, 세미콜론(;)으로 구분 |

**필드 추가** · **필드 삭제**로 필드를 관리합니다. 여러 도형을 선택하고 열면 필드 구성이 모두에 적용되고, **값도 모든 선택한 도형에 적용**을 켜면 값까지 같아집니다. 속성 패널의 **도형 데이터** 구역에서는 값을 바로 고칩니다. 도형 데이터는 보고서·CSV 내보내기·데이터 표시·필드(`{data:이름}`)·찾기에 쓰입니다.

### 데이터 표시

![데이터 표시](docs/tutorial/images/34-dataGraphics.jpg)

도형 아래에 데이터 값을 작게 보여 줍니다.

- **데이터 › 이 도형에 데이터 표시**: 선택한 도형만 켜고 끕니다(속성 패널 도형 데이터 구역의 버튼).
- **데이터 › 모든 도형에 데이터 표시**: 드로잉 전체에 켭니다(페이지 설정 › 레이아웃·연결선에도 있음).

### 도형 데이터 보기

![도형 데이터 표](docs/tutorial/images/35-dataView.jpg)

보기 전환 › **도형 데이터**는 도형의 데이터를 표로 보여 줍니다. 열은 이름, 텍스트, 그리고 데이터 필드마다 하나씩입니다.

- **범위**: **현재 페이지** · **모든 페이지**(모든 페이지일 때는 페이지 열이 앞에 붙음). "데이터 필드 n개"가 함께 보입니다.
- 칸을 두 번 클릭하거나 `F2`로 고치고 Enter로 반영합니다. 열 경계를 끌어 너비를 바꾸고 두 번 클릭하면 내용에 맞춥니다.
- 위쪽 버튼: **필드 추가**(선택한 도형의 도형 데이터 창), **데이터 연결**(CSV를 도형에 연결), **CSV**(도형 데이터를 CSV로 내보내기).

### 도형 시트

![도형 시트](docs/tutorial/images/38-shapeSheet.jpg)

보기 전환 › **도형 시트**는 현재 페이지의 모든 도형(그룹과 그 안의 도형, 연결선)을 한 줄씩 보여 줍니다.

| 열 | 고칠 수 있음 |
|---|---|
| 이름 · 텍스트 · 하이퍼링크 | 예 |
| X · Y · 너비 · 높이 · 각도 | 예 (측정 단위로) |
| 채우기 · 선 | 예 (`#RRGGBB` 형식) |
| 선 두께 · 글꼴 크기 | 예 |
| 마스터 · 레이어 · 데이터(개수) · ID | 보기만 |

여러 도형의 위치·크기·색을 숫자로 한꺼번에 맞출 때 편합니다. **드로잉** 버튼으로 드로잉 보기로 돌아갑니다.

### 찾기와 바꾸기

**편집 › 찾기…**(`Ctrl+F`) · **바꾸기…**(`Ctrl+H`) · **페이지로 이동**(`Ctrl+G`)은 한 창의 세 탭입니다.

| 탭 | 내용 |
|---|---|
| **찾기** | 찾을 내용, 옵션(**대/소문자 구분** · **단어 단위** · **도형 데이터도**), 범위(**현재 페이지** · **모든 페이지**), **이전** · **다음 찾기**. 찾은 도형을 선택하고 "n개 중 m번째"를 보여 줍니다 |
| **바꾸기** | 바꿀 내용과 **바꾸기**(하나) · **모두 바꾸기**(한 번에 실행 취소 가능) |
| **페이지로 이동** | 페이지를 골라 **이동** |

도형 텍스트·이름과(옵션을 켜면) 도형 데이터 값에서 찾습니다. 창은 열어 둔 채로 계속 찾을 수 있습니다.

### 보고서

![보고서](docs/tutorial/images/37-reports.jpg)

**데이터** 메뉴나 도형 보고서 보기의 탭에서 고릅니다. 보고서는 드로잉의 모든 페이지를 대상으로 합니다.

| 보고서 | 내용 |
|---|---|
| **도형 목록** | 페이지·도형·연결선·그룹·데이터가 있는 도형·메모 수, 종류별 도형 수(막대, 상위 20), 스텐실별 도형 수, 도형 목록 표 |
| **도형 데이터** | 데이터가 있는 도형 수, 데이터 필드 수, 숫자 필드 합계("비용 합계" 등)와 막대, 페이지·이름·필드별 값 표 |
| **연결 관계** | 연결선 수, 양쪽이 붙은 연결선 수, 가장 많이 연결된 도형(막대), 연결 목록(시작 도형 · 끝 도형 · 텍스트 · 모양) |
| **페이지** | 페이지별 도형 수(막대), 페이지 목록(배경 페이지 여부 · 크기 · 도형 · 연결선 · 레이어 수 · 배경) |
| **레이어** | 페이지마다 레이어와 그 레이어의 도형 수, 보이기 · 인쇄 · 잠금, 레이어 없는 도형 수 |
| **모든 텍스트** | 텍스트가 있는 모든 도형과 연결선의 페이지 · 종류 · 텍스트 |

**보고서 복사**는 보고서 내용을 글자로 클립보드에 넣어 엑셀이나 문서에 붙여넣게 합니다.

**보고서 내보내기**는 지금 보고 있는 보고서를 파일로 저장합니다. **데이터 › 보고서 내보내기** 하위 메뉴, 보고서 화면 머리글의 **보고서 내보내기…** 버튼, 보고서 빈 곳의 오른쪽 클릭 메뉴에서 형식을 고릅니다.

| 형식 | 내용 |
|---|---|
| **HTML (.html)** | 브라우저에서 바로 여는 한 파일짜리 웹 페이지. 차트는 SVG 그림이고, 각 차트 아래 **값**을 펼치면 숫자 표가 보입니다. 메일에 첨부하거나 사내 위키에 올리기 좋습니다 |
| **Markdown (.md)** | 제목과 GitHub 표. 차트는 숫자 표로 바뀝니다. Git 저장소·이슈·노트 앱에 붙여넣을 때 씁니다 |
| **Word (.docx)** | A4 Word 문서. 제목·표(테두리, 머리글 행이 페이지마다 반복)·차트 그림과 그 숫자 표가 들어 있고, 글꼴은 맑은 고딕입니다. Word·한컴오피스·LibreOffice에서 고쳐 쓸 수 있습니다 |
| **PDF (.pdf)** | A4 쪽마다 보고서를 그린 PDF. 한글 글꼴을 넣지 않아도 어디서나 똑같이 보이도록 쪽을 그림으로 담았기 때문에 글자를 골라 복사할 수는 없습니다 |

파일 이름은 "드로잉 제목 - 보고서 이름"으로 제안되고, 만드는 데 시간이 걸리면 진행 팝업이 뜹니다.

## 자동 레이아웃과 데이터 가져오기

### 페이지 다시 레이아웃

**정렬 › 페이지 다시 레이아웃…**은 연결선으로 이어진 도형을 자동으로 배치합니다. 결과는 `Ctrl+Z`로 되돌립니다.

| 레이아웃 | 배치 |
|---|---|
| **순서도 (위→아래)** | 단계별로 줄을 맞춥니다 |
| **순서도 (왼쪽→오른쪽)** | 단계별로 열을 맞춥니다 |
| **계층 (위→아래)** | 조직도처럼 |
| **계층 (왼쪽→오른쪽)** | 옆으로 펼친 트리 |
| **방사형** | 중심에서 바깥으로 |
| **원형** | 원 위에 배치 |
| **격자** | 줄과 칸으로 |

| 옵션 | 내용 |
|---|---|
| **간격** | 도형 사이 간격(10 ~ 300 px) |
| **대상** | **페이지 전체** · **선택한 도형**(두 개 이상 선택했을 때) |
| **연결선** | **그대로** · 직각 · 직선 · 곡선 — 배치하면서 연결선 모양을 바꿉니다 |

그룹은 하나로 움직이고, 컨테이너·텍스트·선 도형은 제자리에 둡니다. 연결선의 손으로 꺾은 점은 지워져 다시 경로를 찾습니다. **정렬 › 자동 맞춤 및 간격**은 같은 일을 순서도(위→아래), 간격 50으로 바로 합니다.

### 데이터로 조직도 만들기

![데이터로 조직도](docs/tutorial/images/36-orgChart.jpg)

**데이터 › 데이터로 조직도 만들기…**는 표를 조직도로 바꿉니다.

- 첫 줄은 머리글입니다: **이름**, **직함**, **상사**(그 사람의 이름). 머리글은 한국어·영어 모두 알아봅니다(이름/성명/Name, 직함/직위/직책/Title, 상사/관리자/보고 대상/Manager, 부서/팀/Department).
- 나머지 열(부서 등)은 도형 데이터가 됩니다.
- 엑셀에서 복사해 붙여넣거나 **파일 열기…**로 CSV·TSV·TXT 파일을 엽니다. **예제 데이터**로 형식을 볼 수 있습니다.
- 상사가 없는 사람은 경영진, 부하가 있는 사람은 관리자, 나머지는 직위 도형이 되고, 계층 (위→아래)으로 배치됩니다. **간격**을 정할 수 있습니다.
- **조직도 만들기**를 누르면 현재 페이지에 그려지고 "n명의 조직도를 만들었습니다."가 뜹니다.

```
이름,직함,상사,부서
김대표,대표이사,,경영
이부장,개발 부장,김대표,개발
최과장,백엔드,이부장,개발
```

### 데이터를 도형에 연결

**데이터 › 데이터를 도형에 연결…**(도형 데이터 보기의 **데이터 연결**)은 CSV의 행을 현재 페이지의 도형에 붙입니다.

- 첫 줄은 머리글입니다. 각 행은 **ID** 열이 같은 도형, 없으면 **이름**이 같은 도형, 없으면 **텍스트**가 같은 도형에 연결됩니다.
- 나머지 열은 도형 데이터가 됩니다(숫자면 숫자 종류). 같은 이름의 필드가 있으면 값을 바꿉니다.
- **맞는 도형이 없으면 새로 만들기**를 켜면 짝이 없는 행마다 도형을 만듭니다.
- 결과는 "n행 중 m행을 도형에 연결했습니다 (새 도형 k개)."로 알려 줍니다.
- CSV 파일을 창으로 끌어다 놓아도 이 창이 열립니다.

**도형 데이터를 CSV로 내보내기…**로 만든 파일(페이지 · ID · 이름 · 마스터 · 텍스트 · 필드 열)을 엑셀에서 고친 뒤 다시 연결하면 데이터가 한꺼번에 바뀝니다.

### 목록으로 순서도 만들기

**데이터 › 목록으로 순서도 만들기…**는 한 줄에 한 단계씩 쓴 목록을 차례로 연결된 도형으로 만듭니다. **도형 종류**는 프로세스 · 둥근 사각형 · 타원 · 시작/종료 · 주제 중에서 고릅니다.

```
요청 접수
검토
승인
처리
완료 통보
```

웹 버전에서는 다른 곳의 여러 줄 텍스트를 창으로 끌어다 놓아도 같은 방식으로 도형이 만들어집니다.

## 파일 (mdg/mdgt/Visio vsdx/SVG/PNG/PDF/HTML/CSV 내보내기)

![파일 메뉴](docs/tutorial/images/39-fileMenu.jpg)

### 저장

- **저장**(`Ctrl+S`)은 MyDiagram 드로잉 파일(`.mdg`)로 저장합니다. 처음 저장하거나 템플릿·Visio 파일에서 시작했으면 파일 이름을 묻습니다.
- **다른 이름으로 저장…**(`Ctrl+Shift+S`), **모두 저장**(`Ctrl+Alt+S`: 수정된 탭을 모두 저장).
- 그림을 포함한 모든 것이 한 파일에 들어갑니다. 큰 파일은 진행 창이 표시됩니다.
- 데이터베이스 연결을 설정했으면 저장할 때 파일과 데이터베이스에 함께 저장합니다([데이터베이스](#데이터베이스) 참고).
- **설정 › 일반 › 시작할 때 지난번에 연 파일 다시 열기**를 켜면 다음 실행 때 열려 있던 파일을 다시 엽니다.

### 템플릿

**파일 › 템플릿으로 저장…**은 지금 드로잉을 그대로 `.mdgt` 템플릿 파일로 만듭니다. 템플릿을 열면 제목 없는 새 드로잉이 되고(탭 아이콘이 달라짐), 저장할 때 새 `.mdg` 이름을 묻습니다.

### 열기

**열기…**(`Ctrl+O`)로 `.mdg`, `.mdgt`, Visio `.vsdx` · `.vstx` 파일을 엽니다. 여러 파일을 한 번에 고를 수 있고, 이미 열려 있는 파일을 다시 열면 그 탭으로 갑니다. `.mdg` · `.mdgt` 파일을 두 번 클릭해도 MyDiagram에서 열립니다(설치 프로그램이 파일 형식을 등록함).

### Visio와 주고받기

![Visio와 주고받기](docs/tutorial/images/40-visio.jpg)

| 명령 | 내용 |
|---|---|
| **Visio 파일 열기 (.vsdx)…** | Visio 드로잉(`.vsdx`)과 템플릿(`.vstx`)을 엽니다. 페이지, 도형(마스터·스타일 시트·그룹·호와 타원 같은 기하 포함), 텍스트, 채우기와 선, 회전·대칭, 도형 데이터, 하이퍼링크, 레이어, 그림, 붙은 연결선을 읽습니다. 연 파일은 저장하면 MyDiagram 파일(`.mdg`)이 됩니다 |
| **내보내기 › Visio 형식으로 저장 (.vsdx)…** | 페이지·도형·텍스트·서식·데이터·레이어·그림·연결선과 붙이기를 `.vsdx`로 저장합니다. Visio에서 열어 계속 고칠 수 있습니다 |

### 내보내기

**파일 › 내보내기** 하위 메뉴:

| 명령 | 형식 | 내용 |

| **SVG로 내보내기 (현재 페이지)…** | `.svg` | 현재 페이지를 벡터 그림으로. 페이지가 여럿이면 파일 이름에 페이지 이름이 붙습니다 |
| **그림으로 내보내기 (PNG·JPEG·SVG…)…** | 아래 표 | 이미지로 내보내기 창 |
| **웹 페이지로 내보내기 (.html)…** | `.html` | 모든 페이지를 SVG로 담은 한 파일짜리 웹 페이지. 위쪽에 제목·주제와 페이지 바로 가기가 있습니다 |
| **도형 데이터를 CSV로 내보내기…** | `.csv` | 모든 페이지 도형의 페이지 · ID · 이름 · 마스터 · 텍스트와 데이터 필드 열 |

### 그림으로 내보내기

![페이지를 그림으로](docs/tutorial/images/42-imageExport.jpg)

| 항목 | 내용 |
|---|---|
| **파일 형식** | PNG · JPEG · WebP · BMP · TIFF · SVG |
| **배경** | **투명** · **흰색**. JPEG는 투명 배경을 지원하지 않아 흰색으로 저장합니다 |
| **내보낼 영역** | **도형이 있는 부분만**(기본) · **페이지 전체** · **선택한 도형**(선택했을 때) |
| **배율** | 1× · 2× · 3× (SVG는 벡터라 배율과 상관없이 선명함) |
| **품질** | JPEG · WebP의 압축 품질(40 ~ 100%) |
| **이미지 크기** | 만들어질 그림의 픽셀 크기 |

투명 배경으로 저장하면 문서·슬라이드 위에 바로 겹쳐 쓸 수 있습니다. 마지막으로 고른 선택은 다음에도 유지됩니다.

### 최근 파일과 폴더

![최근 파일 관리](docs/tutorial/images/44-recentFiles.jpg)

- **파일 › 최근 파일…**(`Ctrl+R`)은 **최근 파일**과 **최근 폴더**가 있는 창을 엽니다. 각각 10개까지 기억합니다.
- 항목마다 **열기**(폴더는 **이 폴더에서 열기**)와 **목록에서 지우기**가 있고, **모두 지우기** · **폴더 기록 모두 지우기**로 한 번에 지웁니다.
- 없어진 파일은 **없음**으로 표시되고, 열려고 하면 목록에서 지울지 묻습니다(**그대로 두기** · **목록에서 지우기**).
- **파일 › 최근 폴더**는 폴더 목록을 메뉴로 보여 주고, **최근 파일·폴더 기록 모두 지우기**는 두 목록을 함께 지웁니다.
- 시작 페이지와 **설정 › 최근 기록** 탭에서도 같은 목록을 관리합니다.

### 끌어다 놓기

![끌어다 놓기](docs/tutorial/images/45-dragDrop.jpg)

탐색기(Finder)에서 파일을 창으로 끌어오면 "여기에 놓으면 엽니다" 안내가 뜹니다.

| 끌어온 것 | 결과 |
|---|---|
| `.mdg` · `.mdgt` | 드로잉으로 엽니다 |
| `.vsdx` · `.vstx` | Visio 파일을 가져옵니다 |
| 그림(png · jpg · gif · webp · bmp · svg …) | 드로잉이 열려 있으면 놓은 자리에 그림으로 들어가고(여러 개면 조금씩 비켜서), 시작 페이지에서는 배경 이미지가 됩니다 |
| `.csv` · `.tsv` · `.txt` | **데이터를 도형에 연결** 창이 열립니다 |
| 텍스트 (웹 버전) | 한 줄에 도형 하나로 연결된 순서도가 만들어집니다 |

앱 안에서는 **도형** 패널의 도형을 캔버스로 끌어 놓은 자리에 넣습니다(클릭하면 화면 가운데에 들어갑니다).

### 저장하지 않은 변경 확인

- 탭을 닫을 때(`Ctrl+W`) 저장하지 않은 변경이 있으면 **저장** · **저장 안 함** · **취소**를 묻습니다.
- 프로그램을 끝낼 때(**파일 › 끝내기**, 창 닫기) 저장하지 않은 드로잉이 있으면 같은 질문을 합니다.
- 웹 버전에서는 저장하지 않은 드로잉이 있으면 브라우저가 페이지를 떠날지 묻습니다.

## 데이터베이스

파일 대신 데이터베이스에 드로잉을 보관할 수 있습니다(데스크톱 앱 전용 — 웹 브라우저는 DB 서버나 SQLite 파일에 직접 연결할 수 없어 메뉴가 보이지 않습니다).

![데이터베이스에 저장하기](docs/tutorial/images/43-database.jpg)

### 연결 설정

**설정 › 데이터베이스** 탭에서 고릅니다.

| 항목 | 설명 |
|---|---|
| **DB 종류** | 사용 안 함 · SQLite · MariaDB · MySQL · PostgreSQL |
| **SQLite 파일** | SQLite일 때. **찾아보기…**로 기존 파일을 고르거나 새 파일 이름(예: `C:\Data\mydiagram.db`)을 정하면 처음 연결할 때 만들어집니다 |
| **서버 주소 · 포트 · 데이터베이스 이름 · 사용자** | 서버 DB일 때. 포트를 바꾸지 않으면 MariaDB/MySQL 3306, PostgreSQL 5432. 데이터베이스는 미리 만들어 두어야 하고, 이름에는 영문, 숫자, `_`, `$`, `-`만 쓸 수 있습니다 |
| **비밀번호** | 기본으로는 저장하지 않고 프로그램을 닫을 때까지만 기억합니다. **비밀번호를 설정에 저장**을 켜면 설정에 함께 저장됩니다 |
| **연결 테스트** | 접속해 "연결됨 — 서버 버전"을 보여 주고, 드로잉을 담는 표가 없으면 만듭니다. 실패하면 이유를 보여 줍니다 |

### 저장하고 열기

- 연결을 설정하면 **저장**(`Ctrl+S`)은 파일과 데이터베이스에 함께 저장합니다(저장 버튼 툴팁에 "파일과 데이터베이스에 함께 저장"이 보이고, 결과는 "저장됨 — 파일과 데이터베이스"로 알려 줌).
- **파일 › 데이터베이스에 저장**은 지금 탭의 드로잉을 `.mdg` 파일과 똑같은 내용으로 데이터베이스에만 저장합니다. 같은 드로잉을 다시 저장하면 덮어씁니다. 파일 없이 데이터베이스에서 연 드로잉은 이것으로 저장되어 "저장하지 않은 변경"이 사라집니다.
- **파일 › 데이터베이스에서 열기…**는 저장된 드로잉 목록(제목 · 마지막 저장 시각 · 크기)을 보여 줍니다. **열기**로 새 탭에 열고, 휴지통 버튼(**데이터베이스에서 삭제**)으로 지웁니다(확인을 묻고, 되돌릴 수 없음). **새로 고침**으로 목록을 다시 읽습니다.
- 연결이 설정되지 않았으면 두 명령 모두 "먼저 설정 › 데이터베이스에서 연결을 설정하세요"를 알리고 설정의 데이터베이스 탭을 엽니다.

## 인쇄와 미리 보기

![인쇄 미리 보기](docs/tutorial/images/41-print.jpg)

**파일 › 인쇄…**(`Ctrl+P`)는 **인쇄 미리 보기** 창을 엽니다. 설정을 바꾸면 오른쪽 미리 보기가 바로 바뀌고, 아래 화살표로 쪽을 넘깁니다("1 / 3쪽"). 왼쪽 설정은 탭 없이 한 열에 차례로 있습니다.

| 구역 | 항목 |
|---|---|
| **인쇄 범위** | **모든 페이지** · **현재 페이지** · **페이지 범위**(처음 페이지 ~ 마지막 페이지), **인쇄할 내용**("페이지 3개 · 용지 3장") |
| **페이지 설정** | 용지(A3 · A4 · A5 · B4 · B5 · Letter · Legal · Tabloid), 방향(세로 · 가로), 여백(없음 · 좁게 · 보통 · 넓게), 크기(**용지에 맞춤** · **실제 크기** · **배율** 10 ~ 400%), **용지 가운데에**, **페이지 색과 배경 페이지 인쇄** |
| **머리글·바닥글** | 머리글 · 바닥글 켜기와 문구(비워 두면 머리글은 드로잉 제목, 바닥글은 MyDiagram) |

- **용지에 맞춤**은 페이지 하나를 용지 한 장에 맞춥니다. **실제 크기**나 **배율**로 용지보다 큰 페이지는 여러 장에 나눠 인쇄합니다.
- 배경 페이지는 그 배경을 쓰는 페이지와 함께 인쇄되고(**페이지 색과 배경 페이지 인쇄**를 켰을 때), 따로 한 장으로 나오지 않습니다. **인쇄**를 끈 레이어는 나오지 않습니다.
- **인쇄** 버튼은 운영체제의 인쇄 대화 상자를 엽니다(PDF로 저장도 여기서). 페이지 설정은 다음 인쇄와 **PDF로 내보내기**에도 그대로 쓰입니다.

## 꾸미기 (테마·디자인·설정·시작 화면·배경 애니메이션)

### 테마

![테마](docs/tutorial/images/46-theme.jpg)

- 툴바의 **테마 무작위로 바꾸기** 버튼은 누를 때마다 다른 테마를 무작위로 고릅니다. 툴팁에 지금 테마 이름이 보입니다.
- 옆의 ▾(**테마 고르기**)는 **다크 (20)**와 **라이트 (20)**를 두 줄로 보여 주는 창을 엽니다. 위쪽에는 **시스템 설정**(운영체제의 밝기를 따름)과 **사용자 정의**가 있고, 아래에 **사용자 정의 테마 편집…** · **테마 무작위로 바꾸기**가 있습니다.
- **설정 › 테마** 탭: 다크 20 · 라이트 20 · 사용자 정의 그룹. 사용자 정의에서는 바탕 · 표면 · 패널 · 글자 · 흐린 글자 · 테두리 · 강조 · 강조 위 글자 · 줄무늬 행 · 차트 바탕 · 툴바 · 상태 표시줄 색을 하나씩 고치고, **사용자 정의 테마 사용**, **지금 테마의 색 가져오기**, **어두운 테마** 스위치가 있습니다. 글자 대비가 낮으면 "글자가 잘 안 보일 수 있습니다" 경고가 뜹니다.

이 테마는 프로그램 화면(메뉴·패널·표)의 색입니다. 다이어그램 도형의 색은 [테마와 변형](#테마와-변형)(드로잉 디자인)에서 고릅니다.

### 언어

![언어](docs/tutorial/images/47-language.jpg)

툴바의 국기 버튼(**언어 전환**, `Ctrl+Shift+L`)으로 한국어와 영어를 바꿉니다. 한국어일 때는 영국 국기, 영어일 때는 태극기가 보입니다(누르면 그 언어로 바뀜). **설정 › 일반 › 언어**에서도 바꿉니다. 메뉴, 팝업, 보고서, 오류 메시지, 백엔드 메시지까지 모두 바뀝니다. 도형 이름(스텐실)도 그 언어로 보입니다.

### 글꼴

**설정 › 글꼴** 탭에서 시스템에 설치된 모든 글꼴 중 하나를 고르고 **글자 크기**(9 ~ 28 px), **굵기**(가늘게 ~ 아주 굵게), **스타일**(보통·기울임), **행 높이**, **확대/축소**(50 ~ 200%)를 정합니다. 화면 글꼴은 메뉴·패널·표에 적용되고 아래 미리 보기에 바로 보입니다. 드로잉 밖에서 `Ctrl+마우스 휠`을 굴려도 화면 확대/축소가 바뀝니다. (도형 텍스트의 글꼴은 [텍스트와 서식](#텍스트와-서식)에서 고릅니다.)

### 시작 화면과 움직이는 배경

![움직이는 배경](docs/tutorial/images/05-background.jpg)

시작 페이지의 배경은 계속 움직입니다. **설정 › 배경** 탭:

| 항목 | 내용 |
|---|---|
| **배경 종류** | 움직이는 배경 · 이미지 · 없음 |
| **움직이는 배경** | 오로라 · 물결 · 입자 · 별자리 · 거품 · 흐르는 격자 · 순서도 · 별빛 · 비 · 눈 · 반딧불 · 파문 · 코드 비 · 육각 격자 · 궤도 · 라바 램프 · 은하 나선 · 색종이 · 노드 네트워크 · 리본 (20가지), **움직이는 배경 바꾸기**(`Ctrl+Shift+B`, 무작위) |
| **움직임 속도** | 0 ~ 300% |
| **시작할 때 배경 무작위** | 프로그램을 시작할 때마다 다른 움직이는 배경을 고릅니다 |
| **시작 페이지 배경 자동 변경** | 시작 페이지가 열려 있는 동안 정한 시간마다(끄기 · 15초 · 30초 · 1분 · 2분 · 5분) 배경을 바꿉니다 |
| **움직이는 배경은 시작 페이지에서만** | 켜면 보기 뒤에서는 움직이지 않음 |
| **배경 이미지** | **고르기…** · **지우기**. 이미지 크기 제한은 없고, 시작 페이지에 이미지 파일을 끌어다 놓아도 배경이 됩니다 |
| **배경 불투명도 (보기 뒤)** | 보기 뒤 배경의 진하기 |
| **맞춤** | 채우기 · 맞추기 · 바둑판 · 가운데 · 늘이기 |

시작 페이지의 **움직이는 배경** 카드에서도 애니메이션·속도·무작위·자동 변경을 바로 바꿉니다. **보기 › 테마·언어·배경 › 배경 끄기**는 배경을 끕니다.

### 패널

![패널 접기](docs/tutorial/images/48-panels.jpg)

- 도형 패널과 속성 패널은 머리글의 화살표, **보기 › 표시 › 도구 패널 펼치기/접기**(`Ctrl+Shift+1`) · **속성 패널 펼치기/접기**(`Ctrl+Shift+2`), 툴바 버튼으로 접고 펼칩니다.
- 접으면 아이콘과 제목만 남은 좁은 줄이 되고, 맨 위의 **펼치기** 버튼으로 다시 엽니다. 접힌 줄에서도 그리기 도구(도형 패널)와 서식 · 데이터 · 레이어 · 페이지 · 테마 · 메모(속성 패널)를 쓸 수 있습니다.
- 패널 사이 구분자를 끌어 너비를 바꿉니다.

### 설정 창

![설정](docs/tutorial/images/50-settings.jpg)

**도움말 › 설정…**(`Ctrl+,`). 설정은 바로 적용되고 저장되어 다음 실행 때 다시 쓰입니다. **기본값으로**는 모든 설정을 처음 값으로 돌립니다(언어, 배경 이미지, 마지막으로 쓴 폴더, 튜토리얼 기록은 유지).

| 탭 | 항목 |
|---|---|
| **일반** | 언어, 시작할 때 지난번에 연 파일 다시 열기, 도형이 있는 페이지를 삭제하기 전에 묻기, 상태 표시줄에 시계 표시, 상태 표시줄, 마지막으로 쓴 폴더, 튜토리얼 시작 |
| **시작 화면** | 시작할 때 시작 페이지 표시, 최근 파일 표시, 표시할 최근 파일 수(1 ~ 10), 최근 폴더 표시, 예제 드로잉 표시, 움직이는 배경 고르기 표시, 튜토리얼 안내 띠 표시, 시작 화면 **지금 열기**. 바꾼 내용은 시작 화면에 바로 반영됩니다 |
| **테마** | 다크 · 라이트 · 사용자 정의, 시스템 설정 |

## 문제 해결

### 오류 창

오류가 나면 **오류** 창이 뜹니다. 메시지, **시각**, **위치**(무슨 작업 중이었는지), App(버전·플랫폼)과 **자세한 내용**이 있고, **내용 복사** 버튼으로 전부 복사해 문제를 알리거나 기록할 수 있습니다.

| 오류 제목 | 흔한 원인 |
|---|---|
| 파일을 열 수 없습니다 | MyDiagram 파일이 아님(JSON 형식이 아님), 더 새 버전의 MyDiagram으로 만든 파일, 손상되었거나 Visio 파일이 아님 |
| 저장할 수 없습니다 · 내보낼 수 없습니다 | 쓰기 권한이 없는 폴더, 다른 프로그램이 파일을 잡고 있음, 그 시스템이 지원하지 않는 그림 형식 |
| 입력 오류 | 숫자·길이 형식이 틀림("숫자를 입력하세요 (예: 25 mm)."), 색 형식이 틀림("#RRGGBB 형식의 색을 입력하세요.") |
| 그림을 넣지 못했습니다 | 읽을 수 없는 그림 파일 |
| 데이터를 가져오지 못했습니다 | CSV에 머리글 다음 행이 없음, 읽을 수 없는 파일 |
| 데이터베이스에 저장하지 못했습니다 · 데이터베이스 작업을 하지 못했습니다 | 서버 주소·포트·사용자·비밀번호가 틀림, 데이터베이스가 없음, SQLite 파일에 쓸 수 없음 |
| 인쇄할 수 없습니다 | 프린터나 인쇄 대화 상자 문제 |
| 링크를 열지 못했습니다 | 잘못된 웹 주소나 없는 파일 |
| 사용 설명서를 열 수 없습니다 | 설치 폴더의 `docs` 폴더가 지워짐 |

### 심각한 오류와 crash.log

프로그램 내부(백엔드)에서 심각한 오류가 나면 **심각한 오류 (백엔드)** 창에 위치·스레드·백트레이스와 **기록 파일** 경로가 표시됩니다. 같은 내용이 `crash.log`에 쌓입니다.

| OS | crash.log 위치 |
|---|---|
| Windows | `%APPDATA%\com.shkwon.mydiagram\crash.log` |
| macOS | `~/Library/Application Support/com.shkwon.mydiagram/crash.log` |
| Linux | `~/.local/share/com.shkwon.mydiagram/crash.log` |

### "이미 실행 중" 오류

MyDiagram은 사용자마다 하나만 실행됩니다. 이미 실행 중일 때 다시 실행하면 **MyDiagram — 실행 오류** 창에 "MyDiagram 이 이미 실행 중입니다."가 뜨고 새 실행은 끝납니다. 작업 표시줄(Dock)에서 열려 있는 창을 찾아 쓰세요. 이미 열린 창에서 **파일 › 열기…**로 다른 드로잉을 탭으로 열 수 있습니다. 프로그램이 비정상 종료되었더라도 잠금은 운영체제가 풀어 주므로 다음 실행이 막히지 않습니다.

### 그 밖에

| 증상 | 해결 |
|---|---|
| 도형을 고를 수 없음 | 레이어가 잠겨 있거나 숨겨져 있는지(**페이지 › 레이어…**), 배경 페이지의 도형인지, 컨테이너 안쪽을 클릭한 것은 아닌지 확인합니다 |
| 도형이 안 보임 | 레이어의 **보이기**를 확인하고, **페이지 전체 보기**(`Ctrl+Shift+W`)로 페이지 밖에 있는지 봅니다 |
| 도형이 움직이지 않거나 지워지지 않음 | **도형 보호**(이동 금지·삭제 금지 등)를 확인합니다 |
| 끌 때 원하는 곳에 멈추지 않음 | `Alt`를 누른 채 끌거나 **격자에 맞추기** · **스마트 안내선**을 끕니다 |
| 연결선이 도형을 따라오지 않음 | 끝이 붙어 있는지(초록 끝점) 보고, **도형에 붙이기 (연결점)**가 켜져 있는지 확인합니다 |
| 연결선이 이상하게 꺾임 | **연결선 꺾임 지우기**로 손으로 꺾은 점을 지우거나 **연결선 모양**을 바꿉니다 |
| 인쇄물에 도형이 빠짐 | 그 레이어의 **인쇄**가 꺼져 있는지 확인합니다 |
| 화면이 너무 크거나 작음 | `Ctrl+0`(100%로 보기), 드로잉 밖에서는 **설정 › 글꼴 › 확대/축소** |
| 설정을 처음으로 | **설정 › 기본값으로** |
| 웹 버전에서 최근 파일이 안 열림 | 브라우저 보안 때문에 **열기**로 파일을 다시 골라야 할 수 있습니다 |

## 설치와 제거

### Windows

`MyDiagram-Setup-1.0.0.exe`를 실행합니다.

1. 설치 언어(한국어/English)를 고릅니다.
2. 이전에 설치한 MyDiagram의 **설정은 기본값으로 되돌리고, 사용자 데이터는 그대로 둡니다.** 설치 후 처음 실행할 때 테마·글꼴·확대/축소·패널·보기 옵션·창과 팝업 위치·열 너비·인쇄 선택이 처음 상태가 되고, 최근 파일·폴더, 열려 있던 드로잉 목록, 데이터베이스 연결, 배경 이미지, 튜토리얼 기록은 남습니다. 드로잉 파일(.mdg)은 손대지 않습니다.
3. 이전 설치가 있으면 완전히 제거한 뒤 새로 설치합니다.
4. 설치가 끝나면 `.mdg`(드로잉)와 `.mdgt`(템플릿)가 각자의 문서 아이콘으로 등록되어 두 번 클릭으로 열립니다.
5. 시작 메뉴의 **MyDiagram** 폴더에 프로그램과 **MyDiagram User's Guide**(이 설명서) 바로 가기가 생깁니다. 설명서와 튜토리얼 문서, 예제 드로잉은 설치 폴더의 `docs`, `samples` 폴더에 들어 있습니다.

현재 사용자용으로 설치되므로 관리자 권한이 필요 없습니다. 제거는 **설정 › 앱**(또는 제어판 › 프로그램 제거)에서 MyDiagram을 고릅니다.

| 데이터 | 위치 (Windows) |
|---|---|
| 설정, 최근 파일·폴더, 내 도형 | `%LOCALAPPDATA%\com.shkwon.mydiagram` (WebView2 저장소) |
| 창 위치·크기, 배경 이미지, crash.log | `%APPDATA%\com.shkwon.mydiagram` |

### macOS

`MyDiagram-1.0.0-<arch>.dmg`를 열고 MyDiagram을 응용 프로그램 폴더로 끌어 놓습니다. 제거는 응용 프로그램 폴더에서 휴지통으로 옮깁니다. macOS 11 이상이 필요합니다.

### Linux

`.deb`(Debian·Ubuntu), `.rpm`(Fedora 등), `.AppImage` 중 하나를 씁니다. deb·rpm은 `.mdg` · `.mdgt` 파일 형식과 아이콘을 등록합니다. 제거는 패키지 관리자로 합니다.

### 웹 버전

웹 빌드(`dist/`)를 아무 정적 웹 서버에 올리면 브라우저에서 같은 기능을 씁니다. 차이점:

- 파일은 브라우저의 파일 선택 창으로 열고, 저장은 파일 시스템 접근을 지원하는 브라우저(Edge·Chrome)에서는 같은 파일에, 그 밖에는 내려받기로 합니다.
- 팝업 창은 페이지 안에 떠 있는 창으로 열립니다.
- 데이터베이스, 파일 형식 등록, "이미 실행 중" 검사처럼 운영체제 기능이 필요한 것은 데스크톱 앱에서만 됩니다. 시스템 글꼴 목록은 브라우저가 허락할 때만 읽습니다.
- 설정, 최근 기록, 내 도형은 브라우저 저장소에 남습니다.
