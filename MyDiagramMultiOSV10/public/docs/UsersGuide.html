MyDiagram 사용 설명서

MyDiagram은 Microsoft Visio와 비슷한 방식으로 순서도·조직도·네트워크 구성도·UML·데이터베이스 모델·평면도 같은 다이어그램을 그리고, 도형에 데이터를 붙여 보고서로 정리하는 프로그램입니다. Windows · macOS · Linux 데스크톱 앱과 웹 브라우저에서 같은 화면으로 동작합니다.

이 설명서는 하는 일 순서로 정리되어 있습니다. 화면의 메뉴·명령 이름은 프로그램에 표시되는 이름 그대로 적었습니다(예: 삽입 › 텍스트 상자 삽입은 "삽입" 메뉴의 "텍스트 상자 삽입" 명령). 그림은 튜토리얼 화면을 캡처한 것입니다.

English version: UsersGuide.en.md

시작하기 #

처음 실행 #

처음 실행하면 MyDiagram에 오신 것을 환영합니다 창이 뜹니다.

버튼하는 일
튜토리얼 시작예제 드로잉으로 도형 그리기부터 연결·서식·정렬·페이지·데이터·인쇄·설정까지 모든 기능을 차례로 보여 주는 튜토리얼을 시작합니다
예제 열기"온라인 쇼핑몰 운영" 예제 드로잉을 엽니다
나중에창을 닫습니다. 튜토리얼은 언제든 도움말 › 튜토리얼(F11)로 볼 수 있습니다

MyDiagram은 한 번에 하나만 실행됩니다. 이미 실행 중일 때 다시 실행하면 오류 창이 뜨고 새 실행은 끝납니다(문제 해결 참고).

시작 페이지 #

드로잉을 열지 않았을 때(또는 메뉴 막대 맨 앞의 홈 버튼, Ctrl+Shift+H) 보이는 화면입니다. 뒤에서는 배경이 계속 움직입니다.

메뉴 막대의 홈 버튼은 열어 둔 드로잉을 닫지 않습니다. 탭을 누르면 그 드로잉으로 돌아갑니다.

템플릿은 맞는 스텐실을 열고 예제 그림을 넣어 줍니다. 툴바의 새 드로잉(Ctrl+N)이나 탭 줄의 +는 빈 드로잉을 만듭니다. 새 드로잉의 테마·용지·방향·단위·연결선 모양은 설정 › 새 드로잉을 따릅니다.

예제 드로잉 #

예제 드로잉의 "온라인 쇼핑몰"을 열면 세 페이지짜리 드로잉이 열립니다. 첫 페이지는 고객·쇼핑몰·물류 센터 스윔레인으로 나눈 주문 처리 순서도(도형 데이터·메모·하이퍼링크·"메모" 레이어 포함), 둘째는 조직도, 셋째는 서버 구성도입니다. 모든 페이지는 제목 칸이 있는 배경 페이지를 씁니다.

설치 폴더의 samples에는 이 밖에 주문 순서도 · 회사 조직도 · 사무실 네트워크 · 쇼핑몰 데이터베이스 드로잉, 브레인스토밍 템플릿(.mdgt), 그리고 Visio 형식으로 저장한 온라인 쇼핑몰(.vsdx)이 한국어·영어로 들어 있습니다.

튜토리얼 #

도움말 › 튜토리얼(F11), 툴바의 학사모 버튼, 시작 페이지의 튜토리얼 시작으로 시작합니다. 예제 드로잉을 띄워 놓고 56단계로 기능을 하나씩 보여 줍니다.

  • 다음 · 이전 단계 버튼, 자동 재생(▶)으로 넘깁니다. 마지막 단계에서는 마치기를 누릅니다.
  • 장 고르기 목록으로 시작 · 도형 그리기 · 연결하기 · 서식 · 정렬과 배치 · 페이지와 레이어 · 데이터와 보고서 · 파일과 인쇄 · 사용자 설정 · 도움말 중 원하는 장으로 갑니다.
  • 안내 상자는 끌어서 옮길 수 있습니다. Esc나 ✕(튜토리얼 끝내기 (Esc))로 끝냅니다.
  • 내 파일은 바뀌지 않고, 튜토리얼이 바꾼 설정(테마·언어·배경 등)은 끝날 때 원래대로 돌아갑니다.

튜토리얼 문서 — 튜토리얼의 모든 단계를 화면과 함께 정리한 문서는 프로그램 안에서 읽을 수 있습니다. 시작 페이지의 도움말 › 튜토리얼 문서 또는 메뉴의 도움말 › 튜토리얼 문서로 열면 가운데에 문서가 나타나고, 위쪽 막대에서 장으로 이동 · 한국어/English 전환 · 튜토리얼 시작 · 브라우저로 열기를 할 수 있습니다. 홈 버튼으로 돌아갑니다.

화면 구성 #

위에서부터 메뉴 막대와 툴바(한 줄)가 있고, 그 아래 왼쪽에 도형 패널, 오른쪽에 속성 패널이 있습니다. 두 패널 사이 가운데에는 위쪽에 드로잉 탭, 그 아래에 보기(드로잉일 때는 눈금자와 페이지, 아래쪽 페이지 탭)가 있고, 맨 아래는 상태 표시줄입니다. 패널 사이의 구분자를 끌면 너비가 바뀌고, 창 오른쪽 아래 모서리를 끌면 창 크기가 바뀝니다. 창은 툴바 버튼과 메뉴가 가려지지 않는 폭보다 좁아지지 않습니다.

메뉴 막대 #

메뉴 막대 맨 앞의 홈 버튼(Ctrl+Shift+H)은 언제든 시작 페이지로 돌아갑니다. 열어 둔 드로잉은 탭에 그대로 남습니다. ▸ 표시가 있는 항목은 옆으로 하위 메뉴가 열립니다.

  • 클릭하면 선택, Shift+클릭이나 Ctrl+클릭으로 더하거나 뺍니다. 빈 곳에서 끌면 사각형 안의 도형을 고릅니다.
  • 편집 › 선택: 모두 선택(Ctrl+A) · 도형만 선택 · 연결선만 선택 · 같은 종류의 도형 선택 · 선택 해제(Esc).
  • 그룹 안의 도형은 그룹을 선택한 뒤 한 번 더 클릭해 고릅니다.
  • 숨긴 레이어나 잠근 레이어의 도형은 고를 수 없습니다.

하는 일방법

회전위쪽 동그라미 손잡이. Shift: 15°씩

값은 드로잉의 측정 단위(mm · cm · in · pt · px)로 입력합니다. 단위를 붙여 25 mm, 1in처럼 써도 됩니다. 이동하면 상태 표시줄에 이동한 거리가 표시됩니다.

텍스트 입력 #

  • 도형을 두 번 클릭하거나 F2를 누르면 그 자리에서 텍스트를 고칩니다.
  • 도형을 선택하고 바로 타이핑해도 됩니다. 입력한 글자가 원래 텍스트를 바꿉니다.
  • 편집 중 Enter는 줄 바꿈, Ctrl+Enter·Esc·바깥 클릭으로 끝냅니다.
  • 속성 패널의 텍스트 칸에서도 고칩니다.
  • 삽입 › 텍스트 상자 삽입은 화면 가운데에 텍스트 상자를 넣고 바로 입력하게 합니다.

그림·컨테이너·설명선 #

명령하는 일
삽입 › 그림 삽입…PNG · JPEG · GIF · WebP · BMP · SVG 그림을 도형으로 넣습니다(최대 420×320 크기로 맞춤). 그림은 드로잉 파일 안에 들어갑니다. 속성 패널의 그림 바꾸기…로 바꿉니다
삽입 › 컨테이너 삽입선택한 도형들을 둘러싸는 컨테이너를 그 뒤에 넣습니다(선택이 없으면 빈 컨테이너). 컨테이너를 옮기면 안의 도형도 함께 움직입니다
삽입 › 설명선 삽입선택한 도형 오른쪽 위에 꼬리가 그 도형을 가리키는 둥근 설명선을 넣습니다

컨테이너와 스윔레인은 머리글 띠나 테두리를 클릭해야 선택됩니다. 안쪽을 클릭하면 안에 있는 도형을 고르게 됩니다.

내 도형 #

자주 쓰는 도형(여러 개도 가능)을 저장해 두고 모든 드로잉에서 씁니다.

  • 도형을 선택하고 삽입 › 선택을 내 도형으로 저장…을 누르면 이름을 묻고 내 도형 스텐실에 추가합니다.
  • 삽입 › 내 도형 관리…에서 이름을 바꾸고, 삽입하거나 삭제합니다.
  • 내 도형은 프로그램의 저장소에 보관되어 다른 창·다른 드로잉에서도 보입니다.

실행 취소와 복사·붙여넣기 #

  • 모든 편집은 Ctrl+Z로 되돌리고 Ctrl+Y(또는 Ctrl+Shift+Z)로 다시 실행합니다. 탭(드로잉)마다 기록이 따로 있고 200번까지 되돌릴 수 있습니다.
  • Ctrl+C · Ctrl+X · Ctrl+V로 도형(연결선·서식·데이터 포함)을 복사·이동합니다. 같은 것을 다시 붙여넣을 때마다 조금씩 옆으로 놓입니다.
  • 복제(Ctrl+D)는 선택한 도형을 바로 옆에 복사합니다.
  • 다른 프로그램에서 복사한 글자를 붙여넣으면 텍스트 상자가 됩니다. 복사한 도형은 다른 프로그램에 그 텍스트로 붙여넣어집니다.
  • 삭제(Delete 또는 Backspace)는 선택한 도형을 지웁니다. 지운 도형에 붙어 있던 연결선도 함께 지워집니다. 삭제 금지로 보호한 도형은 지워지지 않습니다.

연결선 #

연결선 그리기 #

  • 연결선 도구(Ctrl+3)로 도형에서 도형으로 끌면 양쪽이 붙은 연결선이 생깁니다.
  • 도형이 움직이면 연결선이 따라오고, 직각 연결선은 다른 도형을 피해 길을 찾습니다(연결선이 도형 피해 가기).
  • 빈 곳에서 끌면 끝이 붙지 않은 연결선이 됩니다. Shift로 가로·세로로만 그립니다.
  • 연결선을 두 번 클릭하거나 선택하고 F2를 누르면 레이블(텍스트)을 씁니다. 레이블은 선의 가운데에 놓입니다.

자동 연결 #

포인터 도구로 도형 위에 마우스를 올리면 네 방향에 파란 화살표가 나옵니다.

  • 클릭: 그 방향에 같은 도형(서식·레이어 포함)을 만들어 연결합니다. 그 자리에 이미 도형이 있으면 그 도형에 연결합니다.
  • 끌기: 원하는 곳이나 다른 도형까지 연결선을 그립니다.

보기 › 맞추기·붙이기 › 자동 연결 화살표(또는 설정 › 드로잉)로 끄고 켭니다. 컨테이너·텍스트·선 도형에는 나오지 않습니다.

연결점과 붙이기 #

  • 도형의 연결점(파란 ×)에 연결선 끝을 놓으면 그 점에 붙습니다. 연결선은 그 점이 있는 쪽으로 곧게 나갑니다.
  • 도형 위(점이 아닌 곳)에 놓으면 도형 전체에 붙어(동적 붙이기) 도형이 움직일 때마다 서로 마주 보는 가장 가까운 점으로 바뀝니다.
  • 초록 끝점은 붙어 있다는 뜻입니다. 끝점을 끌어 다른 도형으로 옮기고, Alt를 누른 채 놓으면 붙이지 않습니다.
  • 보기 › 표시 › 연결점 표시로 연결점을 보이거나 숨기고, 도형에 붙이기 (연결점)(보기 › 맞추기·붙이기, 디자인 메뉴)로 붙이기를 끕니다.
  • 속성 패널의 시작 · 끝에 무엇에 붙어 있는지("연결점 2", "도형 전체 (동적)", "붙지 않음")가 보입니다.

모양하는 일

테마와 변형 #

디자인 › 테마·변형…(또는 속성 패널 드로잉의 테마)에서 드로잉 전체의 색·선·글꼴 모양을 고릅니다.

  • 16가지 테마: 오피스 · 선형 · 패싯 · 통합 · 이온 · 회고 · 조각 · 위스프 · 유기적 · 버블 · 시퀀스 · 광채 · 단색 · 청사진 · 자정 · 칠판. 청사진·자정·칠판은 어두운 페이지를 씁니다.
  • 테마마다 4가지 변형(색 배열)이 있습니다. 디자인 › 다음 변형은 다음 변형으로 넘깁니다.
  • 테마를 바꾸면 직접 서식을 바꾸지 않은 모든 도형의 색·선·글꼴이 함께 바뀝니다.
  • 서식 › 서식 지우기 (테마로)는 선택한 도형의 직접 서식을 지워 테마를 따르게 합니다.

(이 테마는 드로잉의 디자인입니다. 프로그램 화면의 색은 꾸미기의 테마로 따로 정합니다.)

여러 페이지 #

드로잉 아래쪽의 페이지 탭으로 페이지를 다룹니다.

  • 탭을 눌러 페이지를 바꾸고, +(페이지 추가, Shift+F11)로 추가합니다. 새 페이지는 현재 페이지의 크기·배경을 따릅니다.
  • 탭을 두 번 클릭하면 이름을 바꾸고, 끌어서 순서를 바꿉니다.
  • 양 끝의 화살표나 Ctrl+PageUp · Ctrl+PageDown으로 이전·다음 페이지로 갑니다. 페이지로 이동(Ctrl+G, 상태 표시줄의 페이지 번호)은 페이지 목록을 보여 줍니다.
  • 페이지 › 페이지 복제는 도형·레이어까지 복사하고, 페이지 삭제는 도형이 있으면 묻습니다. 마지막 남은 페이지는 지울 수 없습니다.
  • 배경 페이지는 탭 줄의 구분선 뒤에 따로 보입니다.

페이지 개요 #

페이지 › 페이지 개요(보기 전환 › 페이지 개요)는 모든 페이지를 축소판으로 보여 줍니다(일반 페이지 다음에 배경 페이지). 축소판마다 크기와 도형 수가 보이고, 클릭하면 그 페이지가 현재 페이지가 되며, 두 번 클릭하면 드로잉으로 갑니다. 끌어서 순서를 바꾸고, 버튼으로 페이지 복제 · 페이지 이름 바꾸기… · 페이지 삭제, 아래의 페이지 추가 · 배경 페이지 추가를 합니다.

배경 페이지 #

배경 페이지는 다른 페이지 뒤에 깔리는 페이지입니다. 배경 페이지에 그린 테두리·로고·제목 칸은 그 배경을 쓰는 모든 페이지에 나타나고, 거기서는 고를 수 없습니다.

  • 페이지 › 배경 페이지 추가로 만들거나, 속성 패널(또는 페이지 설정)의 배경 페이지를 켜서 지금 페이지를 배경 페이지로 바꿉니다.
  • 페이지마다 페이지 › 배경 페이지 지정(속성 패널의 배경)으로 쓸 배경을 고릅니다. 배경 페이지도 다른 배경 페이지를 쓸 수 있습니다.
  • 삽입 › 테두리와 제목 (배경 페이지)은 "배경-1" 배경 페이지에 테두리와 제목 칸({title}, {pageName} · {page}/{pages} · {date})을 만들고, 배경이 없는 모든 페이지에 지정합니다.
  • 배경 페이지는 인쇄·PDF·프레젠테이션에서 따로 한 장으로 나오지 않습니다.

데이터를 도형에 연결 #

데이터 › 데이터를 도형에 연결…(도형 데이터 보기의 데이터 연결)은 CSV의 행을 현재 페이지의 도형에 붙입니다.

  • 첫 줄은 머리글입니다. 각 행은 ID 열이 같은 도형, 없으면 이름이 같은 도형, 없으면 텍스트가 같은 도형에 연결됩니다.
  • 나머지 열은 도형 데이터가 됩니다(숫자면 숫자 종류). 같은 이름의 필드가 있으면 값을 바꿉니다.
  • 맞는 도형이 없으면 새로 만들기를 켜면 짝이 없는 행마다 도형을 만듭니다.
  • 결과는 "n행 중 m행을 도형에 연결했습니다 (새 도형 k개)."로 알려 줍니다.
  • CSV 파일을 창으로 끌어다 놓아도 이 창이 열립니다.

도형 데이터를 CSV로 내보내기…로 만든 파일(페이지 · ID · 이름 · 마스터 · 텍스트 · 필드 열)을 엑셀에서 고친 뒤 다시 연결하면 데이터가 한꺼번에 바뀝니다.

저장 #

저장하고 열기 #

  • 연결을 설정하면 저장(Ctrl+S)은 파일과 데이터베이스에 함께 저장합니다(저장 버튼 툴팁에 "파일과 데이터베이스에 함께 저장"이 보이고, 결과는 "저장됨 — 파일과 데이터베이스"로 알려 줌).
  • 파일 › 데이터베이스에 저장은 지금 탭의 드로잉을 .mdg 파일과 똑같은 내용으로 데이터베이스에만 저장합니다. 같은 드로잉을 다시 저장하면 덮어씁니다. 파일 없이 데이터베이스에서 연 드로잉은 이것으로 저장되어 "저장하지 않은 변경"이 사라집니다.
  • 파일 › 데이터베이스에서 열기…는 저장된 드로잉 목록(제목 · 마지막 저장 시각 · 크기)을 보여 줍니다. 열기로 새 탭에 열고, 휴지통 버튼(데이터베이스에서 삭제)으로 지웁니다(확인을 묻고, 되돌릴 수 없음). 새로 고침으로 목록을 다시 읽습니다.
  • 연결이 설정되지 않았으면 두 명령 모두 "먼저 설정 › 데이터베이스에서 연결을 설정하세요"를 알리고 설정의 데이터베이스 탭을 엽니다.

언어 #

툴바의 국기 버튼(언어 전환, Ctrl+Shift+L)으로 한국어와 영어를 바꿉니다. 한국어일 때는 영국 국기, 영어일 때는 태극기가 보입니다(누르면 그 언어로 바뀜). 설정 › 일반 › 언어에서도 바꿉니다. 메뉴, 팝업, 보고서, 오류 메시지, 백엔드 메시지까지 모두 바뀝니다. 도형 이름(스텐실)도 그 언어로 보입니다.

"이미 실행 중" 오류 #

MyDiagram은 사용자마다 하나만 실행됩니다. 이미 실행 중일 때 다시 실행하면 MyDiagram — 실행 오류 창에 "MyDiagram 이 이미 실행 중입니다."가 뜨고 새 실행은 끝납니다. 작업 표시줄(Dock)에서 열려 있는 창을 찾아 쓰세요. 이미 열린 창에서 파일 › 열기…로 다른 드로잉을 탭으로 열 수 있습니다. 프로그램이 비정상 종료되었더라도 잠금은 운영체제가 풀어 주므로 다음 실행이 막히지 않습니다.

설치와 제거 #

Windows #

MyDiagram-Setup-1.0.0.exe를 실행합니다.

  1. 설치 언어(한국어/English)를 고릅니다.
  2. 이전에 설치한 MyDiagram의 설정은 기본값으로 되돌리고, 사용자 데이터는 그대로 둡니다. 설치 후 처음 실행할 때 테마·글꼴·확대/축소·패널·보기 옵션·창과 팝업 위치·열 너비·인쇄 선택이 처음 상태가 되고, 최근 파일·폴더, 열려 있던 드로잉 목록, 데이터베이스 연결, 배경 이미지, 튜토리얼 기록은 남습니다. 드로잉 파일(.mdg)은 손대지 않습니다.
  3. 이전 설치가 있으면 완전히 제거한 뒤 새로 설치합니다.
  4. 설치가 끝나면 .mdg(드로잉)와 .mdgt(템플릿)가 각자의 문서 아이콘으로 등록되어 두 번 클릭으로 열립니다.
  5. 시작 메뉴의 MyDiagram 폴더에 프로그램과 MyDiagram User's Guide(이 설명서) 바로 가기가 생깁니다. 설명서와 튜토리얼 문서, 예제 드로잉은 설치 폴더의 docs, samples 폴더에 들어 있습니다.

현재 사용자용으로 설치되므로 관리자 권한이 필요 없습니다. 제거는 설정 › 앱(또는 제어판 › 프로그램 제거)에서 MyDiagram을 고릅니다.

macOS #

MyDiagram-1.0.0-<arch>.dmg를 열고 MyDiagram을 응용 프로그램 폴더로 끌어 놓습니다. 제거는 응용 프로그램 폴더에서 휴지통으로 옮깁니다. macOS 11 이상이 필요합니다.

Linux #

.deb(Debian·Ubuntu), .rpm(Fedora 등), .AppImage 중 하나를 씁니다. deb·rpm은 .mdg · .mdgt 파일 형식과 아이콘을 등록합니다. 제거는 패키지 관리자로 합니다.

웹 버전 #

웹 빌드(dist/)를 아무 정적 웹 서버에 올리면 브라우저에서 같은 기능을 씁니다. 차이점:

  • 파일은 브라우저의 파일 선택 창으로 열고, 저장은 파일 시스템 접근을 지원하는 브라우저(Edge·Chrome)에서는 같은 파일에, 그 밖에는 내려받기로 합니다.
  • 팝업 창은 페이지 안에 떠 있는 창으로 열립니다.
  • 데이터베이스, 파일 형식 등록, "이미 실행 중" 검사처럼 운영체제 기능이 필요한 것은 데스크톱 앱에서만 됩니다. 시스템 글꼴 목록은 브라우저가 허락할 때만 읽습니다.
  • 설정, 최근 기록, 내 도형은 브라우저 저장소에 남습니다.
