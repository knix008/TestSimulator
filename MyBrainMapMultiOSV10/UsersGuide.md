# MyBrainMap — 사용자 가이드

프로그램 안의 **도움말 › 도움말**(F1)에 스크린샷이 들어간 자세한 설명(16장)이 있습니다. 이 문서는 그 요약입니다.

## 0. 설치

- **Windows**: `MyBrainMap_1.0.0_x64-setup.exe` 를 실행합니다. 처음 화면에서 설치 언어를 고릅니다.
- **macOS**: `.dmg` 를 열고 앱을 응용 프로그램 폴더로 끌어 놓습니다.
- **Linux**: `.deb` (`sudo apt install ./MyBrainMap_….deb`) 또는 `.AppImage` 를 씁니다.
- **웹**: `npm run web` — 자세한 내용은 [README](README.md#실행).

## 튜토리얼 — 처음 실행할 때

설치 후 **처음 실행하면 튜토리얼이 저절로 시작**됩니다. 연습용 튜토리얼 맵이 열리고, 그 위에 **32단계 안내**가 나타납니다.

- 단계마다 화면의 한 부분(메뉴, 도구 모음 묶음, 맵, 패널, 보기 …)만 밝게 비추고 카드에 기능을 설명합니다.
- 단계가 열리면 **그 기능이 튜토리얼 맵에서 한 동작씩 저절로 실행**됩니다. 비추는 곳이 동작을 따라 옮겨 가고, 카드에 "지금 하는 일"(① ② ③ …)이 나옵니다 — 토픽 추가 · 끌어 옮기기 · 실행 취소 · 격자 · 확대 · 다시 그리기 · 레이아웃 9가지 · 가지별 배치 · 맵 스타일 · 서식 · 아이콘 · 메모 · 관계선 · 경계 · 요약 · 설명선 · 접기 · 왼쪽 패널 · 보기 바꾸기 ….
- **다시 보기** 단추로 한 번 더 봅니다. 데모가 바꾼 맵은 다음 단계로 넘어갈 때 원래대로 돌아갑니다.
- **다음** / `→` / `Enter`, **이전** / `←`, 끝내기 `Esc`.
- 한 번 보고 나면 다시 저절로 열리지 않습니다. **시작 화면 › 시작하기 › 튜토리얼**이나 **도움말 › 튜토리얼**로 언제든 다시 엽니다(**도움말 › 튜토리얼 맵만 열기**는 안내 없이 맵만).
- 같은 내용을 녹화한 영상은 프로그램 폴더의 `MyBrainMap-Tutorial.mp4` 입니다.

## 1. 화면 구성

| 영역 | 설명 |
| --- | --- |
| 메뉴 막대 | 파일 · 편집 · 삽입 · 서식 · 보기 · 도구 · 도움말, 시작 화면 단추, 창 단추 |
| 도구 모음 | 파일, 실행 취소, 토픽 추가, 토픽 내용, 레이아웃 · 스타일, 펼치기 · 접기, 확대, 보기 전환 / 오른쪽 끝에 테마 · 언어 · 설정 · 정보 |
| 탭 | 맵마다 하나. 끌어서 순서, 가운데 단추로 닫기 |
| 사이드바 (왼쪽) | 개요 · 찾기 · 필터 |
| 맵 캔버스 | 빈 곳 끌기 = 이동, 휠 = 스크롤, Ctrl+휠 = 확대, 오른쪽 아래 전체 보기 |
| 작업 창 (오른쪽) | 서식 · 아이콘 · 메모 · 작업 · 링크 · 맵 |
| 상태 표시줄 | 메시지, 선택한 토픽의 수준, 토픽 수, 필터, 레이아웃, 맵 스타일, 확대 비율 |

사이드바와 작업 창은 가장자리를 끌어 너비를 바꿉니다.

## 2. 토픽 만들기

| 키 | 하는 일 |
| --- | --- |
| `Enter` / `Shift+Enter` | 형제 토픽 아래 / 위 (중심 토픽에서는 주 토픽) |
| `Tab` / `Insert` | 하위 토픽 |
| `Ctrl+Shift+Insert` | 상위 토픽 |
| `Ctrl+Shift+Enter` | 설명선 |
| 빈 곳 두 번 누르기 | 플로팅 토픽 |
| `Ctrl+Shift+Q` | 빠른 입력 (여러 줄 → 여러 토픽) |

토픽을 선택하고 바로 입력하면 내용이 바뀝니다(한글도). `F2` 나 두 번 누르기는 지금 내용을 고칩니다. 편집 중 `Enter` 확정, `Shift+Enter` 줄 바꿈, `Esc` 취소, `Tab` 확정 후 하위 토픽.

## 3. 옮기기 · 선택 · 접기

- 토픽을 끌어 다른 토픽 위(하위), 위아래 가장자리(형제)에 놓습니다. 빈 곳에 놓으면 **연결된 채로** 그 자리로 옮겨지고, `Alt` 를 누른 채 놓으면 떼어서 플로팅 토픽이 됩니다.
- 도구 모음의 다시 그리기 단추(위→아래 · 왼→오 · 오→왼 · 양쪽)와 **자동 정리**(`Ctrl+Shift+L`)로 맵을 다시 정돈합니다.
- `Ctrl`/`Shift`+누르기로 여러 개, `Shift`/`Ctrl`+빈 곳 끌기로 사각형 선택.
- 화살표 키로 이동, `Alt+↑/↓` 순서 바꾸기, `Home` 중심 토픽, `Space` 접기/펼치기.
- `Delete` 삭제, `Ctrl+Delete` 토픽만 삭제(하위 토픽 유지), `Ctrl+X/C/V`, `Ctrl+Z/Y`.

## 4. 레이아웃과 스타일

도구 › 레이아웃 또는 작업 창 › 맵: 맵(양쪽), 오른쪽, 왼쪽, 조직도(아래 · 위), 트리(오른쪽 · 왼쪽), 타임라인, 피시본. 서식 › 하위 토픽 배치로 가지마다 다르게. 맵 스타일 16종, 선 모양, 가지 색, 배경, 간격, 번호 매기기. `F4` 는 선택한 가지만 봅니다.

## 5. 토픽 서식

작업 창 › 서식: 모양 9종, 채우기 · 글자 · 테두리 · 선 색과 두께, 글꼴 · 크기 · 굵게(`Ctrl+B`) · 기울임(`Ctrl+I`) · 밑줄(`Ctrl+U`) · 취소선 · 맞춤, 최대 너비, 서식 복사 · 붙이기 · 지우기.

## 6. 아이콘 · 태그 · 작업

- 작업 창 › 아이콘: 우선순위 1–9(`Ctrl+Shift+1…9`, `0` 없애기), 진행률, 깃발 · 표정 · 화살표(묶음마다 하나), 기호(여러 개), 태그.
- 작업 창 › 작업: 시작일, 마감일, 기간, 마일스톤, 진행률, 작업량, 담당. 날짜는 토픽 아래에 표시되고 간트 차트에 막대로 나옵니다.

## 7. 메모 · 링크 · 첨부 · 그림

- 메모(`Ctrl+T`): Markdown, 미리보기. 토픽의 메모 표시를 누르면 열립니다.
- 하이퍼링크(`Ctrl+K`): 웹 주소, 파일, 맵 안의 다른 토픽.
- 첨부 파일: 여러 개, 열기 · 폴더에서 보기. 파일을 토픽 위로 끌어 놓아도 됩니다(데스크톱).
- 그림: 파일, 클립보드(`Ctrl+V`), 끌어 놓기. 맵 파일 안에 저장됩니다.

## 8. 관계선 · 경계 · 설명선

- 관계선(`Ctrl+Shift+R`): 두 토픽을 선택했으면 바로, 아니면 이을 토픽을 누릅니다. 선택하면 손잡이로 곡선을 바꾸고, 오른쪽 단추로 이름 · 점선 · 화살표 · 색.
- 경계(`Ctrl+Shift+B`): 토픽과 가지를 감쌉니다. 구름 모양, 이름.
- 요약(`Ctrl+]`): 하위 토픽 옆에 괄호와 요약 글.
- 댓글 · 사용자 속성: 작업 창 › 메모 아래.

## 9. 개요 · 간트 · 프레젠테이션

- 개요 보기: `Enter` 새 토픽, `Tab`/`Shift+Tab` 들여쓰기, `Alt+↑/↓`, 작업 열 바로 편집.
- 간트 차트: 막대 끌기(이동), 양 끝 끌기(날짜), 일 · 주 · 월, 오늘 선.
- 칸반 보드: 주 토픽은 열, 하위 토픽은 카드. 카드를 끌어 다른 열로 옮기면 맵에서도 옮겨집니다.
- 프레젠테이션(`F5`): 주 토픽마다 한 장, `→` 다음, `←` 이전, `Esc` 끝.
- 격자 · 눈금자 · 전체 보기 창은 도구 모음 단추(`Ctrl+Alt+G / R / O`)로, 왼쪽 · 오른쪽 패널은 경계의 화살표(`Ctrl+Alt+S / P`)로 접고 폅니다.

자세한 설명과 그림은 [doc/](doc/README.md) 에, 따라 하는 영상은 `MyBrainMap-Tutorial.mp4` 에 있습니다.

## 10. 찾기 · 필터

- `Ctrl+F`: 토픽과 메모에서 찾기, 대/소문자 · 단어 · 정규식, 모두 선택, 모두 바꾸기. `F3` 다음 찾기.
- 사이드바 › 필터: 맵 인덱스(우선순위 · 상태 · 아이콘 · 태그와 개수). 누르면 필터, 나머지 흐리게 / 숨기기.

## 11. 파일

- `.tmap` 저장(`Ctrl+S`, `Ctrl+Shift+S`), 열기(`Ctrl+O`), 최근 파일, 세션 복원, 자동 저장.
- 가져오기: FreeMind `.mm`, XMind `.xmind`, MindManager `.mmap`, OPML, Markdown, 텍스트.
- 내보내기(`Ctrl+E`): PNG · JPEG · WebP · BMP · TIFF · SVG · PDF · Word · HTML · Markdown · OPML · 텍스트 · FreeMind · XMind · CSV. `Ctrl+Shift+C` 맵을 그림으로 복사.
  - 그림 크기는 맵의 모든 도형을 포함하는 영역에 여백(기본 20px, 0~80px)을 더한 크기입니다.
  - **배경 투명**은 투명 배경을 저장할 수 있는 형식(PNG · WebP · TIFF · SVG)에서만 고를 수 있습니다.
- 다른 프로그램의 맵 파일(FreeMind · XMind · MindManager · OPML · Markdown · 텍스트)과 .tmap 은 창에 끌어 놓으면 열립니다.
- 인쇄(`Ctrl+P`): 미리보기, 용지 · 방향 · 여백, 한 쪽 맞추기 / 여러 쪽 나누기, 머리글 · 바닥글, 컬러.

## 12. 템플릿

파일 › 템플릿에서 새 맵: 빈 맵, 브레인스토밍, 프로젝트 계획, 회의록, SWOT, 의사결정, 주간 계획, 피시본, 조직도, 로드맵, 독서 노트, OKR, 학습 계획, 여행 계획.

## 13. 설정

`Ctrl+,`: 일반(언어, 표시, 편집, 세션 · 자동 저장), 맵(새 맵의 레이아웃 · 스타일 · 글꼴, 화면 이동 · 휠 확대 · 격자 · 전체 보기), 테마(40종 + 사용자 테마), 시작 화면(배경 장면 · 속도), 내보내기 · 인쇄 기본값.

## 14. 웹 버전

`npm run web` 으로 띄우면 서버가 도는 컴퓨터의 파일을 열고 저장합니다. 파일 대화상자는 앱 안의 것, 설정 · 정보는 화면 안 대화상자, 도움말은 브라우저 팝업, 인쇄는 브라우저 인쇄 창입니다. 다른 컴퓨터에서 쓰려면 `--host 0.0.0.0 --token 비밀` 로 띄우고 `?token=비밀` 로 엽니다.
