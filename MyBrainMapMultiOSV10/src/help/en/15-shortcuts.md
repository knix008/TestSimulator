# Keyboard shortcuts

Also under Help › Keyboard shortcuts. On macOS use `⌘` instead of `Ctrl`.

## Files

| Key | Does |
| --- | --- |
| `Ctrl+N` | New map |
| `Ctrl+O` | Open |
| `Ctrl+S` / `Ctrl+Shift+S` | Save / save as |
| `Ctrl+E` | Export |
| `Ctrl+Shift+C` | Copy map as picture |
| `Ctrl+P` | Print |
| `Ctrl+W` | Close tab |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Next / previous tab |

## Topics

| Key | Does |
| --- | --- |
| `Enter` / `Shift+Enter` | Sibling (below / above) |
| `Tab` / `Insert` | Subtopic |
| `Ctrl+Shift+Insert` | Parent topic |
| `Ctrl+Shift+Enter` | Callout |
| `Ctrl+Shift+Q` | Quick entry |
| `F2`, double-click, or just type | Edit |
| `Delete` / `Ctrl+Delete` | Delete / delete topic only |
| `Ctrl+X` `Ctrl+C` `Ctrl+V` | Cut · copy · paste |
| `Ctrl+Z` / `Ctrl+Y` | Undo / redo |
| `Ctrl+A` | Select all |

## Moving and viewing

| Key | Does |
| --- | --- |
| `← ↑ → ↓` | Move between topics (`Shift`: add to the selection) |
| `Alt+↑` / `Alt+↓` | Reorder |
| `Home` | Central topic |
| `Space` | Fold / unfold |
| `F4` | Show this branch only |
| `F5` | Presentation |
| `F11` | Full screen |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+wheel` | Zoom in / out |
| `Ctrl+0` / `Ctrl+1` | Fit map / actual size |
| `Ctrl+Alt+↓` / `→` / `←` / `M` | Redraw top→bottom / left→right / right→left / both sides |
| `Ctrl+Shift+L` | Auto arrange |
| `Ctrl+Alt+G` / `R` / `O` | Grid / rulers / overview window |
| `Ctrl+Alt+S` / `P` | Fold / unfold the left / right pane |
| `Ctrl+]` | Add / remove a summary |

## Content and format

| Key | Does |
| --- | --- |
| `Ctrl+B` `Ctrl+I` `Ctrl+U` | Bold · italic · underline |
| `Ctrl+Shift+1` … `9` / `0` | Priority / remove |
| `Ctrl+T` | Notes |
| `Ctrl+K` | Hyperlink |
| `Ctrl+Shift+R` | Relationship |
| `Ctrl+Shift+B` | Boundary |
| `Ctrl+F` / `F3` | Find / find next |
| `Ctrl+,` | Settings |
| `F1` | Help |

## Mouse

| Action | Does |
| --- | --- |
| Drag empty space, middle-button drag | Move around |
| `Shift` / `Ctrl` + drag empty space | Rectangle selection |
| Drag a topic | Move it (onto a topic: subtopic · edge: sibling · empty space: floating) |
| Double-click empty space | Floating topic |
| Right-click | Topic, relationship and canvas menus |
