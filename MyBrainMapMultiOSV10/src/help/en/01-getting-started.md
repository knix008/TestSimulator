# Getting started

My BrainMap is a mind-mapping program: you start from a central topic and branch out. It works the same as a desktop app on Windows, macOS and Linux and in a web browser.

![Start page](images/start-page.png)

*The start page: the tutorial at the top, new map, templates, open, import, the 16 sample maps and recent files.*

## Your first map

1. Press **New map** on the start page, or `Ctrl+N`. A **central topic** appears with its text selected.
2. Type the subject and press `Enter` to confirm.
3. `Tab` (or `Insert`) adds a **subtopic** that you can type into right away.
4. To add a topic on the same level press `Enter` again — on a confirmed topic `Enter` makes a **sibling**.
5. Save with `Ctrl+S`. Maps are saved as `.tmap` files.

![A new map](images/main-window.png)

*A map with a few topics. The outline is at the left, the task pane at the right.*

## Tutorial

The first time the program runs after installing, the **tutorial** starts by itself: a 21-step guide that lights up each part of the window and explains it, over a tutorial map that walks through every feature. **Tutorial** at the top of **Get started** on the start page, or **Help › Tutorial**, opens it again any time. More in [Templates and samples](13-templates.md).

## Session

Close the program and open it again: the maps you had open come back, including new maps you never saved and unsaved changes. This can be turned off in [Settings](14-settings.md).
