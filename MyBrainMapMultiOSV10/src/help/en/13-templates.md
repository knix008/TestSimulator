## Tutorial

The **first time the program runs after installing, the tutorial starts by itself**. **Tutorial** at the top of **Get started** on the start page, or **Help › Tutorial**, opens it again any time.

The tutorial shows a **step-by-step guide** over the window: in 32 steps it lights up the menus, the toolbar, the map, the panes, the views … one at a time, explains each and **plays the feature by itself, one move at a time** (the card says what is happening, ① ② ③ …; **Play again** repeats it). `→` / **Next**, `←` / **Back**, `Esc` ends it. Behind the guide is the tutorial map, a practice map that walks through every feature. It has seven lessons — basics, the screen, layouts and arranging, what a topic holds, showing structure, views, find and files — and each topic's note says what to try. The same tutorial is recorded as `MyBrainMap-Tutorial.mp4` in the program folder.

The start page also shows all **16 sample maps** under the templates; click one to open it.

| Template | Content |
| --- | --- |
| Tutorial | A guided map that walks through every feature (with the step-by-step guide) |
| Blank map | One central topic |
| Brainstorming | Problem, ideas, pros and cons, next steps |
| Project plan | Phases with tasks, dates and owners — best seen in the Gantt chart |
| Meeting minutes | Attendees, agenda, decisions, action items |
| SWOT analysis | Strengths, weaknesses, opportunities, threats |
| Decision making | Options with pros and cons, and the criteria |
| Weekly plan | To-dos per day (timeline) |
| Fishbone | The causes of a problem, by category |
| Org chart | Teams and people (top-down) |
| Roadmap | Goals per quarter (timeline) |
| Book notes · Goals (OKR) · Study plan · Trip plan | Frequently used outlines |

Templates are made in the UI language (Korean / English). Templates with dates schedule them from today. The layout and style of a blank map are set in [Settings › Map](14-settings.md).

## Sample files

`samples/ko` and `samples/en` in the project folder hold the 16 sample maps and 14 maps made from the templates as `.tmap` files; `import/` holds one of them saved as FreeMind, XMind, OPML and Markdown to try importing (`npm run samples` makes them again).
