# 단축키

도움말 › 단축키 에서도 볼 수 있습니다. macOS 에서는 `Ctrl` 대신 `⌘` 입니다.

## 파일

| 키 | 하는 일 |
| --- | --- |
| `Ctrl+N` | 새 맵 |
| `Ctrl+O` | 열기 |
| `Ctrl+S` / `Ctrl+Shift+S` | 저장 / 다른 이름으로 저장 |
| `Ctrl+E` | 내보내기 |
| `Ctrl+Shift+C` | 맵을 그림으로 복사 |
| `Ctrl+P` | 인쇄 |
| `Ctrl+W` | 탭 닫기 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 다음 / 이전 탭 |

## 토픽

| 키 | 하는 일 |
| --- | --- |
| `Enter` / `Shift+Enter` | 형제 토픽 (아래 / 위) |
| `Tab` / `Insert` | 하위 토픽 |
| `Ctrl+Shift+Insert` | 상위 토픽 |
| `Ctrl+Shift+Enter` | 설명선 |
| `Ctrl+Shift+Q` | 빠른 입력 |
| `F2`, 두 번 누르기, 또는 그냥 입력 | 편집 |
| `Delete` / `Ctrl+Delete` | 삭제 / 토픽만 삭제 |
| `Ctrl+X` `Ctrl+C` `Ctrl+V` | 잘라내기 · 복사 · 붙여넣기 |
| `Ctrl+Z` / `Ctrl+Y` | 실행 취소 / 다시 실행 |
| `Ctrl+A` | 모두 선택 |

## 이동과 보기

| 키 | 하는 일 |
| --- | --- |
| `← ↑ → ↓` | 토픽 사이 이동 (`Shift`: 선택 추가) |
| `Alt+↑` / `Alt+↓` | 순서 바꾸기 |
| `Home` | 중심 토픽 |
| `Space` | 접기 / 펼치기 |
| `F4` | 이 가지만 보기 |
| `F5` | 프레젠테이션 |
| `F11` | 전체 화면 |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+휠` | 확대 / 축소 |
| `Ctrl+0` / `Ctrl+1` | 맵 전체 / 실제 크기 |
| `Ctrl+Alt+↓` / `→` / `←` / `M` | 위→아래 / 왼→오 / 오→왼 / 양쪽으로 다시 그리기 |
| `Ctrl+Shift+L` | 자동 정리 |
| `Ctrl+Alt+G` / `R` / `O` | 격자 / 눈금자 / 전체 보기 창 |
| `Ctrl+Alt+S` / `P` | 왼쪽 / 오른쪽 패널 접기·펴기 |
| `Ctrl+]` | 요약 붙이기 / 없애기 |

## 내용과 서식

| 키 | 하는 일 |
| --- | --- |
| `Ctrl+B` `Ctrl+I` `Ctrl+U` | 굵게 · 기울임 · 밑줄 |
| `Ctrl+Shift+1` … `9` / `0` | 우선순위 / 없애기 |
| `Ctrl+T` | 메모 |
| `Ctrl+K` | 하이퍼링크 |
| `Ctrl+Shift+R` | 관계선 |
| `Ctrl+Shift+B` | 경계 |
| `Ctrl+F` / `F3` | 찾기 / 다음 찾기 |
| `Ctrl+,` | 설정 |
| `F1` | 도움말 |

## 마우스

| 동작 | 하는 일 |
| --- | --- |
| 빈 곳 끌기 · 가운데 단추 끌기 | 화면 이동 |
| `Shift` / `Ctrl` + 빈 곳 끌기 | 사각형 선택 |
| 토픽 끌기 | 옮기기 (토픽 위: 하위 · 가장자리: 형제 · 빈 곳: 플로팅) |
| 빈 곳 두 번 누르기 | 플로팅 토픽 |
| 오른쪽 단추 | 토픽 · 관계선 · 캔버스 메뉴 |
