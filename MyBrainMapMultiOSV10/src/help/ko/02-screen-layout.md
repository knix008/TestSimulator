# 화면 구성

![주 창](images/main-window.png)

*메뉴 막대, 도구 모음, 탭, 사이드바(왼쪽), 맵 캔버스(가운데), 작업 창(오른쪽), 상태 표시줄.*

## 메뉴 막대

맨 위에는 앱 아이콘과 이름, **시작** 버튼, 그리고 파일 · 편집 · 삽입 · 서식 · 보기 · 도구 · 도움말 메뉴가 있습니다. 데스크톱에서는 메뉴가 운영체제 메뉴로 열리고, 빈 곳을 끌면 창이 움직이며 두 번 누르면 최대화됩니다.

## 도구 모음

![도구 모음](images/toolbar.png)

*왼쪽부터 파일, 실행 취소, 토픽 추가, 토픽 내용, 레이아웃과 스타일, 펼치기/접기, 확대/축소, 보기 전환, 창 표시.*

| 묶음 | 버튼 |
| --- | --- |
| 파일 | 새 맵, 열기, 저장, 내보내기, 인쇄 |
| 토픽 | 하위 · 형제 · 상위 토픽, 설명선, 플로팅 토픽, 관계선, 경계 |
| 내용 | 아이콘, 메모, 링크, 작업 — 작업 창의 해당 탭을 엽니다 (서식은 작업 창의 첫 탭) |
| 맵 | 레이아웃 고르기, 맵 스타일 고르기 |
| 정리 | 위→아래 · 왼→오 · 오→왼 · 양쪽으로 다시 그리기, 자동 정리 |
| 보기 | 모두 펼치기 · 접기, 가지만 보기, 확대 · 축소 · 맵 전체, 맵 · 개요 · 간트 · 칸반, 프레젠테이션 |
| 화면 | 격자, 눈금자, 전체 보기 창 켜기/끄기, 왼쪽 · 오른쪽 패널 접기/펴기 |

창이 좁으면 도구 모음은 묶음 단위로 두 줄이 됩니다. 버튼에 마우스를 올리면 이름과 단축키가 보입니다.

오른쪽 끝에는 테마(누르면 다음 테마, ▾ 는 목록), 언어 전환(국기), 설정, 정보가 있습니다.

## 탭

맵마다 탭이 하나입니다. 저장하지 않은 맵은 탭 이름이 기울어지고 ● 가 붙습니다. 탭을 끌어 순서를 바꾸고, 가운데 버튼으로 닫고, 오른쪽 버튼으로 탭 메뉴를 엽니다.

## 사이드바

- **개요** — 맵 전체가 나무 구조로 보입니다. 항목을 누르면 그 토픽이 선택되고 화면 가운데로 옵니다.
- **찾기** — 토픽과 메모에서 글자를 찾고 바꿉니다. → [찾기와 필터](10-find-filter.md)
- **필터** — 우선순위·아이콘·태그·진행 상태·마감일로 토픽을 거릅니다.

## 작업 창

선택한 토픽의 **서식 · 아이콘 · 메모(댓글 · 사용자 속성 포함) · 작업 · 링크**, 그리고 맵 전체의 **맵** 탭이 있습니다.

## 패널 접고 펴기

사이드바와 작업 창은 가장자리를 끌어 너비를 바꿉니다. 경계 가운데의 작은 화살표를 누르거나 경계를 두 번 누르면(또는 `Ctrl+Alt+S` / `Ctrl+Alt+P`) 패널이 접히고, 접힌 패널은 맵 가장자리의 작은 탭을 눌러 다시 폅니다. 패널 머리의 화살표 단추도 같은 일을 합니다.

## 맵 캔버스

맵이 그려지는 곳입니다. 빈 곳을 끌면 화면이 움직이고, 휠은 스크롤, `Ctrl+휠`은 확대/축소입니다.

- **격자** — 배경의 가는 선(24 단위)과 굵은 선(120 단위). 많이 축소하면 칸이 커집니다. `Ctrl+Alt+G`.
- **눈금자** — 위쪽과 왼쪽 가장자리. 0 은 중심 토픽의 가운데이고, 확대 비율에 맞춰 간격이 바뀝니다. `Ctrl+Alt+R`.
- **전체 보기 창** — 오른쪽 아래에서 맵 전체와 지금 보이는 부분(틀)을 보여 줍니다. 켜 두면 늘 보이고, 누르거나 끌면 그곳으로 이동합니다. `Ctrl+Alt+O`.

세 가지 모두 도구 모음 버튼, 보기 메뉴, 빈 곳의 오른쪽 클릭 메뉴, 설정 › 맵에서 켜고 끕니다.

## 상태 표시줄

왼쪽에 최근 메시지, 오른쪽에 선택한 토픽의 수준, 토픽 수, 필터 상태, 레이아웃, 맵 스타일, 확대 비율이 있습니다. 레이아웃과 스타일은 눌러서 바로 바꿀 수 있습니다.
