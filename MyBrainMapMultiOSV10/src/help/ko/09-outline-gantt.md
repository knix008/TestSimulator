# 개요 보기 · 간트 차트 · 칸반 보드

같은 맵을 네 가지로 볼 수 있습니다: **맵**, **개요**, **간트 차트**, **칸반 보드**. 도구 모음의 네 단추나 보기 메뉴로 바꿉니다. 어느 보기에서 고쳐도 같은 맵이 바뀝니다.

## 개요 보기

![개요 보기](images/outline-view.png)

*개요 보기: 들여쓴 목록과 작업 열.*

맵을 문서의 목차처럼 위에서 아래로 봅니다. 긴 글을 정리하거나 순서를 잡을 때 편합니다.

| 키 | 하는 일 |
| --- | --- |
| `Enter` | 아래에 새 토픽 |
| `Tab` / `Shift+Tab` | 들여쓰기 (위 토픽의 하위로) / 내어쓰기 |
| `Alt+↑` / `Alt+↓` | 순서 바꾸기 |
| `↑` / `↓` | 위 / 아래 줄로 |
| `Ctrl+Space` | 접기 / 펼치기 |
| 빈 토픽에서 `Backspace` | 그 토픽 삭제 |

오른쪽 열에서 우선순위, 진행률, 시작일, 마감일, 담당을 바로 고칩니다.

## 칸반 보드

![칸반 보드](images/kanban-view.png)

*칸반 보드: 주 토픽은 열, 그 하위 토픽은 카드.*

**보기 › 칸반 보드**(도구 모음의 칸반 단추)는 주 토픽을 열로, 그 하위 토픽을 카드로 보여 줍니다. 카드에는 우선순위, 진행률, 마감일, 담당, 하위 토픽 · 메모 · 댓글 수가 보입니다.

- 카드를 다른 열로 끌면 그 주 토픽의 하위 토픽으로 옮겨지고, 카드 사이에 놓으면 그 자리에 들어갑니다. 맵에서도 똑같이 바뀌고 `Ctrl+Z` 로 되돌립니다.
- 열 아래의 **카드 추가**로 하위 토픽을, 오른쪽 끝의 **열 추가**로 주 토픽을 만듭니다.
- 카드나 열 머리를 누르면 그 토픽이 선택되어 작업 창에서 편집할 수 있습니다.

## 간트 차트

![간트 차트](images/gantt-view.png)

*간트 차트: 왼쪽은 작업 목록, 오른쪽은 달력 위의 막대.*

시작일이나 마감일이 있는 토픽이 달력 위의 막대로 보입니다. 그 위의 가지는 회색 **요약 막대**로 하위 작업 전체 기간을 보여 줍니다.

- 막대를 **끌면** 일정이 통째로 옮겨집니다. 막대의 **왼쪽·오른쪽 끝**을 끌면 시작일·마감일이 바뀝니다.
- 막대 안의 진한 부분은 진행률, 초록 막대는 완료된 작업, 마름모는 마일스톤입니다.
- 빨간 세로선은 오늘. **오늘** 단추는 오늘이 보이게 옮깁니다.
- 눈금은 **일 · 주 · 월**로 바꿉니다. **날짜 없는 토픽도 보기**를 켜면 모든 토픽이 줄로 나옵니다.
- 막대를 두 번 누르면 작업 창의 작업 탭이 열립니다.
