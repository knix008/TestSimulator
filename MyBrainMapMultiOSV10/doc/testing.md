# 테스트와 검증

모든 테스트는 결과를 **영어로** 출력합니다(테스트 데이터인 한글 맵 내용과 한글 입력 시험은 그대로). GUI 테스트는 `npm test` 와 같은 모양으로 구역(Section)마다 ✓ / ✗ / – 를 색으로 보여 주고, 끝에 구역별 통과 · 실패 · 건너뜀 표, 실패 목록, 페이지 오류, 통과/실패 막대를 출력합니다. `NO_COLOR=1` 이면 색 없이 출력합니다.

| 명령 | 검증하는 것 |
| --- | --- |
| `npm test` | 단위 테스트 80개 — 튜토리얼 안내(두 언어, 모든 동작이 앱 명령인지) 포함, 모델(편집 · 구조 · 찾기 · 필터 · 번호), 레이아웃(겹침 없음 · 모든 레이아웃 · 템플릿 · 예제), 가져오기 · 내보내기 왕복, 도움말 그림 · 링크, 다국어 키, JSX import, 그리고 **기능 비교 테스트 36개**(`test/parity.test.mjs`, [기능 비교](feature-parity.md)의 표와 같은 이름) |
| `npm run build && npm run smoke` | GUI 스모크 테스트 54단계 — 웹 빌드를 헤드리스 Edge / Chrome 에서 실제 마우스 · 키보드 입력으로 조작: 토픽 만들기, 끌어서 옮기기(연결 유지 · Alt 로 떼기), 관계선, 경계, 템플릿, 보기, 프레젠테이션, 저장 · 열기, 모든 내보내기, 설정, 격자 · 눈금자 · 전체 보기 창 단추, 방향 바꿔 다시 그리기와 자동 정리, Ctrl+Alt 단축키, 패널 접기 · 펴기, 왼쪽 패널 오른쪽 클릭 메뉴(모든 항목 아이콘), 요약 · 댓글 · 칸반, 바뀐 맵 닫을 때 저장 여부 묻기 |
| `npm run build && npm run test:gui` | **모든 명령의 GUI 테스트 322개** — 메뉴 막대 7개 메뉴의 모든 항목, 도구 모음의 모든 단추와 레이아웃 · 맵 스타일 목록의 모든 항목, 테마 · 언어 · 설정 · 정보 단추, 상태 표시줄 고르기, 그리고 컨텍스트 메뉴(토픽 · 경계와 요약이 있는 토픽 · 빈 곳 · 관계선 · 탭 · 왼쪽 패널 항목)의 모든 항목을 실제 마우스로 누르고, 맵 · 선택 · 설정 · 대화상자 · 모드 · 화면 · 상태 메시지 가운데 무엇인가 바뀌었는지와 페이지 오류가 없는지 확인합니다. 명령마다 상태를 되돌려(실행 취소, 열린 것 닫기, 켠 것 끄기) 다음 명령도 같은 맵에서 시작합니다. 컨텍스트 메뉴는 모든 항목에 아이콘이 있는지도 봅니다. 마지막으로 **첫 실행**을 흉내 내 튜토리얼 안내가 저절로 시작되는지, 21단계를 모두 지나며 카드가 창 안에 있는지, "직접 보기"가 실제로 동작하는지, 끝난 뒤 다시는 저절로 열리지 않는지 확인합니다 |
| `npm run help:media` | 도움말 그림(한국어 · 영어 각 32장)을 실제 화면에서 다시 찍기 |
| `npm run tutorial:video` | 튜토리얼 영상 `MyBrainMap-Tutorial.mp4` 와 이 문서의 그림(`doc/images`) 만들기 |

## 실행 취소 · 저장 여부 묻기 검증

- 단위 테스트 "undo / redo of every edit, and the unsaved mark": 서식 변경과 손으로 옮기기를 한 뒤 두 번 실행 취소하면 처음 맵과 **같은 객체**로 돌아가고(저장 안 됨 표시가 사라짐), 두 번 다시 실행하면 옮긴 자리까지 돌아옵니다.
- 스모크 테스트 "closing a changed map asks to save; cancel keeps it": 바뀐 맵을 닫으면 저장 · 저장 안 함 · 취소 세 단추의 대화상자가 나오고, 취소하면 탭이 그대로 남습니다.

## 팝업 창 크기 검증

데스크톱의 별도 창(설정 820×672, 단축키 1000×740, 정보 560×360)은 정해진 크기에서 **스크롤 막대가 없고 잘리는 내용이 없도록** 한국어 · 영어 두 언어로 모든 탭을 실제 크기로 띄워 측정했습니다. 앱 안의 대화상자(템플릿, 예제, 내보내기, 인쇄 미리 보기, 빠른 입력, 설정, 단축키, 확인)도 기본 창 크기(1320×840)에서 같은 방법으로 확인했습니다. 모든 창은 제목 표시줄의 × 와 `Esc` 로 닫힙니다. 도움말 창의 본문만은 긴 글을 읽는 곳이라 스크롤됩니다.
