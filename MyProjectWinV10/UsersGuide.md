## 1. 시작하기

### 프로그램 실행

- 설치한 경우: 시작 메뉴 또는 바탕 화면의 **MyProject** 실행
- 개발 빌드: `dotnet run --project MyProject.csproj -c Debug`

### 새 프로젝트

1. **File → New** 또는 툴바 **New** (Ctrl+N)
2. 빈 프로젝트가 열리고 샘플 태스크 구조가 표시될 수 있습니다.

### 프로젝트 열기

1. **File → Open** (Ctrl+O)
2. `.myprj` 파일을 선택합니다.

### 저장

- **File → Save** (Ctrl+S): 현재 경로에 저장
- **File → Save As**: 새 경로에 저장

저장하지 않은 변경이 있으면 제목 표시줄에 별표(*)가 표시됩니다.

## 2. 화면 구성

```
┌─────────────────────────────────────────────────────────────────┐
│  메뉴 (File | Task | View | Report)                             │
├─────────────────────────────────────────────────────────────────┤
│  툴바 (새로 만들기, 저장, 태스크, 링크, 줌, 보내기 …)         │
├──────────┬──────────────────────────────┬─────────────────────┤
│ 태스크   │         Gantt 차트           │    속성 패널        │
│ 그리드   │  (타임라인, 바, 의존선, 노트) │  (선택 항목 편집)   │
│          │                              │                     │
├──────────┴──────────────────────────────┴─────────────────────┤
│  상태 표시줄 (선택 태스크, 오늘 날짜 등)                        │
└─────────────────────────────────────────────────────────────────┘
```

### 분할선 조절

- **그리드 ↔ Gantt**: 세로 분할선을 드래그하여 그리드 너비를 조절합니다. 너비는 프로젝트에 저장됩니다.
- **Gantt ↔ 속성 패널**: 속성 패널 너비를 드래그로 조절할 수 있습니다.

### 속성 패널 표시/숨김

- 툴바 **Properties Panel** 버튼 (오늘 버튼 옆)
- **View → Properties Panel**

버튼이 눌린 상태(체크)일 때 패널이 표시됩니다. 숨김 상태도 프로젝트에 저장됩니다.

## 3. 프로젝트 관리

### 프로젝트 파일 (.myprj)

- JSON 형식, UTF-8 인코딩
- 포함 내용: 태스크, 의존 관계, 리소스 배정, 노트, 화면 뷰 설정

### 프로젝트 시작일

프로젝트의 기준 시작일은 Gantt 타임라인과 자동 일정 계산에 사용됩니다. 태스크 속성 또는 프로젝트 설정에서 조정할 수 있습니다.

### 템플릿

설치 폴더의 `Template/Template Project.myprj`에 기본 샘플이 포함되어 있습니다. 이 파일을 복사하여 새 프로젝트의 시작점으로 사용할 수 있습니다.

## 4. 태스크 작업

### 태스크 추가

| 방법 | 설명 |
|------|------|
| Insert | 루트 수준 태스크 추가 |
| Ctrl+Shift+Insert | 선택 태스크의 **하위 태스크** 추가 |
| 툴바 Add Task / Add Subtask | 위와 동일 |
| 우클릭 메뉴 | 그리드 또는 Gantt에서 **Add Task** / **Add Subtask** |

### 태스크 선택

- 그리드 행 클릭
- Gantt 차트의 태스크 바 클릭

선택한 태스크는 그리드와 Gantt에서 함께 강조 표시됩니다.

### 태스크 삭제

- Delete 키
- 툴바 **Delete**
- 우클릭 **Delete Task**

하위 태스크가 있는 경우 함께 삭제될 수 있으니 확인하세요.

### 계층 구조 (들여쓰기 / 내어쓰기)

| 작업 | 단축키 | 툴바 |
|------|--------|------|
| 들여쓰기 (하위로) | Alt+Right | Indent |
| 내어쓰기 (상위로) | Alt+Left | Outdent |

들여쓰기는 태스크 트리의 부모-자식 관계를 만듭니다. **요약(Summary)** 태스크는 모든 하위 태스크의 시작·종료·진행률을 자동으로 롤업합니다.

### 접기 / 펼치기

- 그리드의 트리 화살표 클릭
- 툴바 **Expand/Collapse** (선택 태스크의 하위 표시 토글)
- 우클릭 메뉴

### 태스크 유형

| 유형 | 설명 |
|------|------|
| **Normal** | 일반 작업. 기간(일)이 있습니다. |
| **Milestone** | 마일스톤. 시작일 하루, 바가 짧게 표시됩니다. |
| **Summary** | 요약 태스크. 하위 태스크 일정을 자동 집계합니다. |

### 태스크 속성 대화상자

- 태스크 **더블클릭**
- F2
- 툴바 **Task Properties**
- 우클릭 **Properties**

일반 정보, 색상, 리소스, 메모 등을 편집할 수 있습니다.

### 자동 일정 (Auto Schedule)

태스크에 **Auto Schedule**이 켜져 있으면, 의존 관계에 따라 시작일이 자동으로 조정됩니다. 수동으로 시작일을 고정하려면 Auto Schedule을 끄세요.

### 크리티컬 패스

의존 관계와 일정을 분석하여 **크리티컬 패스**에 포함된 태스크가 표시됩니다. 속성 패널과 보고서에서 크리티컬 여부를 확인할 수 있습니다.

## 5. Gantt 차트

### 타임라인

- 상단에 날짜 눈금이 표시됩니다.
- **Ctrl+T** 또는 툴바 **Today**: 오늘 날짜 위치로 스크롤
- **Ctrl++** / **Ctrl+-** 또는 툴바 줌 버튼: 하루 칸 너비 조절 (줌)

### 태스크 바

- 바 길이 = 기간
- 바 내부 색상 = 진행률
- 사용자 지정 바 색·진행률 색 지원 (속성에서 설정)

### 스크롤 동기화

그리드와 Gantt의 세로 스크롤이 연동됩니다. 한쪽을 스크롤하면 다른 쪽도 함께 이동합니다.

### Gantt 이미지 보내기

**Report → Export Gantt as Image** 또는 툴바 이미지 버튼

| 형식 | 투명 배경 |
|------|-----------|
| PNG | 지원 |
| WebP | 지원 |
| JPEG | 흰색 배경으로 평탄화 |
| GIF | 투명 또는 흰색 배경 |

전체 타임라인이 포함된 이미지가 생성됩니다.

## 6. 의존 관계 (태스크 연결)

### 연결 종류

| 코드 | 이름 | 의미 |
|------|------|------|
| **FS** | Finish-to-Start | 선행 태스크가 끝난 후 후행 시작 |
| **FF** | Finish-to-Finish | 선행·후행이 같은 날 끝남 |
| **SS** | Start-to-Start | 선행·후행이 같은 날 시작 |
| **SF** | Start-to-Finish | 선행 시작 후 후행 종료 |

### Link 모드로 연결하기

1. 툴바에서 의존 **종류**(FS/FF/SS/SF)와 선 형태를 선택합니다.
2. **Link** 버튼을 누르거나 Ctrl+L (토글)
3. Gantt에서 **선행 태스크** 바를 클릭
4. **후행 태스크** 바를 클릭 → 연결선이 생성됩니다.

연결 중 **Esc**로 취소할 수 있습니다. Link 버튼이 눌린 상태에서는 미리보기 선이 표시됩니다.

### Lag (지연 일수)

속성 패널의 의존 관계 목록에서 Lag 일수를 설정할 수 있습니다. 양수는 지연, 음수는 선행(Lead)을 의미합니다.

### 의존 관계 삭제

속성 패널의 의존 관계 그리드에서 행을 선택하고 삭제하거나, 우클릭 메뉴를 사용합니다.

## 7. 노트

Gantt 차트 위에 배치하는 **노란색 노트**입니다. 회의 메모, 리스크, 설명 등을 차트와 함께 기록할 때 사용합니다.

### 노트 추가

**방법 1 — 선택 태스크에 추가**

1. 태스크를 선택
2. 툴바 **Notes** 버튼 클릭 (한 번 더 누르면 해당 태스크에 노트 생성)

**방법 2 — 노트 모드**

1. 툴바 **Notes**를 눌러 노트 모드 활성화 (버튼이 눌린 상태)
2. Gantt에서 태스크 **바를 클릭** → 해당 태스크에 노트 추가
3. 다시 **Notes**를 눌러 노트 모드 종료

### 노트 편집

- Gantt에서 노트 마커 **더블클릭** → 차트 위 인라인 편집
- 노트 선택 후 **속성 패널**에서 제목·본문·연결 태스크·기준 날짜 편집
- 우클릭 **Edit Note**

### 서식 있는 텍스트

노트 본문은 RTF 서식을 지원합니다.

| 서식 | 방법 |
|------|------|
| 글꼴 | Segoe UI, Arial, Calibri 등 |
| 크기 | 8pt ~ 24pt |
| 굵게 / 기울임 / 밑줄 / 취소선 | 편집기 툴바 버튼 |

서식은 Gantt 차트에 렌더링되고, HTML·Word·PDF·Excel 보내기에도 반영됩니다.

### 노트 삭제

- 노트 선택 후 **Delete**
- 우클릭 **Delete Note**

### 노트와 태스크 연결

속성 패널에서 **Linked Task**를 변경하면 노트가 다른 태스크에 연결됩니다. **Anchor Date**로 차트 상의 기준 날짜를 지정할 수 있습니다.

## 8. 속성 패널

우측 패널에서 **현재 선택**한 태스크 또는 노트의 속성을 바로 편집합니다.

### 태스크 선택 시

| 항목 | 설명 |
|------|------|
| Name | 태스크 이름 |
| Type | Normal / Milestone / Summary |
| Start / Duration | 시작일, 기간(일), 계산된 종료일 |
| Progress | 0~100% |
| Auto Schedule | 의존 관계 기반 자동 일정 |
| Critical | 크리티컬 패스 여부 (읽기 전용 표시) |
| Deliverable | 산출물 설명 |
| Notes | 태스크 메모 (플레인 텍스트) |
| Bar / Progress Color | 태스크 바·진행률 색 |
| Resources | 리소스 배정 그리드 |
| Dependencies | 선행·후행 의존 관계 목록 |

변경은 즉시 모델에 반영되고 Gantt·그리드에 업데이트됩니다.

### 노트 선택 시

| 항목 | 설명 |
|------|------|
| Title | 노트 제목 |
| Body | 서식 있는 본문 (RTF) |
| Linked Task | 연결 태스크 |
| Anchor Date | 차트 기준 날짜 |

### 아무것도 선택하지 않은 경우

"Select a task or note to edit its properties." 메시지가 표시됩니다.

## 10. 보고 및 보내기

**Report** 메뉴 또는 툴바에서 보내기를 실행합니다. 완료 후 **Open File**로 결과 파일을 바로 열 수 있습니다.

### Excel (.xlsx)

**Report → Export to Excel** 또는 툴바 Excel 버튼

| 시트 | 내용 |
|------|------|
| Summary | 프로젝트 개요, 진행률, 크리티컬·노트 수 |
| Task Schedule | 태스크 목록 + Gantt 타임라인 열 |
| Resource Allocation | 리소스 배정 |
| Dependencies | 의존 관계 목록 |
| Notes | 노트 전체 목록 |

### HTML

**Report → Export to HTML**

브라우저에서 열 수 있는 일정·리소스·노트·크리티컬 패스 보고서입니다.

### Word (.docx)

**Report → Export to Word**

HTML과 유사한 범위의 서식 문서입니다.

### PDF

**Report → Export to PDF** 또는 툴바 PDF 버튼

인쇄·공유용 PDF 보고서입니다.

### Markdown

**Report → Export to Markdown** 또는 툴바 Md 버튼

진행률·일정 요약을 Markdown 형식으로 저장합니다.

### Gantt 이미지

**Report → Export Gantt as Image**

PNG, JPEG, GIF, WebP 형식. [Gantt 이미지 보내기](#gantt-이미지-보내기) 섹션 참고.

### 인쇄

**Report → Print** (Ctrl+P)

시스템 인쇄 대화상자를 통해 Gantt 차트를 인쇄합니다.

## 12. 설정 및 파일 위치

### 앱 전역 설정

```
%LocalAppData%\MyProject\settings.json
```

| 항목 | 설명 |
|------|------|
| LastDirectory | 마지막으로 사용한 폴더 |
| DefaultDependencyType | 기본 의존 종류 (FS 등) |
| TaskGridColumnWidths | 기본 그리드 열 너비 |

### 프로젝트 뷰 설정 (프로젝트 파일 내)

각 `.myprj` 파일에 저장되는 화면 설정:

- 그리드 열 너비
- Gantt 줌(일 칸 너비)
- 그리드/Gantt 분할선 위치
- 속성 패널 너비·표시 여부

### 설치 경로 (MSI 설치 시)

일반적으로 `C:\Program Files\MyProject\` (설치 옵션에 따라 다를 수 있습니다)

## 13. 자주 묻는 질문

### 저장하지 않고 종료하면?

종료 시 저장 여부를 묻는 대화상자가 표시됩니다. Visual Studio 디버거로 실행한 경우에는 개발 편의를 위해 저장 확인이 생략될 수 있습니다.

### 다른 PC에서 프로젝트를 열면?

`.myprj` 파일만 복사하면 태스크·노트·뷰 설정이 함께 열립니다. MyProject와 .NET 8 런타임이 설치된 Windows PC에서 사용할 수 있습니다.

### Excel에서 Gantt가 잘려 보여요

Excel 시트의 타임라인 열 수는 프로젝트 기간에 따라 제한됩니다. 매우 긴 프로젝트는 Gantt 이미지 보내기를 사용하세요.

### 속성 패널이 안 보여요

툴바 **Properties Panel** 버튼을 눌러 표시하거나, **View → Properties Panel**을 선택하세요.

### 노트 서식이 PDF에 안 나와요

본문은 HTML 변환을 통해 보고서에 포함됩니다. 매우 복잡한 RTF는 일부 서식이 단순화될 수 있습니다.

### Link 연결이 안 됩니다

- Link 버튼이 활성(눌린) 상태인지 확인
- 같은 태스크끼리는 연결할 수 없습니다
- 선행 → 후행 순서로 두 태스크를 클릭했는지 확인
