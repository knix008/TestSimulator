## 1. 시작하기

### 프로그램 실행

- 설치한 경우: 시작 메뉴 또는 바탕 화면의 **MyProject** 실행
- 개발 빌드: `dotnet run --project MyProject.csproj -c Debug`

### 새 프로젝트

1. **File → New** 또는 툴바 **New** (Ctrl+N)
2. 빈 프로젝트가 열립니다.

### 프로젝트 열기

1. **File → Open** (Ctrl+O)
2. 지원 형식 중 하나를 선택합니다 (아래 [프로젝트 관리](#3-프로젝트-관리), [Microsoft Project 연동](#4-microsoft-project-연동) 참고).

### 저장

- **File → Save** (Ctrl+S): 현재 경로에 저장
- **File → Save As**: 새 경로에 저장

실제로 태스크·일정·뷰 설정 등을 **편집한 경우**에만 제목 표시줄에 별표(`*`)가 나타나고, 종료·새 프로젝트 시 저장 여부를 묻습니다. 열기만 하고 변경하지 않았다면 저장 확인이 표시되지 않습니다.

## 2. 화면 구성

```
┌─────────────────────────────────────────────────────────────────┐
│  메뉴 (File | Task | View | Report)                             │
├─────────────────────────────────────────────────────────────────┤
│  툴바 (새로 만들기, 저장, 태스크, 링크, 크리티컬 패스, 줌 …)   │
├──────────┬──────────────────────────────┬─────────────────────┤
│ 태스크   │         Gantt 차트           │    속성 패널        │
│ 그리드   │  (타임라인, 바, 의존선, 노트) │  (선택 항목 편집)   │
│          │                              │  [» 접기]           │
├──────────┴──────────────────────────────┴─────────────────────┤
│  상태 표시줄 (선택 태스크, 오늘 날짜 등)                        │
└─────────────────────────────────────────────────────────────────┘
```

### 분할선 조절

- **그리드 ↔ Gantt**: 세로 분할선을 드래그하여 그리드 너비를 조절합니다. 너비는 프로젝트에 저장됩니다.
- **Gantt ↔ 속성 패널**: 속성 패널이 펼쳐진 상태에서 분할선을 드래그하여 너비를 조절할 수 있습니다.

### 속성 패널 표시/숨김

| 방법 | 설명 |
|------|------|
| 툴바 **Properties Panel** | Gantt 오른쪽 패널 표시/숨김 토글 |
| **View → Properties Panel** | 위와 동일 |
| 패널 헤더 **»** | 패널을 좁은 스트립(32px)으로 접기 |
| 스트립의 **«** | 다시 펼치기 |

접기·펼치기 상태와 패널 너비는 프로젝트에 저장됩니다.

## 3. 프로젝트 관리

### MyProject 파일 (.myprj)

- JSON 형식, UTF-8 인코딩
- 포함 내용: 태스크, 의존 관계, 리소스 배정, 노트, 화면 뷰 설정
- MyProject에서 **저장(Save)** 할 때 사용하는 기본 형식입니다.

### 프로젝트 시작일

프로젝트의 기준 시작일은 Gantt 타임라인, 자동 일정, 크리티컬 패스 계산에 사용됩니다.

### 템플릿

설치 폴더의 `Template/Template Project.myprj`에 샘플 프로젝트가 포함되어 있습니다. 복사하여 새 프로젝트의 시작점으로 사용할 수 있습니다.

## 4. Microsoft Project 연동

MyProject는 Microsoft Project와 일정 데이터를 주고받을 수 있습니다.

### 가져오기 (열기)

**File → Open** (Ctrl+O)에서 다음 형식을 선택할 수 있습니다.

| 형식 | 확장자 | 설명 |
|------|--------|------|
| MyProject | `.myprj` | MyProject 네이티브 형식 |
| Microsoft Project | `.mpp`, `.mpt` | MS Project 바이너리/템플릿 |
| MS Project XML | `.xml` | MSPDI XML (MS Project에서 XML로 저장한 파일) |
| MPX | `.mpx` | 레거시 MPX 형식 |

가져온 내용: 태스크 계층, 시작일·기간·진행률, 의존 관계(FS/FF/SS/SF·Lag), 리소스 할당, 메모 등.

> Gantt 차트 노트, 화면 줌·분할선 설정, 태스크 바 색상 등 MyProject 전용 항목은 MS Project 파일에 없으면 가져오지 않습니다.

### Microsoft Project로 보내기

1. **File → Export to Microsoft Project...**
2. 형식 선택:
   - **XML** — MS Project XML (MSPDI). MS Project에서 **파일 → 열기**로 직접 불러올 수 있습니다.
   - **MPX** — 레거시 MPX 형식
3. 저장 후 대화상자에서 **Open File**로 결과를 확인할 수 있습니다.

### 제한 사항

- **`.mpp` 파일로 직접 저장은 지원하지 않습니다.** MS Project로 넘길 때는 XML보내기를 권장합니다.
- 요약 태스크 간 링크는 MS Project와 MyProject 모두에서 하위 태스크 일정으로 해석됩니다.
- 매우 복잡한 MS Project 파일은 버전·내용에 따라 일부 필드가 누락될 수 있습니다.

## 5. 태스크 작업

### 태스크 추가

| 방법 | 설명 |
|------|------|
| Insert | 루트 수준 태스크 추가 |
| Ctrl+Shift+Insert | 선택 태스크의 **하위 태스크** 추가 |
| 툴바 Add Task / Add Subtask | 위와 동일 |
| 우클릭 메뉴 | 그리드 또는 Gantt에서 **Add Task** / **Add Subtask** |

### 태스크 선택

- 그리드 행 클릭
- Gantt 차트의 태스크 바 클릭

선택한 태스크는 그리드와 Gantt에서 함께 강조 표시됩니다.

### 태스크 삭제

- Delete 키
- 툴바 **Delete**
- 우클릭 **Delete Task**

하위 태스크가 있는 경우 함께 삭제될 수 있으니 확인하세요.

### 계층 구조 (들여쓰기 / 내어쓰기)

| 작업 | 단축키 | 툴바 |
|------|--------|------|
| 들여쓰기 (하위로) | Alt+Right | Indent |
| 내어쓰기 (상위로) | Alt+Left | Outdent |

들여쓰기는 태스크 트리의 부모-자식 관계를 만듭니다. **요약(Summary)** 태스크는 모든 하위 태스크의 시작·종료·진행률을 자동으로 롤업합니다.

### 접기 / 펼치기

- 그리드의 트리 화살표 클릭
- 툴바 **Expand/Collapse** (선택 태스크의 하위 표시 토글)
- 우클릭 메뉴

### 태스크 유형

| 유형 | 설명 |
|------|------|
| **Normal** | 일반 작업. 기간(일)이 있습니다. |
| **Milestone** | 마일스톤. 시작일 하루, 바가 짧게 표시됩니다. |
| **Summary** | 요약 태스크. 하위 태스크 일정을 자동 집계합니다. |

### 태스크 그리드 열

| 열 | 설명 |
|----|------|
| ID | 태스크 번호 |
| Task Name | 이름 (요약 태스크는 굵게) |
| Start | 시작일 |
| Days | 기간(일) |
| % | 진행률 |
| Resource | 배정 리소스 (여러 줄 목록) |
| Deliverable | 산출물 (여러 줄 목록) |

**Resource**, **Deliverable** 열을 **더블클릭**하면 그리드에서 직접 편집할 수 있습니다. 리소스는 줄 단위로 `이름` 또는 `이름 (50%)` 형식입니다.

### 완료된 태스크 표시

진행률이 **100%**인 태스크는 그리드 전체 열 텍스트에 **취소선**이 적용되어 완료 상태를 쉽게 구분할 수 있습니다.

### 태스크 속성 대화상자

- 태스크 **더블클릭** (이름 열 등)
- F2
- 툴바 **Task Properties**
- 우클릭 **Properties**

일반 정보, 색상, 리소스, 메모 등을 편집할 수 있습니다.

### 자동 일정 (Auto Schedule)

태스크에 **Auto Schedule**이 켜져 있으면, 의존 관계에 따라 시작일이 자동으로 조정됩니다. 수동으로 시작일을 고정하려면 Auto Schedule을 끄세요.

## 6. 크리티컬 패스

크리티컬 패스는 **프로젝트 시작부터 완료까지**, 일정상 여유가 없어 **반드시 지켜야 하는 태스크**를 의존 관계로 연결한 경로입니다.

### 표시 방법

크리티컬 패스는 기본적으로 **표시되지 않습니다**. 보려면 다음 중 하나를 켜세요.

- 툴바 **Critical Path** 버튼 (눌린 상태 = 표시)
- **View → Show Critical Path**

표시 상태는 프로젝트에 저장됩니다.

### 화면에서의 표시

| 위치 | 표시 |
|------|------|
| 태스크 그리드 | 크리티컬 태스크 이름 **빨간색** |
| Gantt 태스크 바 | 크리티컬 태스크 **빨간 바** |
| Gantt 의존선 | 크리티컬 경로를 잇는 **굵은 빨간 화살표** |
| 요약 태스크 | 하위에 크리티컬 리프 태스크가 있으면 함께 강조 |

요약 태스크끼리 연결된 의존 관계(예: `Planning → Development`)는 내부적으로 **실제 일정을 결정하는 하위 태스크**로 펼쳐 계산되며, Gantt에는 그 리프 태스크 사이의 빨간 연결선으로 경로가 표시됩니다.

### 계산 시점

다음 변경 후 크리티컬 패스가 **자동으로 다시 계산**됩니다.

- 태스크 추가·삭제·이동, 들여쓰기/내어쓰기
- 시작일·기간·진행률·태스크 유형 변경
- 의존 관계 추가·삭제·타입/Lag 변경
- Gantt에서 태스크 바 드래그·리사이즈 후
- 프로젝트 열기·새 프로젝트 적용

### 속성 패널

태스크의 **Critical** 체크박스는 계산 결과를 **읽기 전용**으로 보여 줍니다. 수동으로 켜거나 끌 수 없습니다.

## 7. Gantt 차트

### 타임라인

- 상단에 날짜 눈금이 표시됩니다.
- **Ctrl+T** 또는 툴바 **Today**: 오늘 날짜 위치로 스크롤
- **Ctrl++** / **Ctrl+-** 또는 툴바 줌 버튼: 하루 칸 너비 조절 (줌)

### 태스크 바

- 바 길이 = 기간
- 바 내부 색상 = 진행률
- 사용자 지정 바 색·진행률 색 지원 (속성에서 설정)
- 크리티컬 패스 표시 시 빨간색 강조

### 스크롤 동기화

그리드와 Gantt의 세로 스크롤이 연동됩니다. 한쪽을 스크롤하면 다른 쪽도 함께 이동합니다.

### Gantt 이미지 보내기

**Report → Export Gantt as Image** 또는 툴바 이미지 버튼

| 형식 | 투명 배경 |
|------|-----------|
| PNG | 지원 |
| WebP | 지원 |
| JPEG | 흰색 배경으로 평탄화 |
| GIF | 투명 또는 흰색 배경 |

전체 타임라인이 포함된 이미지가 생성됩니다.

## 8. 의존 관계 (태스크 연결)

### 연결 종류

| 코드 | 이름 | 의미 |
|------|------|------|
| **FS** | Finish-to-Start | 선행 태스크가 끝난 후 후행 시작 |
| **FF** | Finish-to-Finish | 선행·후행이 같은 날 끝남 |
| **SS** | Start-to-Start | 선행·후행이 같은 날 시작 |
| **SF** | Start-to-Finish | 선행 시작 후 후행 종료 |

### Link 모드로 연결하기

1. 툴바에서 의존 **종류**(FS/FF/SS/SF)와 선 형태를 선택합니다.
2. **Link** 버튼을 누르거나 Ctrl+L (토글)
3. Gantt에서 **선행 태스크** 바를 클릭
4. **후행 태스크** 바를 클릭 → 연결선이 생성됩니다.

연결 중 **Esc**로 취소할 수 있습니다. Link 버튼이 눌린 상태에서는 미리보기 선이 표시됩니다.

### Lag (지연 일수)

속성 패널의 의존 관계 목록에서 Lag 일수를 설정할 수 있습니다. 양수는 지연, 음수는 선행(Lead)을 의미합니다.

### 의존 관계 삭제

속성 패널의 의존 관계 그리드에서 행을 선택하고 삭제하거나, 우클릭 메뉴를 사용합니다.

## 9. 노트

Gantt 차트 위에 배치하는 **노란색 노트**입니다. 회의 메모, 리스크, 설명 등을 차트와 함께 기록할 때 사용합니다.

### 노트 추가

**방법 1 — 선택 태스크에 추가**

1. 태스크를 선택
2. 툴바 **Notes** 버튼 클릭 (한 번 더 누르면 해당 태스크에 노트 생성)

**방법 2 — 노트 모드**

1. 툴바 **Notes**를 눌러 노트 모드 활성화 (버튼이 눌린 상태)
2. Gantt에서 태스크 **바를 클릭** → 해당 태스크에 노트 추가
3. 다시 **Notes**를 눌러 노트 모드 종료

### 노트 편집

- Gantt에서 노트 마커 **더블클릭** → 차트 위 인라인 편집
- 노트 선택 후 **속성 패널**에서 제목·본문·연결 태스크·기준 날짜 편집
- 우클릭 **Edit Note**

### 서식 있는 텍스트

노트 본문은 RTF 서식을 지원합니다.

| 서식 | 방법 |
|------|------|
| 글꼴 | Segoe UI, Arial, Calibri 등 |
| 크기 | 8pt ~ 24pt |
| 굵게 / 기울임 / 밑줄 / 취소선 | 편집기 툴바 버튼 |

서식은 Gantt 차트에 렌더링되고, HTML·Word·PDF·Excel 보내기에도 반영됩니다.

### 노트 삭제

- 노트 선택 후 **Delete**
- 우클릭 **Delete Note**

### 노트와 태스크 연결

속성 패널에서 **Linked Task**를 변경하면 노트가 다른 태스크에 연결됩니다. **Anchor Date**로 차트 상의 기준 날짜를 지정할 수 있습니다.

## 10. 속성 패널

우측 패널에서 **현재 선택**한 태스크 또는 노트의 속성을 바로 편집합니다.

### 태스크 선택 시

| 항목 | 설명 |
|------|------|
| Name | 태스크 이름 |
| Type | Normal / Milestone / Summary |
| Start / Duration | 시작일, 기간(일), 계산된 종료일 |
| Progress | 0~100% |
| Auto Schedule | 의존 관계 기반 자동 일정 |
| Critical | 크리티컬 패스 여부 (읽기 전용) |
| Deliverable | 산출물 설명 |
| Notes | 태스크 메모 (플레인 텍스트) |
| Bar / Progress Color | 태스크 바·진행률 색 |
| Resources | 리소스 배정 그리드 |
| Dependencies | 선행·후행 의존 관계 목록 |

변경은 즉시 모델에 반영되고 Gantt·그리드에 업데이트됩니다.

### 노트 선택 시

| 항목 | 설명 |
|------|------|
| Title | 노트 제목 |
| Body | 서식 있는 본문 (RTF) |
| Linked Task | 연결 태스크 |
| Anchor Date | 차트 기준 날짜 |

### 패널 접기

패널 헤더의 **»** 버튼으로 패널을 접으면 Gantt 오른쪽에 32px 스트립만 남고 **«** 버튼으로 다시 펼칠 수 있습니다.

### 아무것도 선택하지 않은 경우

"Select a task or note to edit its properties." 메시지가 표시됩니다.

## 11. 리소스 배정

태스크 속성 대화상자, 속성 패널, 그리드 **Resource** 열 더블클릭, 또는 컨텍스트 메뉴에서 리소스를 배정할 수 있습니다.

- 리소스 이름과 할당량(%)을 입력
- 그리드 Resource 열: 줄 단위로 `담당자` 또는 `담당자 (50%)` 형식
- Excel·HTML·Word·PDF 보고서에 리소스 시트/섹션이 포함됩니다.

## 12. 보고 및 보내기

**Report** 메뉴 또는 툴바에서 보내기를 실행합니다. 완료 후 **Open File**로 결과 파일을 바로 열 수 있습니다.

### Excel (.xlsx)

**Report → Export to Excel** 또는 툴바 Excel 버튼

| 시트 | 내용 |
|------|------|
| Summary | 프로젝트 개요, 진행률, 크리티컬·노트 수 |
| Task Schedule | 태스크 목록 + Gantt 타임라인 열 |
| Resource Allocation | 리소스 배정 |
| Dependencies | 의존 관계 목록 (크리티컬 표시) |
| Notes | 노트 전체 목록 |

### HTML / Word / PDF

일정·리소스·노트·크리티컬 패스·의존 관계를 포함한 보고서입니다.

### Markdown

**Report → Export to Markdown** — 진행률·일정 요약.

### Gantt 이미지

**Report → Export Gantt as Image** — PNG, JPEG, GIF, WebP.

### Microsoft Project

**File → Export to Microsoft Project...** — XML 또는 MPX. [Microsoft Project 연동](#4-microsoft-project-연동) 참고.

### 인쇄

**Report → Print** (Ctrl+P) — Gantt 차트 인쇄.

## 15. 자주 묻는 질문

### 저장하지 않고 종료하면?

**실제로 편집한 내용이 있을 때만** 종료·새 프로젝트·다른 파일 열기 시 저장 여부를 묻습니다. 열기만 하고 아무것도 바꾸지 않았다면 확인 대화상자가 나타나지 않습니다. Visual Studio 디버거로 실행한 경우 종료 시 저장 확인이 생략될 수 있습니다.

### Microsoft Project 파일을 열었는데 저장 형식은?

MS Project 파일을 열면 메모리에 로드되며, **File → Save**는 원래 `.myprj` 경로가 없으면 **Save As**로 `.myprj` 저장을 권장합니다. MS Project 형식으로 다시내려면 **Export to Microsoft Project**를 사용하세요.

### 크리티컬 패스가 안 보여요

**Critical Path** 툴바 버튼 또는 **View → Show Critical Path**를 켜세요. 기본값은 숨김입니다.

### 크리티컬 패스 선이 요약 태스크끼리 연결되지 않아요

요약 태스크 간 링크는 **하위 실제 태스크** 사이의 빨간 굵은 선으로 표시됩니다. 이것이 프로젝트 전체를 관통하는 실제 경로입니다.

### 다른 PC에서 프로젝트를 열면?

`.myprj` 파일만 복사하면 태스크·노트·뷰 설정이 함께 열립니다. MyProject와 .NET 8 런타임이 설치된 Windows PC에서 사용할 수 있습니다.

### Excel에서 Gantt가 잘려 보여요

Excel 시트의 타임라인 열 수는 프로젝트 기간에 따라 제한됩니다. 매우 긴 프로젝트는 Gantt 이미지 보내기를 사용하세요.

### 속성 패널이 안 보여요

툴바 **Properties Panel** 버튼, **View → Properties Panel**, 또는 접힌 스트립의 **«** 버튼을 사용하세요.

### Link 연결이 안 됩니다

- Link 버튼이 활성(눌린) 상태인지 확인
- 같은 태스크끼리는 연결할 수 없습니다
- 선행 → 후행 순서로 두 태스크를 클릭했는지 확인
