# MyWorkspace 사용자 가이드 (Web V10)

MyWorkspace Web V10은 Notion과 유사하게 **Workspace**와 **Page**를 트리로 관리하고, WYSIWYG 방식으로 Markdown 문서를 작성할 수 있는 **Electron** 데스크톱 앱입니다. Windows, macOS, Linux에서 동일한 UI로 사용할 수 있습니다.

WinV10(Windows 네이티브)과 **같은 `.wsp` 포맷**과 DB 스키마를 공유하므로, 프로젝트 파일과 MariaDB 등 외부 DB를 함께 쓸 수 있습니다.

## 1. 시작하기

### 프로그램 실행

| 환경 | 실행 방법 |
|------|-----------|
| **Windows** | `MyWorkspace-Setup-0.1.0.exe` 등 설치 후 시작 메뉴·바탕 화면, 또는 `MyWorkspace-Portable-0.1.0.exe` (설치 없이 실행) |
| **macOS** | `MyWorkspace-*-mac-*.dmg`에서 Applications로 복사 후 실행 |
| **Linux** | `MyWorkspace-*-linux-*.AppImage` 실행, `.deb` 설치, 또는 `.tar.gz` 압축 해제 후 실행 |
| **개발** | 프로젝트 폴더에서 `npm install` → `npm start` |

> 설치 파일은 소스 빌드 시 **프로젝트 루트**에 생성됩니다. 자세한 빌드 방법은 [README.md](README.md)를 참고하세요.

### 최초 실행 흐름

1. **로그인 화면**이 표시됩니다.
2. DB에 사용자가 없으면 기본 관리자 계정(`admin` / `admin`)이 자동 등록됩니다.
3. 기본 관리자로 로그인합니다.
4. DB 연결에 실패하면 **제목 표시줄 `|||` → DB 연결 설정...** 에서 MariaDB·MySQL·PostgreSQL·SQL Server 또는 SQLite를 설정합니다. (관리자만 가능)
5. 로그인 후 **프로필 → 비밀번호 변경** 또는 **관리 → 사용자 관리**에서 계정과 비밀번호를 변경할 수 있습니다.

> DB **접속 계정**(MariaDB `root` 등)과 앱 **로그인 계정**(`admin` 등)은 별개입니다. 앱 사용자는 DB `users` 테이블에서 관리됩니다.

> 기본 관리자(`admin` / `admin`)는 **최초 설치·DB 최초 연결 시**에만 자동 생성됩니다.

> 이메일 서버는 설정하지 않아도 앱을 사용할 수 있습니다.

| 영역 | 설명 |
|------|------|

| **Page 탭** | 편집기 상단에 열린 Page 목록. 탭 클릭으로 전환, **×** 로 닫기. 선택된 탭은 하단 강조선으로 표시 |
| **세로 툴바** (우측) | 저장, Markdown 저장, 보내기, 제목(H1~H6), 서식, Undo/Redo, Workspace·문서 구조·댓글 토글 등 |
| **문서 구조** | H1~H6 제목 Outline, 클릭 시 해당 위치로 이동 |
| **댓글 패널** | Page별 댓글 목록·작성 (편집 영역 오른쪽) |
| **편집 영역** | WinV10과 동일한 WebView 기반 WYSIWYG 편집기 (입력 내용은 Markdown으로 저장) |

메뉴바·툴바·패널·상태바 사이에는 **구분선 테두리 없이** 이어지는 WinV10 스타일 레이아웃입니다.

로그인하면 **마지막으로 열었던 Page**와 **Workspace 패널 접힘·너비**가 사용자별로 복원됩니다.

### Page 검색

1. 제목 표시줄 **Page 검색…** 상자에 키워드를 입력합니다.
2. 검색 결과 목록에서 Page를 선택하면 해당 Page가 열립니다.
3. 검색창을 숨기려면 **`|||` → Page 검색창 표시** 체크를 해제합니다.

## 3. 환경 설정

설정은 **역할과 종류**에 따라 위치가 나뉩니다.

| 위치 | 메뉴 | 설명 |
|------|------|------|
| **`|||`** (제목 표시줄) | **환경 설정...** | 테마, 색상, 글꼴 크기, 언어 변경 |
| **프로필** (하단 내비) | **프로필 수정** | 사용자 ID(이름) 변경 |
| **프로필** | **비밀번호 변경** | 현재 비밀번호 확인 후 변경 |
| **프로필** | **알림 설정** | 이메일 주소, Page·Workspace 알림 |
| **`|||`** | **Page 검색창 표시** | 타이틀바 Page 검색 상자 표시/숨김 |
| **`|||`** | **DB 연결 설정...** | DB 종류·서버·연결 테스트 (관리자) |
| **`|||`** | **이메일 서버 설정** | SMTP 알림 서버 (관리자, 선택) |

### 테마·색상·글꼴·언어

**`|||` → 환경 설정...** 대화상자에서 다음을 변경합니다.

| 항목 | 설명 |
|------|------|
| **테마** | **밝게** / **어둡게** — 메뉴, 트리, 편집기, 대화상자 등 **앱 전체**에 일괄 적용 |
| **색상 테마** | 20종 파스텔 강조색 스와치 중 선택. **사용자 선택색** 버튼으로 임의 색 지정 가능. 어두운 모드에서는 어두운 배경 위에 액센트 색이 표시됩니다 |
| **글꼴 크기** | 매우 작게 ~ 매우 크게 (5단계). UI·편집 본문 글꼴에 반영 |
| **언어** | 한국어 / English |

- 설정은 `appsettings.local.json`에 저장됩니다.
- 테마·색상·글꼴 변경은 대화상자에서 **즉시 미리보기**로 반영됩니다. **확인**을 누르면 저장됩니다.
- 어두운 테마에서는 툴바 아이콘이 자동으로 밝게 보이도록 조정됩니다.

## 4. 데이터베이스 설정

### 지원 DB

| DB 종류 | 설명 |
|---------|------|
| MariaDB | 권장 (기본값) |
| MySQL | MariaDB와 동일 드라이버 |
| PostgreSQL | |
| Microsoft SQL Server | |
| SQLite 3 | 단일 파일 DB (로컬·테스트용, 기본 설치 시 자동 사용) |

### 연결 설정 열기

- **관리자 로그인 후**: 제목 표시줄 **`|||`** → **DB 연결 설정...**

> 일반 사용자는 DB 연결 설정 메뉴를 볼 수 없습니다.

### 연결 테스트

- **연결 테스트** 버튼: 서버 접속 및 DB 존재 여부 확인
- DB가 없으면 **자동 생성** 후 "연결 성공 (DB 생성됨)" 메시지 표시
- **저장** 시에도 연결 테스트가 수행됩니다

### 연결 끊기

- **연결 끊기** 버튼: 현재 DB 연결을 해제하고 로그아웃합니다.
- 연결 정보는 `appsettings.local.json`에 남아 있어, 나중에 **저장**만으로 다시 연결할 수 있습니다.

### 설정 저장 위치

연결 정보(비밀번호 포함)는 [§17 설정 및 파일 위치](#17-설정-및-파일-위치)의 `appsettings.local.json`에 저장됩니다.

> DB **접속 계정**(root 등)과 앱 **로그인 계정**(admin 등)은 별개입니다.

## 6. Workspace와 Page

### 트리 구조

하나의 Workspace 아래에는 **Page**와 **하위 Workspace**가 **같은 레벨(형제)** 로 함께 표시될 수 있습니다.

```
Workspace A
├── Page 1
├── Page 2
├── 하위 Workspace B
│   └── Page 3
└── 하위 Workspace C
```

- Page 아래에는 Page나 Workspace를 만들 수 **없습니다** (Page는 leaf 노드).
- Page가 이미 있는 Workspace에도 **하위 Workspace**를 추가할 수 있습니다.

### Workspace

- **루트 Workspace**: **Workspace → 새 Workspace**
- **하위 Workspace**: Workspace 선택 후 **Workspace → 하위 Workspace 추가** 또는 트리 우클릭
- **이름 변경·삭제**: Workspace 선택 후 메뉴 또는 우클릭

**삭제 조건**: 하위 Workspace와 Page가 **모두 없어야** 합니다.

### Markdown 파일 가져오기 (드래그 앤 드롭)

탐색기(파일 관리자)에서 **`.md` / `.markdown` 파일**을 Workspace 패널의 **Workspace** 또는 **Page** 행 위로 드래그 앤 드롭하면 해당 Workspace에 **새 Page**로 가져옵니다.

| 항목 | 설명 |
|------|------|
| **대상** | Workspace 행, Page 행(해당 Page의 Workspace에 추가), 또는 패널 빈 영역(현재 선택된 Workspace) |
| **Page 제목** | **파일 이름**(확장자 제외). 동일 제목이 있으면 `이름 (2)`처럼 자동 구분 |
| **본문** | Markdown 파일 내용. 첫 `#` 제목은 Page 제목에 맞게 조정됩니다 |
| **이미지·첨부** | Markdown 안의 상대 경로 링크·`{파일명}_assets/` 폴더의 로컬 파일을 Page asset으로 복사 |
| **여러 파일** | 한 번에 여러 `.md`를 드롭하면 각각 Page로 생성되고, **마지막 Page**가 열립니다 |
| **권한** | 해당 Workspace에 **Editor 이상** 편집 권한이 있어야 합니다 |

드롭 가능한 대상 행은 **점선 테두리**로 표시됩니다. HTTP/HTTPS URL 이미지는 그대로 유지되고, 로컬 파일만 가져옵니다.

### Page

- Workspace 선택 후 **Workspace → 새 Page (양식)...** 또는 우클릭
- **빠른 작성**: Workspace를 선택한 뒤 **제목** 또는 **본문**을 입력하면 **즉시** Page가 생성됩니다. 제목을 비워 두면 **`제목없음`** 으로 저장됩니다.

### 트리 우클릭 메뉴

| 항목 | 대상 |
|------|------|
| 하위 Workspace 추가 | Workspace |
| 새 Page (양식)... | Workspace |
| 이름 변경 | Workspace, Page |
| 삭제 | Workspace, Page |
| **잠금 / 잠금 해제** | Workspace, Page (Editor 이상) |
| **Page 보내기...** | Page |
| **Workspace 보내기...** | Workspace |
| 즐겨찾기 추가/제거 | 등록된 Workspace |
| 멤버 관리 | Workspace |

## 7. Page 편집

### 편집기

- **제목**과 **WYSIWYG Markdown 본문**을 편집합니다.
- **자동 저장**: 입력 후 약 2초 뒤 DB에 자동 저장 (상태 표시줄: "수정됨" → "저장됨").
- **수동 저장**: **파일 → Page 저장** (Ctrl+S) 또는 세로 툴바 **저장** 버튼.
- **저장 진행 표시**: 저장에 **3초 이상** 걸릴 때만 **저장 중** 대화상자가 표시됩니다.

### Page 탭

| 동작 | 설명 |
|------|------|
| **Page 열기** | 트리·검색·링크·새 Page 생성 시 탭 추가 |
| **탭 선택** | 변경 사항이 있을 때만 현재 Page 저장 후 전환. 탭별 편집 내용은 메모리에 유지되어 다시 열 때 복원됩니다 |
| **탭 닫기 (×)** | 저장되지 않은 변경이 있으면 확인 |

여러 Page를 동시에 열어 두고 탭으로 전환할 수 있습니다. 저장하지 않은 내용도 탭을 닫기 전까지는 유지됩니다.

### Workspace에서 바로 편집하기

1. 트리에서 **Workspace**를 선택합니다.
2. **제목** 또는 **본문**을 입력하면 Page가 **자동 생성**됩니다.
3. 제목을 입력하지 않으면 **`제목없음`** 으로 추가됩니다.

### 세로 툴바 (우측)

| 버튼 | 기능 |
|------|------|
| 저장 | Page 저장 (Ctrl+S) |
| Markdown 파일 | Markdown 파일로 저장 |
| 보내기 | 현재 Page 보내기 (MD / Word / PDF) |
| Undo, Redo | 실행 취소 / 다시 실행 |
| H1 ~ H6 | 제목 1~6 |
| B, I, S | 굵게, 기울임, 취소선 |
| 코드, 블록 | 인라인·블록 코드 |
| 링크, 이미지, 첨부 | 링크·이미지·파일 삽입 |
| -, 1., > | 글머리·번호 목록, 인용 |
| ---, 표 | 구분선, 표 템플릿 |
| Workspace | Workspace 패널 접기·펼치기 |
| 문서 구조 | 문서 구조 패널 접기·펼치기 |
| 댓글 | 댓글 패널 접기·펼치기 |

### 이미지·첨부

- **이미지**·**첨부** 버튼 또는 편집기에 **드래그 앤 드롭**하여 삽입합니다.
- Page에 포함된 파일은 DB `page_assets`와 `PageAssets/` 캐시에 보관됩니다.
- 이미지 **우클릭** 메뉴에서 댓글 작성(인용)을 시작할 수 있습니다.

### 이미지 크기 조절

삽입된 이미지를 선택하면 **우하단 모서리**에 크기 조절 핸들이 표시됩니다.

| 동작 | 설명 |
|------|------|
| **크기 조절** | 핸들을 드래그하여 가로·세로 크기를 함께 조절합니다 |
| **이동** | 이미지 본문(핸들 제외)을 드래그하여 문서 안에서 위치를 옮깁니다 |
| **크기 저장** | 조절을 마치면 편집기에 크기가 기록되며, Page 저장·보내기 시 반영됩니다 |

조절한 크기는 Markdown 메타데이터(`editor-width`, `editor-height`)로 저장되며, **Markdown·Word·PDF 보내기**에 동일하게 적용됩니다. 저장 후 Page를 다시 열어도 조절한 크기가 유지됩니다.

### 문서 구조(Outline)

- 본문의 H1~H6 제목이 트리로 표시됩니다.
- 항목을 클릭하면 편집기에서 해당 위치로 이동합니다.

## 9. 보내기와 저장

### Markdown 파일로 저장

**파일 → Markdown 파일로 저장...** 또는 세로 툴바 **Markdown 파일** 버튼.

### Page 보내기

| 열기 방법 | 설명 |
|-----------|------|
| **트리 우클릭 → Page 보내기...** | 트리에서 선택한 Page |
| **세로 툴바 보내기** | 현재 편집 중인 Page |

보내기 대화상자에서 **파일 형식**(Markdown / Word / PDF)을 선택합니다. Markdown을 선택하면 **이미지를 Base64로 포함** 옵션을 켤 수 있습니다(단일 `.md` 파일에 이미지를 인라인 삽입).

| 형식 | 확장자 | 첨부·이미지 |
|------|--------|-------------|
| Markdown | `.md` | 기본: `{파일명}_assets/` 폴더에 복사. 옵션: Base64 인라인 |
| Word | `.docx` | 하나의 문서에 포함. 편집기에서 조절한 이미지 크기 유지 |
| PDF | `.pdf` | 본문에 이미지 포함. 편집기에서 조절한 이미지 크기 유지 |

보내기가 끝나면 **완료 또는 실패** 대화상자가 표시되며, 성공 시 **저장 위치(파일 경로)** 를 확인할 수 있습니다. 현재 편집 중인 Page를 보낼 때는 저장하지 않은 변경 내용과 이미지 크기도 반영됩니다.

### Workspace 보내기

**트리에서 Workspace 우클릭 → Workspace 보내기...** — 하위 구조를 유지한 채 모든 Page를 보냅니다.

### 프로젝트 저장 (.wsp)

선택한 **Workspace 전체**를 **`.wsp` 프로젝트 파일**로 저장합니다. WinV10과 동일한 ZIP 기반 포맷입니다.

> **자동 저장은 DB에만 적용**됩니다. `.wsp`는 **파일 → 프로젝트 저장...** 으로 최초 저장 후 **Ctrl+S**로 DB와 함께 갱신할 수 있습니다.

1. 저장할 **Workspace**를 선택합니다.
2. **파일 → 프로젝트 저장...** 실행.
3. `이름.wsp`로 저장합니다.

### 프로젝트 열기

1. **파일 → 프로젝트 열기...** 또는 OS에서 `.wsp` **더블 클릭** (설치 시 파일 연결).
2. **파일 → 최근 프로젝트**에서 최근 파일 선택 (최대 12개).

## 18. 자주 묻는 질문

### Q. WinV10과 Web V10의 차이는?

Web V10은 Electron 기반 **멀티 플랫폼** 앱입니다. UI·편집기·`.wsp`·DB 스키마는 WinV10과 호환되도록 맞춰져 있습니다. 세로 툴바, `|||` 메뉴 배치 등 셸 레이아웃은 WinV10과 동일한 개념입니다.

### Q. 문서 구조와 댓글 패널이 같이 열리나요?

**예, 둘 다 동시에 펼칠 수 있습니다.** 각각 별도 버튼(보기·댓글 메뉴, 세로 툴바)으로 토글합니다.

### Q. Workspace 패널 접힘 상태가 유지되나요?

**예.** 사용자별로 저장되며 다음 로그인 시 복원됩니다.

### Q. Page 탭을 여러 개 열 수 있나요?

**예.** 탭 전환 시 **수정된 내용이 있을 때만** 자동 저장됩니다.

### Q. DB 없이 실행할 수 있나요?

앱 사용에는 DB 연결이 필요합니다 (**기본 SQLite**가 로컬에 자동 생성됩니다). **`.wsp` 프로젝트 파일**로 Workspace 전체를 백업·이동할 수 있습니다.

### Q. DB 연결 설정 메뉴가 안 보여요.

**관리자**로 로그인했는지 확인하세요. 메뉴는 **제목 표시줄 `|||`** 에 있습니다 (관리 메뉴가 아님).

### Q. 외부 Markdown 파일을 Workspace에 넣으려면?

탐색기에서 `.md` 파일을 **Workspace 패널**의 Workspace(또는 Page) 행 위로 **드래그 앤 드롭**하세요. 파일 이름이 Page 제목이 되고, 본문·로컬 이미지가 함께 가져와집니다. WinV10과 동일한 방식입니다.

### Q. Markdown 보내기 시 이미지는 어디에 저장되나요?

`.md` 파일과 같은 폴더에 **`{파일명}_assets`** 폴더가 생성되고, Page에 포함된 이미지·첨부 파일이 그 안에 복사됩니다. 이 형식의 파일을 Workspace 패널에 **드래그 앤 드롭**하면 `_assets` 폴더의 이미지도 함께 가져옵니다.

### Q. 미리보기 창이 따로 있나요?

아니요. 편집 영역 자체가 WYSIWYG 방식으로 Markdown을 렌더링합니다. 별도의 미리보기 분할 창은 없습니다.

### Q. 색상을 바꿨는데 편집기만 바뀌어요.

Web V10에서는 테마·색상 변경 시 **앱 전체**(메뉴, 패널, 편집기)에 즉시 적용됩니다. **환경 설정**에서 **확인**을 눌러 저장했는지 확인하세요.

### Q. PDF·Word 보내기에서 이미지 크기가 편집기와 다르게 나와요.

1. 편집기에서 이미지 **우하단 핸들**로 크기를 조절했는지 확인하세요.
2. **보내기** 전에 Page를 한 번 **저장**(Ctrl+S)해 보세요.
3. 앱을 최신 버전으로 실행 중인지 확인하세요. Web V10은 편집기 HTML의 이미지 크기를 Markdown·PDF·Word 보내기에 병합합니다.

### Q. 보내기 후 파일이 어디에 저장됐는지 모르겠어요.

보내기가 완료되면 **완료 대화상자**에 **저장 위치(파일 경로)** 가 표시됩니다. 실패 시에는 오류 메시지를 확인하세요.

### Q. 저장 후 다시 열면 이미지가 깨져 보여요.

Page를 한 번 저장(Ctrl+S)한 뒤 다시 열어 보세요. `PageAssets/` 에 해당 파일이 있는지 확인하세요.

### Q. 기본 admin 비밀번호를 잊었어요.

DB에 직접 접속하여 `users` 테이블의 `password_hash`를 갱신하거나, DB를 초기화 후 다시 시드해야 합니다.

### Q. 이메일 알림이 오지 않아요.

1. 관리자가 **이메일 알림 사용**을 켰는지
2. SMTP 설정이 올바른지
3. **프로필 → 알림 설정**에 이메일과 알림 종류가 켜져 있는지
4. 해당 Workspace의 **멤버 또는 Owner**인지

를 확인하세요.
