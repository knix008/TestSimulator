# MyPhotoManager 사용 설명서

> 단계별 화면으로 따라 하려면 [튜토리얼 문서](docs/tutorial/README.md)를 보거나, 앱의 시작 화면 › **튜토리얼**을 실행하세요 (도움말 › 튜토리얼에도 있습니다). 튜토리얼은 전용 예제 폴더에서만 작업하고, 끝나면 바뀐 설정을 되돌립니다.

## 1. 화면 구성

```text
┌ 메뉴(파일 편집 보기 정리 만들기 도구 도움말)  [시작] [관리|보기|편집|분류|대시보드]  테마 ▾테마목록 · 국기 · ⚙ · ⓘ ┐
│ ← → ↑ ⟳ │ ↶ ↷ │ 주소(경로)          │ 정렬 그룹 필터 │ 썸네일/타일/목록/상세/필름 스트립 │ 크기 │ 빠른 검색 │ 창 │
├──────────────┬──────────────────────────────────────────────┬───────────────┤
│ 폴더 │카탈로그│                                              │ 속성 │미리 보기│
│ 사람 │ 달력   │            파일 목록 (썸네일)                 │ 지도          │
│ 검색         │                                              │               │
│              ├──────────────────────────────────────────────┤               │
│              │  이미지 바구니 (켜면 보임)                    │               │
└──────────────┴──────────────────────────────────────────────┴───────────────┘
 상태 막대: 항목 수 · 선택 · 썸네일·불러오기 진행률 · 현재 경로
```

- **관리 모드**: 탐색·정리·파일 작업. 창 사이의 경계를 끌어 폭을 바꿉니다.
- **보기 모드**: 사진 한 장을 크게(Enter 또는 두 번 클릭).
- **편집 모드**: 현상·보정·부분 보정·레이어·텍스트(Ctrl+E).
- **대시보드**: 카탈로그 통계. 막대를 누르면 해당 사진 목록으로.

**머리글**: 왼쪽부터 메뉴, **시작**(시작 화면), 모드 단추(관리·보기·편집·**분류**·대시보드), 오른쪽 묶음입니다.

- **시작**: 모드 단추 바로 왼쪽. 시작 화면으로 돌아갑니다. 시작 화면 뒤의 **배경 효과** 22가지(계곡·바다·오로라·별·비·눈·노을·숲·모래 언덕·도시·성운·보케·격자·리본·불씨·호수·일출·반딧불이·도형·잉크·꽃잎·산맥)는 모두 움직이는 3D 장면입니다. 아래의 속도 막대로 **전체 속도**(0–100 %, 20 % 가 기본 빠르기)와 **카메라 이동**·**물체 움직임**(파도·비·눈·나무·입자·도형)·**하늘·빛**(구름·해·별)을 각각 0–300 % 로 바꿉니다. 0 % 인 것은 멈추고 나머지는 계속 움직입니다. **속도 초기화** 는 모두 기본값으로 되돌립니다. 설정 › 시작 화면 탭에서도 같습니다.
- **분류**: **대시보드** 바로 왼쪽. 카탈로그에 쌓인 인물·장면·객체 분류와 장수를 보여주고, 고르면 관리 모드에서 그 분류만 봅니다. 파일을 복사하거나 폴더를 만들지 않습니다. 아직 분석한 사진이 없으면 그렇게 알려 줍니다.

**머리글 오른쪽** (차례대로):

- **테마 버튼**: 누를 때마다 다음 테마로 바뀝니다(어두운 테마 20개, 밝은 테마 20개). 바로 오른쪽 **드롭다운**에서 직접 고르거나, *사용자 정의 테마 편집…* 에서 배경·글자·강조·패널 색을 원형 견본으로 골라 나만의 테마를 만듭니다(고르는 동안 창에 바로 보임, 저장하면 *사용자 정의* 로 남음).
- **언어 버튼**: 한국어 ↔ 영어. 바뀔 언어의 국기가 보입니다(한국어일 때 영국 국기, 영어일 때 태극기).
- **설정**(톱니바퀴)과 **프로그램 정보**(ⓘ: 아이콘·설명·버전·빌드·데이터 폴더·제작자 SHKWON(knix008@naver.com)). 정보 창은 지원 형식을 두 열로 펼쳐 내용이 잘리지 않습니다.

**좌우 패널**: 패널 제목에 아이콘과 이름이 있고, `<`(왼쪽)·`>`(오른쪽) 버튼으로 접습니다. 접으면 아이콘 줄과 세로 제목만 남고, `>`·`<` 로 다시 펴거나 아이콘을 눌러 그 탭으로 펼칩니다. 툴바 오른쪽 버튼으로 패널을 아예 숨기거나 보일 수 있습니다. 접기 단추는 언제나 제목 줄의 오른쪽 끝에 있습니다. 창은 툴바 단추가 모두 보이는 폭보다 좁아지지 않습니다(모드마다 따라감). 관리 모드의 **필름 스트립 보기** 에도 스트립 양쪽에 ◀ ▶ 가 있습니다. 사진을 고르지 않았을 때 오른쪽 패널은 지금 목록의 요약(형식·날짜 범위·카메라·별점, 누르면 그것만 보기)을 보여 줍니다.

**창**: 설정·정보·확인·인쇄 등 모든 대화 상자는 앱 창과 따로 떨어진 창(제목과 아이콘이 있는 크기 고정 창)으로 열리고, 그 창을 닫으면 취소입니다. 수치 칸은 양옆의 − + 로 한 단계씩(누르고 있으면 계속) 바꿉니다. 색은 원형 견본에서 고르고, 무지개 원으로 아무 색이나 고를 수 있습니다.

**실행 취소**: 툴바의 ↶ ↷ (Ctrl+Z / Ctrl+Y)로 이동·복사·이름 바꾸기·새 폴더를 되돌리거나 다시 합니다(여러 장을 한 번에 옮긴 것도 한 번에). 편집 모드에는 편집 단계의 실행 취소/다시 실행이 따로 있습니다.

## 2. 폴더 열기와 가져오기

- **데스크톱**: 왼쪽 *폴더* 창 맨 위에 시스템의 모든 드라이브가 이름(볼륨 이름 또는 "로컬 디스크 (C:)")과 남은 공간 막대와 함께 있습니다. 눌러서 열고 펼칩니다. 그 아래 *바로 가기*(홈·사진·바탕 화면·문서·다운로드)와 *즐겨찾기*. *파일 → 폴더 열기*(Ctrl+O)로 어디든 열 수 있습니다. 폴더를 오른쪽 클릭해 **즐겨찾기에 추가**. 탐색기에서 사진을 "연결 프로그램 → MyPhotoManager"로 열면 그 폴더가 열리고 사진이 보기 모드로 뜹니다. 창으로 파일·폴더를 끌어 놓아도 됩니다(파일은 현재 폴더로 복사할지 묻습니다).
- **웹**: *폴더 열기* — Chrome·Edge 는 쓰기 권한으로 열고 다음 방문에도 기억합니다(권한을 다시 묻는 폴더는 이름 옆 *허용* 을 클릭). *사진 열기* 로 파일만 고를 수도 있고, 사진·폴더를 창에 끌어 놓아도 됩니다. *예제 사진* 으로 바로 시험해 볼 수 있습니다.
- **최근 항목**(*파일 → 최근 항목*): 최근에 연 폴더 10개와 파일 10개. 누르면 바로 열리고(파일은 그 폴더와 함께 보기 모드로), 줄 끝 × 로 하나씩, *목록 모두 지우기* 로 전부 지웁니다. 시작할 때는 마지막 폴더가 열립니다(설정 → 일반).
- **썸네일**: 폴더를 열면 그 폴더의 썸네일을 모두 백그라운드로 만듭니다(상태 막대에 진행률). 썸네일은 폴더마다 따로 저장되어, 다음에 열 때는 저장된 것을 바로 보여 줍니다(바뀐 파일만 다시 만듦). *설정 → 데이터* 에서 지울 수 있습니다.
- **ZIP 보관함**: `.zip`·`.cbz` 를 열면(두 번 클릭) 안의 사진·동영상이 읽기 전용 폴더로 보입니다.
- **가져오기**(*파일 → 사진 가져오기*, Ctrl+Shift+I): 메모리 카드(DCIM 폴더가 있는 드라이브는 자동으로 보임)나 아무 폴더에서 사진을 골라 라이브러리 폴더로 복사합니다. 촬영일로 하위 폴더 만들기(`YYYY/MM`, `YYYY/YYYY-MM-DD` …), 이름 바꾸기 템플릿(일괄 이름 바꾸기와 같음), 키워드·별점 지정, **이미 있는 사진은 건너뛰기**(내용이 같은 파일), 가져온 뒤 원본 삭제.
- **휴대폰·카메라(USB)에서 가져오기**: 가져오기 창의 *휴대폰·카메라* 줄에 연결된 기기가 보입니다(Windows·Linux; 휴대폰은 잠금을 풀고 파일 전송 허용). 누르면 DCIM·Pictures 의 새 사진·동영상만 앱 데이터 폴더로 복사한 뒤 그 목록에서 골라 가져옵니다. 이미 복사한 파일은 건너뜁니다.
- **스캐너에서 가져오기**(*파일 → 스캔*, Windows): 스캐너 창이 뜨고, 스캔한 그림이 현재 폴더에 `scan-날짜시각.jpg` 로 저장됩니다.
- **폴더 동기화**(*파일 → 폴더 동기화*): 원본 폴더의 새 파일·바뀐 파일을 대상 폴더로 복사합니다. *미러* 를 켜면 원본에 없는 대상 파일을 지웁니다(확인을 받습니다).

썸네일 아래 표시(이름·크기·픽셀·날짜)와 겹쳐 그리는 아이콘은 *설정 → 탐색* 에서 고릅니다.

## 4. 정리하기

- **별점**: Ctrl+1…5, 지우기 Ctrl+0. **색상 레이블**: Alt+1(빨강) … Alt+5(보라), 지우기 Alt+0. **태그**: `` ` `` 키.
- **속성 창 → 정리**: 별점·레이블·태그, 제목·설명·작성자·메모, **IPTC** 펼침(헤드라인·저작권·크레디트·출처·행사·세부 장소·도시·시/도·국가·국가 코드·사용 조건·지침), 키워드(입력 후 Enter, 쉼표로 여러 개), 카테고리 체크. 여러 장을 선택하면 한꺼번에 적용되고, 값이 다르면 "(값이 서로 다름)"으로 보입니다.
- **계층 키워드**: `장소|한국|부산` 처럼 `|` 로 이어 씁니다. `kw:장소` 나 카탈로그 창의 상위 키워드는 그 아래 키워드가 붙은 사진까지 찾습니다.
- **카탈로그 창**: 항목을 클릭하면 그 사진들을, **Ctrl+클릭**으로 조건을 더합니다(같은 종류는 "또는", 다른 종류는 "그리고" — 위쪽의 *모두 만족 / 하나라도* 로 바꿈). **모든 미디어** 는 카탈로그에 등록된 사진 전체. 카테고리·키워드 앞의 상자를 누르면 **선택한 사진에 지정/해제**. 카테고리는 오른쪽 클릭으로 하위 카테고리 추가·이름 바꾸기·삭제.
- **자동 카테고리**: 카메라·렌즈·촬영 연도·ISO·초점 거리·조리개·플래시·방향·위치·국가 — EXIF 에서 저절로 만들어집니다.
- **이 폴더 카탈로그에 등록**(폴더 오른쪽 클릭 또는 정리 메뉴): 하위 폴더까지 EXIF 를 읽어 두면 카탈로그·달력·지도·대시보드·검색이 그 사진들 전체를 대상으로 합니다. 열어 본 폴더는 자동으로 등록됩니다.
- **빠른 키워드**(속성 창 → 정리): 이름 붙인 키워드 세트를 만들어 두고 버튼 하나로 선택한 사진에 붙이거나 뗍니다. 처음 아홉 개는 **Alt+Shift+1…9**. 연필 버튼으로 세트 편집.
- **메타데이터 템플릿**(IPTC 펼침 맨 위): 선택한 사진들이 공통으로 가진 IPTC 값·키워드를 이름으로 저장하고, 고르기만 하면 다른 사진에 한 번에 적용.
- **컬렉션**(카탈로그 창): 폴더와 상관없이 사진을 모은 목록. + 로 선택한 사진으로 만들고, 오른쪽 클릭 메뉴 *컬렉션에 추가* 로 더합니다. **스마트 컬렉션**(요술봉 버튼)은 규칙(별점·레이블·키워드·카테고리·인물·텍스트·카메라·렌즈·종류·형식·폴더·촬영일·너비·태그·위치)으로 저절로 채워지고, 조건이 바뀌면 목록도 바뀝니다.
- **이미지 바구니**: Ctrl+B 로 담고, 툴바의 바구니 버튼으로 아래쪽에 펼칩니다. 여러 폴더의 사진을 모아 슬라이드 쇼·인쇄·일괄 처리.
- **메타데이터**:
  - *정리 → EXIF 편집*: JPEG 의 촬영일·제조사·모델·작성자·저작권·설명·소프트웨어·GPS(지우기 포함)를 사진 파일에 직접 씁니다(그림은 다시 압축하지 않음).
  - *정리 → 메타데이터를 파일에 쓰기*: 정리한 내용(제목·설명·키워드·별점·레이블·IPTC·지오태그)을 JPEG·PNG·WebP·TIFF 안에 XMP 로 넣습니다(JPEG 는 작성자·저작권·설명·GPS 를 EXIF 에도). 다른 형식은 사이드카 `.xmp`.
  - *정리 → GPX 트랙으로 위치 지정*: GPS 기록기·휴대폰의 `.gpx` 를 고르면 촬영 시각으로 트랙 위 위치를 찾습니다(두 지점 사이는 보간). 카메라 시계 차이(시·분)와 최대 간격을 정하고, 사진마다 미리 보기를 본 뒤 적용합니다.
  - *정리 → 주소 찾기*: GPS 가 있는 사진에 도시·시/도·국가·세부 장소를 채웁니다(OpenStreetMap, *설정 → 데이터* 에서 지도 사용을 켜야 함).
  - **XMP 사이드카**(설정 → 파일): 켜면 정리할 때 `사진이름.xmp` 를 써서 라이트룸·브리지·darktable 이 별점·레이블·키워드를 읽습니다. *JPEG 안에 넣기* 를 켜면 사이드카 대신 파일 안에 씁니다. 사진에 들어 있는 XMP 별점·키워드는 처음 볼 때 자동으로 가져옵니다.

## 5. 사람

- 왼쪽 **사람** 창의 *얼굴 찾기* (또는 *정리 → 얼굴 찾기*)로 지금 목록의 사진에서 얼굴을 찾습니다. 모든 처리는 컴퓨터 안에서 합니다(모델이 앱에 들어 있음).
- *이름 없는 얼굴* 을 누르면 얼굴마다 이름 칸이 있는 창이 뜹니다. 이미 이름을 붙인 사람과 닮은 얼굴에는 **이름이 제안**되고 ✓ 로 받아들입니다. ✕ 는 "얼굴이 아님".
- 사람 이름을 누르면 그 사람의 사진만 보입니다. 오른쪽 클릭으로 이름 바꾸기·삭제. 검색 `person:이름`.
- 보기 모드에서 **G** 를 누르면 얼굴에 상자와 이름이 보이고, 상자를 눌러 이름을 붙입니다.

### 이미지 분석 · 자동 분류

폴더를 열면 사진을 **백그라운드에서 분석**해 무엇이 찍혔는지 분류합니다. 분석은 별도 스레드(웹 워커)에서 하므로 목록을 넘기거나 사진을 보는 동안 화면이 느려지지 않고, 진행 상황은 상태 막대에만 보입니다(*분석 중 12 / 40*).

- **인물**: 인물 사진(1명, 가까이) · 1명 · 2명 · 단체(3–5명) · 군중(6명 이상) · 사람 없음
- **장면·배경**: 해변 · 바다·물가 · 산·계곡 · 자연·숲 · 꽃 · 하늘 · 노을 · 눈 · 도시·건물 · 실내 · 야경·어두움 · 음식 · 문서·스크린샷 · 흑백
- **객체**: 동물(개·고양이·새·말·물고기·곤충·가축·야생 동물) · 탈것(자동차·버스·트럭·오토바이·자전거·기차·비행기·배) · 음식 · 주방용품 · 가구 · 식물 · 전자 기기 · 가전 · 스포츠 용품 · 소지품 · 거리 시설 · 책 · 생활용품

왼쪽 **카탈로그** 창의 *이미지 분석 (자동 분류)* 에 분류별 사진 수가 보이고, 누르면 그 분류의 사진만 보입니다(Ctrl+클릭으로 "단체 + 해변" 처럼 조합). 오른쪽 **속성** 창의 *분석* 에 그 사진의 분류와 알아본 것(예: seashore, dog)이 보입니다.

- *도구 → 이 폴더 분석·자동 분류* 로 바로 분석, *다시 분석* 으로 고른 사진을 새로, *분석 중지* 로 멈춥니다. 한 번 분석한 사진은 파일이 바뀌지 않는 한 다시 하지 않습니다.
- *도구 → 분류별로 모아서 보기…* : 인물·장면·객체 중 기준을 고르면 그 분류의 사진만 목록으로 모읍니다. 미리 보기에 분류별 장수가 나옵니다. 파일은 원래 폴더에 그대로 있고, 폴더를 만들거나 복사·이동하지 않습니다. 대시보드 왼쪽의 **분류** 단추로도 같은 목록을 엽니다.
- 자동 분석은 *설정 → 데이터* 에서 끌 수 있습니다.
- 모든 처리는 컴퓨터 안에서 합니다: MobileNet v2(ImageNet 1000 가지)와 SSDLite(COCO 80 가지 사물·사람) 모델, 색 통계(하늘·모래·초록·노을·어둠·종이와 글자). 모델은 앱에 들어 있습니다.

## 6. 비공개 폴더

*파일 → 비공개 폴더*:

- **열기**: 처음에는 암호를 정합니다. 사진은 암호로 만든 키(AES-GCM)로 암호화해 앱 데이터에 보관합니다. 암호를 잊으면 열 수 없습니다.
- **선택한 사진을 옮기기**: 원본은 지워지고 비공개 폴더에만 남습니다.
- **복원**: 비공개 폴더에서 고른 사진을 원하는 폴더로 꺼냅니다.
- **잠그기**: 다시 열 때 암호를 묻습니다.

## 7. 찾기

빠른 검색 칸(Ctrl+F)이나 **검색 창**에서:

```text
바다 "빨간 차" -밤                  단어·구절, - 는 제외
rating:3   rating:>=4   label:red   tagged   is:edited
kw:바다   kw:장소|한국   cat:People/Family   person:민지
camera:canon   lens:24-70   ext:jpg   iso:>=1600   has:gps   is:raw   is:video
date:2024   date:2024-05   date:2024-01..2024-06
```

검색 창의 *검색 저장* 으로 카탈로그 창의 **저장된 검색**에 남깁니다. **달력** 창은 촬영일(없으면 파일 날짜)로, **지도** 창은 GPS 로 찾습니다. 지도를 오른쪽 클릭하면 선택한 사진을 그 위치로 지정합니다(파일 목록에서 지도로 끌어 놓아도 됨).

| 끌기 | 확대한 사진 이동 (확대하면 오른쪽 아래 **내비게이터**에서 위치를 보고 끌어 옮김) |
| L | 돋보기(커서 주위를 크게) |

| G | 얼굴 표시 |

도구 모음의 **− 배율 +** 로 축소·확대하고 가운데에 지금 배율이 보입니다. **I** 와 도구 모음의 정보 단추로 촬영 정보 패널을 켜고 끄며, 패널의 `>` · `<` 로 접습니다. 아래 **필름 스트립** 은 가운데로 모이고, 양쪽 **◀ ▶** 로 이전·다음 사진으로 갑니다(휠로 스트립을 옆으로 넘김). 스트립에는 사진과 함께 하위 폴더와 상위 폴더가 폴더 아이콘과 그 폴더 이름으로 보입니다. 폴더를 누르면 보기 모드를 유지한 채 그 폴더로 들어가고, 화살표 키는 사진 사이에서만 움직입니다. 상태 막대에 커서 아래 픽셀의 좌표와 RGB 값, 내장 색 프로필(ICC)이 보입니다. **동영상**: 재생 컨트롤은 처음부터 동영상 폭에 맞게 그려지고, 재생·일시 정지 때 ▶ / ❚❚ 가 잠깐 보였다 사라지며 멈춰 있는 동안은 *일시 정지* 표시가 남습니다. 도구 모음에서 반복·소리·재생 속도·화면 보기(창에 맞춤·실제 크기·창 채우기)를 바꾸고(*설정 → 동영상* 에 자동 재생·컨트롤·음량·이어 보기·끝나면 다음), **프레임 저장** 으로 지금 장면을 JPEG 로, **동영상 자르기** 로 시작·끝 사이만 새 WebM 으로 저장합니다. 큰 RAW·TIFF·PDF 처럼 여는 데 시간이 걸리는 사진은 상태 막대에 불러오는 중이라고 표시됩니다.

**DICOM(의료 영상, .dcm)** 을 열면 DICOM 도구 막대가 나옵니다.

- **윈도/레벨**: 파일에 든 윈도와 촬영 종류별 미리 설정(CT: 뇌·경막하·뇌졸중·연조직·간·종격동·폐·뼈), 중심(C)·폭(W) 입력, 끌어서 조절하는 도구(좌우 = 폭, 상하 = 중심), 되돌리기
- **표시**: 반전, 색상표(회색·핫 아이언·PET·제트·무지개·뼈 …), VOI LUT 와 함수(LINEAR·LINEAR_EXACT·SIGMOID), 오버레이 평면
- **프레임**: 여러 프레임 영상은 슬라이더(휠로도)·이전/다음(↑ ↓)·**시네 재생** — 파일의 프레임 시간 또는 1…120 fps, 반복·왕복·한 번. 윈도 미리 설정에 *자동(값 범위로)* 도 있습니다
- **측정**: 거리(두 번 클릭 또는 끌기), **각도**(점 세 개를 차례로 클릭 — 첫 변의 끝, 꼭짓점, 둘째 변의 끝; 첫 변을 끌어도 됨), **Cobb 각**(두 선, 클릭 또는 끌기), 사각형·타원 ROI 통계(평균·표준 편차·최소·최대·면적). 길이 단위는 *설정 → 뷰어* 에서 mm·cm·inch. 측정은 그 프레임에 속하고, 도구 막대의 **실행 취소·다시 실행**(비어 있으면 흐림)과 Ctrl+Z / Ctrl+Y 로 되돌리기, Del 로 마지막 것 삭제. 왼쪽·오른쪽 회전 단추는 직각과 호 모양이라 실행 취소와 구분됩니다. 그리는 동안 포인터는 + 입니다
- **축척**: 창의 위·왼쪽 가장자리를 따라 **X·Y 눈금자**(축 전체, 그림의 왼쪽 위가 0, 확대·이동을 따라감, 커서 위치 표시), 끌어서 옮기는 **축척 막대**(두 번 클릭하면 제자리), **− 배율 +** 단추(도구 모음의 배율과 함께 바뀜)와 축척 비율(1 px = … mm, 화면 1:N), **1:1** 실제 크기. 눈금자·축척·정보 표시는 각각 켜고 끄며 기억됩니다
- **격자**: *격자 ON/OFF* 단추(또는 D)로 옅은 격자를 켜고 끕니다. 눈금자와 같은 간격의 정사각형이고, 한 칸 안이 5×5 입니다. 선은 옅어서 그림이 비치고, 확대·축소·이동을 눈금자와 같이 따라갑니다
- **점선**: 포인터 위치에 붉은 점선 십자를 그립니다(*점선 ON/OFF* 또는 X). 포인터는 언제나 + 이고, 점선을 꺼도 + 는 남습니다. 프레임 번호 칸의 너비는 재생 중에도 바뀌지 않습니다. 언어를 바꿔도 보고 있는 그림·배율·프레임은 그대로입니다
- **단축키**: R 거리 · A 각도 · C Cobb · T 사각형 · E 타원 · L 윈도 끌기 · Esc 도구 끝(그리던 측정 취소), I 반전 · W 윈도 되돌리기 · M 다음 색상표 · V 오버레이, G 눈금자 · B 축척 막대 · O 정보 · D 격자, ↑↓ Home End 프레임, Space 시네. Ctrl+끌기나 가운데 단추 끌기는 어떤 도구에서나 윈도 조절
- **정보**: 네 귀퉁이에 환자·검사·시리즈·윈도·프레임·배율, 가장자리에 방향(R·L·A·P·H·F), 커서 아래 실제 값(CT 는 HU), **DICOM 태그** 창에서 모든 태그를 찾아보기
- **저장**: ⤓ 단추로 **프레임 내보내기** 창 — 보이는 프레임 또는 모든 프레임(폴더)을 앱이 쓸 수 있는 **모든 형식**(JPEG·PNG·WebP·BMP·TIFF·GIF·JPEG 2000·JPEG XL·PSD·PDF·DICOM·ICO·TGA·QOI·PPM·PCX·SGI·RAS·DDS·HDR·XBM·16비트 TIFF/PNG)으로, 품질도 고릅니다(화면의 윈도·색상표·반전 그대로). 모든 프레임을 **동영상(WebM)** 으로, 태그를 JSON·CSV·TXT 로(태그 창의 *복사* 는 클립보드로)
- **예제**: 실제 움직이는 DICOM — `samples/cine_us_echo_color_120f.dcm`(컬러 도플러 심장 초음파, 120프레임), `samples/cine_us_echo_30f.dcm`(심장 초음파, 30프레임), `samples/cine_mr_10f.dcm`(MR, 10프레임; pydicom 시험 자료). 만든 예제 `samples/cine_heart.dcm`·`samples/cine_phantom.dcm`(`node scripts/make-samples.mjs`). 열고 ▶ 를 누르면 움직입니다. 컬러 영상에는 윈도/레벨·색상표가 나오지 않습니다

압축된 DICOM(JPEG·JPEG 12비트·무손실 JPEG·JPEG-LS·JPEG 2000·RLE, 빅 엔디언·Deflate)도 열립니다.

## 9. 편집 모드

왼쪽 패널의 각 항목을 펼쳐 조정합니다. 슬라이더를 **두 번 클릭하면 0으로**, 항목 제목의 **↺** 는 그 항목을 원본 값으로 되돌립니다. 히스토그램 바로 아래의 **색상 휠** 세 개(어두운·중간·밝은 영역)는 점을 끌어 그 영역에 색을 더합니다(방향 = 색, 거리 = 세기, 두 번 클릭 = 원래대로).

- **밝기**: 자동 보정, 노출(EV)·밝기·대비·밝은 영역·어두운 영역·흰색·검정·안개 제거. RAW 는 LibRaw 로 현상하고 화이트 밸런스(카메라·자동·주광)를 고릅니다.
- **색상**: 화이트 밸런스 **스포이트**(회색이어야 할 곳을 클릭), 색온도·색조·채도·생동감·색상환
- **Color EQ**: 빨강·주황·노랑·초록·청록·파랑·보라·자홍 색역별 색상·채도·밝기 / **Light EQ**: 어두운 곳부터 밝은 곳까지 9단계 밝기 / **스플릿 토닝**: 밝은 영역·어두운 영역 색과 균형
- **레벨**: 자동 레벨, 검정 점·감마·흰 점 / **톤 곡선**: RGB 또는 채널별, 끌어서 점 추가·이동, 점을 두 번 클릭하면 삭제
- **디테일**: 선명하게(반경)·명료도·노이즈 감소·흐림
- **렌즈**: 왜곡·색수차·주변부 밝기, **원근**: 세로·가로 기울기·회전
- **자르기·기하**: 회전·뒤집기, 수평 맞추기(슬라이더 또는 **선 긋기** — 수평이어야 할 선을 따라 끌기), 자르기(자유·원본 비율·1:1·4:3·3:2·16:9 …, 손잡이로 조절, Enter 로 적용), 크기 조절, **캔버스 크기**(위치·배경색)
- **부분 보정**: 그러데이션·방사형·브러시, **올가미**(둘러 그리기)·**자동 선택**(비슷한 색의 이어진 영역)·**색상 범위**(픽셀 타기팅: 누른 색과 같은 색상·채도·밝기 범위의 모든 픽셀)로 영역을 정하고 그 안에만 노출·대비·채도·색온도·선명도 등 적용. 반전·경계 부드럽게. 여러 개를 겹칠 수 있습니다.
- **LUT**: 내장 룩(틸 & 오렌지·따뜻한 필름·차가운 페이드·흑백 필름·고대비)이나 `.cube` 파일(1D·3D)을 강도와 함께
- **보정**: 적목 제거·잡티 제거·**복제 도장**(Alt+클릭으로 원본 위치, 클릭으로 칠하기)·**내용 인식 지우기**(없앨 부분을 칠하면 주변 모양으로 채움)·피부 보정 — 브러시 크기·경도
- **효과**: 흑백·세피아 등 기본 효과와 강도, 비네팅·그레인·모자이크·엠보스·윤곽선, **특수 효과**(유화·연필 스케치·컬러 스케치·카툰·수채화·로모·글로우·하프톤·오래된 사진 등 22가지를 쌓아서), **틸트시프트**
- **그리기**: 선·화살표·사각형·타원·자유선(색·굵기·채우기)
- **텍스트·테두리**: 워터마크 문구(글꼴·색·크기·불투명도·그림자, 사진을 클릭해 위치), 테두리 두께·색
- **레이어**: 다른 사진을 위에 얹고 혼합 모드(곱하기·스크린·오버레이 등 16가지)·불투명도·크기·위치. **조정 레이어**(아래 전체에 노출·대비·채도·색온도…), 레이어마다 **마스크**(위/아래/왼쪽/오른쪽 그러데이션·가운데 타원·브러시로 칠하기, 반전)
- **프리셋**: 지금 설정을 이름 붙여 저장하고 다른 사진에 한 번에 적용. *설정 복사*(Ctrl+Shift+C)·*붙여넣기*(Ctrl+Shift+V)
- **기록**: 지금까지의 단계 목록. 단계를 누르면 그때로 돌아갑니다. **스냅숏**(Ctrl+Shift+N)은 지금 설정을 이름으로 저장해 두고 눌러서 되돌아갑니다.
- **16비트 사진**(16비트 PNG·TIFF): 정보 줄에 *16비트* 가 보이고, 톤·색 보정을 정밀 사본으로 계산해 크게 밝혀도 띠가 생기지 않습니다. 저장하면 16비트 그대로 남습니다(TIFF/PNG 16-bit 형식도 있음).
- **작업에 기록**(프리셋 항목): 지금 설정을 일괄 작업의 한 단계로 넣습니다.

툴바: **저장**(Ctrl+S, 원본에 덮어씀), **다른 이름으로 저장**(Ctrl+Shift+S: JPEG·PNG·WebP·BMP·TIFF·GIF·JPEG 2000·JPEG XL·PSD·PDF·DICOM·ICO·TGA·QOI·PPM·PCX·SGI·Sun RAS·DDS·Radiance HDR·XBM, 품질), **완료**, 실행 취소/다시 실행(Ctrl+Z / Ctrl+Y), **전/후**(B), 모두 초기화.
JPEG 로 저장하면 원래 사진의 EXIF·XMP·ICC 가 그대로 남습니다(방향은 바로 세운 상태로, 옛 썸네일은 지움).
데스크톱에서 원본에 덮어쓰면 처음 한 번 원본을 따로 보관하고 편집 설정도 기억합니다. 다시 편집하면 **원본과 설정으로 열지** 묻습니다 — 그러면 보정이 겹치지 않고 이전 설정을 고칠 수 있습니다(비파괴 재편집). *편집 → 원본 복원* 으로 되돌립니다. 웹에서 읽기 전용 폴더의 사진은 편집 결과를 내려받습니다.

## 10. 만들기 (만들기 메뉴)

- **PDF**: 한 쪽에 한 장, 용지(사진 크기·A4·Letter)·방향·여백·품질·제목.
- **애니메이션 GIF**: 긴 변·프레임 간격·반복·디더링.
- **슬라이드 쇼 내보내기**: WebM 동영상(크기·간격·페이드·**배경 음악** — Opus 소리 트랙) 또는 혼자 열리는 HTML 파일(음악 포함).
- **파노라마**(2장 이상 선택): *자동* 은 특징점을 맞춰 **원근을 보정**(카메라를 돌려 찍은 사진)하고, 맞지 않으면 이동만으로 이어 붙입니다.
- **HDR**(노출이 다른 2장 이상): 정렬 후 노출 합성.
- **초점 스태킹**(초점이 다른 2장 이상): 사진마다 선명한 부분을 모읍니다.
- **ZIP 보관함**: 선택한 파일을 ZIP 하나로.
- 인쇄·밀착 인화, 바탕 화면 배경.

## 11. 일괄 처리 (도구 메뉴 · 오른쪽 클릭 → 일괄 처리)

- **일괄 작업(Actions)**: 편집 설정·자동 레벨·워터마크·회전·크기·별점·키워드·저장 형식 단계를 순서대로 묶어 이름으로 저장하고 여러 사진에 다시 실행합니다.
- **이름 바꾸기**: 템플릿 `*`(원래 이름) `###`(번호, # 개수만큼 자리) `{date:YYYYMMDD_HHmmss}`(촬영일) `{camera}` `{w}` `{h}` `{folder}` `{rating}` `{ext}`, 시작 번호, 대소문자, 찾아 바꾸기(정규식). 미리 보기에서 중복·이미 있는 이름이 빨갛게 보이면 실행되지 않습니다. 서로 이름을 맞바꾸는 경우도 안전하게 처리합니다.
- **크기 조절**: 긴 변 픽셀 · 너비×높이 안에 맞추기 · 백분율, 형식·품질, 저장 위치(원본 바꾸기 / 이름 뒤에 붙여 새 파일 / 다른 폴더).
- **형식 변환**: JPEG·PNG·WebP·BMP·TIFF (원본은 남기거나 휴지통으로).
- **일괄 보정**: 사진마다 자동 레벨, 노출·대비·채도·선명하게, 흑백/세피아.
- **워터마크**: 문구·위치·크기·불투명도·색.
- **프리셋 적용**: 저장한 프리셋이나 복사한 편집 설정을 여러 장에(*편집 → 설정 붙여넣기* 도 같음).
- **날짜·시간 변경**: 일·시간·분만큼 옮기기(카메라 시계가 틀렸을 때) 또는 지정한 시각으로. JPEG 의 EXIF 날짜를 직접 고치고(재압축 없음), 파일 수정 시각도 바꿀 수 있습니다.
- **파일 날짜 ← 촬영일**: 파일 수정 시각을 EXIF 촬영일로.
- **회전·뒤집기**: JPEG 는 EXIF 방향만 바꾸는 무손실 회전, 다른 형식은 다시 저장. **EXIF 기준 자동 회전** 은 방향 표시만 있는 JPEG 의 픽셀을 실제로 돌려 저장합니다.

## 12. 그 밖의 도구

- **비교**(2–4장 선택): 확대·이동이 함께 움직이고, 다른 촬영 정보는 노랗게 표시. 그 자리에서 별점·삭제.
- **중복 사진 찾기**: 현재 목록 또는 폴더 트리에서 *똑같은 파일*(내용 해시) 또는 *비슷한 사진*(크기를 바꾸거나 다시 저장한 것). 그룹마다 가장 큰 사진만 남기고 나머지를 삭제 표시합니다.
- **슬라이드 쇼**(Ctrl+Shift+S, 보기 모드의 S): Space 일시 정지, ←→ 이동, Esc 끝. 간격·전환(페이드·밀어내기·켄 번스)·무작위·반복·설명은 설정에서.
- **인쇄 / 밀착 인화**(Ctrl+P): 왼쪽에 설정, 오른쪽에 쪽 미리 보기(설정을 바꾸면 바로 바뀜, `<` `>` 로 쪽 넘김).
  - 프린터·매수·컬러/흑백·양면
  - 용지(A3·A4·A5·B5·Letter·Legal·Tabloid·4×6·5×7·8×10·사용자 지정 mm)·방향(자동·세로·가로)
  - 배치(한 쪽에 한 장·2×2·3×3·밀착 인화·지갑 크기 또는 열×행)·간격·사진 전체/채우기·칸에 맞춰 회전·테두리
  - 위·아래·왼쪽·오른쪽 여백
  - 파일 이름·날짜·별점, 머리글, 바닥글, 쪽 번호
  - 출력: **인쇄** 를 누르면 미리 보기 창 없이 바로 프린터로 보냅니다(데스크톱). PDF·JPEG·PNG 로 저장할 수도 있습니다. 마지막 설정은 기억합니다.
- **공유**: *파일 → 공유* 는 시스템 공유 창(있으면) 또는 사진 이름이 적힌 새 메일과 파일 위치를 엽니다. *이미지 복사*(Ctrl+Shift+C)는 사진을 클립보드에 넣습니다.
- **연결 프로그램 선택**, **기본 프로그램으로 열기**, **탐색기에서 보기**, **바탕 화면 배경으로 지정** (데스크톱).
- **외부 편집기**(*편집 → 외부 편집기로 편집*): Photoshop·GIMP 같은 프로그램을 등록하고 선택한 사진을 넘깁니다. Ctrl+Shift+E 는 첫 번째 편집기. 돌아오면 썸네일을 새로 만듭니다.
- **작업 공간**(*보기 → 작업 공간*): 패널·탭·폭·보기 방식·정렬을 이름으로 저장하고 Ctrl+Alt+1…9 로 바꿉니다. *기본 배치* 로 돌아갑니다.
- **슬라이드 쇼 배경 음악**: *설정 → 슬라이드 쇼* 에서 음악 파일과 음량을 고르면 쇼 동안 반복 재생되고 일시 정지와 함께 멈춥니다.

## 13. 설정

- 일반: 언어(국기 단추: 시스템/한국어/English), 시작할 때 열 폴더
- 테마: 시스템·사용자 정의·어두운 20·밝은 20 을 미리 보기 카드로(누르면 바로 보이고 취소하면 돌아감), 사용자 정의 테마 편집
- 탐색: 숨김 파일, 사진이 아닌 파일, 하위 폴더 표시, 썸네일 캡션과 아이콘
- 뷰어: 마우스 휠 동작, 작은 사진 키우기, 확대 시 부드럽게, 길이 단위(mm·cm·inch), 색 관리(내장 ICC 프로필을 sRGB 로)
- 동영상: 자동 재생, 반복, 소리 없이 시작, 컨트롤, 이어 보기, 끝나면 다음, 음량, 속도, 화면 보기
- 슬라이드 쇼: 간격·전환·무작위·반복·설명·배경 음악·음악 크기
- 파일: 삭제 전 확인, 휴지통 사용, JPEG 품질, XMP 사이드카, JPEG 안에 메타데이터 넣기
- 데이터·개인 정보: 지도 타일 사용(끄면 인터넷 요청 없음 — 주소 찾기도 꺼짐), 썸네일 캐시 지우기, 카탈로그 내보내기/가져오기/비우기

데이터 위치 — 데스크톱: `%APPDATA%\com.shkwon.myphotomanager`(Windows), `~/Library/Application Support/com.shkwon.myphotomanager`(macOS), `~/.local/share/com.shkwon.myphotomanager`(Linux)의 `catalog.sqlite`(카탈로그, 사진마다 한 줄 — 예전 `catalog.json` 은 처음 실행 때 옮겨짐)·`settings.json`·`originals/`·`thumbnails/`·`mtp/`(기기에서 복사한 사진). 썸네일 캐시와 비공개 폴더는 WebView 저장소(IndexedDB). 웹: 브라우저의 IndexedDB.

## 14. 지원 형식

JPEG·PNG·GIF·WebP·BMP·TIFF(여러 페이지)·HEIC/HEIF·AVIF·PSD·SVG·ICO·DICOM(.dcm, 여러 프레임·압축 포함)·카메라 RAW(DNG·CR2·CR3·NEF·ARW·ORF·RW2 등 — 미리 보기 또는 LibRaw 현상), JPEG 2000(JP2·J2K), JPEG XL, TGA·PCX·PNM(PBM/PGM/PPM/PAM)·Radiance HDR·DDS·SGI·Sun RAS·XBM·QOI, PDF(쪽마다 보기), 동영상(MP4·WebM·MOV 등 — 시스템이 재생할 수 있는 것), ZIP·CBZ(폴더처럼). 전체 목록은 *도움말 → 프로그램 정보* 에 있습니다. TIFF·PSD 의 내장 ICC 프로필은 sRGB 로 변환해 보여 줍니다.

**저장(다른 이름으로 저장·형식 변환)**: JPEG·PNG·WebP·BMP·TIFF·GIF·JPEG 2000·JPEG XL·PSD·PDF·DICOM·ICO·TGA·QOI·PPM·PCX·SGI·Sun RAS·DDS·Radiance HDR·XBM, TIFF·PNG 16비트. HEIC·AVIF 는 읽기만 합니다(브라우저 엔진에 이 형식의 인코더가 없음). 원본에 덮어쓰기는 JPEG·PNG·WebP·BMP·TIFF 만 합니다(다른 형식은 새 파일로).

도움말 → 단축키(F1)에서 전체 목록을 볼 수 있습니다. *도움말 → 단축키 바꾸기* 에서 관리·보기·편집 모드 명령의 단축키를 다시 지정합니다(칸을 누르고 새 키 조합을 누름, ↺ 기본값, ✕ 없음). 같은 키를 두 명령에 주면 빨갛게 표시됩니다.
