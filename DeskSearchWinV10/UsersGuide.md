# DeskSearch — 사용자 가이드

이 문서는 **DeskSearch**를 처음 사용하는 분을 위한 안내입니다. 개발·빌드 정보는 [README.md](README.md)를 참고하세요.

---

## 1. 프로그램 소개

DeskSearch는 Windows용 **데스크톱 파일·폴더 검색 위젯**입니다.

- 화면 상단에 작은 검색창이 항상 표시됩니다.
- PC에 연결된 **모든 드라이브**(고정, 이동식, 네트워크, CD/DVD 등)의 **파일과 폴더**를 백그라운드에서 인덱싱합니다.
- **인덱싱이 진행 중이어도** 검색할 수 있으며, 인덱스가 늘어나면 결과가 자동으로 갱신됩니다.
- 검색어를 입력하면 **파일·폴더 이름**에 검색어가 **연속으로 포함**된 항목이 실시간으로 표시됩니다 (경로는 검색 대상 아님).
- 일치 항목이 없으면 **「일치하는 항목이 없습니다.」** 안내가 표시됩니다.
- **한국어, 영어, 일본어, 중국어** 등 파일·폴더 이름은 화면 언어와 관계없이 검색할 수 있습니다.
- **정규식**으로 파일·폴더 **이름**을 검색할 수 있습니다 (설정에서 활성화). 경로는 검색 대상이 아닙니다.
- **`*(AND)·`+(OR)`** 검색 연산자를 지원합니다 (앞뒤 공백 필요).
- **검색 결과 정렬**을 설정에서 선택할 수 있습니다 (일치도, 이름, 경로, 폴더/파일 우선 등).
- 결과를 클릭하거나 Enter 키로 탐색기에서 바로 열 수 있습니다.
- **작업 표시줄에는 아이콘이 나타나지 않습니다.** 알림 영역(시스템 트레이)에만 상주합니다.
- 프로그램은 **한 번에 하나만** 실행됩니다. 이미 실행 중일 때 다시 실행하면 기존 검색창이 표시됩니다.

## 2. 설치 및 실행

### MSI로 설치한 경우

1. 설치 파일을 실행합니다.
   - **DeskSearchSetup.msi** — 설치 화면 한국어
   - **DeskSearchSetup.en-US.msi** — 설치 화면 English
2. 안내에 따라 설치합니다. 기본 설치 경로: `C:\Program Files\DeskSearch\`
3. 설치 파일 크기는 약 **52MB**이며, .NET 런타임을 별도로 설치할 필요가 없습니다(self-contained).
4. 설치 화면에서 **바탕화면 바로가기**, **시작 메뉴 바로가기**를 각각 선택하거나 해제할 수 있습니다.
5. 이미 설치된 버전을 **업그레이드·재설치**할 때는 기존 프로그램을 **완전히 제거**한 뒤 새로 설치하며, **사용자 데이터(설정·검색 인덱스 등) 삭제 여부**를 선택할 수 있습니다.
6. 설치 후 **DeskSearch.exe**를 실행합니다.

### 프로그램 제거

1. Windows **설정 → 앱 → 설치된 앱**에서 DeskSearch를 선택하고 제거합니다.
2. 제거 과정에서 **사용자 데이터 삭제 여부**를 선택할 수 있습니다.
3. **사용자 데이터 삭제**를 선택하면 `%AppData%\DeskSearch\` 폴더(`settings.json`, `index.db` 등)가 삭제됩니다.
4. 체크하지 않으면 프로그램만 제거되고 사용자 데이터는 유지됩니다.

### 개발 빌드로 실행한 경우

```bash
dotnet run --project DeskSearch/DeskSearch.csproj
```

또는 `DeskSearch\bin\Debug\net8.0-windows\DeskSearch.exe`를 직접 실행합니다.

### 관리자 권한

DeskSearch는 전체 디스크를 검색하기 위해 **관리자 권한**으로 실행됩니다. 처음 실행 시 Windows **UAC(사용자 계정 컨트롤)** 승인 창이 표시될 수 있습니다. **예**를 선택해야 인덱싱이 정상적으로 진행됩니다.

### 시스템 요구사항

| 항목 | 내용 |
|------|------|
| OS | Windows 10 이상 |
| 권한 | 관리자 권한 (UAC 승인) |
| 런타임 | MSI 설치본은 .NET 런타임 불필요 (self-contained) |
| 디스크 | 검색 인덱스는 `%AppData%\DeskSearch\index.db`(SQLite)에 저장. 파일·폴더 수에 따라 용량·RAM 사용량이 달라짐 |

## 3. 화면 구성

```
┌──────────────────────────────────────────────┐
│  ≡   🔍  [ 검색어 입력...              ]  ⚙ │
├──────────────────────────────────────────────┤
│  📁 Documents                                │  ← 폴더 (파란 아이콘)
│     C:\Users\사용자                            │
│  report.pdf                                  │  ← 파일
│     C:\Users\사용자\Documents                 │
└──────────────────────────────────────────────┘
```

| 요소 | 설명 |
|------|------|
| **≡ (드래그 핸들)** | 마우스로 끌어 검색창 위치 이동 |
| **검색 상자** | 파일·폴더 이름 입력 (인덱싱 중에도 사용 가능) |
| **⚙ (설정)** | 설정 창 열기 |
| **결과 목록** | 일치 항목 표시 (최대 2,000건 수집; 창 높이는 1~10개에 맞게 자동 조절, 그 이상은 스크롤). 표시 순서는 설정의 **검색 결과 정렬**을 따름 |
| **폴더 아이콘** | 파란 폴더 아이콘이 붙은 항목은 디렉터리 |
| **좌·우 가장자리** | 드래그하여 검색창 **너비** 조절 (280 ~ 720px) |

## 4. 기본 사용법

### ① 검색

1. 프로그램을 실행합니다. 처음에는 **인덱싱 중** 상태입니다.
2. **인덱싱이 끝나기 전에도** 검색어를 입력할 수 있습니다. 이미 인덱싱된 항목부터 결과가 표시됩니다.
3. 인덱스가 계속 늘어나면 **같은 검색어의 결과도 자동으로 갱신**됩니다.
4. 인덱싱이 완전히 끝나면 전체 드라이브를 대상으로 검색합니다.

우클릭 메뉴 하단에 인덱스 상태가 표시됩니다.

같은 검색어로 대량의 파일을 탐색할 때는 **배치 단위로 순차 검색**합니다. 검색어를 바꾸면 **처음부터** 다시 검색합니다.

#### 검색 연산자 (간단 안내)

검색 대상은 **파일·폴더 이름**뿐입니다. 자세한 문법·예제는 [README.md — 검색 문법](README.md#검색-문법)을 참고하세요.

| 연산자 | 의미 | 예시 |
|--------|------|------|
| (없음) | 이름에 **연속으로 포함** | `report` → `my-report.pdf` |
| `*` (앞뒤 공백) | **AND** — 모두 포함 | `budget * 2024` |
| `+` (앞뒤 공백) | **OR** — 하나라도 포함 | `doc + pdf` |
| `*` `?` (검색어 안) | 와일드카드 (정규식 끔) | `*.pdf`, `report*` |

AND 연산자 `*`는 **앞뒤 공백**이 있을 때만 적용됩니다. `*.pdf`의 `*`는 와일드카드입니다.

연산자는 **앞뒤에 공백**이 있어야 합니다. `foo+bar`처럼 붙이면 일반 문자로 처리됩니다.

### ② 결과 열기

| 동작 | 파일 | 폴더 |
|------|------|------|
| **클릭** / **Enter** | 탐색기에서 해당 파일 위치 표시 | 폴더 열기 |
| **더블클릭** | 기본 프로그램으로 실행 | 폴더 열기 |

### ③ 키보드 단축키

| 키 | 동작 |
|----|------|
| **Enter** | 선택한 결과 열기 |
| **↓** | 검색 결과 목록으로 포커스 이동 |
| **↑** (목록 첫 항목) | 검색창으로 포커스 복귀 |
| **Esc** | 검색어 지우기 / 결과 닫기 |

## 5. 창 이동·크기

- **≡ 핸들**을 드래그하거나
- 검색어가 **비어 있을 때** 검색창 빈 영역을 드래그하거나
- 검색창 **바깥 테두리** 영역을 드래그

→ 창 **위치**를 변경할 수 있습니다.

- 검색창 **왼쪽·오른쪽 가장자리**를 드래그하면 **너비**를 조절할 수 있습니다.

위치·너비·높이는 자동으로 저장되며, 다음 실행 시(트레이에서 복원할 때 포함) 복원됩니다.

## 6. 우클릭 메뉴

검색창·결과 목록·드래그 핸들에서 **우클릭**하면 메뉴가 표시됩니다.

| 메뉴 | 설명 |
|------|------|
| **검색 초기화** | 검색어와 결과 목록 지우기 |
| **인덱스 새로고침** | 전체 인덱스를 처음부터 다시 구축 |
| **바탕화면 폴더 열기** | 탐색기에서 바탕화면 열기 |
| **위치 초기화** | 창을 화면 상단 중앙으로 이동 |
| **다른 프로그램보다 위** | 검색창을 항상 최상위에 표시 (체크) |
| **설정...** | 색상·언어·검색 옵션 설정 |
| **숨기기** | 검색창을 닫지 않고 **트레이로 숨김** |
| **종료** | 프로그램 완전 종료 |

검색 결과 항목에서 우클릭하면 **열기**, **폴더에서 보기**, **경로 복사**, **파일 이름 복사** 등 추가 메뉴가 표시됩니다.

## 7. 시스템 트레이

DeskSearch는 **작업 표시줄에 아이콘을 표시하지 않습니다.** 대신 **알림 영역(시스템 트레이)** 에 상주합니다.

| 동작 | 설명 |
|------|------|
| **창 닫기** (Alt+F4 등) | 종료하지 않고 **트레이로 숨김** |
| **트레이 아이콘 더블클릭** | 검색창 다시 표시 |
| **트레이 아이콘 우클릭** | 메뉴 표시 |

### 트레이 메뉴

| 메뉴 | 설명 |
|------|------|
| **검색창 표시** | 숨겨진 검색창 다시 열기 |
| **숨기기** | 검색창을 트레이로 숨김 |
| **설정...** | 설정 창 열기 |
| **종료** | 프로그램 완전 종료 |

> 프로그램을 완전히 끄려면 우클릭 메뉴 또는 트레이 메뉴에서 **종료**를 선택하세요.

## 8. 설정

검색창의 **⚙ 버튼** 또는 우클릭 메뉴 → **설정...** 에서 아래 항목을 변경할 수 있습니다.

### 검색

| 항목 | 설명 |
|------|------|
| **언어** | 한국어 / English. **선택 즉시** 화면·메뉴·트레이 문구가 바뀝니다. **저장**하면 다음 실행에도 유지되고, **취소**·창 닫기 시 변경 전 언어로 되돌아갑니다 |
| **대소문자 구분** | 켜면 검색어와 이름의 대·소문자가 정확히 일치해야 함 (기본: 끔) |
| **정규식 사용** | 켜면 검색어를 .NET 정규식으로 해석 (예: `^report.*\.pdf$`) |
| **검색 결과 정렬** | 결과 목록 표시 순서 (기본: **일치도**). 저장 후 같은 검색어로 다시 정렬됩니다 |

**검색 결과 정렬** 옵션:

| 옵션 | 설명 |
|------|------|
| **일치도** (기본) | 완전 일치 → 접두어 → 포함 순 (같으면 이름순) |
| **이름 (가→하 / 하→가)** | 파일·폴더 이름 기준 |
| **경로 (가→하 / 하→가)** | 전체 경로 기준 |
| **폴더 먼저, 이름순** | 폴더를 위에 모아 표시 |
| **파일 먼저, 이름순** | 파일을 위에 모아 표시 |

| 항목 | 설명 |
|------|------|
| **검색 제외 — 드라이브** | 체크한 드라이브는 인덱싱·검색에서 제외 |
| **검색 제외 — 디렉터리** | 추가한 폴더와 하위 항목은 인덱싱·검색에서 제외. **찾아보기**에서 폴더를 **여러 개 동시에 선택**하면 바로 목록에 추가됩니다 |

### 인덱싱

| 항목 | 설명 |
|------|------|
| **검색(인덱싱) 진행률** | 현재 단계(**스캔** / **분석** / **인덱스 적용**), 백분율(%), 항목 수 |
| **인덱싱** | 전체 인덱스를 **처음부터** 다시 구축 (`index.building.db` 삭제 후 시작). 진행 중에는 **멈춤**으로 중단 가능 |
| **멈춤** | 인덱싱 일시 중지. 진행 중이던 `index.building.db`는 보존됩니다 |
| **초기화** | 저장된 검색·인덱싱 DB(`index.db`, `index.building.db` 등) **전부 삭제** (확인 대화상자, 인덱싱 중 비활성). 삭제 후 **인덱싱** 버튼으로 다시 구축 |
| **데이터 폴더** | `%AppData%\DeskSearch\`를 탐색기에서 열기 (`settings.json`, `index.db` 등) |
| **인덱싱 주기** | 예약 전체 재동기화 주기 (사용 안 함, 1·4·8·12·24·168시간; 기본 8시간) |

인덱싱·재인덱싱 시 진행률은 **0%부터** 표시되며, 재인덱싱 중에는 상태 줄에 *「검색은 기존 인덱스 사용」* 안내가 나타날 수 있습니다.

### 기타

| 항목 | 설명 |
|------|------|
| **Windows 시작 시 자동 실행** | 로그인할 때 DeskSearch 자동 실행 (HKCU `Run` 레지스트리) |
| **배경색 / 테두리색 / 글자색** | 검색창 색상 프리셋 (밝은·어두운 톤) |
| **배경·창 불투명도** | 40~100% / 50~100% |
| **창 표시 우선순위** | 다른 프로그램보다 위 / 일반 우선 순위 |

파일·폴더 이름은 **모든 언어**로 검색할 수 있습니다. 화면 언어와는 별개입니다.

**어두운 배경색**을 선택하면 글자·테두리·아이콘 색이 자동으로 밝게 조정됩니다.

**언어**는 선택 즉시 반영됩니다. 그 외 항목은 **저장**을 누르면 적용됩니다. 검색 제외 설정이 바뀌면 인덱스가 자동으로 다시 구축됩니다. **검색 결과 정렬**을 바꾼 뒤 저장하면, 검색어가 그대로일 때 결과 목록이 새 순서로 다시 표시됩니다.

설정 파일·검색 인덱스 위치:

```
%AppData%\DeskSearch\
├── settings.json          ← 설정
├── index.db               ← 검색용 인덱스 (live)
└── index.building.db      ← 인덱싱 중 임시 빌드 (완료 후 index.db로 교체)
```

## 9. 인덱싱 안내

### 인덱스 저장 위치

검색 인덱스는 **SQLite 데이터베이스**로 `%AppData%\DeskSearch\`에 저장됩니다.

| 파일 | 역할 |
|------|------|
| `index.db` | **완료된** 검색용 인덱스. 전체 인덱싱이 성공한 뒤에만 존재 |
| `index.building.db` | **인덱싱 중** 임시 빌드 DB. 완료되면 `index.db`로 교체됨 |

### 첫 실행·초기화 vs 재인덱싱

| 상황 | 동작 |
|------|------|
| **첫 실행**(완료된 `index.db` 없음) | `index.building.db`에 구축. **검색은 구축 중 DB** 사용 |
| **초기화** 후 | 검색·인덱싱 DB **전부 삭제**. **인덱싱** 버튼으로 다시 시작 |
| **재인덱싱**(완료된 `index.db` 있음) | 새 데이터는 `index.building.db`에 기록. **검색은 기존 `index.db`만** 사용. 완료 후 한 번에 교체 |

재인덱싱 중에는 live 인덱스를 수정하지 않으므로, 긴 재인덱싱이 진행되어도 **검색 결과가 끊기지 않습니다**.

### 멈춤·종료·다시 시작

| 동작 | 설명 |
|------|------|
| **멈춤** | 스캔을 일시 중지합니다. `index.building.db`에 진행 내용이 남습니다 |
| **인덱싱** | building DB를 **삭제**한 뒤 **처음부터** 전체 스캔을 시작합니다 |
| **프로그램 종료**(인덱싱 중) | building DB는 디스크에 남깁니다. `index.db`가 있으면 그동안 **기존 인덱스로 검색** 가능 |
| **다음 실행** | 이전 building DB는 **삭제**됩니다. 중단된 인덱싱이 있었으면 **자동으로 전체 재스캔**을 시작합니다 |

> **인덱싱** 버튼은 이어하기가 아니라 **처음부터 다시 구축**입니다. 멈춘 뒤 같은 세션에서 이어하려면 별도 재개 버튼은 없으며, **인덱싱**을 누르면 building DB가 삭제되고 처음부터 시작합니다.

### 스캔 실패·재시도

- 특정 드라이브나 폴더에서 오류가 나도 **다른 드라이브는 계속** 인덱싱됩니다.
- 실패한 루트는 완료 처리되지 않으며, 같은 스캔 패스 안에서 **최대 3회** 자동 재시도합니다.
- 그래도 끝나지 않으면 **8초 후** 전체 스캔을 다시 시도합니다.
- 모든 루트가 성공해야 `index.db`로 **교체(promote)** 됩니다.

### 진행 단계 (설정 창)

전체 재인덱싱 시 설정 창에서 아래 단계를 확인할 수 있습니다.

| 단계 | 설명 |
|------|------|
| **스캔** | 드라이브·폴더를 순회하며 파일·폴더 이름 수집 |
| **분석** | 검색 속도를 위한 통계·FTS 최적화 |
| **인덱스 적용** | 빌드 DB를 live `index.db`로 교체 (재인덱싱 시에만) |

### 인덱스 범위

- 바탕화면, 문서, 다운로드, OneDrive 등 **우선 폴더**를 먼저 스캔한 뒤
- Windows가 인식하는 **모든 준비된 드라이브**를 백그라운드에서 스캔합니다.
- 설정의 **검색 제외**에 지정한 드라이브·폴더는 스캔하지 않습니다.

### 스캔 범위

접근 가능한 **모든 하위 디렉터리**와 **모든 파일**을 재귀적으로 검토합니다.

Windows 권한으로 열 수 없는 경로(예: `$Recycle.Bin`, `System Volume Information`)만 자동으로 건너뜁니다. **관리자 권한**으로 실행되며, **긴 경로**(260자 초과)도 지원합니다.

### 인덱싱 중 검색

- 인덱싱이 **완료되기 전에도** 검색할 수 있습니다.
- 아직 인덱싱되지 않은 파일·폴더는 결과에 나타나지 않습니다.
- 인덱스가 업데이트되면 **입력 중인 검색어의 결과도 자동 갱신**됩니다.
- 인덱싱이 완료되면 전체 드라이브를 대상으로 검색합니다.

### 갱신

- 모든 드라이브에서 파일·폴더 **생성·삭제·이름 변경**을 자동 감시합니다 (live `index.db`에 반영).
- **설정 가능한 주기**마다 전체 드라이브를 **전체 재스캔**합니다 (기본 8시간, **사용 안 함** 가능).
- 전체 재스캔이 필요하면 메뉴 → **인덱스 새로고침** 또는 설정 → **인덱싱**을 사용하세요.

인덱싱은 여러 드라이브를 **동시에(병렬로)** 스캔하며, Windows의 백그라운드 모드(CPU·디스크 I/O·메모리 우선순위 하향)를 사용해 인덱싱이 진행되는 동안에도 검색창과 시스템 전반의 반응성이 거의 영향받지 않도록 설계되어 있습니다. 다만 대용량 드라이브(예: `C:\`)는 **수십 분~수 시간**이 걸릴 수 있습니다.

**인덱싱**을 누르면 진행률은 0%부터 다시 표시됩니다. 인덱싱 중 **멈춤**으로 중단할 수 있습니다. 인덱싱이 **끝나기 전에 프로그램을 종료**하면 building DB는 남지만, **다음 실행 시 삭제된 뒤 자동으로 전체 재스캔**이 시작됩니다.

## 10. 자주 묻는 질문

### Q. 검색창이 보이지 않아요.

트레이(알림 영역)의 DeskSearch 아이콘을 **더블클릭**하거나, 우클릭 → **검색창 표시**를 선택하세요.

### Q. 인덱싱 중에 검색할 수 있나요?

네. **인덱싱이 진행 중이어도** 검색할 수 있습니다. 이미 인덱싱된 항목부터 결과가 표시되고, 인덱스가 늘어나면 결과가 갱신됩니다. 전체 드라이브 검색은 인덱싱 완료 후 가장 정확합니다.

### Q. 검색 결과가 점점 늘어나요.

인덱싱이 아직 진행 중이면 정상입니다. 새로 인덱싱된 파일·폴더가 검색 결과에 추가됩니다.

### Q. UAC(관리자 승인) 창이 뜹니다.

전체 디스크 검색을 위해 관리자 권한이 필요합니다. **예**를 선택해 주세요.

### Q. 검색이 안 됩니다.

인덱싱이 막 시작되어 아직 항목이 없을 수 있습니다. 잠시 후 다시 시도하거나, **인덱스 새로고침**·설정의 **인덱싱**을 시도해 보세요. 설정에서 해당 드라이브·폴더가 **검색 제외**에 등록되어 있지 않은지도 확인하세요.

### Q. 특정 드라이브나 폴더를 검색에서 빼고 싶어요.

**설정** → **검색 제외**에서 드라이브를 체크하거나, 제외할 디렉터리를 추가하세요. 저장하면 인덱스가 다시 구축됩니다.

### Q. 인덱싱 중 멈추거나 종료하면 어떻게 되나요?

**멈춤**을 누르면 스캔이 일시 중지되고 `index.building.db`가 보존됩니다. **인덱싱** 버튼은 building DB를 삭제하고 **처음부터** 다시 시작합니다. 프로그램을 **종료**하면 building DB는 디스크에 남지만, **다음 실행 시 삭제**되고 중단된 작업이 있었으면 **자동으로 전체 재스캔**이 시작됩니다. 완료된 `index.db`가 있으면 그동안 **기존 인덱스로 검색**할 수 있습니다.

### Q. 일부 드라이브 인덱싱이 실패하면?

해당 드라이브·폴더만 미완료로 남고, 나머지는 계속 인덱싱됩니다. 실패한 루트는 같은 패스에서 최대 3회 재시도하며, 모두 완료되어야 새 `index.db`로 교체됩니다.

### Q. 재인덱싱 중에도 검색할 수 있나요?

네. 재인덱싱은 별도 파일(`index.building.db`)에서 진행되며, **완료 전까지 검색은 기존 `index.db`** 를 사용합니다. 재인덱싱이 끝나면 새 인덱스로 교체됩니다.

### Q. AND/OR 검색은 어떻게 하나요?

검색어 사이에 **`*`**(AND) 또는 **`+`**(OR)를 **앞뒤 공백과 함께** 넣습니다. 예: `report * 2024`, `doc + pdf`. 자세한 예제는 [README.md — 검색 문법](README.md#검색-문법)을 참고하세요.

### Q. 정규식으로 검색하려면?

**설정** → **정규식 사용**을 켠 뒤 검색하세요. 예: `\.pdf$` (PDF 파일), `^2024` (2024로 시작하는 이름).

### Q. 창이 다른 창 뒤에 가려져요.

**설정** → **창 표시 우선순위** → **다른 프로그램보다 위**를 선택하거나, 우클릭 메뉴에서 **다른 프로그램보다 위**를 체크하세요.

### Q. 프로그램을 완전히 종료하려면?

우클릭 메뉴 또는 트레이 메뉴에서 **종료**를 선택하세요. 창을 닫는 것만으로는 트레이에 남습니다.

### Q. 이미 실행 중인데 다시 실행했어요.

DeskSearch는 **단일 인스턴스**로 동작합니다. 새 창이 뜨지 않고, 이미 실행 중인 검색창이 다시 표시됩니다.

### Q. Windows 시작할 때 자동으로 실행되나요?

설정에서 **Windows 시작 시 자동 실행**을 켜면 로그인 시 DeskSearch가 실행됩니다. 기본값은 켜짐입니다.

### Q. 제거할 때 설정·인덱스가 지워지나요?

제거 과정에서 **사용자 데이터 삭제 여부**를 선택할 수 있습니다. **사용자 데이터 삭제**를 선택하면 `%AppData%\DeskSearch\`(`settings.json`, `index.db` 등)가 삭제됩니다. 체크하지 않으면 프로그램만 제거되고 사용자 데이터는 유지됩니다.

### Q. 어떤 드라이브가 검색되나요?

Windows에서 **사용 가능(Ready)** 상태인 모든 드라이브가 대상입니다. **검색 제외**에 등록한 드라이브는 제외됩니다.

### Q. 영어 UI인데 한국어 파일명도 검색되나요?

네. 화면 언어와 관계없이 **모든 언어의 파일·폴더 이름**을 검색할 수 있습니다.

### Q. "검색 인덱스 업그레이드" 창이 나타났어요.

검색 속도를 높이기 위해 내부 검색 구조를 한 번 업그레이드해야 할 때 **확인 대화상자**가 표시됩니다. **예**를 선택하면 진행률(%)과 함께 업그레이드가 진행되며, 항목 수에 따라 다소 시간이 걸릴 수 있습니다. **아니오**를 선택해도 검색은 계속 사용할 수 있으며, 다음 실행 시 다시 안내됩니다. 한 번 완료되면 다시 나타나지 않습니다.

### Q. 검색은 파일·폴더 경로도 검색하나요?

아니요. 검색은 **파일·폴더 이름**만 대상입니다. 입력한 문자열 전체가 이름 안에 **연속으로** 포함되어야 합니다. 상위 폴더 경로에 검색어가 있어도, 해당 파일·폴더 이름에 포함되지 않으면 결과에 나타나지 않습니다.

### Q. 검색 결과 순서를 바꿀 수 있나요?

**설정** → **검색 결과 정렬**에서 선택할 수 있습니다. 기본값은 **일치도**(완전 일치가 위, 그다음 접두어·포함)입니다. 이름·경로순이나 폴더/파일 우선 정렬도 가능합니다. **저장** 후 같은 검색어로 결과가 다시 정렬됩니다.

### Q. 언어를 바꿨는데 저장하지 않았어요.

설정 창에서 **취소**하거나 창을 닫으면 변경 전 언어로 되돌아갑니다. **저장**하면 다음 실행부터도 선택한 언어가 유지됩니다.
