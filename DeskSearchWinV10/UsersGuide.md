# DeskSearch — 사용자 가이드

이 문서는 **DeskSearch**를 처음 사용하는 분을 위한 안내입니다. 개발·빌드 정보는 [README.md](README.md)를 참고하세요.

---

## 1. 프로그램 소개

DeskSearch는 Windows용 **데스크톱 파일·폴더 검색 위젯**입니다.

- 화면 상단에 작은 검색창이 항상 표시됩니다.
- PC에 연결된 **모든 드라이브**(고정, 이동식, 네트워크, CD/DVD 등)의 **파일과 폴더**를 백그라운드에서 인덱싱합니다.
- 검색어를 입력하면 이름이 일치하거나 포함된 항목이 실시간으로 표시됩니다.
- 결과를 클릭하거나 Enter 키로 탐색기에서 바로 열 수 있습니다.
- **작업 표시줄에는 아이콘이 나타나지 않습니다.** 알림 영역(시스템 트레이)에만 상주합니다.

---

## 2. 설치 및 실행

### MSI로 설치한 경우

1. `DeskSearchSetup.msi`를 실행합니다.
2. 안내에 따라 설치합니다. 기본 설치 경로: `C:\Program Files\DeskSearch\`
3. 설치 화면에서 **바탕화면 바로가기**, **시작 메뉴 바로가기**를 각각 선택하거나 해제할 수 있습니다.
4. 설치 후 **DeskSearch.exe**를 실행합니다.

### 개발 빌드로 실행한 경우

```bash
dotnet run --project DeskSearch/DeskSearch.csproj
```

또는 `DeskSearch\bin\Debug\net8.0-windows\DeskSearch.exe`를 직접 실행합니다.

### 관리자 권한

DeskSearch는 전체 디스크를 검색하기 위해 **관리자 권한**으로 실행됩니다. 처음 실행 시 Windows **UAC(사용자 계정 컨트롤)** 승인 창이 표시될 수 있습니다. **예**를 선택해야 인덱싱이 정상적으로 진행됩니다.

### 시스템 요구사항

| 항목 | 내용 |
|------|------|
| OS | Windows 10 이상 |
| 권한 | 관리자 권한 (UAC 승인) |
| 런타임 | MSI 설치본은 .NET 런타임 불필요 (self-contained) |
| 디스크 | 인덱스는 메모리에 유지되며, 파일·폴더 수에 따라 RAM 사용량이 달라짐 |

## 3. 화면 구성

```
┌──────────────────────────────────────────────┐
│  ≡   🔍  [ 검색어 입력...              ]  ⚙ │
├──────────────────────────────────────────────┤
│  📁 Documents                                │  ← 폴더 (파란 아이콘)
│     C:\Users\사용자                            │
│  report.pdf                                  │  ← 파일
│     C:\Users\사용자\Documents                 │
└──────────────────────────────────────────────┘
```

| 요소 | 설명 |
|------|------|
| **≡ (드래그 핸들)** | 마우스로 끌어 검색창 위치 이동 |
| **검색 상자** | 파일·폴더 이름 입력 |
| **⚙ (설정)** | 설정 창 열기 |
| **결과 목록** | 일치 항목 최대 12개 (입력 시 자동 표시) |
| **폴더 아이콘** | 파란 폴더 아이콘이 붙은 항목은 디렉터리 |
| **좌·우 가장자리** | 드래그하여 검색창 **너비** 조절 (280 ~ 720px) |

## 4. 기본 사용법

### ① 검색

1. 프로그램을 실행합니다. 처음에는 **인덱싱 중** 상태이며, 완료되면 검색이 가능합니다.
2. 검색창에 **파일 이름** 또는 **폴더 이름**의 일부를 입력합니다.
3. 아래 목록에 결과가 나타납니다.

인덱싱이 끝나기 전에는 검색창이 비활성화됩니다. 마우스를 올리면 진행 상태(인덱싱 중 / 완료)를 툴팁으로 확인할 수 있습니다.

같은 검색어로 대량의 파일을 탐색할 때는 **배치 단위로 순차 검색**하며, 검색어를 바꾸지 않으면 이전 위치부터 이어갑니다. 검색어를 지우거나 다른 검색어로 바꾸면 **처음부터** 다시 검색합니다.

### ② 결과 열기

| 동작 | 파일 | 폴더 |
|------|------|------|
| **클릭** / **Enter** | 탐색기에서 해당 파일 위치 표시 | 폴더 열기 |
| **더블클릭** | 기본 프로그램으로 실행 | 폴더 열기 |

### ③ 키보드 단축키

| 키 | 동작 |
|----|------|
| **Enter** | 선택한 결과 열기 |
| **↓** | 검색 결과 목록으로 포커스 이동 |
| **↑** (목록 첫 항목) | 검색창으로 포커스 복귀 |
| **Esc** | 검색어 지우기 / 결과 닫기 |

---

## 5. 창 이동·크기

- **≡ 핸들**을 드래그하거나
- 검색어가 **비어 있을 때** 검색창 빈 영역을 드래그하거나
- 검색창 **바깥 테두리** 영역을 드래그

→ 창 **위치**를 변경할 수 있습니다.

- 검색창 **왼쪽·오른쪽 가장자리**를 드래그하면 **너비**를 조절할 수 있습니다.

위치·너비·높이는 자동으로 저장되며, 다음 실행 시(트레이에서 복원할 때 포함) 복원됩니다.

---

## 6. 우클릭 메뉴

검색창·결과 목록·드래그 핸들에서 **우클릭**하면 메뉴가 표시됩니다.

| 메뉴 | 설명 |
|------|------|
| **검색 초기화** | 검색어와 결과 목록 지우기 |
| **인덱스 새로고침** | 전체 인덱스를 처음부터 다시 구축 |
| **바탕화면 폴더 열기** | 탐색기에서 바탕화면 열기 |
| **위치 초기화** | 창을 화면 상단 중앙으로 이동 |
| **다른 프로그램보다 위** | 검색창을 항상 최상위에 표시 (체크) |
| **설정...** | 색상·언어·불투명도 설정 |
| **숨기기** | 검색창을 닫지 않고 **트레이로 숨김** |
| **종료** | 프로그램 완전 종료 |

검색 결과 항목에서 우클릭하면 **열기**, **폴더에서 보기**, **경로 복사**, **파일 이름 복사** 등 추가 메뉴가 표시됩니다.

---

## 7. 시스템 트레이

DeskSearch는 **작업 표시줄에 아이콘을 표시하지 않습니다.** 대신 **알림 영역(시스템 트레이)** 에 상주합니다.

| 동작 | 설명 |
|------|------|
| **창 닫기** (Alt+F4 등) | 종료하지 않고 **트레이로 숨김** |
| **트레이 아이콘 더블클릭** | 검색창 다시 표시 |
| **트레이 아이콘 우클릭** | 메뉴 표시 |

### 트레이 메뉴

| 메뉴 | 설명 |
|------|------|
| **검색창 표시** | 숨겨진 검색창 다시 열기 |
| **숨기기** | 검색창을 트레이로 숨김 |
| **설정...** | 설정 창 열기 |
| **종료** | 프로그램 완전 종료 |

> 프로그램을 완전히 끄려면 우클릭 메뉴 또는 트레이 메뉴에서 **종료**를 선택하세요.

## 8. 설정

검색창의 **⚙ 버튼** 또는 우클릭 메뉴 → **설정...** 에서 아래 항목을 변경할 수 있습니다.

| 항목 | 설명 |
|------|------|
| **언어** | 한국어 / English |
| **대소문자 구분** | 켜면 검색어와 이름의 대·소문자가 정확히 일치해야 함 (기본: 끔) |
| **배경색** | 검색창 배경 색상 및 프리셋 (밝은 톤 + 다크 톤) |
| **배경 불투명도** | 40% ~ 100% |
| **테두리색** | 검색창 테두리 |
| **글자색** | 검색어·결과 텍스트 색상 (어두운·밝은 프리셋) |
| **창 불투명도** | 전체 창 50% ~ 100% |
| **창 표시 우선순위** | 다른 프로그램보다 위 / 일반 우선 순위 |

**어두운 배경색**을 선택하면 글자·테두리·아이콘 색이 자동으로 밝게 조정되어 가독성을 유지합니다.

**저장**을 누르면 즉시 적용됩니다. **취소**는 변경을 버립니다.

설정 파일 위치:

```
%AppData%\DeskSearch\settings.json
```

## 9. 인덱싱 안내

### 인덱스 범위

- 바탕화면, 문서, 다운로드, OneDrive 등 **우선 폴더**를 먼저 스캔한 뒤
- Windows가 인식하는 **모든 준비된 드라이브**를 백그라운드에서 스캔합니다.

### 스캔 범위

접근 가능한 **모든 하위 디렉터리**를 재귀적으로 검토합니다. `WinSxS`, `node_modules`, `.git` 등도 포함됩니다.

Windows 권한으로 열 수 없는 경로(예: `$Recycle.Bin`, `System Volume Information`)만 자동으로 건너뜁니다. 전체 디스크 접근을 위해 **관리자 권한**으로 실행됩니다.

### 갱신

- 우선 폴더의 파일·폴더 **생성·삭제·이름 변경**은 자동 반영됩니다.
- **4시간**마다 우선 폴더를 재동기화합니다.
- 전체 재스캔이 필요하면 메뉴 → **인덱스 새로고침**을 사용하세요.

인덱싱 중에는 CPU 사용을 낮추기 위해 스캔 속도가 조절됩니다.

## 10. 자주 묻는 질문

### Q. 검색창이 보이지 않아요.

트레이(알림 영역)의 DeskSearch 아이콘을 **더블클릭**하거나, 우클릭 → **검색창 표시**를 선택하세요.

### Q. 작업 표시줄에 아이콘이 보여요.

DeskSearch는 작업 표시줄에 표시되지 않도록 설계되어 있습니다. 트레이(알림 영역) 아이콘만 사용합니다. Windows 설정에서 알림 영역 아이콘 표시를 확인해 보세요.

### Q. UAC(관리자 승인) 창이 뜹니다.

전체 디스크 검색을 위해 관리자 권한이 필요합니다. **예**를 선택해 주세요.

### Q. 검색이 안 됩니다.

인덱싱이 아직 진행 중일 수 있습니다. 우클릭 메뉴 하단의 인덱스 상태를 확인하거나, **인덱스 새로고침**을 시도해 보세요.

### Q. 창이 다른 창 뒤에 가려져요.

**설정** → **창 표시 우선순위** → **다른 프로그램보다 위**를 선택하거나, 우클릭 메뉴에서 **다른 프로그램보다 위**를 체크하세요.

### Q. 프로그램을 완전히 종료하려면?

우클릭 메뉴 또는 트레이 메뉴에서 **종료**를 선택하세요. 창을 닫는 것만으로는 트레이에 남습니다.

### Q. 어떤 드라이브가 검색되나요?

Windows에서 **사용 가능(Ready)** 상태인 모든 드라이브가 대상입니다. 로컬 디스크, USB, 네트워크 드라이브, CD/DVD 등이 포함됩니다. 접근 권한이 없는 경로는 자동으로 건너뜁니다.
