# hwp2md (hephaex)

[hephaex/hwp2md](https://github.com/hephaex/hwp2md) (GPL-3.0) CLI입니다.

## 설치

```powershell
cargo install hwp2md
```

또는 저장소에서 `cargo build --release` 후 `target\release\hwp2md.exe`를 이 폴더에 복사:

`Tools\hwp2md-hephaex\hwp2md.exe`

## HWP2Doc에서 사용

변환 옵션 → **hwp2md (hephaex)** 엔진 선택.

GPL-3.0 라이선스이므로 배포 시 소스 제공 의무를 확인하세요.
