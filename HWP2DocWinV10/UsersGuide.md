# HWP2Doc 사용자 가이드

HWP2Doc는 Windows용 아래한글(HWP/HWPX) 문서 변환 프로그램입니다. 이 문서는 설치부터 변환·편집·미리보기·내보내기까지 일상적인 사용 방법을 설명합니다.

## 1. 시작하기

### 프로그램 실행

- **설치한 경우**: 시작 메뉴 또는 바탕 화면(설치 시 선택)의 **HWP2Doc** 실행
- **개발 빌드**:

```powershell
dotnet run --project HWP2DocWinV10\HWP2DocWinV10.csproj -c Debug
```

### 사전 요구 사항

| 구성 요소 | 설명 |
|-----------|------|
| .NET 10 Desktop Runtime | 프로그램 실행에 필요 |
| WebView2 Runtime | Markdown 편집, 미리보기, PDF 내보내기에 필요 |

MSI 설치 시 위 런타임이 없으면 설치 프로그램이 안내합니다.

### 기본 작업 흐름

1. **파일 → HWP 파일 열기**로 `.hwp` 또는 `.hwpx` 문서를 선택합니다.
2. 변환이 완료되면 **Markdown** 편집 영역과 **미리보기**가 표시됩니다.
3. 필요하면 Markdown 원문을 직접 수정합니다.
4. **문서 구조** 패널에서 제목·표 등을 선택해 해당 위치로 이동할 수 있습니다.
5. **파일** 메뉴 또는 툴바에서 Markdown, Word, PDF 형식으로 내보냅니다.

## 2. 화면 구성

기본 배치(문서 구조 패널은 **오른쪽**):

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  메뉴 (파일 | 보기 | 정보)                                                    │
├──────────────────────────────────────────────────────────────────────────────┤
│  툴바 (열기 | 변환 | Markdown | Word | PDF | 글꼴 | 정보)                     │
├──────────────────────────┬──────────────────────────┬────────────────────────┤
│  Markdown                │  미리보기                 │  문서 구조              │
│  (원문 편집, WebView2)    │  (렌더링 HTML, WebView2)  │  (트리, TreeView)       │
├──────────────────────────┴──────────────────────────┴────────────────────────┤
│  상태 표시줄                                                                  │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 패널 설명

| 패널 | 역할 |
|------|------|
| **Markdown** | 변환된 Markdown **원문**을 편집합니다. 미리보기와 **같은 문서 영역 스타일**(배경, 카드, 글꼴)을 사용합니다. |
| **미리보기** | Markdown을 HTML로 렌더링해 제목·목록·표·이미지 등을 서식과 함께 보여 줍니다. |
| **문서 구조** | 제목, 표, 목록, 인용, 코드 블록 등을 트리로 나열합니다. |

### 분할선 조절

- Markdown과 미리보기 사이, 그리고 편집 영역과 문서 구조 패널 사이의 **세로 분할선**을 드래그해 너비를 조절할 수 있습니다.
- 문서 구조 패널을 숨기면 Markdown과 미리보기가 **동일한 50:50** 너비로 자동 배치됩니다.

## 3. 문서 열기 및 변환

### HWP 파일 열기

1. **파일 → HWP 파일 열기** 또는 툴바 **열기** (`Ctrl+O`)
2. `.hwp` 또는 `.hwpx` 파일을 선택합니다.
3. 선택 즉시 변환이 시작됩니다.

### 다시 변환

이미 연 문서를 원본 파일 기준으로 다시 변환하려면:

- **파일 → 변환** 또는 툴바 **변환** (`F5`)

### 지원 형식

| 확장자 | 설명 |
|--------|------|
| `.hwp` | 아래한글 97~2014 바이너리 형식 |
| `.hwpx` | 아래한글 XML(OXML) 형식 |

## 4. Markdown 편집 및 미리보기

### Markdown 편집 영역

- 변환된 Markdown **원문**이 표시됩니다.
- WebView2 기반 편집 UI로, 미리보기와 **동일한 페이지 레이아웃·글꼴·여백**을 공유합니다.
- 내용을 직접 수정할 수 있습니다.
- 입력을 멈추면 잠시 후(약 0.35초) 미리보기와 문서 구조가 자동으로 갱신됩니다.

> Markdown 패널은 **원문**을, 미리보기 패널은 **렌더링 결과**를 보여 줍니다. `# 제목`과 실제 제목처럼 표시 형태는 다르지만, 문서 영역의 모양과 글꼴 설정은 같습니다.

### 미리보기

- Markdown이 HTML로 렌더링되어 **제목, 목록, 표, 이미지** 등이 서식과 함께 표시됩니다.
- 문서에 포함된 이미지는 변환 시 임시 폴더에 추출되며, 미리보기에서 함께 표시됩니다.

### 미리보기 품질에 대한 참고

- 변환 품질은 **unhwp** 오픈소스 엔진에 의존합니다.
- 한컴 SDK를 사용하지 않으므로, 복잡한 표·머리글/꼬리글·번호 매기기·다단 레이아웃은 원본과 다를 수 있습니다.
- 미리보기 전 Markdown 정규화(줄바꿈 복원, 불릿 통일, 표 보정 등)가 자동으로 적용됩니다.

## 5. 문서 구조 패널

문서 구조 패널은 Markdown에서 **제목, 표, 목록, 인용, 코드 블록, 이미지** 등을 트리 형태로 보여 줍니다.

### 항목 선택

- 트리에서 항목을 **클릭**하면:
  - **Markdown** 편집 영역에서 해당 줄로 이동·선택합니다.
  - **미리보기**에서도 같은 위치로 스크롤합니다.
- 항목을 **더블 클릭**하면 편집 영역에 포커스가 이동합니다.

### 패널 표시/위치 변경

**보기** 메뉴에서 다음을 설정할 수 있습니다.

| 메뉴 | 설명 |
|------|------|
| **문서 구조 표시** | 패널 표시/숨김 (체크) |
| **문서 구조 위치 → 왼쪽** | 구조 패널을 Markdown·미리보기 **왼쪽**에 배치 |
| **문서 구조 위치 → 오른쪽** | 구조 패널을 **오른쪽**에 배치 (기본값) |

설정은 프로그램을 다시 실행해도 유지됩니다.

## 6. 보기 옵션 (글꼴·레이아웃)

### 글꼴 크기

**보기 → 폰트 크기** 또는 툴바 **글꼴** 콤보박스에서 본문 글꼴 크기를 선택합니다.

| 항목 | 내용 |
|------|------|
| 선택 범위 | 8, 9, 10, 11, 12, 14, 16, 18, 20, 24 pt |
| 기본값 | **10 pt** |
| 적용 대상 | Markdown 편집 영역, 미리보기 |
| 내보내기 | Word·PDF 내보내기 시 **본문**에 선택한 크기가 반영됩니다. 제목(h1~h6)은 본문 크기에 맞춰 **자동 비율**로 결정됩니다. |

### 설정 저장 위치

다음 설정은 `%AppData%\HWP2DocWinV10\settings.txt`에 저장됩니다.

- 문서 구조 패널 위치 (왼쪽/오른쪽)
- 문서 구조 패널 표시 여부
- 글꼴 크기

## 7. 내보내기

변환·편집이 끝난 뒤 **파일** 메뉴 또는 툴바에서 형식을 선택합니다.

| 메뉴 | 단축키 | 결과 |
|------|--------|------|
| Markdown으로 내보내기 | `Ctrl+Shift+M` | `.md` 파일 저장. 이미지 등 자산 파일도 같은 폴더에 복사 |
| Word로 내보내기 | `Ctrl+Shift+W` | `.docx` 파일 저장 (미리보기 HTML 기반) |
| PDF로 내보내기 | `Ctrl+Shift+P` | `.pdf` 파일 저장 (WebView2 인쇄 기반) |

### 글꼴 크기와 내보내기

- **Word·PDF**: **보기**에서 설정한 **본문 글꼴 크기**가 적용됩니다.
- **제목**은 본문 대비 CSS 비율(예: h1 = 1.9배)로 자동 계산됩니다.
- **Markdown(.md)** 파일은 순수 텍스트 형식이므로 글꼴 크기 정보는 포함되지 않습니다.

### 내보내기 순서 예시

1. HWP 파일을 연다.
2. Markdown 원문을 필요에 맞게 수정한다.
3. 미리보기에서 결과를 확인한다.
4. **파일 → Markdown으로 내보내기**를 선택하고 저장 위치를 지정한다.
5. Word 또는 PDF가 필요하면 같은 내용으로 추가 내보내기를 실행한다.

> Word·PDF는 **미리보기에 표시된 HTML**을 기준으로 생성됩니다. 원본 HWP와 픽셀 단위로 동일하지 않을 수 있습니다.

## 8. 오류가 발생했을 때

변환, WebView2 초기화, 내보내기 등에서 오류가 나면 **오류 대화 상자**가 표시됩니다.

### 대화 상자 구성

- **요약**: 어떤 작업에서 실패했는지 간단히 안내
- **상세 내용**: 예외 유형, 메시지, 스택 추적 등 구체적인 정보
- **복사** 버튼: 상세 내용 전체를 클립보드에 복사 (지원 문의·디버깅에 활용)
- **확인**: 대화 상자 닫기

### 자주 발생하는 원인

| 증상 | 확인 사항 |
|------|-----------|
| WebView2 초기화 실패 | [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) 설치 여부 |
| 변환 실패 | 파일이 손상되었거나 지원하지 않는 HWP 버전/암호화 여부 |
| unhwp 관련 오류 | 설치 폴더 `Tools\unhwp\unhwp.exe` 존재 여부 |
| PDF 내보내기 실패 | 미리보기가 정상 로드된 뒤 다시 시도 |
| Debug 빌드 실패 (파일 잠김) | 실행 중인 HWP2DocWinV10.exe를 종료한 뒤 다시 빌드 |

## 9. 설치 및 제거

### MSI 설치

1. `HWP2Doc-Setup.msi` 실행
2. .NET 10 Desktop Runtime, WebView2 Runtime 요구 사항 확인
3. 설치 기능 선택 (시작 메뉴, 바탕 화면 바로 가기 등)
4. 설치 완료 후 시작 메뉴에서 **HWP2Doc** 실행

### 제거

**Windows 설정 → 앱 → 설치된 앱**에서 **HWP2Doc**을 선택해 제거합니다.

## 10. 자주 묻는 질문

### Q. 한글 프로그램(한컴 오피스)이 설치되어 있어야 하나요?

아니요. HWP2Doc는 한컴 SDK 없이 **unhwp** 엔진으로 변환합니다.

### Q. Markdown 패널과 미리보기가 내용이 다릅니다.

정상입니다. Markdown 패널은 **편집용 원문**, 미리보기는 **렌더링 결과**를 보여 줍니다. 문서 영역의 배경·글꼴·크기 설정은 동일합니다.

### Q. 변환 결과가 원본과 많이 다릅니다.

한컴 SDK 기반 변환기와 달리 레이아웃·스타일 재현에 한계가 있습니다. 변환 후 Markdown을 수동으로 다듬거나, Word/PDF 내보내기 전에 미리보기를 확인하세요.

### Q. Markdown 내보내기 후 이미지가 보이지 않습니다.

Markdown 파일과 **같은 폴더**(또는 하위 폴더)에 이미지 파일이 함께 저장되어야 합니다. HWP2Doc는 Markdown 내보내기 시 자산 파일을 대상 폴더로 복사합니다.

### Q. Word/PDF에서 글꼴 크기를 바꾸려면?

**보기 → 폰트 크기** 또는 툴바 **글꼴**에서 본문 크기를 변경한 뒤 내보내세요. 제목 크기는 자동으로 조정됩니다.

### Q. Word/PDF 품질을 높이려면?

Markdown과 미리보기를 먼저 만족스럽게 정리한 뒤 내보내세요. Word·PDF는 미리보기 HTML을 기준으로 생성됩니다.

### Q. 프로그램 정보는 어디서 보나요?

**정보 → 프로그램 정보** 또는 툴바 **정보** 버튼 (`F1`)을 사용합니다. 사용 중인 라이브러리(unhwp, Markdig, WebView2, OpenXml) 목록을 확인할 수 있습니다.
