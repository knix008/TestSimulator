# HWP2Doc 사용자 가이드

HWP2Doc는 Windows용 아래한글(HWP/HWPX) 문서 변환 프로그램입니다. 이 문서는 설치부터 변환·편집·미리보기·보내기까지 일상적인 사용 방법을 설명합니다.

## 1. 시작하기

### 프로그램 실행

- **설치한 경우**: 시작 메뉴 또는 바탕 화면(설치 시 선택)의 **HWP2Doc** 실행
- **개발 빌드**:

```powershell
dotnet run --project HWP2DocWinV10\HWP2DocWinV10.csproj -c Debug
```

### 사전 요구 사항

| 구성 요소 | 설명 |
|-----------|------|
| .NET 10 Desktop Runtime | 프로그램 실행에 필요 |
| WebView2 Runtime | Markdown 편집, 미리보기, PDF 보내기에 필요 |
| rhwp (선택) | 변환 엔진 중 하나 — MSI 설치 시 `Tools\rhwp\rhwp.exe` 포함 |
| hwp2md (선택) | roboco-io / hephaex 변환 엔진 — 별도 설치·복사 필요 |
| Ollama (선택) | LLM Markdown 구조화 — 로컬에서 Ollama 서버 실행 필요 |

MSI 설치 시 .NET·WebView2 런타임이 없으면 설치 프로그램이 안내합니다.

### 기본 작업 흐름

1. **파일 → HWP 파일 열기**로 `.hwp` 또는 `.hwpx` 문서를 선택합니다.
2. **변환 옵션** 대화 상자에서 **변환 엔진**과 LLM 사용 여부를 선택합니다.
3. 변환이 완료되면 **Markdown** 편집 영역과 **미리보기**가 표시됩니다.
4. LLM을 켠 경우 변환 결과를 먼저 보여 준 뒤, LLM 구조화가 끝나면 다시 갱신됩니다.
5. 필요하면 Markdown 원문을 직접 수정합니다.
6. **문서 구조** 패널(선택)에서 제목·표 등을 선택해 해당 위치로 이동할 수 있습니다.
7. **파일** 메뉴 또는 툴바에서 Markdown, Word, PDF 형식으로 보냅니다.

## 2. 화면 구성

기본 배치(문서 구조 패널은 **숨김**):

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  메뉴 (파일 | 보기 | 정보)                                                    │
├──────────────────────────────────────────────────────────────────────────────┤
│  툴바 (열기 | 변환 | … | 글꼴 | 문서 구조 | 정보)                              │
├──────────────────────────────────────────┬───────────────────────────────────┤
│  Markdown                                │  미리보기                          │
│  (원문 편집, WebView2)                   │  (렌더링 HTML, WebView2)           │
├──────────────────────────────────────────┴───────────────────────────────────┤
│  상태 표시줄 (사용 가능한 변환 엔진 목록 등)                                   │
└──────────────────────────────────────────────────────────────────────────────┘
```

문서 구조 패널을 켜면 Markdown·미리보기 옆에 트리 패널이 추가됩니다.

### 패널 설명

| 패널 | 역할 |
|------|------|
| **Markdown** | 변환된 Markdown **원문**을 편집합니다. 미리보기와 **같은 문서 영역 스타일**(배경, 카드, 글꼴)을 사용합니다. |
| **미리보기** | Markdown을 HTML로 렌더링해 제목·목록·표·이미지 등을 서식과 함께 보여 줍니다. |
| **문서 구조** | 제목, 표, 목록, 인용, 코드 블록 등을 트리로 나열합니다. (기본 숨김) |

### 분할선 조절

- Markdown과 미리보기 사이, 그리고 편집 영역과 문서 구조 패널 사이의 **세로 분할선**을 드래그해 너비를 조절할 수 있습니다.
- 문서 구조 패널을 숨기면 Markdown과 미리보기가 **동일한 50:50** 너비로 자동 배치됩니다.

### 상태 표시줄

프로그램 시작 시 **사용 가능한 변환 엔진** 목록을 표시합니다.

| 메시지 예시 | 의미 |
|-------------|------|
| `준비 — 엔진: unhwp, rhwp, hwp2md-roboco, hwp2md-hephaex` | 나열된 엔진의 실행 파일을 찾았습니다. |
| `준비 — 엔진: unhwp` | 내장 unhwp만 사용 가능합니다. 외부 CLI가 없습니다. |

변환 완료 시 `변환 완료: 파일명 (엔진명)` 형태로 사용된 엔진이 표시됩니다.

## 3. 문서 열기 및 변환

### HWP 파일 열기

1. **파일 → HWP 파일 열기** 또는 툴바 **열기** (`Ctrl+O`)
2. `.hwp` 또는 `.hwpx` 파일을 선택합니다.
3. **변환 옵션** 대화 상자가 표시됩니다. 엔진과 LLM 옵션을 확인한 뒤 **변환**을 누릅니다.

### 다시 변환

이미 연 문서를 원본 파일 기준으로 다시 변환하려면:

- **파일 → 변환** 또는 툴바 **변환** (`F5`)

매번 **변환 옵션** 대화 상자가 표시됩니다.

### 지원 형식

| 확장자 | 설명 |
|--------|------|
| `.hwp` | 아래한글 97~2014 바이너리 형식 |
| `.hwpx` | 아래한글 XML(OXML) 형식 |

### 변환 진행 표시

- 상태 표시줄에 현재 단계(구조 분석, 엔진 변환, LLM 구조화 등)가 표시됩니다.
- LLM 구조화 중에는 진행률(%)이 표시될 수 있습니다.
- LLM 사용 시: **변환 Markdown·미리보기를 먼저 표시**한 뒤, LLM 완료 후 결과를 다시 갱신합니다.

## 4. 변환 옵션 (엔진 · LLM)

열기·변환 시 표시되는 **변환 옵션** 대화 상자에서 다음을 선택합니다.

### 변환 엔진

라디오 버튼으로 **한 가지 엔진**을 선택합니다. 실행 파일이 없는 엔진은 비활성화됩니다.

| 엔진 | 설명 | 필요 조건 |
|------|------|-----------|
| **unhwp (내장, 기본)** | NuGet 내장. 항상 사용 가능 | 없음 |
| **rhwp** | 표·그림·본문 변환 | `Tools\rhwp\rhwp.exe` |
| **hwp2md (roboco-io)** | MIT CLI, 복잡한 표·레이아웃 비교용 | `Tools\hwp2md-roboco\hwp2md.exe` |
| **hwp2md (hephaex)** | GPL-3.0 CLI, colspan·CommonMark 표 | `Tools\hwp2md-hephaex\hwp2md.exe` |

모든 엔진은 **unhwp로 문서 구조를 먼저 분석**한 뒤, 선택한 엔진으로 Markdown을 생성하고 제목·후처리를 공통 적용합니다.

- 엔진에 마우스를 올리면 설명과 실행 파일 경로(또는 필요 파일 안내)가 툴팁으로 표시됩니다.
- 선택한 엔진은 `settings.txt`의 `ConversionEngine=`에 저장됩니다.

### LLM으로 Markdown 구조화

| 항목 | 설명 |
|------|------|
| **역할** | 문서 **내용은 바꾸지 않고** 선택한 대상의 Markdown **구조·서식**을 다듬습니다. |
| **사전 설정** | **LLM 설정...**에서 Ollama 모델 이름과 **처리 대상**을 지정해야 합니다. |
| **서버** | 기본 `http://localhost:11434` (Ollama) |
| **빠른 LLM** | 기본 켜짐. LLM 호출 횟수를 줄여 속도를 우선합니다. |

**LLM 설정**은 변환 옵션 대화 상자 또는 **정보 → LLM 설정** 메뉴에서 열 수 있습니다.

#### LLM 처리 대상 (체크박스)

| 대상 | 설명 |
|------|------|
| **표** | 깨진 파이프 표·열 불일치를 GFM 표로 복구 |
| **제목** | `#` 계층 정리, 제목처럼 보이는 줄에 제목 부여 |
| **목록** | 글머리·번호 목록을 Markdown 목록으로 정리 |
| **HTML** | 남아 있는 `<table>`, `<h1>` 등을 Markdown으로 변환 |

- **연결 테스트**로 Ollama 실행·모델 목록을 확인합니다.
- 모델이 미설정인 상태에서 LLM을 켜고 변환하면 안내 메시지가 표시됩니다.
- LLM 없이도 규칙 기반 후처리(HTML 표→GFM 표 등)가 자동 적용됩니다.

선택한 엔진·LLM 옵션은 `%AppData%\HWP2DocWinV10\settings.txt`에 저장되어 다음 실행 시 기본값으로 사용됩니다.

## 5. Markdown 편집 및 미리보기

### Markdown 편집 영역

- 변환된 Markdown **원문**이 표시됩니다.
- WebView2 기반 편집 UI로, 미리보기와 **동일한 페이지 레이아웃·글꼴·여백**을 공유합니다.
- 내용을 직접 수정할 수 있습니다.
- 입력을 멈추면 잠시 후(약 0.35초) 미리보기와 문서 구조가 자동으로 갱신됩니다.

> Markdown 패널은 **원문**을, 미리보기 패널은 **렌더링 결과**를 보여 줍니다. `# 제목`과 실제 제목처럼 표시 형태는 다르지만, 문서 영역의 모양과 글꼴 설정은 같습니다.

### 미리보기

- Markdown이 HTML로 렌더링되어 **제목, 목록, 표, 이미지** 등이 서식과 함께 표시됩니다.
- 문서에 포함된 이미지는 변환 시 `assets/` 등 폴더에 추출되며, 미리보기에서 함께 표시됩니다.

### 미리보기 품질에 대한 참고

- **엔진별 차이**: unhwp, rhwp, hwp2md는 표·그림·제목 처리 방식이 다릅니다. 같은 문서로 여러 엔진을 비교해 보세요.
- **공통 후처리**: HTML 표→GFM 파이프 표, 표 정규화, 이미지 경로 통합 등이 자동 적용됩니다.
- 한컴 SDK를 사용하지 않으므로, 복잡한 머리글/꼬리글·번호 매기기·다단 레이아웃은 원본과 다를 수 있습니다.

## 6. 문서 구조 패널

문서 구조 패널은 Markdown에서 **제목, 표, 목록, 인용, 코드 블록, 이미지** 등을 트리 형태로 보여 줍니다.

> **기본값은 숨김**입니다. 툴바 **문서 구조** 버튼을 눌러 표시할 수 있습니다.

### 항목 선택

- 트리에서 항목을 **클릭**하면:
  - **Markdown** 편집 영역에서 해당 줄로 이동·선택합니다.
  - **미리보기**에서도 같은 위치로 스크롤합니다.
- 항목을 **더블 클릭**하면 편집 영역에 포커스가 이동합니다.

### 패널 표시/위치 변경

**보기** 메뉴 또는 툴바 **문서 구조**에서 다음을 설정할 수 있습니다.

| 메뉴 / 버튼 | 설명 |
|-------------|------|
| **문서 구조 표시** | 패널 표시/숨김 (체크) |
| **문서 구조** (툴바) | 패널 표시/숨김 토글 |
| **문서 구조 위치 → 왼쪽** | 구조 패널을 Markdown·미리보기 **왼쪽**에 배치 |
| **문서 구조 위치 → 오른쪽** | 구조 패널을 **오른쪽**에 배치 (기본값) |

설정은 프로그램을 다시 실행해도 유지됩니다.

## 7. 보기 옵션 (글꼴·레이아웃)

### 글꼴 크기

**보기 → 폰트 크기** 또는 툴바 **글꼴** 콤보박스에서 본문 글꼴 크기를 선택합니다.

| 항목 | 내용 |
|------|------|
| 선택 범위 | 8, 9, 10, 11, 12, 14, 16, 18, 20, 24 pt |
| 기본값 | **10 pt** |
| 적용 대상 | Markdown 편집 영역, 미리보기 |
| 보내기 | Word·PDF 보내기 시 **본문**에 선택한 크기가 반영됩니다. 제목(h1~h6)은 본문 크기에 맞춰 **자동 비율**로 결정됩니다. |

### 설정 저장 위치

다음 설정은 `%AppData%\HWP2DocWinV10\settings.txt`에 저장됩니다.

| 키 | 설명 |
|----|------|
| `StructurePanelSide` | 문서 구조 패널 위치 (Left / Right) |
| `StructurePanelVisible` | 문서 구조 패널 표시 여부 |
| `FontSize` | 본문 글꼴 크기 |
| `ConversionEngine` | 마지막 선택 변환 엔진 (Unhwp, Rhwp, Hwp2MdRoboco, Hwp2MdHephaex) |
| `LlmEnabled` | LLM 구조화 사용 여부 |
| `LlmFastMode` | 빠른 LLM 모드 (기본 true) |
| `LlmModel` | Ollama 모델 이름 |
| `LlmTargets` | LLM 처리 대상 플래그 (표·제목·목록·HTML) |
| `RhwpEnabled` | (하위 호환) 이전 rhwp 체크박스 설정 |

## 8. 보내기

변환·편집이 끝난 뒤 **파일** 메뉴 또는 툴바에서 형식을 선택합니다.

| 메뉴 | 단축키 | 결과 |
|------|--------|------|
| Markdown으로 보내기 | `Ctrl+Shift+M` | `.md` 파일 저장. 이미지 등 자산 파일도 같은 폴더에 복사 |
| Word로 보내기 | `Ctrl+Shift+W` | `.docx` 파일 저장 (미리보기 HTML 기반) |
| PDF로 보내기 | `Ctrl+Shift+P` | `.pdf` 파일 저장 (WebView2 인쇄 기반) |

### 글꼴 크기와 보내기

- **Word·PDF**: **보기**에서 설정한 **본문 글꼴 크기**가 적용됩니다.
- **제목**은 본문 대비 CSS 비율(예: h1 = 1.9배)로 자동 계산됩니다.
- **Markdown(.md)** 파일은 순수 텍스트 형식이므로 글꼴 크기 정보는 포함되지 않습니다.

### 보내기 순서 예시

1. HWP 파일을 연다.
2. 변환 옵션(엔진·LLM)을 선택한다.
3. Markdown 원문을 필요에 맞게 수정한다.
4. 미리보기에서 결과를 확인한다.
5. **파일 → Markdown으로 보내기**를 선택하고 저장 위치를 지정한다.
6. Word 또는 PDF가 필요하면 같은 내용으로 추가 보내기를 실행한다.

> Word·PDF는 **미리보기에 표시된 HTML**을 기준으로 생성됩니다. 원본 HWP와 픽셀 단위로 동일하지 않을 수 있습니다.

## 9. 오류가 발생했을 때

변환, WebView2 초기화, 보내기 등에서 오류가 나면 **오류 대화 상자**가 표시됩니다.

### 대화 상자 구성

- **요약**: 어떤 작업에서 실패했는지 간단히 안내
- **상세 내용**: 예외 유형, 메시지, 스택 추적 등 구체적인 정보
- **복사** 버튼: 상세 내용 전체를 클립보드에 복사 (지원 문의·디버깅에 활용)
- **확인**: 대화 상자 닫기

### 자주 발생하는 원인

| 증상 | 확인 사항 |
|------|-----------|
| WebView2 초기화 실패 | [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) 설치 여부 |
| 변환 실패 | 파일이 손상되었거나 지원하지 않는 HWP 버전/암호화 여부 |
| unhwp 관련 오류 | 설치 폴더 `Unhwp.Net.dll`, `runtimes\win-x64\native\unhwp.dll` 존재 여부 |
| rhwp / hwp2md 관련 | 해당 `Tools\...\*.exe` 존재 여부. 없으면 unhwp만 선택하거나 바이너리 배치 |
| LLM 구조화 실패 | Ollama가 실행 중인지, 모델 이름이 올바른지 확인. 실패해도 변환 결과는 유지됨 |
| PDF 보내기 실패 | 미리보기가 정상 로드된 뒤 다시 시도 |
| Debug 빌드 실패 (파일 잠김) | 실행 중인 HWP2DocWinV10.exe를 종료한 뒤 다시 빌드 |

## 10. 설치 및 제거

### MSI 설치

1. `HWP2Doc-Setup.msi` 실행
2. .NET 10 Desktop Runtime, WebView2 Runtime 요구 사항 확인
3. 설치 기능 선택 (시작 메뉴, 바탕 화면 바로 가기 등)
4. 설치 완료 후 시작 메뉴에서 **HWP2Doc** 실행

MSI에는 `Tools\rhwp\rhwp.exe`가 포함됩니다. **hwp2md** 엔진은 MSI에 포함되지 않으며, 필요 시 [README.md](README.md)의 설치 안내를 따르세요.

### 제거

**Windows 설정 → 앱 → 설치된 앱**에서 **HWP2Doc**을 선택해 제거합니다.

## 11. 자주 묻는 질문

### Q. 한글 프로그램(한컴 오피스)이 설치되어 있어야 하나요?

아니요. HWP2Doc는 한컴 SDK 없이 **unhwp**, **rhwp**, **hwp2md** 등 오픈소스 엔진으로 변환합니다.

### Q. 어떤 변환 엔진을 쓰면 좋나요?

| 엔진 | 권장 용도 |
|------|-----------|
| **unhwp** | 별도 설치 없이 빠르게 변환 (기본) |
| **rhwp** | 표·그림 품질이 중요할 때 (MSI에 포함) |
| **hwp2md (roboco-io)** | 복잡한 표·레이아웃 문서 비교 (MIT) |
| **hwp2md (hephaex)** | colspan·CommonMark 표 비교 (GPL-3.0) |

같은 문서로 엔진을 바꿔 가며 품질을 비교해 보세요.

### Q. LLM 구조화는 무엇을 하나요?

Ollama 로컬 모델로 **선택한 대상**(표·제목·목록·HTML)의 Markdown 구조를 정리합니다. 문서 **내용**은 변경하지 않도록 설계되어 있습니다. Ollama가 없거나 실패하면 변환 결과만 유지됩니다.

### Q. LLM 없이 표가 정리되나요?

네. 규칙 기반 후처리로 HTML `<table>`을 GFM 파이프 표로 변환하고 표 형식을 정규화합니다. LLM은 더 복잡한 경우에 선택적으로 사용합니다.

### Q. Markdown 패널과 미리보기가 내용이 다릅니다.

정상입니다. Markdown 패널은 **편집용 원문**, 미리보기는 **렌더링 결과**를 보여 줍니다. 문서 영역의 배경·글꼴·크기 설정은 동일합니다.

### Q. 변환 결과가 원본과 많이 다릅니다.

한컴 SDK 기반 변환기와 달리 레이아웃·스타일 재현에 한계가 있습니다. **rhwp** 또는 **hwp2md** 엔진을 시도하고, 변환 후 Markdown을 수동으로 다듬거나, Word/PDF 보내기 전에 미리보기를 확인하세요.

### Q. 그림이 안 보입니다.

이미지는 `assets/` 또는 `images/` 폴더로 통합됩니다. 엔진별로 자산 추출 방식이 다를 수 있습니다. 여전히 누락되면 다른 엔진으로 다시 변환해 보세요.

### Q. Markdown 보내기 후 이미지가 보이지 않습니다.

Markdown 파일과 **같은 폴더**(또는 `assets/`, `images/` 하위 폴더)에 이미지 파일이 함께 저장되어야 합니다. HWP2Doc는 Markdown 보내기 시 자산 파일을 대상 폴더로 복사합니다.

### Q. Word/PDF에서 글꼴 크기를 바꾸려면?

**보기 → 폰트 크기** 또는 툴바 **글꼴**에서 본문 크기를 변경한 뒤 보내세요. 제목 크기는 자동으로 조정됩니다.

### Q. 프로그램 정보는 어디서 보나요?

**정보 → 프로그램 정보** 또는 툴바 **정보** 버튼 (`F1`)을 사용합니다. unhwp, rhwp, hwp2md, Markdig, WebView2, OpenXml 등 사용 라이브러리를 확인할 수 있습니다.
