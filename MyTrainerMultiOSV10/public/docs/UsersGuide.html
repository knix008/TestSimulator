MyTrainer 사용 설명서

MyTrainer 는 신경망을 그려서 만들고, 데이터를 다듬고, 학습시키면서 층과 뉴런 하나하나가 하는 일을 눈으로 확인하는 프로그램입니다. 학습한 모델은 그림·마이크·웹캠·파일로 바로 시험하고, PyTorch 코드로 보고 고치고, C/C++ 코드나 ONNX 로 내보내 다른 프로그램과 기기에서 쓸 수 있습니다.

  • 웹 브라우저, Windows, macOS, Linux 에서 같은 화면으로 동작합니다(Tauri 2).
  • 학습 엔진은 두 가지입니다: 앱 안에서 바로 학습하는 TensorFlow(TensorFlow.js — WebGPU · WebGL · CPU), 그리고 이 컴퓨터의 Python 으로 실행하는 PyTorch(데스크톱 앱).
  • 54개의 샘플 모델: 퍼셉트론 · MLP · 다항 회귀, 비교 예제(활성화 함수, 과적합과 정규화, 기울기 소실, RNN · GRU · LSTM), CNN 구조(VGG · Inception · DenseNet · MobileNet), 오토인코더(잡음 제거 · 이상 탐지 포함), RNN · LSTM · GRU, Conv1D, CNN + LSTM, 트랜스포머(감성 분석 · 시계열 예측 · 미니 GPT), 잔차 연결, 음성 인식(임베디드용 DS-CNN · BC-ResNet, 한국어 키워드 2종과 실시간용 BC-ResNet+), 이미지·문자(OCR)·영상 인식, 표 데이터(CSV).
  • 처음이면 시작할 때 뜨는 시작 안내 창에서 튜토리얼(화면을 짚어 가며 19단계)이나 튜토리얼 영상으로 시작하세요.

빠른 시작 #

  1. 처음이라면 튜토리얼 시작(시작 안내 창, 시작 화면 위쪽, 도움말 › 튜토리얼 시작)이 아래 과정을 화면을 짚어 가며 함께 해 줍니다.
  2. 시작 화면에서 샘플 모델(예: "나선 3분류")을 누릅니다.
  3. F5(또는 툴바의 ▶)를 누르면 학습이 시작됩니다. 학습 탭에 손실·정확도 곡선이 실시간으로 그려지고, 아래 콘솔에 에포크마다 손실·정확도·검증 값·학습률·걸린 시간이 한 줄씩 나옵니다.
  4. 뉴런 보기 탭(Ctrl+3)에서 뉴런 하나를 클릭하면, 오른쪽 속성 패널에 그 뉴런의 계산(입력 × 가중치 + 편향 → 활성화)이 숫자 그대로 보입니다.
  5. 테스트 탭에서 테스트 샘플을 넘겨 보거나, 직접 그리고, 마이크·웹캠·파일로 시험합니다.
  6. 다 되면 파일 › C/C++ 코드로 내보내기 또는 ONNX 모델로 내보내기로 학습 결과를 내보냅니다.

데이터 탭 #

데이터 출처 #

  • 내장 데이터 — 2차원 점(XOR, 동심원, 반달, 나선, 점 무리, 체커보드), 함수·표(직선, 사인, Friedman), 그림(숫자, 도형, 색깔 도형, 물체, 잡음 낀 숫자(잡음 제거용: 입력은 잡음 · 지워진 칸이 있는 숫자, 정답은 깨끗한 숫자), 숫자 + 이상 그림(이상 탐지용: 숫자 사이에 흑백이 뒤집힌 숫자 · 얼룩 · 격자가 섞임, 이상 비율 조절)), 문자(영문 A–Z, 한글 자음), 음성 명령(포먼트 합성, 멜 스펙트로그램), 영상(움직이는 물체 클립), 시퀀스(사인파 예측, 패턴, 1 세기, 동작 센서), 텍스트(짧은 문장 감성, 영어·한국어 문장(글자 단위 언어 모델)). 샘플 수·잡음·씨앗 같은 값을 바꾸면 바로 다시 만들어집니다.
  • 녹음된 음성 (실제 데이터) — 한국어 키워드: 출근·퇴근·경비·해제. Supertonic TTS 화자 120명(기본 남 5·여 5 + 두 목소리를 섞은 30명 + 세 목소리를 섞어 조금 바꾼 80명)이 평서·명령·질문 억양과 여러 빠르기로 말한 음성 5520개(키워드 3840개 + unknown 1680개)와, 비슷하게 들리는 말·일상어 120여 개(unknown: 출발·퇴장·경보·해지 …)입니다. 증강 복사본(빠르기·높이, 시간 이동, 크기, 마이크 특성, 울림, 배경 소음, 뒤에서 말하는 사람, VTLP, SpecAugment)과 배경 소음(noise) 부류를 더할 수 있습니다. 한국어 키워드: 출근·퇴근·외출·복귀도 같은 방식으로 만든 음성 5520개이며, unknown 에는 외식·외부·복구·복지·귀가·경비·해제처럼 새 키워드와 비슷한 말이 더 들어 있습니다(150여 개).
  • CSV 가져오기 — 쉼표·세미콜론·탭을 자동으로 알아냅니다. 정답 열을 고르면 글자이거나 값의 종류가 적을 때 분류, 아니면 회귀가 됩니다. 글자 특성 열은 원-핫 열로, 빈 숫자는 열의 평균으로 채웁니다.
  • 그림 폴더 가져오기 — 하위 폴더 이름이 클래스입니다(cats/, dogs/ …). PNG · JPEG · GIF · WebP · BMP · AVIF · ICO · SVG · TIFF · TGA 를 읽습니다.
  • 음성 폴더 가져오기 — 하위 폴더 이름이 클래스입니다. WAV · MP3 · OGG · FLAC · M4A · WebM 을 읽어, 소리가 가장 큰 1초를 8 kHz 로 바꿔 저장합니다.

data/ 폴더에 바로 쓸 수 있는 예제가 있습니다: CSV(csv/), 그림(images/), 음성(audio/speech/, audio/kws-ko/, audio/kws-ko-attend/), 예측해 볼 파일(predict/). 자세한 내용은 data/README.md 를 보세요.

샘플을 누르면 그 샘플이 탐침 입력이 됩니다. 뉴런 보기와 학습 탭의 뉴런 그림은 탐침 입력이 네트워크를 지나가는 모습입니다. 음성 샘플은 눌러서 들을 수 있고, 그림 위에서 마우스 휠로 다음 샘플들을 넘겨 봅니다.

전처리 단계 #

단계하는 일
표준화학습 데이터의 평균·표준편차로 (x − μ) / σ
최소-최대 정규화학습 데이터의 최소~최대를 지정한 범위로
다항 특성x₁², x₁x₂ … 곱 특성 추가 (뉴런 하나로 원형 경계를 만드는 샘플 참고)
범위 자르기이상치를 범위 안으로
잡음 증강 · 좌우 뒤집기 · 이동 증강변형한 복사본을 학습 데이터에만 추가
밝기 반전1 − x

통계(평균, 범위)는 학습 데이터에서만 구해 검증·테스트 데이터에 똑같이 적용합니다. 단계는 켜고 끄거나 순서를 바꿀 수 있습니다. 원본 / 전처리 후 단추로 차이를 확인하세요. 같은 전처리가 C 내보내기(mt_preprocess)와 ONNX 내보내기(모델 안)에 그대로 들어갑니다.

나누기 #

검증·테스트 비율, 섞기 씨앗, 클래스 비율 유지(층화 추출)를 정합니다. 음성 데이터에는 화자(원본)별로 나누기가 있어(기본 켬) 한 화자의 음성(또는 한 녹음과 그 증강 복사본)이 학습·검증·테스트 중 한 곳에만 들어갑니다 — 검증·테스트 정확도가 처음 듣는 목소리에 대한 정확도가 됩니다. 아래 막대가 세 부분의 크기를 보여 줍니다.

모델 탭 — 코딩 없이 모델 만들기 #

모델은 층 카드와 연결선으로 된 그래프입니다. 카드에는 층 이름, 종류와 주요 설정, 출력 모양, 매개변수 수, 그리고 학습 중에는 활성값 띠가 보입니다.

하고 싶은 일방법
층 추가팔레트의 층을 캔버스로 끌어 놓기 · 층을 선택하고 팔레트에서 누르기(선택한 층 뒤에 끼워짐) · 빈 곳을 두 번 클릭
두 층 사이에 끼우기팔레트의 층을 연결선 위에 놓기 · 연결선을 오른쪽 클릭 → "이 연결선에 층 끼우기"
연결층 아래쪽 점(출력 포트)을 끌어 다른 층에 놓기
연결 끊기연결선을 누르고 Delete · 오른쪽 클릭 → 연결선 삭제
빠른 편집층을 선택하면 위에 단추가 나타납니다: 위에 끼우기 · 아래에 추가 · 뉴런/필터 −/+ · 다른 층으로 바꾸기 · 복제 · 잔차 연결 · 삭제
여러 층 한 번에블록(Dense+BN+ReLU+드롭아웃, Conv+BN+ReLU+풀링, 분류 머리, LSTM 2층, 깊이별+점별(DS-CNN) …)
설정 바꾸기오른쪽 속성 패널: 이름(코드의 변수 이름), 종류, 뉴런 수·활성화·커널 크기 …
정리자동 배치(Ctrl+L), 화면에 맞추기(Ctrl+0, 가운데 정렬), 확대/축소(− [비율] + 단추, Ctrl+휠, Ctrl+= / Ctrl+-)
방향 · 격자위→아래 / 왼쪽→오른쪽: 같은 배치를 세로 또는 가로로 보여 줍니다(배치는 그대로 남음). 격자(Ctrl+G): 5칸마다 진한 선이 있는 5×5 격자를 켜고 끕니다.
선택클릭, Shift+클릭, Shift+끌기(사각형), Ctrl+A

층 종류: 완전연결, 활성화, Leaky ReLU, 합성곱 2D, 깊이별 합성곱 2D(커널 높이·너비 따로), 최대/평균/전역 평균 풀링, 주파수 평균 풀링(BC-ResNet), 업샘플링, 합성곱 1D, 최대 풀링 1D, 시간 평균 풀링, RNN · LSTM · GRU, 임베딩, 토큰 + 위치 임베딩 · 셀프 어텐션(헤드 수, 인과 마스크) · 마지막 시점(트랜스포머), 드롭아웃, 배치 정규화, 층 정규화, 펼치기, 모양 바꾸기, 더하기(브로드캐스트), 이어 붙이기.

모양은 데이터에서 출력까지 자동으로 계산되며, 맞지 않으면 카드에 빨간 표시와 설명이 붙습니다. 문제 탭에서 모든 문제를 볼 수 있고, 문제를 누르면 그 층으로 이동합니다. 데이터를 바꾸면 출력층의 뉴런 수와 활성화가 작업에 맞게 자동으로 바뀝니다.

뉴런 보기 탭 #

네트워크를 왼쪽(입력)에서 오른쪽(출력)으로 뉴런 단위로 그립니다. 처음에는 창 폭에 맞춰 전체가 보이고, 툴바의 − [비율] + 단추(또는 Ctrl+휠, Ctrl+= / Ctrl+-)로 확대·축소, 맞추기 단추(Ctrl+0)로 다시 창 폭에 맞춥니다. 창보다 작으면 가운데에, 크면 스크롤로 봅니다.

  • 벡터 층은 뉴런 원(색 = 활성값), 그림 층은 채널별 특징 맵, 시퀀스 층은 유닛별 시간 띠로 보입니다.
  • 층과 층 사이는 선으로 연결됩니다: 완전연결은 가중치, 합성곱은 채널 사이 커널 합, 깊이별 합성곱은 채널 1:1, 순환층은 후보 게이트 가중치, 셀프 어텐션은 값·출력 가중치(Wv·Wo), 임베딩은 표의 값, 정규화·풀링·활성화는 1:1. 파랑 = 음수, 빨강 = 양수, 굵고 진할수록 큼. 선 보이기로 켜고 끕니다.
  • 뉴런 위에 마우스를 올리면 그 뉴런으로 들어오고 나가는 선이 강조됩니다.
  • 새 스냅샷이 오면 신호가 입력에서 출력으로 흘러가는 애니메이션이 나옵니다.
  • 뉴런 · 특징 맵의 픽셀 · 시간 걸음을 클릭하면 속성 패널에 그 값이 어떻게 계산됐는지 나옵니다.

모든 그래프 카드에는 제목이 있고, 제목(ⓘ)에 마우스를 올리면 그 카드가 무엇을 보여 주는지 설명이 나옵니다(데이터·테스트 탭도 같습니다). 분류 작업의 출력 확률 카드는 탐침 입력 하나를 지금의 모델에 넣었을 때 클래스(예: 경비·출근·퇴근·해제)마다의 확률이고, 글씨가 진한 막대가 실제 정답입니다. 맨 위에는 탐침 입력이 네트워크를 지나가는 뉴런 활성(선 연결)이 있어 학습하면서 바로 보입니다. 그 아래 차트: 손실(학습/검증, 지난 실행은 점선), 정확도 또는 학습률, 결정 경계(2차원 점, 왼쪽 정렬) · 학습된 곡선 · 원본/복원 · 출력 확률, 기울기 흐름(층별 평균 |∇W|), 층별 가중치 분포. 그래프와 그림은 원래 비율을 유지합니다.

  • 테스트 샘플: 이전/다음/무작위, 음성은 ▶로 듣기, 평가 후에는 틀린 것만 넘겨 보기.
  • 직접 입력: 그림 데이터는 검은 칸에 그리기, 2차원 점은 평면을 클릭, 텍스트는 문장 입력, 표·함수 데이터는 원래 단위의 값 입력(전처리는 자동 적용).
  • 텍스트 생성(글자 단위 언어 모델): 시작 글을 쓰고 글자 수와 온도를 골라 이어 쓰기를 누르면 모델이 다음 글자 확률에서 하나씩 뽑아 글을 이어 씁니다. 온도가 낮을수록 확실한 글자만, 높을수록 다양하게 씁니다.
  • 입력 고르기: 테스트 샘플 · 내 파일(그림·음성·CSV·텍스트 파일이나 폴더를 열어 바로 실행) · 예제(앱에 들어 있는, 학습에 쓰지 않은 예제 입력. 누르면 하나, 모두 실행은 전부) · 직접 입력. 고른 입력이 네트워크를 지나가고 예측이 아래에 나옵니다.
  • 마이크로 시험하기(음성 모델): 한 번 말하기를 누르고 4초 안에 한 단어를 말하면, 말이 끝나는 순간(잠깐 조용해지면) 그 단어 전체를 학습 데이터처럼 가운데에 맞춰 예측합니다. 계속 듣기는 단어가 끝날 때마다 하나씩 예측합니다(단어 일부만 보고 판단하지 않음). 마이크 감도(증폭)와 말소리 기준(이보다 작으면 "조용함")을 조절할 수 있고, 입력 크기 막대의 세로선이 기준입니다.
  • 웹캠으로 시험하기(그림·영상 모델): 웹캠을 켜고 찍어서 예측 또는 계속 인식. 화면 가운데 정사각형을 학습 그림과 같은 크기·채널로 바꾸고, 흰 종이에 그린 글씨는 자동으로 반전합니다. 영상 모델은 프레임 여러 장을 찍어 클립으로 예측합니다.
  • 입력 데이터 선택해서 실행: 그림(모든 형식) · 음성 · 동영상(MP4 · WebM · MOV …) · CSV · 텍스트 파일이나 폴더를 골라 한꺼번에 예측하고, 결과 표를 CSV 로 저장합니다.
  • 입력이 네트워크를 지나가는 모습이 뉴런 보기로 크게 나오고, 예측(클래스 확률 · 값 · 복원 그림)이 보입니다.
  • 성능 (추론 시간): 측정을 누르면 테스트 입력을 하나씩 정한 횟수(20 · 50 · 100 · 200)만큼 넣어 평균 ± 표준 편차, 최소 … 최대, 중앙값, p95 와, 한 번에 여러 개(최대 256)를 넣었을 때의 처리량(입력/초)을 보여 줍니다. 엔진에 요청해서 답을 받을 때까지(앱이 실제로 기다리는 시간)를 잽니다.
  • 평가(학습이 끝나면 자동): 정확도, 평균 F1, 손실, 클래스별 정밀도·재현율·F1, 혼동 행렬, 틀린 샘플 그림. 회귀는 MAE · RMSE · R², 예측-정답 그림과 오차 분포.
  • 복원 오차가 큰 샘플(오토인코더): 테스트 그림을 복원 오차(평균 제곱)가 큰 순서로 24개까지, 입력과 복원을 위아래로 보여 줍니다. 오토인코더는 흔한 그림만 잘 복원하므로 위쪽이 이상 후보입니다. 데이터에 이상 표시가 있으면(숫자 + 이상 그림) 실제 이상에 ● 가 붙어, 이상 탐지가 얼마나 맞았는지 보입니다. 누르면 그 샘플이 입력이 됩니다.

문제 해결 #

  • "모델에 오류가 있습니다" — 문제 탭을 보세요. 가장 흔한 것은 출력층의 뉴런 수가 클래스 수와 다른 경우, 그림 층 앞에 그림이 아닌 입력이 오는 경우, 셀프 어텐션의 특성 수가 헤드 수로 나누어떨어지지 않는 경우입니다.
  • 마이크/웹캠이 안 됨 — 권한을 허용했는지 확인하세요. 다른 프로그램이 카메라를 쓰고 있으면 켜지지 않습니다. 말해도 "조용함"이면 마이크 감도를 올리거나 말소리 기준을 내리세요.
  • PyTorch 엔진을 고를 수 없음 — 웹판에서는 PyTorch 엔진을 쓸 수 없습니다. 데스크톱 앱을 쓰세요.
  • PyTorch 가 없다고 나옴 — Python / PyTorch 환경 창에서 다시 찾기, 또는 설정의 Python 경로에 PyTorch 가 있는 Python 을 직접 적으세요.
  • PyTorch 로 내보내기가 안 됨 — PyTorch 엔진은 학습이 끝나고 실행 중일 때(종료 전) 내보낼 수 있습니다.
