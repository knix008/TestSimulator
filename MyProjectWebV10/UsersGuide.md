# MyProject Web 사용자 가이드

MyProject Web은 브라우저에서 사용하는 과제 일정 관리 프로그램입니다. Gantt 차트로 일정을 보고, 드래그로 변경하며, 작업 간 의존 관계를 연결할 수 있습니다. Windows 버전 **MyProjectWinV10**과 같은 DB를 쓰면 일정을 함께 관리할 수 있습니다.

## 1. 시작하기

### 프로그램 접속

개발 환경 기본 주소:

- **웹 UI**: http://localhost:5173
- **API**: http://localhost:3001

### 로그인

1. 브라우저에서 웹 UI 주소를 엽니다.
2. 로그인 화면에 ID와 비밀번호를 입력합니다.
3. **최초 관리자 계정**: `admin` / `admin`

> DB가 아직 연결되지 않은 상태에서는 bootstrap 계정으로만 로그인할 수 있습니다. DB 연결 후에는 `mp_users`에 저장된 계정으로 로그인합니다.

### DB 연결 (관리자) — 기존 DB 사용

**이미 MariaDB에 `myproject` DB와 일정 데이터가 있으면** 그 DB를 그대로 사용합니다. 데이터는 삭제되지 않습니다.

1. `admin` / `admin`으로 로그인
2. 상단 **DB 설정** 클릭
3. MariaDB 서버 정보 입력
   - **데이터베이스 이름**: `myproject` (기존 DB 이름과 동일하게)
   - 호스트, 포트, 사용자, 비밀번호
4. **연결 테스트** — `기존 데이터베이스 'myproject'에 연결되었습니다.` 확인
5. **저장 및 적용** — 기존 DB에 연결, 누락된 `mp_*` 테이블만 추가

> DB가 없는 경우에만 **저장 및 적용** 시 `myproject`가 새로 생성됩니다.

## 2. 화면 구성

```
┌──────────────────────────────────────────────────────────────┐
│  툴바 (프로젝트, 작업 편집, 주요 경로, 오늘로 이동, 설정…)    │
├──────────────────┬───────────────────────────────────────────┤
│   작업 그리드     │            Gantt 차트                     │
│  (목록·일정 표)   │     (막대, 연결선, 드래그 편집)            │
├──────────────────┴───────────────────────────────────────────┤
│  하단 속성 (선택 작업 정보, 선행 작업 목록)                    │
└──────────────────────────────────────────────────────────────┘
```

| 영역 | 설명 |
|------|------|
| 툴바 | 프로젝트 전환, 작업 추가·삭제, 계층 변경, 의존성 연결, 저장 상태 |
| 작업 그리드 | 작업 목록, 트리 펼치기/접기, 클릭하여 선택 |
| Gantt 차트 | 시간축 막대, 의존성 연결선, 드래그 편집 (그리드와 세로 스크롤 연동) |
| 하단 속성 | 선택한 작업의 이름·일정·진행률·선행 작업 |

작업 그리드와 Gantt 차트는 **같은 행 높이(32px)** 로 맞춰져 있으며, 한쪽을 스크롤하면 다른 쪽도 함께 움직입니다.

## 3. 프로젝트 관리

### 프로젝트 선택

툴바의 **프로젝트** 드롭다운에서 열 프로젝트를 선택합니다.

### 새 프로젝트

**새 프로젝트** 버튼으로 템플릿 프로젝트를 만들 수 있습니다. (수정 권한 필요)

> Windows **MyProjectWinV10**에서 프로젝트를 만드는 것을 권장합니다.

### 새로고침

**새로고침**으로 서버(DB)에서 최신 데이터를 다시 불러옵니다. Win 프로그램에서 수정한 내용을 반영할 때 사용합니다.

### 저장

일정·의존성·계층 변경 후 약 0.8초 뒤 **자동 저장**됩니다. 툴바 **저장** 버튼으로 즉시 저장할 수도 있습니다. `저장 중…` / `저장됨` / `미저장 변경` 상태가 표시됩니다.

## 5. 작업 계층 (요약 작업)

하위 작업을 가진 상위 작업은 **Summary(요약)** 로 표시됩니다.

| 표시 | 설명 |
|------|------|
| 작업 그리드 | 회색 배경, 굵은 글씨 |
| Gantt | 회색 막대, 양쪽 끝 아래 **작은 삼각형** (Win 표준 Summary 스타일) |

요약 작업의 시작·종료·기간은 하위 작업을 **자동 롤업**합니다. 요약 행의 일정·진행률은 직접 편집할 수 없습니다.

### 계층 변경 (수정 권한)

| 동작 | 방법 |
|------|------|
| 들여쓰기 (하위로) | 툴바 **들여쓰기** 또는 **Alt+→** |
| 내어쓰기 (상위로) | 툴바 **내어쓰기** 또는 **Alt+←** |
| 하위 작업 추가 | 작업 선택 후 **하위 작업** |
| 작업 추가 | **작업 추가** 또는 **Insert** |
| 작업 삭제 | **작업 삭제** 또는 **Delete** (하위 작업 포함 삭제) |

## 6. Gantt 차트 — 일정 변경

수정 권한이 있는 사용자만 편집할 수 있습니다.

| 동작 | 방법 |
|------|------|
| 작업 선택 | 막대 클릭 |
| 시작일 이동 | 막대를 좌우로 **드래그** |
| 기간 변경 | 막대 **양쪽 핸들** 드래그 |
| 진행률 변경 | 막대 위 **진행률 핸들** 드래그 |

막대·진행률 변경 시 **주요 경로(CPM)** 가 다시 계산됩니다. 근무일이 아닌 날은 타임라인에서 압축되어 표시될 수 있습니다(프로젝트 근무일 설정).

변경 내용은 자동으로 DB에 저장됩니다.

읽기 전용 사용자는 Gantt를 볼 수만 있고 편집할 수 없습니다.

## 7. 오늘 날짜 표시

오늘이 Gantt 표시 범위 안에 있을 때:

| 표시 | 설명 |
|------|------|
| **빨간 세로선** | 오늘 날짜 열 (헤더 아래~차트 하단) |
| **검은 배경 숫자** | 타임스케일 하단 행의 **날(day)** 숫자 |

**오늘로 이동** 버튼 또는 **Ctrl+T**로 오늘 위치로 가로 스크롤합니다.

오늘이 프로젝트 일정 범위 밖이면 이동할 수 없으며 안내 메시지가 표시됩니다.

## 8. 의존 관계 (작업 연결)

작업 간 **선행 → 후행** 관계를 설정합니다. 기본 종류는 **FS**(선행 작업 완료 후 후행 작업 시작)입니다.

### 방법 1: 의존성 연결 모드

1. 툴바 **의존성 연결** 클릭
2. **선행 작업** 막대 클릭
3. **후행 작업** 막대 클릭

### 방법 2: Alt + 드래그

1. **Alt** 키를 누른 채 선행 작업 막대에서 드래그
2. 후행 작업 막대에서 놓기

### 의존성 제거

1. 후행 작업을 선택
2. 하단 속성의 **선행** 목록에서 **×** 클릭

### 제한 사항

- 자기 자신과 연결 불가
- 이미 있는 연결 중복 불가
- 순환 의존성(A→B→A) 불가
- 요약(Summary) 작업에는 의존성을 연결하지 않습니다

연결선 스타일은 [과제 설정 — Gantt 표시](#10-과제-설정)에서 사용자마다 바꿀 수 있습니다.

## 9. 주요 경로 (Critical Path)

툴바 **주요 경로**를 켜면 Critical Path 작업·연결선이 강조됩니다.

- 그리드: 주요 작업 이름이 **붉은색**으로 표시
- Gantt: 주요 막대·의존선이 설정된 Critical 색으로 표시

일정·기간·의존성이 바뀔 때마다 자동으로 다시 계산됩니다.

기본 표시 여부는 **과제 설정 → Gantt 표시** 탭에서도 지정할 수 있습니다.

## 10. 과제 설정

툴바 **과제 설정**에서 두 가지 탭을 사용합니다.

### 프로젝트 일정 (프로젝트 전체, DB 저장)

| 항목 | 설명 |
|------|------|
| 프로젝트 이름 | `mp_projects`에 저장 |
| 프로젝트 시작일 | 프로젝트 기준 시작일 |
| 주간 근무일 | 일~토 체크 (최소 1일). 변경 시 작업 날짜·간트 **재계산** |

수정 권한이 있어야 저장할 수 있습니다.

### Gantt 표시 (사용자·프로젝트별)

| 항목 | 설명 |
|------|------|
| 기본 의존성 종류 | FS, FF, SS, SF |
| 선 종류 | 실선, 파선, 점선 |
| 경로 형태 | 직각, 곡선 |
| 선 시작 / 끝 도형 | 없음, 화살표, 원, 사각형 등 |
| 연결선 / Critical 색상 | 일반·주요 경로 선 색 |
| 주요 경로 표시 | 켜기/끄기 기본값 |

- Gantt 표시 설정은 **로그인한 사용자마다**, **프로젝트마다** `mp_user_project_view_settings`에 저장됩니다.
- **저장** 버튼을 눌러야 반영됩니다.
- 미리보기 영역에서 연결선 모양을 확인할 수 있습니다.

## 12. 내 계정

툴바 **내 계정**에서 본인 정보를 변경합니다.

- 사용자 ID 변경
- 비밀번호 변경
- 표시 이름, 이메일 변경

변경 시 **현재 비밀번호** 확인이 필요합니다. 저장 내용은 `mp_users` 테이블에 기록됩니다.

> DB 연결 전(bootstrap 세션)에는 계정 변경이 제한될 수 있습니다. DB 연결 후 DB 사용자로 다시 로그인하세요.

## 13. 관리자 기능

관리자(`role: admin`)에게만 표시되는 메뉴입니다.

### DB 설정

- DB 종류, 서버, 포트, DB 이름, 계정 설정
- 연결 테스트 / 저장 및 적용
- `myproject` DB가 없으면 생성

### 사용자 관리

- 사용자 추가·수정·삭제
- 역할: 관리자 / 일반 사용자
- 권한: **읽기**, **수정**

### 내 계정

관리자도 일반 사용자와 같이 본인 ID·비밀번호를 변경할 수 있습니다.

## 14. 사용자 권한

| 권한 | 할 수 있는 일 |
|------|----------------|
| 읽기 | 프로젝트·일정 조회, 과제 설정(Gantt 표시) |
| 수정 | 읽기 + 일정 드래그 변경, 작업·의존성 편집, 프로젝트 생성, 프로젝트 일정 저장 |
| 관리자 | 수정 + DB 설정, 사용자 관리 |

관리자는 읽기·수정 권한을 모두 가집니다.

## 15. 자주 묻는 질문

### Q. 로그인이 안 됩니다.

- ID/비밀번호 확인 (`admin` / `admin`은 최초 설정용)
- DB 연결 후에는 **사용자 관리**에 등록된 계정 사용
- DB 미연결 시 bootstrap 계정만 사용 가능

### Q. 프로젝트가 보이지 않습니다.

- 상단 DB 상태가 **연결됨**인지 확인
- 관리자로 **DB 설정** 완료 여부 확인
- 읽기 권한이 있는지 확인

### Q. 일정을 바꿀 수 없습니다.

- **수정** 권한이 있는 계정인지 확인
- 읽기 전용이면 Gantt가 보기 전용으로 동작합니다

### Q. 작업 목록과 Gantt 막대가 어긋납니다.

- 작업 그리드와 Gantt는 같은 **표시 작업 목록**(접힌 항목 제외)을 사용합니다.
- 트리에서 상위 작업을 **접으면** 하위 행이 숨겨지며 양쪽이 함께 맞춰집니다.
- 그래도 어긋나면 **새로고침** 후 다시 확인하세요.

### Q. 근무일을 바꿨는데 일정이 달라졌습니다.

정상 동작입니다. **과제 설정 → 프로젝트 일정**의 근무일 변경 시 작업 날짜가 근무일 기준으로 다시 맞춰집니다.

### Q. 과제 설정이 다른 PC와 다릅니다.

Gantt **표시** 설정은 **사용자·프로젝트별**로 저장됩니다. **프로젝트 일정**(근무일 등)은 DB에 하나만 저장됩니다.

### Q. Windows 버전(MyProjectWinV10)과 데이터를 공유할 수 있나요?

같은 MariaDB `myproject` DB와 `mp_*` 테이블을 사용하면 공유할 수 있습니다. Win에서 저장한 뒤 웹에서 **새로고침**하세요.

### Q. `npm run db:push`는 언제 하나요?

개발자가 스키마를 처음 적용하거나 테이블 구조가 바뀌었을 때 실행합니다. 일반 사용자는 **DB 설정 → 저장 및 적용**으로 대부분 처리됩니다. 자세한 내용은 [README.md](./README.md)를 참고하세요.
