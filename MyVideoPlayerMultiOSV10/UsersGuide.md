# MyVideoPlayer 사용자 가이드

버전 1.0.0 · 제작자 SHKWON (knix008@naver.com)

이 문서는 MyVideoPlayer를 처음 사용하는 분들을 위한 설명서입니다.

---

## 1. 소개

MyVideoPlayer는 동영상·오디오를 재생하는 프로그램입니다.

- **Windows / macOS / Linux** 데스크톱 앱
- 브라우저에서도 실행 가능 (`npm run web`)
- 로컬 파일과 YouTube 링크 재생
- 재생이 안 되는 파일은 데스크톱에서 호환 형식으로 자동 변환을 시도합니다
- 자막, 테마, 한글/영어, 스펙트럼, 단축키 지원

---

## 2. 설치 (Windows)

1. `MyVideoPlayer-Setup-*.exe` 설치 파일을 실행합니다.
2. 설치 경로를 선택합니다. (원하는 경우 변경 가능)
3. 바탕화면·시작 메뉴 바로가기 옵션을 확인합니다.
4. 설치가 끝나면 프로그램을 실행합니다.

**다시 설치할 때**  
이미 설치된 버전이 있으면 설치 프로그램이 기존 설치를 **완전히 제거한 뒤** 새로 설치합니다.  
(설정·최근 목록 등 사용자 데이터도 함께 정리될 수 있습니다.)

---

## 3. 화면 구성

### 상단 툴바

| 버튼 / 영역 | 기능 |
|-------------|------|
| 브랜드 (아이콘 + MyVideo V…) | 앱 이름·버전 표시. 이 영역과 가운데 빈 공간을 드래그하면 창 이동 |
| 폴더 | 미디어 파일 열기 |
| 시계 | 최근 재생 목록 (최대 10개) |
| CC | 자막 파일 열기 (SMI/SRT/VTT) |
| YouTube | YouTube URL 입력 |
| 다운로드 | 현재 YouTube 영상 저장 (데스크톱만) |
| 막대 그래프 | 스펙트럼 팝업 켜기/끄기 (`Shift`+클릭 또는 `Shift+A`로 스타일 전환) |
| 전체 화면 | 전체 화면 전환 |
| 투명도 슬라이더 | 창 투명도 (데스크톱만) |
| 지구본 + **ENG** / **한글** | 언어 전환. 현재가 한글이면 `ENG`, 영어면 `한글` 표시 |
| 팔레트 | 테마 선택 메뉴 |
| 톱니바퀴 | 설정 |
| i | 프로그램 정보 |
| ─ □ ✕ | 최소화 / 최대화 / 닫기 (데스크톱) |

툴바 **브랜드·가운데 빈 공간**을 드래그하면 창을 옮길 수 있고, **더블클릭**하면 최대화/이전 크기로 전환됩니다.  
창 **가장자리**를 드래그하면 크기를 바꿀 수 있습니다.

### 중앙 화면

- 동영상/오디오가 표시됩니다. 주변 여백 색은 선택한 테마를 따릅니다.
- 파일을 끌어다 놓아도 열립니다.
- YouTube URL을 붙여 넣을 수도 있습니다.
- 스펙트럼이 켜져 있으면 영상 위 팝업으로 표시되며, 제목 줄을 드래그해 위치를 옮길 수 있습니다.

### 하단 컨트롤

- 시크 바 (재생 위치, 진행 구간 강조)
- 이전 / 재생·일시정지 / 정지 / 다음
- 음량(0–100%) · 음소거
- 재생 배속

### 상태 표시줄

파일 이름, 형식, 자막, 재생 상태, 배속, 테마, 실행 환경(Web/데스크톱)을 보여 줍니다.  
언어를 바꾸면 상태 문구(재생 중, 배속, 테마 이름 등)도 함께 바뀝니다.

## 4. 기본 사용법

### 4.1 파일 열기

- 툴바 **열기** 버튼, 또는 `Ctrl+O`
- 화면으로 파일 **드래그 앤 드롭**
- 지원 예: MP4, WebM, MKV, MOV, MP3, AAC, WAV, FLAC 등  
  (H.265/HEVC는 PC 코덱 지원 여부에 따라 달라질 수 있습니다.)
- 데스크톱에서 재생 오류가 나면 **호환 변환**(리먹스 → H.264 재인코딩)을 자동으로 시도합니다.

### 4.2 재생 제어

| 동작 | 방법 |
|------|------|
| 재생 / 일시정지 | 재생 버튼 또는 **Space** |
| 정지 | 정지 버튼 또는 `S` / `.` |
| 앞·뒤로 이동 | `←` `→` 또는 `J` `L` (설정의 시크 간격만큼) |
| 처음으로 / 끝으로 | `Home` / `End` |
| 위치 점프 | 숫자 `0`–`9` (0%–90%) |
| 음량 | `↑` `↓` |
| 음소거 | `M` |
| 배속 | `[` `]` |
| 전체 화면 | `F` (종료는 `Esc`) |

### 4.3 자막

- 같은 폴더에 미디어와 **같은 이름**의 `.smi` / `.srt` / `.vtt`가 있으면 자동으로 불러옵니다.  
  예: `movie.mp4` → `movie.srt`
- 툴바에서 자막 파일을 직접 열 수도 있습니다.
- `C` 키 또는 설정에서 자막 표시를 켜고 끌 수 있습니다.
- 설정에서 자막 글자 크기를 바꿀 수 있습니다.

### 4.4 최근 재생

- 툴바 최근 버튼 또는 `Ctrl+R`
- 최대 10개까지 저장됩니다.
- 항목별 삭제 또는 전체 삭제가 가능합니다.
- **로컬 파일**을 목록에서 다시 여는 기능은 데스크톱 앱에서만 동작합니다.

---

## 5. YouTube

1. 툴바 YouTube 버튼 또는 `Ctrl+Y`
2. URL 또는 영상 ID를 입력하고 재생합니다.
3. **저장**(데스크톱): `Ctrl+S` 또는 저장 버튼으로 로컬에 내려받을 수 있습니다.

참고:

- 웹 모드에서는 재생만 가능하고 저장은 지원하지 않습니다.
- 다운로드 품질은 네트워크·영상에 따라 달라질 수 있습니다.
- PC에 `yt-dlp`가 설치되어 있으면 다운로드에 우선 사용됩니다.
- 마지막으로 저장한 폴더는 다음에 기억됩니다.

---

## 6. 설정

`Ctrl+,` 또는 툴바 설정 버튼으로 엽니다.

설정은 **모양 / 재생 / 화면** 섹션으로 나뉩니다.

| 항목 | 설명 |
|------|------|
| 언어 | English / 한국어 |
| 테마 | Dark, Light, Ocean, Forest 또는 사용자 테마 |
| 창 투명도 | 데스크톱에서 창 불투명도 (툴바 슬라이더와 동일) |
| 재생 배속 | 기본 배속 |
| 시크 간격 | ← → 이동 시간(초) |
| 시작 볼륨 | 실행 시 음량(%) |
| 자동 재생 | 파일 연 뒤 바로 재생 |
| 반복 재생 | 끝나면 다시 재생 |
| 자막 크기 | 글자 크기 |
| 스펙트럼 스타일 | 레인보우, 미러, 웨이브 등 |
| 자막 표시 | 자막 켜기/끄기 |
| 스펙트럼 표시 | 오디오가 있을 때 스펙트럼 팝업 표시 |

### 사용자 테마

1. 툴바 테마 메뉴 또는 설정 → 테마에서 **사용자 정의…**
2. 색을 고른 뒤 미리보기·저장
3. 필요하면 사용자 테마를 삭제할 수 있습니다.

대화상자(설정, 정보, 오류 등)와 영상 배경 여백도 선택한 테마 색을 따릅니다.

## 7. 단축키 요약

| 키 | 동작 |
|----|------|
| `Space` | 재생 / 일시정지 |
| `S` / `.` | 정지 |
| `←` / `J` | 뒤로 |
| `→` / `L` | 앞으로 |
| `Home` / `End` | 처음 / 끝 |
| `0`–`9` | 0%–90% 위치 |
| `↑` / `↓` | 볼륨 |
| `M` | 음소거 |
| `[` / `]` | 배속 감소 / 증가 |
| `F` | 전체 화면 |
| `Esc` | 전체 화면 종료 · 메뉴 닫기 |
| `A` | 스펙트럼 팝업 |
| `Shift+A` | 스펙트럼 스타일 전환 |
| `C` | 자막 표시 |
| `Ctrl+O` | 파일 열기 |
| `Ctrl+R` | 최근 재생 |

입력란이나 대화상자에 글자를 입력하는 중에는 대부분의 단축키가 동작하지 않습니다. (`Esc` 제외)

## 8. 웹에서 사용하기

개발자·테스트용으로 브라우저에서도 실행할 수 있습니다.

```bash
npm install
npm run web
```

브라우저에서 `http://localhost:5173` 을 엽니다.

웹 모드 제한:

- 창 최소화/최대화/투명도 없음
- YouTube **저장** 불가
- FFmpeg **호환 변환** 불가
- 최근 목록의 **로컬 파일 다시 열기** 불가 (보안상 경로 접근 제한)

## 9. 문제 해결

| 증상 | 확인 사항 |
|------|-----------|
| 재생이 안 됨 | 코덱 미지원일 수 있습니다. 데스크톱에서는 자동 변환을 기다린 뒤 다시 시도해 보세요. 수동으로는 MP4(H.264)+AAC로 변환할 수 있습니다. |
| 캐시 오류 / 창이 이상함 | Electron을 **한 번만** 실행하세요. 디버그용으로 두 개를 띄우면 캐시 충돌이 날 수 있습니다. |
| 자막이 안 보임 | 파일 이름이 영상과 같은지, 설정에서 자막 표시가 켜져 있는지 확인하세요. |
| 스펙트럼이 안 보임 | 미디어를 연 뒤 스펙트럼 버튼을 켜 두었는지 확인하세요. YouTube 모드에서는 표시되지 않습니다. |
| YouTube만 안 됨 | 네트워크·영상 제한(임베드 금지)일 수 있습니다. |
| 저장 실패 | 데스크톱 앱인지, 저장 경로 권한, `yt-dlp` 설치 여부를 확인하세요. |
| 단축키가 안 됨 | 입력란에 포커스가 가 있지 않은지, 창이 활성화되어 있는지 확인하세요. Space는 재생/일시정지입니다. |
| 오류 창 | **복사**로 내용을 저장한 뒤 문의 시 첨부하면 도움이 됩니다. |

---

## 10. 제거

Windows: **설정 → 앱 → 설치된 앱**에서 MyVideoPlayer를 제거하거나, 설치 폴더의 Uninstall을 실행합니다.  
제거 시 앱 데이터도 함께 삭제되도록 구성되어 있습니다.
