# MyVideoPlayer 사용자 가이드

버전 1.0.0 · 제작자 SHKWON (knix008@naver.com)

이 문서는 MyVideoPlayer를 처음 사용하는 분들을 위한 설명서입니다.  
개발·구조 설명은 [Architecture.md](Architecture.md), 실행·빌드 요약은 [README.md](README.md)를 보세요.

---

## 1. 소개

MyVideoPlayer는 동영상·오디오를 재생하는 프로그램입니다.

- **Windows / macOS / Linux** 데스크톱 앱 (Electron)
- 브라우저에서도 실행 가능 (`npm run web`)
- 로컬 파일: HTTP Range 스트리밍으로 재생
- 재생이 안 되는 파일은 데스크톱에서 **호환 변환**(리먹스 → H.264)을 자동 시도
- YouTube 재생·저장, RTSP 시청·녹화, 자막(SMI/SRT/VTT), 테마, 한글/영어
- 화면 맞춤(가득 채움 / 비율 유지 / 원본 크기), **화면 회전**(90° 단위), **축소 모드**, 재생 목록·스펙트럼 창, `Esc` 일괄 최소화, 단축키

설정·최근 목록·대화상자 폴더는 데스크톱에서 사용자 데이터(`persist.json`)에 저장됩니다. 웹에서는 브라우저 `localStorage`를 사용합니다.

## 2. 설치

### 2.1 Windows (설치 파일)

1. `MyVideoPlayer-Setup-*.exe` 를 실행합니다.  
   (개발자가 만든 경우: 프로젝트에서 `npm run build:win` → `dist/` 또는 프로젝트 루트)
2. 설치 경로를 선택합니다.
3. 바탕화면·시작 메뉴 바로가기 옵션을 확인합니다.
4. 설치가 끝나면 프로그램을 실행합니다.

**다시 설치할 때**  
이미 설치된 버전이 있으면 설치 프로그램이 기존 설치를 **완전히 제거한 뒤** 새로 설치합니다.  
(설정·최근 목록 등 사용자 데이터도 함께 정리될 수 있습니다.)

### 2.2 macOS / Linux

| OS | 빌드 명령 | 결과물 예 |
|----|-----------|-----------|
| macOS | `npm run build:mac` | `dist/` 아래 DMG, zip |
| Linux | `npm run build:linux` | `dist/` 아래 AppImage, deb |

해당 OS(또는 동일 환경 CI)에서 빌드하는 것을 권장합니다.  
자세한 빌드 표는 [Architecture.md §8 Packaging](Architecture.md) 및 [README.md](README.md)를 참고하세요.

### 2.3 개발용으로 바로 실행

```bash
npm install
npm start          # 데스크톱 (yt-dlp 번들도 준비)
npm run web        # 브라우저 http://localhost:5173
```

Electron은 **한 인스턴스만** 실행하세요. 동시에 두 개를 띄우면 캐시 충돌이 날 수 있습니다.

## 3. 화면 구성

### 상단 툴바

| 버튼 / 영역 | 기능 |
|-------------|------|
| 브랜드 (아이콘 + MyVideo V…) | 앱 이름·버전. 이 영역과 가운데 빈 공간을 드래그하면 창 이동 (IPC 드래그) |
| 폴더 | 미디어 파일 열기 |
| 시계 | 최근 재생 메뉴 (최대 30개) |
| 목록 | **재생 목록** 창 열기/닫기 (`Ctrl+L`) |
| CC | 자막 파일 열기 (SMI/SRT/VTT) |
| YouTube | YouTube 또는 RTSP URL 입력 |
| 다운로드 / 멈춤 | YouTube 저장 또는 RTSP 녹화 시작·종료 (데스크톱) |
| 회전 ↺ / 각도 / ↻ | **화면 회전**. 왼쪽·오른쪽 버튼이 각각 90°씩 돌리고, 가운데 각도 표시를 누르면 해제됩니다 |
| 막대 그래프 | 스펙트럼 창 켜기/끄기 (`Shift`+클릭 또는 `Shift+A`로 스타일 전환) |
| 전체 화면 | 전체 화면 전환 |
| 축소 / 확장 | **축소 모드** 전환. 축소 시 PIP 아이콘, 확장 시 전체 레이아웃 아이콘 |
| 투명도 슬라이더 | **플레이어 창** 투명도 (데스크톱만). 스펙트럼·재생 목록 창은 각 창 제목줄에서 따로 조절 |
| 지구본 + **ENG** / **한글** | 언어 전환. 현재가 한글이면 `ENG`, 영어면 `한글` |
| 팔레트 | 테마 선택 메뉴 |
| 톱니바퀴 | 설정 (재생 중에도 열 수 있음) |
| i | 프로그램 정보 |
| ─ □ ✕ | **모든 앱 창** 최소화 / 최대화 / 닫기 (데스크톱). 최소화는 `Esc`와 같이 스펙트럼·재생 목록도 함께 접힘 |

- 브랜드·가운데 빈 공간 **드래그** → 창 이동, **더블클릭** → 최대화/복원  
- 창 **가장자리** 드래그 → 크기 변경  
- 창 너비는 툴바 버튼이 가려지지 않도록 **최소 폭**이 제한됩니다.

### 중앙 화면

- 동영상/오디오가 표시됩니다. 주변 여백 색은 테마의 무대 색(`--bg-stage`)을 따릅니다.
- 파일을 끌어다 놓아도 열립니다.
- YouTube / RTSP URL을 붙여 넣을 수도 있습니다.
- **화면 맞춤**에 따라 영상이 무대를 채우거나(잘림), 비율을 유지하거나, 원본 픽셀 크기로 표시됩니다.
- 가로·세로가 뒤바뀐 채로 저장된 영상은 **화면 회전**으로 바로 세워서 볼 수 있습니다. 자막·스펙트럼 표시는 회전하지 않습니다.
- 스펙트럼이 켜져 있으면 **별도 창**으로 표시됩니다. 각 창 상단에서 **자기 창 투명도**만 조절합니다. (YouTube 모드에서는 표시되지 않습니다.)
- 재생 목록도 **별도 창**입니다 (`Ctrl+L` / 목록 버튼).
- YouTube·RTSP 저장/연결 중에는 화면 위 **진행 팝업**이 뜨며, 영상을 가리지 않는 플로팅 형태입니다. 연결을 누르면 URL 창이 닫히고 단계별 진행률이 보이며, 완료될 때까지 다시 누르지 않아도 됩니다.

### 축소 모드

툴바 **축소/확장** 버튼으로 전환합니다. 선택은 다음에 앱을 열어도 유지됩니다.

| 모드 | 보이는 항목 |
|------|-------------|
| 축소 | 브랜드 아이콘, **파일 열기**, 축소 해제, 창 버튼 · 시크/재생·정지·이전·다음 · 음량 · 화면 맞춤 · 화면 회전 ↺ ↻ |
| 확장 | 전체 툴바 · 컨트롤 · 상태 표시줄 |

- 축소 아이콘(PIP)과 확장 아이콘(전체 레이아웃)이 서로 다릅니다.
- 데스크톱에서는 창을 작게 줄였다가, 확장 시 이전 창 크기로 복원합니다.
- 축소 모드에서도 **파일 열기**와 드래그 앤 드롭으로 미디어를 열 수 있습니다.
- 축소 모드로 전환해도 **스펙트럼 창**·**재생 목록 창**은 그대로 유지됩니다.
- 축소 모드에서는 버튼·슬라이더가 겹치지 않도록 **최소 창 크기**가 제한됩니다.

### 재생 목록 창

- 툴바 **목록** 버튼 또는 `Ctrl+L`로 별도 창을 열고 닫습니다 (스펙트럼 창과 같은 방식).
- 최근 재생한 로컬 파일 / YouTube / RTSP 항목이 표시됩니다 (최대 30개).
- 항목을 클릭하면 다시 재생합니다. 항목 삭제·전체 삭제가 가능합니다.
- 창 표시 여부는 설정에 기억됩니다. 축소 모드에서도 창을 유지합니다.
- 제목줄에서 **이 창의 투명도**만 조절할 수 있습니다.
- 데스크톱에서 `Esc`(또는 툴바 최소화)로 접으면 플레이어·스펙트럼과 **함께** 최소화되고, 작업 표시줄에서 아무 창이나 다시 선택하면 같이 복원됩니다.

### 하단 컨트롤

- 시크 바 (재생 위치, 진행 구간 강조)
- 이전 / 재생·일시정지 / 정지 / 다음
- 음량(0–100%) · 음소거
- **화면 맞춤** (화면을 꽉 채움 / 비율 유지 / 원본)
- 재생 배속

### 상태 표시줄

파일 이름, 형식, 자막, 재생 상태, 배속, 테마, 실행 환경(Web/데스크톱)을 보여 줍니다.  
언어를 바꾸면 상태 문구(재생 중, 배속, 테마 이름 등)도 함께 바뀝니다.

## 4. 기본 사용법

### 4.1 파일 열기

- 툴바 **열기** 버튼, 또는 `Ctrl+O`
- 화면으로 파일 **드래그 앤 드롭**
- 지원 예: MP4, WebM, MKV, MOV, MP3, AAC, WAV, FLAC 등  
  (H.265/HEVC는 PC 코덱 지원 여부에 따라 달라질 수 있습니다.)
- 데스크톱에서 재생 오류가 나면 **호환 변환**을 자동으로 시도합니다. 변환 결과는 앱 데이터 폴더의 캐시에 보관됩니다.

### 4.2 재생 제어

| 동작 | 방법 |
|------|------|
| 재생 / 일시정지 | 재생 버튼 또는 **Space** |
| 정지 | 정지 버튼 또는 `S` / `.` |
| 앞·뒤로 이동 | `←` `→` 또는 `J` `L` (설정의 시크 간격만큼) |
| 처음으로 / 끝으로 | `Home` / `End` |
| 위치 점프 | 숫자 `0`–`9` (0%–90%) |
| 음량 | `↑` `↓` |
| 음소거 | `M` |
| 배속 | `[` `]` |
| 전체 화면 | `F` (종료는 `Esc`) |
| 모든 창 최소화 | `Esc` (메뉴·대화상자가 없을 때, 데스크톱). 작업 표시줄에서 다시 선택하면 함께 복원 |

### 4.3 화면 맞춤

하단 제어바의 **화면 맞춤** 버튼에서 선택합니다. 선택은 다음에 앱을 열어도 유지됩니다.

| 모드 | 설명 |
|------|------|
| 화면을 꽉 채움 | 무대를 가득 채웁니다. 비율이 다르면 가장자리가 잘릴 수 있습니다. |
| 비율 유지 | 잘리지 않게 무대 안에 맞춥니다. (기본값) |
| 원본 | 영상의 원래 픽셀 크기로 표시합니다. |

### 4.4 화면 회전

가로·세로가 뒤바뀐 채로 다운로드된 영상을 바로 세울 때 씁니다. 툴바 오른쪽의 **회전** 묶음(↺ · 각도 · ↻), 화면 오른쪽 클릭 메뉴의 **화면 회전**, 또는 `R` 키로 조절합니다.

| 조작 | 동작 |
|------|------|
| ↻ 버튼 · `R` | 오른쪽(시계 방향)으로 90° |
| ↺ 버튼 · `Shift+R` | 왼쪽(반시계 방향)으로 90° |
| 가운데 각도 표시 · 메뉴의 **회전 없음** | 회전 해제 (0°). 이미 0°이면 눌리지 않습니다 |

- 왼쪽·오른쪽이 **각각 별도 버튼**이므로 조합 키 없이 원하는 방향으로 돌릴 수 있습니다.
- 가운데 표시는 현재 각도(0° / 90° / 180° / 270°)를 보여 주며, 회전 중일 때는 강조 색으로 바뀝니다.
- **축소 모드**에서도 ↺ ↻ 두 버튼은 그대로 남습니다 (가운데 각도 표시만 숨겨집니다).
- 90°·270°에서는 **화면 맞춤** 설정이 회전된 방향을 기준으로 다시 적용되므로, 세로 영상을 눕히면 화면 너비에 맞게 채워집니다.
- 자막·스펙트럼·진행 팝업은 함께 회전하지 않고 똑바로 유지됩니다.
- YouTube 재생 중에는 회전할 수 없습니다 (YouTube 플레이어는 앱이 직접 그리지 않습니다).

**툴바 회전과 설정의 관계**

| 위치 | 적용 범위 |
|------|-----------|
| 툴바 버튼 · 우클릭 메뉴 · `R` | **지금 재생 중인 영상**만. 다른 파일을 열면 설정의 기본값으로 돌아갑니다 |
| 설정 → 화면 → **열 때 화면 회전** | 파일을 열 때마다 적용되는 **기본값**. 앱을 다시 열어도 유지됩니다 |

세로로 찍힌 영상을 주로 본다면 설정에서 기본값을 90°로 두고, 어쩌다 한 번인 파일은 툴바 버튼으로 돌리면 됩니다.

### 4.5 축소 모드

1. 툴바에서 **축소** 버튼(PIP 아이콘)을 누릅니다.
2. 작은 창에서 재생·볼륨·파일 열기만 사용합니다.
3. **확장** 버튼(전체 레이아웃 아이콘)으로 원래 화면으로 돌아갑니다.
4. 스펙트럼·재생 목록 창이 열려 있었다면 축소 중에도 그대로 둡니다.

### 4.6 자막

- 같은 폴더에 미디어와 **같은 이름**의 `.smi` / `.srt` / `.vtt`가 있으면 자동으로 불러옵니다.  
  예: `movie.mp4` → `movie.srt`
- 툴바에서 자막 파일을 직접 열 수도 있습니다.
- `C` 키 또는 설정에서 자막 표시를 켜고 끌 수 있습니다.
- 설정에서 자막 글자 크기를 바꿀 수 있습니다.

### 4.7 최근 재생 · 재생 목록

- 툴바 최근(시계) 버튼 또는 `Ctrl+R` → 빠른 최근 메뉴
- 툴바 목록 버튼 또는 `Ctrl+L` → **재생 목록** 별도 창
- 최대 30개까지 저장됩니다 (로컬 / YouTube / RTSP).
- 항목별 삭제 또는 전체 삭제가 가능합니다.
- **로컬 파일**을 목록에서 다시 여는 기능은 데스크톱 앱에서만 동작합니다.
- 축소 모드에서도 재생 목록 창은 유지됩니다.

## 5. YouTube

1. 툴바 YouTube 버튼 또는 `Ctrl+Y`
2. URL 또는 영상 ID를 입력하고 재생합니다. (`youtu.be` 짧은 링크도 가능)
3. 연결이 시작되면 URL 창이 닫히고 **진행 팝업**에 단계(정보 가져오기 → 플레이어 로딩 → 완료)가 표시됩니다. 연결 중에는 버튼이 **연결 중…**으로 바뀌어 중복 클릭을 막습니다.
4. **저장**(데스크톱): `Ctrl+S` 또는 저장 버튼으로 로컬에 내려받을 수 있습니다.
5. 저장 중 **멈춤**을 누르면 지금까지 받은 분량을 가능한 범위에서 남기고 재생할 수 있습니다.

참고:

- 웹 모드에서는 재생만 가능하고 저장은 지원하지 않습니다.
- 다운로드 품질은 네트워크·영상에 따라 달라질 수 있습니다.
- 앱에 포함된 `yt-dlp`를 우선 사용합니다. (없어도 `youtubei.js`로 시도할 수 있습니다.)
- 일부 영상은 로그인이 필요할 수 있으며, 데스크톱에서 안내되는 경우 브라우저 로그인으로 쿠키를 사용할 수 있습니다.
- 마지막으로 열기/저장한 폴더는 다음에 기억됩니다.

## 6. RTSP (데스크톱)

1. YouTube/URL 대화상자에 `rtsp://` 또는 `rtsps://` 주소를 입력하거나, 화면에 URL을 붙여 넣습니다.
2. 연결이 시작되면 진행 팝업에 **RTSP 연결 중** 단계가 표시됩니다. (영상에 오디오 트랙이 있으면 소리도 함께 재생됩니다.)
3. 연결이 되면 라이브 스트림이 재생됩니다.
4. **저장**(`Ctrl+S`)으로 MP4 녹화를 시작할 수 있습니다.
5. 녹화 중 **멈춤**/저장을 다시 누르면 파일을 확정한 뒤 이어서 재생할 수 있습니다.

웹 모드에서는 RTSP를 지원하지 않습니다.

## 7. 설정

`Ctrl+,` 또는 툴바 설정 버튼으로 엽니다.  
설정·정보 창을 열어도 **재생은 계속**됩니다. (`Esc`로 닫기)

설정은 **모양 / 재생 / 화면** 섹션으로 나뉩니다.

| 항목 | 설명 |
|------|------|
| 언어 | English / 한국어 |
| 테마 | Dark, Light, Ocean, Forest 또는 사용자 테마 |
| 창 투명도 | 데스크톱 **플레이어** 창 상단 슬라이더로 해당 창만 조절. 스펙트럼·재생 목록은 각 창 제목줄 슬라이더 |
| 재생 배속 | 기본 배속 |
| 시크 간격 | ← → 이동 시간(초) |
| 시작 볼륨 | 실행 시 음량(%) |
| 자동 재생 | 파일 연 뒤 바로 재생 |
| 반복 재생 | 끝나면 다시 재생 |
| 자막 크기 | 글자 크기 |
| 열 때 화면 회전 | 파일을 열 때 적용할 기본 회전 각도 (0° / 90° / 180° / 270°). [4.4 화면 회전](#44-화면-회전) 참고 |
| 스펙트럼 스타일 | 레인보우, 미러, 웨이브, 방사형, 파티클, 네온, 리본, 플레임, 오빗, 터널, 스타필드, 펄스, LED 블록, 스파이럴, 리퀴드 |
| 자막 표시 | 자막 켜기/끄기 |
| 스펙트럼 표시 | 로컬 미디어 재생 시 별도 스펙트럼 창 표시 |
| 툴바·제어바·상태바 자동 숨김 | 켜면 재생 중 바가 사라지고, 상·하 가장자리에 마우스를 올리면 다시 표시. 끄면 항상 표시 |

화면 맞춤·재생 목록 창·축소 모드 표시는 제어바·툴바에서 바꾸며, 설정 파일에 함께 저장됩니다. **열 때 화면 회전**은 설정 창의 **화면** 항목에 있습니다 (툴바 회전 버튼은 저장되지 않는 일회성 조정입니다).

### 사용자 테마

1. 툴바 테마 메뉴 또는 설정 → 테마에서 **사용자 정의…**
2. 색을 고른 뒤 미리보기·저장
3. 필요하면 사용자 테마를 삭제할 수 있습니다.

대화상자·툴바 메뉴·영상 배경 여백도 선택한 테마(및 밝은/어두운 대비)를 따릅니다.

개발·테스트용으로 브라우저에서도 실행할 수 있습니다.


웹 모드 제한 ([Architecture.md](Architecture.md)와 동일):

- 창 최소화/최대화/투명도·캡션 버튼 없음

## 10. 문제 해결

| 증상 | 확인 사항 |
|------|-----------|
| 재생이 안 됨 | 코덱 미지원일 수 있습니다. 데스크톱에서는 자동 변환이 끝날 때까지 기다리세요. 필요하면 MP4(H.264)+AAC로 변환하세요. |
| 캐시 오류 / 창이 이상함 | Electron을 **한 번만** 실행하세요. |
| 자막이 안 보임 | 파일 이름이 영상과 같은지, 설정에서 자막 표시가 켜져 있는지 확인하세요. |
| 스펙트럼이 안 보임 | 로컬 미디어를 연 뒤 스펙트럼 버튼을 켜 두었는지 확인하세요. YouTube 모드에서는 나오지 않습니다. 별도 창이 다른 모니터 뒤에 있을 수 있습니다. |
| Esc로 창이 사라짐 | 데스크톱에서는 메뉴가 없을 때 `Esc`가 **모든 앱 창**을 최소화합니다. 작업 표시줄에서 다시 선택하면 함께 돌아옵니다. |
| YouTube만 안 됨 | 네트워크·임베드 제한일 수 있습니다. |
| YouTube 저장 실패 | 데스크톱 앱인지, 저장 경로 권한, 앱 재시작(번들 yt-dlp)을 확인하세요. |
| YouTube/RTSP 연결이 멈춘 것 같음 | 진행 팝업과 상태 표시줄을 확인하세요. 연결 중에는 재생 버튼을 다시 누르지 마세요. 취소를 누르면 중단됩니다. |
| RTSP 연결 실패 | URL(`rtsp://` / `rtsps://`), 네트워크, 카메라 권한을 확인하세요. |
| RTSP에 소리가 없음 | 소스에 오디오 트랙이 있는지 확인하세요. 있으면 AAC로 함께 재생됩니다. |
| 영상이 옆으로 누워서 나옴 | 가로·세로가 뒤바뀐 채로 저장된 파일입니다. 툴바의 ↺ ↻ 버튼이나 `R` 키로 바로 세우세요. 이런 파일이 잦다면 설정 → 화면 → **열 때 화면 회전**에 기본 각도를 지정하세요. [4.4 화면 회전](#44-화면-회전) |
| 회전 버튼이 눌리지 않음 | YouTube 재생 중에는 회전할 수 없습니다. 가운데 각도 표시는 이미 0°일 때 비활성입니다. |
| 축소 모드에서 버튼이 없음 | 축소 모드에서는 열기·재생 컨트롤·화면 맞춤·화면 회전(↺ ↻)·축소 해제만 보입니다. 확장 버튼으로 전체 UI를 복원하세요. |
| 단축키가 안 됨 | 입력란에 포커스가 없는지, 창이 활성화되어 있는지 확인하세요. |
| 오류 창 | **복사**로 내용을 저장한 뒤 문의 시 첨부하면 도움이 됩니다. |
| 창을 너무 줄일 수 없음 | 툴바 버튼이 가려지지 않도록 최소 너비가 적용되어 있습니다. |
| 터미널에 ffmpeg 로그 | 기본 실행에서는 숨깁니다. 디버그가 필요하면 `MYVIDEOPLAYER_VERBOSE=1`로 실행하세요. |
