MyProductionFlow tutorial

The in-app Tutorial, chapter by chapter and step by step. It has 6 chapters and 27 steps and shows every feature by driving the real program. The pictures were taken while the tutorial ran in the web version (npm run tutorial:docs takes them again).

Running the tutorial #

  • Start page › Start the tutorial, the Tutorial button at the right of the toolbar, Help › Tutorial or F11.
  • In the card at the bottom right: Next / Previous step one step at a time, Auto play to the end, the chapter list to jump to a chapter, ✕ or Esc to stop at any time. Drag the card by its header to move it.
  • The tutorial works in a project of its own (the 84 m² apartment template). Your open project comes back when it ends, and the settings it changes (theme, language, panels …) are put back.
  • While it runs, popups (menus, Settings, the render window) open inside the main window instead of their own windows.
  • Every feature is explained in detail in the User's guide.

1. Start #

1. Welcome to MyProductionFlow #

Draw the flow of a factory, warehouse or road network with blocks and simulate it. Press Next to see every feature in turn.

2. Templates #

Start straight away from a basic process, conveyor, warehouse, traffic, system dynamics or agent template.

3. Sample models #

60 samples (10 per group): manufacturing, logistics, services, traffic, rail, pedestrians, SD, fluids and agents. Click one to open it; F5 runs it.

2. Building a model #

4. The workspace #

Left: the block library. Centre: the 2D editor and the 3D view. Right: the model list and properties. Bottom: statistics, charts, problems and experiments.

5. Library #

137 blocks in 12 categories: process, machines, handling, warehouse, traffic, rail, pedestrians, fluids, SD, agents, analysis, layout. Drag one onto the canvas, or click it and then click where it goes.

6. Placing blocks #

Click where the block goes. With one block selected, the new one is connected to it automatically. Conveyors, roads and walls take one click per point.

7. Connecting #

Drag a block's green dot (output) onto the next block to connect them. With the connect tool (C), drag from block to block.

8. Properties #

Edit the process time distribution (with a histogram preview), capacity, workers, reject rate and breakdowns (MTBF, MTTR) right here.

9. Model list #

Every block by category. Click to select, double-click to go to it.

10. Model check #

Unconnected outputs, wrong expressions, missing pools and more are found while you edit. Click one to go to the block.

3. Running and animation #

11. Run bar #

Run (F5), step one event (F6), stop, run to the end (F7). It shows model time, progress, events and speed.

12. 2D animation #

Entities move, and blocks show their state colour (busy green, idle yellow, blocked orange, failed red) and a utilization bar. The red lines on the top and left rulers mark the mouse; the 5 × 5 grid keeps its size while you zoom. The red circle in the run bar records the animation as a video.

13. 3D animation #

The same model in 3D. Drag to orbit, right-drag to pan, wheel to zoom. Blocks can be picked and moved in 3D too. The eye button in the run bar makes the camera follow an entity.

14. Speed #

How much model time passes per second. The [ and ] keys change it too.

15. Live statistics #

Select a block while running to see its utilization, waiting and throughput live.

4. Analysis and experiments #

16. Statistics #

Throughput, cycle time, WIP and bottleneck cards, advice, and tables for stations, queues and handling.

17. Analysis #

After a run the bottom panel lists the problems found (bottlenecks, blocking, breakdowns, waiting, overload, overflow) with the numbers, the cause and the fixes. Apply puts a fix into the model.

18. Charts #

The model's charts, WIP and output, a station state timeline and the cycle time distribution. Add chart plots any value.

19. Experiments #

Parameter variation, Monte Carlo replications, optimization, sensitivity analysis (tornado) and multi-parameter optimization run the model many times to find the best value. Save runs as scenarios to compare them side by side.

20. Report #

A report with settings, results, advice and charts to print or save as HTML or CSV.

5. SD, agents, traffic #

21. System dynamics #

Stocks, flows and parameters make continuous models (Bass diffusion). Equations use the names; parameters change with sliders while running.

22. Agents #

Moving agents change state by their statechart (SIR epidemic): contact, rate, timeout and condition transitions.

23. Hybrid #

SD demand sets the arrival rate of a process, and the process output fills an SD stock: all three methods in one model.

24. Traffic #

Roads and traffic lights make a junction; watch the queues build up.

6. Files and settings #

25. Saving #

Models are saved as .mpf (JSON) files that open with a double click in Explorer.

26. Settings #

The default view, grid snap, ports and names, 3D quality and shadows, and the time unit of new models.

27. Done #

Run the tutorial again any time with F11 or this button. The user's guide is in the Help menu too.

Run the tutorial again any time from Help › Tutorial (F11). A recording of the whole tour plays from Help › Tutorial video (once made with npm run tutorial:video).
