## 시작하기 / Getting Started

### 데스크톱 앱 / Desktop

```bash
npm install
npm start
```

또는 빌드된 **Image Viewer Setup** 설치 파일을 실행합니다.

### 웹 브라우저 / Web

```bash
npm install
npm run web
```

브라우저에서 **http://127.0.0.1:8080** 을 엽니다.

## 실행 모드 / Run Modes

| | 데스크톱 (Electron) | 웹 (Browser) |
|--|---------------------|--------------|
| 실행 | `npm start` 또는 설치본 | `npm run web` |
| 탐색기 | 실제 드라이브 (`C:`, `D:` …) | **Local Files** 가상 루트 |
| 파일/폴더 열기 | OS 대화상자 | 브라우저 파일/폴더 선택 |
| 마지막 폴더 복원 | 자동 | 세션마다 다시 열기 필요 |
| 탐색기에서 표시 / 삭제 | 지원 | 미지원 |
| 촬영 정보 (EXIF 등) | 지원 | 파일 크기·날짜 수준 |

데스크톱에서는 마지막에 열었던 폴더가 자동으로 복원됩니다.  
웹에서는 **파일 열기** / **폴더 열기** 또는 드래그 앤 드롭으로 시작합니다.

## 인터페이스 / Interface

Windows / Linux 데스크톱은 **테두리 없는 창**입니다. 제목줄 역할은 툴바가 합니다.

```
┌─────────────────────────────────────────────────────────────┐
│  [아이콘 Image Viewer V1.0.2]  툴바 … 줌  [─ □ ×]            │
├─────────────────┬───────────────────────────────────────────┤
│  탐색기          │                                           │
│  (전체 경로 표시) │          이미지 뷰어                        │
│  C: / D: / …    │          (Canvas 기반)                     │
│  (파일 트리)     │                                           │
├─────────────────┤                                           │
│  파일 정보       │              [효과 패널]                   │
│  파일 / 촬영 /   │              (우측 오버레이)                │
│  위치 / 전체 태그 │                                           │
├─────────────────┴───────────────────────────────────────────┤
│  [상태바: 줌 % | 크기 | 형식 | n/m]                          │
└─────────────────────────────────────────────────────────────┘
```

- 툴바를 드래그하면 창을 이동합니다.
- 오른쪽 위 **최소화 / 최대화 / 닫기**로 창을 제어합니다. 닫기는 저장하지 않은 변경이 있으면 확인합니다.
- `F11`으로 전체 화면을 켜고 끕니다.

### 사이드바 크기 조절

- **좌우**: 사이드바 오른쪽 경계 드래그
- **상하**: 파일 트리와 파일 정보 패널 사이 구분선 드래그
- 처음에는 탐색기와 파일 정보 창 **높이가 같습니다**. 구분선을 움직이면 그 비율이 저장됩니다.

## 이미지 열기 / Opening Images

### 지원 형식

| 카테고리 | 형식 |
|---------|-----|
| 기본 이미지 | JPEG, PNG, GIF, BMP, WebP, AVIF, SVG, ICO |
| 고급 이미지 | TIFF, HEIC / HEIF / HIF, DICOM (.dcm, .dicom) |
| 동영상 | MP4, WebM, MOV, MKV, AVI, FLV, WMV 등 (재생만) |
| 오디오 | MP3, WAV, FLAC, AAC, OGG 등 (재생만) |

### 여는 방법

- **파일 열기**: 툴바 버튼 또는 `Ctrl+O`
- **폴더 열기**: 툴바 버튼 또는 `Ctrl+Shift+O`
- **드래그 앤 드롭 (뷰어)**: 창 중앙에 놓으면 해당 파일/폴더를 **엽니다**
- **드래그 앤 드롭 (탐색기)**: 트리의 **특정 폴더** 위에 놓으면 그 폴더로 **복사**합니다 (`Shift`를 누른 채 놓으면 **이동**)
- **탐색기**: 트리에서 이미지 클릭
- **탐색기에서 더블클릭** (설치본, 파일 연결이 켜진 경우): 이미 실행 중이면 그 창에서 파일을 엽니다

> 파일/폴더 대화상자는 **마지막으로 열었던 폴더**를 기본 위치로 엽니다 (데스크톱).

## 탐색기 / Explorer

### 데스크톱

- 최상위에 **드라이브**가 표시됩니다 (예: `C:`, `D:`).
- 폴더를 펼치면 하위 항목이 로드됩니다.
- 상단 경로 바에 **전체 경로**가 표시됩니다 (예: `C:\Users\...\Pictures`).
- 외부 파일을 폴더 행 위에 드롭하면 해당 디렉터리로 복사됩니다. 같은 이름이 있으면 `파일 (1).ext`처럼 저장됩니다.
- 폴더를 선택해 둔 상태에서 탐색기 빈 영역에 놓아도 그 폴더로 복사됩니다.
- 탐색기의 파일/폴더를 **밖으로 드래그**하면 바탕화면·Windows 탐색기 등으로 **복사**됩니다 (여러 개 선택 가능).
- 우클릭 **폴더로 복사…** / **폴더로 이동…**으로 대상 폴더를 골라 내보내기할 수 있습니다.

### 웹

- **Local Files** 루트가 표시됩니다.
- **폴더 열기**로 선택한 폴더가 이 루트에 마운트됩니다.
- 브라우저 보안상 OS 드라이브에 직접 접근할 수 없습니다.

## 파일 정보 / File Information

왼쪽 아래 **파일 정보** 패널은 선택한 파일의 속성을 보여 줍니다. 값이 있는 섹션만 나타납니다.

| 섹션 | 내용 |
|------|------|
| **파일** | 이름, 크기(바이트 포함), 해상도(이미지) 또는 길이(A/V), 형식, 생성/수정/접근일, 색공간·DPI(이미지), 경로 |
| **촬영** | (사진) 카메라, 렌즈, 촬영일, 노출(`1/30 s` 등), 조리개, ISO, 초점거리, 플래시, 화이트밸런스, 측광, 저작권 등 |
| **미디어** | (동영상·오디오) 컨테이너, 코덱, 길이, 채널(모노/스테레오), 샘플·프레임레이트, 추정 비트레이트 등 |
| **위치** | GPS 좌표, 고도, 도시/국가 (태그가 있을 때만) |
| **DICOM** | 환자명, 모달리티, 검사일 등 |
| **전체 메타데이터 / 태그** | EXIF·IPTC·XMP·ICC 또는 A/V 태그 나머지를 이름 그대로 표시 |

패널을 스크롤하면 긴 목록을 볼 수 있습니다. 툴바나 메뉴의 파일 정보 대화상자에도 같은 내용이 텍스트로 들어갑니다.

웹 모드에서는 OS가 제공하는 파일 크기·날짜 위주로 표시되고, 카메라 EXIF·상세 A/V 메타는 데스크톱에서만 읽습니다.

## 동영상·오디오 / Video and Audio

동영상·오디오·애니메이션 GIF는 **재생 전용**입니다 (픽셀 편집 불가).

| 조작 | 방법 |
|------|------|
| 재생 / 일시정지 | 하단 **재생·일시정지** 버튼, `Space`, 동영상 화면 클릭(드래그하지 않은 짧은 클릭) |
| 멈춤 | **멈춤** 버튼 (처음으로 되돌림) |
| 탐색 | 동영상 시크 바·시간 표시 |
| 우클릭 | 재생 / 일시정지 / 멈춤 포함 컨텍스트 메뉴 |

화면 중앙 배지:
- **재생·멈춤**: 짧게 깜빡인 뒤 사라짐
- **일시정지**: 실제로 멈춘 동안만 유지 (클릭하면 다시 재생). 파일을 **처음 열 때**는 표시되지 않음

## 이미지 편집 / Editing Images

**정지 이미지**만 편집할 수 있습니다. 동영상·오디오는 보기 전용입니다.

| 동작 | 단축키 / 방법 |
|-----|-------|
| 편집 모드 열기 | `Ctrl+E`, 툴바 **이미지 편집**, 메뉴 **편집 → 이미지 편집** |
| 왼쪽 90° 회전 | `Ctrl+[` |
| 오른쪽 90° 회전 | `Ctrl+]` |
| 수평 / 수직 뒤집기 | 툴바 버튼 |
| 실행 취소 / 다시 실행 | `Ctrl+Z` / `Ctrl+Y` (최대 20단계) |

실행 취소는 픽셀뿐 아니라 **효과·회전·뒤집기**도 되돌립니다.

편집 창에서는 선택 도구·자르기·효과·변환·테두리를 한 화면에서 사용합니다.

- **적용 후 닫기**: 편집 결과를 뷰어에 반영합니다. 내용이 바뀌었으면 파일이 수정됨(`●`)으로 표시되며, 종료 시 저장 여부를 물을 수 있습니다.
- **취소** / `Esc`: 편집 세션을 **버리고** 닫습니다. 저장/버리기 대화상자는 뜨지 않습니다. 미리보기만으로는 파일이 더러워지지 않습니다.

## 선택 도구 / Selection Tools

| 도구 | 사용법 |
|-----|--------|
| 사각형 | 드래그로 영역 선택 |
| 올가미 | 누른 채 자유 곡선 → 놓으면 닫힘 |
| 다각형 | 클릭으로 꼭짓점 추가 → **더블클릭**으로 닫기 |
| 마법 지팡이 | 유사 색상 영역 자동 선택 |

`Esc`로 선택을 취소합니다.

> 선택 윤곽선은 **화면상 항상 일정한 두께**로 표시됩니다. 아주 큰 이미지에서도 선이 얇아져 사라지지 않으며, 확대·축소해도 굵기가 유지됩니다.

## 배경 제거 / Background Removal

1. 선택 도구로 보존할 영역(또는 배경)을 선택합니다.
2. **배경 제거**를 실행하면 선택 **바깥**이 투명해집니다.
3. 투명도를 유지하려면 **PNG**로 저장하세요.

편집 창의 **배경 제거 알고리즘** 드롭다운에서 방식을 고를 수 있습니다.

| 종류 | 항목 | 설명 |
|------|------|------|
| **AI** | `rembg1` (U2Net), `rembg2` (RMBG-2.0), `rembg3` (ISNet) | 선택 없이 피사체를 자동 인식해 배경을 제거 |
| 알고리즘 | 모서리/테두리 채우기, 컬러 키, 밝기, 선택 기반 | 단색·단순 배경에 적합, 파이썬 불필요 |

### AI 배경 제거 자동 설치 / Auto-install

AI 방식(`rembg1/2/3`)은 파이썬과 `rembg`·`onnxruntime` 패키지를 사용합니다. 처음 실행할 때 필요한 것이 없으면 **자동으로 내려받아 설치**하며, 그동안 **진행률**이 표시됩니다.

- 패키지가 없으면 **현재 설치된 파이썬**에 자동 설치합니다 (기존 파이썬을 다른 버전으로 바꾸지 않습니다).
- 파이썬이 전혀 없으면 (Windows) 공식 설치본을 내려받아 **사용자 전용**으로 설치합니다 (관리자 권한 불필요).
- 첫 실행 시 AI 모델 파일(약 170MB)도 한 번 내려받아 `~/.u2net`에 캐시합니다. 이 단계에서 잠시 멈춘 것처럼 보일 수 있습니다.
- 이후 실행은 다운로드 없이 바로 처리됩니다.

## 효과 적용 / Applying Effects

편집 창의 **프리셋** / **조정** 패널에서 밝기, 대비, 채도, 색조, 흐림, 선명도, 비네트, 색온도, 흑백, 세피아, 반전, 그레인, 포스터라이즈, 솔라라이즈 등을 조절합니다.

- 슬라이더를 **드래그하는 동안** 미리보기가 갱신됩니다.
- 손을 **놓는 순간** 실행 취소 기록에 남습니다.
- 슬라이더 위에서 휠을 돌리면 값이 아니라 **패널이 스크롤**됩니다.
- 대화형 조정에는 전체 화면 진행 표시가 뜨지 않습니다 (프리셋·리셋 등은 필요할 때 표시될 수 있음).

**미니어처** 프리셋: 장면을 디오라마·모형처럼 보이게 하는 얕은 심도 + 장난감 색감입니다. **디오라마 심도** 슬라이더(기본 프리셋 값 30)로 강도를 조절합니다.

### 프리셋 분류 / Preset categories

약 118개의 프리셋이 **10개 카테고리**로 나뉘어 접었다 펼 수 있게 표시됩니다. 각 카테고리 제목을 클릭하면 접기/펼치기가 되고, 그 상태는 **기억**됩니다 (다음에 열 때도 유지).

| 카테고리 | 예시 |
|---------|------|
| 컬러 필름 / Color Film | Portra, Ektar, Fuji400H, Superia |
| 슬라이드 필름 / Slide Film | Kodachrome, Velvia, Provia |
| 흑백 / Black & White | Silver, Noir, Tri-X, Newspaper |
| 인스턴트·토이 / Instant·Toy | Polaroid, SX-70, Holga, Lomo |
| 시네마 / Cinema | CineStill, Teal & Orange |
| 크로스·실험 / Cross·Experimental | Cross-process, Redscale, Glitch |
| 따뜻한·골드 / Warm | Golden Hour, Sunset, Autumn, Amber |
| 차가운·블루 / Cool | Arctic, Moonlight, Winter, Cyberpunk |
| 기본·톤 / Tonal | Vivid, Fade, High Key, Low Key |
| 크리에이티브·효과 / Creative | Neon, HDR, Infrared, Watercolor |

**Reset**으로 기본값으로 되돌립니다.

## 테두리·여백 글 / Border and Caption

조정 패널 하단 **테두리 / 여백**:

| 항목 | 설명 |
|------|------|
| **테두리 두께** | 0–**480px** (값에 `px` 표시). 사진 주변 매트 여백 |
| **테두리 색** | 매트 색 |
| **테두리 효과** | 소프트 그림자, 인셋, 베벨, 글로우 등 + 방향·강도(`px`) |
| **여백에 정보 표시** | 캡션 on/off, 위치(상·하·좌·우 모서리/중앙) |
| **글꼴** | 글꼴 종류, 크기(`px`, 6–120), 색(자동 또는 직접) |
| **글꼴 스타일** | 굵게 / 기울임 / 밑줄 / 취소선 |
| **넣을 항목** | `{file}`, `{date}`, `{camera}`, `{gps}` 등 토큰 클릭으로 삽입 |
| **여백 글** | 템플릿 직접 수정 |

큰 글자를 쓰려면 테두리 두께도 충분히 넓혀 주세요. 여백보다 글자가 크면 잘릴 수 있습니다.

## 저장 / Saving

- `Ctrl+Shift+S` 또는 툴바 저장 버튼
- 형식: **PNG**, **JPEG**, **WebP**, **BMP** (확장자에 따라 결정)
- 투명도가 필요하면 **PNG**를 사용하세요.
- HEIC로 연 사진은 **다른 이름으로 저장** 시 기본 확장자가 JPG입니다.

데스크톱: 선택한 경로에 파일이 기록됩니다.  
웹: 브라우저 저장 대화상자 또는 다운로드로 저장됩니다.

## 설치 및 기본 앱 / Installer and Default App

Windows **Setup** 설치 중 **파일 연결** 페이지가 나옵니다.

- 기본값: **지원하는 이미지 파일의 기본 앱으로 Image Viewer 등록** (체크됨)
- 대상: JPEG, PNG, GIF, BMP, WebP, AVIF, SVG, ICO, TIFF, HEIC/HEIF, DICOM
- 동영상·오디오는 기본 재생 앱을 바꾸지 않습니다.

체크를 해제하면 연결을 등록하지 않습니다. 설치 후에도 **Windows 설정 > 앱 > 기본 앱**에서 Image Viewer를 고를 수 있습니다.

macOS / Linux 패키지에도 같은 이미지 형식이 문서 형식으로 등록되어, “다음으로 열기” 목록에 나타납니다.

이미 실행 중인 상태에서 파일을 다시 열면 **새 창을 만들지 않고** 기존 창에서 엽니다.

## 문제 해결 / Troubleshooting

### 작업 표시줄에 Electron 기본 아이콘이 보여요 (Windows, `npm start`)
앱을 모두 종료한 뒤 다시 `npm start` 하세요.  
개발용 실행 파일이 `src/assets/icon.ico`로 패치됩니다.  
필요 시 `npm run patch:icon`을 실행하세요. 그래도 같으면 Windows 아이콘 캐시 때문일 수 있습니다.

### 창 테두리·메뉴가 없고 닫기 버튼이 안 보여요
Windows/Linux는 프레임 없는 창입니다. 오른쪽 위 **×** 로 닫고, 툴바를 드래그해 창을 옮기세요. 이 변경은 **앱을 완전히 재시작**해야 적용됩니다 (렌더러만 새로고침하면 이전 창이 남을 수 있습니다).

### 파일 정보에 촬영/GPS가 안 나와요
데스크톱에서 해당 파일에 EXIF가 있어야 합니다. `read-image-meta`는 메인 프로세스에 있으므로, 기능을 넣은 뒤에는 **앱을 완전히 재시작**하세요. 웹 모드에서는 EXIF를 읽지 않습니다.

### 탐색기에 아무것도 안 보여요
최신 버전에서는 시작 시 드라이브(또는 웹의 Local Files)가 표시됩니다.  
앱을 재시작한 뒤에도 비어 있으면 개발자 도구 콘솔 오류를 확인하세요.

### TIFF가 표시되지 않아요
- 데스크톱: Electron 메인 프로세스의 `sharp` 변환을 사용합니다.
- 웹: `src/vendor/UTIF.js`를 넣고 `index.html` 주석을 제거하세요.

### HEIC/HEIF가 표시되지 않아요 / 색이 이상해요
- 데스크톱: `heic-convert`(libheif)로 먼저 JPEG로 디코딩합니다. 앱을 다시 시작한 뒤 HEIC를 다시 열어보세요.
- `samples/sample.heic`, `samples/sample.heif`는 실제 HEVC 사진 샘플입니다.
- 저장 시 HEIC는 기본 확장자가 **JPG**입니다 (`다른 이름으로 저장`).
- 웹: `src/vendor/heic2any.min.js` + `index.html` 주석 해제
- Windows HEIF 확장도 도움이 될 수 있습니다.

### DICOM이 표시되지 않아요
기본 파서가 포함되어 있으나, 일부 압축 DICOM은 지원하지 않을 수 있습니다.

### AI 배경 제거가 "패키지가 필요합니다"라고 해요 / 느려요
- 처음 실행 시 필요한 파이썬 패키지(`rembg`, `onnxruntime`)를 **자동으로 내려받아 설치**합니다. 인터넷 연결과 수백 MB 다운로드가 필요하며, 진행률이 표시됩니다.
- 파이썬이 없으면 (Windows) 공식 설치본을 자동으로 내려받아 사용자 폴더에 설치합니다. 관리자 권한은 필요 없습니다.
- 첫 실행에서 AI 모델(약 170MB)을 한 번 더 내려받는 동안 잠시 멈춘 것처럼 보일 수 있습니다. 두 번째부터는 빠릅니다.
- 오프라인이거나 자동 설치가 실패하면, 사용 중인 파이썬에서 `pip install rembg onnxruntime`를 직접 실행한 뒤 다시 시도하세요.
- AI 대신 **알고리즘** 방식(모서리 채우기·컬러 키 등)은 파이썬 없이 즉시 동작합니다.

### 큰 이미지에서 선택 윤곽선이 안 보였어요
최신 버전은 윤곽선 두께를 화면 배율에 맞춰 보정하므로 이미지 크기·확대율과 무관하게 일정하게 보입니다. 앱을 새로고침하거나 재시작한 뒤 다시 선택해 보세요.

### 설치했는데 더블클릭이 다른 앱으로 열려요
설치 마법사에서 파일 연결 체크가 켜져 있어야 합니다. Windows 10 이상은 이미 다른 기본 앱이 있으면 **설정 > 앱 > 기본 앱**에서 Image Viewer를 지정하세요. 동영상 파일은 이 앱의 기본 연결 대상이 아닙니다.

### 웹에서 폴더가 안 열려요
Chrome / Edge 등 **Directory Picker**를 지원하는 최신 브라우저를 사용하세요.  
미지원 브라우저는 폴더 선택 입력(`webkitdirectory`)으로 대체됩니다.

### 동영상이 재생되지 않아요
시스템에 해당 코덱이 있어야 합니다. MP4 (H.264), WebM은 일반적으로 지원됩니다.

### 동영상 열자마자 일시정지 배지가 보여요
최신 버전에서는 처음 열 때 배지를 표시하지 않습니다. 앱을 새로고침하거나 재시작한 뒤 다시 열어 보세요.

### 테두리 글꼴·두께가 예전과 같아요
편집 창을 닫았다가 다시 열면 조정 패널이 갱신됩니다. 두께는 최대 480px이며 값에 `px`가 붙습니다.
