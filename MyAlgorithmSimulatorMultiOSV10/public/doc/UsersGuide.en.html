User's guide

Getting started

MyAlgorithmSimulator shows how an algorithm moves, one step at a time, and lets you read and run the same algorithm in several programming languages.

The program opens on the start screen. Pick an algorithm over the moving background, or choose Continue to reopen the one you looked at last.

  • Settings changes the playback speed, the start-screen background, and that background's speed and opacity.
  • About shows the version and the author.
  • User's guide opens this window.

The window

Opening an algorithm splits the window into four parts.

  • Left is the algorithm list and the input. Algorithms are grouped by kind, and each one has its own icon.
  • Centre is the picture of the current step. Comparisons, swaps, visited vertices and paths each have a colour.
  • Bottom is the program panel. Program is the source code and Pseudocode is the statement for this step. The matching line is highlighted as the picture changes.
  • Right is the explanation, the variables at this step, and the result of running the code.

The View menu hides or shows the left panel, the right panel and the program panel.

Stepping through

The toolbar moves the algorithm one step at a time, or plays it automatically.

  • Back and Step move one step backward and forward.
  • Auto run keeps turning the picture until the end. Click it again to pause.
  • Start returns to the first step.
  • The slider jumps straight to a step.
  • The speed menu runs from 0.25× to 8×.

On every step the picture, the statement under it, the marked source line and the variables on the right all refer to the same step. Only a source line that carries a step marker lights up. Without a marker, the statement still changes.

Code and samples

Choosing a language in the program panel opens that language's sample. The languages are C, C++, Java, Python, Go, Rust and JavaScript.

A sample reads the left-hand input box as standard input and writes its result to standard output. Edit the code, and use Sample to load the original again. The File menu saves the code or opens an existing file.

A Java program's class must be named Main.

Running code

Run compiles and runs the code you are editing, then shows the output on the right. A run stops if it takes longer than 15 seconds.

The web browser runs JavaScript only. C, C++, Java, Python, Go and Rust run in the desktop app. If a compiler is missing, Install developer tools can install it: winget on Windows, Homebrew on macOS, and apt or dnf on Linux.

Input

The box at the lower left is the value the algorithm receives. Sorting takes a list of integers, string algorithms take text, graphs take edges, and A* takes a grid.

  • Apply rebuilds the steps from the edited input.
  • Random makes a new input.
  • On an A* grid, click the picture to add or remove a wall. S is the start, G is the goal and # is a wall.

If the input does not match the expected form, the reason appears under the box and the picture keeps the previous steps.

Theme, background and language

The Theme button on the toolbar shows the current theme name and opens the light and dark themes. The theme you pick is applied to this guide window as well.

The start screen has twenty-one backgrounds, and each one is a picture of an algorithm moving: bars, a tree, a graph, a grid and the rest. Pick a name, or use Change background, and set the speed and opacity from 0 to 100% with the slider or the decrease and increase buttons. The speed starts at 20%. Turn on Random and the background changes every shuffle interval, from 5 to 120 seconds.

The language button is a flag. A Korean screen shows the UK flag, and an English screen shows the Korean flag. Clicking it switches the menus and the explanations. The flag in this window changes only the guide.
