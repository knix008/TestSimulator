MyAlgorithmSimulator 사용 설명서

알고리즘이 한 단계씩 어떻게 움직이는지 보고, 같은 알고리즘을 C, C++, Java, Python, Go, Rust, JavaScript로 직접 실행해 보는 학습 프로그램입니다. 웹 브라우저와 Windows, macOS, Linux에서 같은 화면으로 동작합니다.

화면

  • 왼쪽 — 알고리즘 목록과 입력. 입력을 고친 뒤 적용(Ctrl+Enter)을 누르면 처음부터 다시 계산합니다. 무작위는 새 입력을 만듭니다.
  • 가운데 — 현재 단계의 그림과, 아래쪽의 의사코드. 실행 중인 줄이 강조됩니다.
  • 오른쪽 — 설명, 복잡도, 색 범례, 그리고 코드 편집기와 실행 결과. 변수 탭은 그 단계의 변수 값입니다.

단계 이동

키동작
Space재생 / 일시정지
→ / ←한 단계 앞 / 뒤
Home처음으로
R무작위 입력

도구 모음의 슬라이더로 원하는 단계로 바로 이동하고, 속도로 재생 속도를 바꿉니다.

코드 실행

코드 탭에서 언어를 고르면 그 언어의 샘플이 열립니다. 샘플은 입력 상자의 내용을 표준 입력으로 읽고 결과를 출력합니다. 고쳐서 실행해 볼 수 있고, 파일로 저장하거나 기존 파일을 열 수도 있습니다.

웹 브라우저에서는 JavaScript를 실행합니다. C, C++, Java, Python, Go, Rust는 데스크톱 앱에서 실행되며, 컴파일러가 없으면 실행 › 개발 도구 설치…에서 패키지 관리자(Windows는 winget, macOS는 Homebrew, Linux는 apt 또는 dnf)로 설치합니다.

A* 격자

경로 탐색의 격자는 클릭으로 벽을 넣거나 지울 수 있습니다. S는 시작, G는 목표, #는 벽입니다.
