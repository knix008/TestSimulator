# MyDeskBox 사용 안내

바탕화면 아이콘을 반투명 박스에 모아 두는 프로그램입니다. Windows, macOS, Linux에서 동작합니다. 배경 그림 위에 사각형을 그리지 않고, 박스마다 투명한 창을 띄웁니다.

## 설치와 실행

개발 중인 소스를 바로 띄울 때:

```bash
npm install
npm start
```

설치 파일로 깔 때는 운영체제에 맞는 묶음을 씁니다. 만드는 방법은 [README.md](README.md)의 설치 파일 만들기를 보면 됩니다.

- Windows 설치 첫 화면에서 한국어와 영어 중 설치 언어를 고릅니다.
- 바탕화면 바로 가기와 시작 메뉴 바로 가기는 각각 만들지 물어봅니다.
- 이미 깔려 있으면 그 설치본을 지우고 다시 설치합니다. 박스 배치는 그대로 둡니다.
- 예전 설정을 모두 지울지도 고를 수 있습니다. 기본은 지우지 않는 쪽입니다.

## 처음 실행

설정을 한 번도 저장하지 않은 첫 실행에서는 바탕화면 항목을 종류별로 나눠 박스를 만듭니다.

| 종류 | 들어가는 것 | 기본 테마 |
| --- | --- | --- |
| 폴더 | 폴더 | 청록 |
| 바로가기 | `.lnk`, `.url`, `.desktop` | 바다 |
| 문서 | 문서, 스프레드시트, 한글 문서 등 | 황금 |
| 사진·영상 | 그림, 영상, 소리 | 노을 |
| 시스템 | 휴지통, 내 PC 같은 셸 항목 | 밤 |
| 그 밖의 것 | 위에 속하지 않는 파일 | 강철 |

비어 있는 종류는 박스를 만들지 않습니다. 나눌 항목이 하나도 없으면 빈 곳을 끌어 박스를 그리는 상태로 시작합니다. 이미 한 번 실행해 배치가 있으면 그 배치를 유지하고, 다시 자동으로 나누지 않습니다.

## 박스 만들기와 옮기기

- 트레이 아이콘을 누르거나, 박스 메뉴의 **새 박스 그리기**로 빈 곳을 끌어 박스를 만듭니다. Esc 로 취소합니다.
- Windows에서는 바탕화면 빈 곳을 끌어 사각형을 만들면, 그 자리에 박스를 만들지 물어봅니다. 너무 작은 사각형은 묻지 않습니다.
- 제목 줄을 끌면 박스가 움직이고, 안의 아이콘도 함께 움직입니다.
- 가장자리를 끌면 크기가 바뀝니다. 아이콘 순서는 유지한 채 칸에 맞게 다시 놓입니다.
- 제목을 두 번 누르면 접히고, 제목 줄만 남습니다. 다시 두 번 누르면 펼쳐집니다.
- 박스를 지우면 안에 있던 항목은 바탕화면 자리로 돌아갑니다. 삭제를 취소하면 그대로입니다.

## 항목 넣기와 빼기

- 박스 안에서 아이콘을 끌면, 커서가 가리키는 칸이 비도록 있던 아이콘이 밀립니다.
- 아이콘이 박스보다 많으면 오른쪽 막대로 넘겨 봅니다.
- 아이콘을 박스 밖에 놓으면 바탕화면으로 돌아갑니다.
- 파일 탐색기에서 끌어다 놓아도 들어갑니다.
- Windows에서는 바탕화면의 휴지통을 끌어 박스에 넣을 수 있습니다. 끌어 넣기가 안 되는 항목은 박스 메뉴의 **바탕화면 항목 담기**로 담습니다.
- 아이콘을 두 번 누르면 그 파일이나 프로그램이 열립니다. 휴지통처럼 파일이 아닌 항목도 열립니다.
- 아이콘 위 메뉴에는 **열기**와 **바탕화면으로 꺼내기**가 있습니다.
- 박스에 담은 항목은 바탕화면에서 치워집니다. 같은 항목이 두 곳에 함께 있지 않습니다.
- 박스가 덮은 자리의 바탕화면 아이콘은 옆의 빈 칸으로 밀려납니다.

앱을 종료하면 박스에 담아 두었던 바탕화면 아이콘은 원래 자리로 돌아갑니다. Windows에서 휴지통을 담아 두었다면, 종료와 함께 바탕화면에 다시 나타납니다. 바로 안 보이면 바탕화면을 클릭한 뒤 F5를 누릅니다.

## 이 박스의 설정

제목 줄 오른쪽의 톱니, 또는 오른쪽 단추 메뉴의 **이 박스 설정**에서 그 박스만 바꿉니다.

- 이름
- 테마 스무 가지. 원하는 색이 없으면 바탕과 제목 줄 색을 직접 고릅니다.
- 모서리. 각진 것부터 둥근 것까지 슬라이더와 − + 로 정합니다.
- 투명도. 너무 흐리거나 너무 진해지지 않는 범위 안에서 정합니다.
- 접어 두기
- 기본값. 이 박스만 처음 모습으로 되돌립니다.

박스에 손을 올리면 오른쪽 아래에 크기 조절 표시가 옅게 나타납니다.

## 트레이

트레이 아이콘을 누르면 박스를 그립니다. 메뉴에서는 전체를 다룹니다.

- **박스 숨기기** / **박스 보이기**. Windows에서는 바탕화면 빈 곳을 두 번 눌러도 같습니다. 숨긴 채로 박스를 그리면 함께 다시 보입니다.
- 언어. 한국어와 영어. 고르면 모든 박스와 메뉴에 함께 적용됩니다.
- 시작할 때 실행
- 앞으로 만들 박스의 테마, 모서리, 투명도
- 설정 폴더 열기
- 프로그램 정보
- 종료

## 한 번에 하나만

바탕화면 아이콘은 컴퓨터에 하나뿐입니다. MyDeskBox를 두 번 켜면 나중에 켠 쪽은 알림을 남기고 끝납니다. 설치본과 개발용 실행을 같이 켜도 같습니다. 먼저 켠 쪽을 트레이에서 종료한 뒤 다시 실행합니다.

## 설정이 저장되는 곳

배치는 사용자 데이터 폴더의 `layout.json`에 저장됩니다. Windows에서는 보통 `%APPDATA%\mydeskbox` 입니다. 트레이의 **설정 폴더 열기**로 그 폴더를 엽니다. 첫 실행의 자동 분류를 다시 하게 하려면 앱을 종료한 뒤 이 폴더의 `layout.json`을 지웁니다.
