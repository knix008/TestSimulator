# My Editor — 사용자 가이드

## 1. 화면 구성

```
┌ 메뉴 바 ─────────────────────────────────────────────────────────────────┐
│ [로고] My Editor  파일 편집 찾기 보기 언어 인코딩 도움말   현재 파일 경로  테마 ▾ 🇬🇧 ⚙설정 ⓘ정보  ─ ☐ ✕ │
├ 도구 모음 ────────────────────────────────────────────────────────────────┤
│ 새문서 열기 저장 모두저장 닫기 | 실행취소 다시실행 | 잘라내기 복사 붙여넣기 | 찾기 바꾸기 | 줄바꿈 ¶ + − 트리 │
├ 폴더 트리 ─┬ 탭 ─────────────────────────────────────────────── + < > ┤
│ work       │ app.js ×  README.md ×  notes.txt ×  새 문서 1 ●            │
│  ├ docs    ├ (Markdown 문서일 때) H1 H2 H3 H4 H5 H6  B I S <> | 99 ≡ 1. ☑ … │
│  │ └ README├ (찾기 열림) 찾을 내용 [Aa][ab][.*]  1/6  ↑ ↓ ≡        ✕  │
│  ├ src     │                                                            │
│  └ notes   │   1  // 편집 영역 (CodeMirror 6)                             │
├ 상태 표시줄 ┴───────────────────────────────────────────────────────────┤
│ 준비됨          줄 4, 열 33  567자·21줄  공백: 4  LF  UTF-8  JavaScript  100% ⋱ │
└──────────────────────────────────────────────────────────────────────────┘
```

- **메뉴 바**는 창의 제목 표시줄을 겸합니다. 빈 곳을 드래그하면 창이 움직이고, 더블클릭하면 최대화됩니다.
- 오른쪽 위 **테마** 버튼은 누를 때마다 다음 테마로 바뀌고, ▾ 를 누르면 16개 테마 목록이 나옵니다. **국기** 버튼은 한국어 ↔ 영어를 전환합니다.
- **상태 표시줄**의 들여쓰기 · 줄 끝 · 인코딩 · 언어 · 확대율은 모두 버튼입니다. 눌러서 바로 바꿀 수 있습니다.
- 우측 하단 ⋱ 마커를 드래그하면 창 크기가 바뀝니다(데스크톱).

## 2. 문서 열기 · 저장

| 동작 | 방법 |
|---|---|
| 새 문서 | Ctrl+N, 도구 모음 첫 버튼, 탭 줄의 `+` |
| 열기 | Ctrl+O(여러 파일 선택 가능), 파일을 창에 끌어다 놓기, 탐색기에서 더블클릭, 폴더 트리에서 클릭 |
| 저장 / 다른 이름으로 | Ctrl+S / Ctrl+Alt+S — 새 문서는 저장 위치를 묻습니다 |
| 모두 저장 | Ctrl+Shift+S |
| 다시 불러오기 | 파일 › 다시 불러오기(수정 중이면 확인) |
| 닫기 | Ctrl+W, 탭의 ×, 탭 가운데 클릭 — 저장하지 않은 문서는 저장 / 저장 안 함 / 취소를 묻습니다 |
| 최근 파일 | 파일 메뉴 아래쪽(최근 12개) |

- 다른 프로그램이 파일을 바꾸면, 편집하지 않은 문서는 자동으로 다시 읽고(설정에서 끌 수 있음) 편집 중인 문서는 물어봅니다. 디스크에서 지워진 파일은 알려 주고 탭을 유지합니다.
- 프로그램을 닫았다가 다시 열면 열려 있던 탭, 커서 위치, 저장하지 않은 **새 문서의 내용**까지 그대로 돌아옵니다(설정 › 시작할 때 이전 세션 복원).
- 64 MB 를 넘는 파일과 이진 파일은 열기 전에 알려 줍니다.

## 3. 탭

- 드래그해서 순서를 바꿀 수 있습니다.
- 탭이 창 폭보다 많아지면 오른쪽 끝에 `<` `>` 버튼이 나타납니다. 마우스 휠로도 스크롤됩니다. 활성 탭은 항상 보이게 유지됩니다.
- Ctrl+Tab / Ctrl+Shift+Tab, Ctrl+PgDn / PgUp 으로 이동, Ctrl+1 ~ Ctrl+9 로 n번째 탭.
- 오른쪽 클릭: 저장, 다른 이름으로, 다시 불러오기, 닫기 / 다른 탭 모두 닫기 / 오른쪽 탭 모두 닫기 / 모두 닫기, 탐색기에서 보기, 기본 앱으로 열기, 경로 · 파일 이름 복사.
- 이탤릭 이름 + ● 은 저장하지 않은 문서, 👁 은 읽기 전용 파일입니다.

## 4. 편집

| 기능 | 단축키 |
|---|---|
| 실행 취소 / 다시 실행 | Ctrl+Z / Ctrl+Y |
| 줄 복제 / 줄 삭제 | Ctrl+D / Ctrl+L |
| 줄 위·아래로 이동 | Alt+↑ / Alt+↓ |
| 주석 토글 | Ctrl+/ |
| 들여쓰기 / 내어쓰기 | Tab / Shift+Tab |
| 소문자 / 대문자 | Ctrl+U / Ctrl+Shift+U |
| 다중 커서 | Alt+클릭 |
| 사각형 선택 | Alt+드래그 |
| 코드 접기 | 줄 번호 옆 ▾ 클릭, 보기 › 모두 접기 / 펼치기 |

편집 메뉴에는 줄 정렬(오름/내림차순), 줄 끝 공백 제거, 빈 줄 · 중복 줄 제거, 날짜/시간 · 파일 경로 삽입도 있습니다. 선택 영역이 있으면 선택된 줄에만, 없으면 문서 전체에 적용됩니다.

## 5. 찾기 · 바꾸기

- Ctrl+F 로 찾기 줄이 열립니다. 입력하는 대로 일치하는 곳이 강조되고 `현재 / 전체` 개수가 표시됩니다.
- Enter = 다음, Shift+Enter = 이전, F3 / Shift+F3 도 같습니다. ≡ 버튼은 일치하는 곳을 모두 선택합니다(다중 커서).
- `Aa` 대/소문자 구분, `ab` 단어 단위, `.*` 정규식. 정규식이 잘못되면 입력 칸이 빨갛게 표시됩니다.
- Ctrl+H 로 바꾸기 줄이 추가됩니다. 바꾸기 칸에서 Enter = 하나 바꾸기, Ctrl+Enter = 모두 바꾸기. 정규식일 때 `$1` 같은 그룹 참조를 쓸 수 있습니다.
- Ctrl+G 줄로 이동: `12` 또는 `12:5`(줄:열).
- Esc 로 닫습니다.

## 6. 언어 · 인코딩 · 줄 끝

- **언어**는 확장자로 자동 판별됩니다. 언어 메뉴(자주 쓰는 25개) 또는 `언어…` 로 열리는 검색 목록(150+)에서 직접 고를 수 있고, 상태 표시줄의 언어 이름을 눌러도 됩니다. 문법은 처음 쓸 때만 내려받듯 로드됩니다.
- **인코딩**은 열 때 BOM · UTF-8 · UTF-16 · 시스템 코드 페이지(한국어 Windows 는 CP949) 순으로 판별합니다. 인코딩 메뉴에서 다른 인코딩을 고르면 **저장할 때** 그 인코딩으로 씁니다. 잘못 판별된 파일은 `다른 인코딩으로 다시 열기…` 로 다시 읽으세요. 표현할 수 없는 문자가 있으면 저장 전에 경고합니다.
- **줄 끝**(CRLF / LF / CR) 은 파일에서 감지하며, 인코딩 메뉴 아래쪽이나 상태 표시줄에서 바꿀 수 있습니다. 새 문서의 기본값은 설정 › 파일에서 정합니다.

## 7. 폴더 트리 (Ctrl+B)

- 파일 › 폴더 열기(Ctrl+Shift+O) 또는 트리 상단의 📂 로 폴더를 열면 **하위 폴더까지 모두 펼쳐** 파일 전체가 트리로 보입니다. (`node_modules`, `.git`, `dist` 같은 무거운 폴더는 접힌 채로 두며, 클릭하면 펼쳐집니다.)
- 파일을 클릭하면 열리고, 열린 파일은 강조 색으로, 현재 문서는 선택 색으로 표시됩니다.
- 상단 버튼: 폴더 열기, 새로 고침, 모두 펼치기, 모두 접기, 숨김 파일 표시, 폴더 닫기. 필터 칸에 글자를 넣으면 이름이 맞는 항목만 남습니다.
- 오른쪽 클릭: 새 파일 · 새 폴더 · 이름 바꾸기 · 삭제 · 탐색기에서 보기 · 경로 복사 · 새로 고침.
- 경계선을 드래그하면 너비가 바뀝니다.

## 8. Markdown 편집

`.md` 문서를 열면 탭 아래에 Markdown 도구 모음이 나타납니다.

| 버튼 | 단축키 | 동작 |
|---|---|---|
| H1 ~ H6 | Ctrl+1 ~ Ctrl+6 | 선택한 줄을 제목으로(같은 단계를 다시 누르면 해제) |
| **B** / *I* / ~~S~~ / `<>` | Ctrl+B / Ctrl+I / Ctrl+Shift+X / Ctrl+` | 선택 영역(없으면 커서 위치의 단어)을 굵게 · 기울임 · 취소선 · 인라인 코드로 감싸기, 이미 감싸져 있으면 풀기 |
| 인용 / 목록 / 번호 목록 / 체크리스트 | Ctrl+Shift+Q / 8 / 7 / 9 | 선택한 줄 앞에 기호 추가(다시 누르면 제거) |
| 코드 블록 | Ctrl+Shift+C | 선택 영역을 ``` 로 감싸기 |
| 링크 / 이미지 / 표 / 구분선 | Ctrl+K / Ctrl+Shift+I | 틀을 넣고 URL 부분을 선택해 둠 |

- **WYSIWYG** 버튼(Ctrl+Shift+W)이 켜져 있으면 제목은 크게, 굵게·기울임은 그대로, 목록은 •, 체크리스트는 실제 체크박스(클릭으로 토글), 인용은 왼쪽 막대, 코드 블록은 상자, 구분선은 선으로 **문서 안에서 바로** 보입니다. 기호(`#`, `**`, `-` …)는 **커서가 있는 줄에서만** 나타나므로 언제든 직접 고칠 수 있습니다. 끄면 원본 기호가 모두 보입니다.
- **미리보기** 버튼(Ctrl+Shift+M)은 오른쪽에 렌더링된 HTML 창을 엽니다. 편집하는 대로 갱신되고 편집기 스크롤을 따라갑니다. 경계선을 드래그해 너비를 조절합니다.
- Markdown 문서에서는 Ctrl+B 가 굵게이므로 폴더 트리는 Ctrl+Shift+B 로 여닫습니다.

## 9. 보기 · 설정

- 보기 메뉴: 자동 줄 바꿈, 줄 번호, 공백 문자 표시, 현재 줄 강조, 코드 접기, 폴더 트리 / 도구 모음 / 상태 표시줄 표시, 확대 / 축소 / 기본 크기(Ctrl+= / Ctrl+− / Ctrl+0, Ctrl+휠), 전체 화면(F11).
- 설정(Ctrl+,) — **일반**: UI 언어, 테마, 글꼴(고정폭 글꼴 이름 입력 또는 목록에서 선택), 글꼴 크기, 세션 복원, 닫을 때 확인. **편집기**: 탭 크기, Tab 키로 공백 입력, 줄 바꿈 · 줄 번호 · 공백 표시 · 현재 줄 · 괄호 자동 닫기 · 짝 괄호 강조 · 코드 접기. **파일**: 새 문서 인코딩 · 줄 끝, 저장할 때 줄 끝 공백 제거 · 마지막 줄 바꿈 추가, 외부 변경 자동 다시 읽기.
- 모든 설정은 바꾸는 즉시 적용되고 저장됩니다.

## 10. 웹 버전

```bash
npm run web                       # http://127.0.0.1:5190
node server/server.js --host 0.0.0.0 --port 8080 --token 비밀값
```

- 브라우저에서 같은 화면을 씁니다. 파일은 **서버가 실행되는 컴퓨터**의 것이며, 열기 / 저장 / 폴더 선택 대화상자는 앱 안에서 그립니다(드라이브 목록, 상위 폴더, 경로 직접 입력, 숨김 파일).
- 브라우저에서 끌어다 놓은 파일은 내용을 읽어 새 문서로 엽니다(저장하려면 위치를 고릅니다).
- 창 버튼 · 탐색기에서 보기 · 기본 앱으로 열기는 웹 버전에 없습니다.
- 다른 컴퓨터에서 접속을 허용할 때는 반드시 `--token` 을 쓰세요. 주소 뒤에 `?token=…` 을 붙이면 브라우저가 기억합니다.

## 11. 데이터 파일과 문제 해결

- 세션·설정: `session.json` (위치는 README 의 표 참고). 지우면 기본값으로 시작합니다.
- 오류 대화상자의 **자세히 복사**로 코드 · 경로 · 스택을 클립보드에 담아 문의할 수 있습니다.
- 시작이 안 되고 `Cannot find module 'electron'` 류의 메시지가 나오면 시스템 환경 변수 `ELECTRON_RUN_AS_NODE` 를 지우세요(`npm start` 는 자동으로 제거합니다).
- `npm start` 가 포트 5189 때문에 실패하면 이전 실행이 남아 있는 것입니다 — `npm run free:port` 가 먼저 실행되지만, 그래도 안 되면 작업 관리자에서 electron 을 종료하세요.
