MyEBookReader Guide

Read PDF, EPUB, MOBI, AZW3, DjVu, FB2 and CBZ with page-turn effects, highlight them, and take out their text and pictures — version 1.0.2 · Windows · macOS · Linux · web browser

This guide opens in a window of its own (F1, or Help in the title bar). Use aA [−] [+] in the bar at the top to change the guide's text size, and the 한국어 / English buttons to change its language. The pictures show the Korean interface.

1. Introduction

MyEBookReader reads e-books in many formats — PDF, EPUB, MOBI, AZW/AZW3 (Kindle), DjVu, FB2, CBZ, TXT, Markdown and HTML — in one program. Whatever the format, you turn pages one or two at a time with the same page-turn effects, and highlights, bookmarks, copying text and pictures, search and printing work just as they do for a PDF.

  • Flowing text such as EPUB and MOBI is laid out into pages when it opens; aA in the toolbar changes its font size.
  • Every book you open collects in Opened files; the ones you love go on the shelves of your Library.
  • Highlights in a PDF are saved inside the file; for other formats they are saved in a workspace (.ebkvw).

3. Start screen

The start screen appears when the program starts; Home in the title bar brings it back.

  • Getting started — open, open URL, opened files.
  • Recent files — ✕ removes one line; 🗑 Clear all beside the heading clears the whole list. The files themselves are not touched.
  • My library — the covers of your library. 🗑 Clear all empties it; See all opens the library screen.
  • Move and resize panels — drag the ⠿ handle at the start of a panel's title (top-left on the intro card) to move it, and its bottom-right corner to resize it. The arrangement is remembered.
  • Auto arrange at the top right of the start screen puts every panel back in its automatic place.
  • Home is a toggle — pressed, it shows the start screen; pressed again, it goes back to the book (or the empty window).
  • Right-click a recent file or a library book for open, add to / remove from library, remove from recent files, show in folder and copy path.

Pick one of 21 3D scenes about reading and books — book cloud, pages, stars, falling letters, galaxy, aurora, ink and more.

  • Random background · opacity (10–100 %) · motion speed (10–300 %)
  • Change every 15 seconds to 5 minutes, in order or at random.

4. Opening books

  • File ▾ → Open (Ctrl+O) — the type list of the dialog narrows it to books and workspaces, PDF, EPUB, Kindle, DjVu, FictionBook, comics, text or pictures. Several files open as tabs.
  • Drag and drop book files onto the window.
  • Open URL downloads a book from the internet.
  • The folder panel lists PDF, EPUB, MOBI, AZW, AZW3, DjVu, FB2 and CBZ files.
  • Choose Set as the default reader for e-books when installing to open EPUB, MOBI, AZW3, DjVu, FB2 and CBZ by double-clicking. PDF is only added to the "Open with" list.
Flowing text such as EPUB and MOBI is laid out into pages as it opens. A book of several hundred pages usually takes 1–4 seconds, while Laying out pages is shown.

6. Page-turn effects

With the page layout on single page or two-page view, the chosen effect plays when you turn a page — the same in every format (continuous view scrolls instead). Each press of the effect button goes none → fade → slide → flip; ▾ picks from the list.

  • Turn with the ‹ › buttons beside the page, PageUp / PageDown, ← / →, the mouse wheel or the page number.
  • The next page is drawn before the turn plays, so even quick turns never show a blank page.
  • With "reduce animations" on in Windows, pages change without an effect.

7. Font size (aA)

When flowing text is open — EPUB, MOBI, AZW3, FB2, TXT, Markdown, HTML — the toolbar shows aA [−] 18px [+].

  • Each press changes the text by 2 px (10–40 px). The size is remembered for the next book.
  • The pages are laid out again and you stay in the same chapter, at the same place in it; only the page count changes.
  • It is not shown for PDF, DjVu, comics and pictures, whose type is part of the page — zoom those instead.
Highlights are kept as positions on the page. Read a highlighted book at the same text size: changing it can move highlights off their words.

8. Fit and zoom

Zoom with the toolbar, Ctrl++ / - or Ctrl+wheel; drag an empty spot to move a large page. Layout is single page, continuous or two-page view, and the ↺ rotate left · ↻ rotate right buttons turn the page by 90°. However small you make the window, every toolbar and title-bar button stays visible: the window does not get narrower than they need.

9. Selecting and copying text

With the text tool (Ctrl+1) drag over the words — the selection shows just as in a PDF — and copy with Ctrl+C or the right-click menu. Several lines copy in reading order.

  • Every right-click menu item has an icon. Document tabs (close this tab, close other tabs, library, show in folder, copy path) and text fields such as the search box (cut, copy, paste, select all) have menus too.
  • Ctrl+A selects the page; copy this page's text; File ▾ → Export text writes the whole book to a .txt.

10. Pictures and areas

  • Image tool (Ctrl+2) takes a picture out at its full resolution; a comic or DjVu page is one picture.
  • Area tool (Ctrl+3) cuts out any rectangle — tables, formulas, text — as PNG, JPEG, WebP, GIF or BMP.
  • Read mode (Ctrl+4) selects nothing.

11. Highlights

  1. Select the words with the text tool.
  2. Choose Highlight in the right-click menu or the ▾ beside the copy button.
  3. Save with Ctrl+S — inside the file for a PDF, in a workspace (.ebkvw) for other formats.

12. Search

Ctrl+F opens the search panel. Clicking a result turns to that page and marks the word on it. EPUB, MOBI, FB2, TXT and DjVu with OCR text are all searchable.

13. Saving

  • Save (Ctrl+S) — a PDF gets its highlights, comments, bookmarks and attachments written into the file. EPUB, MOBI and the rest are never rewritten; a workspace (.ebkvw) is saved instead.
  • Save As — a PDF as name-annotated.pdf, other formats as a new workspace.
  • A workspace keeps the book's path, the page and view, highlights, bookmarks, clips and attachments; double-click it to open the book as you left it. MyPDFViewer workspaces (pdfvw) open too.
  • Unsaved changes are asked about before a tab or the window closes.

14. Opened files

Open it with the Opened files button. Every book you open collects here with its first page (or cover) and name.

  • 🗑 Clear all empties the list at once. Books in your library stay, and no file is deleted.
  • Search, all / library only, and sort by last opened, name, added or size.

15. Library

Add to library (☆ on a card, the right-click menu, or ☆ on a recent file in File ▾) and the toolbar's Library button shows your books like shelves.

  • Four views: shelves, covers, list, details. ✕ takes one book off; 🗑 Clear all empties the library (files and Opened files stay).

17. Printing

Open the print window with the 🖨 Print button on the toolbar (right after the selection tools), File ▾ → Print, or Ctrl+P.

In the narrow column on the left choose all, the current page or a custom range (1-5, 8, 11-13), the printer, copies and orientation; check the pages in the wide preview on the right (only the sheet that will print is paper-white; around it is the viewer backdrop) and press [Print] to print straight away. An EPUB prints with the pages it was laid out into.

18. Settings

  • Appearance — 40 themes, interface font and size. Viewer — zoom, layout, effect. Start screen, Copying, Files.
  • The book's text size is set with aA in the toolbar (section 7).
  • Settings and About open in windows of their own. Drag the title strip to move them anywhere, outside the program's window too; the main window waits while one is open.
  • Right-click menus are not cut off at the window edge: they carry on past the program's window.
  • Every number is set with [−] value [+]: the current value sits in the middle with its unit; sliders have − and + at either end and show their value centred above the bar.

About

Each supported format lists its extensions and whether it is reflowable text (adjustable text size) or fixed pages. Convert CBR (RAR comics) to CBZ, and Amazon KFX or DRM books to AZW3, MOBI or EPUB, before opening them.

20. Install and data

  • Installers are built with npm run build:win (macOS build:mac, Linux build:linux).
  • The installer asks about shortcuts and Set as the default reader for e-books. An earlier Electron build (MyEbooks) is removed first, and you are asked whether to keep its settings.
  • Settings, recent files, opened files and the library are kept in %APPDATA%\MyEBookReader\settings.json.
If something goes wrong, Copy error details in the error window copies everything at once.
