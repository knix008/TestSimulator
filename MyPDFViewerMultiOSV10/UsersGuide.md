# MyPDFViewer 사용 설명서

PDF를 읽고, 그 안의 **텍스트와 이미지를 꺼내 쓰는** 데 초점을 맞춘 프로그램입니다.
Windows · macOS · Linux 설치본과 웹 브라우저에서 동일하게 동작합니다.

제작자: **SHKWON(knix008@naver.com)**

## 1. 화면 구성

```
┌──────────────────────────────────────────────────────────────┐
│ MyPDFViewer v1.0.0 — 문서이름.pdf              ─  □  ✕      │ ← 타이틀 바
├──────────────────────────────────────────────────────────────┤
│ 열기 URL 최근 │ 저장 │ 취소/재실행 │ 도구 │ 복사 도구 │ …  │⚙ⓘ│ ← 툴바
├────┬─────────────────────────────────────────────────────────┤
│ 폴 │ 문서1.pdf │ 문서2.pdf │ …                          < > │ ← 문서 탭
│ 더 ├─────────────────────────────────────────────────────────┤
│    │                                                         │
│ 목 │                    페 이 지                              │
│ 차 │                                                         │
├────┴─────────────────────────────────────────────────────────┤
│ ✔ 준비됨 │ 문서.pdf │ 폴더 │ 페이지 3/12 │ 배율 120% │ …    │ ← 상태 바
└──────────────────────────────────────────────────────────────┘
```

* **타이틀 바** — 프로그램 이름과 버전, 현재 문서 이름을 보여줍니다. 변경된 내용이 있으면 이름 뒤에 `•` 이 붙습니다.
* **툴바** — 항상 한 줄이며, 모든 버튼에 설명(툴팁)이 있습니다. 명령은 종류별로 묶여 있습니다.

  | 버튼 | 담긴 것 |
  | --- | --- |
  | **파일 ▾** | 열기 · URL 열기 · **PDF로 저장** · **PDF 다른 이름으로 저장** · **파일 첨부** · 작업 파일로 저장 · 텍스트 내보내기 · 인쇄 · 최근 파일 목록 |
  | **복사 ▾** | 페이지 전체 선택 · 형광펜 · 코멘트 · 이미지 추출 · 책갈피 추가 |
  | **보기 ▾** | 너비/페이지/실제 크기 맞춤 · 회전 · 페이지 배치 · 첫/마지막 쪽 |

  나머지(실행 취소·다시 실행, 선택 도구 3종, 텍스트 복사, 쪽 이동, 확대·축소)는 바로 눌러 쓰고,
  **주석 · 책갈피 · 찾기 · 사이드바 · 테마 · 언어(국기 토글) · 설정 · 정보**는 오른쪽 끝에 고정됩니다.
* **문서 탭** — 툴바 바로 아래, **문서 영역 위에만** 표시됩니다 (좌측 패널 위로는 올라가지 않습니다).
  탭이 많아 가려지면 오른쪽 `<` `>` 로 숨은 탭을 가져옵니다. `Ctrl+Tab` 으로 옮기고 `Ctrl+W` 로 닫습니다.
* **사이드바** — **폴더** · 축소판 · 목차 · 찾기 · 이미지 · 책갈피 · **주석** · 클립.
  패널 제목은 굵게 보이고, 그 줄 오른쪽 아이콘으로 폴더 열기 · 목차 모두 펼치기/접기 ·
  이미지 추출 · 주석/첨부를 합니다. 오른쪽 **구분선을 끌어 너비를 바꿀 수 있고**,
  아이콘을 다시 누르면 닫힙니다.
* **상태 바** — 진행 상태, 파일과 폴더, 페이지, 배율, 파일 크기, 선택한 글자 수, 편집 기록 수, 저장 여부.

## 2. 파일 열기

| 방법 | 설명 |
| --- | --- |
| 툴바 **열기** (Ctrl+O) | PDF 또는 작업 파일(`.pdfvw`)을 고릅니다 |
| 툴바 **URL 열기** | 인터넷 주소에서 PDF를 내려받아 엽니다 (진행률 표시) |
| 툴바 **최근 파일** | 최근에 연 파일 10개. 각 항목의 휴지통으로 하나씩, 위쪽 *전체 지우기* 로 한 번에 지웁니다 |
| 사이드바 **폴더** | 데스크톱에서 폴더를 고르면 하위 폴더와 **확장자가 정확히 `.pdf` 인 파일**이 트리로 나타납니다. 파일을 누르면 새 탭으로 엽니다. 폴더 탐색은 웹에서는 사용할 수 없습니다 |
| 끌어다 놓기 | 창 안으로 PDF 파일을 끌어다 놓습니다 |
| 파일 두 번 클릭 | 설치 후 `.pdfvw` 파일을 두 번 누르면 바로 열립니다. PDF는 설치할 때 *PDF 파일의 기본 뷰어로 설정* 을 고르면 두 번 클릭으로 열리고, 고르지 않았다면 *연결 프로그램*에서 MyPDFViewer를 선택하면 됩니다 |

암호가 걸린 PDF는 암호를 묻는 창이 뜹니다. 큰 파일은 여는 동안 진행률 창이 나타납니다
(짧게 끝나는 작업에서는 창이 깜빡이지 않도록 잠깐 기다렸다 표시합니다).

## 3. 보기

* **연속 보기**(기본) — 페이지가 세로로 이어져 스크롤로 넘깁니다.
  툴바의 **페이지 보기** 버튼으로 *한 쪽씩* 보기로 바꿀 수 있습니다.
  페이지가 뷰어보다 크거나 확대하면 **스크롤바가 자동으로** 나타납니다.
* **너비 맞춤 / 페이지 맞춤 / 실제 크기** — 창 크기에 맞추거나 100%로 봅니다.
* **확대 · 축소** — 툴바 버튼, `Ctrl` + `+` / `-`, 또는 **`Ctrl` + 마우스 휠**.
  확대·축소해도 **보고 있던 페이지와 위치를 그대로 유지**합니다.
* **회전** — 왼쪽/오른쪽으로 90°씩.
* 어두운 테마에서 페이지를 반전해 보려면 설정 → 보기 → *어두운 테마에서 페이지 반전*.

## 4. 텍스트 복사

1. 툴바 가운데의 선택 도구에서 **텍스트** 를 고릅니다 (기본값, `Ctrl+1`). 마우스 포인터가 I 빔 모양이 됩니다.
2. 마우스로 끌어 원하는 부분을 선택합니다. 선택은 **줄 단위**이며, 시작 줄의 특정 칸에서
   끝 줄의 특정 칸까지 이어집니다 (사각형 영역이 아닙니다).
3. `Ctrl+C` 또는 툴바 **텍스트 복사** 를 누릅니다. 설정에서 *선택 후 자동 복사* 를 켜 두면
   텍스트·그림·영역을 고르는 즉시 클립보드로 들어갑니다.

* `Ctrl+A` — 현재 페이지의 모든 텍스트를 선택합니다.
* 오른쪽 클릭 → *이 페이지 텍스트 복사* — 선택 없이 페이지 전체 텍스트를 복사합니다.
* 툴바 **텍스트 내보내기** — 문서 전체 텍스트를 `.txt` 파일로 저장합니다.
* 복사한 텍스트는 사이드바 **클립** 에도 쌓여 나중에 다시 꺼낼 수 있습니다.

## 5. 이미지 복사와 저장

툴바 가운데에 선택 도구가 **세 개로 나뉘어** 있습니다.

| 도구 | 단축키 | 포인터 | 하는 일 |
| --- | --- | --- | --- |
| **텍스트** | Ctrl+1 | I 빔 | 글자를 끌어 선택하고 복사 |
| **이미지** | Ctrl+2 | 손가락 | 페이지 안의 그림을 클릭해 선택 |
| **영역** | Ctrl+3 | 십자 | 원하는 부분을 사각형으로 끌어 캡처 |

`Ctrl+M` 으로 세 도구를 차례로 넘기고, `Esc` 를 누르면 언제든 텍스트 도구로 돌아옵니다.

### 5.1 원하는 영역을 사각형으로 잘라내기 (영역 도구, Ctrl+3)

페이지의 아무 곳이나 **마우스로 사각형을 끌면** 그 부분이 잘려 나오고 캡처 창이 열립니다.
그림이 아닌 부분(표, 수식, 본문 일부, 페이지 전체 등)도 그대로 이미지가 됩니다.

캡처 창에서 할 수 있는 일:

| 버튼 | 하는 일 |
| --- | --- |
| **복사** | 클립보드로 복사합니다 (PNG) |
| **저장…** | 파일로 저장합니다. 형식은 아래에서 고른 것이 쓰입니다 |
| **클립에 보관** | 사이드바 *클립* 에 담아 둡니다 |

**지원하는 저장 형식**

| 형식 | 특징 |
| --- | --- |
| **PNG** | 무손실. 글자·도표처럼 경계가 뚜렷한 내용에 가장 좋습니다 |
| **JPEG** | 사진에 적합하고 파일이 작습니다. 품질(10–100%) 조절 가능 |
| **WebP** | 최신 형식. 같은 품질에서 JPEG보다 작습니다. 품질 조절 가능 |
| **GIF** | 256색. 오래된 프로그램에서도 열립니다 |
| **BMP** | 무압축 비트맵. 파일이 크지만 어디서나 열립니다 |

창 위쪽 미리보기는 **실제로 인코딩한 결과**이고, 오른쪽에 예상 파일 크기가 함께 표시되므로
JPEG 품질을 낮췄을 때 얼마나 작아지고 얼마나 뭉개지는지 미리 확인할 수 있습니다.

> 저장 창에서 직접 확장자를 입력해도 됩니다. `그림.webp` 처럼 적으면 그 형식으로 저장됩니다.
> 클립보드 복사는 호환성을 위해 항상 PNG로 이루어집니다.

### 5.2 그림을 골라서 복사하기 (이미지 도구, Ctrl+2)

이미지 도구를 켜면 페이지에 들어 있는 **그림마다 점선 테두리**가 표시됩니다.
그림 위로 마우스를 옮기면 포인터가 손가락 모양으로 바뀌고 테두리가 진해집니다.

1. 그림을 **왼쪽 클릭** 하면 선택됩니다. 선택된 그림은 굵은 테두리로 표시되고,
   상태 바에 크기가 나타납니다. **이때 복사는 일어나지 않습니다.**
2. 그림 위에서 **오른쪽 클릭** 하면 메뉴가 열리고 다음을 고를 수 있습니다.

   | 메뉴 | 하는 일 |
   | --- | --- |
   | **이미지 복사** | 원본 해상도 그대로 클립보드로 (화면 배율과 무관) |
   | **이미지로 저장…** | PNG · JPEG · WebP · GIF · BMP 중 골라 파일로 저장 |
   | **이미지를 클립에 보관** | 사이드바 *클립* 에 담아 둡니다 |
   | **이미지 선택 해제** | 선택을 해제합니다 (`Esc` 도 동일) |

   그림 위에서 바로 오른쪽 클릭해도 그 그림이 선택된 뒤 메뉴가 열립니다.

### 5.3 페이지의 이미지 한꺼번에 뽑기

툴바 **이미지 추출** 을 누르면 현재 페이지에 들어 있는 이미지를 모두 찾아
사이드바 *이미지* 패널에 보여 줍니다. 각각 복사하거나 저장할 수 있습니다.
너무 작은 장식용 이미지는 설정 → 복사 → *추출할 최소 이미지 크기* 로 걸러집니다.

## 5.4 인쇄 (Ctrl+P)

툴바의 **인쇄** 버튼을 누르면 무엇을 인쇄할지 먼저 고릅니다.

| 선택 | 설명 |
| --- | --- |
| **전체** | 문서의 모든 쪽 |
| **현재 페이지** | 지금 보고 있는 쪽 하나만 |
| **사용자 지정** | 쪽 번호와 범위를 직접 입력 — `1-5, 8, 11-13` 처럼 쉼표로 나열 |

* 아래쪽에 **몇 쪽이 인쇄되는지** 미리 표시되고, 잘못된 범위(예: 문서보다 큰 쪽 번호)는
  이유를 알려 주며 인쇄 버튼이 비활성화됩니다.
* 고른 쪽만 준비된 뒤 **시스템 인쇄 창**이 열립니다. 프린터·용지·매수는 그 창에서 정합니다.
* 쪽 수가 많으면 준비하는 동안 진행률 창이 표시됩니다.

## 6. 찾기 · 목차 · 책갈피 · 주석

* **찾기** (`Ctrl+F`) — 문서 전체에서 검색하고, 결과를 누르면 해당 쪽으로 이동합니다.
  그 페이지에서 **찾은 단어가 노란 배경으로 표시**됩니다.
* **목차** — PDF에 목차가 있으면 **트리 구조**로, 실제 쪽 번호와 함께 표시됩니다.
  * 하위 항목이 있는 줄의 **화살표**를 눌러 접었다 펼 수 있고, 부모와 자식은 연한 연결선으로 이어집니다.
  * **Outline** 제목 오른쪽 아이콘으로 **모두 펼치기 / 모두 접기** 를 합니다.
  * 항목을 누르면 해당 쪽으로 이동하며, **선택한 항목만** 색이 칠해집니다.
* **책갈피** — 툴바 또는 오른쪽 클릭으로 현재 위치를 담아 둡니다. 텍스트를 선택한 상태면
  그 문구가 이름이 되고, 페이지에는 **선택 배경색**으로 표시됩니다 (테두리 없는 형광 표시).
* **형광펜** — 텍스트를 선택하고 형광펜 버튼을 누르면 노란색으로 칠해집니다.
* **코멘트** — 텍스트를 선택한 뒤 코멘트를 남기면, 페이지에는 색으로만 표시되고
  옆에 내용 카드가 붙습니다. 사이드바 **주석** 목록에서 항목을 누르면 그 위치로 이동합니다.
  PDF에 원래 들어 있던 주석도 같은 목록에 보입니다 (삭제는 이 프로그램에서 단 것만 됩니다).
* **파일 첨부** — **파일 → 파일 첨부**, 오른쪽 클릭, 또는 주석 패널 제목 오른쪽 **첨부 아이콘**으로
  현재 페이지에 파일을 붙입니다. **PDF로 저장**하면 문서 안에 들어갑니다.

형광펜 · 코멘트 · 책갈피 · 첨부 · 클립은 모두 **실행 취소(Ctrl+Z) / 다시 실행(Ctrl+Y)** 대상입니다 (최대 100단계).

## 7. 저장

### 7.1 PDF로 저장 (Ctrl+S)

주석 · 책갈피 · 첨부 파일을 **PDF 안에** 씁니다. Acrobat 등 다른 뷰어에서도 보입니다.

* `Ctrl+S` 또는 **파일 → PDF로 저장** 을 누르면 **저장 창이 열립니다.**
  원본을 바로 덮어쓰지 않으며, 원하는 이름과 위치를 고를 수 있습니다.
* 기본으로 제안하는 이름은 `문서이름-annotated.pdf` 입니다.
* 책갈피는 PDF 목차(Outline)로, 첨부는 Embedded File로 들어갑니다.

끝내지 않은 작업이 있으면 창을 닫거나 다른 문서를 열기 전에 **PDF로 저장할지** 묻습니다.

### 7.2 작업 파일 (.pdfvw)

**파일 → 작업 파일로 저장** 은 이 프로그램 전용 `.pdfvw` 파일을 만듭니다.
원본 PDF의 경로, 마지막으로 보던 쪽과 배율, 형광펜·코멘트·책갈피·클립·첨부가 담깁니다.
두 번 클릭하면 PDF가 다시 열리면서 작업 내용이 그대로 복원됩니다.

> `.pdfvw` 는 PDF 자체를 담지 않습니다. 원본 PDF를 옮기거나 지우면
> "이 작업 파일이 가리키는 PDF를 찾을 수 없습니다"라는 안내가 나옵니다.

## 8. 설정

툴바 오른쪽 **⚙ 설정** 에서 바꾼 값은 즉시 적용되고 다음 실행 때 그대로 복원됩니다.
탭을 바꿔도 설정 창 크기는 그대로입니다.

툴바의 **테마** 버튼을 누르면 다음 테마로 바뀌고, 오른쪽 화살표로 20개 목록에서 고릅니다.
**언어** 버튼은 **바꿀 언어의 국기**입니다. 한글일 때는 영국 국기, 영어일 때는 태극기가 보이고, 누르면 그 언어로 바뀝니다.

| 탭 | 항목 |
| --- | --- |
| **모양** | 테마 20종, 언어(한국어/English, 국기), 글꼴 종류(시스템 전체) · 크기(− / +) · 굵게/기울임/밑줄 |
| **보기** | 기본 확대 방식, 페이지 배치, 상태 바 표시, 툴바 글자 표시, 페이지 반전, 마지막 쪽 기억 |
| **복사** | 추출할 최소 이미지 크기, 캡처 저장 형식, 캡처 품질, 영역 캡처 후 동작, **텍스트·그림·영역 선택 후 자동 복사** |
| **파일** | 최근 파일 목록(개별·전체 삭제), 최근 폴더, 설정 저장 위치, 모든 설정 초기화 |

## 10. 오류가 났을 때

오류는 조용히 넘어가지 않고 팝업으로 표시됩니다. 팝업에는

* **무엇을 하다가** 생긴 문제인지 (파일 열기, 저장, 클립보드 복사 …)
* **오류 내용** 한 줄 요약
* *자세히 보기* 를 누르면 나오는 **기술 상세(스택)**

가 들어 있고, **오류 내용 복사** 버튼으로 전부 한 번에 복사해 그대로 전달할 수 있습니다.

## 11. 웹 브라우저에서 쓸 때의 차이

* 브라우저는 보안상 파일의 실제 경로를 알 수 없어, PDF·`.pdfvw` 저장은 *다운로드* 로 이루어지고
  최근 파일 목록에는 이름만 남습니다.
* 이미지 클립보드 복사는 HTTPS(보안 컨텍스트)에서만 동작합니다. 데스크톱 앱은 제한이 없습니다.
* 테마 목록이 창 밖으로 펼쳐지는 것은 데스크톱 앱에서만 됩니다. 웹에서는 페이지 안에 목록이 열립니다.
* **폴더 트리**는 데스크톱 앱에서만 됩니다. 웹에서는 안내 문구만 보입니다.
* 나머지 기능(보기 · 선택 · 캡처 · 형식 변환 저장 · 검색 · 주석 · 테마 · 설정 저장)은 동일합니다.
