# MyPDFViewer

PDF를 읽고, 그 안의 **텍스트와 이미지를 손쉽게 복사**할 수 있는 다중 플랫폼 뷰어입니다.
하나의 코드베이스로 **웹 브라우저 · Windows · macOS · Linux** 에서 동작하며,
각 플랫폼용 설치 파일을 만들 수 있습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| PDF 보기 | 연속 스크롤 / 한 쪽씩 보기, 너비 맞춤 · 페이지 맞춤 · 실제 크기 · 자유 확대(25 %–800 %), **Ctrl+휠 확대**(보던 위치 유지), 90° 회전. 확대하면 스크롤바가 자동으로 나타납니다 |
| 문서 탭 | 여러 PDF를 **탭**으로 동시에 엽니다. 탭은 툴바 아래·문서 위에만 있고 좌측 패널 위로는 올라가지 않습니다. 탭이 많으면 오른쪽 `<` `>` 로 숨은 탭을 옮깁니다 (Ctrl+Tab / Ctrl+W) |
| 텍스트 복사 | 마우스로 끌어 선택, 페이지 전체 선택(Ctrl+A), 클립보드 복사(Ctrl+C), 문서 전체 텍스트를 `.txt` 로 내보내기 |
| 영역 캡처 | 페이지의 **아무 곳이나 사각형으로 끌어** 이미지로 잘라내 복사하거나 저장 (그림이 아닌 표·수식·본문도 가능) |
| 저장 형식 | **PNG · JPEG · WebP · GIF · BMP** — 미리보기와 예상 파일 크기를 보며 고르고, JPEG·WebP는 품질 조절 |
| 이미지 복사 | 그림을 클릭해 **선택**하고, 오른쪽 클릭 메뉴에서 원본 해상도로 복사·저장·클립 보관. 페이지의 이미지 일괄 추출도 가능 |
| 선택 도구 | 툴바에서 **텍스트(Ctrl+1) · 이미지(Ctrl+2) · 영역(Ctrl+3)** 세 가지를 분명히 구분해 고릅니다 — 각각 I 빔 · 손가락 · 십자 포인터 |
| 인쇄 | **전체 · 현재 페이지 · 사용자 지정 범위**(`1-5, 8, 11-13`) 중에서 고른 뒤 시스템 인쇄 창으로 (Ctrl+P) |
| 찾기 | 문서 전체 검색, 결과 목록에서 해당 쪽으로 이동하고 **페이지 위에 검색어를 강조** |
| 주석 | 형광펜, 코멘트, 책갈피, **파일 첨부**, 복사한 텍스트·이미지 클립. PDF에 있던 주석도 읽습니다 |
| 실행 취소 / 다시 실행 | 형광펜·코멘트·책갈피·첨부·클립 등 모든 편집을 최대 100단계까지 (Ctrl+Z / Ctrl+Y) |
| PDF로 저장 | **Ctrl+S** — 주석·책갈피·첨부를 PDF 안에 씁니다. 저장 창에서 **다른 이름을 고를 수 있고**, 기본 제안은 `문서이름-annotated.pdf` 입니다 |
| 작업 파일 | `.pdfvw` 형식으로도 저장 가능 — 원본 PDF 경로, 마지막 쪽, 형광펜·책갈피·클립·첨부를 그대로 복원 |
| 사이드바 | **폴더 트리**(데스크톱) · 축소판 · 접히는 **목차 트리** · 찾기 · 이미지 · 책갈피 · **주석** · 클립. 제목은 굵게 보이고, 패널 동작(폴더 열기 · 모두 펼치기/접기 · 추출 · 주석 추가)은 제목 오른쪽 **아이콘**입니다. **구분선을 끌어 너비를 조절**합니다 (기본 220px) |
| 테마 | **20가지** 테마. 버튼을 누르면 다음 테마로 바뀌고, 오른쪽 화살표로 목록에서 고릅니다 (목록에 스크롤바 없음, 창 밖으로 펼쳐질 수 있음) |
| 언어 | 한국어 · English. 툴바 국기는 **지금 쓸 언어**를 보여 줍니다 (한글 UI → 영국 국기, 영어 UI → 태극기). 누르면 그 언어로 바뀝니다 |
| 글꼴 | 시스템에 설치된 **모든 글꼴**, 크기(10–24px), 굵게 · 기울임 · 밑줄 |
| 최근 파일 | 최대 10개, 개별 삭제 · 전체 삭제, 최근 폴더 기억 |
| 타이틀 바 | 프로그램 이름과 버전, 현재 문서 이름, 변경 표시 |
| 상태 바 | 진행 상태 · 파일 · 폴더 · 쪽 번호 · 배율 · 크기 · 선택 글자 수 · 편집 기록 · 저장 여부 |
| 진행 표시 | 열기 · 저장 · 다운로드 · 이미지 추출 등 오래 걸리는 작업의 진행률 팝업 |
| 오류 처리 | 무슨 작업 중이었는지 + 구체적 오류 + 기술 상세(스택)를 팝업으로 표시하고 **한 번에 복사** |
| 설정 유지 | 테마 · 언어 · 글꼴 · 보기 방식 · 최근 파일 · 마지막 폴더를 다음 실행 때 그대로 복원 |
| 컨텍스트 메뉴 | 페이지 위에서 오른쪽 클릭 — 복사 · 형광펜 · 도구 전환 · 이동 · 확대 · 회전 · 문서 속성 |

### 파일 형식 등록

설치 프로그램이 다음을 시스템에 등록합니다.

* `.pdfvw` — MyPDFViewer 작업 파일. **전용 아이콘**을 가지며 두 번 클릭하면 원본 PDF와 작업 내용이 함께 열립니다.
* `.pdf` — 항상 **[연결 프로그램]** 목록에 추가됩니다. 설치 화면의
  **[PDF 파일의 기본 뷰어로 설정]** 을 선택하면 기본 뷰어로도 등록됩니다 (선택하지 않으면 기존 기본 프로그램을 그대로 둡니다).
  Windows 8 이후로는 기본 앱을 설치 프로그램이 마음대로 바꿀 수 없어, 이미 다른 PDF 프로그램이
  기본으로 지정되어 있으면 Windows **[기본 앱]** 설정 창이 열리고 마지막 확인만 사용자가 누르면 됩니다.

아이콘은 모두 `assets/icon.svg`(프로그램)와 `assets/file-icon.svg`(문서)에서 생성되며,
테두리가 투명한 3D 형태에 좌측 상단이 빛나는 형태입니다. 설치 파일도 같은 아이콘을 사용합니다.

## 실행

```bash
npm install          # 의존성 설치 (pdf.js 런타임 파일과 빌드 정보도 함께 준비됩니다)

npm start            # 데스크톱(Electron) 개발 실행 — 항상 최신 소스가 반영됩니다
                     # (이전 개발 서버가 포트를 잡고 있으면 자동으로 정리하고 시작합니다)
npm run web          # 웹 브라우저용 개발 서버 (http://localhost:5179)
npm test             # 단위·계약 테스트 (Vitest). 항목마다 통과/실패를 색으로 나열합니다 (진행 점 … 없음)
npm run test:watch   # 파일 변경 때마다 테스트를 다시 실행합니다
```

## 설치 파일 만들기

```bash
npm run build:win    # Windows  → release/MyPDFViewer Setup 1.0.0.exe (NSIS)
npm run build:mac    # macOS    → release/*.dmg  (x64 + arm64)
npm run build:linux  # Linux    → release/*.AppImage, *.deb
npm run build        # 웹 배포용 정적 파일 → dist/
```

빌드가 끝나면 설치 파일이 프로젝트 최상위로 복사됩니다.
Windows 설치 프로그램은 설치 경로 선택, 바탕화면 · 시작 메뉴 바로 가기 선택(한국어/영어)을 제공합니다.

## 구조

```
assets/          icon.svg (프로그램) · file-icon.svg (.pdfvw 문서)
build/           생성된 아이콘(ico/icns/png) · installer.nsh (NSIS 사용자 정의)
electron/        main.js (창·IPC·파일 입출력·다운로드) · preload.js · folder-list.js
public/pdfjs/    pdf.js 런타임 데이터 (CJK cmaps, 표준 글꼴)
scripts/         아이콘 생성 · 빌드 정보 · pdf.js 자산 복사 · 실행 · 설치 파일 복사
src/
  App.jsx        전체 상태와 동작을 묶는 최상위 컴포넌트
  components/    Toolbar · TabBar · Sidebar · FolderTree · PdfView · StatusBar · ThemePopup · 각종 대화상자
  lib/pdf.js     pdf.js 래퍼 (렌더링 · 텍스트 레이어 · 이미지 추출 · 주석 읽기 · 검색)
  lib/pdf-write.js  주석·책갈피·첨부를 PDF에 쓰기 (pdf-lib)
  lib/comments.js   PDF/작업 주석 정규화와 목록 합치기
  lib/tabs.js    문서 탭 키 · 이웃 탭 · 넘침 스크롤
  lib/folders.js 폴더 트리 항목 분류 (확장자가 정확히 pdf 인 파일만)
  lib/image.js   PNG/JPEG/WebP는 캔버스, GIF·BMP는 자체 인코더 (median cut + LZW)
  lib/print.js   인쇄 범위 해석 · 페이지 래스터화 · 인쇄용 HTML
  lib/history.js 스냅샷 기반 실행 취소/다시 실행
  lib/workspace.js  .pdfvw 파일 읽기/쓰기
  lib/settings.js   설정 기본값 · 저장 · 최근 파일
  lib/platform.js   Electron / 웹 런타임 추상화 (대화상자 · 저장 · 클립보드 · 진행률)
  i18n.js        한국어 · 영어 문자열
test/            Vitest 스위트와 한국어 요약 리포터
```

웹과 데스크톱은 같은 화면 코드를 사용하고, 파일 접근처럼 런타임이 다른 부분만
`lib/platform.js` 한 곳에서 갈라집니다.

## 참고

* **Ctrl+S** 는 원본 PDF를 덮어쓰지 않습니다. 저장 창에서 이름을 고르며, 기본값은 `문서이름-annotated.pdf` 입니다.
* 웹 브라우저에서는 보안 정책상 파일 경로를 알 수 없어 PDF·`.pdfvw` 저장은 *다운로드* 로 이루어지고,
  최근 파일 목록의 항목은 이름만 기억됩니다.
* 이미지 클립보드 복사는 브라우저에서 HTTPS(보안 컨텍스트)가 필요하며 항상 PNG로 이루어집니다.
  파일로 저장할 때는 다섯 가지 형식을 모두 쓸 수 있습니다. 데스크톱 앱은 제한이 없습니다.
* `pdfjs-dist` 는 4.8.69에 고정되어 있습니다. 4.9 이상은 Electron 31(Chromium 126)에 없는
  `Promise.try` 를 써서 PDF가 열리지 않습니다 — 올리려면 Electron 32 이상이 함께 필요합니다.
* 암호가 걸린 PDF는 열 때 암호를 묻습니다. 암호가 걸린 문서에 주석을 다시 쓰는 것은 지원하지 않습니다.
* 끝내지 않은 주석·책갈피·첨부가 있으면 창을 닫거나 그 탭을 닫기 전에 저장할지 묻습니다.
* 폴더 트리의 PDF 목록은 확장자가 정확히 `pdf` 인 파일만 포함합니다. 작업 파일(`.pdfvw`)은 열기 대화상자로 엽니다.
