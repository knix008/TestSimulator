# MyPDF Editor 사용자 가이드

MyPDF Editor는 Windows용 PDF 뷰어 및 텍스트 편집 프로그램입니다. 이 문서는 일상적인 작업 흐름과 각 기능의 사용 방법을 설명합니다.

## 1. 시작하기

### 프로그램 실행

- **설치한 경우**: 시작 메뉴 또는 바탕 화면의 **MyPDF Editor** 실행. `.pdf` 파일을 더블클릭해도 열립니다 (설치 시 PDF 파일 연결을 선택한 경우).
- **개발 빌드**:

```bash
dotnet run --project MyPDFEditorWinV10.csproj -c Debug
```

PDF 파일을 인수로 넘기면 바로 열립니다.

```bash
dotnet run --project MyPDFEditorWinV10.csproj -- "C:\문서\sample.pdf"
```

### 기본 작업 흐름

1. PDF 파일을 연다.
2. 필요하면 **편집 → PDF에서 텍스트 가져오기**로 텍스트를 추출한다.
3. 우측 편집창에서 내용을 수정한다.
4. PDF 위에서 이미지 영역을 선택해 복사·저장하거나 편집창에 삽입한다.
5. **파일** 메뉴에서 PDF, Markdown, Word 형식으로 보낸다.

## 2. 화면 구성

```
┌──────────────────────────────────────────────────────────────────────┐
│  메뉴 (파일 | 편집 | 보기 | 정보)                                     │
├──────────────────────────────────────────────────────────────────────┤
│  툴바 (열기, 텍스트 가져오기, 이미지 복사/저장/삽입, 페이지, 보내기) │
├────────────────────────────┬─────────────────────────────────────────┤
│  PDF 뷰어                  │  텍스트 편집창                          │
│  (페이지 표시, 영역 선택)   │  (RichTextBox)                          │
│                            ├─────────────────────────────────────────┤
│                            │  추출 이미지 미리보기                    │
├────────────────────────────┴─────────────────────────────────────────┤
│  상태 표시줄 (파일 경로, 현재 페이지)                                 │
└──────────────────────────────────────────────────────────────────────┘
```

### 분할선 조절

- **좌우 분할**: PDF 뷰어와 편집 영역 사이의 세로 분할선을 드래그하여 너비를 조절합니다.
- **우측 상·하 분할**: 텍스트 편집창과 이미지 미리보기 사이의 가로 분할선을 드래그하여 높이를 조절합니다.

## 3. PDF 열기 및 탐색

### PDF 열기

1. **파일 → PDF 열기** 또는 툴바 **열기**
2. `.pdf` 파일을 선택합니다.

### 페이지 이동

| 방법 | 설명 |
|------|------|
| **보기 → 이전 페이지 / 다음 페이지** | 현재 페이지 기준으로 이동 |
| 툴바 **◀ / ▶** 버튼 | 이전·다음 페이지 |
| 상태 표시줄 | `페이지 N / 전체` 형식으로 현재 위치 표시 |

### 확대 / 축소

| 메뉴 | 설명 |
|------|------|
| **보기 → 확대** | PDF 화면 확대 |
| **보기 → 축소** | PDF 화면 축소 |

PDF를 처음 열면 **너비 맞춤** 모드로 표시됩니다.

## 4. 텍스트 추출 및 편집

### PDF에서 텍스트 가져오기

1. PDF 파일을 연 상태에서 **편집 → PDF에서 텍스트 가져오기** 또는 툴바 **텍스트 가져오기**
2. PdfPig 엔진이 PDF 전체에서 텍스트를 추출합니다.
3. 편집창에 이미 내용이 있으면 **덮어쓰기 / 이어 붙이기 / 취소**를 선택할 수 있습니다.

### 편집

- 우측 **텍스트 편집창**에서 자유롭게 입력·수정합니다.
- 내용이 변경되면 제목 표시줄에 `●` 표시가 나타납니다.
- 프로그램을 종료할 때 저장하지 않은 변경 사항이 있으면 확인 메시지가 표시됩니다.

> **참고**: 추출된 텍스트는 PDF 레이아웃과 완전히 동일하지 않을 수 있습니다. 복잡한 표·다단 레이아웃 PDF는 수동 정리가 필요할 수 있습니다.

## 5. 이미지 작업

### 화면 영역 선택 (렌더링 이미지)

1. PDF 뷰어에서 마우스로 **드래그**하여 사각형 영역을 선택합니다.
2. 선택 영역은 파란 테두리로 표시됩니다.

### 선택 영역 복사

- **편집 → 선택 영역 이미지 복사** 또는 툴바 **복사**
- 클립보드에 비트맵 이미지로 복사됩니다. 다른 프로그램에 붙여넣기(Ctrl+V)할 수 있습니다.

### 선택 영역 파일로 저장

1. **편집 → 선택 영역 이미지 저장** 또는 툴바 **저장**
2. 저장 형식을 선택합니다: **PNG, JPEG, GIF, WebP, AVIF**
3. 저장 위치와 파일 이름을 지정합니다.

### 선택 영역을 편집창에 삽입

- **편집 → 선택 영역을 편집창에 삽입** 또는 툴바 **삽입**
- RichTextBox 편집창 커서 위치에 이미지가 삽입됩니다.

### PDF 내장 이미지 추출 (현재 페이지)

| 메뉴 | 설명 |
|------|------|
| **편집 → 현재 페이지 이미지 편집창에 추가** | 현재 페이지에 포함된 이미지를 우측 하단 미리보기 패널에 표시 |
| **편집 → 현재 페이지 이미지 파일로 저장** | 현재 페이지의 모든 내장 이미지를 지정 폴더에 일괄 저장 |

미리보기 패널의 이미지를 **우클릭**하면 **파일로 저장** 메뉴로 개별 저장할 수 있습니다.

### 지원 이미지 저장 형식

| 형식 | 확장자 | 비고 |
|------|--------|------|
| PNG | `.png` | 무손실, 투명도 지원 |
| JPEG | `.jpg` | 사진·압축에 적합 |
| GIF | `.gif` | 애니메이션 미지원 (정지 이미지) |
| WebP | `.webp` | 고효율 압축 |
| AVIF | `.avif` | 고효율 압축 |

## 6. 보내기

편집창의 텍스트와 삽입된 이미지를 아래 형식으로 저장합니다. PDF를 열지 않았거나 편집 내용이 비어 있으면 안내 메시지가 표시됩니다.

| 메뉴 / 툴바 | 형식 | 설명 |
|-------------|------|------|
| **파일 → PDF로 저장** | `.pdf` | PDFsharp로 새 PDF 생성 |
| **파일 → Markdown으로 저장** | `.md` | 텍스트 및 이미지 참조 포함 |
| **파일 → Word로 저장** | `.docx` | Open XML Word 문서 |

각 항목은 **다른 이름으로 저장** 대화상자를 통해 경로를 지정합니다.

## 7. 설치 및 제거

### MSI 설치

Release 빌드로 생성된 `MyPDFEditorWinV10Setup.msi`를 실행합니다.

| 설치 단계 | 설명 |
|-----------|------|
| 환영 | 설치 시작 |
| 기존 설치 확인 | 이전 버전이 있으면 업그레이드 동의 |
| 기능 선택 | **PDF 파일 연결** 여부 선택 (기본값: 끔) |
| 바로 가기 설정 | **시작 메뉴** / **바탕 화면** 바로 가기 각각 체크박스로 선택 |
| 설치 확인 | 선택 내용 확인 후 설치 |

### 제거

**설정 → 앱 → 설치된 앱** 또는 **제어판 → 프로그램 제거**에서 **MyPDF Editor v1.0**을 선택합니다.

| 제거 옵션 | 설명 |
|-----------|------|
| 작업 데이터 삭제 | `%AppData%\MyPDFEditorWinV10` 폴더 삭제 여부 선택 |

### 작업 데이터 위치

```
%AppData%\MyPDFEditorWinV10\
```

## 8. 자주 묻는 질문

### PDF가 열리지 않습니다

- 파일이 손상되었거나 암호로 보호된 PDF일 수 있습니다.
- 경로에 특수 문자가 많으면 다른 위치로 복사 후 다시 시도해 보세요.

### 텍스트가 제대로 추출되지 않습니다

- 스캔본 PDF(이미지 기반)는 OCR이 없으므로 텍스트 추출이 되지 않습니다.
- 표·다단·수식이 많은 문서는 추출 순서가 원본과 다를 수 있습니다.

### 선택 영역 복사가 비활성화됩니다

- 먼저 PDF를 연 뒤, PDF 뷰어 위에서 드래그하여 영역을 선택해야 합니다.

### MSI가 생성되지 않습니다

- **Release** 구성으로 빌드했는지 확인합니다.
- WiX 빌드만 건너뛴 경우(`SkipInstaller=true`)가 아닌지 확인합니다.
- MSI만 별도 빌드: `dotnet build installer\MyPDFEditorWinV10.Installer.wixproj -c Release -p:Platform=x64`

### 프로그램 정보는 어디서 보나요?

- 메뉴 **정보** 또는 툴바 **정보** 버튼을 클릭합니다.
