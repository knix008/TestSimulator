MyHeatManager 사용 설명서

MyHeatManager는 전자 기기·배터리·건물 외피·우주 장비 같은 장치의 열을 시뮬레이션하는 프로그램입니다. 2D 단면이나 3D 적층 모델을 그리고, 재료·열원·경계 조건을 정한 뒤 해석하면 온도·열유속·유속·응력 분포와 수명 추정, 히트맵을 볼 수 있습니다.

계산은 Rust 엔진이 맡습니다. 데스크톱 프로그램(Windows · macOS · Linux)에서는 네이티브로, 웹판에서는 같은 엔진을 WebAssembly로 컴파일해 브라우저 안에서 실행합니다. 설치본은 Node.js 같은 다른 프로그램이 없어도 실행됩니다.

화면 구성 #

화면은 MyCAD와 같은 배치입니다.

제목 줄과 메뉴 막대 #

시스템 제목 표시줄은 없습니다. 맨 윗줄 하나에 다음이 차례로 놓입니다.

  • 프로그램 아이콘 · MyHeatManager · 버전, 그 뒤에 일정한 간격을 두고 지금 열린 모델 이름(폭이 정해진 칸이라 길면 … 으로 줄입니다).
  • 🏠 홈 단추(시작 화면 열기/닫기) — 파일 메뉴 바로 왼쪽.
  • 파일 · 편집 · 보기 · 모델 · 해석 · 결과 · 도구 · 도움말 메뉴. 메뉴 하나를 연 채로 옆 메뉴에 마우스를 올리면 그 메뉴로 바뀝니다.
  • 작업대 선택(형상 · 재료 · 열원·경계 · 해석 · 결과 · 신뢰성 · 히트맵 (HAM)) — 왼쪽 도구 패널의 내용을 바꿉니다.
  • 오른쪽 끝의 최소화 · 최대화 · 닫기 단추(데스크톱).

빈 곳을 끌면 창이 움직이고(화면 가장자리에 붙이기 포함) 두 번 누르면 최대화됩니다. 창 크기는 테두리나 상태 표시줄 오른쪽 아래의 크기 조절 표시를 끌어 바꿉니다. 창은 도구 모음의 단추가 모두 보이는 폭보다 좁아지지 않습니다(글꼴 크기나 언어를 바꾸면 그 폭을 다시 잽니다).

테마 목록 #

▾ 를 누르면 테마 목록이 펼쳐집니다.

  • 어두운 테마와 밝은 테마가 두 열로 나뉘어 위에서 아래로 늘어섭니다(각 20개).
  • 테마마다 두 줄짜리 칸입니다 — 윗줄은 색 띠(배경 · 패널 · 단추 · 강조 · 글자), 아랫줄은 이름. 지금 테마는 강조 표시됩니다.
  • 맨 아래 사용자 정의 테마 줄에 내 테마 칸과 사용자 정의 테마 설정…, 테마 설정… 이 있습니다. 둘은 환경 설정 창을 각각 사용자 테마 탭과 테마 탭으로 엽니다.

패널 #

  • 왼쪽 패널(도구 · 모델 트리): 위는 작업대의 도구 무리, 아래는 모델 트리(해석 · 해석 영역 · 재료 · 물체 · 경계 조건 · 탐침 · 결과). 무리 제목을 누르면 접힙니다. 물체 옆의 ◉ 는 숨기기 스위치입니다(숨긴 물체는 해석에서 빠집니다).
  • 오른쪽 패널(속성): 선택한 물체·경계·탐침·재료의 속성. 아무것도 선택하지 않으면 모델 이름과 해석 설정, 결과 요약이 보입니다.
  • 좌우 패널의 제목 막대에는 아이콘·제목과 접기 단추(« / »)가 있습니다. 접으면 아이콘과 세로 제목만 있는 좁은 띠가 남고, 띠를 누르면 다시 펼쳐집니다.
  • 아래 그래프 패널: 제목 막대에 아이콘 · 그래프 제목, 탭(탐침 · 단면선 · 물체 최고 온도 · 잔차 (수렴)), 오른쪽에 접기(▾ / ▴)와 감추기(✕)가 있습니다. 접으면 제목 막대만 남고, 감춘 패널은 도구 모음의 그래프 패널 단추로 다시 보입니다. 패널 위의 막대를 끌어 높이를 바꿉니다. 그래프에서 오른쪽 단추를 누르면 그래프 그림 저장… 이 있습니다.
  • 도구 모음의 패널 단추 셋은 패널을 아예 감추거나 다시 보입니다.

탭과 뷰포트 #

  • 모델마다 탭이 하나씩 생깁니다. 탭 줄 오른쪽 끝에는 언제나 < > 단추가 있어 넘친 탭을 앞뒤로 넘겨 보고(더 갈 곳이 없으면 흐려짐), 그 옆의 + 는 새 모델입니다. 탭에서 오른쪽 단추를 누르면 다른 탭 닫기 가 있습니다.
  • 뷰포트에는 눈금자, 색 막대, 프레임 슬라이더가 있습니다.
  • 보기 단추: ▦ 격자(G) — mm 눈금 도면 격자(확대하면 촘촘해지고 원점의 x·y 축은 강조색), # 계산 격자(M) — 해석에 쓰는 셀 경계, ⊹ 좌표축 — 3D 보기의 x · y · z 축과 눈금, 📏 눈금자 — 아래(x)와 왼쪽(y)에 보이는 범위의 주·보조 눈금과 커서 위치, 🏷 이름표(보기 메뉴) — 물체·탐침 이름.
  • 상태 표시줄: 상태, 셀 수, 선택 수, 커서 좌표(환경 설정의 길이 단위)와 그 위치의 값, 엔진 종류(네이티브 / WebAssembly), 저장 여부, 파일 경로.

3D 보기 #

3D 보기(3)는 해석 전에는 물체를 입체로, 해석 뒤에는 결과를 보여 줍니다(3D 모델은 해석한 셀의 바깥 면에 색, 2D 모델은 값을 높이와 색으로 그린 카펫 그림). 왼쪽 단추로 돌리고, 오른쪽 단추로 옮기고, 휠로 확대합니다.

  • 무한 격자: z = 0 평면에 끝없이 이어지는 격자가 있습니다. 확대·축소에 맞춰 간격이 바뀌고 멀리 갈수록 흐려집니다.
  • 좌표축: x · y · z 축과 눈금. 눈금 숫자에 길이 단위가 붙고(예: 20 mm), 축 끝 옆에는 축 이름 X · Y · Z 만 적힙니다. 확대·축소하면 눈금 간격이 1 · 2 · 5 단위로 다시 정해집니다.
  • 격자와 좌표축은 물체 뒤에 그려지므로 물체를 가리지 않고, 눈금 숫자도 격자에 덮이지 않습니다.
  • 격자(G)와 좌표축은 도구 모음·보기 메뉴에서 켜고 끕니다. 길이 단위(mm · cm · m · in)와 온도 단위(°C · K · °F)는 환경 설정 › 일반에서 정합니다. 길이 단위는 눈금자·좌표축 눈금·커서 좌표에 함께 쓰입니다.
  • 원위치(Ctrl+0)는 처음 시점으로, 화면에 맞춤(F)은 모델 전체가 보이도록 되돌립니다.

대화 상자와 메뉴 창 #

데스크톱 프로그램에서는 대화 상자와 펼침 메뉴(메뉴 막대의 메뉴, 오른쪽 단추 메뉴, 테마 목록)가 각자의 창으로 열립니다. 그래서 주 창이 작아도 메뉴와 대화 상자가 주 창 밖까지 펼쳐집니다.

  • 대화 상자가 열려 있는 동안 주 창은 흐리게 덮이고, 흐린 주 창을 누르면 대화 상자가 앞으로 나옵니다.
  • 메뉴 창은 바깥을 누르거나(창이 초점을 잃음) Esc 를 누르면 닫힙니다.
  • 웹판에서는 대화 상자와 메뉴가 페이지 안에 열립니다. 튜토리얼 중에도 튜토리얼이 가리킬 수 있도록 페이지 안에 엽니다.
  • 재료 라이브러리 같은 대화 상자의 목록은 항목을 골라도 스크롤 위치가 그대로 남습니다.

아래 단추: ↺ 초기화(모든 설정을 기본값으로, 최근 파일은 남김) · 취소(창을 열 때의 설정으로 되돌리고 닫기) · 적용(지금 설정을 두고 닫기).

시작 화면 #

프로그램을 켜면 시작 화면이 열립니다(메뉴 막대의 🏠 홈 이나 도움말 › 시작 화면으로 언제든 다시 엽니다).

  • 위쪽: 프로그램 이름과 소개, 사용 설명서 · 튜토리얼 문서 단추와 튜토리얼 시작. 튜토리얼을 아직 마치지 않았으면 안내 띠가 나옵니다.
  • 새로 만들기: 분야별 무리로 나뉜 출발점 — 기본(빈 2D · 빈 3D 모델), 전자 · 전력(전자 기기 냉각 · PCB 부품 · 전력 모듈 (DBC) · 수냉 냉각판), 유동 · CHT(난류 유동 · 데이터 센터 · 자연 대류 · 미세 유체), 에너지 · 소재(배터리 팩 · 상변화 축열 · 줄 발열 · 태양광 모듈), 구조(정적 구조 · 고유 진동수 · 열응력), 건물 · 생활(건물 외피 · 열 쾌적성 · 바닥 난방), 우주 · 기타(우주 장비 · 머그컵 식기). 아래에 열기 · 예제에서 새로 만들기 · 절점 데이터 가져오기.
  • 최근 파일(✕ 로 목록에서 지움, 최근 목록 지우기)과 도움말: 튜토리얼 · 튜토리얼 문서 · 사용 설명서 · 단축키 · 배치 실행 안내.
  • 움직이는 배경: 20종 — 열 기둥 · 등온선 · 대류 셀 · 불씨 · 히트맵 · 유선 · 물결 · 오로라 · 입자 · 회로 기판 · 적외선 열화상 · 열 확산 · 불꽃 · 김 · 햇빛 (복사) · 카르만 와류 · 끓음 · 녹는 결정 · 히트파이프 · 온도 막대. 배경 섞기, 속도(0–300 %), 배경 투명도(0–95 %, 높을수록 배경이 흐려짐), 시작할 때마다 다른 배경. 색은 테마를 따르고, 같은 설정이 환경 설정 › 시작 화면에도 있습니다.
  • 예제: 따로 된 칸에 36개 예제가 미리 보기 · 이름 · 태그 · 설명과 함께 있습니다. 누르면 새 탭에 열립니다.
  • 아래의 시작할 때 시작 화면 보이기 를 끄면 바로 편집 화면으로 시작합니다.

카드 옮기기와 크기 바꾸기 #

시작 화면의 카드(새로 만들기 · 최근 파일 · 움직이는 배경 · 예제)는 자유롭게 배치할 수 있습니다.

  • 카드 제목의 ⠿ 를 끌면 카드의 반투명한 모습이 포인터를 따라오고, 놓일 자리가 점선으로 표시되며 다른 카드들이 비켜나 자리를 만듭니다.
  • 카드 오른쪽 아래의 크기 조절 표시를 끌면 폭(1–3 열)과 높이가 바뀝니다. 두 번 누르면 높이가 내용에 맞게 자동으로 돌아갑니다.
  • 배치는 저장되어 다음에도 그대로입니다. 환경 설정 › 시작 화면 › 시작 화면 배치 의 초기화로 처음 배치로 돌아갑니다.

튜토리얼 #

튜토리얼 시작(시작 화면) 또는 도움말 › 튜토리얼 을 누르면 실제 화면이 단계마다 움직이며 기능을 보여 줍니다 — 시작 화면, 화면 둘러보기, 모델 그리기, 재료, 열원과 경계 조건, 해석, 결과 보기, 고급 해석, SimScale 방식 해석, 신뢰성 · U-값 · 히트맵, 파일과 출력, 꾸미기의 12장 72단계입니다.

  • 오른쪽 아래 카드: 단계 설명, ⏮ 이전 · ▶ 자동 재생 · 다음 ⏭, 장 목록, ✕ 끝내기. 카드 머리를 끌어 옮길 수 있습니다.
  • 지금 단계가 가리키는 곳은 노란 테두리로 강조됩니다.
  • 튜토리얼은 자기 예제(튜토리얼: 전원 모듈 등)를 새 탭에서 열어 쓰고, 끝나면 그 탭을 닫고 바꾼 설정(테마 · 패널 · 작업대)을 되돌립니다. 사용자의 모델은 건드리지 않습니다.
  • 도움말 › 튜토리얼 문서 는 같은 단계를 화면 그림과 함께 한 문서로 보여 줍니다.

사용 설명서와 튜토리얼 문서 창 #

도움말 › 사용 설명서(F1)와 튜토리얼 문서는 별도의 창으로 열립니다. 문서 창은 프로그램의 테마 색을 따르고, 열려 있는 동안 테마를 바꾸면 함께 바뀝니다. 문서 위쪽의 언어 전환은 다른 언어의 국기로 표시됩니다 — 한국어 문서에는 영국 국기, 영어 문서에는 태극기. 왼쪽에는 제목 목차가 있습니다.

빠른 시작 #

  1. 파일 › 예제에서 새로 만들기… 를 열거나 시작 화면의 예제 칸에서 고릅니다(36개, 아래 예제 참고).
  2. 카드를 누르면 새 탭에 모델이 열립니다.
  3. 도구 모음의 ▶ 해석 실행(F5)을 누릅니다. 진행 막대가 뷰포트 위에 나타나고 ■ 로 멈출 수 있습니다.
  4. 끝나면 온도 분포와 색 막대가 나타납니다. 뷰포트 왼쪽 위의 필드 선택, 도구 모음의 등온선·벡터, 3D 보기(3)로 결과를 살펴봅니다.
  5. 결과 › 해석 보고서… 에서 물체별 온도, 경계별 열량, 에너지 수지를 보고 HTML로 저장하거나 인쇄…(Ctrl+P)로 인쇄합니다.

모델 만들기 #

해석 영역과 격자 #

모델 › 해석 영역·격자… (또는 모델 트리의 해석 영역) 에서 정합니다.

  • 차원: 2D(단면, 깊이는 지면에 수직인 두께) 또는 3D(깊이가 z 방향 크기).
  • 폭·높이·깊이 (mm)와 셀 수. 셀 크기 = 크기 / 셀 수입니다. 얇은 층(솔더, TIM)이 셀 하나보다 얇으면 격자에 잡히지 않으니 셀을 촘촘히 하세요(모델 검사가 알려 줍니다). ⊞ 격자 자동 설정은 가장 얇은 물체가 셀 두 개 이상이 되도록 셀 수를 정합니다.
  • 배경 재료: 물체가 없는 곳의 재료(예: 공기). 없음이면 그 셀은 해석하지 않습니다 — 고체만 있는 모델에서 바깥 면에 대류·복사 경계를 줄 때 씁니다.

물체 그리기 #

  • 사각형(R): 드래그. 3D 에서는 상자가 되고 속성 패널의 z 범위 로 높이를 정합니다.
  • 원(C): 중심에서 드래그. 3D 에서는 원기둥.
  • 다각형(P): 점을 클릭하고 더블클릭·Enter 또는 첫 점 클릭으로 닫습니다. Esc 는 취소.
  • 선택(V): 물체를 누르고 끌어 이동, 손잡이로 크기 조절, Shift/Ctrl+클릭으로 여러 개 선택. 빈 곳이나 가운데·오른쪽 버튼 드래그로 화면 이동, 휠로 확대.
  • 겹친 곳은 나중에 그린(위에 있는) 물체의 재료가 됩니다. 맨 앞으로 / 맨 뒤로 로 순서를 바꿉니다. 예를 들어 알루미늄 케이스 위에 PCM 주머니를 그리면 주머니 부분만 PCM 이 됩니다.
  • 파일 › DXF 가져오기… 는 DXF 도면의 닫힌 폴리라인과 원을 물체로 가져옵니다(해석 영역이 작으면 도면에 맞게 넓힙니다).
  • 격자 맞춤 간격은 환경 설정 › 편집기에서 바꿉니다.

재료 #

재료 라이브러리(🧱)에는 금속, 전자 재료(실리콘·FR-4·유효 PCB·솔더·TIM·그래파이트), 세라믹·유리, 건축 재료, 고분자·복합재, 배터리 셀, 유체(공기·물·글리콜·오일·절연 냉매), 상변화 재료(파라핀·얼음·염 수화물), 다공성 매체(금속 폼·충전층)가 있습니다. 모델에 추가하면 모델 안에 복사본이 생기므로 파일은 라이브러리 없이도 열립니다.

  • 방향별 k(kx, ky, kz)를 비우면 k 를 씁니다. PCB 단면은 kx(면 방향)가 크고 ky(두께 방향)가 작습니다.
  • 분류: 고체 · 유체(점도 μ, 부피 팽창 β 필요) · 상변화(녹는점, 녹는 구간, 잠열, 액상 k) · 다공성(공극률 ε, 투과율 K, 공극 유체).
  • 구조용: 영률 E, 푸아송 비 ν, 열팽창 계수 α. 전기용: 전기 전도도 σ(MS/m)와 저항 온도 계수(σ = σ₀ / (1 + αR(T − 20))).
  • 생체 열전달용 혈류 관류(1/s) · 대사열(W/m³) · 혈액 온도(°C, 기본 37)는 재료 편집기에 칸이 없습니다. 종양 고주파 소작 예제처럼 모델 파일(perfusion, metabolic, bloodT)에 들어 있는 값이 그대로 쓰입니다.
  • 도구 › 열분석 (DSC/TGA)… 에서 DSC 녹는 피크로 상변화 재료를 만들어 모델에 추가할 수 있습니다(열분석 참고).
  • 물체를 선택하고 속성 패널의 재료 를 고르거나, 재료 라이브러리에서 재료 지정 을 누릅니다.

열원 #

물체를 선택하고 속성 패널의 발열(W)을 입력합니다. 발열은 그 물체의 셀에 고르게 나뉩니다. 2D 모델에서는 깊이(두께)만큼의 물체가 내는 열입니다.

  • 발열 시간표: 줄마다 시간(s), W — 과도 해석에서 선형 보간합니다(펄스, 듀티 사이클, 시간에 따라 줄어드는 수화열).
  • 전류 시간표 + 저항(Ω): 줄마다 시간(s), A — 발열 = I²R (배터리 주행 사이클).

탐침 #

탐침(T) 도구로 점을 찍으면 그 위치의 온도가 기록됩니다. 과도 해석에서는 그래프 패널에 시간 변화가 그려지고, 결과 위에 값이 표시됩니다.

해석 #

해석 › 해석 설정… 또는 속성 패널(선택 없음)에서 정합니다.

  • 정상 상태: 평형 온도. 복사·온도 의존 k 가 있으면 반복(피카드)으로 풉니다.
  • 과도 상태: 종료 시간, 시간 간격, 저장 프레임 수, 초기 온도. 후진 오일러(무조건 안정)입니다. 시간 간격이 크면 빠르지만 빠른 변화를 놓칩니다.
  • 유동 (CHT): 유체·다공성 재료 영역의 유동을 함께 풉니다(2D). 강제 대류에는 유입구(또는 팬)와 유출구가, 자연 대류에는 중력과 기준 온도가 쓰입니다. 난류 (k-ω SST) 를 켜면 층류 대신 난류 모델로 풉니다. 유동 반복 이 부족하면 상태 표시줄에 경고가 나옵니다.
  • 줄 발열 (전기): 전위장을 풀어 전류에 의한 발열을 열 해석에 더합니다.
  • 열응력: 열 해석이 끝난 온도로 응력을 계산합니다. 지지가 없으면 강체 운동만 막아 자유 팽창으로 풉니다. 2D 는 평면 응력(또는 평면 변형률). 열팽창 포함 을 끄고 하중·자중 (중력) 만 주면 정적 구조 해석입니다.
  • 고유 진동수: 모드 수만큼 고유 진동수와 모드 형상을 구합니다.
  • 모델 검사(✔): 재료 없는 물체, 열이 빠져나갈 경계 없음, 유체 없는 유동, 셀 수 과다, 잘못된 팬 곡선 같은 문제를 해석 전에 알려 줍니다. 오류가 있으면 해석을 시작하지 않습니다.
  • 환경 설정의 수정 후 자동 실행을 켜면 모델을 고칠 때마다 다시 계산합니다.

모델을 결과가 나온 뒤에 고치면 뷰포트에 모델이 바뀜 — 다시 실행 이 표시됩니다.

결과 보기 #

  • 필드: 온도 · 열유속 |q| · 속도 · 압력 · 난류 점성 · 폰 미세스 응력(MPa) · 변위(µm) · 모드 형상 · 액상률 · 전위 · 전류 밀도 · 열 쾌적성 (PMV). 결과에 없는 필드는 흐리게 표시됩니다.
  • 등온선, 벡터(열유속, 유속 필드에서는 속도), 유선, 변형 형상(변위를 과장해서 그림).
  • 애니메이션(Space)과 프레임 슬라이더: 과도 결과를 시간 순서로 봅니다. 온도 색 범위는 모든 프레임에 같게 유지됩니다.
  • 단면선: 두 점을 클릭하면 그 선을 따른 값이 그래프 패널에 그려집니다.
  • 3D 보기: 3D 보기 참고. 3D 모델을 2D 보기에서 볼 때는 왼쪽 위의 층 (z) 으로 단면 높이를 고릅니다.
  • 상태 표시줄에 커서 위치의 값이 나옵니다. 온도 단위는 환경 설정 › 일반, 색 지도와 색 단계·등온선 수는 환경 설정 › 결과 표시에서 바꿉니다.
  • 내보내기(파일 메뉴): CSV(셀별 값), PNG(뷰포트), VTK(ParaView 등에서 모든 필드), CalculiX (.inp)(격자·재료·경계 조건을 CalculiX 입력 파일로 — FreeCAD · Gmsh · ParaView 워크플로), 해석 보고서(HTML), 인쇄.

열분석 (DSC / TGA) #

도구 › 열분석 (DSC/TGA)… (재료 작업대에도 있음) 은 열분석 장비가 내보낸 곡선 CSV 를 읽습니다. 예제 데이터로 바로 해 볼 수도 있습니다.

  • DSC: 온도와 열유량(mW) 곡선. 시료 질량과 가열 속도, 적분 구간을 정하면 기준선 위 피크를 적분해 잠열과 시작 · 피크 · 끝 온도, 겉보기 비열을 구합니다. 보정 (표준 물질) 에서 인듐 · 주석 · 아연 · 물의 측정값으로 온도와 잠열을 보정합니다. 상변화 재료로 추가 를 누르면 그 결과로 상변화 재료가 모델에 생깁니다.
  • TGA: 온도와 질량(%) 곡선에서 5 · 10 · 50 % 감량 온도, DTG 피크, 잔류량, 단계 수를 구합니다.

신뢰성 (Sherlock 방식) #

결과 › 신뢰성 해석… 에서 부품(물체)마다 활성화 에너지 Ea, 정격 온도와 정격 MTTF, 연간 열 사이클 수, 사이클 ΔT 를 정합니다.

  • 아레니우스: AF = exp[Ea/k·(1/T정격 − 1/T사용)], MTTF = MTTF정격 / AF, FIT = 10⁹/MTTF. T사용 은 해석한 물체 최고 온도입니다.
  • 코핀-맨슨: N_f = C·ΔT^−n. ΔT 를 비워 두면 과도 해석의 물체 최고 온도 변동폭, 정상 상태면 주위 대비 상승분(전원 켜고 끄기 1회)을 씁니다.
  • 부품 수명은 둘 중 짧은 값, 시스템은 직렬(FIT 합)로 계산하고 5년 생존 확률을 보여 줍니다.

U-값과 결로 (THERM 방식) #

창틀·벽체 단면 모델에서 결과 › U-값 (건물 외피)… 를 엽니다. 실내 쪽과 실외 쪽 대류 경계를 고르면 U = |Q| / (A·ΔT), R = 1/U, 선 열관류 L2D(W/mK), 열량을 보여 줍니다.

아래의 결로 · 곰팡이 위험 (ISO 13788) 칸에 실내 상대 습도를 넣으면 실내 표면 최저 온도, 이슬점, 온도 계수 fRsi = (T표면 − T실외) / (T실내 − T실외) 와 판정(결로 위험 · 곰팡이 주의(fRsi < 0.75) · 안전)이 나옵니다. 예제 창틀 단면, 경량 철골 벽체, 발코니 슬래브 열교 가 이 설정으로 되어 있습니다.

히트맵과 배치 실행 (HAM 방식) #

절점 데이터 히트맵 #

도구 › 절점 데이터 가져오기… 로 CSV 를 엽니다(파일을 창에 끌어다 놓아도 됩니다).

  • 열: node(또는 id, name), x, y, [z], T(또는 temp, temperature), [time]. 쉼표·세미콜론·탭 구분, 열 이름에 (K) 가 있으면 켈빈으로 읽습니다.
  • 역거리 가중(IDW) 보간으로 히트맵을 그리고 최소·최대·평균·표준편차·P5/P50/P95, 가장 뜨거운 절점, 한계 온도 초과 절점을 보여 줍니다. 시간 열이 있으면 시간을 고를 수 있습니다.
  • 히트맵을 PNG 로, 보간한 격자를 CSV 로 저장합니다. 예제 데이터 불러오기 로 위성 패널 절점 데이터를 바로 볼 수 있습니다.

명령줄 배치 실행 #

설치한 프로그램은 창 없이 모델을 일괄 실행합니다(도구 › 배치 실행 (API)… 에 안내가 있습니다).

MyHeatManager --batch model.myheat
MyHeatManager --batch a.myheat b.myheat --out results --field T
MyHeatManager --batch pcb.myheat --field vonMises --frame last --quiet

모델마다 이름.summary.json(통계·탐침·물체·경계·에너지 수지), 이름.필드.csv(셀 값), 이름.필드.png(히트맵)를 씁니다. 실패한 모델이 있으면 종료 코드 2 입니다. 설계안 여러 개를 스크립트나 CI 로 돌릴 때 씁니다.

인쇄 #

파일 › 인쇄…(Ctrl+P) 또는 도구 모음의 인쇄 단추는 인쇄 창을 엽니다. 왼쪽은 쪽 설정, 오른쪽은 설정을 바꿀 때마다 바로 다시 그려지는 여러 쪽 미리보기(쪽 수 표시)입니다.

  • 용지: 용지 크기 A3 · A4 · A5 · B4 · B5 · Letter · Legal · Tabloid, 방향(세로 · 가로).
  • 여백: 없음 · 좁게 · 보통 · 넓게, 또는 사용자 지정(위 · 아래 · 왼쪽 · 오른쪽 따로).
  • 인쇄할 내용: 제목과 설명, 뷰포트 그림(그림 폭 %), 색 범례, 차트, 모델 (물체·경계), 결과 요약·탐침, 해석 기록.
  • 머리글·바닥글: 머리글 글(처음엔 모델 이름), 바닥글에 날짜, 쪽 번호.
  • 모양: 색(컬러 · 흑백), 글자 크기.

인쇄를 누르면 시스템 인쇄 창이 열리고, 프린터와 매수는 거기서 고릅니다. 고른 설정은 프로그램을 끌 때까지 기억합니다.

  • 모델은 .myheat(JSON) 파일입니다. 설치하면 파일 형식이 등록되어(전용 아이콘) 두 번 클릭으로 열립니다. 여러 파일을 탭으로 함께 열 수 있습니다.
  • 데스크톱 프로그램은 여러 개를 동시에 실행할 수 있습니다. 처음 실행한 것만 이전 세션을 되살리고, 나중 것은 창을 조금 비켜 엽니다.
  • 웹판에서는 열기는 파일 선택 창으로, 저장은 내려받기로 합니다.
  • 최근 파일은 파일 메뉴 아래쪽, 시작 화면과 환경 설정 › 파일에 있습니다.

계산 방법 (요약) #

  • 균일한 직교 격자의 유한 체적법. 면 열전도도는 조화 평균, 경계는 반 셀 저항과 직렬로 연결합니다.
  • 선형계는 불완전 촐레스키(IC0) 전처리 켤레 기울기법(대칭), 대류항이 있는 에너지식은 ILU(0) BiCGSTAB.
  • 복사는 h_rad = εσ(T² + T∞²)(T + T∞) 로 선형화해 반복합니다(절대 온도).
  • 상변화는 이전·현재 온도 사이 엔탈피 차이로 구한 겉보기 열용량을 반복 갱신해 녹는 구간을 건너뛰지 않습니다.
  • 유동은 엇갈림(MAC) 격자의 투영법, 압력 푸아송 방정식은 IC0-CG. 다공성 영역은 다르시-브링크만 항력, 자연 대류는 부시네스크 근사. 난류는 k-ω SST(벽 처리 자동), 팬은 매 유동 단계마다 팬 곡선과 측정한 압력 상승이 같아지는 유량으로 다가갑니다.
  • 줄 발열은 온도 의존 전기 전도도로 전위장을 풀어 σ|∇V|² 를 열원으로 더합니다. 생체 열전달은 Pennes 항 ω_b ρ_b c_b (T_a − T) + q_m 을 셀마다 더합니다.
  • 열응력·정적 구조는 셀 꼭짓점 절점의 쌍일차(2D)/삼일차(3D) 유한 요소, 요소별 행렬 없이 곱하는 야코비 전처리 CG. 모드 해석은 같은 강성 행렬로 고유값을 구합니다.

정확도는 격자에 달려 있습니다. 같은 모델을 셀 수를 두 배로 늘려 다시 풀어 결과가 거의 같으면 격자가 충분한 것입니다.
