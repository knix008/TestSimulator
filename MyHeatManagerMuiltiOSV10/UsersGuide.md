# MyHeatManager 사용 설명서

MyHeatManager는 전자 기기·배터리·건물 외피·우주 장비 같은 **장치의 열을 시뮬레이션**하는 프로그램입니다. 2D 단면이나 3D 적층 모델을 그리고, 재료·열원·경계 조건을 정한 뒤 해석하면 온도·열유속·유속·응력 분포와 수명 추정, 히트맵을 볼 수 있습니다.

계산은 **Rust 엔진**이 맡습니다. 데스크톱 프로그램(Windows · macOS · Linux)에서는 네이티브로, 웹판에서는 같은 엔진을 WebAssembly로 컴파일해 브라우저 안에서 실행합니다. 설치본은 Node.js 같은 다른 프로그램이 없어도 실행됩니다.

## 화면 구성

### 제목 줄과 메뉴 막대

시스템 제목 표시줄은 없습니다. 맨 윗줄 하나에 다음이 차례로 놓입니다.

- 프로그램 아이콘 · **MyHeatManager** · 버전, 그 뒤에 일정한 간격을 두고 **지금 열린 모델 이름**(폭이 정해진 칸이라 길면 … 으로 줄입니다).
- **🏠 홈** 단추(시작 화면 열기/닫기) — 파일 메뉴 바로 왼쪽.
- 파일 · 편집 · 보기 · 모델 · 해석 · 결과 · 도구 · 도움말 메뉴. 메뉴 하나를 연 채로 옆 메뉴에 마우스를 올리면 그 메뉴로 바뀝니다.
- **작업대 선택**(형상 · 재료 · 열원·경계 · 해석 · 결과 · 신뢰성 · 히트맵 (HAM)) — 왼쪽 도구 패널의 내용을 바꿉니다.
- 오른쪽 끝의 최소화 · 최대화 · 닫기 단추(데스크톱).

빈 곳을 끌면 창이 움직이고(화면 가장자리에 붙이기 포함) 두 번 누르면 최대화됩니다. 창 크기는 테두리나 상태 표시줄 오른쪽 아래의 **크기 조절 표시**를 끌어 바꿉니다. 창은 **도구 모음의 단추가 모두 보이는 폭**보다 좁아지지 않습니다(글꼴 크기나 언어를 바꾸면 그 폭을 다시 잽니다).

### 도구 모음

왼쪽부터 다음 무리가 구분선으로 나뉘어 있습니다. 단추에 마우스를 올리면 이름·설명·단축키가 나옵니다.

| 무리 | 단추 |
|---|---|
| 파일 | **새 모델**(문서 아이콘) · 열기 · 저장 · **인쇄**(저장 오른쪽) |
| 편집 | 실행 취소 · 다시 실행 |
| 그리기 | 선택 · 사각형 · 원 · 다각형 · 탐침 |
| 보기 | 화면에 맞춤 · 2D 보기 · **3D 보기**(입체 정육면체 아이콘) · 격자 · 계산 격자 · 좌표축 · 눈금자 |
| 해석 | **▶ 해석 실행**(파란색, 실행 중에는 눌린 상태) · **■ 중지**(빨간색, 해석 중에만 켜짐) |
| 결과 | 온도 · 열유속 · 속도 · 폰 미세스 응력 · 등온선 · 벡터 · 유선 · 애니메이션 |
| 연구 | 📊 매개변수 연구 |
| 패널 | 도구 패널(왼쪽) · 속성 패널(오른쪽) · 그래프 패널(아래) — 그린 아이콘 |
| 확대 | − · 확대 비율 · + · **⌖ 원위치**(Ctrl+0) |

**원위치**는 모델을 뷰포트 정중앙에 두고 원본 비율(100 %)로 보여 줍니다. 3D 보기에서는 처음 시점으로 돌아갑니다. **화면에 맞춤**(F)은 모델 전체가 꽉 차게 보이도록 비율을 정합니다.

오른쪽 끝에는 **언어**(누르면 다른 언어로 바뀝니다 — 한국어 화면에서는 영국 국기, 영어 화면에서는 태극기), **테마**(누르면 같은 밝기의 다음 테마) 와 **▾ 테마 목록**, **⚙ 환경 설정**, **정보**가 있습니다.

### 테마 목록

▾ 를 누르면 테마 목록이 펼쳐집니다.

- **어두운 테마**와 **밝은 테마**가 두 열로 나뉘어 위에서 아래로 늘어섭니다(각 20개).
- 테마마다 두 줄짜리 칸입니다 — 윗줄은 색 띠(배경 · 패널 · 단추 · 강조 · 글자), 아랫줄은 이름. 지금 테마는 강조 표시됩니다.
- 맨 아래 **사용자 정의 테마** 줄에 내 테마 칸과 **사용자 정의 테마 설정…**, **테마 설정…** 이 있습니다. 둘은 환경 설정 창을 각각 *사용자 테마* 탭과 *테마* 탭으로 엽니다.

### 패널

- **왼쪽 패널(도구 · 모델 트리)**: 위는 작업대의 도구 무리, 아래는 **모델 트리**(해석 · 해석 영역 · 재료 · 물체 · 경계 조건 · 탐침 · 결과). 무리 제목을 누르면 접힙니다. 물체 옆의 ◉ 는 숨기기 스위치입니다(숨긴 물체는 해석에서 빠집니다).
- **오른쪽 패널(속성)**: 선택한 물체·경계·탐침·재료의 속성. 아무것도 선택하지 않으면 모델 이름과 해석 설정, 결과 요약이 보입니다.
- 좌우 패널의 제목 막대에는 아이콘·제목과 **접기 단추**(« / »)가 있습니다. 접으면 아이콘과 세로 제목만 있는 좁은 띠가 남고, 띠를 누르면 다시 펼쳐집니다.
- **아래 그래프 패널**: 제목 막대에 아이콘 · *그래프* 제목, 탭(탐침 · 단면선 · 물체 최고 온도 · 잔차 (수렴)), 오른쪽에 **접기**(▾ / ▴)와 **감추기**(✕)가 있습니다. 접으면 제목 막대만 남고, 감춘 패널은 도구 모음의 그래프 패널 단추로 다시 보입니다. 패널 위의 막대를 끌어 높이를 바꿉니다. 그래프에서 오른쪽 단추를 누르면 *그래프 그림 저장…* · *탐침 값 CSV 저장…* · *단면선 값 CSV 저장…* · *3D 단면선…* 이 있습니다.
- 도구 모음의 패널 단추 셋은 패널을 아예 감추거나 다시 보입니다.

### 탭과 뷰포트

- 모델마다 탭이 하나씩 생깁니다. 탭 줄 오른쪽 끝에는 언제나 **< >** 단추가 있어 넘친 탭을 앞뒤로 넘겨 보고(더 갈 곳이 없으면 흐려짐), 그 옆의 **+** 는 새 모델입니다. 탭에서 오른쪽 단추를 누르면 *다른 탭 닫기* 가 있습니다.
- 뷰포트에는 눈금자, 색 막대, 프레임 슬라이더가 있습니다.
- **보기 단추**: ▦ **격자**(G) — mm 눈금 도면 격자(확대하면 촘촘해지고 원점의 x·y 축은 강조색), # **계산 격자**(M) — 해석에 쓰는 셀 경계, ⊹ **좌표축** — 3D 보기의 x · y · z 축과 눈금, 📏 **눈금자** — 아래(x)와 왼쪽(y)에 보이는 범위의 주·보조 눈금과 커서 위치, 🏷 **이름표**(보기 메뉴) — 물체·탐침 이름.
- **상태 표시줄**: 상태, 셀 수, 선택 수, 커서 좌표(환경 설정의 길이 단위)와 그 위치의 값, 엔진 종류(네이티브 / WebAssembly), 저장 여부, 파일 경로.

## 3D 보기

**3D 보기**(3)는 해석 전에는 물체를 입체로, 해석 뒤에는 결과를 보여 줍니다(3D 모델은 해석한 셀의 바깥 면에 색, 2D 모델은 값을 높이와 색으로 그린 카펫 그림). 왼쪽 단추로 돌리고, 오른쪽 단추로 옮기고, 휠로 확대합니다.

- **무한 격자**: z = 0 평면에 끝없이 이어지는 격자가 있습니다. 확대·축소에 맞춰 간격이 바뀌고 멀리 갈수록 흐려집니다.
- **좌표축**: x · y · z 축과 눈금. 눈금 숫자에 길이 단위가 붙고(예: `20 mm`), 축 끝 옆에는 축 이름 **X · Y · Z** 만 적힙니다. 확대·축소하면 눈금 간격이 1 · 2 · 5 단위로 다시 정해집니다.
- 격자와 좌표축은 **물체 뒤에** 그려지므로 물체를 가리지 않고, 눈금 숫자도 격자에 덮이지 않습니다.
- 격자(G)와 좌표축은 도구 모음·보기 메뉴에서 켜고 끕니다. **길이 단위**(mm · cm · m · in)와 **온도 단위**(°C · K · °F)는 환경 설정 › 일반에서 정합니다. 길이 단위는 눈금자·좌표축 눈금·커서 좌표에 함께 쓰입니다.
- **원위치**(Ctrl+0)는 처음 시점으로, **화면에 맞춤**(F)은 모델 전체가 보이도록 되돌립니다.

## 대화 상자와 메뉴 창

데스크톱 프로그램에서는 **대화 상자**와 **펼침 메뉴**(메뉴 막대의 메뉴, 오른쪽 단추 메뉴, 테마 목록)가 **각자의 창**으로 열립니다. 그래서 주 창이 작아도 메뉴와 대화 상자가 주 창 밖까지 펼쳐집니다.

- 대화 상자가 열려 있는 동안 주 창은 흐리게 덮이고, 흐린 주 창을 누르면 대화 상자가 앞으로 나옵니다.
- 메뉴 창은 바깥을 누르거나(창이 초점을 잃음) Esc 를 누르면 닫힙니다.
- **웹판**에서는 대화 상자와 메뉴가 페이지 안에 열립니다. **튜토리얼 중**에도 튜토리얼이 가리킬 수 있도록 페이지 안에 엽니다.
- 재료 라이브러리 같은 대화 상자의 목록은 항목을 골라도 **스크롤 위치가 그대로** 남습니다.

## 환경 설정

**도구 › 환경 설정…** 또는 도구 모음의 ⚙ 로 엽니다. 왼쪽 탭을 고르면 오른쪽에 그 설정이 나오고, 바꾼 값은 **바로 화면에 반영**됩니다(미리 보기).

| 탭 | 설정 |
|---|---|
| 일반 | 언어, 온도 단위(°C · K · °F), 길이 단위(mm · cm · m · in), 작업대, 수정 후 자동 실행, 닫을 때 저장 확인 |

## 시작 화면

프로그램을 켜면 **시작 화면**이 열립니다(메뉴 막대의 **🏠 홈** 이나 도움말 › 시작 화면으로 언제든 다시 엽니다).

- 위쪽: 프로그램 이름과 소개, **사용 설명서** · **튜토리얼 문서** 단추와 **튜토리얼 시작**. 튜토리얼을 아직 마치지 않았으면 안내 띠가 나옵니다.
- **새로 만들기**: 분야별 무리로 나뉜 출발점 — *기본*(빈 2D · 빈 3D 모델), *전자 · 전력*(전자 기기 냉각 · PCB 부품 · 전력 모듈 (DBC) · 수냉 냉각판), *유동 · CHT*(난류 유동 · 데이터 센터 · 자연 대류 · 미세 유체), *에너지 · 소재*(배터리 팩 · 상변화 축열 · 줄 발열 · 태양광 모듈), *구조*(정적 구조 · 고유 진동수 · 열응력), *건물 · 생활*(건물 외피 · 열 쾌적성 · 바닥 난방), *우주 · 기타*(우주 장비 · 머그컵 식기). 아래에 열기 · 예제에서 새로 만들기 · 절점 데이터 가져오기.
- **최근 파일**(✕ 로 목록에서 지움, *최근 목록 지우기*)과 **도움말**: 튜토리얼 · 튜토리얼 문서 · 사용 설명서 · 단축키 · 배치 실행 안내.
- **움직이는 배경**: 20종 — 열 기둥 · 등온선 · 대류 셀 · 불씨 · 히트맵 · 유선 · 물결 · 오로라 · 입자 · 회로 기판 · 적외선 열화상 · 열 확산 · 불꽃 · 김 · 햇빛 (복사) · 카르만 와류 · 끓음 · 녹는 결정 · 히트파이프 · 온도 막대. **배경 섞기**, **속도**(0–300 %), **배경 투명도**(0–95 %, 높을수록 배경이 흐려짐), *시작할 때마다 다른 배경*. 색은 테마를 따르고, 같은 설정이 환경 설정 › 시작 화면에도 있습니다.
- **예제**: 따로 된 칸에 43개 예제가 미리 보기 · 이름 · 태그 · 설명과 함께 있습니다. 누르면 새 탭에 열립니다.
- 아래의 *시작할 때 시작 화면 보이기* 를 끄면 바로 편집 화면으로 시작합니다.

### 카드 옮기기와 크기 바꾸기

시작 화면의 카드(새로 만들기 · 최근 파일 · 움직이는 배경 · 예제)는 자유롭게 배치할 수 있습니다.

- 카드 제목의 **⠿** 를 끌면 카드의 반투명한 모습이 포인터를 따라오고, 놓일 자리가 점선으로 표시되며 다른 카드들이 비켜나 자리를 만듭니다.
- 카드 오른쪽 아래의 **크기 조절 표시**를 끌면 폭(1–3 열)과 높이가 바뀝니다. **두 번 누르면** 높이가 내용에 맞게 자동으로 돌아갑니다.
- 배치는 저장되어 다음에도 그대로입니다. 환경 설정 › 시작 화면 › *시작 화면 배치* 의 **초기화**로 처음 배치로 돌아갑니다.

## 튜토리얼

**튜토리얼 시작**(시작 화면) 또는 **도움말 › 튜토리얼** 을 누르면 실제 화면이 단계마다 움직이며 기능을 보여 줍니다 — 시작 화면, 화면 둘러보기, 모델 그리기, 재료, 열원과 경계 조건, 해석, 결과 보기, 고급 해석, SimScale 방식 해석, 신뢰성 · U-값 · 히트맵, 파일과 출력, 꾸미기의 **12장 85단계**입니다. 3D 단면과 등치면, 계산기 · 히스토그램, 3D 유동과 CHT, 내부 팬, 면 사이 복사(S2S), 태양 복사 하중, DSC 반응 속도론 · Tg · cp, 3D 절점 히트맵, 전자 냉각 도우미, 솔더 피로 · 수명, 진동 PSD 표 · 충격, 다른 제품의 파일 형식, 해석기 파일 · IDF 가져오기도 각각 한 단계씩 다룹니다.

- 오른쪽 아래 카드: 단계 설명, ⏮ 이전 · ▶ 자동 재생 · 다음 ⏭, 장 목록, ✕ 끝내기. 카드 머리를 끌어 옮길 수 있습니다.
- 지금 단계가 가리키는 곳은 노란 테두리로 강조됩니다.
- 튜토리얼은 **자기 예제**(튜토리얼: 전원 모듈 등)를 새 탭에서 열어 쓰고, 끝나면 그 탭을 닫고 바꾼 설정(테마 · 패널 · 작업대)을 되돌립니다. 사용자의 모델은 건드리지 않습니다.
- **도움말 › 튜토리얼 문서** 는 같은 단계를 화면 그림과 함께 한 문서로 보여 줍니다.

## 사용 설명서와 튜토리얼 문서 창

**도움말 › 사용 설명서**(F1)와 **튜토리얼 문서**는 **별도의 창**으로 열립니다. 문서 창은 프로그램의 테마 색을 따르고, 열려 있는 동안 테마를 바꾸면 함께 바뀝니다. 문서 위쪽의 언어 전환은 다른 언어의 국기로 표시됩니다 — 한국어 문서에는 영국 국기, 영어 문서에는 태극기. 왼쪽에는 제목 목차가 있습니다.

## 빠른 시작

1. **파일 › 예제에서 새로 만들기…** 를 열거나 시작 화면의 **예제** 칸에서 고릅니다(43개, 아래 [예제](#예제) 참고).
2. 카드를 누르면 새 탭에 모델이 열립니다.
3. 도구 모음의 **▶ 해석 실행**(F5)을 누릅니다. 진행 막대가 뷰포트 위에 나타나고 ■ 로 멈출 수 있습니다.
4. 끝나면 온도 분포와 색 막대가 나타납니다. 뷰포트 왼쪽 위의 필드 선택, 도구 모음의 등온선·벡터, **3D 보기**(3)로 결과를 살펴봅니다.
5. **결과 › 해석 보고서…** 에서 물체별 온도, 경계별 열량, 에너지 수지를 보고 HTML로 저장하거나 **인쇄…**(Ctrl+P)로 인쇄합니다.

| 인덕션 냄비 물 데우기 (과도) | 2D 과도 | 냄비 바닥에 2 kW, 상판으로 새는 열과 바닥·물 온도 상승 |
| 종양 고주파 소작 (생체 열전달) | 2D 과도 | 간 종양 속 전극 10분 가열, Pennes 식으로 50 °C(괴사) 도달 여부 |
| 팬 곡선 전자 함체 (Icepak 방식) | 2D 정상 | 팬 곡선과 함체(필터 포함) 저항이 만나는 운전점과 부품 온도 |
| 전력 모듈 DBC 기판 (3D 열응력) | 3D 정상 | DBC 기판 위 IGBT 칩 4개(각 60 W)의 3D 온도와 솔더·세라믹 응력 |
| 온수 바닥 난방 단면 | 2D 정상 | 40 °C 온수관(150 mm 간격) 위 바닥 표면 온도 고르기와 아래로 새는 열 |
| 커피 머그컵 식기 (과도) | 2D 과도 | 80 °C 커피가 자연 대류 + 복사로 30분 동안 식음 |

## 모델 만들기

### 해석 영역과 격자

**모델 › 해석 영역·격자…** (또는 모델 트리의 *해석 영역*) 에서 정합니다.

- **차원**: 2D(단면, *깊이*는 지면에 수직인 두께) 또는 3D(*깊이*가 z 방향 크기).
- **폭·높이·깊이** (mm)와 **셀 수**. 셀 크기 = 크기 / 셀 수입니다. 얇은 층(솔더, TIM)이 셀 하나보다 얇으면 격자에 잡히지 않으니 셀을 촘촘히 하세요(모델 검사가 알려 줍니다). **⊞ 격자 자동 설정**은 가장 얇은 물체가 셀 두 개 이상이 되도록 셀 수를 정합니다.
- **배경 재료**: 물체가 없는 곳의 재료(예: 공기). *없음*이면 그 셀은 해석하지 않습니다 — 고체만 있는 모델에서 바깥 면에 대류·복사 경계를 줄 때 씁니다.

### 물체 그리기

- **사각형**(R): 드래그. 3D 에서는 상자가 되고 속성 패널의 *z 범위* 로 높이를 정합니다.
- **원**(C): 중심에서 드래그. 3D 에서는 원기둥.
- **다각형**(P): 점을 클릭하고 더블클릭·Enter 또는 첫 점 클릭으로 닫습니다. Esc 는 취소.
- **선택**(V): 물체를 누르고 끌어 이동, 손잡이로 크기 조절, Shift/Ctrl+클릭으로 여러 개 선택. 빈 곳이나 가운데·오른쪽 버튼 드래그로 화면 이동, 휠로 확대.
- 겹친 곳은 **나중에 그린(위에 있는) 물체의 재료**가 됩니다. *맨 앞으로 / 맨 뒤로* 로 순서를 바꿉니다. 예를 들어 알루미늄 케이스 위에 PCM 주머니를 그리면 주머니 부분만 PCM 이 됩니다.
- **파일 › DXF 가져오기…** 는 DXF 도면의 닫힌 폴리라인과 원을 지금 모델에 물체로 가져옵니다(해석 영역이 작으면 도면에 맞게 넓힙니다). 도면 · THERM 단면 · Gmsh 메시 · 해석기 입력 파일(Nastran · Ansys · CalculiX · COMSOL) · IDF 기판을 **새 모델**로 열려면 **파일 › 가져오기 (THERM · Gmsh · 해석기 · IDF)…** 나 **열기…** 를 씁니다([지원 파일 형식](#지원-파일-형식) 참고).
- **도구 › JEDEC 2저항 패키지… · 방열판 만들기… · 발열 지도 가져오기…** 는 값만 넣으면 물체를 만들어 줍니다([전자 냉각 도우미](#전자-냉각-도우미-icepak-방식) 참고).
- 격자 맞춤 간격은 환경 설정 › 편집기에서 바꿉니다.

### 재료

**재료 라이브러리**(🧱)에는 금속, 전자 재료(실리콘·FR-4·유효 PCB·솔더·TIM·그래파이트), 세라믹·유리, 건축 재료, 고분자·복합재, 배터리 셀, 유체(공기·물·글리콜·오일·절연 냉매), 상변화 재료(파라핀·얼음·염 수화물), 다공성 매체(금속 폼·충전층)가 있습니다. **모델에 추가**하면 모델 안에 복사본이 생기므로 파일은 라이브러리 없이도 열립니다.

- **방향별 k**(kx, ky, kz)를 비우면 k 를 씁니다. PCB 단면은 kx(면 방향)가 크고 ky(두께 방향)가 작습니다.
- **분류**: 고체 · 유체(점도 μ, 부피 팽창 β 필요) · 상변화(녹는점, 녹는 구간, 잠열, 액상 k) · 다공성(공극률 ε, 투과율 K, 공극 유체).
- 구조용: 영률 E, 푸아송 비 ν, 열팽창 계수 α. 전기용: **전기 전도도 σ**(MS/m)와 **저항 온도 계수**(σ = σ₀ / (1 + αR(T − 20))).
- 생체 열전달용 **혈류 관류율**(1/s) · **대사 발열**(W/m³) · **혈액 온도**(°C, 기본 37)는 재료 편집기 아래쪽 칸에서 정합니다(*종양 고주파 소작* 예제 참고). 관류율이 0 이면 Pennes 항이 없습니다.
- **k(T)** 와 **cp(T)**: 온도에 따라 바뀌는 열전도율과 비열을 `°C:값, °C:값` 형식으로 넣습니다(예: `20:150, 200:140` W/mK, `20:900, 300:1050` J/kgK). 표 사이는 직선 보간, 양 끝 밖은 끝 값입니다. 비우면 위의 상수 k · cp 를 씁니다. cp(T) 는 과도 해석에서만 쓰이고(엔탈피로 풀어 에너지가 정확히 보존됨), 정상 해석은 cp 를 쓰지 않습니다. 유동(CHT)의 이류 항은 상수 ρcp 를 씁니다.
- **태양 흡수율**(기본 0.6)은 [태양 복사 하중](#태양-복사-하중)에서 그 재료 표면이 흡수하는 햇빛의 비율입니다. 방사율과는 다릅니다(예: 흰 도장은 흡수율 ≈ 0.2, 방사율 ≈ 0.9).
- **방사율**은 복사 경계 외에 [면 사이 복사](#면-사이-복사-s2s)에서 그 재료 표면의 방사율로 쓰입니다.
- **도구 › 열분석 (DSC/TGA)…** 에서 DSC 녹는 피크로 상변화 재료를, 사파이어 법으로 cp(T) 재료를 만들어 모델에 추가할 수 있습니다([열분석](#열분석-dsc--tga) 참고). **도구 › PCB 적층 계산기…** 는 적층의 유효 열전도율을 재료로 넣습니다.
- 물체를 선택하고 속성 패널의 *재료* 를 고르거나, 재료 라이브러리에서 **재료 지정** 을 누릅니다.

### 열원

물체를 선택하고 속성 패널의 **발열**(W)을 입력합니다. 발열은 그 물체의 셀에 고르게 나뉩니다. 2D 모델에서는 깊이(두께)만큼의 물체가 내는 열입니다.

- **발열 시간표**: 줄마다 `시간(s), W` — 과도 해석에서 선형 보간합니다(펄스, 듀티 사이클, 시간에 따라 줄어드는 수화열).
- **전류 시간표** + **저항**(Ω): 줄마다 `시간(s), A` — 발열 = I²R (배터리 주행 사이클).

### 경계 조건

열원·경계 작업대나 모델 메뉴에서 고릅니다. 물체를 선택한 채로 누르면 그 물체의 바깥 면에, 선택이 없으면 기본 대상(바깥 면 전체 / 해당 변)에 붙습니다. 속성 패널에서 **종류**, **대상**과 값을 고칩니다.

| 종류 | 값 | 비고 |
|---|---|---|
| 고정 온도 | T | |
| 열유속 | q (W/m², + 는 들어오는 열) | |
| 대류 | h, 유체 온도, (방사율), **h 결정 방법** | 방사율을 주면 복사가 함께 계산됩니다. h 를 상관식으로 구할 수도 있습니다(아래) |
| 복사 | 방사율, 주위 온도 | 진공(우주)에서는 대류 없이 이것만 |
| 단열 | — | 대칭면, 절단면 |
| 접촉 열저항 | R (m²K/W) | 물체와 이웃 재료 사이 |
| 박막층 | 층 두께(mm), 열전도율 k, 층 모델 | 모델 › 박막층. 물체 또는 해석 영역 변에만(아래) |
| 유입구 / 유출구 / 개방 | 속도, 유입 온도 (난류면 난류 강도 · 혼합 길이) | 유동(CHT)용, 영역의 변(3D 는 앞 · 뒤 면 포함). 속성 패널에서 벽 · 미끄럼으로도 바꿀 수 있음 |
| 팬 (팬 곡선) | 유입 온도, 팬 곡선 `m³/s:Pa, …` | 유동용, 영역의 변(3D 는 앞 · 뒤 면 포함). 속성 패널의 **종류**에서 *팬 (팬 곡선)* 을 고르고 곡선을 고칩니다. 3D 면에서 곡선의 유량은 그 면 전체를 지나는 유량입니다. 해석 뒤 **운전점**(L/s · Pa)이 나옵니다 |
| 내부 팬 | 바람 방향(+x … −z), 팬 곡선 `m³/s:Pa, …`, 영역 | 모델 › 내부 팬. 대상은 *영역 안 (region)*(영역: 2D x0, y0, x1, y1 / 3D x0, y0, z0, x1, y1, z1, mm) 또는 물체(그 물체의 유체 셀). 영역 가운데의 한 단면에 곡선의 압력 상승을 주고, 해석 뒤 **운전점**과 유량이 나옵니다. 팬이 단면 전체를 덮지 않으면 팬 둘레로 공기가 되돌아 돌 수 있습니다 |
| 전압 / 접지 / 전류 유입 | V / 0 V / I (A) | 줄 발열용 |
| 구조 고정 / 롤러 | — | 열응력·구조 지지(롤러는 속성 패널의 종류에서) |
| 압력 하중 / 힘 하중 | p (kPa) / Fx · Fy (· Fz) (N) | 정적 구조용 |

- **대상**: 왼쪽·오른쪽·아래·위 변(3D 는 앞면·뒷면도), *모든 바깥 면*, 또는 특정 물체.
- **구간**: 변의 일부에만(예: 아래 변의 2–8 mm 에만 열유속).
- **영역** `x0, y0, x1, y1`: 그 사각형 안의 면에만 적용합니다. 창틀처럼 *모든 바깥 면* 을 실외 쪽(x < 32)과 실내 쪽으로 나눌 때 씁니다.
- 한 면에 여러 조건이 걸리면 물체 대상 > 변 대상 > 모든 바깥 면 순이고, 같은 순위에서는 목록의 나중 것이 이깁니다. 아무 조건도 없는 면은 단열입니다.
- **U-값 태그**(대류 · 복사 경계): Frame · Edge · COG · Divider · SHGC Exterior · Interior · Exterior 중 하나를 붙이면 U-값 창에서 태그별 U-값이 나옵니다([U-값과 결로](#u-값과-결로-therm-방식) 참고).

### 시간에 따라 바뀌는 경계 값

해석 종류가 **과도 상태**이면 경계의 속성 패널에 시간 표 칸이 더 나옵니다. 형식은 `시간:값, 시간:값` (초)이고, 비우면 위의 상수 값을 씁니다.

| 경계 | 시간 표 칸 | 단위 |
|---|---|---|
| 고정 온도 | 온도 (t) | s:°C |
| 열유속 | 열유속 (t) | s:W/m² |
| 대류 | 열전달 계수 h (t), 유체 온도 (t) | s:W/m²K, s:°C |
| 복사 | 주위 온도 (t) | s:°C |

- 값은 표 사이를 직선 보간하고, 처음보다 앞이나 끝보다 뒤는 끝 값을 씁니다. 각 시간 단계의 끝 시각 값이 쓰이고, 경계 열량 · 에너지 수지도 같은 값으로 셉니다.
- 정상 해석에서는 t = 0 값만 씁니다(모델 검사가 알려 줍니다). h 표의 값은 0 이상이어야 하고, h 결정 방법이 *직접 입력* 이 아니면 상관식이 h 표보다 앞섭니다.
- 예: *하루 동안의 외벽* 예제는 바깥 기온 · h 와 실내 온도를 표로 바꿉니다. 열원의 시간 변화는 물체의 **발열 시간표**로 정합니다.

### 대류 상관식 (h 결정 방법)

대류 경계의 **h 결정 방법**에서 h 를 직접 넣는 대신 상관식으로 구하게 할 수 있습니다.

| h 결정 방법 | 상관식 | 더 넣는 값 |
|---|---|---|
| 직접 입력 | — | h |
| 자연 대류 · 수직면 (Churchill–Chu) | 전 범위 Churchill–Chu | 특성 길이 |
| 자연 대류 · 수평면 위로 (Lloyd–Moran) | 0.54 Ra^¼ (Ra ≤ 10⁷), 0.15 Ra^⅓ | 특성 길이 |
| 자연 대류 · 수평면 아래로 | 0.27 Ra^¼ | 특성 길이 |
| 강제 대류 · 평판 | 층류 0.664 Re^½ Pr^⅓, Re > 5·10⁵ 이면 (0.037 Re^0.8 − 871) Pr^⅓ | 특성 길이, 속도 |

- 물성은 **공기**(200–1000 K 표)를 막 온도에서 씁니다. 물이나 오일 같은 다른 유체에는 맞지 않습니다.
- 표면이 유체보다 차가우면 수평면 위 · 아래 식이 서로 바뀝니다. h 는 면 온도에 맞춰 반복 계산되고, 해석 뒤 속성 패널에 **계산된 평균 h** 가 나옵니다.
- 예: *자연 대류 방열판 (h 상관식)* 예제.

### 박막층

**모델 › 박막층** 은 코팅 · 열 계면 재료 · 페인트처럼 셀 하나보다 얇은 층을 격자로 나누지 않고 넣습니다. **층 두께**(mm)와 **열전도율 k**, **층 모델**을 정합니다.

- **저항형 (두께 방향만)**: 면에 R = d/k 를 직렬로 더합니다. 물체 사이 면에서는 접촉 열저항처럼, 바깥 면에서는 반 셀과 그 면의 경계 조건(온도 · 대류 · 복사) 사이에 들어갑니다.
- **전도형 (면내 전도 포함)**: 저항에 더해 층을 따라 흐르는 열(k·d)을 이웃 셀 사이에 더합니다. 모서리를 도는 층은 면내로 이어지지 않습니다.
- 대상은 물체(그 물체와 다른 모든 것 사이의 면) 또는 해석 영역의 변입니다. *모든 바깥 면* 은 쓸 수 없고, 구간 · 영역은 쓸 수 있습니다. 층의 온도는 따로 풀지 않고 붙은 셀의 온도로 봅니다.
- 예: *단열 코팅 터빈 날개 (박막층)* 예제.

### 탐침

**탐침**(T) 도구로 점을 찍으면 그 위치의 온도가 기록됩니다. 과도 해석에서는 그래프 패널에 시간 변화가 그려지고, 결과 위에 값이 표시됩니다.

## 해석

**해석 › 해석 설정…** 또는 속성 패널(선택 없음)에서 정합니다.

- **정상 상태**: 평형 온도. 복사·온도 의존 k·대류 상관식·면 사이 복사가 있으면 반복(피카드)으로 풉니다.
- **과도 상태**: 종료 시간, 시간 간격, 저장 프레임 수, 초기 온도. 후진 오일러(무조건 안정)입니다. 시간 간격이 크면 빠르지만 빠른 변화를 놓칩니다. cp(T) 재료나 상변화 재료가 있으면 시간 단계마다 엔탈피에 대해 뉴턴 반복을 합니다.
- **유동 (CHT)**: 유체·다공성 재료 영역의 유동을 함께 풉니다(2D · 3D). 3D 유동은 셀 수에 따라 오래 걸릴 수 있고, 유체 셀이 100만 개를 넘으면 경고가 나옵니다. 강제 대류에는 유입구(또는 팬 · 내부 팬)와 유출구가, **자연 대류**에는 중력과 기준 온도가 쓰입니다. **난류 (k-ω SST)** 를 켜면 층류 대신 난류 모델로 풉니다. *유동 반복* 이 부족하면 상태 표시줄에 경고가 나옵니다.
- **줄 발열 (전기)**: 전위장을 풀어 전류에 의한 발열을 열 해석에 더합니다.
- **열응력**: 열 해석이 끝난 온도로 응력을 계산합니다. 지지가 없으면 강체 운동만 막아 자유 팽창으로 풉니다. 2D 는 평면 응력(또는 *평면 변형률*). *열팽창 포함* 을 끄고 하중·*자중 (중력)* 만 주면 정적 구조 해석입니다.
- **고유 진동수**: 모드 수만큼 고유 진동수와 모드 형상을 구합니다.
- **태양 복사 하중**: 해석 설정의 확인란과 일사량 · 태양 고도 · 방위각입니다. 아래 [태양 복사 하중](#태양-복사-하중) 참고.
- **면 사이 복사 (S2S)**: 해석 설정의 확인란입니다. 아래 [면 사이 복사](#면-사이-복사-s2s) 참고.
- **쾌적성** 입력(유동을 켰을 때): **대사량**(met, 기본 1.2), **착의량**(clo, 기본 0.5), **상대 습도**(%, 기본 50), **평균 복사 온도**(끄면 공기 온도와 같음). 결과 › 열 쾌적성 (PMV) · 불만족률 (PPD) 계산에 쓰입니다.
- **모델 검사**(✔): 재료 없는 물체, 열이 빠져나갈 경계 없음, 유체 없는 유동, 셀 수 과다, 잘못된 팬 곡선, 특성 길이 없는 상관식, 두께 · k 가 없는 박막층, 정상 해석의 시간 표, 음수인 cp(T), 복사가 지나갈 셀이 없는 S2S 같은 문제를 해석 전에 알려 줍니다. 오류가 있으면 해석을 시작하지 않습니다.
- 환경 설정의 **수정 후 자동 실행**을 켜면 모델을 고칠 때마다 다시 계산합니다.

모델을 결과가 나온 뒤에 고치면 뷰포트에 *모델이 바뀜 — 다시 실행* 이 표시됩니다.

### 면 사이 복사 (S2S)

**해석 설정 › 면 사이 복사 (S2S)** 를 켜면 물체 표면끼리 복사로 열을 주고받습니다(회색 · 확산). 진공 장비, 공동, 함체 안쪽처럼 대류가 약한 곳에서 중요합니다.

- **복사가 지나는 곳**: *빈 공간*(배경 *없음* 셀, 기본) 또는 *빈 공간 + 유체*. 복사면은 불투명한 셀(그 밖의 모든 해석 셀)과 투명한 셀 사이의 면이고, 방사율은 불투명한 쪽 **재료의 방사율**입니다.
- 해석 영역 가장자리에 닿은 투명 셀의 면은 **열린 곳**(흑체)입니다. 그 변에 복사 경계(또는 방사율이 있는 대류 경계)가 있으면 그 주위 온도, 없으면 모델의 주위 온도를 씁니다.
- 뷰 팩터: 2D 는 Hottel 의 교차 줄 방법(가려짐 검사 포함, 2D 모델은 z 로 무한히 길다고 봄), 3D 는 면 조각마다 256개 광선의 몬테카를로입니다. 면은 조각으로 묶이고(조각이 3000개를 넘지 않게 커짐) 복사도는 반복할 때마다 다시 풉니다.
- 결과에는 순 복사 열유속 필드 **qrad** 가 들어갑니다(VTK · VTU 내보내기에 포함). 바깥과 주고받은 복사 열은 에너지 수지의 경계 열량에 더해집니다.
- 제한: 회색 · 확산 면만(파장별 · 경면 반사 없음), 참여 매질(연기 · 가스)과 태양 광선 추적은 없습니다. 면까지의 반 셀 온도 차는 무시합니다. S2S 로 복사하는 면에서는 그 면 경계의 방사율은 쓰지 않고 대류만 남습니다(경고로 알려 줌). 닫힌 공동만으로는 온도 수준이 정해지지 않으니 열린 곳이나 다른 경계가 필요합니다.
- 예: *진공 오븐 면 사이 복사 (S2S)* 예제.

### 태양 복사 하중

**해석 설정 › 태양 복사 하중** 을 켜면 햇빛이 드러난 면에 열을 줍니다(Icepak · SOLIDWORKS Flow 의 태양 하중).

- 입력: **일사량** G (W/m², 해를 마주한 면 기준), **태양 고도**(x-z 평면 위의 각, 위쪽이 +y), **태양 방위각**(+x 에서 +z 쪽으로 잰 각). 재료마다 **태양 흡수율** α 를 씁니다.
- 드러난 면 — 불투명한 셀이 빈 공간 · 유체 셀이나 영역 밖을 보는 면 — 가운데 해를 향한 면(바깥 법선 n, n·s > 0)이 α · G · (n·s) · 면적을 받습니다. 면 가운데서 해 쪽으로 쏜 광선이 다른 불투명한 셀에 막히면 그늘입니다(2D 모델은 z 로 무한히 긴 단면으로 보고 x-y 평면에서 그림자를 따집니다).
- 받은 열은 그 면 뒤 셀의 열원으로 더해지므로 같은 면의 대류 · 복사 경계와 함께 쓰입니다. 에너지 수지에는 발열로 들어가고, 결과 요약에 **흡수한 햇빛**(W)이 나옵니다.
- 해가 지평선 아래(고도 ≤ 0)면 열이 없습니다. 산란 일사(하늘빛), 반사, 유리 투과는 계산하지 않습니다.
- 예: *햇빛 아래 옥외 함체 (태양 하중, 3D)* 예제.

## 결과 보기

- **필드**: 온도 · 열유속 |q| · 속도 · 압력 · 난류 점성 · 폰 미세스 응력(MPa) · 변위(µm) · 모드 형상 · 액상률 · 전위 · 전류 밀도 · 열 쾌적성 (PMV) · 불만족률 (PPD). 결과에 없는 필드는 흐리게 표시됩니다.
- **등온선**, **벡터**(열유속, 유속 필드에서는 속도), **유선**, **변형 형상**(변위를 과장해서 그림).
- **애니메이션**(Space)과 프레임 슬라이더: 과도 결과를 시간 순서로 봅니다. 온도 색 범위는 모든 프레임에 같게 유지됩니다.
- **단면선**: 두 점을 클릭하면 그 선을 따른 값이 그래프 패널에 그려집니다.
- **3D 보기**: [3D 보기](#3d-보기) 참고. 3D 모델을 2D 보기에서 볼 때는 왼쪽 위의 **층 (z)** 으로 단면 높이를 고릅니다.
- 상태 표시줄에 커서 위치의 값이 나옵니다. 온도 단위는 환경 설정 › 일반, 색 지도와 색 단계·등온선 수는 환경 설정 › 결과 표시에서 바꿉니다.
- 값 저장: 그래프 패널에서 오른쪽 단추 › **탐침 값 CSV 저장…**(탐침마다 시간에 따른 값, 탐침이 있을 때) · **단면선 값 CSV 저장…**(마지막 단면선을 따라 잰 값).
- **해석 보고서**에는 물체별 온도 외에 **물체별 적분 (부피 · 평균 · ∫T dV)** 표가 있습니다 — 물체마다 부피(cm³), 최저 · 평균 · 최고 온도, ∫T dV(°C·cm³). 과도 결과는 마지막 프레임으로 셉니다.
- 내보내기(파일 메뉴): **CSV**(셀별 값), **PNG**(뷰포트), **VTK** · **VTU**(ParaView 등에서 모든 필드), 해석기 입력 파일과 메시 · 형상 파일, **해석 보고서**(HTML), **인쇄**. 형식마다 자세한 내용은 [지원 파일 형식](#지원-파일-형식)에 있습니다.

### 3D 후처리 (단면 · 등치면 · 3D 단면선)

3D 모델의 결과를 **3D 보기**로 보면 뷰포트 위 칩 줄에 다음이 더 나옵니다(ParaView 의 Slice · Contour · Plot Over Line 에 해당).

- **단면**: *끔* · x · y · z 중 하나를 고르면 그 축에 수직인 평면으로 결과를 잘라 셀마다 색으로 보여 줍니다. 옆의 숫자(1 … 셀 수)는 평면이 지나는 **셀 번호**입니다.
- **◍ 등치면**: 켜면 정한 값(처음엔 색 범위의 가운데)의 면을 그리고 바깥 면은 반투명해져 안이 보입니다. 옆 칸에서 값을 바꿉니다(온도는 환경 설정의 온도 단위).
- **결과 › 3D 단면선…**: 점 A · B 의 x · y · z (mm)를 입력하면 그 두 점을 잇는 선을 따라 부피 속 값을 그래프 패널에 그립니다. 3D 결과에서만 켜집니다.
- **3D 보기에서 누르기**: 결과를 3D 로 볼 때 모델을 누르면(끌지 않고) 그 점의 좌표와 값이 상태 표시줄에 나옵니다. 3D 모델에서 **탐침** 도구를 고른 채 누르면 3D 보기를 그대로 둔 채 그 자리에 탐침이 놓입니다.

### 계산기 · 히스토그램

**결과 › 계산기 · 히스토그램…** (ParaView 의 Calculator · Histogram) 은 결과 필드로 셀마다 식을 계산합니다.

- 식: `+ − * / ^ ( )`, 비교 `< <= > >= == !=`(참이면 1, 거짓이면 0), 함수 `sqrt abs exp log log10 sin cos tan min max pow hypot floor ceil round sign`, 상수 `pi e`. 예: `T + 273.15`, `sqrt(qx^2 + qy^2)`, `max(T - Tamb, 0)`, `T > 80`.
- 쓸 수 있는 이름: 결과에 있는 필드(`T`, `qx` `qy` `qz`, `u` `v`, `p`, `vonMises`, `dispX` …, `liquid`, `nut`, `V`, `J` …), 크기 `q` · `U` · `disp`, 셀 중심 `x` `y` `z`(mm), 모델의 주위 온도 `Tamb`, 프레임 시각 `t`. 창에 지금 결과에서 쓸 수 있는 이름이 나옵니다.
- 최솟값 · 평균 · 최댓값, 셀 수와 계산이 안 된 셀 수(예: 음수의 log), 값 구간마다 부피 비율(%)의 히스토그램이 나옵니다. 격자가 균일하므로 셀 비율이 곧 부피 비율입니다.
- **뷰포트에 표시** 를 누르면 그 값이 *계산 필드* 로 뷰포트에 칠해집니다(필드 선택 · 결과 메뉴의 *계산 필드*). 다시 해석하면 사라집니다. **필드 CSV 저장** · **히스토그램 CSV 저장** 으로 값을 내보냅니다.
- 식은 이 프로그램의 작은 식 해석기로 읽으므로 코드를 실행하지 않습니다.

| 격자 자동 설정 | ⊞ 격자 자동 설정 | — | 가장 얇은 물체가 셀 두 개 이상이 되는 셀 수 |

**매개변수 연구**는 열린 모델을 바꾸지 않고 사본으로 여러 번 풉니다. 표의 한 줄에서 **적용**을 누를 때만 그 값이 모델에 들어갑니다.

유동 · CHT · 난류는 2D 와 3D 에서 풉니다. 압축성 유동, 다상 유동(VOF), 격자 볼츠만 풍환경, 전자기 해석은 지원하지 않습니다([지원하지 않는 기능](#지원하지-않는-기능) 참고).

## 열분석 (DSC / TGA)

**도구 › 열분석 (DSC/TGA)…** (재료 작업대에도 있음) 은 열분석 장비가 내보낸 곡선 CSV 를 읽습니다. 예제 데이터로 바로 해 볼 수도 있습니다.

- **DSC**: 온도와 열유량(mW) 곡선. 시료 질량과 가열 속도, 적분 구간을 정하면 기준선 위 피크를 적분해 **잠열**과 **시작 · 피크 · 끝 온도**, **겉보기 비열**을 구합니다. **상변화 재료로 추가** 를 누르면 그 결과로 상변화 재료가 모델에 생깁니다.
  - **기준선**: 직선 또는 **시그모이드**(피크 앞뒤 접선을 면적 비율로 섞음 — 피크 앞뒤의 비열이 다를 때).
  - **여러 피크**: **+ 피크 추가** 로 구간을 더 넣으면 피크마다 한 줄씩 잠열과 온도가 나옵니다.
  - **미분 곡선**(dHF/dT, Savitzky–Golay)과 **전환율 α** 보기로 피크가 어디서 시작하고 끝나는지 봅니다.
  - **유리 전이 (Tg)**: 계단 모양 구간에서 앞뒤 기준선과 변곡점 접선으로 시작 · 중간점 · 끝 온도와 Δcp 를 구합니다(ASTM E1356 / ISO 11357-2).
  - **보정 (표준 물질)**: 인듐 · 주석 · 아연 · 물의 측정값으로 온도와 잠열을 보정합니다. *다점 (온도)* 로 바꾸면 표준 물질 여러 개로 온도 보정 직선과 R² 를 구합니다.
- **반응 속도론**: 가열 속도가 다른 DSC 곡선을 여러 개 넣으면 피크 온도의 이동으로 **Kissinger**, 한 전환율 α 에서의 온도로 **Ozawa–Flynn–Wall**(적분형) · **Friedman**(미분형, ln(β·dα/dT) 대 1/T) 활성화 에너지 Ea (kJ/mol)를 구합니다. **Ea(α) (모델 없음)** 보기는 α = 0.1 … 0.9 마다 OFW · Friedman Ea 를 그리고 표로 보여 줍니다 — 거의 평평하면 반응이 한 단계입니다. 곡선 보기 · Kissinger 그래프 · Ea(α) 를 오갑니다.
- **TGA**: 온도와 질량(%) 곡선에서 5 · 10 · 50 % 감량 온도, DTG 피크, 잔류량, 그리고 **질량 감소 단계**(단계마다 온도 구간 · 감량 · DTG 피크)를 구합니다. **DTG** 곡선을 함께 그릴 수 있습니다.
- **cp (사파이어 법)**: 빈 팬 · 사파이어 · 시료의 세 곡선으로 ASTM E1269 비열 cp(T)를 구합니다. **재료 cp(T)로 사용** 을 누르면 그 표가 [cp(T)](#재료) 로 들어간 재료가 모델에 생깁니다(물체가 선택되어 있으면 그 재료를 복사해서).

각 탭의 *예제* 단추로 예제 데이터를 바로 불러올 수 있고, 설치본의 `samples/formats/` 에는 `dsc-indium.csv` · `tga-polymer.csv` 가 있습니다.

## 신뢰성 (Sherlock 방식)

**결과 › 신뢰성 해석…** 에서 부품(물체)마다 활성화 에너지 Ea, 정격 온도와 정격 MTTF, 연간 열 사이클 수, 사이클 ΔT 를 정합니다.

- **아레니우스**: AF = exp[Ea/k·(1/T정격 − 1/T사용)], MTTF = MTTF정격 / AF, FIT = 10⁹/MTTF. T사용 은 해석한 물체 최고 온도입니다.
- **코핀-맨슨**: N_f = C·ΔT^−n. ΔT 를 비워 두면 과도 해석의 물체 최고 온도 변동폭, 정상 상태면 주위 대비 상승분(전원 켜고 끄기 1회)을 씁니다.
- 부품 수명은 둘 중 짧은 값, 시스템은 직렬(FIT 합)로 계산하고 5년 생존 확률을 보여 줍니다.

### 솔더 피로 · 수명

**도구 › 솔더 피로 · 수명 분석…** 은 해석 결과의 온도로 솔더 접합의 수명을 고장 물리 방식으로 셉니다. 탭이 다섯입니다.

- **열 사이클 · 마이너**: *이력 출처*(물체 최고 온도 또는 탐침)의 온도 이력을 **레인플로**(ASTM E1049)로 세어 사이클마다 ΔT · 평균 · 횟수 · Nf · 손상을 표로 보이고, **마이너** 합으로 이력 1회의 손상 D 와 수명(반복 수 · 년)을 구합니다. 수명 모델은 **코핀-맨슨**(C, n) 또는 **엥겔마이어**(중립점 거리 LD, Δα — *재료에서* 부품 · 기판 재료의 열팽창 계수로, 솔더 높이 h, 유지 시간)입니다. *이력 반복/일* 로 하루에 이력이 몇 번 되풀이되는지 정합니다. 정상 해석 결과는 주위 온도 → 최고 온도를 전원 1사이클로 셉니다.
- **노리스-란즈버그**: 가속 시험과 현장의 ΔT · 주파수 · 최고 온도, 지수 n · m, Ea, 시험 수명으로 가속 계수 AF 와 현장 수명(= AF × 시험 수명)을 구합니다.
- **와이블**: 형상 β 와 MTTF(신뢰성 해석에 그 부품이 있으면 거기서, 없으면 직접 입력)로 척도 η, B10 · B1 수명, 임무 시간의 신뢰도와 R(t) 곡선을 보여 줍니다.
- **진동 (스타인버그)**: 고유 진동수 fn(모드 해석 결과가 있으면 1차 모드), 입력, 기판 변 B · 부품 길이 L · 기판 두께 h · 위치 계수 r · 부품 상수 c 로 허용 변위 Z허용과 응답 Z(3σ), 그 비와 수명(시간)을 구합니다. 입력은 셋 중 하나입니다 — **G rms**, **PSD**(fn 에서의 값과 대역폭, Miles 식 Q = √fn), **PSD 표**(`Hz:g²/Hz, …` 꺾은선 스펙트럼, 로그–로그 보간; MIL-STD-810 최소 내구 형태 · IEC 60068-2-64 평탄 · 평탄 0.04 g²/Hz 프리셋). PSD 표는 1자유도 전달 함수 |H|² 로 대역 전체를 적분해 응답 G rms 를 구하고(입력 G rms · Miles 식 값과 함께), 입력 · 응답 PSD 를 로그 그래프로 그립니다.
- **충격 (반정현파)**: 최대 가속도(g) · 펄스 길이(ms) · 증폭 Q 와 fn 으로 1자유도 기판 모드의 운동 방정식을 시간 적분(RK4)해 최대 상대 변위, 질량의 최대 가속도, 충격 응답(aMax / 입력, 충격 응답 스펙트럼 값)과 최대가 펄스 뒤(잔류 진동)인지를 보여 줍니다. 진동 탭의 스타인버그 허용 변위와 비교한 여유(Z허용 / 최대 변위)가 나오며 1 보다 크면 여유가 있습니다(보수적 기준).

### 조화 응답

**도구 › 조화 응답…** 은 고유 진동수 해석 결과(모드별 진동수와 유효 질량비)로 사인 스윕 응답을 모드 중첩으로 그립니다. 최저 · 최고 주파수, 감쇠비, 축(자동이면 유효 질량이 가장 큰 축), 종류(*모드 중첩 (상대 진폭)* 또는 *바닥 반력 / 강체*)를 정하면 진폭 · 위상 곡선과 응답 최대점 표가 나옵니다. *모드 중첩* 은 모드 형상 없이 유효 질량비의 √ 를 참여 계수로 쓰므로 진폭이 상대값입니다. 모델에 탐침이 있으면 종류에 **탐침 ○○ 의 전달률 (모드 형상)** 이 더 나옵니다 — 탐침 위치의 모드 형상과 엔진이 내보낸 부호 있는 참여 계수로 바닥 가속도 대비 절대 가속도의 비(전달률)와 상대 변위(mm/g)를 계산합니다. 한 모드라면 고전적인 1자유도 전달률과 같습니다. 모드 결과가 없으면 먼저 모드 해석을 켜고 풀라고 알려 줍니다.

## U-값과 결로 (THERM 방식)

창틀·벽체 단면 모델에서 **결과 › U-값 (건물 외피)…** 를 엽니다. 실내 쪽과 실외 쪽 대류 경계를 고르면 U = |Q| / (A·ΔT), R = 1/U, 선 열관류 L2D(W/mK), 열량을 보여 줍니다.

경계 조건에 **U-값 태그**(Frame · Edge · COG · Divider · SHGC Exterior · Interior · Exterior)를 붙여 두면 **태그별 U-값 (THERM · NFRC)** 표에 태그마다 전체 길이와 투영 길이 기준 U-값이 나옵니다.

**프레임 공동 유효 열전도율 (ISO 10077-2)** 칸은 공동의 폭(열 흐름 방향) · 높이, ΔT · 평균 온도, 양쪽 면의 방사율, 열 흐름 방향으로 공기 공동의 등가 열전도율 k_eq 와 대류 · 복사 열전달 계수 h_a · h_r 을 구합니다. **공동 재료** 를 고르고 **재료에 적용** 을 누르면 그 재료의 열전도율이 k_eq 로 바뀝니다 — 다시 해석하면 반영됩니다.

아래의 **결로 · 곰팡이 위험 (ISO 13788)** 칸에 **실내 상대 습도**를 넣으면 실내 표면 최저 온도, **이슬점**, 온도 계수 **fRsi** = (T표면 − T실외) / (T실내 − T실외) 와 판정(결로 위험 · 곰팡이 주의(fRsi < 0.75) · 안전)이 나옵니다. 예제 *창틀 단면*, *경량 철골 벽체*, *발코니 슬래브 열교* 가 이 설정으로 되어 있습니다.

## 히트맵과 배치 실행 (HAM 방식)

### 절점 데이터 히트맵

**도구 › 절점 데이터 가져오기…** 로 CSV 를 엽니다(파일을 창에 끌어다 놓아도 됩니다).

- 열: `node`(또는 id, name), `x`, `y`, `[z]`, `T`(또는 temp, temperature), `[time]`. 쉼표·세미콜론·탭 구분, 열 이름에 `(K)` 가 있으면 켈빈으로 읽습니다.
- 역거리 가중(IDW) 보간으로 히트맵을 그리고 최소·최대·평균·표준편차·P5/P50/P95, 가장 뜨거운 절점, **한계 온도** 초과 절점을 보여 줍니다. 시간 열이 있으면 시간을 고를 수 있습니다.
- 히트맵을 PNG 로, 보간한 격자를 CSV 로 저장합니다. *예제 데이터 불러오기* 로 위성 패널 절점 데이터를 바로 볼 수 있습니다.
- **도구 › 히트맵 비교 (차이 · 포락선)…** 는 절점 CSV 를 두 개 이상(또는 *예제 한 쌍*) 불러와 같은 절점 번호끼리 **B − A 차이**나 모든 데이터의 **포락선 (최대)** 을 히트맵과 통계로 보여 주고 CSV 로 내보냅니다. 시간 열이 있으면 시간을 고릅니다.
- 절점에 **z** 값이 여럿이면(3D 절점 데이터) **보기**(평면 지도 (IDW) / 3D 점)와 **z 범위** 칸이 나옵니다. 평면 지도와 통계는 z 범위 안의 절점만 써서 층별로 잘라 볼 수 있고, 3D 점 보기는 절점을 온도 색 점으로 그리며 끌어서 돌립니다. *3D 예제 (배터리 모듈)* 단추로 세 층의 열전대 데이터를 바로 볼 수 있습니다.

```
MyHeatManager --batch pcb.myheat --field vonMises --frame last --quiet
```

모델마다 `이름.summary.json`(통계·탐침·물체·경계·에너지 수지), `이름.필드.csv`(셀 값), `이름.필드.png`(히트맵)를 씁니다. 실패한 모델이 있으면 종료 코드 2 입니다. 설계안 여러 개를 스크립트나 CI 로 돌릴 때 씁니다.

## 인쇄

**파일 › 인쇄…**(Ctrl+P) 또는 도구 모음의 인쇄 단추는 **인쇄 창**을 엽니다. 왼쪽은 쪽 설정, 오른쪽은 설정을 바꿀 때마다 바로 다시 그려지는 **여러 쪽 미리보기**(쪽 수 표시)입니다.

- **용지**: 용지 크기 A3 · A4 · A5 · B4 · B5 · Letter · Legal · Tabloid, 방향(세로 · 가로).
- **여백**: 없음 · 좁게 · 보통 · 넓게, 또는 사용자 지정(위 · 아래 · 왼쪽 · 오른쪽 따로).

**인쇄**를 누르면 시스템 인쇄 창이 열리고, 프린터와 매수는 거기서 고릅니다. 고른 설정은 프로그램을 끌 때까지 기억합니다.

## 지원 파일 형식

**파일 › 지원 파일 형식…** 에 같은 표가 있습니다. 설치본의 `samples/formats/` 폴더에 형식마다 예제 파일(방열판 2D · PCB 3D · 창틀 단면 · IDF 제어 기판 등)이 있습니다.

| 제품 | 형식 | 열기 | 저장 | 내용 |
|---|---|:-:|:-:|---|
| MyHeatManager | `.myheat` | ✓ | ✓ | 모델(JSON) |
| CalculiX | `.inp` | ✓ | ✓ | 입력 덱(CalculiX · Abaqus): 격자 · 재료 · 경계 조건. 열면 요소 · 노드 집합, *MATERIAL, *SOLID SECTION, *BOUNDARY, *FILM, *RADIATE, *DFLUX 를 읽습니다 |
| Nastran / Simcenter | `.bdf` | ✓ | ✓ | 정상 열해석(SOL 153) 벌크 데이터: 2D CQUAD4 + PSHELL(두께 = 해석 영역 깊이), 3D CHEXA, MAT4(이방성이면 MAT5), SPC · CONV · QBDY1 · QVOL. 열면 GRID · CQUAD4 · CTRIA3 · CHEXA · CTETRA · CPENTA · PSHELL · PSOLID · MAT4/5 · CHBDY · CONV · QBDY1 · QVOL · SPC 를 읽습니다(자유 · 짧은 · 긴 필드) |
| Ansys | `.cdb` | ✓ | ✓ | MAPDL 입력(/INPUT 또는 Workbench External Model): PLANE55 / SOLID70, D TEMP · SFE CONV · SFE HFLUX · BFE HGEN, 정상 열해석. 열면 NBLOCK · EBLOCK, MP · MPDATA, R, D TEMP, SFE, BFE 를 읽습니다(CDWRITE 형식 포함) |
| COMSOL | `.mphtxt` | ✓ | ✓ | 텍스트 메시(버전 4, m 단위): 재료마다 도메인, 경계 조건마다 경계. 열면 도메인마다 재료, 경계 개체마다 대류 경계가 됩니다(물성 · 경계 값은 없음) |
| Gmsh | `.msh` | ✓ | ✓ | MSH 2.2 ASCII: 재료 · 경계 조건마다 물리 그룹. 열면 그룹마다 외곽선을 따라 물체를 만들고, 이름 끝의 `[type]` 으로 경계 조건 종류를 정합니다(없으면 대류) |

| ParaView | `.vtk` · `.vtu` | — | ✓ | 결과: 셀마다 모든 필드(마지막 프레임), 열유속 · 속도 · 변위는 벡터 |
| STL | `.stl` | — | ✓ | 보이는 물체를 닫힌 입체로(2D 는 깊이만큼 돌출, 원은 48각 기둥) |
| DXF (CAD) | `.dxf` | ✓ | ✓ | R12 도면(mm): 물체마다 레이어, 닫힌 폴리라인 · 원 |
| CSV | `.csv` | ✓ | ✓ | 셀별 필드 값 저장 / 절점 측정값 · 발열 지도 · DSC · TGA 읽기 |
| PNG | `.png` | — | ✓ | 뷰포트 · 그래프 · 히트맵 그림 |
| ECAD (IDF 3.0) | `.emn` + `.emp` | ✓ | — | 기판 외곽 · 두께와 부품 배치(.emn), 부품 외곽 · 높이 · `POWER_OPR`(.emp) → 3D 기판 · 부품 물체와 대류 경계. 데스크톱은 같은 이름의 .emp 를 함께 읽고, 웹판은 라이브러리 파일을 한 번 더 고릅니다(취소하면 기판만) |

- 해석기 입력 파일(Nastran · Ansys · CalculiX)은 SI 단위(m, °C)로, 메시 · 도면 파일(Gmsh · VTU · STL · DXF · THERM)은 mm 로 씁니다.
- 메시를 쓰는 형식은 해석에 쓰는 바로 그 직교 격자를 씁니다 — 재료가 있는 셀마다 사각형(2D) / 육면체(3D) 요소 하나.
- 해석기 입력 파일에서 복사는 등가 대류 계수로 근사하고, 유동 · 구조 · 전기 · 팬 조건은 쓰지 않습니다.
- 해석기 입력 파일을 열면 노드 · 요소 · 재료 · 열 경계 · 발열만 읽고, 형상은 Gmsh 가져오기처럼 재료마다 외곽선을 따라 물체로 바꿉니다. 이 프로그램이 쓴 파일에는 영역 크기 주석이 있어 영역과 격자가 그대로 돌아오고, 다른 프로그램의 파일은 크기로 단위(m / mm)를 짐작합니다(상태 표시줄에 알림). 사면체 · 곡면 메시는 외곽선이 계단이 되거나 경계 상자로 바뀝니다.

**지원하지 않는 형식** — 공개되지 않은 이진 형식이거나 B-rep 형상 커널이 필요한 형식입니다. 지원 파일 형식 창에 형식마다 대신 쓸 방법이 있습니다.

| 형식 | 제품 | 대신 |
|---|---|---|
| `.mph` | COMSOL | COMSOL 에서 메시를 `.mphtxt` 로 내보내거나, 이 프로그램의 `.mphtxt` 를 COMSOL 로 가져가기 |
| `.sldprt` · `.sldasm` | SOLIDWORKS | SOLIDWORKS 에서 DXF(단면) 또는 STL 로 저장 |
| `.wbpj` · `.wbpz` · `.db` | Ansys | MAPDL 에서 CDWRITE 로 `.cdb` 를 쓰거나, 이 프로그램의 `.cdb` 를 External Model 로 가져가기 |
| `.cas` · `.dat` | Ansys Fluent | 유동 결과를 Fluent 에서 VTK · CSV 로 내보내기 |
| `.sim` · `.fem` | Nastran / Simcenter | Simcenter 에서 Nastran `.bdf` 로 내보내거나, 이 프로그램의 `.bdf` 를 가져가기 |
| `.x_t` | Parasolid | DXF(단면) 또는 STL |
| `.step` · `.stp` · `.iges` · `.igs` | STEP · IGES | CAD 에서 DXF(단면) 또는 STL 로 저장 |

## 지원하지 않는 기능

- **유동의 격자** — 유동도 같은 균일 직교 격자에서 풀므로 좁은 틈(핀 사이 등)은 셀 셋 이상이 되도록 잡아야 합니다. 벽 함수는 거친 격자에서 난류 마찰을 크게 잡습니다(첫 셀 y+ ≈ 11 이하 권장). 위가 열린 자연 대류 굴뚝은 비물리적으로 빨라질 수 있습니다.
- **압축성 유동, 다상 유동(VOF), 격자 볼츠만 풍환경**, 다른 난류 모델(k-ε, LES).
- **전자기 해석** — 유도 가열 · 마이크로파 가열 등. 직류 줄 발열만 됩니다.
- **복사**: 파장별(비회색) · 경면 반사, 참여 매질(연기 · 가스), 산란 일사 · 반사 · 유리 투과. S2S 는 회색 · 확산 면만, 태양 하중은 직달 일사와 그림자만입니다.
- **격자**: 균일한 직교 격자만 씁니다. 곡면은 계단 모양으로 근사되고, 국부 세분화 · 적응 격자 · 비정렬 메시 해석은 없습니다(Gmsh 메시는 외곽선을 따서 물체로 바꿔 엽니다).
- **구조**: 선형 탄성 · 작은 변형만. 소성 · 크리프 · 접촉 비선형 · 대변형 · 좌굴은 없습니다. 조화 응답은 모드 형상 없이 계산한 상대 진폭입니다.
- **파일**: STEP · IGES · Parasolid · CAD 원본 파일(SOLIDWORKS 등), COMSOL `.mph`, Ansys Workbench 프로젝트, ODB++ · Gerber 는 열 수 없습니다. 해석기 입력 파일은 열 해석 카드만 읽습니다(구조 · 유동 · 전기 카드는 읽지 않음).

## 설치와 빌드

### 설치 (Windows)

- 설치 프로그램은 처음에 **한국어 / English** 중 설치 언어를 고릅니다.
- MyHeatManager 는 한 번만 설치됩니다. 이전 설치가 있으면(버전 상관없이) 먼저 묻고, **예**를 고르면 실행 중인 창을 닫고 이전 설치를 **완전히 지운 뒤** 다시 설치합니다. **아니요**면 아무것도 바꾸지 않고 멈춥니다.
- 이전 설치나 사용 기록이 있으면 **사용자 데이터를 지울지** 묻습니다 — 예: 설정 · 최근 파일 · 창 위치를 지움, 아니요: 데이터를 두고 다음 실행 때 설정만 기본값으로(최근 파일은 남김), 취소: 설치 중단. 다른 곳에 저장한 `.myheat` 파일은 건드리지 않습니다.
- *바로 가기* 페이지에서 바탕화면 · 시작 메뉴 바로 가기를 고릅니다. 시작 메뉴 폴더에는 사용 설명서 바로 가기도 생깁니다.

## 계산 방법 (요약)

- 균일한 직교 격자의 **유한 체적법**. 면 열전도도는 조화 평균, 경계는 반 셀 저항과 직렬로 연결합니다.
- 선형계는 **불완전 촐레스키(IC0) 전처리 켤레 기울기법**(대칭), 대류항이 있는 에너지식은 **ILU(0) BiCGSTAB**.
- 복사는 h_rad = εσ(T² + T∞²)(T + T∞) 로 선형화해 반복합니다(절대 온도).
- 상변화는 이전·현재 온도 사이 엔탈피 차이로 구한 겉보기 열용량을 반복 갱신해 녹는 구간을 건너뛰지 않습니다. cp(T) 재료도 같은 엔탈피 방식이라 에너지가 보존됩니다.
- 면 사이 복사는 뷰 팩터(2D 교차 줄 방법, 3D 몬테카를로 광선)와 복사도 식을 바깥 반복마다 다시 풀어 면의 열원으로 넣습니다. 대류 상관식의 h 와 시간 표 경계 값도 반복 · 시간 단계마다 다시 구합니다.
- 태양 하중은 드러난 면마다 해 쪽으로 격자 광선을 진행해 그늘을 가리고, 흡수한 열을 고정 열원으로 더합니다.
- 박막층은 면 열전도도에 R = d/k 를 직렬로 더하고, 전도형이면 층을 따라 흐르는 k·d 를 이웃 셀 사이에 더합니다.
- 유동은 엇갈림(MAC) 격자의 **투영법**(2D · 3D 같은 코드, 3D 는 7점 압력 방정식), 압력 푸아송 방정식은 IC0-CG. 다공성 영역은 다르시-브링크만 항력, 자연 대류는 부시네스크 근사. 난류는 **k-ω SST**(벽 처리 자동), 팬은 매 유동 단계마다 팬 곡선과 측정한 압력 상승이 같아지는 유량으로 다가갑니다. 내부 팬은 영역 가운데 단면의 압력 점프로, 측정한 유량의 곡선 압력으로 매 단계 다가갑니다.
- 줄 발열은 온도 의존 전기 전도도로 전위장을 풀어 σ|∇V|² 를 열원으로 더합니다. 생체 열전달은 Pennes 항 ω_b ρ_b c_b (T_a − T) + q_m 을 셀마다 더합니다.
- 열응력·정적 구조는 셀 꼭짓점 절점의 쌍일차(2D)/삼일차(3D) 유한 요소, 요소별 행렬 없이 곱하는 야코비 전처리 CG. 모드 해석은 같은 강성 행렬로 고유값을 구합니다.

정확도는 격자에 달려 있습니다. 같은 모델을 셀 수를 두 배로 늘려 다시 풀어 결과가 거의 같으면 격자가 충분한 것입니다.
