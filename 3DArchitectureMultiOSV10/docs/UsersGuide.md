## 1. 화면 구성

```
┌──────────────────────────────────────────────────────────┐
│  [툴바]  파일명   언어  테마  축  그리드  조명  AI  설정  스크린샷 │
├──────────┬──────────────────────────────────┬────────────┤
│          │                                  │            │
│  좌측    │         3D 뷰포트 (Canvas)        │  우측      │
│  설정    │                                  │  속성      │
│  패널    │    [조명 제어 패널] (드래그 가능)   │  패널      │
│          │                                  │            │
├──────────┴──────────────────────────────────┴────────────┤
│  [파일 드롭 영역]  — 파일이 없을 때 표시                      │
└──────────────────────────────────────────────────────────┘
```

| 영역 | 설명 |
|------|------|
| **툴바** | 파일 열기, 뷰 전환, 기능 버튼 모음 |
| **좌측 설정 패널** | 벽 높이·두께 슬라이더, 이미지 분석 파라미터, 바닥/천장 토글 |
| **3D 뷰포트** | Three.js WebGL 렌더링 영역. 마우스로 뷰 조작 |
| **조명 제어 패널** | 조명 세기·색상 조정, 태양 위치 기즈모 토글 (드래그 이동 가능) |
| **우측 속성 패널** | 선택된 객체 정보, 씬 통계 표시 |

## 2. 파일 열기

### 방법 1 — 드래그 & 드롭

파일 탐색기에서 파일을 앱 창으로 직접 드래그합니다.

### 방법 2 — 파일 대화상자

툴바 왼쪽 **파일 열기** 버튼(폴더 아이콘)을 클릭하면 파일 선택 창이 열립니다.

### 지원 형식별 처리 과정

| 파일 형식 | 처리 방식 |
|-----------|-----------|
| `.dxf` | LWPOLYLINE·LINE 선분 추출 → 벽 메시 생성 → 레이어별 정리 |
| `.ifc` | IFC 파서로 IfcWall 요소 추출 → 3D 배치 |
| `.obj` `.gltf` `.glb` | Three.js Loader로 직접 씬 로드 |
| `.jpg` `.jpeg` `.png` `.bmp` `.webp` `.svg` | 이미지 벽 감지 파이프라인 실행 후 3D 씬 생성 |

## 4. 좌측 설정 패널

### 4-1. 3D 옵션

| 슬라이더 | 설명 | 기본값 |
|---------|------|--------|
| **벽 높이 (Wall Height)** | 생성되는 벽의 높이(m) | 2.5 m |
| **벽 두께 (Wall Thickness)** | 생성되는 벽의 두께(m) | 0.2 m |

토글 버튼:

| 토글 | 설명 |
|------|------|
| **바닥 (Floor)** | 바닥 평면 On/Off |
| **천장 (Ceiling)** | 천장 평면 On/Off |
| **와이어프레임 (Wireframe)** | 와이어프레임 렌더 On/Off |

### 4-2. 이미지 분석 파라미터 (이미지 파일 전용)

이미지 평면도 파일을 열었을 때만 표시됩니다.  
Sobel 에지 감지 및 Hough 변환에 사용하는 파라미터입니다.

| 파라미터 | 설명 |
|---------|------|
| **에지 임계값 (Edge Threshold)** | Sobel 강도 임계값. 낮으면 더 많은 선분 감지 |
| **최소 선분 길이** | Hough 변환 최소 선분 픽셀 길이 |
| **선분 병합 간격** | 가까운 선분을 병합하는 최대 픽셀 간격 |

**[분석 실행]** 버튼을 눌러 변경된 파라미터로 재분석합니다.

## 5. 조명 제어 패널

툴바의 **조명(💡)** 버튼으로 패널을 표시/숨김합니다.

패널 상단 헤더를 **마우스로 드래그**하면 화면 내 원하는 위치로 이동할 수 있습니다.

### 조명 슬라이더

| 항목 | 범위 | 설명 |
|------|------|------|
| **환경광 (Ambient)** | 0 – 2 | 전체적인 기본 밝기 |
| **태양광 (Sun)** | 0 – 4 | 방향성 주광원 세기 |
| **보조광 (Fill)** | 0 – 2 | 그림자 완화용 보조 광원 세기 |

### 색상 선택기

| 항목 | 설명 |
|------|------|
| **Sun Color** | 태양광 색상 (기본: 따뜻한 흰색 `#fff8e1`) |
| **Ambient Color** | 환경광 색상 (기본: 흰색 `#ffffff`) |

### 위치 기즈모 (Position Gizmo)

**Position Gizmo** 토글 버튼으로 태양 위치 조정 핸들을 On/Off합니다.

- **ON**: 3D 씬 안에 금색 구체(Gizmo)가 표시됩니다. 이 구체를 드래그하면 태양광의 방향이 바뀝니다.
- **OFF**: 기즈모가 숨겨지고 현재 태양 위치가 유지됩니다.

**[초기화]** 버튼: 모든 조명 설정을 기본값으로 되돌립니다.

## 6. 레이어 패널

DXF 또는 IFC 파일을 열면 우측 또는 하단 레이어 패널에 레이어 목록이 표시됩니다.

- 각 레이어 옆 **눈 아이콘(👁)**을 클릭해 레이어를 표시/숨김합니다.
- 레이어를 숨기면 해당 레이어의 모든 벽 메시가 즉시 사라집니다.

## 8. AI 모델 관리자

툴바의 **AI 모델** 버튼을 클릭하면 열립니다.

### 브라우저 ONNX 모델 (인터넷 연결 필요, 최초 1회 다운로드)

| 모델 | 크기 | 특징 |
|------|------|------|
| **Depth Anything V2 Small** | 99 MB | DINOv2 기반, 518×518 입력, 고품질 깊이 맵 |
| **MiDaS v2.1 Small** | 66 MB | 256×256 입력, 경량 빠른 추론 |

**사용법:**
1. 원하는 모델의 **[다운로드]** 버튼 클릭 → 진행률 표시
2. 다운로드 완료 후 **[불러오기(Load)]** 버튼 클릭
3. 이미지 파일 열기 → 좌측 패널에서 AI 추론 실행

> 다운로드된 모델은 브라우저 **IndexedDB**에 저장되어 앱 재시작 후에도 재다운로드 없이 사용 가능합니다.

### Python 서버 모델 (GPU 지원)

| 모델 | 크기 | 특징 |
|------|------|------|
| **Depth Anything V2 Base** | 390 MB | 고정밀, CUDA GPU 지원, Python 서버 필요 |

**사전 조건:** [README.md](README.md)의 AI Python 서버 설정 참고

서버가 실행 중이면 모델 관리자에서 **서버 연결됨** 상태가 표시되고, 다운로드·로드·추론 버튼이 활성화됩니다.

## 9. 슬라이더 범위 설정

툴바의 **설정(⚙)** 버튼으로 열립니다.

좌측 설정 패널 슬라이더의 최솟값·최댓값 범위를 조정합니다.

| 항목 | 기본 범위 | 허용 범위 |
|------|-----------|-----------|
| **벽 높이 최솟값** | 0 m | 0 이상 |
| **벽 높이 최댓값** | 6 m | 0 초과 ~ 30 이하 |
| **벽 두께 최솟값** | 0 m | 0 이상 |
| **벽 두께 최댓값** | 1.0 m | 0 초과 ~ 2 이하 |

각 입력란 좌우의 **‹** / **›** 버튼으로 0.1 m씩 조정하거나, 숫자를 직접 입력할 수 있습니다.

- **[기본값으로 초기화]**: 모든 범위를 기본값으로 되돌림
- **[적용]**: 변경된 범위를 즉시 적용
- **[취소]**: 변경 사항을 버리고 닫기

## 11. 스크린샷 저장

툴바의 **스크린샷** 버튼을 클릭하면 현재 3D 뷰포트가 PNG 파일로 저장됩니다.

- **Electron(데스크톱)**: 저장 위치를 선택하는 파일 저장 대화상자가 열립니다.
- **브라우저**: 파일이 자동으로 다운로드 폴더에 저장됩니다.
- 파일 이름 형식: `screenshot_YYYY-MM-DD_HH-MM-SS.png`
