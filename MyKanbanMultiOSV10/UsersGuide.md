## 시작하기

앱 실행 후 브라우저에서 `http://localhost:3000` 에 접속하거나, Electron 앱을 실행합니다.

**초기 관리자 계정**
- 아이디: `admin`
- 비밀번호: `admin`

> 첫 로그인 후 반드시 비밀번호를 변경하세요. (설정 → 비밀번호 변경)

---

## 로그인 및 계정

### 로그인
아이디와 비밀번호를 입력하고 **로그인** 버튼을 클릭합니다.

### 계정 등록 요청
1. 로그인 화면 하단의 **계정 등록 요청** 클릭
2. 아이디, 비밀번호, 이름, 이메일 입력 후 제출
3. 관리자가 승인하면 로그인 가능

### 비밀번호 변경
헤더의 ⚙ (설정) → **비밀번호 변경** 섹션에서 현재 비밀번호와 새 비밀번호를 입력합니다.

### 언어 전환
헤더의 **한 / EN** 버튼을 클릭하면 한국어↔영어가 즉시 전환됩니다.

### 테마 전환
헤더의 **☽ / ☀** 버튼을 클릭하면 라이트↔다크 테마가 전환됩니다.

## 프로젝트 관리

### 새 프로젝트 만들기
1. 상단 **+ 새 프로젝트** 버튼 클릭
2. 프로젝트 이름과 설명 입력
3. **만들기** 클릭 → 기본 컬럼(할 일 / 진행 중 / 완료)이 자동 생성됩니다

### 프로젝트 목록
- 내가 생성한 프로젝트와 멤버로 참여한 프로젝트가 모두 표시됩니다
- 각 카드에 나의 권한(소유자/관리자/편집자/뷰어)이 배지로 표시됩니다

### 프로젝트 수정/삭제
- 프로젝트 카드 우상단의 ✏ (편집) 또는 🗑 (삭제) 버튼을 사용합니다
- 삭제는 소유자와 시스템 관리자만 가능합니다

## 칸반 보드 사용

### 컬럼 관리
- **컬럼 추가**: 보드 우측의 **+ 컬럼 추가** 버튼 또는 빈 공간 클릭
- **컬럼 이름 변경**: 컬럼 헤더 더블클릭 또는 ⋮ 메뉴 → 이름 변경
- **컬럼 삭제**: 컬럼 헤더의 ⋮ 메뉴 → 컬럼 삭제 (포함된 카드도 함께 삭제됩니다)

### 카드 이동 (드래그 앤 드롭)
카드를 다른 컬럼이나 같은 컬럼 내 다른 위치로 드래그해서 이동할 수 있습니다.

---

## 카드 관리

### 카드 추가
컬럼 하단의 **+ 카드 추가** 버튼을 클릭합니다.

| 필드 | 설명 |
|------|------|
| 제목 | 카드 이름 (필수) |
| 설명 | 상세 내용 |
| 담당자 | 프로젝트 멤버 중 선택 |
| 마감일 | 날짜 선택 |
| 카드 배경색 | 8가지 색상 중 선택 |

### 카드 색상
카드에 색상을 지정하면 컬럼 내에서 카드 왼쪽에 색상 바가 표시됩니다.
- 파랑, 초록, 노랑, 주황, 빨강, 보라, 분홍, 청록

### 마감일 표시
- **빨강**: 기한이 지난 카드 (overdue)
- **주황**: 3일 이내 마감
- **정상**: 여유 있는 마감

### 파일 첨부
카드 편집 모달에서 **파일 첨부** 버튼으로 여러 파일을 첨부할 수 있습니다. (최대 20MB/파일)

## 멤버 관리

### 멤버 추가
보드 우측 상단 **👤 멤버** 버튼 → **멤버 추가** 섹션에서 사용자를 선택하고 권한을 지정합니다.

### 권한 종류

| 권한 | 카드 보기 | 카드 편집 | 멤버 관리 | 프로젝트 삭제 |
|------|-----------|-----------|-----------|---------------|
| 시스템 관리자 | ✓ | ✓ | ✓ | ✓ |
| 소유자 | ✓ | ✓ | ✓ | ✓ |
| 프로젝트 관리자 | ✓ | ✓ | ✓ | ✗ |
| 편집자 | ✓ | ✓ | ✗ | ✗ |
| 뷰어 | ✓ | ✗ | ✗ | ✗ |

### 멤버 권한 변경
멤버 목록에서 각 멤버의 권한 드롭다운을 변경하면 즉시 적용됩니다.

## 프로젝트 요약

보드 우측 상단 **요약** 버튼을 클릭하면 Summary 화면이 표시됩니다.

### 통계 카드
- **전체 카드**: 프로젝트 내 총 카드 수
- **완료된 카드**: 마지막 컬럼의 카드 수
- **기한 초과**: 마감일이 지난 미완료 카드 수
- **완료율**: 완료/전체 백분율

### 컬럼별 분포
각 컬럼의 카드 수를 막대 그래프로 표시합니다.

### 번다운 차트 (최근 30일)
- **파란 영역**: 남은 카드 수 (생성 누계 - 완료 누계)
- **노란 점선**: 일별 생성된 카드 수
- **초록 점선**: 일별 완료된 카드 수

## 사용자 관리

> 시스템 관리자(`admin`)만 접근 가능합니다. 헤더의 👤 버튼을 클릭합니다.

### 전체 사용자 탭
- 모든 사용자의 목록, 권한, 상태 확인
- **편집**: 이름, 이메일, 권한, 상태, 비밀번호 변경 가능
- **삭제**: 사용자 계정 삭제

### 승인 대기 탭
등록 요청을 한 사용자 목록이 표시됩니다.
- **승인**: 계정을 활성화하여 로그인 허용
- **거부**: 요청을 삭제

### 새 사용자 직접 추가
**+ 사용자 추가** 버튼으로 관리자가 직접 계정을 생성할 수 있습니다.

## 환경 설정

헤더의 ⚙ 버튼 → 설정 화면

### 데이터베이스 설정 (관리자 전용)
현재 연결된 DB 정보를 표시하며, 다른 DB로 전환할 수 있습니다.

1. DB 유형 버튼 클릭 (SQLite3 / MariaDB / MySQL / PostgreSQL / MS SQL)
2. 연결 정보 입력 (호스트, 포트, DB명, 사용자, 비밀번호)
3. **연결 테스트** → 성공 확인
4. **적용** 클릭

> ⚠ DB를 변경해도 기존 데이터는 자동으로 이전되지 않습니다.

### SQLite 초기화
현재 어떤 DB를 사용하든 SQLite3 기본 설정으로 되돌립니다.

### 내 프로필
표시 이름과 이메일을 변경할 수 있습니다.
