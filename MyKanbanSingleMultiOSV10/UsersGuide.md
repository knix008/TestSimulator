## 시작하기

앱 실행 후 브라우저에서 `http://localhost:3000` 에 접속하거나, Electron 앱을 실행합니다. 로그인 화면 없이 프로젝트 목록이 바로 열립니다.

표시 이름은 **설정 → 내 프로필**에서 변경할 수 있습니다.

### 샘플 프로젝트 열기
처음 사용 시 **파일 → 샘플 열기** 메뉴(Electron) 또는 보드 목록 화면의 샘플 버튼을 클릭하면 `sample.kprj`를 불러올 수 있습니다.

---

## 계정

이 앱은 단일 사용자용입니다. 실행하면 로컬 계정으로 바로 작업할 수 있으며, 로그인·로그아웃·비밀번호는 사용하지 않습니다.

### 프로필
헤더의 ⚙ (설정) → **내 프로필**에서 표시 이름과 이메일을 수정합니다. 변경 내용은 자동 저장됩니다.

### 언어 전환
헤더의 **한 / EN** 버튼을 클릭하면 한국어↔영어가 즉시 전환됩니다.

### 테마 전환
헤더의 **☽ / ☀** 버튼을 클릭하면 라이트↔다크 테마가 전환됩니다.

## 프로젝트 관리

### 새 프로젝트 만들기
1. 상단 **+ 새 프로젝트** 버튼 클릭
2. 프로젝트 이름과 설명 입력
3. **만들기** 클릭 → 기본 컬럼(할 일 / 진행 중 / 완료)이 자동 생성됩니다

### 프로젝트 목록
- 내가 생성한 프로젝트와 멤버로 참여한 프로젝트가 모두 표시됩니다
- 각 카드에 나의 권한(소유자/관리자/편집자/뷰어)이 배지로 표시됩니다

### 프로젝트 수정/삭제
- 프로젝트 카드 우상단의 ✏ (편집) 또는 🗑 (삭제) 버튼을 사용합니다
- 삭제는 소유자와 시스템 관리자만 가능합니다

### 프로젝트 내보내기 / 가져오기 (.kprj)
- **내보내기**: 보드 화면 상단 내보내기 버튼 또는 파일 메뉴 → `.kprj` 파일로 저장
- **가져오기**: 파일 메뉴 → **프로젝트 열기** 또는 `.kprj` 파일을 드래그앤드롭

## 칸반 보드 사용

### 컬럼 관리
- **컬럼 추가**: 보드 우측의 **+ 컬럼 추가** 버튼
- **컬럼 이름 변경**: 컬럼 헤더 더블클릭 또는 우클릭 메뉴 → 이름 변경
- **컬럼 삭제**: 우클릭 메뉴 → 컬럼 삭제 (포함된 카드도 함께 삭제됩니다)
- **컬럼 배경색**: 우클릭 메뉴 → 🎨 컬럼 배경색

### 컬럼 배경색 설정
컬럼을 우클릭하여 **🎨 컬럼 배경색** 메뉴를 선택합니다.

- 미리 정의된 **20가지 색상** 중 선택하거나
- **직접 입력**: 네이티브 색상 선택기(🎨) 또는 HEX 코드 입력(`#RRGGBB`)
- **없음(✕)** 을 선택하면 색상이 제거됩니다
- 배경색은 라이트/다크 테마 모두에서 자연스럽게 표시됩니다 (18% 불투명도)

### 카드 이동 (드래그 앤 드롭)
- 카드를 잡고 다른 컬럼으로 드래그합니다
- 컬럼 전체가 드롭 영역이므로 빈 공간 어디에나 놓을 수 있습니다
- 파란색 선 인디케이터가 카드가 삽입될 위치를 표시합니다
- 같은 컬럼 안에서 순서를 변경할 수도 있습니다

### 컨텍스트 메뉴 (우클릭)
| 위치 | 메뉴 항목 |
|------|-----------|
| 보드 빈 공간 | 새 카드 추가, 컬럼 추가, 새로고침 |
| 컬럼 헤더/영역 | 이름 변경, 배경색 설정, 컬럼 삭제 |
| 카드 | 카드 편집, 카드 삭제 |

## 카드 관리

### 카드 추가
컬럼 하단의 **+ 카드 추가** 버튼을 클릭합니다.

| 필드 | 설명 |
|------|------|
| 제목 | 카드 이름 (필수) |
| 설명 | 상세 내용 |
| 담당자 | 프로젝트 멤버 중 선택 |
| 마감일 | 날짜 선택 |
| 카드 배경색 | 20가지 프리셋 + 사용자 정의 색상 |

### 카드 배경색
카드에 배경색을 지정하면 카드 전체 배경에 색상이 적용됩니다.

- **20가지 프리셋**: 동일한 20가지 색상 팔레트 제공
- **직접 입력**: 네이티브 색상 선택기(🎨) 또는 HEX 코드 입력(`#RRGGBB`)
- **없음(✕)**: 기본 배경색 사용
- 색상은 테마에 맞게 반투명(25% 불투명도)으로 적용됩니다

### 마감일 표시
- **빨강**: 기한이 지난 카드 (overdue)
- **주황**: 3일 이내 마감
- **정상**: 여유 있는 마감

### 파일 첨부
카드 편집 모달에서 **파일 첨부** 버튼으로 여러 파일을 첨부할 수 있습니다. (최대 20MB/파일)

- 첨부된 파일 목록에서 파일명을 **더블클릭**하면 시스템에 등록된 기본 앱으로 파일이 열립니다
- 웹 브라우저 모드에서는 새 탭에서 파일이 열립니다
- 🗑 아이콘을 클릭하면 첨부파일을 삭제할 수 있습니다

### 자동 저장
카드 편집 모달에서 내용을 수정하면 잠시 후 자동으로 저장됩니다. 상태바에서 저장 상태를 확인할 수 있습니다.

## 멤버 관리

### 멤버 추가
보드 우측 상단 **👤 멤버** 버튼 → **멤버 추가** 섹션에서 사용자를 선택하고 권한을 지정합니다.

### 권한 종류

| 권한 | 카드 보기 | 카드 편집 | 멤버 관리 | 프로젝트 삭제 |
|------|-----------|-----------|-----------|---------------|
| 시스템 관리자 | ✓ | ✓ | ✓ | ✓ |
| 소유자 | ✓ | ✓ | ✓ | ✓ |
| 프로젝트 관리자 | ✓ | ✓ | ✓ | ✗ |
| 편집자 | ✓ | ✓ | ✗ | ✗ |
| 뷰어 | ✓ | ✗ | ✗ | ✗ |

### 멤버 권한 변경
멤버 목록에서 각 멤버의 권한 드롭다운을 변경하면 즉시 적용됩니다.

## 프로젝트 요약

보드 우측 상단 **요약** 버튼을 클릭하면 Summary 화면이 표시됩니다.

### 통계 카드
- **전체 카드**: 프로젝트 내 총 카드 수
- **완료된 카드**: 마지막 컬럼의 카드 수
- **기한 초과**: 마감일이 지난 미완료 카드 수
- **완료율**: 완료/전체 백분율

### 컬럼별 분포
각 컬럼의 카드 수를 막대 그래프로 표시합니다.

### 번다운 차트 (최근 30일)
- **파란 영역**: 남은 카드 수 (생성 누계 - 완료 누계)
- **노란 점선**: 일별 생성된 카드 수
- **초록 점선**: 일별 완료된 카드 수

## Undo / Redo

편집 내용을 취소하거나 다시 실행할 수 있습니다.

### 단축키
| 동작 | Windows/Linux | macOS |
|------|--------------|-------|
| 실행 취소 | `Ctrl+Z` | `Cmd+Z` |
| 다시 실행 | `Ctrl+Y` 또는 `Ctrl+Shift+Z` | `Cmd+Y` 또는 `Cmd+Shift+Z` |

상단 메뉴바의 **편집 → 실행 취소 / 다시 실행** 버튼으로도 사용할 수 있습니다.

### 지원 동작
- 카드 생성 / 수정 / 삭제
- 카드 이동 (컬럼 간, 순서 변경)
- 컬럼 추가 / 이름 변경 / 삭제
- 컬럼 배경색 변경
- 프로젝트 이름/설명 수정

> 보드를 전환하면 undo/redo 스택이 초기화됩니다.

## 환경 설정

헤더의 ⚙ 버튼 → 설정 화면

### 일반
- **표시 이름**: 헤더와 댓글에 보이는 이름입니다. 입력하면 자동으로 저장됩니다.
- **컬럼 추가 버튼 표시**: 보드에서 컬럼 추가 버튼을 켜거나 끕니다.

### 데이터베이스
현재 연결이 표시됩니다. 다른 데이터베이스로 바꾸면 프로젝트 데이터가 함께 옮겨집니다.

1. 데이터베이스 종류를 선택합니다. (SQLite3 / MariaDB / MySQL / PostgreSQL / MS SQL)
2. 필요한 연결 정보를 입력합니다.
3. **연결 테스트**로 확인한 뒤 **적용**을 누릅니다.

**SQLite 초기화**는 기본 SQLite 파일로 되돌립니다.
