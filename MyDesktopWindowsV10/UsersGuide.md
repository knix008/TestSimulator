# MyDesktop 사용 안내

바탕화면이 아이콘으로 뒤덮여 있을 때, 그것들을 **펜스**라고 부르는 반투명 판에 묶어 두는
프로그램입니다. 배경화면 위에 얹힌 판 위로 아이콘이 모이고, 모든 앱 창 아래에 있으므로 작업을
가리지 않습니다.

가장 먼저 알아 두면 좋은 것: **MyDesktop은 파일을 옮기지도 지우지도 않습니다.** 항목을 펜스에
넣는다는 건 그것을 바탕화면 대신 펜스에 그린다는 뜻일 뿐입니다. 파일은 계속
`C:\Users\<사용자>\Desktop`에 있고 탐색기에서도 그대로 보입니다.

---

## 설치

`MyDesktop-win-x64.msi`를 더블클릭합니다.

- 기계 전체에 설치되므로 관리자 권한을 한 번 묻습니다.
- `C:\Program Files\MyDesktop`에 깔리고 시작 메뉴에 **MyDesktop** 바로 가기가 생깁니다.
- 별도의 런타임을 깔 필요가 없습니다. 필요한 .NET을 설치 파일이 함께 들고 있습니다.
- 이미 깔려 있으면 **예전 설치를 먼저 걷어내고** 새로 깝니다. 프로그램 폴더에 옛 파일이 남지
  않습니다. 펜스 배치는 그대로 남습니다(아래 네 번째 항목을 켜지 않는 한).
- MyDesktop이 실행 중이면 설치가 알아서 정상 종료시킵니다. 바탕화면 아이콘이 꺼진 채 남지
  않도록 강제로 끝내지 않고 프로그램 자신의 종료 절차를 거칩니다.

설치 중 구성 요소 선택 화면에서 네 가지를 켜고 끌 수 있습니다(설치 화면은 영어입니다).

| 설치 화면의 항목 | 기본값 | 하는 일 |
| --- | --- | --- |
| **Start Menu shortcut** | 켜짐 | 시작 메뉴에 MyDesktop을 넣습니다 |
| **Desktop shortcut** | 꺼짐 | 바탕화면에 바로 가기를 놓습니다 (바탕화면을 비우는 프로그램이라 기본은 꺼짐) |
| **Start with Windows** | 켜짐 | 로그인하면 MyDesktop이 스스로 뜹니다 |
| **Start with an empty layout** | 꺼짐 | 이 PC에 저장된 펜스와 설정을 치우고 처음 쓰는 것처럼 시작합니다. **지우지는 않습니다** — 기존 배치는 `fences.json.before-reset.bak`으로 남으므로, 실수로 켰다면 그 파일의 이름을 `fences.json`으로 되돌리면 그대로 돌아옵니다 |

> 네 번째 항목은 계정마다 적용됩니다. 이 PC의 다른 계정은 각자 MyDesktop을 처음 띄울 때
> 자기 배치가 치워집니다.

마지막 화면의 **Start MyDesktop now**도 기본으로 켜져 있습니다. 설치가 끝나면 바로 실행되어
트레이 아이콘이 나타나고, 이때 위에서 고른 자동 실행이 이 계정의 시작 프로그램으로 등록됩니다.
자동 실행은 나중에 트레이 메뉴나 설정 창의 **Windows 시작 시 실행**로 언제든 켜고 끌 수 있으며,
관리자 권한이 필요 없습니다.

> 자동 실행은 계정별로 등록됩니다. 설치할 때 켜 두면 이 PC를 쓰는 다른 계정에서도 MyDesktop을
> 처음 실행하는 순간 똑같이 등록됩니다.

제거는 **설정 ▸ 앱 ▸ 설치된 앱**에서 합니다. 제거해도 펜스 배치 파일은 남으므로, 다시 깔면 쓰던
모습 그대로 돌아옵니다.

> 프로그램을 지운 뒤 바탕화면 아이콘이 보이지 않는다면, 바탕화면을 우클릭해
> **보기 ▸ 바탕 화면 아이콘 표시**를 켜면 됩니다. 아래 [문제가 생겼을 때](#문제가-생겼을-때)를
> 보십시오.

## 처음 실행하면

창이 뜨지 않습니다. MyDesktop은 **트레이 앱**입니다. 알림 영역(시계 옆)에 아이콘이 생깁니다.

- 아이콘 **우클릭** → 전체 메뉴
- 아이콘 **더블클릭** → 설정 창

> Windows 11은 새로 생긴 트레이 아이콘을 처음에는 **숨은 아이콘**(작업 표시줄의 `^`) 안에
> 넣어 둡니다. 거기서 아이콘을 작업 표시줄로 끌어다 놓으면 항상 보입니다.

로그인하면서 MyDesktop이 탐색기보다 먼저 뜰 수도 있는데, 그때는 알림 영역이 아직 없습니다.
MyDesktop은 영역이 생길 때까지 기다렸다가 아이콘을 올리고, 탐색기가 다시 시작되어도 아이콘을
다시 올립니다.

처음 실행할 때 바탕화면 내용을 훑어 **Programs / Folders / Documents** 세 펜스로 나눠 담습니다.
마음에 들지 않으면 펜스 이름을 바꾸거나, 항목을 끌어 옮기거나, 펜스를 지우면 됩니다.

## 바탕화면에서 쓰는 제스처

| 동작 | 결과 |
| --- | --- |
| 빈 바탕화면에서 **오른쪽 버튼으로 드래그** | 그린 사각형이 새 펜스가 되고 바로 이름을 입력할 수 있습니다 |
| 빈 바탕화면 **더블클릭** | 모든 펜스가 사라졌다가, 한 번 더 하면 돌아옵니다 |
| 빈 바탕화면 **오른쪽 클릭** | 평소의 Windows 바탕화면 메뉴가 그대로 뜹니다 |
| 빈 바탕화면에서 **왼쪽 버튼으로 드래그** | 사각형에 닿은 아이콘이 전부 선택됩니다. `Ctrl`을 누른 채 끌면 이미 고른 것에 더합니다 |
| 아이콘 **오른쪽 클릭** | 그 항목에 대한 **Windows 메뉴 그대로**입니다. 여러 개를 골라 두었다면 선택한 전부가 대상입니다 |
| 아이콘 **더블클릭** / 끌기 | 탐색기에서와 같습니다 — 열기, 그리고 원하는 자리로 옮기기 |
| 여러 개를 고른 뒤 그중 하나를 **끌기** | 고른 것이 **전부 함께** 움직이고, 서로의 간격도 그대로 유지됩니다. 펜스 안이든 바탕화면이든 같습니다 |

처음 세 가지는 트레이 메뉴에서 끌 수 있습니다(**바탕화면 우클릭 드래그로 펜스 만들기**,
**바탕화면 더블클릭으로 펜스 숨기기**).

> 선택과 메뉴는 아이콘 **칸 전체**가 받습니다. 그림이나 글자를 정확히 맞출 필요 없이, 아이콘이
> 차지한 네모 안 어디를 눌러도 같게 동작합니다.

## 펜스 다루기

### 옮기기와 크기 조절

제목 표시줄을 끌면 펜스가 움직이고, 가장자리와 모서리를 끌면 크기가 바뀝니다. 격자와 화면
가장자리, 그리고 다른 펜스에 자석처럼 붙습니다. 붙는 동작은 설정에서 끌 수 있습니다.

### 말아 올리기

제목 표시줄을 **더블클릭**하거나 오른쪽 위 **▲** 버튼을 누르면 제목만 남기고 접힙니다. 한 번 더
하면 펴집니다.

### 이름 바꾸기

제목을 우클릭해 **펜스 이름 바꾸기**를 고르거나, 새로 만든 직후 바로 입력하면 됩니다.
Enter로 확정, Esc로 취소합니다.

### 항목 넣고 빼기

- 바탕화면이나 탐색기, 그 밖의 프로그램에서 **끌어다 놓으면** 펜스에 들어갑니다. 파일은 있던
  자리에 그대로 있고, 펜스는 그것을 가리킬 뿐입니다.
- 펜스 안의 **빈 곳에서 드래그**하면 사각형에 닿은 항목이 전부 선택됩니다(바탕화면과 같습니다).
  펜스 가장자리 몇 픽셀은 크기 조절 손잡이이니 조금 안쪽에서 시작하십시오.
- 펜스나 바탕화면에서 **다른 프로그램으로** 끌어다 놓을 수도 있습니다. 받는 쪽은 탐색기에서 끌어온
  것과 똑같이 처리합니다.
- 펜스 안에서 끌면 **순서**가 바뀝니다. 여러 개를 골라 두었다면 고른 것이 전부 함께 갑니다.
- 다른 펜스로 끌면 그쪽으로 **옮겨집니다**. 항목 우클릭 ▸ **펜스로 옮기기**로도 됩니다.
- 펜스 밖 바탕화면으로 끌어내면 펜스에서 빠지고 바탕화면에 다시 나타납니다.
- 항목 우클릭 ▸ **펜스에서 빼기** — 펜스 목록에서만 빼고 **파일은 건드리지 않습니다.**
- 항목 우클릭 ▸ **삭제**(또는 `Delete` 키) — **파일을 휴지통으로 보냅니다.** 되돌릴 수 있지만,
  위의 "펜스에서 빼기"와는 전혀 다른 동작입니다.

### 항목 우클릭 메뉴

펜스 안이든 MyDesktop이 그린 바탕화면이든, 항목을 우클릭하면 **Windows 바탕화면이 그 항목에
보여주는 메뉴 그대로** 나옵니다 — 열기, 연결 프로그램, 보내기, 잘라내기, 복사, 삭제, 이름 바꾸기,
속성은 물론 압축 프로그램·편집기·백신처럼 다른 프로그램이 설치한 항목까지 전부 들어 있습니다.
셸에게 메뉴를 받아 그대로 띄우므로 고른 명령은 탐색기에서 고를 때와 똑같이 동작합니다.

맨 아래에 MyDesktop 자신의 항목이 구분선 뒤에 붙습니다.

| 위치 | 붙는 항목 |
| --- | --- |
| 펜스 안 | 펜스로 옮기기 · 펜스에서 빼기 · 아이콘 새로 고침 |
| 바탕화면 | 펜스에 넣기 · 여기에 새 펜스 · MyDesktop 설정… |

**여러 개를 골라 두고** 그중 하나를 우클릭하면 메뉴는 선택한 전부에 적용됩니다 — 한꺼번에
압축하거나 복사하거나 휴지통으로 보낼 수 있고, 이것도 탐색기와 같습니다. 선택한 항목들이 서로
다른 폴더에서 왔다면(예: 휴지통 같은 시스템 항목과 파일을 함께 고른 경우) 공통 폴더에 속한
것들만 대상이 됩니다. 엉뚱한 폴더에 명령이 실행되지 않게 하기 위해서입니다.

### 외형

펜스를 우클릭하면 나오는 메뉴에서 바꿉니다.

| 메뉴 | 하는 일 |
| --- | --- |
| **정렬 기준** | 직접 정한 순서 / 이름 / 종류 / 수정한 날짜. 이름 정렬은 탐색기와 같은 규칙이라 `파일2`가 `파일10`보다 앞에 옵니다 |
| **아이콘 크기** | 작게 · 보통 · 크게 · 아주 크게 |
| **이름 표시** | 아이콘 밑 글자를 켜고 끕니다 |
| **펜스 색** · **강조색** | 판 색과 제목·테두리 강조색. 각각 **20가지**가 준비돼 있고, 맨 아래 **사용자 지정 색…**을 고르면 Windows 색 선택 창이 열려 어떤 색이든 쓸 수 있습니다(투명도는 그대로 유지됩니다). 설정 창에서도 같은 20가지와 **Custom…** 단추를 씁니다 |
| **투명도** | 불투명부터 거의 투명까지 다섯 단계 |

## 폴더 포털

펜스를 폴더에 **연결**하면, 그 폴더의 내용이 펜스에 실시간으로 비칩니다. 폴더에 파일이 생기면
펜스에도 바로 나타나고, 지우면 사라집니다.

- 만들기: 트레이 메뉴 ▸ **새 폴더 포털…**, 또는 펜스 우클릭 ▸ **폴더 포털로 만들기…**
- 다른 폴더로 바꾸기: 펜스 우클릭 ▸ **다른 폴더로 바꾸기…**
- 평범한 펜스로 되돌리기: 펜스 우클릭 ▸ **폴더 연결 끊기**
- 숨김 파일도 보려면: 펜스 우클릭 ▸ **숨김 항목 표시**

포털 펜스에 탐색기에서 파일을 끌어다 놓으면 탐색기와 같은 규칙을 따릅니다 — 같은 드라이브면
이동, 다른 드라이브면 복사입니다.

## "MyDesktop이 바탕화면을 그림"

기본으로 켜져 있는 설정이고, 이게 **펜스에 넣은 항목이 바탕화면에서 사라지는 이유**입니다.

켜져 있으면 MyDesktop은 Windows의 바탕화면 아이콘 표시를 끄고, 휴지통과 **어느 펜스에도 들어
있지 않은** 항목들을 직접 그립니다. 그래서 펜스에 담은 항목이 배경화면에 겹쳐 보이지 않습니다.
파일 자체는 Desktop 폴더에 그대로 있으므로 탐색기에서는 계속 보입니다.

끄면 바탕화면을 다시 Windows에 넘깁니다. 그러면 펜스 안의 항목이 바탕화면에도 **같이** 보이게
됩니다. 판만 얹고 싶고 중복은 개의치 않는다면 그렇게 써도 됩니다.

## 설정 창

트레이 아이콘을 더블클릭하면 열립니다. 메뉴로 하는 일을 한자리에서 할 수 있고, 몇 가지는
여기서만 됩니다.

- 왼쪽 목록에서 펜스를 고르면 오른쪽에 그 펜스의 모든 설정이 나옵니다.
- **불투명도**와 **아이콘 크기**를 슬라이더로 미세하게 맞출 수 있습니다.
- **항목 추가** · **폴더 추가** — 끌어다 놓는 대신 파일 선택 대화상자로 고릅니다.
- **바탕화면에 표시** — 숨기거나 말아 둔 펜스를 다시 꺼냅니다.
- **격자** 크기와 자석처럼 붙는 동작을 조절합니다.

바꾼 내용은 즉시 적용되고 저장됩니다. 확인 버튼이 없습니다.

| 파일 | 내용 |
| --- | --- |
| `fences.json` | 펜스와 그 안의 항목, 위치, 색, 그리고 모든 설정 |
| `fences.json.before-reset.bak` | 설치할 때 **Start with an empty layout**을 켠 적이 있다면, 그때 치워 둔 예전 배치입니다. 되돌리려면 이 파일의 이름을 `fences.json`으로 바꾸고 MyDesktop을 다시 시작하면 됩니다 |
| `diagnostics.log` | 제스처 기록. 문제를 알릴 때 첨부하면 도움이 됩니다 |

이 폴더를 통째로 복사해 두면 다른 기계에서 같은 배치를 그대로 쓸 수 있습니다. 다만 파일 경로가
그대로 들어 있으므로, 사용자 이름이나 드라이브가 다르면 일부 항목이 비어 보일 수 있습니다.

## 문제가 생겼을 때

### 바탕화면 아이콘이 전부 사라졌습니다

MyDesktop이 Windows의 아이콘 표시를 끈 채로 비정상 종료된 경우입니다. 정상 종료할 때는 반드시
되돌려 놓지만, 강제 종료는 그 과정을 건너뜁니다.

바탕화면을 우클릭해 **보기 ▸ 바탕 화면 아이콘 표시**를 켜면 즉시 돌아옵니다. 아이콘 배치도
그대로입니다.

### 펜스가 다른 창 뒤로 숨습니다

정상입니다. 펜스는 일부러 모든 앱 창 **아래**에 있습니다. 보려면 창을 최소화하거나
`Win`+`D`를 누르면 됩니다.

### 펜스가 아예 보이지 않습니다

- 빈 바탕화면을 더블클릭해 보십시오. 빠른 숨김이 켜진 상태일 수 있습니다.
- 트레이 메뉴에서 **모든 펜스 숨기기**가 눌려 있는지 확인하십시오.
- 설정 창에서 펜스를 고른 뒤 **바탕화면에 표시**를 누르면 확실히 꺼냅니다.

### 오른쪽 드래그로 펜스가 만들어지지 않습니다

- 트레이 메뉴에서 **바탕화면 우클릭 드래그로 펜스 만들기**가 켜져 있어야 합니다.
- **빈** 바탕화면에서 시작해야 합니다. 아이콘이나 펜스 위에서 시작하면 그쪽 메뉴가 뜹니다.
- 너무 작게 그리면 무시합니다. 손가락 두 마디 정도는 끌어야 합니다.

### 설치했는데 고쳐졌다던 것이 그대로입니다

**설정 ▸ 앱 ▸ 설치된 앱**에서 MyDesktop의 버전을 확인하십시오. `1.0.0`이면 예전 설치가 남아 있는
것입니다. 한동안 모든 빌드가 같은 버전을 달고 나왔고, Windows는 버전이 같으면 파일을 바꾸지
않습니다 — 설치는 성공했다고 말하면서 옛 프로그램을 그대로 둡니다.

지금 설치 파일은 빌드할 때마다 버전이 올라가므로 이 일이 생기지 않습니다. 그래도 의심스러우면
제어판에서 MyDesktop을 제거한 뒤 다시 설치하십시오. 펜스 배치는 제거해도 남습니다.

### 아이콘을 우클릭했는데 바탕화면 메뉴가 뜹니다

압축·복사·삭제 대신 **여기에 새 펜스 · MyDesktop 설정…** 만 보인다면, 클릭이 아이콘이 아니라
그 뒤의 배경화면으로 간 것입니다. 예전 빌드에서 아이콘 칸의 바깥 2~3px이 클릭을 받지 못해
생기던 증상이고, 지금은 칸 전체가 받습니다.

그래도 같은 일이 생기면 `%LOCALAPPDATA%\MyDesktop\diagnostics.log` 를 함께 보내 주십시오.
우클릭마다 `desktop right-click at ... item=...` 한 줄이 남고, 거기서 MyDesktop이 그 지점에
무엇이 있다고 봤는지 바로 알 수 있습니다.

### 마우스가 멈춘 것 같습니다

`diagnostics.log`를 함께 보내 주십시오. 마우스 훅은 조용히 실패하는 유일한 부분이라 일부러
기록을 남깁니다. 급할 때는 작업 관리자에서 **MyDesktop**을 끝낸 뒤, 위의 방법으로 바탕화면
아이콘을 다시 켜면 됩니다.

### 두 번 실행해도 아무 일이 없습니다

한 번에 하나만 뜨는 프로그램입니다. 이미 떠 있으면 두 번째 실행은 조용히 종료합니다. 트레이
아이콘을 확인하십시오.
