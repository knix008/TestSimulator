# P2P Chat (하이브리드 방식)

WebRTC P2P 및 서버 중계 방식을 지원하는 채팅 애플리케이션입니다. **채팅 내용은 서버에 저장되지 않으며**, 대화 기록은 **각 브라우저의 `localStorage`** 에만 남습니다. 서버는 **방 메타데이터**(이름, ID, 생성 시각, 비밀번호, 최대 인원)와 시그널링/메시지 중계만 담당합니다.

## 주요 기능

- ✅ **하이브리드 연결 방식**: 2명 이하는 P2P, 3명 이상은 서버 중계
- ✅ **비밀번호 보호**: 방 생성 시 선택적으로 비밀번호 설정 가능
- ✅ **유연한 인원 관리**: 방별로 최대 2~20명까지 설정 가능
- ✅ **파일 전송**: 이미지, 동영상, 압축 파일 전송 지원 (최대 10MB)
- ✅ **관리자 화면**: 방 생성/삭제, 실시간 접속 현황 확인
- ✅ **로컬 히스토리**: 브라우저 localStorage에 대화 기록 저장

### 지원 파일 형식

- **이미지**: JPEG, PNG, GIF, WebP, BMP
- **동영상**: MP4, WebM, QuickTime, AVI
- **압축 파일**: ZIP, RAR, 7Z, TAR, GZIP

## 구성

| 경로 | 설명 |
|------|------|
| `server/` | WebSocket 시그널 서버 + 메시지 중계 + **관리용 HTTP GUI** (`/`) |
| `server/admin/` | 관리자 웹 인터페이스 (정적 파일) |
| `client/` | 채팅 웹 클라이언트 (정적 파일 + `serve`) |

## 요구 사항

- Node.js 18 이상 권장 (`crypto.randomUUID`, ES Modules 지원)

## 실행 방법

### 1. 시그널 서버

```bash
cd server
npm install
npm start
```

- 기본 포트: **8787** (`PORT` 환경 변수로 변경 가능)
- **관리 화면:** 브라우저에서 `http://localhost:8787/`  
  방 목록·생성·삭제, 시그널 연결 수 확인
- **WebSocket:** `ws://localhost:8787` (채팅 클라이언트에서 사용)

### 2. 채팅 클라이언트

```bash
cd client
npm start
```

브라우저에서 `http://localhost:3000` 을 연 뒤, 시그널 주소에 `ws://localhost:8787` 을 입력하고 **서버 연결** → 방 만들기 또는 목록에서 **입장**합니다.

- 방 생성 시 **비밀번호**와 **최대 인원**(2~20명)을 설정할 수 있습니다
- 📎 버튼으로 **이미지, 동영상, 압축 파일**을 전송할 수 있습니다 (최대 10MB)
- 전송된 이미지는 바로 표시되며, 동영상은 재생 가능하고, 압축 파일은 다운로드 링크가 생성됩니다

## 사용 방법

1. **서버 연결**: 시그널 서버 주소 입력 후 연결
2. **방 생성/입장**: 
   - 새 방 만들기: 이름, 비밀번호(선택), 최대 인원 설정
   - 기존 방 입장: 목록에서 선택 (🔒 아이콘은 비밀번호 필요)
3. **채팅하기**:
   - 텍스트 메시지 입력 후 전송
   - 📎 버튼으로 파일 전송 (이미지/동영상/압축 파일)
4. **연결 방식**:
   - 2명 이하: P2P 직접 연결 (서버에 메시지 저장 안 됨)
   - 3명 이상: 서버 중계 (실시간 중계만, 저장 안 됨)

## 참고

- 시그널 주소는 **`ws://` 또는 `wss://`** 입니다. `http://` 로 시그널 포트만 열면 `Upgrade Required` 가 나올 수 있습니다.
- 채팅 GUI는 **3000번**(클라이언트 `serve`), 관리 GUI는 **8787번**(서버 HTTP)입니다.
- 관리 페이지에는 기본 **인증이 없습니다**. 외부에 공개할 경우 반드시 접근 제어를 추가하세요.
- **파일 전송 제한**: 10MB 이하, 이미지/동영상/압축 파일만 허용
- **대화 기록**: localStorage에 저장되므로 브라우저를 삭제하면 기록도 사라집니다
