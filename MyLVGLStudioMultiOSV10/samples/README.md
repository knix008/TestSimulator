# Samples

My LVGL Studio의 샘플 프로젝트입니다. `npm run samples`로 생성합니다.

| 폴더 | 내용 | LVGL |
|---|---|---|
| `HomeControl` | 스마트 홈 제어: Arc, 슬라이더, 스위치와 화면 전환 이벤트 | 9.6.0 |
| `LoginForm` | 로그인 입력: Text Area와 연결된 Keyboard | 9.6.0 |
| `DataDashboard` | 데이터 대시보드: Chart, Table, Bar, Arc (800×480) | 9.6.0 |
| `GridLayout` | Grid 레이아웃: Grid로 만든 계산기 자판 | 9.6.0 |
| `ImageGallery` | 이미지 갤러리: Image, Image Button, Animation Image | 9.6.0 |
| `SettingsTabs` | 설정 화면: Tabview, List, Spinbox, Button Matrix | 9.6.0 |
| `ScrollMenu` | 수직 스크롤 메뉴: 화면 아래로 이어지는 메뉴를 끌어서 스크롤 | 9.6.0 |
| `MediaPlayer` | 음악 플레이어: 표지 이미지, 슬라이더, 재생 버튼 이벤트 | 9.6.0 |
| `WeatherStation` | 날씨 스테이션: 큰 글꼴, 선 Chart, 예보 Table | 9.6.0 |
| `CarDashboard` | 자동차 계기판: 아래 슬라이더를 끌면 속도계와 숫자가 함께 움직임 (800×480) | 9.6.0 |
| `FactoryPanel` | 공장 제어 패널: Grid 안의 카드, 상태 Bar, 정지 버튼 | 9.6.0 |
| `CalendarPlanner` | 일정 플래너: Calendar와 일정 List | 9.6.0 |
| `SmartWatch` | 스마트워치: 원형 화면(240×240)의 시계, 링을 끌면 숫자가 바뀜 | 9.6.0 |
| `RoundGauge` | 원형 계기판: 원형 화면(360×360), 슬라이더로 움직이는 링 | 9.6.0 |
| `Thermostat` | 온도 조절기: 원형 화면(360×360), 링을 돌리면 온도와 표시등이 바뀜 | 9.6.0 |
| `FitnessRings` | 운동 링: 원형 화면(466×466), 세 링을 각각 끌기 | 9.6.0 |
| `CompassDial` | 나침반: 원형 화면(360×360), 링을 끌면 바늘 그림이 회전 | 9.6.0 |
| `AudioMixer` | 오디오 믹서: 세로 페이더 6개, 끌면 레벨과 숫자가 움직임 (800×480) | 9.6.0 |
| `BatteryMonitor` | 배터리 모니터: 하나를 끌면 Bar, Arc, LED, 숫자가 함께 움직임 | 9.6.0 |
| `LightDimmer` | 조명 조절: 슬라이더로 LED 밝기 조절 | 9.6.0 |
| `WashingMachine` | 세탁기: Roller로 코스 선택, 시간 끌기, 저절로 도는 드럼 | 9.6.0 |
| `Greenhouse` | 온실 제어: Arc와 슬라이더 연동, 스위치로 LED 켜기 (800×480) | 9.6.0 |
| `LoadingGallery` | 애니메이션 모음: 저절로 움직이는 Arc, Bar, Spinner (800×480) | 9.6.0 |
| `ElevatorPanel` | 엘리베이터 패널: 세로 슬라이더로 층 이동, Grid 버튼으로 호출 | 9.6.0 |
| `AppWindows` | 창과 메뉴: Window, Menu, Tile View, Message Box | 9.6.0 |
| `Typography` | 글자와 그림: Spangroup, Canvas, Line, 글꼴 크기 | 9.6.0 |
| `ModernScale` | LVGL 9 계기판: Scale, Barcode, QR Code, Arc Label | 9.6.0 |
| `LegacyMeter` | LVGL 8 계기판: Meter, Color Wheel (LVGL 8.4) | 8.4.0 |

LVGL 소스는 들어 있지 않습니다. 설계와 실행 화면은 앱에 내장된 엔진으로 동작하고, 네이티브 실행이 필요할 때만 해당 버전을 내려받습니다.
