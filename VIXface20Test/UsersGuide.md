# VixReader Test — 사용자 가이드

Intellivix 리더 장치의 펌웨어를 검사하는 프로그램입니다. 네트워크(Ethernet)로 장치에
**HTTPS**로 연결해 명령을 보내고 결과를 확인합니다. Windows·macOS·Linux 데스크톱과
웹 브라우저에서 동일하게 사용할 수 있습니다.

---

## 1. 설치

### 설치본으로 설치 (권장)
| OS | 파일 | 방법 |
|----|------|------|
| Windows | `VixReader Test Setup x.y.z.exe` | 실행 → 설치 경로 선택 → 설치 |
| macOS | `VixReader Test-x.y.z.dmg` | 열기 → 앱을 Applications 로 드래그 |
| Linux | `VixReader Test-x.y.z.AppImage` | 실행 권한(`chmod +x`) 후 실행, 또는 `.deb` 설치 |

### 개발/소스 실행
```bash
npm install
npm start
```
> Windows에서 창이 뜨지 않으면 `ELECTRON_RUN_AS_NODE` 환경변수를 해제하세요.
> PowerShell: `$env:ELECTRON_RUN_AS_NODE=""` 후 `npm start`.

### 웹으로 사용
```bash
npm run web      # http://localhost:5173
```
브라우저 사용 시 장치가 브라우저가 신뢰하는 HTTPS 인증서와 CORS를 지원해야 합니다.

## 2. 화면 구성

프로그램은 **고정 크기 창**이며 스크롤이 없습니다. 모든 기능이 한 화면에 보입니다.

```
┌───────────────────────────────────────────────────────────────┐
│ [로고] VixReader Test        Ethernet(HTTPS)  IP □  포트 □  [연결]│  ← 상단: 연결 설정
│                              장치타입 ▼  경로 □          [보고서]│
├──────────────────────────────────────────┬────────────────────┤
│ 장치 제어 명령 선택                        │                    │
│  [시리얼 읽기][시리얼 쓰기][설정 지우기]   │                    │
│ 장치 테스트 명령 선택                      │      준 비          │  ← 오른쪽: 결과 표시
│  [펌웨어][MAC][자가진단][LED]...(15개)     │   (대형 상태 표시)  │
│ LED 색상 테스트                            │                    │
│  □빨강 □녹색 □파랑   [설정]                │  대상 / 세션 정보   │
├──────────────────────────────────────────┴────────────────────┤
│ 로그                                                    [지우기]│  ← 하단: 로그
│ [10:13:52] 연결 시도 ...                                        │
└───────────────────────────────────────────────────────────────┘
```

## 3. 장치 연결

1. **Ethernet (HTTPS)** 가 선택돼 있는지 확인합니다. (Serial은 지원하지 않습니다.)
2. **IP 주소**를 장치 주소로 입력합니다. 기본값 `192.168.0.2`.
3. 필요하면 **포트**(기본 `8443`)와 **경로**(기본 `/at`)를 바꿉니다.
4. **연결...** 버튼을 누릅니다.
   - 성공하면 버튼이 초록색 **연결됨**으로 바뀌고, 결과 표시가 주황색 **연결됨**이 됩니다.
   - 연결 시 `AT`, `AT+TEST=BEGIN` 순서로 핸드셰이크가 전송됩니다.
   - 실패하면 결과 표시가 **연결 안됨**이 되고 로그에 원인이 나옵니다.

> 연결 후에만 명령 버튼이 동작합니다. 연결 없이 누르면 "먼저 연결하세요" 메시지가 뜹니다.

## 4. 버튼별 기능

### 장치 제어 명령
| 버튼 | 동작 | 명령 |
|------|------|------|
| 시리얼 번호 읽기 | 장치 시리얼 조회 | `AT+SERIAL?` |
| 시리얼 번호 쓰기 | 입력한 값으로 설정(입력창 표시) | `AT+SERIAL=<값>` |
| 장치 설정 지우기 | 설정 초기화 | `AT+CLEAR` |

### 장치 테스트 명령
| 버튼 | 명령 | 버튼 | 명령 |
|------|------|------|------|
| 펌웨어 버전 읽기 | `AT+VER?` | 센서 테스트 | `AT+TEST=SENSOR` |
| MAC 주소 읽기 | `AT+MAC?` | LFID 테스트 | `AT+TEST=LFID` |
| 자가 진단 | `AT+TEST=BIST` | NFC 테스트 | `AT+TEST=NFC` |
| LED 테스트 | `AT+TEST=LED` | Bluetooth 테스트 | `AT+TEST=BLE` |
| 부저 테스트 | `AT+TEST=BUZZER` | 도어 버튼 테스트 | `AT+TEST=BUTTON` |
| 릴레이제어 | `AT+TEST=LOCK` | 템퍼 버튼 | `AT+TEST=TAMPER` |
| AUX IN 테스트 | `AT+TEST=AUXIN` | 리셋 버튼 | `AT+TEST=DEFBUTTON` |
| | | 장치 재부팅 | `AT+REBOOT` |

- **읽기** 계열(시리얼·MAC·펌웨어): 결과 표시에 응답 값이 파란색으로 나옵니다.
- **테스트** 계열: 응답이 `OK` 면 초록 **성공**, `FAIL` 이면 빨강 **실패**.

### LED 색상 테스트
빨강·녹색·파랑을 조합해 체크한 뒤 **설정**을 누르면 해당 색 명령이 전송됩니다.
(예: 빨강+녹색 → `AT+TEST=LED_YELLOW`, 셋 다 → `LED_WHITE`, 없음 → `LED_BLACK`)

## 5. 결과 표시(오른쪽 큰 박스)

| 상태 | 색 | 의미 |
|------|----|------|
| 준비 | 회색 | 시작 직후 대기 |
| 연결됨 | 주황 | 장치 연결 성공 |
| 성공 | 초록 | 마지막 명령 성공(OK) |
| 실패 | 빨강 | 마지막 명령 실패(FAIL/오류/미연결) |
| (데이터) | 파랑 | 읽기 명령의 응답 값 |

아래 **대상**은 현재 통신 주소, **세션**은 현재 결과 저장 세션 번호입니다.

---

## 6. 결과 저장과 보고서(CSV)

- 각 명령 결과는 자동으로 저장됩니다. **시리얼 번호가 바뀌면 새 세션(새 행)** 이 만들어져
  장치별로 결과가 구분됩니다.
- **보고서 생성** 버튼 → 시작일·종료일 선택(비우면 전체) → **내보내기**.
  - 데스크톱: 저장 위치를 고르면 CSV 파일이 저장됩니다(Excel 호환, UTF-8 BOM).
  - 웹: 브라우저 다운로드로 저장됩니다.

---

## 7. 버튼 항목 바꾸기

버튼과 명령은 `buttons.json` 파일로 정의됩니다. 코드 수정 없이 추가·변경할 수 있습니다.

- **설치 후 재빌드 없이** 바꾸려면 사용자 데이터 폴더에 `buttons.json` 을 두세요(앱이 우선 사용):
  - Windows: `%APPDATA%\VixReader Test\buttons.json`
  - macOS: `~/Library/Application Support/VixReader Test/buttons.json`
  - Linux: `~/.config/VixReader Test/buttons.json`
- 형식과 예시는 [Architecture.md](Architecture.md#설정-buttonsjson) 참고.

## 8. 문제 해결

| 증상 | 원인 / 해결 |
|------|-------------|
| 연결 실패 (타임아웃) | IP/포트 확인, 장치 전원·네트워크 확인, 방화벽 확인 |
| "먼저 연결하세요" | 명령 전에 **연결...** 을 먼저 눌러야 합니다 |
| 창이 안 뜸(개발 실행) | `ELECTRON_RUN_AS_NODE` 해제 후 재실행 |
| 웹에서 통신 안 됨 | 장치의 HTTPS 인증서를 브라우저가 신뢰해야 하고 CORS 필요 |
| 인증서 경고 | 데스크톱 앱은 자체 서명 인증서를 자동 허용합니다(정상) |

테스트 장치가 없을 때는 가짜 장치 서버로 전체 흐름을 확인할 수 있습니다:
```bash
npm run mock     # https://0.0.0.0:8443/at 에서 대기
```
앱에서 IP `127.0.0.1`, 포트 `8443` 으로 연결하세요.
