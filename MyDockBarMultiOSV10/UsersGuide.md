# MyDockBar 사용 설명서

MyDockBar는 Windows, macOS, Linux에서 쓰는 프로그램 실행 독(dock)입니다.
화면 가장자리에 막대를 띄우고, 자주 쓰는 프로그램을 아이콘으로 올려 두고,
마우스를 올리면 아이콘이 커집니다.

메뉴 이름은 한국어/English 두 가지를 함께 적었습니다. 프로그램이 어느 언어로
실행 중이든 같은 항목을 찾을 수 있습니다.

## 1. 설치

### Windows

`MyDockBar-1.0.0-Setup.exe`를 실행합니다. (x64와 arm64를 모두 담고 있어
어느 PC에서나 같은 파일을 쓰면 됩니다.)

1. **언어 선택** — 설치 화면에 쓸 언어를 고릅니다.
2. **기존 버전 확인** — 이미 설치되어 있으면 이렇게 묻습니다.

   > MyDockBar 1.0.0 이(가) 이미 설치되어 있습니다.
   > 기존 프로그램을 삭제하고 이 버전을 설치할까요?

   - **예** — 기존 버전을 제거한 뒤 새로 설치합니다.
   - **아니오** — 설치를 취소하고 기존 버전을 그대로 둡니다.

   처음 설치할 때는 이 질문이 나오지 않습니다.
3. **사용권 계약**과 **설치 폴더**를 확인합니다. (업그레이드일 때는 건너뜁니다.)

설치가 끝나면 **바탕화면**과 **시작 메뉴**에 바로가기가 만들어집니다.

> 명령줄에서 자동 설치하려면 `MyDockBar-1.0.0-Setup.exe /S` 를 쓰면 됩니다.
> 이때 위 질문은 자동으로 **예**로 처리됩니다.

### macOS

`MyDockBar-1.0.0.dmg`를 열고 MyDockBar를 Applications 폴더로 끌어다 놓습니다.

### Linux

`MyDockBar-1.0.0.AppImage`에 실행 권한을 주고 실행하거나, `.deb` / `.rpm`
패키지를 설치합니다.

### 제거

Windows는 **설정 → 앱**에서, 또는 시작 메뉴의 제거 항목으로 제거합니다.
제거해도 개인 설정은 남습니다. 완전히 지우려면
[설정 파일 위치](#9-설정-파일-위치)의 폴더를 함께 삭제하세요.

## 2. 처음 실행하면

MyDockBar는 **작업 표시줄에 나타나지 않습니다.** 시스템 트레이(알림 영역)에
있습니다.

처음 실행하면 컴퓨터에 설치된 프로그램을 살펴보고 잘 알려진 것 몇 개를 독에
올려 둡니다. 그 뒤에 독 자체의 버튼 네 개가 붙습니다.

| 아이콘 | 하는 일 |
| --- | --- |
| 집 | 내 폴더 열기 |
| 모니터 | 바탕화면 보기 (모든 창 최소화) |
| 휴지통 | 휴지통 열기 |
| 톱니바퀴 | MyDockBar 설정 열기 |

이 네 개는 **삭제할 수 없습니다.** 특히 톱니바퀴를 지울 수 있으면 설정으로
돌아올 길이 없어지기 때문입니다.

## 3. 독 사용하기

### 기본 조작

| 동작 | 결과 |
| --- | --- |
| 아이콘 **클릭** | 프로그램 실행 |
| 이미 실행 중인 프로그램 **클릭** | 새로 실행하지 않고 **그 창을 앞으로** 가져옵니다. 창이 여러 개면 목록에서 고릅니다. |
| 아이콘 **우클릭** | 그 항목의 메뉴 (열기, 파일 탐색기에서 보기, **항목 설정**, 독에서 제거) |
| 빈 곳 **우클릭** | 독 메뉴 (추가, 잠금, 자동 숨김, 설정, 종료) |
| 마우스 **올리기** | 아이콘이 커지고 이름이 뜹니다 |

실행 중인 프로그램 아래에는 작은 점이 표시됩니다.

### 휴지통

휴지통 아이콘은 **비어 있을 때와 차 있을 때 모양이 다릅니다.**
우클릭하면 **휴지통 비우기 / Empty Recycle Bin** 을 쓸 수 있습니다.

### 트레이 메뉴

트레이 아이콘을 우클릭하면 자주 쓰는 것들이 모여 있습니다.

- **독 표시 / 숨기기** (Show / Hide Dock)
- **테마** (Theme) — 48가지 중에서 바로 고르기
- **위치** (Position) — 아래 / 위 / 왼쪽 / 오른쪽
- **언어** (Language) — 시스템과 동일 / English / 한국어
- **독 잠금** (Lock Dock)
- **자동 숨김** (Auto-hide)
- **설정…** (Settings)
- **MyDockBar 종료** (Quit)

트레이 아이콘을 **더블클릭**하면 독을 켜고 끌 수 있습니다.

## 4. 항목 추가와 삭제

### 추가하는 네 가지 방법

1. **끌어다 놓기** — 프로그램이나 폴더를 독 위로 끌어옵니다. 아이콘들이 **양옆으로
   벌어지면서** 들어갈 자리를 보여 줍니다. 원하는 위치에서 놓으면 됩니다.
2. **우클릭 → 프로그램 추가…** — 파일을 고릅니다. **마우스를 우클릭한 그 자리에**
   들어갑니다.
3. **설정 → 프로그램 탭** — 설치된 프로그램 목록에서 **추가** 를 누릅니다.
4. **설정 → 독 항목 탭** — 프로그램/폴더/구분선/URL을 추가합니다.

### 순서 바꾸기

독에서 아이콘을 끌어서 옮깁니다. 다른 아이콘들이 부드럽게 비켜 줍니다.

### 삭제하는 두 가지 방법

- 아이콘을 **독 밖으로 끌어내면** 삭제됩니다. 아이콘이 작아지면서 사라집니다.
- 아이콘을 **우클릭 → 독에서 제거**.

> 한 번 고른 사용자 아이콘은 **기억됩니다.** 항목을 지웠다가 나중에 같은
> 프로그램을 다시 추가하면 그때 고른 아이콘이 그대로 돌아옵니다.

### 구분선

우클릭 → **구분선 추가** 를 하면 마우스 위치에 세로선이 들어갑니다. 관련 있는
프로그램끼리 묶어 놓을 때 씁니다.

### 잠금

**동작 탭**의 *항목 잠금*, 또는 트레이 메뉴의 **독 잠금** 을 켜면 추가·삭제·
이동이 모두 막힙니다. 실수로 아이콘을 끌어내는 일을 막고 싶을 때 쓰세요.

## 5. 아이콘이 이상할 때

프로그램 아이콘이 엉뚱하게 나오거나 빈 문서로 보일 때가 있습니다. Windows가
프로그램마다 아이콘을 여러 개 갖고 있는데, 그중 어느 것을 쓸지 정해 주지 않는
경우가 있기 때문입니다.

**아이콘을 직접 고를 수 있습니다.**

1. 아이콘을 우클릭 → **항목 설정…**
2. **사용자 아이콘** 줄의 **아이콘 변경…** 을 누릅니다.
3. 세 가지 중에서 고릅니다.

   | 단추 | 내용 |
   | --- | --- |
   | **기본 제공** | MyDockBar가 갖고 있는 아이콘들 |
   | **프로그램 파일에서** | 그 프로그램(또는 다른 `.exe` / `.dll`)이 가진 **모든** 아이콘 |
   | **이미지 파일에서** | 직접 준비한 PNG, SVG, ICO 등 |

4. 아이콘을 고르고 **확인** 을 누릅니다. (더블클릭해도 됩니다.)

**프로그램 파일에서** 는 그 파일 안에 든 아이콘을 전부 꺼내서 보여 줍니다.
예를 들어 Notepad++는 300개가 넘습니다. `C:\Windows\System32\shell32.dll`
같은 시스템 파일을 골라서 Windows 기본 아이콘을 가져다 쓸 수도 있습니다.

원래대로 되돌리려면 같은 자리의 **기본값 사용** 을 누릅니다.

## 6. 설정 창

독의 톱니바퀴 아이콘, 트레이 메뉴의 **설정…**, 또는 우클릭 → **독 설정…** 으로
엽니다. 창 크기는 고정이고 스크롤이 없습니다. 탭 여덟 개로 나뉘어 있습니다.

### 일반 (General)

- **마우스를 올리면 이름 표시**
- **언어** — 시스템과 동일 / English / 한국어
- **설정 내보내기 / 가져오기** — 설정을 JSON 파일로 저장하고 불러옵니다.
  다른 컴퓨터로 옮길 때 쓰세요.
- **아이콘 캐시 비우기** — 아이콘이 갱신되지 않을 때

### 테마 (Themes)

48가지 테마. [7. 테마](#7-테마)를 보세요.

### 아이콘 (Icons)

| 설정 | 내용 |
| --- | --- |
| 아이콘 크기 | 24 ~ 128 px |
| 아이콘 간격 | 아이콘 사이 간격 |
| 배경 여백 | 막대의 **얇은 쪽** 여백. 가로 독은 위아래, 세로 독은 좌우가 조절됩니다. 양 끝 여백은 항상 일정하게 유지되고 아이콘은 가운데 정렬됩니다. |
| 배경 높이 | 막대 두께를 직접 지정 (자동으로 두려면 맨 왼쪽) |
| 독 투명도 | 독 전체 |
| 배경 투명도 | 배경 막대만 (아이콘은 그대로) |
| 이름 표시 / 반사 효과 / 실행 표시점 | 켜고 끄기 |
| 실행 중인 프로그램의 아이콘도 표시 | 독에 없는 프로그램이라도 열려 있으면 아이콘을 함께 보여 줍니다 |

### 확대 (Zoom)

| 설정 | 내용 |
| --- | --- |
| 최대 확대율 | 마우스 아래 아이콘이 커지는 정도 |
| 확대 범위 | 양옆으로 몇 개가 함께 커지는지 |
| 확대 곡선 | 포물선(기본) / 코사인 / 직선 / 사용 안 함 |
| 클릭 효과 | 튕기기 / 눌리기 / 없음 |

오른쪽 **미리 보기** 에서 지금 설정이 어떤 모양인지 바로 확인할 수 있습니다.

### 위치 (Position)

- **위치** — 아래 / 위 / 왼쪽 / 오른쪽
- **정렬** — 가운데 / 시작 / 끝
- **가장자리 간격** — 화면 끝에서 얼마나 띄울지
- **모니터** — 주 모니터 / 마우스가 있는 모니터 / 특정 모니터

아래쪽 그림에 모니터 배치와 독이 붙을 자리가 표시됩니다.

### 동작 (Behaviour)

- **자동 숨김** — 마우스가 화면 가장자리에 닿을 때만 독이 나옵니다.
  표시 지연·숨김 지연·남겨둘 두께를 조절할 수 있습니다.
- **창 우선 순위** — 항상 최상위 / 일반 창보다 위 / 보통
- **항상 위에 표시**, **모든 작업 공간에 표시**
- **항목 잠금**
- **실행 중인 프로그램을 누르면 그 창을 앞으로**
- **로그인할 때 MyDockBar 시작**

### 독 항목 (Dock Items)

독에 있는 것들의 목록입니다. 행을 끌어서 순서를 바꾸고, **편집** 으로 이름·대상·
실행 인수·아이콘을 고치고, **제거** 로 지웁니다. 이 탭에 파일을 끌어다 놓아도
추가됩니다. 항목이 많으면 아래쪽 **이전 / 다음** 으로 넘깁니다.

기본 항목(집·바탕화면·휴지통·설정)은 **제거** 가 꺼져 있습니다.

### 프로그램 (Applications)

컴퓨터에 설치된 프로그램 목록입니다. 검색창으로 찾고 **추가** 를 누르면 독에
들어갑니다. 프로그램을 새로 설치한 뒤에는 **다시 검색** 을 누르세요.

### 아래쪽 단추

- **기본값으로 초기화** — 모든 설정을 처음 상태로 되돌립니다.
- **확인** — 창을 닫습니다. 설정은 바꾸는 즉시 저장되므로 따로 저장할 필요가
  없습니다.

## 7. 테마

**테마 탭**에 48가지가 있습니다. **어두운 테마 24개**와 **밝은 테마 24개** 로
나뉘어 있고, 각 단추에 실제 모양이 작게 그려져 있습니다.

테마는 색만 바꾸는 것이 아니라 **모양도 바꿉니다.**

| 모양 | 생김새 |
| --- | --- |
| bar | 기본 둥근 막대 |
| pill | 양 끝이 완전히 둥근 캡슐 |
| slab | 각진 판 |
| tray | 화면 쪽은 각지고 바깥쪽만 둥근 쟁반 |
| shelf / shelf3d | 안쪽으로 들어가는 선반 (RocketDock·Leopard 느낌) |
| notched | 끝이 깎인 모양 |
| tile | 아이콘마다 돋움 타일 |
| slot | 아이콘마다 파인 홈 |
| floating | 배경 없이 아이콘만 |

옛 RocketDock 스킨을 참고한 테마도 있습니다: **Classic**, **Leopard**,
**Aero**, **Timber**, **Brushed**, **Midnight**.

테마를 고르면 **설정 창 색도 함께 바뀝니다.**

## 8. 내 테마 만들기

테마는 `theme.json` 하나가 든 폴더입니다.

**설정 → 테마 → 테마 폴더 열기…** 를 누르면 열리는 폴더 안에 새 폴더를 만들고
`theme.json`을 넣으면 목록에 나타납니다.

```json
{
  "id": "my-theme",
  "name": "내 테마",
  "description": "테마 목록에 표시될 설명",
  "dark": true,
  "variables": {
    "--plate-bg": "linear-gradient(180deg, #333, #111)",
    "--plate-radius": "16px",
    "--icon-shadow": "0 6px 12px rgba(0,0,0,.5)"
  }
}
```

색과 모양 모두 `variables`로 정합니다. 값을 몇 개만 적어도 나머지는 기본값이
쓰이므로 그대로 동작합니다. 쓸 수 있는 값은
[README](README.md#themes)에 정리되어 있고, `themes/` 폴더의 파일들이 그대로
예제입니다.

## 9. 설정 파일 위치

| 운영체제 | 위치 |
| --- | --- |
| Windows | `%APPDATA%\MyDockBar` |
| macOS | `~/Library/Application Support/MyDockBar` |
| Linux | `~/.config/MyDockBar` |

이 폴더 안에 있는 것들:

| 이름 | 내용 |
| --- | --- |
| `config.json` | 모든 설정과 독 항목 |
| `themes/` | 직접 넣은 테마 |
| `icon-cache/`, `extracted-icons/`, `custom-icons/` | 아이콘 캐시 |

설정은 바꾸는 즉시 저장되고 다음에 실행할 때 그대로 쓰입니다.

## 10. 문제 해결

**독이 안 보입니다**
시스템 트레이 아이콘을 더블클릭하거나, 우클릭 → **독 표시 / 숨기기**.
자동 숨김이 켜져 있으면 마우스를 화면 가장자리 끝까지 가져가세요.

**작업 표시줄에 MyDockBar가 없습니다**
정상입니다. MyDockBar는 트레이에만 있습니다.

**아이콘이 이상하게 나옵니다**
[5. 아이콘이 이상할 때](#5-아이콘이-이상할-때)를 보세요.

**프로그램 목록에 새로 설치한 프로그램이 없습니다**
**프로그램 탭 → 다시 검색**.

**아이콘을 추가하거나 지울 수 없습니다**
독이 잠겨 있습니다. 트레이 메뉴의 **독 잠금 해제**, 또는 설정 → 동작 →
*항목 잠금* 을 끄세요.

**클릭해도 창이 안 올라옵니다**
설정 → 동작 → *실행 중인 프로그램을 누르면 그 창을 앞으로* 가 켜져 있는지
확인하세요. 끄면 누를 때마다 새로 실행됩니다.

**실행 중인 프로그램 아이콘에 시스템 프로그램이 섞여 나옵니다**
나오지 않아야 정상입니다. Windows 폴더 안의 프로그램, 탐색기·검색 같은 화면
구성 요소, MyDockBar 자신은 모두 빠집니다.

**전체 화면 프로그램 위에 독이 겹칩니다**
설정 → 동작 → **창 우선 순위** 를 *일반 창보다 위* 나 *보통* 으로 바꾸세요.

**설정을 다른 컴퓨터로 옮기고 싶습니다**
설정 → 일반 → **설정 내보내기…** 로 저장한 파일을 옮긴 뒤 **설정 가져오기…**.
