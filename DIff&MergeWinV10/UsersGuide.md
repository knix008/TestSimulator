# Diff & Merge Win V10 — 사용자 가이드

Diff & Merge는 Windows용 Git 3-way 병합 충돌 해결 도구입니다. Base(공통 조상), Local(우리), Remote(상대) 세 버전을 나란히 비교하고, 충돌을 하나씩 해결한 뒤 병합 결과를 저장할 수 있습니다. `git mergetool`로도 사용할 수 있습니다.

## 시작하기

### 실행 방법

- **개발 빌드:** `dotnet run --project DiffMergeWinV10.App`
- **설치본:** 시작 메뉴 또는 바탕화면의 **Diff & Merge Win V10** 바로 가기

### .NET 런타임

프레임워크 종속(framework-dependent) 빌드를 사용하는 경우 [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)이 필요합니다.

### 마지막 세션 자동 복원

앱을 종료하기 전에 작업하던 세션이 다음 실행 시 자동으로 다시 열립니다.

| 이전 작업 | 복원 내용 |
|-----------|-----------|
| **Base/Local/Remote 열기** | 네 개 경로(Base, Local, Remote, 병합 결과 파일) |
| **충돌 파일 열기** | 해당 충돌 파일 |

**파일 → 환경 설정... → 마지막 세션 지우기**로 기억된 세션을 제거할 수 있습니다.

## 화면 구성

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  [메뉴: 파일 | 편집 | 보기 | 도움말]  [도구 모음]  [글꼴 크기]  [정보]      │
├──────────────────────┬──────────────────────┬──────────────────────────────┤
│  Base (공통 조상)     │  Local (우리)         │  Remote (상대)               │
│  [줄번호 | 내용]      │  [줄번호 | 내용]      │  [줄번호 | 내용]             │
├──────────────────────┴──────────────────────┴──────────────────────────────┤
│  충돌 목록          │  결과 (편집 가능)                                    │
│  (해결 상태)        │  [줄번호 | 병합 결과 — 직접 편집 가능]               │
├─────────────────────┴──────────────────────────────────────────────────────┤
│  상태 표시줄 (해결된 충돌 수, 병합 파일 경로)                               │
└─────────────────────────────────────────────────────────────────────────────┘
```

| 영역 | 설명 |
|------|------|
| **Base** | 공통 조상 버전 (읽기 전용). 3-way merge 시 Git이 제공하는 `$BASE` |
| **Local** | 현재 브랜치(ours) 버전 (읽기 전용) |
| **Remote** | 병합 대상 브랜치(theirs) 버전 (읽기 전용) |
| **충돌** | 충돌 구간 목록 — 미해결/해결됨 상태 표시 |
| **결과** | 최종 병합 텍스트 — 직접 편집 가능 |

- 상단 세 패널(Base / Local / Remote)은 **세로 스크롤이 동기화**됩니다.
- 분할선을 드래그하여 패널 크기를 조절할 수 있습니다.
- 각 내용 패널 왼쪽에 **줄 번호**가 표시되며, 줄마다 리스트처럼 **배경색**이 적용됩니다.

### 줄 배경색 의미

| 색상 | 의미 |
|------|------|
| 흰색 / 연한 회색 (교차) | 충돌이 없는 일반 줄 (zebra striping) |
| 노란색 | 아직 해결되지 않은 충돌 구간 |
| 녹색 | 해결된 충돌 구간 |
| 충돌 목록에서 선택 | 연한 파란색 (선택 강조) |

## 파일 열기

### Base / Local / Remote 세 파일 열기

Git `mergetool`이 제공하는 것과 같은 3-way merge 방식입니다.

1. **파일 → Base/Local/Remote 열기...** 또는 도구 모음 **Base/Local/Remote 열기**
2. **BASE(공통 조상) 파일** 선택
3. **LOCAL(우리) 파일** 선택
4. **REMOTE(상대) 파일** 선택
5. **병합 결과를 저장할 파일** 경로 지정 (다른 이름으로 저장 대화상자)

앱이 세 파일을 비교하여 충돌 구간만 표시합니다. 겹치지 않는 변경은 자동으로 병합됩니다.

### 충돌 파일 열기

`git merge` 후 작업 트리에 남은, `<<<<<<<` 표식이 포함된 파일을 직접 열 때 사용합니다.

1. **파일 → 충돌 파일 열기...** 또는 도구 모음 **충돌 파일 열기**
2. 충돌 표식이 있는 파일 선택

파일 안의 `<<<<<<<` / `|||||||` / `=======` / `>>>>>>>` 마커를 파싱하여 충돌 목록을 만듭니다. Base 정보가 없는 경우 Base 패널에는 *(Base 없음)* 이 표시될 수 있습니다.

### 명령줄에서 열기

```
DiffMergeWinV10.App.exe                              # 대화상자로 파일 선택
DiffMergeWinV10.App.exe <충돌-파일>                   # 충돌 마커 파싱
DiffMergeWinV10.App.exe <BASE> <LOCAL> <REMOTE> <MERGED>   # git mergetool 규약
```

## 패널 설명

### Base / Local / Remote (읽기 전용)

- 각 패널 헤더의 **Base 사용**, **Local 사용**, **Remote 사용**, **둘 다 사용** 버튼으로 현재 선택된 충돌을 한 번에 해결할 수 있습니다.
- 패널 내 텍스트는 읽기 전용입니다. 복사는 **편집 → 복사** 또는 컨텍스트 메뉴를 사용하세요.
- **보기 → 자동 줄 바꿈**으로 긴 줄 표시 방식을 전환할 수 있습니다.

### 충돌 목록

- `충돌 #1 - 미해결`, `충돌 #2 - Local` 등으로 각 충돌의 번호와 해결 상태를 보여 줍니다.
- 항목을 클릭하면 **결과** 패널에서 해당 구간으로 스크롤됩니다.
- **이전 충돌** / **다음 충돌** 버튼(또는 메뉴)으로 순서대로 이동할 수 있습니다.

### 결과 (편집 가능)

- 충돌 해결 결과가 실시간으로 반영됩니다.
- 자유롭게 텍스트를 수정할 수 있습니다 (자동 병합 결과를 미세 조정할 때 유용).
- **결과** 패널 헤더의 **둘 다 사용** 버튼은 현재 충돌에 Local과 Remote 내용을 모두 유지합니다.

## 충돌 해결

충돌 목록에서 항목을 선택한 뒤, 아래 방법 중 하나로 해결합니다.

| 동작 | 설명 |
|------|------|
| **Base 사용** | 공통 조상(Base) 내용으로 해당 충돌을 해결 |
| **Local 사용** | Local(우리) 내용으로 해결 |
| **Remote 사용** | Remote(상대) 내용으로 해결 |
| **둘 다 사용** | Local과 Remote 내용을 순서대로 모두 유지 |

해결 방법은 **편집** 메뉴, 도구 모음, 패널 헤더 버튼, 컨텍스트 메뉴(우클릭)에서 모두 사용할 수 있습니다.

해결된 충돌은 목록에서 상태가 `Local`, `Remote`, `Base`, `둘 다` 등으로 바뀌고, 결과 패널의 해당 구간 배경이 **녹색**으로 표시됩니다.

## 결과 편집 및 저장

### 저장

1. **파일 → 저장** 또는 도구 모음 **저장**
2. 병합 결과가 `$MERGED` 경로(또는 3-way 열기 시 지정한 경로)에 기록됩니다.

### 다른 이름으로 저장

**파일 → 다른 이름으로 저장...** — 새 경로에 결과를 저장합니다.

### 미해결 충돌이 남아 있을 때

저장 시 아직 **미해결** 충돌이 있으면 확인 대화상자가 표시됩니다. 계속하면 `<<<<<<<` 충돌 표식이 그대로 포함된 채로 저장됩니다.

### 종료 시 저장 확인

저장하지 않고 창을 닫으면 "저장하지 않고 닫으시겠습니까?" 확인이 표시됩니다.

### git mergetool 종료 코드

- **저장 후 종료** → 종료 코드 `0` (Git이 충돌 해결됨으로 인식)
- **저장 없이 종료** → 종료 코드 `0`이 아님 (Git이 아직 미해결로 인식)

`git mergetool`과 함께 쓸 때는 `mergetool.diffmerge.trustExitCode true` 설정이 필요합니다.

## 환경 설정 (Preferences)

**파일 → 환경 설정...** (`Preferences...`)

| 항목 | 설명 |
|------|------|
| **패널 글꼴 크기** | Base / Local / Remote / 결과 패널의 고정폭 글꼴 크기 (6.0 ~ 18.0pt) |
| **소스/결과 패널 자동 줄 바꿈** | 긴 줄을 패널 너비에 맞춰 줄 바꿈 |
| **언어** | **한국어**(기본) 또는 **English** — 메뉴, 도구 모음, 대화상자, 상태 표시줄 등 UI 전체에 적용. 확인 즉시 반영 |
| **마지막 세션 지우기** | 다음 **확인** 클릭 시 기억된 마지막 작업 세션 삭제 |

도구 모음의 **글꼴 크기** 숫자 상자로도 글꼴 크기를 바꿀 수 있으며, 변경 내용은 설정 파일에 자동 저장됩니다.

## git mergetool 연동

### 설정

```powershell
git config --global mergetool.diffmerge.cmd '"C:\\Program Files\\DiffMergeWinV10\\DiffMergeWinV10.App.exe" "$BASE" "$LOCAL" "$REMOTE" "$MERGED"'
git config --global mergetool.diffmerge.trustExitCode true
```

### 사용

병합 충돌이 발생한 저장소에서:

```powershell
git mergetool -t diffmerge
```

Git이 `$BASE`, `$LOCAL`, `$REMOTE`, `$MERGED` 경로를 인자로 넘깁니다. 작업 후 **저장**하고 창을 닫으면 Git이 해당 파일을 해결된 것으로 처리합니다.

## 설정 및 데이터 저장 위치

| 항목 | 위치 |
|------|------|
| 사용자 설정 | `%AppData%\DiffMergeWinV10\settings.json` |

설정 파일에 저장되는 내용:

- 창 위치 및 크기, 최대화 여부
- 패널 글꼴 크기, 자동 줄 바꿈
- UI 언어 (기본값: Korean)
- 마지막 작업 세션 (3-way 파일 경로 또는 충돌 파일 경로)

병합 대상 **소스 파일 내용**은 설정 파일에 저장되지 않습니다. 경로만 기억됩니다.

## 문제 해결

### 앱이 시작되지 않음

- [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)이 설치되어 있는지 확인하세요.

### 마지막 세션이 복원되지 않음

- 이전에 열었던 파일이 이동되거나 삭제되었을 수 있습니다.
- **환경 설정 → 마지막 세션 지우기** 후 다시 파일을 열어 보세요.

### git mergetool 후에도 충돌로 남음

- **저장** 없이 창을 닫았는지 확인하세요.
- `mergetool.diffmerge.trustExitCode true`가 설정되어 있는지 확인하세요.

### 글꼴 크기를 바꿨는데 레이아웃이 어색함

- 창 크기를 조금 변경하면 줄 배경이 다시 맞춰집니다.
- **보기 → 자동 줄 바꿈** 상태에 따라 줄 배경 표시 방식이 달라질 수 있습니다.

### 영어 UI로 전환

**파일 → 환경 설정... → 언어 → English → 확인**
