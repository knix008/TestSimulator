# MyWeather 사용 설명서

MyWeather 1.0.0은 선택한 나라와 도시의 일간, 주간, 월간 날씨를 보여 줍니다. 한국어와 영어를 지원합니다.

English notes are included in each section.

## 설치

Windows에서는 프로젝트 루트의 `MyWeather-Setup-1.0.0.exe`를 실행합니다. 설치 파일의 아이콘은 프로그램 아이콘과 같은 `assets/icon.ico`입니다.

1. 설치 언어를 고릅니다. English 또는 한국어입니다.
2. 이미 설치된 MyWeather가 있으면 프로그램 폴더와 이전 바로가기를 완전히 지운 뒤 다시 설치합니다.
3. 이전에 저장한 설정이나 날씨 파일이 있으면 삭제할지 물어봅니다. 아니오를 고르면 그 데이터는 남습니다.
4. 바탕화면 바로가기와 시작 메뉴 바로가기를 각각 선택할 수 있습니다. 둘 다 만들지 않을 수도 있습니다. 만들어지는 바로가기는 프로그램 아이콘 파일을 그대로 사용합니다.

Linux와 macOS의 `installer/linux/install.sh`, `installer/macos/install.sh`도 같은 질문을 합니다. 언어, 기존 설치 삭제, 사용자 데이터 삭제, 바탕화면 바로가기, 시작 메뉴에 해당하는 바로가기를 사용자가 결정합니다.

The Windows setup file asks for the language first. An existing installation is removed completely and installed again. Saved data is deleted only if you answer yes. Desktop and Start menu shortcuts are separate checkboxes and use the program icon.

## 실행

프로그램을 실행하면 창은 열리지만 작업 표시줄에는 아이콘이 나타나지 않습니다. 아이콘은 시스템 트레이에 있습니다. 일간·주간·월간 예보, 설정, 프로그램 정보는 메인 창 옆에 열려 두 창이 함께 보입니다. 같은 창은 하나만 열리고, 버튼을 다시 누르면 그 창이 앞으로 옵니다.

트레이 아이콘을 누르거나 마우스 오른쪽 단추로 누르면 메뉴가 열립니다. 맨 위의 창 표시는 프로그램 창만 다시 엽니다. 날씨, 파일, 편집은 하위 메뉴이고, 설정, 프로그램 정보, 종료는 바로 표시됩니다. 각 항목에는 아이콘이 있습니다.

- 날씨: 새로고침, 일간 예보, 주간 예보, 월간 예보
- 파일: 새로 만들기, 열기, 저장, 다른 이름으로 저장, 인쇄
- 편집: 실행 취소, 다시 실행, 복사, 붙여넣기

The window stays off the taskbar. Click the tray icon to open these menus. Every entry has an icon. English labels are used when the app language is English. General settings can start MyWeather when the system starts, and the window still stays off the taskbar.

## 날씨 보기

프로그램을 다시 실행하면 마지막으로 사용한 창 크기와 위치를 그대로 엽니다. 그 위치가 현재 화면에 없으면 처음처럼 가운데에 엽니다. 날씨 그림은 옆의 도시, 날짜, 기온 글자와 같은 높이이고 위아래로 약간의 여백을 둡니다. 창을 줄이거나 키우면 그림과 글자가 같은 비율로 함께 바뀌므로, 창을 가로 313, 세로 150까지 줄여 작은 위젯처럼 쓸 수 있습니다. 창이 좁아지면 제목의 프로그램 이름이 먼저 사라지고 제목 줄의 여백과 간격이 좁아지므로, 가장 작은 창에서도 예보 단추 셋과 오른쪽 단추가 모두 제 크기로 남습니다.

메인 창은 항상 오늘 날씨와 오늘 날짜만 보여 줍니다. 다른 날을 골라도 메인 창은 오늘로 유지됩니다. 창 위쪽의 세 단추는 일간, 주간, 월간 예보를 엽니다. 각 예보 창 제목에는 아이콘과 함께, 일간은 월과 일, 주간은 시작부터 끝까지, 월간은 연도와 월이 표시됩니다. 단추에 마우스를 올리면 툴팁이 보입니다. 주간이나 월간 예보에서 날짜를 두 번 누르면 그 날의 일간 예보가 열립니다. 일간 예보가 이미 열려 있으면 그 창의 내용이 그 날로 바뀝니다. 월간 예보에서 날짜를 고르면 열려 있는 일간 예보와 주간 예보도 그 날로 바뀝니다. 메인 창의 단추로 열면 항상 오늘을 보여 줍니다. 예보 칸에는 테두리가 없고, 마우스를 올리면 조금 떠 보입니다. 날씨 화면이나 예보의 날짜를 마우스 오른쪽 단추로 누르면 배경 선택과 배경 삭제도 나옵니다.

위치는 설정에서 나라와 도시로 고르거나, 위도와 경도를 직접 넣을 수 있습니다. 위치 탭이 하나일 때는 도시 이름 탭을 숨기고, 도시 이름은 날씨 그림 쪽에 둡니다. 위치를 더 추가하면 탭 이름은 사용자가 붙인 이름이나 번호입니다.

## 설정

설정은 일반, 날씨 출처, 모양, 바탕·글꼴로 나뉩니다. 네 탭은 언어를 바꿔도 한 줄에 모두 보입니다. 값을 바꾸면 바로 적용됩니다. 확인을 누르면 저장되고, 취소하면 창을 열기 전 값으로 돌아갑니다. 날씨 출처에서 정보를 가져올 곳을 켜고 끌 수 있습니다. 일반 설정에서 시스템 시작 시 자동 실행을 켤 수 있고, 날짜 표시 방법도 고를 수 있습니다. 켜도 작업 표시줄에는 아이콘이 나오지 않습니다. 초기화를 누르면 언어, 날짜 표시, 위치, 테마, 투명도, 바탕 그림, 글꼴, 출처, 확인 주기, 표시 우선 순위, 자동 실행이 처음 값으로 돌아갑니다. 최근 파일과 창 위치는 그대로입니다.

처음 실행과 주기 확인은 진행 창 없이 백그라운드에서 날씨를 받아옵니다. 새로고침 버튼을 누르면 진행 창으로 상태를 보여 줍니다. 일반 설정에서 확인 주기를 1시간, 2시간, 4시간, 6시간, 12시간, 24시간 중에서 고르면 그 간격으로 바로 다시 받아오고, 확인을 누르면 저장됩니다.

일반 설정에서 표시 우선 순위를 고릅니다. 평균은 받은 출처를 평균하고, 한 출처를 고르면 그 값을 보여 줍니다. 그 출처가 없으면 평균을 사용합니다. 선택한 값은 저장됩니다.

배경 투명도는 0부터 100까지입니다. 0은 배경이 완전히 불투명합니다. 100이어도 배경은 약 25% 불투명도로 남아 창이 사라지지 않습니다. 글자는 투명해지지 않습니다.

테마는 라이트 20개, 다크 20개, 사용자 정의입니다. 설정에서 테마를 고르면 메인 창과 이미 열려 있는 창이 함께 바뀝니다. 배경 투명도, 그림 투명도, 글꼴 크기는 입력 좌우의 감소, 증가 버튼으로도 바꿀 수 있습니다. 그림 투명도 0은 그림을 숨기고, 100은 그림을 완전히 보여 줍니다. 이것은 창 배경 투명도와 다른 값입니다. 같은 바탕 그림과 그림 투명도는 일간, 주간, 월간 예보 창에도 쓰입니다.

Background transparency runs from 0 through 100. At 100 the window background stays visible. Wallpaper opacity is a separate control and may be 0. Both sliders have decrease and increase buttons.

## 파일

날씨 문서는 `.myweather` 파일입니다. 이 파일의 아이콘은 프로그램 아이콘과 다른 문서 아이콘입니다. 최근 파일은 창 메뉴에서 다시 열 수 있습니다.

창을 닫거나 트레이에서 종료를 고르면, 저장하지 않은 내용이 있을 때 저장, 버리기, 취소를 묻습니다.
