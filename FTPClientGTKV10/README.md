# FTP Client (GTK)

GTK3 기반 FTP 클라이언트입니다. **FTP**, **FTPS**, **SFTP**를 libcurl로 지원하며, 연결 사이트를 저장·관리할 수 있습니다.

---

## 기능

| 항목 | 설명 |
|------|------|
| 프로토콜 | FTP / FTPS / SFTP (libcurl) |
| 파일 목록 | 서버 & 로컬 쌍 패널, 이름·권한·수정일·크기 컬럼 |
| 컬럼 정렬 | 이름·수정일·크기 헤더 클릭으로 오름차순/내림차순 토글 |
| 파일 전송 | ← 업로드 / → 다운로드 (구분 바 버튼, 더블클릭, 우클릭 메뉴) |
| 구분 바 | 44px 넓이, 양측 모두 드래그 가능, 버튼 구분 바 위에 상하 배치 |
| 디렉터리 탐색 | 더블클릭 이동, `[..]` 상위 폴더 |
| 삭제 | 서버: 우클릭 → 삭제 / 로컬: 우클릭 → 휴지통으로 이동 |
| 사이트 관리 | 접속 정보 저장·편집·삭제, 툴바 드롭다운으로 빠른 적용 |
| 자동 새로 고침 | 로컬 디렉터리 변경 시 GFileMonitor로 자동 갱신 |
| 새로 고침 버튼 | 서버/로컬 패널 헤더의 🔄 버튼 |
| 전송 진행 | 진행바(% 표시) + 상태바 메시지 |
| 로그 패널 | 연결·전송·삭제·오류 이벤트 실시간 기록 (하단 분리창, 최소 7줄) |
| 비동기 처리 | 연결·목록·전송·삭제가 백그라운드 스레드, UI 블로킹 없음 |
| 아이콘 | `daemon_hammer.ico` → 4가지 크기 바이너리 내장 (GLib Resource) |

## 화면 구성

```
┌─────────────────────────────────────────────────────────────────────────┐
│ [프로파일▼] │ [프로토콜▼] [호스트] [포트] [사용자] [비밀번호] [연결] │ [저장] [관리] │
├─────────────────────────────┬──────┬──────────────────────────────────┤
│  서버 (Server)           🔄 │  ←   │  로컬 (Local)                🔄  │
│  /home/user/               │  →   │  /home/shkwon/Documents/         │
│  이름  권한  수정일  크기   │      │  이름  권한  수정일  크기        │
│  ┌─────────────────────┐  │      │  ┌────────────────────────────┐  │
│  │ [..] 상위 폴더      │  │      │  │ [..] 상위 폴더              │  │
│  │ 📁 docs             │  │      │  │ 📁 photos                   │  │
│  │ 📄 index.html  1.2K │  │      │  │ 📄 report.pdf   512K        │  │
│  └─────────────────────┘  │      │  └────────────────────────────┘  │
├─────────────────────────────┴──────┴──────────────────────────────────┤
│ ┌─ 로그 ────────────────────────────────────────────────────────────┐  │
│ │ [연결] 서버에 성공적으로 연결되었습니다.                           │  │
│ │ [업로드] /home/shkwon/file.txt  →  /home/user/file.txt            │  │
│ └───────────────────────────────────────────────────────────────────┘  │
│  ██████████░░░  75%                                                     │
│  서버: /home/user/                                                      │
└─────────────────────────────────────────────────────────────────────────┘
```

- **← 버튼**: 로컬 → 서버 업로드 (구분 바 상단)
- **→ 버튼**: 서버 → 로컬 다운로드 (구분 바 하단)
- **우클릭**: 서버(다운로드·삭제·새로 고침) / 로컬(업로드·삭제·새로 고침)
- **구분 바**: 드래그로 서버/로컬 패널 너비 조절 (양측 모두 가능)
- **컬럼 헤더**: 이름·수정일·크기 클릭 시 정렬, 디렉터리는 항상 상단

## 빌드

### 의존성 설치 (최초 1회)

```bash
make deps
```

| 패키지 | 버전 | 용도 |
|--------|------|------|
| libgtk-3-dev | 3.x | UI 프레임워크 |
| libglib2.0-dev | 2.x | 스레드, 설정, GFileMonitor |
| libcurl4-openssl-dev | 7.x+ | FTP / FTPS / SFTP 전송 |
| pkg-config | — | 빌드 설정 |
| imagemagick | — | ICO → PNG 변환 (아이콘 빌드) |

### 빌드 및 실행

```bash
make          # 빌드
make run      # 빌드 + 실행
make clean    # 빌드 산출물 삭제
make install  # /usr/local/bin 설치 (PREFIX 변경 가능)
```

## 로컬 FTP 서버 (테스트용)

vsftpd를 설치해 이 PC에서 바로 테스트할 수 있습니다.

```bash
make ftp-server       # vsftpd 설치 및 시작 (sudo 필요)
make ftp-server-stop  # vsftpd 중지
```

접속 예시:

| 항목 | 값 |
|------|----|
| 프로토콜 | FTP |
| 호스트 | `127.0.0.1` |
| 포트 | `21` |
| 사용자 | 현재 Linux 계정 (예: `shkwon`) |
| 비밀번호 | 해당 계정 비밀번호 |

## 사용법

1. 툴바 드롭다운에서 저장된 프로파일을 선택하거나, 직접 접속 정보를 입력합니다.
2. **연결** 버튼을 누르면 서버에 접속하고 디렉터리 목록이 표시됩니다.
3. 폴더를 더블클릭하면 이동합니다 (`[..]`는 상위 폴더).
4. 구분 바의 **← 버튼**으로 로컬 파일을 서버로 업로드합니다.
5. 구분 바의 **→ 버튼**으로 서버 파일을 로컬로 다운로드합니다.
6. 우클릭 메뉴에서 업로드·다운로드·삭제·새로 고침을 사용할 수 있습니다.
7. 컬럼 헤더(이름·수정일·크기)를 클릭하면 정렬됩니다.
8. 접속 정보는 **사이트 저장**으로 등록하고, **사이트 관리**로 편집합니다.

## 알려진 제한

- SFTP 삭제는 현재 미지원 (libcurl의 SFTP 삭제 명령 미노출)
- 서버 디렉터리 자동 새로 고침 없음 (새로 고침 버튼 또는 우클릭 메뉴 이용)
