# MyCAD 사용 설명서

MyCAD는 웹·Windows·macOS·Linux에서 같은 화면으로 동작하는 3D CAD입니다.
FreeCAD의 워크벤치 구성을 따르고, CATIA(GSD·시트메탈·키네매틱스·지식공학)와
SketchUp(푸시풀·그룹·태그·장면) 방식을 함께 제공합니다.

---

## 1. 화면 구성

| 위치 | 내용 |
| --- | --- |
| 메뉴 막대 | 파일·편집·보기·삽입·부품·스케치·서피스·어셈블리·도면·해석·제조·건축·스케치업·커널·도구·도움말 (22개) |
| 워크벤치 선택 | 메뉴 막대 오른쪽 끝. 고르면 왼쪽 도구 패널이 바뀝니다 (30개) |
| 도구 모음 | 자주 쓰는 명령(내보내기 오른쪽이 인쇄). 오른쪽 끝에 패널 열기/닫기·글자 크기·배율·조명·언어·테마·설정·정보 |
| 왼쪽 패널 | 워크벤치 도구(스케치·피처·불리언·패턴처럼 분류별 그룹으로 묶여 있고 그룹마다 개수 표시), 사양 트리, 피처 목록. 선택한 항목은 강조와 ✓로 표시됩니다 |
| 뷰포트 | 3D 화면. 좌표축·그리드·줄자·뷰큐브 |
| 오른쪽 패널 | 선택한 객체의 속성(이름·색·위치·회전·치수·배율·재질·표시·잠금). 수치는 모두 `− 값 +` 형태 |
| 상태 표시줄 | 객체 수, 선택 수, 스냅, 배율, 단위, 표시 방식, 투영, 저장 여부, 마지막 명령 결과 |

양쪽 패널 사이에는 **구분자**가 있어 드래그로 폭을 조절할 수 있고, 두 번 누르면
내용이 가려지지 않는 최소 폭으로 돌아갑니다. 도구 모음의 ▛·▜ 버튼으로 각 패널을
닫거나 다시 열 수 있습니다.

### 마우스 조작

- **왼쪽 드래그(빈 곳)**: 회전 / **오른쪽 드래그**: 이동 / **휠**: 확대·축소
  (설정 > 뷰포트의 **마우스 조작 방식**에서 CAD·Blender·Touchpad·Maya 중 선택)
- **객체 클릭**: 선택, **Shift+클릭**: 추가 선택
  - 선택한 객체는 캔버스에서 외곽선과 사각 틀로 표시되고, 사양 트리·장면 목록에서도
    강조됩니다. 사양 트리의 행을 눌러 선택할 수도 있습니다
- **객체 드래그**: 바닥면(XZ)을 따라 이동
  - `Shift` + 드래그: 위아래(Y) 이동
  - `Alt` + 드래그: 스냅을 끄고 1mm 단위로 이동 (최소 이동 단위는 항상 1mm)
  - 이동은 드래그 한 번이 실행 취소 한 단계입니다

### 단축키

`Ctrl+C` 복사 · `Ctrl+V` 붙여넣기 · `Ctrl+Z` 실행 취소 · `Ctrl+Y` 다시 실행 ·
`Ctrl+S` 저장 · `Ctrl+P` 인쇄 · `Delete` 삭제 · `Esc` 열린 메뉴 닫기

전체 목록은 **도움말 > 키보드 단축키**에 있습니다.

## 2. 파일 다루기

MyCAD는 한 번에 하나만 실행됩니다. 이미 떠 있는 상태에서 다시 실행하거나 파일을
더블클릭하면 새 창 대신 열려 있는 창이 앞으로 나오고 그 파일을 엽니다.

열기·저장·내보내기 창은 **마지막으로 작업한 폴더**에서 시작하고, 저장할 때는 문서
이름이 미리 채워집니다. 폴더는 용도별(열기·저장·가져오기·배경)로 기억하며, 아직
기억된 것이 없으면 가장 가까운 용도의 폴더를 씁니다(파일을 연 직후 저장하면 그
파일이 있던 폴더에서 시작합니다).

MyCAD는 **STEP(.step/.stp)·IGES(.igs/.iges)·PLY·OFF·Collada(.dae)** 같은 표준 CAD
교환 형식과 STL·OBJ·DXF·SVG·OpenSCAD·IFC·점군·G코드·CSV를 모두 엽니다. 열기 창의
첫 필터가 "지원하는 모든 파일"이고, 그 아래에 형식별 필터가 있습니다.

### 열기

- **파일 > 열기**로 지원 형식을 모두 볼 수 있습니다.
- 탐색기에서 **파일을 뷰포트로 끌어다 놓아도** 됩니다.
- 설치 시 연결한 형식은 **두 번 클릭만으로** MyCAD에서 열립니다.

지원 형식: `.mycad` `.stl` `.obj` `.dxf` `.svg` `.scad` `.ifc` `.asc` `.xyz`
`.nc` `.gcode` `.mycadmacro` `.mycadaddon` `.csv`

### 최근 파일

최근 10개를 기억합니다. **파일 메뉴 아래쪽**에 나오고,
**설정 > 최근 파일**에서 하나씩(✕) 또는 전체(최근 파일 모두 삭제) 지울 수 있습니다.

### 내보내기

도구 모음의 **내보내기** 버튼 또는 **파일 > 내보내기**에서 형식을 고릅니다.

| 형식 | 담기는 내용 |
| --- | --- |
| MyCAD 문서 | 피처·파라미터까지 포함한 문서 전체 |
| STL / OBJ | 삼각형 메쉬 |
| SVG / DXF 스케치 | 스케치 윤곽 |
| 도면 SVG / DXF | 정면·평면·측면·아이소 4면 투영 도면 |
| IFC4 | BIM 요소(없으면 솔리드를 벽으로) |
| G코드 | 윤곽 + 포켓 가공 경로 |
| 점군(ASC) | 메쉬 정점 |
| CSV | 스프레드시트 값(없으면 치수·파라미터 표) |
| 매크로 / Python | 문서를 다시 만드는 스크립트 |

"선택한 객체만"을 켜면 선택한 것만 나갑니다.

### 인쇄

도구 모음의 🖨 버튼을 누르면 미리보기 창이 열립니다.

- **페이지** 탭: 인쇄 범위(전체·현재·사용자 지정), 선택 객체만, 매수
- **용지** 탭: 용지(A3·A4·A5·Letter·Legal), 방향, 여백, 투영 방향, 용지에 맞춤/축척, 테두리
- **머리글/바닥글** 탭: 제목, 머리글, 바닥글, 페이지 번호, 날짜

오른쪽에 실제 출력과 같은 시트가 보입니다. **출력**을 누르면 바로 인쇄됩니다.

## 3. 모델 만들기

### 기본 도형

**삽입** 메뉴에서 박스·구·원기둥·원뿔·토러스·평면·웨지·프리즘·타원체·튜브·
스파이럴·링·피라미드를 넣습니다.

### 스케치 → 솔리드 (파트 디자인)

1. 워크벤치를 **파트 디자인**으로 바꿉니다.
2. **사각형 스케치**를 누르고 너비·높이를 입력합니다.
   (대화상자 위쪽에 그 명령이 무엇을 하는지 한 줄 설명이 나옵니다.)
3. **패드**로 두께를 주면 솔리드가 됩니다.
4. **포켓·구멍·필렛·모따기·셸·패턴**으로 다듬습니다.
5. **파라미터**로 수식을 넣고 **업데이트**를 누르면 다시 계산됩니다.

### 불리언

두 객체를 선택하고 **합집합 / 차집합 / 교집합 / 배타적 합집합 / 불리언 조각**.

### 정확한 모따기와 필렛 (커널 워크벤치)

**커널** 워크벤치의 **B-rep 챔퍼 / B-rep 필렛**은 근사가 아니라 정확한 계산입니다.
챔퍼는 모서리마다 반평면으로 자르고, 필렛은 반지름만큼 줄인 형상에 구를 굴려
평면·원통·구면 패치를 만듭니다. **B-rep 정보**로 면·모서리·꼭짓점 수와
오일러 지표(닫힌 껍질이면 2)를 확인할 수 있습니다.

### SketchUp 방식

**스케치업** 워크벤치에서 사각형·원·다각형·호를 그리고 **푸시/풀**로 세웁니다.
**폴로미**(경로 스윕), **그룹·컴포넌트**, **태그**(레이어), **장면**, **단면 평면**,
**페인트 통**, **줄자·각도기**, **3D 텍스트**, **솔리드 도구**, **샌드박스 지형**을
제공합니다.

## 4. 해석과 제조

- **해석(FEM)**: 재질을 고르고 고정·하중 구속을 추가한 뒤 **볼륨 FEM 해석**을
  실행하면 사면체 메쉬를 만들어 변위와 폰 미제스 응력, 안전계수를 보고합니다.
  간단한 확인에는 보·트러스·고유진동수·열 해석도 있습니다.
- **제조(CAM)**: 윤곽·포켓·드릴·3D 표면·헬리컬·인그레이빙·어댑티브 경로를 만들고
  grbl·LinuxCNC·Mach3·Marlin·Fanuc 포스트로 G코드를 씁니다.
- **시트메탈**: 월과 플랜지를 쌓고 K-factor로 전개 길이를 계산해 전개도 DXF를 냅니다.
- **건축(BIM)**: 벽·기둥·보·슬래브·지붕·창·문·계단·공간과 층을 만들고
  수량을 산출하거나 IFC4로 내보냅니다.

---

## 5. 스크립트와 애드온

- **커널 > Python 매크로 실행**: 샌드박스 Python으로 형상을 만듭니다.
  `import Part`, `Part.makeBox(...)`, `doc.addObject(...)`, `obj.Shape = ...`,
  `doc.recompute()` 같은 FreeCAD 형태의 API를 씁니다.
- `.mycadmacro` 파일은 `box(40, 20, 10)` 같은 간단한 명령 형식도 지원합니다.
- **애드온 목록 / 설치 / 사용 전환 / 실행 / 제거**로 확장을 관리합니다.
  애드온은 데이터(매니페스트)일 뿐이고, 명령은 샌드박스 Python으로만 실행됩니다.
  `.mycadaddon` 파일을 열면 바로 설치됩니다.

## 6. 화면 설정

### 배율

도구 모음 오른쪽의 `− 100% +`. 가운데 숫자를 누르면 100%로 돌아갑니다.

### 표시 방식과 투영

**보기** 메뉴에서 원래대로·음영·평면+외곽선·와이어프레임·점·은선 제거·음영 없음
일곱 가지 표시 방식을 고르고, **투영**으로 원근 ↔ 정투영을 전환합니다.
**뷰 초기화** 버튼(⟲)은 시점·배율·이동을 한 번에 되돌립니다.

### 단위계

설정 > 뷰포트의 **단위계**에서 mm·cm·m·inch·foot 중 고르면 상태 표시줄의 스냅·
측정·부피 표시가 함께 바뀝니다. 문서 자체는 항상 밀리미터로 저장됩니다.

### 단면 평면

설정 > 뷰포트의 **단면 평면**에서 X·Y·Z 각각을 켜고 오프셋을 정하면 그 면을
기준으로 모델을 잘라 볼 수 있습니다(◨ 버튼으로 남길 쪽을 바꿉니다).

### 조명

☀ 버튼으로 켜고 끄며, 옆의 ▾를 누르면 **광원 종류**(평행광·점광원·스포트라이트·
하늘광·3점 조명·환경광만), **광원 색** 6가지, **방향·높이·세기·환경광** 슬라이더,
그리고 스튜디오·정수리·측광·부드럽게·3점 조명·스포트·야외·작업등·평면광 프리셋이
나옵니다. 캔버스의 광원 표시를 직접 끌어 위치를 바꿀 수도 있습니다.

### 글자 크기

도구 모음의 `− A 13 +`로 화면 글자 크기를 바로 조절하고, 가운데를 누르면 기본값
13px로 돌아갑니다. 설정 > 글꼴에서 글꼴·크기·스타일을 함께 정할 수 있습니다.

### 테마

도구 모음의 색상 견본 버튼을 누르면 다음 테마로 넘어가고, ▾로 전체 목록
(Dark 20개, Light 20개, 사용자 정의)에서 직접 고를 수 있습니다. 40가지 프리셋은
모두 파스텔 톤으로 맞춰져 있고, 글자·강조색은 읽기 쉬운 대비를 유지합니다
(고대비 테마 2종은 접근성을 위해 일부러 선명하게 둡니다).

**설정 > 테마 > 사용자 정의**에서는 40가지 프리셋 중 하나를 눌러 그 색을 그대로
가져온 뒤, 13가지 색(배경·패널·경계선·글자·강조·뷰포트·그리드 등)을 원하는 대로
바꿀 수 있습니다.

### 설정 창

데스크톱(Windows·macOS·Linux)에서는 설정이 **별도의 창**으로 열립니다. 창 크기는
1040×700으로 고정되어 있고, 어느 탭에서도 내용이 잘리지 않습니다. 설정 버튼을 다시
누르면 새 창이 열리는 대신 이미 열린 창이 앞으로 나오며, 프로그램을 끝내면 설정 창도
함께 닫힙니다. 설정 창에서 바꾼 값은 본 창에 바로 반영됩니다(웹 브라우저에서는
지금까지처럼 화면 안 대화상자로 열립니다).

왼쪽 탭(일반·테마·글꼴·뷰포트·인쇄 기본값·모양·최근 파일)에서 항목이 상자로
묶여 있고, 숫자 항목에는 −/+ 버튼이 있습니다. 뷰포트 탭에서 그리드·줄자·좌표축·
축 자동 확대·스냅·단위계·마우스 조작 방식·투영·표시 방식·단면 평면·조명을
조정합니다.

### 언어

국기 버튼을 누르면 한국어 ↔ 영어가 바뀝니다. 한국어일 때는 영국 국기,
영어일 때는 태극기가 보입니다(누르면 바뀔 언어를 나타냅니다).

## 7. 설치와 파일 연결 (Windows)

이미 설치된 MyCAD가 있으면 설치 프로그램이 **제거할지 먼저 묻습니다**. 예를 고르면
기존 버전을 제거한 뒤 설치하고, 아니요를 고르면 기존 설치 위에 덮어씁니다. 저장된
사용자 데이터(설정·최근 파일)의 삭제 여부도 따로 묻습니다.

설치 중 **파일 형식 연결** 페이지에서 MyCAD로 열 형식을 체크합니다.
`.mycad`는 MyCAD 고유 문서라 항상 연결되고, 나머지 12종은 선택 사항이며
기본값은 자주 쓰는 형식만 켜져 있습니다. 제거하면 설치 때 만든 연결만 지워집니다.

## 10. 자주 묻는 것

**명령이 "선택된 객체가 없습니다"라고 합니다.**
대부분의 편집 명령은 대상 객체가 필요합니다. 뷰포트나 사양 트리에서 먼저 선택하세요.

**B-rep 챔퍼/필렛이 "볼록 솔리드가 필요합니다"라고 합니다.**
정확한 계산은 볼록 형상에만 적용됩니다. 오목한 형상에는 파트 디자인의
필렛·모따기를 쓰세요.

**도면에 숨은 선까지 보입니다.**
현재 투영은 은선 제거를 하지 않습니다. 필요하면 단면도나 아이소 뷰를 쓰세요.

**창을 줄였더니 도구 모음이 잘립니다.**
창 최소 너비는 모든 도구 버튼이 보이도록 계산되어 있어 그 아래로는 줄어들지 않습니다.
