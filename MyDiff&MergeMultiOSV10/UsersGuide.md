# My Diff & Merge V1.0 — 사용자 가이드

My Diff & Merge는 **파일 · 디렉터리 비교**와 **3-way 병합**을 하나로 묶은 도구입니다.
Git의 `difftool` / `mergetool`로 등록해서 쓸 수도 있고, Git 없이 단독으로도 쓸 수
있습니다. Windows · macOS · Linux 데스크톱 앱과 웹 앱이 모두 같은 프로그램입니다.

## 시작하기

### 실행

| 방법 | 명령 |
|------|------|
| 데스크톱(개발) | `npm start` |
| 웹(개발) | `npm run dev:web` → 브라우저에서 `http://127.0.0.1:5176` |
| 설치본 | 시작 메뉴 또는 바탕화면의 **My Diff & Merge** |

### 명령줄에서 바로 열기

```
MyDiffMerge                                    빈 화면으로 시작
MyDiffMerge A B                                두 파일(또는 두 폴더) 비교
MyDiffMerge BASE LOCAL REMOTE MERGED           3-way 병합
MyDiffMerge conflicted.txt                     <<<<<<< 표식이 있는 충돌 파일
MyDiffMerge session.dmrg                       저장해 둔 세션
MyDiffMerge C:\path\to\repo                    Git 저장소
```

경로는 **옵션 없이 순서대로** 넘깁니다. 두 개면 비교, 네 개면 병합입니다.

### 끌어다 놓기

창 어디에나 파일이나 폴더를 끌어다 놓으면 바로 열립니다. 두 개를 놓으면 비교,
네 개를 놓으면 3-way 병합, 하나를 놓으면 충돌 파일로 엽니다.

## 화면 구성

```
┌──────────────────────────────────────────────────────────────────────────┐
│ ▣ My Diff & Merge V1.0  파일 편집 보기 비교 병합 도구 도움말  ─  □  ×    │ ← 제목 줄 겸 메뉴 막대
├──────────────────────────────────────────────────────────────────────────┤
│ [열기] [저장] [실행취소] [복사] [이동] [충돌해결] [새로고침] [인쇄]      │
│          [보기 옵션] [패널]   [글꼴 −13+][🎨▾][🇰🇷][− 100% +][설정][정보] │ ← 도구 모음
├──────────────────────────────────────────────────────────────────────────┤
│ [left.txt ↔ right.txt ×] [src ↔ src ×] [merged.txt ×]            [‹] [›] │ ← 탭
├──────────┬╌┬──────────────────────────────────────────┬╌┬───────────────┤
│  도구    │ │                                          │ │    속성       │
│          │ │            비교 / 병합 화면              │ │               │
│ 열기     │ │   ▮ ◀ 차이 스크롤 막대          차이 ▶ ▮ │ │ 파일          │
│ 이동     │ │                                          │ │ 수치          │
│ 충돌해결 │ │                                          │ │ 선택 항목     │
│ 필터     │ │                                          │ │               │
├──────────┴╌┴──────────────────────────────────────────┴╌┴───────────────┤
│ 준비됨                         +3 −1 ~2  줄 12/480  LF  100%  KO         │ ← 상태 표시줄
└──────────────────────────────────────────────────────────────────────────┘
        ↑ 구분자(드래그로 폭 조절, 더블클릭으로 원래 폭)
```

| 영역 | 내용 |
|------|------|
| **좌측 패널** | 세션 — 새 세션 종류, 저장한 세션, 최근 항목. **병합 탭에서는 충돌 목록**으로 바뀌어, 충돌마다 Base·내 것·상대 것의 내용을 **펼쳐서** 보여 주고 눌러서 바로 선택합니다. |
| **우측 패널** | **병합할 때만** 나옵니다 — 입력 파일, 진행(충돌/해결/미해결), 해결 방법별 집계, 선택한 충돌의 정보. 읽기 전용입니다. |
| **하단 기록 패널** | 지금까지 일어난 일이 시각과 함께 쌓입니다. **창 전체 폭**을 쓰며(좌우 패널 아래가 아니라 바깥), 복사·지우기·닫기 단추가 있습니다. 툴바의 목록 단추로 열고 닫습니다. |
| **제목 줄 겸 메뉴 막대** | 맨 앞에 **프로그램 아이콘과 이름**, 가운데에 메뉴, 오른쪽 끝에 **최소화 · 최대화 · 닫기**. 빈 곳을 끌면 창이 움직입니다. 메뉴 각 항목에는 **아이콘과 레이블**이 함께 있고, 메뉴는 창 밖으로도 **한 줄로** 펼쳐집니다. |
| **도구 모음** | 왼쪽은 실행 버튼, 오른쪽은 설정입니다 — 보기 옵션, 패널 여닫기, **글꼴 크기**(`−` `+`), **테마**(누르면 밝게 ↔ 어둡게, `▾`로 직접 고르기), **언어**(국기를 누르면 전환), **확대**(`−` `+`), 설정, 프로그램 정보. 모든 버튼에 **툴 팁**이 있습니다. |
| **탭** | 비교할 때마다 새 탭이 열립니다. 탭은 **좌우 패널 사이**에 있습니다. 탭이 넘치면 오른쪽 끝에 **`‹ ›` 버튼**이 생깁니다. |
| **좌측 패널** | 도구 모음(열기 · 이동 · 충돌 해결 · 필터 · 충돌 목록). |
| **우측 패널** | **속성만** 표시합니다 — 경로, 크기, 줄 수, 차이 개수, 선택 항목의 정보. |
| **구분자** | 두 패널과 비교 화면 사이의 **구분자를 끌면** 패널 폭이 바뀌고, **더블클릭하면** 두 패널이 같은 기본 폭으로 돌아갑니다. |
| **차이 스크롤 막대** | 비교 화면 좌우 바깥의 **두꺼운 세로 막대**. 문서 전체를 줄여 담아 추가·삭제·변경을 **색으로** 보여 주고, 끌거나 누르면 그 위치로 이동합니다. 마우스 휠은 비교 영역 어디에서 굴려도 세로로 스크롤됩니다. |
| **크기 변경 마커** | 창 오른쪽 아래 모서리의 빗금. 끌어서 창 크기를 바꿉니다. |
| **상태 표시줄** | 마지막 작업 결과와 현재 상태(차이 개수, 커서 위치, 줄 끝, 확대 비율, 언어). 두 파일이 같다는 안내도 여기에 나옵니다. |

창을 아무리 좁혀도 도구 모음 버튼이 가려지지 않습니다. 최소 폭이 도구 모음 폭과
두 패널 폭에 맞춰 자동으로 정해집니다.

## 세션

프로그램을 처음 열면 시작 화면에 **세션 종류**가 모두 나옵니다. 좌측 패널에도 같은
목록이 있어 언제든 새로 시작할 수 있습니다.

| 세션 | 하는 일 |
|------|---------|
| **폴더 비교** | 두 폴더를 트리로 나란히 |
| **폴더 동기화** | 미러 · 업데이트 · 양방향으로 두 폴더를 맞춤 |
| **텍스트 비교** | 두 파일을 줄·단어 단위로 |
| **텍스트 병합** | Base · 내 것 · 상대 것을 3-way로 |
| **충돌 파일** | `<<<<<<<` 표시가 든 파일을 풀어서 |
| **이미지 비교** | 두 그림을 나란히 · 겹쳐서 · 차이만 |
| **16진수 비교** | 두 파일을 바이트 단위로 |
| **표 비교** | CSV · TSV 를 셀 단위로 (구분자 자동 인식, 열 너비 맞춤, 키 열 정렬) |
| **오디오 태그 비교** | MP3 의 ID3 태그와 비트레이트 |
| **버전 정보 비교** | 실행 파일 · package.json · Info.plist 의 버전 정보 |
| **레지스트리 비교** | `.reg` 내보내기 파일을 정규화해서 |
| **FTP 비교** | 내 폴더와 FTP · FTPS 서버 폴더 |
| **Git 저장소** | 작업 트리의 변경과 이력 (분기·병합 그래프 포함) |

좌측 패널의 **저장 단추**를 누르면 지금 탭이 세션 목록에 남고, 다음에 눌러서 그대로
다시 엽니다. 목록의 항목은 **개별 삭제**할 수 있습니다.

## 비교 창에서 할 수 있는 일

- **찾기 / 바꾸기** (`Ctrl+F` · `Ctrl+H`): 화면에 불러온 줄이 아니라 **파일 전체**를
  찾습니다. 대소문자 구분 · 단어 단위 · 정규식 단추가 있고, 바꾸기는 좌·우 한쪽만
  골라서 할 수 있습니다.
- **줄로 이동** (`Ctrl+G`), **책갈피** (`Ctrl+F2` 로 표시, `F2` 로 다음 책갈피).
- **구문 강조**: 파일 확장자로 언어를 알아내 주석 · 문자열 · 숫자 · 예약어에 색을
  입힙니다.
- **문법 규칙으로 "사소한 차이 무시"** — 툴바와 설정의 *비교* 탭에 있습니다.
  - **주석 무시**: `i++; // 고침` 과 `i++;` 는 같은 줄로 봅니다.
  - **따옴표 종류 무시**: `'a'` 와 `"a"` 를 같게 봅니다.
  - **숫자 표기 무시**: `0x10` 과 `16` 을 같게 봅니다.

  문자열 안의 `//` 나 `#` 는 주석으로 보지 않으며, **보이는 내용은 그대로입니다** —
  규칙은 "무엇을 차이로 볼지"만 바꿉니다.
- **뒤로 / 앞으로** (`Alt+←` · `Alt+→`): 보던 내용으로 되돌아갑니다. 탭을 옮겨
  다닌 것도, 저장소 안에서 변경 목록 ↔ 커밋을 오간 것도 모두 기억합니다.

## 폴더 비교에서 더

- **이름 바뀐 파일 찾기**: 한쪽에서 사라지고 다른 쪽에 나타난 파일이 내용이 같으면
  **이름 바뀜**으로 묶어서 보여 줍니다.
- **압축 파일 안까지**: zip · jar · docx 같은 압축 파일을 열어서 그 안의 파일까지
  비교합니다. 압축을 풀지 않고 색인의 CRC 만 읽으므로 느려지지 않습니다.
- **이동 · 이름 바꾸기**도 복사 · 삭제와 함께 툴바에 있습니다.
- **평면 목록**: 트리 대신 전체 경로가 붙은 한 줄짜리 목록으로 볼 수 있습니다.

## 폴더 동기화

**폴더 동기화** 세션을 열면 트리 위에 동기화 줄이 생깁니다.

1. **방식**을 고릅니다 — 미러(오른쪽/왼쪽), 업데이트(오른쪽/왼쪽), 양방향.
2. **미리보기**를 누르면 무엇을 복사하고 무엇을 지울지 계산해서 개수로 보여 줍니다.
   이 단계에서는 **아무것도 바뀌지 않습니다**.
3. **동기화 실행**을 누르면 복사 수와 삭제 수를 확인한 뒤 실행합니다. 복사가 먼저,
   삭제가 나중에 실행됩니다.

- **미러**는 한쪽을 다른 쪽과 똑같이 만듭니다 — 상대편에 없는 파일은 **지웁니다**.
- **업데이트**는 새 파일만 덮어씁니다. **아무것도 지우지 않습니다**.
- **양방향**은 각 파일마다 최신 쪽이 이깁니다. 내용은 다른데 시각이 같으면 사람이
  판단할 일이므로 **건드리지 않습니다**.
- **1시간 차이는 서머타임으로 봅니다** 단추를 켜두면, 2초 이내 차이(FAT 파일시스템)와
  정확히 1~2시간 차이(서머타임)는 같은 시각으로 봅니다.

## 파일 비교

**파일 → 파일 비교 열기...** (`Ctrl+O`) 또는 도구 모음 첫 번째 버튼.

- 두 파일이 **줄 단위로 정렬**되어 나란히 표시됩니다.
- 색: 추가(초록) · 삭제(빨강) · 변경(노랑). 변경된 줄에서는 **바뀐 단어만** 진하게
  표시합니다.
- 각 패널 위의 **경로 막대**에서 그 쪽 파일을 바꿀 수 있습니다. 직접 입력하거나
  붙여넣고 Enter, 또는 폴더 아이콘으로 찾아보기.
- 오른쪽 가장자리의 **개요 막대**는 파일 전체의 차이 분포입니다. 클릭하면 그 위치로
  이동합니다.

### 차이 사이 이동

| | |
|---|---|
| 다음 차이 | `F8` |
| 이전 차이 | `F7` |
| 첫 차이 / 마지막 차이 | `Ctrl+Home` / `Ctrl+End` |

### 한쪽을 다른 쪽에 반영하기

차이가 있는 줄에 마우스를 올리면 가운데 열에 **`›` `‹` 버튼**이 나타납니다.

- `›` — 그 **차이 블록 전체**를 오른쪽 파일에 씁니다.
- `‹` — 왼쪽 파일에 씁니다.

파일은 바로 저장됩니다. 블록 단위라 한 줄짜리 변경이든 여러 줄짜리 변경이든 한 번에
반영됩니다.

### 줄 직접 고치기

어느 쪽이든 줄을 **더블클릭**하면 그 자리에서 편집할 수 있습니다. Enter로 확정하면
파일에 기록되고, Esc로 취소합니다.

### 차이만 보기

도구 모음의 **차이만 보기**(깔때기 아이콘)를 누르면 같은 부분을 접고 차이와 그
앞뒤 세 줄만 남깁니다. 수천 줄짜리 파일에서 세 군데가 바뀐 경우에 특히 유용합니다.

### 공백 · 대소문자 무시

도구 모음의 **공백 무시** / **대소문자 무시**를 켜면 그 차이는 같은 것으로 봅니다.
화면에 표시되는 글자는 그대로이고, 비교 기준만 달라집니다.

## 디렉터리 비교

**파일 → 디렉터리 비교 열기...** (`Ctrl+Shift+O`)

두 폴더가 **좌우 트리**로 나란히 표시됩니다.

- 각 트리 **맨 위의 경로 막대**에서 그 쪽 폴더를 바꿀 수 있습니다. `↑` 버튼은 상위
  폴더로 올라갑니다.
- 폴더는 **접고 펼칠** 수 있고, 폴더 자체의 상태는 그 안의 내용을 모아서 정해집니다
  (안이 전부 같으면 "같음", 하나라도 다르면 "다름").
- 한쪽에만 있는 항목은 반대쪽 자리가 비어 있어서, **두 트리의 줄이 항상 맞습니다**.
  빈자리는 줄무늬와 다른 회색 띠로 칠해져, 어느 쪽에 없는지가 한눈에 보입니다.
- 부모와 자식은 **연결선**으로 이어지고, 한 폴더의 마지막 항목에서 선이 끝납니다.
  깊은 곳의 파일이 어느 폴더에 들어 있는지를 눈으로 따라갈 수 있습니다.
- 이름 앞 아이콘은 **파일의 종류**를 말합니다 — 그림, 소리, 영상, 압축, 표, 문서,
  소스 코드, 설정, 실행 파일, 인증서. 그 옆의 작은 표시는 **비교 결과**(다름 · 한쪽에만
  있음)로, 둘은 서로 다른 질문에 답하므로 같은 자리를 다투지 않습니다.
- **파일을 더블클릭하면** 그 두 파일의 내용 비교가 새 탭으로 열립니다.

### 트리 도구 모음

| 버튼 | 하는 일 |
|------|---------|
| 모두 펼치기 / 모두 접기 | 트리 전체 |
| 변경된 항목만 펼치기 | 차이가 있는 폴더만 펼칩니다(비교를 열면 이 상태로 시작) |
| 우측으로 복사 / 좌측으로 복사 | 선택한 파일이나 **폴더 전체**를 반대쪽에 복사 |
| 좌측 / 우측 삭제 | 선택한 항목을 그쪽에서 삭제 — **확인을 먼저 묻습니다** |
| 찾기 | 경로에 포함된 글자로 걸러내기 |

### 필터와 파일 마스크

- 좌측 패널의 **필터**로 같은 항목 · 다른 항목 · 좌측에만 · 우측에만을 각각 켜고 끌
  수 있습니다. 개수도 함께 표시됩니다.
- **설정 → 비교**의 **파일 마스크**(`*.ts, *.md`)를 지정하면 그 파일만 비교하고,
  **제외 마스크**(`*.log`)에 해당하는 파일은 아예 보지 않습니다.
- **제외할 폴더**(기본값: `.git`, `node_modules`, `dist`, ...)는 아예 들어가지
  않습니다.

## 바이너리 · 이미지 비교

### 바이너리

텍스트가 아닌 파일을 열면 자동으로 **16진수(Hex) 덤프**로 비교합니다. 한 줄에 16
바이트씩, 양쪽을 나란히 놓고 **다른 바이트만 빨갛게** 표시합니다. 오른쪽 끝에는
ASCII가 함께 나옵니다. 가로 폭이 모자라면 가로로 스크롤됩니다.

### 이미지

양쪽이 모두 그림 파일(`png`, `jpg`, `gif`, `webp`, `bmp`, `avif`, `ico`)이면 그림
비교 화면이 열립니다.

| 모드 | 내용 |
|------|------|
| **나란히 보기** | 두 그림을 좌우로, 같은 배율로 |
| **겹쳐 보기** | 두 그림을 겹치고 슬라이더로 섞는 비율 조절 |
| **차이만 보기** | 달라진 픽셀만 빨갛게, 나머지는 어둡게 |

**다른 부분 표시**를 켜면 달라진 영역이 양쪽 그림 위에 **빨간 상자**로 표시됩니다.
거의 같은 두 그림에서 달라진 곳을 찾아다니지 않아도 됩니다. 도구 모음 오른쪽에는 그림
크기와 **달라진 픽셀 수·비율**이 함께 나옵니다.

#### 확대·축소와 이동

한 픽셀의 차이는 줄여 본 화면에서는 보이지 않습니다. 그래서 그림 비교는 **10%에서 1600%**까지
확대할 수 있고, 200%부터는 픽셀을 흐릿하게 뭉개지 않고 그대로 보여 줍니다.

| 조작 | 하는 일 |
|------|---------|
| **확대 / 축소** 버튼, `Alt`+휠 | 한 단계씩 확대·축소 (보던 위치를 가운데 두고) |
| **창에 맞추기** / **실제 크기** | 창 크기에 맞추거나 100%로 |
| 그림을 **끌기**, 더블클릭 | 이동 / 「맞추기 ↔ 실제 크기」 전환 |

나란히 보기에서 **양쪽은 같은 배율로, 같은 곳을** 보여 줍니다. 한쪽을 옮기면 반대쪽도
같이 움직이므로, 크기가 커서 일부만 보이는 그림도 같은 자리끼리 비교됩니다. 크기가 서로 다른 두
그림은 둘을 덮는 크기를 기준으로 비교하고, 그 사실을 비교 화면 위에 알려 줍니다.

## 3-way 병합과 충돌 해결

### 여는 방법

| 방법 | 쓰는 때 |
|------|---------|
| **파일 → 3-way 병합 열기...** | Base / Local / Remote 세 파일이 따로 있을 때 |
| **파일 → 충돌 파일 열기...** | `git merge` 후 `<<<<<<<` 표식이 남은 파일 |
| **Git 저장소에서 충돌 파일 더블클릭** | 가장 정확합니다 — Git 인덱스에 남아 있는 세 단계를 모두 읽어 **공통 조상까지** 복원합니다 |
| `git mergetool` | 아래 [Git 연동](#git-연동) 참고 |

### 화면

위쪽에 **Base(공통 조상) · Local(우리) · Remote(상대)** 세 패널, 아래쪽에
**결과(편집 가능)** 패널이 있습니다. 네 패널은 **줄 단위로 정렬**되어 같이
스크롤됩니다. 공통 조상이 없는 충돌 파일이면 Local · Remote 두 패널만 나옵니다.

- 겹치지 않는 변경은 **자동으로 병합**되고, 정말로 충돌하는 부분만 표시됩니다.
- 충돌 구간은 연한 빨강, 해결한 구간은 연한 초록입니다.

### 해결하기

좌측 패널의 **충돌 목록**에서 충돌을 고른 뒤 (또는 화면에서 클릭한 뒤):

| 선택 | 단축키 | 결과 |
|------|--------|------|
| Base 사용 | `Ctrl+1` | 공통 조상 내용으로 |
| Local 사용 | `Ctrl+2` | 우리 쪽 내용으로 |
| Remote 사용 | `Ctrl+3` | 상대 쪽 내용으로 |
| 둘 다 사용 | `Ctrl+4` | 우리 쪽 다음에 상대 쪽을 이어서 |
| 해결 취소 | `Ctrl+Shift+0` | 다시 미해결로 |

**모두 Local로 해결 / 모두 Remote로 해결**은 병합 메뉴에 있습니다.
**이전 충돌 / 다음 충돌**은 `Shift+F7` / `Shift+F8`.

결과 패널의 줄을 **더블클릭하면 직접 고칠** 수 있습니다. 손으로 고친 충돌은 목록에
"수정됨"으로 표시됩니다.

**모든 동작은 실행 취소(`Ctrl+Z`) · 다시 실행(`Ctrl+Y`)** 할 수 있습니다.

### 저장

**파일 → 병합 결과 저장**(`Ctrl+S`).

- 아직 해결하지 않은 충돌이 있으면 **먼저 확인을 묻고**, 계속하면 `<<<<<<<` 표식이
  그대로 들어간 채 저장됩니다.
- Git 저장소의 충돌 파일을 전부 해결하고 저장하면 **`git add`까지 자동으로**
  수행합니다.
- 저장하지 않은 변경이 있으면 종료할 때 **저장 여부를 묻습니다**.

## Git 연동

### 저장소 열기

**파일 → Git 저장소 열기...** — 작업 트리의 변경, 스테이지된 변경, 추적되지 않는
파일, 충돌 파일이 한 목록에 나오고, 오른쪽에는 커밋 기록이 나옵니다.

- 변경 항목을 **더블클릭**하면 해당 두 버전의 비교가 열립니다.
- **충돌 파일**을 더블클릭하면 3-way 병합으로 열립니다.
- 커밋을 클릭하면 그 커밋이 건드린 파일 목록으로 바뀝니다.

### difftool / mergetool로 등록

**설정 → Git** 탭에서 버튼 한 번으로 등록·해제할 수 있습니다. 등록 상태와 실제
명령줄도 같은 화면에 나옵니다.

등록한 뒤에는:

```bash
git difftool      # 변경된 파일을 하나씩 비교
git mergetool     # 충돌 파일을 하나씩 해결
```

병합 결과를 저장하면 종료 코드 `0`, 저장하지 않고 닫으면 0이 아닌 값을 돌려주므로
Git이 해결 여부를 올바르게 판단합니다.

## 탭 · 세션 · 최근 항목

### 탭

비교할 때마다 새 탭이 열립니다. 탭이 창 폭을 넘으면 **스크롤바 대신 오른쪽 끝에
`‹ ›` 버튼**이 나타납니다. 탭은 `×` 또는 가운데 버튼 클릭, `Ctrl+W`로 닫습니다.

### 세션 (`.dmrg`)

**파일 → 세션 다른 이름으로 저장...** 으로 지금 열려 있는 탭 구성을 저장하고,
**세션 열기...** 로 되돌릴 수 있습니다. `.dmrg` 파일은 설치할 때 시스템에
등록되므로 **탐색기에서 더블클릭해도** 열립니다. 전용 아이콘이 붙습니다.

### 최근 사용한 파일

최근 **10개**까지 기억합니다. **파일 메뉴** 아래쪽, 그리고 시작 화면에 나옵니다.

- 개별 삭제: 시작 화면의 휴지통 버튼, 또는 **설정 → 최근 항목**에서.
- 전체 삭제: **파일 → 최근 목록 모두 지우기**.

열었던 **폴더**도 함께 기억해서, 다음에 파일을 찾아볼 때 그 자리에서 시작합니다.

## 인쇄

도구 모음의 인쇄 버튼 또는 `Ctrl+P` → **인쇄 미리보기** 창이 열립니다.

- **인쇄 범위**: 전체 · 현재 문서(지금 보고 있는 쪽) · 사용자 지정(`1-3, 7`).
- **페이지 설정**: 용지(A4 · A3 · Letter · Legal), 방향, 여백(mm), 줄 번호, 색상
  배경, 머리글/바닥글.
- 미리보기는 **실제 인쇄될 페이지 그대로**입니다. 설정을 바꾸면 즉시 다시
  페이지를 나눕니다.
- `‹ ›`로 쪽을 넘기고, **인쇄** 버튼으로 바로 출력합니다.

## 설정

도구 모음의 톱니 버튼 또는 `Ctrl+,`. 창은 **고정 크기이고 스크롤이 없으며**, 항목은
**한 줄에 하나씩** 7개 탭에 나뉘어 있습니다. 숫자를 넣는 칸에는 좌우에 `−` `+`
단추가 있습니다.

| 탭 | 내용 |
|----|------|
| **일반** | 언어(한국어 / English), 종료 확인, 세션 복원, 패널 표시, 설정 파일 위치 |
| **모양** | 테마 40종(밝게 20 · 어둡게 20)과 **사용자 정의 테마**, 확대 비율, 패널 폭, 창 제목 색상 |
| **사용자 정의** | 내 테마의 네 가지 색(바탕 · 패널 · 글자 · 강조)과 밝게/어둡게. 나머지 색은 여기서 자동으로 만들어집니다. |
| **글꼴** | 시스템에 설치된 **모든 글꼴**, 크기, 굵기, 스타일, 미리보기 |
| **비교** | 자동 줄 바꿈, 단어 강조, 공백·대소문자 무시, 차이만 보기, 제외 폴더, 파일 마스크 |
| **최근 항목** | 최근 목록 확인 · 개별 삭제 · 전체 삭제 |
| **Git** | difftool / mergetool 등록 상태와 등록·해제 |

자주 쓰는 보기 옵션(차이만 보기, 줄 바꿈, 단어 강조, 공백 무시, 대소문자 무시)과
글꼴 크기는 **도구 모음에서 바로** 바꿀 수 있습니다.

모든 설정은 **즉시 저장되고 다음 실행 때 그대로 복원**됩니다. 창 위치와 크기도
기억합니다.

## 문제 해결

### 오류가 났을 때

오류는 **팝업 창**으로 자세한 내용까지 보여 줍니다. **오류 내용 복사** 버튼을
누르면 전체 내용이 클립보드에 들어가므로 그대로 붙여넣어 알려 주시면 됩니다.

### 디렉터리 비교가 너무 느립니다

- **설정 → 비교**에서 **제외할 폴더**에 `node_modules`, `dist` 같은 큰 폴더를
  넣어 주세요(기본으로 들어 있습니다).
- **파일 마스크**로 관심 있는 파일만 보도록 좁히면 훨씬 빨라집니다.

### 아주 큰 파일에서 자동 줄 바꿈이 켜지지 않습니다

줄 바꿈을 켜면 모든 줄의 높이를 따로 계산해야 하므로, 2만 줄이 넘는 파일에서는
자동으로 꺼진 상태로 표시합니다. 차이만 보기를 함께 쓰면 대부분 해결됩니다.

### `git mergetool`이 끝나도 충돌로 남아 있습니다

- 저장하지 않고 창을 닫지 않았는지 확인하세요.
- `mergetool.mydiffmerge.trustExitCode`가 `true`인지 확인하세요
