MyMarkDownMaker — 따라하기

프로그램 안의 따라하기(도움말 › 따라하기, F11)와 같은 단계입니다.

시작 화면

1. MyMarkDownMaker

여러 Markdown 파일을 하나의 문서로 병합하고, 구조를 보며 번호를 매기고, 표지와 목차를 붙여 HTML · PDF · Word 로 내보내는 프로그램입니다.

2. 시작하기

폴더 추가는 폴더(와 하위 폴더)의 Markdown 파일을 모두 가져옵니다. 파일 추가, 새 문서, 저장한 문서 열기도 여기서 합니다.

3. 샘플 문서

샘플을 누르면 몇 개의 파일이 하나의 문서로 병합되어 열립니다. 어떤 파일도 바뀌지 않습니다.

4. 움직이는 배경

시작 화면의 배경은 16가지 문서 장면 중에서 고르거나 자동으로 바뀌게 할 수 있습니다. 카드는 끌어서 옮기고 크기를 바꿀 수 있습니다.

5. 시작 화면 버튼

메뉴 막대 왼쪽의 시작 버튼으로 언제든 이 화면과 문서 사이를 오갑니다.

문서 만들기

6. 파일 목록

병합할 파일입니다. 체크를 끄면 빠지고, 손잡이를 끌거나 ▲▼ 로 순서를 바꿉니다. 바꾸는 즉시 다시 병합됩니다.

7. 병합 옵션

하위 폴더 포함, 파일명 헤더, 병합할 때 번호 매기기를 켜고 끕니다. 번호 다시 매기기(F7)와 다시 병합(F5)도 여기 있습니다.

8. 구조

문서의 헤딩 트리입니다. 항목을 누르면 편집기나 미리보기에서 그 위치로 갑니다.

9. 그림

문서의 모든 그림입니다. 크기를 문서 폭의 비율로 바꾸면 미리보기와 모든 내보내기에 반영됩니다.

10. 미리보기

표지, 목차, 그림 목차와 본문을 내보내기와 같은 모양으로 보여 줍니다. Ctrl+휠로 확대합니다.

11. 편집

병합된 문서를 직접 고칩니다. 위의 서식 막대와 Ctrl+B, Ctrl+1…5 같은 단축키를 씁니다. 실행 취소(Ctrl+Z)는 파일 목록 변경도 되돌립니다.

12. 나란히 보기

왼쪽에서 고치고 오른쪽에서 결과를 봅니다. 가운데 경계선을 끌어 폭을 나눕니다.

다듬고 내보내기

13. 문서 속성

표지 제목·버전·작성자·날짜, 목차와 그림 목차, 페이지 번호, 머리글과 바닥글, 내보내기 글꼴을 여기서 바로 바꿉니다.

14. 페이지 구성

표지, 목차, 그림 목차, 페이지 번호, 머리글, 바닥글을 한 번에 켜고 끄며, 본문 글자 크기를 바꿉니다.

15. 내보내기

Markdown, HTML, PDF, Word 로 내보냅니다. PDF 와 인쇄의 목차에는 실제 페이지 번호가 들어갑니다.

16. 문제 · 메시지 · 정보

건너뛴 헤딩 수준, 찾지 못한 그림, 닫히지 않은 코드 블록 같은 문제를 보여 줍니다. 누르면 그 줄로 갑니다.

17. 상태 표시줄

파일, 헤딩, 그림 수와 분량, 저장 여부, 글꼴, 확대 비율, 테마와 언어를 보여 줍니다.

설정과 도움말

18. 테마

다크 20개, 라이트 20개 테마와 직접 만드는 테마가 있습니다. ▾ 로 목록을 엽니다.

19. 설정

일반, 시작 화면, 테마, 글꼴, 배경, 병합, 표지·목차, 내보내기 글꼴, 머리글·바닥글, 최근 목록, 단축키를 탭으로 나눠 둡니다.

20. 단축키

자주 쓰는 기능은 모두 단축키가 있습니다.

21. 끝

튜토리얼은 도움말 메뉴나 툴바 오른쪽 버튼(F11)으로 다시 볼 수 있습니다.
