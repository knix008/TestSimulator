MyMarkDownMaker — Tutorial

The same steps the tutorial shows in the program (Help › Tutorial, F11).

Start page

1. MyMarkDownMaker

Merge many Markdown files into one document, number it while you see its structure, add a cover and contents and export it to HTML · PDF · Word.

2. Get started

Add folder takes every Markdown file of a folder (and its sub-folders). Add files, a new document and opening a saved one are here too.

3. Sample documents

A sample merges a few files into one document and opens it. No file is changed.

4. Moving background

Pick one of 16 document scenes for the start page or let it change on its own. Cards can be dragged and resized.

5. The Start button

The Start button at the left of the menu bar switches between this page and the document at any time.

Making the document

6. The file list

The files to merge. Untick one to leave it out, drag the grip or use ▲▼ to change the order. The document is merged again at once.

7. Merge options

Sub-folders, file name headings and numbering when merging go on and off here, next to Renumber (F7) and Merge again (F5).

8. Structure

The heading tree of the document. Click an entry to go there in the editor or the preview.

9. Figures

Every picture of the document. Its size as a share of the page width reaches the preview and every export.

10. Preview

The cover, contents, list of figures and body as the exports show them. Ctrl+wheel zooms.

11. Edit

Edit the merged document itself, with the formatting bar above and keys like Ctrl+B and Ctrl+1…5. Undo (Ctrl+Z) also undoes file list changes.

12. Side by side

Edit on the left, see the result on the right. Drag the divider to share the width.

Finishing and exporting

13. Document properties

Cover title, version, author and date, contents and list of figures, page numbers, header and footer and the export font — all at hand.

14. Pages

Cover, contents, list of figures, page numbers, header and footer in one click each, and the body text size.

15. Export

Export to Markdown, HTML, PDF or Word. The contents of the PDF and the print carry the real page numbers.

16. Problems · messages · information

Skipped heading levels, missing pictures, unclosed code blocks and more. Click one to go to its line.

17. Status bar

Files, headings and pictures, length, whether it is saved, the font, the zoom, the theme and the language.

Settings and help

18. Themes

20 dark and 20 light themes and one of your own. ▾ opens the list.

19. Settings

General, start page, theme, fonts, background, merging, cover & contents, export font, header & footer, recent and shortcuts, each on its own tab.

20. Shortcuts

Everything you use often has a key.

21. Done

See the tutorial again from the Help menu or the toolbar button at the right (F11).
