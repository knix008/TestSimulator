# 사용자 가이드 — MyMarkDownMaker

## 1. 실행

- **데스크톱(개발):** `npm install` 후 `npm start`
- **웹:** `npm run web` → 브라우저에서 `http://localhost:5178`
- **설치본:** `npm run build:win`(또는 `:mac` / `:linux`) 로 만든 설치 파일 실행

## 2. 화면 구성

```
┌ 툴바 ─ 폴더 추가 · 파일 추가 · 병합 · 번호 다시 매기기 · 내보내기▾ │ 비우기 · 언어 · 테마 · 설정 · 정보 ┐
├ 옵션 ─ 하위 폴더 포함 · 정렬 · 제외 패턴 · 파일명 헤더 삽입 · 헤딩 번호 매기기 ──────────────────────────┤
│                                    │                                                                    │
│  [파일] [구조]  ← 사이드바         │   [미리보기] [편집]  ← 메인 영역                                    │
│   - 체크 / 순서(≡ 드래그·▲▼) / 제거 │   - 렌더링 결과 / 원문 편집                                          │
│                                    │                                                                    │
├ 상태바 ─ 상태 메시지 · 파일 수 · 헤딩 수 · 단어/글자 수 · 폰트 · 테마 · 소스 경로 ─────────────────────────┤
```

## 3. 기본 사용 흐름

1. **파일 수집**
   - **폴더 추가** — 폴더를 고르면 하위의 `.md`/`.markdown` 파일이 목록에 추가됩니다(*하위 폴더 포함* 옵션으로 재귀 수집).
   - **파일 추가** — 개별 파일을 선택해 추가합니다.
   - 폴더·파일은 **여러 번 반복해서 누적**할 수 있으며, 이미 있는 파일은 자동으로 제외됩니다.
2. **정렬 · 선택 · 순서 조정 (파일 탭)**
   - **정렬**: 이름 오름/내림, 최신/오래된 날짜순. **직접 지정** 은 순서를 수동으로 바꿀 때 자동 선택됩니다.
   - **선택/해제**: 각 행의 체크박스 또는 파일 이름을 클릭하면 병합 대상에 포함/제외됩니다.
   - **순서 변경**: 행 왼쪽의 손잡이(≡)를 **드래그**하거나, 행의 **▲ / ▼** 버튼을 사용합니다.
   - **제거**: 행의 **✕** 버튼.
   - **제외 패턴**: 쉼표로 구분, 와일드카드 지원(`_draft, temp*`). 폴더/파일 추가 시 적용됩니다.
3. **옵션**
   - **파일명 헤더 삽입**: 각 파일 앞에 `## 상대경로` 헤더를 넣어 섹션을 구분합니다.
   - **헤딩 번호 매기기**: 병합 시 문서 전체에 계층 번호를 자동 부여합니다.
4. **미리보기 (자동)** — 파일을 선택/체크/재정렬하거나 옵션을 바꾸면 **자동으로 병합되어** 오른쪽 미리보기와 왼쪽 **구조** 트리가 즉시 갱신됩니다. (툴바의 **병합** 버튼은 구조 탭으로 전환 + 강제 재병합용)
5. **구조 탭** 의 항목을 클릭하면 미리보기가 해당 헤딩으로 스크롤됩니다.
6. **번호 다시 매기기** — 편집으로 헤딩이 바뀌었거나 번호를 정리하려면 누르세요. 기존 번호를 지우고 1, 1.1, 1.1.1 … 로 다시 매깁니다.
7. **내보내기** — 툴바의 **내보내기▾** 를 열면:
   - 상단 **파일 이름** 입력칸(기본값: 첫 병합 파일 이름, 수정 가능)
   - **Markdown / HTML / PDF / Word** 중 선택
   - 데스크톱에서는 저장 위치를 묻고, 웹에서는 다운로드(또는 PDF는 인쇄 대화상자에서 "PDF로 저장")됩니다.
   - 내보낸 문서에는 **표지 페이지**와 **목차(인덱스) 페이지**가 본문 앞에 자동으로 들어갑니다. **PDF 목차에는 각 항목의 페이지 번호가 표시**됩니다.

## 4. 편집 탭

- **편집** 탭에서 병합 결과를 직접 수정할 수 있습니다. 수정 내용은 **미리보기** 와 **구조** 트리에 즉시 반영됩니다.
- 편집 후 **번호 다시 매기기** 로 번호를 재정렬하세요.
- 참고: 편집 후 다시 파일을 추가/선택하거나 옵션을 바꾸면 소스 기준으로 재병합되어 편집 내용이 대체됩니다. 편집 결과가 최종이면 바로 내보내기 하세요.

## 5. 설정 (⚙)

툴바의 톱니 버튼으로 **별도의 설정 창**을 엽니다. 이 창은 메인 창과 독립적으로 **이동**할 수 있으며, 변경 사항은 메인 창에 즉시 반영됩니다.

- **일반**
  - **언어**: 한국어 / English
  - **테마**: Dark / Light / Midnight / Nord / Forest / Rose / Solarized / Contrast (스와치 클릭). 툴바의 테마 버튼으로 순환할 수도 있습니다.
- **내보내기 글꼴**
  - **글꼴**: 드롭다운에서 선택. 맨 위 **System Default**(시스템 기본) 또는 시스템에 설치된 폰트. 선택한 글꼴은 미리보기에도 반영됩니다.
  - **기본 크기**: pt 단위.
- **표지 / 목차**
  - **표지 페이지** 자동 생성 여부, **표지 제목**(비우면 문서 제목 사용)
  - **목차 페이지** 생성 여부
- **머리글 / 바닥글 / 페이지 번호**
  - **머리글 문구 / 바닥글 문구** 와 각 정렬(왼쪽/가운데/오른쪽)
  - **페이지 번호** 표시/숨김, 위치(상/하 × 좌/중/우), **표지 포함 여부**
  - 이 설정은 내보내기(PDF에서 가장 정확, HTML/Word는 서식 지원 범위 내)에 적용됩니다.

설정은 자동 저장되어 다음 실행 시 유지됩니다.

## 6. 컨텍스트 메뉴 (우클릭)

- **파일**: 이 파일 선택/해제 · 위로/아래로 · 제거 · 전체 선택/해제 · 병합
- **구조**: 해당 위치로 이동 · 헤딩 텍스트 복사 · 번호 다시 매기기
- **미리보기**: 복사 · 전체 복사 · 번호 다시 매기기 · PDF/Word 내보내기
- **편집**: 잘라내기 · 복사 · 붙여넣기 · 전체 선택 · 번호 다시 매기기

## 7. 팁

- **번호 매기기** 는 코드블록(```` ``` ````) 안의 `#` 을 헤딩으로 오인하지 않습니다.
- 문서가 H2부터 시작해도 번호가 `1`, `1.1` 로 자연스럽게 붙습니다(상위 빈 레벨은 생략).
- 툴바·버튼 위에 마우스를 올리면 빠른 툴팁이 표시됩니다.

## 8. 자주 묻는 질문

- **Q. 웹에서 폴더를 선택했는데 파일이 안 보여요.**
  A. 폴더 안에 `.md`/`.markdown` 파일이 있어야 하며, 제외 패턴에 걸리지 않았는지 확인하세요.
- **Q. 폰트 목록이 몇 개만 나와요.**
  A. 브라우저/OS가 Local Font Access API 를 지원하지 않거나 권한이 거부되면 기본 폰트 목록으로 대체됩니다. 데스크톱(Electron) 버전에서는 시스템 폰트 전체가 표시됩니다.
- **Q. 설치 시 바로가기를 안 만들 수 있나요?**
  A. Windows 설치 마법사에서 바탕화면/시작 메뉴 바로가기를 개별 선택할 수 있습니다.
