# 사용자 가이드 — MyMarkDownMaker

## 1. 실행

- **데스크톱(개발):** `npm install` 후 `npm start`
- **웹:** `npm run web` → 브라우저에서 `http://localhost:5178`
- **설치본:** `npm run build:win`(또는 `:mac` / `:linux`) 로 만든 설치 파일 실행

## 2. 화면 구성

```
┌ 툴바(항상 한 줄) ─ 📁 · 📄 · 저장 · 인쇄 │ 정렬▾ · 하위폴더 · 파일명헤더 · 번호매기기 · 다시병합 │ 내보내기▾ │ 표지 · 목차 · 그림목차 · 페이지번호 · 머리글 · 바닥글 │ 글꼴크기 −/+ │ 확대/축소 −100%+ │ 실행취소 · 다시실행 │ 비우기 · 언어 · 테마 · 설정 · 정보 ┐
│                                    │                                                                    │
│  [파일] [구조] [그림] ← 사이드바   │   [편집] [미리보기]  ← 메인 영역                                    │
│   - 체크 / 순서(≡ 드래그·▲▼) / 제거 │   - Markdown 기호 바 + 원문 + 그림 패널 / 렌더링 결과                │
│                                    │                                                                    │
├ 상태바 ─ 상태 메시지 · 파일 수 · 헤딩 수 · 그림 수 · 단어/글자 수 · 폰트 · 테마 · 소스 경로 · 크기조절◢ ──┤
```

> 창은 **툴바 한 줄이 잘리지 않는 폭보다 좁아지지 않습니다.** 이 최소 폭은 실제로 그려진 툴바를 재서 정하므로 언어를 바꿔도 맞습니다. 오른쪽 아래 모서리의 **◢ 표시를 끌면** 창 크기를 조절할 수 있습니다(제목 표시줄이 앱 자체 것이라 OS 손잡이가 없습니다).
>
> 병합과 번호 매기기는 **자동**이라 별도 버튼이 없습니다. 파일이나 옵션을 바꾸면 즉시 병합되고, 편집을 멈추면 잠시 뒤 헤딩 번호와 목차가 자동으로 다시 매겨집니다. 이 자동 갱신은 **번호와 목차 줄만** 손대므로 직접 고친 글은 그대로 남습니다. 툴바의 **번호 매기기** 버튼으로 이 자동 번호를 끄고 켤 수 있습니다.

## 3. 기본 사용 흐름

1. **파일 수집**
   - **폴더 추가**(폴더 아이콘) — 폴더를 고르면 하위의 `.md`/`.markdown` 파일이 목록에 추가됩니다(툴바의 *하위폴더* 옵션으로 재귀 수집). **마지막에 연 폴더를 기억**하므로, 다음에 실행해도 폴더 선택 창이 그 폴더에서 바로 열립니다.
   - **파일 추가**(문서 아이콘) — 개별 파일을 선택해 추가합니다.
   - 이 두 버튼은 아이콘만 있습니다. 마우스를 올리면 이름과 설명이 나옵니다.
   - 폴더·파일은 **여러 번 반복해서 누적**할 수 있으며, 이미 있는 파일은 자동으로 제외됩니다.
2. **정렬 · 선택 · 순서 조정 (파일 탭)**
   - **정렬**은 툴바에 있습니다. **직접 지정** 은 순서를 수동으로 바꿀 때 자동 선택됩니다.
   - **선택/해제**: 각 행의 체크박스 또는 파일 이름을 클릭하면 병합 대상에 포함/제외됩니다.
   - **순서 변경**: 행 왼쪽의 손잡이(≡)를 **드래그**하거나, 행의 **▲ / ▼** 버튼을 사용합니다.
   - **제거**: 행의 **✕** 버튼.
3. **툴바의 병합 옵션** (버튼이 켜지면 강조 색으로 표시됩니다)
   - **정렬▾**: 이름 오름/내림, 최신/오래된 날짜순, 직접 지정
   - **하위폴더**: 폴더 추가 시 하위 폴더까지 재귀 수집
   - **파일명헤더**: 각 파일 앞에 `## 상대경로` 헤더를 넣어 섹션을 구분
   - **번호매기기**: **병합할 때** 문서 전체에 계층 번호(1, 1.1, 1.1.1 …)를 매김(끄면 원문 헤딩 유지)
   - **번호 다시 매기기**(그 옆의 목록 아이콘): 지금 이 문서의 헤딩 번호를 다시 매기고 목차를 맞춥니다. **편집 중에는 번호가 저절로 바뀌지 않습니다** — 이 버튼을 누를 때만 바뀝니다.
   - 이 네 가지(정렬·하위폴더·파일명헤더·번호매기기)는 **다음 실행에도 유지**되며 설정 창의 **병합 옵션** 에서도 바꿀 수 있습니다.
4. **자동 병합 · 미리보기** — 파일을 선택/체크/재정렬하거나 옵션을 바꾸면 **자동으로 병합되어** 오른쪽 미리보기와 왼쪽 **구조** 트리가 즉시 갱신됩니다. 병합이 오래 걸리면 진행률 팝업이 표시됩니다. **문서를 한 번이라도 직접 고친 뒤에는 이 자동 병합이 멈춥니다** — 편집한 문서가 사라지지 않도록, 툴바의 **다시 병합** 버튼을 누를 때만 원본에서 새로 만듭니다.
5. **구조 탭** 에는 문서가 가진 **표지 · 목차 · 그림 목차 페이지가 맨 위에** 회색 기울임으로 표시되고, 그 아래에 본문 헤딩 트리가 이어집니다(표지 줄에는 표지에 적힌 제목이 보입니다). 어느 항목이든 클릭하면 **보고 있는 탭 안에서** 그 위치로 갑니다 — 미리보기면 그 페이지/헤딩으로 스크롤하고, 편집 중이면 편집기가 그 줄로 스크롤하며 줄이 선택됩니다(탭이 바뀌지 않습니다). 그림 탭도 같습니다.
   - 이 페이지들은 헤딩이 아니므로 번호가 붙지 않고 목차에도 들어가지 않습니다. 상태바의 헤딩 수에도 세지 않습니다.
6. **저장** — 툴바 왼쪽, **파일 추가 옆의 저장**(디스크 아이콘) 또는 **Ctrl S** 로 편집한 문서를 그대로 `.md` 파일에 저장합니다.
   - 처음 저장할 때만 위치를 묻고, 그다음부터는 **같은 파일에 덮어씁니다.** 다른 이름으로 저장하려면 **Ctrl Shift S**.
   - 저장하지 않은 변경이 있으면 버튼 오른쪽 위에 **작은 점**이 표시됩니다(옵션 토글처럼 켜진 모양이 되지는 않습니다). 마우스를 올리면 현재 저장 경로가 보입니다.
   - 저장되는 내용은 **Markdown 내보내기와 똑같습니다** — 표지·목차 블록이 주석 표시(`<!-- mmm:cover -->`)와 함께 그대로 들어가고, 그림은 원본 데이터로 되살아나 파일 안에 들어갑니다. 이 주석은 다른 Markdown 뷰어에서는 보이지 않습니다.
   - 웹에서는 브라우저가 이전 경로에 덮어쓸 수 없어 매번 다운로드됩니다.
7. **인쇄** — 저장 버튼 오른쪽의 **인쇄**(프린터 아이콘) 또는 **Ctrl P**.
   - 인쇄되는 것은 **미리보기 그대로**입니다 — 표지, 목차(실제 페이지 번호 채워짐), 그림 목차, 본문, 머리글·바닥글·쪽 번호까지 PDF 내보내기와 완전히 같은 결과를 그대로 프린터로 보냅니다.
   - 시스템 인쇄 대화상자가 열리므로 프린터·매수·범위는 거기서 고릅니다. 창을 닫으면 상태바에 취소되었다고 표시됩니다.
8. **내보내기** — 툴바의 **내보내기▾** 를 열면:
   - 상단 **파일 이름** 입력칸(기본값: 표지 제목, 수정 가능)
   - **Markdown / HTML / PDF / Word** 중 선택
   - 데스크톱에서는 저장 위치를 묻고, 웹에서는 다운로드(또는 PDF는 인쇄 대화상자에서 "PDF로 저장")됩니다.
   - 내보낸 문서에는 **표지 페이지**와 **목차(인덱스) 페이지**가 본문 앞에 자동으로 들어갑니다. **목차의 각 항목 오른쪽에는 실제 페이지 번호**가 표시되며(최상위 H1 항목은 굵게), PDF·Word·HTML에 모두 적용됩니다. *(Word 페이지 번호는 근사값)*
   - 문서에 그림이 있으면 목차 다음에 **그림 목차 페이지**가 별도로 들어갑니다(그림이 없으면 만들어지지 않습니다).

## 4. 그림 탭

- 좌측 **그림** 탭에는 문서에 포함된 모든 그림이 `그림 N` 번호와 썸네일로 나열됩니다.
- 항목을 클릭하면 **미리보기**에서는 해당 그림으로 스크롤하고, **편집** 탭에서는 그 그림을 넣은 이미지 링크가 선택됩니다.
- 편집 중 커서가 이미지 링크 안에 있으면 목록에서 해당 그림이 자동으로 강조됩니다.
- 각 항목의 **슬라이더로 그림 크기**(문서 폭 대비 10~100%)를 조절할 수 있고, **되돌리기** 로 원본 크기로 돌아갑니다. 조절한 크기는 원문에 `![설명](… "w=60%")` 로 기록되어 미리보기와 모든 내보내기에 그대로 반영됩니다.
- 크기를 지정하지 않은 그림은 **페이지에 맞게 자동으로 줄여서** 내보냅니다. 원본이 페이지보다 넓으면 페이지 폭에, 세로로 너무 길면 페이지 높이에 맞춰 비율을 유지한 채 축소하므로 PDF·Word에서 그림이 여백을 넘어가지 않습니다(작은 그림은 억지로 늘리지 않습니다).
- 내보낸 문서에서는 단독으로 놓인 그림 아래에 `그림 N. 설명` 캡션이 붙고, **그림 목차 페이지**의 항목이 이 번호를 가리킵니다. 설명은 이미지의 대체 텍스트(`![설명](...)`)를 쓰며, 없으면 이미지 파일 이름을 사용합니다.
- **번호는 앱이 새로 매깁니다.** 대체 텍스트에 이미 번호가 들어 있으면(`그림 3-1. 처리 흐름`, `[그림 5] 인증 절차`, `Figure 2. Access control`, `1-1. 개요도` 등) 그 부분을 떼어 내고 문서 순서대로 `그림 1, 2, 3 …` 을 다시 붙입니다. 그래서 `그림 1. 그림 3-1 처리 흐름` 처럼 번호가 겹쳐 나오지 않습니다. (`2024 매출 그래프` 처럼 번호로 보기 어려운 앞자리는 그대로 둡니다.)

## 5. 편집 탭

- **편집** 탭은 미리보기와 **똑같은 문서 전체**(표지 · 목차 · 그림 목차 · 본문)를 Markdown 원문으로 보여 주며, 그 전체를 직접 고칠 수 있습니다. 고친 내용이 그대로 미리보기와 내보내기에 반영됩니다.
- 표지·목차·그림 목차는 다음과 같은 주석 표시로 감싸여 있습니다. 이 표시가 있어야 내보낼 때 표지는 가운데 정렬된 표지 페이지로, 목차는 페이지 번호가 붙은 표로 만들어집니다. **표시 줄은 지우지 마세요.**

  ```
  <!-- mmm:cover -->
  # 문서 제목
  <!-- /mmm:cover -->
  ```

- 표지의 날짜가 `2026\. 9. 9.` 처럼 **역슬래시와 함께** 보일 수 있습니다. Markdown 에서 `2026.` 으로 시작하는 줄은 번호 목록으로 읽히기 때문에 그렇게 되지 않도록 표시해 둔 것으로, 미리보기와 내보낸 문서에는 `2026. 9. 9.` 로 나옵니다. 지우지 마세요.
- 목차 항목의 `[제목](#h-3)` 에서 **`#h-3` 부분이 페이지 번호를 찾는 열쇠**입니다. 제목 글자는 마음대로 고쳐도 되지만 괄호 안의 앵커는 그대로 두세요(지우면 그 항목만 페이지 번호가 비어 나옵니다).
- 문서에 그림이 있으면 편집기 오른쪽에 **그림 패널**이 붙어, 원문을 고치면서도 실제 이미지를 볼 수 있습니다.
- 편집기 본문에서 이미지는 `mmm-img:N` 같은 짧은 참조로 보입니다. 이는 수 MB짜리 Base64 데이터가 편집 화면을 뒤덮지 않게 하기 위한 것으로, 미리보기와 **모든 내보내기에서 원본 이미지 데이터로 되살아나 문서에 내장**됩니다. 이 참조 문자열은 지우거나 바꾸지 마세요.
- 편집기 위에 **Markdown 기호 바**가 있습니다. 커서가 있는 줄이나 선택한 글에 표시를 넣고 뺍니다.
  - **H1 ~ H5** — 제목 수준(같은 단추를 다시 누르면 제목 해제). 이 문서 형식은 **H6을 쓰지 않습니다.**
  - **B / I / S / `** — 굵게 · 기울임 · 취소선 · 인라인 코드 (다시 누르면 해제)
  - **• / 1. / ❝** — 글머리 목록 · 번호 목록 · 인용
  - **🔗 / 🖼 / { } / ▦ / ―** — 링크 · 그림 · 코드 블록 · 표 · 구분선
  - 단축키: **Ctrl B**, **Ctrl I**, **Ctrl 1~5**
- **구조 트리·미리보기·통계는 타이핑을 따라오지 않습니다.** **한 줄을 다 쓴 뒤**에 한 번만 갱신됩니다 — Enter, 방향키·Home·End 로 줄을 벗어날 때, 마우스로 다른 곳을 클릭할 때, 편집기 밖으로 나갈 때, 탭을 바꿀 때, 그리고 그냥 입력을 멈췄을 때입니다. 그래서 큰 문서에서도 글자 입력이 밀리지 않습니다. 미리보기는 **미리보기 탭을 열 때** 그 시점 내용으로 만들어집니다.
- **목차는 자동으로 따라옵니다.** 헤딩을 고치거나 더하거나 지우면 목차 페이지가 그에 맞게 갱신됩니다(그림을 넣거나 빼면 그림 목차도 마찬가지).
- **헤딩 번호는 저절로 바뀌지 않습니다.** 번호를 다시 매기는 것은 지금 쓰고 있는 줄을 앱이 고쳐 쓰는 일이라, **툴바의 번호 다시 매기기 버튼을 누를 때만** 일어납니다(병합할 때는 *번호매기기* 옵션에 따라 한 번 매겨집니다).
- 헤딩이 하나도 없는 상태로 병합했다면 문서에 목차 블록 자체가 없습니다. 이때 헤딩을 새로 쓰면 **목차 블록이 자동으로 만들어집니다**(그림을 처음 넣었을 때 그림 목차도 같습니다). 목차를 원하지 않으면 툴바의 **목차** 버튼을 끄세요 — 꺼 두면 만들어지지 않습니다.
- **고친 내용은 그대로 남습니다.** 자동 갱신은 앱이 만들어 주는 부분(헤딩 번호, 목차·그림 목차의 줄)만 제자리에서 고쳐 씁니다. 표지 문구, 본문, 직접 넣은 빈 줄은 건드리지 않으므로 표지 제목이나 날짜를 손으로 고쳐도 되돌아가지 않습니다. 손으로 지운 표지·목차 블록도 다시 살아나지 않습니다.
- **한 번 손대면 그 문서는 독립된 문서입니다.** 예전에는 파일 목록에서 체크 하나만 바꿔도 원본에서 다시 병합되어 편집 내용이 통째로 날아갔습니다. 이제는 편집한 뒤에 파일 선택·순서·병합 옵션을 바꾸면 **문서를 그대로 두고**, 툴바의 **다시 병합** 버튼이 강조되어 선택이 바뀌었음을 알려 줍니다. 원본에서 새로 만들고 싶을 때만 그 버튼을 누르세요(그때는 편집 내용이 사라집니다).
- 설정 창에서 표지·목차 관련 설정을 바꾸면 **표지/목차/그림 목차 블록만** 새로 만들어집니다(본문 편집 내용은 유지). 편집 결과가 최종이면 바로 내보내기 하세요.

## 6. 미리보기 탭

**미리보기** 는 내보낼 문서 전체를 그대로 보여 줍니다.

1. **표지** — 제목·부제(머리글 문구)·버전/작성자/날짜
2. **목차** — 각 항목을 클릭하면 본문의 해당 헤딩으로 이동
3. **그림 목차** — 각 항목을 클릭하면 해당 그림으로 이동 (그림이 없으면 이 페이지 자체가 없습니다)
4. **본문** — 그림이 그대로 표시되고, 단독 그림에는 `그림 N.` 캡션이 붙습니다

각 블록 사이의 점선은 내보낼 때 **페이지가 나뉘는 위치**입니다. 페이지 번호는 실제 페이지 나눔이 필요하므로 미리보기에는 표시되지 않고, PDF·Word·HTML 내보내기에서 채워집니다.

## 7. 설정 (⚙)

### 툴바의 빠른 설정 버튼

자주 바꾸는 내보내기 옵션은 설정 창을 열지 않고 툴바에서 바로 켜고 끌 수 있습니다. 켜져 있으면 버튼이 강조 색으로 표시되고, 마우스를 올리면 현재 상태(켬/끔)가 툴팁에 나옵니다.

| 버튼 | 하는 일 |
|------|---------|
| 번호 다시 매기기 | 지금 문서의 헤딩 번호를 다시 매기고 목차를 맞춥니다(토글이 아니라 동작) |
| 다시 병합 | 선택한 파일에서 문서를 다시 만듭니다. 편집한 문서를 유지하는 중이면 강조됩니다 |
| 표지 | 표지 페이지 생성 여부 |
| 목차 | 목차 페이지 생성 여부 |
| 그림 목차 | 그림 목차 페이지 생성 여부 (그림이 없으면 켜도 만들어지지 않음) |
| 페이지 번호 | 내보낸 문서의 페이지 번호 표시 여부 |
| 머리글 | 머리글 문구 사용 여부 (문구 자체는 설정 창에서 입력. 툴팁에 현재 문구가 보입니다) |
| 바닥글 | 바닥글 문구 사용 여부 (문구 자체는 설정 창에서 입력) |
| **− 10pt +** | 본문 기본 글꼴 크기(6~40pt) |

**툴바의 모든 옵션은 설정 창에도 같은 항목이 있습니다** — 정렬·하위 폴더·파일명 헤더·번호 매기기는 설정 창의 **병합 옵션** 에, 표지·목차·그림 목차·페이지 번호·머리글·바닥글은 그 아래 항목들에 있습니다. 툴바와 설정 창은 **같은 설정 하나**를 고치는 것이라 어느 쪽에서 바꾸든 즉시 서로 반영되고, **모두 저장되어 다음 실행에 그대로 복원됩니다**(테마·언어·확대 비율도 마찬가지).

### 화면 확대 / 축소

툴바 오른쪽의 **− 100% +** 로 미리보기와 편집 화면을 확대·축소합니다(50~300%, 10% 단위). 가운데 비율 숫자를 누르면 100%로 돌아갑니다.

- 단축키: **Ctrl +** / **Ctrl −** / **Ctrl 0**, 그리고 **Ctrl + 마우스 휠**
- 저장·인쇄 단축키: **Ctrl S**(저장) / **Ctrl Shift S**(다른 이름으로 저장) / **Ctrl P**(인쇄) — 편집 중에도 동작합니다.
- 실행 취소·다시 실행: 툴바 확대/축소 오른쪽의 **↶ ↷** 버튼, 또는 편집기에서 **Ctrl Z** / **Ctrl Y**(=Ctrl Shift Z). 연속으로 친 글은 한 단계로 묶이고, 앱이 자동으로 매기는 번호·목차 갱신은 별도 단계가 되지 않습니다. 새로 병합하면 기록이 초기화됩니다.
- 미리보기·편집 창의 우클릭 메뉴에도 같은 항목이 있습니다.
- 화면에서 크게 보기 위한 기능이라 **내보낸 문서에는 영향을 주지 않습니다**(내보내기 크기는 글꼴 크기와 그림 크기 설정이 결정합니다). 선택한 비율은 다음 실행에도 유지됩니다.

### 설정 창

툴바의 톱니 버튼으로 **별도의 설정 창**을 엽니다. 이 창은 메인 창과 독립적으로 **이동**할 수 있고, 모든 항목이 한 화면에 들어오도록 **3단 레이아웃의 고정 크기**로 열립니다(크기 조절 불가, 가로·세로 스크롤 없음). 변경 사항은 메인 창에 즉시 반영됩니다. 하단의 **설정 초기화** 버튼으로 모든 내보내기 설정을 기본값으로 되돌릴 수 있습니다.

- **일반**
  - **언어**: 한국어 / English (툴바의 지구본 아이콘으로도 전환)
  - **테마**: Dark / Light / White / Midnight / Nord / Forest / Rose / Solarized / Contrast / Ocean / Mocha / Sky / Violet / Amber / Mint / Sand (스와치 클릭, 총 16종). 툴바의 테마 버튼으로 순환할 수도 있습니다.
- **내보내기 글꼴**
  - **글꼴**: 드롭다운에서 선택. 맨 위 **System Default**(시스템 기본) 또는 시스템에 설치된 폰트. 선택한 글꼴은 미리보기와 내보내기에 동일하게 반영됩니다.
  - **기본 크기**: pt 단위(기본 10). 좌우 **− / +** 버튼으로 1씩 조절하거나 직접 입력.
  - **줄 간격**: 기본 1.5. 좌우 **− / +** 버튼으로 0.5씩 조절하거나 직접 입력.
- **표지 / 목차 / 그림 목차**
  - **표지 페이지** 자동 생성 여부, **표지 제목**(비우면 문서 제목 사용), 버전/작성자/날짜 표시
  - 표지 제목은 **내보내기 기본 파일 이름**이기도 합니다 — 내보내기 창의 이름 칸에 표지 제목이 그대로 채워집니다(직접 다른 이름을 입력하면 그 이름이 우선). 표지가 없는 문서만 첫 번째 파일 이름을 씁니다.
  - **제목 글꼴 / 크기 / 정렬**: 표지 제목만 따로 글꼴과 크기(pt, 비우면 자동)를 정하고 왼쪽·가운데·오른쪽 정렬을 고를 수 있습니다.
  - **버전·작성자·날짜 정렬**: 표지의 세 줄을 한꺼번에 왼쪽·가운데·오른쪽으로 맞춥니다.
  - **작성 날짜**: 달력에서 고릅니다. 고르지 않으면 항상 **오늘 날짜**가 들어가며, **오늘** 버튼을 누르면 다시 그 상태로 돌아갑니다. 표지에는 선택한 언어에 맞는 형식으로 표시됩니다.
  - **목차 페이지** 생성 여부 (목차 항목 오른쪽에 페이지 번호 표시)
  - **그림 목차 페이지** 생성 여부 (그림이 없는 문서에서는 켜 두어도 만들어지지 않습니다). 끄면 본문의 `그림 N.` 캡션도 표시되지 않습니다.
- **머리글 / 바닥글 / 페이지 번호**
  - **머리글 사용 / 바닥글 사용** — 툴바의 머리글·바닥글 버튼과 같은 스위치입니다. 끄면 문구는 그대로 남아 있고 표시만 빠지므로, 다시 켜면 같은 문구가 돌아옵니다. 머리글 문구는 **표지의 부제**로도 쓰이므로 끄면 표지 부제도 함께 빠집니다.
  - **머리글 문구 / 바닥글 문구** 와 각 정렬(왼쪽/가운데/오른쪽)
  - **페이지 번호** 표시/숨김, 위치(상/하 × 좌/중/우), **표지 포함 여부**
  - **PDF 와 Word(.doc) 에 모두 적용됩니다.** Word 는 CSS 머리글/바닥글을 이해하지 못하므로 Word 전용 머리글·바닥글 블록과 진짜 `PAGE` 필드로 내보냅니다(문서를 고쳐도 쪽 번호가 알아서 다시 매겨집니다). 표지에 번호를 넣지 않도록 해 두면 Word 에서도 첫 쪽만 번호가 빠집니다.
  - HTML 내보내기는 브라우저가 페이지로 나뉘지 않으므로 화면에서는 머리글·바닥글이 보이지 않습니다(브라우저 인쇄 시에도 브라우저 자체 머리글/바닥글이 우선합니다).

설정은 자동 저장되어 다음 실행 시 유지됩니다. 설정 창은 **폼 높이에 맞춰 스스로 크기를 잡으므로** 항목이 늘어도 가려지지 않습니다.

### 오류가 났을 때

무엇이든 실패하면 **팝업**이 뜹니다 — 무엇을 하다 실패했는지, 오류 메시지, 그리고 있으면 스택까지 보여 줍니다. **내용 복사** 버튼을 누르면 그 전부가 클립보드에 담기므로 그대로 붙여 넣어 문의하실 수 있습니다. 내보내기·저장·인쇄뿐 아니라 예기치 못한 오류도 같은 팝업으로 나옵니다.

## 8. 종료 시 저장 확인

병합하거나 편집한 뒤 **아직 내보내지 않은 변경 내용**이 있는 상태로 앱을 닫으면 확인 창이 뜹니다.

- **저장** — Markdown(`.md`) 저장 대화상자를 열고, 저장이 끝나면 종료합니다. 저장 대화상자를 취소하면 앱은 그대로 열려 있습니다.
- **저장 안 함** — 변경 내용을 버리고 바로 종료합니다.
- **취소** — 종료를 멈추고 작업을 계속합니다.

한 번 내보내기에 성공하면 그 내용은 "저장됨"으로 간주되어, 이후 다시 고치기 전까지는 확인 창이 뜨지 않습니다. 웹 버전에서는 브라우저 자체의 "이 사이트를 나가시겠습니까?" 경고로 대체됩니다.

## 10. 팁

- 넓은 **ASCII 도형**(코드블록 안의 박스 그림)은 내보낼 때 페이지 폭에 맞게 글자 크기를 줄여서 넣습니다. 줄바꿈을 하면 그림이 깨지기 때문에 축소하는 쪽을 택했습니다. 화면 미리보기에서는 가로 스크롤로 원래 크기 그대로 봅니다.
- **번호 매기기** 는 코드블록(```` ``` ````) 안의 `#` 을 헤딩으로 오인하지 않습니다.
- 문서가 H2부터 시작해도 번호가 `1`, `1.1` 로 자연스럽게 붙습니다(상위 빈 레벨은 생략).
- 툴바·버튼 위에 마우스를 올리면 빠른 툴팁이 표시됩니다.

## 11. 자주 묻는 질문

- **Q. 웹에서 폴더를 선택했는데 파일이 안 보여요.**
  A. 폴더 안에 `.md`/`.markdown` 파일이 있는지 확인하세요.
- **Q. 내보낸 PDF/Word에서 목차의 페이지 번호가 실제와 조금 달라요.**
  A. PDF는 실제 페이지를 정확히 계산합니다. Word는 열 때 자체적으로 다시 페이지를 나누므로 A4 기준의 근사값으로 표시됩니다.
- **Q. 폰트 목록이 몇 개만 나와요.**
  A. 브라우저/OS가 Local Font Access API 를 지원하지 않거나 권한이 거부되면 기본 폰트 목록으로 대체됩니다. 데스크톱(Electron) 버전에서는 시스템 폰트 전체가 표시됩니다.
- **Q. 설치 시 바로가기를 안 만들 수 있나요?**
  A. Windows 설치 마법사에서 바탕화면/시작 메뉴 바로가기를 개별 선택할 수 있습니다.
