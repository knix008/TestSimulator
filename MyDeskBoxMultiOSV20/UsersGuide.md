# MyDeskBox 사용 안내

바탕화면 항목을 반투명 박스에 모아 두는 프로그램입니다. Windows, macOS, Linux에서 동작합니다. 배경 그림 위에 사각형을 그리지 않고, 박스마다 투명한 창을 띄웁니다.

## 설치와 실행

개발 중인 소스를 바로 띄울 때:

```bash
npm install
npm start
```

설치 파일로 깔 때는 운영체제에 맞는 묶음을 씁니다. 만드는 방법은 [README.md](README.md)의 설치 파일 만들기를 보면 됩니다.

- Windows 설치 첫 화면에서 한국어와 영어 중 설치 언어를 고릅니다.
- 바탕화면 바로 가기와 시작 메뉴 바로 가기는 각각 만들지 물어봅니다.
- 이미 깔려 있으면 프로그램만 다시 깝니다. 박스 배치도, 박스에 담아 둔 파일도 그대로 둡니다. 바로 가기는 지금 있는 그대로를 따라갑니다.
- 예전 설정을 모두 지울지는 프로그램이 깔려 있지 않을 때만 물어봅니다. 기본은 지우지 않는 쪽이고, 고르면 한 번 더 확인합니다. 박스에 담겨 있던 파일은 지우기 전에 바탕화면으로 돌려 놓습니다.

### 다음부터는 저절로 켜집니다

설치하고 나면 로그인할 때 스스로 켜집니다. 시스템을 다시 켜도 박스가 지난번 자리와 크기, 지난번 테마 그대로 돌아옵니다. 숨겨 둔 채로 끝냈다면 숨은 채로 시작합니다.

원하지 않으면 트레이 메뉴의 **빠른 설정 › 시작할 때 실행** 이나 설정 창의 **일반** 탭에서 끕니다. 한 번 끄면 다시 켜 주지 않습니다.

### 작업 표시줄에는 나타나지 않습니다

박스도, 설정 창도, 묻는 창도 작업 표시줄에 단추를 만들지 않습니다. macOS 에서는 Dock 아이콘도 감춥니다. 프로그램을 다루는 자리는 트레이 아이콘 하나입니다.

## 담는다는 것은 옮긴다는 뜻입니다

가장 먼저 알아 두실 것입니다. **박스에 담으면 그 파일이 박스의 폴더로 옮겨 갑니다.**

- 자리는 설정 폴더 아래 `boxes\<박스 이름>` 입니다.
- 옮겨 갔으므로 바탕화면에서는 사라집니다. 같은 항목이 두 곳에 함께 보이지 않습니다.
- 꺼내거나, 박스를 지우거나, 프로그램을 끝내면 **담기 전에 있던 폴더로 돌아갑니다.**
- 탐색기로 그 폴더를 열어 파일을 넣거나 지워도 됩니다. 박스가 곧 따라옵니다.

### 바탕화면에 같은 이름으로 새로 만들면

담긴 파일은 박스 폴더에 있어 탐색기 눈에 보이지 않습니다. 그래서 박스가 이미 들고 있는 이름으로도 바탕화면에 '새 폴더' 나 '새 텍스트 문서' 가 아무 말 없이 만들어집니다.

그런 것이 생기면 바로 물어봅니다.

| 고른 것 | 일어나는 일 |
| --- | --- |
| 대체 | 새로 만든 것이 그 박스로 들어갑니다. 박스에 있던 것은 휴지통으로 갑니다. |
| 새로 만들기 | 새로 만든 것을 바탕화면에 그대로 둡니다. 박스는 그대로입니다. |

한 번 물은 것은 다시 묻지 않습니다. 켤 때 이미 바탕화면에 있던 것도 묻지 않습니다.

프로그램 없이 되돌려야 할 일이 생기면 `boxes\restore.json` 을 보면 됩니다. 어느 파일이 어디서 왔는지 적혀 있습니다.

## 처음 실행

설정을 한 번도 저장하지 않은 첫 실행에서는 바탕화면 항목을 종류별로 나눠 담을지 물어봅니다. 나눠 담으면 **그 파일들이 박스 폴더로 옮겨 가므로**, 원하지 않으면 거절하고 빈 바탕화면으로 시작할 수 있습니다.

| 종류 | 들어가는 것 | 기본 테마 |
| --- | --- | --- |
| 폴더 | 폴더 | 청록 |
| 바로가기 | `.lnk`, `.url`, `.desktop` | 바다 |
| 문서 | 문서, 스프레드시트, 한글 문서 등 | 황금 |
| 사진·영상 | 그림, 영상, 소리 | 노을 |
| 시스템 | 휴지통, 내 PC 같은 셸 항목 | 밤 |
| 그 밖의 것 | 위에 속하지 않는 파일 | 강철 |

비어 있는 종류는 박스를 만들지 않습니다. 나눌 항목이 하나도 없거나 나눠 담기를 거절하면 빈 곳을 끌어 박스를 그리는 상태로 시작합니다. 이미 한 번 실행해 배치가 있으면 그 배치를 유지하고, 다시 자동으로 나누지 않습니다.

## 박스 만들기와 옮기기

- 트레이 아이콘을 누르거나, 박스 메뉴의 **새 박스 그리기**로 빈 곳을 끌어 박스를 만듭니다. Esc 로 취소합니다.
- Windows에서는 바탕화면 빈 곳을 끌어 사각형을 만들면, 그 자리에 박스를 만들지 물어봅니다. 너무 작은 사각형은 묻지 않습니다.
- 제목 줄을 끌면 박스가 움직입니다. 가장자리를 끌면 크기가 바뀝니다.
- 제목을 두 번 누르면 접히고, 제목 줄만 남습니다. 다시 두 번 누르면 펼쳐집니다.
- 박스를 지우면 안에 있던 파일은 모두 담기 전 폴더로 돌아갑니다. 삭제를 취소하면 그대로입니다.

### 자리와 크기는 원하는 대로, 가까우면 딱 맞게

박스를 바탕화면 아이콘 격자에 **묶어 두지 않습니다.** 원하는 자리와 크기로 둘 수 있고, 다음 경우에만 자석처럼 붙습니다.

- 아이콘 칸 경계에서 **한 칸의 1/5 안**에 들어오면 그 칸에 딱 맞게 붙습니다.
- 화면 가장자리에 가까우면 가장자리에 딱 붙습니다. 왼쪽 끝에 붙여 두면 되튀지 않고 그대로 붙어 있습니다.
- **크기만 바꾸면 자리는 그대로입니다.** 자리만 옮기면 크기가 그대로입니다.
- **켤 때는 박스를 손보지 않습니다.** 어제 놓아 둔 자리에 오늘도 그대로 있습니다. 화면 수나 해상도가 바뀌어 자리가 화면 밖으로 나간 경우에만 안으로 들입니다.

### 박스끼리는 겹치지 않습니다

- 다른 박스 위에 놓으면 **가장 적게 움직이는 쪽**으로 비킵니다.
- 크기를 키우다 옆 박스에 닿으면 자리를 옮기지 않고 **닿은 데서 멈춥니다.**

## 항목 넣기와 빼기

- 아이콘은 **박스 → 바탕화면, 바탕화면 → 박스, 박스 → 박스** 모두 끌어 옮길 수 있습니다. 끄는 동안 아이콘은 계속 손을 따라다닙니다.
- 박스 안에서 아이콘을 끌면, 커서가 가리키는 칸이 비도록 있던 아이콘이 밀립니다.
- 아이콘이 박스보다 많으면 오른쪽 막대로 넘겨 봅니다.
- 파일 탐색기에서 끌어다 놓아도 들어갑니다. 바탕화면이 아닌 폴더에서 온 파일은 **그 폴더로** 돌아갑니다.
- 아이콘의 **그림 위**에 놓으면 그 항목에게 넘깁니다. 폴더나 폴더 바로가기면 그 안으로 들어가고, 휴지통이면 버려집니다. 그 밖의 항목이면 **그 항목이 실행되면서 놓은 파일을 입력으로 받습니다.** 넘겨준 파일은 박스에 그대로 남습니다.
- 그림이 아닌 칸 사이에 놓으면 넘기지 않고 차례만 바뀝니다.
- 담으려는 이름이 박스에 이미 있으면 **대체할지 물어봅니다.** 대체하면 박스에 있던 것이 휴지통으로 가고, 취소하면 담지 않고 파일을 있던 자리에 둡니다.
- 아이콘을 두 번 누르면 열립니다. 설정에서 **한 번 눌러 열기**로 바꿀 수 있습니다.
- 아이콘 위 오른쪽 단추 메뉴에는 **열기**, **이름 바꾸기**, **바탕화면으로 꺼내기**, **삭제**가 있습니다. 삭제하면 파일은 휴지통으로 갑니다.
- **이름 바꾸기**는 아이콘 글자 자리에 입력칸을 띄웁니다. Enter로 바꾸고 Esc로 그만둡니다. 박스 폴더 안의 파일 이름이 실제로 바뀌므로, 꺼내면 바뀐 이름으로 바탕화면에 돌아갑니다. 확장자를 감춰 보고 있었다면 확장자는 그대로 이어 줍니다.

### 다른 항목 위에 놓기

아이콘의 **그림 위**에 놓으면 그 항목에게 넘깁니다. 그림 둘레로 조금 넉넉하게 받아 주니 가운데를 정확히 겨누지 않아도 됩니다. 받을 항목이 정해지면 그 아이콘이 밝아지고 그림이 살짝 커집니다. 그 표시가 없으면 아이템 사이에 끼워 넣는 것입니다.

| 아래에 있는 것 | 일어나는 일 |
| --- | --- |
| 휴지통 | 버립니다 |
| 폴더, 폴더를 가리키는 바로가기 | 그 안으로 옮깁니다 |
| 프로그램, 프로그램 바로가기 | 그 프로그램이 실행되면서 놓은 파일을 받습니다. 놓은 파일은 박스에 남습니다 |
| 문서 | 짝지어 둔 프로그램이 두 파일을 함께 엽니다 |

칸의 **좌우 끝과 글자 줄**은 '사이에 끼우기' 로 남겨 두었습니다. 거기에 놓으면 순서만 바뀝니다.

같은 박스 안에서든, 다른 박스에서 건너오든, 바탕화면이나 탐색기에서 끌어 오든 모두 같습니다.

### 박스 안의 아이콘은 바탕화면과 똑같이 보입니다

- 이름은 탐색기가 바탕화면에 적는 글 그대로입니다. 확장자를 감추는 설정과 폴더의 번역된 이름(`Documents` → `문서`)까지 따라갑니다.
- 폴더는 폴더답게, 바로가기는 가리키는 프로그램의 그림으로 보입니다.
- **그림 파일은 미리 보기**로 보입니다. 종류 그림이 아니라 사진 자체가 작게 나옵니다.

### 휴지통

- Windows에서는 바탕화면의 휴지통을 끌어 박스에 넣을 수 있습니다. 끌어 넣기가 안 되는 항목은 박스 메뉴의 **바탕화면 항목 담기**로 담습니다.
- 담으면 바탕화면 쪽 휴지통은 감춰집니다. 박스가 대신 보여 주므로 두 곳에 겹쳐 보이지 않습니다.
- **가득 찼을 때와 비었을 때 그림이 다릅니다.** 오른쪽 단추 메뉴의 **휴지통 비우기**로 비울 수 있습니다.
- 꺼내거나 프로그램을 끝내면 바탕화면에 다시 나타납니다. 바로 안 보이면 바탕화면을 클릭한 뒤 F5를 누릅니다.

## 바탕화면 아이콘은 박스를 피해 갑니다

- 박스가 덮은 자리의 아이콘은 밖의 빈 칸으로 비킵니다. 박스 아래에 아이콘이 깔리지 않습니다.
- 갈 곳은 **제자리에서 가장 가까운 빈 칸**입니다. 화면 구석으로 날아가지 않고 옆으로 한 걸음만 옮깁니다.
- **박스를 옮기면 비켰던 아이콘이 제자리로 돌아옵니다.** 박스가 지나간 자리에 구멍이 남지 않습니다.
- 박스를 끄는 동안에도 아이콘이 따라 비킵니다.
- 이 동안 Windows의 '아이콘 자동 정렬'은 꺼 둡니다. 켜져 있으면 탐색기가 아이콘을 박스 밑으로 곧바로 되돌려 놓기 때문입니다. 프로그램을 끝내면 원래대로 되돌립니다.

## 끝내면 바탕화면이 돌아옵니다

담아 둔 파일과 비켰던 아이콘이 **모두** 원래 자리로 돌아갑니다. 끝나는 길이 어느 쪽이든 같습니다.

| 어떻게 끝나든 | 무엇이 돌아오나 |
| --- | --- |
| 트레이의 **종료** | 담은 파일, 아이콘 자리, 감춘 휴지통, 자동 정렬 설정 |
| `Ctrl+C`, 로그아웃, 작업 종료 | 위와 같음 |
| 큰 오류로 멈춤 | 위와 같음. 되돌린 **뒤에** 무슨 오류인지 알려 줍니다 |
| 전원 내림, 작업 관리자의 강제 종료 | 아무것도 못 하고 끝나므로, **다음에 켤 때** 남은 파일을 제자리로 돌려놓습니다 |

큰 오류로 멈출 때 뜨는 창에는 판과 운영체제와 오류 내용이 적혀 있고, **복사** 단추로 그대로 클립보드에 담아 전할 수 있습니다.

기다리지 않고 지금 돌려받고 싶으면 트레이나 설정 창의 **바탕화면으로 모두 돌려주기**를 누릅니다. 박스는 그대로 남고 안의 것만 비워집니다.

## 프로그램 설정

트레이 메뉴의 **설정**을 누르면 설정 창이 열립니다. 창 크기는 고정이고 항목은 탭으로 나뉩니다. 제목 줄에는 톱니바퀴가 있습니다.

| 탭 | 들어 있는 것 |
| --- | --- |
| 일반 | 언어, 아이콘을 한 번/두 번 눌러 열기, 시작할 때 실행 |
| 모양 | 새 박스의 테마·모서리·투명도, 박스 그림자 |
| 폴더 | 박스 폴더와 설정 폴더 열기, 보관함 자리 보기, 바탕화면으로 모두 돌려주기 |
| 프로그램 정보 | 판, 만든 이, 전자우편 |

자주 바꾸는 값은 트레이의 **빠른 설정** 아래에도 그대로 있습니다.

## 이 박스의 설정

제목 줄 오른쪽의 톱니, 또는 오른쪽 단추 메뉴의 **이 박스 설정**에서 그 박스만 바꿉니다.

- 이름
- 테마 서른 가지. 원하는 색이 없으면 바탕과 제목 줄 색을 직접 고릅니다.
- 모서리. 각진 것부터 둥근 것까지 슬라이더와 − + 로 정합니다.
- 투명도. 너무 흐리거나 너무 진해지지 않는 범위 안에서 정합니다.
- 접어 두기
- 기본값. 이 박스만 처음 모습으로 되돌립니다.

박스 이름을 바꿔도 **폴더 이름은 그대로 둡니다.** 안에 든 파일의 자리가 흔들리지 않게 하기 위해서입니다.

박스 이름은 오른쪽 단추 메뉴의 **박스 이름 바꾸기**로도 바꿀 수 있습니다. 제목 줄에 입력칸이 뜹니다. 담긴 항목 하나의 이름은 그 아이콘 위에서 오른쪽 단추를 눌러 **이름 바꾸기**로 바꿉니다. 박스 이름과 달리 이것은 파일 이름 자체가 바뀝니다.

박스에 손을 올리면 오른쪽 아래에 크기 조절 표시가 옅게 나타납니다.

## 트레이

트레이 아이콘을 누르면 박스를 그립니다. 메뉴에서는 전체를 다룹니다.

- **박스 그리기**
- **박스 숨기기** / **박스 보이기**. Windows에서는 바탕화면 빈 곳을 두 번 눌러도 같습니다. 숨긴 채로 박스를 그리면 함께 다시 보입니다.
  - 두 번 누르는 사이 시간은 Windows 설정(마우스 속성)의 두 번 클릭 속도를 그대로 따릅니다.
  - 아이콘 위나 박스 위에서 누른 것은 세지 않습니다. **빈 바탕화면**에서만 걸립니다.
- **언어**. 한국어와 영어. 고르면 모든 박스와 메뉴에 함께 적용됩니다.
- **설정**. 설정 창을 엽니다.
- **빠른 설정**. 언어, 시작할 때 실행, 새 박스 테마·모서리·투명도, 그림자, 아이콘 열기, 바탕화면으로 모두 돌려주기, 박스 폴더 열기, 설정 폴더 열기가 한 메뉴에 있습니다.
- **프로그램 정보**
- **종료**

## 한 번에 하나만

바탕화면 아이콘은 컴퓨터에 하나뿐입니다. MyDeskBox를 두 번 켜면 나중에 켠 쪽은 알림을 남기고 끝납니다. 설치본과 개발용 실행을 같이 켜도 같습니다. 먼저 켠 쪽을 트레이에서 종료한 뒤 다시 실행합니다.

## 설정과 파일이 저장되는 곳

사용자 데이터 폴더에 모여 있습니다. Windows에서는 보통 `%APPDATA%\MyDeskBox` 입니다. 트레이의 **설정 폴더 열기**로 엽니다.

| 이름 | 무엇 |
| --- | --- |
| `layout.json` | 박스 배치와 설정 |
| `icon-homes.json` | 아이콘을 비키기 전 자리, 감추기 전의 휴지통 설정 |
| `boxes\` | 박스마다 하나씩 있는 폴더. 담은 파일이 여기에 있습니다 |
| `boxes\restore.json` | 담은 파일이 어디서 왔는지 |

`layout.json` 에는 박스의 자리와 크기, 테마, 접힘, 숨김, 그리고 **시작할 때 실행** 을 껐는지가 함께 들어 있습니다. 그래서 다시 켜면 지난번 모습 그대로 돌아옵니다. 박스에 담겨 있던 파일은 끝낼 때 바탕화면으로 돌려주므로, 다시 켜면 박스는 제자리에 빈 채로 섭니다.

첫 실행의 자동 분류를 다시 하게 하려면, 프로그램을 **정상 종료**해 파일을 모두 돌려받은 뒤 `layout.json` 을 지웁니다.

## 다른 운영체제

담기는 파일을 옮기는 일이라 어디서나 똑같이 됩니다. 다만 macOS의 Finder와 리눅스 데스크톱 환경은 아이콘 하나의 자리를 바꾸는 길을 주지 않으므로, 그 두 곳에서는 바탕화면 아이콘을 비켜 주지 않고 박스도 격자에 붙이지 않습니다. 박스는 놓은 자리에 그대로 서고, 담은 것은 그대로 보여 줍니다.

로그인할 때 스스로 켜지는 자리도 운영체제마다 다릅니다.

| 운영체제 | 어디에 적히는가 |
| --- | --- |
| Windows | 레지스트리 `HKCU\...\Run` 의 `MyDeskBox`. 작업 관리자의 **시작 프로그램** 탭에 그 이름으로 보이고, 거기서 꺼도 됩니다. 프로그램을 지우면 함께 치웁니다 |
| macOS | 시스템 설정의 **로그인 항목** |
| Linux | `~/.config/autostart/mydeskbox.desktop` |

작업 관리자나 시스템 설정에서 끄면 MyDeskBox 는 다음에 켤 때 그것을 다시 적습니다. 끄시려면 트레이 메뉴나 설정 창에서 꺼 주세요. 그쪽에서 끈 것은 기억합니다.
