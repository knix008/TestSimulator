# MyDeskBox

Windows, macOS, Linux 바탕화면에 반투명 박스를 두는 펜스입니다. 배경 그림에 사각형을 그리지 않고, 박스마다 투명한 창을 띄웁니다.

- 쓰는 법: [UsersGuide.md](UsersGuide.md)
- 코드 구조: [ARCHITECTURE.md](ARCHITECTURE.md)

## 실행

[Tauri 2](https://tauri.app) 로 만듭니다. Node.js 18 이상과 Rust(stable) 가 있어야 합니다. Windows 는 WebView2 런타임을 쓰는데 Windows 10·11 에는 이미 들어 있습니다. Linux 는 `webkit2gtk-4.1` 과 `libayatana-appindicator3` 개발 꾸러미가 필요합니다.

```bash
npm install
npm start          # tauri dev: 디버그로 빌드해 바로 띄운다. 처음 한 번은 몇 분 걸린다
npm start -- --restore-desktop   # 뒤의 인자는 앱에 넘어간다
```

MyDeskBox 는 한 번에 하나만 뜹니다. 설치본이 이미 돌고 있으면 `npm start` 로 띄운 쪽은 설치본에게 '박스 그리기' 를 넘기고 바로 끝납니다. 개발본을 보려면 설치본을 먼저 끄십시오.

검사하거나 손으로 확인할 때는 사용자 데이터와 바탕화면을 다른 폴더로 돌릴 수 있습니다. 진짜 바탕화면의 파일을 옮기지 않으려면 늘 이렇게 띄우십시오.

| 환경 변수 | 뜻 |
| --- | --- |
| `MYDESKBOX_DATA_DIR` | 사용자 데이터 폴더(기본 `%APPDATA%\MyDeskBox`) 대신 쓸 곳 |
| `MYDESKBOX_DESKTOP_DIR` | 바탕화면 폴더 대신 쓸 곳 |
| `MYDESKBOX_TRACE` | 무엇이 언제 일어났는지 적어 둘 파일 |

처음 실행하면 바탕화면 항목을 폴더·바로가기·문서처럼 종류별로 나눠 담을지 물어봅니다. 나눠 담으면 파일이 실제로 박스 폴더로 옮겨 가므로, 원하지 않으면 거절하고 빈 바탕화면으로 시작할 수 있습니다. 나눌 것이 없거나 거절하면 화면을 끌어 박스를 그리는 상태로 시작합니다. Esc 로 취소하고, 트레이 아이콘에서 다시 그립니다.

## 트레이에만 있습니다

창틀도 작업 표시줄 단추도 없습니다. 박스도, 설정 창도, 묻는 창도 모두 작업 표시줄에 뜨지 않습니다. macOS 에서는 Dock 아이콘도 감춥니다. 다루는 자리는 트레이 아이콘 하나입니다.

**설치하면 로그인할 때 스스로 켜집니다.** 시스템을 다시 켜도 박스가 지난번 자리에 그대로 돌아옵니다. 트레이의 '빠른 설정 › 시작할 때 실행' 이나 설정 창의 일반 탭에서 끌 수 있고, 한 번 끄면 다시 켜 주지 않습니다.

- Windows 는 `HKCU\...\Run` 에 `MyDeskBox` 라는 이름으로 적고, 프로그램을 지울 때 그 자리도 함께 치웁니다. Electron 판과 같은 이름이라 예전 판이 적어 둔 것을 그대로 이어받습니다.
- macOS 는 `~/Library/LaunchAgents/com.suhokwon.mydeskbox.plist` 를 둡니다.
- Linux 는 `~/.config/autostart/mydeskbox.desktop` 을 둡니다.
- `npm start` 로 띄운 개발본은 등록하지 않습니다. `src-tauri/target` 안의 실행 파일을 적어 두면 그 폴더를 지운 뒤에도 로그인할 때마다 없어진 자리를 부르게 됩니다.

켤 때마다 설정에 적힌 값대로 운영체제 쪽을 다시 맞춥니다. 다시 설치했거나 다른 자리에 설치했어도 새 자리가 다시 적힙니다.

## 담는다는 것은 옮긴다는 뜻

이 프로그램의 바탕이 되는 약속입니다.

- 박스에 담으면 그 파일이 **박스의 폴더로 옮겨 갑니다**. 자리는 설정 폴더 아래 `boxes\<박스 이름>` 입니다.
- 옮겨 갔으므로 바탕화면에서는 사라집니다. 같은 항목이 두 곳에 함께 보이지 않습니다.
- 꺼내거나, 박스를 지우거나, 프로그램을 끝내면 **담기 전에 있던 폴더로 돌아갑니다**.
- 박스가 보여 주는 것은 그 폴더의 내용입니다. 탐색기에서 넣거나 지운 것도 그대로 드러납니다.

아이콘 자리만 옮기고 파일은 두는 방식도 써 봤지만, 탐색기의 자동 정렬·격자 맞춤·새로 고침이 저마다 자리를 되돌려 놓아 끝나지 않는 다툼이 됩니다. 파일을 옮기면 다툴 거리가 없어집니다.

### 바탕화면에 같은 이름으로 새로 만들면

담긴 파일은 박스 폴더에 있어 탐색기 눈에 보이지 않습니다. 그래서 탐색기는 박스가 이미 들고 있는 이름으로도 '새 폴더' 나 '새 텍스트 문서' 를 아무 말 없이 만듭니다. 그대로 두면 같은 이름이 바탕화면과 박스에 두 벌이 됩니다.

그래서 생기자마자 묻습니다.

- **대체** — 새로 만든 것이 그 박스로 들어가고, 박스에 있던 것은 휴지통으로 갑니다.
- **새로 만들기** — 새로 만든 것을 바탕화면에 그대로 둡니다. 박스는 건드리지 않습니다.

한 번 물은 항목은 다시 묻지 않습니다. 켤 때 이미 바탕화면에 있던 것도 묻지 않습니다.

## 쓰는 법

- 박스는 여러 개를 둘 수 있습니다. 트레이 아이콘을 누르거나 박스 메뉴의 '새 박스 그리기' 로 이어서 그립니다.
- 제목 줄을 끌면 박스가 움직이고, 가장자리를 끌면 크기가 바뀝니다. 제목을 두 번 누르면 접힙니다.
- 아이콘은 **박스 → 바탕화면, 바탕화면 → 박스, 박스 → 박스** 모두 끌어 옮길 수 있습니다. 끄는 동안 아이콘은 계속 손을 따라다닙니다.
- 박스 안에서 아이콘을 끌면 커서가 가리키는 칸이 비도록 있던 아이콘이 밀립니다. 아이콘이 박스보다 많으면 오른쪽 막대로 넘겨 봅니다.
- 아이콘을 두 번 누르면 열립니다. 설정에서 한 번 눌러 열기로 바꿀 수 있습니다.
- 끌어다 놓기는 언제나 **옮기는** 일입니다. 아이콘의 **그림 위**에 놓으면 폴더나 폴더 바로가기면 그 안으로, 휴지통이면 버려집니다. 그 밖의 항목 위에 놓으면 아무것도 실행되지 않고 그 박스에 담깁니다. 받을 항목이 정해지면 그 아이콘이 밝아지므로 놓기 전에 알 수 있습니다. 칸의 좌우 끝과 글자 줄은 '사이에 끼우기' 자리라 순서만 바뀝니다.
- 같은 박스 안에서든, 다른 박스에서 건너오든, 바탕화면이나 탐색기에서 끌어 오든 넘기는 자리는 같습니다.
- 옮기는 일은 대체가 아닙니다. 담을 때에는 묻지 않고, 이름이 같은 다른 파일이 있으면 뒤에 번호를 붙여 둘 다 남깁니다. 대체는 새로 만들 때만 묻습니다.
- 파일 탐색기에서 끌어 놓아도 들어갑니다. 바탕화면이 아닌 폴더에서 온 파일은 그 폴더로 돌아갑니다.
- Windows 에서는 휴지통을 끌어 박스에 넣을 수 있습니다. 담으면 바탕화면 쪽 휴지통은 감춰지고, 가득 찼을 때와 비었을 때 그림이 다릅니다. 끌어 넣기가 안 되는 항목은 박스 메뉴의 '바탕화면 항목 담기' 로 담습니다.
- 바탕화면 빈 곳을 왼쪽 단추로 끌어 사각형을 만들면 그 자리에 박스를 만들지 물어봅니다.
- Windows 에서는 바탕화면 빈 곳을 두 번 눌러 박스를 숨기거나 다시 보일 수 있습니다. 숨긴 채로 박스를 그리면 함께 다시 보입니다.

### 박스 안의 아이콘은 바탕화면과 똑같이

- 이름은 셸에게 물어 탐색기가 적는 글 그대로 씁니다. 확장자를 감추는 설정과 폴더의 번역된 이름(`Documents` → `문서`)까지 따라갑니다.
- 폴더는 폴더답게, 바로가기는 가리키는 프로그램의 그림으로 보입니다.
- 그림 파일은 종류 그림이 아니라 **미리 보기**로 보입니다.

### 자리와 크기

- 박스를 아이콘 격자에 **묶어 두지 않습니다.** 칸 경계에서 한 칸의 1/5 안에 들어올 때만 자석처럼 붙고, 그 사이의 자리와 크기는 놓은 그대로 씁니다.
- 화면 가장자리에도 붙습니다. 왼쪽 끝에 붙여 두면 되튀지 않습니다.
- 크기만 바꾸면 자리는 그대로이고, 자리만 옮기면 크기가 그대로입니다.
- 켤 때는 박스를 손보지 않습니다. 어제 놓아 둔 자리에 오늘도 그대로 있습니다.
- 박스끼리는 겹치지 않습니다. 겹치게 놓으면 가장 적게 움직이는 쪽으로 비키고, 크기를 키우다 닿으면 닿은 데서 멈춥니다.

### 바탕화면 아이콘

- 박스가 덮은 자리의 아이콘은 제자리에서 **가장 가까운 빈 칸**으로 비킵니다. 박스 아래에 아이콘이 깔리지 않습니다.
- 박스를 옮기면 비켰던 아이콘이 제자리로 돌아옵니다.
- 그 동안 Windows 의 '아이콘 자동 정렬' 은 꺼 둡니다. 켜져 있으면 탐색기가 아이콘을 박스 밑으로 곧바로 되돌려 놓습니다. 프로그램을 끝내면 원래대로 되돌립니다.

### 끝내면 바탕화면이 돌아온다

담아 둔 파일과 비켰던 아이콘, 감춘 휴지통, 탐색기 설정이 모두 원래대로 돌아갑니다. 트레이로 끝내든, `Ctrl+C` 로 끊든, 로그아웃으로 창이 닫히든, 큰 오류로 멈추든 같은 길을 지납니다. 큰 오류일 때는 **먼저 되돌린 뒤** 무슨 오류인지 알려 주고, '복사' 단추로 그 내용을 클립보드에 담을 수 있습니다. 전원 내림처럼 아무것도 못 하고 끝난 경우에는 다음에 켤 때 남은 파일을 제자리로 돌려놓습니다.

## 프로그램 설정

트레이 메뉴의 '설정' 이 설정 창을 엽니다. 크기가 고정된 창이고 스크롤 막대 없이 네 탭으로 나뉩니다.

| 탭 | 들어 있는 것 |
| --- | --- |
| 일반 | 언어, 아이콘을 한 번/두 번 눌러 열기, 시작할 때 실행 |
| 모양 | 새 박스의 테마·모서리·투명도, 박스 그림자 |
| 폴더 | 박스 폴더와 설정 폴더 열기, 보관함 자리, 숨김·임시 파일 보이기(모든 박스와 새 박스), 바탕화면으로 모두 돌려주기 |
| 프로그램 정보 | 판, 만든 이, 전자우편 |

자주 바꾸는 값은 트레이의 '빠른 설정' 아래에도 그대로 있습니다.

## 박스 설정

박스마다 자기 설정 창이 있습니다. 제목 줄 오른쪽의 톱니를 누르거나, 오른쪽 단추 메뉴의 '이 박스 설정' 을 고릅니다.

- 이름 바꾸기. 이름을 바꿔도 폴더 이름은 그대로 두어 안에 든 파일의 자리가 흔들리지 않게 합니다.
- 테마: 서른 가지 중에 고릅니다. 마음에 드는 색이 없으면 바탕과 제목 줄 색을 직접 고를 수 있습니다.
- 모서리: 각진 사각형부터 둥근 것까지 슬라이더로 정합니다. 좌우의 − + 로 한 칸씩 움직일 수도 있습니다.
- 투명도: 슬라이더와 − + 로 정합니다.
- 접어 두기: 켜고 끄는 단추
- 숨김·임시 파일 보이기: 이 박스만 따로 정합니다. 박스의 오른쪽 단추 메뉴에도 같은 항목이 있습니다. 트레이의 빠른 설정과 설정 창 폴더 탭의 '숨김·임시 파일 보이기' 는 모든 박스에 한꺼번에 걸리고, 새 박스도 그 값을 따릅니다. 켜 두면 숨김·임시 파일은 탐색기처럼 흐린 아이콘으로 보입니다. 기본은 꺼져 있어 탐색기처럼 숨김·시스템·임시 속성이 붙은 파일과 `~$문서.docx`, `.tmp`, `.crdownload` 같은 임시 파일을 그리지 않습니다. 파일은 박스 폴더에 그대로 있고 그리는 것만 바뀝니다.
- 기본값: 이 박스만 처음 모습으로 되돌립니다. 확인: 창을 닫습니다.

오른쪽 단추 메뉴에는 박스 이름 바꾸기, 접기/펼치기, 이 박스 설정, 테마, 모서리, 투명도, 바탕화면 항목 담기, 새 박스 그리기, 박스 삭제가 있습니다. 아이콘 위에서 누르면 '열기', '이름 바꾸기', '바탕화면으로 꺼내기', '삭제', '속성' 이 함께 나옵니다. 휴지통 위에서는 '휴지통 비우기' 도 나옵니다.

항목의 '이름 바꾸기' 는 아이콘 글자 자리에 입력칸을 띄웁니다. 박스 폴더 안의 파일 이름이 실제로 바뀌므로 꺼내면 바뀐 이름으로 바탕화면에 돌아갑니다. 확장자를 감춰 보고 있었다면 확장자는 그대로 이어 줍니다.

박스에 손을 올리면 오른쪽 아래에 크기 조절 표시가 옅게 나타납니다.

## 생김새

박스는 납작한 사각형이 아니라 두께가 있는 판처럼 보입니다.

- 위에서 빛이 드는 것처럼 위쪽은 밝고 아래쪽은 어둡습니다. 제목 줄은 한 단 올라와 보입니다.
- 그림자를 켜면 박스 바깥으로 그림자가 떨어집니다. 그때 창은 박스보다 사방 18px 크고, 그 여백이 그림자 자리입니다.
- 아이콘에 그림자가 두 겹 깔려 판 위에 떠 있는 것처럼 보이고, 가리키면 살짝 기울며 떠오릅니다.
- 끌고 있는 아이콘은 크게 들리고 그림자가 짙어집니다. 박스 밖으로 나가면 작은 창이 그 그림을 들고 손을 따라다닙니다.

## 설치 파일 만들기

```bash
npm run build:win     # Windows 설치 파일 (NSIS)
npm run build:mac     # macOS dmg
npm run build:linux   # Linux AppImage, deb
npm run build         # 지금 운영체제의 것 모두
npm run pack          # 설치 파일 없이 실행 파일만 (src-tauri/target/release/MyDeskBox.exe)
```

결과는 `src-tauri/target/release/bundle/` 에 놓이고, 설치 파일이 프로젝트 루트로도 복사됩니다(`tools/copy-installer.js`). Windows 는 `MyDeskBox-Setup-1.0.0-x64.exe` 로 이름을 바꾸고, macOS(`MyDeskBox_1.0.0_aarch64.dmg`)와 Linux(`.deb`, `.AppImage`)는 Tauri 가 지은 이름 그대로입니다. Windows 설치 파일은 약 2.5 MB 입니다(Electron 판은 85 MB).

Windows 설치 파일은 이렇게 동작합니다. Tauri 의 NSIS 설치 프로그램에 `src-tauri/windows/hooks.nsh` 를 덧붙였습니다.

- 처음에 설치 언어를 한국어와 영어 중에서 고릅니다. 사용자 계정에 깝니다(`%LOCALAPPDATA%\MyDeskBox`, 관리자 권한이 필요 없음).
- **앞서 깐 MyDeskBox 가 있으면 완전히 지운 뒤 새로 깝니다.** Electron 판(`%LOCALAPPDATA%\Programs\MyDeskBox`)과 Tauri 판 모두 찾고, 둘 다 있으면 둘 다 지웁니다. 돌고 있으면 먼저 닫고(앱은 닫히면서 바탕화면을 되돌립니다), 앞 판의 제거 프로그램을 조용히 돌린 뒤 남은 파일과 그 판을 가리키던 바로 가기까지 치웁니다. 폴더만 없어지고 '앱' 목록에 남은 깨진 줄도 지웁니다.
- **사용자 데이터(`%APPDATA%\MyDeskBox`: 박스 배치·설정·박스에 담아 둔 파일)가 있으면 지울지 물어봅니다.** 첫 화면이 뜨기 전에 묻습니다.
  - 예: 한 번 더 확인한 뒤, 새로 깐 프로그램으로 박스에 담아 둔 파일을 담기 전 자리로 돌려놓고(`MyDeskBox.exe --restore-desktop`) 데이터를 지웁니다.
  - 아니오(기본): 데이터를 그대로 둡니다. 형식이 같아 새 프로그램이 박스 배치를 그대로 이어서 씁니다.
  - 취소: 설치를 그만둡니다.
  - 조용한 설치(`/S`)와 수동 설치(`/P`)에서는 묻지 않고 데이터를 둡니다.
- 시작 메뉴 바로 가기를 만들고, 마지막 화면에서 바탕화면 바로 가기를 만들지 고릅니다.
- 시작프로그램에 앞 판의 경로가 적혀 있으면 새 경로로 바꿉니다.
- 설치 파일과 바로 가기 모두 프로그램과 같은 아이콘을 씁니다.
- **지울 때는 바탕화면을 켜기 전 모습으로 돌려놓습니다.** 돌고 있는 앱을 닫은 뒤 박스에 담아 둔 파일은 담기 전 자리로, 비켜 둔 아이콘은 적어 둔 자리로, 감춘 휴지통은 다시 보이게 돌아갑니다. 되돌리는 일은 프로그램 자신이 합니다(`MyDeskBox.exe --restore-desktop`). 실행 파일을 부를 수 없거나 되돌리지 못한 것이 있으면 제거 프로그램이 보관함의 파일을 바탕화면으로 옮기고 감춘 아이콘의 레지스트리 값을 지웁니다. 시작프로그램 값과, 박스에서 돌아온 것까지 이 프로그램을 가리키는 바로 가기를 모두 치웁니다.
- 제거 화면의 '애플리케이션 데이터 삭제' 를 고르면 `%APPDATA%\MyDeskBox` 와 WebView2 자료(`%LOCALAPPDATA%\com.suhokwon.mydeskbox`)도 지웁니다. 고르지 않으면 남겨 두어, 다시 깔면 박스가 돌아옵니다.

지우는 길은 두 번 지납니다. 프로그램 파일을 지우기 전(`NSIS_HOOK_PREUNINSTALL`)에 프로그램에게 되돌리라고 부르고, 다 지운 뒤(`NSIS_HOOK_POSTUNINSTALL`)에 보관함에 남은 것을 한 번 더 훑습니다. 설정 폴더를 지워도 `boxes\restore.json` 만 있으면 손으로 되돌릴 수 있습니다.

macOS 와 Linux 묶음은 그 운영체제에서 만들어야 합니다.

## 운영체제

- Windows: 담긴 파일은 박스 폴더에 있으므로 바탕화면 아이콘이 아예 없습니다. 아이콘을 다루는 일은 **박스가 덮은 자리에서 비켜 주는 것** 하나뿐입니다.
  - 한 칸의 크기는 탐색기에게 직접 묻고(`LVM_GETITEMSPACING`), 격자의 원점은 아이콘 자리가 아니라 위상에서 구합니다. 그래야 아이콘이 움직여도 격자가 흔들리지 않고 박스가 제자리에 머뭅니다.
  - '아이콘 자동 정렬' 이 켜져 있으면 탐색기가 비킨 아이콘을 박스 밑으로 되돌려 놓습니다. 아이콘을 옮기기 전에 꺼 두고, 끝낼 때 원래대로 되돌립니다. '격자에 맞춤' 은 건드리지 않습니다 — 그 비트를 보내는 것만으로 모든 아이콘이 격자로 끌려갑니다.
  - 바탕화면 아이콘은 컴퓨터에 하나뿐이라 MyDeskBox 도 한 번에 하나만 뜹니다. 두 벌이 함께 돌면 서로 상대가 옮긴 아이콘을 되돌려 놓으므로, 나중에 켠 쪽은 먼저 켠 쪽에게 '박스 그리기' 를 넘기고 곧바로 끝납니다(`tauri-plugin-single-instance`). 식별자가 다른 판이 바탕화면을 잡고 있으면 그 사실을 알리고 끝납니다.
  - 아이콘 그림과 이름은 셸에서 직접 가져옵니다. 바탕화면에 보이던 그대로 박스 안에서도 나옵니다.
  - 휴지통 같은 셸 항목은 옮길 파일이 없으므로 목록에만 담고, 바탕화면 쪽 아이콘은 레지스트리로 감췄다가 끝낼 때 되살립니다.
- macOS: `~/Desktop` 의 파일을 박스 폴더로 옮겨 창 안에 보여 줍니다. Finder 는 아이콘 하나의 자리를 바꾸는 API 를 주지 않아, 바탕화면 아이콘은 건드리지 않고 박스도 격자에 붙이지 않습니다.
- Linux: XDG 바탕화면 폴더를 같은 방식으로 다룹니다. 데스크톱 환경마다 아이콘 창이 달라 자리를 직접 옮기지는 않습니다.

로그인할 때 스스로 켜지는 길도 운영체제마다 다릅니다. Windows 는 `Run` 레지스트리 값, macOS 는 LaunchAgent, Linux 는 `~/.config/autostart/mydeskbox.desktop` 을 직접 둡니다(`src-tauri/src/autostart.rs`). 자세한 것은 [트레이에만 있습니다](#트레이에만-있습니다) 를 보시면 됩니다.

## 그림 파일

프로그램이 쓰는 그림은 모두 `src/assets/` 에 있습니다. 창(렌더러)과 함께 실행 파일 안에 실립니다. 앱·트레이 아이콘과 메뉴 그림, 테마 미리보기, 국기까지 전부 코드로 그려 두었습니다. 앱 아이콘에는 'BOX' 를 도톰한 글자로 새겨 두었고, 작게 쓸 때는 글자 없는 그림으로 바뀝니다.

```bash
node tools/make-icons.js
```

`src/shared/themes.json` 의 테마나 `tools/icons.js` 의 생김새를 고친 뒤 위 명령을 다시 돌리면 `src/assets/` 가 새로 만들어집니다. 테마는 `themes.json` 한 곳에만 있고, 창과 Rust(`src-tauri/src/themes.rs`) 가 모두 그 파일을 읽습니다.

## 검사

```bash
npm test           # JS 검사와 Rust 검사를 모두 돌린다
npm run test:js    # 창 쪽 검사만, 파일별로 묶어 보기 좋게 찍는다
npm run test:rust  # 앱 쪽 검사만 (cargo test)
npm run test:tap   # JS 검사를 도구가 읽기 좋은 TAP 형식으로
```

앱의 판단은 거의 모두 Rust 쪽에 있고, 창과 운영체제 대신 가짜 창(`host/testkit.rs`)과 가짜 바탕화면(`desktop/fake.rs`)으로 검사합니다. Electron 판의 검사를 그대로 옮겨 같은 약속을 지킵니다. 검사는 운영체제 임시 폴더에 폴더를 만들어 쓰고, 박스 검사가 쓴 폴더는 지우지 않고 두므로 실패한 검사가 무엇을 남겼는지 들여다볼 수 있습니다.

보관함 폴더의 담기·꺼내기·되돌리기, 끝내는 네 가지 길과 갑작스러운 종료 뒤의 복구, 박스를 격자와 가장자리에 붙이는 규칙, 박스끼리 겹치지 않기, 바탕화면 아이콘 비켜 주기와 되돌아오기, 칸 계산과 그림자 여백, 박스 만들기·지우기·숨김, 끌어 옮기기 세 갈래와 항목 위에 놓기, 이름이 부딪힐 때 묻기, 담긴 항목 이름 바꾸기, 휴지통, 두 번 누르기, 테마, 언어, 메뉴와 설정 창, 첫 실행 분류, 설치 설정, `src/assets/` 의 파일까지 확인합니다.
