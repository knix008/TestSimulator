# MyDeskBox

Windows, macOS, Linux 바탕화면에 반투명 박스를 두는 펜스입니다. 배경 그림에 사각형을 그리지 않고, 박스마다 투명한 창을 띄웁니다.

- 쓰는 법: [UsersGuide.md](UsersGuide.md)
- 코드 구조: [ARCHITECTURE.md](ARCHITECTURE.md)

## 실행

```bash
npm install
npm start
```

처음 실행하면 폴더, 바로가기, 문서처럼 종류별로 박스를 만들어 바탕화면 항목을 나눕니다. 나눌 항목이 없으면 화면을 끌어 박스를 그립니다. Esc 로 취소할 수 있고, 트레이 아이콘에서 다시 그릴 수 있습니다. 자세한 조작은 [UsersGuide.md](UsersGuide.md)에 있습니다.

## 쓰는 법

- 박스는 여러 개를 둘 수 있습니다. 트레이 아이콘을 누르거나 박스 메뉴의 '새 박스 그리기' 로 이어서 그립니다.
- 제목 줄을 끌면 박스가 이동합니다. 안의 아이콘도 같이 이동합니다.
- 가장자리를 끌면 크기가 바뀌고, 아이콘은 순서를 유지한 채 칸에 맞게 다시 놓입니다.
- 아이콘을 두 번 누르면 그 프로그램이나 파일이 열립니다.
- 아이콘을 끌어 옮기면 커서가 가리키는 칸이 비도록 있던 아이콘이 밀립니다.
- 아이콘이 박스보다 많으면 오른쪽 막대로 넘겨 봅니다.
- 박스 밖에 놓으면 바탕화면으로 돌아갑니다. 파일 탐색기에서 끌어 놓아도 들어갑니다. 박스에서 박스로도 옮길 수 있습니다.
- Windows 에서는 휴지통을 끌어 박스에 넣을 수 있습니다. 끌어 넣기가 안 되는 항목은 박스 메뉴의 '바탕화면 항목 담기' 로 담습니다. 앱을 종료하면 휴지통은 바탕화면에 다시 나타납니다.
- 제목을 두 번 누르면 접힙니다.
- 박스를 지우면 안에 있던 항목은 모두 바탕화면 제자리로 돌아갑니다.
- 박스에 담으면 그 파일이 박스 폴더(설정 폴더 아래 `boxes`)로 옮겨 갑니다. 바탕화면에서는 사라지고, 같은 항목이 두 곳에 함께 있지 않습니다.
- 끝내면 담아 둔 파일을 담기 전 폴더로 모두 돌려줍니다. `Ctrl+C` 로 끊거나 큰 오류로 멈출 때도 같습니다.
- 박스가 놓인 자리의 바탕화면 아이콘은 옆의 빈 칸으로 밀려납니다. 박스 아래에 아이콘이 비쳐 보이지 않습니다.
- 바탕화면 빈 곳을 왼쪽 단추로 끌어 사각형을 만들면 그 자리에 박스를 만들지 물어봅니다.
- 트레이 아이콘을 누르면 박스를 그립니다. 메뉴에서 박스를 숨기거나 다시 보일 수 있습니다.
- Windows 에서는 바탕화면 빈 곳을 두 번 눌러도 숨기거나 다시 보입니다. 숨긴 채로 박스를 그리면 함께 다시 보입니다.

## 프로그램 설정

트레이 메뉴의 '설정' 이 설정 창을 엽니다. 크기가 고정된 창이고 항목은 일반 / 모양 / 폴더 / 프로그램 정보 탭으로 나뉩니다.

## 박스 설정

박스마다 자기 설정 창이 있습니다. 제목 줄 오른쪽의 톱니를 누르거나, 오른쪽 단추 메뉴의 '이 박스 설정' 을 고릅니다.

- 이름 바꾸기
- 테마: 스무 가지 중에 고릅니다. 마음에 드는 색이 없으면 바탕과 제목 줄 색을 직접 고를 수 있습니다.
- 모서리: 각진 사각형부터 둥근 것까지 슬라이더로 정합니다. 좌우의 − + 로 한 칸씩 움직일 수도 있습니다.
- 투명도: 슬라이더와 − + 로 정합니다.
- 접어 두기: 켜고 끄는 단추
- 기본값: 이 박스만 처음 모습으로 되돌립니다. 확인: 창을 닫습니다.

오른쪽 단추 메뉴에는 이름 바꾸기, 접기/펼치기, 테마, 모서리, 투명도, 바탕화면 항목 담기, 새 박스 그리기, 박스 삭제가 있습니다. 아이콘 위에서 누르면 '열기' 와 '바탕화면으로 꺼내기' 가 함께 나옵니다.

박스에 손을 올리면 오른쪽 아래에 크기 조절 표시가 옅게 나타납니다.

## 트레이 설정

트레이 아이콘의 메뉴에서 전체 동작을 정합니다.

- 언어: 한국어와 영어. 국기와 이름을 함께 보여 주고, 고르면 모든 박스와 메뉴에 한꺼번에 적용됩니다.
- 시작할 때 실행
- 새 박스 테마, 새 박스 투명도
- 설정 폴더 열기
- 프로그램 정보: 이름과 판, 만든 이를 보여 줍니다.

## 생김새

박스는 납작한 사각형이 아니라 두께가 있는 판처럼 보입니다.

- 박스 바깥으로 그림자가 떨어집니다. 창은 박스보다 사방 18px 크고, 그 여백이 그림자 자리입니다.
- 위에서 빛이 드는 것처럼 위쪽은 밝고 아래쪽은 어둡습니다. 제목 줄은 한 단 올라와 보입니다.
- 아이콘에 그림자가 두 겹 깔려 판 위에 떠 있는 것처럼 보이고, 가리키면 살짝 기울며 떠오릅니다.
- 끌고 있는 아이콘은 크게 들리고 그림자가 짙어집니다.

## 설치 파일 만들기

```bash
npm run build:win     # Windows 설치 파일 (NSIS)
npm run build:mac     # macOS dmg, zip
npm run build:linux   # Linux AppImage, deb
npm run build         # 지금 운영체제의 것
```

결과는 `dist/` 에 놓이고, 그 안의 설치 파일 하나가 프로젝트 루트로도 복사됩니다. Windows 는 `MyDeskBox-Setup-…exe`, macOS 는 dmg, Linux 는 deb 입니다. Windows 설치 파일은 이렇게 동작합니다.

- 처음에 설치 언어를 한국어와 영어 중에서 고릅니다.
- 바탕화면과 시작 메뉴에 바로 가기를 만들지 각각 물어봅니다. 만들지 않기를 고르면 만들지 않습니다.
- 이미 설치돼 있으면 그 설치본을 먼저 지우고 새로 설치합니다. 설정 파일은 그대로 두므로 박스 배치를 잃지 않습니다.
- 예전 설정을 모두 지우고 새로 시작할지도 고를 수 있습니다. 기본은 '지우지 않음' 입니다.
- 설치 파일과 바로 가기 모두 프로그램과 같은 아이콘을 씁니다.
- 지울 때는 만들어 둔 바로 가기까지 함께 치웁니다.

macOS 와 Linux 묶음은 그 운영체제에서 만들어야 합니다.

## 운영체제

- Windows: 박스에 넣은 탐색기 아이콘은 화면 밖으로 치워 창 안 아이콘과 겹치지 않게 합니다. 앱을 끝내면 원래 자리로 되돌립니다.
  - 바탕화면의 '아이콘 자동 정렬' 과 '아이콘을 격자에 맞춤' 이 켜져 있으면 탐색기가 아이콘 자리를 곧바로 되돌려 놓습니다. 아이콘을 처음 옮길 때 두 설정을 끄고, 앱을 끝낼 때 원래대로 되돌립니다. 이 처리를 하지 않으면 아이콘이 제자리로 돌아가며 화면이 계속 깜빡입니다.
  - 바탕화면 아이콘은 컴퓨터에 하나뿐이라 MyDeskBox 도 한 번에 하나만 뜹니다. 설치본과 소스를 같이 켜면 서로 상대가 치운 아이콘을 되돌려 놓아 화면이 깜빡이므로, 나중에 켠 쪽은 알림을 남기고 곧바로 끝납니다.
  - 치운 아이콘은 화면 오른쪽 멀리에 둡니다. 음수 자리에 두면 휴지통 같은 항목을 탐색기가 제자리로 되돌립니다.
  - 아이콘 그림은 셸에서 직접 가져옵니다. 바탕화면에 보이던 그림이 박스 안에서도 그대로 나옵니다.
  - 바탕화면 폴더에 있는 항목만 치웁니다. 다른 폴더에서 끌어 온 파일은 애초에 바탕화면에 없으므로 건드리지 않습니다.
- macOS: `~/Desktop` 의 파일을 창 안에 보여 줍니다. Finder 는 아이콘 하나의 자리를 바꾸는 API 를 주지 않아, 바탕화면 아이콘은 그대로 둡니다.
- Linux: XDG 바탕화면 폴더의 파일을 창 안에 보여 줍니다. 데스크톱 환경마다 아이콘 창이 달라 자리를 직접 옮기지는 않습니다.

## 그림 파일

프로그램이 쓰는 그림은 모두 `assets/` 에 있습니다. 앱·트레이 아이콘과 메뉴 그림, 테마 미리보기, 국기까지 전부 코드로 그려 두었습니다. 앱 아이콘에는 'BOX' 를 도톰한 글자로 새겨 두었고, 작게 쓸 때는 글자 없는 그림으로 바뀝니다.

```bash
node tools/make-icons.js
```

`src/main/themes.js` 의 테마나 `tools/icons.js` 의 생김새를 고친 뒤 위 명령을 다시 돌리면 `assets/` 가 새로 만들어집니다.

## 검사

```bash
npm test        # 결과를 파일별로 묶어 보기 좋게 찍는다
npm run test:tap  # 도구가 읽기 좋은 TAP 형식
```

칸 계산과 그림자 여백, 박스 여러 개 만들기와 지우기, 숨김 처리, 바탕화면과 겹치지 않기, 두 번 누르기, 테마, 언어, 메뉴 그림, 첫 실행 분류, 휴지통을 집어 담기, 바탕화면 아이콘 밀어내기, 설치 설정, `assets/` 의 파일까지 확인합니다. 각 검사 뒤에 걸린 시간이 붙고, 맨 아래 요약 줄은 한글과 `-` 로 찍힙니다.
