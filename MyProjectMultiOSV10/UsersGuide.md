# MyProject Multi-OS 사용자 가이드

MyProject Multi-OS는 **Windows, macOS, Linux**에서 동작하는 Gantt 차트 프로젝트 관리 프로그램입니다. `.myprj` 파일로 일정을 저장하며, Windows 버전 **MyProjectWinV10**과 파일 형식을 공유합니다.

브라우저에서 DB 기반으로 사용하려면 **MyProjectWebV10**을 이용하세요. ([Web 사용자 가이드](../MyProjectWebV10/UsersGuide.md))

## 1. 시작하기

### 프로그램 실행

| 플랫폼 | 실행 방법 |
|--------|-----------|
| **Windows** | 시작 메뉴 또는 설치 폴더의 **MyProject** 실행 |
| **macOS** | Applications 폴더의 **MyProject.app** 실행 (또는 DMG에서 드래그 설치) |
| **Linux** | `.AppImage`에 실행 권한 부여 후 실행, 또는 `.deb` 패키지 설치 |
| **개발 모드** | `npm run dev` (Node.js 20+ 필요) |

### 새 프로젝트

1. **파일 → 새 프로젝트** 또는 툴바 **New** (Ctrl+N / ⌘N)
2. 템플릿 기반 빈 프로젝트가 열립니다.

### 프로젝트 열기

1. **파일 → 열기...** (Ctrl+O / ⌘O)
2. **파일 → 최근 파일**에서 이전에 연 파일을 바로 열 수 있습니다.

### 저장

| 메뉴 | 단축키 | 설명 |
|------|--------|------|
| **저장** | Ctrl+S / ⌘S | 현재 경로에 `.myprj` 저장 |
| **다른 이름으로 저장...** | Ctrl+Shift+S | 새 경로·파일명으로 저장 |

편집 후에는 창 제목과 툴바에 `*` 표시가 나타납니다. 종료·새 프로젝트 시 저장 여부를 확인합니다.

## 2. 플랫폼별 설치

### Windows

1. `MyProject-x.x.x-win-x64.exe` (NSIS 설치 프로그램) 실행
2. 설치 경로 선택 후 설치
3. 시작 메뉴·바탕 화면 바로 가기에서 실행

### macOS

1. `MyProject-x.x.x-mac-arm64.dmg` (Apple Silicon) 또는 `...-mac-x64.dmg` (Intel) 마운트
2. **MyProject** 아이콘을 Applications 폴더로 드래그
3. Gatekeeper 경고 시: 시스템 설정 → 개인정보 보호 및 보안에서 허용

> macOS에서 처음 실행 시 “확인되지 않은 개발자” 메시지가 나올 수 있습니다. 공식 빌드·서명 정책은 배포 환경에 따릅니다.

### Linux

**AppImage**

```bash
chmod +x MyProject-x.x.x-linux-x86_64.AppImage
./MyProject-x.x.x-linux-x86_64.AppImage
```

**deb (Debian/Ubuntu 계열)**

```bash
sudo dpkg -i myproject_x.x.x_amd64.deb
myproject   # 또는 Applications 메뉴에서 MyProject
```

### Web (브라우저)

데스크톱 설치 파일이 아닌 **MyProjectWebV10**을 서버에 배포합니다.

- 개발: `npm run dev:web` (MultiOS 루트) 또는 WebV10에서 `npm run dev`
- UI: http://localhost:5173 (기본)
- 로그인·DB 설정: [Web 사용자 가이드](../MyProjectWebV10/UsersGuide.md) 참고

## 3. 화면 구성

```
┌──────────────────────────────────────────────────────────────────────┐
│  메뉴 (파일 | 편집 | 작업 | 보기 | 보고서 | 도움말) — 아이콘 포함   │
├──────────────────────────────────────────────────────────────────────┤
│  툴바 (실행 취소, 파일, 작업, 연결, 주요 경로, 줌, 속성, 인쇄 …)    │
├──────────┬───────────────────────────────┬──────────────────────────┤
│ 작업     │         Gantt 차트           │    속성 패널 (우측)      │
│ 그리드   │  (타임라인, 막대, 의존선,     │  (선택 작업 편집)        │
│          │   Gantt 메모)                 │                          │
├──────────┴───────────────────────────────┴──────────────────────────┤
│  상태 표시줄 (파일, 작업 수, 의존 수, 선택 작업)                      │
└──────────────────────────────────────────────────────────────────────┘
```

| 영역 | 설명 |
|------|------|
| **메뉴** | Win 버전과 유사한 File / Edit / Task / View / Report / Help |
| **툴바** | 자주 쓰는 기능 (아이콘 + 레이블) |
| **작업 그리드** | 작업 목록, 트리, 인라인 편집 |
| **Gantt 차트** | 시간축, 드래그 편집, 의존성 연결선 |
| **속성 패널** | 선택 작업의 상세 속성 (우측 3분할) |
| **상태 표시줄** | 파일 경로, 통계, 현재 선택 |

### 분할선 조절

- **그리드 ↔ Gantt**: 가운데 분할선을 드래그해 그리드 너비 조절
- **Gantt ↔ 속성 패널**: 우측 분할선을 드래그해 속성 패널 너비 조절 (220~480px)

그리드·속성 패널 표시 상태와 너비는 `.myprj`에 저장됩니다.

## 4. 프로젝트 관리

### MyProject 파일 (.myprj)

- JSON 형식, UTF-8
- 포함: 작업, 의존 관계, 리소스 배정, Gantt 메모, 화면 설정(분할 너비, 선택 작업 등)
- **MyProjectWinV10**과 동일한 version 1 형식

### 지원하는 열기 형식

| 형식 | 확장자 | 설명 |
|------|--------|------|
| MyProject | `.myprj` | 기본 형식 |
| MS Project XML | `.xml` | MSPDI XML |
| MPX | `.mpx` | 레거시 MPX |
| MS Project | `.mpp`, `.mpt` | Java+MPXJ 환경 없으면 XML 변환 권장 |

### 과제 설정

**파일 → 과제 설정...** 에서 다음을 변경할 수 있습니다.

- 프로젝트 이름·시작일
- 주간 근무일 (일정·CPM 계산 기준)
- Gantt 표시 (연결선 스타일, 기본 의존 유형, 주요 경로 표시 등)

변경 후 **저장**하면 `.myprj`에 반영됩니다.

### 환경 설정

**파일 → 환경 설정...** 에서 UI 언어(한국어/English)를 선택합니다. 설정은 사용자 데이터 폴더에 저장됩니다.

## 5. Microsoft Project 연동

### 가져오기

**파일 → 열기...** 에서 `.xml`, `.mpx`, `.myprj` 등을 선택합니다.

- **XML**: 가장 안정적인 상호 운용 형식
- **MPX**: 기본 필드(이름, 일정, 의존) 가져오기
- **MPP/MPT**: 런타임에 Java와 MPXJ JAR이 없으면 오류 안내 — MS Project에서 **XML로 저장** 후 열기를 권장

### 내보내기

**파일 → Microsoft Project로 내보내기...**

| 형식 | 확장자 |
|------|--------|
| MS Project XML | `.xml` |
| MPX | `.mpx` |

## 6. 작업(태스크) 작업

| 동작 | 메뉴 / 툴바 | 단축키 |
|------|-------------|--------|
| 작업 추가 | 작업 → 작업 추가 | Insert |
| 하위 작업 추가 | 작업 → 하위 작업 추가 | Ctrl+Shift+Insert |
| 작업 삭제 | 작업 → 작업 삭제 | Delete |
| 들여쓰기 | 작업 → 들여쓰기 | Alt+→ |
| 내어쓰기 | 작업 → 내어쓰기 | Alt+← |
| 작업 속성 | 작업 → 작업 속성... | **F2** |
| 펼치기/접기 | 작업 → 펼치기/접기 | (선택 작업) |

### 완료 작업 표시

진행률 **100%** 인 작업은 그리드에서 **취소선**으로 표시됩니다 (Win 버전과 동일).

### 실행 취소 / 다시 실행

| 동작 | 단축키 |
|------|--------|
| 실행 취소 | Ctrl+Z / ⌘Z |
| 다시 실행 | Ctrl+Y / ⌘Y |

작업·일정·의존성 변경을 최대 50단계까지 되돌릴 수 있습니다.

## 7. 주요 경로 (Critical Path)

**보기 → 주요 경로 표시** 또는 툴바 **Critical Path** 로 CPM 기준 주요 경로를 강조합니다.

- 그리드·Gantt에서 주요 경로 작업이 강조 표시됩니다.
- 설정은 `.myprj`에 저장됩니다.

## 8. Gantt 차트

| 동작 | 방법 |
|------|------|
| 작업 선택 | 막대 또는 그리드 행 클릭 |

| 스크롤 연동 | 그리드와 Gantt 세로 스크롤 자동 동기화 |

## 9. 의존 관계 (작업 연결)

### 연결 모드

1. 선행 작업 선택
2. **작업 → 연결** 또는 툴바 **Link** (Ctrl+L)
3. 후행 작업 클릭

**연결 해제**: 연결 모드 중 **Unlink** 또는 Esc

### 의존 유형

| 유형 | 의미 |
|------|------|
| **FS** | Finish-to-Start (기본) |
| **FF** | Finish-to-Finish |
| **SS** | Start-to-Start |
| **SF** | Start-to-Finish |

**작업 → 의존 유형** 메뉴 또는 툴바 **의존 유형** 콤보에서 기본 유형을 선택합니다.

선택된 의존선이 있으면 해당 선의 유형만 변경됩니다.

## 10. Gantt 메모

- **작업 → Gantt 메모 추가**: 선택 작업에 연결된 메모를 Gantt 위에 배치
- 메모를 드래그해 날짜·위치 조정
- 더블클릭 또는 편집 모드에서 본문 수정 (plain text)

> RTF 서식은 Win 버전과 달리 편집 UI는 텍스트 위주이며, `bodyRtf` 필드는 파일에 보존됩니다.

## 11. 속성 패널과 작업 속성

### 우측 속성 패널

- **보기 → 속성 패널** 또는 툴바 **Properties** 로 표시/숨김
- 선택 작업의 이름, 일정, 진행률, 선행 작업 등을 편집

### 작업 속성 대화상자 (F2)

더 많은 필드를 한 화면에서 편집할 때 **F2** 또는 **작업 → 작업 속성...** 을 사용합니다.

## 16. Web 버전과 함께 쓰기

| 구분 | Multi-OS (데스크톱) | WebV10 |
|------|---------------------|--------|
| 데이터 | `.myprj` 파일 | MariaDB 등 |
| 오프라인 | ✅ (파일만 있으면 됨) | ❌ (서버 필요) |
| MS Project | XML/MPX 가져오기·내보내기 | — |
| 팀 공유 | 파일 공유(OneDrive, Git 등) | DB + 로그인 |

**Win `.myprj` ↔ Multi-OS**: 파일을 그대로 복사해 열고 저장하면 됩니다.

**Win/Web DB ↔ Multi-OS**: DB에 있는 프로젝트는 Win/Web에서 `.myprj`로 내보낸 뒤 Multi-OS에서 열 수 있습니다 (Win 내보내기 기능 사용).

## 17. 자주 묻는 질문

### Q. Win 버전과 100% 동일한가요?

UI·`.myprj`·일정 계산은 공통 코드를 사용합니다. MS Project `.mpp` 직접 열기, RTF 메모 편집, DB 직접 연동 등 일부 Win 전용 기능은 제한적입니다.

### Q. macOS에서 “손상된 앱”이라고 나옵니다.

공식 서명되지 않은 빌드일 수 있습니다. 시스템 설정에서 허용하거나, 개발자 ID로 서명된 배포본을 사용하세요.

### Q. Linux AppImage가 실행되지 않습니다.

```bash
chmod +x MyProject-*.AppImage
./MyProject-*.AppImage --no-sandbox   # 일부 환경에서만 필요
```

### Q. Web 빌드는 어디서 하나요?

브라우저용은 **MyProjectWebV10**입니다. Multi-OS 루트에서 `npm run build:web` 또는 WebV10 폴더에서 `npm run build`를 실행하세요. ([README.md](./README.md) 참고)

### Q. MPP 파일을 열 수 없습니다.

MS Project에서 **파일 → 다른 이름으로 저장 → XML** 로 저장한 뒤 Multi-OS에서 `.xml`을 여세요. 또는 Win 버전에서 `.myprj`로 저장 후 사용하세요.
