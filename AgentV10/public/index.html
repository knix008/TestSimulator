Ollama 기반 웹 챗봇 데모

일반적인 데모 웹페이지 레이아웃에 채팅 위젯을 포함한 샘플입니다. 응답은 로컬 Ollama 서버의 gemma4:26b 모델에서 생성됩니다.

서비스 소개

이 영역은 실제 서비스 페이지의 설명, 배너, 카드형 콘텐츠를 배치하는 자리입니다. 현재는 데모 목적의 안내 텍스트만 포함합니다.

빠른 응답

로컬 환경에서 동작하여 네트워크 의존성이 낮습니다.

데이터 제어

민감한 대화 데이터를 외부 API에 전송하지 않습니다.

확장 가능

기존 웹페이지에 위젯 형태로 쉽게 통합할 수 있습니다.
