MyBoard — 따라하기

프로그램 안의 따라하기(도움말 › 따라하기, F11)와 같은 단계입니다.

시작 화면

1. 시작 화면

움직이는 배경 위의 카드들이 시작 화면입니다. 카드는 손잡이로 옮기고 모서리로 크기를 바꿉니다.

2. 시작 카드

새 프로젝트, 열기, 데이터베이스 연결, 가져오기, 마지막 보드 이어서 같은 일이 모두 여기 있습니다.

3. 템플릿

칸반, 소프트웨어 팀, 버그 추적, 개인용 중 하나로 프로젝트를 만들면 상태·유형·보드가 함께 만들어집니다.

4. 데이터베이스

지금 쓰는 데이터베이스의 종류와 연결 상태입니다. 바꾸기로 MySQL·PostgreSQL·SQL Server 등에 연결합니다.

5. 홈 단추

작업 중에도 홈 단추로 언제든 시작 화면에 돌아옵니다.

작업 화면

6. 프로젝트 패널

프로젝트마다 보드, 백로그, 보고서, 설정이 나무 모양으로 있습니다. 오른쪽 클릭으로 아이콘을 바꿉니다.

7. 보드

가운데가 보드입니다. 카드를 열 사이로 끌어 상태를 바꿉니다.

8. 이슈 상세

카드를 누르면 오른쪽에 설명, 댓글, 첨부, 기록이 나옵니다. 단추로 접어 둘 수 있습니다.

9. 하단 패널

활동(누가 무엇을 바꿨는지), 메시지, 정보를 봅니다. Ctrl+J 로 켜고 끕니다.

10. 상태 표시줄

데이터베이스, 사용자, 실시간 연결, 이슈 수를 보여 줍니다.

11. 테마

팔레트 단추는 테마를 무작위로, 옆의 화살표는 40가지 테마 목록을 엽니다.

설정과 도움말

12. 설정

언어, 시작 화면, 테마, 글꼴, 배경, 보드 표시, 데이터베이스, 최근 목록을 바꿉니다.

13. 단축키

자주 쓰는 일의 단축키입니다. C 는 이슈 만들기입니다.

14. 끝

따라하기는 도움말 메뉴나 F11 로 다시 볼 수 있습니다.
