MyBoard — Tutorial

The same steps the tutorial shows in the program (Help › Tutorial, F11).

Start page

1. The start page

Cards over a moving background make the start page. Move a card by its handle, resize it by its corner.

2. Start card

New project, open, connect a database, import, continue the last board — all here.

3. Templates

Create a project from Kanban, Software team, Bug tracking or Simple personal: its statuses, types and board come with it.

4. Database

The kind of database in use and its connection. Change… connects to MySQL, PostgreSQL, SQL Server and more.

5. Home button

The Home button brings you back to the start page at any time.

Workspace

6. Projects panel

Each project lists its boards, backlog, reports and settings as a tree. Right-click to change its icon.

7. Board

The board is in the middle. Drag cards across the columns to change their status.

8. Issue detail

Click a card to see its description, comments, attachments and history on the right. Fold the panel with its button.

9. Bottom panel

Activity (who changed what), messages and information. Ctrl+J shows or hides it.

10. Status bar

The database, the user, the realtime connection and the issue counts.

11. Themes

The palette button picks a random theme; the arrow beside it lists all 40.

Settings and help

12. Settings

Language, start page, theme, fonts, background, board display, database and the recent list.

13. Shortcuts

Shortcuts for frequent work. C creates an issue.

14. Done

Run the tutorial again from the Help menu or with F11.
