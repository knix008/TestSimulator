# Command Center — 사용자 가이드

Command Center는 좌·우 두 창을 나란히 두고 파일을 관리하는 듀얼 페인 파일 관리자입니다.

## 화면 구성

```
┌─────────────────────────────────────────────────────────┐
│ 메뉴 (파일 / 편집 / 보기 / 설정)                            │
├─────────────────────────────────────────────────────────┤
│ 툴바: 새 폴더·새 파일·복사·이동·이름·삭제·새로고침 │ 🔍 검색 [____] [Indexing] │ 언어·테마·정보 │
├─────────────────────────────────────────────────────────┤
│ [드라이브▾][ 현재 경로            ▾] │ [드라이브▾][ 현재 경로       ▾] │
│                                     │◄▶│                              │
│   왼쪽 파일 목록                     │버│   오른쪽 파일 목록            │
│                                     │튼│                              │
├─────────────────────────────────────────────────────────┤
│ 상태 표시줄                                    색인 상태 (우측) │
└─────────────────────────────────────────────────────────┘
```

- 가운데 세로 막대의 버튼으로 좌↔우 복사·이동을 합니다.
- 현재 **활성 창**은 전체 테두리가 강조색으로 표시됩니다(클릭/포커스로 전환).

## 폴더 이동

- **드라이브 선택**: 각 창 상단 왼쪽의 드라이브 드롭다운에서 선택
- **경로 열기**: 그 옆의 현재 경로 상자(또는 ▾)를 클릭하면 폴더 트리가 펼쳐집니다
- **하위 폴더로 이동**: 목록에서 폴더 더블클릭
- **상위 폴더로**: 목록 맨 위의 `..` 더블클릭 또는 `Backspace`

## 파일 작업

| 작업 | 방법 |
|------|------|
| 다른 창으로 복사 | 가운데 **→ 복사 / ← 복사** 버튼, 또는 `F5` |
| 다른 창으로 이동 | 가운데 **→ 이동 / ← 이동** 버튼, 또는 `F6` |
| 이름 바꾸기 | `F2` |
| 삭제(휴지통) | `F8` 또는 `Delete` |
| 새 폴더 | 툴바 새 폴더, 또는 `F7` |
| 새 파일 | 툴바 새 파일 |
| 전체 선택 | `Ctrl+A` |
| 복사/잘라내기/붙여넣기 | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` |
| 새로고침 | `F5`(목록) / 툴바 새로고침 |

> **삭제는 기본적으로 휴지통으로 이동**됩니다(영구 삭제 아님). 필요 시 휴지통에서 복원할 수 있습니다.

### 드래그 앤 드롭

- **외부 → 창**: 탐색기 등에서 파일을 창으로 끌어다 놓으면 **복사**됩니다. `Shift`를 누른 채 놓으면 **이동**됩니다.
- **창 → 외부**: 목록에서 선택한 항목을 다른 앱/탐색기로 끌어다 놓을 수 있습니다.
- 같은 폴더에 놓으면 아무 작업도 하지 않습니다.

## 검색 (툴바)

1. 툴바의 **🔍 검색** 입력창에 찾을 이름을 입력하고 **Enter**를 누릅니다.
2. 결과가 **입력창 바로 아래 드롭다운**으로 표시됩니다(별도 팝업 창 없음).
3. 결과에서 항목을 고르면:
   - 폴더면 그 폴더로 이동
   - 파일이면 파일이 있는 폴더로 이동한 뒤 그 파일을 **선택·표시**
4. 검색은 항상 **이름 기준**이며, 색인이 준비되어 있으면 **전체 드라이브**를 대상으로 합니다.

### 색인(Indexing)

- 앱은 시작 시 고정 드라이브 전체를 백그라운드로 색인하고, 그 결과를 저장해 다음 실행에서도 바로 사용합니다.
- 파일 변경은 자동으로 색인에 반영됩니다.
- 툴바의 **Indexing** 버튼을 누르면 전체 재색인을 시작하며, 진행 중에는 버튼이 **멈춤**으로 바뀝니다(다시 누르면 중지).
- 색인 진행 상태는 상태 표시줄 오른쪽에 표시됩니다.

## 압축 / 해제

목록에서 항목을 선택하고 **마우스 오른쪽 버튼 → 압축하기…**:
- ZIP으로 압축, 압축 레벨 선택
- 지정 용량 단위로 **분할 압축**(`.001`, `.002`, …)

`.zip`(또는 분할 아카이브)을 선택하고 **압축 해제…**로 원하는 폴더에 풉니다.

## 미리보기

파일을 한 개 선택하면 하단 미리보기 영역에 내용이 표시됩니다.

## 설정

**설정** 메뉴에서:
- **언어**: 한국어 / English (즉시 전환)
- **테마**: 라이트 / 다크 (즉시 전환)
- **검색 색인**: 색인 시작/중지, 재색인, 색인 상태 보기

툴바 오른쪽의 언어·테마 버튼으로도 빠르게 전환할 수 있습니다.

## 자주 쓰는 단축키 요약

| 키 | 기능 |
|----|------|
| `F2` | 이름 바꾸기 |
| `F5` | (활성 창의 선택 항목) 반대 창으로 복사 |
| `F6` | 반대 창으로 이동 |
| `F7` | 새 폴더 |
| `F8` / `Delete` | 휴지통으로 이동 |
| `Ctrl+A/C/X/V` | 전체선택 / 복사 / 잘라내기 / 붙여넣기 |
| `Backspace` | 상위 폴더 |

## 데이터 저장 위치

설정·세션·즐겨찾기와 검색 색인(`search-index.bin`)은 `%LocalAppData%\CommandCenter` 폴더에 저장됩니다.
