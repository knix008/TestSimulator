MyMarkdownMaster — 따라하기

프로그램 안의 따라하기(도움말 › 튜토리얼, Shift+F1)와 같은 단계입니다.

시작

1. MyMarkdownMaster

폴더 하나가 보관함입니다. 그 안의 Markdown 메모를 [[링크]]로 잇고, 그래프·캔버스·검색으로 둘러보고, 분할 편집과 미리보기로 씁니다.

2. 바로 가기

폴더를 보관함으로 열거나 새 보관함을 만듭니다. 웹에서는 브라우저 안에 보관함을 둘 수도 있습니다.

3. 예제 보관함

사용 안내·제텔카스텐·프로젝트·일기·연구·소설 예제를 새 보관함으로 열어 봅니다.

4. 배경

시작 화면의 움직이는 배경과 카드 투명도를 고릅니다. 카드는 끌어 옮기고 크기를 바꿀 수 있습니다.

보관함과 보기

5. 파일

왼쪽 패널의 파일 목록입니다. 폴더를 접었다 펴고, 파일을 끌어 폴더로 옮기거나 창으로 끌어 열 수 있습니다. 패널은 ‹ 단추로 접힙니다.

6. 실시간 보기

서식을 보면서 바로 씁니다. 커서가 있는 줄만 Markdown 기호가 드러납니다.

7. 링크

[[ 를 입력하면 메모 이름이 자동 완성됩니다. #제목, ^블록, |별칭도 됩니다. ![[ ]] 은 다른 메모를 끼워 넣습니다.

8. 읽기 보기

다 만든 모습입니다. 수식, 다이어그램, 차트, 콜아웃, 할 일 체크가 그대로 동작합니다.

9. 나란히 보기

왼쪽은 원문, 오른쪽은 미리보기이고 스크롤이 맞춰집니다. 가운데 선을 끌어 폭을 바꾸고, ‹ › 단추로 한쪽을 접었다 펼 수 있습니다.

10. 창 나누기

창을 오른쪽·아래로 나누고, 탭을 끌어 다른 창이나 창의 가장자리로 옮깁니다. 작업 공간으로 저장할 수 있습니다.

찾기와 연결

11. 검색

보관함 전체를 Rust 코어가 찾습니다. tag:, path:, file:, line:( ), section:( ), task-todo:, [속성:값], /정규식/ 을 쓸 수 있습니다.

12. 백링크

이 메모를 가리키는 메모와, 이름만 적고 링크하지 않은 언급입니다. 언급은 단추 하나로 링크가 됩니다.

13. 개요

제목의 목록입니다. 누르면 그 자리로 가고, 하위 제목은 접었다 펼 수 있습니다.

14. 그래프

메모와 링크의 지도입니다. 끌고, 확대하고, 필터와 그룹 색, 힘을 조절합니다. 오른쪽 패널에는 지금 메모의 로컬 그래프가 있습니다.

15. 명령 팔레트

Ctrl+P 로 모든 명령을, Ctrl+O 로 메모를 이름으로 찾습니다.

쓰기

16. 속성

메모 맨 위의 YAML 속성입니다. 표에서 바로 고치고, 태그·별칭·날짜를 넣습니다.

17. 오늘의 메모

Alt+D 로 오늘 날짜의 메모를 엽니다. 템플릿과 폴더는 설정 › 메모에서 정합니다.

18. 글쓰기 도구

집중 모드, 타자기 스크롤, 문체 검사, 슬라이드 발표. 오른쪽 통계 탭에서 단어 수 목표와 읽는 시간을 봅니다.

19. 캔버스

카드와 메모를 자유롭게 놓고 선으로 잇는 무한 보드입니다(JSON Canvas).

20. AI 도우미

OpenAI, Claude, Gemini, Ollama 등 여러 AI를 연결해 대화하고, 요약·다듬기·번역·태그 만들기를 메모에 적용합니다.

내보내기·설정

21. 내보내기

PDF, Word, ODT, EPUB, RTF, LaTeX, HTML 등 18가지 형식. 다시 내보내기는 Ctrl+Alt+E.

22. 상태 표시줄

백링크 수, 단어·글자, 읽는 시간, 목표 진행률, 줄·칸, 저장 상태, 문제 수입니다.

23. 테마

밝고 어두운 여러 테마와 읽기 테마(크림, 솔라라이즈드, 고대비 …)가 있습니다.

24. 설정

편집기·읽기·파일과 링크·메모·글쓰기·내보내기·AI를 탭마다 설정합니다.

25. 끝

튜토리얼은 언제든 다시 볼 수 있습니다. 이제 원래 보관함으로 돌아갑니다.
