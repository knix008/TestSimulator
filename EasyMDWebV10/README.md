# EasyMD - Node.js 기반 Markdown 편집기

> Express 기반의 가벼운 Node.js 웹앱입니다. 브라우저에서 Markdown 문서를 편집하고
> 실시간으로 미리보기를 확인하며, 서버에 저장하거나 파일로 다운로드할 수 있습니다.

## 주요 기능

- **실시간 미리보기** — 왼쪽에서 입력하면 오른쪽에 즉시 렌더링됩니다.
- **파일 열기 / 다운로드** — 로컬 `.md` 파일을 업로드하여 편집하고 다시
  다운로드할 수 있습니다.
- **서버 저장 / 불러오기 / 삭제** — `documents/` 폴더에 직접 저장되며,
  사이드바의 **내 문서** 섹션에서 한 번의 클릭으로 다시 열 수 있습니다.
- **문서 구조(목차) 사이드바** — 입력한 제목을 추출해 H1\~H6 단계별 색상
  아이콘과 함께 표시하고, 클릭하면 해당 위치로 부드럽게 스크롤합니다.
- **마우스 클릭 가능한 Markdown 툴바** — 굵게, 기울임, 제목, 목록, 표, 코드,
  체크리스트 등 모든 도구가 **아이콘 + 한글 레이블**과 함께 표시됩니다.
- **라이트 / 다크 테마** — 시스템 설정에 따라 자동 적용되며, 즉시 전환할 수 있습니다.
- **자동 저장** — 입력 내용은 브라우저 `localStorage`에 자동 보관됩니다.
- **GFM 지원** — 표, 체크리스트, 코드 하이라이팅(`highlight.js`),
  XSS 방지(`DOMPurify`).

## 화면 구성

```
┌──────────────────────────────────────────────────────────────────────┐
│ [메뉴바]  새 문서 · 열기 · 다운로드 · 서버 저장 · 사이드바 · 미리보기 · 테마 │
├──────────────────────────────────────────────────────────────────────┤
│ [툴바]   H1 H2 H3 │ 굵게 기울임 취소선 │ 링크 이미지 코드 코드블록 │ ...  │
├──────────────┬───────────────────────────┬───────────────────────────┤
│  사이드바     │        에디터              │        미리보기           │
│              │                            │                           │
│  ▸ 문서 구조  │  # 제목                   │  제목                     │
│    H1 ...    │  ## 소제목                │  소제목                   │
│    H2 ...    │  - 목록                    │  • 목록                   │
│              │                            │                           │
│  ▸ 내 문서    │                            │                           │
│    📄 a.md   │                            │                           │
│    📄 b.md   │                            │                           │
└──────────────┴───────────────────────────┴───────────────────────────┘
```

## 요구 사항

- **Node.js 18 이상** (개발 환경: v22)
- 최신 브라우저 (Chrome, Edge, Firefox, Safari)
- CDN 라이브러리 로드를 위한 인터넷 연결 (오프라인 사용은 [개발](#개발) 참조)

## 빠른 시작

```bash
# 1) 저장소 클론
git clone <repo-url> EasyMDWebV10
cd EasyMDWebV10

# 2) 의존성 설치
npm install

# 3) 서버 시작 (기본 포트 3000)
npm start
```

서버가 시작되면 브라우저에서 <http://localhost:3000> 에 접속합니다.

```text
  EasyMD 서버 실행 중
  → http://localhost:3000
  → 저장 폴더: /.../EasyMDWebV10/documents
```

원하는 포트로 바꾸려면:

```bash
PORT=8080 npm start
```

## 폴더 구조

```
EasyMDWebV10/
├── server.js          # Express 서버 + REST API 엔드포인트
├── package.json       # 의존성/스크립트 정의
├── package-lock.json  # 잠금 파일 (커밋 권장)
├── .gitignore         # Git 추적 제외 규칙
├── README.md          # 이 문서
├── documents/         # 서버에 저장되는 .md 파일이 쌓이는 곳
│   └── .gitkeep       # 빈 폴더 유지를 위한 자리표시 파일
└── public/            # 브라우저로 전달되는 정적 자원
    ├── index.html     # 메뉴/툴바/사이드바/에디터/미리보기 레이아웃
    ├── styles.css     # 모던 UI, 라이트·다크 테마, 반응형 스타일
    └── app.js         # 편집기·미리보기·목차·서버 API 연동 로직
```

> `.gitignore`는 `node_modules/`, 환경 변수 파일, 그리고 `documents/` 안의
> 사용자 문서를 추적하지 않습니다(`.gitkeep`만 커밋).

## REST API

기본 베이스 경로: `/api/documents`

| 메서드   | 경로                  | 설명                                          |
| -------- | --------------------- | --------------------------------------------- |
| `GET`    | `/api/documents`      | 저장된 문서 목록 조회 (이름·크기·수정일)      |
| `GET`    | `/api/documents/:name` | 특정 문서 내용 읽기                          |
| `PUT`    | `/api/documents/:name` | 문서 생성/덮어쓰기 (본문은 Markdown 텍스트)  |
| `DELETE` | `/api/documents/:name` | 문서 삭제                                    |
| `GET`    | `/api/health`         | 헬스 체크                                     |

### 사용 예시

```bash
# 목록 조회
curl http://localhost:3000/api/documents

# 저장 (생성 또는 덮어쓰기)
curl -X PUT -H "Content-Type: text/markdown" \
     --data "# 안녕하세요" \
     http://localhost:3000/api/documents/hello.md

# 읽기
curl http://localhost:3000/api/documents/hello.md

# 삭제
curl -X DELETE http://localhost:3000/api/documents/hello.md
```

### 파일명 규칙

- 허용 확장자: `.md`, `.markdown`, `.txt`
- 거부: `..`, `/`, `\`, 200자 초과, 한글·영문·숫자·공백·`-_.()` 외 특수문자
- 경로 탈출 시 `400 잘못된 파일명입니다.` 응답

## 단축키

| 동작              | 단축키                |
| ----------------- | --------------------- |
| 새 문서           | `Ctrl` + `N`          |
| 파일 열기         | `Ctrl` + `O`          |
| 다운로드          | `Ctrl` + `S`          |
| 서버 저장         | `Ctrl` + `Shift` + `S` |

## 툴바 항목

각 버튼은 아이콘과 한글 레이블이 함께 표시되며, 마우스 클릭으로 동작합니다.
텍스트를 선택한 상태에서 누르면 선택 영역에 서식이 적용됩니다.

- 제목 1 / 제목 2 / 제목 3 (`#`, `##`, `###`)
- 굵게 · 기울임 · 취소선 (`**`, `*`, `~~`)
- 링크 · 이미지 (`[text](url)`, `![alt](url)`)
- 인라인 코드 · 코드 블록 (`` ` ``, ```` ``` ````)
- 인용 (`>`)
- 목록 · 번호 목록 · 체크리스트 (`-`, `1.`, `- [ ]`)
- 구분선 (`---`)
- 표 삽입

## 개발

```bash
# 변경 시 자동 재시작 (Node 18+의 --watch 사용)
npm run dev
```

### 정적 파일만 직접 열어 사용하기

서버 없이 `public/index.html`을 브라우저에서 직접 열어도 편집/다운로드/업로드/
실시간 미리보기는 동작합니다. 단, 사이드바의 **내 문서** 섹션과 서버 저장
기능은 비활성화됩니다.

### 오프라인에서 사용하기

`public/index.html`은 다음 라이브러리를 CDN에서 로드합니다.

- `marked`, `DOMPurify`, `highlight.js`

오프라인 환경에서는 위 파일들을 로컬에 내려받아 `<script>` / `<link>` 경로를
바꿔주세요.

## 보안 메모

- 서버는 `documents/` 폴더 안의 파일만 다룹니다.
- `safeFilename()` 검증으로 경로 탈출(`..`, `/`, `\`)을 차단합니다.
- 클라이언트는 미리보기 렌더링 시 `DOMPurify`로 결과 HTML을 정제하여 XSS를
  방지합니다.
- 본 앱에는 인증/권한 기능이 없습니다. 공용 네트워크에 노출하기 전에
  리버스 프록시 단에서 보호하거나 인증을 추가하세요.
