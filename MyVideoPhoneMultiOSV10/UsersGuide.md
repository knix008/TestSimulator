버전 1.0.0 · 제작자 SHKWON (knix008@naver.com)

이 문서는 MyVideoPhone를 처음 사용하는 분들을 위한 설명서입니다.  
개발·구조는 [Architecture.md](Architecture.md), 실행·빌드는 [README.md](README.md)를 보세요.

---

## 1. 소개

MyVideoPhone는 **로컬 네트워크(IP) 영상 전화** 프로그램입니다.

- **Windows / macOS / Linux** 데스크톱 앱 (Electron)
- 상대방 **IP만 입력**해 통화 연결 · 수신 시 **확인/거부** · 통화 종료
- 마이크 ON/OFF, 내 카메라 미리보기(PIP)
- 선택: RTSP 카메라 보기·통화 녹화, 로컬 미디어 재생(보조)
- 테마, 한글/영어, 화면 맞춤

기본 전화 포트는 **8765**입니다. 설정·창 투명도 등은 사용자 데이터(`persist.json`)에 저장됩니다.

## 2. 설치

### 2.1 Windows

1. `MyVideoPhone-Setup-*.exe` 실행 (`npm run build:win` 결과물)
2. 설치 경로·바로가기 옵션 확인
3. 설치 후 실행

**다시 설치:** 기존 설치를 정리한 뒤 새로 설치합니다. 사용자 데이터도 함께 지워질 수 있습니다.

### 2.2 macOS / Linux

| OS | 빌드 | 결과 |
|----|------|------|
| macOS | `npm run build:mac` | DMG, zip |
| Linux | `npm run build:linux` | AppImage, deb |

### 2.3 개발용 실행

```bash
npm install
npm start                 # 데스크톱
npm run start:multi       # 두 번째 인스턴스 테스트용(별도 데이터 폴더)
npm run web               # 브라우저 UI만 (통화/RTSP 불가)
```

같은 PC에서 웹캠 하나를 두 앱이 동시에 열지 못하는 경우가 많습니다(특히 Windows). 통화 테스트는 **두 대의 PC** 또는 가상 카메라를 권장합니다.

## 3. 화면 구성

### 상단 툴바

| 영역 | 기능 |
|------|------|
| 브랜드 (아이콘 + MyVideoPhone) | 앱 식별. 빈 툴바 영역과 함께 드래그하면 창 이동 / 더블클릭 시 최대화 |
| 마이크 | 마이크 켜기/끄기 |
| 카메라 | 로컬 미리보기(PIP) 켜기/끄기 |
| 화면 맞춤 | 가득 채움 / 비율 유지 / 원본 크기 |
| 투명도 | 창 투명도 (데스크톱) |
| ENG / 한글 | 언어 전환 |
| 설정 | 모양·화면 설정 |
| i | 프로그램 정보 |
| ─ □ ✕ | 최소화 / 최대화 / 트레이로 숨기기 |

✕(닫기)는 종료가 아니라 **트레이로 숨기기**입니다. 완전 종료는 트레이 메뉴의 **종료**를 사용하세요. 트레이로 숨기면 웹캠·마이크 장치는 해제됩니다.

### 중앙 화면

- 상대방 영상(또는 RTSP/로컬 미디어)
- 통화 상태 배지, 내 카메라 PIP
- 대기 화면의 **연결하기**로도 통화 시작 가능
- IP / `rtsp://` 주소를 붙여 넣을 수 있습니다

### 하단 컨트롤

| 컨트롤 | 기능 |
|--------|------|
| **큰 원형 버튼** | **대기:** 통화 연결 · **통화 중:** 통화 종료 (빨간색) |
| 음량 / 음소거 | 재생 음량 |

### 상태 표시줄

파일/대상, 형식, 상태, 테마, 실행 환경 등을 표시합니다. 언어 전환 시 문구도 함께 바뀝니다.

## 4. 영상 전화 사용법

### 4.1 걸기 (발신)

1. 하단 큰 버튼 또는 `Ctrl+Y`로 **연결** 대화상자를 엽니다.
2. 상대방 **IP 주소**를 입력합니다. (예: `192.168.0.10`)  
   - 포트가 8765가 아니면 `IP:포트` 형식도 가능합니다.
3. **연결하기**를 누릅니다.
4. 상대가 **확인**할 때까지 대기합니다. (거부·부재·통화 중이면 안내 문구)
5. 수락되면 상대 영상이 재생됩니다.

연결 대화상자에는 **내 주소(힌트)**가 표시될 수 있습니다. 상대에게 이 IP를 알려 주세요.

### 4.2 받기 (수신)

1. 상대가 연결을 요청하면 **수신 요청** 창과 알림이 뜹니다.
2. **확인** → 통화 시작 (상대 영상을 가져옵니다)  
   **거부** 또는 Esc → 거절

### 4.3 끊기

- 하단 큰 버튼이 **통화 종료**로 바뀐 상태에서 누르기
- 또는 `Esc` (메뉴가 열려 있지 않을 때)

### 4.4 마이크 · 카메라

- 툴바 **마이크**: 내 음성 송신 ON/OFF  
- 툴바 **카메라**: 내 화면 PIP 미리보기 ON/OFF  
- 설정에서 “통화 중 로컬 카메라 미리보기”를 끌 수 있습니다.

## 5. RTSP · 로컬 미디어 (보조)

### RTSP (데스크톱)

1. 연결 대화상자 또는 화면 붙여넣기로 `rtsp://` / `rtsps://` 주소 입력
2. 라이브 스트림 재생
3. `Ctrl+S`로 MP4 녹화 시작 · 다시 누르면 저장 종료

### 로컬 파일

- 파일을 화면으로 드래그 앤 드롭
- 재생이 안 되면 데스크톱에서 호환 변환을 시도할 수 있습니다.

웹 모드(`npm run web`)에서는 IP 전화·RTSP·변환을 지원하지 않습니다.

## 7. 단축키

| 키 | 동작 |
|----|------|
| `Ctrl+Y` | 통화 연결 대화상자 |
| `Esc` | 메뉴 닫기 · (통화 중) 통화 종료 |
| `Ctrl+,` | 설정 |
| `Ctrl+S` | 통화/RTSP 녹화 토글 (데스크톱) |
| `M` | 음소거 |
| `↑` / `↓` | 볼륨 |
| `Space` | 재생 / 일시정지 (미디어 재생 시) |
| `[` / `]` | 배속 (미디어 재생 시) |

입력란·대화상자에 포커스가 있으면 대부분의 단축키는 동작하지 않습니다.

## 8. 문제 해결

| 증상 | 확인 |
|------|------|
| 연결 안 됨 | 같은 LAN인지, 방화벽에서 **8765** 허용, 상대 앱 실행 여부 |
| 수신 창이 안 뜸 | 상대가 올바른 IP로 걸었는지, 트레이에만 숨겨져 있지 않은지 |
| 영상 오류 / URL safety | 최신 빌드 사용 (UI 프록시로 `localhost`/`127.0.0.1` 이슈 완화) |
| 웹캠이 안 열림 | 다른 앱이 카메라를 쓰는지(Windows는 보통 독점). 트레이 복귀 후 다시 시도 |
| 마이크 없음 | OS 마이크 권한 허용 |
| 오류 창 **복사** 안 됨 | 데스크톱 앱인지 확인. 복사 후 “클립보드에 복사되었습니다” 메시지 확인 |
| 창을 너무 줄일 수 없음 | 툴바 최소 너비 제한입니다 |
| ffmpeg 로그가 많음 | 기본은 숨김. 디버그는 `MyVideoPhone_VERBOSE=1` |
