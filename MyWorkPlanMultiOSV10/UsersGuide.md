# MyWorkPlan 사용 설명서

버전 1.0.0

MyWorkPlan은 Microsoft Project와 비슷한 방식으로 작업·일정·자원·비용을 계획하고 진행을 추적하는 프로그램입니다. Windows · macOS · Linux 데스크톱 앱과 웹 브라우저에서 같은 화면으로 동작합니다.

이 설명서는 처음 실행부터 계획 만들기, 일정·자원·진행 관리, 보고서와 인쇄, 꾸미기와 문제 해결까지 하는 일 순서로 정리되어 있습니다. 메뉴·버튼 이름은 프로그램에 표시되는 이름 그대로 적었습니다. 예를 들어 **작업 › 작업 삽입**은 "작업" 메뉴의 "작업 삽입" 명령을 뜻합니다. 그림은 모두 실제 프로그램 화면입니다.

> English version: [UsersGuide.en.md](UsersGuide.en.md)

## 시작하기

### 처음 실행

프로그램을 실행하면 **시작 화면**이 열립니다([시작 화면](#시작-화면) 참고). 처음 실행할 때는 그 위에 **MyWorkPlan에 오신 것을 환영합니다** 창이 한 번 뜹니다.

| 버튼 | 하는 일 |
|---|---|
| **튜토리얼 시작** | 예제 프로젝트로 모든 기능을 차례로 보여 주는 튜토리얼을 시작합니다 |
| **예제 열기** | "웹사이트 리뉴얼" 예제 프로젝트를 새 탭에 엽니다 |
| **나중에** | 창을 닫습니다. 튜토리얼은 언제든 **도움말 › 튜토리얼**(`F11`)로 볼 수 있습니다 |

### 가장 빠른 시작 방법

1. 시작 화면의 **예제 프로젝트** 카드에서 마음에 드는 예제를 누릅니다. 새 탭에 완성된 계획이 열립니다.
2. 또는 **새로 만들기** 카드에서 **빈 프로젝트**나 템플릿을 고릅니다.
3. 표 맨 아래 빈 행에 작업 이름을 쓰고, **기간** 칸에 `5d`처럼 기간을 넣습니다.
4. 작업 두 개를 고르고 `Ctrl+F2`로 연결하면 날짜가 자동으로 계산됩니다.
5. `Ctrl+S`로 `.mwp` 파일로 저장합니다.

### 한 번에 하나만 실행

MyWorkPlan은 사용자마다 하나만 실행됩니다. 이미 실행 중일 때 다시 실행하면 오류 창이 뜨고 새 실행은 끝납니다. 이미 열린 창에서 **파일 › 열기…**로 다른 프로젝트를 탭으로 열어 쓰세요([문제 해결](#문제-해결) 참고).

## 시작 화면

프로젝트를 열지 않았을 때, 또는 메뉴 막대의 **홈** 버튼(`Ctrl+Shift+H`)이나 **파일 › 시작 페이지**를 누르면 보이는 화면입니다. 열어 둔 프로젝트는 탭에 그대로 남아 있습니다. 시작 화면에서 **홈**을 다시 누르면 보고 있던 계획으로 돌아가고, 열린 계획이 없으면 새 빈 프로젝트가 열립니다([메뉴 막대](#메뉴-막대-제목-표시줄) 참고).

![시작 화면 — 반투명 카드 보드와 움직이는 배경](docs/guide/images/ko/01-start.png)

시작 화면은 움직이는 배경 위에 반투명 **카드**를 세 칸(열) 격자에 늘어놓은 보드입니다. 처음 배치는 다음과 같습니다.

| 카드 | 처음 위치 | 내용 |
|---|---|---|
| 머리 카드 | 맨 위, 세 칸 전체 | 프로그램 아이콘·이름·버전, 문서 버튼, **도움말 ▾**, **튜토리얼 시작** |
| **바로 가기** | 둘째 줄 왼쪽 두 칸 | 자주 쓰는 명령 10개 |
| **최근 항목** | 둘째 줄 오른쪽 한 칸 | 최근 파일과 최근 폴더 |
| **새로 만들기** | 세 칸 전체 | 빈 프로젝트와 템플릿 7개(모두 8개) |
| **예제 프로젝트** | 세 칸 전체 | 8개 분야 40개 예제 |
| **움직이는 배경** | 세 칸 전체 | 배경 애니메이션 21가지와 배경 조절 |

시작 화면에는 테마 카드가 없습니다. 테마는 툴바의 테마 버튼이나 **설정 › 테마** 탭에서 바꿉니다([꾸미기](#꾸미기) 참고).

### 위쪽 도구 줄

보드 오른쪽 위에 다음 세 가지가 있습니다.

| 항목 | 하는 일 |
|---|---|
| **시작할 때 시작 페이지 표시** 체크 상자 | 끄면 다음 실행부터 시작 화면 없이 바로 작업 화면이 열립니다(**설정 › 일반**과 **설정 › 시작 화면**에도 같은 항목이 있음) |
| **시작 화면 설정** | 설정 창을 **시작 화면** 탭으로 엽니다 |
| **자동 정렬** | 옮기거나 크기를 바꾼 카드를 모두 처음 배치로 되돌립니다 |

튜토리얼을 아직 마치지 않았다면 도구 줄 아래에 "처음이세요? …" 안내 띠가 보이고, 띠의 **시작하기** 버튼으로 튜토리얼을 시작합니다. 안내 띠는 **설정 › 시작 화면 › 튜토리얼 안내 띠 표시**로 숨길 수 있습니다.

### 머리 카드

| 버튼 | 하는 일 |
|---|---|
| **사용 설명서** | 이 설명서를 별도의 문서 창으로 엽니다(모든 기능 설명과 화면) |
| **튜토리얼 문서** | 튜토리얼의 모든 단계를 화면과 함께 정리한 문서를 별도의 문서 창으로 엽니다 |
| **튜토리얼 영상** | 튜토리얼 전체 과정을 녹화한 영상을 별도의 영상 창에서 재생합니다 |

세 버튼이 여는 창은 [문서 창](#문서-창)을 보세요.
| **도움말 ▾** | 도움말 메뉴와 같은 항목(튜토리얼 · 튜토리얼 문서 · 튜토리얼 영상 · 사용 설명서 · 단축키 목록… · 설정… · 프로그램 정보…)을 버튼 아래에 펼칩니다 |
| **튜토리얼 시작** | 튜토리얼을 시작합니다 |

### 바로 가기 카드

다섯 개씩 두 줄, 모두 10개의 타일이 있습니다. 타일에 마우스를 올리면 설명이 보입니다.

| 타일 | 하는 일 |
|---|---|
| **열기** | 저장한 계획(`.mwp`)이나 템플릿(`.mwpt`)을 엽니다 |
| **가져오기** | MS Project XML·CSV 파일을 가져옵니다 |
| **인쇄** | 열린 계획을 인쇄합니다. 열린 계획이 없으면 "인쇄할 계획 파일을 고르세요." 알림과 함께 파일 고르기 창이 먼저 열리고, 파일을 열면 바로 인쇄 미리 보기 창이 뜹니다 |
| **튜토리얼 시작** | 예제 계획으로 모든 기능을 따라가 봅니다 |
| **단축키 목록** | 모든 단축키를 봅니다 |
| **English** / **한국어** | 화면 언어를 바꿉니다. 지금 한국어이면 영국 국기와 "English", 영어이면 태극기와 "한국어"가 보입니다 |
| **설정** | 프로그램 설정 창을 엽니다 |
| **시작 화면 설정** | 설정 창의 **시작 화면** 탭을 엽니다 |
| **프로그램 정보** | 버전과 만든 사람을 봅니다 |
| **끝내기** | 프로그램을 닫습니다(저장하지 않은 계획이 있으면 먼저 묻습니다) |

### 최근 항목 카드

- **최근 파일**: 최근에 연 계획 파일. 누르면 열고, 오른쪽 ✕로 목록에서 하나씩 지웁니다. 목록이 있으면 머리글에 **모두 지우기** 버튼이 생깁니다.
- **최근 폴더**: 최근에 파일을 열거나 저장한 폴더. 누르면 그 폴더에서 열기 창이 열립니다. ✕로 하나씩, **폴더 기록 모두 지우기**로 한 번에 지웁니다.
- 보이는 개수는 **설정 › 시작 화면 › 표시할 최근 파일 수**(1~10, 기본 8)로 정합니다. 최근 파일과 최근 폴더는 각각 따로 숨길 수 있고, 둘 다 숨기면 카드가 사라집니다.

### 새로 만들기 카드

빈 프로젝트와 7가지 템플릿이 있습니다. 누르면 그 내용으로 새 탭이 열립니다.

| 타일 | 내용 |
|---|---|
| **빈 프로젝트** | 작업 없이 빈 계획에서 시작합니다 |
| **소프트웨어 개발** | 요구사항부터 설계·개발·테스트·배포까지 이어지는 개발 프로젝트 |
| **건축 공사** | 허가와 착공 준비, 기초·골조·설비·마감 공사, 준공까지의 공정표 |
| **행사 기획** | 장소 섭외와 홍보, 운영 준비, 당일 진행과 사후 정리 |
| **마케팅 캠페인** | 시장 조사와 크리에이티브 제작, 채널 준비, 캠페인 집행과 성과 분석 |
| **제품 출시** | 제품 마무리와 영업·지원 준비를 거쳐 출시와 초기 대응까지 |
| **연구 프로젝트** | 연구 설계와 윤리 심의, 데이터 수집과 분석, 보고서 작성까지 |
| **사무실 이전** | 새 사무실 계약과 공사, 짐 꾸리기, 이사 당일과 기존 사무실 반납까지 |

템플릿에는 단계(요약 작업), 작업, 연결, 마일스톤, 자원이 미리 들어 있습니다. 템플릿으로 만든 프로젝트는 처음 저장할 때 새 파일 이름을 묻습니다.

### 예제 프로젝트 카드

8개 분야에 다섯 개씩, 모두 40개의 예제 계획이 있습니다. 자세한 목록은 [예제 프로젝트](#예제-프로젝트)를 보세요. **설정 › 시작 화면 › 예제 프로젝트 표시**를 끄면 카드가 숨겨집니다.

### 움직이는 배경 카드

| **자동 변경** | 시작 화면이 열려 있는 동안 정한 시간마다 배경을 바꿉니다: 끄기 · 15초마다 · 30초마다 · 1분마다 · 2분마다 · 5분마다 |

배경의 종류·속도·자동 변경은 **설정 › 배경** 탭에서도 정합니다. **설정 › 시작 화면 › 움직이는 배경 고르기 표시**를 끄면 이 카드가 숨겨집니다.

### 카드 옮기기와 크기 바꾸기

- **옮기기**: 카드 머리글 왼쪽의 네 방향 화살표 손잡이를 끕니다. 반투명한 카드 사본이 포인터를 따라오고, 놓일 자리가 점선 테두리로 보이며 다른 카드는 비켜 납니다. 카드는 서로 겹치지 않고, 위쪽 빈자리로 저절로 올라붙습니다. 화면 위아래 끝으로 끌면 보드가 스크롤됩니다.
- **크기 바꾸기**: 카드 오른쪽 아래 모서리의 점 무늬를 끌어 너비(1~3칸)와 높이를 바꿉니다.
- **내용에 맞추기**: 그 모서리를 두 번 클릭하면 카드 높이가 다시 내용에 맞춰집니다.
- 바꾼 배치는 설정에 저장되어 다음 실행 때도 그대로입니다. 처음 배치로 돌리려면 위쪽의 **자동 정렬**(또는 **설정 › 시작 화면 › 카드 배치 › 자동 정렬**)을 누릅니다.

![설정의 시작 화면 탭](docs/guide/images/ko/21-settings-start.png)

**시작 화면 설정** 버튼이나 **도움말 › 설정…**의 **시작 화면** 탭에서 시작 화면에 보일 것을 고릅니다. 바꾼 내용은 시작 화면에 바로 반영됩니다.

| 항목 | 내용 |
|---|---|
| **시작할 때 시작 페이지 표시** | 실행할 때 시작 화면을 보일지 |
| **튜토리얼 안내 띠 표시** | 튜토리얼을 마치기 전에 보이는 안내 띠 |
| **최근 파일 표시** · **최근 폴더 표시** | 최근 항목 카드의 두 목록 |
| **표시할 최근 파일 수** | 1~10 (기본 8) |

| **움직이는 배경 고르기 표시** | 움직이는 배경 카드 |
| **카드 불투명도** | 20%~100%, 10% 단위 |
| **카드 배치** | **자동 정렬** 버튼: 카드를 처음 배치로 |
| **시작 화면** | **지금 열기** 버튼: 시작 화면으로 바로 갑니다 |

## 예제 프로젝트

![예제 프로젝트 40개](docs/guide/images/ko/02-start-samples.png)

시작 화면의 **예제 프로젝트** 카드에는 8개 분야에 다섯 개씩, 모두 40개의 예제 계획이 있습니다. 분야 이름 옆의 숫자는 예제 수이고, 카드 머리글 오른쪽의 숫자는 전체 개수(40)입니다.

- 예제를 누르면 **지금 화면 언어로** 새 탭에 열리고, "예제 "…"을(를) 열었습니다." 알림이 뜹니다. 아직 저장하지 않은 새 계획이므로 마음대로 고쳐 볼 수 있고, 저장하려면 `Ctrl+S`로 새 파일 이름을 정합니다.
- 이름 옆에 **초록 점**이 있는 예제는 이미 **진행 중**인 계획입니다. 몇 주 전에 시작한 것으로 꾸며져 기준 계획, 완료율, 실제 날짜, 상태 날짜가 들어 있어서 추적 간트·진행선·늦은 작업·보고서를 바로 볼 수 있습니다.
- **웹사이트 리뉴얼**은 튜토리얼이 쓰는 예제로, 기준 계획·진행·늦은 작업·초과 할당이 모두 들어 있습니다.
- 같은 예제가 설치 폴더의 `samples` 폴더에 파일로도 들어 있습니다. 한국어판은 `<이름>.ko.mwp`, 영어판은 `<이름>.en.mwp`입니다(예: `wedding.ko.mwp`). **열기**로 열 수 있습니다.

## 튜토리얼과 도움말

### 튜토리얼

![튜토리얼 안내 상자](docs/guide/images/ko/22-tutorial.png)

**도움말 › 튜토리얼**(`F11`), 툴바의 학사모 버튼, 시작 화면의 **튜토리얼 시작**으로 시작합니다. 실제 프로그램을 움직이면서 68단계로 모든 기능을 하나씩 보여 줍니다. 설명하는 곳은 주황색 테두리로 강조되고, 오른쪽 아래 안내 상자에 제목과 설명이 나옵니다.

- **다음** 버튼, **이전 단계** 버튼, **자동 재생**(▶)으로 넘깁니다. 안내 상자에 지금 단계 번호와 전체 단계 수가 보입니다.
- **장 고르기** 목록으로 시작 페이지 · 계획 만들기 · 일정 잡기 · 자원과 비용 · 진행 추적 · 보기 · 보고서 · 파일과 인쇄 · 꾸미기 · 도움말 중 원하는 장으로 바로 갑니다.
- 안내 상자는 머리글을 끌어서 옮길 수 있습니다. `Esc`나 ✕로 끝냅니다.
- 내 파일은 바뀌지 않습니다. 튜토리얼이 바꾼 설정(테마·언어·배경 등)은 끝날 때 원래대로 돌아갑니다.
- 튜토리얼을 끝까지 마치면 시작 화면의 안내 띠가 사라집니다. **설정 › 일반 › 튜토리얼**의 **튜토리얼 시작** 버튼으로 다시 볼 수 있습니다.

### 문서 창

**사용 설명서**, **튜토리얼 문서**, **튜토리얼 영상**은 메인 창과 따로 떨어진 **자기 창**으로 열립니다. **도움말** 메뉴나 시작 화면의 머리 카드 버튼으로 엽니다.

| 실행 환경 | 열리는 곳 |
|---|---|
| 데스크톱 앱 | 운영체제의 제목 표시줄이 있는 별도 창. 창 크기와 위치를 기억하고, 이미 열려 있으면 새로 만들지 않고 그 창을 앞으로 가져옵니다. 문서를 보면서 메인 창에서 계속 작업할 수 있습니다 |
| 웹 버전 | 브라우저의 새 탭 |
| 튜토리얼 진행 중 | 프로그램 위에 뜨는 틀. 오른쪽 위 ×로 닫습니다 |

문서는 처음에 지금 화면 언어로 열립니다.

### 사용 설명서

![사용 설명서 창](docs/guide/images/ko/28-guide-window.png)

이 설명서입니다. **도움말 › 사용 설명서** 또는 시작 화면의 **사용 설명서** 버튼으로 엽니다. 왼쪽에 목차, 오른쪽에 본문이 있고, 창 위쪽 막대에 다음 도구가 있습니다(튜토리얼 문서 창도 같습니다).

| 막대 항목 | 하는 일 |
|---|---|
| **장으로 이동** | 고른 장으로 스크롤합니다 |
| **문서에서 찾기** | 찾을 말을 입력하면 문서 안의 일치 항목을 강조하고 개수를 보여 줍니다. `Ctrl+F`로 칸에 가고, `Enter`(또는 ▼, `F3`)로 다음, `Shift+Enter`(또는 ▲, `Shift+F3`)로 이전 항목, `Esc`로 지웁니다 |
| **글자 크기** | `A − 16px +`: 12~26px. `Ctrl++` · `Ctrl+-`로 바꾸고 `Ctrl+0`으로 16px로 돌립니다. 모든 문서 창에 함께 적용되고 기억되며, 언어를 바꿔도 그대로입니다 |

| **인쇄** | 지금 문서를 인쇄합니다(`Ctrl+P`) |
| **브라우저로 열기** | 같은 문서를 기본 웹 브라우저로 엽니다 |

## 화면 구성

![화면 구성 — 간트 차트 보기](docs/guide/images/ko/04-gantt.png)

위에서부터 **메뉴 막대**와 **툴바**(한 줄)가 있고, 그 아래 왼쪽에 **도구 모음** 패널, 오른쪽에 **속성** 패널이 있습니다. 두 패널 사이 가운데에는 위쪽에 **프로젝트 탭**, 그 아래에 **보기**, 보기 아래에 **하단 패널(일정 점검)**이 있고, 맨 아래는 **상태 표시줄**입니다. 패널 사이의 구분자를 끌면 너비가 바뀝니다.

### 창 크기

- 창 가장자리나 오른쪽 아래 모서리(삼각형으로 놓인 점 여섯 개)를 끌어 창 크기를 바꿉니다.
- 창의 최소 폭은 툴바와 메뉴 막대가 다 들어가는 폭입니다. 그래서 툴바는 언제나 한 줄이고 가려지는 버튼이 없습니다. Windows 스냅(Snap)이나 다른 프로그램이 창을 그보다 좁게 줄여도 창이 곧바로 최소 폭으로 되돌아옵니다.

### 메뉴 막대 (제목 표시줄)

데스크톱 앱에는 운영체제의 제목 표시줄이 따로 없고, **메뉴 막대가 제목 표시줄 역할**을 합니다.

| 위치 | 내용 |
|---|---|
| 왼쪽 끝 | 프로그램 아이콘, **MyWorkPlan**, 버전(v1.0.0) |
| 그다음 | **홈** 버튼과 메뉴(파일 · 편집 · 보기 · 작업 · 자원 · 프로젝트 · 보고서 · 도움말) |
| 오른쪽 끝 | 창 버튼: **최소화** · **최대화**(최대화된 상태에서는 **이전 크기로**) · **닫기** |

- 메뉴 막대의 빈 곳을 끌면 창이 옮겨지고, 두 번 클릭하면 최대화와 이전 크기 사이를 오갑니다. 화면 가장자리로 끌어 붙이는 Windows 스냅도 그대로 됩니다.
- **닫기**는 **파일 › 끝내기**와 같아서, 저장하지 않은 계획이 있으면 먼저 저장할지 묻습니다.
- 웹 버전에는 아이콘·이름·버전만 보이고 창 버튼은 없습니다(브라우저 창의 버튼을 씁니다).

**홈** 버튼(`Ctrl+Shift+H`)은 켜고 끄는 버튼입니다.

| 지금 화면 | 홈을 누르면 |
|---|---|
| 열린 계획 | 시작 화면으로 갑니다. 열어 둔 계획은 탭에 그대로 남습니다 |
| 시작 화면, 열린 계획이 있음 | 보고 있던 계획으로 돌아갑니다 |
| 시작 화면, 열린 계획이 없음 | 새 **빈 프로젝트**를 엽니다 |

메뉴의 모든 항목에는 아이콘과 단축키가 함께 표시되고, 메뉴는 메인 창 밖까지 펼쳐집니다. 지금 쓸 수 없는 명령은 흐리게 보입니다. 웹 버전에는 데이터베이스 명령이 없습니다.

### 컬러 아이콘

메인 창, 메뉴, 팝업 창의 모든 아이콘은 뜻에 따라 저마다 색이 있습니다. 예를 들어 삭제·닫기는 빨강, 열기·최근 항목은 주황(호박색), 저장·데이터베이스는 남색, 인쇄·그림은 보라, 비용·임금은 갈색, 새로 만들기·추가는 초록, 도움말·정보는 파랑, 설정은 회청색입니다. 보기·보고서·템플릿·예제처럼 사물을 나타내는 아이콘은 이름마다 정해진 색을 씁니다. 그래서 같은 명령은 툴바·메뉴·팝업 어디서나 같은 색으로 보입니다. 밝은 테마에서는 조금 진하게, 어두운 테마에서는 조금 밝게 그려져 어느 테마에서도 잘 보입니다.

### 툴바

| 위치 | 버튼 |
|---|---|
| 왼쪽 | 새 프로젝트 · 열기 · 저장 · 인쇄 │ 실행 취소 · 다시 실행 │ 복사 · 붙여넣기 │ 작업 삽입 · 마일스톤 삽입 · 들여쓰기 · 내어쓰기 · 작업 연결 · 정보 │ 보기 전환(지금 보기 이름 ▾) │ 주 공정 표시 · 주 공정 찾기 │ 확대/축소 `[−] 100% [+]` │ 시간 눈금 축소 · 확대 │ 도구 패널 · 하단 패널 · 속성 패널 |
| 오른쪽 | 튜토리얼(학사모) · 테마(무작위) + ▾ · 언어(국기) · 설정 · 프로그램 정보(ⓘ) |

모든 버튼에 툴팁이 있습니다. 실행 취소·다시 실행 버튼의 툴팁은 무엇을 되돌리는지 알려 줍니다(예: "실행 취소: 기간 변경").

### 프로젝트 탭

프로젝트마다 탭이 하나씩 생깁니다. 탭이 많으면 양 끝의 화살표나 마우스 휠로 넘기고, `Ctrl+Tab`으로 다음 탭, `Ctrl+Shift+Tab`으로 이전 탭으로 갑니다. 탭 줄의 빈 곳을 두 번 클릭하거나 **+**를 누르면 새 프로젝트가 생깁니다. 저장하지 않은 변경이 있으면 탭 이름 뒤에 ●가 붙습니다.

|---|---|

| **차트에 표시** | 주 공정(Critical Path) 표시 · 여유 시간 표시 · 기준 계획 막대 표시 · 진행선 표시 |

### 속성 패널 (오른쪽)

선택한 것의 속성을 보여 주고 바로 고치게 합니다. 값을 고치고 `Enter`를 누르면 반영되고, `Ctrl+Z`로 되돌릴 수 있습니다.

| 선택 | 보이는 내용 |
|---|---|
| 없음 | 프로젝트: 제목, 프로젝트 시작, 완료, 기간, 상태 날짜, 완료율, 비용, 작업량, 작업 수, 자원 수, 주 공정·늦음·초과 할당·일정 충돌 개수, 버튼(프로젝트 · 달력 · 기준 계획 · 평준화) |
| 작업 하나 | 작업 이름, WBS, 기간, 시작, 완료, 완료율, 선행 작업, 자원 이름, 모드, 제약 유형·날짜, 마감일, 우선순위, 비용, 작업량, 총 여유 시간, 상태 표시(주 공정·늦어지고 있습니다·초과 할당·완료 차이), 메모, 막대 색, **자세히…** · **할당** · **찾아가기** |
| 작업 여러 개 | 선택 개수, 시작·완료, 비용, 연결 · 연결 끊기 · 들여쓰기 · 내어쓰기 · 0% · 50% · 100% · 비활성 · 정보 |
| 자원 | 이름, 종류, 약어, 그룹, 최대 단위, 표준 단가, 사용당 비용, 작업량, 비용, 할당된 작업 목록 |
| 연결선 | 선행 작업, 후속 작업, 연결 유형, 지연, **연결 삭제** |

**숫자 칸** — 숫자 값은 `[−] 값 단위 [+]` 모양의 칸으로, 값이 가운데 놓이고 모든 칸이 한 줄로 가지런히 맞춰집니다.

| 선택 | 칸 | 범위 · 한 번에 바뀌는 양 |
|---|---|---|
| 작업 | **기간** | 작업의 단위(일 · 주 · 시간 …) 그대로, 1씩 |
| 작업 | **완료율** | 0~100%, 5%씩 |
| 작업 | **우선순위** | 0~1000, 50씩 |
| 자원 | **최대 단위** | %, 10%씩 |
| 자원 | **표준 단가** | 원/시간, 1,000원씩(달러는 $1씩) |
| 자원 | **사용당 비용** | 금액 |
| 연결 | **지연** | 일, -365~365일. `50%`처럼 비율로 준 지연은 글자 칸으로 남습니다 |

- **−** · **+**를 누르면 한 단계씩, 누르고 있으면 계속 바뀝니다.
- 값을 직접 입력하고 `Enter`를 눌러도 되고, 칸 안에서 `↑` · `↓` 키로 한 단계씩 올리고 내릴 수 있습니다.

### 상태 표시줄

왼쪽부터 명령 결과(예: "작업 3개를 50% 완료로 표시했습니다."), **새 작업: 자동 일정/수동 일정**(클릭해서 바꾸기), 저장됨/수정됨, 작업 수, 선택 수, 주 공정 수, 프로젝트 완료 날짜, 완료율, 충돌 수, 필터 적용 중, 테마 이름, 언어, 시간 눈금 슬라이더, 확대 비율, 시계가 보입니다. **보기 › 상태 표시줄**로 숨기거나 보입니다.

### 하단 패널: 일정 점검

![하단 패널 — 일정 점검](docs/guide/images/ko/26-bottom-panel.png)

열린 계획의 보기 아래에 **일정 점검** 패널이 있습니다. 계획을 고칠 때마다 일정의 문제, 주 공정, 초과 할당, 지연, 마일스톤을 바로 다시 모아 보여 줍니다. 시작 화면에는 나오지 않습니다.

머리글에는 아이콘과 **일정 점검** 제목, 다섯 개 탭이 있고, 탭마다 해당 항목 수가 배지로 붙습니다(문제·초과 할당·지연은 있으면 색 배지).

| 탭 | 보여 주는 것 |
|---|---|
| **문제** | **심각도** · **문제** · **위치** 표. **오류**: 순환 연결(작업이 자기 자신을 기다림), 달력 오류(작업 시간이 없는 달력), 마감일 초과. **경고**: 제약 조건 충돌, 초과 할당(가장 바쁜 날 %와 일수), 늦은 작업(예정 %보다 덜 됨). **정보**: 연결 없는 작업(선행·후속 작업이 없음), 자원 없는 작업, 기간이 0인 수동 작업. 오류부터 차례로 늘어섭니다 |
| **주 공정** | 요약 줄(주 공정 작업 수와 남은 작업 수, 경로 수, 완료 날짜, 전체 기간)과 주 공정 작업 표. **차트에 표시** 버튼은 [주 공정 찾기](#주-공정과-여유-시간)를 켭니다 |
| **초과 할당** | 초과 할당된 사람마다 최대 사용 · 최대 단위 · **초과 일수** · **기간** · **겹치는 작업**. **다음 초과 할당** · **모두 평준화** 버튼 |
| **지연** | 늦어지는 작업과 **이유**: 마감일 초과, 늦음(완료율 / 예정 %), 기준 계획보다 늦게 끝남. 주 공정 작업이면 함께 표시됩니다 |
| **마일스톤** | 모든 마일스톤의 날짜와 **상태**: 완료 · 마감일 초과 · 늦어짐 · 예정대로 |

- **행을 누르면** 그 작업이나 자원으로 갑니다. 작업은 간트 차트(작업 보기가 아니면 간트 차트로 바꿈)에서 그 행을 선택해 보여 주고, 사람은 자원 시트(자원 보기가 아니면 자원 시트로 바꿈)에서 선택합니다.
- **접기/펴기**: 머리글 오른쪽의 접기 버튼을 누르면 머리글 한 줄만 남습니다. 접혀도 아이콘, 제목, 탭별 개수는 계속 보이고, 탭을 누르거나 펴기 버튼을 누르면 다시 열립니다.
- **끄기**: 머리글의 ×로 패널을 끕니다. 다시 켜려면 툴바의 **하단 패널** 버튼(도구 패널 버튼과 속성 패널 버튼 사이), `Ctrl+Shift+3`, **보기 › 표시 › 하단 패널 (일정 점검)**을 씁니다. **보기 › 표시 › 하단 패널 접기/펴기**로 접고 펼 수도 있습니다.
- **높이**: 패널 위쪽 가장자리를 위아래로 끌어 높이를 바꿉니다(120~640픽셀, 기본 230). 높이와 켜짐·접힘 상태는 저장되어 다음 실행 때도 그대로입니다.

### 팝업 창

작업 정보, 설정, 인쇄 미리 보기 같은 창은 데스크톱 앱에서 각자 독립된 창으로 열립니다. 메인 창 밖으로 옮길 수 있고, 메인 창을 닫으면 함께 닫힙니다. 웹 버전과 튜토리얼 중에는 메인 창 안에 떠 있는 창으로 열립니다.

## 계획 만들기

### 작업 추가와 편집

- **작업 › 작업 삽입**(`Insert`)은 선택한 행 위에 새 작업을 넣고 이름을 바로 입력하게 합니다.
- 표 맨 아래의 빈 행("여기에 새 작업 이름을 입력하세요")에 이름을 입력해도 작업이 생깁니다.
- **요약 작업 삽입**(`Ctrl+Shift+K`)은 선택한 작업들을 하위 작업으로 묶는 요약 작업을 만듭니다.
- 셀은 두 번 클릭하거나 `F2`·`Enter`로 편집합니다. 편집 중 `Enter`는 아래 칸, `Tab`은 오른쪽 칸으로 넘어가고 `Esc`는 취소합니다.
- 행 번호를 클릭해 선택하고(`Ctrl`+클릭: 여러 개, `Shift`+클릭: 범위), 행을 위아래로 끌어 옮깁니다. 좌우로 끌면 개요 수준이 바뀝니다.
- **작업 › 삭제**(`Delete`)는 선택한 작업과 그 하위 작업을 지웁니다. 삭제 전에 물어봅니다(**설정 › 일반 › 삭제하기 전에 묻기**).

### 기간

기간 칸에 숫자와 단위를 입력합니다. 시작·완료 날짜는 달력에 맞춰 자동으로 계산됩니다.

| 입력 | 뜻 |
|---|---|
| `5d`, `5일`, `5 days` | 작업일 5일 |
| `3w`, `3주` | 3주 |
| `4h`, `4시간` | 4시간 |
| `30m`, `30분` | 30분 |
| `1mo`, `1개월` | 1개월 |
| `2ed`, `3eh` | 경과 시간(쉬는 날·밤도 셈): 경과 2일, 경과 3시간 |
| `5d?` | 예상 기간(물음표가 붙어 표시됨) |
| `0d` | 마일스톤 |
| `5` | 단위 없는 숫자는 일 |

하루·한 주·한 달이 몇 시간인지는 **설정 › 일정**의 **하루 작업 시간**(8) · **한 주 작업 시간**(40) · **한 달 작업일**(20)을 따릅니다.

### 마일스톤

기간이 0인 작업이 마일스톤(마름모)입니다. **작업 › 마일스톤 삽입**(`Ctrl+Shift+M`)으로 넣거나, 기간에 `0`을 입력하거나, 작업 정보의 **마일스톤으로 표시**를 켭니다.

### 개요 (요약 작업)

- **들여쓰기 (하위 작업으로)**(`Alt+Shift+→`)는 작업을 위 작업의 하위 작업으로 만듭니다. 위 작업은 요약 작업이 되어 하위 작업의 기간·작업량·비용·완료율을 합칩니다.
- **내어쓰기**(`Alt+Shift+←`)로 되돌립니다. **위로 이동** · **아래로 이동**(`Alt+Shift+↑/↓`)은 하위 작업과 함께 옮깁니다.
- 요약 작업 이름 앞의 삼각형으로 접고 펼칩니다. **보기 › 요약 작업만 보기 (모두 접기)** · **모든 하위 작업 보기 (모두 펼치기)**로 한 번에 할 수 있습니다.
- WBS 코드(1, 1.1, 1.2 …)는 개요에 따라 자동으로 매겨집니다.

### 연결과 지연

- 작업을 둘 이상 선택하고 **작업 연결**(`Ctrl+F2`)을 누르면 위에서 아래 순서로 완료-시작(FS)으로 이어집니다. **연결 끊기**(`Ctrl+Shift+F2`)는 선택한 작업의 연결을 지웁니다.
- 간트 막대를 위아래로 끌어 다른 막대 위에 놓아도 연결됩니다.
- **선행 작업** 칸에 직접 입력할 수 있습니다: `3`, `5SS+2d`, `7FF-1d`, `4FS+50%`처럼 작업 ID 뒤에 연결 유형과 지연을 붙이고 쉼표로 구분합니다.
- 연결선을 두 번 클릭하면 **작업 연결** 창이 열리고, 오른쪽 클릭하면 유형을 바로 바꾸는 메뉴가 나옵니다.

| 연결 유형 | 뜻 |
|---|---|
| **완료-시작 (FS)** | 선행 작업이 끝나야 후속 작업이 시작 (기본) |
| **시작-시작 (SS)** | 선행 작업이 시작하면 후속 작업도 시작 |
| **완료-완료 (FF)** | 선행 작업이 끝나야 후속 작업이 끝남 |
| **시작-완료 (SF)** | 선행 작업이 시작해야 후속 작업이 끝남 |

**지연**은 `2d`(2일 뒤), `-1d`(1일 앞당김), `50%`(선행 작업 기간의 절반)처럼 씁니다. 요약 작업에 건 연결은 그 안의 모든 작업에 적용됩니다. 순환이 생기는 연결이나 요약 작업과 그 하위 작업 사이의 연결은 만들지 않습니다.

### 막대 끌기

| 끄는 곳 | 바뀌는 것 |
|---|---|
| 막대 가운데 | 시작 날짜 (작업에 "다음 날짜 이후에 시작" 제약이 걸립니다) |
| 막대 오른쪽 끝 | 기간 |
| 막대 왼쪽의 진행 손잡이 | 완료율 |
| 막대를 위아래로 다른 막대 위에 | 두 작업 연결 |
| 차트 빈 곳 (또는 `Ctrl+끌기`) | 차트 이동 |

막대를 두 번 클릭하면 작업 정보 창이 열립니다.

### 실행 취소와 복사·붙여넣기

- 모든 편집은 `Ctrl+Z`로 되돌리고 `Ctrl+Y`(또는 `Ctrl+Shift+Z`)로 다시 실행합니다. 탭(프로젝트)마다 기록이 따로 있습니다.
- `Ctrl+C` · `Ctrl+X` · `Ctrl+V`로 작업(하위 작업·연결·할당 포함)이나 자원을 복사·이동합니다.
- 엑셀이나 메모장에서 복사한 목록도 작업으로 붙여넣어집니다. 들여쓰기(공백 두 칸 또는 탭)는 개요 수준, 탭 뒤의 값은 기간이 됩니다. 반대로 복사한 작업은 엑셀에 이름·기간·시작·완료 열로 붙여넣어집니다.
- **아래로 채우기**(`Ctrl+D`): 여러 작업을 선택한 뒤 셀 하나를 고르면 첫 작업의 그 값이 아래 작업들에 복사됩니다.

### 작업 정보 창

![작업 정보 창](docs/guide/images/ko/05-task-info.png)

작업을 두 번 클릭하거나 **작업 › 정보…**(`Shift+F2`)를 누르면 열립니다. 작업을 여러 개 선택하고 열면 **여러 작업 정보** 창이 되어, 바꾼 항목만 선택한 모든 작업에 적용됩니다.

| 탭 | 항목 |
|---|---|
| **일반** | 이름, 기간과 **예상**, 완료율, 우선순위(0~1000), 일정 모드(자동/수동), 시작·완료(수동 일정일 때 직접 입력), **마일스톤으로 표시**, **활성** |
| **선행 작업** | 선행 작업 목록(작업 · 연결 유형 · 지연), **선행 작업 추가**, 연결 삭제 |
| **자원** | 할당된 자원과 단위(작업 자원 %, 재료 수량, 비용 자원 금액), **자원 할당**, 할당 해제 |
| **고급** | 제약 유형과 제약 날짜, 마감일, 작업 유형, 노력 기반, 작업 달력, 고정 비용, WBS 코드 |
| **메모** | 메모, 하이퍼링크 (웹 주소나 파일) |
| **사용자 지정 필드** | 텍스트1~3, 숫자1, 플래그1, 막대 색, 간트 막대 숨기기, 시간 표시 막대에 표시 |

**메모…** 명령은 이 창을 메모 탭으로 엽니다.

### 반복 작업

**작업 › 반복 작업…**은 주간 회의처럼 되풀이되는 작업을 한 번에 만듭니다.

| 항목 | 내용 |
|---|---|
| **이름** · **기간 · 시각** | 예: 주간 회의, `1h`, 시작 시각 `10:00` |
| **반복** | 매일 · 매주 · 매월 · 매년, **간격**(몇 일·주·달마다) |
| **요일** / **날짜** | 매주: 요일 체크, 매월·매년: 날짜 |
| **작업일에만** | 매일 반복에서 쉬는 날 건너뛰기 |
| **시작** · **끝** | 시작 날짜, 끝은 **횟수**(반복 횟수) 또는 **날짜까지**(끝 날짜) |

결과는 요약 작업 하나와 그 아래 회차별 작업이며, 회차마다 "다음 날짜 이후에 시작" 제약으로 날짜가 고정됩니다. 표시기 열에 반복 작업 아이콘이 붙습니다.

### 그 밖의 작업 명령

| 명령 | 하는 일 |
|---|---|
| **작업 비활성화** | 작업을 지우지 않고 일정·비용 계산에서 뺍니다(회색 표시). 다시 누르면 활성 |

| **프로젝트 › 다른 프로젝트 삽입…** | 다른 파일(.mwp · .mwpt · XML · CSV)의 작업을 요약 작업 하나 아래에 넣음. 같은 이름의 자원은 합쳐짐 |

## 일정

### 자동 일정과 수동 일정

- **자동 일정** 작업은 연결·제약·달력에 따라 날짜가 계산됩니다.
- **수동 일정** 작업은 입력한 시작·완료 날짜에 그대로 머뭅니다(막대가 다른 모양으로 표시).
- 선택한 작업은 **작업 › 수동 일정** · **자동 일정**으로 바꿉니다. 새 작업의 모드는 상태 표시줄의 **새 작업: 자동 일정/수동 일정**을 클릭하거나 **설정 › 일정 › 새 작업의 일정 모드**에서 정합니다.

### 제약 조건

작업 정보 › **고급** 탭(또는 속성 패널)의 **제약 유형**과 **제약 날짜**로 정합니다.

| 제약 유형 | 뜻 |
|---|---|
| **가능한 한 빨리** | 기본. 연결이 허락하는 가장 이른 날짜 |
| **가능한 한 늦게** | 후속 작업과 프로젝트 완료를 늦추지 않는 가장 늦은 날짜 |
| **다음 날짜 이후에 시작** | 제약 날짜보다 일찍 시작하지 않음 |
| **다음 날짜 이전에 시작** | 제약 날짜까지는 시작 |
| **다음 날짜 이후에 완료** | 제약 날짜보다 일찍 끝나지 않음 |
| **다음 날짜 이전에 완료** | 제약 날짜까지는 끝남 |
| **반드시 시작해야 하는 날짜** | 그 날짜에 시작 |
| **반드시 완료해야 하는 날짜** | 그 날짜에 완료 |

연결과 제약이 맞지 않으면(예: 선행 작업 때문에 "반드시 시작해야 하는 날짜"를 지킬 수 없음) 상태 표시줄에 **충돌** 개수가 뜨고 표시기 열에 경고가 붙습니다. **프로젝트 정보 › 작업이 제약 날짜를 항상 따름**이 켜져 있으면 제약 날짜가, 꺼져 있으면 연결이 이깁니다. 충돌과 순환 연결, 달력 오류는 [하단 패널](#하단-패널-일정-점검)의 **문제** 탭에 모여 있어, 행을 누르면 그 작업으로 갑니다.

### 마감일

**마감일**은 작업을 옮기지는 않지만 늦은 날짜 계산에 들어가고, 작업이 마감일을 넘기면 표시기 열에 "마감일을 넘겼습니다" 경고가 뜹니다. 간트 차트에는 마감일 표시가 그려집니다. 마감일을 넘긴 작업은 [하단 패널](#하단-패널-일정-점검)의 **문제** · **지연** 탭에도 나옵니다.

### 달력과 작업 시간

**프로젝트 › 작업 시간 변경…**에서 달력을 고칩니다.

- 기본 달력: **표준**(월~금 08:00-12:00, 13:00-17:00), **24시간**, **야간 근무**.
- **새 달력** · **이름 바꾸기** · **삭제** · **프로젝트 달력으로** 버튼으로 달력을 관리합니다.
- **작업 주** 탭: 요일마다 **작업하는 날** 스위치와 작업 시간(예: `08:00-12:00, 13:00-17:00`, 24시간제).
- **예외 (휴일·특근)** 탭: 이름, 시작, 끝과 시간을 넣고 **추가**. 시간을 비우면 쉬는 날, 시간을 쓰면 특근입니다.
- 작업은 자기 **작업 달력** → 할당된 작업 자원의 달력 → 프로젝트 달력 순서로 달력을 씁니다.

### 주 공정과 여유 시간

![주 공정 찾기](docs/guide/images/ko/06-critical-path.png)

- **주 공정 작업**(빨간 막대)은 여유 시간이 없어서 늦어지면 프로젝트 완료가 늦어지는 작업입니다. **보기 › 주 공정(Critical Path) 표시**로 켜고 끕니다.
- **여유 시간 표시**를 켜면 막대 뒤에 가는 선으로 자유 여유 시간(다른 작업을 늦추지 않고 미룰 수 있는 시간)이 보입니다.
- **총 여유 시간** · **자유 여유 시간** · **빠른/늦은 시작·완료**는 **일정** 표에서 볼 수 있습니다.
- **프로젝트 정보 › 여유 시간이 이 일수 이하면 주 공정**으로 기준을 넓힐 수 있습니다(기본 0일).

**주 공정 찾기** — 툴바의 주 공정 찾기 버튼(`Ctrl+Shift+P`, **프로젝트** 메뉴에도 있음)은 켜고 끄는 버튼입니다. 누르면 일정을 앞에서 뒤로(가장 빠른 시작·완료) 그리고 뒤에서 앞으로(가장 늦은 시작·완료) 다시 계산하고, 여유 시간이 없는 작업을 시작에서 끝까지 이어지는 경로로 찾아 표시합니다. 주 공정 작업과 연결선은 빨갛게 강조되고 나머지는 흐려지며, 차트는 경로의 처음으로 이동합니다. 상태 표시줄에 주 공정 작업 수가, 알림에 경로(예: `12. 디자인 시스템 → … → 34. 프로젝트 종료`)와 완료 날짜가 나옵니다. 다시 누르거나 상태 표시줄의 주 공정 항목을 누르면 꺼집니다. [하단 패널](#하단-패널-일정-점검)의 **주 공정** 탭은 주 공정 작업을 표로 보여 주고, 그 탭의 **차트에 표시**도 이 기능을 켭니다.

### 일정 기준과 프로젝트 정보

**프로젝트 › 프로젝트 정보…**

| 탭 | 항목 |
|---|---|
| **일반** | 제목, **일정 기준**(프로젝트 시작 날짜 / 프로젝트 완료 날짜), 시작 날짜 또는 완료 날짜, 프로젝트 달력, 우선순위, 통화(₩ · $ · € · ¥ · £), 주 공정 여유 기준, 제약 날짜 따르기 |
| **상태** | 상태 날짜, 오늘, 완료율, 늦은 작업·주 공정·충돌 개수 |
| **통계** | 시작·완료·기간·작업량·비용의 현재 · 기준 계획 · 실제 · 남음, 작업·마일스톤·자원 수 |
| **속성** | 주제, 작성자, 관리자, 회사, 범주, 키워드, 설명 |

**일정 기준**을 "프로젝트 완료 날짜"로 하면 완료 날짜에서 거꾸로 계산해 모든 작업이 가능한 한 늦게 놓입니다. **프로젝트 통계…**는 이 창을 통계 탭으로, **상태 날짜…**는 상태 탭으로 엽니다.

### 지금 계산

일정은 편집할 때마다 자동으로 다시 계산됩니다. **프로젝트 › 지금 계산**(`F9`)은 오늘 날짜 기준 값(늦은 작업 등)을 새로 고칠 때 씁니다.

## 자원과 비용

### 자원 시트

![자원 시트](docs/guide/images/ko/13-resource-sheet.png)

**자원 › 자원 시트** 보기에서 자원을 등록합니다. 맨 아래 빈 행에 이름을 입력하거나 **자원 추가**(`Ctrl+Shift+R`)를 누릅니다.

| 종류 | 쓰임 | 비용 계산 |
|---|---|---|
| **작업** | 사람·장비. 최대 단위(100% = 한 사람 전일), 달력 | 작업량(시간) × 표준 단가 + 사용당 비용 |
| **재료** | 시멘트·종이처럼 수량으로 쓰는 것. 재료 단위(예: 톤) | 수량 × 표준 단가 + 사용당 비용 |
| **비용** | 출장비·임대료처럼 금액만 있는 것 | 할당할 때 입력한 금액 |

자원을 두 번 클릭하면 **자원 정보** 창(일반 · 비용 · 할당 · 메모 탭)이 열립니다. 초과 할당된 자원은 빨갛게 표시됩니다.

### 자원 할당

작업을 선택하고 **자원 › 자원 할당…**(`Alt+F10`)을 엽니다. 자원을 체크하고 단위(작업 자원은 %, 50% = 반나절)를 정하면 작업량과 비용이 계산됩니다. 아래 칸에 새 자원 이름을 쓰고 **추가하고 할당**을 누르면 자원을 만들면서 할당합니다.

**자원 이름** 칸에 직접 `김철수, 이영희[50%]`처럼 입력해도 됩니다. 없는 이름은 새 작업 자원으로 만들어집니다. 요약 작업에는 자원을 할당하지 않습니다.

### 작업 유형과 노력 기반

작업 정보 › **고급**에서 정합니다.

| 작업 유형 | 기간을 바꾸면 |
|---|---|
| **단위 고정** (기본) | 작업량이 따라 바뀜 |
| **기간 고정** | 기간만 바뀜 |
| **작업량 고정** | 작업량은 그대로, 단위가 바뀜 |

**노력 기반 (자원을 늘리면 기간이 줄어듦)**을 켜면, 작업 자원을 더 할당할 때 전체 작업량이 유지되도록 기간이 줄어듭니다(기간 고정 작업 제외).

### 비용

- 작업 비용 = 할당된 자원의 비용 + **고정 비용**. 요약 작업과 프로젝트는 하위 작업 비용을 합칩니다.
- **비용** 표에서 고정 비용, 비용, 기준 비용, 비용 차이, 실제 비용, 남은 비용을 봅니다. 실제 비용은 완료율만큼 계산됩니다.
- 통화 기호는 **프로젝트 정보 › 통화**에서 고릅니다.

### 개인별 임금과 인건비

![자원 정보의 임금 입력](docs/guide/images/ko/24-resource-wage.png)

사람(작업 자원)마다 임금을 시급뿐 아니라 일급·주급·월급·연봉으로 넣을 수 있습니다. 일정 계산은 시간 단위로 하므로, 프로그램이 임금을 **시간당 단가**로 바꿔 표준 단가로 씁니다.

1. 자원 시트에서 사람을 두 번 클릭해 **자원 정보** 창을 열고 **비용** 탭으로 갑니다.
2. **임금 기준**에서 **시급** · **일급** · **주급** · **월급** · **연봉** 중 하나를 고릅니다.
3. **임금** 칸(예: `₩/월`)에 금액을 넣습니다. 아래 **시간당 단가** 줄에 바뀐 값이 입력하는 대로 바로 보입니다. 예: "시간당 ₩90,000 (₩14,400,000 ÷ 160시간)".
4. **확인**을 누르면 그 시간당 단가가 자원의 **표준 단가**가 되고, 작업량 × 표준 단가로 비용이 다시 계산됩니다.

| 임금 기준 | 시간당 단가 계산 |
|---|---|
| **시급** | 그대로 |
| **일급** | 금액 ÷ 하루 작업 시간 |
| **주급** | 금액 ÷ 한 주 작업 시간 |
| **월급** | 금액 ÷ (한 달 작업일 × 하루 작업 시간) |
| **연봉** | 금액 ÷ (12 × 한 달 작업일 × 하루 작업 시간) |

기본값(하루 8시간, 한 주 40시간, 한 달 20일)이면 월급 4,000,000원은 시간당 25,000원입니다. **설정 › 일정**의 **하루 작업 시간** · **한 주 작업 시간** · **한 달 작업일**을 바꾸면 일급·주급·월급·연봉인 사람들의 시간당 단가가 새 값에 맞게 다시 계산됩니다.

**인건비 표** — 자원 시트에서 **보기 › 표 (열 묶음)**(또는 도구 모음의 **표** 목록)를 **인건비**로 바꾸면 이름 · 그룹 · **임금 기준** · **임금** · **표준 단가** · **작업량** · **비용** · **전체 비용 중 비율** 열이 보입니다. 임금 기준과 임금은 표에서 바로 고칠 수 있습니다. **표준 단가** 칸에 직접 금액을 입력하면 그 사람은 다시 시급으로 바뀝니다.

**작업의 인건비** — 작업 표의 **비용** 표에는 **인건비** 열이 있어, 작업 비용 중 사람에게 드는 몫을 따로 봅니다.

**프로젝트 통계** — **프로젝트 › 프로젝트 통계…**의 표에 **인건비** 줄(현재 · 기준 계획 · 실제 · 남음)과 **인건비 비율** 줄("인건비 / 전체 비용, 재료비, 그 밖의 비용")이 있습니다.

전체 내용은 **보고서 › 인건비 보고서**에서 봅니다([보고서](#보고서) 참고).

### 초과 할당

![자원 사용](docs/guide/images/ko/14-resource-usage.png)

자원이 하루에 할 수 있는 양(최대 단위 × 그날 작업 시간)보다 많은 일이 겹치면 초과 할당입니다.

- 자원 시트에서 빨간색, 작업의 표시기 열에 "자원이 초과 할당되었습니다" 아이콘이 붙습니다.
- **자원 사용** 보기에서 넘치는 날이 빨간 칸으로 보입니다.
- **자원 그래프** 보기는 한 자원의 날짜별 작업량을 막대로, 사용 가능한 양을 선으로 보여 줍니다(일 단위/주 단위).
- **자원 › 다음 초과 할당**은 초과 할당된 다음 작업으로 이동합니다.
- [하단 패널](#하단-패널-일정-점검)의 **초과 할당** 탭은 초과 할당된 사람마다 초과 일수·기간·겹치는 작업을 보여 주고, 거기서 **다음 초과 할당**과 **모두 평준화**를 바로 누를 수 있습니다.

![자원 그래프](docs/guide/images/ko/15-resource-graph.png)

### 자원 평준화

![평준화 옵션](docs/guide/images/ko/19-leveling.png)

**자원 › 모두 평준화**는 초과 할당이 없어질 때까지 우선순위가 낮은 작업부터 뒤로 미룹니다. 미룬 양은 **평준화 지연** 필드에 들어가며 **평준화 지우기**로 원래대로 돌립니다(작업을 선택했으면 그 작업만).

**평준화 옵션…** 창:

| 항목 | 내용 |
|---|---|
| **평준화 순서** | 표준 (시작·우선순위) · ID 순 · 우선순위 먼저 |
| **여유 시간 안에서만 평준화 (완료 날짜를 늦추지 않음)** | 켜면 프로젝트 완료를 늦추는 이동은 하지 않음 |
| **평준화하기 전에 이전 평준화 지우기** | 기본 켜짐 |
| **초과 할당된 자원** | 지금 초과 할당된 자원 목록 |
| 버튼 | 평준화 지우기 · 저장(옵션만) · **지금 평준화** |

우선순위 1000인 작업, 수동 일정 작업, 이미 시작한 작업, "반드시 시작/완료해야 하는 날짜" 작업은 옮기지 않습니다. 다 풀지 못하면 남은 자원 이름이 상태 표시줄에 표시됩니다.

### 팀 플래너

![팀 플래너](docs/guide/images/ko/16-team-planner.png)

**자원 › 팀 플래너**는 사람마다 한 줄에 작업 블록을 보여 줍니다. 블록을 다른 사람의 줄로 끌면 담당자가 바뀌고, 맨 아래 **할당되지 않은 작업** 줄에서 끌어오면 할당됩니다. 초과 할당된 줄은 빨갛게 표시됩니다.

## 진행 추적

### 기준 계획

![기준 계획 설정](docs/guide/images/ko/18-baseline.png)

계획을 확정하면 **프로젝트 › 기준 계획 설정…**으로 지금 일정(시작 · 완료 · 기간 · 작업량 · 비용)을 저장해 둡니다.

- 창 위쪽의 **작업**에서 **설정**(저장)과 **지우기**를 고릅니다.
- **기준 계획**과 **기준 계획 1~10**, 모두 11개까지 저장합니다. 저장한 날짜가 목록에 표시됩니다(예: "기준 계획 (2026. 10. 19. 저장)").
- **대상**: **전체 프로젝트** 또는 **선택한 작업**(괄호 안은 선택한 작업 수).
- 기준 계획을 다시 저장할 때 **이전 기준 계획을 기준 계획 1에 남기기**로 이전 것을 보관할 수 있습니다.
- **기준 계획 지우기…**는 저장한 기준 계획을 지웁니다(일정은 바뀌지 않음).
- 차이(시작 차이, 완료 차이, 기간·작업량·비용 차이)와 추적 간트의 회색 막대는 **기준 계획**(0번)과 비교합니다.

### 완료율

작업을 고르고 **0% 완료** · **25% 완료** · **50% 완료** · **75% 완료** · **100% 완료**를 누릅니다(작업 메뉴, 도구 모음의 진행 영역). 실제 시작·완료 날짜가 자동으로 기록되고 막대 안의 어두운 부분으로 진행률이 보입니다. 막대의 진행 손잡이를 끌거나 속성 패널의 **완료율** 칸(`[−] 값 [+]`, 5%씩)으로도 바꿉니다.

**예정대로 진행으로 표시**는 선택한 작업을 상태 날짜까지 일정대로 진행한 것으로 표시합니다.

### 작업 업데이트

**작업 › 작업 업데이트…**(작업 하나 선택)는 완료율, 실제 기간, 남은 기간, 실제 시작, 실제 완료를 자세히 입력하는 창입니다.

### 프로젝트 업데이트

**프로젝트 › 프로젝트 업데이트…**

| 항목 | 내용 |
|---|---|
| **기준 날짜 (상태 날짜)** | 이 날짜가 프로젝트의 상태 날짜가 됩니다 |
| **이 날짜까지 일정대로 완료로 표시** | 이 날짜 전에 끝나야 하는 작업은 100%, 걸쳐 있는 작업은 지난 시간만큼 완료로 표시 |
| **남은 작업을 이 날짜 뒤로 다시 일정** | 아직 시작하지 않았는데 이 날짜 전에 시작하기로 된 작업을 이 날짜 이후로 옮김 |
| **대상** | 전체 프로젝트 또는 선택한 작업 |

### 상태 날짜

상태 날짜는 진행 상황을 판단하는 기준일입니다(늦은 작업, 진행선, 보고서, 프로젝트 업데이트). **프로젝트 › 상태 날짜…**(프로젝트 정보의 상태 탭)에서 정합니다. 정하지 않으면 오늘을 씁니다. 상태 날짜까지 끝났어야 하는데 덜 된 작업은 **늦은 작업**이 되어 표시기 열에 "늦어지고 있습니다"가 붙습니다. 늦은 작업과 기준 계획보다 늦게 끝나는 작업은 [하단 패널](#하단-패널-일정-점검)의 **지연** 탭에서, 마일스톤의 상태(완료 · 마감일 초과 · 늦어짐 · 예정대로)는 **마일스톤** 탭에서 한눈에 봅니다.

### 추적 간트와 진행선

![추적 간트](docs/guide/images/ko/07-tracking.png)

**추적 간트** 보기는 위에 현재 일정 막대, 아래에 기준 계획 회색 막대를 그립니다. **보기 › 진행선 표시**를 켜면 상태 날짜에서 각 작업이 어디까지 진행했는지 이은 선이 보입니다. 선이 왼쪽으로 꺾이면 늦은 작업입니다. 간트 차트에서도 **기준 계획 막대 표시**를 켜면 기준 계획이 보입니다.

예제 중 "진행 중"(초록 점) 예제를 열면 기준 계획과 진행이 이미 들어 있어서 이 보기를 바로 확인할 수 있습니다.

### 간트 차트

왼쪽은 작업 표, 오른쪽은 간트 차트입니다. 가운데 구분자로 너비를 나눕니다. 차트에는 2단 시간 눈금, 쉬는 날 음영, 오늘 선, 상태 날짜 선, 연결 화살표, 마감일, 기준 계획 막대, 여유 시간 선이 그려집니다. 검은 괄호 모양 막대는 요약 작업, 마름모는 마일스톤, 빨간 막대는 주 공정 작업입니다. 막대 옆 글자는 **설정 › 간트 차트 › 막대 옆 글자**(이름 · 자원 · 완료율 · 없음)로 고릅니다. 그림은 [화면 구성](#화면-구성)을 보세요.

### 네트워크 다이어그램

![네트워크 다이어그램](docs/guide/images/ko/10-network.png)

### 일정표

![일정표](docs/guide/images/ko/11-calendar.png)

달력에 작업이 걸쳐 있는 날을 막대로 보여 줍니다. **이번 달** · **프로젝트 시작 달** 버튼, 달 이름 양옆의 화살표(이전 달 · 다음 달)나 마우스 휠로 달을 넘깁니다. 한 주에 다 들어가지 않으면 "+N"으로 표시됩니다.

### 시간 표시 막대

![시간 표시 막대](docs/guide/images/ko/12-timeline.png)

프로젝트 전체를 한 줄에 요약합니다. 최상위 요약 작업(단계)은 막대, 마일스톤은 마름모, **시간 표시 막대에 추가**한 작업은 말풍선으로 보입니다. 보고용으로 좋습니다.

## 표·열·필터·그룹·정렬·찾기

### 표 (열 묶음)

**보기 › 표 (열 묶음)** 또는 도구 모음의 **표** 목록으로 열 묶음을 바꿉니다.

| 표 | 열 |
|---|---|
| **입력** | 표시기, 모드, 작업 이름, 기간, 시작, 완료, 선행 작업, 자원 이름 |
| **일정** | 시작, 완료, 늦은 시작, 늦은 완료, 자유 여유 시간, 총 여유 시간 |
| **비용** | 고정 비용, 인건비, 비용, 기준 비용, 비용 차이, 실제 비용, 남은 비용 |
| **작업량** | 작업량, 기준 작업량, 작업량 차이, 실제 작업량, 남은 작업량, 완료율 |
| **추적** | 실제 시작, 실제 완료, 완료율, 실제 기간, 남은 기간, 실제 비용, 실제 작업량 |
| **차이** | 시작, 완료, 기준 시작, 기준 완료, 시작 차이, 완료 차이 |
| **기준 계획** | 기준 기간, 기준 시작, 기준 완료, 기준 작업량, 기준 비용 |

| **제약 조건** | 기간, 제약 유형, 제약 날짜, 마감일, 우선순위, 작업 유형 |

자원 시트에는 입력 · 비용 · 인건비 · 작업량 · 요약 표가 있습니다.

### 열 선택

- **보기 › 열 선택…**: 왼쪽 **표시할 열**에서 순서를 바꾸고(위로/아래로) 숨기며, 오른쪽 **사용할 수 있는 열**에서 더합니다. **기본 열로** 되돌릴 수 있습니다. 표마다 따로 저장됩니다.
- 열 머리글을 오른쪽 클릭하면 정렬, 이 열 숨기기, 열 너비 원래대로가 있습니다.
- 열 경계를 끌어 너비를 바꾸고, 두 번 클릭하면 내용에 맞춥니다.

### 필터와 강조 표시

**보기 › 필터** 또는 도구 모음의 **필터** 목록:

모든 작업 · 활성 작업 · 완료된 작업 · 완료되지 않은 작업 · 주 공정 작업 · 마일스톤 · 요약 작업 · 늦은 작업 · 초과 할당된 작업 · 시작하지 않은 작업 · 진행 중인 작업 · 마감일이 있는 작업 · 제약 조건이 있는 작업 · 수동 일정 작업 · 날짜 범위… · 자원 사용 작업…

- 필터를 걸어도 맞는 작업 위의 요약 작업은 남아서 개요가 유지됩니다.
- **필터 대신 강조 표시**를 켜면 모든 작업을 보이면서 맞는 작업만 칠합니다.
- 도구 모음의 **검색** 칸은 작업 이름 · 메모 · 자원 이름을 바로 걸러 줍니다.
- 필터가 걸려 있으면 상태 표시줄에 **필터 적용 중**이 뜹니다. **필터·그룹·정렬 지우기**로 모두 풉니다.

### 그룹과 정렬

- **그룹**: 그룹 없음 · 주 공정 여부 · 마일스톤 여부 · 우선순위 · 자원 · 상태 · 기간 · 완료율 · 제약 조건 · 일정 모드. 그룹마다 머리 행에 개수가 보입니다.
- **정렬**: ID 순 (기본) · 이름순 · 시작 날짜순 · 완료 날짜순 · 기간순 · 우선순위순 · 비용순 · 작업량순 · 여유 시간순.

### 찾기·바꾸기·이동

**찾기** 창에는 네 탭이 있습니다.

| 탭 | 단축키 | 내용 |
|---|---|---|
| **찾기** | `Ctrl+F` | 찾을 내용, 찾을 필드(작업 이름 · 메모 · 자원 이름 · 텍스트1~3 · 하이퍼링크), 대/소문자 구분, 단어 단위로, **이전** · **다음 찾기** |
| **바꾸기** | `Ctrl+H` | 바꿀 내용과 **모두 바꾸기** (한 번에 실행 취소 가능) |
| **이동** | `Ctrl+G` | 작업 ID 또는 날짜로 이동 |
| **날짜 범위 필터** | | 시작~끝 기간에 걸친 작업만 보이기 |

창은 열어 둔 채로 계속 찾을 수 있습니다.

| **단계별 인건비** | 최상위 단계마다 인건비 막대, 막대 아래 회색은 그 단계의 전체 비용 |
| **개인별 인건비** | 사람마다 이름 · 그룹 · 임금 기준 · 임금 · 표준 단가 · 작업량 · 인건비 · 실제 비용 · 인건비 중 비율, 맨 아래 합계 |

다른 보고서처럼 **보고서 내보내기** · **보고서 복사** · **인쇄…**를 쓸 수 있습니다.

**보고서 복사**는 보고서 내용을 글자로 클립보드에 넣어 엑셀이나 문서에 붙여넣게 합니다. 보고서 화면의 **인쇄…**는 [인쇄 미리 보기](#인쇄와-미리-보기)를 엽니다(작업 표와 간트 차트가 인쇄됩니다).

### 보고서 내보내기

**보고서 내보내기**는 지금 보고 있는 보고서를 파일로 저장합니다. **보고서 › 보고서 내보내기** 하위 메뉴, 보고서 화면 머리글의 **보고서 내보내기…** 버튼, 보고서 빈 곳의 오른쪽 클릭 메뉴에서 형식을 고릅니다.

| 형식 | 내용 |
|---|---|
| **HTML (.html)** | 브라우저에서 바로 여는 한 파일짜리 웹 페이지. 차트는 SVG 그림이고, 각 차트 아래 **값**을 펼치면 숫자 표가 보입니다. 메일에 첨부하거나 사내 위키에 올리기 좋습니다 |
| **Markdown (.md)** | 제목과 GitHub 표. 차트는 숫자 표로 바뀝니다. Git 저장소·이슈·노트 앱에 붙여넣을 때 씁니다 |
| **Word (.docx)** | A4 Word 문서. 제목·표(테두리, 머리글 행이 페이지마다 반복)·차트 그림과 그 숫자 표가 들어 있고, 글꼴은 맑은 고딕입니다. Word·한컴오피스·LibreOffice에서 고쳐 쓸 수 있습니다 |
| **PDF (.pdf)** | A4 쪽마다 보고서를 그린 PDF. 한글 글꼴을 넣지 않아도 어디서나 똑같이 보이도록 쪽을 그림으로 담았기 때문에 글자를 골라 복사할 수는 없습니다 |

파일 이름은 "프로젝트 제목 - 보고서 이름"으로 제안되고, 만드는 데 시간이 걸리면 진행 팝업이 뜹니다.

## 파일

### 저장

- **저장**(`Ctrl+S`)은 MyWorkPlan 프로젝트 파일(`.mwp`)로 저장합니다. 처음 저장하거나 템플릿·예제·가져온 파일에서 시작했으면 파일 이름을 묻습니다.
- **다른 이름으로 저장…**(`Ctrl+Shift+S`), **모두 저장**(`Ctrl+Alt+S`: 수정된 탭을 모두 저장).
- 파일은 임시 파일에 다 쓴 뒤 바꿔치기하므로 저장 도중 문제가 생겨도 원래 파일이 깨지지 않습니다. 큰 파일은 진행 창이 표시됩니다.
- **설정 › 일반 › 시작할 때 지난번에 연 파일 다시 열기**를 켜면 다음 실행 때 열려 있던 파일을 다시 엽니다.

### 템플릿

**파일 › 템플릿으로 저장…**은 진행 상황(완료율·실제 날짜), 기준 계획, 상태 날짜, 평준화 지연을 뺀 `.mwpt` 파일을 만듭니다. 템플릿을 열면 제목 없는 새 프로젝트가 되고, 저장할 때 새 `.mwp` 이름을 묻습니다.

### 가져오기와 내보내기

| 명령 | 형식 | 비고 |
|---|---|---|
| **가져오기 (MS Project XML · CSV)…** | `.xml`(MS Project XML), `.csv` · `.tsv` · `.txt` | 작업·개요·연결·지연·제약·달력·자원·할당·기준 계획을 읽습니다. CSV 머리글은 영어·한국어(MS Project 이름) 모두 알아봅니다. 가져온 프로젝트는 저장하면 `.mwp`가 됩니다 |
| **MS Project XML로 내보내기…** | `.xml` | Microsoft Project 2010 이후 버전에서 열 수 있는 MSPDI 형식 |
| **CSV로 내보내기…** | `.csv` | UTF-8(BOM), 영어 머리글: ID, WBS, Name, Outline Level, Duration, Start, Finish, Predecessors, Resource Names, % Complete, Cost, Work, Milestone, Notes |
| **간트 차트 그림으로 내보내기 (PNG)…** | `.png` | 표(이름·기간·시작·완료)와 간트 차트 전체를 한 장의 그림으로 |

**열기…**(`Ctrl+O`)로도 XML과 CSV를 열 수 있습니다. 시작 화면의 **가져오기** 타일도 같은 일을 합니다.

### 최근 파일과 폴더

- **파일 › 최근 파일…**(`Ctrl+R`)은 **최근 파일**과 **최근 폴더** 탭이 있는 창을 엽니다. 각각 10개까지 기억합니다.
- 항목마다 **열기**(폴더는 **이 폴더에서 열기**)와 **목록에서 지우기**가 있고, **모두 지우기** · **폴더 기록 모두 지우기**로 한 번에 지웁니다.
- 없어진 파일은 **없음**으로 표시되고, 열려고 하면 목록에서 지울지 묻습니다.
- **파일 › 최근 폴더**는 폴더 목록을 메뉴로 보여 주고, **최근 파일·폴더 기록 모두 지우기**는 두 목록을 함께 지웁니다.
- 시작 화면의 **최근 항목** 카드와 **설정 › 최근 기록** 탭에서도 같은 목록을 관리합니다.

### 끌어다 놓기

탐색기(Finder)에서 파일을 창으로 끌어오면:

| 끌어온 것 | 결과 |
|---|---|
| `.mwp` · `.mwpt` · `.json` | 프로젝트로 엽니다 |
| `.xml` · `.csv` · `.tsv` · `.txt` | 가져옵니다 |
| 이미지(png · jpg · gif · webp · bmp · svg …) | 배경 이미지가 됩니다 |
| 텍스트 (웹 버전) | 한 줄에 작업 하나로 추가됩니다 |

`.mwp` · `.mwpt` 파일을 두 번 클릭해도 MyWorkPlan에서 열립니다(설치 프로그램이 파일 형식을 등록함). 이미 열려 있는 파일을 다시 열면 그 탭으로 갑니다.

### 저장하지 않은 변경 확인

- 탭을 닫을 때(`Ctrl+W`) 저장하지 않은 변경이 있으면 **저장** · **저장 안 함** · **취소**를 묻습니다.
- 프로그램을 끝낼 때(**파일 › 끝내기**, 시작 화면의 **끝내기**, 창 닫기) 저장하지 않은 프로젝트가 있으면 목록을 보여 주고 같은 질문을 합니다.
- 접고 펼친 상태만 바뀐 것은 변경으로 치지 않습니다.

## 데이터베이스

파일 대신 데이터베이스에 계획을 보관할 수 있습니다(데스크톱 앱 전용 — 웹 버전은 DB에 직접 연결할 수 없어 메뉴가 보이지 않습니다).

### 연결 설정

**설정 › 데이터베이스** 탭에서 고릅니다.

| 항목 | 설명 |
|---|---|
| **DB 종류** | 사용 안 함 · SQLite · MariaDB · MySQL · PostgreSQL |
| **SQLite 파일** | SQLite일 때. **찾아보기…**로 기존 파일을 고르거나 새 파일 이름을 정하면 처음 연결할 때 만들어집니다 |
| **서버 주소 · 포트 · 데이터베이스 이름 · 사용자** | 서버 DB일 때. 포트를 바꾸지 않으면 MariaDB/MySQL 3306, PostgreSQL 5432. 데이터베이스는 미리 만들어 두어야 합니다 |
| **비밀번호** | 기본으로는 저장하지 않고 프로그램을 닫을 때까지만 기억합니다. **비밀번호를 설정에 저장**을 켜면 설정에 함께 저장됩니다 |
| **연결 테스트** | 접속해 서버 버전을 보여 주고, 계획을 담는 표 `myworkplan_plans`가 없으면 만듭니다. 실패하면 이유(비밀번호는 빼고)를 보여 줍니다 |

### 저장하고 열기

- **파일 › 데이터베이스에 저장**은 지금 탭의 계획을 `.mwp` 파일과 똑같은 내용으로 저장합니다. 같은 계획(프로젝트 ID가 같음)을 다시 저장하면 덮어씁니다. 파일 없이 데이터베이스에서 연 계획은 이것으로 저장되어 "저장하지 않은 변경"이 사라집니다.
- **파일 › 데이터베이스에서 열기…**는 저장된 계획 목록(제목 · 마지막 저장 시각 · 크기, 최근 것부터)을 보여 줍니다. **열기**로 새 탭에 열고, 휴지통 버튼으로 데이터베이스에서 지웁니다(확인을 묻고, 되돌릴 수 없음).
- 연결이 설정되지 않았으면 두 명령 모두 설정의 데이터베이스 탭을 엽니다.

## 인쇄와 미리 보기

![인쇄 미리 보기](docs/guide/images/ko/20-print.png)

**파일 › 인쇄…**(`Ctrl+P`), 툴바의 인쇄 버튼, 시작 화면의 **인쇄** 타일은 **인쇄 미리 보기** 창을 엽니다. 시작 화면에서 누를 때 열린 계획이 없으면 먼저 인쇄할 계획 파일을 고르게 하고, 파일이 열리면 바로 이 창이 뜹니다. 설정을 바꾸면 오른쪽 미리 보기가 바로 바뀌고, 아래 화살표로 쪽을 넘깁니다.

| 탭 | 항목 |
|---|---|
| **인쇄 범위** | 전체 프로젝트 · 현재 보기 (필터 적용된 작업) · 사용자 지정(작업 ID 범위, 날짜 범위, 선택한 작업만), 인쇄할 내용(작업 수·쪽 수) |
| **페이지 설정** | 용지, 방향(세로·가로), 여백(좁게·보통·넓게), 배율(50~150%), 내용(표 + 간트 차트 · 표만 · 간트 차트만), 범례 |
| **머리글·바닥글** | 머리글·바닥글 켜기와 문구 |

**인쇄** 버튼은 운영체제의 인쇄 대화 상자를 엽니다(PDF로 저장도 여기서). 인쇄물은 테마와 상관없이 흰 바탕에 검은 글자로 나오고, 시간 눈금은 쪽 너비에 맞춰지며 행이 많으면 다음 쪽으로 이어집니다. 페이지 설정은 다음 인쇄 때도 유지됩니다.

## 꾸미기

### 테마

- 툴바의 **테마 무작위로 바꾸기** 버튼은 누를 때마다 다른 테마를 무작위로 고릅니다. 툴팁에 지금 테마 이름이 보입니다.
- 옆의 ▾(**테마 고르기**)는 **다크 (20)**와 **라이트 (20)**를 두 줄로 보여 주는 창을 엽니다. 위쪽에는 **시스템 설정**(운영체제의 밝기를 따름)과 **사용자 정의**가 있습니다.
- **설정 › 테마** 탭: 다크 20 · 라이트 20 · 사용자 정의 그룹. 사용자 정의에서는 바탕 · 표면 · 패널 · 글자 · 흐린 글자 · 테두리 · 강조 · 강조 위 글자 · 줄무늬 행 · 차트 바탕 · 툴바 · 상태 표시줄 색을 하나씩 고치고, **지금 테마의 색 가져오기**, **어두운 테마** 스위치가 있습니다. 글자 대비가 낮으면 "글자가 잘 안 보일 수 있습니다" 경고가 뜹니다.
- 테마는 시작 화면의 카드와 팝업 창에도 똑같이 적용됩니다. 시작 화면에는 테마를 고르는 카드가 따로 없습니다.

### 언어

툴바의 국기 버튼(**언어 전환**, `Ctrl+Shift+L`)이나 시작 화면의 **English** / **한국어** 타일로 한국어와 영어를 바꿉니다. 한국어일 때는 영국 국기, 영어일 때는 태극기가 보입니다(누르면 그 언어로 바뀜). **설정 › 일반 › 언어**에서도 바꿉니다. 메뉴, 팝업, 보고서, 오류 메시지까지 모두 바뀝니다. 이미 연 예제는 그대로이고, 언어를 바꾼 뒤 여는 예제는 새 언어로 열립니다.

### 글꼴

**설정 › 글꼴** 탭에서 시스템에 설치된 글꼴 중 하나를 고르고 **글자 크기**, **굵기**(가늘게 ~ 아주 굵게), **스타일**(보통·기울임), **행 높이**, **확대/축소**를 정합니다. 글꼴은 표와 차트에 적용되고 아래 미리 보기에 바로 보입니다.

### 배경과 움직이는 배경

**설정 › 배경** 탭:

| 항목 | 내용 |
|---|---|
| **배경 종류** | 움직이는 배경 · 이미지 · 없음 |
| **움직이는 배경** | 21가지 애니메이션 중 하나, **움직이는 배경 바꾸기**(`Ctrl+Shift+B`, 무작위) |
| **움직임 속도** | 0~300% |
| **시작할 때 배경 무작위** | 실행할 때마다 다른 배경 |
| **시작 페이지 배경 자동 변경** | 끄기 · 15초 · 30초 · 1분 · 2분 · 5분마다 |
| **움직이는 배경은 시작 페이지에서만** | 켜면 보기 뒤에서는 움직이지 않음 |
| **배경 이미지** | **고르기…** · **지우기**. 이미지 크기 제한은 없고, 이미지 파일을 창으로 끌어다 놓아도 배경이 됩니다 |
| **배경 불투명도 (보기 뒤)** | 보기 뒤 배경의 진하기 |
| **맞춤** | 채우기 · 맞추기 · 바둑판 · 가운데 · 늘이기 |

같은 조절 대부분이 시작 화면의 **움직이는 배경** 카드에도 있습니다. **보기 › 배경 끄기**는 배경 이미지를 지웁니다. 배경색은 테마를 따릅니다.

### 패널

![패널을 모두 접은 화면](docs/guide/images/ko/27-panels-folded.png)

- 도구 모음과 속성 패널은 머리글 끝의 접기 버튼(패널 가장자리에 겹화살표가 있는 아이콘), **보기 › 표시 › 도구 패널 펼치기/접기**(`Ctrl+Shift+1`) · **속성 패널 펼치기/접기**(`Ctrl+Shift+2`), 툴바의 패널 버튼으로 접고 펼칩니다.
- 접힌 패널은 폭 44픽셀의 좁은 세로 줄이 됩니다. 줄 맨 위에 패널의 아이콘과 짧은 이름(**도구** · **속성**)이 있고, 그 아래 **펼치기** 버튼으로 다시 엽니다. 그 밑에는 아이콘만 있는 버튼이 늘어서 있어 보기 전환(왼쪽)과 정보·프로젝트·달력·기준 계획·평준화 같은 주요 명령(오른쪽)을 접힌 채로 쓸 수 있습니다. 버튼 이름은 마우스를 올리면 툴팁으로 보입니다.
- 하단 패널은 머리글의 접기 버튼으로 접으면 한 줄만 남습니다([하단 패널: 일정 점검](#하단-패널-일정-점검) 참고). 그림은 세 패널을 모두 접은 모습입니다.
- 패널 사이 구분자를 끌어 너비를 바꾸고, 하단 패널은 위쪽 가장자리를 끌어 높이를 바꿉니다.

### 확대와 시간 눈금

- **확대/축소**(50~200%): `Ctrl+마우스 휠`, `Ctrl+=` · `Ctrl+-` · `Ctrl+0`, 툴바의 `[−] 100% [+]`(값을 직접 입력해도 됨).
- **시간 눈금**: 차트 위에서 `Ctrl+마우스 휠`, `Ctrl+Shift+=` · `Ctrl+Shift+-`, 툴바 버튼, 상태 표시줄 슬라이더. 일 · 주 · 월 · 분기 단위로 바뀝니다.
- **프로젝트 전체 보기**는 프로젝트가 차트 너비에 맞게 시간 눈금을 맞추고, **오늘로 이동**은 오늘 날짜로 스크롤합니다.
- 차트는 빈 곳을 끌거나 `Ctrl+끌기`로 이동합니다.

## 문제 해결

### 오류 창

오류가 나면 **오류** 창이 뜹니다. 메시지, **시각**, **위치**(무슨 작업 중이었는지), App(버전·플랫폼)과 **자세한 내용**이 있고, **내용 복사** 버튼으로 전부 복사해 문제를 알리거나 기록할 수 있습니다.

| 오류 제목 | 흔한 원인 |
|---|---|
| 파일을 열 수 없습니다 | MyWorkPlan 파일이 아님, 더 새 버전에서 만든 파일, MS Project XML이 아님, CSV에 작업이 없음 |
| 저장할 수 없습니다 · 내보낼 수 없습니다 | 쓰기 권한이 없는 폴더, 다른 프로그램이 파일을 잡고 있음 |
| 입력 오류 | 기간·날짜·선행 작업 형식이 틀림(메시지에 예가 나옴), 순환 연결 |
| 인쇄할 수 없습니다 | 프린터나 인쇄 대화 상자 문제 |
| 사용 설명서를 열 수 없습니다 | 설치 폴더의 `docs` 폴더가 지워짐 |

### 심각한 오류와 crash.log

프로그램 내부(백엔드)에서 심각한 오류가 나면 **심각한 오류 (백엔드)** 창에 위치·스레드·백트레이스와 **기록 파일** 경로가 표시됩니다. 같은 내용이 `crash.log`에 쌓입니다.

| OS | crash.log 위치 |
|---|---|
| Windows | `%APPDATA%\com.shkwon.myworkplan\crash.log` |
| macOS | `~/Library/Application Support/com.shkwon.myworkplan/crash.log` |
| Linux | `~/.local/share/com.shkwon.myworkplan/crash.log` |

### "이미 실행 중" 오류

MyWorkPlan은 사용자마다 하나만 실행됩니다. 이미 실행 중일 때 다시 실행하면 **MyWorkPlan — 실행 오류** 창에 "MyWorkPlan 이 이미 실행 중입니다."가 뜨고 새 실행은 끝납니다. 작업 표시줄(Dock)에서 열려 있는 창을 찾아 쓰세요. 이미 열린 창에서 **파일 › 열기…**로 다른 프로젝트를 탭으로 열 수 있습니다. 프로그램이 비정상 종료되었더라도 잠금은 운영체제가 풀어 주므로 다음 실행이 막히지 않습니다.

### 시작 화면 문제

| 증상 | 해결 |
|---|---|
| 카드 배치가 엉망이 됨 | 위쪽 도구 줄의 **자동 정렬**을 누릅니다 |
| 카드가 너무 작아 내용이 잘림 | 카드 오른쪽 아래 모서리를 두 번 클릭해 내용에 맞춥니다 |
| 최근 항목·예제·배경 카드가 없음 | **설정 › 시작 화면**에서 해당 항목을 켭니다 |
| 카드 글자가 배경 때문에 잘 안 보임 | **카드 불투명도**를 높이거나 **움직임 속도**를 낮춥니다 |
| 실행할 때 시작 화면이 안 보임 | **설정 › 일반** 또는 **설정 › 시작 화면**의 **시작할 때 시작 페이지 표시**를 켭니다. 언제든 **홈**(`Ctrl+Shift+H`)으로 열 수 있습니다 |
| 튜토리얼 영상이 재생되지 않음 | 영상 파일이 아직 없는 경우입니다. 소스 폴더에서 `npm run tutorial:video`로 만듭니다 |

### 그 밖에

| 증상 | 해결 |
|---|---|
| 일정이 이상하게 계산됨 | 표시기 열과 상태 표시줄의 충돌 개수를 확인하고, **제약 조건** 표로 제약을 살펴봅니다. 수동 일정 작업이 아닌지 확인합니다 |
| 작업이 안 보임 | 필터·검색·접힌 요약 작업을 확인하고 **필터·그룹·정렬 지우기**를 누릅니다 |
| 화면이 너무 크거나 작음 | `Ctrl+0`(100%로 보기) |
| 설정을 처음으로 | **설정 › 기본값으로** |
| 웹 버전에서 최근 파일이 안 열림 | 브라우저 보안 때문에 **열기**로 파일을 다시 골라야 할 수 있습니다 |

## 설치와 제거

### Windows

`MyWorkPlan-Setup-1.0.0.exe`를 실행합니다.

1. 설치 언어(한국어/English)를 고릅니다.
2. 이전에 설치한 MyWorkPlan의 **설정은 기본값으로 되돌리고, 사용자 데이터는 그대로 둡니다.** 설치 후 처음 실행할 때 테마·글꼴·확대/축소·패널·보기 옵션·창과 팝업 위치·열 너비·인쇄 선택이 처음 상태가 되고, 최근 파일·폴더, 열려 있던 계획 목록, 데이터베이스 연결, 배경 이미지, 튜토리얼 기록은 남습니다. 계획 파일(.mwp)은 손대지 않습니다.
3. 이전 설치가 있으면 완전히 제거한 뒤 새로 설치합니다.
4. 설치가 끝나면 `.mwp`(프로젝트)와 `.mwpt`(템플릿)가 각자의 문서 아이콘으로 등록되어 두 번 클릭으로 열립니다.
5. 시작 메뉴의 **MyWorkPlan** 폴더에 프로그램과 **MyWorkPlan User's Guide**(이 설명서) 바로 가기가 생깁니다. 설명서와 튜토리얼 문서는 설치 폴더의 `docs` 폴더에, 예제 프로젝트 40개(한국어·영어판)와 템플릿은 `samples` 폴더에 들어 있습니다.

현재 사용자용으로 설치되므로 관리자 권한이 필요 없습니다. 제거는 **설정 › 앱**(또는 제어판 › 프로그램 제거)에서 MyWorkPlan을 고릅니다.

| 데이터 | 위치 (Windows) |
|---|---|
| 설정(시작 화면 카드 배치 포함), 최근 파일·폴더 | `%LOCALAPPDATA%\com.shkwon.myworkplan` (WebView2 저장소) |
| 창 위치·크기, 배경 이미지, crash.log | `%APPDATA%\com.shkwon.myworkplan` |

### macOS

`MyWorkPlan-1.0.0-<arch>.dmg`를 열고 MyWorkPlan을 응용 프로그램 폴더로 끌어 놓습니다. 제거는 응용 프로그램 폴더에서 휴지통으로 옮깁니다. macOS 11 이상이 필요합니다.

### Linux

`.deb`(Debian·Ubuntu), `.rpm`(Fedora 등), `.AppImage` 중 하나를 씁니다. deb·rpm은 `.mwp` · `.mwpt` 파일 형식과 아이콘을 등록합니다. 제거는 패키지 관리자로 합니다.

### 웹 버전

웹 빌드(`dist/`)를 아무 정적 웹 서버에 올리면 브라우저에서 같은 기능을 씁니다. 차이점:

- 파일은 브라우저의 파일 선택 창으로 열고, 저장은 파일 시스템 접근을 지원하는 브라우저(Edge·Chrome)에서는 같은 파일에, 그 밖에는 내려받기로 합니다.
- 팝업 창은 페이지 안에 떠 있는 창으로 열립니다.
- 데이터베이스, 파일 형식 등록, "이미 실행 중" 검사처럼 운영체제 기능이 필요한 것은 데스크톱 앱에서만 됩니다. 시스템 글꼴 목록은 브라우저가 허락할 때만 읽습니다.
- 설정과 최근 기록은 브라우저 저장소에 남습니다.
