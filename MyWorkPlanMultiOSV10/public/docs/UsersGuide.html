MyWorkPlan 사용 설명서

MyWorkPlan은 Microsoft Project와 비슷한 방식으로 작업·일정·자원·비용을 계획하고 진행을 추적하는 프로그램입니다. Windows · macOS · Linux 데스크톱 앱과 웹 브라우저에서 같은 화면으로 동작합니다.

이 설명서는 하는 일 순서로 정리되어 있습니다. 화면의 메뉴·명령 이름은 프로그램에 표시되는 이름 그대로 적었습니다(예: 작업 › 작업 삽입은 "작업" 메뉴의 "작업 삽입" 명령). 그림은 튜토리얼 화면을 캡처한 것입니다.

English version: UsersGuide.en.md

시작하기 #

처음 실행 #

처음 실행하면 MyWorkPlan에 오신 것을 환영합니다 창이 뜹니다.

버튼하는 일
튜토리얼 시작예제 프로젝트로 모든 기능을 차례로 보여 주는 튜토리얼을 시작합니다
예제 열기"웹사이트 리뉴얼 (예제)" 프로젝트를 엽니다
나중에창을 닫습니다. 튜토리얼은 언제든 도움말 › 튜토리얼(F11)로 볼 수 있습니다

MyWorkPlan은 한 번에 하나만 실행됩니다. 이미 실행 중일 때 다시 실행하면 오류 창이 뜨고 새 실행은 끝납니다(문제 해결 참고).

시작 페이지 #

프로젝트를 열지 않았을 때(또는 메뉴 막대 맨 앞의 홈 버튼, Ctrl+Shift+H) 보이는 화면입니다. 뒤에서는 배경이 계속 움직입니다.

템플릿에는 단계(요약 작업), 작업, 연결, 마일스톤, 자원이 미리 들어 있습니다. 템플릿으로 만든 프로젝트는 처음 저장할 때 새 파일 이름을 묻습니다.

예제 프로젝트 #

예제 프로젝트의 "웹사이트 리뉴얼"을 열면 왼쪽에 작업 표, 오른쪽에 간트 차트가 보입니다. 검은 괄호 모양 막대는 요약 작업, 마름모는 마일스톤, 빨간 막대는 주 공정 작업입니다.

튜토리얼 #

도움말 › 튜토리얼(F11), 툴바의 학사모 버튼, 시작 페이지의 튜토리얼 시작으로 시작합니다. 예제 프로젝트를 띄워 놓고 64단계로 기능을 하나씩 보여 줍니다.

  • 다음 · 이전 단계 버튼, 자동 재생(▶)으로 넘깁니다.
  • 장 고르기 목록으로 시작 페이지 · 계획 만들기 · 일정 잡기 · 자원과 비용 · 진행 추적 · 보기 · 보고서 · 파일과 인쇄 · 꾸미기 · 도움말 중 원하는 장으로 갑니다.
  • 안내 상자는 끌어서 옮길 수 있습니다. Esc나 ✕로 끝냅니다.
  • 내 파일은 바뀌지 않고, 튜토리얼이 바꾼 설정(테마·언어·배경 등)은 끝날 때 원래대로 돌아갑니다.

튜토리얼 문서 — 튜토리얼의 모든 단계를 화면과 함께 정리한 문서는 프로그램 안에서 읽을 수 있습니다. 홈 화면의 도움말 › 튜토리얼 문서 또는 메뉴의 도움말 › 튜토리얼 문서로 열면 가운데에 문서가 나타나고, 위쪽 막대에서 장으로 이동 · 한국어/English 전환 · 튜토리얼 시작 · 브라우저로 열기를 할 수 있습니다. 홈 버튼으로 돌아갑니다.

화면 구성 #

위에서부터 메뉴 막대와 툴바(한 줄)가 있고, 바로 그 아래에 왼쪽 도구 모음 패널과 오른쪽 속성 패널이 있습니다. 두 패널 사이 가운데에는 위쪽에 프로젝트 탭, 그 아래에 보기가 있고, 맨 아래는 상태 표시줄입니다. 패널 사이의 구분자를 끌면 너비가 바뀌고, 창 오른쪽 아래 모서리를 끌면 창 크기가 바뀝니다. 창은 툴바 버튼이 가려지지 않는 폭보다 좁아지지 않습니다.

프로젝트 탭 #

프로젝트마다 탭이 하나씩 생깁니다. 탭이 많으면 양 끝의 화살표나 마우스 휠로 넘기고, Ctrl+Tab으로 다음 탭으로 갑니다. 탭 줄의 빈 곳을 두 번 클릭하면 새 프로젝트가 생깁니다. 저장하지 않은 변경이 있으면 메뉴 막대 오른쪽의 프로젝트 이름 뒤에 ●가 붙습니다.

작업 추가 #

  • 작업 › 작업 삽입(Insert)은 선택한 행 위에 새 작업을 넣고 이름을 바로 입력하게 합니다.
  • 표 맨 아래의 빈 행("여기에 새 작업 이름을 입력하세요")에 이름을 입력해도 작업이 생깁니다.
  • 요약 작업 삽입(Ctrl+Shift+K)은 선택한 작업들을 하위 작업으로 묶는 요약 작업을 만듭니다.
  • 셀은 두 번 클릭하거나 F2·Enter로 편집합니다. 편집 중 Enter는 아래 칸, Tab은 오른쪽 칸으로 넘어가고 Esc는 취소합니다.
  • 행 번호를 클릭해 선택하고(Ctrl+클릭: 여러 개, Shift+클릭: 범위), 행을 위아래로 끌어 옮깁니다. 좌우로 끌면 개요 수준이 바뀝니다.
  • 작업 › 삭제(Delete)는 선택한 작업과 그 하위 작업을 지웁니다. 삭제 전에 물어봅니다(설정 › 일반 › 삭제하기 전에 묻기).

기간이 0인 작업이 마일스톤(마름모)입니다. 작업 › 마일스톤 삽입(Ctrl+Shift+M)으로 넣거나, 기간에 0을 입력하거나, 작업 정보의 마일스톤으로 표시를 켭니다.

개요 (요약 작업) #

  • 들여쓰기 (하위 작업으로)(Alt+Shift+→)는 작업을 위 작업의 하위 작업으로 만듭니다. 위 작업은 요약 작업이 되어 하위 작업의 기간·작업량·비용·완료율을 합칩니다.
  • 내어쓰기(Alt+Shift+←)로 되돌립니다. 위로 이동 · 아래로 이동(Alt+Shift+↑/↓)은 하위 작업과 함께 옮깁니다.
  • 요약 작업 이름 앞의 삼각형으로 접고 펼칩니다. 보기 › 요약 작업만 보기 (모두 접기) · 모든 하위 작업 보기 (모두 펼치기)로 한 번에 할 수 있습니다.
  • WBS 코드(1, 1.1, 1.2 …)는 개요에 따라 자동으로 매겨집니다.

연결과 지연 #

  • 작업을 둘 이상 선택하고 작업 연결(Ctrl+F2)을 누르면 위에서 아래 순서로 완료-시작(FS)으로 이어집니다. 연결 끊기(Ctrl+Shift+F2)는 선택한 작업의 연결을 지웁니다.
  • 간트 막대를 위아래로 끌어 다른 막대 위에 놓아도 연결됩니다.
  • 선행 작업 칸에 직접 입력할 수 있습니다: 3, 5SS+2d, 7FF-1d, 4FS+50%처럼 작업 ID 뒤에 연결 유형과 지연을 붙이고 쉼표로 구분합니다.
  • 연결선을 두 번 클릭하면 작업 연결 창이 열리고, 오른쪽 클릭하면 유형을 바로 바꾸는 메뉴가 나옵니다.

연결 유형뜻
완료-시작 (FS)선행 작업이 끝나야 후속 작업이 시작 (기본)
시작-시작 (SS)선행 작업이 시작하면 후속 작업도 시작
완료-완료 (FF)선행 작업이 끝나야 후속 작업이 끝남
시작-완료 (SF)선행 작업이 시작해야 후속 작업이 끝남

지연은 2d(2일 뒤), -1d(1일 앞당김), 50%(선행 작업 기간의 절반)처럼 씁니다. 요약 작업에 건 연결은 그 안의 모든 작업에 적용됩니다. 순환이 생기는 연결이나 요약 작업과 그 하위 작업 사이의 연결은 만들지 않습니다.

실행 취소와 복사·붙여넣기 #

  • 모든 편집은 Ctrl+Z로 되돌리고 Ctrl+Y(또는 Ctrl+Shift+Z)로 다시 실행합니다. 탭(프로젝트)마다 기록이 따로 있습니다.
  • Ctrl+C · Ctrl+X · Ctrl+V로 작업(하위 작업·연결·할당 포함)이나 자원을 복사·이동합니다.
  • 엑셀이나 메모장에서 복사한 목록도 작업으로 붙여넣어집니다. 들여쓰기(공백 두 칸 또는 탭)는 개요 수준, 탭 뒤의 값은 기간이 됩니다. 반대로 복사한 작업은 엑셀에 이름·기간·시작·완료 열로 붙여넣어집니다.
  • 아래로 채우기(Ctrl+D): 여러 작업을 선택한 뒤 셀 하나를 고르면 첫 작업의 그 값이 아래 작업들에 복사됩니다.

자동 일정과 수동 일정 #

  • 자동 일정 작업은 연결·제약·달력에 따라 날짜가 계산됩니다.
  • 수동 일정 작업은 입력한 시작·완료 날짜에 그대로 머뭅니다(막대가 다른 모양으로 표시).

마감일 #

마감일은 작업을 옮기지는 않지만 늦은 날짜 계산에 들어가고, 작업이 마감일을 넘기면 표시기 열에 "마감일을 넘겼습니다" 경고가 뜹니다. 간트 차트에는 마감일 표시가 그려집니다.

달력과 작업 시간 #

  • 새 달력 · 이름 바꾸기 · 삭제 · 프로젝트 달력으로 버튼으로 달력을 관리합니다.
  • 작업 주 탭: 요일마다 작업하는 날 스위치와 작업 시간(예: 08:00-12:00, 13:00-17:00, 24시간제).

주 공정과 여유 시간 #

  • 주 공정 작업(빨간 막대)은 여유 시간이 없어서 늦어지면 프로젝트 완료가 늦어지는 작업입니다. 보기 › 주 공정(Critical Path) 표시로 켜고 끕니다.
  • 여유 시간 표시를 켜면 막대 뒤에 가는 선으로 자유 여유 시간(다른 작업을 늦추지 않고 미룰 수 있는 시간)이 보입니다.
  • 총 여유 시간 · 자유 여유 시간 · 빠른/늦은 시작·완료는 일정 표에서 볼 수 있습니다.
  • 프로젝트 정보 › 여유 시간이 이 일수 이하면 주 공정으로 기준을 넓힐 수 있습니다(기본 0일).

주 공정 찾기 버튼 — 툴바의 주 공정 찾기 버튼(Ctrl+Shift+P, 프로젝트 메뉴에도 있음)은 토글입니다. 누르면 일정을 앞에서 뒤로(가장 빠른 시작·완료) 그리고 뒤에서 앞으로(가장 늦은 시작·완료) 다시 계산하고, 여유 시간이 없는 작업을 시작에서 끝까지 이어지는 경로로 찾아 표시합니다. 주 공정 작업과 연결선은 빨갛게 강조되고 나머지는 흐려지며, 차트는 경로의 처음으로 이동합니다. 상태 표시줄에 주 공정 작업 수가, 알림에 경로(예: 12. 디자인 시스템 → … → 34. 프로젝트 종료)와 완료 날짜가 나옵니다. 다시 누르거나 상태 표시줄의 주 공정 항목을 누르면 꺼집니다.

자원과 비용 #

자원 시트 #

자원 › 자원 시트 보기에서 자원을 등록합니다. 맨 아래 빈 행에 이름을 입력하거나 자원 추가(Ctrl+Shift+R)를 누릅니다.

종류쓰임비용 계산
작업사람·장비. 최대 단위(100% = 한 사람 전일), 달력작업량(시간) × 표준 단가 + 사용당 비용
재료시멘트·종이처럼 수량으로 쓰는 것. 재료 단위(예: 톤)수량 × 표준 단가 + 사용당 비용
비용출장비·임대료처럼 금액만 있는 것할당할 때 입력한 금액

자원을 두 번 클릭하면 자원 정보 창(일반 · 비용 · 할당 · 메모 탭)이 열립니다. 초과 할당된 자원은 빨갛게 표시됩니다.

자원 할당 #

작업을 선택하고 자원 › 자원 할당…(Alt+F10)을 엽니다. 자원을 체크하고 단위(작업 자원은 %, 50% = 반나절)를 정하면 작업량과 비용이 계산됩니다. 아래 칸에 새 자원 이름을 쓰고 추가하고 할당을 누르면 자원을 만들면서 할당합니다.

자원 이름 칸에 직접 김철수, 이영희[50%]처럼 입력해도 됩니다. 없는 이름은 새 작업 자원으로 만들어집니다. 요약 작업에는 자원을 할당하지 않습니다.

비용 #

  • 작업 비용 = 할당된 자원의 비용 + 고정 비용. 요약 작업과 프로젝트는 하위 작업 비용을 합칩니다.
  • 비용 표에서 고정 비용, 비용, 기준 비용, 비용 차이, 실제 비용, 남은 비용을 봅니다. 실제 비용은 완료율만큼 계산됩니다.
  • 통화 기호는 프로젝트 정보 › 통화에서 고릅니다.

초과 할당 #

자원이 하루에 할 수 있는 양(최대 단위 × 그날 작업 시간)보다 많은 일이 겹치면 초과 할당입니다.

  • 자원 시트에서 빨간색, 작업의 표시기 열에 "자원이 초과 할당되었습니다" 아이콘이 붙습니다.
  • 자원 사용 보기에서 넘치는 날이 빨간 칸으로 보입니다.
  • 자원 그래프 보기는 한 자원의 날짜별 작업량을 막대로, 사용 가능한 양을 선으로 보여 줍니다(일 단위/주 단위).
  • 자원 › 다음 초과 할당은 초과 할당된 다음 작업으로 이동합니다.

자원 평준화 #

자원 › 모두 평준화는 초과 할당이 없어질 때까지 우선순위가 낮은 작업부터 뒤로 미룹니다. 미룬 양은 평준화 지연 필드에 들어가며 평준화 지우기로 원래대로 돌립니다(작업을 선택했으면 그 작업만).

자원 › 팀 플래너는 사람마다 한 줄에 작업 블록을 보여 줍니다. 블록을 다른 사람의 줄로 끌면 담당자가 바뀌고, 맨 아래 할당되지 않은 작업 줄에서 끌어오면 할당됩니다. 초과 할당된 줄은 빨갛게 표시됩니다.

진행 추적 #

기준 계획 #

계획을 확정하면 프로젝트 › 기준 계획 설정…으로 지금 일정(시작 · 완료 · 기간 · 작업량 · 비용)을 저장해 둡니다.

  • 기준 계획과 기준 계획 1~10, 모두 11개까지 저장합니다. 저장한 날짜가 목록에 표시됩니다.
  • 대상: 전체 프로젝트 또는 선택한 작업.
  • 기준 계획을 다시 저장할 때 이전 기준 계획을 기준 계획 1에 남기기로 이전 것을 보관할 수 있습니다.
  • 기준 계획 지우기…는 저장한 기준 계획을 지웁니다(일정은 바뀌지 않음).
  • 차이(시작 차이, 완료 차이, 기간·작업량·비용 차이)와 추적 간트의 회색 막대는 기준 계획(0번)과 비교합니다.

완료율 #

작업을 고르고 0% 완료 · 25% 완료 · 50% 완료 · 75% 완료 · 100% 완료를 누릅니다(작업 메뉴, 도구 모음의 진행 영역). 실제 시작·완료 날짜가 자동으로 기록되고 막대 안의 어두운 부분으로 진행률이 보입니다. 막대의 진행 손잡이를 끌거나 속성 패널의 슬라이더로도 바꿉니다.

예정대로 진행으로 표시는 선택한 작업을 상태 날짜까지 일정대로 진행한 것으로 표시합니다.

작업 업데이트 #

상태 날짜 #

상태 날짜는 진행 상황을 판단하는 기준일입니다(늦은 작업, 진행선, 보고서, 프로젝트 업데이트). 프로젝트 › 상태 날짜…(프로젝트 정보의 상태 탭)에서 정합니다. 정하지 않으면 오늘을 씁니다. 상태 날짜까지 끝났어야 하는데 덜 된 작업은 늦은 작업이 되어 표시기 열에 "늦어지고 있습니다"가 붙습니다.

추적 간트와 진행선 #

추적 간트 보기는 위에 현재 일정 막대, 아래에 기준 계획 회색 막대를 그립니다. 보기 › 진행선 표시를 켜면 상태 날짜에서 각 작업이 어디까지 진행했는지 이은 선이 보입니다. 선이 왼쪽으로 꺾이면 늦은 작업입니다. 간트 차트에서도 기준 계획 막대 표시를 켜면 기준 계획이 보입니다.

보기 #

툴바의 보기 버튼(지금 보기 이름 ▾), 왼쪽 도구 모음, 보기 메뉴에서 12가지 보기로 바꿉니다. 보기는 탭마다 따로 기억되고, 새 프로젝트의 처음 보기는 설정 › 일반 › 새 프로젝트의 기본 보기에서 정합니다.

간트 차트 #

왼쪽은 작업 표, 오른쪽은 간트 차트입니다. 가운데 구분자로 너비를 나눕니다. 차트에는 2단 시간 눈금, 쉬는 날 음영, 오늘 선, 상태 날짜 선, 연결 화살표, 마감일, 기준 계획 막대, 여유 시간 선이 그려집니다. 막대 옆 글자는 설정 › 간트 차트 › 막대 옆 글자(이름 · 자원 · 완료율 · 없음)로 고릅니다. 그림은 예제 프로젝트를 보세요.

작업 사용 #

작업마다 할당된 자원을 아래에 펼치고, 오른쪽에 날짜별 작업 시간을 보여 줍니다. 시간 눈금을 확대/축소하면 일·주·월 단위로 바뀝니다.

네트워크 다이어그램 #

작업을 상자(ID, 이름, 날짜, 기간, 자원)로, 연결을 화살표로 그립니다. 빨간 상자는 주 공정, X 표시는 완료, 사선은 진행 중입니다. 끌어서 이동하고 Ctrl+휠로 확대/축소하며, 상자를 두 번 클릭하면 작업 정보가 열립니다.

일정표 #

달력에 작업이 걸쳐 있는 날을 막대로 보여 줍니다. 이전 달 · 다음 달 · 이번 달 · 프로젝트 시작 달 버튼이나 마우스 휠로 달을 넘깁니다. 한 주에 다 들어가지 않으면 "+N"으로 표시됩니다.

시간 표시 막대 #

"이미 실행 중" 오류 #

MyWorkPlan은 사용자마다 하나만 실행됩니다. 이미 실행 중일 때 다시 실행하면 MyWorkPlan — 실행 오류 창에 "MyWorkPlan 이 이미 실행 중입니다."가 뜨고 새 실행은 끝납니다. 작업 표시줄(Dock)에서 열려 있는 창을 찾아 쓰세요. 이미 열린 창에서 파일 › 열기…로 다른 프로젝트를 탭으로 열 수 있습니다. 프로그램이 비정상 종료되었더라도 잠금은 운영체제가 풀어 주므로 다음 실행이 막히지 않습니다.

설치와 제거 #

Windows #

MyWorkPlan-Setup-1.0.0.exe를 실행합니다.

  1. 설치 언어(한국어/English)를 고릅니다.
  2. 이전에 설치한 MyWorkPlan이 저장한 데이터(설정, 최근 파일·폴더, 배경 이미지)가 있으면 지울지 묻습니다. 아니요를 고르면 그대로 씁니다.
  3. 이전 설치가 있으면 완전히 제거한 뒤 새로 설치합니다.
  4. 설치가 끝나면 .mwp(프로젝트)와 .mwpt(템플릿)가 각자의 문서 아이콘으로 등록되어 두 번 클릭으로 열립니다.
  5. 시작 메뉴의 MyWorkPlan 폴더에 프로그램과 MyWorkPlan User's Guide(이 설명서) 바로 가기가 생깁니다. 설명서와 튜토리얼 문서, 예제 프로젝트는 설치 폴더의 docs, samples 폴더에 들어 있습니다.

현재 사용자용으로 설치되므로 관리자 권한이 필요 없습니다. 제거는 설정 › 앱(또는 제어판 › 프로그램 제거)에서 MyWorkPlan을 고릅니다.

창 위치·크기, 배경 이미지, crash.log%APPDATA%\com.shkwon.myworkplan

macOS #

MyWorkPlan-1.0.0-<arch>.dmg를 열고 MyWorkPlan을 응용 프로그램 폴더로 끌어 놓습니다. 제거는 응용 프로그램 폴더에서 휴지통으로 옮깁니다. macOS 11 이상이 필요합니다.

Linux #

.deb(Debian·Ubuntu), .rpm(Fedora 등), .AppImage 중 하나를 씁니다. deb·rpm은 .mwp · .mwpt 파일 형식과 아이콘을 등록합니다. 제거는 패키지 관리자로 합니다.

웹 버전 #

웹 빌드(dist/)를 아무 정적 웹 서버에 올리면 브라우저에서 같은 기능을 씁니다. 차이점:

  • 파일은 브라우저의 파일 선택 창으로 열고, 저장은 파일 시스템 접근을 지원하는 브라우저(Edge·Chrome)에서는 같은 파일에, 그 밖에는 내려받기로 합니다.
  • 팝업 창은 페이지 안에 떠 있는 창으로 열립니다.
  • 파일 형식 등록, "이미 실행 중" 검사처럼 운영체제 기능이 필요한 것은 데스크톱 앱에서만 됩니다. 시스템 글꼴 목록은 브라우저가 허락할 때만 읽습니다.
  • 설정과 최근 기록은 브라우저 저장소에 남습니다.
