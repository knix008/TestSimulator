# 한국어 OCR — 사용자 가이드

이 문서는 **OCRWinV10** 프로그램을 처음 사용하는 분을 위한 안내입니다. 개발·빌드 정보는 [README.md](README.md)를 참고하세요.

---

## 1. 프로그램 소개

한국어 OCR은 Windows용 **한글·영문 OCR** 프로그램입니다.

- 인쇄 문서, 스캔 이미지, PDF, 손글씨 사진 등에서 텍스트를 추출합니다.
- 여러 OCR 엔진 중에서 상황에 맞게 선택할 수 있습니다.
- 인식 결과는 화면에서 확인하고, 파일로 저장하거나 클립보드에 복사할 수 있습니다.

---

## 2. 설치 및 실행

### MSI로 설치한 경우

1. `OCRWinV10Setup.msi`를 실행합니다.
2. 안내에 따라 설치합니다. 기본 설치 경로: `C:\Program Files\한국어 OCR\`
3. **시작 메뉴** 또는 **바탕화면**의 「한국어 OCR」 바로가기로 실행합니다.

### 개발 빌드로 실행한 경우

- `OCRWinV10.exe`를 직접 실행합니다. (.NET 10 런타임 필요)

### 시스템 요구사항

| 항목 | 내용 |
|------|------|
| OS | Windows 10 (17763) 이상 / Windows 11 |
| 권장 | PaddleOCR 사용 시 **인터넷 불필요** (모델 내장) |
| Windows OCR | 설정 → 시간 및 언어 → **한국어 언어팩** 설치 권장 |

## 3. 화면 구성

```
┌─────────────────────────────────────────────────────────────┐
│  메뉴: 파일 | 도움말                                          │
├─────────────────────────────────────────────────────────────┤
│  도구 모음: 열기 | ◀ ▶ | OCR 실행 | 엔진 | 전처리 | ...       │
├──────────────────────────┬──────────────────────────────────┤
│  원본 이미지              │  인식 결과 (박스)                 │
│                          │                                  │
├──────────────────────────┴──────────────────────────────────┤
│  텍스트 결과 (인식된 글)                                      │
│  [복사] [텍스트 저장] [박스 이미지] [모두 저장] [지우기]        │
├─────────────────────────────────────────────────────────────┤
│  상태: 진행 메시지 (진행률 %)     [████████░░]  언어·엔진 정보 │
└─────────────────────────────────────────────────────────────┘
```

| 영역 | 설명 |
|------|------|
| **원본 이미지** | 열어 둔 파일의 현재 페이지 |
| **인식 결과 (박스)** | 글자 위치를 파란 박스로 표시한 이미지 |
| **텍스트 결과** | 추출된 문자열 (편집·복사 가능) |
| **하단 버튼** | 복사, 저장, 결과 지우기 |
| **상태 표시줄** | 작업 상태, **OCR 진행률(%)**, 진행 바 |

## 4. 기본 사용 순서

### ① 파일 열기

- 도구 모음 **열기** 클릭, 또는 **Ctrl+O**
- 탐색기에서 이미지/PDF 선택
- 또는 프로그램 창에 파일을 **끌어다 놓기**

**지원 형식 예:** JPG, PNG, BMP, TIFF, GIF, WebP, AVIF, HEIC, PDF 등

PDF는 **페이지별**로 이미지가 로드됩니다. **◀ / ▶** 버튼으로 페이지를 바꿉니다.

### ② OCR 엔진 선택

도구 모음 **OCR 엔진** 콤보에서 선택합니다.

| 엔진 | 권장 용도 | 최초 실행 |
|------|-----------|-----------|
| **PaddleOCR (한·영, 권장)** | 일반 한글·영문 문서, 손글씨 | 모델 내장, 바로 사용 |
| EasyOCR (한·영) | 혼합 문서·손글씨 대안 | 약 100MB 다운로드 |
| Windows OCR | 간단한 인쇄체 | OS 내장 |
| Tesseract | 오프라인·다국어 | 한국어 데이터 다운로드 |

엔진 옆에 **(미설치)** 가 보이면, OCR 실행 시 설치 창이 뜹니다. 완료될 때까지 기다려 주세요.

### ③ 전처리 모드 선택

| 모드 | 설명 |
|------|------|
| **자동** | 일반 인쇄·스캔 문서 (기본) |
| **손글씨** | 필기체·낮은 대비 — 3종 전처리 후 최적 결과 선택 |
| **없음** | 원본 그대로 인식 |

### ④ OCR 실행

- **OCR 실행** 버튼 또는 **F5**
- 상태 표시줄에 단계와 **진행률(%)** 이 표시됩니다.
- 실행 중 **취소** 버튼으로 중단할 수 있습니다.

### ⑤ 결과 활용

텍스트 패널 **아래 버튼**:

| 버튼 | 기능 | 단축키 (파일 메뉴) |
|------|------|-------------------|
| **복사** | 전체 텍스트를 클립보드에 복사 | — |
| **텍스트 저장** | UTF-8 텍스트 파일(.txt) | Ctrl+S |
| **박스 이미지** | 박스가 그려진 이미지 저장 | Ctrl+Shift+S |
| **모두 저장** | 텍스트 + 박스 이미지 한 번에 | Ctrl+Shift+A |
| **지우기** | 텍스트·박스 결과만 지움 | — |

- 박스 이미지는 **원본과 같은 확장자**로 저장됩니다 (PDF 원본은 PNG).
- 결과가 없으면 저장·복사 버튼은 비활성화됩니다.

## 5. 설정 자동 저장

프로그램을 **종료할 때** 아래 항목이 자동 저장되며, 다음 실행 시 복원됩니다.

- 선택한 OCR 엔진
- 전처리 모드
- 창 크기·위치
- 패널 분할 위치
- 마지막으로 파일을 연 폴더

저장 위치: `%AppData%\OCRWinV10\settings.json`

## 6. OCR 엔진별 안내

### PaddleOCR (권장)

- 한국어 V5 인식 모델이 **설치 폴더에 포함**되어 있습니다.
- 별도 다운로드 없이 오프라인에서 사용할 수 있습니다.
- 한글·숫자·영문이 섞인 문서와 손글씨에 강합니다.

### EasyOCR

- 첫 사용 시 인터넷으로 모델을 받습니다 (~100MB).
- 방화벽·회사망에서 실패하면 PaddleOCR을 사용하세요.

### Windows OCR

- Windows에 내장된 OCR을 사용합니다.
- **한국어 언어팩**이 없으면 인식 품질이 떨어질 수 있습니다.

### Tesseract

- 첫 사용 시 한국어·영어 학습 데이터를 다운로드합니다.
- 설치가 끝나면 오프라인 사용 가능합니다.

## 7. 자주 묻는 질문 (FAQ)

### PaddleOCR을 사용할 수 없다고 나옵니다

1. **최신 버전**으로 다시 설치했는지 확인합니다 (모델이 앱에 포함된 빌드).
2. 설치 팝업에서 **다운로드·초기화가 100%** 될 때까지 기다립니다.
3. 그래도 실패하면 **EasyOCR** 또는 **Windows OCR**로 시도합니다.
4. 수동 설치: 아래 폴더에 `inference.json`, `inference.pdiparams`, `inference.yml` 세 파일이 있는지 확인합니다.  
   `%LocalAppData%\OCRWinV10\engines\paddle\korean_PP-OCRv5_mobile_rec\`

### 인식이 부정확합니다

- **자동** → 인쇄 문서, **손글씨** → 필기·메모 사진
- 해상도가 낮으면 원본을 더 크게 스캔하거나 촬영합니다.
- 엔진을 **PaddleOCR** 또는 **EasyOCR**로 바꿔 비교해 봅니다.

### PDF 여러 페이지

- **◀ / ▶** 로 페이지를 이동한 뒤, **각 페이지마다 F5**로 OCR을 실행합니다.

### HEIC / WebP 사진

- 열기는 지원됩니다. 박스 이미지 저장 시 일부 형식은 **PNG**로 저장될 수 있습니다.

### 프로그램을 제거하려면

- **설정 → 앱 → 설치된 앱**에서 「한국어 OCR」을 선택 후 제거합니다.
