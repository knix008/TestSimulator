# CaptureMaster 사용 설명서

## 1. 화면 구성

```
┌ 타이틀 바 ──────────────────────────────────────────────────────────────┐
│ ◉ CaptureMaster v1.0.0 — ● Screen 2026-09-14 12-00-07        ─  □  ✕ │
├ 툴바 1행 ───────────────────────────────────────────────────────────────┤
│ 화면 창 영역 녹화 │ 열기 URL 최근 저장 다른이름 내보내기 인쇄 │ 실행취소 다시실행 복사 붙여넣기 │ 확대 축소 맞춤 100% │
│                                                     … 투명도 0 ━━━● 100 100% │ 🏳(국기)  ⚙ 설정  ⓘ 정보 │
├ 툴바 2행 ───────────────────────────────────────────────────────────────┤
│ 선택 펜 사각형 타원 화살표 직선 텍스트 형광펜 모자이크 번호 자르기 │ 🎨■ ╱[4] A[24] 채우기 │ 삭제 자르기 적용 │
├ 탭 ─────────────────────────────────────────────────────────────────────┤
│ [Screen 2026-09-14 … ● ✕] [Region … ✕] [Recording … ✕]                  │
├ 편집 영역 ───────────────────────────────────────────────────────────────┤
│                        (캡처 이미지 + 주석 / 동영상 플레이어)              │
├ 상태 바 ─────────────────────────────────────────────────────────────────┤
│ 준비 │ 3440 × 1440 px │ 주석 3개 │ 선택 700 × 500 │ X 802 Y 602 │ 도구: 선택 │ 50% │ 수정됨 │ 문서 2개 │ 테마 ◢ │
└─────────────────────────────────────────────────────────────────────────┘
```

- **타이틀 바**: 프로그램 이름, 버전, 현재 문서 이름(수정되면 ● 표시). 더블클릭으로 최대화/복원.
- **툴바**: 버튼은 모두 아이콘으로만 표시되며, 마우스를 올리면 툴팁(설명 + 단축키)이 나타납니다. 창은 툴바가 잘리지 않는 폭보다 작아지지 않습니다.
- **상태 바**: 이미지 크기, 주석 수, 선택 영역, 커서 위치(이미지 픽셀), 현재 도구, 확대율, 저장 상태, 열린 문서 수, 테마. 오른쪽 끝의 크기 변경 마커(◢)를 드래그하면 창 크기를 바꿀 수 있습니다.
- 창은 항상 **최소 크기**(툴바의 모든 버튼이 보이는 폭)로 시작하며, 마지막 위치만 기억합니다. 캡처한 이미지는 그 창 안에 맞춰(창에 맞춤) 표시됩니다.
- 문서가 없을 때는 시작 화면에 여섯 가지 시작 버튼과 단축키 안내가 보입니다. 파일을 창 위에 끌어다 놓아도 열립니다.

## 2. 캡처

| 방법 | 버튼 / 단축키 | 동작 |
|---|---|---|
| 전체 화면 | 화면 · `Ctrl+N` | 모니터가 하나면 즉시, 여러 개면 모니터 선택 창이 뜹니다. 모니터의 실제 픽셀 해상도로 캡처됩니다. |
| 창 | 창 · `Ctrl+Shift+W` | 열려 있는 창 목록(썸네일)에서 고릅니다. 창의 실제 크기로 캡처됩니다. |
| 영역 | 영역 · `Ctrl+Shift+R` | 마우스가 있는 모니터가 얼어붙은 화면으로 덮이고, 드래그로 영역을 고른 뒤 **Enter**(또는 더블클릭, 캡처 버튼)로 확정합니다. `Esc`/우클릭은 취소, `Ctrl+A` 는 전체. |

설정 → 캡처 에서 **지연 시간**(초, 카운트다운 표시), **캡처할 때 CaptureMaster 창 숨기기**, **캡처 후 클립보드에도 복사** 를 정할 수 있습니다.
캡처가 끝나면 새 탭이 열리고 오른쪽 아래에 "캡처 완료 (W × H)" 알림이 잠깐 표시됩니다.

## 3. 동영상 녹화

1. 녹화 버튼(`Ctrl+Shift+V`)을 누릅니다. 모니터가 여러 개면 녹화할 모니터를 고릅니다.
2. 항상 위에 뜨는 작은 **녹화 컨트롤 창**(경과 시간, 일시정지/계속, 중지, 취소)이 화면 오른쪽 위에 나타나고, 설정에 따라 메인 창은 최소화됩니다. 상태 바에도 빨간 점과 경과 시간이 표시됩니다.
3. **중지**(또는 `Ctrl+Shift+V`)를 누르면 파일이 마무리되고 새 탭에서 바로 재생할 수 있습니다. **취소**는 파일을 지웁니다.

녹화 중에는 데이터가 1초 단위로 디스크에 바로 기록되므로 긴 녹화도 메모리를 차지하지 않습니다.

설정 → 녹화: 형식(자동/WebM VP9/VP8/MP4 — 시스템이 지원하는 것만 표시), fps(15/24/30/60), 비트레이트, 시스템 소리(Windows), 마이크, 녹화 중 창 최소화, 저장 위치 묻기, 녹화 저장 폴더(비우면 내 비디오 폴더).

## 4. 주석 편집

| 도구 | 키 | 사용법 |
|---|---|---|
| 선택 | `V` | 주석 클릭 → 이동, 모서리/끝점 핸들로 크기 조절, 빈 곳 드래그 → 영역 선택(자르기·인쇄·복사에 사용) |
| 펜 | `P` | 자유 곡선 |
| 사각형 / 타원 | `R` / `O` | 드래그. `Shift` 로 정사각형/정원. **채우기** 를 켜면 반투명하게 채움 |
| 화살표 / 직선 | `A` / `L` | 드래그. `Shift` 로 45° 단위 |
| 텍스트 | `T` | 클릭 → 입력. `Ctrl+Enter` 확정, `Esc` 취소, `Enter` 줄바꿈. 기존 텍스트는 더블클릭으로 편집 |
| 형광펜 | `H` | 반투명 강조 영역 |
| 모자이크 | `M` | 영역을 픽셀화(원본은 보존되며 언제든 지울 수 있음) |
| 번호 | `N` | 클릭한 곳에 1, 2, 3 … 배지 |
| 자르기 | `C` | 영역 드래그 후 `Enter`(또는 "자르기 적용") |

- 색상·선 굵기·글자 크기는 툴바 2행에서 바꾸며, 새 주석의 기본값으로 저장됩니다.
- 선택한 주석: `Delete` 삭제, 방향키로 1px(Shift: 10px) 이동, `Ctrl+D` 복제, 우클릭 메뉴에서 맨 앞/맨 뒤로.
- `Ctrl+Z` / `Ctrl+Y`(또는 `Ctrl+Shift+Z`) 로 100단계까지 되돌리기/다시 실행.
- 확대/축소: `Ctrl+마우스 휠`(커서 기준), `Ctrl+=` / `Ctrl+-`, `Ctrl+0` 창에 맞춤, `Ctrl+1` 실제 크기.

## 5. 복사 · 붙여넣기

- `Ctrl+C`: 주석이 선택되어 있으면 그 주석을, 영역이 선택되어 있으면 그 영역의 이미지를, 아니면 전체 합성 이미지를 클립보드에 복사합니다. 다른 프로그램(워드, 메신저 등)에 바로 붙여 넣을 수 있습니다.
- `Ctrl+X`: 선택한 주석을 잘라냅니다.
- `Ctrl+V`: 클립보드에 이미지가 있으면 새 문서로 열고, 복사해 둔 주석이 있으면 현재 문서에 붙여 넣습니다.
- 우클릭 메뉴에 "이미지 복사", "선택 영역 이미지 복사", "선택 영역으로 자르기" 가 있습니다.

## 6. 파일

| 동작 | 단축키 | 설명 |
|---|---|---|
| 열기 | `Ctrl+O` | `.cmcap`, 이미지(PNG/JPG/GIF/WebP/BMP), 동영상(WebM/MP4/MKV). 여러 파일 동시 선택 가능 |
| URL 열기 | `Ctrl+L` | 웹 주소의 이미지를 내려받아 엽니다(진행률 표시) |
| 최근 파일 | 툴바 ▾ | 최근 10개. 항목의 ✕ 로 하나씩, "최근 파일 모두 지우기" 로 전체 삭제. 설정 → 파일에서도 관리 |
| 저장 / 다른 이름으로 | `Ctrl+S` / `Ctrl+Shift+S` | 캡처를 `.cmcap`(이미지 + 주석, 언제든 다시 편집 가능)로 저장. 탐색기에서 `.cmcap` 을 더블클릭하면 CaptureMaster 로 열립니다 |
| 내보내기 | `Ctrl+E` | 주석이 합성된 PNG / JPEG / WebP / BMP. 저장 대화상자에서 고른 확장자가 형식을 결정합니다 |
| 인쇄 | `Ctrl+P` | 아래 7절 |

마지막으로 연/저장한/내보낸 폴더는 각각 기억되어 다음 대화상자의 시작 위치가 됩니다.
탭을 닫거나(`Ctrl+W`) 프로그램을 종료할 때 저장하지 않은 변경이 있으면 **저장 / 저장 안 함 / 취소** 를 묻습니다.

## 7. 인쇄

인쇄 창에서 범위를 고릅니다.

- **모든 문서** — 열린 탭을 한 장씩
- **현재 문서**
- **사용자 지정** — 목록에서 문서를 체크. 현재 문서에 선택 영역이 있으면 "선택 영역만" 도 선택 가능

용지 방향(가로/세로, 이미지 비율에 따라 자동 제안)과 "페이지에 맞추기" 를 정한 뒤 **인쇄…** 를 누르면 시스템 인쇄 대화상자가 열립니다. 동영상 문서는 현재 프레임이 인쇄됩니다.

## 8. 설정 (`Ctrl+,`)

| 페이지 | 항목 |
|---|---|
| 일반 | 언어(한국어/English), 창 투명도, 투명 배경 체크무늬 |
| 모양 | 테마 16종(미드나이트, 데이라이트, 그라파이트, 오션, 포레스트, 선셋, 고대비, 노르드, 드라큘라, 솔라라이즈드 다크/라이트, 모노카이, 로즈, 라벤더, 민트, 커피), UI 글꼴(시스템에 설치된 모든 글꼴) · 크기 · 굵게 · 기울임 |
| 캡처 | 지연 시간, 창 숨기기, 카운트다운, 클립보드 복사, 내보내기 기본 형식과 품질 |
| 녹화 | 형식, fps, 비트레이트, 시스템 소리, 마이크, 창 최소화, 저장 위치 묻기, 저장 폴더 |
| 주석 기본값 | 색상, 선 굵기, 채우기, 텍스트 글꼴·크기·굵게·기울임 |
| 파일 · 최근 목록 | 최근 파일 개별/전체 삭제, 기억된 폴더 지우기 |

모든 변경은 즉시 적용되고 자동 저장되어 다음 실행 때 복원됩니다. "모든 설정 초기화" 는 기본값으로 되돌립니다.
툴바의 언어 버튼(바꿀 언어의 국기: 🇬🇧 / 🇰🇷)으로 한국어 ↔ English 를 바로 바꿀 수 있고, 투명도 슬라이더(0~100)는 툴바에서 직접 조절합니다(창이 완전히 사라지지 않도록 실제 투명도는 15% 아래로 내려가지 않습니다).

## 9. 오류가 났을 때

오류가 발생하면 별도의 창에 **무엇을 하다가**(예: 파일 열기 실패), **무슨 오류인지**, 그리고 기술적인 상세 내용(스택, 버전, 플랫폼)이 표시됩니다.
**오류 내용 복사** 버튼을 누르면 전체 내용이 클립보드에 들어가므로 메일이나 메신저에 붙여 넣어 전달할 수 있습니다. 상세 내용 영역은 마우스로 드래그해 일부만 복사할 수도 있습니다.

## 11. 플랫폼별 참고

- **Windows**: 설치 프로그램이 이전 버전을 완전히 제거한 뒤 설치하며, 남아 있는 데이터 삭제 여부를 묻습니다. 시스템 소리 녹음은 Windows 에서만 지원됩니다.
- **macOS**: 처음 캡처/녹화할 때 "화면 기록" 권한을 요청합니다. 시스템 설정 → 개인 정보 보호 및 보안 → 화면 기록에서 CaptureMaster 를 허용하세요. 마이크도 같은 방식입니다.
- **Ubuntu (Wayland)**: 캡처/녹화 때 GNOME 의 화면 공유 대화상자가 뜹니다. 공유할 화면을 고르고 허용하면 그 화면이 캡처됩니다. X11 세션에서는 대화상자 없이 바로 캡처됩니다.
- **macOS / Linux 재설치**: 새 버전을 처음 실행할 때 이전 설정을 유지할지 삭제할지 묻습니다.
