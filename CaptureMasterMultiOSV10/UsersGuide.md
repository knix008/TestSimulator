# CaptureMaster 사용 설명서

## 1. 화면 구성

```
┌ 타이틀 바 ──────────────────────────────────────────────────────────────┐
│ ◉ CaptureMaster v1.0.0 — ● Screen 2026-09-14 12-00-07        ─  □  ✕ │
├ 툴바 ───────────────────────────────────────────────────────────────────┤
│ 화면 창 영역 녹화 │ 열기 URL 최근 저장 다른이름 내보내기 인쇄 │ ↶ 실행취소 ↷ 다시실행 │ 잘라내기 복사 붙여넣기 │ 확대 [100%] 축소 맞춤 실제크기 │
│                                                     … 투명도 0 ━━━● 100 100% │ 🎨 테마 ▾  ◐ 다음 테마  🏳(국기)  ⚙ 설정  ⓘ 정보 │
```

- **타이틀 바**: 프로그램 이름, 버전, 현재 문서 이름(수정되면 ● 표시). 더블클릭으로 최대화/복원.
- **툴바**: 버튼은 모두 아이콘으로만 표시되며, 마우스를 올리면 툴팁(설명 + 단축키)이 나타납니다. 창은 툴바 한 줄이 잘리지 않는 폭, 그리고 좌우 패널(도구 모음 · 캡처 기록)과 최소 480px의 편집 영역이 함께 들어가는 폭 중 큰 값보다 작아지지 않습니다. 패널을 넓히면 최소 폭도 함께 늘고, 접으면 줄어듭니다. 패널 경계를 드래그해도 편집 영역이 480px보다 좁아지지는 않으므로 창이 저절로 커지지 않습니다.
- **도구 모음**(왼쪽 패널): 선택 · 펜 · 사각형 등 편집 도구가 이름과 단축키와 함께 세로로 놓입니다. 위쪽의 ‹ 단추나 `Ctrl+B` 로 접고 펼치며, 접으면 아이콘만 있는 얇은 띠가 남아 그대로 도구를 고를 수 있습니다. 오른쪽 경계를 드래그해 폭을 바꿀 수 있고(캡처 기록과 같은 최소 210px(스크롤 바 폭 포함) · 최대 480px). 접힘과 폭은 바로 저장되고, 다음 실행에서 창이 나타나기 전에 그대로 적용됩니다. 아래쪽 **선택** 구역에는 선택 영역 모양(사각형 · 둥근 사각형 · 원형), 모두 선택, 자르기 적용, 삭제, 선택 해제가 있고, 맨 아래 **속성** 구역에서 새 주석의 색상 · 선 굵기 · 글자 크기 · 채우기를 정합니다(접은 띠에는 색상과 채우기만 표시됩니다). 이미지 문서일 때만 쓸 수 있습니다.
- **상태 바**: 이미지 크기, 주석 수, 선택 영역, 커서 위치(이미지 픽셀), 현재 도구, 확대율, 저장 상태, 열린 문서 수, 테마. 오른쪽 끝의 크기 변경 마커(◢)를 드래그하면 창 크기를 바꿀 수 있습니다.
- 창을 닫을 때의 **크기 · 위치 · 최대화**와 좌우 패널의 접힘을 기억하고, 다음 실행에서 그 상태 그대로 열립니다. 처음 실행할 때는 툴바가 한 줄로 들어가는 최소 폭과, 왼쪽 도구 모음이 보이는 높이로 시작합니다. 그 최소 폭보다 좁아지지는 않습니다. 높이를 줄이면 도구 모음 목록에 세로 스크롤 바가 생깁니다(접은 띠는 마우스 휠로 스크롤). 캡처한 이미지는 그 창 안에 맞춰(창에 맞춤) 표시됩니다.
- 문서가 없을 때는 시작 화면에 여섯 가지 시작 버튼과 단축키 안내가 보입니다. 파일을 창 위에 끌어다 놓아도 열립니다.

## 2. 캡처

| 방법 | 버튼 / 단축키 | 동작 |
|---|---|---|
| 전체 화면 | 화면 · `Ctrl+N` | 모니터가 하나면 즉시, 여러 개면 모니터 선택 창이 뜹니다. 모니터의 실제 픽셀 해상도로 캡처됩니다. |
| 창 | 창 · `Ctrl+Shift+W` | 열려 있는 창 목록(썸네일)에서 고릅니다. 창의 실제 크기로 캡처됩니다. |
| 영역 | 영역 · `Ctrl+Shift+R` | 마우스가 있는 모니터가 얼어붙은 화면으로 덮이고, 드래그로 영역을 고른 뒤 **Enter**(또는 더블클릭, 캡처 버튼)로 확정합니다. `Esc`/우클릭은 취소, `Ctrl+A` 는 전체. |

설정 → 캡처 에서 **지연 시간**(초, 카운트다운 표시), **캡처할 때 CaptureMaster 창 숨기기**, **캡처 후 클립보드에도 복사** 를 정할 수 있습니다.
캡처가 끝나면 새 탭이 열리고, 캡처는 **캡처 저장 폴더**(설정 → 일반, 비워 두면 `내 사진\CaptureMaster`)에 설정한 이미지 형식으로 자동 저장됩니다. 오른쪽 아래에 "캡처를 저장했습니다: 파일 이름 (W × H)" 알림이 잠깐 표시됩니다. 주석을 단 뒤 `Ctrl+S` 로 저장하면 주석을 다시 편집할 수 있는 `.cmcap` 파일이 따로 만들어집니다.

### 캡처 기록

창 오른쪽의 **캡처 기록** 패널에 캡처와 녹화가 날짜별(오늘 · 어제 · 날짜)로 최신순으로 쌓입니다. 각 항목에는 썸네일, 이름, 시각, 크기, 파일 용량이 표시됩니다.

- **열기**: 항목을 클릭합니다. 이미 탭으로 열려 있으면 그 탭으로 전환하고, 아니면 저장된 파일을 엽니다. 현재 탭에 해당하는 항목은 강조 표시됩니다.
- **폴더에서 보기**: 항목 위에 마우스를 올리면 나타나는 📁 단추. 탐색기가 열리고 그 파일이 선택됩니다.
- **기록에서 제거**: 같은 자리의 ✕ 단추. 목록에서만 빠지고 **파일은 삭제되지 않습니다.**
- **기록 모두 지우기**: 패널 위쪽의 🗑 단추. 확인 후 목록을 비웁니다. 파일은 그대로 남습니다.
- **캡처 폴더 열기**: 패널 위쪽의 📁 단추.
- 항목을 우클릭하면 열기 · 폴더에서 보기 · 경로 복사 · 캡처 폴더 열기 · 제거 · 모두 지우기 · 캡처 기록 접기 메뉴가 나옵니다.
- 파일을 옮기거나 지운 항목은 줄이 그어지고 "파일을 찾을 수 없음" 으로 표시됩니다.
- 패널 위쪽의 › 단추나 `Ctrl+H` 로 접고 펼칩니다. 접으면 오른쪽 끝에 얇은 띠만 남습니다. 패널 왼쪽 경계를 드래그하면 폭을 바꿀 수 있습니다. 접힘과 폭은 바로 저장되고, 다음 실행에서 창이 나타나기 전에 그대로 적용됩니다.

## 3. 동영상 녹화

1. 녹화 버튼(`Ctrl+Shift+V`)을 누르고, **화면** 탭에서 모니터를 고르거나 **창** 탭에서 녹화할 창을 고릅니다.
   창을 녹화하면 그 창의 내용만 녹화되며, 다른 창에 가려져 있어도 녹화됩니다. 창 크기를 바꾸면 처음 크기 안에 맞춰 녹화되고, 창이 닫히면 녹화가 자동으로 끝납니다.
   **소리**: 설정 → 녹화의 **시스템 소리**를 켜면 컴퓨터에서 나는 소리(스피커 출력)가, **마이크**를 켜면 마이크 입력이 함께 녹음되며, 둘 다 켜면 하나로 섞입니다. 화면 녹화와 창 녹화 모두 해당합니다(창 녹화의 시스템 소리는 그 창만이 아니라 컴퓨터 전체의 소리입니다). 장치를 쓸 수 없으면 알림을 띄우고 그 소리 없이 녹화합니다. GIF 는 소리 없이 녹화됩니다.
2. 항상 위에 뜨는 작은 **녹화 컨트롤 창**(경과 시간, 일시정지/계속, 중지, 취소)이 화면 오른쪽 위에 나타나고, 설정에 따라 메인 창은 최소화됩니다. 상태 바에도 빨간 점과 경과 시간이 표시됩니다.
3. **중지**(또는 `Ctrl+Shift+V`)를 누르면 파일이 마무리되고 새 탭에서 바로 재생할 수 있습니다. **취소**는 파일을 지웁니다.

**재생.** 녹화한(또는 열어 본) 동영상 아래 가운데에 재생 컨트롤이 있습니다: 재생 위치 막대와 경과/전체 시간, 처음으로 · 5초 뒤로 · 재생/일시 정지 · 5초 앞으로 · 끝으로, 왼쪽에 음소거와 음량, 오른쪽에 재생 속도(0.25×–2×) · 반복 재생 · 전체 화면. 화면을 클릭하면 재생/일시 정지, 더블클릭하면 전체 화면입니다.

| 키 | 동작 |
|---|---|
| `Space` / `K` | 재생 · 일시 정지 |
| `←` / `→` | 5초 뒤로 / 앞으로 (`J` / `L` 은 10초) |
| `↑` / `↓` | 음량 |
| `Home` / `End` | 처음 / 끝 |
| `,` / `.` | 일시 정지 중 한 프레임 뒤로 / 앞으로 |
| `M` · `F` | 음소거 · 전체 화면 |

녹화 중에는 데이터가 1초 단위로 디스크에 바로 기록되므로 긴 녹화도 메모리를 차지하지 않습니다.

설정 → 녹화: 형식(자동/WebM VP9/VP8/MP4 — 시스템이 지원하는 것만 표시), fps(15/24/30/60), 비트레이트, 시스템 소리(Windows), 녹화 중 창 최소화, 저장 위치 묻기, 녹화 저장 폴더(비우면 내 비디오 폴더).

설정 → 녹화 → **시스템 소리**:
- **녹화할 때 시스템 소리 녹음**: 켜야 컴퓨터 소리가 녹화에 들어갑니다.
- **녹음 음량**: 0–300%(100% = 들리는 그대로). 녹화 파일에 들어가는 크기만 바꾸며 스피커나 Windows 음량은 그대로입니다. 마이크 음량과 따로 정하므로 둘의 크기 균형을 맞출 수 있습니다.
- **시스템 소리 테스트**: 음악이나 영상을 틀어 두고 **테스트**를 누르면 녹음될 크기가 막대로 표시됩니다.

설정 → 녹화 → **마이크**:
- **녹화할 때 마이크 녹음**: 켜야 녹화에 마이크가 들어갑니다.
- **입력 장치**: 시스템 기본 장치 또는 특정 마이크. 고른 마이크가 빠져 있으면 "(연결되지 않음)" 으로 표시되고 기본 장치로 녹음합니다. ⟳ 단추로 목록을 새로 고칩니다(장치를 꽂거나 빼면 자동으로 갱신).
- **입력 음량**: 0–300%(100% = 원래 크기). 녹음에 그대로 적용됩니다.
- **에코 제거 · 잡음 억제 · 자동 음량 조절**: 마이크 소리 처리. 시스템 소리를 함께 녹음할 때는 에코 제거를 켜 두면 스피커 소리가 마이크로 다시 들어가는 것이 줄어듭니다.
- **마이크 테스트**: **테스트**를 누르면 위 설정이 적용된 입력 크기가 막대로 표시됩니다(흰 선은 최근 최대치). 막대가 빨간 끝까지 차면 음량을 내리세요. 테스트는 중지를 누르거나 설정 창을 닫으면 끝납니다.

## 4. 주석 편집

| 도구 | 키 | 사용법 |
|---|---|---|
| 선택 | `V` | 주석 클릭 → 이동, 모서리/끝점 핸들로 크기 조절, 빈 곳 드래그 → 영역 선택(자르기·인쇄·복사에 사용) |
| 펜 | `P` | 자유 곡선 |
| 사각형 / 타원 | `R` / `O` | 드래그. `Shift` 로 정사각형/정원. **채우기** 를 켜면 반투명하게 채움 |
| 화살표 / 직선 | `A` / `L` | 드래그. `Shift` 로 45° 단위 |
| 텍스트 | `T` | 클릭 → 입력. `Ctrl+Enter` 확정, `Esc` 취소, `Enter` 줄바꿈. 기존 텍스트는 더블클릭으로 편집 |
| 형광펜 | `H` | 반투명 강조 영역 |
| 모자이크 | `M` | 영역을 픽셀화(원본은 보존되며 언제든 지울 수 있음) |
| 번호 | `N` | 클릭한 곳에 1, 2, 3 … 배지 |
| 자르기 | `C` | 영역 드래그 후 `Enter`(또는 도구 모음의 "자르기 적용") |

- 색상·선 굵기·글자 크기·채우기는 도구 모음 패널의 "속성" 구역에서 바꾸며, 새 주석의 기본값으로 저장됩니다.
- 선택한 주석: `Delete` 삭제, 방향키로 1px(Shift: 10px) 이동, `Ctrl+D` 복제, 우클릭 메뉴에서 맨 앞/맨 뒤로.
- `Ctrl+Z` / `Ctrl+Y`(또는 `Ctrl+Shift+Z`) 로 100단계까지 되돌리기/다시 실행.
- 확대/축소: 툴바의 확대 · 축소 · 창에 맞춤 · 실제 크기 단추, `Ctrl+마우스 휠`(커서 기준), `Ctrl+=` / `Ctrl+-`, `Ctrl+0` 창에 맞춤, `Ctrl+1` 실제 크기. 확대 · 축소 단추 사이에 현재 배율이 가운데 정렬로 표시됩니다. 그 배율(예: 50%)을 누르면 25%–800% 중에서 고를 수 있습니다(10%–800% 범위). 확대한 그림은 **마우스 가운데 단추로 드래그**해 움직입니다. 창에 맞춤 상태에서는 창 크기를 바꾸면 이미지도 함께 커지거나 작아지며, 손으로 배율을 바꾸면 그 배율이 유지됩니다.

## 5. 선택 · 잘라내기 · 복사 · 붙여넣기

- 선택 도구(`V`)로 빈 곳을 드래그하면 영역이 선택됩니다. `Ctrl+A` 는 이미지 전체를 선택합니다.
- **선택 영역 모양**: 도구 모음 패널 "선택" 구역의 세 단추(또는 이미지 우클릭 메뉴)에서 **사각형 · 둥근 사각형 · 원형** 중에 고릅니다. 드래그할 때 `Shift` 를 누르면 정사각형/정원이 됩니다. 선택이 있는 상태에서 모양을 바꾸면 그 선택도 바로 바뀌고, 고른 모양은 기억됩니다. 복사 · 잘라내기 · 지우기 · 자르기는 그 모양대로 동작합니다(원형으로 자르면 바깥 모서리는 투명해집니다). 인쇄의 "선택 영역만" 은 모양을 둘러싼 사각형으로 인쇄합니다.
- `Ctrl+C`: 주석이 선택되어 있으면 그 주석을, 영역이 선택되어 있으면 그 영역의 이미지를, 아니면 전체 합성 이미지를 클립보드에 복사합니다. 어느 경우든 그림으로 들어가므로 다른 프로그램(워드, 그림판, 메신저 등)에 바로 붙여 넣을 수 있습니다.
- `Ctrl+X`: 선택한 주석을 잘라냅니다. 주석 없이 영역만 선택되어 있으면 그 영역을 클립보드에 넣고 투명하게 비웁니다(영역 안에 완전히 들어 있던 주석도 함께 잘립니다).
- `Delete`: 선택한 주석을 지우고, 주석 없이 영역만 선택되어 있으면 그 영역을 투명하게 지웁니다.
- `Ctrl+V`: 현재 이미지 위에 붙여 넣습니다. 다른 프로그램에서 복사한 그림은 이동·크기 조절이 되는 그림 개체로(모서리 핸들은 비율 유지), 텍스트는 텍스트 주석으로 들어갑니다. 이 프로그램에서 복사한 주석은 편집 가능한 주석 그대로 붙습니다. 영역이 선택되어 있으면 그 위치에, 아니면 가운데에 놓입니다.
- `Ctrl+Alt+V`: 클립보드의 그림을 새 문서로 엽니다. 열린 문서가 없을 때는 `Ctrl+V` 도 같습니다.
- 우클릭 메뉴와 툴바에도 잘라내기·복사·붙여넣기가 있습니다.

자동 저장된 캡처도 "파일 위치 열기" 로 저장된 파일을 바로 찾을 수 있습니다.

탭을 닫거나(`Ctrl+W`) 프로그램을 종료할 때 저장하지 않은 변경이 있으면 **저장 / 저장 안 함 / 취소** 를 묻습니다.

## 7. 인쇄

인쇄 창의 왼쪽은 페이지 설정, 오른쪽은 실제로 인쇄될 페이지의 미리보기입니다. 설정을 바꾸면 미리보기가 바로 바뀌고, 아래의 ‹ › 단추로 쪽을 넘겨 볼 수 있습니다.

- **출력** — 프린터(기본 프린터가 먼저 선택됨, "PDF로 저장" 포함), 매수, 컬러/흑백, 단면/양면(긴 쪽·짧은 쪽 넘김)
- **문서** — 모든 문서(탭마다 한 쪽) · 현재 문서 · 사용자 지정(목록에서 체크). 현재 문서에 선택 영역이 있으면 "선택 영역만" 도 선택 가능
- **용지** — 용지 크기(A4·A3·A5·B4·B5·Letter·Legal), 방향(자동은 이미지 비율을 따름), 배치(용지에 맞춤 · 용지 채우기 · 실제 크기 · 배율 지정), 여백, 머리글(문서 이름과 쪽 번호)

**인쇄** 를 누르면 시스템 인쇄 대화상자 없이 선택한 프린터로 바로 인쇄됩니다. "PDF로 저장" 을 고르면 단추가 **저장** 으로 바뀌고, 저장 위치를 묻은 뒤 미리보기와 같은 PDF 를 만듭니다. 설정은 다음에 인쇄 창을 열 때도 유지됩니다. 동영상 문서는 현재 프레임이 인쇄됩니다. 직접 인쇄를 지원하지 않는 환경(웹 버전 등)에서는 같은 페이지로 시스템 인쇄 대화상자가 열립니다.

## 9. 오류가 났을 때

오류가 발생하면 별도의 창에 **무엇을 하다가**(예: 파일 열기 실패), **무슨 오류인지**, 그리고 기술적인 상세 내용(스택, 버전, 플랫폼)이 표시됩니다.
**오류 내용 복사** 버튼을 누르면 전체 내용이 클립보드에 들어가므로 메일이나 메신저에 붙여 넣어 전달할 수 있습니다. 상세 내용 영역은 마우스로 드래그해 일부만 복사할 수도 있습니다.

## 11. 플랫폼별 참고

- **Windows**: 설치 프로그램이 이전 버전을 완전히 제거한 뒤 설치하며, 남아 있는 데이터 삭제 여부를 묻습니다. 시스템 소리 녹음은 Windows 에서만 지원됩니다.
- **macOS**: 처음 캡처/녹화할 때 "화면 기록" 권한을 요청합니다. 시스템 설정 → 개인 정보 보호 및 보안 → 화면 기록에서 CaptureMaster 를 허용하세요. 마이크도 같은 방식입니다.
- **Ubuntu (Wayland)**: 캡처/녹화 때 GNOME 의 화면 공유 대화상자가 뜹니다. 공유할 화면을 고르고 허용하면 그 화면이 캡처됩니다. X11 세션에서는 대화상자 없이 바로 캡처됩니다.
- **macOS / Linux 재설치**: 새 버전을 처음 실행할 때 이전 설정을 유지할지 삭제할지 묻습니다.
