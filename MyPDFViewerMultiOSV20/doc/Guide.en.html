MyPDFViewer Program Guide

Read PDFs, highlight them and save the highlights into the PDF, and take out their text and pictures — Windows · macOS · Linux · web browser

1. Introduction

MyPDFViewer opens PDFs quickly, lets you highlight passages and save the highlights into the PDF itself, and copies text and pictures out of a document. Every document you open is collected in the gallery; the ones you love go into your library, shown like books on shelves.

  • A document always opens fitted to the window; the toolbar switches to actual size, fit width or fit height.
  • Highlights are standard PDF annotations, so other PDF readers show them too.
  • Pick the printer, copies and orientation and press [Print] — no second system print window.
  • The start screen has 21 moving 3D backgrounds with adjustable opacity and speed.

2. Start screen

The start screen appears when the program starts; the Home button at the left of the toolbar brings it back at any time. It uses the whole window, left panel included.

  • Title card — name and version, [Program guide] (opens this guide in a new window) and [Open the library].
  • Get started — Open, Open URL, Gallery, and your recently opened files with an ✕ to forget each.
  • My library — your library on a shelf; a book opens its document.
  • Start-screen background — choose and tune the moving background (below).
  • Untick Show this screen at startup to start with an empty window.

Start-screen background

Books · Pages · Stars · Letters · Planes · Tunnel · Waves · Galaxy · Cubes · Helix · Knot · Sphere · Bubbles · Snow · Fireflies · Starmap · Aurora · Hexes · Orbits · Hills · Ink — 21 3D scenes about reading, books and paper. Hover a button for a description.

  • Random background picks any other one.
  • Opacity 10 %–100 %, motion speed 10 %–300 %.
  • Change automatically every 15 s to 5 min, in order or in random order.

The same controls are in Settings → Start screen. Colours follow the current theme.

3. Opening documents

  • Open (Ctrl+O) a PDF or a .pdfvw workspace; several files open as tabs.
  • Open URL downloads a PDF from the internet.
  • Drag and drop PDFs from your file manager onto the window.
  • The folder panel starts in the folder you last opened a file from, or your home folder if that is gone.

5. Copying text and pictures

  • Text tool (Ctrl+1) — drag to select, Ctrl+C.
  • Image tool (Ctrl+2) — click a picture, then copy or save it at full resolution.
  • Region tool (Ctrl+3) — drag a rectangle and keep it as a picture (PNG · JPEG · WebP · GIF · BMP).

6. Highlights

  1. Select text with the text tool — several lines are fine.
  2. Choose Highlight from the copy menu or the right-click menu. The whole selection becomes one highlight.
  3. Save with Ctrl+S; the highlight goes into the PDF as a standard annotation.

7. Saving

  • Save PDF (Ctrl+S) writes highlights, comments, bookmarks and attachments into the open PDF.
  • Save PDF As keeps the original and writes a copy (name-annotated.pdf).
  • Save workspace keeps the PDF path, page, highlights, bookmarks and clips in a .pdfvw.

8. Gallery

Open it with the Gallery button. Every PDF you open is added by itself, shown with its first page and name. It uses the whole window.

9. Library

Add to library (☆ on a gallery card, or the right-click menu) and open it large with the Library button. The library uses the whole window; the toolbar Sidebar and Document info buttons (F9 · F8) open the side panels beside it.

  • Four views — shelves, covers, list, details; one size slider scales them all, down to very small.
  • Titles stay on one line (shortened with …) so the books stand level.
  • ✕ takes a book off the shelves; Clear all empties the library. Files and gallery cards stay.

11. Right-click menus

Pages, every left-panel entry and every gallery or library card have a menu, each item with an icon: copy, highlight, add to gallery or library, show in folder, copy path, delete and more.

12. Printing

  • All · current page · custom range (1-5, 8, 11-13).
  • Pick the printer, copies and orientation and press [Print] — it prints at once. The printer and orientation are remembered.
  • Use [System print dialog…] for paper, duplex and other settings.

15. Installing and your data

  • Build the Windows installer with npm run build:win (build:mac, build:linux).
  • Settings, recent files, the gallery and the library live in %APPDATA%\MyPDFViewer\settings.json.
