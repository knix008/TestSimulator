# MyPDFViewer

PDF를 읽고, **형광펜을 칠해 PDF에 저장**하고, 그 안의 **텍스트와 이미지를 손쉽게 복사**할 수 있는 다중 플랫폼 뷰어입니다.
하나의 코드베이스로 **웹 브라우저 · Windows · macOS · Linux** 에서 동작하며,
데스크톱 앱은 **Tauri 2**(Rust + 운영체제 웹뷰)로 만들어 각 플랫폼용 설치 파일을 만들 수 있습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| PDF 보기 | 연속 스크롤 / 한 쪽씩 보기, 자유 확대(25 %–800 %), **Ctrl+휠 확대**(보던 위치 유지), 90° 회전. 확대하면 스크롤바가 자동으로 나타납니다 |
| 보기 맞춤 | 문서를 열면 항상 **화면 맞춤**(쪽 전체가 창 안에)으로 보여 줍니다. 툴바의 보기 버튼 네 개 — **화면 맞춤 · 원본 크기 · 폭 맞춤 · 높이 맞춤** — 로 바로 바꿉니다 (오른쪽 클릭 메뉴에도 있음) |
| 문서 탭 | 여러 PDF를 **탭**으로 동시에 엽니다. 탭은 툴바 아래·문서 위에만 있고 좌측 패널 위로는 올라가지 않습니다. 탭이 많으면 오른쪽 `<` `>` 로 숨은 탭을 옮깁니다 (Ctrl+Tab / Ctrl+W) |
| 텍스트 복사 | 마우스로 끌어 선택, 페이지 전체 선택(Ctrl+A), 클립보드 복사(Ctrl+C), 문서 전체 텍스트를 `.txt` 로 내보내기 |
| 영역 캡처 | 페이지의 **아무 곳이나 사각형으로 끌어** 이미지로 잘라내 복사하거나 저장 (그림이 아닌 표·수식·본문도 가능) |
| 저장 형식 | **PNG · JPEG · WebP · GIF · BMP** — 미리보기와 예상 파일 크기를 보며 고르고, JPEG·WebP는 품질 조절 |
| 이미지 복사 | 그림을 클릭해 **선택**하고, 오른쪽 클릭 메뉴에서 원본 해상도로 복사·저장·클립 보관. 페이지의 이미지 일괄 추출도 가능 |
| 선택 도구 | 툴바에서 **텍스트(Ctrl+1) · 이미지(Ctrl+2) · 영역(Ctrl+3) · 읽기(Ctrl+4)** 네 가지를 분명히 구분해 고릅니다 — 각각 I 빔 · 손가락 · 십자 · 화살표(확대 시 손) 포인터 |
| 인쇄 | **전체 · 현재 페이지 · 사용자 지정 범위**(`1-5, 8, 11-13`), **프린터 · 매수 · 용지 방향**을 인쇄 창에서 고르고 [인쇄] 를 누르면 **바로 인쇄** — 시스템 인쇄 창이 다시 뜨지 않습니다 (Ctrl+P). 세부 설정이 필요하면 [시스템 인쇄 창…] |
| 찾기 | 문서 전체 검색, 결과 목록에서 해당 쪽으로 이동하고 **페이지 위에 검색어를 강조** |
| 주석 | 형광펜, 코멘트, 책갈피, **파일 첨부**, 복사한 텍스트·이미지 클립. PDF에 있던 주석도 읽습니다 |
| 실행 취소 / 다시 실행 | 형광펜·코멘트·책갈피·첨부·클립 등 모든 편집을 최대 100단계까지 (Ctrl+Z / Ctrl+Y) |
| 형광펜 | 글자를 끌어 선택한 뒤 복사 메뉴나 오른쪽 클릭 메뉴의 **형광펜**. 저장하면 PDF의 표준 형광펜 주석(Highlight)으로 들어가 **다시 열 때도, 다른 PDF 프로그램에서도** 그대로 보입니다 |
| PDF로 저장 | **Ctrl+S** — 형광펜·주석·책갈피·첨부를 **열린 PDF 파일에 바로** 씁니다 (변경 내용 저장). 다른 파일로 남기려면 **PDF 다른 이름으로 저장** — 기본 제안은 `문서이름-annotated.pdf` 입니다 |
| 작업 파일 | `.pdfvw` 형식으로도 저장 가능 — 원본 PDF 경로, 마지막 쪽, 형광펜·책갈피·클립·첨부를 그대로 복원 |
| 시작 화면 | 프로그램을 켜면 좌측 패널까지 덮는 **시작 화면** — 열기 · URL · 열어 본 파일, **최근 연 파일**(✕ 로 지우기), **내 서재** 책장, **프로그램 설명** 버튼. 배경은 **움직이는 3D 장면 21가지**(책 구름 · 낱장 · 별빛 · 은하 · 오로라 · 잉크 …)를 아이콘 버튼으로 고르고 **투명도 · 움직임 속도 · 자동 변경 간격 · 무작위 순서**를 조절합니다 (설정 → 시작 화면에도 같은 조절). 툴바 맨 왼쪽 **홈** 버튼으로 언제든 다시 엽니다 |
| 도움말 | 툴바 **도움말**(?) 버튼, **F1**, 시작 화면 **프로그램 설명** — 그림이 들어 있는 상세 설명서([doc/Guide.html](doc/Guide.html), 영어 [doc/Guide.en.html](doc/Guide.en.html))를 **새 창**으로 엽니다 |
| 열어 본 파일 | 툴바 **열어 본 파일** 버튼 — 열어 본 PDF가 **저절로 쌓여** 첫 쪽 그림과 이름으로 모입니다. **타일 보기**(크기 조절 슬라이더) · **자세히 보기**(이름 · 폴더 · 크기 · 날짜, 머리글로 정렬), 찾기, **서재에 추가 ☆**, ✕ 로 목록에서 빼기(파일은 지우지 않음). 파일을 열어야만 들어오고, 따로 추가하는 메뉴는 없습니다 |
| 서재 | 툴바 **서재** 버튼 — 서재에 넣은 문서를 **창 전체**에 크게 봅니다 — 처음엔 패널 없이, **사이드바 · 문서 정보** 버튼(F9 · F8)으로 좌우 패널을 옆에 열 수 있습니다. **책장 · 표지 · 목록 · 자세히** 네 가지 보기, 크기 슬라이더(60~360px), 정렬 · 찾기, ✕ 로 하나 빼기 · **전체 삭제**. 제목은 한 줄(…)이라 책이 고르게 섭니다. 좌측 패널 **서재** 탭에서도 열기 · 개별 · 전체 삭제 |
| 형광펜 목록 | 좌측 패널 **형광펜** 탭 — 문서의 형광펜(저장 전 · PDF에 저장됨)을 목록으로 보고 눌러서 그 자리로 이동, **개별 삭제 · 모두 지우기** (확인 창 없이 즉시) |
| 기록 | 좌측 패널 **기록** 탭 — **최근 연 파일**(그림과 이름)과 편집 기록. 항목마다 ✕ 와 **전체 삭제** (확인 창 없이 즉시) |
| 사이드바 | **폴더 트리**(데스크톱 — **마지막으로 연 폴더**에서 시작하고, 그 폴더가 없으면 홈 폴더) · 축소판 · 접히는 **목차 트리** · 찾기 · 이미지 · 책갈피 · **주석** · **형광펜** · 클립 · **서재** · **기록**. 모든 항목에 아이콘이 붙은 **오른쪽 클릭 메뉴**가 있습니다. 제목은 굵게 보이고, 패널 동작(폴더 열기 · 모두 펼치기/접기 · 추출 · 주석 추가)은 제목 오른쪽 **아이콘**입니다. **구분선을 끌어 너비를 조절**합니다 (기본 220px) |
| 테마 | **40가지** 테마(어두운 20 · 밝은 20). 버튼을 누르면 다음 테마로 바뀌고, 오른쪽 화살표로 목록에서 고릅니다 (목록에 스크롤바 없음, 창 밖으로 펼쳐질 수 있음) |
| 언어 | 한국어 · English. 툴바 국기는 **지금 쓸 언어**를 보여 줍니다 (한글 UI → 영국 국기, 영어 UI → 태극기). 누르면 그 언어로 바뀝니다 |
| 글꼴 | 시스템에 설치된 **모든 글꼴**, 크기(10–24px), 굵게 · 기울임 · 밑줄 |
| 최근 파일 | 최대 10개, 개별 삭제 · 전체 삭제, 최근 폴더 기억 |
| 타이틀 바 | 프로그램 이름과 버전, 현재 문서 이름, 변경 표시 |
| 상태 바 | 진행 상태 · 파일 · 폴더 · 쪽 번호 · 배율 · 크기 · 선택 글자 수 · 편집 기록 · 저장 여부 |
| 진행 표시 | 열기 · 저장 · 다운로드 · 이미지 추출 등 오래 걸리는 작업의 진행률 팝업 |
| 오류 처리 | 무슨 작업 중이었는지 + 구체적 오류 + 기술 상세(스택)를 팝업으로 표시하고 **한 번에 복사** |
| 설정 유지 | 테마 · 언어 · 글꼴 · 보기 방식 · 최근 파일 · 마지막 폴더를 다음 실행 때 그대로 복원 |
| 컨텍스트 메뉴 | 페이지 위에서 오른쪽 클릭 — 복사 · 형광펜 · 도구 전환 · **서재에 추가 / 빼기** · 이동 · 확대 · 보기 맞춤 · 회전. 좌측 패널과 [열어 본 파일] · 서재 카드에도 각자의 메뉴가 있고, 모든 항목에 아이콘이 있습니다 |

### 파일 형식 등록

설치 프로그램이 다음을 시스템에 등록합니다.

* `.pdfvw` — MyPDFViewer 작업 파일. **전용 아이콘**을 가지며 두 번 클릭하면 원본 PDF와 작업 내용이 함께 열립니다.
* `.pdf` — 항상 **[연결 프로그램]** 목록에 추가됩니다. 설치 화면의
  **[PDF 파일의 기본 뷰어로 설정]** 을 선택하면 기본 뷰어로도 등록됩니다 (선택하지 않으면 기존 기본 프로그램을 그대로 둡니다).
  Windows 8 이후로는 기본 앱을 설치 프로그램이 마음대로 바꿀 수 없어, 이미 다른 PDF 프로그램이
  기본으로 지정되어 있으면 Windows **[기본 앱]** 설정 창이 열리고 마지막 확인만 사용자가 누르면 됩니다.

아이콘은 모두 `assets/icon.svg`(프로그램)와 `assets/file-icon.svg`(문서)에서 생성되며,
테두리가 투명한 3D 형태에 좌측 상단이 빛나는 형태입니다. 설치 파일도 같은 아이콘을 사용합니다.

## 실행

```bash
npm install          # 의존성 설치 (pdf.js 런타임 파일과 빌드 정보도 함께 준비됩니다)
                     #   생략해도 됩니다 — 아래 명령들은 node_modules/ 가 없거나
                     #   빠진 패키지가 있으면 npm install 을 자동으로 먼저 실행합니다

npm start            # 데스크톱(Tauri) 개발 실행 — tauri dev: Vite 개발 서버 + Rust 호스트
                     # (이전 개발 서버가 포트를 잡고 있으면 자동으로 정리하고 시작합니다)
npm run web          # 웹 브라우저용 개발 서버 (http://localhost:5179)
npm test             # 전체 테스트 = test:js + test:rust
npm run test:js      # 화면·라이브러리·계약 테스트 (Vitest). 항목마다 통과/실패를 색으로 나열합니다
npm run test:rust    # Rust 호스트 테스트 (cargo test — 폴더 목록, 인자 해석, 다운로드 이름 …)
npm run test:watch   # 파일 변경 때마다 Vitest 를 다시 실행합니다
```

데스크톱 앱을 만들려면 [Rust](https://rustup.rs) 와 Tauri 의 운영체제별 준비물
(Windows: WebView2 · MSVC 빌드 도구, Linux: webkit2gtk-4.1)이 필요합니다.

## 설치 파일 만들기

```bash
npm run build:win    # Windows  → MyPDFViewer_1.0.0_x64-setup.exe (NSIS)
npm run build:mac    # macOS    → *.dmg
npm run build:linux  # Linux    → *.AppImage, *.deb
npm run build:all    # 이 컴퓨터에서 만들 수 있는 모든 형식
npm run build        # 웹 배포용 정적 파일 → dist/
```

`tauri build` 의 결과(`src-tauri/target/release/bundle/`)는 빌드가 끝나면 프로젝트 최상위로 복사됩니다.
Windows 설치 프로그램은 설치 경로 선택, 바탕화면 · 시작 메뉴 바로 가기와 PDF 기본 뷰어 선택(한국어/영어)을 제공합니다.
예전 **Electron 판**이 설치되어 있으면 먼저 조용히 지우고, 남아 있는 설정·최근 파일을 지울지 물어봅니다
(설정 파일은 두 판이 같은 `%APPDATA%\MyPDFViewer\settings.json` 을 씁니다).

빌드에 필요한 패키지가 설치되어 있지 않으면 `npm install` 을 먼저 실행한 뒤 이어서 빌드합니다.

## 빌드 결과 지우기

```bash
npm run clean        # 빌드로 생긴 것을 모두 삭제
                     #   dist/ · src-tauri/target/ · src-tauri/gen/ · public/pdfjs/ ·
                     #   src/build-info.json · 최상위로 복사된 설치 파일 · 캐시
npm run clean:all    # 위의 모든 것 + node_modules/ (완전 초기화)
npm run clean:dry    # clean:all 기준으로 목록만 표시 (지우지 않음)
                     #   npm run clean -- --dry-run 은 clean 기준
```

지워지는 것은 모두 `.gitignore` 된 생성물이며, `npm run build:win` 을 다시 실행하면
그대로 다시 만들어집니다. 소스나 `assets/*.svg` 처럼 git 이 추적하는 파일은 건드리지 않습니다.

## 참고

* **Ctrl+S** 는 형광펜·주석을 **열린 PDF 파일에 바로** 저장합니다. 원본을 그대로 두려면 *PDF 다른 이름으로 저장* 을 쓰세요.
  경로를 모르는 문서(URL로 연 문서, 웹 브라우저)는 Ctrl+S 도 저장 창을 띄웁니다.
* PDF에 들어 있는 형광펜은 쪽 그림으로 그려지고, 그 메모 카드는 **주석** 패널에서 고를 때만 펼쳐집니다
  (형광펜 메모는 대개 칠한 글자 자체라, 늘 펼쳐 두면 아래 줄을 가립니다).
* 웹 브라우저에서는 보안 정책상 파일 경로를 알 수 없어 PDF·`.pdfvw` 저장은 *다운로드* 로 이루어지고,
  최근 파일 목록의 항목은 이름만 기억됩니다.
* 이미지 클립보드 복사는 브라우저에서 HTTPS(보안 컨텍스트)가 필요하며 항상 PNG로 이루어집니다.
  파일로 저장할 때는 다섯 가지 형식을 모두 쓸 수 있습니다. 데스크톱 앱은 제한이 없습니다.
* `pdfjs-dist` 는 4.8.69(legacy 빌드)에 고정되어 있습니다. macOS·Linux 의 시스템 웹뷰(WKWebView · WebKitGTK)는
  버전이 제각각이라, 최신 문법을 쓰지 않는 legacy 빌드를 씁니다.
* 암호가 걸린 PDF는 열 때 암호를 묻습니다. 암호가 걸린 문서에 주석을 다시 쓰는 것은 지원하지 않습니다.
* 끝내지 않은 주석·책갈피·첨부가 있으면 창을 닫거나 그 탭을 닫기 전에 저장할지 묻습니다.
* 폴더 트리의 PDF 목록은 확장자가 정확히 `pdf` 인 파일만 포함합니다. 작업 파일(`.pdfvw`)은 열기 대화상자로 엽니다.
