# My Document Converter V1.0 사용자 안내서

## 1. 설치와 실행

| 플랫폼 | 방법 |
| --- | --- |
| Windows | `My Document Converter V1.0 Setup 1.0.0.exe` 를 실행합니다. 이전 버전이 있으면 자동으로 완전히 제거한 뒤 설치하고, 이전 설정 데이터가 남아 있으면 삭제할지 묻습니다. |
| macOS | dmg 를 열어 응용 프로그램 폴더로 끌어 놓습니다. |
| Linux | AppImage 에 실행 권한을 주고 실행하거나 deb/rpm 을 설치합니다. |
| 웹 | `npm run dev` 후 http://127.0.0.1:5174 (또는 `dist/` 를 웹 서버에 올립니다). |

설치하면 `.mdcv` 프로젝트 파일이 프로그램에 연결되어 더블클릭으로 열립니다.

## 2. 화면 구성

```
┌ 제목 표시줄: 아이콘 · 프로그램 이름 · 버전 · 현재 문서 · [ – □ × ] ┐
│ 메뉴: 파일 · 편집 · 보기 · 변환 · 도구 · 도움말                    │
│ 툴바: 새로 만들기/열기/저장/저장/내보내기/인쇄 | 실행취소/다시실행 | │
│       잘라내기/복사/붙여넣기 | 도구/속성 패널 | 확대/축소 | 변환/바꾸기 │
│                       …  [국기] [테마 전환] [테마 ▾] [설정] [정보] │
├──────────┬───────────────────────────────────┬────────────────────┤
│ 도구 패널 │ 탭 · 탭 · 탭                 < > │ 속성 패널          │
│ 변환 형식 │ ┌ 원본 ─────────┬ 변환 결과 ────┐ │ 일반 / 메타데이터 │
│ 보기      │ │ 편집기        │ 미리보기       │ │ Markdown / HTML    │
│ 문서 목록 │ │               │               │ │ 페이지 / 글꼴      │
│           │ └───────────────┴───────────────┘ │ 문서 정보          │
├──────────┴───────────────────────────────────┴────────────────────┤
│ 상태 표시줄: 메시지 · 형식 · 단어/글자 · 줄,열 · 저장 · 확대 · 언어 · 테마        │
└───────────────────────────────────────────────────────────────────┘
```

- 툴바의 모든 버튼에 마우스를 올리면 **툴팁**이 나옵니다.
- 메뉴는 창과 **별도의 창**으로 열려 창 크기에 상관없이 한 열로 전부 보입니다. 모든 항목에 아이콘과 레이블이 있습니다. 항목이 많은 **입력 형식 / 출력 형식** 은 종류(Markdown, 마크업, 위키, 오피스 …)별 하위 메뉴로 나뉘고, 현재 선택된 형식이 든 종류에는 점(●)이 표시됩니다.
- 편집기에서 **오른쪽 클릭**하면 편집용 컨텍스트 메뉴(실행 취소/다시 실행, 잘라내기/복사/붙여넣기, 변환, 결과 복사, 변환 결과 내보내기…, 통계, 탭 닫기)가, **변환 결과 창**에서 오른쪽 클릭하면 결과용 컨텍스트 메뉴(**변환 결과 내보내기…**, 변환 결과 복사, 결과를 새 문서로 열기, 지금 변환, 형식 바꾸기, 인쇄, 통계)가 열립니다.
- 창 최소 크기는 툴바 버튼이 모두 보이는 폭입니다.

## 3. 문서 변환하기

1. **파일 › 열기**(Ctrl+O)로 문서를 열거나, 파일을 창에 **끌어다 놓거나**, **파일 › 새 문서**(Ctrl+N)로 빈 문서를 만들어 입력합니다. **파일 › URL에서 열기**로 웹 문서를 가져올 수도 있습니다.
2. 왼쪽 **도구 패널**에서 **입력** 형식(열 때 확장자로 자동 판단)과 **출력** 형식을 고릅니다. 형식 버튼을 누르면 종류별로 나뉜 메뉴가 열리고, 현재 형식이 든 종류에 점(●)이 표시됩니다(테마 색을 그대로 쓰므로 어떤 테마에서도 잘 읽힙니다). **바꾸기**(Ctrl+Shift+X)는 두 형식을 맞바꿉니다.
3. **입력할 때 자동 변환**이 켜져 있으면 오른쪽 **변환 결과**에 바로 나타납니다. 끄면 **변환**(F9) 버튼으로 실행합니다.
4. **파일 › 변환 결과 내보내기**(Ctrl+E)로 결과를 파일로 저장합니다. DOCX/ODT/EPUB/PDF 같은 이진 형식은 이 방법으로 저장합니다.

**편집 › 변환 결과 복사**(Ctrl+Shift+C)는 결과 텍스트를 클립보드에 넣습니다. **변환 › 결과를 새 문서로 열기**는 결과를 새 탭의 원본으로 씁니다(예: HTML → Markdown 으로 바꾼 뒤 다시 편집).

### 지원 형식

Pandoc 이 다루는 형식을 모두 자체 엔진으로 지원합니다 (읽기 45종 · 쓰기 60여 종). 종류별로 나열하면:

| 종류 | 읽기 | 쓰기 |
| --- | --- | --- |
| Markdown | Pandoc Markdown, strict, PHP Extra, MultiMarkdown, GFM, CommonMark, CommonMark(확장), Djot | 왼쪽 전부 + Markua |
| 마크업 | HTML, 일반 텍스트, reStructuredText, LaTeX, Org, Textile, AsciiDoc, Typst, Haddock, Muse, txt2tags, POD | HTML(5/4/분할 ZIP), 일반 텍스트, ANSI, RST, LaTeX, ConTeXt, Texinfo, Org, Textile, AsciiDoc(3종), Typst, Haddock, Muse |
| 위키 | MediaWiki, DokuWiki, TikiWiki, TWiki, Vimwiki, Creole, Jira | MediaWiki, DokuWiki, XWiki, Zim, Jira |
| 매뉴얼 페이지 | man, mdoc | man, ms |
| 오피스 | DOCX, ODT, RTF, PostScript | DOCX, ODT, OpenDocument(fodt), RTF, ICML, PDF(데스크톱), PostScript |
| 전자책 | EPUB, FB2 | EPUB 3, EPUB 2, FB2 |
| 슬라이드 | – | reveal.js, Slidy, Slideous, S5, DZSlides, Beamer, PPTX |
| XML | DocBook, JATS, BITS, OPML | DocBook 5/4, JATS(3종), TEI, OPML |
| 참고문헌 | BibTeX, BibLaTeX, CSL JSON, RIS, EndNote XML | BibTeX, BibLaTeX, CSL JSON |
| 데이터 | CSV, TSV, ipynb, Pandoc JSON, Pandoc native | CSV, TSV, ipynb, Pandoc JSON, Pandoc native |

각 형식의 샘플 문서가 `samples/` 폴더에 종류별로 들어 있습니다 (`samples/README.md` 참고).

**PostScript** 출력은 Pandoc 에 없는 이 프로그램만의 형식입니다. 입력·출력 형식 목록의 **오피스** 종류에 있고(파일 열기의 확장자 .ps/.eps 도 자동 인식), 출력 형식을 PostScript 로 고르면 속성 패널에 **PostScript** 그룹(글꼴 내장 켜기/끄기, 본문 글꼴 나눔고딕/나눔고딕코딩, 본문 크기, 제목 밑줄·코드 상자)이 나타납니다. 새 문서의 기본값은 **설정 › 출력 옵션 › PostScript** 탭에서 정합니다. 용지 크기·방향·여백은 **페이지** 옵션을 따르고, 목차(페이지 번호 포함)·절 번호·각주·표·코드 상자·체크 박스가 지원됩니다. 본문 글꼴은 프로그램과 함께 설치되는 **나눔고딕 / 나눔고딕코딩**(OFL)이며 문서가 쓰는 글자만 PS 파일 안에 내장되므로, 받는 쪽에 한글 글꼴이 없어도 Ghostscript·프린터·PS 뷰어에서 그대로 보입니다. PostScript 를 **열면** 이 프로그램이 만든 파일은 원래 구조 그대로, 다른 프로그램이 만든 파일은 본문 텍스트(제목·문단)를 추출해 보여 줍니다.

**변환 › 지원 형식…**에서 같은 표를 볼 수 있습니다. 브라우저에서 PDF 는 인쇄 대화상자의 "PDF로 저장"을 사용합니다.

### 변환 옵션 (오른쪽 속성 패널)

| 그룹 | 항목 |
| --- | --- |
| 일반 | 완전한 문서로 출력, 목차·목차 깊이, 절 번호, 줄 바꿈(자동/없음/원본 유지)·줄 너비, 줄 끝(LF/CRLF) |
| 메타데이터 | 제목·작성자·날짜 (비우면 원본의 값) |
| Markdown | 종류(Pandoc/GitHub/CommonMark), 제목 스타일, 목록·강조 기호, 코드 울타리 |
| HTML / EPUB | 스타일시트(기본/GitHub/최소/인쇄용/없음), 수식 렌더링, `<section>` 감싸기 |
| 페이지 | 용지, 가로 방향, 여백 — PDF·인쇄·DOCX·ODT·RTF·LaTeX 에 적용 |
| 문서 글꼴 | 본문 글꼴·크기, 코드 글꼴 (시스템 글꼴 목록에서 선택) |
| LaTeX | 문서 클래스, 글꼴 크기 |

출력 형식에 따라 필요한 그룹만 표시됩니다. **이 옵션을 기본값으로 저장**을 누르면 새 문서가 같은 옵션으로 시작합니다.

### 엔진

변환은 모두 프로그램에 내장된 엔진이 처리합니다. Pandoc 을 비롯한 외부 프로그램을 설치할 필요가 없고, 어느 플랫폼에서든 같은 결과가 나옵니다.

- **저장 여부 질문**: 문서 내용이 열었을 때(또는 마지막 저장) 그대로이면 탭이나 프로그램을 닫을 때 묻지 않습니다. 출력 형식이나 변환 옵션을 바꾼 것만으로는 "수정됨"이 되지 않으며(프로젝트 .mdcv 는 예외), 실행 취소로 원래 내용에 돌아가면 다시 "수정 안 됨"이 됩니다.

## 4. 저장

- **저장**(Ctrl+S): 원본 텍스트를 열었던 파일에 씁니다. 새 문서는 저장 대화상자가 열립니다.
- **다른 이름으로 저장**(Ctrl+Shift+S).
- **프로젝트로 저장 (.mdcv)**: 원본·입력/출력 형식·옵션을 한 파일에 저장합니다. 나중에 열면 같은 상태로 돌아옵니다.
- 저장하지 않은 변경이 있는 탭을 닫거나 프로그램을 종료하면 **저장 여부를 묻습니다**.
- 열기/저장/내보내기/일괄 변환에 쓴 **폴더는 기억**되어 다음 대화상자의 시작 위치가 됩니다.

## 5. 일괄 변환

**파일 › 일괄 변환…**(Ctrl+B): 파일을 추가하고 출력 형식과 출력 폴더를 고른 뒤 **모두 변환**을 누릅니다. 진행률이 표시되고 결과는 같은 이름에 새 확장자로 저장됩니다. 브라우저에서는 결과가 ZIP 으로 내려받아집니다.

## 6. 인쇄

**파일 › 인쇄…**(Ctrl+P)에서:

- **인쇄 내용**: 변환 결과 또는 원본 텍스트
- **인쇄 범위**: 현재 문서 / 모든 문서(열린 탭 전부) / 사용자 지정 페이지(예: `1-3, 5`)
- **페이지 설정**: 용지, 방향, 여백 — 미리보기에 즉시 반영되고 페이지 수가 표시됩니다
- **프린터**와 **매수**를 고르고 **인쇄**를 누르면 바로 출력됩니다. **시스템 인쇄 대화상자…**로 운영체제 대화상자를 쓸 수도 있습니다(브라우저에서는 이 방법으로 PDF 저장).

## 7. 편집

- **실행 취소 / 다시 실행**(Ctrl+Z / Ctrl+Y): 입력·형식 변경·옵션 변경 모두 되돌릴 수 있습니다. 연속 입력은 한 단계로 묶입니다.
- **잘라내기 / 복사 / 붙여넣기 / 모두 선택**(Ctrl+X/C/V/A).
- **Tab** 은 공백 4 칸을 넣습니다.
- **Ctrl+마우스 휠** 또는 Ctrl+ +/− 로 편집기와 미리보기를 확대/축소합니다(Ctrl+0 은 원래 크기).
- **편집 › 문서 메타데이터…**로 출력 문서의 제목·작성자·날짜를 지정합니다.
- **도구 › 문서 통계…**: 단어·글자·줄·제목·문단·표·이미지·링크 수와 원본/결과 크기.

## 8. 보기

- **원본만 / 원본+결과 / 결과만**: 도구 패널의 세 버튼 또는 **보기** 메뉴.
- **도구 패널**(Ctrl+1), **속성 패널**(Ctrl+2) 숨기기/보이기 — 툴바의 두 패널 버튼으로도 여닫습니다. 패널을 닫으면 편집기와 미리보기가 그 자리를 차지합니다.
- **자동 줄 바꿈**, **줄 번호**.
- 탭이 많아 화면을 넘으면 탭 줄 양쪽에 **‹ ›** 버튼이 나타나 탭을 이동합니다. 가운데 버튼 클릭으로 탭을 닫을 수 있습니다.

## 9. 테마, 언어, 글꼴, 배경

- 툴바 오른쪽의 **테마 전환** 버튼(Ctrl+T)은 다음 테마로 넘어가고, 옆의 **드롭다운**에서 20 가지 테마(다크 13 · 라이트 7) 중 하나를 바로 고릅니다. **보기 › 테마** 메뉴와 설정 창에서도 바꿀 수 있습니다.
- **국기 버튼**은 언어를 전환합니다. 한국어일 때는 영국 국기(영어로 전환), 영어일 때는 태극기(한국어로 전환)가 보입니다.
- **설정 › 글꼴**: 시스템에 설치된 모든 글꼴 중에서 편집기 글꼴(고정폭 글꼴이 먼저), 크기, 굵게/기울임, 미리보기 글꼴과 크기를 정합니다.
- **설정 › 모양**: 테마, **배경 이미지** 선택·제거, 배경 불투명도, 맞춤(채우기/맞추기/바둑판/가운데). 이미지 크기 제한은 없습니다.
- 모든 팝업 창은 크기가 고정되어 있고(크기 조절 불가) 스크롤바가 없습니다. 내용이 많은 창은 탭(설정, 지원 형식)이나 두 열(키보드 단축키), 한 쪽씩 넘기는 미리보기(인쇄)로 정리되어 있습니다.
- 설정 창은 **일반 · 모양 · 글꼴 · 편집기 · 변환 · 출력 옵션** 탭으로 나뉘며 창 크기는 항상 같습니다. **출력 옵션** 탭은 다시 일반 / 메타데이터 / Markdown / HTML·EPUB / 페이지 / 문서 글꼴 / LaTeX 로 나뉘어 새 문서의 변환 옵션 기본값을 정합니다.

모든 설정은 자동으로 저장되어 다음 실행 때 그대로 적용됩니다. 열려 있던 탭도 복원됩니다(설정에서 끌 수 있음).

## 10. 최근 파일

**파일 › 최근 파일** 하위 메뉴에 최근 10 개가 나열됩니다. 항목 옆 **✕** 로 하나씩 지우거나 **최근 파일 모두 지우기**로 한 번에 지웁니다. **최근 파일 목록…** 대화상자에서도 같은 일을 할 수 있습니다.

## 11. 오류

오류가 나면 팝업에 내용과 자세한 정보(버전, 시각, 동작, 문서, 스택, 환경)가 표시됩니다. **오류 내용 복사**로 전체를 클립보드에 넣어 문의에 붙일 수 있습니다.
