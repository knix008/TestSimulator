# MyGitJS

Web, Windows, macOS, Linux에서 같은 화면을 쓰는 Git 클라이언트입니다. 명령은 상위 프로젝트 루트에서 실행합니다.

- [README.md](../README.md) — 설치, 실행, 테스트
- [UsersGuide.md](../UsersGuide.md) — 화면과 작업 방법
- [Architecture.md](../Architecture.md) — UI, API, `git` 호출 구조

```powershell
cd ..
npm install
npm run dev:web
npm test
```

브라우저 주소는 http://127.0.0.1:5173 입니다. API는 http://127.0.0.1:4730 입니다.
