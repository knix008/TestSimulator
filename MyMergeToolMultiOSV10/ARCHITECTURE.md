# 구조

MyMerge 10.0은 번들러 없는 정적 페이지입니다. Electron은 그 페이지를 창에 띄우고, 메뉴와 팝업은 부모 창과 따로 열었다가 본 창이 닫히면 함께 닫습니다.

```
index.html           본 화면
style/styles.css     테마 변수와 고정 크기 팝업
src/merge.js         3-way 머지와 충돌 표시
src/app.js           도구 모음, 메뉴, 패널, 팝업
src/i18n.js          한국어와 영어
src/themes.js        테마 40개와 사용자 정의
electron/main.js     창, 불투명도, Git, 설치 후 파일 연결
build/installer.nsh  재설치와 저장 데이터 질문
test/                브라우저 테스트
```

스크립트는 ES 모듈이 아닙니다. `index.html`이 순서대로 읽습니다. 파일 프로토콜과 HTTP에서 같이 동작합니다.

## 머지

`merge3`는 기준 파일과 양쪽 수정본의 줄 단위 차이를 구간으로 합칩니다. 한쪽만 바뀌면 그 쪽을 결과에 넣고, 양쪽이 같은 곳을 다르게 바꾸면 `<<<<<<<` 표시를 남깁니다. 큰 파일은 공통 앞뒤 줄을 먼저 자른 뒤 가운데만 비교합니다.

결과 창에서 기준, 로컬, 원격, 양쪽을 고르면 그 충돌 구간만 바뀝니다. 실행 취소는 문서 전체의 스냅샷입니다.

## 화면

창 제목은 MyMerge 10.0입니다. 도구 모음은 한 줄이고 테마, 언어, 설정, 프로그램 정보는 메뉴 막대 오른쪽에 있으며, 최소 폭은 `src/metrics.js`의 1200픽셀입니다. Electron 창의 `minWidth`도 같은 값입니다.

메뉴는 한 열입니다. 각 항목은 아이콘과 레이블을 함께 가집니다. 브라우저에서는 본문 밖의 고정 레이어에 그리고, Electron에서는 부모에 붙인 별도 창으로 엽니다. 그래서 본 창보다 길어져도 잘리지 않습니다.

팝업은 너비와 높이가 고정이고 안에 스크롤바를 두지 않습니다. 설정처럼 항목이 많으면 탭으로 나눕니다. 한 항목은 한 줄입니다. 본 창을 닫으면 자식 창도 닫힙니다.

왼쪽 패널은 머지 도구와 충돌 목록이고, 오른쪽 패널은 경로와 인코딩 같은 속성입니다. 탭이 가로를 넘치면 스크롤바 대신 `<` `>` 버튼으로 옮깁니다.

설정, 최근 파일 10개, 마지막 폴더, 글꼴, 테마, 투명도, 바탕 그림은 `localStorage`와 IndexedDB에 남습니다. 바탕 그림은 크기 제한 없이 넣습니다.

## 데스크톱

`electron/main.js`는 창 아이콘으로 `assets/icon.ico`를 씁니다. 설치 프로그램 아이콘도 같은 파일입니다. 세션 파일 `.mmerge`는 `assets/document.ico`로 등록합니다.

Git 명령은 저장소를 검사하고 충돌 단계 `:1:`, `:2:`, `:3:`을 읽습니다. 웹에서는 파일을 열거나 끌어다 놓고, 충돌 표시가 있는 텍스트를 직접 해석합니다.

## 테스트

`npm test`는 로컬 서버를 띄운 뒤 헤드리스 브라우저로 `test/index.html`을 엽니다. 케이스는 종류별 묶음으로 실행되고, 콘솔에 묶음별 통과 수와 Summary가 나옵니다.
