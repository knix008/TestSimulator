## 설치와 제거 (Windows)

`MyClock-Setup-1.0.0.exe` 를 실행하면 아래 순서로 진행됩니다.
한국어 Windows 에서는 한국어로, 그 밖에서는 영어로 표시됩니다.

| 페이지 | 내용 |
|--------|------|
| 사용권 계약 | **동의함**을 누릅니다 |
| 설치 옵션 | 모든 사용자 / 현재 사용자만 — 처음 설치할 때만 나옵니다 |
| 설치 위치 | 기본값 `C:\Users\<이름>\AppData\Local\Programs\MyClock` — 처음 설치할 때만 나옵니다 |
| 재설치 방식 선택 | **이미 설치된 MyClock 이 있을 때만** 나옵니다 (아래 참고) |
| 바로가기 선택 | 바탕화면 · 시작 메뉴 바로가기를 각각 만들지 체크 |
| 설치 | 파일 복사 |

### 재설치 방식 선택

같은 컴퓨터에 MyClock 이 이미 있으면 두 가지 중 하나를 고릅니다.

| 선택 | 결과 |
|------|------|
| **기존 설정을 유지하고 새 버전으로 덮어쓰기** (기본) | 프로그램 파일만 새 것으로 바뀝니다. 테마·알람·타이머·세계 시간·일정 등 설정과 데이터는 그대로 남습니다. |
| **완전히 삭제한 뒤 새로 설치** | 프로그램 파일과 함께 설정·데이터 폴더, 기존 바로가기까지 모두 지운 뒤 처음 상태로 설치합니다. **되돌릴 수 없습니다.** |

### 바로가기

체크한 항목만 만들어집니다. 나중에 직접 만들거나 지워도 되고,
프로그램을 제거하면 설치 때 만든 바로가기도 함께 지워집니다.

### 제거

Windows **설정 › 앱 › 설치된 앱 › MyClock › 제거**, 또는 설치 폴더의
`Uninstall MyClock.exe` 를 실행합니다. 프로그램·바로가기·설정 데이터가 함께 지워집니다.

## 기본 화면

평소에는 **시계만** 보입니다. 창 배경은 투명해서 뒤의 화면이 그대로 비칩니다.

마우스를 시계 위에 올리면 숨어 있던 요소가 나타납니다.

```
┌─────────────────────────────────┐
│ 2026년 09월 17일 목      [◷][⚙] │  ← 날짜 · 모드 전환 · 설정
│                                 │
│        09 : 17 : 48             │  ← 시계
│                                 │
│                              ◢  │  ← 크기 조절 손잡이
└─────────────────────────────────┘
```

| 요소 | 기능 |
|------|------|
| ◷ / ▦ | 디지털 ↔ 아날로그 전환 |
| ⚙ | 설정 패널 열기 / 닫기 |
| ◢ (오른쪽 아래) | 끌어서 창 크기 조절 |

마우스를 치우면 다시 시계만 남습니다.

디지털 시계에서는 글자가 잘 읽히도록 **아주 옅은 배경**이 함께 깔립니다 (뒤 화면이 비칩니다).
아날로그 시계에서는 둥근 문자판 뒤에 사각형이 생기지 않도록 **배경을 깔지 않습니다**.

표시 자리는 이렇습니다.

| 모드 | 어디에 |
|------|--------|
| 디지털 | 숫자 **바로 위 한 줄**에 "도시 · 오전/오후 · 날짜" (도시는 추가 시계만, 날짜는 마우스를 올렸을 때) |
| 아날로그 | 오전/오후 · 도시 · 날짜를 모두 **문자판 안**에 큼직하게 그립니다. 문자판 바깥에는 글자가 없습니다 |

7세그먼트·도트 스타일에서는 **켜진 숫자 부분만** 그려지고 나머지는 완전히 투명합니다.
어떤 배경 위에 두어도 숫자 외의 영역이 색 덩어리로 보이지 않습니다.

## 디지털 ↔ 아날로그 전환

세 가지 방법 중 편한 것을 쓰면 됩니다.

1. 시계 위 **◷ / ▦ 버튼** 클릭 — 가장 빠릅니다
2. 설정 패널 → **설정** 탭 → **시계 모드** 에서 디지털/아날로그 선택
3. 시계에서 **우클릭** → *아날로그(또는 디지털) 시계로 전환*

두 모드는 **창 크기를 따로 기억합니다.** 아날로그를 크게, 디지털을 작게 써 두면
전환할 때마다 각자의 크기로 돌아갑니다.
**창 위치는 그대로 유지**되므로, 전환해도 시계가 화면을 가로질러 움직이지 않습니다.

## 창 구성

MyClock 은 **창 하나가 한 가지만** 맡습니다.

| 창 | 하는 일 | 여는 방법 |
|----|---------|-----------|
| 시계 창 | 시각 표시 | 실행하면 뜹니다 |
| 추가 시계 창 | 다른 도시의 시각 | 세계 시간 창에서 도시의 **시계** 단추 |
| 설정 창 | **설정만**. 시계마다 자기 설정 창을 갖습니다 | 그 시계 위의 ⚙ · 우클릭 *설정...* |
| 세계 시간 / 알람 / 타이머 / 스톱워치 / 캘린더 | 각 기능 | 우클릭 메뉴 또는 트레이 메뉴에서 그 이름 |
| 프로그램 정보 | 버전·빌드·제작자 | 우클릭 → *프로그램 정보...* 또는 트레이 메뉴 |

설정 창은 시계마다 하나씩이고, 그 밖의 창은 **언제나 하나**뿐입니다 (이미 떠 있으면 앞으로 옵니다).

창마다 제목 줄 왼쪽에 그 창의 아이콘이 붙어 있어 어떤 창인지 한눈에 보입니다.

알람·타이머·스톱워치·캘린더·세계 시간은 **앱 전체가 하나로** 씁니다. 어느 창에서 고쳐도
같은 알람·같은 타이머입니다. 시계마다 다른 것은 **설정(모양·시간대)** 뿐입니다.

설정 패널은 시계 옆에 붙어 열립니다. 오른쪽에 공간이 부족하면 왼쪽에 열리고, 시계를
끌어 옮기면 따라옵니다. 떠 있는 창으로 떼어내고 싶으면 제목 줄의 **⧉** 를 누릅니다.

**닫는 방법** — 오른쪽 위 **✕**, **Esc**, 또는 우클릭 → *설정 닫기*.

## 시계 여러 개 두기

**메뉴에서 바로 추가**

- 시계 위 우클릭 → **시계 추가...** → 세계 시간 목록의 도시가 그대로 메뉴로 나옵니다.
  고르면 그 도시의 시계가 바로 열립니다.
- 트레이 아이콘 우클릭 → **시계 추가 ▸** 에서도 같은 목록을 고를 수 있고,
  **시계 닫기 ▸** 로 열어 둔 시계를 닫을 수 있습니다.

**목록에 없는 도시로 추가**

1. 우클릭 → **세계 시간** (또는 메뉴의 *다른 도시 찾기...*)
2. 도시를 찾아 목록에 넣고, 그 줄의 **시계** 단추를 누릅니다.
3. 그 도시의 시계 창이 하나 더 뜹니다. 창에는 **도시 이름**이 함께 보입니다.

시계마다 테마·디지털/아날로그·스타일·시간 형식·밝기·색을 **따로** 정할 수 있습니다.

**시계마다 자기 설정 창**을 갖습니다. 어떤 시계를 고칠지 고를 필요가 없습니다 —
그 시계의 ⚙ 를 누르면 그 시계만의 설정 창이 옆에 뜨고, 제목에 어느 시계인지 적혀 있습니다
(예: *파리 시계 설정*). 시계를 닫으면 그 설정 창도 함께 닫힙니다.

| 하고 싶은 것 | 방법 |
|--------------|------|
| 이 시계만 설정 | 시계 위 **⚙** (또는 우클릭 → *이 시계 설정...*) |
| 시간대 바꾸기 | 그 시계의 설정 창 → **시계** 갈래 → **시간대 (도시)** |
| 도시 이름 숨기기 | 설정 창의 **창에 도시 이름 표시**, 또는 우클릭 → *도시 이름 숨기기* |
| 디지털 ↔ 아날로그 | 시계 위 **◷ / ▦**, 또는 우클릭 |
| 밝기 | 시계 위에서 마우스 휠, 또는 설정 창의 밝기 슬라이더 |
| 닫기 | 시계 위 **✕**, 우클릭 → *이 시계 닫기*, 또는 설정 탭의 **이 시계 닫기** |

열어 둔 시계는 위치·크기와 함께 기억되어 다음 실행에 그대로 다시 뜹니다.

패널은 시계 **오른쪽**에 붙어 열립니다. 오른쪽에 공간이 부족하면 자동으로
왼쪽에 열리고, 창을 끌어 옮기면 패널도 따라옵니다.

**닫는 방법**

- 패널 오른쪽 위 **✕ 버튼**
- **Esc** 키 (입력 폼이 열려 있으면 폼이 먼저 닫힙니다)
- 우클릭 → *설정 닫기*

## 세계 시간

### 도시 추가

1. 설정 패널 → **세계 시간** 탭
2. 검색창에 도시명·영문명·국가명 입력 (예: `서울`, `Tokyo`, `프랑스`)
3. 추천 목록에서 선택 (↑↓ 키로도 고를 수 있습니다)
4. **추가** 클릭 또는 Enter

286개 도시가 등록되어 있고, 시간대는 자동으로 설정됩니다.

### 그 밖의 조작

| 동작 | 방법 |
|------|------|
| 삭제 | 항목 오른쪽 **✕** |
| 순서 바꾸기 | 항목을 끌어서 원하는 자리에 놓기 |

각 항목에는 현지 시각과 미니 아날로그 시계가 함께 표시되고,
날짜가 다르면 `+1일` / `-1일` 이 붙습니다.

## 알람

### 추가

1. 설정 패널 → **알람** 탭 → **알람 추가**
2. 시간 입력, 레이블 입력(선택)
3. 반복하려면 **반복** 체크 → 요일 버튼으로 선택
4. **저장**

### 관리

| 동작 | 방법 |
|------|------|
| 켜기 / 끄기 | 왼쪽 토글 스위치 |
| 수정 | **편집** 버튼 |
| 삭제 | 오른쪽 **✕** |

설정한 시각이 되면 팝업과 알람음이 울립니다.
반복 알람이 아니면 울린 뒤 자동으로 꺼집니다.

## 타이머

설정 패널 → **타이머** 탭.

| 동작 | 방법 |
|------|------|
| 시간 설정 | 시 · 분 · 초의 **−** / **+** 버튼 |
| 시작 / 재개 | **시작** 버튼 |
| 일시정지 | **일시정지** 버튼 |
| 정지 (처음으로) | **정지** 버튼 |
| 타이머 추가 | **타이머 추가** 버튼 |
| 타이머 삭제 | 오른쪽 위 **✕** |

타이머가 돌아가는 동안에는 **시계 본체에 남은 시간이 표시**되고,
끝나면 팝업과 알람음이 울립니다. 레이블을 적어 두면 팝업에 함께 나옵니다.

## 캘린더

설정 패널 → **캘린더** 탭, 또는 우클릭 → *캘린더*.

| 동작 | 방법 |
|------|------|
| 달 이동 | 위쪽 **◀ ▶** |
| 날짜 선택 | 달력의 날짜 클릭 |
| 일정 추가 | **일정 추가** 버튼 |
| 일정 수정 / 삭제 | 아래 목록의 **편집** / **✕** |

### 일정 항목

| 항목 | 설명 |
|------|------|
| 제목 · 날짜 | 필수 |
| 종일 | 체크하면 시간 입력이 사라집니다 |
| 시간 | 시작 ~ 종료 |
| 종료일 | 여러 날에 걸친 일정 |
| 반복 | 없음 · 매일 · 매주 · 매월 · 매년 |
| 미리 알림 | 정각 · 5분 · 10분 · 30분 · 1시간 · 1일 전 |
| 색상 | 달력에 표시되는 막대 색 |
| 메모 | 자유 입력 |

미리 알림을 설정하면 그 시각에 팝업과 알림음이 울립니다.
달력 칸에는 일정이 최대 3개까지 보이고, 더 있으면 `+n` 으로 표시됩니다.

## 설정

설정 창은 갈래 탭으로 나뉘어 있어 스크롤 없이 한 화면에 들어옵니다.

알람음·세계 시간 형식·항상 위에 표시 같은 **앱 전체 설정은 메인 시계의 설정 창**에만
있습니다. 추가한 시계의 설정 창에는 그 시계의 모양 설정만 나옵니다.

| 갈래 | 들어 있는 것 |
|------|--------------|
| 🎨 테마 | 바탕(어두운/밝은)과 테마 29색 + 사용자 색 — **열면 이 갈래가 먼저** 나옵니다 |

**시스템 설정은 트레이 아이콘**에 있습니다 — 트레이 우클릭 → *시스템 설정* 에서
항상 위에 표시 · 시작 시 자동 실행 · 기본값으로 초기화를 다룹니다.
세계 시간 24시간 표기는 **세계 시간 창**에 있습니다.

항목마다 왼쪽에 작은 아이콘이 붙어 있습니다.

### 색을 테마 색으로 되돌리기

디지털 숫자나 오전/오후 색을 직접 고른 뒤 다시 테마 색으로 돌아가고 싶으면,
**지금 쓰고 있는 테마 버튼을 한 번 더 누르면** 됩니다.

---

### 어두운 바탕 / 밝은 바탕

테마 목록 위의 **어두운 바탕 / 밝은 바탕** 단추로 바탕 밝기를 고릅니다.
29가지 색은 모두 두 판을 가지고 있어서, 쓰던 색은 그대로 두고 바탕만 바뀝니다
(예: *포레스트* 를 쓰는 중에 **밝은 바탕** 을 누르면 밝은 포레스트가 됩니다).
목록의 칸들도 고른 바탕으로 칠해져, 고르기 전에 실제 색을 볼 수 있습니다.

밝은 바탕에서는 네온색처럼 흰 바탕에 묻히는 색을 자동으로 조금 어둡게 조여
숫자와 바늘이 읽히도록 합니다.

---

### 내 색으로 테마 만들기

마음에 드는 색이 없으면 **사용자 정의 테마 색** 의 색 상자를 눌러 색을 고릅니다.
고른 색이 강조색·분침·디지털 숫자 색이 되고, 바탕·버튼·눈금 색은 그 색에 맞춰
자동으로 만들어집니다. 바탕 밝기는 위의 **어두운 바탕 / 밝은 바탕** 선택을 그대로 따릅니다.

테마 목록 맨 끝의 **사용자 색** 칸이 지금 고른 색을 보여 줍니다. 다른 테마를 썼다가
이 칸을 다시 누르면 고른 색 테마로 돌아옵니다.

## 전체 화면 시계

설정 탭의 **전체 화면으로 보기** 버튼, 또는 우클릭 → *전체 화면 시계*.

현재 설정한 모드·스타일·테마 그대로 화면 전체에 시계를 띄웁니다.
**배경은 투명**해서 바탕화면 위에 시계만 큼직하게 뜹니다.
**아무 키나 누르거나 클릭하면** 닫힙니다.

## 작업 표시줄과 시스템 트레이

MyClock 은 **작업 표시줄에 아이콘을 표시하지 않는** 트레이 전용 앱입니다.
시계 창이 화면에 보이는 동안에도 작업 표시줄에는 아무것도 나타나지 않고,
실행 중임은 시스템 트레이 아이콘으로만 알 수 있습니다. (macOS 에서는 Dock 아이콘도 감춥니다.)
창을 다시 앞으로 가져오려면 트레이 아이콘을 두 번 클릭하거나 Alt+Tab 을 쓰세요.

다음 어느 것으로든 트레이로 들어갑니다.

- 우클릭 메뉴 → *트레이로 숨기기*
- 창 최소화 (Win+D, Win+M 등 — 최소화된 창을 남기지 않고 바로 트레이로 갑니다)
- 창 닫기

트레이 아이콘은 현재 시각을 가리키는 미니 아날로그 시계이며 매초 갱신됩니다.

| 동작 | 기능 |
|------|------|
| 더블 클릭 | 창 보이기 |
| 우클릭 | 메뉴 (열기 / 설정... / 종료) |

창을 닫아도 앱은 트레이에 남습니다. 완전히 끝내려면 트레이 메뉴의 **종료**
또는 우클릭 메뉴의 **종료**를 쓰세요.
