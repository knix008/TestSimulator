## 설치와 제거 (Windows)

`MyClock-Setup-1.0.0.exe` 를 실행하면 아래 순서로 진행됩니다.
한국어 Windows 에서는 한국어로, 그 밖에서는 영어로 표시됩니다.

| 페이지 | 내용 |
|--------|------|
| 사용권 계약 | **동의함**을 누릅니다 |
| 설치 옵션 | 모든 사용자 / 현재 사용자만 — 처음 설치할 때만 나옵니다 |
| 설치 위치 | 기본값 `C:\Users\<이름>\AppData\Local\Programs\MyClock` — 처음 설치할 때만 나옵니다 |
| 재설치 방식 선택 | **이미 설치된 MyClock 이 있을 때만** 나옵니다 (아래 참고) |
| 바로가기 선택 | 바탕화면 · 시작 메뉴 바로가기를 각각 만들지 체크 |
| 설치 | 파일 복사 |

### 재설치 방식 선택

같은 컴퓨터에 MyClock 이 이미 있으면 두 가지 중 하나를 고릅니다.

| 선택 | 결과 |
|------|------|
| **기존 설정을 유지하고 새 버전으로 덮어쓰기** (기본) | 프로그램 파일만 새 것으로 바뀝니다. 테마·알람·타이머·세계 시간·일정 등 설정과 데이터는 그대로 남습니다. |
| **완전히 삭제한 뒤 새로 설치** | 프로그램 파일과 함께 설정·데이터 폴더, 기존 바로가기까지 모두 지운 뒤 처음 상태로 설치합니다. **되돌릴 수 없습니다.** |

### 바로가기

체크한 항목만 만들어집니다. 나중에 직접 만들거나 지워도 되고,
프로그램을 제거하면 설치 때 만든 바로가기도 함께 지워집니다.

### 제거

Windows **설정 › 앱 › 설치된 앱 › MyClock › 제거**, 또는 설치 폴더의
`Uninstall MyClock.exe` 를 실행합니다. 프로그램·바로가기·설정 데이터가 함께 지워집니다.

## 기본 화면

평소에는 **시계만** 보입니다. 창 배경은 투명해서 뒤의 화면이 그대로 비칩니다.

마우스를 시계 위에 올리면 숨어 있던 요소가 나타납니다.

```
┌─────────────────────────────────┐
│ 2026년 09월 17일 목      [◷][⚙] │  ← 날짜 · 모드 전환 · 설정
│                                 │
│        09 : 17 : 48             │  ← 시계
│                                 │
│                              ◢  │  ← 크기 조절 손잡이
└─────────────────────────────────┘
```

| 요소 | 기능 |
|------|------|
| ◷ / ▦ | 디지털 ↔ 아날로그 전환 |
| ⚙ | 설정 패널 열기 / 닫기 |
| ◢ (오른쪽 아래) | 끌어서 창 크기 조절 |

마우스를 치우면 다시 시계만 남습니다.

7세그먼트·도트 스타일에서는 **켜진 숫자 부분만** 그려지고 나머지는 완전히 투명합니다.
어떤 배경 위에 두어도 숫자 외의 영역이 색 덩어리로 보이지 않습니다.

## 디지털 ↔ 아날로그 전환

세 가지 방법 중 편한 것을 쓰면 됩니다.

1. 시계 위 **◷ / ▦ 버튼** 클릭 — 가장 빠릅니다
2. 설정 패널 → **설정** 탭 → **시계 모드** 에서 디지털/아날로그 선택
3. 시계에서 **우클릭** → *아날로그(또는 디지털) 시계로 전환*

두 모드는 **창 크기를 따로 기억합니다.** 아날로그를 크게, 디지털을 작게 써 두면
전환할 때마다 각자의 크기로 돌아갑니다.
**창 위치는 그대로 유지**되므로, 전환해도 시계가 화면을 가로질러 움직이지 않습니다.

## 창 이동 · 크기 조절

| 동작 | 방법 |
|------|------|
| 이동 | 시계의 아무 곳이나 끌기 |
| 크기 조절 | 오른쪽 아래 손잡이(◢)를 끌기, 또는 창 가장자리 끌기 |
| 최대화 / 복원 | 우클릭 → *최대화* / *창 크기 복원* |
| 디지털 밝기 | 디지털 모드에서 시계 위에 마우스 휠 굴리기 |

창 위치와 크기는 자동으로 저장되어 다음 실행 때 복원됩니다.

| 종료 | 앱 종료 |

## 설정 패널 열고 닫기

**여는 방법**

- 시계 위 **⚙ 버튼**
- 우클릭 → *설정...*
- 트레이 아이콘 우클릭 → *설정...*

패널은 시계 **오른쪽**에 붙어 열립니다. 오른쪽에 공간이 부족하면 자동으로
왼쪽에 열리고, 창을 끌어 옮기면 패널도 따라옵니다.

**닫는 방법**

- 패널 오른쪽 위 **✕ 버튼**
- **Esc** 키 (입력 폼이 열려 있으면 폼이 먼저 닫힙니다)
- 우클릭 → *설정 닫기*

## 세계 시간

### 도시 추가

1. 설정 패널 → **세계 시간** 탭
2. 검색창에 도시명·영문명·국가명 입력 (예: `서울`, `Tokyo`, `프랑스`)
3. 추천 목록에서 선택 (↑↓ 키로도 고를 수 있습니다)
4. **추가** 클릭 또는 Enter

286개 도시가 등록되어 있고, 시간대는 자동으로 설정됩니다.

### 그 밖의 조작

| 동작 | 방법 |
|------|------|
| 삭제 | 항목 오른쪽 **✕** |
| 순서 바꾸기 | 항목을 끌어서 원하는 자리에 놓기 |

각 항목에는 현지 시각과 미니 아날로그 시계가 함께 표시되고,
날짜가 다르면 `+1일` / `-1일` 이 붙습니다.

## 알람

### 추가

1. 설정 패널 → **알람** 탭 → **알람 추가**
2. 시간 입력, 레이블 입력(선택)
3. 반복하려면 **반복** 체크 → 요일 버튼으로 선택
4. **저장**

### 관리

| 동작 | 방법 |
|------|------|
| 켜기 / 끄기 | 왼쪽 토글 스위치 |
| 수정 | **편집** 버튼 |
| 삭제 | 오른쪽 **✕** |

설정한 시각이 되면 팝업과 알람음이 울립니다.
반복 알람이 아니면 울린 뒤 자동으로 꺼집니다.

## 타이머

설정 패널 → **타이머** 탭.

| 동작 | 방법 |
|------|------|
| 시간 설정 | 시 · 분 · 초의 **−** / **+** 버튼 |
| 시작 / 재개 | **시작** 버튼 |
| 일시정지 | **일시정지** 버튼 |
| 정지 (처음으로) | **정지** 버튼 |
| 타이머 추가 | **타이머 추가** 버튼 |
| 타이머 삭제 | 오른쪽 위 **✕** |

타이머가 돌아가는 동안에는 **시계 본체에 남은 시간이 표시**되고,
끝나면 팝업과 알람음이 울립니다. 레이블을 적어 두면 팝업에 함께 나옵니다.

## 캘린더

설정 패널 → **캘린더** 탭, 또는 우클릭 → *캘린더*.

| 동작 | 방법 |
|------|------|
| 달 이동 | 위쪽 **◀ ▶** |
| 날짜 선택 | 달력의 날짜 클릭 |
| 일정 추가 | **일정 추가** 버튼 |
| 일정 수정 / 삭제 | 아래 목록의 **편집** / **✕** |

### 일정 항목

| 항목 | 설명 |
|------|------|
| 제목 · 날짜 | 필수 |
| 종일 | 체크하면 시간 입력이 사라집니다 |
| 시간 | 시작 ~ 종료 |
| 종료일 | 여러 날에 걸친 일정 |
| 반복 | 없음 · 매일 · 매주 · 매월 · 매년 |
| 미리 알림 | 정각 · 5분 · 10분 · 30분 · 1시간 · 1일 전 |
| 색상 | 달력에 표시되는 막대 색 |
| 메모 | 자유 입력 |

미리 알림을 설정하면 그 시각에 팝업과 알림음이 울립니다.
달력 칸에는 일정이 최대 3개까지 보이고, 더 있으면 `+n` 으로 표시됩니다.

## 설정

설정 패널 → **설정** 탭.

| 항목 | 설명 |
|------|------|
| 알람 / 타이머 종료음 | 32가지 중 선택, 볼륨 조절, **미리듣기** |
| 시계 모드 | 디지털 / 아날로그 |
| 디지털 표시 밝기 | 디지털 시계의 밝기 — 시계 위에서 마우스 휠을 굴려도 조절됩니다 |
| 시간 형식 | 12시간 / 24시간 |
| 테마 | 18가지 색 테마. 버튼이 각 테마의 색으로 칠해져 있고, 작은 문자판 안의 점이 그 테마의 숫자 색입니다. 고르면 디지털 표시 색도 그 테마의 색으로 바뀝니다 |
| 오전/오후 색상 · 디지털 숫자 색상 | 직접 고른 색은 다음 테마 변경 전까지 유지됩니다 |
| 디지털 스타일 | 7세그먼트 · LCD · 미니멀 · 레트로 · 네온 · 도트 · 한글 · 매트릭스 · 빈티지 · 씬 |
| 아날로그 스타일 | 클래식 · 미니멀 · 로마 숫자 · 인덱스 · 철도 · 바우하우스 · 도트 · 파일럿 · 항해 · 모던 · 스팀펑크 |
| 세계 시간 형식 | 세계 시간만 24시간으로 표시 |
| 전체 화면 시계 | 전체 화면으로 열기 |
| 항상 위에 표시 | 다른 창 위에 고정 |
| 시작 시 자동 실행 | 로그인할 때 자동 실행 |
| 기본값으로 초기화 | 모든 설정을 처음 상태로 |

---

### 색을 테마 색으로 되돌리기

디지털 숫자나 오전/오후 색을 직접 고른 뒤 다시 테마 색으로 돌아가고 싶으면,
**지금 쓰고 있는 테마 버튼을 한 번 더 누르면** 됩니다.

## 전체 화면 시계

설정 탭의 **전체 화면으로 보기** 버튼, 또는 우클릭 → *전체 화면 시계*.

## 작업 표시줄과 시스템 트레이

시계 창이 화면에 보일 때만 **작업 표시줄**에 MyClock 아이콘이 표시됩니다.
트레이에서 동작하는 동안에는 작업 표시줄에 아무것도 남지 않습니다.

다음 어느 것으로든 트레이로 들어갑니다.

- 우클릭 메뉴 → *트레이로 숨기기*
- 창 최소화 (Win+D, Win+M, 작업 표시줄 클릭 등 — 최소화된 창을 남기지 않고 바로 트레이로 갑니다)
- 창 닫기

트레이 아이콘은 현재 시각을 가리키는 미니 아날로그 시계이며 매초 갱신됩니다.

| 동작 | 기능 |
|------|------|
| 더블 클릭 | 창 보이기 |
| 우클릭 | 메뉴 (열기 / 설정... / 종료) |

창을 닫아도 앱은 트레이에 남습니다. 완전히 끝내려면 트레이 메뉴의 **종료**
또는 우클릭 메뉴의 **종료**를 쓰세요.
