## 기본 화면 구성

```
┌─────────────────────────────────┐
│  🕐 MyClock   [⬜][📅] │ [─][□][✕] │  ← 타이틀바
├─────────────────────────────────┤
│           2025년 05월 31일 토           │  ← 날짜
├─────────────────────────────────┤
│                                 │
│          8 8 : 8 8 : 8 8        │  ← 시계 표시 영역
│                                 │
├─────────────────────────────────┤
│                             [▶] │  ← 설정 패널 열기 버튼
└─────────────────────────────────┘
```

| 위치 | 요소 | 기능 |
|------|------|------|
| 타이틀바 좌측 | 아이콘 + MyClock | 창 드래그로 이동 |
| 타이틀바 우측 첫 번째 버튼 | ⬜ / 🕐 | 디지털 ↔ 아날로그 전환 |
| 타이틀바 우측 두 번째 버튼 | 📅 | Google Calendar 창 열기 |
| 타이틀바 컨트롤 | ─ □ ✕ | 최소화 · 최대화 · 닫기 |
| 하단 우측 | ▶ | 설정 패널 열기/닫기 |

## 시계 모드 전환

타이틀바의 첫 번째 버튼을 클릭하면 디지털과 아날로그 시계를 전환합니다.

- **디지털 모드**: 7세그먼트, LCD 텍스트, 미니멀 중 선택 가능
- **아날로그 모드**: 클래식, 미니멀, 로만, 인덱스 중 선택 가능

아날로그 모드에서는 하단에 현재 시각이 텍스트로 함께 표시됩니다.

## 설정 패널

창 우하단의 **▶** 버튼을 클릭하면 설정 패널이 슬라이드로 열립니다.

### 패널 자동 위치 전환

설정 패널은 화면 여백에 따라 **자동으로 좌우 위치가 결정**됩니다.

- 시계 창 우측에 공간이 충분하면 → 오른쪽으로 열림 (버튼: **▶**)
- 우측 공간이 부족하면 → 왼쪽으로 열림 (버튼: **◀**)

창을 드래그해서 이동하면, 열린 상태에서도 실시간으로 패널이 따라 이동합니다.
화면 모서리에 닿아 공간이 부족해지면 반대편으로 자동 전환됩니다.

### 패널 탭 구성

| 탭 | 내용 |
|----|------|
| 세계시간 | 도시 추가·삭제, 미니 아날로그 시계 |
| 알람 | 알람 추가·삭제·활성화 |
| 설정 | 테마·스타일·형식·밝기·색상·초기화 |

## 디지털 스타일

(디지털 모드일 때만 적용)

| 스타일 | 설명 |
|--------|------|
| 7세그먼트 | 실제 LED 전광판 스타일. 꺼진 세그먼트가 흐리게 표시됨 |

| 미니멀 | Segoe UI Light 폰트, 시:분만 표시, 깔끔한 느낌 |

## 아날로그 스타일

설정 패널 → **설정** 탭 → **아날로그 스타일** 에서 선택합니다.
(아날로그 모드일 때만 적용)

| 스타일 | 설명 |
|--------|------|
| 클래식 | 눈금 + 아라비아 숫자 (1–12) |
| 미니멀 | 눈금만, 숫자 없음 |
| 로만 | 눈금 + 로마 숫자 (I–XII) |
| 인덱스 | 숫자 없음, 시각 위치에 굵은 바 마커 |

## 알람

### 알람 추가

1. 설정 패널 → **알람** 탭
2. 시간 입력 (HH:MM 형식)
3. 레이블 입력 (선택 사항)
4. **추가** 버튼 클릭

### 알람 옵션

| 옵션 | 설명 |
|------|------|
| 활성/비활성 | 토글 스위치로 개별 켜기/끄기 |
| 반복 | 체크 시 매일 반복, 요일 선택 가능 |
| 삭제 | 항목 우측 ✕ 버튼 |

### 알람 발동

설정한 시간이 되면 팝업 창과 시스템 알림음이 울립니다.
반복 알람이 아닌 경우 발동 후 자동으로 비활성화됩니다.

## 세계 시간

### 도시 추가

1. 설정 패널 → **세계시간** 탭
2. 검색창에 도시명 또는 국가명 입력 (예: Tokyo, 뉴욕, London)
3. 자동완성 목록에서 도시 선택
4. **추가** 버튼 클릭

각 도시 항목에는 현재 시각과 미니 아날로그 시계가 함께 표시됩니다.

### 도시 삭제

목록에서 항목 우측 **✕** 버튼 클릭

### 시간 형식

세계 시간은 메인 시계의 12/24시간 설정과 별도로 적용할 수 있습니다.
설정 패널 → **설정** 탭 → **세계시간 24시간** 체크박스

## Google Calendar 연동

### 사전 설정 (최초 1회)

Google Calendar와 연동하려면 Google Cloud Console에서 OAuth 2.0 자격증명을 발급받아야 합니다.

#### 1단계 — Google Cloud 프로젝트 만들기

1. [Google Cloud Console](https://console.cloud.google.com) 접속
2. 상단 프로젝트 선택 → **새 프로젝트** → 이름 입력 (예: MyClock) → **만들기**

#### 2단계 — Google Calendar API 활성화

1. 왼쪽 메뉴 → **API 및 서비스** → **라이브러리**
2. "Google Calendar API" 검색 → **사용 설정**

#### 3단계 — OAuth 동의 화면 구성

1. **API 및 서비스** → **OAuth 동의 화면**
2. User Type: **외부** → **만들기**
3. **앱 이름** 입력 (예: MyClock), **지원 이메일** 선택 → **저장 후 계속**
4. 범위 추가 없이 **저장 후 계속**
5. **테스트 사용자** 탭 → **사용자 추가** → 본인 Gmail 주소 입력 → **저장**

> 테스트 상태에서는 테스트 사용자로 등록된 계정만 로그인할 수 있습니다.

#### 4단계 — OAuth 자격증명 만들기

1. **API 및 서비스** → **사용자 인증 정보**
2. **사용자 인증 정보 만들기** → **OAuth 클라이언트 ID**
3. 애플리케이션 유형: **데스크톱 앱**
4. 이름 입력 → **만들기**
5. 생성된 항목 우측 **⬇ JSON 다운로드** 클릭

#### 5단계 — 자격증명 파일 배치

다운로드한 JSON 파일을 아래 이름으로 저장합니다.

```
%AppData%\MyClock\google_credentials.json
```

> 파일 탐색기 주소창에 `%AppData%\MyClock` 을 입력하면 해당 폴더로 바로 이동합니다.
> 폴더가 없으면 앱을 한 번 실행한 뒤 다시 시도하세요.

### Google Calendar 연결

1. 타이틀바의 📅 버튼 클릭 → Calendar 창 열림
2. **연결** 버튼 클릭
3. 시스템 브라우저가 열리며 Google 로그인 화면 표시
4. 로그인 후 **"MyClock이 Google 캘린더에 액세스하려고 합니다"** → **허용**
5. 브라우저를 닫으면 앱에 연결 완료, 14일 이내 일정이 표시됨

로그인 토큰은 `%AppData%\MyClock\google_token\` 에 저장되어 다음 실행 시 자동으로 연결됩니다.

---

### 일정 표시

연결 후 Calendar 창에서 향후 14일 이내의 일정이 표시됩니다.

| 정보 | 표시 방식 |
|------|-----------|
| 날짜/시간 | 종일 일정은 날짜만, 시간 일정은 날짜 + 시각 |
| 미리 알림 | Google Calendar에 설정된 미리 알림 시간 표시 |

**동기화** 버튼을 클릭하면 즉시 최신 일정을 가져옵니다.
앱 실행 중에는 15분마다 자동으로 동기화됩니다.

---

### 미리 알림

Google Calendar에 등록된 미리 알림 설정을 그대로 따릅니다.
이벤트마다 설정된 시간(예: 30분 전, 1시간 전 등)에 팝업과 알림음으로 알려줍니다.

> 종일 일정은 미리 알림이 발동되지 않습니다.

---

### 연결 해제

Calendar 창 → **연결 해제** 버튼 클릭
저장된 토큰이 삭제되며 자동 연결이 비활성화됩니다.

## 시스템 트레이

창을 최소화하면 작업 표시줄 대신 **시스템 트레이**에 숨겨집니다.
트레이 아이콘은 현재 시각을 나타내는 미니 아날로그 시계로 매초 갱신됩니다.

| 동작 | 기능 |
|------|------|
| 아이콘 더블 클릭 | 창 복원 |
| 아이콘 우클릭 | 컨텍스트 메뉴 (열기 / 닫기) |

## 창 이동 및 크기 조절

| 방법 | 동작 |
|------|------|
| 타이틀바 드래그 | 창 이동 |
| 모서리/가장자리 드래그 | 창 크기 조절 |
| 최대화 버튼 (□) | 최대화 ↔ 일반 크기 전환 |

창 위치와 크기는 종료 시 자동 저장되어 다음 실행 시 복원됩니다.
