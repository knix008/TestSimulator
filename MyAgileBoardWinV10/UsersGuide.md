## 1. 시작하기

### 프로그램 실행

- **MSI 설치**: `bin/Release/installer/MyAgileBoard_Setup.msi` 실행 후 안내에 따라 설치
- 개발 빌드: `dotnet run --project MyAgileBoardWinV10/MyAgileBoardWinV10.csproj`
- Visual Studio: `MyAgileBoardWinV10.sln`을 연 뒤 F5

설치 시 **기능 선택** 화면에서 **바탕화면 바로가기**와 **시작 메뉴 바로가기**를 각각 선택할 수 있습니다. 제거는 Windows **설정 → 앱 → 설치된 앱**에서 MyAgileBoard를 선택합니다.

### 새 프로젝트

1. **파일 → 새 프로젝트** 또는 툴바 **새로 만들기** (Ctrl+N)
2. 기본 컬럼(Backlog, To Do, In Progress, Review, Done)이 포함된 빈 보드가 열립니다.

### 프로젝트 열기

1. **파일 → 열기** (Ctrl+O)
2. `.mab` 파일을 선택합니다.
3. 대화상자는 **마지막으로 사용한 폴더**에서 시작합니다. 처음 실행 시에는 현재 프로젝트 경로 또는 **내 문서**가 사용됩니다.

### 저장

- **파일 → 저장** (Ctrl+S): 현재 경로에 저장
- **파일 → 다른 이름으로 저장** (Ctrl+Shift+S): 새 경로에 저장

실제로 보드를 **편집한 경우**에만 제목 표시줄에 별표(`*`)가 나타나고, 종료·새 프로젝트·다른 파일 열기 시 저장 여부를 묻습니다. 열기만 하고 변경하지 않았다면 저장 확인이 표시되지 않습니다.

## 2. 화면 구성

```
┌──────────────────────────────────────────────────────────────────┐
│  메뉴 (파일 | 편집 | 프로젝트 | 보내기 | 보기 | 도움말)           │
├──────────────────────────────────────────────────────────────────┤
│  툴바 (새로 만들기, 열기, 저장, 보내기, Summary, Burn Down …)    │
├──────────────────────────────────────────────────────────────────┤
│  [컬럼 1]  [컬럼 2]  [컬럼 3]  …  [+ 컬럼]                       │
│   카드      카드      카드    (캔버스 위 자유 배치)              │
├──────────────────────────────────────────────────────────────────┤
│  상태 표시줄: 전체 N개 | 완료 N개 | 진행중 N개                   │
└──────────────────────────────────────────────────────────────────┘
```

### 상태 표시줄

| 항목 | 설명 |
|------|------|
| **전체** | 모든 컬럼의 카드 수 합계 |
| **완료** | 완료 컬럼으로 지정된 컬럼의 카드 수 |
| **진행중** | 완료 컬럼이 아니면서 카드가 1개 이상 있는 컬럼의 카드 수 합계 |

### 툴바 주요 버튼

| 버튼 | 설명 |
|------|------|
| **보내기** | Report(Markdown/Word/PDF), 인쇄, 컬럼 카드 이미지 |
| **눈금** | 컬럼 캔버스 배경 눈금 표시/숨기기 |

## 3. 프로젝트 관리

### MyAgileBoard 파일 (.mab)

- JSON 형식, UTF-8 인코딩
- **저장 시 포함되는 내용**:
  - 프로젝트 이름, 생성일
  - 창 위치·크기·최대화 상태
  - 모든 컬럼 설정(이름, 색상, 글꼴, 너비, 완료 컬럼 여부)
  - 모든 카드(내용, 색상, 크기, 캔버스 좌표, 회전, 접힘, Z 순서)
  - 아카이브된 완료 카드
  - Burn Down 차트 색상
  - 배경 눈금 표시 여부

### 프로젝트 설정

**프로젝트 → 프로젝트 설정**에서 다음을 확인·변경할 수 있습니다.

- 프로젝트 이름
- **배경 눈금 표시** (체크 시 컬럼 캔버스에 격자 표시)
- 생성일 (읽기 전용)
- 저장 경로 (저장된 경우)

### 샘플 프로젝트

`Samples/Sample.mab`에 **MyAgileBoard 샘플 보드**가 포함되어 있습니다.

- 4개 컬럼(To Do, In Progress, Review, Done), 카드 10장 + 보관함 1장
- 다양한 크기·색상·회전 예시
- **모든 카드**에 우측 상단 접힘과 크기 조절 그립이 적용되어 있습니다

**파일 → 열기**로 불러와 기능과 레이아웃을 참고할 수 있습니다.

## 4. 컬럼 작업

### 컬럼 추가

1. 보드 오른쪽 끝 **+ 컬럼** 버튼 클릭
2. 컬럼 설정 대화상자에서 이름·색상·완료 컬럼 여부 등을 지정합니다.

### 컬럼 설정 변경

컬럼 헤더의 **메뉴(⋮)** → **컬럼 설정**에서 다음을 변경할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 컬럼 이름 | 헤더에 표시되는 이름 |
| 헤더 색상 | 컬럼 제목 바 배경색 |
| 캔버스 색상 | 카드가 올라가는 영역 배경색 |
| 제목 글꼴 | 글꼴, 크기, 굵게/기울임 |
| 제목 글자 색 | 자동(헤더 대비) 또는 직접 선택 |
| 컬럼 너비 | 컬럼 간 상대 너비 비율 |
| 완료 컬럼 | 완료 처리 컬럼 여부 |

설정 변경 시 **보드에 실시간 미리보기**가 적용됩니다. **취소**하면 열기 전 상태로 되돌아갑니다.

### 완료 컬럼

- **완료 컬럼**으로 지정된 컬럼에 카드가 들어오면 `CompletedAt`(완료 시각)이 자동 기록됩니다.
- 완료 컬럼이 아닌 곳으로 옮기면 완료 시각이 해제됩니다.
- 메뉴에서 **완료 컬럼으로 지정/해제**를 토글할 수도 있습니다.

### 컬럼 순서 변경

컬럼 **헤더를 드래그**하여 원하는 위치에 놓습니다. 드롭 위치에 파란색 안내선이 표시됩니다.

### 컬럼 삭제

컬럼 메뉴 → **컬럼 삭제**. 카드가 남아 있으면 삭제 전 확인 메시지가 표시됩니다.

### 배경 눈금(그리드)

- **보기 → 배경 눈금 표시** 또는 툴바 **눈금** 버튼
- **프로젝트 설정**에서도 변경 가능
- 설정은 `.mab` 파일에 저장됩니다

## 5. 카드 작업

### 카드 추가

1. 컬럼 하단 **+** 버튼 또는 컬럼 메뉴 → **카드 추가**
2. 카드 편집 대화상자에서 내용을 입력하고 **확인**

새 카드 추가 시 보드에 바로 표시되며, **취소**하면 추가 전 상태로 되돌아갑니다.

### 카드 편집

카드를 **더블클릭**하면 편집 대화상자가 열립니다. 필드 변경 시 **보드에 실시간 미리보기**가 적용되고, **취소**하면 편집 시작 전 상태로 복원됩니다.

| 필드 | 설명 |
|------|------|
| 제목 | 필수. 글꼴·색·굵게/기울임/밑줄/취소선 서식 지원 |
| 설명 | Rich Text(서식) 지원, 특수문자/이모티콘 삽입 |
| 담당자 | 담당자 이름 |
| 우선순위 | Low / Medium / High / Critical |
| 스토리 포인트 | 0~100 (Burn Down 차트에 사용) |
| 마감일 | 선택 사항 |
| 태그 | 쉼표 등으로 구분한 태그 문자열 |
| 카드 색상 | 팔레트 또는 사용자 지정 색 |
| 우측 상단 | **접힘** / **접힘 없음** (종이 접힌 모서리 표시) |
| 메모 크기 | 자동 / 작음 / 중간 / 큼 / 넓음 / 사용자 지정(너비·높이) |

### 카드 이동

- 카드를 **드래그**하여 컬럼 캔버스 위 원하는 위치에 놓습니다.
- 다른 컬럼 위로 드래그하면 컬럼 간 이동도 가능합니다.
- 드롭 위치에 파란색 안내 영역이 표시됩니다.

### 카드 크기 조절

- 카드 **우측 하단**의 은은한 대각선 그립을 드래그하여 크기를 조절합니다.
- 그립은 카드 배경색과 어울리게 표시되며, 마우스를 올리면 커서가 크기 조절 모양으로 바뀝니다.

### 카드 회전

1. 카드를 **클릭**하여 선택합니다(점선 테두리).
2. 아래 단축키로 회전합니다.

| 키 | 동작 |
|----|------|
| `Ctrl+[` | 15° 반시계 방향 |
| `Ctrl+]` | 15° 시계 방향 |
| `Ctrl+0` | 회전 초기화(0°) |

### 카드 앞/뒤 순서

카드 **우클릭** 메뉴에서 Z 순서를 변경할 수 있습니다.

- 앞으로 보내기 / 가장 앞으로 보내기
- 뒤로 보내기 / 가장 뒤로 보내기

겹쳐 놓은 카드의 표시 순서를 조절할 때 사용합니다.

### 카드 접힘(도그이어)

- 카드 우측 상단에 종이가 접힌 듯한 장식이 표시됩니다.
- **카드 편집 → 우측 상단 → 접힘 없음**을 선택하면 숨길 수 있습니다.
- 설정은 `.mab` 파일에 저장됩니다.

### 카드 삭제

카드에서 삭제를 실행하면 확인 후 제거됩니다.

- **완료 컬럼**의 카드를 삭제하면 보드에서는 사라지지만 **아카이브**에 보관됩니다.
- 다른 컬럼의 카드는 아카이브 없이 삭제됩니다.

## 6. 보기 및 리포트

### Summary / 차트 (Ctrl+T)

- 전체·완료·진행중·기한 초과 카드 수
- 컬럼별 카드 수 목록
- 우선순위별 분포
- 컬럼별 파이 차트, 우선순위별 막대 차트

### 완료된 항목 보기

완료 컬럼에서 삭제(아카이브)된 카드를 **주별 / 월별 / 연별** 탭으로 조회합니다.

표시 항목: 제목, 포인트, 우선순위, 담당자, 원래 컬럼, 아카이브 시각

### Burn Down 차트

- **시작일·종료일**을 지정해 기간별 완료 포인트 추이를 확인합니다.
- 완료 컬럼에 남아 있는 카드(`CompletedAt`)와 아카이브된 카드(`ArchivedAt`)를 합산합니다.
- 기본 기간은 최근 14일입니다.
- **색상 설정** 버튼으로 일별 막대·이상선·잔여선 색을 변경할 수 있으며, 색상은 **프로젝트 파일에 저장**됩니다.

## 7. 보내기 (Export)

**보내기** 메뉴 또는 툴바 **보내기** 버튼에서 다음을 실행할 수 있습니다.

| 항목 | 설명 | 단축키 |
|------|------|--------|
| **Report — Markdown** | 요약·통계·차트 포함 `.md` 파일 | Ctrl+Shift+M |
| **Report — Word** | `.docx` 문서 | Ctrl+Shift+W |
| **Report — PDF** | `.pdf` 문서 | Ctrl+Shift+P |
| **Report 인쇄** | 인쇄 미리보기 | Ctrl+P |
| **컬럼 카드 이미지** | 컬럼별 카드 보드를 PNG 등으로 저장 | — |

컬럼 카드 이미지는 폴더를 선택하면 `{프로젝트명}_cards` 하위에 컬럼별 이미지 파일이 생성됩니다.

## 8. 실행 취소 / 다시 실행

| 메뉴 | 단축키 | 설명 |
|------|--------|------|
| 실행 취소 | Ctrl+Z | 이전 상태로 되돌림 |
| 다시 실행 | Ctrl+Y | 취소한 작업을 다시 적용 |

다음 작업은 실행 취소 대상이 됩니다.

- 카드 추가·이동·편집·삭제·크기·회전·Z 순서 변경
- 컬럼 추가·삭제·순서 변경·설정 변경
- 완료 컬럼 토글

실행 취소로 저장 시점과 동일한 상태로 돌아가면 제목 표시줄의 `*`도 사라집니다.

## 10. 설정 및 파일 위치

### 앱 설정

| 항목 | 경로 |
|------|------|
| 최근 사용 폴더 | `%LocalAppData%\MyAgileBoard\settings.json` |

열기·저장·다른 이름으로 저장 시 사용한 폴더가 기록되며, 다음 **열기** 대화상자의 시작 위치로 사용됩니다.

### 프로젝트 파일

사용자가 지정한 경로에 `.mab` 파일로 저장됩니다. 아직 저장하지 않은 새 프로젝트는 **다른 이름으로 저장**으로 먼저 경로를 지정해야 합니다.

프로젝트를 저장하면 컬럼·카드·차트 색상·그리드 설정 등 **보드의 모든 설정**이 함께 기록됩니다.

## 11. 자주 묻는 질문

### 종료할 때마다 저장하라고 나옵니다

실제로 카드·컬럼을 변경했을 때만 확인이 표시됩니다. 파일만 열고 닫는 경우에는 묻지 않습니다. 제목에 `*`가 보이면 저장되지 않은 변경이 있다는 뜻입니다.

### 열기 대화상자가 항상 내 문서에서 시작합니다

한 번 이상 파일을 열거나 저장한 뒤에는 마지막 폴더가 기억됩니다. 앱을 다시 실행해도 `%LocalAppData%\MyAgileBoard\settings.json`에 저장된 경로를 사용합니다.

### 완료한 카드를 삭제했는데 어디에 있나요?

완료 컬럼에서 삭제한 카드는 **보기 → 완료된 항목 보기**의 아카이브에서 확인할 수 있습니다.

### Burn Down 차트에 포인트가 0으로 나옵니다

카드 편집에서 **스토리 포인트**를 1 이상으로 설정하세요. 완료 시각(`CompletedAt`) 또는 아카이브 시각이 차트 기간 안에 있어야 해당 일자에 반영됩니다.

### 여러 완료 컬럼을 둘 수 있나요?

컬럼 설정에서 여러 컬럼을 완료 컬럼으로 지정할 수 있습니다. 통계의 **완료** 수와 Summary는 완료 컬럼에 있는 모든 카드를 합산합니다.

### 카드 크기 조절 그립이 보이지 않습니다

카드 **우측 하단** 모서리에 카드 색과 비슷한 은은한 대각선 줄이 표시됩니다. 마우스를 올리면 크기 조절 커서(`↘`)가 나타납니다. 회전된 카드에도 그립이 함께 그려집니다.

### 일부 카드에만 접힘이 보입니다

**카드 편집 → 우측 상단**에서 **접힘** / **접힘 없음**을 선택할 수 있습니다. 샘플 프로젝트(`Samples/Sample.mab`)는 모든 카드에 접힘이 켜져 있습니다.

### 설정을 바꿨는데 저장 후 다시 열면 사라집니다

**파일 → 저장**(Ctrl+S)으로 `.mab`에 기록해야 합니다. 컬럼 색 with·Burn Down 색상·그리드 표시 등은 모두 프로젝트 파일에 저장됩니다.
