# DCMViewer 사용자 가이드

DCMViewer는 Windows용 DICOM 및 일반 이미지 뷰어입니다. 의료용 DICOM 파일(`.dcm`)과 JPG, PNG 등 일반 이미지를 같은 화면에서 열어 보고, 확대·축소·내보내기를 할 수 있습니다.

## 1. 시작하기

### 지원 형식

| 구분 | 확장자 |
|------|--------|
| DICOM | `.dcm`, `.dicm` |
| 일반 이미지 | `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`, `.bmp`, `.tif`, `.tiff`, `.ico` |

### 실행 방법

- **설치 후**: 시작 메뉴 또는 바탕 화면의 DCMViewer 바로 가기 실행
- **개발/직접 실행**: `DCMViewer.exe` 실행
- **파일 연결 후**: 탐색기에서 `.dcm` 파일 더블 클릭
- **명령줄**: `DCMViewer.exe "경로\파일.dcm"`

### 권장 환경

- Windows 10 / 11 (64비트)
- .NET 8 Desktop Runtime (프레임워크 종속 배포 시)
- JPEG2000 등 일부 압축 DICOM: Visual C++ 재배포 패키지 필요할 수 있음

## 2. 화면 구성

```
┌─────────────────────────────────────────────────────────────┐
│  [파일]  [도움말]                                            │  ← 메뉴 바
├─────────────────────────────────────────────────────────────┤
│  내보내기: [PNG] [JPEG] [BMP] [TIFF] [GIF]            [ℹ]  │  ← 툴바
├──────────────┬──────────────────────────────────────────────┤
│              │  [확대율 %]                                   │
│  파일 정보   │                                               │
│  (메타데이터)│         이미지 뷰어 영역                       │
│              │                                               │
│              │  ──────────── 프레임 슬라이더 ────────────    │
├──────────────┴──────────────────────────────────────────────┤
│  상태 표시줄 (파일 경로, 환자 정보, 검사 정보 등)              │
└─────────────────────────────────────────────────────────────┘
```

| 영역 | 설명 |
|------|------|
| **메뉴 바** | 파일 열기, DCM 연결 등록, 도움말 |
| **툴바** | 이미지 내보내기 버튼, 프로그램 정보(ℹ) 버튼 |
| **파일 정보** | DICOM 메타데이터 또는 일반 이미지 정보 (내용이 길면 스크롤) |
| **이미지 뷰어** | 확대/축소·패닝 대상 영역 |
| **확대율 표시** | 좌측 상단, 초기 화면 맞춤 대비 현재 배율(%) |
| **프레임 슬라이더** | 다중 프레임 DICOM일 때만 표시 |
| **상태 표시줄** | 파일 경로, 환자/검사 요약, 프레임 번호 등 |

## 3. 파일 열기

### 메뉴에서 열기

1. **파일 → 열기** (`Ctrl+O`)
2. 파일 형식 필터 선택 후 파일 선택
3. **열기** 클릭

### 파일 열기 대화상자 필터

- **모든 지원 형식** — DICOM + 일반 이미지
- **DICOM** — `.dcm`, `.dicm`
- **이미지** — JPG, PNG, GIF, WebP, BMP, TIFF
- **모든 파일** — `*.*`

### 연결된 파일로 열기

`.dcm` 파일을 DCMViewer와 연결해 두었다면 탐색기에서 더블 클릭만으로 열 수 있습니다.

## 4. 이미지 보기

### 처음 열었을 때

- 이미지는 **창 크기에 맞게** 자동으로 표시됩니다.
- 작은 이미지는 **화면 중앙**에 배치됩니다.

### 확대 / 축소

| 방법 | 동작 |
|------|------|
| **마우스 휠 위** | 확대 |
| **마우스 휠 아래** | 축소 |

- 휠 한 칸마다 약 **1.2배**씩 변경됩니다.
- 확대·축소 중에는 빠른 미리보기를 위해 화질이 잠시 낮아졌다가, 휠 입력이 멈추면 고화질로 다시 그려집니다.
- 이미지가 화면보다 클 때는 **화면 중심**을 기준으로 확대·축소됩니다.
- 좌측 상단에 **초기 맞춤 대비 배율(%)** 이 표시됩니다. (100% = 처음 맞춤 크기)

### 화면에 맞춤 / 실제 크기

이미지 영역에서 **우클릭 → 컨텍스트 메뉴** 사용:

| 메뉴 | 설명 |
|------|------|
| **화면에 맞춤** | 현재 창 크기에 맞게 다시 맞춤 |
| **실제 크기 (100%)** | 픽셀 1:1 크기로 표시 (원본 해상도) |

### 이미지 이동 (패닝)

- 이미지가 화면보다 **클 때만** 이동 가능합니다.
- **왼쪽 마우스 버튼**을 누른 채 드래그하면 이미지를 이동할 수 있습니다.
- 커서가 **십자 화살표(↔)** 로 바뀌면 이동 가능 상태입니다.

### 다중 프레임 DICOM

- CT, MRI 등 **여러 프레임**이 있는 DICOM은 이미지 아래 **슬라이더**가 나타납니다.
- 슬라이더를 움직여 프레임을 변경할 수 있습니다.
- 상태 표시줄과 파일 정보 패널에 현재 프레임 번호가 표시됩니다.

### 창 크기 변경

- 창 크기를 바꾸면 **화면 맞춤 기준**이 다시 계산됩니다.
- 이미지가 화면보다 작으면 계속 **중앙**에 유지됩니다.

## 5. 파일 정보 패널

왼쪽 **파일 정보** 패널에는 열린 파일의 메타데이터가 표시됩니다.

### DICOM 파일

예시 항목:

- 환자명, 환자 ID, 생년월일, 성별
- Modality, 검사/시리즈 설명
- Study Date, Series Date
- Institution, Manufacturer
- 이미지 크기, Bits Allocated
- 프레임 번호 (다중 프레임인 경우)

값이 없는 항목은 표시되지 않습니다.

### 일반 이미지

- 파일 이름, 형식, 픽셀 크기

내용이 패널보다 길면 **세로 스크롤**이 자동으로 나타납니다.

## 6. 이미지 내보내기

현재 화면에 표시 중인 이미지(선택된 DICOM 프레임 포함)를 다른 형식으로 저장할 수 있습니다.

### 툴바에서 내보내기

1. 파일을 연다.
2. 툴바에서 **PNG**, **JPEG**, **BMP**, **TIFF**, **GIF** 중 하나 클릭.
3. 저장 위치와 파일 이름을 지정한다.

### 컨텍스트 메뉴에서 내보내기

이미지 영역 **우클릭 → 내보내기 →** 원하는 형식 선택.

> 파일을 열기 전에는 내보내기 버튼과 메뉴가 비활성화됩니다.

| 메뉴 | 단축키 | 설명 |
|------|--------|------|
| **열기** | `Ctrl+O` | 새 파일 열기 |
| **화면에 맞춤** | — | 창에 맞게 크기 조정 |

## 9. .dcm 기본 프로그램 등록

탐색기에서 `.dcm` 파일을 DCMViewer로 바로 열려면 파일 연결을 등록합니다.

### 앱에서 등록

1. **파일 → DCM 기본 프로그램으로 등록** 선택
2. Windows 확인 대화상자가 나오면 **허용**
3. 등록 완료 메시지 확인

### 등록 해제

**파일 → DCM 연결 등록 해제** 선택 후 확인.

### 등록 후

- 탐색기에서 `.dcm` 파일 아이콘이 DCMViewer 형식 아이콘으로 표시됩니다.
- 더블 클릭으로 DCMViewer가 실행되며 해당 파일이 열립니다.

## 10. MSI 설치

Release 빌드로 생성된 MSI 설치 프로그램을 사용할 수 있습니다.

### 설치 단계

1. `DCMViewer.Installer.msi` 실행
2. 설치 경로 확인 (기본: `Program Files\DCMViewer`)
3. **사용자 정의** 단계에서 원하는 항목 선택

### 선택 가능한 항목 (기본값: 모두 선택)

| 항목 | 설명 |
|------|------|
| **시작 메뉴 바로 가기** | 시작 메뉴에 DCMViewer 링크 생성 |
| **바탕 화면 바로 가기** | 바탕 화면에 DCMViewer 링크 생성 |
| **.dcm 기본 프로그램 등록** | `.dcm` 연결 + 기본 프로그램 설정 시도 |

원하지 않는 항목의 **체크를 해제**하면 해당 기능은 설치되지 않습니다.

## 11. 문제 해결

### DICOM 파일이 열리지 않음

- 파일이 손상되었거나 DCMViewer가 지원하지 않는 형식일 수 있습니다.
- **JPEG / JPEG-LS / JPEG2000** 등 압축 DICOM은 **Visual C++ 재배포 패키지** 설치가 필요할 수 있습니다.
- 다른 DICOM 뷰어에서 파일이 정상인지 확인해 보세요.

### .dcm 아이콘이 바뀌지 않음

1. **파일 → DCM 연결 등록 해제**
2. **파일 → DCM 기본 프로그램으로 등록** 다시 실행
3. 탐색기 새로고침(`F5`) 또는 다시 로그인

### 확대/축소가 느림

- 매우 큰 DICOM(고해상도·대용량)은 확대·축소 시 처리 시간이 걸릴 수 있습니다.
- 휠 입력을 멈추면 잠시 후 고화질로 다시 렌더링됩니다.

### 내보내기 버튼이 비활성화됨

- 먼저 **파일 → 열기**로 이미지 또는 DICOM을 연 뒤 사용하세요.
