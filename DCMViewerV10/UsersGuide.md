# DCMViewer 사용자 가이드

DCMViewer는 Windows용 DICOM 및 일반 이미지 뷰어입니다. 의료용 DICOM 파일(`.dcm`)과 JPG, PNG, ICO 등 일반 이미지를 같은 화면에서 열어 보고, 폴더 탐색·확대·축소·내보내기·일괄 변환을 할 수 있습니다.

## 1. 시작하기

### 지원 형식

| 구분 | 확장자 | 비고 |
|------|--------|------|
| DICOM | `.dcm`, `.dicm` | 다중 프레임 지원 |
| 일반 이미지 | `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`, `.bmp`, `.tif`, `.tiff` | 내보내기 가능 |
| 아이콘 | `.ico` | **보기 전용** (내보내기 없음) |

### 실행 방법

- **설치 후**: 시작 메뉴 또는 바탕 화면의 DCMViewer 바로 가기 실행
- **개발/직접 실행**: `DCMViewer.exe` 실행
- **파일 연결 후**: 탐색기에서 `.dcm` 파일 더블 클릭
- **명령줄**: `DCMViewer.exe "경로\파일.dcm"`

### 권장 환경

- Windows 10 / 11 (64비트)
- .NET 8 Desktop Runtime (프레임워크 종속 배포 시)
- JPEG2000 등 일부 압축 DICOM: Visual C++ 재배포 패키지 필요할 수 있음

### 마지막 폴더 기억

- 프로그램은 마지막으로 사용한 작업 폴더를 `%LocalAppData%\DCMViewer\last_directory.txt`에 저장합니다.
- 시작 시 파일을 지정하지 않고 실행하면, 저장된 폴더(없으면 **내 사진**)를 좌측 트리에 표시합니다.

## 2. 화면 구성

```
┌─────────────────────────────────────────────────────────────┐
│  [파일]  [도움말]                                            │  ← 메뉴 바
├─────────────────────────────────────────────────────────────┤
│  내보내기: [PNG][JPEG][BMP][TIFF][GIF]  [일괄 변환]    [ℹ]  │  ← 툴바
├──────────────┬──────────────────────────────────────────────┤
│  폴더        │  [확대율 %]                                   │
│  ├ ..        │                                               │
│  ├ 하위폴더  │         이미지 뷰어 영역                       │
│  ├ file.dcm  │                                               │
│  └ file.png  │  ──────────── 프레임 슬라이더 ────────────    │
│  ─────────── │                                               │
│  파일 정보   │                                               │
│  (메타데이터)│                                               │
├──────────────┴──────────────────────────────────────────────┤
│  상태 표시줄 (파일 경로, 환자 정보, 검사 정보 등)              │
└─────────────────────────────────────────────────────────────┘
```

| 영역 | 설명 |
|------|------|
| **메뉴 바** | 파일 열기, 폴더 선택, 일괄 변환, DCM 연결 등록, 도움말 |
| **툴바** | 이미지 내보내기, 일괄 변환, 프로그램 정보(ℹ) |
| **폴더 트리** | 작업 폴더 탐색, 파일 한 번 클릭으로 미리보기 |
| **파일 정보** | DICOM 메타데이터 또는 일반 이미지 정보 |
| **이미지 뷰어** | 확대/축소·패닝 대상 영역 |
| **확대율 표시** | 좌측 상단, 초기 화면 맞춤 대비 현재 배율(%) |
| **프레임 슬라이더** | 다중 프레임 DICOM일 때만 표시 |
| **상태 표시줄** | 파일 경로, 환자/검사 요약, 프레임 번호 등 |

## 3. 파일 열기

### 메뉴에서 열기

1. **파일 → 열기** (`Ctrl+O`)
2. 파일 형식 필터 선택 후 파일 선택
3. **열기** 클릭

### 파일 열기 대화상자 필터

- **모든 지원 형식** — DICOM + 일반 이미지 + ICO
- **DICOM** — `.dcm`, `.dicm`
- **이미지** — JPG, PNG, GIF, WebP, BMP, TIFF, ICO
- **모든 파일** — `*.*`

### 연결된 파일로 열기

`.dcm` 파일을 DCMViewer와 연결해 두었다면 탐색기에서 더블 클릭만으로 열 수 있습니다.

### 오류 발생 시

파일을 열 수 없으면 **오류 상세** 대화상자가 표시됩니다. 메시지와 스택 추적을 확인·복사할 수 있습니다.

## 4. 폴더 탐색

좌측 상단 **폴더** 트리에서 DICOM·이미지 파일을 탐색할 수 있습니다.

### 작업 폴더 변경

| 방법 | 설명 |
|------|------|
| **파일 → 폴더 선택** | 표시할 루트 폴더를 직접 선택 |
| **하위 폴더 더블 클릭** | 해당 폴더로 이동 |
| **`..` 더블 클릭** | 상위 폴더로 이동 |
| **루트 폴더 더블 클릭** | 상위 폴더로 이동 |

### 파일 미리보기

| 동작 | 설명 |
|------|------|
| **파일 한 번 클릭** | DCM / 이미지 파일을 뷰어에 표시 |
| **파일 더블 클릭** | 한 번 클릭과 동일하게 열기 |

트리에는 지원 형식(DCM, 이미지)만 표시됩니다. 하위 폴더는 `+`를 펼칠 때 내용이 로드됩니다.

### 폴더 트리 컨텍스트 메뉴 (우클릭)

| 메뉴 | 단축키 | 설명 |
|------|--------|------|
| **열기** | — | 선택한 파일 열기 |
| **복사** | `Ctrl+C` | 파일/폴더 경로를 클립보드에 복사 |
| **붙여넣기** | `Ctrl+V` | 복사한 항목을 현재 폴더에 붙여넣기 |
| **삭제** | `Delete` | 휴지통으로 이동 |
| **폴더 선택** | — | 작업 폴더 변경 |
| **새로 고침** | — | 트리 다시 불러오기 |

## 5. 이미지 보기

### 처음 열었을 때

- 이미지는 **창 크기에 맞게** 자동으로 표시됩니다.
- 작은 이미지는 **화면 중앙**에 배치됩니다.

### 확대 / 축소

| 방법 | 동작 |
|------|------|
| **마우스 휠 위** | 확대 |
| **마우스 휠 아래** | 축소 |

- 휠 한 칸마다 약 **1.08배**씩 변경됩니다.
- 확대·축소 중에는 빠른 미리보기를 위해 화질이 잠시 낮아졌다가, 휠 입력이 멈추면 고화질로 다시 그려집니다.
- 이미지가 화면보다 클 때는 **화면 중심**을 기준으로 확대·축소됩니다.
- 좌측 상단에 **초기 맞춤 대비 배율(%)** 이 표시됩니다. (100% = 처음 맞춤 크기)

### 화면에 맞춤 / 실제 크기

이미지 영역에서 **우클릭 → 컨텍스트 메뉴** 사용:

| 메뉴 | 설명 |
|------|------|
| **화면에 맞춤** | 현재 창 크기에 맞게 다시 맞춤 |
| **실제 크기 (100%)** | 픽셀 1:1 크기로 표시 (원본 해상도) |

### 이미지 이동 (패닝)

- 이미지가 화면보다 **클 때만** 이동 가능합니다.
- **왼쪽 마우스 버튼**을 누른 채 드래그하면 이미지를 이동할 수 있습니다.

### 다중 프레임 DICOM

- CT, MRI 등 **여러 프레임**이 있는 DICOM은 이미지 아래 **슬라이더**가 나타납니다.
- 슬라이더를 움직여 프레임을 변경할 수 있습니다.
- 상태 표시줄과 파일 정보 패널에 현재 프레임 번호가 표시됩니다.

### ICO 파일

- `.ico` 파일은 **미리보기만** 지원합니다.
- ICO 파일을 연 상태에서는 **내보내기** 버튼과 메뉴가 비활성화됩니다.

## 6. 파일 정보 패널

좌측 하단 **파일 정보** 패널에는 열린 파일의 메타데이터가 표시됩니다.

### DICOM 파일

예시 항목:

- 환자명, 환자 ID, 생년월일, 성별
- Modality, 검사/시리즈 설명
- Study Date, Series Date
- Institution, Manufacturer
- 이미지 크기, Bits Allocated
- 프레임 번호 (다중 프레임인 경우)

값이 없는 항목은 표시되지 않습니다.

### 일반 이미지

- 파일 이름, 형식, 픽셀 크기

내용이 패널보다 길면 **세로 스크롤**이 자동으로 나타납니다.

## 7. 이미지 내보내기

현재 화면에 표시 중인 이미지(선택된 DICOM 프레임 포함)를 다른 형식으로 저장할 수 있습니다.

### 툴바에서 내보내기

1. 파일을 연다.
2. 툴바에서 **PNG**, **JPEG**, **BMP**, **TIFF**, **GIF** 중 하나 클릭.
3. 저장 위치와 파일 이름을 지정한다.

### 컨텍스트 메뉴에서 내보내기

이미지 영역 **우클릭 → 내보내기 →** 원하는 형식 선택.

> 파일을 열기 전, 또는 **ICO 파일**을 연 상태에서는 내보내기 버튼과 메뉴가 비활성화됩니다.

## 8. 폴더 일괄 변환

폴더 안의 모든 DCM 파일을 PNG, JPEG, BMP, TIFF, GIF 중 선택한 형식으로 한 번에 변환합니다.

### 사용 방법

**방법 1 — 툴바**

1. **일괄 변환** 버튼 클릭
2. 변환 형식 선택 (PNG / JPEG / BMP / TIFF / GIF)
3. DCM 파일이 있는 **소스 폴더** 선택

**방법 2 — 메뉴**

1. **파일 → 폴더 일괄 변환** → 원하는 형식 선택
2. 소스 폴더 선택

### 출력 위치

- 소스 폴더 아래 `converted_{확장자}` 폴더가 자동 생성됩니다.
  - 예: PNG → `converted_png`, JPEG → `converted_jpg`
- 같은 이름의 폴더가 이미 있으면 `converted_png_2`, `converted_png_3` … 순서로 생성됩니다.

### 다중 프레임 DICOM

- 프레임마다 별도 파일로 저장됩니다.
- 파일 이름 형식: `파일명_frame01.png`, `파일명_frame02.png`, …

### 완료 후

- 성공/실패 개수와 저장 위치를 알려주는 대화상자가 표시됩니다.
- 일부 파일 변환에 실패하면 **오류 상세** 대화상자에서 실패 목록을 확인할 수 있습니다.

## 11. .dcm 기본 프로그램 등록

탐색기에서 `.dcm` 파일을 DCMViewer로 바로 열려면 파일 연결을 등록합니다.

### 앱에서 등록

1. **파일 → DCM 기본 프로그램으로 등록** 선택
2. Windows 확인 대화상자가 나오면 **허용**
3. 등록 완료 메시지 확인

### 등록 해제

**파일 → DCM 연결 등록 해제** 선택 후 확인.

### 등록 후

- 탐색기에서 `.dcm` 파일 아이콘이 DCMViewer 형식 아이콘으로 표시됩니다.
- 더블 클릭으로 DCMViewer가 실행되며 해당 파일이 열립니다.

## 12. MSI 설치

Release 빌드로 생성된 MSI 설치 프로그램을 사용할 수 있습니다.

### 설치 단계

1. `DCMViewer.Installer.msi` 실행
2. 설치 경로 확인 (기본: `Program Files\DCMViewer`)
3. **사용자 정의** 단계에서 원하는 항목 선택

### 선택 가능한 항목 (기본값: 모두 선택)

| 항목 | 설명 |
|------|------|
| **시작 메뉴 바로 가기** | 시작 메뉴에 DCMViewer 링크 생성 |
| **바탕 화면 바로 가기** | 바탕 화면에 DCMViewer 링크 생성 |
| **.dcm 기본 프로그램 등록** | `.dcm` 연결 + 기본 프로그램 설정 시도 |

원하지 않는 항목의 **체크를 해제**하면 해당 기능은 설치되지 않습니다.

## 13. 문제 해결

### DICOM 파일이 열리지 않음

- 파일이 손상되었거나 DCMViewer가 지원하지 않는 형식일 수 있습니다.
- **JPEG / JPEG-LS / JPEG2000** 등 압축 DICOM은 **Visual C++ 재배포 패키지** 설치가 필요할 수 있습니다.
- 오류 상세 대화상자의 메시지를 확인하세요.
- 다른 DICOM 뷰어에서 파일이 정상인지 확인해 보세요.

### .dcm 아이콘이 바뀌지 않음

1. **파일 → DCM 연결 등록 해제**
2. **파일 → DCM 기본 프로그램으로 등록** 다시 실행
3. 탐색기 새로고침(`F5`) 또는 다시 로그인

### 확대/축소가 느림

- 매우 큰 DICOM(고해상도·대용량)은 확대·축소 시 처리 시간이 걸릴 수 있습니다.
- 휠 입력을 멈추면 잠시 후 고화질로 다시 렌더링됩니다.

### 내보내기 버튼이 비활성화됨

- 먼저 DICOM 또는 일반 이미지 파일을 연 뒤 사용하세요.
- **ICO 파일**은 보기 전용이므로 내보내기가 제공되지 않습니다.

### 빌드 시 exe 복사 오류

- DCMViewer가 실행 중이면 빌드가 실패할 수 있습니다. 앱을 종료한 뒤 다시 빌드하세요.
