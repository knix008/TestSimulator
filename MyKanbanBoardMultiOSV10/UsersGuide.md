# MyKanbanBoard 사용 설명서

MyKanbanBoard는 할 일을 **열**(예: 할 일 · 진행 중 · 완료)과 **카드**로 관리하는 칸반 보드 프로그램입니다. Windows, macOS, Linux 데스크톱 앱과 웹 브라우저에서 쓸 수 있습니다.

## 1. 설치

1. `MyKanbanBoard-Setup-1.0.0.exe`를 실행합니다.
2. 설치 언어(**한국어** / **English**)를 고릅니다.
3. 이전에 설치한 MyKanbanBoard가 있으면 자동으로 완전히 지운 뒤 다시 설치합니다.
4. 이전 버전이 저장한 데이터(설정, 최근 파일, 배경 이미지)가 있으면 **지울지 묻습니다.** 계속 쓰려면 "아니요"를 누르세요.

설치가 끝나면 `.mkanban`(보드) 파일과 `.mkproj`(프로젝트) 파일을 두 번 클릭해 바로 열 수 있습니다. 두 파일은 각자 전용 아이콘으로 표시됩니다.

## 2. 화면 구성

| 위치 | 이름 | 하는 일 |
|---|---|---|
| 맨 위 | 메뉴 막대 | 파일 · 편집 · 보기 · 보드 · 프로젝트 · 도움말 |
| 그 아래 | 툴바 | 자주 쓰는 기능. 버튼에 마우스를 올리면 설명(툴팁)이 나옵니다. 오른쪽 끝에 **설정**과 **프로그램 정보** |
| 툴바 아래 | 탭 | 열린 보드들. 탭이 많아 넘치면 오른쪽 끝의 `<` `>` 로 이동 |
| 왼쪽 | 도구 패널 | 프로젝트, 도구(카드·열·템플릿), 필터, 열 목록 |
| 가운데 | 보드 | 열과 카드 |
| 오른쪽 | 속성 패널 | 선택한 카드·열·보드의 속성을 보고 고침 |
| 맨 아래 | 상태 표시줄 | 저장 여부, 파일 위치, 열·카드 수, 선택 수, 확대 비율, 실행 취소 개수, 테마, 언어, 알림 |

좌우 패널은 머리글의 `<` / `>` 버튼으로 **접을 수 있습니다.** 접으면 아이콘과 이름이 있는 좁은 막대(레일)가 남고(맨 위가 펼치기 버튼), 속성 패널의 내용은 선택한 것(카드 / 여러 카드 / 열 / 보드)에 따라 자동으로 바뀝니다. 레일의 그 버튼(카드·열·템플릿·프로젝트·필터·열 목록 / 속성·보드)도 바로 쓸 수 있습니다.

툴바의 **검색 칸**(Ctrl + F)에 글자를 입력하면 그 글자가 들어 있는 카드만 보입니다(도구 패널의 검색과 같은 값). 창 **오른쪽 아래 모서리의 점 무늬**를 끌면 창 크기를 바꿀 수 있습니다.

툴바 오른쪽 끝에는 **테마 버튼**(누를 때마다 다음 테마로 바뀜)과 그 옆의 **▾**(테마 목록), **언어**, **설정**, **프로그램 정보**가 있습니다. 툴바의 확대 비율은 `[−] 100% [+]` 칸에서 바꾸거나 직접 입력합니다(두 번 클릭하면 100%).

## 3. 보드 다루기

### 열
- **추가**: 툴바의 열 추가 버튼, 도구 패널의 "열", 또는 열 머리를 오른쪽 클릭 → "왼쪽에 열 추가 / 오른쪽에 열 추가"
- **이름 바꾸기**: 열 제목을 두 번 클릭
- **삭제**: 열을 선택하고 Delete, 또는 열 메뉴 → "열 삭제" (카드가 있으면 확인을 묻습니다)
- **순서 바꾸기**: 열 머리를 끌어서 옮기기
- 속성 패널 또는 **열 설정 창**(열 메뉴 → "열 속성…")에서 열 색, **배경색**(파스텔 20색 또는 "사용자 정의 색"), **배경 불투명도**, **WIP 제한**(0 = 없음)을 정합니다. 제한을 넘으면 빨간색으로 표시됩니다. 배경색이 어두우면 열 글자는 자동으로 밝게 바뀝니다.

### 카드
- **추가**: 열 아래의 "+ 카드 추가", 열 머리의 `+`, 도구 패널의 "카드"·템플릿(작업·버그·기능·아이디어)을 클릭하거나 보드로 끌어다 놓기
- **고치기**: 카드를 클릭해 선택하면 오른쪽 속성 패널에서 제목, 설명, 색, 우선순위, 마감일, 담당자, 태그, 열, 체크리스트를 고칩니다. 카드를 **두 번 클릭**(또는 Enter)하면 **카드 설정 창**이 열립니다(일반 · 설명 · 체크리스트 · 첨부 파일 탭). 이 창으로 **이미지와 파일을 끌어다 놓으면 첨부**되고, "적용"을 누르면 한 번에 반영됩니다(실행 취소도 한 번).
- **설명 서식**: 설명 칸에서 글자를 **마우스로 선택**한 뒤 위의 도구로 글꼴, 크기(`[−] 14px [+]`), 굵기, **굵게**, *기울임*을 바꿉니다. 선택한 부분에만 적용되며, 지우개 버튼은 선택한 부분의 서식을 지웁니다.
- **마감일**: 칸 옆의 달력 버튼을 누르면 달력이 열립니다(이전/다음 달, 오늘, 지우기). `2026-10-15`처럼 직접 입력해도 되며, 없는 날짜는 받아들이지 않습니다.
- **옮기기**: 카드를 끌어 다른 위치·열로, 또는 Alt + ← / →
- **여러 개 선택**: Ctrl + 클릭, Ctrl + A(모든 카드)

### 첨부 파일과 이미지
- 카드를 선택하고 속성 패널의 **"파일 첨부…"** 를 누르거나, 파일을 **카드 위로 끌어다 놓으면** 첨부됩니다(파일당 최대 50 MB).
- 이미지는 카드에 **썸네일**로 보입니다. 썸네일을 클릭하면 **이미지 보기** 창에서 원본을 볼 수 있고 `<` `>`(또는 ← →)로 같은 카드의 다른 이미지로 넘어갑니다.
- 첨부 목록의 버튼: 이미지 보기 · 연결된 프로그램으로 열기 · 다른 이름으로 저장 · 첨부 삭제
- 첨부 파일은 보드(또는 프로젝트) 파일·DB에 함께 저장됩니다.

### 실행 취소와 클립보드
- 실행 취소 **Ctrl + Z**, 다시 실행 **Ctrl + Y**(또는 Ctrl + Shift + Z). 툴바 버튼의 툴팁에 무엇을 되돌리는지 나옵니다.
- 카드 복사 **Ctrl + C**, 잘라내기 **Ctrl + X**, 붙여넣기 **Ctrl + V**. 다른 프로그램에서 복사한 글은 **줄마다 카드 하나**로 붙여넣어집니다.

### 확대와 축소
**Ctrl + 마우스 휠**, 또는 Ctrl + = / Ctrl + - / Ctrl + 0(100%). 30%~300%.

### 오른쪽 클릭 메뉴
카드, 열, 보드 빈 곳, 탭, 입력 칸마다 **다른 메뉴**가 나옵니다. 메뉴 맨 위에 무엇에 대한 메뉴인지(예: "카드", "열: 할 일") 아이콘과 함께 표시되고, 모든 항목에 아이콘과 이름이 있습니다. 메뉴는 창 밖으로 나가도 전부 보입니다.

### 필터
도구 패널의 필터에서 제목·설명·태그·첨부 이름 검색, 우선순위, 색, 태그, "마감 지난 카드만"으로 걸러 봅니다(Ctrl + F).

## 4. 파일

| 동작 | 방법 |
|---|---|
| 새 보드 | Ctrl + N |
| 열기 | Ctrl + O (`.mkanban`, `.mkproj`, `.json`) — 마지막으로 연 폴더를 기억합니다 |
| 저장 / 다른 이름으로 | Ctrl + S / Ctrl + Shift + S |
| 최근 파일 | Ctrl + R — 최근 10개. 하나씩 지우거나 "모두 지우기" |
| 끌어다 놓기 | 보드 파일은 열기, 텍스트 파일(.txt .md .csv)은 놓은 열에 카드로, 이미지는 배경으로, 카드 위에 놓으면 첨부 |

큰 파일을 열거나 저장할 때 시간이 걸리면 **진행 상황 창**이 뜹니다. 문제가 생기면 **오류 창**에 자세한 내용이 나오며, "오류 내용 복사"로 복사해 문의할 때 붙여넣을 수 있습니다.

끝낼 때 저장하지 않은 보드나 프로젝트가 있으면 **저장 / 저장 안 함 / 취소**를 묻습니다. 메인 창을 닫으면 열려 있던 팝업 창도 함께 닫힙니다.

## 5. 프로젝트와 데이터베이스

**프로젝트**는 여러 보드를 한데 묶고, 어디에 저장할지(저장소)를 정한 것입니다. 프로젝트 파일 확장자는 `.mkproj`입니다.

1. 메뉴 **프로젝트 → 새 프로젝트…** (또는 툴바의 프로젝트 버튼)
2. **일반** 탭: 이름과 설명
3. **저장소** 탭에서 종류를 고릅니다.
   - **로컬 파일** — DB를 쓰지 않습니다. 보드와 첨부 파일이 `.mkproj` 파일 안에 저장됩니다. (DB 설정이 없을 때의 기본값)
   - **SQLite** — DB 파일 경로를 입력하거나 "찾아보기…"로 고릅니다. 상대 경로는 프로젝트 파일 폴더 기준입니다.
   - **MariaDB / MySQL / PostgreSQL** — 서버 주소, 포트, 데이터베이스 이름, 사용자, 비밀번호. 데이터베이스는 서버에 미리 만들어 두어야 하며, 필요한 테이블은 자동으로 만들어집니다.
4. **연결 테스트**로 접속을 확인하고 "만들기"를 누릅니다.
5. 지금 보드를 프로젝트에 넣으려면 **프로젝트 → 현재 보드를 프로젝트에 추가**. 프로젝트의 보드는 탭에 폴더 아이콘으로 표시되고, 도구 패널 맨 위의 프로젝트 목록에서 고를 수 있습니다.
6. **프로젝트 저장**(프로젝트 보드에서 Ctrl + S)을 하면 DB에 보드가 저장되고 `.mkproj`에는 접속 설정과 보드 목록이 저장됩니다.

비밀번호는 **"비밀번호를 프로젝트 파일에 저장"** 을 켰을 때만 파일에 남습니다. 끄면 프로젝트를 열 때마다 비밀번호를 묻습니다. 프로젝트 설정의 **보드** 탭에서 보드 순서를 바꾸거나 프로젝트에서 뺄 수 있습니다. 프로젝트 보드의 탭을 닫으면 그 보드는 프로젝트에서 빠집니다(닫기 전에 묻습니다).

웹 브라우저에서는 **로컬 파일** 저장소만 쓸 수 있습니다(DB는 데스크톱 앱).

## 6. 인쇄

툴바의 인쇄 버튼(최근 파일 버튼 오른쪽, Ctrl + P)을 누르면 **인쇄 미리보기** 창이 열립니다.

- **인쇄 범위**: 열린 보드 전체 / 현재 보드 / 사용자 지정(인쇄할 열 고르기, "선택한 카드만")
- **페이지 설정**: 용지(A4·A3·A5·Letter·Legal), 방향(세로·가로), 여백, 배율, 카드 설명·머리글·바닥글
- 아래의 `<` `>`로 쪽을 넘겨 보고 **인쇄**를 누르면 바로 인쇄 대화상자가 열립니다.

## 7. 설정

툴바 오른쪽 끝의 톱니바퀴(Ctrl + ,). 바꾼 설정은 바로 적용되고 다음에 실행할 때도 그대로입니다.

| 탭 | 내용 |
|---|---|
| 일반 | 언어(한국어/English), 시작할 때 지난 보드 다시 열기, 삭제 전 묻기, 상태 표시줄 시계, 패널 표시, 마지막으로 연 폴더 |
| 테마 | **다크 테마 20종** · **라이트 테마 20종** · **사용자 정의**(바탕·패널·글자·테두리·강조·열·카드·툴바 등 12가지 색과 어두운 테마 여부를 직접 정함, "현재 테마의 색 가져오기") · 시스템 설정 |
| 카드 글꼴 | 시스템에 설치된 모든 글꼴, 크기(`[−] 14px [+]`), 굵기, 스타일(보통/기울임), 미리보기 — **카드와 열의 표시 내용에만** 적용(메뉴·툴바·패널은 그대로) |
| 배경 | 보드 뒤 배경 이미지(크기 제한 없음), 이미지 불투명도, 맞춤(채우기·맞추기·바둑판·가운데·늘이기) |
| 보드 | 카드 간격, 카드에 설명·태그 표시, 새 보드의 열, 보드 확대 |
| 최근 파일 | 목록 보기, 하나씩 지우기, 모두 지우기 |
| 단축키 | 단축키 목록 |

툴바의 팔레트 버튼은 테마를, 국기 버튼은 언어를 바로 바꿉니다. 창 크기와 위치도 기억합니다. 창은 툴바 버튼이 가려지지 않는 폭보다 좁아지지 않습니다.

## 9. 프로그램 정보

## 10. 오류가 났을 때

문제가 생기면 오류 창이 뜹니다. 프로그램 내부의 **심각한 오류**도 같은 창에 위치·스레드·백트레이스와 기록 파일(crash.log) 경로까지 자세히 나오며, **"오류 내용 복사"** 로 그대로 복사해 문의에 붙여넣을 수 있습니다.
