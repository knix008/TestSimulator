# MyCAD 사용 안내서

## 1. 화면

- **제목 표시줄**: `MyCAD V1.0 — 도면 이름`.
- **메뉴**: 맨 왼쪽의 **집 버튼**(시작 페이지로) · 파일 · 편집 · 보기 · 그리기 · 수정 · 부품 · 3D 솔리드 · 도움말. 메뉴는 따로 뜨는 창이라 주 창 밖으로도 펼쳐지고, 머리글 없이 메뉴 항목만 나옵니다.
- **툴바**: 모든 버튼에 툴팁이 있습니다. 오른쪽 끝의 줄 버튼(`툴바 2줄로 보기`)을 누르면 두 줄이 되고, 둘째 줄에 FreeCAD 의 Part 툴바처럼 3D 도형 · 돌출 · 회전 · 불리언 · 단면 · 투상도 버튼이 모두 나옵니다. 한 줄일 때는 `3D ▾` 단추로 같은 메뉴를 엽니다.
- **왼쪽 패널**: 그리기 · 치수 · 수정 · 3D 솔리드 · 부품(6분류) · 레이어. **오른쪽 패널**: 선택한 객체의 속성 (숫자 칸에 `25.4*2` 같은 계산식 가능).
- **캔버스**: Ctrl+휠 확대/축소, 가운데 버튼 끌기 이동. 격자는 어느 배율에서도 굵은 칸 하나에 가는 칸 5×5 가 보이고, 십자선은 점선입니다. 눈금자는 `Ctrl+R`.
- **길이 단위**: 설정 › 일반 › **길이 단위** (mm · cm · m · in · ft). 도면은 항상 mm 로 저장되고, 속성 칸 · 눈금자(왼쪽 위 모서리에 단위) · 상태 표시줄 좌표 · 치수 문자 · 3D 좌표축 눈금이 고른 단위로 바뀝니다. 다른 단위를 붙여 입력하면 자동 변환됩니다: `1in`, `2.5cm`, `5'3"`, 좌표 `1in,20mm`.
- **축척 막대** (`Ctrl+Shift+B`, 툴바 버튼): 2D 캔버스 위에 막대 길이가 실제 몇 mm(또는 고른 단위)인지와 화면 축척(100% = 1:1)을 보여 줍니다. 막대를 끌면 옮겨지고, 시작선·끝선을 끌면 길이가 바뀌며, 두 번 클릭하면 딱 떨어지는 길이(1·2·5×10ⁿ)로 맞춰집니다. 3D 보기에서는 나오지 않습니다.
- **문제 패널** (`Ctrl+Shift+M`, 툴바 버튼, 보기 메뉴, 상태 표시줄의 오류·경고 수): 캔버스 아래에 도면에서 잘못된 곳을 보여 줍니다. 고칠 때마다 잠시 뒤 다시 검사합니다.
  - **오류**: 길이가 0인 객체, 넓이가 없는 닫힌 윤곽, 측정 길이가 0인 치수, 부품이 없는 불리언 · 윤곽이 없는 돌출 솔리드, 지나치게 큰 좌표(단위 · 축척 실수).
  - **경고**: 같은 자리에 겹친 똑같은 객체, 맞닿지 않은 끝점, 거의 닫힌 윤곽, 내용 없는 문자, 넓이 없는 해칭. "맞닿지 않음"의 기준 틈은 도면 크기의 1/10 000 (0.01–0.5 mm).
  - **참고**: 겹친 꼭짓점, 없는 레이어에 있는 객체.
  - 줄을 클릭하면 해당 객체가 선택되고 화면에 보입니다(틈은 크게 확대). 머리글의 오류 · 경고 · 참고 단추로 종류별로 거릅니다.

## 2. 2D 그리기

선(L) · 폴리선 · 사각형 · 원 · 호 · 타원 · 정다각형 · 문자 · 중심선, 치수(선형 · 정렬 · 반지름 · 지름 · 각도).
아래 명령 줄에 `10,20`(절대) · `@30,0`(상대) · `@50<30`(거리<각도) 를 입력할 수 있습니다. F3 스냅, F7 격자, F8 직교, F9 격자 스냅.

## 3. 부품 라이브러리

왼쪽 패널 › 부품 에서 분류 아이콘(체결 요소 · 핀·키·링 · 기어·풀리 · 베어링·축 · 스프링 · 형강)을 고르고 타일을 누르면 치수 창이 뜹니다.
호칭 크기(M3~M24), 종류(보통/얇은형/나일론 너트, 평/대형/스프링 와셔, 관통/카운터보어/카운터싱크/탭 구멍 …), 보기(위/옆/정면/단면)를 고르고 `배치` 후 도면을 클릭합니다. 타일을 도면으로 끌어다 놓으면 기본 치수로 바로 놓입니다.

## 4. 3D 솔리드 (FreeCAD Part 워크벤치)

| 하고 싶은 것 | 방법 |
| --- | --- |
| 도형 넣기 | 3D 솔리드 › 상자 · 원기둥 · 구 · 원뿔 · 토러스 · 튜브 · 쐐기 · 각기둥 · 타원체 · 나선. 창에서 치수와 위치(X·Y·Z)·회전(X·Y·Z)을 정하면 음영 미리보기와 부피가 보입니다. |
| 2D → 3D | 닫힌 윤곽(사각형, 원, 닫힌 폴리선, 부품 외형 …)을 선택하고 **돌출**(안쪽 윤곽은 구멍) · **회전**(축: Y축 · X축 · 왼쪽 모서리 · 아래 모서리) · **로프트**(윤곽 두 개를 차례로 선택) · **스윕**(선/폴리선 경로를 따라 원형 관) |
| 불리언 | 솔리드 두 개 이상을 선택 (처음 선택한 것이 기준) › 합치기 · 빼기 · 교차. 결과는 트리로 남아 **분해**하면 원래 솔리드로 돌아갑니다. |
| 단면 | 솔리드 선택(없으면 전체) › 단면 만들기 › 높이 Z → 단면 윤곽이 2D 폴리선으로 그려집니다. |
| 투상도 | 투상도 만들기 › 정면 · 평면 · 우측면 · 등각 선택 → 도면 오른쪽에 3각법으로 배치, 숨은선은 점선(숨은선 레이어). |
| 고치기 | 솔리드를 선택하고 오른쪽 패널에서 치수 · 위치 · 회전 · 배율을 바꾸거나 `솔리드 편집…`. 2D 의 이동 · 회전 · 대칭 · 크기 · 배열도 솔리드에 됩니다. |
| 3D 로 보기 | 툴바의 정육면체(`Ctrl+Shift+3`). 끌기 회전, 휠 확대, 시점(등각 · 위 · 정면 · 오른쪽), 해 모양을 끌어 조명 이동(해는 확대·축소해도 화면에서 같은 크기), 조명 켜기/끄기(끄면 해와 그림자가 사라지고 시점을 따라가는 기본 조명으로 고르게 비춥니다 — 3D 막대의 조명 버튼이나 `Ctrl+Shift+G` 로 다시 켭니다), 와이어프레임, `2D 판 보기`(닫힌 2D 윤곽을 두께만큼 판으로)를 켜고 끕니다. 조명(해)은 화면 표시용이라 도면 파일 · 인쇄 · PNG · STL/3MF/STEP/FCStd 등 어떤 출력에도 들어가지 않습니다. |

## 5. 파일

- **열기**(`Ctrl+O`): .mcad, **2D CAD: DXF(R12–2018, 바이너리, cp949 등 ANSI) · SVG · IGES · HP-GL(.plt) · Gerber(.gbr/.gtl…) · Excellon(.drl)**, **3D: .FCStd · .step/.stp · .stl · .obj · .ply · .off · .amf · .3mf**. 다른 형식은 새 탭으로 열리고, 저장하면 .mcad 이름을 묻습니다. 탐색기에서 끌어다 놓아도 됩니다(SVG 도 도면으로 열림).
- **2D CAD 도면 가져오기**: 위 2D 형식만 고르는 열기 창. 전체 목록은 도움말 › 프로그램 정보 › **지원 파일 형식** 탭.
- **3D 모델 가져오기**(`Ctrl+I`): 지금 도면에 솔리드를 더합니다.
- **내보내기**: DXF R12 · **DXF 2000** · SVG · **IGES** · **HP-GL/2** · PNG, 그리고 3D: STL(3D 프린팅 창) · 3MF · AMF · OBJ · PLY · OFF · STEP · **FreeCAD 문서(.FCStd)**.
  - FCStd 는 매개변수 그대로 (상자는 Part::Box, 돌출은 스케치 + Part::Extrusion, 불리언은 Part::Cut …) 저장되어 FreeCAD 에서 열고 수정할 수 있습니다. 모양이 비어 보이면 FreeCAD 에서 `재계산(Ctrl+R)`.
  - FreeCAD 에서 만든 FCStd 를 열면 상자 · 원기둥 · 구 · 원뿔 · 토러스 · 쐐기 · 각기둥 · 타원체 · 돌출 · 회전 · 로프트 · 나선/스윕 · 불리언 · 대칭 · 메시 · 스케치를 읽습니다. 읽지 못한 객체는 알림에 이름이 나옵니다.
- **인쇄**(`Ctrl+P`): 전체 · 현재 · 사용자 범위, 용지 · 방향 · 축척, 미리보기에서 바로 인쇄.

## 6. 시작 페이지 · 튜토리얼

- **시작 페이지**: 실행하면 열립니다. 메뉴 줄 맨 왼쪽의 **집 버튼**, 탭 줄의 집 탭, 보기 › 시작 페이지로 언제든 돌아옵니다. 뒤에는 맞물린 기어 두 개가 3D로 돌아갑니다(Windows 에서 '애니메이션 효과'를 끄면 시점은 멈추고 기어만 돕니다). 할 수 있는 일 11가지마다 튜토리얼 레슨과 샘플 버튼, 샘플 26개(썸네일, 클릭하면 새 탭), 최근 파일, 오늘의 팁. 설정 › 일반에서 시작할 때 보일지 고릅니다.
- **따라 하는 튜토리얼**(도움말 메뉴 · 시작 페이지): 16레슨 83단계. **보기**는 실제 화면을 커서와 강조 표시로 조작해 보여 주고(재생 · 속도 · 이전/다음), **직접 하기**는 할 일과 클릭할 곳을 표시하고 해내면 다음 단계로 넘어갑니다. 튜토리얼 패널은 **따로 뜨는 창**이라(주 창에 딸림) 주 창 밖 어디로든 머리글을 끌어 옮길 수 있고, `Esc` 나 × 로 닫습니다.
- **튜토리얼 문서**: [doc/Tutorial.md](doc/Tutorial.md) — 같은 레슨을 단계마다 그림과 함께(도움말 › 튜토리얼 문서는 HTML 판을 브라우저로 엽니다). 동영상: `MyCAD-Tutorial.mp4`.

## 7. 오류가 났을 때

- 모든 오류는 **오류 창**에 메시지 · 작업 · 시각 · 프로그램 정보 · 자세한 내용(스택)이 나오고 **오류 내용 복사** 버튼으로 통째로 복사됩니다. 팝업 창을 띄울 수 없는 경우에는 같은 내용이 주 창 안에 나옵니다.
- 프로그램 내부의 심각한 오류(백엔드 패닉)도 위치 · 스레드와 함께 오류 창에 나오고 `crash.log`(데이터 폴더)에 기록됩니다. 프로그램이 계속 실행될 수 없는 오류라면 끝나기 전에 Windows 메시지 상자로 내용을 보여 줍니다(`Ctrl+C` 로 복사).
- 강제 종료 · 전원 차단 · 충돌처럼 **아무 말 없이 끝난 경우**에도, 다음에 실행하면 "지난번 실행이 비정상적으로 끝났습니다" 오류 창이 그 실행의 `crash.log` 기록과 함께 나옵니다.
- 3D 좌표축의 숫자 · 축 이름은 확대해도 화면에서 같은 크기(100 %에서 13 px)로 보이고, 멀리서는 눈금 간격보다 커지지 않게 줄어듭니다.
- 3D 좌표축 눈금 숫자 크기는 설정 › 도면 › **3D 좌표축 눈금 숫자 크기**(40–250 %)에서 바꿉니다.

## 8. 기능표

도움말 › **기능표** (또는 왼쪽 패널 3D 솔리드 머리글의 기능표 아이콘). FreeCAD 의 기능과 하나씩 맞대어 보여 줍니다. 워크벤치별 탭에 각 기능이 `지원 · 부분 지원 · 미지원` 으로 나오고, 항목에 마우스를 올리면 그 기능을 하는 MyCAD 명령이 보입니다.
