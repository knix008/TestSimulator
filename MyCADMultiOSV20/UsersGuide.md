# MyCAD 사용 안내서

## 1. 화면

- **제목 표시줄**: `MyCAD V1.0 — 도면 이름`.
- **메뉴**: 맨 왼쪽의 **집 버튼**(시작 페이지로) · 파일 · 편집 · 보기 · 그리기 · 수정 · 부품 · 3D 솔리드 · 도움말. 메뉴는 따로 뜨는 창이라 주 창 밖으로도 펼쳐지고, 머리글 없이 메뉴 항목만 나옵니다.
- **툴바**: 모든 버튼에 툴팁이 있습니다. 오른쪽 끝의 줄 버튼(`툴바 2줄로 보기`)을 누르면 두 줄이 되고, 둘째 줄에 FreeCAD 의 Part 툴바처럼 3D 도형 · 돌출 · 회전 · 불리언 · 단면 · 투상도 버튼이 모두 나옵니다. 한 줄일 때는 `3D ▾` 단추로 같은 메뉴를 엽니다.
- **왼쪽 패널**: 그리기 · 치수 · 수정 · 3D 솔리드 · 부품(6분류) · 레이어. **오른쪽 패널**: 선택한 객체의 속성 (숫자 칸에 `25.4*2` 같은 계산식 가능).
- **캔버스**: Ctrl+휠 확대/축소, 가운데 버튼 끌기 이동. 격자는 어느 배율에서도 굵은 칸 하나에 가는 칸 5×5 가 보이고, 십자선은 점선입니다. 눈금자는 `Ctrl+R`.
- **길이 단위**: 설정 › 일반 › **길이 단위** (mm · cm · m · in · ft). 도면은 항상 mm 로 저장되고, 속성 칸 · 눈금자(왼쪽 위 모서리에 단위) · 상태 표시줄 좌표 · 치수 문자 · 3D 좌표축 눈금이 고른 단위로 바뀝니다. 다른 단위를 붙여 입력하면 자동 변환됩니다: `1in`, `2.5cm`, `5'3"`, 좌표 `1in,20mm`.
- **축척 막대** (`Ctrl+Shift+B`, 툴바 버튼): 2D 캔버스 위에 막대 길이가 실제 몇 mm(또는 고른 단위)인지와 화면 축척(100% = 1:1)을 보여 줍니다. 막대를 끌면 옮겨지고, 시작선·끝선을 끌면 길이가 바뀌며, 두 번 클릭하면 딱 떨어지는 길이(1·2·5×10ⁿ)로 맞춰집니다. 3D 보기에서는 나오지 않습니다.
- **문제 패널** (`Ctrl+Shift+M`, 툴바 버튼, 보기 메뉴, 상태 표시줄의 오류·경고 수): 캔버스 아래에 도면에서 잘못된 곳을 보여 줍니다. 고칠 때마다 잠시 뒤 다시 검사합니다.
  - **오류**: 길이가 0인 객체, 넓이가 없는 닫힌 윤곽, 측정 길이가 0인 치수, 부품이 없는 불리언 · 윤곽이 없는 돌출 솔리드, 지나치게 큰 좌표(단위 · 축척 실수).
  - **경고**: 같은 자리에 겹친 똑같은 객체, 맞닿지 않은 끝점, 거의 닫힌 윤곽, 내용 없는 문자, 넓이 없는 해칭. "맞닿지 않음"의 기준 틈은 도면 크기의 1/10 000 (0.01–0.5 mm).
  - **참고**: 겹친 꼭짓점, 없는 레이어에 있는 객체.
  - 줄을 클릭하면 해당 객체가 선택되고 화면에 보입니다(틈은 크게 확대). 머리글의 오류 · 경고 · 참고 단추로 종류별로 거릅니다.

## 2. 2D 그리기

선(L) · 폴리선 · 사각형 · 원 · 호 · 타원 · 정다각형 · 문자 · 중심선, 치수(선형 · 정렬 · 반지름 · 지름 · 각도).
아래 명령 줄에 `10,20`(절대) · `@30,0`(상대) · `@50<30`(거리<각도) 를 입력할 수 있습니다. F3 스냅, F7 격자, F8 직교, F9 격자 스냅.

## 3. 부품 라이브러리

왼쪽 패널 › 부품 에서 분류 아이콘(체결 요소 · 핀·키·링 · 기어·풀리 · 베어링·축 · 스프링 · 형강)을 고르고 타일을 누르면 치수 창이 뜹니다.
호칭 크기(M3~M24), 종류(보통/얇은형/나일론 너트, 평/대형/스프링 와셔, 관통/카운터보어/카운터싱크/탭 구멍 …), 보기(위/옆/정면/단면)를 고르고 `배치` 후 도면을 클릭합니다. 타일을 도면으로 끌어다 놓으면 기본 치수로 바로 놓입니다.

## 4. 3D 솔리드 (FreeCAD Part 워크벤치)

| 하고 싶은 것 | 방법 |
| --- | --- |
| 도형 넣기 | 3D 솔리드 › 상자 · 원기둥 · 구 · 원뿔 · 토러스 · 튜브 · 쐐기 · 각기둥 · 타원체 · 나선. 창에서 치수와 위치(X·Y·Z)·회전(X·Y·Z)을 정하면 음영 미리보기와 부피가 보입니다. |
| 2D → 3D | 닫힌 윤곽(사각형, 원, 닫힌 폴리선, 부품 외형 …)을 선택하고 **돌출**(안쪽 윤곽은 구멍, **구배 각도** + 는 위로 좁아짐 — FreeCAD 의 TaperAngle 과 같게 구멍도 좁아짐) · **회전**(축: Y축 · X축 · 왼쪽 모서리 · 아래 모서리) · **로프트**(윤곽 둘 이상을 차례로 선택 — 아래에서 위로 고르게 놓임, 면: 직선 · 매끄럽게) · **스윕**(선/폴리선 경로를 따라 원형 관; 닫힌 윤곽을 함께 고르면 그 단면으로) |
| 포켓 · 그루브 · 구멍 | 2D 윤곽과 솔리드 하나를 함께 선택 › **포켓**(솔리드 윗면에서 깊이만큼 또는 관통) · **그루브**(윤곽을 돌린 모양을 빼기) · **구멍**(원마다: 지름(원에서) · 깊이 · 단순/자리파기/접시머리 · 평평/드릴 끝 118°). 결과는 빼기 트리라 분해하면 원래대로. |
| 메시 단순화 | 솔리드 선택 › **메시 단순화**: 모양은 거의 그대로, 삼각형을 절반쯤으로(닫힌 메시 유지). |
| 불리언 | 솔리드 두 개 이상을 선택 (처음 선택한 것이 기준) › 합치기 · 빼기 · 교차. 결과는 트리로 남아 **분해**하면 원래 솔리드로 돌아갑니다. |
| 모깎기 · 모따기 · 두께 · 오프셋 | 상자 · 돌출 · 각기둥 · 원기둥(360°) · 튜브 솔리드 하나를 선택 › 3D 솔리드 › **모깎기 (3D)** · **모따기 (3D)** (크기 + 모서리: 모두 · 윗면 둘레 · 세로 · 윗면+세로 · 밑면 둘레), **두께**(속을 비우고 윗면을 엶), **3D 오프셋**(+ 키우기, − 줄이기). 원래 솔리드 자리에 들어가고 **분해**하면 원래 솔리드로 돌아갑니다. |
| 형강 · 계단 · 난간 · 통심선 · 배관 | **기둥 · 보**: 단면(사각 · 원 · H · ㄷ · ㄱ · T · 각관 · 원형관), **규격 단면** 목록(IPE · HEA · HEB · UPN · L · T · RHS · SHS · CHS)을 고르면 치수가 그대로; 꺾인 보는 이등분 면에서 맞물림. **계단** 모양: 일자 · ㄱ자 · ㄷ자(참) · 나선. **난간** 채움: 난간대만 · 난간 살(120 이하 간격) · 유리. **통심선** 배치: 격자 · 방사형(각도 간격, 원형 줄). **배관** 굽힘 반지름(엘보), 종류: 배관 · 전선 · 사각 덕트. |
| 모양 철근 · 물량표 CSV · 패널 재단 | 구조체 없이 선 · 폴리선을 선택하고 **철근**: 그 모양대로 굽힌 철근(개수 · 간격). 건축 메뉴 › **물량표를 CSV 로**: 객체마다 한 줄(이름 · 종류 · 층 · 재료 · 개수 · 길이 · 면적 · 부피), Excel 에서 한글 그대로. **패널 재단**: 선택한 패널(또는 닫힌 윤곽)을 2440 × 1220 판에 배치해 도면 오른쪽 재단 레이어에 그리고 판마다 사용률. |
| 형상 검사 · 메시 수리 | 3D 솔리드 › **형상 검사**: 선택한 솔리드(없으면 전체)마다 닫혔는지, 열린 · 비다양체 모서리, 방향이 어긋난 곳, 안팎이 뒤집힌 껍질, 자기 교차, 퇴화 · 중복 삼각형을 보여 줍니다. 고칠 수 있는 솔리드에 체크하고 **수리**하면(또는 **메시 수리** 명령) 틈(T 접점)을 잇고 구멍을 메우고 방향을 맞춘 메시 솔리드가 됩니다. BIM 객체는 블록마다 따로 검사합니다. |
| 풍선 · 기하 공차 · 데이텀 | 치수 · 측정 › **풍선**(가리킬 부품 → 풍선 자리; 번호가 1, 2, 3 … 저절로), **기하 공차**(공차를 줄 면 → 틀 자리; 속성에서 기호 14종 · 공차 값 · ⌀ · Ⓜ/Ⓛ · 데이텀 A\|B\|C), **데이텀**(데이텀 면 → 문자 상자; A, B, C … 저절로). 지시선의 속성 **종류**로 메모 · 풍선 · 기하 공차 · 데이텀을 서로 바꿀 수 있습니다. DXF · SVG · 인쇄에 그대로 나옵니다. |
| 보조선 | 객체 선택 › 스케치 구속 칸의 **보조선**(또는 속성의 체크): 파란 점선이 되고, 스냅 · 구속에는 쓰이지만 돌출 · 포켓 · CAM · FEM · 내보내기 · 인쇄에서는 빠집니다. |
| 스케치 구속 | 왼쪽 **스케치 구속** 칸(또는 수정 메뉴): 선 · 원 · 호 · 점을 선택(두 개는 차례로)하고 **일치 · 수평 · 수직 · 평행 · 직각 · 같게 · 접선 · 동심 · 점을 선 위에 · 대칭(점 둘 + 셋째로 고른 선) · 고정 · 거리 · 가로 거리 · 세로 거리(부호 있음) · 반지름 · 지름 · 각도**를 누르면 풀이기가 도형을 맞춥니다. 도면 위에 보라(기하) · 빨강(치수) 표시가 붙고, 객체 속성의 **구속 조건** 목록에서 치수 값을 고치거나 지웁니다. 상태: 자유도 n · 완전 구속 · 중복 구속 · 충돌. 끝점을 끌거나 객체를 고치면 그 객체는 그대로, 나머지가 따라옵니다. |
| FEM 골조 해석 | 골조를 선(또는 폴리선)으로 입면에 그리고(끝이 만나는 곳이 절점) 3D 솔리드 › **FEM — 골조 해석**. 재료(강재 · 알루미늄 · 목재 · 콘크리트 · 직접), 단면(사각 · 원 · 관 · I 형 · A·I), 보에 걸리는 등분포 하중(N/mm), 자중, 절점마다 지지(자유 · 핀 · 고정 · 롤러)와 하중 Fx · Fy(N) · M(N·m)을 정하면 오른쪽에 변형 모양(빨간 점선)과 휨 모멘트도(파랑)가, 아래에 최대 변위 · 모멘트 · 응력 · 항복 대비가 바로 나옵니다. **결과 그리기**는 FEM 레이어에 그림과 요약을 넣고(다시 하면 바뀜), **설정 저장**은 조건만 도면에 둡니다. 선형 정적 · 2D 보 요소(직접 강성법)입니다. |
| 스크립트 콘솔 · 매크로 | 보기 › **스크립트 콘솔**(`Ctrl+Shift+J`). 오른쪽에 JavaScript 를 쓰고 **실행**(`Ctrl+Enter`, 기록은 `Ctrl+↑/↓`). `cad` 객체: `line(x1,y1,x2,y2)` · `circle(cx,cy,r)` · `arc` · `rect` · `polyline([[x,y]…], closed)` · `point` · `text` · `solid(kind, params, place)` · `add(type, data)` · `update(id, patch)` · `remove(ids)` · `move/copy/rotate/scale` · `constrain(type, refs, value)` · `entities(type)` · `get(id)` · `measure(id)` · `select(ids)` · `run(명령)` · `commands()` · `print(…)`. 고친 것마다 실행 취소 한 단계. **매크로 기록**을 누르고 그리거나 명령을 실행한 뒤 멈추면 `cad.*` 줄이 편집기에 들어오고, 이름을 붙여 **매크로로 저장** → 목록에서 실행 · 불러오기 · 지우기(설정에 보관). |
| CAM (G 코드) | 2D 윤곽을 선택(없으면 보이는 것 전부) › 파일 › **CAM — G 코드 만들기**. 가공: **윤곽**(바깥/안쪽, 구멍은 늘 안에서), **포켓**(지그재그 + 마무리 윤곽, 섬은 남김), **드릴**(원의 중심에 G83 펙/G81), **각인**(선 그대로). 공구 지름 · 깊이 · 한 번 깊이 · 겹침 · 이송/내려가는 속도 · 주축 회전 · 안전 높이 · 하향 절삭을 정하면 오른쪽에 경로(파랑)와 빠른 이동(점선)이 보이고 아래에 절삭 길이와 예상 시간이 나옵니다. **G 코드 저장** → .nc (mm, G21 G90; LinuxCNC · GRBL). |
| 클론 | 객체를 선택 › 수정 › **클론**: 원본을 따라 모양이 바뀌는 복사본(FreeCAD Draft Clone). 클론은 이동 · 회전 · 크기 · 대칭만 따로 갖고(속성에 보임), 색 · 레이어도 따로 정할 수 있습니다. 속성의 **원본 선택**, **독립시키기**(보통 객체로). 원본을 지우면 클론은 그 자리에 보통 객체로 남습니다. |
| 작업 평면 | 수정 › **작업 평면**: 원점 → X 축이 향할 점. 그 뒤 명령칸 좌표(`10,0`, `@30,0`, `@50<30`) · 격자 · 격자 스냅 · 직교 · 상태 표시줄 좌표가 이 평면 기준입니다. 아무것도 선택하지 않은 속성 패널에서 원점 · 각도 · **높이 Z**(새 솔리드와 돌출이 이 높이에 놓임)를 고치거나 **전체 좌표로** 되돌립니다. |
| 2D 자르기 · 연장 · 모깎기 · 모따기 | 수정 › **자르기**(X, 다른 선과 만나는 곳까지 누른 부분을 잘라 냄) · **연장**(W, 끝 가까이 눌러 다음 선까지) · **모깎기**(J) · **모따기**(K): 남길 쪽의 두 선을 차례로 누르거나 폴리선 · 사각형의 모서리 하나를 누릅니다. 반지름/거리는 명령칸에 입력. |
| 단면 | 솔리드 선택(없으면 전체) › 단면 만들기 › 높이 Z → 단면 윤곽이 2D 폴리선으로 그려집니다. |
| 투상도 | 투상도 만들기 › 정면 · 평면 · 우측면 · 등각 선택 → 도면 오른쪽에 3각법으로 배치, 숨은선은 점선(숨은선 레이어). |
| 고치기 | 솔리드를 선택하고 오른쪽 패널에서 치수 · 위치 · 회전 · 배율을 바꾸거나 `솔리드 편집…`. 2D 의 이동 · 회전 · 대칭 · 크기 · 배열도 솔리드에 됩니다. |
| 3D 로 보기 | 툴바의 정육면체(`Ctrl+Shift+3`). 끌기 회전, 휠 확대, 시점(등각 · 위 · 정면 · 오른쪽), 해 모양을 끌어 조명 이동(해는 확대·축소해도 화면에서 같은 크기), 조명 켜기/끄기(끄면 해와 그림자가 사라지고 시점을 따라가는 기본 조명으로 고르게 비춥니다 — 3D 막대의 조명 버튼이나 `Ctrl+Shift+G` 로 다시 켭니다), 와이어프레임, `2D 판 보기`(닫힌 2D 윤곽을 두께만큼 판으로)를 켜고 끕니다. 조명(해)은 화면 표시용이라 도면 파일 · 인쇄 · PNG · STL/3MF/STEP/FCStd 등 어떤 출력에도 들어가지 않습니다. |

## 4-1. 건축 (BIM)

FreeCAD BIM 워크벤치처럼 건물을 **3D 객체**로 만들고, 2D 화면에서는 그 모델을 바닥에서 1 m 높이로 자른 **평면도**로 봅니다. 같은 도면에서 3D 보기(Ctrl+Shift+3)를 누르면 입체로 보입니다.

- **벽**: 선 · 폴리선 · 사각형을 그려 선택하고 *건축 (BIM) › 벽* — 선마다 벽 하나 (닫힌 윤곽은 모서리가 맞춰진 고리 벽). 두께 · 높이 · 정렬(가운데/왼쪽/오른쪽).
- **창 · 문**: 벽을 선택하고 *창 넣기* / *문 넣기* — 편집 창의 *창·문·개구부* 에서 칩을 눌러 고르고 종류(창 · 문 · 양개문 · 미닫이 · 개구부) · 시작 위치 · 폭 · 창대 높이 · 높이 · 여는 쪽 · 경첩을 바꿉니다. 벽이 그만큼 뚫리고 창틀 · 유리 · 문짝이 들어갑니다.
- **슬래브 · 지붕 · 공간**: 닫힌 윤곽을 선택하고 실행. 지붕은 박공 · 모임 · 외쪽 · 평지붕, 경사 · 처마 길이 · 두께. 공간은 이름(속성 패널)과 바닥 면적이 평면도에 표시됩니다.
- **커튼월 · 보 · 난간**: 선을 선택하고 실행. **기둥 · 계단 · 가구·설비 · 통심선**: 바로 넣기 창.
- **물량표**: 벽 길이 · 면적 · 체적, 창 · 문 개수, 슬래브 · 지붕 면적, 실별 면적을 도면 오른쪽에 문자 표로.
- **IFC**: *3D 내보내기 › IFC 4* 로 IfcWall · IfcWindow · IfcDoor · IfcSlab · IfcSpace … (개구부 · 물량 포함). MyCAD 가 만든 IFC 는 다시 열면 매개변수 객체 그대로, 다른 프로그램의 IFC 는 이름 붙은 메시로 열립니다.
- **층**: 건축 객체를 처음 만들면 *대지 › 건물 › 1층* 이 생깁니다. 왼쪽 패널 **건물 (BIM)** 에서 층 추가, 새 객체를 놓을 층(✓), 평면도에 보일 층(도면 아이콘), 층 보이기(눈)를 정합니다. *건물·층·재료…* 창에서 층 이름 · 표고 · 층고를 바꾸면 그 층의 객체가 함께 움직입니다. 3D 보기에는 모든 층이 보입니다.
- **재료**: 같은 창의 *재료* 탭에서 색과 해칭을 정하고, 속성 패널에서 객체의 재료를 고릅니다. 벽 편집 창의 *재료 층* 탭에서 바깥→안 순서로 층(벽돌 · 단열재 · 콘크리트 · 석고보드 …)을 쌓으면 다층 벽이 됩니다 (두께 = 층의 합, 평면은 층마다 해칭).
- **지붕**: 아무 닫힌 윤곽 위에 모임 지붕이 얹힙니다. 지붕 편집 창의 *변별 경사* 탭에서 변마다 경사를 주고, 90° 로 하면 박공이 됩니다.
- **창**: 창은 세로 칸 × 가로 칸으로 나눕니다. 2D 로 창 모양(가장 큰 윤곽 = 창틀, 안쪽 윤곽 = 유리)을 그리고 벽과 함께 선택해 *스케치로 창 만들기* 를 누르면 그 모양의 창이 됩니다.
- **철근 · 트러스 · 패널 · 배관**: 기둥 · 보 · 슬래브를 선택하고 *철근 넣기* (주근 · 띠철근 · 2방향 배근, 무게는 물량표에), 선을 선택하고 *트러스* / *배관*, 닫힌 윤곽을 선택하고 *패널* (물결 길이를 주면 골판).
- 축척 1:100 도면에서는 점선 · 선 굵기가 종이 기준으로 커집니다 (도면 › 축척).

3D 축 눈금은 크기에 맞는 단위로(건물은 m, 부품은 mm) 짧게 쓰고, 축 이름에 단위를 붙입니다. 2D 커서의 점선 십자선 색과 굵기는 설정 › 도면에서 바꿉니다 (기본 빨강, 1 px).

3D 보기 막대의 **스타일** 단추(보기 메뉴에도 있음)로 기본 · 음영 · 조명 없음 · 점토 · 숨은선 제거 · X-Ray · 스케치 · 와이어프레임 · 메시 · 점 중에서 고릅니다. 고른 스타일은 다음에도 유지됩니다.

## 5. 파일

- **열기**(`Ctrl+O`): .mcad, **2D CAD: DXF(R12–2018, 바이너리, cp949 등 ANSI) · SVG · IGES · HP-GL(.plt) · Gerber(.gbr/.gtl…) · Excellon(.drl)**, **3D: .FCStd · .step/.stp · .stl · .obj · .ply · .off · .amf · .3mf**. 다른 형식은 새 탭으로 열리고, 저장하면 .mcad 이름을 묻습니다. 탐색기에서 끌어다 놓아도 됩니다(SVG 도 도면으로 열림).
- **2D CAD 도면 가져오기**: 위 2D 형식만 고르는 열기 창. 전체 목록은 도움말 › 프로그램 정보 › **지원 파일 형식** 탭.
- **3D 모델 가져오기**(`Ctrl+I`): 지금 도면에 솔리드를 더합니다.
- **내보내기**: DXF R12 · **DXF 2000** · SVG · **IGES** · **HP-GL/2** · PNG, 그리고 3D: STL(3D 프린팅 창) · 3MF · AMF · OBJ · PLY · OFF · **VRML 2.0(.wrl)** · **COLLADA(.dae)** · STEP · **BREP(.brep, OpenCASCADE)** · **OpenSCAD(.scad/.csg)** · **FreeCAD 문서(.FCStd)**. BREP 은 면마다 평면으로 닫힌 솔리드(FreeCAD 가 그대로 읽음)를 쓰고, 읽을 때는 평면 · 원기둥 · 원뿔 · 구 · 토러스 면을 받아 틈을 메웁니다. OpenSCAD 는 상자 · 원기둥 · 구 · 돌출 · 회전 · 불리언을 그 명령 그대로 쓰고(FreeCAD 의 OpenSCAD 워크벤치가 .csg 로 열면 매개변수 객체), 읽을 때는 변수 · for · if · 2D 도형의 돌출 · 변환 · 불리언을 해석합니다(사용자 module 은 아직 못 읽음). VRML · DAE 는 색을 담고, 읽을 때 변환(Transform/node) · 단위 · 위쪽 축(Y_UP)을 맞춥니다.
  - FCStd 는 매개변수 그대로 (상자는 Part::Box, 돌출은 스케치 + Part::Extrusion, 불리언은 Part::Cut …) 저장되어 FreeCAD 에서 열고 수정할 수 있습니다. 모양이 비어 보이면 FreeCAD 에서 `재계산(Ctrl+R)`.
  - FreeCAD 에서 만든 FCStd 를 열면 상자 · 원기둥 · 구 · 원뿔 · 토러스 · 쐐기 · 각기둥 · 타원체 · 돌출 · 회전 · 로프트 · 나선/스윕 · 불리언 · 대칭 · 메시 · 스케치를 읽습니다. 읽지 못한 객체는 알림에 이름이 나옵니다.
- **인쇄**(`Ctrl+P`): 전체 · 현재 · 사용자 범위, 용지 · 방향 · 축척, 미리보기에서 바로 인쇄.

## 6. 시작 페이지 · 튜토리얼

- **시작 페이지**: 실행하면 열립니다. 메뉴 줄 맨 왼쪽의 **집 버튼**, 탭 줄의 집 탭, 보기 › 시작 페이지로 언제든 돌아옵니다. 뒤에는 맞물린 기어 두 개가 3D로 돌아갑니다(Windows 에서 '애니메이션 효과'를 끄면 시점은 멈추고 기어만 돕니다). 할 수 있는 일 11가지마다 튜토리얼 레슨과 샘플 버튼, 샘플 26개(썸네일, 클릭하면 새 탭), 최근 파일, 오늘의 팁. 설정 › 일반에서 시작할 때 보일지 고릅니다.
- **따라 하는 튜토리얼**(도움말 메뉴 · 시작 페이지): 16레슨 83단계. **보기**는 실제 화면을 커서와 강조 표시로 조작해 보여 주고(재생 · 속도 · 이전/다음), **직접 하기**는 할 일과 클릭할 곳을 표시하고 해내면 다음 단계로 넘어갑니다. 튜토리얼 패널은 **따로 뜨는 창**이라(주 창에 딸림) 주 창 밖 어디로든 머리글을 끌어 옮길 수 있고, `Esc` 나 × 로 닫습니다.
- **튜토리얼 문서**: [doc/Tutorial.md](doc/Tutorial.md) — 같은 레슨을 단계마다 그림과 함께(도움말 › 튜토리얼 문서는 HTML 판을 브라우저로 엽니다). 동영상: `MyCAD-Tutorial.mp4`.

## 7. 오류가 났을 때

- 모든 오류는 **오류 창**에 메시지 · 작업 · 시각 · 프로그램 정보 · 자세한 내용(스택)이 나오고 **오류 내용 복사** 버튼으로 통째로 복사됩니다. 팝업 창을 띄울 수 없는 경우에는 같은 내용이 주 창 안에 나옵니다.
- 프로그램 내부의 심각한 오류(백엔드 패닉)도 위치 · 스레드와 함께 오류 창에 나오고 `crash.log`(데이터 폴더)에 기록됩니다. 프로그램이 계속 실행될 수 없는 오류라면 끝나기 전에 Windows 메시지 상자로 내용을 보여 줍니다(`Ctrl+C` 로 복사).
- 강제 종료 · 전원 차단 · 충돌처럼 **아무 말 없이 끝난 경우**에도, 다음에 실행하면 "지난번 실행이 비정상적으로 끝났습니다" 오류 창이 그 실행의 `crash.log` 기록과 함께 나옵니다.
- 3D 좌표축의 숫자 · 축 이름은 확대해도 화면에서 같은 크기(100 %에서 13 px)로 보이고, 멀리서는 눈금 간격보다 커지지 않게 줄어듭니다.
- 3D 좌표축 눈금 숫자 크기는 설정 › 도면 › **3D 좌표축 눈금 숫자 크기**(40–250 %)에서 바꿉니다.
