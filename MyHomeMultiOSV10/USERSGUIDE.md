# User's Guide / 사용자 가이드

**MyHomeMaker** v1.0.0 — 블록을 끌어다 놓아 홈페이지를 만드는 그래픽 웹사이트 제작 도구  
Author / 저작자: **SHKWON** (`knix008@naver.com`)

이 문서는 설치·실행과 주요 기능을 한 번에 훑어보는 안내서입니다. 그림이 있는 자세한 사용 설명서는 프로그램의 **도움말 › 사용 설명서**(또는 [doc/UsersGuide.md](doc/UsersGuide.md) · [English](doc/UsersGuide.en.md))에, 따라 하는 튜토리얼은 **도움말 › 튜토리얼**(F11)과 [doc/Tutorial.md](doc/Tutorial.md)에 있습니다. 내부 구조는 [ARCHITECTURE.md](ARCHITECTURE.md)를 보세요.

This guide covers installing, running and the main features in one place. The full illustrated manual is in the app (**Help › User's guide**, or [doc/UsersGuide.en.md](doc/UsersGuide.en.md)); the hands-on tutorial is **Help › Tutorial** (F11).

## 1. 설치와 실행 / Installation

### 설치 파일 (사용자)

| 운영 체제 | 파일 |
|---|---|
| Windows | `MyHomeMaker-Setup-<버전>.exe` — 설치 언어(한국어·English)를 고르고 설치합니다. |
| macOS | `MyHomeMaker-<버전>-<arch>.dmg` |
| Linux | `.deb` · `.rpm` · `.AppImage` |
| 웹 | `MyHomeMaker-Web-<버전>.zip` — 웹 서버에 풀어 올리면 브라우저에서 씁니다. |

- 설치는 하나만 있을 수 있습니다. 이미 설치되어 있으면 완전히 지우고 다시 설치할지 묻고, 이전 사용자 데이터(설정·최근 기록 등)를 지울지 따로 묻습니다. 남기면 다음 실행 때 환경 설정만 기본값으로 돌아가고 내 사전·내 테마·최근 기록은 그대로입니다.
- 프로그램은 여러 개 동시에 실행할 수 있습니다. 한 창에는 사이트가 하나씩 열립니다.

### 개발자 / Developers

```bash
npm install
npm start              # 데스크톱 앱 (tauri dev, http://localhost:1460)
npm run dev            # 웹 버전만 (Vite)
npm test               # 단위 · Rust · 웹 · 데스크톱 검사
npm test -- --quick    # 단위 · Rust 만
npm run build:win      # 설치 파일 (build:mac / build:linux / build:webapp / build:all)
```

설치 파일은 `release/` 와 프로젝트 루트에 복사됩니다. 그 밖의 명령은 [README.md](README.md)에 있습니다.

## 2. 화면 / The window

```
┌ 아이콘 · MyHomeMaker v1.0.0 │ 시작 │ 파일 편집 삽입 페이지 보기 디자인 도구 도움말 │ 사이트 이름 ● ─ □ × ┐
├ 툴바(아이콘) ─────────────────────────────────────────────────────────────────────────────┤
│ 블록 패널            │ 페이지 탭                               < > │ 사이트 패널                │
│  · 블록 묶음 5개      │ 캔버스 (데스크톱 · 태블릿 · 휴대폰 너비)    │  · 머리글 · 페이지 · 블록 목록 │
│  · 사이트 디자인 카드  │                                           │  · 내용 · 스타일 · 페이지 · 사이트 │
│                      ├─ 문제점 패널 (Ctrl+J) ─────────────────────┤                            │
└ 상태 표시줄 ──────────────────────────────────────────────────────────────────────────────┘
```

- **메뉴 막대 줄**이 제목 표시줄입니다. 빈 곳을 끌어 창을 옮기고, 두 번 눌러 최대화합니다. 사이트 이름 옆 ● 는 저장하지 않은 변경입니다.
- **툴바**는 아이콘만 보이고, 마우스를 올리면 이름과 단축키가 나옵니다. 저장 오른쪽에 **인쇄**와 **미리 보기**(브라우저로 홈페이지 보기, F5)가 있습니다.
- **좌우 패널**은 접으면 이름이 세로로 적힌 얇은 띠가 되고, 띠를 누르면 다시 펼쳐집니다. 시작 화면에서는 패널이 보이지 않습니다.
- **페이지 탭**이 많으면 오른쪽 **< >** 로 넘깁니다.

## 3. 사이트 만들기 / Making a site

1. **시작 화면** 또는 **파일 › 새로 만들기**(Ctrl+N)에서 빈 사이트, 템플릿 12가지, 예제 40가지 중 하나로 시작합니다. 처음 실행하면 튜토리얼을 권하는 창이 시작 화면에 뜹니다.
2. 왼쪽 **블록 패널**의 블록을 누르거나 끌어 페이지에 넣습니다(블록 35가지 + 머리글·바닥글).
3. 캔버스에서 블록을 눌러 고르고, 글을 한 번 더 누르면 그 자리에서 고칩니다. 오른쪽 **내용 · 스타일 · 페이지 · 사이트** 탭에서 나머지를 정합니다.
   - 버튼 글자 칸 아래의 **버튼 속성**: 그 버튼만의 모양·크기·모서리·색·아이콘·전체 폭·새 창. 목록 항목마다 **항목 속성**: 숨기기·강조·배경색·글자색.
4. 페이지는 탭 줄의 **+**(Ctrl+Shift+N)로 더하고, 이름·주소·메뉴 표시는 페이지 탭에서 바꿉니다.
5. **문제점 패널**(Ctrl+J)에서 오류·경고·맞춤법을 확인하고 고칩니다.
6. **저장**(Ctrl+S)하면 `.myhome` 파일 하나에 페이지·그림·디자인이 모두 들어갑니다. **템플릿으로 저장**은 `.mhomt` 입니다.
7. **게시**(Ctrl+Shift+P)로 폴더·ZIP·한 페이지 HTML 을 만듭니다.

### 예제 사이트

예제 40가지(회사·음식·개인·모임 네 분야 × 10)는 홈 구성이 여덟 가지로 나뉩니다: 기본형, 분할 배너+숫자, 이야기형, 작품 전시형, 숫자·절차형, 팀 소개형, 공지·안내형, 상품형. 구성에 따라 *우리 이야기 · 소식 · 자주 묻는 질문* 페이지가 더해지고, 15가지에는 글이 들어 있는 게시판이 있습니다(카드에 *게시판* 표시).

## 4. 디자인과 내 테마 / Designs and my themes

- **사이트 디자인 40가지**(밝은 26 · 어두운 14)는 색·글꼴·모서리·폭·글자 크기를 한 번에 정합니다.
- 블록 패널 아래의 **사이트 디자인** 묶음, 또는 **디자인 › 디자인 바꾸기…**(Ctrl+Shift+D)에서 카드를 누르면 사이트에 **바로 적용되어 보입니다.** 마음에 들면 **적용**, 아니면 **취소**로 원래 디자인으로 돌아갑니다(디자인 창은 *취소*로 닫으면 돌아감).
- **내 테마**: 디자인 창의 *내 테마* 탭에서 새로 만들거나(바탕 디자인, 이름, 색 12가지, 글꼴, 모서리, 폭, 글자 크기 — 오른쪽 미리 보기), *지금 사이트 디자인으로* 시작합니다. **디자인 › 현재 디자인을 내 테마로 저장…** 도 같습니다. 내 테마는 모든 사이트에서 쓸 수 있고, 적용한 사이트는 값을 파일 안에 가지고 있어 다른 컴퓨터에서도 같게 보입니다.
- 사이트 탭에서 색·글꼴 하나하나를 바꿀 수도 있습니다.

프로그램 창의 **테마**(툴바 오른쪽 팔레트)는 MyHomeMaker 자체의 색이고, 만드는 사이트의 디자인과는 따로입니다.

## 5. 게시판 / Bulletin board

**게시판** 블록(블록 패널 › 내용 구성)은 글 목록(번호·분류·제목·글쓴이·날짜·조회)과 글 본문, 분류 단추·검색·쪽 번호, 글쓰기 양식을 보여 줍니다. 공지는 맨 위에 고정됩니다. 글은 내용 탭의 *글* 목록에서 더하고 고칩니다.

**글 저장 위치**

| 선택 | 동작 |
|---|---|
| 사이트 안(정적) — 기본 | 글이 페이지 안에 들어갑니다. 글쓰기 양식은 *글 보낼 주소*(Formspree 같은 양식 서비스)나 *받을 이메일*로 보내고, 확인한 뒤 직접 올립니다. |
| 데이터베이스(게시판 서버) | 글을 DB 에 둡니다. 게시한 사이트의 게시판 서버가 글을 보여 주고 웹사이트에서 쓴 글을 바로 저장합니다. |

### 데이터베이스 연결 (데스크톱 앱)

**도구 › 데이터베이스 연결 설정…** 또는 **설정 › 데이터베이스**:

| DB | 입력 |
|---|---|
| **SQLite3** (기본) | 파일 경로. 비워 두면 앱 데이터 폴더의 `board.db` |
| MySQL · MariaDB · PostgreSQL · MSSQL | 서버 주소, 포트(기본 3306 · 3306 · 5432 · 1433), 데이터베이스 이름, 사용자, 비밀번호 |

- **연결 테스트**로 확인합니다(표 `myhomemaker_board_posts` 를 만들고 서버 버전을 보여 줌).
- 비밀번호는 *비밀번호를 설정에 저장*을 켤 때만 저장되고, 아니면 프로그램을 닫을 때까지만 기억합니다.
- 게시판 내용 탭의 **DB로 글 저장**은 이 게시판의 글로 DB 의 글을 바꾸고, **DB에서 글 가져오기**는 DB 의 글(웹사이트에서 쓴 글 포함)을 가져옵니다.

### 게시판 서버

DB 게시판이 있는 사이트를 게시하면 `server/` 폴더가 함께 생깁니다.

서버 언어는 **설정 › 데이터베이스**에서 고릅니다. 기본은 Node.js 이고, Go, Rust, Python 도 같은 API 와 같은 데이터베이스를 씁니다. 이 언어는 프로그램에 포함되어 있지 않습니다. 없는 것은 같은 화면의 **서버 언어 설치**로 받습니다.

```bash
cd <게시한 폴더>/server
# Node.js
npm install                   # MySQL · MariaDB · PostgreSQL · MSSQL 일 때
set DB_PASSWORD=비밀번호        # macOS/Linux: export DB_PASSWORD=…
npm start                     # http://localhost:8080/
# Go
go mod tidy
go run .
# Rust
cargo run --release
# Python
pip install -r requirements.txt   # SQLite3 가 아니면
python server.py
```

- SQLite3 의 Node.js 서버는 22.13 이상이면 따로 설치할 것이 없고, 지금 DB 파일이 `server/board.db` 로 함께 갑니다.
- 비밀번호는 게시 파일에 쓰지 않습니다(`DB_PASSWORD` 환경 변수에서 읽음).
- 자세한 내용은 `server/README.md` 에 있습니다. 서버 없이 HTML 만 열어도 페이지에 들어 있던 글은 보입니다.

## 6. 코드 편집기 / Code editor

**도구 › 코드 편집기**(Ctrl+Shift+E)는 HTML · CSS · JavaScript · JSON 을 고치는 별도 창입니다. `.html` · `.css` · `.js` 파일을 **파일 › 열기**나 끌어 놓기로 열어도 이 창에서 열립니다.

- 탭(많으면 오른쪽 **< >**), 구문 색, 줄 번호, 자동 들여쓰기, 주석(Ctrl+/), 찾기(Ctrl+F) · 바꾸기(Ctrl+H) · 줄로 이동(Ctrl+G), 자동 줄 바꿈, 글자 크기
- HTML 은 오른쪽에 **실시간 미리 보기**, *브라우저에서 보기*
- **정리**(Shift+Alt+F, Prettier) · **검사**(F8, JSHint · HTMLHint · JSON · CSS)
- **사이트 CSS · JS · head** — 사이트 전체에 들어가는 코드. 입력하는 대로 캔버스에 적용되고 게시할 때 `style.css` · `script.js` · 모든 페이지의 `<head>` 에 들어갑니다.
- **보기 › 파일 편집**(Ctrl+Shift+U) — 메뉴와 페이지는 그대로 두고, 아래에서 페이지 HTML · `style.css` · `script.js` 를 고칩니다. 입력은 페이지에 바로 반영되고 **저장**은 사이트를 저장합니다. 오류가 있는 줄은 표시되고, 아래 **문제점** 탭에도 나옵니다. **도구 › 현재 페이지 HTML 편집**은 그 페이지의 HTML을 엽니다.

### 패키지

정리·검사 도구(Prettier, JSHint, HTMLHint)는 처음에, 그리고 **설정 › 패키지**를 열거나 자동 설치를 켜면, 인터넷(jsDelivr, 안 되면 unpkg)에서 받아 설치됩니다. 진행률은 그 창과 상태 표시줄에 보이고 **×**로 취소합니다. 실패하면 **다시 받기**가 남습니다. 받은 파일은 SHA-256 이 맞을 때만 보관합니다.

## 7. 인쇄 / Printing

**파일 › 인쇄…**(Ctrl+P, 툴바의 저장 오른쪽):

- 프린터와 매수(Windows 는 대화 상자 없이 바로 인쇄, 목록이 없으면 시스템 인쇄 창)
- 범위: 모든 페이지 · 현재 페이지 · 페이지 범위
- 용지(A3 · A4 · A5 · B4 · B5 · Letter · Legal), 세로·가로, 여백, 화면 폭(데스크톱 · 태블릿 · 휴대폰), 크기(용지 폭에 맞춤 — 긴 페이지는 여러 장 / 한 장에 맞춤 / 배율), 배경 인쇄
- 머리글(사이트 · 페이지, 날짜) · 바닥글(쪽 번호), 직접 쓴 문구
- 오른쪽 미리 보기에서 **< >** 또는 PageUp · PageDown 으로 장을 넘깁니다.

## 8. 게시 / Publishing

**파일 › 게시·내보내기 › 사이트 게시…**(Ctrl+Shift+P):

| 방법 | 결과 |
|---|---|
| 폴더 (데스크톱) | 사이트 이름의 폴더에 `index.html`, 페이지마다 `.html`, `style.css`, (사이트 JS 가 있으면) `script.js`, `assets/`, (DB 게시판이 있으면) `server/` |
| ZIP | 같은 파일을 ZIP 하나로 |
| 이 페이지만 | 스타일과 그림이 들어간 HTML 파일 하나 |

게시한 사이트는 자바스크립트 없이도 동작합니다(휴대폰 메뉴, 질문 펼치기, 게시판 글 열기). GitHub Pages, Netlify, Cloudflare Pages 나 웹 호스팅에 올리면 됩니다. DB 게시판은 게시판 서버를 띄울 수 있는 곳(Node.js, Go, Rust 또는 Python)이 필요합니다.

| 무엇 | 어디 |
|---|---|
| 사이트 | `.myhome`(JSON 한 파일: 페이지·블록·그림·디자인·사이트 코드), 템플릿 `.mhomt` |
| 설정, 최근 기록, 내 테마, 내 사전, DB 연결 | 프로그램의 WebView2 프로필(Windows: `%LOCALAPPDATA%\com.shkwon.myhomemaker`) |
| 창 위치, 배경 그림, 기본 SQLite 파일 `board.db` | `%APPDATA%\com.shkwon.myhomemaker` |
| 패키지 파일 | 프로그램 저장소(IndexedDB) |

웹 버전은 같은 기능을 브라우저에서 쓰되, 파일은 브라우저의 파일 열기·저장으로 다루고 데이터베이스 연결과 프린터 직접 인쇄는 데스크톱 앱에서만 됩니다.

## 12. 문제 해결 / Troubleshooting

- **패키지를 받지 못함** — 인터넷 연결을 확인하고 상태 표시줄의 **다시 받기** 또는 설정 › 패키지에서 다시 받습니다. 오류 내용이 카드에 나옵니다.
- **DB 연결 실패** — 설정 › 데이터베이스에서 서버 주소·포트·이름·사용자를 확인하고 *연결 테스트*를 누릅니다. 오류 문구에 비밀번호는 나오지 않습니다.
- **게시판 서버가 시작되지 않음** — 고른 언어가 설치되어 있어야 합니다. 설정 › 데이터베이스의 **서버 언어 설치**를 쓰세요. Node.js 의 SQLite3 는 22.13 이상, 다른 DB 는 `npm install` 과 `DB_PASSWORD` 가 필요합니다. Go 는 `go mod tidy` 다음 `go run .`, Rust 는 `cargo run --release`, Python 은 `python server.py` 입니다. `server/README.md` 를 보세요.
- **창이 너무 좁음** — 툴바 단추가 가려지지 않도록 창의 최소 폭이 툴바에 맞춰집니다. 패널을 접으면 캔버스가 넓어집니다.
- **프로그램이 갑자기 닫힘** — 앱 데이터 폴더의 `crash.log` 와 함께 알려 주세요.
