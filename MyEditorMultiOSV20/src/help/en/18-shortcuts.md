# Keyboard shortcuts

All of My Editor's shortcuts gathered in one place. Inside the program, **Help › Keyboard shortcuts** or the **Keyboard shortcuts** card on the start page shows the list in a window (a separate window on the desktop, laid out in two or three columns without scrolling).

![Keyboard shortcuts window](images/shortcuts.png)
*Figure: The Keyboard shortcuts window*

On macOS, ⌘ (Command) is used instead of Ctrl. The shortcuts shown in the menus change accordingly.

## Files

| Shortcut | Function |
|---|---|
| Ctrl+N | New document |
| Ctrl+O | Open file |
| Ctrl+Shift+O | Open folder |
| Ctrl+S | Save |
| Ctrl+Alt+S | Save as |
| Ctrl+Shift+S | Save all |
| Ctrl+P | Print (print preview) |
| Ctrl+W | Close |
| Ctrl+Shift+W | Close all |
| Alt+F4 (macOS ⌘Q) | Exit |

## Tabs

| Shortcut | Function |
|---|---|
| Ctrl+Tab / Ctrl+PgDn | Next tab |
| Ctrl+Shift+Tab / Ctrl+PgUp | Previous tab |
| Ctrl+1 … Ctrl+9 | nth tab (in Markdown documents, Ctrl+1 – 6 are headings) |
| Middle click on a tab | Close the tab |

## Editing

| Shortcut | Function |
|---|---|
| Ctrl+Z / Ctrl+Y | Undo / Redo |
| Ctrl+X / Ctrl+C / Ctrl+V | Cut / Copy / Paste |
| Del | Delete |
| Ctrl+A | Select all |
| Ctrl+D | Duplicate line |
| Ctrl+L | Delete line |
| Alt+↑ / Alt+↓ | Move line up / down |
| Ctrl+/ | Toggle comment |
| Tab / Shift+Tab | Indent / Outdent |
| Ctrl+U / Ctrl+Shift+U | lowercase / UPPERCASE (whole document when nothing is selected) |
| Shift+Alt+F | Format document |
| Ctrl+Space | Open the autocomplete list |
| Alt+click | Add a cursor (multiple cursors) |
| Alt+drag | Rectangular selection |
| Esc | Back to one cursor · close the autocomplete list |

Ctrl+D · Ctrl+L · Ctrl+U do nothing while the cursor is in an input field (the find bar and so on).

## Search

| Shortcut | Function |
|---|---|
| Ctrl+F | Find |
| Ctrl+H | Replace |
| F3 / Shift+F3 | Find next / previous |
| Enter / Shift+Enter (in the find field) | Find next / previous |
| Enter (in the Replace with field) | Replace one |
| Ctrl+Enter (in the Replace with field) | Replace all |
| Esc | Close find |
| Ctrl+Shift+F | Find in folder |
| Ctrl+Alt+F | Find in open documents |
| Ctrl+G | Go to line |

## View

| Shortcut | Function |
|---|---|
| Ctrl+B | Show / hide the folder tree |
| Ctrl+Shift+B | Folder tree (works in Markdown documents too) |
| Ctrl+= (Ctrl++) / Ctrl+− | Zoom in / out |
| Ctrl+0 | Reset zoom |
| Ctrl+mouse wheel | Zoom in / out (over a picture, zooms the picture) |
| F11 | Full screen |
| Ctrl+Shift+M | Preview (Markdown · HTML · SVG) |
| Ctrl+\\ | Editor split left / right ↔ single |
| Ctrl+Alt+1 / 2 / 3 / 4 | Editor panes: single / left-right / top-bottom / four |
| F6 | Next editor pane |

## Tools

| Shortcut | Function |
|---|---|
| F7 | Spell check on / off |
| F8 | Next problem (code check) |
| Ctrl+\` | Terminal panel (outside Markdown documents) |
| Ctrl+Shift+\` | New terminal |
| Ctrl+, | Settings |
| F1 | Help |

## In Markdown documents

While editing a Markdown document, the following keys become formatting commands.

| Shortcut | Function |
|---|---|
| Ctrl+1 … Ctrl+6 | Headings H1 – H6 |
| Ctrl+B / Ctrl+I | Bold / Italic |
| Ctrl+Shift+X | Strikethrough |
| Ctrl+\` | Inline code |
| Ctrl+Shift+C | Code block |
| Ctrl+Shift+Q | Quote |
| Ctrl+Shift+8 / 7 / 9 | Bullet list / Numbered list / Task list |
| Ctrl+K | Link |
| Ctrl+Shift+I | Insert image |
| Ctrl+Shift+W | WYSIWYG column on / off |
| Ctrl+Shift+M | Preview on / off |

## In the terminal input

| Key | Function |
|---|---|
| Enter | Run the command |
| ↑ / ↓ | Command history |
| Tab | Completion (press twice for the list of candidates) |
| Ctrl+L | Clear the screen |
| Ctrl+C (when the input is empty) | Interrupt the running command |
| Esc | Clear the input line |

## In the picture · hex views

| Key · mouse | Function |
|---|---|
| Left click / right click | Zoom the picture in / out |
| Drag | Pan the picture |
| ← → or PgUp / PgDn | Previous / next image (multi-image HEIC · DICOM) |
| Home / End | First / last image |
| Space | DICOM play / stop |
| Click / Shift+click (hex) | Select a byte / select a range |
| Ctrl+A / Ctrl+C (hex) | Select all / copy as hex |

## Help window · tutorial · dialogs

| Key | Function |
|---|---|
| Alt+← / Alt+→ (Help window) | Previous chapter / next chapter |
| Enter (dialogs) | The default button (OK · Go · Save and so on) |
| Esc (dialogs) | Close · cancel |
| ↑ ↓ Enter (language picker · font list) | Choose an item |
| ← → ↑ ↓ Home End (start page speed sliders) | Change the value |
