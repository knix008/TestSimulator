# 웹 버전과 문제 해결

My Editor 는 데스크톱 앱과 같은 화면을 브라우저에서 쓰는 **웹 버전**도 제공합니다. 이 장은 웹 버전의 실행과 차이점, 데이터 파일의 위치, 자주 겪는 문제의 해결 방법을 설명합니다.

## 웹 버전 실행

프로젝트 폴더에서 다음 명령으로 실행합니다.

```bash
npm run web                       # 빌드 후 http://127.0.0.1:5190 (브라우저가 자동으로 열림)
node server/server.js --host 0.0.0.0 --port 8080 --token 비밀값
```

- `npm run web` 은 화면을 빌드한 뒤 이 컴퓨터에서만 접속할 수 있는 서버(127.0.0.1:5190)를 띄우고 브라우저를 엽니다.
- 다른 컴퓨터에서 접속하게 하려면 `--host 0.0.0.0` 과 원하는 `--port` 를 주고, **반드시 `--token` 을 함께** 쓰세요. 토큰 없이 외부에 열면 서버가 경고를 출력합니다.
- 접속할 때 주소 뒤에 `?token=비밀값` 을 붙이면 브라우저가 기억합니다. 서버를 시작할 때 토큰이 붙은 주소가 출력됩니다.
- `--config` 로 설정 파일의 위치를 바꿀 수 있습니다.

## 웹 버전의 차이점

- 편집하는 파일은 브라우저가 있는 컴퓨터가 아니라 **서버가 실행되는 컴퓨터**의 것입니다.
- 열기 · 저장 · 폴더 선택 대화상자는 앱 안에서 그립니다. 드라이브 목록, 상위 폴더, 경로 직접 입력, 숨김 파일 표시가 있고, 파일마다 크기와 수정 시각이 보입니다. 같은 이름의 파일에 저장하려 하면 덮어쓸지 묻습니다.
- 브라우저에서 끌어다 놓은 파일은 경로를 알 수 없으므로 **내용을 읽어 새 문서로** 엽니다(64 MB 까지). 저장할 때 서버 컴퓨터의 위치를 고릅니다.
- 창 버튼(최소화 · 최대화 · 닫기), 크기 조절 표시, **탐색기에서 보기**, **기본 앱으로 열기**는 없습니다.
- 메뉴는 운영체제 메뉴 대신 페이지 안의 메뉴로 열리고, 항목이 많으면 창에 맞춰 여러 열로 표시됩니다.
- 설정 · 정보 · 단축키 · 인쇄 미리보기는 별도 창 대신 페이지 안에서 옮길 수 있는 창으로 열립니다.
- 인쇄는 새 브라우저 창을 열어 브라우저의 인쇄 기능을 씁니다. 팝업 차단을 풀어야 할 수 있습니다.
- 정보 창의 실행 환경에 "웹 브라우저" 라고 나옵니다.

## 데이터 파일의 위치

설정과 세션(열린 탭, 최근 파일, 창 배치, 사전에 추가한 낱말 등)은 `session.json` 파일 하나에 저장됩니다.

| 항목 | Windows | macOS | Linux |
|---|---|---|---|
| 데스크톱 앱 `session.json` | `%APPDATA%\My Editor\` | `~/Library/Application Support/My Editor/` | `~/.config/My Editor/` |
| 웹 버전 (`--config` 로 변경) | `%APPDATA%\My Editor\` | `~/Library/Application Support/My Editor/` | `~/.config/my-editor/` |

- `session.json` 을 지우면 모든 설정과 세션이 기본값으로 시작합니다.
- 앱에서 설치한 npm 정렬 도구(Prettier · sql-formatter)는 같은 설정 폴더 안의 `tools/node` 에 들어갑니다.

## 오류가 났을 때

오류가 나면 제목과 설명이 있는 오류 창이 뜨고, 그 아래 **자세히** 칸에 오류 코드 · 경로 · 메시지 · 스택이 나옵니다. **자세히 복사** 버튼을 누르면 이 내용을 모두 클립보드에 담으므로("오류 내용을 클립보드에 복사했습니다."), 그대로 붙여넣어 문의할 수 있습니다.

## 문제 해결

**파일을 열면 글자가 깨져 보입니다.**
인코딩이 잘못 판별된 것입니다. **인코딩 › 다음 인코딩으로 다시 열기…** 에서 올바른 인코딩(한국어 문서는 보통 한국어 (EUC-KR / CP949))을 고르세요. 앞으로 UTF-8 로 저장하려면 인코딩 메뉴에서 UTF-8 을 고르고 저장합니다([언어 · 인코딩 · 줄 끝](07-언어-인코딩-줄끝.md)).

**파일이 16진수로만 열립니다.**
내용에 텍스트에 쓰이지 않는 제어 바이트가 있어 이진 파일로 판단된 것입니다. 이진 파일은 16진수 보기(읽기 전용)로만 열립니다.

**"파일이 너무 큽니다" 라며 열리지 않습니다.**
64 MB 를 넘는 텍스트 파일은 열지 않습니다. 필요한 부분만 다른 도구로 잘라 내어 여세요.

**저장할 때 "인코딩 경고" 가 뜹니다.**
문서의 인코딩으로 표현할 수 없는 글자가 있습니다. 그대로 저장하면 그 글자는 "?" 로 바뀝니다. 취소하고 인코딩을 UTF-8 로 바꾼 뒤 저장하세요.

**문서 정렬 버튼이 꺼져 있거나 "들여쓰기만 정리했습니다" 라고 나옵니다.**
그 언어의 정렬 도구가 설치되어 있지 않거나, 정렬이 꺼져 있거나, 이미 정렬되어 있는 것입니다. 도구 모음의 정렬 도구 이름을 누르거나 설정 › 정렬에서 도구를 고르고 설치하세요. 직접 설치한 뒤에도 "설치 안 됨" 이면 PATH 에 추가하고 **다시 찾기** 를 누르거나 앱을 다시 시작하세요([정렬과 검사](12-정렬과-검사.md)).

**상태 표시줄의 코드 검사 항목이 "—" 입니다.**
그 언어의 검사 도구가 없거나 설치되지 않았습니다. 설정 › 검사에서 도구를 골라 설치하세요.

**터미널에서 vim · top 같은 프로그램이 이상하게 보입니다.**
터미널은 줄 단위로 동작하므로 화면 전체를 직접 그리는 프로그램은 맞지 않습니다. 이런 프로그램은 운영체제의 터미널에서 실행하세요([터미널과 로그](14-터미널과-로그.md)).

**터미널 출력에 색이 없습니다.**
설정 › 터미널의 **출력을 색으로 표시** 가 켜져 있는지 확인하세요. 파이프로 연결된 프로그램 중에는 스스로 색을 내지 않는 것도 있습니다.

**프로그램을 켤 때마다 시작 화면이 보입니다 / 보이지 않습니다.**
설정 › 시작 화면의 **시작 시 항상 시작 화면 보기** 를 확인하세요. 꺼져 있어도 복원된 문서가 없으면 시작 화면이 보입니다. 시작 화면은 메뉴 바의 **시작** 버튼으로 언제든 닫을 수 있습니다.

**지난번 탭이 복원되지 않습니다.**
설정 › 일반 › 세션의 **시작할 때 이전 세션 복원** 이 켜져 있는지 확인하세요. 그사이 지워지거나 옮겨진 파일의 탭은 복원되지 않습니다.

**Ctrl+B · Ctrl+1 같은 키가 다르게 동작합니다.**
Markdown 문서에서는 서식 단축키로 바뀝니다. 폴더 트리는 Ctrl+Shift+B, 탭 이동은 Ctrl+Tab 을 쓰세요([단축키](18-단축키.md)).

**설정을 처음 상태로 돌리고 싶습니다.**
설정 창 아래의 **기본값으로 되돌리기** 를 누르세요. 그래도 문제가 남으면 프로그램을 끈 뒤 `session.json` 을 지우고 다시 실행하세요.

**개발 모드(`npm start`)가 포트 5189 때문에 시작되지 않습니다.**
이전 개발 서버가 남아 있는 것입니다. `npm start` 는 먼저 `npm run free:port` 를 실행하지만, 그래도 안 되면 5189 포트를 쓰는 프로세스를 종료하세요. 개발 모드의 Vite 서버는 포트를 하나만 쓰므로 `npm start` 는 한 번에 하나만 띄울 수 있습니다. 설치한 프로그램은 여러 번 실행해도 됩니다.
