# 단축키

My Editor 의 모든 단축키를 한곳에 모았습니다. 프로그램 안에서는 **도움말 › 단축키** 나 시작 화면의 **단축키** 카드로 목록 창을 띄울 수 있습니다(데스크톱에서는 별도 창, 스크롤 없이 두세 열로 표시).

![단축키 창](images/shortcuts.png)
*그림: 단축키 창*

macOS 에서는 Ctrl 대신 ⌘ (Command) 를 씁니다. 메뉴에 표시되는 단축키도 그에 맞게 바뀝니다.

## 파일

| 단축키 | 기능 |
|---|---|
| Ctrl+N | 새 문서 |
| Ctrl+O | 파일 열기 |
| Ctrl+Shift+O | 폴더 열기 |
| Ctrl+S | 저장 |
| Ctrl+Alt+S | 다른 이름으로 저장 |
| Ctrl+Shift+S | 모두 저장 |
| Ctrl+P | 인쇄 (인쇄 미리보기) |
| Ctrl+W | 닫기 |
| Ctrl+Shift+W | 모두 닫기 |
| Alt+F4 (macOS ⌘Q) | 종료 |

## 탭

| 단축키 | 기능 |
|---|---|
| Ctrl+Tab / Ctrl+PgDn | 다음 탭 |
| Ctrl+Shift+Tab / Ctrl+PgUp | 이전 탭 |
| Ctrl+1 … Ctrl+9 | n번째 탭 (Markdown 문서에서는 Ctrl+1 ~ 6 이 제목) |
| 탭 위 가운데 클릭 | 탭 닫기 |

## 편집

| 단축키 | 기능 |
|---|---|
| Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 |
| Ctrl+X / Ctrl+C / Ctrl+V | 잘라내기 / 복사 / 붙여넣기 |
| Del | 삭제 |
| Ctrl+A | 모두 선택 |
| Ctrl+D | 줄 복제 |
| Ctrl+L | 줄 삭제 |
| Alt+↑ / Alt+↓ | 줄 위 / 아래로 이동 |
| Ctrl+/ | 주석 토글 |
| Tab / Shift+Tab | 들여쓰기 / 내어쓰기 |
| Ctrl+U / Ctrl+Shift+U | 소문자 / 대문자 (선택이 없으면 문서 전체) |
| Shift+Alt+F | 문서 정렬 |
| Ctrl+Space | 자동 완성 목록 열기 |
| Alt+클릭 | 커서 추가 (다중 커서) |
| Alt+드래그 | 사각형 선택 |
| Esc | 다중 커서 · 자동 완성 목록 닫기 |

Ctrl+D · Ctrl+L · Ctrl+U 는 입력 칸(찾기 줄 등)에 커서가 있을 때는 동작하지 않습니다.

## 찾기

| 단축키 | 기능 |
|---|---|
| Ctrl+F | 찾기 |
| Ctrl+H | 바꾸기 |
| F3 / Shift+F3 | 다음 / 이전 찾기 |
| Enter / Shift+Enter (찾기 칸에서) | 다음 / 이전 찾기 |
| Enter (바꿀 내용 칸에서) | 하나 바꾸기 |
| Ctrl+Enter (바꿀 내용 칸에서) | 모두 바꾸기 |
| Esc | 찾기 닫기 |
| Ctrl+Shift+F | 폴더에서 찾기 |
| Ctrl+Alt+F | 열린 문서에서 찾기 |
| Ctrl+G | 줄로 이동 |

## 보기

| 단축키 | 기능 |
|---|---|
| Ctrl+B | 폴더 트리 보이기 / 숨기기 |
| Ctrl+Shift+B | 폴더 트리 (Markdown 문서에서도 동작) |
| Ctrl+= (Ctrl++) / Ctrl+− | 확대 / 축소 |
| Ctrl+0 | 기본 크기 |
| Ctrl+마우스 휠 | 확대 / 축소 (그림 위에서는 그림 확대 · 축소) |
| F11 | 전체 화면 |
| Ctrl+Shift+M | 미리보기 (Markdown · HTML · SVG) |
| Ctrl+\\ | 편집 창 좌우 나누기 ↔ 하나 |
| Ctrl+Alt+1 / 2 / 3 / 4 | 편집 창: 하나 / 좌우 / 상하 / 4개 |
| F6 | 다음 편집 창 |

## 도구

| 단축키 | 기능 |
|---|---|
| F7 | 스펠링 체크 켜기 / 끄기 |
| F8 | 다음 문제 (코드 검사) |
| Ctrl+\` | 터미널 패널 (Markdown 문서 밖에서) |
| Ctrl+Shift+\` | 새 터미널 |
| Ctrl+, | 설정 |
| F1 | 도움말 |

## Markdown 문서에서

Markdown 문서를 편집하는 동안에는 다음 키가 서식 명령으로 바뀝니다.

| 단축키 | 기능 |
|---|---|
| Ctrl+1 … Ctrl+6 | 제목 H1 ~ H6 |
| Ctrl+B / Ctrl+I | 굵게 / 기울임 |
| Ctrl+Shift+X | 취소선 |
| Ctrl+\` | 인라인 코드 |
| Ctrl+Shift+C | 코드 블록 |
| Ctrl+Shift+Q | 인용 |
| Ctrl+Shift+8 / 7 / 9 | 글머리 기호 목록 / 번호 매기기 목록 / 체크리스트 |
| Ctrl+K | 링크 |
| Ctrl+Shift+I | 이미지 넣기 |
| Ctrl+Shift+W | WYSIWYG 열 켜기 / 끄기 |
| Ctrl+Shift+M | 미리보기 켜기 / 끄기 |

## 터미널 입력 칸에서

| 키 | 기능 |
|---|---|
| Enter | 명령 실행 |
| ↑ / ↓ | 명령 기록 |
| Tab | 자동 완성 (두 번 누르면 후보 목록) |
| Ctrl+L | 화면 지우기 |
| Ctrl+C (입력이 비어 있을 때) | 실행 중인 명령 중단 |
| Esc | 입력 줄 지우기 |

## 그림 · 16진수 보기에서

| 키 · 마우스 | 기능 |
|---|---|
| 왼쪽 클릭 / 오른쪽 클릭 | 그림 확대 / 축소 |
| 끌기 | 그림 이동 |
| ← → 또는 PgUp / PgDn | 이전 / 다음 장 (여러 장 HEIC · DICOM) |
| Home / End | 처음 / 마지막 장 |
| Space | DICOM 연속 재생 / 멈춤 |
| 클릭 / Shift+클릭 (16진수) | 바이트 선택 / 범위 선택 |
| Ctrl+A / Ctrl+C (16진수) | 모두 선택 / 16진수로 복사 |

## 도움말 창 · 튜토리얼 · 대화상자

| 키 | 기능 |
|---|---|
| Alt+← / Alt+→ (도움말 창) | 이전 장 / 다음 장 |
| Enter (대화상자) | 기본 버튼 (확인 · 이동 · 저장 등) |
| Esc (대화상자) | 닫기 · 취소 |
| ↑ ↓ Enter (언어 고르기 · 글꼴 목록) | 항목 고르기 |
| ← → ↑ ↓ Home End (시작 화면 속도 막대) | 값 바꾸기 |
