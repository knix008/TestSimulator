# 화면 구성

이 장은 My Editor 창의 각 부분 — 맨 위의 메뉴 바부터 맨 아래의 상태 표시줄까지 — 이 무엇이고 어떻게 쓰는지 설명합니다.

![편집기 전체 화면](images/main-window.png)
*그림: 폴더 트리, 탭, 코드가 열린 편집기 창*

위에서 아래로 다음 순서로 놓여 있습니다.

1. **메뉴 바** (제목 표시줄 역할을 겸함)
2. **도구 모음**
3. 왼쪽 **폴더 트리** + 오른쪽 **탭 줄 · 편집 영역**
4. **하단 패널** (터미널 · 로그 · 문제점, 열었을 때만)
5. **상태 표시줄**

## 제목 표시줄과 메뉴 바

My Editor 창에는 운영체제의 제목 표시줄이 따로 없습니다. 맨 윗줄이 제목 표시줄과 메뉴 바를 겸합니다.

- 왼쪽 끝의 **로고와 이름**(My Editor V1.1), 그리고 메뉴 오른쪽의 빈 곳을 끌면 창이 움직입니다. 빈 곳을 **더블클릭**하면 최대화 / 이전 크기로 바뀝니다.
- 이름 바로 오른쪽의 **시작** 버튼(집 모양)은 시작 화면을 열고 닫습니다. 시작 화면이 열려 있는 동안 버튼이 눌린 모양으로 보입니다.
- 그다음에 메뉴 8개가 아이콘과 함께 같은 간격으로 놓입니다: **파일 · 편집 · 찾기 · 편집기 · 보기 · 언어 · 인코딩 · 도움말**.
- 오른쪽 끝에는 **최소화 · 최대화(이전 크기로) · 닫기** 창 버튼이 있습니다(데스크톱 앱).

데스크톱 앱에서 메뉴를 누르면 운영체제의 기본 메뉴로 열리므로 항목이 많아도 창 밖까지 펼쳐집니다. 웹 버전에서는 페이지 안의 메뉴로 열리고, 메뉴 하나가 열린 채 다른 메뉴 제목으로 마우스를 옮기면 그 메뉴로 바뀝니다.

| 메뉴 | 들어 있는 것 | 자세히 |
|---|---|---|
| 파일 | 새 문서, 열기, 폴더 열기/닫기, 저장, 인쇄, 닫기, 탐색기에서 보기, 최근 파일, 종료 | [파일](03-파일.md) |
| 편집 | 실행 취소, 잘라내기 · 복사 · 붙여넣기, 줄 편집, 대소문자, 줄 정렬, 문서 정렬, 삽입 | [편집](05-편집.md) |
| 찾기 | 찾기, 바꾸기, 폴더/열린 문서에서 찾기, 줄로 이동 | [찾기와 바꾸기](06-찾기와-바꾸기.md) |
| 편집기 | 자동 들여쓰기 · 자동 완성 · 줄 바꿈 · 줄 번호 · 미니맵 등 켜고 끄기, 스펠링 체크, 코드 검사 | [보기와 테마](16-보기와-테마.md) |
| 보기 | 시작 화면, 화면 요소 표시, 창 나누기, 미리보기 · 구조, 하단 패널, 확대/축소, 전체 화면 | [보기와 테마](16-보기와-테마.md) |
| 언어 | 구문 강조 언어 고르기 | [언어 · 인코딩 · 줄 끝](07-언어-인코딩-줄끝.md) |
| 인코딩 | 저장 인코딩, 다른 인코딩으로 다시 열기, 줄 끝 | [언어 · 인코딩 · 줄 끝](07-언어-인코딩-줄끝.md) |
| 도움말 | 도움말(F1), 튜토리얼, 단축키, 설정, 정보 | 이 장 아래 |

![도움말 메뉴](images/menu-help.png)
*그림: 도움말 메뉴*

**도움말** 메뉴의 항목은 다음과 같습니다.

- **도움말** (F1): 이 도움말 창을 엽니다.
- **튜토리얼**: 화면 위에서 기능을 짚어 주는 둘러보기를 시작합니다([시작하기](01-시작하기.md)).
- **단축키**: 단축키 목록 창을 엽니다([단축키](18-단축키.md)).
- **설정** (Ctrl+,): 설정 창을 엽니다([설정](17-설정.md)).
- **정보**: 프로그램 이름, 버전, 작성자, 실행 환경(데스크톱 · 웹 브라우저와 운영체제), 빌드 시각 등을 보여 줍니다.

![정보 창](images/about.png)
*그림: 정보 창*

설정 · 정보 · 단축키 · 도움말은 데스크톱 앱에서 **별도의 창**으로 열립니다. 메인 창 밖으로도 옮길 수 있고, 메인 창 위에 떠 있으며, 메인 창을 최소화하거나 닫으면 함께 최소화 · 닫힙니다. 웹 버전에서는 페이지 안에서 제목을 끌어 옮길 수 있는 창으로 열립니다. 저장 여부를 묻는 창처럼 답이 필요한 창은 뒤를 흐리게 하고 답을 기다립니다.

## 도구 모음

메뉴 바 아래의 아이콘 줄입니다. 마우스를 올리면 이름과 단축키가 풍선 도움말로 나옵니다. 보기 › 도구 모음으로 숨길 수 있고, 숨기면 오른쪽 끝의 테마 · 언어 · 설정 · 정보 버튼이 메뉴 바 오른쪽으로 옮겨집니다.

![도구 모음](images/toolbar.png)
*그림: 도구 모음*

왼쪽부터 순서대로 다음 버튼이 있습니다(구분선으로 묶음이 나뉩니다).

| | 모두 저장 | 바뀐 문서 모두 저장 (Ctrl+Shift+S) — 바뀐 문서가 있을 때만 켜짐 |

켜고 끄는 버튼(공백 문자 표시, 폴더 트리, 미리보기, 탭 안내선, 줄 바꿈, 자동 들여쓰기, 스펠링 체크, 자동 완성, 터미널 · 로그 · 문제점)은 켜져 있을 때 강조 색으로 표시됩니다. 문서 종류에 맞지 않는 버튼(예: 코드 파일의 미리보기 · 실행)은 흐리게 꺼집니다.

창 폭은 메뉴 바와 도구 모음이 모두 보일 만큼보다 좁아지지 않습니다.

## 탭 줄

편집 영역 바로 위에 열린 문서가 탭으로 늘어섭니다.

![탭 줄](images/tabbar.png)
*그림: 탭 줄 — 오른쪽 끝에 + 와 스크롤 버튼*

- 탭에는 파일 종류 아이콘과 이름이 있고, 마우스를 올리면 전체 경로가 보입니다.
- 저장하지 않은 문서는 × 대신 **●** 점이 보입니다(점을 눌러도 닫기). 읽기 전용 파일에는 눈 모양 표시가 붙습니다.
- 오른쪽 끝의 **+** 는 새 문서, 탭이 창 폭보다 많을 때만 나타나는 **<** **>** 는 탭 줄을 스크롤합니다.

탭 다루는 방법은 [탭](04-탭.md) 장에서 자세히 설명합니다. Markdown · SVG · 그림 문서에서는 탭 줄 아래에 그 종류 전용 도구 줄(Markdown 도구 모음 등)이 한 줄 더 나타납니다.

## 폴더 트리

창 왼쪽에는 **폴더 트리** 패널이 있습니다(Ctrl+B 또는 도구 모음 버튼으로 보이기/숨기기, Markdown 문서에서는 Ctrl+Shift+B). 폴더를 열면 그 안의 파일이 연결선이 있는 트리로 보이고, 머리의 🔍 버튼을 누르면 패널 아래 절반에 **폴더에서 찾기** 영역이 열립니다. 폴더 트리와 편집 영역 사이의 경계선을 끌면 폭이 바뀝니다. 자세한 사용법은 [폴더 트리](08-폴더-트리.md) 를 보세요.

## 편집 영역

탭 줄 아래가 실제 글을 쓰는 곳입니다(편집 엔진은 CodeMirror 6).

- 왼쪽 여백(거터)에는 **줄 번호**, 코드를 접고 펴는 **▾ 표시**, 코드 검사 결과를 알리는 **색 점**(빨강 오류 · 노랑 경고 · 파랑 정보)이 있습니다.
- 코드 문서에서는 오른쪽 끝에 문서 전체를 작게 보여 주는 **미니맵**이 있습니다. 끌거나 누르면 그 위치로 이동합니다.
- 커서가 있는 줄은 옅게 강조되고, 짝이 맞는 괄호도 강조됩니다.
- Markdown · HTML · SVG 문서는 미리보기 등을 켜면 같은 창 안에서 편집기 옆에 열이 더 생깁니다.
- 그림 파일은 편집기 대신 그림이, 이진 파일은 16진수 보기가, 오디오 · 동영상은 재생기가 이 자리를 채웁니다([HTML · SVG · 그림 · 이진](10-HTML-SVG-그림-이진.md)).
- 오른쪽 클릭하면 실행 취소, 잘라내기 · 복사 · 붙여넣기, 주석 토글, 대/소문자, 문서 정렬, 찾기 · 바꾸기 · 줄로 이동이 든 메뉴가 나옵니다. 철자가 틀린 낱말 위라면 맨 위에 제안 낱말도 나옵니다.

편집 영역을 여러 개로 나눌 수도 있습니다([창 나누기](11-창-나누기.md)).

## 하단 패널

**터미널 · 로그 · 문제점** 세 탭이 한 패널에 들어 있으며, 열면 폴더 트리 아래까지 포함해 **창 왼쪽 끝에서 오른쪽 끝까지** 펼쳐집니다. 도구 모음의 터미널 · 로그 · 문제점 버튼이나 보기 메뉴로 엽니다. 이미 앞에 보이는 탭의 버튼을 한 번 더 누르면 패널이 닫힙니다. 패널 위쪽 경계선을 끌어 높이를 바꿉니다. 자세한 내용은 [터미널과 로그](14-터미널과-로그.md), 문제점은 [정렬과 검사](12-정렬과-검사.md) 를 보세요.

## 상태 표시줄

창 맨 아래 줄입니다. 왼쪽에는 방금 한 일을 알리는 메시지(저장됨, 열림 …, 평소에는 "준비됨")가 나오고, 새 메시지가 오면 잠깐 반짝입니다. 같은 메시지는 하단 패널의 **로그** 탭에도 쌓입니다. 보기 › 상태 표시줄로 숨길 수 있습니다.

![상태 표시줄](images/statusbar.png)
*그림: 상태 표시줄 — 오른쪽 항목은 대부분 누를 수 있는 버튼*

오른쪽 항목은 왼쪽부터 다음과 같습니다.

| 항목 | 예 | 누르면 |
|---|---|---|
| 커서 위치 | 줄 4, 열 33 | — (다중 커서면 뒤에 ×3 처럼 커서 수) |
| 선택 | 12자 선택, 40자 (3줄) 선택 | — (선택했을 때만 보임) |
| 문서 크기 | 567자 · 21줄 | — |
| 코드 검사 | ✕ 2 ⚠ 1 / ✓ / — | 문제점 패널을 엽니다. 마우스를 올리면 사용한 검사 도구 이름 |
| 들여쓰기 | 공백: 4 / 탭: 4 | 자동 들여쓰기 켜기/끄기, 공백 2 · 3 · 4 · 8, 탭 2 · 4 · 8 중 고르기 |
| 줄 끝 | CRLF / LF / CR | 줄 끝 바꾸기 |
| 인코딩 | UTF-8 | 저장할 인코딩 고르기, 다른 인코딩으로 다시 열기… |
| 언어 | JavaScript | 자동, 일반 텍스트, 자주 쓰는 12개 언어, 언어… (전체 목록) |
| 배율 | 100% | 기본 크기로 되돌리기 |
| ⋱ 크기 조절 표시 | | 끌어서 창 크기 바꾸기(데스크톱) |

코드 검사 항목은 코드 검사가 켜져 있고 문서가 열려 있을 때만 보입니다. 오류가 있으면 빨강, 경고만 있으면 노랑으로 칠해지고, 검사 중에는 흐리게 보입니다.

## 창 크기 조절

- 상태 표시줄 오른쪽 끝의 **⋱ 표시**를 끌면 창 크기가 바뀝니다(데스크톱 앱). 창 가장자리를 끌어도 됩니다.
- 메뉴 바의 빈 곳을 더블클릭하거나 최대화 버튼을 누르면 최대화 / 이전 크기로 전환됩니다.
- **F11**(보기 › 전체 화면)은 전체 화면으로 바꿉니다.
- 창의 위치와 크기는 다음 실행 때 그대로 복원됩니다.
