# 보기와 테마

화면에 무엇을 보일지, 글자를 어떻게 그릴지, 어떤 색으로 꾸밀지를 정하는 방법입니다. 편집기가 글을 그리는 방식은 **편집기** 메뉴에, 창의 배치는 **보기** 메뉴에 있습니다. 모든 항목은 바꾸는 즉시 적용되고 저장됩니다.

### 자동 줄 바꿈

켜면 창 폭보다 긴 줄이 다음 줄로 접혀 보입니다. 파일에 줄 바꿈 문자가 들어가는 것은 아니며 보기만 바뀝니다. 도구 모음의 자동 줄 바꿈 버튼으로도 켜고 끕니다.

### 공백 문자 표시

켜면 공백은 가운데 점, 탭은 화살표로 보이고, 줄 끝에 남은 공백은 따로 강조됩니다. 도구 모음의 **¶** 버튼으로도 켜고 끕니다.

### 미니맵

코드 문서의 편집기 오른쪽 끝에 문서 전체를 작게(글자마다 작은 색 블록, 테마의 구문 색으로) 그린 그림입니다. 지금 화면에 보이는 부분이 띠로 표시됩니다.

- **누르면** 그 위치로 스크롤되고 커서가 그 줄로 갑니다.
- **끌면** 편집기가 마우스를 따라 스크롤됩니다(미니맵 밖으로 나가도 계속 따라감).
- 편집기보다 긴 문서는 미니맵 자체도 편집기와 함께 스크롤됩니다.
- Markdown · 그림 · 오디오 · 동영상 문서에는 나오지 않습니다. 보기 › **구조** 는 코드 문서에서 미니맵을, Markdown 문서에서 구조(제목 트리)를 켜고 끕니다.

**탭 안내선**은 들여쓰기 안에 탭 크기마다 가는 세로선을 그려 블록의 깊이를 쉽게 알아보게 합니다. 도구 모음에도 전용 버튼이 있습니다.

**전체 화면**(F11)에서는 창이 화면 전체를 덮습니다. 다시 F11 을 누르면 돌아옵니다.

도구 모음 · 상태 표시줄 · 폴더 트리 표시는 설정 › 일반 › 화면 묶음에서도 바꿀 수 있습니다.

## 테마

40가지 기본 테마(어두운 테마 20 · 밝은 테마 20)가 있고, 각 테마는 창의 색뿐 아니라 **편집기의 구문 강조 색**까지 함께 바꿉니다. 기본 테마는 미드나이트입니다.

도구 모음 오른쪽 끝(도구 모음을 숨기면 메뉴 바 오른쪽)의 **테마 버튼**으로 바꿉니다.

- 버튼의 **앞부분**(팔레트 아이콘과 지금 테마 이름)을 누를 때마다 **다음 테마**로 바뀝니다. 마우스를 올리면 다음에 올 테마 이름이 나옵니다. 시작 화면의 **다음 테마** 카드도 같습니다.
- **▾** 를 누르면 모든 테마 목록이 나옵니다. **어두운 테마 20개가 한 열, 밝은 테마 20개가 그 옆 한 열**로 나란히 보이고, 각 테마 앞에 대표 색 견본이 있으며, 지금 테마에 체크가 붙습니다. 직접 만든 테마는 ★ 표시로 그 모드의 열 뒤에 나옵니다.

## 사용자 정의 테마

설정 › 테마 탭 아래쪽 **사용자 정의 테마** 부분에서 나만의 테마를 만듭니다.

1. 바탕으로 쓸 테마를 먼저 고릅니다.
2. **+ '테마 이름'을(를) 바탕으로 새 테마 만들기** 를 누르면 지금 테마를 복사한 새 테마("… (사용자)")가 만들어지고 바로 적용됩니다.
3. **이름**을 바꾸고, **어두운 테마 / 밝은 테마** 중 어느 모드인지 고릅니다(테마 목록에서 어느 열에 들어갈지가 정해짐).
4. 아래 15가지 색을 색 고르기 상자나 `#rrggbb` 값으로 정합니다. 바꾸는 즉시 화면에 반영됩니다.
   - 편집기 배경 · 패널 배경 · 메뉴·툴바 배경 · 마우스 오버 · 비활성 선택
   - 테두리 · 진한 테두리 · 글자 · 흐린 글자
   - 강조색 · 진한 강조색 · 강조색 위 글자
   - 폴더 아이콘 · 파일 아이콘 · 경고·오류
5. 드롭다운에서 다른 사용자 정의 테마를 고르면 그 테마가 적용되고 편집 대상이 됩니다. **이 테마 삭제** 는 지금 사용자 정의 테마를 지우고 미드나이트로 돌아갑니다.

만든 테마는 도구 모음의 테마 목록과 설정의 카드에 ★ 표시로 나타납니다.

## 글꼴

편집기 글꼴은 도구 모음의 **글꼴 칸**(T 아이콘 옆)이나 설정 › 일반 › 화면의 **글꼴**에서 고릅니다.

![글꼴 고르기](images/font-picker.png)
*그림: 시스템 글꼴 목록 — 각 이름이 그 글꼴로 그려짐*

- 칸을 누르면 **시스템에 설치된 모든 글꼴**이 스크롤되는 목록으로 나옵니다(처음 누를 때 읽어 옴). 각 항목은 그 글꼴로 그려져 고르기 전에 모양을 볼 수 있습니다.
- 글자를 입력하면 목록이 걸러지고, ↑ ↓ 로 옮기고 Enter 로 고릅니다. Esc 는 목록을 닫습니다. 목록에 없는 이름을 직접 입력해도 됩니다.
- 비우면 기본 고정폭 글꼴을 씁니다.
- 옆의 **− 크기 +** 로 글꼴 크기(8 – 40px)를 바꿉니다. 확대 / 축소(Ctrl+= / Ctrl+−, Ctrl+휠)와 같은 값입니다.
- **줄 높이**(글꼴 크기의 1 – 3배, 기본 1.55)는 설정 › 일반 › 화면에서 정합니다.

글꼴 · 크기 · 줄 높이는 소스 편집기와 WYSIWYG 열에 함께 적용되고, 16진수 보기도 글꼴 크기를 따릅니다.

## UI 언어

화면의 언어는 **한국어**와 **English** 두 가지입니다.

- 도구 모음 오른쪽(또는 메뉴 바 오른쪽)의 **국기 버튼**을 누르면 바로 전환됩니다. 국기는 **바꿀 언어**의 국기입니다(한국어 화면에서는 영국 국기, 영어 화면에서는 태극기).
- 설정 › 일반 › 화면의 **UI 언어**에서도 고릅니다.
- 메뉴 · 대화상자 · 설정 · 별도 창(설정, 정보, 단축키)이 모두 함께 바뀝니다. 메뉴 제목 간격은 언어가 바뀌어도 고르게 유지됩니다.

설정 창의 **기본값으로 되돌리기**는 UI 언어를 바꾸지 않습니다.
