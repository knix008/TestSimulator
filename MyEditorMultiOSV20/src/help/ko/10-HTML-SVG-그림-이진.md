# HTML · SVG · 그림 · 이진 파일

My Editor 는 텍스트만이 아니라 웹 페이지, 벡터 그림, 사진 · 의료 영상, 이진 파일, 오디오 · 동영상도 엽니다. 파일 종류마다 편집 창의 모습과 쓸 수 있는 도구가 다릅니다.

| 파일 | 편집 창 | 쓸 수 있는 것 |
|---|---|---|
| HTML (.html, .htm) | 소스 편집기 | 미리보기, 브라우저에서 실행 |
| SVG (.svg) | 소스 편집기 + 그림 미리보기 | SVG 요소 넣기 도구 줄 |
| PNG · JPEG · GIF · WebP · BMP · ICO · AVIF | 그림이 창을 채움 | 확대 · 이동, Hexa |
| HEIC · HEIF | 그림 (여러 장이면 슬라이더) | 확대 · 이동, 장 넘기기, Hexa |
| DICOM (.dcm, .dicom) | 의료 영상 (프레임 · 시리즈 슬라이더) | 윈도우/레벨, 프리셋, 반전, HU 값, 정보, Hexa |
| 오디오 · 동영상 | 재생기 | 재생 · 정지 · 위치 · 음량 |
| 그 밖의 이진 파일 | 16진수 보기 | 바이트 선택 · 16진수 복사 |

## HTML 미리보기

HTML 문서에서 도구 모음의 **미리보기** 버튼(눈 모양, Ctrl+Shift+M) 또는 보기 › 미리보기를 누르면 편집기 오른쪽에 페이지가 그려집니다.

![HTML 미리보기](images/html-preview.png)
*그림: HTML 소스와 옆의 미리보기*

- 미리보기는 그 문서가 있는 편집 창 안의 **격리된 페이지**입니다. 페이지의 스크립트는 편집기와 분리된 채 실행됩니다.
- 문서 폴더를 기준으로 한 로컬 **그림 · CSS · 스크립트 파일**도 함께 불러옵니다.
- **입력하는 대로** 갱신됩니다. 저장하지 않아도 됩니다.
- 편집기와 미리보기 사이의 경계선을 끌어 폭을 바꿉니다(20% – 80%).
- 미리보기 켜기 상태는 모든 HTML 문서에 공통이며 기억됩니다.

## HTML 실행

도구 모음의 **실행** 버튼(재생 모양) 또는 보기 › 실행은 HTML 파일을 **시스템 기본 브라우저**에서 엽니다. 브라우저는 디스크의 파일을 읽으므로, 저장하지 않은 변경이 있거나 새 문서이면 **먼저 저장**합니다(새 문서는 위치를 묻습니다). 열리면 상태 표시줄에 "브라우저에서 열었습니다: 이름" 이 나옵니다. HTML 이 아닌 문서에서는 이 버튼이 꺼져 있습니다.

## SVG

SVG 는 텍스트(XML) 문서이므로 소스를 편집기에서 고치고, 오른쪽 **그림 미리보기**에서 결과를 봅니다. 미리보기는 기본으로 켜져 있으며, 도구 모음의 미리보기 버튼(SVG 일 때는 그림 아이콘)이나 Ctrl+Shift+M 으로 끄고 켭니다. 입력을 멈추면 곧바로 다시 그려집니다.

![SVG 편집과 미리보기](images/svg-preview.png)
*그림: SVG 소스, 요소 넣기 도구 줄, 그림 미리보기*

SVG 문서에서는 탭 줄 아래에 **요소 넣기 도구 줄**이 나타납니다. 버튼을 누르면 커서 위치에 그 요소의 틀이 들어갑니다.

| 버튼 | 들어가는 것 |
|---|---|
| 사각형 | `<rect>` |
| 원 | `<circle>` |
| 타원 | `<ellipse>` |
| 선 | `<line>` |
| 꺾은선 | `<polyline>` |
| 다각형 | `<polygon>` |
| 경로(곡선) | `<path>` |
| 텍스트 | `<text>` |
| 이미지 | `<image>` |
| 그룹 (선택 영역을 감쌈) | `<g>` — 선택한 요소들을 감쌉니다 |
| 그러데이션 정의 | `<linearGradient>` |
| 재사용 (use) | `<use>` |
| 변형 속성 (회전·이동) | `transform=` 속성 |

미리보기에서는 그림 파일과 같은 방법(아래)으로 확대 · 축소 · 이동합니다.

## 그림 보기

PNG · JPEG · GIF · WebP · BMP · ICO · AVIF · HEIC · HEIF · DICOM 파일을 열면 **그림이 편집 창을 채웁니다**. 그림 파일은 여기서 편집하거나 저장할 수 없습니다.

![그림 보기](images/image-view.png)
*그림: 그림 파일 — 위에 안내와 Hexa 버튼, 아래에 크기와 배율*

- 처음에는 **창에 맞춤**으로 보입니다.
- **왼쪽 클릭**: 확대, **오른쪽 클릭**: 축소, **Ctrl+마우스 휠**: 확대 · 축소(5% – 1600%). 확대해도 그림이 창 가운데에 머뭅니다.
- 그림이 창보다 크면 **끌어서 이동**합니다.
- 투명한 부분 뒤에는 바둑판무늬가 깔립니다.
- 아래 줄에 파일 이름, **픽셀 크기**(예: 1920 × 1080 px), 지금 배율 또는 "창에 맞춤" 이 나옵니다.
- 탭 줄 아래 도구 줄에는 사용법 안내와 오른쪽 끝의 **Hexa** 버튼이 있습니다.

### HEIC · HEIF

아이폰 사진 등에 쓰이는 HEIC · HEIF 는 디코드해서 보여 줍니다. 한 파일에 그림이 여러 장 들어 있으면 그림 아래에 **슬라이더**가 생깁니다.

- ◀ ▶ 버튼, 슬라이더 끌기, **← → (또는 PgUp / PgDn)** 로 장을 넘깁니다. **Home / End** 는 처음 / 마지막 장.
- "n / 전체" 로 지금 장이 표시됩니다.

### DICOM

의료 영상 DICOM(.dcm) 파일은 다음 도구와 함께 열립니다.

- 여러 프레임이 든 파일, 또는 **같은 폴더에 있는 같은 시리즈의 .dcm 파일들**을 슬라이더로 넘겨 봅니다(키보드는 HEIC 와 같음).
- **연속 재생** 버튼(또는 Space)으로 프레임을 자동으로 넘깁니다.
- **창 너비 · 창 중심** 슬라이더로 윈도우/레벨을 조절합니다.
- **프리셋**: 기본 · 복부 · 뼈 · 뇌 · 폐 · 연부 · 간 — 누르면 그 부위에 맞는 윈도우/레벨이 됩니다.

| 프리셋 | 창 너비 | 창 중심 |
|---|---|---|
| 복부 | 400 | 40 |
| 뼈 | 1800 | 400 |
| 뇌 | 80 | 40 |
| 폐 | 1500 | −600 |
| 연부 | 350 | 50 |
| 간 | 150 | 30 |

- **반전** 버튼: 흑백을 뒤집습니다.
- **DICOM 정보** 버튼: 환자 · 검사 · 시리즈 · 모달리티 · 비트 수 등 태그 정보를 펼칩니다.
- 그림 위에서 마우스를 움직이면 아래 줄에 그 지점의 **HU 값**(CT 등) 또는 픽셀 값이 나옵니다.

## Hexa (그림 옆 16진수)

그림 파일에서 도구 줄의 **Hexa** 버튼, 보기 › Hexa, 탭 오른쪽 클릭 메뉴의 Hexa, 또는 창을 나눴을 때 창 머리의 Hexa 버튼을 누르면 **그림 옆에 파일의 바이트가 16진수로** 나란히 보입니다. 다시 누르거나 16진수 보기 머리의 × 로 닫습니다.

## 16진수 보기 (이진 파일)

텍스트가 아닌 파일(실행 파일, 압축, PDF, 알 수 없는 형식 등)을 열면 "이진 파일을 16진수로 엽니다" 라고 알리고 **16진수 보기**로 엽니다. 크기가 큰 파일도 보이는 부분만 읽어서 바로 열립니다.

![16진수 보기](images/hex-view.png)
*그림: 오프셋 · 16진수 · ASCII 세 열의 16진수 보기*

- 머리에 파일 이름과 크기("이진 파일 · 1.2 MB (1,234,567 바이트)")가 나옵니다.
- 본문은 **오프셋 · 16진수 바이트 · ASCII** 세 열입니다. 글자로 보일 수 없는 바이트는 점으로 표시됩니다.
- **바이트를 누르면** 선택되고(16진수 열과 ASCII 열에 함께 강조), **Shift+클릭**으로 범위를 넓힙니다. **Ctrl+A** 는 전체를 선택합니다.
- 몇 GB 짜리 파일도 화면에 보이는 줄만 64 KB 씩 읽어 오므로 작은 파일처럼 스크롤됩니다. 글자로 보일 수 없는 바이트는 ASCII 열에 · 로 표시됩니다.
- 아래 줄에 커서 위치의 오프셋(16진수와 10진수), 그 바이트의 값과 글자, 선택한 바이트 수가 나옵니다.
- **Ctrl+C** 는 선택한 바이트를 16진수 문자열로 복사합니다(한 번에 1 MB 까지).
- 16진수 보기는 **읽기 전용**입니다. 편집 · 저장 · 찾기는 할 수 없습니다.

## 오디오 · 동영상

mp3 · wav · ogg · oga · flac · aac · m4a · opus · aiff · aif · wma (오디오), mp4 · m4v · webm · ogv · mov · mkv · avi (동영상) 파일은 **재생기**로 열립니다.

- **재생 / 일시정지**, **정지** 버튼
- **위치** 막대로 원하는 시점으로 이동
- **음소거 / 음소거 해제** 버튼과 **음량** 막대
- 상태 표시: 불러오는 중 · 재생 중 · 일시정지 · 정지 · 끝

운영체제의 웹 엔진이 재생하지 못하는 코덱이면 "이 형식은 여기서 재생할 수 없습니다" 라고 나옵니다. 오디오 · 동영상은 편집 · 저장할 수 없습니다.

> 팁: 그림 · 이진 파일 · 오디오 · 동영상에서는 미니맵 · 찾기 · 문서 정렬 같은 텍스트 도구가 꺼집니다. 이진 파일은 텍스트로 바꿔 보는 기능이 없고 늘 16진수 보기로 열립니다.
