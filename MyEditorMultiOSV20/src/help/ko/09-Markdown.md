# Markdown

`.md` 문서를 열면 Markdown 전용 기능이 켜집니다: 서식을 넣는 **Markdown 도구 모음**, 기호를 렌더링한 채로 고치는 **WYSIWYG** 열, 결과 페이지를 보여 주는 **미리보기** 열, 제목을 트리로 보여 주는 **구조** 열입니다. 네 가지는 모두 그 문서가 있는 편집 창 안에 나란히 열립니다.

## 열 배치

Markdown 문서의 편집 창은 최대 네 개의 열로 나뉩니다. 왼쪽부터 다음 순서입니다.

| 열 | 머리 제목 | 켜고 끄기 | 기본값 |
|---|---|---|---|
| 구조 | 구조 | Markdown 도구 모음 오른쪽의 구조 버튼, 보기 › 구조, 열 머리의 × | 꺼짐 |
| 소스 편집기 | 편집 | 항상 보임 | |
| WYSIWYG | WYSIWYG | Markdown 도구 모음 오른쪽의 WYSIWYG 버튼, Ctrl+Shift+W, 보기 › WYSIWYG, 열 머리의 × | 켜짐 |
| 미리보기 | 미리보기 | 도구 모음의 미리보기 버튼, Ctrl+Shift+M, 보기 › 미리보기, 열 머리의 × | 꺼짐 |

- 열 사이의 **구분선을 끌면** 그 구분선 양쪽 두 열의 폭만 바뀝니다. 바꾼 폭은 기억됩니다.
- 편집 · WYSIWYG · 미리보기 중 하나를 열거나 닫으면 세 내용 열은 다시 같은 폭으로 맞춰집니다. 구조 열은 그보다 좁게 열립니다.
- 창을 나눴을 때도 이 열들은 **그 문서가 있는 창 안에만** 생기고 다른 창 옆에 붙지 않습니다. 켜고 끄는 설정은 모든 Markdown 문서에 공통입니다.
- Markdown 문서에는 미니맵이 나오지 않습니다(구조 열이 그 역할을 합니다).

## Markdown 도구 모음

Markdown 문서가 활성 문서이면 탭 줄 아래에 서식 버튼 줄이 나타납니다. 버튼은 소스 편집기와 WYSIWYG 중 커서가 있는 쪽에 적용됩니다. 마우스를 올리면 이름과 단축키가 나옵니다.

| 버튼 | 단축키 | 동작 |
|---|---|---|
| H1 ~ H6 | Ctrl+1 ~ Ctrl+6 | 커서가 있는 줄(선택한 줄들)을 그 단계 제목으로 바꿉니다. 같은 단계를 다시 누르면 제목이 풀립니다 |
| **B** | Ctrl+B | 굵게 — `**…**` 로 감쌉니다 |
| *I* | Ctrl+I | 기울임 — `*…*` |
| ~~S~~ | Ctrl+Shift+X | 취소선 — `~~…~~` |
| <> | Ctrl+\` | 인라인 코드 — 백틱으로 감쌈 |
| 인용 | Ctrl+Shift+Q | 줄 앞에 `>` (다시 누르면 제거) |
| 글머리 기호 목록 | Ctrl+Shift+8 | 줄 앞에 `-` |
| 번호 매기기 목록 | Ctrl+Shift+7 | 줄 앞에 `1.` `2.` … |
| 체크리스트 | Ctrl+Shift+9 | 줄 앞에 `- [ ]` |
| 코드 블록 | Ctrl+Shift+C | 선택 영역을 백틱 세 개(코드 펜스)로 감쌉니다. 선택이 없으면 빈 코드 블록을 넣습니다 |
| 링크 | Ctrl+K | `[텍스트](url)` 을 넣고 `url` 부분을 선택해 둡니다. 선택한 글이 있으면 그것이 링크 글자가 됩니다 |
| 이미지 | Ctrl+Shift+I | 이미지 넣기 창을 엽니다(아래 절) |
| 표 | | 머리글 3칸 · 본문 2줄짜리 표 틀을 넣고 첫 머리글을 선택해 둡니다 |
| 구분선 | | `---` 줄을 넣습니다 |

굵게 · 기울임 · 취소선 · 인라인 코드는 선택한 글을 감싸고, 이미 감싸져 있으면 풉니다. 줄 앞 기호(인용 · 목록 · 체크리스트)도 다시 누르면 제거됩니다.

도구 모음 **오른쪽 끝**에는 **구조** 버튼과 **WYSIWYG** 버튼이 있습니다. 켜져 있을 때 강조됩니다.

> 팁: Markdown 문서에서는 Ctrl+B 가 굵게, Ctrl+1 ~ 6 이 제목, Ctrl+\` 가 인라인 코드이므로, 폴더 트리는 **Ctrl+Shift+B**, 탭 이동은 Ctrl+Tab, 터미널은 도구 모음 버튼이나 보기 메뉴를 쓰세요.

## WYSIWYG 편집

WYSIWYG 열은 같은 문서를 **렌더링된 모습 그대로 편집**하는 두 번째 편집기입니다. 여기서 고친 내용은 곧바로 소스에 반영되고(실행 취소 기록도 하나), 소스에서 고친 내용도 곧바로 여기에 나타납니다.

![WYSIWYG 편집](images/md-wysiwyg.png)
*그림: 소스 편집기(왼쪽)와 WYSIWYG 열(오른쪽)*

- 제목은 단계별로 크게, 굵게 · 기울임 · 취소선은 그 모양으로 보이고 기호는 숨겨집니다.
- 목록 기호는 **•**, 체크리스트는 **실제 체크 상자**(누르면 `[ ]` ↔ `[x]` 가 바뀜), 인용은 왼쪽 막대, 코드 블록은 상자, 구분선은 선으로 보입니다.
- 기호(`#`, `**`, `-` …)는 **커서가 있는 줄에서만** 다시 나타나므로 언제든 직접 고칠 수 있습니다.
- 커서를 옮기면 두 편집기가 같은 위치를 같은 높이에 보여 주도록 서로 따라갑니다.
- 소스 편집기는 WYSIWYG 와 관계없이 늘 원본 기호를 그대로, 고정폭 글꼴로 보여 줍니다.

### 그림

WYSIWYG 에서 `![설명](경로)` 와 `<img src=… width=…>` 는 **실제 그림**으로 보입니다. 경로는 문서 폴더 기준 상대 경로, 절대 경로, http(s) 주소, data URL 모두 됩니다.

- 다른 기호와 달리 커서가 그 줄에 있어도 구문이 아니라 늘 그림으로 보입니다. 커서는 그림을 한 글자처럼 건너뛰고, Backspace / Delete 는 그림을 통째로 지웁니다. 구문을 고치려면 소스 편집기에서 고치세요.
- 그림 **오른쪽 아래 모서리의 손잡이를 끌면 크기**가 바뀝니다. 크기는 모든 Markdown 렌더러가 이해하는 `<img src="…" alt="…" width="N">` 형태로 문서에 기록됩니다.

## 이미지 넣기

Markdown 도구 모음의 이미지 버튼(Ctrl+Shift+I)은 **이미지 넣기** 창을 엽니다.

- **파일 / URL**: 찾아보기…로 그림 파일을 고르거나, 경로나 http(s) 주소를 입력합니다. 고르면 창 안에 미리 보입니다.
- **대체 텍스트**: 그림을 설명하는 글(alt).
- **포함 방식**
  - **링크**: 문서 폴더 기준 상대 경로로 참조합니다(가능할 때). 문서와 그림을 함께 옮겨야 합니다.
  - **내장**: 그림을 Base64 로 바꿔 문서 안에 넣습니다. 늘어나는 용량이 표시됩니다. 문서 하나만 있으면 어디서나 그림이 보입니다.
- **너비**: px 단위. 비우면 원본 크기입니다. 너비를 주면 `<img … width="N">` 형태로 들어갑니다.
- **넣기** 를 누르면 커서 위치에 들어갑니다.

또는 PNG · JPEG · GIF · WebP · SVG · BMP · AVIF · ICO · HEIC · HEIF · DCM 파일을 Markdown 문서에 **끌어다 놓거나**(놓은 위치에 들어감), 클립보드의 그림을 **붙여넣으면**(Ctrl+V) 파일 참조가 아니라 **Base64 data URL 로 문서 안에 포함**됩니다. 그림이 아닌 파일을 끌어다 놓으면 그 파일이 열립니다.

## 미리보기

도구 모음의 **미리보기** 버튼(눈 모양, Ctrl+Shift+M)은 렌더링된 결과 페이지를 소스 오른쪽 열에 엽니다.

![Markdown 미리보기](images/md-preview.png)
*그림: 소스 옆의 미리보기 열*

- 편집하는 대로 잠시 뒤 갱신됩니다. 문서 폴더 기준의 로컬 그림도 보입니다.
- 편집기와 미리보기는 **양방향으로 따라갑니다**. 편집기에서 커서를 옮기면 커서가 있는 문단 · 제목 · 목록이 편집기의 커서 줄과 같은 높이에 오도록 미리보기가 스크롤되고, 편집기를 스크롤하면 맨 위에 보이는 블록을 따라갑니다. 미리보기를 스크롤하면 편집기가 미리보기 맨 위에 보이는 내용의 줄로 이동합니다.
- 미리보기의 http(s) 링크를 누르면 시스템 브라우저로 열립니다.
- 미리보기에서 글을 선택해 복사할 수 있습니다.

미리보기에서 **오른쪽 클릭**하면 메뉴가 나옵니다.

| 항목 | 설명 |
|---|---|
| 이미지 복사 | (그림 위에서) 그림을 클립보드로 복사해 다른 프로그램에 붙여넣을 수 있게 합니다 |
| 이미지 다른 이름으로 저장… | (그림 위에서) 그림을 파일로 내보냅니다 |
| 복사 | 선택한 글 복사 |
| 모두 선택 | 미리보기 전체 선택 |
| 인쇄… | 인쇄 미리보기 열기 — Markdown 은 렌더 결과 그대로 인쇄됩니다 |

**이미지 저장** 창에서는 다음을 고릅니다.

- **파일 형식**: PNG · JPEG · WebP · BMP, 또는 원본 그대로.
- JPEG · WebP 의 **품질**.
- 그림에 투명한 부분이 있으면 **투명 배경 유지**(PNG · WebP) 또는 **배경색**으로 채우기. JPEG · BMP 는 투명을 지원하지 않아 늘 배경색으로 채우며, 색은 고를 수 있습니다. 미리보기의 바둑판무늬가 투명한 부분입니다.
- **파일 이름**과 저장 위치.

## 구조 (제목 트리)

**구조** 열은 문서의 제목(`#` ~ `######`, 그리고 `===` / `---` 로 밑줄 친 제목)을 폴더 트리처럼 연결선이 있는 **트리**로 보여 줍니다. 깊은 단계의 제목은 바로 앞의 얕은 제목 아래에 들어갑니다. 코드 블록 안의 `#` 은 제목으로 치지 않습니다.

![구조](images/md-outline.png)
*그림: 편집기 왼쪽의 구조 열*

- 머리에 "구조" 와 제목 개수가 보이고, **모두 펼치기 · 모두 접기 · ×(닫기)** 버튼이 있습니다.
- 가지 앞의 ⊞ / ⊟ 로 그 가지만 접고 폅니다.
- 제목을 누르면 커서가 그 제목으로 가고, 소스 편집기와 WYSIWYG 열 모두 그 제목이 맨 위에 오도록 스크롤됩니다.
- **커서가 들어 있는 제목**이 강조되어 지금 어디를 편집하는지 알 수 있습니다.
- 제목에 마우스를 올리면 제목 단계와 줄 번호가 보입니다.
- 제목이 없으면 "제목이 없습니다 (# 제목 …)" 라고 나옵니다.
- 편집하는 대로 다시 만들어집니다.

코드 문서에서 보기 › 구조는 같은 자리의 **미니맵**을 켜고 끕니다([보기와 테마](16-보기와-테마.md)).
