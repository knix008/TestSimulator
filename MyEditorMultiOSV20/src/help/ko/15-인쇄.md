# 인쇄

인쇄는 언제나 **인쇄 미리보기**를 먼저 보여 줍니다. 종이에 나올 모습을 쪽 단위로 확인하고, 옵션을 바꿔 보고, 프린터와 매수를 고른 뒤 인쇄합니다.

## 인쇄 시작

- **Ctrl+P**
- **파일 › 인쇄…**
- 도구 모음의 **인쇄** 버튼
- 시작 화면의 **인쇄…** 카드
- Markdown 미리보기의 오른쪽 클릭 메뉴 › 인쇄…

문서를 인쇄용으로 만드는 동안(긴 코드는 구문 강조와 쪽 나누기에 시간이 걸림) 진행 막대가 있는 작은 창이 뜹니다. 데스크톱 앱에서 인쇄 미리보기는 별도의 창으로 열립니다.

## 문서 종류별 인쇄 결과

| 문서 | 인쇄되는 모습 |
|---|---|
| 코드 · 일반 텍스트 | 고른 용지로 쪽을 나눈 **목록**. 구문 강조 · 줄 번호 · 머리글 등은 인쇄 설정을 따름 |
| Markdown | 미리보기와 같은 **렌더링 결과**(그림 포함) |
| HTML | 그 페이지를 렌더링한 결과(로컬 그림 · CSS 포함) |
| 그림 파일 · SVG | 그림 그대로 |

인쇄 설정(용지 · 머리글 · 구문 강조 등)은 **코드와 일반 텍스트**에만 적용됩니다. Markdown · HTML · 그림에는 적용되지 않습니다.

## 인쇄 미리보기 창

![인쇄 미리보기](images/print-preview.png)
*그림: 인쇄 미리보기 — 위에 배율과 옵션, 가운데에 쪽, 오른쪽에 프린터 설정*

**위쪽 줄**

- 문서 이름
- **축소 / 배율 / 확대**: 50% · 75% · 100% · 125% · 150% 사이를 오갑니다. Ctrl+마우스 휠로도 바꿉니다.
- **맞춤**: 쪽이 창에 맞도록 크기를 맞춥니다.

**옵션 줄** (코드 · 텍스트 문서일 때만) — 체크하면 미리보기에 바로 반영되고, 설정 › 인쇄의 같은 항목에도 저장됩니다.

| 체크 상자 | 뜻 |
|---|---|
| 파일 이름 / 경로 | 쪽 위에 파일 이름(경로)과 언어 |
| 줄 번호 | 왼쪽에 줄 번호 열 |
| 페이지 테두리 | 쪽마다 둘레에 테두리 |
| 페이지 번호 | 쪽 아래에 "n / 전체" |
| 인쇄 날짜 | 머리글에 인쇄한 날짜 |
| 구문 강조 | 키워드 · 문자열 · 주석 색(용지에 맞는 밝은 색) |
| 컬러 | 끄면 흑백(굵기만 유지) |
| 줄무늬 | 한 줄씩 연한 회색 배경 |
| 여백 배경 | 줄 번호 열에 옅은 배경 |
| 줄 바꿈 | 쪽 폭보다 긴 줄을 다음 줄로 이어서 인쇄(끄면 잘림) |

**가운데** — 실제 용지 크기의 쪽이 차례로 보입니다.

**오른쪽 칸**

- **프린터**: 설치된 프린터 목록. 프린터가 없으면 "설치된 프린터가 없습니다. 기본 프린터로 인쇄합니다." 라고 나옵니다.
- **매수**: 1 – 99
- **용지 크기**: A4 · Letter · Legal · A5
- **방향**: 세로 · 가로
- **색**: 컬러 · 흑백

**아래쪽** — **취소** 는 창을 닫고, **인쇄** (또는 Enter) 는 인쇄합니다. 데스크톱 앱은 고른 프린터로 바로 보내며, 보내는 동안 "인쇄하는 중…" 이 표시됩니다. 실패하면 이유가 오른쪽 칸 아래에 나옵니다. 웹 버전은 새 브라우저 창을 열어 브라우저의 인쇄 기능으로 보냅니다.

## 인쇄 설정

설정 › **인쇄** 탭에서 코드 · 텍스트 인쇄의 기본값을 정합니다. 오른쪽에 두 쪽짜리 **미리보기** 견본이 있어 바꾼 결과를 바로 보여 줍니다.

![인쇄 설정](images/settings-print.png)
*그림: 설정 › 인쇄*

| 묶음 | 항목 | 기본값 |
|---|---|---|
| 용지 | 용지 크기 (A4 · Letter · Legal · A5) | A4 |
| | 방향 (세로 · 가로) | 세로 |
| | 여백 (6 – 25 mm) | 12 mm |
| 구성 | 파일 이름 / 경로 | 켜짐 |
| | 줄 번호 | 켜짐 |
| | 페이지 테두리 | 꺼짐 |
| | 페이지 번호 | 꺼짐 |
| | 인쇄 날짜 | 꺼짐 |
| 글꼴 | 글꼴 크기 (7 – 14 pt, 0.5 단위) | 9.5 pt |
| | 줄 간격 (1.1 – 2.0) | 1.45 |
| | 긴 줄 자동 줄 바꿈 | 켜짐 |
| 모양 | 구문 강조 (키워드·문자열·주석 색) | 켜짐 |
| | 컬러로 인쇄 (끄면 흑백, 굵기만 유지) | 켜짐 |
| | 줄무늬 배경 (한 줄씩 연한 회색) | 켜짐 |
| | 줄 번호 여백 배경 | 켜짐 |

들여쓰기의 탭 문자는 편집기의 탭 크기대로 펼쳐서 인쇄합니다. 설정 창의 **기본값으로 되돌리기**는 인쇄 설정도 위 기본값으로 되돌립니다.

> 팁: 코드 리뷰용으로 종이를 아끼려면 가로 방향 · 글꼴 8 pt · 줄 바꿈 켜기 · 줄무늬 끄기를 써 보세요. 흑백 프린터라면 컬러를 끄면 회색 대신 굵기로 구분되어 더 선명합니다.
