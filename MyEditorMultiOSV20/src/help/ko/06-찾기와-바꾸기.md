# 찾기와 바꾸기

현재 문서에서 글을 찾고 바꾸는 **찾기 줄**, 폴더 전체나 열린 문서 모두를 뒤지는 **검색 영역**, 그리고 원하는 줄로 바로 가는 **줄로 이동**을 설명합니다. 명령은 **찾기** 메뉴에 모여 있습니다.

![찾기 메뉴](images/menu-find.png)
*그림: 찾기 메뉴*

| 메뉴 항목 | 단축키 | 설명 |
|---|---|---|
| 찾기… | Ctrl+F | 찾기 줄을 엽니다 |
| 다음 찾기 | F3 | 다음 일치 위치로 |
| 이전 찾기 | Shift+F3 | 이전 일치 위치로 |
| 바꾸기… | Ctrl+H | 바꾸기 칸까지 있는 찾기 줄을 엽니다 |
| 일치하는 항목 모두 선택 | | 찾은 곳마다 커서를 만듭니다(찾기 줄이 열려 있을 때) |
| 폴더에서 찾기… | Ctrl+Shift+F | 폴더 트리에 열린 폴더의 모든 파일에서 찾습니다 |
| 열린 문서에서 찾기… | Ctrl+Alt+F | 열려 있는 모든 문서에서 찾습니다 |
| 줄로 이동… | Ctrl+G | 줄 번호(와 열)로 이동합니다 |

## 찾기 줄

**Ctrl+F**, 도구 모음의 찾기 버튼, 편집 영역의 오른쪽 클릭 메뉴로 엽니다. 탭 줄 바로 아래, 편집기 위에 찾기 줄이 나타나고 입력 칸에 커서가 놓입니다. 문서에서 한 줄 안의 글을 선택한 채로 열면 그 글이 찾을 내용으로 들어갑니다.

![찾기 줄](images/find.png)
*그림: 찾기 줄 — 일치하는 곳이 문서에 강조되고 현재 / 전체 개수가 보임*

- 입력하는 대로 일치하는 곳이 모두 강조되고, 오른쪽에 **현재 / 전체**(예: 2 / 6) 또는 "n개 일치" 가 나옵니다. 하나도 없으면 "일치 없음" 이 나오고 입력 칸이 붉게 표시됩니다.
- **Enter** 또는 **F3** = 다음, **Shift+Enter** 또는 **Shift+F3** = 이전. 끝에 닿으면 처음으로 돌아갑니다. 오른쪽의 **↑ ↓** 버튼도 같습니다.
- **≡ (일치하는 항목 모두 선택)**: 찾은 곳을 모두 선택해 다중 커서를 만듭니다. 이어서 입력하면 모든 곳이 한꺼번에 바뀝니다.
- **×** 또는 **Esc** 로 닫습니다(커서가 편집 영역이나 찾기 줄에 있을 때).
- 찾기 줄이 닫힌 상태에서 F3 / Shift+F3 을 누르면 찾기 줄이 열립니다.

입력 칸 안쪽 오른쪽의 세 버튼으로 찾는 방식을 바꿉니다. 켜진 버튼은 강조됩니다.

| 버튼 | 이름 | 설명 |
|---|---|---|
| Aa | 대/소문자 구분 | 켜면 `Apple` 과 `apple` 을 다르게 봅니다 |
| ab (밑줄) | 단어 단위 | 켜면 낱말 전체가 같을 때만 찾습니다(`cat` 은 `category` 에서 찾지 않음) |
| .* | 정규식 | 찾을 내용을 정규식으로 해석합니다. 식이 잘못되면 입력 칸이 빨갛게 표시되고 아무것도 찾지 않습니다 |

16진수 보기 · 그림 · 오디오 · 동영상 문서에서는 찾기 줄이 열리지 않습니다.

## 바꾸기

**Ctrl+H**, 도구 모음의 바꾸기 버튼으로 엽니다. 찾기 줄 아래에 **바꿀 내용** 칸이 한 줄 더 생깁니다. 찾기 줄 왼쪽 끝의 **▸ / ▾** 버튼으로 찾기만 ↔ 바꾸기를 오갈 수도 있습니다.

![바꾸기](images/replace.png)
*그림: 바꾸기 칸이 열린 찾기 줄*

- **바꾸기** 버튼 또는 바꿀 내용 칸에서 **Enter**: 지금 일치한 곳 하나를 바꾸고 다음으로 넘어갑니다.
- **모두 바꾸기** 버튼 또는 바꿀 내용 칸에서 **Ctrl+Enter**: 문서 안의 모든 일치를 한꺼번에 바꿉니다.
- 정규식을 켰을 때는 바꿀 내용에 `$1`, `$2` 처럼 괄호로 묶은 그룹을 참조할 수 있습니다. 예를 들어 찾을 내용 `(\w+)@(\w+)`, 바꿀 내용 `$2 at $1`.
- 바꾼 것은 모두 Ctrl+Z 로 되돌릴 수 있습니다. 모두 바꾸기도 한 번의 실행 취소로 되돌아갑니다.

## 폴더에서 찾기

폴더 트리에 열린 폴더 안의 모든 파일에서 찾습니다. **Ctrl+Shift+F**, 찾기 › 폴더에서 찾기…, 폴더 트리 머리의 **🔍** 버튼으로 엽니다(폴더 트리가 숨겨져 있었다면 함께 보입니다). 편집기에서 한 줄 안의 글을 선택해 두었다면 그 글이 찾을 내용으로 들어갑니다.

![폴더에서 찾기](images/find-in-files.png)
*그림: 폴더 트리 아래 절반의 검색 영역과 파일별 결과*

검색 영역은 폴더 패널의 **아래 절반**에 열립니다. 폴더 트리와 검색 영역 사이의 구분선을 끌면 비율이 바뀌고, 검색 영역 머리의 **×** (또는 🔍 를 다시 누름)로 닫습니다.

1. 맨 위의 **열린 문서 / 폴더** 버튼으로 범위를 고릅니다. 폴더가 열려 있지 않으면 폴더 버튼은 꺼져 있습니다.
2. **찾을 내용 (Enter)** 칸에 글을 넣습니다. 옆의 **Aa · ab · .*** 은 찾기 줄과 같은 뜻입니다.
3. 범위가 폴더면 그 아래 두 칸에 파일 이름 패턴을 쉼표로 나눠 넣을 수 있습니다.
   - **포함**: 예 `*.js, src/**` — 이 패턴에 맞는 파일만 찾습니다.
   - **제외**: 예 `*.min.js, test/**` — 이 패턴에 맞는 파일과 폴더는 건너뜁니다.
4. **찾기** 버튼이나 Enter 로 시작합니다. 폴더 검색은 백그라운드에서 돌며 진행 창이 뜨고, **취소** 로 멈출 수 있습니다.

결과는 다음과 같이 나옵니다.

- 버튼 옆에 "n개 일치 · 파일 m개" 요약. 결과가 너무 많으면 "(결과가 많아 일부만 표시)" 가 붙습니다(최대 2,000개).
- **파일별로 묶여** 파일 이름, 폴더 안 상대 경로, 일치 개수가 나오고, 파일 이름 줄을 누르면 그 묶음이 접히고 펴집니다.
- 그 아래 각 일치가 **줄 번호**와 그 줄의 내용(일치 부분 강조)으로 나옵니다. 누르면 그 파일이 열리고 그 위치로 커서가 갑니다.

폴더 검색은 다음을 건너뜁니다: `.git` · `.svn` · `.hg` · `node_modules` · `dist` · `release` · `build` · `out` · `target` · `.next` · `.cache` · `__pycache__` · `.venv` · `venv` · `.idea` · `.vscode` · `bower_components` · `coverage` 폴더, 2 MB 가 넘는 파일, 이진 파일. 한 번에 훑는 파일은 5만 개까지입니다.

## 열린 문서에서 찾기

**Ctrl+Alt+F** 또는 찾기 › 열린 문서에서 찾기… 는 같은 검색 영역을 범위 "열린 문서" 로 엽니다. 탭으로 열려 있는 모든 문서를 **저장하지 않은 내용까지 포함해** 찾습니다. 결과를 누르면 그 탭으로 전환되어 그 위치로 갑니다. 폴더가 열려 있지 않을 때도 쓸 수 있습니다.

> 팁: 바꾸기는 현재 문서에서만 됩니다. 여러 파일을 고칠 때는 폴더에서 찾기로 위치를 확인한 뒤 결과를 하나씩 눌러 Ctrl+H 로 바꾸세요.

## 줄로 이동

**Ctrl+G**, 찾기 › 줄로 이동…, 오른쪽 클릭 메뉴로 엽니다. 작은 창에 지금 줄 번호가 미리 들어 있고, 안내에 문서의 줄 수("줄 번호 (1 ~ n), 또는 줄:열")가 나옵니다.

![줄로 이동](images/goto-line.png)
*그림: 줄로 이동 창*

- `120` 처럼 줄 번호만 넣으면 그 줄의 처음으로 갑니다.
- `120:15` 또는 `120,15` 처럼 넣으면 120번째 줄의 15번째 열로 갑니다.
- **Enter** 또는 **이동** 을 누르면 이동하고, 그 줄이 화면 가운데로 옵니다. **Esc** 나 **취소** 로 닫습니다.
- 문서보다 큰 번호를 넣으면 마지막 줄로 갑니다.
