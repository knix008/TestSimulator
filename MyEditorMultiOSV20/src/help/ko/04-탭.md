# 탭

열린 문서는 편집 영역 위의 **탭 줄**에 하나씩 탭으로 놓입니다. 이 장은 탭을 고르고, 옮기고, 닫는 방법과 탭의 오른쪽 클릭 메뉴를 설명합니다.

![탭 줄](images/tabbar.png)
*그림: 탭 줄*

## 탭에 보이는 것

- **아이콘**: 파일 종류를 나타냅니다 — 코드, 일반 텍스트, 그림, 오디오, 동영상, 이진(16진수) 파일, 저장한 적 없는 새 문서가 서로 다른 아이콘입니다.
- **이름**: 파일 이름. 새 문서는 "새 문서 1" 처럼 표시됩니다. 이름이 길면 말줄임표로 줄어듭니다.
- **풍선 도움말**: 마우스를 올리면 전체 경로와 함께 "(수정됨)", "(읽기 전용)" 표시가 나옵니다.
- **●** (닫기 버튼 자리): 저장하지 않은 변경이 있는 문서입니다. 저장하면 다시 × 로 바뀝니다.
- **눈 모양 표시**: 읽기 전용 파일입니다. 내용을 볼 수만 있고 고칠 수 없습니다.
- 지금 편집 중인 **활성 탭**은 강조 색으로 보입니다.

## 탭 고르기와 이동

| 방법 | 동작 |
|---|---|
| 탭 클릭 | 그 문서로 전환 |
| Ctrl+Tab / Ctrl+PgDn | 다음 탭 (마지막에서는 첫 탭으로) |
| Ctrl+Shift+Tab / Ctrl+PgUp | 이전 탭 |
| Ctrl+1 … Ctrl+9 | 1번째 … 9번째 탭 |
| 탭 줄 위에서 마우스 휠 | 탭 줄을 좌우로 스크롤 |

Markdown 문서를 편집하는 중에는 Ctrl+1 ~ Ctrl+6 이 제목(H1 ~ H6) 서식으로 쓰이므로 탭 이동에 쓰이지 않습니다([Markdown](09-Markdown.md) 참고). 창을 나눴을 때는 탭을 누르면 활성 편집 창에 그 문서가 보이고, 다른 창에 이미 보이는 문서의 탭이면 그 창이 활성 창이 됩니다([창 나누기](11-창-나누기.md)).

## 탭이 많을 때

탭이 창 폭보다 많아지면 탭 줄 오른쪽 끝, **+** 버튼 옆에 **<** **>** 버튼이 나타납니다. 누르면 탭 줄이 부드럽게 스크롤되고, 더 갈 곳이 없는 쪽 버튼은 흐려집니다. 스크롤 막대는 없으며, 마우스 휠로도 스크롤됩니다. 활성 탭은 언제나 보이는 자리로 저절로 스크롤됩니다.

## 순서 바꾸기

탭을 끌어서 다른 탭 위에 놓으면 그 자리로 옮겨집니다. 놓을 자리는 끄는 동안 표시됩니다. 바꾼 순서는 세션에 저장되어 다음 실행 때도 유지됩니다.

## 새 탭과 닫기

- 탭 줄 오른쪽의 **+** (새 탭)는 빈 새 문서를 만듭니다(Ctrl+N 과 같음).
- 탭의 **×** 를 누르거나, 탭 위에서 **마우스 가운데 버튼**을 누르면 그 탭이 닫힙니다.
- **Ctrl+W** 는 현재 탭을, **Ctrl+Shift+W** 는 모든 탭을 닫습니다.
- 저장하지 않은 문서는 닫기 전에 저장 / 저장 안 함 / 취소 를 묻습니다. 여러 탭을 한꺼번에 닫을 때 취소를 고르면 거기서 멈추고 나머지 탭은 남습니다.

## 탭 오른쪽 클릭 메뉴

탭을 오른쪽 클릭하면 그 탭이 활성 탭이 되고 다음 메뉴가 나옵니다. 메뉴의 명령은 오른쪽 클릭한 탭에 적용됩니다.

![탭 오른쪽 클릭 메뉴](images/tab-context.png)
*그림: 탭의 오른쪽 클릭 메뉴*

| 항목 | 설명 |
|---|---|
| 저장 | 이 문서를 저장 |
| 다른 이름으로 저장… | 새 위치 · 이름으로 저장 |
| 다시 불러오기 | 디스크의 내용으로 다시 읽기(새 문서에서는 꺼짐) |
| 문서 정렬 | 언어별 정렬 도구로 정리 (Shift+Alt+F) |
| 닫기 | 이 탭 닫기 |
| 다른 탭 모두 닫기 | 이 탭만 남기고 닫기(탭이 하나면 꺼짐) |
| 오른쪽 탭 모두 닫기 | 이 탭보다 오른쪽에 있는 탭 닫기(맨 오른쪽 탭이면 꺼짐) |
| 모두 닫기 | 모든 탭 닫기 |
| Hexa | 그림 파일일 때만: 그림 옆에 바이트를 16진수로 보이기/숨기기 |
| 탐색기에서 보기 | 파일이 있는 폴더를 열어 파일을 선택(데스크톱) |
| 기본 앱으로 열기 | 운영체제의 기본 프로그램으로 열기(데스크톱) |
| 경로 복사 | 전체 경로를 클립보드로 |
| 파일 이름 복사 | 파일 이름만 클립보드로 |

복사하면 상태 표시줄에 "클립보드에 복사했습니다." 가 나옵니다. 탐색기에서 보기와 기본 앱으로 열기는 웹 버전에서 쓸 수 없습니다.

> 팁: 작업하던 문서 몇 개만 남기고 정리하려면, 남길 탭들을 왼쪽으로 끌어 모은 뒤 마지막 탭에서 **오른쪽 탭 모두 닫기** 를 쓰세요.
