# 파일

문서를 만들고, 열고, 저장하고, 닫는 방법과 프로그램이 파일을 지켜 주는 방식(외부 변경 감지, 세션 복원 등)을 설명합니다. 대부분의 명령은 **파일** 메뉴에 있습니다.

![파일 메뉴](images/menu-file.png)
*그림: 파일 메뉴*

| 메뉴 항목 | 단축키 | 설명 |
|---|---|---|
| 새 문서 | Ctrl+N | 이름 없는 빈 문서("새 문서 1" …)를 새 탭으로 엽니다 |
| 열기… | Ctrl+O | 파일을 골라 엽니다(여러 개 선택 가능) |
| 폴더 열기… | Ctrl+Shift+O | 폴더를 골라 왼쪽 폴더 트리에 표시합니다 |
| 폴더 닫기 | | 폴더 트리의 폴더를 닫습니다(폴더가 열려 있을 때만 보임) |
| 저장 | Ctrl+S | 현재 문서를 저장합니다 |
| 다른 이름으로 저장… | Ctrl+Alt+S | 새 위치 · 이름으로 저장합니다 |
| 모두 저장 | Ctrl+Shift+S | 바뀐 문서를 모두 저장합니다 |
| 다시 불러오기 | | 디스크의 내용으로 다시 읽습니다 |
| 인쇄… | Ctrl+P | 인쇄 미리보기를 엽니다([인쇄](15-인쇄.md)) |
| 닫기 | Ctrl+W | 현재 탭을 닫습니다 |
| 모두 닫기 | Ctrl+Shift+W | 모든 탭을 닫습니다 |
| 다른 탭 모두 닫기 | | 현재 탭만 남깁니다 |
| 탐색기에서 보기 | | 파일이 있는 폴더를 열고 파일을 선택해 보여 줍니다(데스크톱) |
| 기본 앱으로 열기 | | 운영체제에서 그 확장자에 연결된 프로그램으로 엽니다(데스크톱) |
| 경로 복사 | | 파일의 전체 경로를 클립보드에 복사합니다 |
| 최근 파일 | | 최근에 연 파일 최대 10개 |
| 최근 파일 목록 지우기 | | 최근 파일 기록을 모두 지웁니다 |
| 종료 | Alt+F4 (macOS ⌘Q) | 프로그램을 끝냅니다 |

저장된 적이 없는 새 문서는 경로가 없으므로 다시 불러오기 · 탐색기에서 보기 · 기본 앱으로 열기 · 경로 복사가 흐리게 꺼집니다.

## 새 문서

**Ctrl+N**, 도구 모음의 첫 번째 버튼, 탭 줄 오른쪽의 **+**, 시작 화면의 새 문서 카드 중 아무것으로나 만듭니다. 새 문서는 "새 문서 1", "새 문서 2" … 처럼 이름이 붙고, 처음 저장할 때 위치와 이름을 정합니다.

새 문서의 인코딩 · 줄 끝 · 언어는 설정 › 일반 › 파일 묶음의 **새 문서 인코딩**(기본 UTF-8), **새 문서 줄 끝**(기본 Unix (LF)), **새 문서 언어**(기본 "자동 (확장자로 판별)")에서 정합니다. 언어가 자동이면 입력한 내용으로 언어를 짐작하고, 저장할 때 붙인 확장자로 다시 판별합니다.

## 파일 열기

다음 방법이 모두 같은 결과를 냅니다.

- **Ctrl+O** 또는 도구 모음의 두 번째 버튼, 파일 › 열기… — 대화상자에서 여러 파일을 한꺼번에 고를 수 있습니다. 대화상자는 현재 문서의 폴더(없으면 폴더 트리의 폴더)에서 시작합니다.
- **폴더 트리**에서 파일을 누릅니다.
- 파일을 **창에 끌어다 놓습니다**(아래 절 참고).
- 탐색기(Finder)에서 연결된 파일을 **더블클릭**하거나, 명령줄에 파일 경로를 주고 실행합니다.
- 시작 화면 · 파일 메뉴의 **최근 파일**을 누릅니다.

이미 열려 있는 파일을 다시 열면 새 탭을 만들지 않고 그 탭으로 이동합니다. 파일을 열면 상태 표시줄에 "열림: 이름" 이 나오고 최근 파일 맨 위에 올라갑니다. 지워져서 없는 파일을 최근 파일에서 고르면 오류를 알리고 목록에서 빠집니다.

파일 종류에 따라 열리는 모양이 다릅니다.

| 파일 | 열리는 모양 |
|---|---|
| 텍스트 · 소스 코드 | 편집기 (구문 강조 언어는 확장자로 자동 판별) |
| SVG | 소스 편집기 + 옆에 그림 미리보기 |
| PNG · JPEG · GIF · WebP · BMP · ICO · AVIF · HEIC · HEIF · DICOM | 그림이 창을 채움 |
| 오디오 · 동영상 (mp3 · wav · mp4 · webm …) | 재생기 |
| 그 밖의 이진 파일 | 16진수(Hexa) 보기 |

자세한 내용은 [HTML · SVG · 그림 · 이진](10-HTML-SVG-그림-이진.md) 장을 보세요.

## 폴더 열기

**Ctrl+Shift+O**, 도구 모음의 세 번째 버튼, 파일 › 폴더 열기…, 폴더 트리 머리의 폴더 버튼으로 폴더를 엽니다. 폴더 트리가 숨겨져 있었다면 함께 보이게 됩니다. 폴더는 한 번에 하나만 열리며, 다음 실행 때도 같은 폴더가 다시 열립니다. **파일 › 폴더 닫기** 나 트리 머리의 × 로 닫습니다. 자세한 사용법은 [폴더 트리](08-폴더-트리.md) 를 보세요.

## 저장

- **저장 (Ctrl+S)**: 현재 문서를 그 파일에 씁니다. 새 문서라면 저장 위치와 이름을 묻습니다. 저장하면 상태 표시줄에 "저장됨: 이름" 이 나오고 탭의 ● 가 사라집니다.
- **다른 이름으로 저장 (Ctrl+Alt+S)**: 늘 위치와 이름을 묻습니다. 저장 후 탭은 새 파일을 가리킵니다.
- **모두 저장 (Ctrl+Shift+S)**: 바뀐 문서를 모두 저장합니다. 바뀐 것이 없으면 "저장할 변경 사항이 없습니다." 라고 알립니다. 이름이 없는 새 문서는 차례로 위치를 묻고, 그때 취소하면 거기서 멈춥니다.

저장할 때 다음 설정이 함께 적용됩니다(설정 › 일반 › 파일).

- **저장할 때 줄 끝**: 파일의 원래 줄 끝 유지(기본) / 항상 Unix (LF) / 항상 Windows (CR LF).
- **저장할 때 줄 끝 공백 제거**, **저장할 때 마지막 줄 바꿈 추가** (기본 꺼짐).
- **저장할 때 자동 정렬** (설정 › 정렬, 기본 꺼짐) — 저장 직전에 문서 정렬을 실행합니다.
- 문서의 인코딩으로 표현할 수 없는 글자가 있으면 저장 전에 **인코딩 경고**("일부 문자는 … 로 표현할 수 없어 "?" 로 바뀝니다")로 묻습니다.

16진수 보기 · 그림 · 오디오 · 동영상은 여기서 편집 · 저장할 수 없습니다.

### 자동 저장

설정 › 일반 › 세션 묶음의 **자동 저장** 에서 고릅니다.

- **안 함** (기본)
- **창이 포커스를 잃을 때**: 다른 프로그램으로 전환하는 순간 바뀐 파일을 모두 저장합니다.
- **마지막 편집 후 n초 뒤**: 입력을 멈추고 n초(1 – 600, 기본 5)가 지나면 저장합니다.

자동 저장은 디스크에 있는 파일만 저장합니다. 이름 없는 새 문서와 읽기 전용 파일은 저장하지 않습니다.

## 다시 불러오기와 닫기

**파일 › 다시 불러오기** 는 디스크의 내용으로 문서를 다시 읽습니다. 저장하지 않은 변경이 있으면 "현재 변경 사항이 사라집니다. 계속할까요?" 라고 먼저 묻습니다.

문서를 닫는 방법은 여러 가지입니다: **Ctrl+W**, 탭의 ×(또는 ●), 탭 위에서 **마우스 가운데 버튼 클릭**, 도구 모음의 탭 닫기, 탭 오른쪽 클릭 메뉴.

저장하지 않은 문서를 닫으면 **저장 / 저장 안 함 / 취소** 를 묻습니다. 저장을 고르면 저장한 뒤 닫고, 저장 안 함은 변경을 버리고 닫으며, 취소는 아무것도 하지 않습니다.

![저장하지 않은 변경 사항](images/dirty-close.png)
*그림: 닫기 전에 저장 여부를 묻는 창*

프로그램을 끝낼 때 저장하지 않은 문서가 여러 개면 "저장하지 않은 문서가 n개 있습니다. 저장할까요?" 라고 한 번에 묻습니다(모두 저장 / 저장 안 함 / 취소). 이 확인은 설정 › 일반 › 세션의 **닫을 때 저장 여부 확인** 으로 끌 수 있습니다(끄면 묻지 않고 닫습니다).

## 최근 파일

한 번 연 파일은 최근 파일 목록에 남습니다.

- **파일 메뉴** 아래쪽에 최대 10개가 이름과 폴더 경로로 나옵니다. 항목 오른쪽의 × (목록에서 제거)로 하나씩 지울 수 있고, **최근 파일 목록 지우기** 로 모두 지웁니다.
- **시작 화면** 의 최근 파일 묶음에는 최대 8개가 나옵니다.

## 드래그 앤 드롭

탐색기나 바탕화면의 파일을 My Editor 창에 끌어다 놓으면 열립니다. 여러 개를 한꺼번에 놓아도 됩니다.

예외로, **Markdown 문서**를 편집하는 중에 **그림 파일**(PNG · JPEG · GIF · WebP · SVG · BMP · AVIF · ICO · HEIC · HEIF · DCM)만 끌어다 놓으면 파일을 여는 대신 놓은 위치에 그림이 문서 안에 들어갑니다([Markdown](09-Markdown.md) 참고). 웹 버전에서는 브라우저가 경로를 알려 주지 않으므로 놓은 파일의 내용을 읽어 새 문서로 엽니다(저장할 때 위치를 고릅니다).

## 외부 변경 감지

다른 프로그램이 열려 있는 파일을 바꾸면, My Editor 창으로 돌아오거나 그 문서의 탭으로 전환할 때 알아챕니다.

- **편집하지 않은 문서**는 자동으로 다시 읽습니다. 설정 › 일반 › 세션의 **외부에서 바뀐 파일 자동 다시 읽기 (수정하지 않은 경우)** 를 끄면 매번 묻습니다.
- **편집 중인 문서**는 "다른 프로그램에서 변경되었습니다. 다시 불러올까요?" 라고 묻습니다. **예** 는 디스크 내용으로 바꾸고, **아니요** 는 지금 내용을 유지합니다(이때 문서는 수정됨으로 표시되어 저장하면 덮어씁니다).
- 파일이 **디스크에서 지워지면** "탭을 그대로 유지합니다 — 저장하면 다시 만들어집니다." 라고 알려 줍니다.
- 파일의 **읽기 전용** 속성이 바뀌면 탭의 표시와 편집 가능 여부도 따라 바뀝니다.

## 세션 복원

프로그램을 닫았다 다시 열면 지난번 상태가 그대로 돌아옵니다(설정 › 일반 › 세션의 **시작할 때 이전 세션 복원**, 기본 켜짐).

- 열려 있던 **탭과 순서, 활성 탭, 커서 위치**
- 저장하지 않은 **새 문서의 내용**, 열린 파일에 저장하지 않고 남긴 **편집 내용**
- 문서마다 직접 고른 언어 · 줄 끝
- 열려 있던 **폴더**, 최근 파일, **창 위치와 크기**
- 편집 창 나누기 상태와 각 창의 문서, 패널 폭 · 높이

그사이 지워지거나 옮겨진 파일의 탭은 복원하지 않습니다(저장하지 않은 변경이 있었다면 그 내용은 새 문서로 돌아옵니다). 열려 있던 폴더가 없어졌으면 폴더 없이 시작합니다. 복원할 문서가 하나도 없으면 [시작 화면](01-시작하기.md) 으로 시작합니다.

## 큰 파일과 이진 파일

- **64 MB 를 넘는 텍스트 파일**은 열지 않고 "파일이 너무 큽니다" 라고 알려 줍니다.
- 텍스트가 아닌 **이진 파일**(실행 파일, 압축 파일, PDF 등)은 편집기 대신 **16진수 보기**로 엽니다. 크기가 커도 필요한 부분만 읽으므로 빠르게 열립니다.
- 시간이 걸리는 열기 · 저장에는 진행 막대가 있는 작은 창이 뜹니다.

## 여러 창 실행

설치한 프로그램은 여러 번 실행할 수 있고, 실행할 때마다 **새 창**이 따로 열립니다. 탐색기에서 연결된 파일을 더블클릭해도 새 창이 뜹니다. 설치 프로그램은 txt · md · json · js · html 같은 텍스트 · 소스 확장자를 이 앱과 연결합니다.
