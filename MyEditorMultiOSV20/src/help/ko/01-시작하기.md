# 시작하기

My Editor 는 여러 문서를 탭으로 열어 편집하는 텍스트 · 코드 편집기입니다. Windows · macOS · Linux 데스크톱 앱과 브라우저에서 쓰는 웹 버전이 같은 화면을 씁니다. 이 장에서는 프로그램을 처음 켰을 때 보이는 **시작 화면**, 기능을 하나씩 짚어 주는 **튜토리얼**, 지금 보고 있는 **도움말 창**, 그리고 처음 사용할 때 권하는 순서를 설명합니다.

## 시작 화면이 열리는 때

시작 화면은 편집 영역 자리에 나타나는 안내 화면입니다. 다음 경우에 열립니다.

- 프로그램을 켰는데 **복원된 문서가 하나도 없을 때** — 처음 실행했거나, 지난번에 탭을 모두 닫고 끝냈거나, 설정에서 세션 복원을 끈 경우입니다.
- **시작 시 항상 시작 화면 보기** 가 켜져 있으면, 이전 세션의 문서가 복원되었더라도 켤 때마다 시작 화면이 먼저 보입니다(기본값은 꺼짐).
- 언제든 메뉴 바 왼쪽의 **시작** 버튼(집 모양)이나 **보기 › 시작 화면** 을 누르면 열리고, 한 번 더 누르면 닫힙니다. 보기 메뉴의 항목에는 지금 열려 있는지 체크 표시가 붙습니다.

새 문서 만들기, 파일 열기, 최근 파일 열기처럼 편집으로 넘어가는 버튼을 누르면 시작 화면은 저절로 닫히고 편집기로 돌아갑니다. 열려 있던 문서는 그대로 뒤에 남아 있습니다.

![시작 화면](images/start-page.png)
*그림: 시작 화면 — 왼쪽부터 시작하기 · 할 수 있는 일 · 최근 파일 · 배경 효과*

맨 위에는 프로그램 이름(My Editor V1.1)과 "문서를 새로 만들거나 열고, 미리보기·구조·터미널로 이어서 작업하세요." 라는 안내가 있고, 그 아래에 네 묶음이 나란히 놓입니다.

## 시작하기 열

가장 왼쪽 **시작하기** 열에는 처음 할 일이 카드로 모여 있습니다.

| 카드 | 설명 | 같은 기능 |
|---|---|---|
| 튜토리얼 | 기능을 단계별로 둘러봅니다 | 도움말 › 튜토리얼 |
| 새 문서 | 빈 문서를 만듭니다(강조된 카드) | Ctrl+N |
| 열기… | 파일을 골라 엽니다 | Ctrl+O |
| 폴더 열기… | 폴더 트리를 엽니다 | Ctrl+Shift+O |
| 설정 | 테마, 글꼴, 저장 방식을 바꿉니다 | Ctrl+, |
| 단축키 | 편집에 쓰는 키를 봅니다 | 도움말 › 단축키 |

카드 아래에는 **시작 시 항상 시작 화면 보기** 체크 상자가 있습니다. 여기서 켜고 끈 값은 설정 › 시작 화면의 같은 항목과 하나로 연결되어 있습니다.

## 할 수 있는 일

가운데 **할 수 있는 일** 묶음은 자주 쓰는 기능 12가지를 바둑판처럼 늘어놓은 것입니다. 누르면 시작 화면이 닫히고 지금 문서에 그 기능이 실행됩니다. 문서 종류에 맞지 않는 기능(예: 코드 파일에서 실행)은 편집기에서 꺼져 있으므로 눌러도 아무 일이 일어나지 않습니다.

| 카드 | 하는 일 | 자세한 설명 |
|---|---|---|
| 찾기… | 문서 안에서 찾습니다 | [찾기와 바꾸기](06-찾기와-바꾸기.md) |
| 바꾸기… | 찾은 내용을 바꿉니다 | [찾기와 바꾸기](06-찾기와-바꾸기.md) |
| 미리보기 | Markdown · HTML · SVG 미리보기 | [Markdown](09-Markdown.md), [HTML · SVG](10-HTML-SVG-그림-이진.md) |
| Markdown WYSIWYG 편집 | Markdown 기호를 렌더링해서 편집 | [Markdown](09-Markdown.md) |
| 실행 | HTML 을 브라우저에서 엽니다 | [HTML · SVG](10-HTML-SVG-그림-이진.md) |
| 구조 | 제목 트리 또는 미니맵 | [Markdown](09-Markdown.md), [보기와 테마](16-보기와-테마.md) |
| 터미널 | 아래 패널의 터미널 탭 | [터미널과 로그](14-터미널과-로그.md) |
| 로그 | 같은 패널의 로그 탭 | [터미널과 로그](14-터미널과-로그.md) |
| 문서 정렬 | 언어별 도구로 문서를 정렬 | [정렬과 검사](12-정렬과-검사.md) |
| 인쇄… | 미리보기를 본 뒤 인쇄 | [인쇄](15-인쇄.md) |
| 좌우로 나누기 | 편집 창을 나눕니다 | [창 나누기](11-창-나누기.md) |
| 다음 테마 | 다음 색 테마로 바꿉니다 | [보기와 테마](16-보기와-테마.md) |

바둑판 바로 아래의 **사용법 보기** 버튼은 이 도움말 창을 엽니다("모든 기능의 자세한 설명을 화면과 함께 별도 창에서 봅니다").

## 최근 파일과 오늘의 팁

**최근 파일** 묶음에는 최근에 연 파일이 최대 8개까지 이름으로 나옵니다. 마우스를 올리면 전체 경로가 보이고, 누르면 그 파일이 열리면서 편집기로 돌아갑니다. 아직 연 파일이 없으면 "아직 연 파일이 없습니다." 라고 나옵니다. 더 많은 기록(최대 10개)과 목록에서 지우기는 파일 메뉴에 있습니다([파일](03-파일.md) 참고).

그 아래 별 모양의 **팁** 카드는 날마다 하나씩 바뀌는 짧은 요령입니다(모두 7가지). **자세히** 를 누르면 설명이 펼쳐지고 **접기** 로 다시 줄어듭니다. 팁은 다음과 같은 내용입니다.

- Ctrl+N 으로 새 문서를 만듭니다.
- Ctrl+O 로 파일을 엽니다.
- Ctrl+S 로 저장합니다.
- Markdown 은 툴바의 미리보기·WYSIWYG·구조가 켜집니다.
- HTML 은 미리보기와 실행이 켜집니다.
- 터미널·로그·문제점은 아래 패널의 탭입니다.
- 시작 화면은 메뉴의 시작 버튼이나 보기 메뉴로 열고 닫습니다.

## 배경 효과

시작 화면 뒤에는 움직이는 3D 그림이 깔려 있습니다. 가장 오른쪽 **배경 효과** 묶음에서 그 그림을 고르고 움직임을 조절합니다. 그림의 색은 지금 쓰는 테마를 따릅니다.

![배경 효과 조절](images/start-background.png)
*그림: 장면 버튼과 투명도 · 속도 막대*

**장면** 버튼은 21가지입니다. 누른 장면이 바로 배경이 되고, 고른 버튼이 강조됩니다(기본은 터미널).

터미널 · 코드 비 · 회로 · 서버실 · 브랜치 · 토큰 · 이진수 · 키보드 · 칩 · 네트워크 · 호출 스택 · 구문 트리 · 디버거 · 컨테이너 · 광섬유 · 16진수 · 파이프라인 · 저장소 · API · 기호 · 메모리

그 아래에 막대가 다섯 개 있습니다. 막대를 끌거나 누르면 값이 바뀌고, 양옆의 − / + 는 한 칸씩(투명도·전체 속도는 5%, 나머지는 10%) 바꿉니다. 막대에 포커스가 있을 때는 ← → ↑ ↓ 로 한 칸씩, Home / End 로 최솟값 / 최댓값이 됩니다.

| 막대 | 범위 | 기본값 | 뜻 |
|---|---|---|---|
| 배경 투명도 (%) | 0 – 100 | 80 | 그림이 얼마나 비쳐 보이는지 |
| 전체 속도 (%) | 0 – 100 | 20 | 모든 움직임의 빠르기 |
| 카메라 이동 (%) | 0 – 300 | 100 | 시점이 움직이는 빠르기 |
| 물체 움직임 (%) | 0 – 300 | 100 | 장면 속 물체의 빠르기 |
| 하늘·빛 (%) | 0 – 300 | 100 | 하늘과 빛의 변화 빠르기 |

**속도 초기화** 는 전체 속도 · 카메라 · 물체 · 하늘 값을 처음 값으로 되돌립니다(장면과 투명도는 그대로). 같은 조절 막대는 설정 › 시작 화면 탭에도 있습니다([설정](17-설정.md) 참고).

> 팁: 움직이는 배경이 신경 쓰이면 전체 속도를 0 으로 내리세요. 그림은 멈춘 채로 남습니다.

## 튜토리얼 투어

**도움말 › 튜토리얼** 또는 시작 화면의 **튜토리얼** 카드를 누르면, 실제 화면 위에서 기능을 하나씩 가리키는 둘러보기가 시작됩니다. 오른쪽 아래에 안내 카드가 뜨고, 지금 설명하는 부분(도구 모음 버튼, 시작 화면의 묶음 등)은 테두리로 강조됩니다. 단계에 따라 시작 화면과 편집기 사이를 저절로 오갑니다. 둘러보기는 화면만 가리킬 뿐 **내 파일은 바꾸지 않습니다**.

![튜토리얼 카드](images/tour.png)
*그림: 튜토리얼 카드 — 장 선택, 단계 번호, 진행 막대, 이전 · 자동 재생 · 다음*

카드의 구성은 다음과 같습니다.

- **장 선택 상자**: 시작 화면 · 파일 · 편집 · 보기 · 도구 다섯 장 중 하나를 고르면 그 장의 첫 단계로 건너뜁니다.
- **단계 번호** (예: 3 / 19)와 그 아래 진행 막대, 그리고 "이 장의 n / m" 표시.
- 단계 제목과 설명.
- **이전** / **다음** 버튼으로 한 단계씩 움직입니다. 마지막 단계에서는 다음 대신 **마치기** 가 나옵니다.
- **자동 재생** 은 약 4.5초마다 다음 단계로 넘어가며 끝까지 보여 줍니다. 재생 중에는 버튼이 **일시정지** 로 바뀝니다.
- 오른쪽 위 × (튜토리얼 끝내기)는 언제든 둘러보기를 닫습니다.

튜토리얼이 다루는 19단계는 다음과 같습니다.

| 장 | 단계 |
|---|---|
| 시작 화면 | 환영 인사, 시작하기, 할 수 있는 일, 배경 |
| 파일 | 새 문서, 파일 열기, 폴더, 최근 파일 |
| 편집 | 찾기, 바꾸기, 문서 정렬 |
| 보기 | 미리보기, WYSIWYG, 실행, 구조 |
| 도구 | 터미널, 로그, 설정, 둘러보기를 마쳤습니다 |

## 도움말 창 (사용법 보기)

**도움말 › 도움말**(F1) 이나 시작 화면의 **사용법 보기** 를 누르면 지금 읽고 있는 이 도움말이 **별도의 창**으로 열립니다. 편집기와 나란히 띄워 두고 따라 해 볼 수 있습니다.

![도움말 창](images/help-window.png)
*그림: 도움말 창 — 왼쪽에 장 목록과 검색, 오른쪽에 본문*

- **장 목록**: 왼쪽에 모든 장이 번호 순서로 나옵니다. 장 이름을 누르면 그 장이 열리고, 지금 보는 장 아래에는 그 장의 절(소제목) 목록이 펼쳐집니다. 절을 누르면 본문이 그 자리로 스크롤됩니다.
- **도움말 검색**: 맨 위 검색 칸에 낱말을 넣으면 그 낱말이 모두 들어 있는 장만 목록에 남고("n개 장에서 찾음"), 각 장 옆에 첫 낱말이 나오는 횟수가 표시됩니다. 본문에서는 첫 낱말이 모두 노란 표시로 강조되고 첫 번째 위치로 스크롤됩니다. 칸을 비우면 원래 목록으로 돌아갑니다.
- **이전 / 다음 버튼**: 본문 아래쪽에 앞 장과 다음 장의 이름이 적힌 버튼과 "n / 전체" 쪽 번호가 있습니다.
- **Alt+← / Alt+→**: 키보드로 이전 장 / 다음 장으로 넘어갑니다.
- 본문 안의 다른 장 링크를 누르면 그 장으로, 웹 주소 링크는 시스템 브라우저로 열립니다.

## 처음 사용하는 순서

처음이라면 다음 순서를 권합니다.

1. 시작 화면의 **튜토리얼** 로 화면 구성을 한 번 둘러봅니다(자동 재생을 켜 두면 1분 반 정도).
2. **설정** 에서 테마와 글꼴, 글꼴 크기를 마음에 들게 고릅니다. 도구 모음 오른쪽의 테마 버튼과 국기 버튼으로도 바로 바꿀 수 있습니다([보기와 테마](16-보기와-테마.md)).
3. 작업할 프로젝트가 있다면 **폴더 열기**(Ctrl+Shift+O)로 왼쪽에 폴더 트리를 띄웁니다([폴더 트리](08-폴더-트리.md)).
4. 트리에서 파일을 누르거나 **열기**(Ctrl+O)로 파일을 엽니다. 파일을 창에 끌어다 놓아도 됩니다([파일](03-파일.md)).
5. 편집한 뒤 **Ctrl+S** 로 저장합니다. 프로그램을 닫았다 열면 열려 있던 탭과 커서 위치가 그대로 돌아옵니다.
6. 키를 익히려면 **도움말 › 단축키** 창을 띄워 두거나 [단축키](18-단축키.md) 장을 보세요.

> 팁: 시작 화면을 다시 보고 싶으면 메뉴 바 왼쪽의 **시작** 버튼을 누르세요. 닫을 때도 같은 버튼입니다.
