# 편집

글을 고치는 모든 명령을 설명합니다. 대부분은 **편집** 메뉴에 있고, 편집 영역의 오른쪽 클릭 메뉴와 도구 모음에도 일부가 있습니다. 편집 동작을 켜고 끄는 항목(자동 들여쓰기, 자동 완성 등)은 **편집기** 메뉴에 모여 있습니다.

![편집 메뉴](images/menu-edit.png)
*그림: 편집 메뉴*

## 기본 편집

| 명령 | 단축키 | 설명 |
|---|---|---|
| 실행 취소 | Ctrl+Z | 마지막 편집을 되돌립니다. 문서마다 따로 기록됩니다 |
| 다시 실행 | Ctrl+Y | 되돌린 편집을 다시 합니다 |
| 잘라내기 | Ctrl+X | 선택한 내용을 클립보드로 옮깁니다 |
| 복사 | Ctrl+C | 선택한 내용을 복사합니다. 다중 선택이면 줄을 바꿔 이어 붙입니다 |
| 붙여넣기 | Ctrl+V | 클립보드의 글을 커서 위치에 넣습니다 |
| 삭제 | Del | 선택한 내용을 지웁니다 |
| 모두 선택 | Ctrl+A | 문서 전체를 선택합니다 |

도구 모음의 실행 취소 · 다시 실행 · 잘라내기 · 복사 · 붙여넣기 버튼과 편집 영역의 오른쪽 클릭 메뉴도 같은 일을 합니다.

## 줄 단위 편집

| 명령 | 단축키 | 설명 |
|---|---|---|
| 줄 복제 | Ctrl+D | 커서가 있는 줄(또는 선택한 줄들)을 바로 아래에 복사합니다 |
| 줄 삭제 | Ctrl+L | 커서가 있는 줄을 통째로 지웁니다 |
| 줄 위로 이동 | Alt+↑ | 줄(또는 선택한 줄들)을 한 줄 위로 옮깁니다 |
| 줄 아래로 이동 | Alt+↓ | 한 줄 아래로 옮깁니다 |
| 주석 토글 | Ctrl+/ | 그 언어의 주석 기호(// , # , <!-- --> …)를 붙이거나 뗍니다 |
| 들여쓰기 | Tab | 선택한 줄을 한 단계 들여씁니다 |
| 내어쓰기 | Shift+Tab | 한 단계 내어씁니다 |

선택 영역 없이 Tab 을 누르면 커서 위치에 들여쓰기 한 단계(공백 또는 탭 문자)를 넣습니다. 들여쓰기 한 단계의 크기와 문자는 아래 "자동 들여쓰기" 절을 보세요.

## 대소문자와 줄 정리

편집 메뉴의 다음 명령은 **선택한 부분이 있으면 그 부분(줄 단위 명령은 선택이 걸친 줄 전체)에만, 선택이 없으면 문서 전체에** 적용됩니다.

| 명령 | 단축키 | 설명 |
|---|---|---|
| 대문자로 | Ctrl+Shift+U | 영문을 모두 대문자로 |
| 소문자로 | Ctrl+U | 영문을 모두 소문자로 |
| 줄 정렬 (오름차순) | | 줄을 가나다 · ABC 순으로. 숫자는 크기 순(2 가 10 보다 앞)이고 대소문자는 구분하지 않습니다 |
| 줄 정렬 (내림차순) | | 반대 순서로 |
| 줄 끝 공백 제거 | | 각 줄 끝의 공백 · 탭을 지웁니다 |
| 빈 줄 제거 | | 비어 있거나 공백만 있는 줄을 지웁니다 |
| 중복 줄 제거 | | 앞에 이미 나온 것과 똑같은 줄을 지웁니다(처음 것은 남김) |

> 팁: 선택하지 않은 채로 Ctrl+U 를 누르면 문서 전체가 소문자로 바뀝니다. 실수했다면 Ctrl+Z 로 되돌리세요.

## 삽입과 문서 정렬

- **날짜/시간 삽입**: 커서 위치에 지금 날짜와 시각을 운영체제의 지역 형식으로 넣습니다.
- **파일 경로 삽입**: 현재 문서의 전체 경로를 넣습니다(저장한 파일일 때만).
- **문서 정렬** (Shift+Alt+F): 언어별 정렬 도구로 문서 전체를 보기 좋게 정리합니다. 정렬할 내용이 없거나 이미 정렬되어 있으면 꺼집니다. 자세한 내용은 [정렬과 검사](12-정렬과-검사.md) 를 보세요.

## 다중 커서와 사각형 선택

- **Alt+클릭**: 클릭한 자리에 커서를 하나 더 만듭니다. 여러 곳에 같은 글을 한꺼번에 입력할 수 있습니다. 상태 표시줄의 커서 위치 뒤에 ×3 처럼 커서 수가 나옵니다.
- **Alt+드래그**: 사각형(세로 블록)으로 선택합니다. 줄마다 같은 열 범위가 선택되어 열 단위로 지우거나 입력할 수 있습니다.
- 찾기 줄의 **≡ (일치하는 항목 모두 선택)** 이나 찾기 › 일치하는 항목 모두 선택은 찾은 곳마다 커서를 만들어 줍니다([찾기와 바꾸기](06-찾기와-바꾸기.md)).
- Esc 를 누르면 커서가 하나로 돌아옵니다.

## 자동 들여쓰기

자동 들여쓰기가 켜져 있으면(기본) Enter 로 새 줄을 만들 때 이전 줄의 들여쓰기를 유지하고, 여는 괄호 다음 줄은 한 단계 더 들여쓰며, 닫는 괄호를 입력하면 그 줄을 알맞게 맞춥니다. 끄면 Enter 는 들여쓰기 없이 줄만 바꿉니다.

켜고 끄는 곳: 도구 모음의 자동 들여쓰기 버튼, **편집기 › 자동 들여쓰기**, 상태 표시줄의 들여쓰기 메뉴 맨 위, 설정 › 일반 › 들여쓰기.

들여쓰기 한 단계는 두 설정으로 정합니다.

- **들여쓰기 문자**: 공백 삽입(기본) 또는 탭 문자 삽입. Tab 키는 이 설정대로 공백 또는 탭 문자를 넣습니다.
- **탭 크기**: 탭 1개 = 공백 n자리(1 – 16, 기본 4). 공백 삽입일 때 Tab 키가 넣는 공백 수이기도 합니다.

상태 표시줄의 `공백: 4` (또는 `탭: 4`) 를 누르면 공백 2 · 3 · 4 · 8, 탭 2 · 4 · 8 중에서 바로 고를 수 있습니다. 이 설정은 모든 문서에 공통입니다.

## 괄호와 따옴표

- **괄호·따옴표 자동 닫기** (기본 켜짐): `(`, `[`, `{`, `"`, `'` 를 입력하면 닫는 짝이 함께 들어가고 커서는 그 사이에 놓입니다. 닫는 짝을 직접 입력하면 겹쳐 쓰지 않고 건너뜁니다.
- **짝 괄호 강조** (기본 켜짐): 커서가 괄호 옆에 있으면 짝이 되는 괄호를 함께 강조합니다.

두 설정은 설정 › 일반 › 편집 보조에서 켜고 끕니다.

## 코드 접기

함수나 블록, 제목 아래 내용을 접어 둘 수 있습니다(코드 접기가 켜져 있을 때, 기본 켜짐).

- 줄 번호 오른쪽의 **▾** 를 누르면 그 블록이 접히고 **▸** 로 바뀝니다. 다시 누르면 펼쳐집니다.
- **편집기 › 모두 접기 / 모두 펼치기** 로 문서 전체를 한 번에 접고 폅니다.
- 접는 표시 자체는 **편집기 › 코드 접기** 또는 설정 › 일반 › 표시의 **코드 접기** 로 숨깁니다.

## 자동 완성

입력하는 동안 커서 아래에 제안 목록이 나타납니다(기본 켜짐). 제안에는 그 언어의 키워드 · 태그 · 속성 · 이름과 **문서 안에 이미 있는 낱말**이 함께 나옵니다.

![자동 완성](images/autocomplete.png)
*그림: 입력 중에 나타나는 자동 완성 목록*

- ↑ ↓ 로 고르고 **Enter** 로 넣습니다. **Esc** 로 목록을 닫습니다.
- 목록이 닫혀 있을 때 **Ctrl+Space** 로 직접 엽니다.
- **Dockerfile**(Dockerfile · Containerfile · *.dockerfile)은 명령어 · 이미지 이름 · 플래그를, **Kubernetes 매니페스트**(YAML)는 키 · kind · apiVersion · 값을 제안합니다.
- 켜고 끄는 곳: 도구 모음의 자동 완성 버튼, **편집기 › 자동 완성**, 설정 › 일반 › 편집 보조의 **입력 중 자동 완성**.

## 확대와 축소

편집기 글자 크기를 바꿔 화면을 확대 · 축소합니다. 확대 / 축소는 글꼴 크기 설정을 1px 씩 바꾸는 것이며(8 – 40px), 100% 는 기본 크기 12px 입니다.

| 방법 | 동작 |
|---|---|
| Ctrl+= (Ctrl++) / Ctrl+− | 확대 / 축소 |
| Ctrl+마우스 휠 (편집 영역 위) | 확대 / 축소 |
| Ctrl+0 | 기본 크기(100%) |
| 도구 모음의 확대 · 축소 버튼 | 확대 / 축소. 사이의 배율(예: 117%)을 누르면 기본 크기 |
| 상태 표시줄의 배율 | 기본 크기 |
| 도구 모음의 − 크기 + | 글꼴 크기를 직접 지정 |

그림을 보고 있을 때 Ctrl+휠은 글자 대신 그림을 확대 · 축소합니다.
