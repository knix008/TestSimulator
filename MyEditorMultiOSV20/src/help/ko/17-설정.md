# 설정

설정 창에서는 화면 · 편집 · 파일 · 시작 화면 · 테마 · 터미널 · 정렬 · 검사 · 인쇄에 관한 모든 옵션을 바꿉니다. **바꾸는 즉시 적용되고 저장**되므로 따로 저장 버튼은 없습니다.

## 설정 창 열기

- **Ctrl+,**
- **도움말 › 설정**
- 도구 모음 오른쪽 끝의 **톱니바퀴** 버튼(도구 모음을 숨기면 메뉴 바 오른쪽)
- 시작 화면의 **설정** 카드
- 터미널 패널 머리의 ⚙ (터미널 탭이 열린 채로), 문제점 패널 머리의 ⚙ (검사 탭이 열린 채로)

데스크톱 앱에서 설정은 **별도의 창**(크기 고정)으로 열립니다. 메인 창 밖으로도 옮길 수 있고, 메인 창을 최소화하거나 닫으면 함께 따라갑니다. 설정 창에서 바꾼 값은 즉시 메인 창(테마 · 언어 포함)에 적용되고, 메인 창에서 바꾼 테마 · 언어도 설정 창에 반영됩니다. 설정 창은 편집기가 뜬 뒤 미리 준비되어 언제 열어도 기다림 없이 나타납니다. 웹 버전에서는 페이지 안에서 옮길 수 있는 창으로 열립니다.

창 위쪽에 **일반 · 시작 화면 · 테마 · 터미널 · 정렬 · 검사 · 인쇄** 탭이 있고, 아래쪽에 **기본값으로 되돌리기** 와 **확인** 버튼이 있습니다. 확인 · Enter · Esc · 오른쪽 위 × 는 창을 닫습니다.

## 시작 화면

![설정 › 시작 화면](images/settings-start.png)

### 시작할 때

- **시작 시 항상 시작 화면 보기** (기본 꺼짐): 켜면 이전 세션의 문서가 복원되었더라도 켤 때마다 시작 화면이 먼저 보입니다. 끄면 문서가 복원되었을 때는 시작 화면을 건너뜁니다. 열린 문서가 없으면 이 설정과 관계없이 항상 시작 화면이 보입니다. 시작 화면 왼쪽 열 아래의 같은 체크 상자와 같은 설정입니다.

### 배경 효과

시작 화면의 배경 효과 묶음과 똑같은 조절 막대입니다([시작하기](01-시작하기.md) 참고).

- 장면 21가지 (기본 터미널)
- 배경 투명도 (%) 0 – 100, 기본 80
- 전체 속도 (%) 0 – 100, 기본 20
- 카메라 이동 · 물체 움직임 · 하늘·빛 (%) 0 – 300, 기본 100
- **속도 초기화**: 네 속도 값을 기본값으로

## 정렬

- **저장할 때 자동 정렬** (기본 꺼짐)
- 언어마다 정렬 도구: 자동 / 각 도구 / 편집기 들여쓰기만 / 사용 안 함
- 언어 옆의 ⬇ 설치 · ↻ 다시 설치 버튼, 위쪽의 **다시 찾기** 버튼

자세한 내용은 [정렬과 검사](12-정렬과-검사.md) 를 보세요.

## 검사

- 맨 위 **코드 검사** 체크 (일반 탭의 같은 항목과 같음)
- 언어마다 검사 도구: 자동 / 각 도구 / 사용 안 함
- 설치되지 않은 도구의 ⬇ 설치 버튼, **다시 찾기** 버튼

자세한 내용은 [정렬과 검사](12-정렬과-검사.md) 를 보세요.

## 인쇄

용지(크기 · 방향 · 여백), 구성(파일 이름 / 경로 · 줄 번호 · 페이지 테두리 · 페이지 번호 · 인쇄 날짜), 글꼴(크기 · 줄 간격 · 긴 줄 자동 줄 바꿈), 모양(구문 강조 · 컬러 · 줄무늬 · 줄 번호 여백 배경)과 두 쪽짜리 미리보기 견본이 있습니다. 항목별 설명과 기본값은 [인쇄](15-인쇄.md) 를 보세요.

## 기본값으로 되돌리기

창 아래 왼쪽의 **기본값으로 되돌리기** 를 누르면 "모든 설정을 기본값으로 되돌릴까요?" 라고 확인한 뒤 **되돌리기** 를 누르면 처음 상태로 돌아갑니다.

- 되돌리는 것: 테마, 글꼴 · 글꼴 크기 · 줄 높이, 자동 저장, 새 문서 언어 · 인코딩 · 줄 끝, 저장할 때 줄 끝 · 공백 · 마지막 줄 바꿈, 숨김 파일, 들여쓰기 · 탭 크기, 표시 항목(줄 바꿈 · 줄 번호 · 미니맵 · 공백 표시 · 탭 안내선 · 현재 줄 · 접기), 괄호 자동 닫기 · 짝 괄호, 세션 복원 · 시작 화면 항상 보기 · 외부 변경 다시 읽기 · 닫을 때 확인, Markdown WYSIWYG, 스펠링 체크, 자동 들여쓰기, 코드 검사, 자동 완성, 언어별 정렬 · 검사 도구, 저장할 때 자동 정렬, 터미널(셸 · 시작 디렉터리 · 색 · 프롬프트), 모든 인쇄 설정.
- 그대로 두는 것: **UI 언어**, 그리고 보기 메뉴에서 정하는 **창 배치**(폴더 트리 · 도구 모음 · 상태 표시줄 표시, 편집 창 나누기, 하단 패널, 패널 크기 등), 시작 화면의 배경 효과(장면 · 투명도 · 속도), 사용자 정의 테마와 사용자 정의 프롬프트 목록, 사전에 추가한 낱말.

## 설정이 저장되는 곳

설정과 세션은 `session.json` 파일 하나에 저장됩니다. 위치는 [웹 버전과 문제 해결](19-웹-버전과-문제-해결.md) 장의 표를 보세요. 이 파일을 지우면 모든 설정이 기본값으로 시작합니다.
