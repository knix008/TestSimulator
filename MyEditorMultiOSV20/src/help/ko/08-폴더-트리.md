# 폴더 트리

창 왼쪽의 **폴더** 패널은 폴더 하나를 연결선이 있는 트리로 보여 줍니다. 프로젝트의 파일을 고르고, 새 파일 · 폴더를 만들고, 이름을 바꾸거나 지울 수 있습니다.

![폴더 트리](images/folder-tree.png)
*그림: 폴더 트리 — 머리의 버튼들, 필터 칸, 연결선이 있는 트리*

## 보이기와 숨기기

- **Ctrl+B**, 도구 모음의 폴더 트리 버튼, **보기 › 폴더 트리**, 설정 › 일반 › 화면의 폴더 트리 체크로 보이고 숨깁니다.
- **Markdown 문서**를 편집할 때는 Ctrl+B 가 굵게(Bold)로 쓰이므로 **Ctrl+Shift+B** 로 여닫습니다. Ctrl+Shift+B 는 다른 문서에서도 똑같이 동작합니다.
- 폴더 트리와 편집 영역 사이의 **경계선을 끌면** 폭이 바뀝니다. 머리의 제목과 버튼이 모두 보이는 폭보다 좁아지지 않고, 최대 600px 까지 넓어집니다. 폭은 기억됩니다.

## 폴더 열기와 닫기

- **파일 › 폴더 열기…** (Ctrl+Shift+O), 도구 모음의 폴더 열기 버튼, 패널 머리의 **폴더 열기** 버튼으로 폴더를 고릅니다. 폴더가 없을 때 패널 가운데에 보이는 **폴더 열기…** 버튼도 같습니다.
- 한 번에 폴더 하나만 열립니다. 다른 폴더를 열면 바뀝니다.
- 머리의 **×** (폴더 닫기) 또는 **파일 › 폴더 닫기** 로 닫습니다.
- 열린 폴더는 다음 실행 때 다시 열립니다(그사이 폴더가 없어졌으면 폴더 없이 시작).

## 트리 다루기

- 처음에는 폴더의 **최상위 항목만** 보입니다. 폴더(⊞)를 누르면 그 폴더만 펼쳐지고(⊟), 다시 누르면 닫힙니다. 다른 폴더를 여닫아도 이미 펼친 폴더는 그대로 남습니다.
- 폴더가 먼저, 그다음 파일이 이름순으로 나옵니다. 파일 앞의 아이콘은 종류(코드, 마크업 · 설정, 그림, 오디오, 동영상, 압축, 실행 · 문서, 일반 텍스트)를 나타냅니다.
- **파일을 누르면** 탭으로 열립니다. 이미 열려 있으면 그 탭으로 이동합니다.
- **열려 있는 파일**은 강조 색 글자로, **지금 편집 중인 파일**은 선택 색 배경으로 표시됩니다.
- 항목에 마우스를 올리면 전체 경로가 보입니다. 읽지 못한 폴더에는 ⚠ 표시가 붙습니다.

## 머리 버튼

패널 머리의 "폴더" 제목 오른쪽에 버튼이 있습니다.

| 버튼 | 이름 | 하는 일 |
|---|---|---|
| 🔍 | 검색 | 패널 아래 절반에 폴더에서 찾기 영역을 열고 닫습니다([찾기와 바꾸기](06-찾기와-바꾸기.md)) |
| 폴더 | 폴더 열기… | 다른 폴더를 고릅니다 |
| ↻ | 새로 고침 | 디스크를 다시 읽습니다. 펼쳐 둔 상태는 유지됩니다 |
| ⌄ | 모두 펼치기 | 모든 하위 폴더를 펼칩니다 |
| ⌃ | 모두 접기 | 모든 폴더를 접습니다 |
| 눈 | 숨김 파일 표시 | 이름이 . 으로 시작하는 파일 · 폴더를 보이거나 숨깁니다 |
| × | 폴더 닫기 | 폴더를 닫습니다 |

**모두 펼치기**는 `node_modules` · `.git` · `dist` · `build` · `out` · `target` · `bin` · `obj` · `vendor` · `coverage` · `__pycache__` · `.venv` 처럼 파일이 아주 많은 폴더는 접어 둔 채로 두고, 12단계 깊이 또는 항목 5,000개를 넘으면 거기서 멈춥니다.

**숨김 파일 표시**는 설정 › 일반 › 폴더 트리의 **숨김 파일(.으로 시작) 표시** 와 같은 설정입니다(기본 꺼짐).

## 필터

머리 아래의 **필터…** 칸에 글자를 넣으면 이름에 그 글자가 들어 있는 항목(과 그 항목이 든 폴더)만 남습니다. 대소문자는 구분하지 않습니다. 필터는 이미 읽어 들인(한 번이라도 펼친) 폴더 안에서만 찾으므로, 깊은 곳까지 거르려면 먼저 **모두 펼치기**를 누르세요. 칸을 비우면 원래 트리로 돌아갑니다.

## 오른쪽 클릭 메뉴

항목을 오른쪽 클릭하면 메뉴가 나옵니다. 폴더와 파일에서 조금 다릅니다.

| 항목 | 폴더 | 파일 | 설명 |
|---|---|---|---|
| 새 파일… | ○ | | 이 폴더 안에 빈 파일을 만들고 바로 엽니다 |
| 새 폴더… | ○ | | 이 폴더 안에 폴더를 만듭니다 |
| 열기 | | ○ | 파일을 탭으로 엽니다 |
| 이름 바꾸기… | ○ | ○ | 이름을 바꿉니다. 열려 있는 파일이면 탭 이름도 바뀝니다 |
| 삭제 | ○ | ○ | 지웁니다(되돌릴 수 없음) |
| 탐색기에서 보기 | ○ | ○ | 운영체제의 파일 관리자에서 보여 줍니다(데스크톱) |
| 경로 복사 | ○ | ○ | 전체 경로를 클립보드로 |
| 새로 고침 | ○ | ○ | 그 폴더(파일이면 그 파일이 든 폴더)를 다시 읽습니다 |

- 새 파일 · 새 폴더 · 이름 바꾸기는 이름을 묻는 작은 창을 띄웁니다. `\ / : * ? " < > |` 처럼 파일 이름에 쓸 수 없는 글자가 있으면 **만들기** 버튼이 꺼집니다. 이름 바꾸기 창은 확장자를 뺀 부분이 선택된 채로 열립니다.
- 새 파일은 설정의 새 문서 인코딩 · 줄 끝으로 만들어집니다.
- **삭제**는 "되돌릴 수 없습니다" 라고 확인한 뒤 지웁니다. 지운 파일이 탭으로 열려 있었다면 탭은 남고 수정됨으로 표시되므로, 저장하면 다시 만들 수 있습니다.
- 맨 위의 폴더 자체(루트)는 이름 바꾸기 · 삭제를 할 수 없습니다.

> 팁: 폴더를 열어 두면 터미널은 그 폴더에서 시작하고, 편집 창의 문서 고르기 목록에도 그 폴더의 파일이 나옵니다.
