## 시작하기 / Getting Started

### 데스크톱 (Electron)

```bash
npm install
npm start
```

Windows에서 `AV Editor Setup x.y.z.exe`를 설치한 뒤, 시작 메뉴 또는 바탕 화면 바로가기로 실행할 수도 있습니다.

### 브라우저 (Web)

```bash
npm install
npm run web
```

기본 주소: `http://127.0.0.1:4173/`  
별도 빌드 없이 `src/renderer`를 바로 서빙합니다.  
배포용 정적 패키지는 `npm run build:web` → `dist-web/` 입니다.

## 파일 탐색기 / File Explorer

### Electron (데스크톱)

- 시작 시 **최근에 작업한 폴더**를 자동으로 펼칩니다.
- 상단 **경로 표시줄**에 현재 폴더의 전체 경로가 표시됩니다.
- 드라이브가 여러 개이면 헤더의 **드라이브 선택**으로 이동합니다.
- 폴더 아이콘 버튼으로 다른 폴더를 열 수 있습니다.
- OS에서 파일을 **현재 폴더로 드래그**하면 복사됩니다.
- 패널 밖으로 **드래그 아웃**하면 네이티브 파일 드래그가 시작됩니다.

### 미디어 파일

- 지원 비디오: MP4, AVI, MOV, MKV, WebM, FLV, WMV, M4V, TS, MTS …
- 지원 오디오: MP3, WAV, AAC, FLAC, OGG, M4A, WMA, Opus, AIFF …
- **클릭**: 미리보기 + 파일 정보 표시  
- **더블클릭**: 타임라인에 클립 추가  

### 파일 정보 패널

선택한 미디어의 이름, 종류, 크기, 포맷, 재생 시간, 해상도, fps, 코덱, 샘플레이트, 채널, 비트레이트, 수정/생성일, 경로 등을 표시합니다.  
가능한 경우 MediaInfo(WASM)로 상세 메타데이터를 채우고, 없으면 HTML5 미디어 프로브로 보완합니다.

## 웹 Library / Web Library

웹 모드의 왼쪽 트리는 **디스크 폴더가 아니라** 브라우저 세션의 가상 경로 `/library` 입니다.

| 동작 | 설명 |
|------|------|
| 샘플 시드 | 시작 시 `samples/manifest.json`의 샘플이 Library에 자동 등록됩니다 |
| Add media / Import | 파일을 골라 Library에 추가합니다 |
| 드래그 앤 드롭 | 탐색기·바탕화면에서 Library로 파일을 넣을 수 있습니다 |
| 우클릭 삭제 | Library 항목만 제거합니다 (디스크 파일은 건드리지 않음) |
| 새로고침 | 세션 메모리이므로 페이지를 새로고치면 Library는 초기화됩니다 (샘플은 다시 시드) |

재생하려면 샘플을 쓰거나 Import / 드롭으로 미디어를 Library에 넣은 뒤 선택하면 됩니다.

## 미리보기 / Preview

### 재생 컨트롤

| 버튼 | 동작 |
|------|------|
| 처음으로 / 끝으로 | 시작 또는 끝으로 이동 |
| 되감기 / 빨리감기 | 약 5초 이동 |
| 재생 / 일시정지 | Space |
| 정지 | 일시정지 후 클립/미디어 시작 위치로 |
| 음량 / 음소거 | 볼륨 조절 |
| 전체화면 | 미리보기 영역 전체화면 |

툴바·미리보기 바·Space·우클릭 메뉴가 같은 재생 시계를 사용합니다.

### 전송 큐 오버레이 / Transport cues

재생·일시정지·정지·되감기·빨리감기·건너뛰기 버튼을 누르면 미리보기 중앙에 해당 아이콘이 잠시 표시됩니다.

- 일반 동작: 약 **0.9초** 후 사라짐  
- **일시정지**: 다른 전송 버튼이 눌리기 전까지 **계속 표시**

Electron과 웹 모두 동일하게 동작합니다.

### 보기 모드

| 모드 | 설명 | 단축키 |
|------|------|--------|
| 창에 맞추기 | 비율 유지, 화면에 맞춤 | `Ctrl+0` |
| 화면에 꽉 채우기 | 화면을 가득 채움 (잘릴 수 있음) | `Ctrl+2` |
| 원본 크기 (1:1) | 실제 해상도 (필요 시 스크롤) | `Ctrl+1` |

선택한 보기 모드는 저장되어 다음 실행에도 적용됩니다.

### 이펙트 / Effects

- 비디오 프리셋: Normal, Vivid, Cinematic, Noir, Warm  
- 오디오 프리셋: Clean, Voice, Punch, Mellow, Radio  
- 슬라이더: 밝기 / 대비 / 채도, 베이스 / 트레블, 배속

## 타임라인 편집 / Timeline Editing

- 기본 트랙: 비디오 2개, 오디오 2개  
- 미디어를 타임라인으로 드래그하거나 파일 더블클릭으로 클립 추가  
- **클립 선택** 후 분할(`Ctrl+B`) / 삭제(`Del`)  
- 클립을 드래그해 위치·길이 조절  
- 타임라인 확대/축소 (`Ctrl++` / `Ctrl+-`)  
- 빈 영역 우클릭: 트랙 추가, 줌, 미디어 가져오기

## 프로젝트 / Projects

| 동작 | 메뉴 / 단축키 |
|------|----------------|
| 새 프로젝트 | 파일 → 새 프로젝트 (`Ctrl+N`) |
| 열기 | 파일 → 프로젝트 열기 (`Ctrl+O`) |
| 저장 | 파일 → 프로젝트 저장 (`Ctrl+S`) |
| 다른 이름 저장 | 파일 → 다른 이름으로 저장 (`Ctrl+Shift+S`) |
| 미디어 가져오기 | 파일 → 미디어 가져오기 (`Ctrl+I`) |
| 내보내기 | 파일 → 내보내기 (`Ctrl+E`) |

프로젝트 파일 확장자: **`.avp`** (타임라인 상태 JSON)

| 환경 | 저장 / 열기 |
|------|-------------|
| Electron | OS 대화상자로 디스크에 읽고 씀 |
| Web | 열기 = 파일 선택, 저장 = 브라우저 다운로드 |

내보내기(Export)는 현재 **플레이스홀더**입니다. 실제 인코딩은 이후 FFmpeg 등으로 연결할 수 있습니다.

## 설치 및 웹 배포 / Install and Web

### Windows 설치 파일

```bash
npm run build:win
```

생성 파일 예: `AV Editor Setup 1.0.0.exe` (루트 폴더에 복사됨)

설치 마법사에서 설치 경로를 선택할 수 있습니다.  
이미 설치된 버전이 있으면 **실행 중인 프로그램을 종료**하고 **기존 설치 폴더·설정을 삭제한 뒤** 새로 설치합니다.  
바탕 화면 / 시작 메뉴 바로가기는 기본으로 생성됩니다.

### 웹 정적 배포

```bash
npm run build:web
# dist-web/ 을 정적 호스팅에 업로드하거나
npx --yes serve dist-web
```

개발 중에는 `npm run web`만으로 충분합니다 (소스 직접 서빙).

## 문제 해결 / Troubleshooting

### 드라이브/폴더가 안 보입니다 (Electron)
- 앱을 다시 시작해 보세요. Windows에서는 드라이브 문자를 직접 조회합니다.

### 웹에서 재생할 파일이 없습니다
- Library에 샘플이 보이면 그것을 선택하세요.
- 없으면 **Add media** / Import 또는 파일을 Library로 드래그하세요.
- 페이지를 새로고치면 Library는 초기화됩니다.

### 전송 큐(재생/일시정지 아이콘)가 안 보입니다
- 브라우저에서 **강력 새로고침**(Ctrl+F5)을 해 보세요.
- `npm run web`으로 최신 `src/renderer`를 서빙하는지 확인하세요.
- 오래된 `dist-web`을 쓰는 경우 `npm run build:web`으로 다시 빌드하세요.

### 미리보기 컨트롤·타임라인이 안 보입니다
- 창 크기를 키우거나 앱을 재시작해 보세요. 레이아웃은 최소 해상도(약 1024×680)를 가정합니다.

### 아이콘이 Electron 기본입니다
```bash
npm run generate-icons
npm start
```

### 메뉴가 영어로만 나옵니다
- 툴바 또는 **언어** 메뉴에서 `한국어`를 선택하세요. 메뉴가 즉시 다시 구성됩니다.

### 빌드 후 루트에 exe가 없습니다
```bash
npm run copy-artifacts
```
`dist/`에 있는 설치 파일을 프로젝트 루트로 복사합니다.
