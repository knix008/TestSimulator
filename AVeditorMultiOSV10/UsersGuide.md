## 시작하기 / Getting Started

### 개발 실행 / Development

```bash
npm install
npm start
```

### 설치 파일로 실행 / Installed app

Windows에서 `AV Editor Setup x.y.z.exe`를 실행해 설치한 뒤, 시작 메뉴 또는 바탕 화면 바로가기로 실행합니다.

## 인터페이스 / Interface

```
┌──────────────────────────────────────────────────────────────┐
│  [툴바: 파일 · 미디어 · 편집 · 재생 · 줌 · 테마 · 언어]         │
├────────────────┬─────────────────────────────────────────────┤
│  파일 트리      │  미리보기 (영상/오디오)                       │
│  (경로 표시)    │  [보기 모드: 맞춤 / 꽉채움 / 원본]            │
│                │  [재생 컨트롤]                               │
├────────────────┤                                             │
│  파일 정보      ├─────────────────────────────────────────────┤
│  (선택 파일)    │  타임라인 (비디오/오디오 트랙)                 │

└──────────────────────────────────────────────────────────────┘
```

### 패널 크기 조절 / Resizing

- 왼쪽 사이드바 **오른쪽 경계**를 드래그하면 폭을 조절할 수 있습니다.
- 조절한 폭은 다음에 앱을 열 때도 유지됩니다.

## 파일 탐색기 / File Explorer

### 기본 동작

- 시작 시 **최근에 작업한 폴더**를 자동으로 펼칩니다.
- 상단 **경로 표시줄**에 현재 폴더의 전체 경로가 표시됩니다.
- 드라이브가 여러 개이면 헤더의 **드라이브 선택**으로 이동합니다.
- 폴더 아이콘 버튼으로 다른 폴더를 열 수 있습니다.

### 미디어 파일

- 지원 비디오: MP4, AVI, MOV, MKV, WebM, FLV, WMV, M4V, TS, MTS …
- 지원 오디오: MP3, WAV, AAC, FLAC, OGG, M4A, WMA, Opus, AIFF …
- **클릭**: 미리보기 + 파일 정보 표시  
- **더블클릭**: 타임라인에 클립 추가  

### 파일 정보 패널

선택한 미디어의 이름, 종류, 크기, 포맷, 수정/생성일, 경로를 표시합니다.

## 미리보기 / Preview

### 재생 컨트롤

| 버튼 | 동작 |
|------|------|
| 처음으로 / 끝으로 | 시작 또는 끝으로 이동 |
| 되감기 / 빨리감기 | 약 5초 이동 |
| 재생 / 일시정지 | Space |
| 정지 | 일시정지 후 처음으로 |
| 음량 / 음소거 | 볼륨 조절 |
| 전체화면 | 미리보기 영역 전체화면 |

### 보기 모드

| 모드 | 설명 | 단축키 |
|------|------|--------|
| 창에 맞추기 | 비율 유지, 화면에 맞춤 | `Ctrl+0` |
| 화면에 꽉 채우기 | 화면을 가득 채움 (잘릴 수 있음) | `Ctrl+2` |
| 원본 크기 (1:1) | 실제 해상도 (필요 시 스크롤) | `Ctrl+1` |

선택한 보기 모드는 저장되어 다음 실행에도 적용됩니다.

## 타임라인 편집 / Timeline Editing

- 기본 트랙: 비디오 2개, 오디오 2개  
- 미디어를 타임라인으로 드래그하거나 파일 더블클릭으로 클립 추가  
- **클립 선택** 후 분할(`Ctrl+B`) / 삭제(`Del`)  
- 클립을 드래그해 위치·길이 조절  
- 타임라인 확대/축소 (`Ctrl++` / `Ctrl+-`)  
- 빈 영역 우클릭: 트랙 추가, 줌, 미디어 가져오기

## 프로젝트 / Projects

| 동작 | 메뉴 / 단축키 |
|------|----------------|
| 새 프로젝트 | 파일 → 새 프로젝트 (`Ctrl+N`) |
| 열기 | 파일 → 프로젝트 열기 (`Ctrl+O`) |
| 저장 | 파일 → 프로젝트 저장 (`Ctrl+S`) |
| 다른 이름 저장 | 파일 → 다른 이름으로 저장 (`Ctrl+Shift+S`) |
| 미디어 가져오기 | 파일 → 미디어 가져오기 (`Ctrl+I`) |
| 내보내기 | 파일 → 내보내기 (`Ctrl+E`) |

프로젝트 파일 확장자: **`.avp`**

## 테마 및 언어 / Theme and Language

- **테마**: 툴바 해/달 버튼 또는 보기 → 테마 전환 (`Ctrl+T`)
- **언어**: 툴바 `EN`/`KO` 버튼 또는 메뉴 **언어**  
  - UI, 툴팁, **네이티브 메뉴**가 함께 전환됩니다.

## 컨텍스트 메뉴 / Context Menus

우클릭 메뉴가 다음 영역에 있습니다.

| 영역 | 주요 항목 |
|------|-----------|
| 파일 트리 | 미리보기, 타임라인 추가, 경로 복사, 탐색기에서 보기, 새로고침 |
| 미리보기 | 재생/정지, 보기 모드, 타임라인 추가, 가져오기 |
| 타임라인 | 분할, 삭제, 줌, 트랙 추가 |

각 메뉴 항목에는 아이콘이 함께 표시됩니다.

## 설치 (Windows) / Installation

```bash
npm run build:win
```

생성 파일 예: `AV Editor Setup 1.0.0.exe` (루트 폴더에 복사됨)

설치 마법사에서 설치 경로를 선택할 수 있습니다.  
이미 설치된 버전이 있으면 **실행 중인 프로그램을 종료**하고 **기존 설치 폴더·설정을 삭제한 뒤** 새로 설치합니다.  
바탕 화면 / 시작 메뉴 바로가기는 기본으로 생성됩니다.

## 문제 해결 / Troubleshooting

### 드라이브/폴더가 안 보입니다
- 앱을 다시 시작해 보세요. Windows에서는 드라이브 문자를 직접 조회합니다.

### 미리보기 컨트롤·타임라인이 안 보입니다
- 창 크기를 키우거나 앱을 재시작해 보세요. 레이아웃은 최소 해상도(약 1024×680)를 가정합니다.

### 아이콘이 Electron 기본입니다
```bash
npm run generate-icons
npm start
```

### 메뉴가 영어로만 나옵니다
- 툴바 또는 **언어** 메뉴에서 `한국어`를 선택하세요. 메뉴가 즉시 다시 구성됩니다.

### 빌드 후 루트에 exe가 없습니다
```bash
npm run copy-artifacts
```
`dist/`에 있는 설치 파일을 프로젝트 루트로 복사합니다.
