# MyImageViewer 도움말

MyImageViewer는 사진, 그림, 동영상, 오디오, DICOM 의료 영상을 보고 고치는 프로그램입니다. 이 문서는 메뉴와 화면의 기능을 하나씩 설명합니다.

## 시작 화면

프로그램을 켜면 파일이나 폴더를 열기 전에 **홈**이 나옵니다. 하늘과 들판 위에 카드가 놓여 있고, 카드를 누르면 그 기능으로 바로 갑니다.

- **폴더 열기**는 탐색기에 그 폴더를 펼칩니다.
- **파일 열기**는 이미지, 동영상, 오디오, DICOM을 고릅니다.
- **최근 폴더**는 예전에 연 폴더입니다. 이름을 누르면 다시 엽니다.
- 이미지가 필요한 카드(편집, 인쇄, 리사이즈, 배경 제거, 상세 정보)는 파일을 연 뒤에 동작합니다. 파일이 없으면 상태 표시줄에 안내가 나옵니다.

메뉴 바의 **홈**을 누르면 언제든 이 화면으로 돌아옵니다. 이미 연 파일은 유지됩니다. 설정의 “시작할 때 마지막 폴더와 파일 다시 열기”가 켜져 있으면, 다음에 켤 때 홈 대신 그 파일로 들어갑니다. 파일을 두 번 눌러 실행한 경우에도 홈을 건너뜁니다.

## 창과 메뉴 바

제목 표시줄은 없습니다. 예전에 제목 표시줄에 있던 내용이 메뉴 바로 옮겨졌습니다.

| 위치 | 내용 |
|------|------|
| 왼쪽 | 아이콘, **MyImageViewer**, 버전(빌드 번호가 있으면 함께) |
| 가운데 | **홈**, **파일 · 편집 · 보기 · 창 · 도움말** |
| 파일 이름 | 지금 연 파일. 저장하지 않은 변경이 있으면 이름 앞에 ● |
| 오른쪽 | 최소화, 최대화/복원, 닫기 |

메뉴 바의 빈 곳이나 프로그램 이름을 드래그하면 창이 움직입니다. 단추 위에서는 드래그되지 않습니다. `F11`은 전체 화면입니다. 닫을 때 저장하지 않은 변경이 있으면 저장, 저장 안 함, 취소를 묻습니다.

**도움말** 메뉴에는 **도움말**, **단축키**, **정보**가 있습니다. 도움말은 이 설명을 열고, `F1`도 같습니다. 단축키와 정보는 각각의 창을 엽니다.

메뉴와 우클릭 메뉴는 창 가장자리를 넘어서도 표시되므로 잘리지 않습니다. 모든 메뉴 항목에 아이콘이 있습니다. 선택된 항목은 아이콘을 그대로 두고 오른쪽에 ✓가 붙습니다. 메뉴 밖을 누르거나 `Esc`를 누르면 닫힙니다.

대화상자(설정, 정보, 인쇄, 크기 조절, 상세 정보, 확인 창)는 각각 독립된 창으로 열립니다. 제목 줄을 끌면 화면 어디로든, 메인 창 밖으로도 옮길 수 있습니다. 대화상자를 닫을 때까지 메인 창은 뒤에서 기다립니다.

## 파일 메뉴

- **파일 열기** (`Ctrl+O`): 파일 대화상자에서 하나를 고릅니다. 탐색기와 이전/다음 목록도 그 폴더로 맞춥니다.
- **폴더 열기** (`Ctrl+Shift+O`): 폴더를 고릅니다. 마우스를 올리면 최근 폴더가 나오고, 항목의 ×로 그 기록만 지울 수 있습니다.
- **다른 이름으로 저장** (`Ctrl+Shift+S`): 편집한 그림을 새 파일로 저장합니다. JPEG/WebP는 품질을 고릅니다.
- **내보내기**: PNG, JPEG, WebP, BMP. 지금 화면에 보이는 결과(회전, 보정, DICOM 윈도우)를 그 형식으로 씁니다.
- **인쇄** (`Ctrl+P`): 인쇄 미리보기. 동영상·오디오·썸네일 시트에서는 꺼집니다.
- **상세 정보** (`Ctrl+I`): 파일 이름, 경로, 크기, 형식, 해상도, EXIF, DICOM 태그를 표로 보여 줍니다. 전체를 복사할 수 있습니다.
- **탐색기에서 보기**, **삭제**: 데스크톱에서만. 삭제는 확인 후 휴지통이 아니라 선택한 파일을 지웁니다.
- **종료**: 창을 닫습니다.

파일이나 폴더를 창에 끌어다 놓아도 열립니다. 폴더는 열리고, 파일은 뷰어에 열립니다. 탐색기의 폴더나 썸네일 화면 위에 놓으면 파일이 그 폴더로 들어갑니다. 같은 드라이브면 이동, 다른 드라이브면 복사입니다.

## 탐색기

왼쪽은 **탐색기**와 **파일 정보**입니다. 위쪽 드라이브 단추(`C:`, `D:` …)로 디스크를 바꿉니다. 폴더를 누르면 펼쳐지고, 이미지 파일을 누르면 뷰어에 열립니다.

파일 아이콘은 형식마다 색이 다릅니다. JPEG는 주황, PNG는 초록, GIF는 보라, DICOM은 빨강, 동영상과 오디오도 각자 색이 있습니다. 폴더는 노란색입니다.

패널 제목의 접기 단추, 또는 도구 모음의 왼쪽 패널 단추로 탐색기를 세로 막대로 줄입니다. 막대에는 아이콘과 세로 제목만 남습니다. 경계선을 드래그하면 너비를 바꿉니다.

아래 **파일 정보**는 선택한 파일의 크기, 형식, 수정 시각, 이미지라면 픽셀 크기를 보여 줍니다. 사진이면 카메라, 렌즈, 노출, GPS가 있을 때 함께 나옵니다.

웹 브라우저로 실행하면(`npm run web`) 실제 드라이브 대신 브라우저가 허락한 폴더만 보입니다. 이름 바꾸기, 삭제, 탐색기에서 보기는 데스크톱에서만 됩니다.

시작할 때는 마지막으로 연 폴더가 썸네일 화면으로 열리고, 마지막에 본 이미지가 선택되어 있습니다. 그 폴더가 없어졌으면 최근 폴더 중 남아 있는 가장 최근 폴더가 열립니다. 설정 › 일반에서 끌 수 있습니다.

## 이미지 보기

가운데가 뷰어입니다. 그림이 없으면 안내 문구가 있고, 파일을 열면 캔버스에 그려집니다.

- **확대/축소**: `Ctrl++`, `Ctrl+-`, 도구 모음의 돋보기, 또는 그림 위에서 휠. 배율 칸에 `100%`처럼 직접 쳐도 됩니다. 휠 단계는 설정에서 5/10/25/50%입니다.
- **창에 맞추기** (`Ctrl+0`), **실제 크기** (`Ctrl+1`).
- **이동**: 포인터 도구에서 드래그. 커서는 손 모양입니다.
- **이전/다음**: `←` `→`, `Page Up` `Page Down`, 가장자리 화살표. 같은 폴더의 이미지·동영상·오디오 순서입니다.
- **회전** (`Ctrl+[`, `Ctrl+]`), **수평/수직 뒤집기**. 바로 적용되고 실행 취소할 수 있습니다.
- 투명 PNG 뒤에는 바둑판을 깔 수 있습니다. 설정에서 끄면 단색입니다.
- 크게 확대했을 때 픽셀을 부드럽게 할지, 각 픽셀을 네모로 보일지는 설정의 “확대 시 픽셀 다듬기”입니다. 의료 영상이나 도트 그림은 끄는 편이 좋습니다.

오른쪽은 **색상 · 보정**입니다. 히스토그램(빨강/초록/파랑과 밝기), 색상환, 밝기·대비·채도·색조·색온도가 있습니다. 슬라이더를 움직이면 바로 반영되고, 한 번 놓을 때마다 실행 취소 한 단계입니다. 슬라이더를 두 번 누르면 그 항목만 기본값으로 돌아갑니다. **색상 초기화**는 색 보정을 모두 되돌립니다. DICOM은 이쪽 대신 자체 윈도우/레벨을 씁니다.

## 썸네일

**창 › 폴더 썸네일 보기** 또는 홈의 썸네일 카드는 폴더를 바둑판으로 보여 줍니다. 칸을 누르면 그 파일이 열리고 썸네일 화면은 닫힙니다. 정렬과 아이콘/목록 전환은 썸네일 도구에 있습니다.

썸네일은 연 폴더마다, 그리고 시작할 때 최근 폴더들까지 백그라운드에서 만들어 썸네일 DB에 저장해 둡니다. 다음에 열면 바로 나옵니다. 설정에서 캐시 크기를 보고 비울 수 있습니다.

이미지를 보는 동안 아래에는 그 폴더의 필름스트립이 나옵니다. 양옆의 ‹ / ›, 또는 `←` / `→`로 넘깁니다.

**끌어서 놓기**: 썸네일(또는 선택한 전체)을 탐색기의 폴더나 폴더 칸 위로 끌어 놓으면 그 폴더로 이동합니다. `Ctrl`을 누르면 복사, `Esc`는 취소입니다. 창 가장자리 밖까지 끌면 Windows 탐색기, 바탕화면, 다른 프로그램에 놓을 수 있습니다. 이때는 항상 복사됩니다.

## 동영상과 오디오

MP4, WebM, MOV, MKV, AVI 등을 열면 아래쪽에 재생 막대가 나옵니다.

- 재생, 일시정지(`Space`), 정지
- 탐색 슬라이더와 현재 시간 / 길이
- 음량과 음소거. 값은 설정에 기억됩니다.
- 자막이 있으면 자막 단추로 켜고 끕니다. 파일 단추로 `.srt` 등을 고르고, 언어를 고를 수 있습니다. 기본 언어와 “자막이 있으면 표시”는 설정에 있습니다.

오디오 파일은 음표와 재생기로 표시됩니다. 동영상·오디오는 회전이나 색 보정의 대상이 아닙니다.

## DICOM

`.dcm`, `.dicom`을 열면 두 줄의 DICOM 막대가 나옵니다.

**위 줄 — 어떻게 보이는가**

- 윈도우 프리셋(폐, 뼈, 뇌 등 파일이 가진 값)
- **C** 윈도우 중심, **W** 윈도우 폭. 숫자를 고치거나 `Ctrl`을 누른 채 드래그합니다.
- 반전(`I`), 윈도우 재설정(`W`), 컬러맵(`M`)
- 픽셀 값 범위, VOI 함수

**아래 줄 — 어디를 보고 무엇을 재는가**

- 프레임 슬라이더, 이전/다음 프레임(`Ctrl+Page Up` / `Ctrl+Page Down`), 처음/끝(`Home` / `End`)
- 시네 재생(`Space`)과 초당 프레임. 파일에 속도가 없으면 설정의 기본 fps를 씁니다.
- 오버레이 평면(`V`), 주석(`O`), 눈금자(`G`), 스케일 바(`B`)
- 측정: 자(`R`), 각도(`A`), 타원 ROI(`E`), 사각형 ROI(`T`). 측정 지우기.

모서리에는 환자·검사 글자, 방향 표시, 스케일 바가 겹쳐 그려집니다. 주석 표시와 오버레이 색은 설정에서 바꿉니다. DICOM을 PNG 등으로 내보내면 지금 윈도우가 적용된 화면이 저장됩니다.

## 편집 창

**편집 › 이미지 편집** 또는 `Ctrl+E`. 편집 창도 메뉴 바에 아이콘, “이미지 편집”, 파일 이름이 있습니다.

도구:

- **포인터**: 그림을 옮기고 선택 영역을 다룹니다.
- **사각형, 올가미, 다각형, 마법 지팡이**: 영역을 선택합니다. 마법 지팡이는 비슷한 색을 묶고, 허용 오차 숫자로 범위를 바꿉니다.
- **잘라내기 / 복사**, **선택 영역으로 자르기**, **선택 해제**
- **배경 제거**: 알고리즘을 고른 뒤 배경을 투명하게 만듭니다. 사람이 있는 사진, 상품 사진에 맞춘 방식이 따로 있습니다.
- 회전, 뒤집기, 리사이즈, 실행 취소(`Ctrl+Z`), 다시 실행(`Ctrl+Y`)

왼쪽은 프리셋(흑백, 세피아, 반전 등), 오른쪽은 밝기·대비 같은 조정이고 조정 맨 위에 색상환이 있습니다. 패널 제목마다 아이콘이 있습니다. 제목의 ‹ / › 단추, 도구 모음의 왼쪽·오른쪽 패널 단추, 또는 **보기 › 왼쪽 / 오른쪽 패널**로 패널을 세로 막대로 접습니다. 막대에는 아이콘과 제목이 남고, 누르면 다시 펼쳐집니다. 설정 오른쪽의 ⓘ 단추는 프로그램 정보를 보여 줍니다. **적용**은 편집을 뷰어에 반영하고 창을 닫습니다. **취소**(`Esc`)는 버립니다. **새 이름으로 저장**은 원본을 그대로 두고 `파일이름_변경.png` 같은 이름으로 제안합니다. HEIC 원본은 JPEG로 제안합니다.

뷰어에서 한 회전·뒤집기·색 보정도 같은 실행 취소 스택에 쌓입니다. **모든 편집 초기화**는 파일을 다시 연 상태로 되돌립니다.

## 리사이즈

**편집 › 이미지 리사이즈** (`Ctrl+Shift+R`)는 미리보기와 함께 크기를 정합니다.

- 방법: 퍼센트, 픽셀, 긴 변, 가로·세로 안에 맞추기
- 프리셋 단추, 가로세로 비율 고정
- 리샘플: 고품질(부드러움), 중간, 최근접(픽셀)
- 저장 폴더, 파일 이름, 형식(PNG/JPEG/WebP/BMP), JPEG·WebP 품질
- “현재 이미지에도 적용”을 켜면 뷰어의 그림도 같이 바뀝니다.

## 인쇄

인쇄 미리보기는 왼쪽이 종이, 오른쪽이 설정입니다.

- 프린터, 용지(A4, Letter, Legal, A3, A5, Tabloid), 여백(없음/좁게/보통/넓게)
- 방향: 자동, 세로, 가로
- 배율: 페이지에 맞추기, 실제 크기, 사용자 지정(%)
- 매수, 컬러 또는 회색
- 머리글: 파일 이름, 날짜, 둘 다, 직접 입력. 왼쪽/가운데/오른쪽
- 쪽 번호: 위치와 형식(`1 / 1`, `1`, `Page 1`, `- 1 -`)

**인쇄**를 누르면 고른 프린터로 보냅니다.

## 창 메뉴

- 왼쪽 패널(탐색기·파일 정보), 오른쪽 패널(색상·보정) 접기
- 폴더 썸네일 보기
- 전체 화면, 최소화, 최대화/복원
- 설정

## 테마와 언어

도구 모음의 팔레트는 **다음 테마**, 옆의 작은 화살표는 테마 목록입니다. 다크와 라이트가 여러 개 있고, 설정 대화상자의 테마 탭에서도 고릅니다.

언어 단추는 한국어와 English를 오갑니다. 국기는 지금 누르면 바뀌는 쪽을 보여 줍니다. 메뉴, 대화상자, 이 도움말이 함께 바뀝니다.

## 설정

- **일반**: 언어, 마지막 폴더/파일 복원, 최근 폴더 지우기, 썸네일 캐시 비우기, Windows 기본 앱으로 등록
- **테마**: 다크/라이트 목록
- **보기와 편집**: 휠 확대 단계, 투명 바둑판, 확대 시 픽셀 다듬기, 배경 제거 알고리즘
- **DICOM**: 주석 표시, 기본 시네 속도, 오버레이 색
- **미디어**: 자막 표시, 선호 언어, 음량, 음소거

**모든 설정 초기화**는 이 값들을 설치 직후로 되돌립니다. 최근 폴더 목록은 일반 탭에서 따로 지웁니다.

## 단축키

| 동작 | 키 |
|------|----|
| 도움말 | `F1` |
| 파일 열기 | `Ctrl+O` |
| 폴더 열기 | `Ctrl+Shift+O` |
| 다른 이름으로 저장 | `Ctrl+Shift+S` |
| 인쇄 | `Ctrl+P` |
| 상세 정보 | `Ctrl+I` |
| 이미지 편집 | `Ctrl+E` |
| 확대 / 축소 | `Ctrl++` / `Ctrl+-` |
| 창에 맞추기 / 실제 크기 | `Ctrl+0` / `Ctrl+1` |
| 왼쪽 / 오른쪽 회전 | `Ctrl+[` / `Ctrl+]` |
| 리사이즈 | `Ctrl+Shift+R` |
| 이전 / 다음 | `←` `Page Up` / `→` `Page Down` |
| 실행 취소 / 다시 실행 | `Ctrl+Z` / `Ctrl+Y` |
| 복사 | `Ctrl+C` |
| 선택 해제 / 닫기 | `Esc` |
| 전체 화면 | `F11` |
| DICOM 프레임 | `Ctrl+Page Up` / `Ctrl+Page Down`, `Home` / `End` |
| DICOM 재생 | `Space` |
| DICOM 반전 / 윈도우 재설정 | `I` / `W` |
| DICOM 윈도우 드래그 | `Ctrl`+드래그 |

탐색기에 포커스가 있을 때 `Ctrl+C` / `Ctrl+X` / `Ctrl+V`는 파일을 복사·잘라 내기·붙여 넣기합니다. 그때의 `Ctrl+P`도 붙여 넣기입니다. 그 밖에서는 `Ctrl+P`가 인쇄입니다.

## 웹으로 실행

데스크톱은 `npm start`, 브라우저 모드는 `npm run web` 입니다. 브라우저는 보안 때문에 디스크 전체를 보여 주지 못하고, 마지막 폴더 복원, 삭제, 탐색기에서 보기, 전체 화면 창 단추, 일부 메타데이터가 없습니다. 보기·확대·회전·편집·인쇄 미리보기의 흐름은 같습니다.

같은 내용의 영문 문서는 `doc/help.md` 입니다.
