# MyDBTools 튜토리얼

이 튜토리얼은 MyDBTools를 처음 쓰는 분이 **30분 안에** 주요 기능을 한 번씩 직접 해 보도록
안내합니다. 예제 스키마를 열어 살펴보고, 테이블과 관계를 더하고, 정규화 분석을 고치고,
SQL로 내보내고, 인쇄 창을 써 보고, 마지막으로 나만의 테마를 만듭니다.

각 단계의 메뉴·단추 이름은 프로그램 화면에 나오는 그대로입니다. 막히면
[사용자 설명서](UsersGuide.md)의 해당 장을 펼쳐 보세요.

---

## 준비

- 데스크톱: **MyDBTools** 를 실행합니다. 개발 환경이라면 프로젝트 폴더에서 `npm start`.
- 웹: `npm run web` 후 브라우저에서 <http://127.0.0.1:5174> 를 엽니다.

프로그램이 열리면 **시작 화면**이 보입니다. 보이지 않으면 메뉴 막대 맨 앞의 **홈** 단추를
누르세요.

---

## 1단계 — 시작 화면 둘러보기

1. 맨 위 제목 카드에서 프로그램 이름과 버전 **MyDBTools v1.0.1** 을 확인합니다.
2. **시작하기** 카드에는 새로 만들기 · 프로젝트 열기 · 데이터베이스 열기 · 작업 공간 열기가 있습니다.
3. **도움말** 카드의 **사용자 설명서** 를 눌러 봅니다. 설명서가 **별도 창**으로 열립니다.
   창 위쪽의 **튜토리얼** 단추로 지금 보고 있는 이 문서로 바꿀 수 있습니다. 확인했으면 설명서
   창은 옆에 두고 돌아옵니다.
4. 아래 **예제 (20)** 카드에 20개 예제의 다이어그램 미리 보기가 차례로 그려지는 것을 봅니다.
5. 맨 아래 **움직이는 배경** 카드에서 **눈** 을 누르고, **속도** 를 200% 로, **카드 불투명도** 를
   60% 로 바꿔 봅니다. 배경이 빨라지고 카드 뒤로 더 비쳐 보입니다. **자동 변경** 을 **15초마다** 로 두면
   시작 화면이 열려 있는 동안 배경이 저절로 바뀝니다.
6. **예제** 카드의 **⠿** 손잡이를 끌어 **시작하기** 카드 위에 놓아 보고, 카드 오른쪽 아래 모서리를 끌어
   크기도 바꿔 봅니다. 제목 카드의 **카드 정렬** 로 원래대로 돌립니다. 제목 카드는 움직이지 않습니다.

> 결과: 시작 화면의 카드 구성을 알고, 설명서 창을 따로 띄울 수 있습니다.

---

## 2단계 — 예제 열기

1. 예제 중 **도서관** (SQLite) 카드를 누릅니다.
2. 시작 화면이 닫히고 새 탭 **Library** 에 7개 테이블이 화면에 맞춰 나타납니다.
3. 오른쪽 **구조** 탭에서 `books` 를 눌러 봅니다. 캔버스에서 같은 테이블이 선택되고
   아래 **속성** 패널에 테이블 속성이 나옵니다.
4. 마우스 휠로 확대·축소하고, 빈 곳을 끌어 화면을 옮겨 봅니다. **Ctrl+0** 으로 다시 전체 맞춤.

> 확인: 테이블 머리 색은 대상 DB 색입니다(SQLite는 보라 계열). 열쇠 표시는 PK,
> `FK` 표시는 외래 키입니다.

---

## 3단계 — 테이블과 관계 더하기

도서관에 **리뷰** 기능을 더해 봅니다.

1. **편집 → 테이블 추가** (Ctrl+T). 새 테이블이 오른쪽에 생깁니다.
2. 새 테이블을 **더블클릭**해 테이블 편집 창을 엽니다(별도 창입니다).
   - 이름: `reviews`
   - **추가** 로 컬럼을 세 개 더합니다: `book_id` (INTEGER, NULL 허용 끄기),
     `member_id` (INTEGER, NULL 허용 끄기), `rating` (INTEGER)
   - **확인** 을 누릅니다.
3. 왼쪽 도구 패널에서 **1:N** 을 고른 뒤, `books` 테이블에서 `reviews` 테이블로 **끌어 놓습니다**.
   `books.id` → `reviews.book_id` 관계가 생깁니다.
4. 같은 방법으로 `members` → `reviews` 관계를 만듭니다.
5. 도구 모음의 **자동 정렬** 단추를 눌러 배치를 정리합니다.

> 결과: 탭 이름 옆과 제목 표시줄에 `●` 가 붙어 저장하지 않은 변경이 있음을 알려 줍니다.

---

## 4단계 — 정규화 분석 고치기

1. 오른쪽 **정규화** 탭(또는 F5)을 엽니다.
2. 위쪽 칩에서 **1NF ~ 3NF** 를 켭니다.
3. 목록의 항목을 누르면 해당 테이블이 선택되고 문제 컬럼이 노랗게 강조됩니다.
4. 제안대로 고쳐 봅니다. 예를 들어 `reviews` 에 PK가 없다는 경고가 있으면, `reviews` 의
   `id` 컬럼(새 테이블에 자동으로 생긴 컬럼)이 PK인지 속성 패널에서 확인합니다.
5. **인덱스 어드바이저** 탭으로 가서 `reviews.book_id`, `reviews.member_id` 에
   인덱스 제안이 있는지 확인하고 `CREATE INDEX` 문을 봅니다.

> 결과: 경고 수가 줄어드는 것을 확인합니다. 분석은 편집할 때마다 바로 다시 계산됩니다.

---

## 5단계 — 저장하고 SQL로 내보내기

1. **파일 → 다른 이름으로 저장** (Ctrl+Shift+S) → `MyLibrary.mdprj` 로 저장합니다.
   저장 완료 창이 경로를 알려 주고 `●` 표시가 사라집니다.
2. 도구 모음의 DB 드롭다운에서 **PostgreSQL** 로 바꿔 봅니다. 테이블 머리 색이 바뀝니다.
3. **파일 → 내보내기 → SQL → PostgreSQL 스크립트** 로 `.sql` 파일을 만듭니다.
4. 같은 메뉴의 **이미지 → PNG** 로 다이어그램 그림도 저장해 봅니다.

> 확인: 만든 `.sql` 파일을 메모장으로 열면 `CREATE TABLE` 과 `ALTER TABLE … FOREIGN KEY` 가 있습니다.

---

## 6단계 — 인쇄 창 쓰기

1. **파일 → 인쇄…** (Ctrl+P) 를 누릅니다. **인쇄 창이 따로** 열리고 메인 창은 그대로 쓸 수 있습니다.
2. 위 도구 모음에서 **다이어그램 / 스키마 보고서 / 분석 보고서** 를 번갈아 눌러 미리 보기가
   바뀌는 것을 봅니다.
3. **다이어그램** 으로 돌아와 **세로 / 가로** 를 바꾸고, 색을 **현재 테마 색** 으로 바꿔 봅니다.
4. **PDF로 저장** 을 눌러 PDF를 만들어 봅니다(종이를 아끼려면 인쇄 대신 이 방법으로 확인하세요).
5. 오른쪽 위 빨간 **✕** 로 인쇄 창을 닫습니다.

> 참고: Windows 데스크톱 판은 **인쇄** 를 누르면 고른 프린터로 대화 상자 없이 바로 보냅니다.

---

## 7단계 — 테마와 캔버스 배경

1. 메뉴 막대 오른쪽의 **테마 드롭다운** 을 열고 **다크 계열** 열에서 **도쿄 나이트** 를 고릅니다.
   **캔버스 바탕까지** 함께 바뀝니다. 드롭다운의 **다음 테마** 로 차례대로 넘겨 볼 수도 있습니다.
2. 드롭다운 맨 위의 **테마 설정…** 을 엽니다.
3. **캔버스 배경** 에서 **청사진** 을 고릅니다. 메인 창의 캔버스가 바로 바뀝니다.
   화면을 끌어 보면 무늬가 다이어그램과 함께 움직입니다.
4. **사용자 정의 테마** 를 만듭니다.
   - **현재 테마에서 시작** 을 누릅니다.
   - 이름: `내 도서관`, 종류: **다크**
   - 창 배경 `#101828`, 패널 `#1d2939`, 캔버스 `#0c111d`, 강조색 `#f79009`, 글자 `#f2f4f7`
   - 오른쪽 미리 보기를 확인한 뒤 **테마로 저장** 을 누릅니다.
5. 테마 드롭다운 맨 아래 **사용자 정의 테마** 묶음에 `내 도서관` 이 생긴 것을 확인합니다.
6. 마음에 드는 테마로 되돌리고 창을 닫습니다.

> 결과: 사용자 정의 테마는 설정에 저장되어 다음 실행 때도 남아 있습니다.

---

## 8단계 — 패널 다루기

1. 도구 모음 오른쪽 끝의 두 단추로 하단 · 오른쪽 패널을 접었다 펼쳐 봅니다.
2. 접힌 패널은 아이콘과 제목만 남은 얇은 막대가 됩니다. 막대를 누르면 다시 펼쳐집니다.
3. 오른쪽 패널과 캔버스 사이의 구분자를 끌어 너비를 바꿔 봅니다.
4. 캔버스 아래 **출력** 패널의 **문제점** 탭에서 항목을 눌러 테이블로 이동하고, **로그** 탭에서
   지금까지의 작업 기록을, **정보** 탭에서 스키마 요약을 확인합니다.

## 9단계 — 마무리

1. **홈** 단추로 시작 화면을 엽니다. **최근 파일** 에 `MyLibrary.mdprj` 가 보입니다(데스크톱 판).
2. 시작 화면 맨 아래 **프로그램을 시작할 때 시작 화면 표시** 를 원하는 대로 둡니다.
3. 열린 탭을 모두 다시 열고 싶다면 **파일 → 작업 공간 저장** 으로 `.mdwsp` 파일을 만들어 둡니다.

수고하셨습니다. 이제 다른 예제(병원, 은행, 벡터 검색 등)를 열어 같은 과정을 반복해 보거나,
**파일 → 데이터베이스 열기** 로 실제 SQLite 파일이나 SQL 스크립트를 가져와 다이어그램을
만들어 보세요. 단축키 전체 목록은 [사용자 설명서](UsersGuide.md#12-단축키-목록)에 있습니다.
