# 사용자 가이드 — UML Editor

이 문서는 **UML Editor**(MyUML) 사용법을 설명합니다.

## 1. 설치와 실행

### Windows 설치본

1. `UML-Editor-Setup-<version>.exe`를 실행합니다.
2. 설치 위치를 선택한 뒤 설치를 진행합니다.
3. 바탕화면·시작 메뉴의 **UML Editor**로 실행합니다.

같은 앱이 이미 있으면 설치 프로그램이 이전 설치와 앱 데이터를 정리한 뒤 새로 설치합니다.

### 개발 실행 (소스)

```powershell
npm install
npm start
```

## 2. 화면 구성

- **상단 툴바**: 새 문서, 열기, 저장, 실행 취소/다시 실행, 확대·축소, 테마, 언어,보내기
- **왼쪽 팔레트**: 현재 다이어그램에 넣을 요소·커넥터
- **가운데 캔버스**: 다이어그램 편집 영역
- **오른쪽 속성**: 선택 항목의 이름·타입·연결 속성 등
- **다이어그램 탭/목록**: 프로젝트 안 여러 다이어그램 전환

## 3. 프로젝트 파일 (`.umlprj`)

| 항목 | 설명 |
|------|------|
| 확장자 | `.umlprj` |
| 내용 | 여러 다이어그램이 들어 있는 JSON 프로젝트 |
| 열기 | 메뉴/툴바 **열기**, 또는 Explorer에서 파일 더블클릭 |
| 저장 | **저장** / **다른 이름으로 저장** |

권장: 의미 있는 프로젝트 이름을 지정한 뒤 저장합니다.

샘플 프로젝트는 `samples/` 폴더에 다이어그램 종류별로 있습니다 (`01-class` … `13-timing`).

## 4. 다이어그램 종류

새 다이어그램을 만들 때 아래 종류를 고를 수 있습니다.

1. Class  
2. Profile  
3. Package  
4. Object  
5. Composite Structure  
6. Component  
7. Deployment  
8. Use Case  
9. Sequence  
10. Communication  
11. Activity  
12. State Machine  
13. Timing  

종류마다 팔레트 도구가 달라집니다.

## 5. 기본 편집

1. 팔레트에서 요소를 선택한 뒤 캔버스를 클릭해 배치합니다.
2. 커넥터 도구를 고른 뒤 시작 요소 → 끝 요소 순으로 클릭해 연결합니다.
3. 요소나 선을 선택하면 오른쪽에서 이름·속성·다중성 등을 수정합니다.
4. 드래그로 이동, 모서리로 크기 조절을 합니다.
5. 선은 직선 / 직교 / 곡선으로 바꿀 수 있습니다 (속성 또는 관련 UI).

### 실행 취소

- **실행 취소** / **다시 실행** 버튼, 또는 일반 단축키 환경의 Undo/Redo를 사용합니다.

### 테마·언어

- **Light / Dark** 테마 전환
- **한국어 / English** UI 전환

## 6. 컴포넌트 다이어그램 — 연결(Interface Pair)

컴포넌트 다이어그램에서 **연결**(영어: Interface Pair)은 “조립 선”이 아니라 **제공(원) + 요구(반원) 인터페이스 쌍**을 만드는 도구입니다.

1. 팔레트에서 **연결**을 선택합니다.
2. 시작 쪽(컴포넌트 또는 포트)을 클릭합니다.
3. 끝 쪽을 클릭합니다.
4. 원에 가까운 쪽이 provided, 반원 쪽이 required로 맞춰집니다.
5. 쌍의 한쪽을 선택하면 양쪽이 함께 강조됩니다.
6. 속성/컨텍스트 메뉴의 **원/반원 방향 바꾸기**로 역할을 바꿀 수 있습니다.

포트가 가까이 있으면 드롭 시 포트에 붙습니다. 컴포넌트끼리, 포트끼리도 연결할 수 있습니다.

## 7. 선 교차와 직교 경로

- 선이 다른 선과 교차하면 **브리지(점프)** 로 표시되어 겹침을 구분하기 쉽습니다.
- **직교** 라우팅은 도형을 피하도록 꺾은선을 만듭니다. 중간 구간을 드래그해 위치를 조정할 수 있습니다.

## 8. 이미지보내기

툴바의보내기로 캔버스를 이미지로 저장할 수 있습니다 (PNG, GIF 등).  
투명 배경 옵션이 있는 형식은 배경을 비울 수 있습니다.

## 9. 패키지·배경 요소

패키지 등 배경 역할 노드는 다른 요소·선보다 아래에 그려져, 선이 가려지지 않도록 처리됩니다. 패키지 채우기는 투명에 가깝게 표시될 수 있습니다.

## 10. 아이콘 안내

| 아이콘 | 의미 |
|--------|------|
| 파란 사각형 앱 아이콘 | UML Editor 프로그램 |
| 문서 모양 프로젝트 아이콘 | `.umlprj` 프로젝트 파일 |

설치 후에도 Explorer 아이콘이 예전처럼 보이면 새로고침하거나, 앱을 다시 설치한 뒤 확인해 보세요.

## 11. 문제 해결

| 증상 | 조치 |
|------|------|
| `.umlprj` 더블클릭이 안 됨 | UML Editor를 설치했는지, 파일 연결이 등록됐는지 확인 |
| 아이콘이 안 바뀜 | Windows 아이콘 캐시·이전 바로가기 확인, 재설치 |
| 설치가 실패함 (`EPERM` 등) | 실행 중인 UML Editor를 종료한 뒤 `release/win-unpacked`를 삭제하고 다시 빌드/설치 |
| 소스 실행과 설치본 설정이 섞임 | 소스 실행은 별도 userData(`MyUML Source`)를 사용합니다 |
