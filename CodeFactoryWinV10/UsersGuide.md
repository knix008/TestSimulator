# Code Analyzer — 사용자 가이드

Code Analyzer는 Windows용 **다언어 코드 분석 도구**입니다. 이 문서는 앱을 **처음부터 끝까지 사용하는 방법**을 설명합니다.  
각 지표·경고의 **의미와 해석**은 **[CodeAnalysisGuide.md](CodeAnalysisGuide.md)** 를 참고하세요.

## 1. 시작하기

### 요구 사항

- Windows 10 이상
- [.NET 8](https://dotnet.microsoft.com/download) 런타임(개발자 빌드 시 SDK)
- Git 핫스팟 분석: 분석 대상 폴더가 Git 저장소이고 `git` 명령을 사용할 수 있을 것

### 실행 방법

**명령줄**

```powershell
dotnet run --project CodeAnalyzer
```

**Visual Studio**

1. `CodeAnalyzer.sln`을 엽니다.
2. 시작 프로젝트를 **CodeAnalyzer**로 지정합니다.
3. **F5**로 실행합니다.

**MSI 설치**

Release 빌드로 생성한 `CodeAnalyzer.Setup.msi`를 설치한 뒤 시작 메뉴에서 실행합니다. 자세한 내용은 [CodeAnalyzer.Setup/README.md](CodeAnalyzer.Setup/README.md)를 참고하세요.

## 2. 화면 구성

```
┌─────────────────────────────────────────────────────────────┐
│ [파일 ▼]  🔍 찾기: [________]  ◀ 이전   다음 ▶              │  ← 메뉴·검색
├──────────────┬──────────────────────────────────────────────┤
│  분석 패널   │  뷰: [호출 그래프 ▼]  시작 함수  레이아웃 …   │  ← 툴바
│  · 루트 경로 │                                              │
│  · 언어 선택 │           다이어그램 / 목록 영역              │
│  · 제외 폴더 │                                              │
│  · 분석 실행 │                                              │
├──────────────┴──────────────────────────────────────────────┤
│ 상태 표시줄 · 진행률                                         │
└─────────────────────────────────────────────────────────────┘
```

| 영역 | 설명 |
|------|------|
| **왼쪽 패널** | 분석 대상 경로, 언어, 제외 디렉터리, **분석 실행** / **분석 설정** |
| **상단 툴바** | 뷰 전환, 시작 함수·타입, 레이아웃·연결선, 펼치기/접기, 뒤로 |
| **중앙** | 선택한 뷰의 그래프 또는 표 |
| **메뉴·검색** | 파일 작업, 함수·파일·타입 검색 |
| **하단 상태줄** | 진행률, 분석 요약, 마지막 작업 결과 |

## 3. 분석 실행

### 기본 순서

1. **루트 디렉터리** — **찾아보기...**로 분석할 프로젝트 폴더를 선택합니다.
2. **분석할 프로그래밍 언어** — C#, Python, Java 등 필요한 항목을 체크합니다. (최소 1개)
3. **하위 디렉터리 제외** — `bin`, `obj`, `.git` 등은 기본 제외됩니다. 추가로 빼고 싶은 폴더를 체크합니다.
4. **(선택) 분석 설정...** — 검사 항목·임계값·중복 코드 최소 줄 수를 조정합니다.
5. **분석 실행** — 분석이 끝날 때까지 기다립니다. 실행 중에는 버튼이 **멈춤**으로 바뀌며, 클릭하면 중지를 요청할 수 있습니다.

### 분석 완료 후

- **분석 완료** 대화상자에 요약(함수 수, 순환 호출, 경고 등)이 표시됩니다.
- **요약 복사**로 텍스트를 클립보드에 복사할 수 있습니다.
- 상태 표시줄에 소요 시간·파일 수·메트릭 요약이 나타납니다.

### 주의

- 경로가 없거나 언어를 하나도 선택하지 않으면 분석을 시작할 수 없습니다.
- **분석 설정**이나 임계값을 바꾼 뒤에는 **다시 분석**해야 결과에 반영됩니다.
- 설정은 `%LocalAppData%\CodeAnalyzer\settings.json`에 자동 저장됩니다.

## 4. 파일 메뉴

**파일** 메뉴와 각 하위 항목 앞에 아이콘이 표시됩니다.

| 메뉴 | 단축키 | 설명 |
|------|--------|------|
| **결과 불러오기...** | Ctrl+O | 이전에 저장한 JSON 분석 결과를 불러옵니다. |
| **결과 저장...** | Ctrl+S | 현재 분석 결과를 JSON으로 저장합니다. |
| **메트릭 CSV보내기...** | — | 함수·파일·타입·패키지·전역 변수·접근 관계를 CSV로 저장합니다. |
| **분석 보고서보내기 (HTML/MD/Word/PDF)...** | — | 종합 보고서를 HTML, Markdown, Word, PDF 중 선택해 저장합니다. |
| **이미지로 내보내기...** | Ctrl+E | 현재 그래프·다이어그램 뷰를 PNG 이미지로 저장합니다. |

분석 결과가 없으면 저장·보내기 메뉴는 비활성화됩니다. 분석 중에는 **결과 불러오기**를 사용할 수 없습니다.

## 5. 검색

메뉴 오른쪽 **🔍 찾기** 상자에서 함수·타입·파일·디렉터리를 검색합니다.

| 동작 | 방법 |
|------|------|
| 검색 시작 | Ctrl+F로 포커스 이동 후 텍스트 입력 |
| 결과 목록 | 입력하면 아래에 일치 항목 팝업 표시 |
| 항목 선택 | ↓/↑ 이동, Enter로 해당 위치로 이동 |
| 다음 / 이전 | **다음 ▶** (F3), **◀ 이전** (Shift+F3) |
| 닫기 | Esc |

검색으로 선택한 함수는 **호출 그래프**의 시작 함수로 설정되거나, 해당 파일·위치로 이동합니다.

## 6. 도구 모음(툴바)

| 컨트롤 | 설명 |
|--------|------|
| **뷰** | 호출 그래프, 클래스 다이어그램, 코드 메트릭 등 11종 뷰 전환 |
| **시작 함수** | 호출 그래프·일부 구조 뷰의 루트 함수 선택 (자동 진입점 포함) |
| **레이아웃** | 좌→우 / 위→아래 트리 배치 |
| **연결선** | 직선 / 직각(orthogonal) / 베지어 |
| **모두 펼치기 / 접기** | 트리형 그래프 노드 일괄 펼침·접음 |
| **◀ 뒤로** | 이전에 보던 그래프 루트·파일·디렉터리로 되돌아감 (Alt+←) |
| **뷰 초기화** | 줌·스크롤을 기본 상태로 |

표 형태 뷰(코드 메트릭, 중복 코드, 전역 변수)에서는 레이아웃·연결선·펼치기가 비활성화됩니다. **전역 변수 접근 그래프**를 볼 때는 레이아웃·연결선만 사용할 수 있습니다.

## 7. 뷰 종류

뷰 콤보에서 다음 항목을 선택합니다.

| 뷰 | 용도 |
|----|------|
| **호출 그래프** | 함수 간 호출 관계를 트리로 탐색 |
| **클래스 다이어그램** | 타입 간 관계 |
| **시퀀스 다이어그램** | 호출·메시지 흐름 |
| **데이터 흐름도** | 데이터 이동 요약 |
| **상속 구조** | 상속 계층 |
| **파일 호출 관계** | 파일 단위 참조·호출 |
| **디렉터리 호출 관계** | 폴더(패키지) 단위 관계 |
| **코드 메트릭** | 함수·파일·타입·패키지·아키텍처 수치 표 |
| **중복 코드** | 동일 코드 블록 그룹 |
| **전역 변수** | 전역 변수 목록·접근 함수·접근 그래프 |
| **DB ERD** | 탐지된 DB 스키마·테이블 관계 |

### 더블클릭·탐색

- 그래프 **노드 더블클릭**: 해당 항목을 새 루트로 설정하거나 관련 뷰로 이동
- **코드 메트릭·아키텍처** 행 더블클릭: 관련 함수·파일·그래프·중복 코드로 이동
- **중복 코드** 그룹 더블클릭: 해당 파일 위치로 이동

## 8. 코드 메트릭 탭

**코드 메트릭** 뷰 상단 탭:

| 탭 | 내용 |
|----|------|
| **함수** | CC, 인지 복잡도, Fan-in/out, MI, Halstead 등 |

| **타입** | LCOM, DIT, NOC, WMC, RFC, 타입 간 의존 |
| **패키지** | Ca, Ce, 불안정성(I), 추상도(A), 거리(D) |

- **열 헤더에 마우스를 올리면** 해당 지표 설명 툴팁이 표시됩니다.
- 임계값을 넘는 행은 **경고·심각** 색으로 강조됩니다.
- 열 헤더 클릭으로 정렬할 수 있습니다.

## 9. 전역 변수 뷰

**전역 변수** 뷰는 공유 상태와 숨은 결합을 파악하는 데 사용합니다.

### 화면 구성

- **상단 목록**: 전역 변수 이름, 파일, 줄, 접근 함수 수 등
- **접근 함수**: 선택한 변수를 읽거나 쓰는 함수 목록 (종류: Read / Write / ReadWrite)
- **미리보기**: 선언 주변 소스 코드

### 주요 동작

| 동작 | 방법 |
|------|------|
| 접근 그래프 보기 | 변수 **더블클릭**, **접근 함수 그래프** 버튼, 또는 우클릭 메뉴 |
| 선언 파일 열기 | **선언 위치 파일 열기** 버튼 또는 우클릭 메뉴 |
| 접근 함수로 이동 | 접근 함수 목록 **더블클릭** → 해당 함수 위치로 이동 |

### 접근 그래프

- **왼쪽**: 접근하는 함수들
- **오른쪽**: **하나의** 전역 변수 노드 (`[G]` 표시)
- 모든 접근 함수에서 전역 변수로 **화살표**가 연결됩니다.
- 접근 함수가 없으면 전역 변수 노드만 표시됩니다.
- 그래프를 본 뒤 **뷰**를 다른 항목으로 바꾸면 일반 분석 화면으로 돌아갑니다.

## 11. 분석 설정

**분석 설정...** 버튼에서 다음을 한곳에서 관리합니다.

### 검사 항목 포함·제외

- 코드 메트릭 종류, 아키텍처 인사이트, 중복 코드, Git 핫스팟 등
- 불필요한 항목을 끄면 **분석 시간이 단축**됩니다.

### 품질 경고 임계값

- CC, 인지 복잡도, God file, LCOM, 패키지 I, Git 핫스팟 등
- 각 항목 옆 **?** 또는 헤더 툴팁으로 설명 확인

### 중복 코드

- **최소 줄 수**(기본 10): 이 길이 이상 동일한 연속 줄이 두 곳 이상이면 중복 그룹으로 묶습니다.

**확인**을 누르면 설정이 저장되며, 다음 **분석 실행**부터 적용됩니다.

## 12. 결과 저장·불러오기·보내기

### JSON 결과 저장·불러오기

| 작업 | 형식 | 포함 내용 |
|------|------|-----------|
| 저장 | `.json` | 호출 그래프, 메트릭, 중복, 전역 변수·접근 관계, 구조 등 |
| 불러오기 | `.json` | 저장 당시와 동일한 분석 결과를 다시 표시 (재분석 불필요) |

불러오기 시 저장 파일에 기록된 **루트 디렉터리**가 복원됩니다. 소스 파일 열기·Git 분석은 해당 경로가 유효할 때 정상 동작합니다.

### CSV (메트릭)

- 함수, 파일, 타입, 패키지, **전역 변수**, **전역 변수 접근** 섹션 포함
- Excel·스프레드시트·BI 도구 연동에 적합

### 분석 보고서

HTML / Markdown / Word / PDF 형식. 주요 섹션:

1. 개요  
2. 적용 임계값  
3. 품질 요약·주요 발견  
4. 우선 조치 로드맵  
5. 함수·파일·타입·패키지 메트릭 (상위·경고 위주)  
6. 중복 코드  
7. **전역 변수 및 접근 함수**  
8. 아키텍처 인사이트  
9. 지표 용어집(부록)

각 항목에 **권장 조치** 문구가 포함될 수 있습니다. 대형 프로젝트는 행 수가 제한됩니다.

### PNG 이미지

현재 표시 중인 **호출 그래프·구조 다이어그램·ERD** 등을 캡처합니다. 표 뷰(메트릭, 중복, 전역 변수)는 내보내기 대상이 아닙니다.

## 14. 자주 묻는 질문

**Q. 분석이 오래 걸립니다.**  
A. **분석 설정**에서 불필요한 검사를 끄거나, 제외 디렉터리를 늘리거나, 분석 언어 수를 줄여 보세요.

**Q. 호출 그래프에 함수가 없습니다.**  
A. 해당 언어가 선택되었는지, 파일이 제외 폴더에 들어가지 않았는지 확인하세요. 동적 호출·리플렉션은 정적 분석에서 누락될 수 있습니다.

**Q. Git 핫스팟이 0입니다.**  
A. 루트가 Git 저장소가 아니거나 `git`을 실행할 수 없을 때 발생합니다.

**Q. 경고 색이 안 바뀝니다.**  
A. **분석 설정**에서 임계값을 변경한 뒤 **분석을 다시 실행**했는지 확인하세요.

**Q. 전역 변수 접근 함수가 비어 있습니다.**  
A. 함수 본문에서 해당 변수를 참조하지 않거나, 분석 범위·언어 밖일 수 있습니다. C#/VB는 Roslyn, 그 외는 Tree-sitter/패턴 기반이라 정확도가 다릅니다.

**Q. 보고서와 화면 숫자가 조금 다릅니다.**  
A. 보고서는 상위·경고 항목 위주로 **행 수를 제한**합니다. 전체 데이터는 CSV·JSON 저장을 사용하세요.
