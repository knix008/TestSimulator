# MyWorkspace 사용자 가이드

MyWorkspace는 Notion과 유사하게 **Workspace**와 **Page**를 트리로 관리하고, WYSIWYG 방식으로 Markdown 문서를 작성할 수 있는 Windows 프로그램입니다. 이 문서는 일상적인 사용 방법을 설명합니다.

## 1. 시작하기

### 프로그램 실행

- **MSI 설치 후**: 시작 메뉴 또는 바탕 화면의 **MyWorkspace** 실행
- **개발 빌드**: `dotnet run --project src/MyWorkspace.Win/MyWorkspace.Win.csproj`

### 최초 실행 흐름

1. **로그인 화면**이 표시됩니다.
2. DB에 사용자가 없으면 기본 관리자 계정(`admin` / `admin`)이 자동 등록됩니다.
3. 기본 관리자로 로그인합니다.
   - ID: `admin`
   - 비밀번호: `admin`
4. DB 연결에 실패하면 **제목 표시줄 `|||` (프로그램 설정) → DB 연결 설정...** 에서 MariaDB·MySQL·PostgreSQL·SQL Server 또는 SQLite를 설정합니다. (관리자만 가능)
5. 로그인 후 **프로필 → 비밀번호 변경** 또는 **관리 → 사용자 관리**에서 관리자·일반 사용자 계정과 비밀번호를 변경할 수 있습니다.

> DB **접속 계정**(MariaDB `root` 등)과 앱 **로그인 계정**(`admin` 등)은 별개입니다. 앱 사용자는 DB `users` 테이블에서 관리됩니다.

> 기본 관리자(`admin` / `admin`)는 **최초 설치·DB 최초 연결 시**에만 자동 생성됩니다. 이후에는 관리자가 **사용자 관리**에서 계정을 추가·수정·삭제합니다.

> 이메일 서버는 설정하지 않아도 앱을 사용할 수 있습니다.

## 2. 화면 구성

```
┌──┬─────────────────────────────────────────────────────────────────────────┐
│≡ │  제목 표시줄  [Page 검색…]  [|||]                    [세션]             │
├──┼──────────────┬──────────────────────────────────────────────────────────┤
│  │  Workspace   │  [제목]  ________________________________                 │
│파│  (패널 제목) │  [툴바: 저장 | MD저장 | 내보내기 | H1~H6 | 서식 | …]     │
│일│              │  ┌──────────┬──────────────────────┬───────────────────┐ │
│  │  · 즐겨찾기  │  │ 문서 구조│  Markdown 편집       │ 댓글 (선택)       │ │
│W │  · Workspace │  │(Outline) │  WebView2 WYSIWYG    │                   │ │
│  │    ├ Page    │  └──────────┴──────────────────────┴───────────────────┘ │
│보│    └ 하위 WS │                                                           │
│기│              │                                                           │
│댓│              │                                                           │
│글│              │                                                           │
│관│              │                                                           │
│리│              │                                                           │
│  │  [프로필]    │                                                           │
│  │  [설정]      │                                                           │
│  │  [로그아웃]  │                                                           │
├──┴──────────────┴──────────────────────────────────────────────────────────┤
│  상태 표시줄 (역할, Page 이름, 저장 상태)                                  │
└────────────────────────────────────────────────────────────────────────────┘
```

| 영역 | 설명 |
|------|------|
| **좌측 내비게이션 레일** | 상단: **파일**, **Workspace**, **보기**(문서 구조), **댓글**, **관리** 메뉴. 하단: **프로필**, **설정**, **로그아웃** |
| **제목 표시줄 Page 검색** | Page 제목·본문 검색 (로그인·DB 연결 시). **`|||` → Page 검색창 표시** 로 숨기거나 표시 |
| **제목 표시줄 `|||`** | 관리자 전용 **DB 연결 설정**, **이메일 서버 설정**, **Page 검색창 표시** |
| **Workspace 패널** | Workspace·Page 계층, 즐겨찾기, 드래그 앤 드롭. 패널 제목·테두리로 구분 |
| **제목 행** | Page 제목 입력 (`제목` 레이블 + 텍스트 상자) |
| **Markdown 툴바** | 저장, Markdown 저장, 내보내기, 제목(H1~H6), 서식, Undo/Redo, **문서 구조**, **댓글** 토글 등 |
| **문서 구조** | H1~H6 제목 Outline, 클릭 시 해당 위치로 이동 (**보기** 메뉴·툴바 **문서 구조** 버튼) |
| **댓글 패널** | Page별 댓글 목록·작성 (편집 영역 오른쪽). **댓글** 메뉴·툴바·패널 **×** 로 접기 |
| **편집 영역** | WebView2 기반 WYSIWYG 편집기 (입력 내용은 Markdown으로 저장) |

좌측 Workspace 패널·문서 구조·편집·댓글 패널의 **하단이 같은 위치**에 맞춰져 있으며, 각 패널에는 **굵은 패널 제목**이 표시됩니다. **문서 구조**와 **댓글**은 각각 별도 버튼으로 접거나 펼칩니다.

### Page 검색

1. 제목 표시줄 **Page 검색…** 상자에 키워드를 입력합니다.
2. 검색 결과 목록에서 Page를 선택하면 해당 Page가 열립니다.
3. 검색창을 숨기려면 **`|||` → Page 검색창 표시** 체크를 해제합니다. 설정은 `appsettings.local.json`에 저장됩니다.

### 파일 메뉴 (내비게이션 **파일**)

| 메뉴 | 설명 |
|------|------|
| **Page 저장** | 현재 Page 수동 저장 (Ctrl+S) |
| **Markdown 파일로 저장...** | 현재 Page를 `.md` 파일로 저장 |
| **버전 이력...** | 선택한 Page의 이전 버전 보기·복원 |
| **트리 새로 고침** | Workspace 트리 다시 로드 (F5) |
| **새 프로젝트...** | 새 Workspace를 만들고 `.wsp` 프로젝트 파일로 저장 |
| **프로젝트 저장...** | 선택 Workspace 전체를 `.wsp` 파일로 저장 |
| **프로젝트 열기...** | `.wsp` 프로젝트 파일 가져오기 |
| **최근 프로젝트** | 최근에 연 `.wsp` 파일 목록 |
| **로그인...** | 로그아웃 상태에서만 표시 |
| **프로그램 정보...** | 버전, 저작권 정보 |
| **종료** | 프로그램 종료 |

### 편집 메뉴

편집기 **우클릭** 컨텍스트 메뉴 또는 단축키로 서식·삽입 기능을 사용합니다.

| 동작 | 단축키 |
|------|--------|
| **실행 취소** | Ctrl+Z |
| **다시 실행** | Ctrl+Y |

## 3. 환경 설정

설정은 **역할과 종류**에 따라 위치가 나뉩니다.

| 위치 | 메뉴 | 설명 |
|------|------|------|
| **설정** (하단 내비) | **환경 설정...** | 테마, 색상, 글꼴 크기, 언어 변경 |
| **프로필** (하단 내비) | **프로필 수정** | 사용자 ID(이름) 변경 |
| **프로필** | **비밀번호 변경** | 현재 비밀번호 확인 후 변경 |
| **프로필** | **알림 설정** | 이메일 주소, Page·Workspace 알림 |
| **`|||`** (제목 표시줄) | **Page 검색창 표시** | 타이틀바 Page 검색 상자 표시/숨김 (로그인 시) |
| **`|||`** (제목 표시줄) | **DB 연결 설정...** | DB 종류·서버·연결 테스트 (관리자) |
| **`|||`** | **이메일 서버 설정** | SMTP 알림 서버 (관리자, 선택) |

### 테마·색상·글꼴·언어

**설정 → 환경 설정...** 대화상자에서 다음을 변경합니다.

| 항목 | 설명 |
|------|------|
| **테마** | **밝게** / **어둡게** — 메뉴, 트리, 편집기, 대화상자에 일괄 적용 |
| **색상 테마** | 20종 파스텔 강조색 스와치 중 선택. **사용자 선택색** 버튼으로 임의 색 지정 가능 |
| **글꼴 크기** | 매우 작게 ~ 매우 크게 (5단계). UI·편집 본문 글꼴에 반영 |
| **언어** | 한국어 / English |

- 설정은 `%LocalAppData%\MyWorkspaceWinV10\appsettings.local.json`에 저장됩니다.
- 테마·색상·글꼴 변경은 **미리보기**로 즉시 반영됩니다. **확인**을 누르면 저장됩니다.
- 어두운 테마에서는 Markdown 툴바 아이콘이 자동으로 밝게 보이도록 조정됩니다.

## 4. 데이터베이스 설정

### 지원 DB

| DB 종류 | 설명 |
|---------|------|
| MariaDB | 권장 (기본값) |
| MySQL | MariaDB와 동일 드라이버 |
| PostgreSQL | |
| Microsoft SQL Server | |
| SQLite 3 | 단일 파일 DB (로컬·테스트용) |

### 연결 설정 열기

- **관리자 로그인 후**: 제목 표시줄 **`|||`** → **DB 연결 설정...**

> 일반 사용자는 DB 연결 설정 메뉴를 볼 수 없습니다.

### 연결 테스트

- **연결 테스트** 버튼: 서버 접속 및 DB 존재 여부 확인
- DB가 없으면 **자동 생성** 후 "연결 성공 (DB 생성됨)" 메시지 표시
- **저장** 시에도 연결 테스트가 수행됩니다

### 연결 끊기

- **연결 끊기** 버튼: 현재 DB 연결을 해제하고 로그아웃합니다.
- 연결 정보(서버·DB 이름 등)는 `appsettings.local.json`에 남아 있어, 나중에 **저장**만으로 다시 연결할 수 있습니다.
- 연결이 끊긴 상태에서는 로그인할 수 없습니다. 관리자가 **DB 연결 설정**에서 **연결 테스트** 후 **저장**하면 다시 사용할 수 있습니다.

### 설정 저장 위치

연결 정보(비밀번호 포함)는 다음 파일에 저장됩니다.

```
%LocalAppData%\MyWorkspaceWinV10\appsettings.local.json
```

> DB **접속 계정**(root 등)과 앱 **로그인 계정**(admin 등)은 별개입니다. 앱 사용자는 DB `users` 테이블에서 관리됩니다.

## 6. Workspace와 Page

### 트리 구조

하나의 Workspace 아래에는 **Page**와 **하위 Workspace**가 **같은 레벨(형제)** 로 함께 표시될 수 있습니다.

```
Workspace A
├── Page 1
├── Page 2
├── 하위 Workspace B
│   └── Page 3
└── 하위 Workspace C
```

- Page 아래에는 Page나 Workspace를 만들 수 **없습니다** (Page는 leaf 노드).
- Page가 이미 있는 Workspace에도 **하위 Workspace**를 추가할 수 있습니다.

### Workspace

- **루트 Workspace**: **Workspace → 새 Workspace**
- **하위 Workspace**: Workspace 선택 후 **Workspace → 하위 Workspace 추가** 또는 트리 우클릭
- **이름 변경·삭제**: Workspace 선택 후 메뉴 또는 우클릭
- **이동**: Workspace를 다른 Workspace 위로 **드래그 앤 드롭** (하위로 이동, 자기 자신·하위 Workspace로는 불가)

**삭제 조건**: 하위 Workspace와 Page가 **모두 없어야** 합니다. Page가 남아 있으면 먼저 Page를 삭제하세요.

### Page

- Workspace 선택 후 **Workspace → 새 Page (양식)...** 또는 우클릭 **새 Page (양식)...**
- **빠른 작성**: Workspace를 선택한 뒤 **제목** 또는 **본문**을 입력하면 **즉시** Page가 생성됩니다. 제목을 비워 두면 **`제목없음`** 으로 저장됩니다.
- **이동**: Page를 대상 Workspace로 드래그 앤 드롭

### 트리 우클릭 메뉴

| 항목 | 대상 |
|------|------|
| 하위 Workspace 추가 | Workspace |
| 새 Page (양식)... | Workspace |
| 이름 변경 | Workspace, Page |
| 삭제 | Workspace, Page |
| **Page 내보내기...** | Page |
| **Workspace 내보내기...** | Workspace |
| 즐겨찾기 추가/제거 | 등록된 Workspace |
| 멤버 관리 | Workspace |

## 7. Page 편집

### 편집기

- **제목**과 **WYSIWYG Markdown 본문**을 편집합니다. 편집 내용은 내부적으로 Markdown으로 저장됩니다.
- **자동 저장**: 입력 후 약 2초 뒤 **DB에** 자동 저장 (상태 표시줄: "수정됨" → "저장됨"). `.wsp` 프로젝트 파일에는 자동 저장되지 않습니다.
- **수동 저장**: **파일 → Page 저장** (Ctrl+S) — 현재 Page를 **DB**에 저장합니다. **프로젝트 열기** 또는 **프로젝트 저장**으로 연 `.wsp` 파일이 있고 DB에 연결되어 있으면, 같은 파일에도 함께 저장합니다. DB 연결이 없을 때는 DB(또는 로컬 SQLite) 저장만 수행합니다.

### Workspace에서 바로 편집하기

1. 좌측 트리에서 **Workspace**를 선택합니다 (Page가 아님).
2. 제목 상자는 비워 두고 편집기가 준비됩니다.
3. **제목**을 입력하거나 **본문**을 입력하면 Page가 **자동 생성**되고, 트리에서 해당 Page가 선택됩니다.
4. 제목을 입력하지 않으면 **`제목없음`** 으로 Workspace에 추가됩니다.

### Markdown 툴바

| 버튼 | 기능 |
|------|------|
| 저장 | Page 저장 (Ctrl+S) |
| Markdown 파일 | Markdown 파일로 저장 |
| 내보내기 | **현재 편집 중인 Page** 내보내기 (MD / Word / PDF) |
| Undo, Redo | 실행 취소 / 다시 실행 |
| H1 ~ H6 | 제목 1~6 |
| B, I, S | 굵게, 기울임, 취소선 |
| 코드, 블록 | 인라인·블록 코드 |
| 링크, 이미지, 첨부 | 링크·이미지·파일 삽입 |
| -, 1., > | 글머리·번호 목록, 인용 |
| ---, 표 | 구분선, 표 템플릿 |
| 문서 구조 | 문서 구조 패널 접기·펼치기 |
| 댓글 | 댓글 패널 접기·펼치기 |
| 정보 | 프로그램 정보 |

툴바 버튼 위에 마우스를 올리면 기능 설명이 표시됩니다.

### 이미지·첨부

- **이미지**·**첨부** 버튼 또는 편집기에 **파일·이미지를 드래그 앤 드롭**하여 삽입할 수 있습니다.
- 표 안에도 이미지를 넣고 **드래그로 위치를 옮길** 수 있습니다.
- 같은 파일을 여러 번 넣으면 `file_2.jpg`처럼 **고유한 파일명**으로 저장됩니다.
- Page에 포함된 이미지·첨부는 DB `page_assets`와 `%LocalAppData%\MyWorkspaceWinV10\PageAssets\` 캐시에 보관됩니다.
- 이미지 **우클릭** 메뉴에서도 댓글 작성(인용)을 시작할 수 있습니다.

### 문서 구조(Outline)

- 본문의 H1~H6 제목이 트리로 표시됩니다.
- 항목을 클릭하면 편집기에서 해당 제목 위치로 이동합니다.
- 편집 중 커서가 있는 제목과 Outline이 연동됩니다.

## 8. Page 댓글

Page마다 **댓글 스레드**를 남길 수 있습니다. 협업 시 Page 본문과 분리된 논의·메모에 사용합니다.

### 패널 열기·닫기

| 방법 | 설명 |

- 본인이 작성한 댓글은 **삭제**할 수 있습니다. Page **Editor** 이상 권한이 있으면 다른 사용자 댓글도 삭제할 수 있습니다.
- Page를 바꾸면 해당 Page의 댓글 목록이 자동으로 로드됩니다.

## 9. 내보내기와 저장

### Markdown 파일로 저장

**파일 → Markdown 파일로 저장...** 또는 툴바 **Markdown 파일** 버튼으로 **현재 편집 중인 Page**를 `.md` 파일로 저장합니다.

### Page 내보내기

Page를 Markdown, Word, PDF로 내보냅니다.

| 열기 방법 | 설명 |
|-----------|------|
| **Workspace 트리 우클릭 → Page 내보내기...** | 트리에서 선택한 Page를 내보냅니다 (편집기를 열지 않아도 됨) |
| **툴바 내보내기** | **현재 편집 중인 Page**만 내보냅니다 |

형식 선택 후 저장 위치를 지정합니다. 저장되지 않은 변경은 먼저 DB에 저장됩니다.

| 형식 | 확장자 | 첨부·이미지 |
|------|--------|-------------|
| Markdown | `.md` | `{파일명}_assets/` 폴더에 이미지·첨부 파일 복사 |
| Word | `.docx` | 이미지·첨부 파일을 **하나의 문서**에 포함 |
| PDF | `.pdf` | 이미지는 본문에 표시. 기타 파일은 `{파일명}_assets/`에 두고 **파일명 링크**로 표시 |

### Workspace 내보내기

**Workspace 트리에서 Workspace를 우클릭 → Workspace 내보내기...** 를 선택합니다.

1. 내보낼 형식(Markdown / Word / PDF)을 선택합니다.
2. 저장할 **폴더**를 지정합니다.
3. 선택한 Workspace 이름의 하위 폴더가 생성되고, 포함된 **모든 Page**가 하위 Workspace 구조를 유지한 채 내보내집니다.

마지막으로 사용한 내보내기 폴더는 기억됩니다.

### 프로젝트 저장 (.wsp)

선택한 **Workspace 전체**(하위 Workspace, Page, 본문에 포함된 이미지·첨부 파일)를 하나의 **`.wsp` 프로젝트 파일**로 로컬 디스크에 저장합니다. MariaDB 같은 원격 DB 없이도 파일만으로 백업·공유·이동할 수 있습니다.

> **자동 저장은 DB에만 적용**됩니다. `.wsp` 프로젝트 파일은 **파일 → 프로젝트 저장...** 으로 최초 저장·경로 지정 후, **Ctrl+S**로 DB와 함께 갱신할 수 있습니다.

1. 좌측 트리에서 저장할 **Workspace**(또는 그 아래 Page)를 선택합니다.
2. **파일 → 프로젝트 저장...** 을 실행합니다.
3. 저장 위치와 파일 이름(`이름.wsp`)을 지정합니다.

마지막으로 사용한 프로젝트 폴더는 `appsettings.local.json`에 기억되며, 다음 **프로젝트 저장**·**프로젝트 열기** 대화상자에서 자동으로 사용됩니다.

`.wsp` 파일은 ZIP 형식이며 `workspace.json`과 `assets/` 폴더로 구성됩니다.

### 프로젝트 열기

1. **파일 → 프로젝트 열기...** 를 실행하거나, 탐색기에서 `.wsp` 파일을 **더블 클릭**합니다. (MSI 설치 시 `.wsp` 확장자와 아이콘이 등록됩니다.)
2. **파일 → 최근 프로젝트** 에서 최근에 연 `.wsp` 파일을 바로 선택할 수 있습니다.
3. 프로젝트 내용이 **새 Workspace 트리**로 DB에 가져와집니다.

**최근 프로젝트** 목록은 `appsettings.local.json`에 저장됩니다(최대 12개).

- 항목 **클릭**: 해당 프로젝트 열기
- 항목 **우클릭 → 목록에서 제거**: 최근 목록에서만 삭제 (파일 자체는 삭제되지 않음)
- **최근 목록 모두 지우기**: 목록 전체 삭제

파일이 이동·삭제되어 없으면 회색으로 표시되며, 열기 시 목록에서 제거할지 묻습니다.

마지막으로 연 프로젝트 파일의 폴더도 기억되어, 이후 프로젝트 저장·열기 시 같은 위치에서 시작합니다.

> SQLite 등 로컬 DB를 쓰는 경우에도 `.wsp`는 **별도의 portable 백업**으로 활용할 수 있습니다. 원격 DB와 무관하게 파일 하나로 Workspace 묶음을 보관할 수 있습니다.

## 14. 알림 설정 (선택)

이메일 알림은 **완전히 선택 사항**입니다. SMTP 서버 없이도 모든 기능을 사용할 수 있습니다.

### 사용자 — 알림 수신 설정

**프로필 → 알림 설정**

| 항목 | 설명 |
|------|------|
| **이메일** | 알림 수신 주소 |
| **Page 생성·수정·삭제 알림** | 해당 Workspace의 Page 변경 |
| **Workspace 변경·멤버 변경 알림** | 이름 변경, 멤버 추가/제거 |

알림을 받으려면 **이메일 주소 등록 + 해당 옵션 체크 + 관리자 SMTP 설정**이 모두 필요합니다.

### 관리자 — 이메일 서버 설정

제목 표시줄 **`|||`** → **이메일 서버 설정**

| 항목 | 설명 |
|------|------|
| **이메일 알림 사용** | 체크 해제 시 알림 비활성 (앱 운영에는 영향 없음) |
| **SMTP 서버 / 포트** | 예: `smtp.example.com`, `587` |
| **SSL/TLS** | 대부분의 SMTP에서 사용 |
| **발신 주소** | 수신자에게 표시되는 From |

설정은 `appsettings.local.json`의 `Email` 섹션에 저장됩니다.

### 알림이 발송되는 경우 (예)

- Page 생성·수정·삭제
- Workspace 이름 변경
- Workspace 멤버 추가·제거

변경을 수행한 본인에게는 알림이 가지 않습니다. 이메일 발송 실패 시에도 Page 저장 등 작업은 정상 완료됩니다.

## 17. 자주 묻는 질문

### Q. 문서 구조와 댓글 패널이 같이 열리나요?

**아니요.** **문서 구조**와 **댓글**은 각각 별도 버튼(보기·댓글 메뉴, 툴바)으로 접거나 펼칩니다. 둘 다 동시에 펼칠 수 있습니다.

### Q. Page 검색은 어디를 검색하나요?

제목 표시줄 **Page 검색…** 은 현재 접근 가능한 Workspace 범위에서 **Page 제목과 본문**을 검색합니다. 로그인하고 DB에 연결된 상태에서 사용할 수 있습니다.

### Q. 저장 후 다시 열면 이미지가 깨져 보여요.

예전 버전에서 `file.jpg (2)` 형식으로 저장된 링크가 있으면 자동으로 복구합니다. 문제가 계속되면 Page를 한 번 저장(Ctrl+S)한 뒤 다시 열어 보세요. `%LocalAppData%\MyWorkspaceWinV10\PageAssets\` 에 해당 파일이 있는지도 확인하세요.

### Q. DB 없이 실행할 수 있나요?

앱 **실행·편집**에는 DB 연결이 필요합니다 (**기본값 MariaDB**, SQLite 등으로 변경 가능). 다만 **`.wsp` 프로젝트 파일**로 Workspace 전체를 로컬에 저장해 두면, 원격 DB 서버 없이도 파일만으로 백업·이동·다른 PC에서 **프로젝트 열기**가 가능합니다.

### Q. Page가 있는 Workspace에 하위 Workspace를 추가할 수 있나요?

**예.** Page와 하위 Workspace는 같은 Workspace 아래 형제로 공존할 수 있습니다. Page **아래**에만 하위 Workspace를 만들 수 없습니다.

### Q. Workspace를 선택했는데 Page가 없어도 바로 글을 쓸 수 있나요?

**예.** Workspace를 선택한 뒤 **제목** 또는 **본문**을 입력하면 Page가 **즉시** 생성됩니다. 제목을 입력하지 않으면 **`제목없음`** 으로 추가됩니다. 템플릿을 쓰려면 **새 Page (양식)...** 메뉴를 사용하세요.

### Q. Page나 Workspace를 어디서 내보내나요?

**Workspace 패널**에서 Page 또는 Workspace를 **우클릭**하면 **Page 내보내기...** 또는 **Workspace 내보내기...** 메뉴가 표시됩니다. 편집 중인 Page는 **툴바 내보내기** 버튼으로도 내보낼 수 있습니다.

### Q. Markdown 내보내기 시 이미지는 어디에 저장되나요?

`.md` 파일과 같은 폴더에 **`{파일명}_assets`** 폴더가 생성되고, Page에 포함된 이미지·첨부 파일이 그 안에 복사됩니다.

### Q. Word와 PDF 내보내기의 차이는?

**Word**는 이미지와 첨부 파일을 **하나의 `.docx` 파일**에 포함합니다. **PDF**는 이미지를 본문에 넣고, PDF로 직접 넣기 어려운 파일은 **`_assets` 폴더**에 두고 본문에 **파일명 링크**로 표시합니다.

### Q. 미리보기 창이 따로 있나요?

아니요. 편집 영역 자체가 WYSIWYG 방식으로 Markdown을 렌더링합니다. 별도의 미리보기 분할 창은 없습니다.

### Q. 로그아웃할 때 확인 창이 뜨나요?

**예.** 하단 **로그아웃** 버튼을 누르면 확인 대화상자가 표시됩니다.

### Q. 기본 admin 비밀번호를 잊었어요.

DB에 직접 접속하여 `users` 테이블의 `password_hash`를 갱신하거나, DB를 초기화 후 다시 시드해야 합니다. 운영 환경에서는 설치 직후 비밀번호 변경을 권장합니다.

### Q. 이메일 알림이 오지 않아요.

다음을 확인하세요.

1. 관리자가 **이메일 알림 사용**을 켰는지
2. SMTP 서버·발신 주소가 올바른지
3. 본인 **프로필 → 알림 설정**에 이메일과 알림 종류가 켜져 있는지
4. 해당 Workspace의 **멤버 또는 Owner**인지

### Q. 즐겨찾기에 Workspace가 안 보여요.

본인이 **Owner 또는 멤버**로 등록된 Workspace만 즐겨찾기할 수 있습니다. 하위 Workspace만 접근 가능한 경우, 상위 Workspace에 직접 등록되어 있지 않으면 즐겨찾기 대상이 아닐 수 있습니다.

### Q. Page가 저장되지 않아요.

Page가 선택되어 있는지, Workspace에 **Editor 이상** 권한이 있는지 확인하세요. 상태 표시줄의 "저장 실패" 메시지를 참고하세요.

### Q. 다른 PC에서도 같은 데이터를 보려면?

동일한 DB 서버(MariaDB 등)를 가리키도록 **DB 연결 설정**을 각 PC에서 동일하게 구성하거나, **프로젝트로 저장(.wsp)** 한 파일을 다른 PC에서 **프로젝트 열기**하세요. `appsettings.local.json`은 PC마다 별도입니다.
