# ICOMaker 사용자 안내서 (User's Guide)

ICOMaker로 아이콘을 디자인하고 `.ico` 파일로 내보내는 방법을 안내합니다.

---

## 1. 실행

- **데스크톱 앱**: `npm start`
- **웹 브라우저**: `npm run web` 후 `http://localhost:5173` 접속

창에는 타이틀바가 없으며, **최소화 / 최대화 / 닫기** 버튼은 **툴바 오른쪽 끝**에 있습니다.

---

## 2. 화면 구성

```
┌───────────────────────────────────────────────────────────┐
│ 툴바: 가져오기 · 확대/축소/맞춤 · 내보내기 · 언어 · 테마 · 정보 · ⌿ ▢ ✕ │
├────────────┬──────────────────────────────┬───────────────┤
│ 그리기 도구 │  [ICO · 512×512 · 개체 · 크기 …] │  속성 / 효과   │
│  (좌측)     │                              │               │
│  + 개체목록  │        디자인 캔버스           │  ICO 내보내기  │
├────────────┴──────────────────────────────┴───────────────┤
│ 상태 바: ● 준비됨          도구 · 선택 · 확대율                │
└───────────────────────────────────────────────────────────┘
```

- **좌측** — 그리기 도구 + 개체 목록(레이어)
- **중앙** — 아이콘 디자인 캔버스 (상단에 현재 ICO 정보 표시)
- **우측** — 선택한 개체의 속성·효과 + ICO 내보내기 설정
- **하단** — 프로그램 상태 바

---

## 3. 도형 그리기

1. 좌측 **그리기 도구**에서 도형을 선택합니다.
   - **기본**: 선택 · 사각형 · 원/타원 · 선 · 자유 곡선 · 텍스트
   - **도형**: 삼각형 · 직각삼각형 · 마름모 · 사다리꼴 · 평행사변형 · 오각형 · 육각형 ·
     팔각형 · 별 · 십자 · 갈매기 · 화살표 · 하트 · 번개 · 초승달 · 구름 · 고리 · 톱니바퀴
   - **입체 도형**: 정육면체 · 원기둥 · 구 · 원뿔 · 피라미드
2. 캔버스에서 **드래그**하여 크기를 정하며 그립니다.
   - **선**: 시작점에서 끝점까지 드래그
   - **자유 곡선**: 누른 채 자유롭게 이동
   - **텍스트**: 클릭하면 텍스트 개체가 생성됩니다(내용은 우측에서 편집)
3. 그리면 자동으로 **선택 도구**로 전환됩니다.

---

## 4. 개체 편집

- **선택**: 선택 도구로 개체를 클릭
- **이동**: 선택 후 드래그
- **크기 조절**: 선택 시 나타나는 **우하단 핸들** 드래그 (선은 양 끝점)
- **회전**: 우측 속성의 **회전** 슬라이더(0~360°)
- **삭제**: `Delete` 키 또는 개체 목록/컨텍스트 메뉴의 삭제
- **복제**: `Ctrl+D` 또는 컨텍스트 메뉴 복제
- **선택 해제**: `Esc` 또는 빈 곳 클릭

### 순서(z-order) 변경
개체가 겹칠 때 앞뒤 순서를 바꿉니다.
- **개체 목록**: 각 항목의 ▲(앞으로) / ▼(뒤로) 버튼
- **컨텍스트 메뉴(우클릭)**: 맨 앞으로 · 앞으로 · 뒤로 · 맨 뒤로

> 개체 목록에서 **위쪽**에 있을수록 화면에서 **앞(위)** 에 표시됩니다.

---

## 5. 속성 & 효과 (우측 패널)

### 속성
- **채우기 색** / **선 색** — 각각 색상 선택기 아래에 **20색 파스텔 프리셋** 제공
- **선 두께**, **모서리 둥글기**(사각형), **글자 크기/내용**(텍스트)
- **불투명도**, **회전**

### 효과
- **3D 입체 효과** — 좌상단 광원 기준의 베벨 조명 (깊이·광원 X/Y 조절)
- **그림자** — 거리·번짐·농도
- **흐림**

---

## 6. 이미지 가져오기

- 툴바 **가져오기** 버튼 또는 좌측 도구의 **이미지**, 혹은 캔버스로 **드래그&드롭**
- 지원 포맷: PNG · JPG · GIF · BMP · WebP · AVIF · SVG · **TIFF · HEIC · DICOM(.dcm)**
  - TIFF/HEIC/DICOM은 자동으로 변환되어 캔버스에 배치됩니다.
- 가져온 이미지도 하나의 개체이므로 이동·크기·회전·효과를 적용할 수 있습니다.

---

## 7. ICO 내보내기 (우측 패널 하단)

1. **배경** — "투명 배경" 체크 해제 시 색 선택 + **배경 여백**(%)으로 배경 크기 조절
2. **투명도(전체)** — 아이콘 전체의 불투명도
3. **아이콘 크기** — 16 / 24 / 32 / 48 / 64 / 128 / 256 px 중 다중 선택
   (기본은 가장 작은 16px, 필요한 크기를 추가로 선택)
4. **크기별 개별 파일(.ico)로 저장** 옵션
   - **꺼짐**: 선택한 모든 크기가 **하나의 멀티해상도 `.ico`** 에 포함
   - **켜짐**: 크기마다 **개별 `.ico`** 파일 (데스크톱=폴더 선택 저장 / 웹=zip 다운로드)
5. **ICO로 내보내기** 클릭 → 저장 위치 선택

> 내보내기 버튼 아래 안내문과 캔버스 상단 정보 바에서 현재 설정이 어떻게 저장될지 확인할 수 있습니다.

## 8. 확대 / 축소

- 툴바의 **확대 / 축소 / 창에 맞춤 / 실제 크기** 버튼
- 캔버스 위에서 **마우스 휠**
- 현재 확대율은 캔버스 좌하단 배지와 하단 상태 바에 표시됩니다.

---

## 9. 테마 · 언어

- **테마**: 툴바의 테마 버튼으로 **다크 / 라이트** 전환 (설정은 저장됨)
- **언어**: 툴바의 언어 버튼으로 **한국어 / English** 전환 (설정은 저장됨)

## 10. 단축키

| 단축키 | 동작 |
|---|---|
| `Delete` / `Backspace` | 선택한 개체 삭제 |
| `Esc` | 선택 해제 |
| `Ctrl + D` | 선택한 개체 복제 |
| 마우스 휠 | 캔버스 확대/축소 |
| 우클릭 | 컨텍스트 메뉴 |

---

## 11. 문제 해결

- **오류 팝업** — 오류가 나면 상세 내용이 팝업으로 표시되며 **내용 복사** 버튼으로 복사할 수 있습니다.
- **이미 실행 중** — 프로그램은 하나만 실행됩니다. 두 번째 실행 시 알림 후 종료되고 기존 창이 앞으로 나옵니다.
- **HEIC/DICOM이 안 열림** — 압축된 일부 DICOM(비압축 외 전송 구문)은 지원되지 않을 수 있습니다.
  다른 포맷으로 변환 후 시도하세요.
