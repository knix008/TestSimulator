MyBroadcasting — 따라하기

프로그램 안의 따라하기(도움말 › 따라하기, F11)와 같은 단계입니다.

시작 화면

1. MyBroadcasting

개인 방송 스튜디오입니다. 장면을 만들고, 소스를 얹고, 소리를 맞춘 뒤 방송하거나 녹화합니다. 오른쪽 아래 카드로 한 단계씩 넘어가세요.

2. 시작하기

새 장면 모음, 가져오기(다른 방송 프로그램의 장면 파일도 됩니다), 이어서 하기, 자동 구성 마법사가 여기 있습니다.

3. 예제 장면 모음

토크쇼·게임·강의·음악·뉴스·카운트다운 예제를 눌러 바로 열어 볼 수 있습니다.

4. 움직이는 배경

시작 화면 배경 16가지를 고르거나, 그림을 쓰거나, 속도를 바꿀 수 있습니다. 카드는 끌어서 옮깁니다.

5. 시작 화면 단추

언제든 이 단추로 시작 화면과 작업 화면을 오갑니다.

방송 꾸미기

6. 장면

장면은 방송 화면 한 판입니다. 누르면 그 장면으로 전환하고, 끌어서 순서를 바꾸고, 오른쪽 단추로 추가·삭제·필터를 다룹니다.

7. 소스

장면에 올린 화면·카메라·그림·글자·소리입니다. 위에 있는 것이 앞에 그려집니다. 눈은 보이기, 자물쇠는 잠금입니다.

8. 소스 추가

+ 단추로 디스플레이·창·게임 캡처, 웹캠, 마이크, 미디어, 이미지, 슬라이드 쇼, 브라우저, 텍스트, 색, 다른 장면을 추가합니다. 파일을 끌어다 놓아도 됩니다.

9. 미리 보기

소스를 끌어 옮기고, 모서리로 크기를 바꾸고(Shift: 비율 무시, Alt: 자르기), 둥근 손잡이로 돌립니다. 화면 가장자리와 다른 소스에 맞춰 붙습니다.

10. 속성

선택한 소스의 설정입니다. 바꾸면 바로 화면에 나타납니다.

11. 필터

크로마 키, 색 보정, LUT, 마스크, 흐림, 스크롤… 영상 필터와 소음 억제, 압축기, 노이즈 게이트, 이퀄라이저 같은 오디오 필터를 차례로 겁니다.

12. 변환

위치·회전·크기·기준점·경계 상자·자르기·혼합 모드를 숫자로 정하고, 화면 맞춤·늘이기·가운데·뒤집기를 합니다.

13. 오디오 믹서

소리가 있는 소스마다 미터, 음량 막대, 음소거, 모니터링이 있습니다. 톱니 단추로 고급 오디오 속성과 필터를 엽니다.

14. 전환 효과

컷·페이드·스와이프·슬라이드·스팅어·색으로 페이드·루마 와이프 중에서 고르고 길이를 정합니다.

방송하기

15. 스튜디오 모드

왼쪽 미리 보기에서 다음 장면을 준비하고, 가운데 전환 단추나 T-바로 오른쪽 프로그램(송출)에 보냅니다.

16. 멀티뷰

미리 보기·프로그램과 장면 8개를 한눈에 봅니다. 장면을 누르면 고르고, 두 번 누르면 전환합니다.

17. 방송과 녹화

방송 시작, 녹화(일시정지), 리플레이 버퍼, 가상 카메라, 스크린샷 단추입니다. 켜져 있으면 빨갛게 바뀝니다.

18. 방송 제어

큰 단추와 방송·녹화 시간이 한곳에 모여 있습니다.

19. 방송 설정

Twitch·YouTube·치지직·SOOP·Kick·Facebook 이나 사용자 지정 서버(RTMP·RTMPS·SRT·RIST·WHIP)와 스트림 키를 넣습니다.

20. 출력 설정

인코더, 비트레이트, 녹화 형식과 폴더, 오디오 트랙, 파일 나누기, 리플레이 버퍼를 정합니다.

21. 상태 표시줄

방송·녹화 시간, 비트레이트, 드롭 프레임, FPS, CPU 와 문제 개수를 보여 줍니다.

설정과 도움말

22. 단축키

모든 동작에 키를 줄 수 있습니다: 방송·녹화, 장면, 소스 보이기, 음소거, 눌러서 말하기, 미디어 제어. 데스크톱 앱에서는 다른 프로그램이 앞에 있어도 동작합니다.

23. 테마

테마 40가지와 사용자 정의 테마를 고를 수 있습니다.

24. 보고서 인쇄

장면 구성표(그림 포함), 소스 목록, 오디오 구성, 단축키 표, 출력 설정서, 세션 기록, 기능 목록을 인쇄하거나 PDF 로 저장합니다.

25. 다 됐습니다

튜토리얼은 이 단추로 언제든 다시 볼 수 있습니다. 사용 설명서는 도움말 메뉴에 있습니다.
