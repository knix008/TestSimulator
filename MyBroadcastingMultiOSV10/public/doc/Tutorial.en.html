MyBroadcasting — Tutorial

The same steps the tutorial shows in the program (Help › Tutorial, F11).

Start page

1. MyBroadcasting

A personal broadcasting studio: build scenes, add sources, mix the sound, then go live or record. Step through with the card at the bottom right.

2. Get started

New collection, import (other broadcasting programs' scene files too), continue and the auto-configuration wizard live here.

3. Sample collections

Open a talk show, gaming, lecture, music, news or countdown sample with one click.

4. Moving backgrounds

Pick one of 16 backgrounds, use a picture or change the speed. Drag the cards to move them.

5. Start page button

This button switches between the start page and the studio at any time.

Building the show

6. Scenes

A scene is one screen of the show. Click to switch to it, drag to reorder, and use the buttons to add, remove and filter.

7. Sources

Screens, cameras, pictures, text and sound in the scene. Higher ones are drawn on top. The eye shows / hides, the lock locks.

8. Add a source

The + button adds display / window / game capture, webcam, microphone, media, image, slide show, browser, text, colour or another scene. Dropping files works too.

9. Preview

Drag sources to move them, use the corners to resize (Shift: free, Alt: crop), the round handle to rotate. They snap to the edges and to other sources.

10. Properties

The selected source's settings. Changes show at once.

11. Filters

Chain video filters (chroma key, colour correction, LUT, mask, blur, scroll…) and audio filters (noise suppression, compressor, gate, equalizer…).

12. Transform

Set position, rotation, size, alignment, bounding box, crop and blending exactly; fit, stretch, center or flip.

13. Audio mixer

Every source with sound has a meter, a fader, mute and monitoring. The gear opens advanced audio and filters.

14. Transitions

Choose cut, fade, swipe, slide, stinger, fade to colour or luma wipe, and its duration.

Going live

15. Studio mode

Prepare the next scene in the preview on the left, then send it to the program on the right with the Transition button or the T-bar.

16. Multiview

See the preview, the program and eight scenes at once. Click a scene to pick it, double-click to transition.

17. Stream and record

Start streaming, record (pause), replay buffer, virtual camera and screenshot. Active ones turn red.

18. Controls

Big buttons and the stream / recording times in one place.

19. Stream settings

Pick Twitch, YouTube, CHZZK, SOOP, Kick, Facebook or a custom server (RTMP, RTMPS, SRT, RIST, WHIP) and enter the stream key.

20. Output settings

Encoders, bitrates, recording format and folder, audio tracks, file splitting and the replay buffer.

21. Status bar

Stream and recording times, bitrate, dropped frames, FPS, CPU and the problem count.

Settings and help

22. Hotkeys

Every action can have keys: outputs, scenes, showing sources, mute, push-to-talk, media controls. In the desktop app they work while another program is in front.

23. Theme

Pick one of 40 themes or your own.

24. Printed reports

Print or save as PDF the scene rundown (with pictures), source list, audio setup, hotkey sheet, output settings, session log and feature list.

25. All set

Replay the tutorial any time with this button. The user's guide is in the Help menu.
