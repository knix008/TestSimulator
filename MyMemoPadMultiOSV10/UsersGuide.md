# MyMemoPad 사용 설명서

Windows · macOS · Linux 데스크톱 앱과 브라우저(Web)에서 노란 메모 패드를 사용합니다.

---

## 1. 설치와 실행

### 데스크톱

1. 설치 파일을 실행합니다. Node.js 나 Rust 같은 별도 프로그램은 설치할 필요가 없습니다.
   - Windows: `MyMemoPad-Setup-1.0.0.exe`
   - macOS: `MyMemoPad-1.0.0.dmg` → Applications로 드래그
   - Linux: `MyMemoPad-1.0.0.AppImage` 또는 `.deb`
2. Windows 설치 프로그램은 차례로 다음을 묻습니다.
   - **설치 언어**: 한국어 / English. 이후 화면이 모두 고른 언어로 나옵니다.
   - **재설치 방식** (이미 설치되어 있거나 메모가 남아 있을 때만): *메모와 설정을 유지하고 덮어쓰기*(권장) 또는 *완전히 삭제한 뒤 새로 설치*.
   - **설치 옵션**: 바탕화면 바로가기, 시작 메뉴 바로가기, **시스템 시작 시 자동 실행**.
3. 시작 메뉴 / Applications / 바탕화면 바로가기로 실행합니다.
4. 처음 실행하면 빈 메모 창과 **시스템 트레이**(macOS는 메뉴 막대) 아이콘이 나타납니다.

> Windows 10/11 에는 화면 표시에 쓰는 WebView2 가 이미 들어 있습니다. 없는 컴퓨터라면 설치 프로그램이 자동으로 받아 설치합니다.

### 웹

브라우저에서 앱을 연 경우(개발: `npm run web`) 목록과 편집은 동일하지만, **트레이·자동 실행·창 투명도는 없습니다.** 데이터는 그 브라우저의 저장소에 남습니다.

---

## 2. 메모 창

상단 버튼 (왼쪽 → 오른쪽):

| 버튼 | 동작 |
|------|------|
| 초록 **+** | 현재 내용을 저장한 뒤 새 빈 메모를 엽니다 |
| 빨간 휴지통 | 저장된 메모를 삭제합니다 (확인 필요) |
| 파란 톱니바퀴 | 글꼴·색·투명도·언어·자동 실행 설정 |
| 메모 묶음 | 메모 목록을 엽니다 |
| 노란 **–** | 창을 최소화합니다 |
| 빨간 **X** | 창을 닫습니다. 첫 창은 **종료가 아니라 트레이로 숨깁니다** |

- 툴바의 빈 곳을 드래그하면 창을 옮길 수 있습니다.
- 창 가장자리를 드래그하면 크기를 바꿀 수 있습니다.
- 내용이 있으면 창을 닫을 때 자동 저장됩니다.
- 서식 단축키: `Ctrl+B` 굵게, `Ctrl+I` 기울임, `Ctrl+U` 밑줄, `Ctrl+Shift+S` 취소선 (macOS는 `Ctrl` 대신 `⌘`).
- **오른쪽 클릭 메뉴**: 굵게·기울임·밑줄·취소선 버튼, 실행 취소·다시 실행, 잘라내기·복사·붙여넣기·모두 선택, 새 메모·메모 목록·설정.

---

## 3. 메모 목록

메모 묶음 버튼 또는 트레이 메뉴 **메모 목록 열기**로 엽니다. 제목 옆에 메모 개수가 표시됩니다.

- 카드를 **한 번 클릭**하면 선택, **두 번 클릭**하면 해당 메모를 엽니다.
- 카드의 휴지통으로 그 메모만 삭제합니다.
- 카드를 **오른쪽 클릭**하면 열기·삭제·새 메모·불러오기·설정 메뉴가 나옵니다.
- **불러오기**: `.txt` / `.rtf` / `.html` / `.md` 파일을 새 메모 창으로 엽니다.
- **새 메모**: 빈 메모 창을 엽니다.
- 키보드: `↑` `↓` 이동, `Enter` 열기, `Delete` 삭제, `Esc` 닫기.

---

## 4. 설정

- **적용 범위**: 선택 영역 또는 전체 문서에 글꼴·서식을 적용합니다.
- **배경색**: 파스텔 팔레트(현재 색에 파란 테두리) 또는 사용자 지정 색. 미리보기는 확인 전에 다른 창에도 반영될 수 있습니다. 취소를 누르면 되돌립니다.
- **창 투명도**: 메모 창에서만 표시됩니다. 0%가 불투명입니다.
- **언어**: 한국어 / English. 모든 창과 트레이 메뉴에 바로 반영됩니다.
- **시스템 시작 시 자동 실행**: 로그인 후 창 없이 트레이만 띄웁니다. 웹에서는 사용할 수 없습니다.
- **기본값**: 노란 메모 기본 모양으로 되돌립니다.

저장된 메모의 글꼴·색·투명도는 **그 메모에만** 저장됩니다. 아직 저장하지 않은 창에서 확인을 누르면 이후 새 메모의 기본 모양이 됩니다.

---

## 5. 시스템 트레이

- 첫 메모 창의 **X**는 프로그램을 끝내지 않습니다. 트레이에 남습니다.
- 트레이 아이콘을 클릭(또는 두 번 클릭)하면 목록이 열립니다. (macOS는 클릭하면 메뉴가 열립니다.)
- 트레이 오른쪽 클릭 메뉴 (모두 아이콘이 있습니다):
  - **메모 목록 열기**
  - **새 메모**
  - **시스템 시작 시 자동 실행: 켜짐 / 꺼짐** — 누를 때마다 바뀝니다
  - **종료** — 프로그램을 끝내는 유일한 방법입니다

로그인 자동 실행이 켜져 있으면 시작 시 창이 깜빡이지 않고 트레이만 등록됩니다.

---

## 6. 데이터 위치

데스크톱 앱은 사용자 데이터 폴더에 JSON으로 저장합니다.

- Windows: `%APPDATA%\MyMemoPad\`
- macOS: `~/Library/Application Support/MyMemoPad/`
- Linux: `~/.config/MyMemoPad/`

| 파일 | 내용 |
|------|------|
| `memos.json` | 메모 본문 (HTML) |
| `editor_settings.json` | 언어, 기본 글꼴·색 |
| `memo_settings.json` | 메모별 모양 |

이전(Electron) 판의 메모는 같은 폴더를 쓰므로 그대로 이어집니다. WinForms MemoPadV10의 RTF `memos.json`을 복사해 오면 평문으로 읽어 들입니다.

프로그램을 제거할 때 **앱 데이터 삭제**를 고르면 이 폴더도 지워집니다.

---

## 7. 문제 해결

- 창이 사라졌다면 트레이 아이콘을 확인하세요. 종료는 트레이 메뉴의 **종료**입니다.
- 예기치 않은 오류가 나면 상세 대화상자에서 **내용 복사**로 보고할 수 있습니다.
- Windows에서 설치 시 SmartScreen 경고가 나올 수 있습니다. 이 빌드는 코드 서명이 없습니다.
- macOS Gatekeeper가 확인되지 않은 개발자라고 하면, 시스템 설정에서 해당 앱 실행을 허용하세요.
