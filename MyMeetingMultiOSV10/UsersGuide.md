# 사용자 가이드 — MyMeeting

## 1. 실행

- **데스크톱(개발):** `npm install` 후 `npm start`
- **웹:** `npm run web` → 브라우저에서 `http://localhost:5179`
- **설치본:** `npm run build:win`(또는 `:mac` / `:linux`) 로 만든 설치 파일 실행

## 2. 화면 구성

```
┌ 툴바 ─ 새로 만들기 · 예시 · 열기 · 저장 · 내보내기▾ │ 비우기 · 언어(🌐) · 테마 · 설정 · 정보 ┐
│                                    │                                                     │
│  [회의 정보] [구조]  ← 사이드바     │   [미리보기] [편집]  ← 메인 영역                     │
│   제목·날짜·시간·장소·주관자·작성자  │   편집: 회의 내용 본문 직접 입력                     │
│   참석자·안건·결정·실행 항목         │   미리보기: 완성된 회의록 렌더링                     │
│                                    │                                                     │
├ 상태바 ─ 상태 메시지 · 참석자/안건 수 · 단어/글자 수 · 폰트 · 테마 ─────────────────────────┤
```

> **편집은 메인 창의 "편집" 탭에서 바로 입력**합니다(기본으로 열리는 탭). 완성된 회의록은 **"미리보기" 탭**에서 확인합니다.

## 3. 기본 사용 흐름

1. **회의 정보 입력 (회의 정보 탭)**
   - **제목** — 회의 제목. 내보내기 파일 이름·표지 제목의 기본값이 됩니다.
   - **날짜** — 직접 입력하거나, 옆의 **달력 버튼**을 눌러 달력에서 선택할 수 있습니다(선택 시 `YYYY-MM-DD` 로 채워지며, 이후 직접 수정도 가능).
   - **시작/종료 시간, 장소, 주관자, 작성자** — 자유 입력.
   - **참석자 · 안건 · 결정 사항 · 실행 항목** — **한 줄에 하나씩** 입력하면 자동으로 목록으로 정리됩니다(실행 항목은 체크리스트로 표시).
2. **회의 내용 작성 (편집 탭)**
   - 메인 창의 **편집** 탭에서 논의 내용을 **Markdown** 으로 직접 작성합니다(제목은 `## 소제목`, 목록은 `- 항목` 등).
3. **미리보기 확인 (미리보기 탭)**
   - 회의 정보 표 + 안건 + 회의 내용 + 결정 사항 + 실행 항목이 완성된 회의록으로 렌더링됩니다.
   - **각 섹션에는 번호(1, 2, 2.1 …)가 자동으로 매겨집니다.** 제목과 날짜·작성자 등 정보 항목에는 번호가 붙지 않습니다.
4. **구조 탭** 의 항목을 클릭하면 미리보기가 해당 위치로 스크롤됩니다.
5. **저장 / 열기**
   - **저장** — 작성한 회의록을 `.mtg`(JSON) 파일로 저장합니다. 나중에 **열기** 로 다시 불러와 이어서 편집할 수 있습니다.
   - 작성 중인 회의록은 자동으로 보관되어, 프로그램을 다시 열면 마지막 상태가 복원됩니다.
6. **내보내기** — 툴바의 **내보내기▾** 를 열면:
   - 상단 **파일 이름** 입력칸(기본값: 회의 제목, 수정 가능)
   - **Markdown / HTML / PDF / Word / 텍스트** 중 선택
   - 데스크톱에서는 저장 위치를 묻고, 웹에서는 다운로드(또는 PDF는 인쇄 대화상자에서 "PDF로 저장")됩니다.
   - 내보낸 문서에는 **표지 페이지**와 **목차(인덱스) 페이지**가 본문 앞에 자동으로 들어가며, **목차의 각 항목 오른쪽에 실제 페이지 번호**가 표시됩니다(PDF·Word·HTML). *(Word 페이지 번호는 근사값)*

> **예시 불러오기** — 툴바의 **예시** 버튼을 누르면 완성된 예시 회의록이 채워져 형식을 참고할 수 있습니다.

## 4. 설정 (⚙)

툴바의 톱니 버튼으로 **별도의 설정 창**을 엽니다. 이 창은 메인 창과 독립적으로 **이동**할 수 있으며(2단 레이아웃), 변경 사항은 메인 창에 즉시 반영됩니다. 하단의 **설정 초기화** 버튼으로 모든 내보내기 설정을 기본값으로 되돌릴 수 있습니다.

- **일반**
  - **언어**: 한국어 / English (툴바의 지구본 아이콘으로도 전환)
  - **테마**: Dark / Light / White / Midnight / Nord / Forest / Rose / Solarized / Contrast / Ocean / Mocha / Sky (스와치 클릭, 총 12종). 툴바의 테마 버튼으로 순환할 수도 있습니다.
- **내보내기 글꼴**
  - **글꼴**: 드롭다운에서 선택. 맨 위 **System Default**(시스템 기본) 또는 **시스템에 설치된 모든 폰트**. 선택한 글꼴은 미리보기와 내보내기에 동일하게 반영됩니다.
  - **기본 크기**: pt 단위(기본 10). 좌우 **− / +** 버튼으로 조절하거나 직접 입력.
  - **줄 간격**: 기본 1.5. 좌우 **− / +** 버튼으로 조절하거나 직접 입력.
- **표지 / 목차**
  - **표지 페이지** 자동 생성 여부, **표지 제목**(비우면 회의 제목 사용), 버전/작성자/날짜 표시
  - **목차 페이지** 생성 여부 (목차 항목 오른쪽에 페이지 번호 표시)
- **머리글 / 바닥글 / 페이지 번호**
  - **머리글 문구 / 바닥글 문구** 와 각 정렬(왼쪽/가운데/오른쪽)
  - **페이지 번호** 표시/숨김, 위치(상/하 × 좌/중/우), **표지 포함 여부**

설정은 자동 저장되어 다음 실행 시 유지됩니다.

## 5. 컨텍스트 메뉴 (우클릭)

- **편집**: 잘라내기 · 복사 · 붙여넣기 · 전체 선택 · 저장
- **미리보기**: 복사 · 전체 복사 · PDF/Word 내보내기
- **구조**: 해당 위치로 이동 · 헤딩 텍스트 복사

## 6. 오류 팝업

오류가 발생하면 **상세 내용을 담은 팝업**이 표시됩니다. 팝업의 내용은 선택할 수 있으며, **내용 복사** 버튼으로 클립보드에 복사해 다른 곳에 붙여넣을 수 있습니다.

## 8. 자주 묻는 질문

- **Q. 참석자/안건을 어떻게 여러 개 입력하나요?**
  A. 해당 칸에 **한 줄에 하나씩** 입력하면 자동으로 목록으로 정리됩니다.
- **Q. 날짜를 달력으로 고르고 싶어요.**
  A. 날짜 칸 옆의 달력 버튼을 누르면 달력이 열립니다. 직접 타이핑도 가능합니다.
- **Q. 섹션 번호를 끄고 싶어요.**
  A. 번호는 각 섹션(안건·회의 내용·결정·실행)에 자동으로 매겨지며, 제목·날짜 등 정보 항목에는 붙지 않습니다.
- **Q. 폰트 목록이 몇 개만 나와요.**
  A. 브라우저/OS가 Local Font Access API 를 지원하지 않거나 권한이 거부되면 기본 폰트 목록으로 대체됩니다. 데스크톱(Electron) 버전에서는 시스템 폰트 전체가 표시됩니다.
- **Q. 설치 시 바로가기를 안 만들 수 있나요?**
  A. Windows 설치 마법사에서 바탕화면/시작 메뉴 바로가기를 개별 선택할 수 있습니다.
