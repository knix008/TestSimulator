# 사용자 가이드 — MyMeeting

## 1. 실행

- **데스크톱(개발):** `npm install` 후 `npm start`
- **웹:** `npm run web` → 브라우저에서 `http://localhost:5179`
- **설치본:** `npm run build:win`(또는 `:mac` / `:linux`) 로 만든 설치 파일 실행

## 2. 화면 구성

```
┌ 툴바 ─ 새로 만들기·예시·열기·저장·내보내기▾ · ↶↷ · 글꼴·크기 │ 비우기·언어·테마·설정·정보 ┐
│                                    ┊                                                     │
│  [회의 정보] [구조]  ← 사이드바     ┊   [편집] [Markdown]  ← 메인 영역                     │
│   제목·날짜·시간·장소·주관자·작성자  ┊   편집: WYSIWYG(서식 툴바 + 이미지/미디어)          │
│   참석자·안건·결정·실행 항목         ┊   Markdown: 원본 소스 직접 편집                     │
│                                    ┊  (┊ = 드래그로 패널 크기 조절)                       │
├ 상태바 ─ 상태 메시지 · 참석자/안건 수 · 단어/글자 수 · 폰트 · 테마 ─────────────────────────┤
```

> **본문은 메인 창의 "편집" 탭(WYSIWYG, 기본)에서 서식이 적용된 형태로 바로 편집**합니다. 원본 마크다운을 보거나 직접 고치려면 **"Markdown" 탭**으로 전환하세요 — 두 탭은 같은 내용을 공유합니다. 사이드바와 편집 영역 사이 **구분자를 드래그**하면 패널 폭을 조절할 수 있습니다(더블클릭: 기본값).

## 3. 기본 사용 흐름

1. **회의 정보 입력 (회의 정보 탭)**
   - **제목** — 회의 제목. 내보내기 파일 이름·표지 제목의 기본값이 됩니다.
   - **날짜** — 직접 입력하거나, 옆의 **달력 버튼**을 눌러 달력에서 선택할 수 있습니다(선택 시 `YYYY-MM-DD` 로 채워지며, 이후 직접 수정도 가능).
   - **시작/종료 시간, 장소, 주관자, 작성자** — 자유 입력.
   - **참석자 · 안건 · 결정 사항 · 실행 항목** — **한 줄에 하나씩** 입력하면 자동으로 목록으로 정리됩니다(실행 항목은 체크리스트로 표시).
2. **회의 내용 작성 (편집 탭)**
   - 메인 창의 **편집** 탭에서 논의 내용을 작성합니다. 상단 **서식 툴바**로 굵게·기울임·취소선·밑줄, 제목 H1~H6, 목록/번호목록/체크리스트, 인용, 코드/코드블록, 링크, 표, 이미지, 구분선을 클릭 한 번에 적용할 수 있습니다.
   - **실행 취소 / 다시 실행**과 **글꼴·크기**는 상단 메인 툴바에 있으며, 편집·Markdown 두 탭 모두에서 동작합니다(글꼴·크기는 내보내기에도 적용).
   - **이미지·동영상·오디오**는 파일을 **드래그 앤 드롭**하거나 **붙여넣기(Ctrl+V)**, 또는 툴바/우클릭의 **이미지·미디어 삽입**으로 넣습니다. 삽입한 이미지·동영상은 **모서리 핸들을 끌어 크기 조절**할 수 있고, **표 셀 안에도** 넣을 수 있습니다. 넣은 미디어는 문서에 내장되어 저장·내보내기에 그대로 포함됩니다.
   - **Markdown 탭**으로 전환하면 원본 마크다운(제목 `## 소제목`, 목록 `- 항목` 등)을 직접 보고 편집할 수 있습니다.
3. **자동 섹션 번호 · 미리보기**
   - 내보내거나 미리볼 때 회의 정보 표 + 안건 + 회의 내용 + 결정 사항 + 실행 항목이 완성된 회의록으로 렌더링되고, **각 섹션에 번호(1, 2, 2.1 …)가 자동으로 매겨집니다.** 제목과 날짜·작성자 등 정보 항목에는 번호가 붙지 않습니다.
4. **구조 탭** 의 항목을 클릭하면 편집기의 해당 위치로 이동합니다.
5. **저장 / 열기**
   - **저장** — 작성한 회의록을 `.mtg`(JSON) 파일로 저장합니다. 나중에 **열기** 로 다시 불러와 이어서 편집할 수 있습니다.
   - 작성 중인 회의록은 자동으로 보관되어, 프로그램을 다시 열면 마지막 상태가 복원됩니다.
6. **내보내기** — 툴바의 **내보내기▾** 를 열면:
   - 상단 **파일 이름** 입력칸(기본값: 회의 제목, 수정 가능)
   - **Markdown / HTML / PDF / Word / 텍스트** 중 선택
   - 데스크톱에서는 저장 위치를 묻고, 웹에서는 다운로드(또는 PDF는 인쇄 대화상자에서 "PDF로 저장")됩니다.
   - 내보낸 문서에는 **표지 페이지**와 **목차(인덱스) 페이지**가 본문 앞에 자동으로 들어가며, **목차의 각 항목 오른쪽에 실제 페이지 번호**가 표시됩니다(PDF·Word·HTML). *(Word 페이지 번호는 근사값)*

> **예시 불러오기** — 툴바의 **예시** 버튼을 누르면 완성된 예시 회의록이 채워져 형식을 참고할 수 있습니다.

## 4. 설정 (⚙)

툴바의 톱니 버튼으로 **별도의 설정 창**을 엽니다. 이 창은 메인 창과 독립적으로 **이동**할 수 있으며(2단 레이아웃), 변경 사항은 메인 창에 즉시 반영됩니다. 하단의 **설정 초기화** 버튼으로 모든 내보내기 설정을 기본값으로 되돌릴 수 있습니다.

- **일반**
  - **언어**: 한국어 / English (툴바의 지구본 아이콘으로도 전환)
  - **테마**: Dark / Light / White / Midnight / Nord / Forest / Rose / Solarized / Contrast / Ocean / Mocha / Sky (스와치 클릭, 총 12종). 툴바의 테마 버튼으로 순환할 수도 있습니다.
- **내보내기 글꼴** *(글꼴·크기는 메인 툴바에서도 바로 조절 가능 — 설정 창과 동기화)*
  - **글꼴**: 드롭다운에서 선택. 맨 위 **System Default**(시스템 기본) 또는 **시스템에 설치된 모든 폰트**. 선택한 글꼴은 편집 화면·미리보기·내보내기에 동일하게 반영됩니다.
  - **기본 크기**: pt 단위(기본 10). 좌우 **− / +** 버튼으로 조절하거나 직접 입력.
  - **줄 간격**: 기본 1.5. 좌우 **− / +** 버튼으로 조절하거나 직접 입력.
- **표지 / 목차**
  - **표지 페이지** 자동 생성 여부, **표지 제목**(비우면 회의 제목 사용), 버전/작성자/날짜 표시
  - **목차 페이지** 생성 여부 (목차 항목 오른쪽에 페이지 번호 표시)
- **머리글 / 바닥글 / 페이지 번호**
  - **머리글 문구 / 바닥글 문구** 와 각 정렬(왼쪽/가운데/오른쪽)
  - **페이지 번호** 표시/숨김, 위치(상/하 × 좌/중/우), **표지 포함 여부**

설정은 자동 저장되어 다음 실행 시 유지됩니다.

## 5. 컨텍스트 메뉴 (우클릭)

- **편집(WYSIWYG)**: 실행 취소 · 다시 실행 · 잘라내기 · 복사 · 붙여넣기 · 전체 선택 · 이미지·미디어 삽입 · 저장 · PDF/Word 내보내기
- **Markdown 소스**: 실행 취소 · 다시 실행 · 잘라내기 · 복사 · 붙여넣기 · 전체 선택
- **구조**: 해당 위치로 이동 · 헤딩 텍스트 복사

> 붙여넣기는 외부(브라우저·Word 등)의 **서식·표·이미지**를 정리해 넣고, 편집기에서 복사하면 서식·이미지가 외부 앱으로 그대로 전달됩니다. 데스크톱(Electron)에서는 컨텍스트 메뉴가 **창에 잘리지 않는 OS 네이티브 메뉴**로 표시됩니다.

## 6. 오류 팝업

오류가 발생하면 **상세 내용을 담은 팝업**이 표시됩니다. 팝업의 내용은 선택할 수 있으며, **내용 복사** 버튼으로 클립보드에 복사해 다른 곳에 붙여넣을 수 있습니다.

## 8. 자주 묻는 질문

- **Q. 참석자/안건을 어떻게 여러 개 입력하나요?**
  A. 해당 칸에 **한 줄에 하나씩** 입력하면 자동으로 목록으로 정리됩니다.
- **Q. 날짜를 달력으로 고르고 싶어요.**
  A. 날짜 칸 옆의 달력 버튼을 누르면 달력이 열립니다. 직접 타이핑도 가능합니다.
- **Q. 섹션 번호를 끄고 싶어요.**
  A. 번호는 각 섹션(안건·회의 내용·결정·실행)에 자동으로 매겨지며, 제목·날짜 등 정보 항목에는 붙지 않습니다.
- **Q. 폰트 목록이 몇 개만 나와요.**
  A. 브라우저/OS가 Local Font Access API 를 지원하지 않거나 권한이 거부되면 기본 폰트 목록으로 대체됩니다. 데스크톱(Electron) 버전에서는 시스템 폰트 전체가 표시됩니다.
- **Q. 이미지/동영상을 어떻게 넣나요? 내보낸 파일에도 포함되나요?**
  A. 파일을 편집 영역에 **드래그 앤 드롭**하거나 **붙여넣기**, 또는 툴바/우클릭의 **이미지·미디어 삽입**으로 넣습니다. 넣은 미디어는 문서 안에 내장되어 md/html/pdf/word 내보내기에 그대로 포함됩니다(외부 파일 불필요). 단, PDF 는 영상 재생이 안 되고 Word 의 영상·오디오 재생은 버전에 따라 제한됩니다. 동영상을 많이 넣으면 파일이 매우 커질 수 있습니다.
- **Q. 밑줄·취소선도 되나요?**
  A. 됩니다. 취소선은 Markdown(`~~…~~`)으로, 밑줄은 표준 Markdown 에 없어 `<u>…</u>` HTML 로 저장되며 미리보기·내보내기에 반영됩니다.
- **Q. 최근 파일 목록에서 특정 항목만 지우고 싶어요.**
  A. 열기 드롭다운의 최근 파일 항목 오른쪽 **×** 버튼으로 개별 삭제하거나, **기록 삭제**로 전체를 지울 수 있습니다.
- **Q. 설치 시 바로가기를 안 만들 수 있나요?**
  A. Windows 설치 마법사에서 바탕화면/시작 메뉴 바로가기를 개별 선택할 수 있습니다.
