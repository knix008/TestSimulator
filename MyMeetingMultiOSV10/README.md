# MyMeeting

회의 정보를 **구조적으로 입력**하고(제목·날짜·시간·장소·주관자·작성자·참석자·안건·결정 사항·실행 항목), 회의 내용을 **Markdown 으로 작성**하여, 완성된 회의록을 **Markdown / HTML / PDF / Word / 텍스트** 로 내보내는 크로스플랫폼 회의록 작성 도구입니다.

동일한 코드베이스로 **Web / Windows / macOS / Linux** 에서 동작합니다. (React + Vite + Electron)

![icon](assets/icon.svg)

## 주요 기능

### 회의록 작성
- **구조적 입력** — 좌측 "회의 정보" 패널에서 제목, 날짜, 시작/종료 시간, 장소, 주관자, 작성자, 참석자, 안건, 결정 사항, 실행 항목을 입력합니다. 참석자·안건·결정·실행 항목은 **한 줄에 하나씩** 입력하면 자동으로 목록으로 정리됩니다.
- **날짜·시간 입력 + 검증** — 날짜는 **직접 입력**하거나 **달력**에서 선택할 수 있고, 시간은 **직접 입력**하거나 **드롭다운(15분 단위)** 에서 선택할 수 있습니다. 시간은 `HH:MM` 형식과 시작≤종료 순서를 **검증**하여 잘못 입력하면 표시해 줍니다.
- **WYSIWYG 편집 + 서식 툴바** — 메인 창의 편집기는 **Markdown 을 해석해 서식이 적용된 형태로 표시**하며, 그 화면에서 **직접 편집**합니다(별도 미리보기 불필요). 내부적으로는 Markdown 으로 저장되어 모든 내보내기가 그대로 동작합니다. **서식 툴바**(굵게·기울임·**취소선**·**밑줄**·**제목 H1~H6**·목록·번호목록·체크리스트·인용·코드·코드블록·링크·표·이미지·구분선)로 클릭 한 번에 서식을 적용할 수 있습니다. *(취소선은 `~~…~~`, 밑줄은 표준 Markdown 에 없어 `<u>…</u>` HTML 로 저장됩니다.)*
- **실행 취소 / 다시 실행** — 상단 툴바의 되돌리기/다시 실행 버튼으로 편집·Markdown 두 탭 모두에서 되돌릴 수 있습니다(우클릭 메뉴에도 포함).
- **편집 / Markdown 두 탭** — 메인 영역은 **"편집"(WYSIWYG)** 과 **"Markdown"(원본 소스)** 탭으로 나뉩니다. Markdown 탭에서 원본 마크다운을 직접 보고 편집할 수 있으며, 두 탭은 같은 본문을 공유해 **양방향으로 반영**됩니다.
- **미디어 삽입(이미지·동영상·오디오)** — **드래그 앤 드롭**, **붙여넣기**, 또는 툴바/우클릭 메뉴의 **이미지·미디어 삽입**(파일 열기)으로 넣을 수 있습니다. 이미지·동영상은 **핸들을 끌어 크기 조절**이 되고, **표 셀 안에도** 넣을 수 있습니다. 미디어는 **base64 로 문서에 내장**되어 모든 내보내기(md/html/pdf/word)에 그대로 포함됩니다. *(큰 이미지는 자동 축소, 동영상/오디오는 원본 내장)*
- **문서 글꼴·크기 (툴바)** — 상단 툴바에서 **시스템 글꼴**과 **크기(pt)** 를 바로 선택합니다. 편집기 표시는 물론 **미리보기·내보내기에 동일하게 적용**되며 설정 창과 양방향 동기화됩니다.
- **서식 있는 복사/붙여넣기** — 외부(브라우저·Word 등)에서 **서식·표·이미지**를 붙여넣으면 정리되어 삽입되고(원격 이미지는 내장 시도), 편집기에서 복사하면 서식·이미지가 외부 앱으로 그대로 전달됩니다.
- **양식(템플릿) 선택** — 툴바의 **예시** 드롭다운에서 일반 회의록·데일리 스크럼·프로젝트 회의·회고·이사회·1:1·고객 미팅 등 **다양한 회의록 양식**을 골라 불러올 수 있습니다. 양식은 `templates/` 폴더의 JSON 으로 관리되어 자유롭게 추가·수정할 수 있습니다.
- **자동 섹션 번호** — 내보낸 문서에서 각 섹션에 자동으로 번호(1, 2, 2.1 …)가 매겨집니다(제목·날짜·작성자 등 정보 항목 제외).
- **문서 구조 TreeView** — "구조" 탭에서 회의 내용의 헤딩을 **부모-자식 연결선이 있는 트리**로 표시하고 각 항목의 **제목 수준(H1·H2·H3…)** 을 배지로 보여줍니다. 클릭하면 편집기의 해당 위치로 이동합니다.
- **패널 크기 조절** — 좌측 패널(회의 정보/구조)과 편집 영역 사이의 **구분자를 드래그**해 폭을 조절할 수 있고(더블클릭 시 기본값), 설정은 유지됩니다.
- **최근 파일 / 폴더 기억** — 열기·저장·내보내기 대화상자는 **마지막으로 사용한 폴더**에서 시작하며, **최근 파일 10개**를 기억합니다. 열기 드롭다운에서 최근 파일을 바로 열거나, **항목별 삭제(×)** 또는 **기록 삭제(전체)** 로 지울 수 있습니다.
- **자동 저장 / 열기** — 작성 중인 회의록은 자동으로 보관되어 재실행 시 복원됩니다. `.mtg`(JSON) 파일로 저장/열기가 가능합니다.

### 내보내기
- **5가지 형식** — Markdown(`.md`), HTML(`.html`), PDF(`.pdf`), Word(`.doc`), 텍스트(`.txt`). 파일 이름은 회의 제목을 기본값으로 제안하며 직접 수정 가능합니다.
- **미디어 내장** — 본문에 넣은 이미지·동영상·오디오가 내보낸 파일 안에 base64/MIME 파트로 **내장**되어 외부 파일 참조 없이 단독으로 열립니다. *(PDF 는 정적이라 영상은 재생 안 됨, Word 의 영상·오디오 재생은 버전에 따라 제한)*
- **표지(Cover) + 목차(Index) 페이지 자동 생성** — 표지 제목·작성자·버전·날짜를 설정할 수 있고, 목차는 본문 앞 별도 페이지로 만들어집니다. **PDF·Word·HTML 목차에 각 항목의 페이지 번호가 우측 정렬로 표시**됩니다(paged.js 페이지네이션으로 실제 페이지 계산).
- **내보내기 서식** — 글꼴·크기는 **툴바** 또는 설정 창에서, 줄 간격·머리글/바닥글 문구·정렬·페이지 번호 표시·위치는 설정 창에서 지정합니다. 툴바에서 바꾼 글꼴·크기는 미리보기·내보내기에 즉시 반영됩니다.

### 사용성
- **설정 창(별도의 이동 가능한 창)** — 언어·테마·내보내기 서식을 2단 레이아웃의 별도 창에서 변경. **설정 초기화** 버튼으로 기본값 복원.
- **12가지 테마** — Dark / Light / White / Midnight / Nord / Forest / Rose / Solarized / Contrast / Ocean / Mocha / Sky. 테마마다 툴바 아이콘이 다르게 표시되며, 툴바 버튼으로 순환할 수 있습니다.
- **시스템 폰트 지원** — 설정에서 시스템에 설치된 모든 글꼴을 선택하고 크기·줄 간격을 조정할 수 있습니다.
- **컨텍스트 메뉴** — 편집·Markdown·구조 영역에서 우클릭 메뉴(아이콘 + 레이블). 편집 메뉴는 실행 취소/다시 실행 · 잘라내기/복사/붙여넣기/전체 선택 · 이미지·미디어 삽입 · 저장/PDF·Word 내보내기를 제공합니다. **Electron 에서는 창 경계에 잘리지 않는 OS 네이티브 메뉴**로 표시되고(실패 시 앱 내 메뉴로 폴백), 웹에서는 앱 내 메뉴로 표시됩니다.
- **아이콘 툴바** — 모든 툴바/메뉴 버튼에 아이콘이 함께 표시되며, 빠른 툴팁을 제공합니다.
- **오류 팝업(복사 가능)** — 오류 발생 시 상세 내용을 팝업으로 보여주며, **내용 복사** 버튼으로 클립보드에 복사해 붙여넣을 수 있습니다.
- **한국어 / 영어(ko/en)** — 지구본 아이콘 버튼으로 전환하며, 선택 상태는 저장됩니다.
- **프로그램 정보** — 제작자(SHKWON · knix008@naver.com), 버전, 플랫폼, **빌드 시각·커밋**, 런타임 정보를 정보 창에서 확인할 수 있습니다.

## 실행 (개발)

```bash
npm install
npm start
```

- `npm start` 는 Vite 개발 서버와 Electron 앱을 함께 띄웁니다(코드 수정이 즉시 반영).
- 웹 버전만 보려면 `npm run web` 후 브라우저에서 `http://localhost:5179` 접속.

## 빌드 / 설치

```bash
npm run build:win     # Windows NSIS 설치 파일(.exe)
npm run build:mac     # macOS DMG
npm run build:linux   # Linux AppImage + deb
npm run build         # 웹 정적 배포본 (dist/)
```

- 설치 파일은 `release/` 에 생성되며, 빌드 후 자동으로 프로젝트 루트에도 복사됩니다.
- **바로가기 선택** — Windows 설치 시 **바탕화면 / 시작 메뉴 바로가기** 생성 여부를 개별 선택할 수 있습니다.
- **완전 재설치** — 이전 버전이 설치되어 있으면 설치 관리자가 **기존 버전을 먼저 완전히 제거**(프로그램 파일·레지스트리·앱 데이터)한 뒤 새로 설치합니다.
- **파일 연결(.mtg)** — 설치 시 `.mtg` 확장자를 등록해 **기본 프로그램**으로 설정합니다. `.mtg` 파일을 더블클릭하면 MyMeeting 이 실행되어 해당 회의록을 엽니다.
- **아이콘** — 앱 아이콘은 `assets/icon.svg`, `.mtg` 파일 아이콘은 `assets/file-icon.svg` 로부터 `npm run generate:icons`(빌드 전 자동 실행)에서 `.ico/.icns/.png`(앱: `icon.*`, 파일: `file.*`)로 생성됩니다.

## 기술 스택

| 영역 | 사용 |
|------|------|
| UI / 번들링 | React 18 + Vite 5 |
| 데스크톱 셸 | Electron 31 (Windows/macOS/Linux) |
| Markdown 렌더링 | marked |
| HTML 살균 | DOMPurify |
| Word(.doc) 변환 | MHT(multipart/related) — Office 네임스페이스 + 이미지·오디오·동영상 파트 |
| PDF 페이지네이션(목차 페이지 번호) | paged.js (메인 프로세스 오프스크린 렌더) |
| 아이콘 래스터화 | sharp |
| 인스톨러 패키징 | electron-builder (NSIS / DMG / AppImage / deb) |

자세한 내용은 [Architecture.md](Architecture.md) 와 [UsersGuide.md](UsersGuide.md) 를 참고하세요.
